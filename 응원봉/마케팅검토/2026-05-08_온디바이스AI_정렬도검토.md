# 응원봉 ↔ onDevice_AI_검증 정렬도 검토 (마케팅 관점)

## 결론 한 줄

> **온디바이스 검증은 "마케팅 자산"으로만 활용하고, 응원봉 본체 펌웨어에 microGPT 4K를 탑재하려는 시도는 멈춰야 한다.** 응원봉 자체 검토서(2026-02-27)가 이미 결론 낸 **"스마트폰 Gemma 2B 하이브리드"**가 정답이고, 본 vault는 그것과는 다른 목적(PR·특허·B2B 영업)을 가진 별도 트랙으로 운영해야 한다.

---

## 1. 두 트랙의 본질적 미스매치

| 항목 | 응원봉 본체 (제품) | onDevice_AI_검증 (현재 진행) |
|---|---|---|
| **킬러 기능** | "다음 곡 뭐야?" "RM 생일 언제야?" — K팝 도메인 응답 | 영문 이름 32,033개 학습 → 가짜 이름 생성 |
| **요구 모델 크기** | 최소 1B~2B params (Gemma 2B 권장) | 4,192 params (microGPT) |
| **권장 위치** | **스마트폰** (newMvp 검토서 결론) | ESP32-S3 SRAM 520KB |
| **응답 품질 요구** | 사용자가 "AI 비서"라 인식할 수준 | 음절 패턴 흉내 수준 |
| **응답 시간** | 3~8초 (스마트폰) | ~50ms/토큰 (보드, 이론) |

### 핵심 미스매치
microGPT 4K는 "name → name" 패턴 생성기. 응원봉 사용자가 기대하는 건 **K팝 지식이 들어간 진짜 비서**. 같은 "AI"란 단어를 쓰지만 **체급이 6~7자릿수 다름** (4K vs 2B).

→ 응원봉 본체에 microGPT 4K를 넣으면 사용자는 "이상한 답변만 나온다"고 느낌 = **사용자 만족 0**, **마케팅은 오히려 마이너스**.

## 2. 마케팅 가치 영역 분리

### 2.1 ✅ 가져갈 마케팅 자산 (high ROI)

| # | 자산 | 마케팅 임팩트 | 비용 |
|---|---|---|---|
| 1 | **PR 콘텐츠** "1만원짜리 칩에 GPT가 돈다 — 한국 첫 시도" | 언론 1~3건 노출 가능, K팝×AI 교차 화제성 | 영상 1편 (3분), 보도자료 1건 |
| 2 | **특허 청구항 보강** "On-Device AI 응원봉" 별도 청구 | AI FanStick 특허 깊이 추가 | 변리사 비용 100~300만 |
| 3 | **Stage 4 영업 1,500만 패키지** 첫 사례 자료 | 한국기계·임베디드 스타트업 영업 무기 | 이미 vault에서 작성됨 |
| 4 | **강사양성 Day 5 사례** + **호오컨설팅·인프런 강의** | 강사 권위 + 1년 누계 200~600만 | 강의 자료 1종 |
| 5 | **데모 1대용 ESP32-S3 응원봉** (전시·미팅용) | 영업 미팅 시 시연 도구 | 보드 1개 + 1주 작업 |

### 2.2 ❌ 버릴 영역 (low ROI / 마이너스)

| # | 진행 중 항목 | 왜 버려야 하나 |
|---|---|---|
| 1 | **양산 응원봉 칩을 ESP32-C3 → ESP32-S3-N16R8로 교체** | +1,500원/대. 5만 대 기준 +7,500만 BOM. 사용자가 인지·지불할 가치 미입증 |
| 2 | **응원봉 본체 펌웨어에 microGPT C++ 포팅 (양산)** | 사용자 입장에서 답변 품질 < 스마트폰 Gemma 2B. 체감 후퇴 |
| 3 | **Korean-Small 154K SLM을 응원봉에 탑재** | 응원봉 본체에 SLM 넣어도 K팝 도메인 응답은 여전히 Gemma 2B에 미달. 비용↑ 가치↓ |
| 4 | **"응원봉 자체 GPT, 외부 인터넷 0%" 카피를 사용자 마케팅에 사용** | 사용자가 실제 써보면 "이게 무슨 GPT야"가 됨. B2B 영업·PR 카피로만 한정해야 안전 |

## 3. 정지선 (Stop Line) — 어디까지 진행할까

```

   ↓

[🔵 Phase 2] ESP32-S3 보드 1대 hello_world  ← 진행 권장 (PR·시연용)
[🔵 Phase 2] microGPT C++ 포팅 (보드 1대) ← 진행 권장 (PR 영상 1편)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
★★★★★ 마케팅 정지선 (STOP) ★★★★★
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[⛔ Phase 3] Korean-Small 154K 한국어 확장      ← 정지
[⛔ Phase 3] 양산 응원봉 칩 교체 (S3-N16R8)     ← 정지
[⛔ Phase 3] 양산 펌웨어에 SLM 통합              ← 정지
```

### 3.1 정지선 근거 (마케팅 비용편익)

- **Phase 2까지** = 데모 1대 + PR 1건 + 영업 자료. 비용 1주, 임팩트 6개월 누계 2,000만+
- **Phase 3 진입** = 양산 BOM·펌웨어 영향. 비용 수개월 + 7,500만 BOM 증가, 임팩트 불명

### 3.2 정지선 재검토 트리거

다음 중 하나라도 발생하면 본 정지선을 재검토:

- [ ] ESP32-S3 가격이 ESP32-C3 수준으로 떨어짐 (BOM 부담 해소)
- [ ] 1B+ 파라미터 모델이 ESP32-S3 SRAM/PSRAM에 탑재 가능해짐 (체급 격차 해소)
- [ ] 응원봉 사용자가 "오프라인 응답"을 강하게 요구 (니즈 입증)
- [ ] 경쟁사가 응원봉 자체 AI 탑재 출시 (선점 압박)

## 4. 응원봉 본체 권장 아키텍처 (변경 없음, 잠금)

### 4.1 검토서(2026-02-27) 결론과 동일

```
[사용자 음성] → [스마트폰 앱]
                    ├─ 온라인: Cloud Gemini (2초, 고품질) ← 95%
                    ├─ 오프라인: 스마트폰 Gemma 2B (5초, 중품질) ← 4%
                    └─ 폴백: 규칙 기반 (즉시) ← 1%
                            ↓ BLE
                    [응원봉 ESP32-C3] ← 명령 수신만 (LED·진동)
```

### 4.2 응원봉 사용자 마케팅 카피

- ❌ "GPT가 내장된 응원봉" (사용자 기대 격차 크면 클레임)
- ✅ **"AI 팬덤 비서가 내 손 안에"** (스마트폰+응원봉 통합 경험)
- ✅ **"오프라인에서도 작동하는 첫 응원봉"** (Gemma 2B 폴백 강조)

## 6. 한 문단 요약

응원봉 프로젝트의 본질은 **"K팝 팬이 손에 들고 다니며 즐기는 AI 경험"**이고, 그 경험은 스마트폰의 Gemma 2B로 이미 충분하다. onDevice_AI_검증은 **"제품의 일부"가 아니라 "회사의 기술 자산·B2B 무기·PR 콘텐츠"**로 위치시키고, 양산 응원봉의 BOM·펌웨어를 건드리는 단계 직전에서 멈추는 것이 마케팅 ROI를 극대화한다. 보드 1대 + 영상 1편 + 영업 자료 1세트까지가 현명한 정지선이다.
