========================================
PPT에 나레이션 음성 삽입하기 (VBA 매크로)
========================================

[준비물]
- ESP32C3_4차시_무지개LED_프레젠테이션.pptx
- audio_files 폴더 (slide1.mp3 ~ slide22.mp3)
- 위 두 파일이 같은 폴더에 있어야 합니다

[실행 순서]

1단계: PPT 파일 열기
   - ESP32C3_4차시_무지개LED_프레젠테이션.pptx를 PowerPoint에서 엽니다

2단계: VBA 편집기 열기
   - Alt + F11 키를 누릅니다
   - VBA 편집기 창이 열립니다

3단계: 매크로 코드 입력
   - 메뉴에서 [삽입] → [모듈] 을 클릭합니다
   - 새로 열린 코드 창에 "오디오삽입_매크로.txt" 파일의 내용을 전체 복사하여 붙여넣기 합니다

4단계: 매크로 실행
   - F5 키를 누르거나
   - 메뉴에서 [실행] → [Sub/사용자 정의 폼 실행] 클릭
   - "InsertAudioToSlides" 선택 후 [실행] 클릭
   - 22개 슬라이드에 오디오가 자동으로 삽입됩니다

5단계: 다른 이름으로 저장
   - Ctrl + Shift + S (다른 이름으로 저장)
   - 파일명: ESP32C3_4차시_무지개LED_프레젠테이션_음성포함.pptx
   - 저장

6단계: 확인
   - F5를 눌러 슬라이드 쇼 시작
   - 각 슬라이드에서 나레이션이 자동으로 재생됩니다!

[문제 해결]
- "매크로를 사용할 수 없습니다" 메시지가 나오면:
  → 파일 → 옵션 → 보안 센터 → 보안 센터 설정
  → 매크로 설정 → "모든 매크로 포함" 선택 → 확인
  → PowerPoint 재시작 후 다시 시도

- audio_files 폴더를 찾을 수 없다는 메시지:
  → PPT 파일과 audio_files 폴더가 같은 폴더에 있는지 확인
