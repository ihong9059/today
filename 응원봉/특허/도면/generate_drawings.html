【도 4】 BLE 명령 프로토콜 구조

【4-1】 명령 프레임 구조

바이트 필드 설명
0 TYPE 명령 유형 (1 문자: C, P, T, B, L, S)
1 DELIM 구분자 (콜론 ':')
2~N PARAMS 파라미터 (가변 길이)
형식: <TYPE>:<PARAMETERS> | 예시: "C:255,100,0"

【4-2】 명령 유형별 상세

TYPE 명령명 파라미터 형식 예시
C Color (색상 변경) R,G,B (각 0-255) "C:255,0,128"
P Pattern (패턴 변경) 패턴명 "P:rainbow"
T Text (텍스트 표시) UTF-8, 최대 32바이트 "T:좋아좋아"
B Buzzer (버저 피드백) 소리 유형 "B:ack"
L Luminance (밝기 조절) 밝기 값 (0-255) "L:200"
S Song Info (곡 정보) 곡제목|색상명 "S:Dynamite|Gold"

【4-3】 응답 프레임 구조

응답 의미
OK 명령 실행 성공
ERR:01 알 수 없는 명령 유형
ERR:02 파라미터 형식 오류
ERR:03 값 범위 초과 (RGB > 255)
ERR:04 명령 실행 실패
