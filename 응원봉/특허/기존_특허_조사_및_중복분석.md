## 1. 조사 개요

AI FanStick 프로젝트의 특허 출원을 위해, 기존 응원봉 통신 관련 특허를 조사하고 당사 기술과의 중복 여부를 분석하였습니다.

### 조사 범위
- 한국 특허 (KIPRIS)
- 미국 특허 (USPTO, Google Patents)
- 유럽 특허

### 조사 키워드
- 응원봉, 라이트스틱, 콘서트 조명
- 무선 LED 제어, BLE 통신
- AI 음성 비서, 웨어러블

#### 기존 특허에 없는 AI FanStick 고유 기술

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI FanStick 핵심 차별점                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 동적 시스템 프롬프트 기반 AI 응답 생성                       │
│     ────────────────────────────────────────                   │
│     - 현재 곡 인덱스, 셋리스트, 멤버정보를 실시간 프롬프트화     │

│     - 기존 특허: 단순 정보 전달 (가사, 큐 전송)                 │
│     - AI FanStick: AI가 실시간 상황 이해 후 답변 생성           │
│                                                                 │
│  2. AI 응답 내 LED 색상 정보 파싱                               │
│     ────────────────────────────────────────                   │

│     - 기존 특허: 중앙 서버에서 직접 제어 신호 전송              │

│                                                                 │

│     ────────────────────────────────────────                   │

│     - 기존 특허 (US11675996): 일반 AI 비서 (콘서트 비특화)      │
```

## 4. 중복 위험 분석

### 4.1 위험도 평가

| AI FanStick 특허 항목 | 기존 특허 중복 위험 | 위험도 | 비고 |
|----------------------|-------------------|--------|------|
| 항목 1: AI 시스템 프롬프트 방식 | 없음 | **낮음** | 기존 특허에 AI 프롬프트 동적 생성 없음 |
| 항목 2: BLE 명령 프로토콜 | KR101730301 (부분) | 중간 | BLE 통신 자체는 유사하나, 명령 구조 차별화 필요 |
| 항목 3: 음성-AI-LED 파이프라인 | US11675996 (부분) | 중간 | 콘서트 특화 + LED 색상 파싱으로 차별화 |
| 항목 4: 상태 기반 자동 동기화 | KR101822968, US9686843 | 높음 | 기존 특허와 기능적 유사성 높음 |
| 항목 5: LED 패턴 애니메이션 | 다수 | 높음 | LED 패턴 제어는 일반적 기술 |

### 4.2 회피 설계 권장사항

#### 중간 위험 항목 대응

**항목 2 (BLE 명령 프로토콜)**
- 기존 특허: 일방향 제어 신호 중심
- 회피 방안: AI 응답 기반 양방향 통신 강조, 프로토콜 확장 (`A:` AI 응답 명령 추가 등)

**항목 3 (음성-AI-LED 파이프라인)**
- 기존 특허 (US11675996): 일반 웨어러블 AI 비서
- 회피 방안: 콘서트 전용 시스템 프롬프트, 셋리스트 연동, 팬챈트 정보 포함 등 도메인 특화 강조

#### 높은 위험 항목 대응

**항목 4 (상태 기반 자동 동기화)**
- 출원 보류 또는 청구항 범위 축소 권장
- AI 응답에 기반한 동기화로 재정의 (중앙 서버 직접 제어가 아닌 AI 결정 기반)

**항목 5 (LED 패턴 애니메이션)**
- 단독 특허보다 다른 항목의 종속항으로 편입 권장
- AI가 패턴을 선택/권장하는 방식으로 청구항 수정

## 5. 결론 및 권장사항

### 5.1 특허 출원 권장 우선순위 (재조정)

| 순위 | 특허 항목 | 중복 위험 | 권장 |
|------|----------|----------|------|
| **1** | 항목 1: AI 시스템 프롬프트 방식 | 낮음 | **적극 출원 권장** |
| **2** | 항목 3: 음성-AI-LED 파이프라인 | 중간 | 도메인 특화 강조 후 출원 |
| 3 | 항목 2: BLE 명령 프로토콜 | 중간 | AI 응답 연동 특징 강조 |
| 4 | 항목 4: 상태 기반 자동 동기화 | 높음 | 청구항 재설계 필요 |
| - | 항목 5: LED 패턴 애니메이션 | 높음 | 단독 출원 비권장 |

### 5.2 청구항 수정 권장안

#### 항목 1 청구항 강화 (핵심 차별점 강조)
기존:
> "로컬 데이터를 기반으로 시스템 프롬프트를 동적으로 생성하는 단계"

수정:
> "콘서트의 현재 곡 인덱스, 셋리스트, 아티스트 멤버 정보, 팬 챈트, 및 응원색 RGB 값을 포함하는 로컬 데이터를 기반으로, 상기 현재 곡에 특화된 문맥 정보를 반영한 시스템 프롬프트를 매 사용자 질문 시마다 동적으로 재생성하는 단계"

#### 항목 3 청구항 강화 (US11675996과 차별화)
기존:
> "AI 응답에서 텍스트 부분과 LED 제어 명령을 분리 파싱하는 단계"

수정:
> "AI 응답에서 자연어 텍스트 부분과 `[LED:R,G,B]` 형식의 LED 색상 제어 명령을 정규식 기반으로 분리 파싱하고, 상기 LED 색상이 현재 곡의 공식 응원색과 상이한 경우 이를 검증하는 단계"

### 5.3 선행 기술 조사 보완 필요

- **KIPRIS 직접 검색**: "팬라이트", "비트로" 출원 특허 상세 확인
- **PCT 국제 출원**: 해외 진출 시 PCT 경로 검토
- **특허 전문가 검토**: 청구항 범위 최적화를 위한 변리사 상담 권장
