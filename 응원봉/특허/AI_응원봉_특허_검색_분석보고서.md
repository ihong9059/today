### 2.3 PixMob 기술 분석

**적용 사례:**
- 2014 Super Bowl XLVIII (8만 픽셀 인간 스크린)
- Coldplay, Taylor Swift, BTS 콘서트

- ❌ 음성 인터페이스 없음
- ❌ 실시간 질의응답 없음
- ⭕ LED 중앙 제어 유사

## 3. 선행 기술 대비 신규성 분석

### 3.1 기존 기술의 한계

```
┌─────────────────────────────────────────────────────────────────┐
│                   기존 응원봉 기술의 한계                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   1. 일방향 통신만 지원                                         │
│      - 중앙 → 응원봉 (LED 제어 신호)                           │
│      - 응원봉 → 중앙 (피드백 없음)                             │
│                                                                  │
│   2. 단순 LED 제어                                              │
│      - 색상 변경, 점멸, 밝기 조절                               │
│      - 사전 프로그래밍된 시퀀스만                               │
│                                                                  │
│   3. 사용자 상호작용 없음                                       │
│      - 질문/응답 불가                                           │
│      - 개인화된 정보 제공 불가                                  │
│                                                                  │
│   4. 콘텐츠 정적                                                 │
│      - 실시간 정보 제공 불가                                    │
│      - 현재 콘서트 상태 반영 불가                               │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 본 발명의 신규성

```
┌─────────────────────────────────────────────────────────────────┐
│                   AI FanStick 핵심 차별점                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ★★★ 핵심 신규성 1: 콘서트 콘텍스트 동적 주입 ★★★           │
│   ─────────────────────────────────────────────                 │
│   • 로컬 JSON DB에서 실시간 콘서트 정보 로드                   │
│   • 현재 곡 인덱스, 셋리스트, 아티스트 정보를                  │
│     시스템 프롬프트로 변환하여 AI API에 전송                   │
│   • AI가 실시간 콘서트 상황 인지 및 정확한 답변 생성          │
│                                                                  │
│   → 기존 특허에서 발견되지 않는 완전히 새로운 접근법!          │
│                                                                  │
│                                                                  │
│   ★★ 핵심 신규성 2: 음성-AI-LED 통합 파이프라인 ★★            │
│   ─────────────────────────────────────────────                 │
│   • 음성 입력 → STT → AI 처리 → TTS + LED 제어               │
│   • 단일 음성 질문으로 정보 제공 + 조명 변경 동시 수행        │
│   • 3초 이내 실시간 응답                                       │
│                                                                  │
│   → 기존 응원봉은 LED 제어만, AI 비서 기능 없음               │
│                                                                  │
│                                                                  │
│   ★ 핵심 신규성 3: AI 응답 기반 자동 LED 색상 추천 ★          │
│   ─────────────────────────────────────────────                 │
│   • AI 응답에 [LED:R,G,B] 형식 포함                           │
│   • 응답 파싱 → BLE 명령 변환 → 응원봉 LED 제어              │
│   • "다음 곡 뭐야?" → "좋아좋아야!" + 파란색 자동 변경        │
│                                                                  │
│   → AI 응답과 LED 제어의 자동 연동은 기존 기술에 없음         │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
