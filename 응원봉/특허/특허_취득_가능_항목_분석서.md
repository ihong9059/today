## 1. 개요

본 문서는 AI FanStick MVP 프로젝트의 기술 구현을 분석하여, 특허 취득이 가능한 핵심 기술 및 방법론을 도출한 것입니다. 코드 분석 및 설계 문서를 기반으로 신규성, 진보성, 산업상 이용가능성을 고려하여 특허 출원 항목을 제안합니다.

---

## 2. 핵심 기술 요약

AI FanStick은 다음과 같은 주요 기술 요소로 구성됩니다:

| 구분 | 기술 요소 | 구현 파일 |
|------|----------|----------|
| 통신 | BLE 5.0 양방향 통신 프로토콜 | `ble_server.h`, `BleManager.kt` |
| AI | 시스템 프롬프트 기반 콘텍스트 주입 | `prompt_generator.py` |
| 제어 | LED 색상/패턴 동기화 | `led_controller.h` |
| 데이터 | 로컬 JSON 기반 콘서트 상태 관리 | `concert_data.json` |
| 앱 | 음성-AI-LED 연동 파이프라인 | `MainViewModel.kt`, `ApiService.kt` |

## 3. 특허 취득 가능 항목

### 3.1 [특허 항목 1] AI 기반 콘서트 정보 안내 시스템 및 방법

#### 발명의 명칭
**"실시간 콘서트 정보를 시스템 프롬프트로 동적 주입하여 AI 응답을 생성하는 스마트 응원봉 시스템 및 방법"**

#### 기술적 특징

```
┌─────────────────────────────────────────────────────────────────┐
│                    핵심 발명 포인트                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   기존 방식: AI가 학습 데이터로만 답변 → 실시간 정보 답변 불가   │
│                                                                 │
│   본 발명:                                                      │
│   1. 로컬 JSON DB에서 콘서트 정보 로드                          │
│   2. 현재 곡 인덱스 + 셋리스트 + 멤버정보를 시스템 프롬프트화   │
│   3. 매 API 호출 시 동적으로 생성된 프롬프트 주입               │
│   4. AI가 실시간 콘서트 상황에 맞는 정확한 답변 생성            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 청구항 초안

1. **독립항 1**: 응원봉 장치와 연동된 스마트폰 애플리케이션에서, (a) 콘서트 셋리스트, 현재 곡 인덱스, 아티스트 정보를 포함하는 로컬 데이터를 로드하는 단계; (b) 상기 로컬 데이터를 기반으로 현재 콘서트 상태를 반영한 시스템 프롬프트를 동적으로 생성하는 단계; (c) 사용자 음성 질문과 상기 시스템 프롬프트를 AI 서버로 전송하는 단계; (d) AI 응답에서 LED 색상 정보를 추출하여 BLE를 통해 응원봉 장치로 전송하는 단계;를 포함하는 AI 기반 콘서트 정보 안내 방법.

2. **종속항 1-1**: 상기 시스템 프롬프트는 현재 곡, 다음 곡, 남은 곡 수, 곡별 응원색 RGB 값, 팬 챈트 정보를 포함하는 것을 특징으로 하는 방법.

3. **종속항 1-2**: 상기 AI 응답에 포함된 LED 색상 정보는 `[LED:R,G,B]` 형식으로 파싱되어 응원봉의 WS2812 LED를 제어하는 것을 특징으로 하는 방법.

#### 신규성/진보성 근거

| 구분 | 설명 |
|------|------|
| 신규성 | 기존 응원봉은 중앙 송신기의 일방향 신호로만 제어됨. AI 비서 기능 탑재 응원봉은 존재하지 않음 |
| 진보성 | 단순 RAG(검색증강생성)이 아닌, 실시간 상태(현재 곡 인덱스)를 프롬프트에 동적 반영하여 문맥인식 AI 응답 생성 |
| 산업 이용가능성 | K-POP 콘서트, 스포츠 경기장 등 대규모 이벤트에 즉시 적용 가능 |

#### 관련 코드
- `prompt_generator.py`: 127-186번 라인 (PromptGenerator.generate 메서드)
- `MainViewModel.kt`: 171-214번 라인 (askAi, handleAiResponse 메서드)

### 3.2 [특허 항목 2] BLE 명령 프로토콜 및 응원봉 제어 시스템

#### 발명의 명칭
**"구조화된 BLE 명령 프로토콜을 이용한 스마트 응원봉 양방향 제어 시스템"**

#### 기술적 특징

```
┌─────────────────────────────────────────────────────────────────┐
│                    BLE 명령 프로토콜 구조                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   명령 형식: <TYPE>:<PARAMETERS>                                │
│                                                                 │
│   ┌──────┬────────────┬─────────────────────────────────┐      │
│   │ Type │ 파라미터    │ 설명                            │      │
│   ├──────┼────────────┼─────────────────────────────────┤      │
│   │  C   │ R,G,B      │ LED 색상 변경 (0-255)           │      │
│   │  P   │ pattern    │ LED 패턴 (rainbow/pulse/blink)  │      │
│   │  T   │ text       │ OLED 텍스트 표시                │      │
│   │  B   │ sound      │ 버저 피드백 (ack/beep/error)    │      │
│   │  L   │ brightness │ 밝기 조절 (0-255)               │      │
│   │  S   │ title|color│ 곡 정보 표시 (제목|색상명)      │      │
│   └──────┴────────────┴─────────────────────────────────┘      │
│                                                                 │
│   응답 형식: OK / ERR:<ERROR_CODE>                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 청구항 초안

1. **독립항 2**: BLE(Bluetooth Low Energy)를 통해 스마트폰과 응원봉 장치 간 양방향 통신을 수행하는 시스템에 있어서, (a) 명령 유형을 나타내는 단일 문자와 콜론(:) 구분자, 그리고 파라미터로 구성된 구조화된 명령 문자열을 정의하는 프로토콜; (b) 상기 명령을 파싱하여 LED 색상, 패턴, 텍스트 표시, 오디오 피드백 중 하나를 실행하는 마이크로컨트롤러; (c) 명령 실행 결과를 OK 또는 에러 코드로 응답하는 양방향 통신 메커니즘;을 포함하는 스마트 응원봉 제어 시스템.

2. **종속항 2-1**: 상기 LED 패턴은 rainbow(무지개), pulse(페이드), blink(깜빡임), wave(파도) 중 하나이며, 각 패턴은 설정된 시간 간격으로 자동 업데이트되는 것을 특징으로 하는 시스템.

3. **종속항 2-2**: 상기 곡 정보 명령(S)은 파이프(|) 구분자로 곡 제목과 색상명을 분리하여 OLED 디스플레이에 표시하는 것을 특징으로 하는 시스템.

#### 관련 코드
- `ble_server.h`: 160-212번 라인 (parseCommand 메서드)
- `BleManager.kt`: 202-257번 라인 (명령 전송 메서드들)

┌─────────────────────────────────────────────────────────────────┐

### 3.4 [특허 항목 4] 콘서트 상태 기반 자동 LED 동기화

#### 발명의 명칭
**"콘서트 셋리스트 진행 상태에 따라 응원봉 LED를 자동 동기화하는 시스템 및 방법"**

#### 기술적 특징

```
┌─────────────────────────────────────────────────────────────────┐
│                    상태 기반 자동 동기화                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   concert_data.json                                             │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  "setlist": [                                            │   │
│   │    {"order": 1, "title": "Dynamite",                    │   │
│   │     "color_rgb": [255, 215, 0], ...},                   │   │
│   │    {"order": 2, "title": "좋아좋아",                     │   │
│   │     "color_rgb": [0, 100, 255], ...},                   │   │
│   │    ...                                                  │   │
│   │  ],                                                      │   │
│   │  "current_state": {"song_index": 0}  ← 상태 추적        │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│   상태 변경 트리거:                                             │
│   1. 사용자 "다음 곡" 버튼 → song_index += 1                   │
│   2. 응원봉 버튼 → BLE 알림 → song_index 변경                 │
│   3. AI 응답 "다음 곡으로" → song_index 변경                  │
│                                                                 │
│   자동 LED 업데이트:                                            │
│   song_index 변경 → 해당 곡의 color_rgb 로드 → BLE 전송       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 청구항 초안

1. **독립항 4**: 복수의 곡과 각 곡에 대응하는 LED 색상 정보를 포함하는 셋리스트 데이터를 저장하고, 현재 곡 인덱스를 추적하는 응원봉 제어 시스템에 있어서, (a) 사용자 입력 또는 AI 응답에 의해 현재 곡 인덱스가 변경되는 것을 감지하는 단계; (b) 변경된 인덱스에 해당하는 곡의 LED 색상 RGB 값을 조회하는 단계; (c) 조회된 RGB 값을 BLE 명령으로 변환하여 응원봉 장치로 전송하는 단계; (d) 응원봉 장치의 LED를 상기 RGB 값으로 자동 변경하는 단계;를 포함하는 콘서트 상태 기반 LED 자동 동기화 방법.

2. **종속항 4-1**: 상기 셋리스트 데이터는 곡별로 응원색 이름, RGB 값, 팬 챈트, 하이라이트 동작을 포함하며, JSON 형식으로 저장되는 것을 특징으로 하는 방법.

#### 관련 코드
- `prompt_generator.py`: 81-109번 라인 (ConcertData 클래스)

### 3.5 [특허 항목 5] LED 패턴 애니메이션 제어

#### 발명의 명칭
**"저전력 마이크로컨트롤러에서 실행되는 응원봉 LED 다중 패턴 애니메이션 제어 방법"**

#### 기술적 특징

| 패턴명 | 알고리즘 | 업데이트 주기 |
|--------|---------|--------------|
| rainbow | 색상 휠(wheel) 함수로 0-255 순환 | 200ms |
| pulse | sin() 함수로 밝기 페이드 인/아웃 | 20ms |
| blink | 색상 ON/OFF 토글 | 500ms |
| wave | sin() 함수로 색상 파동 효과 | 30ms |

#### 청구항 초안

1. **독립항 5**: WS2812 호환 LED가 장착된 응원봉 장치에서, (a) BLE를 통해 패턴 명령을 수신하는 단계; (b) 수신된 패턴 유형에 따라 업데이트 주기와 애니메이션 알고리즘을 선택하는 단계; (c) 메인 루프에서 현재 시간과 마지막 업데이트 시간을 비교하여 패턴 업데이트 여부를 결정하는 단계; (d) 선택된 알고리즘에 따라 LED 색상을 계산하고 출력하는 단계;를 포함하는 LED 패턴 애니메이션 제어 방법.

2. **종속항 5-1**: 상기 rainbow 패턴은 0-255 값을 입력받아 RGB 값을 반환하는 wheel() 함수를 사용하며, 8 단위로 값을 증가시키며 순환하는 것을 특징으로 하는 방법.

3. **종속항 5-2**: 상기 pulse 및 wave 패턴은 sin() 함수를 사용하여 현재 색상의 밝기를 0.0-1.0 범위로 조절하는 것을 특징으로 하는 방법.

#### 관련 코드
- `led_controller.h`: 102-178번 라인 (update 메서드, wheel 함수)
