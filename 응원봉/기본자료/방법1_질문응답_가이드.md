## 1. AI가 답변할 수 있는 범위

### 1.1 핵심 원리

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                  │
│   AI(Gemini)는 "우리가 알려준 정보"만 알고 있습니다!            │
│                                                                  │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │          JSON 파일에 저장된 정보                         │   │
│   │                                                          │   │
│   │  ✅ 셋리스트 (곡 순서, 제목, 응원색)                    │   │
│   │  ✅ 멤버 정보 (이름, 생일, 포지션)                      │   │
│   │  ✅ 팬덤 용어 (보라해, 아미 등)                         │   │
│   │  ✅ 현재 곡 정보                                         │   │
│   │                                                          │   │
│   └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │          시스템 프롬프트에 포함                          │   │
│   │                                                          │   │
│   │  "현재 곡은 Dynamite이고,                               │   │
│   │   다음 곡은 좋아좋아입니다.                             │   │
│   │   진의 생일은 12월 4일입니다..."                        │   │
│   │                                                          │   │
│   └─────────────────────────────────────────────────────────┘   │
│                              │                                   │
│                              ▼                                   │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │          Gemini AI                                       │   │
│   │                                                          │   │
│   │  이 정보를 바탕으로 자연스럽게 답변 생성                 │   │
│   │                                                          │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 답변 가능/불가능 정리

| 구분 | 답변 가능 | 답변 불가능 |
|------|-----------|-------------|
| **셋리스트** | 다음 곡, 현재 곡, 남은 곡 수 | 오늘 갑자기 바뀐 셋리스트 |
| **멤버 정보** | 생일, 본명, 포지션 | 오늘 입은 옷, 현재 위치 |
| **응원법** | 미리 입력된 팬챈트, 응원색 | 즉석에서 만든 응원법 |
| **팬덤 용어** | 미리 정의된 용어 | 신조어, 밈 |
| **일반 상식** | Gemini의 기본 지식 | 최신 뉴스 (실시간) |

## 2. 질문 카테고리별 상세 가이드

### 2.1 셋리스트 관련 질문

#### 가능한 질문들

```
"다음 곡 뭐야?"
"다음 노래 뭐 해?"
"다음에 뭐 나와?"
"지금 곡 뭐야?"
"이 노래 제목이 뭐야?"
"몇 곡 남았어?"
"얼마나 더 해?"
"앵콜 언제야?"
"마지막 곡이 뭐야?"
"첫 곡이 뭐였어?"
```

#### AI 응답 예시

| 질문 | AI 응답 예시 |
|------|-------------|
| "다음 곡 뭐야?" | "다음 곡은 '좋아좋아'야! 파란색으로 바꿔줄게 💙" |
| "몇 곡 남았어?" | "아직 4곡 남았어! 끝까지 힘내자 아미! 🔥 지금은 골드 유지해!" |
| "이 노래 제목이 뭐야?" | "지금 곡은 'Dynamite'야! 영어 가사지만 떼창 가능! 🎤" |
| "마지막 곡이 뭐야?" | "오늘 마지막 곡은 'Butter'야! 노란색으로 마무리할 거야 💛" |

#### 한계점

```
❌ 답변 불가능한 경우:

Q: "오늘 앵콜 몇 곡이야?"
A: "음... 셋리스트에는 앵콜 정보가 없어서 잘 모르겠어 😅
    보통은 2-3곡 하는데, 오늘은 어떨지 기대해보자!"

→ 앵콜 정보가 JSON에 없으면 AI는 "모른다"고 답하거나
  일반적인 정보로 답변함
```

## 4. AI 응답 품질 향상 팁

### 4.1 좋은 질문 vs 애매한 질문

| 좋은 질문 (구체적) | 애매한 질문 (모호) |
|-------------------|-------------------|
| "다음 곡 뭐야?" | "뭐 해?" |
| "진 생일 언제야?" | "진 어때?" |
| "이 곡 응원법 알려줘" | "뭐 해야 해?" |
| "보라해가 뭔 뜻이야?" | "그거 뭐야?" |

### 4.2 AI가 잘 이해하는 질문 패턴

```
[셋리스트]
"다음 곡/노래 + 뭐야/뭐해/알려줘"
"지금 곡/노래 + 뭐야/제목"
"몇 곡 + 남았어/더해"

[멤버]
"[이름] + 생일/본명/포지션 + 뭐야/언제야/알려줘"
"막내/리더/형 + 누구야"

[응원법]
"응원법/응원색/팬챈트 + 알려줘/뭐야"
"떼창 + 언제/어디서"

[용어]
"[용어] + 뭐야/뭔 뜻이야/무슨 의미야"
```

### 4.3 JSON 데이터 품질의 중요성

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                  │
│   AI 응답 품질 = JSON 데이터 품질                               │
│                                                                  │
│   ✅ 좋은 데이터:                                               │
│   {                                                              │
│     "fan_chant": "BTS! BTS! 외치고 0:45에 떼창 시작",           │
│     "key_moments": [                                             │
│       {"time": "0:45", "action": "떼창 'Cause I-I-I'm...'"},    │
│       {"time": "2:30", "action": "점프"}                        │
│     ]                                                            │
│   }                                                              │
│                                                                  │
│   ❌ 나쁜 데이터:                                               │
│   {                                                              │
│     "fan_chant": "팬챈트",                                       │
│     "key_moments": []                                            │
│   }                                                              │
│                                                                  │
│   → 데이터가 상세할수록 AI 답변도 상세해짐!                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 5. 답변 불가능한 경우 처리

### 5.1 AI의 "모른다" 응답 유형

```
Type 1: JSON에 정보 없음
─────────────────────────
Q: "오늘 앵콜 몇 곡이야?"
A: "앵콜 곡 수는 정확히 모르겠어!
    보통은 2-3곡 하니까 기대해봐! 💜"

Type 2: 실시간 정보 요청
─────────────────────────
Q: "지금 무대에 누가 있어?"
A: "지금 무대 상황은 내가 직접 볼 수 없어서 모르겠어!
    눈으로 직접 봐~ 최고의 순간일 거야! ✨"

Type 3: 미래 정보 요청
─────────────────────────
Q: "다음 콘서트 언제야?"
A: "다음 일정은 아직 공개 전인 것 같아!
    공식 채널 확인해봐~ 💜"

Type 4: 외부 정보 요청
─────────────────────────
Q: "인스타 팔로워 몇 명이야?"
A: "정확한 팔로워 수는 내가 실시간으로 확인 못 해!
    직접 인스타 들어가서 봐~ 엄청 많을 거야! 😄"
```

### 5.2 프롬프트에 포함된 "모른다" 규칙

```
시스템 프롬프트에 이 규칙이 포함됨:

## 응답 규칙
...
5. 모르는 정보는 솔직히 "잘 모르겠어"라고 답변해
   - 추측하지 말고 솔직하게
   - 대신 관련된 알고 있는 정보를 알려줘
   - 긍정적인 톤 유지
```

## 6. 응답 시간과 토큰 제한

### 6.1 예상 응답 시간

```
질문 입력 ─────► STT 변환 ─────► Gemini API ─────► TTS 출력
              (0.5~1초)      (1~2초)        (0.5~1초)

총 예상 시간: 2~4초
```

### 6.2 토큰 제한 고려

```
┌─────────────────────────────────────────────────────────────────┐
│  시스템 프롬프트 크기 vs AI 응답 품질                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  프롬프트가 너무 길면:                                          │
│  - API 호출 비용 증가                                           │
```

## 7. 질문-응답 테스트 체크리스트

### 7.1 필수 테스트 항목

```
셋리스트 관련 (5개)
─────────────────────
□ "다음 곡 뭐야?" → 다음 곡 제목 + 응원색 포함
□ "지금 곡 뭐야?" → 현재 곡 제목 포함
□ "몇 곡 남았어?" → 숫자 + 격려 메시지
□ "첫 곡이 뭐였어?" → 첫 곡 제목 포함
□ "마지막 곡이 뭐야?" → 마지막 곡 제목 포함

멤버 관련 (7개 - 각 멤버)
─────────────────────
□ "[멤버] 생일 언제야?" → 생일 날짜 포함
□ "[멤버] 본명 뭐야?" → 본명 포함
□ "막내 누구야?" → 정국 언급
□ "리더 누구야?" → RM 언급

응원법 관련 (3개)
─────────────────────
□ "응원법 알려줘" → 팬챈트 + 동작 포함
□ "응원색 뭐야?" → 색상 이름 + LED 변경 언급
□ "떼창 언제야?" → 시간 정보 포함

팬덤 용어 (3개)
─────────────────────
□ "보라해가 뭐야?" → 의미 + 뷔 언급
□ "아미가 뭐야?" → 팬클럽 설명
□ "떼창이 뭐야?" → 의미 설명

모르는 질문 처리 (2개)
─────────────────────
□ "오늘 뷔 옷 뭐야?" → "모른다" + 긍정적 답변
□ "다음 투어 언제야?" → "모른다" + 대안 제시
```

### 7.2 응답 품질 기준

```
✅ 좋은 응답:
- 질문에 직접 답변
- 1-2문장으로 간결
- 이모지 포함
- LED 색상 언급 (해당되는 경우)
- 친근한 말투

❌ 나쁜 응답:
- 질문과 무관한 답변
- 너무 긴 설명 (3문장 이상)
- 딱딱한 말투
- 정보만 나열
- LED 색상 언급 없음
```

## 9. 요약

### 9.1 AI가 잘 답변하는 질문

```
✅ JSON에 저장된 정보에 대한 질문
✅ 현재 콘서트 진행 상황
✅ 멤버 기본 프로필
✅ 미리 정의된 팬덤 용어
✅ 저장된 응원법/팬챈트
```

### 9.2 AI가 답변하기 어려운 질문

```
❌ 실시간 정보 (지금 누가 무대에 있는지)
❌ 미래 정보 (다음 투어 일정)
❌ JSON에 없는 새로운 용어
❌ 개인적인 질문 (오늘 기분 어때?)
❌ 매우 세부적인 정보 (정확한 떼창 초 단위)
```
