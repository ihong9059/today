## 1. 시스템 개요

### AI FanStick이란?

AI FanStick은 K-POP 콘서트에서 사용하는 **AI 기반 스마트 응원봉** 시스템입니다.

관객이 스마트폰에 대고 "다음 곡 뭐야?"라고 물으면, AI가 셋리스트를 참고하여 응답하고 응원봉의 LED 색상을 자동으로 바꿔줍니다. 콘서트 본부에서는 수천 개의 응원봉을 동시에 제어할 수 있습니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| AI 대화 (음성) | 음성으로 질문하면 AI가 콘서트 정보, 응원법 등을 안내 |
| AI 대화 (텍스트) | 시끄러운 환경에서 문자로 질문 입력 가능 |
| 자동 LED 제어 | 현재 곡에 맞는 응원 색상으로 자동 변경 |
| 본부 연동 | 콘서트 본부에서 전체 응원봉 색상/패턴 동시 제어 |
| 추첨 이벤트 | 관객 중 당첨자 선정 → 당첨 응원봉에 특수 효과 |
| BLE 통신 | 스마트폰과 응원봉(ESP32) 간 저전력 블루투스 연결 |

## 2. 구성 요소

시스템은 **4가지 요소**로 구성됩니다.

```
  [1] 응원봉           [2] 스마트폰 앱       [3] AI 서버          [4] 본부 관제
  (ESP32-C3)          (Android)            (FastAPI)           (WebSocket)
  ┌──────────┐       ┌──────────┐        ┌──────────┐        ┌──────────┐
  │ LED      │ BLE   │ AI       │ HTTP   │ Gemini   │        │ 관리자   │
  │ OLED     │◄─────►│ FanStick │───────►│ API      │        │ 대시보드 │
  │ Buzzer   │       │ App      │ WS     │          │        │          │
  │ Button   │       │          │◄──────►│          │        │          │
  └──────────┘       └──────────┘        └──────────┘        └──────────┘
                                               │                   │
                                               └───── 서버 ────────┘
                                           (100.79.180.64, Tailscale)
```

### 각 요소 상세

| 요소 | 하드웨어/소프트웨어 | 역할 |
|------|---------------------|------|
| 응원봉 | ESP32-C3 SuperMini + WS2812 LED + SSD1306 OLED + Buzzer | 실물 응원봉, BLE로 스마트폰과 연결 |
| 스마트폰 앱 | Android (Kotlin, Jetpack Compose) | 사용자 인터페이스, 음성 입출력, BLE/서버 연결 |
| AI 서버 | Python FastAPI + Gemini AI | 음성 질문 처리, 콘서트 데이터 기반 AI 응답 |
| 본부 관제 | Python FastAPI + WebSocket | 전체 응원봉 실시간 제어, 추첨, 브라우저 대시보드 |

## 4. 서버 설정 및 실행

서버는 `100.79.180.64` 에서 운영됩니다.

### 4.1 SSH 접속

```bash
ssh uttec@100.79.180.64
# 비밀번호: uttec
```

### 4.2 AI 서버 실행 (Port 8081)

AI 질문 처리를 담당하는 서버입니다.

```bash
cd ~/ai_fanstick_server
source venv/bin/activate
python main.py
```

실행 확인:
```bash
curl http://100.79.180.64:8081/
# 응답: {"name":"AI FanStick MVP Server","version":"1.0.0","status":"running"}
```

### 4.3 Control Center 실행 (Port 8091)

본부 관제 WebSocket 서버입니다.

```bash
cd ~/control_center
source venv/bin/activate
python server.py
```

실행 확인:
```bash
curl http://100.79.180.64:8091/api/devices
# 응답: {"total":0,"connected":0,"ble_connected":0,"devices":[]}
```

### 4.4 환경 변수 (.env)

AI 서버에 필요한 API 키 설정:

```
# ~/ai_fanstick_server/.env
OPENAI_API_KEY=sk-...
GEMINI_API_KEY=AI...
AI_PROVIDER=gemini
```

## 5. 응원봉(ESP32) 준비

### 5.1 하드웨어 구성

| 부품 | GPIO | 역할 |
|------|:----:|------|
| WS2812 RGB LED | GPIO 1 | 응원 색상 표시 |
| Buzzer | GPIO 2 | 멜로디/알림음 |
| Button | GPIO 5 | 사용자 입력 |
| OLED SDA | GPIO 6 | I2C 데이터 (SSD1306) |
| OLED SCL | GPIO 7 | I2C 클럭 (SSD1306) |

### 5.2 펌웨어 업로드

```bash
cd 응원봉/mvp/firmware_arduino

# 컴파일
arduino-cli compile --fqbn esp32:esp32:nologo_esp32c3_super_mini FanStick_BLE_KR

# 업로드 (USB 연결 후)
arduino-cli upload -p [포트] --fqbn esp32:esp32:nologo_esp32c3_super_mini FanStick_BLE_KR
```

### 5.3 전원 ON 확인

ESP32에 전원을 넣으면:
1. LED가 짧게 점등 (초기화)
2. OLED에 "AI FanStick" 표시
3. BLE 광고 시작 (스마트폰에서 검색 가능)

## 7. 연결 순서 (Step by Step)

### 전체 과정 요약

```
Step 1          Step 2          Step 3          Step 4
서버 실행   →   앱 실행    →   서버 연결   →   응원봉 연결
(SSH)          (스마트폰)      (자동)         (BLE 스캔)
                                    │              │
                               Step 5          Step 6
                               본부 연결   →   사용 시작!
                               (WebSocket)     (AI 대화)
```

### Step 1: 서버 실행

1. SSH로 서버에 접속
2. AI 서버 실행 (Port 8081)
3. Control Center 실행 (Port 8091)
4. 각각 정상 응답 확인

### Step 2: Tailscale 확인

1. 스마트폰에서 Tailscale 앱 실행
2. VPN 연결 상태 확인 (초록색 아이콘)
3. 100.79.180.64 서버가 목록에 있는지 확인

### Step 3: 앱 실행 및 서버 연결

1. AI FanStick 앱 실행
2. 앱 하단에 **"서버 연결됨"** 표시 확인
3. 연결 안 되면 → Tailscale 상태 확인

### Step 4: 응원봉 BLE 연결

1. ESP32 응원봉 전원 ON
2. 앱에서 **"응원봉 연결"** 버튼 터치
3. BLE 스캔 → 장치 목록에서 선택
4. 연결 성공 시:
   - 앱: "응원봉 연결됨" 표시
   - 응원봉: LED 녹색 점등 + 확인음

### Step 5: 본부 연결

1. 앱에서 **"본부 연결"** 버튼 터치
2. WebSocket으로 Control Center에 연결
3. 연결 성공 시: **"본부 연결됨 (ID: xxxxxxxx)"** 표시
4. 관리자 대시보드(http://100.79.180.64:8091)에서 디바이스 확인

### Step 6: 사용 시작!

모든 연결이 완료되면 AI 대화, LED 제어, 본부 명령 수신이 가능합니다.

## 8. 기능별 사용법

### 8.1 AI 대화 — 두 가지 입력 방식

앱은 **음성 입력**과 **텍스트 입력** 두 가지 방식을 모두 지원합니다.
상황에 따라 편한 방식을 선택하세요.

```
┌─────────────────────────────────────────────────────┐
│                  AI 질문 입력 방식                     │
│                                                     │
│   [텍스트 입력창] [전송]    ← 시끄러운 환경 (공연장)  │
│                                                     │
│        [  마이크  ]         ← 조용한 환경             │
└─────────────────────────────────────────────────────┘
```

#### 방법 A: 음성 입력 (조용한 환경)

1. 앱 하단의 **마이크 버튼** 터치
2. 질문을 말함
3. 버튼에서 손을 뗌
4. AI 응답을 음성으로 들음 + LED 자동 변경

**동작 타임라인:**
```
0.0초    버튼 터치 → 녹음 시작
~1.5초   말하기 완료, 버튼 놓기
~2.0초   STT 변환 (앱: "듣는 중...")
~3.0초   AI 응답 수신 (앱: "생각하는 중...")
~3.5초   TTS 음성 출력 + LED 색상 변경
```

#### 방법 B: 텍스트 입력 (시끄러운 환경)

콘서트장처럼 소음이 큰 환경에서는 음성 인식이 어렵습니다.
이때 **텍스트 입력**을 사용하세요.

1. 마이크 버튼 위의 **텍스트 입력창**에 질문을 타이핑
2. **보라색 전송 버튼** 터치 또는 키보드의 **Send(전송)** 키
3. AI 응답이 화면에 표시 + 음성 출력 + LED 자동 변경

**텍스트 입력의 장점:**
- 소음 환경에서도 정확한 질문 전달
- 한글/영문 모두 가능
- 키보드 Send 키로 빠르게 전송
- 음성 입력과 동일한 AI 응답 + LED 제어

#### 예시 질문과 AI 응답

음성/텍스트 어떤 방식이든 동일한 AI 응답을 받습니다.

| 질문 | AI 응답 | LED 동작 |
|------|---------|----------|
| "다음 곡 뭐야?" | "다음 곡은 '좋아좋아'야! 파란색으로 바꿔줄게!" | 파란색으로 변경 |
| "이 곡 응원법 알려줘" | "후렴구에서 'BTS! BTS!' 외치고 점프!" | 현재 색 유지 |
| "RM 생일 언제야?" | "남준이 생일은 9월 12일이야!" | 현재 색 유지 |
| "보라색으로 바꿔줘" | "알겠어! 보라색으로 바꿔줄게!" | 보라색(128,0,255) |
| "무지개 패턴 보여줘" | "무지개 패턴 시작!" | 무지개 순환 |
| "멤버 알려줘" | "BTS는 RM, 진, 슈가, 제이홉, 지민, 뷔, 정국 7명이야!" | 골드색 |

### 8.2 LED 제어

앱에서 직접 LED를 제어할 수 있습니다.

**색상 변경**: 색상 팔레트에서 원하는 색 선택
**패턴 변경**: 패턴 목록에서 선택

| 패턴 | 설명 |
|------|------|
| solid | 단색 고정 |
| rainbow | 무지개 색상 순환 |
| pulse | 페이드 인/아웃 |
| blink | 깜빡임 |
| wave | 파도 효과 |

### 8.3 곡 진행

셋리스트에 따라 곡을 이동할 수 있습니다.

- **다음 곡**: 앱에서 ▶ 버튼 또는 음성 "다음 곡"
- **이전 곡**: 앱에서 ◀ 버튼 또는 음성 "이전 곡"
- 곡 변경 시 LED 색상이 자동으로 해당 곡의 응원 색으로 변경됩니다.

### 8.4 BLE 명령어 프로토콜

앱에서 ESP32로 전송되는 BLE 명령:

| 명령 | 형식 | 예시 | 설명 |
|------|------|------|------|
| 색상 | `C:R,G,B` | `C:255,0,128` | LED 색상 설정 |
| 패턴 | `P:패턴명` | `P:rainbow` | LED 패턴 |
| 텍스트 | `T:텍스트` | `T:BTS 사랑해` | OLED 표시 |
| 멜로디 | `B:패턴` | `B:dynamite` | 멜로디 재생 |
| 밝기 | `L:값` | `L:128` | 밝기 (0-255) |

## 9. 본부 관제 (Control Center)

### 9.2 대시보드 기능

| 메시지 전송 | 전체 OLED에 표시 | 텍스트 입력 후 전송 |

### 9.3 추첨 이벤트 진행 방법

1. 관객들이 앱에서 "본부 연결" 완료
2. 대시보드에서 연결 수 확인 (예: 150명)
3. 추첨 인원 입력 (예: 5명)
4. "추첨" 버튼 클릭
5. 당첨자 응원봉:
   - LED: 무지개 효과
   - 멜로디: 축하 음악
   - OLED: "축하합니다!"
6. 전체에 당첨 결과 브로드캐스트
7. MC: "응원봉이 반짝이는 분들 무대로 올라오세요!"

### 9.4 API 엔드포인트

## 10. 문제 해결 (Troubleshooting)

### 10.1 서버 연결 실패

| 증상 | 원인 | 해결 |
|------|------|------|
| 앱에서 "서버 연결 실패" | Tailscale VPN 꺼짐 | 스마트폰 Tailscale 앱 실행 및 연결 |
| 서버 ping은 되지만 접속 불가 | 서버 프로세스 중단됨 | SSH 접속 후 서버 재시작 |
| 접속 timeout | VPN 라우팅 문제 | Tailscale 앱 재시작 |

**서버 프로세스 확인:**
```bash
ssh uttec@100.79.180.64
ss -tlnp | grep -E '8081|8091'
```

### 10.2 본부 연결 실패 (WebSocket 404)

| 증상 | 원인 | 해결 |
|------|------|------|
| "expected 101 but was 404" | 다른 서비스가 해당 포트 점유 | 포트 확인 후 Control Center 재시작 |
| "본부 연결 실패: timeout" | Control Center 미실행 | SSH 접속 후 Control Center 시작 |

**확인 방법:**
```bash
# 포트 8091에서 Control Center가 실행 중인지 확인
curl http://100.79.180.64:8091/api/devices
```

### 10.3 BLE 연결 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| 스캔에서 장치가 안 보임 | ESP32 전원 꺼짐 또는 BLE 비활성 | ESP32 리셋, 스마트폰 블루투스 재시작 |
| 연결 후 바로 끊김 | 거리 초과 또는 간섭 | 3m 이내로 접근, 다른 BLE 장치 끄기 |
| LED 명령이 안 먹힘 | Characteristic 찾기 실패 | 앱 재시작 후 재연결 |

### 10.4 음성 인식 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| "음성을 인식하지 못했어요" | 마이크 권한 미허용 | 설정 → 앱 → 권한 → 마이크 허용 |
| 인식률이 낮음 | 주변 소음 | **텍스트 입력으로 전환** 또는 마이크에 가까이 |
| STT 후 서버 오류 | AI API 키 만료 | 서버 .env 파일의 API 키 확인 |

> **Tip:** 공연장처럼 시끄러운 환경에서는 음성 대신 **텍스트 입력**을 사용하세요. 마이크 버튼 위 입력창에 질문을 타이핑하면 됩니다.

### 10.5 앱 설치 실패

| 증상 | 원인 | 해결 |
|------|------|------|
| INSTALL_FAILED_UPDATE_INCOMPATIBLE | 서명 키 불일치 | `adb uninstall com.uttec.fanstick` 후 재설치 |
| USB 디버깅 unauthorized | 디버깅 미승인 | 스마트폰 화면에서 "USB 디버깅 허용" |

## 데이터 흐름 요약

### AI 대화 흐름 (음성/텍스트 공통)

```
사용자(음성) → STT ─┐
                     ├→ 앱 → HTTP POST /api/ask → AI서버 → Gemini API
사용자(텍스트) ─────┘                                          │
                                                               │
사용자(음성) ← TTS ← 앱 ← JSON 응답 (텍스트+LED색상) ←────────┘
                      │
                      └── BLE 명령 → ESP32 → LED 색상 변경
```

### 본부 제어 흐름

```
관리자(브라우저) → Control Center → WebSocket Broadcast → 앱 #1 → BLE → 응원봉 #1
                                                        → 앱 #2 → BLE → 응원봉 #2
                                                        → 앱 #N → BLE → 응원봉 #N
                                                        (동시에 모두 LED 변경)
```

### 추첨 흐름

```
관리자 "5명 추첨" → Control Center → 무작위 5명 선정
                                     ├── 당첨자 → winner 메시지 → LED 무지개 + 축하 멜로디
                                     └── 전체   → lottery_result → 결과 표시
```
