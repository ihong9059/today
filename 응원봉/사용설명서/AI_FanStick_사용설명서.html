01 시스템 개요

AI FanStick은 K-POP 콘서트에서 사용하는 AI 기반 스마트 응원봉 시스템입니다.

관객이 스마트폰에 대고 "다음 곡 뭐야?"라고 물으면, AI가 셋리스트를 참고하여 응답하고 응원봉의 LED 색상을 자동으로 바꿔줍니다. 콘서트 본부에서는 수천 개의 응원봉을 동시에 제어할 수 있습니다.

02 구성 요소

시스템은 4가지 요소로 구성됩니다.

요소구성역할
응원봉ESP32-C3 + WS2812 LED + OLED + Buzzer실물 응원봉, BLE로 스마트폰과 연결
스마트폰 앱Android (Kotlin, Jetpack Compose)사용자 인터페이스, 음성 입출력
AI 서버Python FastAPI + Gemini AI음성 질문 처리, 콘서트 데이터 AI 응답
본부 관제Python FastAPI + WebSocket전체 응원봉 실시간 제어, 추첨

04 서버 설정 및 실행

source venv/bin/activate

source venv/bin/activate

10 문제 해결 (Troubleshooting)

서버 연결 실패

앱에서 "서버 연결 실패"
원인: Tailscale VPN이 꺼져 있음
해결: 스마트폰 Tailscale 앱 실행 → VPN 연결 → 앱 재시작
서버 ping은 되지만 접속 불가
원인: 서버 프로세스가 중단됨
해결: SSH 접속 후 서버 재시작 → ss -tlnp | grep -E '8081|8091' 로 확인

본부 연결 실패

"expected 101 but was 404"
원인: 다른 서비스가 해당 포트를 점유 중
해결: 포트 확인 → Control Center 재시작 → curl http://100.79.180.64:8091/api/devices

BLE 연결 문제

스캔에서 장치가 안 보임
원인: ESP32 전원 꺼짐 또는 BLE 비활성
해결: ESP32 리셋 → 스마트폰 블루투스 재시작 → 3m 이내 접근

음성 인식 문제

음성이 인식되지 않음 / 인식률이 낮음
원인: 주변 소음이 크거나 마이크 권한 미허용
해결: 텍스트 입력으로 전환하세요. 마이크 버튼 위 입력창에 질문을 타이핑하면 동일한 AI 응답을 받을 수 있습니다. 마이크 권한은 설정 → 앱 → 권한에서 허용.

앱 설치 실패

INSTALL_FAILED_UPDATE_INCOMPATIBLE
원인: 서명 키가 다른 APK
해결: adb uninstall com.uttec.fanstick → 재설치
