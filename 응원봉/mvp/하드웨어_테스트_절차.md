## 1. 하드웨어 구성

### 1.1 ESP32-C3 SuperMini GPIO 핀 맵

| 기능 | GPIO | 연결 대상 |
|------|------|----------|
| LED (DIN) | GPIO1 | WS2812 RGB LED |
| Buzzer | GPIO2 | 2.7kHz Buzzer (BCX56 경유) |
| Button | GPIO5 | 택트 스위치 (풀업) |
| I2C SDA | GPIO6 | OLED, AHT20 |
| I2C SCL | GPIO7 | OLED, AHT20 |

## 2. 개발 환경 설정

### 2.1 Arduino CLI 설치 확인

```bash
# Arduino CLI 버전 확인
arduino-cli version

# ESP32 코어 확인
arduino-cli core list | grep esp32
# 결과: esp32:esp32 3.3.3

# 보드 목록 확인
arduino-cli board listall | grep -i supermini
# 결과: Nologo ESP32C3 Super Mini  esp32:esp32:nologo_esp32c3_super_mini
```

### 2.2 필요 라이브러리

```bash
# 라이브러리 설치 (필요시)
arduino-cli lib install "Adafruit NeoPixel"
arduino-cli lib install "Adafruit SSD1306"
arduino-cli lib install "Adafruit GFX Library"

# 설치 확인
arduino-cli lib list | grep -i "neopixel\|ssd1306\|gfx"
```

### 5.3 테스트 명령어

| 명령 | 형식 | 예시 | 설명 |
|------|------|------|------|
| 색상 변경 | C:R,G,B | C:255,0,0 | 빨간색 LED |
| 패턴 | P:패턴명 | P:rainbow | 무지개 패턴 |
| 텍스트 | T:메시지 | T:Hello | OLED 표시 |
| 버저 | B:패턴 | B:ack | 확인음 |
| 밝기 | L:값 | L:128 | 50% 밝기 |

### 5.4 LED 패턴 목록

| 패턴명 | 설명 |
|--------|------|
| solid | 단색 고정 |
| rainbow | 무지개 색상 순환 |
| pulse | 페이드 인/아웃 |
| blink | 깜빡임 |
| wave | 파도 효과 |

### 5.5 버저 패턴 목록

| 패턴명 | 설명 |
|--------|------|
| ack | 확인음 (짧은 비프) |
| beep | 일반 비프 |
| error | 에러음 (3회 비프) |
| success | 성공음 (상승음) |
| connect | 연결음 (2회 비프) |

## 6. 시리얼 모니터 테스트

### 6.1 Arduino IDE 없이 시리얼 모니터

```bash
# screen 사용
screen /dev/cu.usbmodem141101 115200

# 또는 minicom 사용
minicom -D /dev/cu.usbmodem141101 -b 115200
```

### 6.2 명령 입력 테스트

시리얼 모니터에서 직접 명령 입력:
```
C:255,0,0    # 빨간색
P:rainbow   # 무지개
B:success   # 성공음
T:Hello     # OLED 텍스트
```

## 7. 문제 해결

### 7.1 포트가 보이지 않는 경우

1. USB 케이블 확인 (데이터 케이블 필요)
2. ESP32-C3 리셋 버튼 누르기
3. 다른 USB 포트 시도

### 7.2 업로드 실패

1. BOOT 버튼을 누른 상태에서 RESET 누르기
2. BOOT 버튼 놓기
3. 업로드 시도

### 7.3 시리얼 통신 안됨

1. 보드레이트 확인 (115200)
2. 시리얼 포트 점유 확인 (다른 프로그램 종료)
