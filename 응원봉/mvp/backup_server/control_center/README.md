# AI FanStick Control Center
## 콘서트 응원봉 본부 관제 시스템

### 개요

본부 관제 시스템은 콘서트장에서 수천 개의 AI 응원봉을 실시간으로 제어하고,
팬들과 상호작용하며, 추첨 이벤트를 진행할 수 있는 중앙 관리 서버입니다.

## 주요 기능

### 1. 실시간 디바이스 관리
- WebSocket을 통한 실시간 연결 상태 모니터링
- 연결된 응원봉 수 실시간 표시
- 개별 디바이스 정보 확인

### 2. 추첨 시스템
- 연결된 응원봉 중 무작위 추첨
- 1~100명 동시 추첨 가능
- 당첨자에게 자동으로:
  - 당첨 LED 효과 (무지개 패턴)
  - 축하 멜로디 재생
  - 당첨 메시지 표시
  - 진동 알림

### 3. 전체 LED 제어
- 모든 응원봉의 LED 색상 동시 변경
- 패턴 효과: Rainbow, Pulse, Blink
- 실시간 색상 동기화

### 4. 전체 멜로디 재생
- 모든 응원봉에서 동시 멜로디 재생
- 알림, 당첨, Dynamite, ARMY 등

### 5. 메시지 전송
- 모든 응원봉에 메시지 브로드캐스트
- OLED 디스플레이에 텍스트 표시

### 6. 개별 디바이스 제어
- 특정 응원봉에 당첨 효과 전송
- 디버깅 및 테스트용

## 사용 시나리오

### 시나리오 1: 콘서트 시작 전 색상 동기화

1. 관리자가 본부 대시보드 접속 (http://localhost:8090/admin)
2. 관객들이 스마트폰 앱에서 "📡 본부 연결" 버튼 클릭
3. 연결된 디바이스 수가 실시간으로 증가
4. 콘서트 시작 시 관리자가 "Purple" 색상 클릭
5. → 모든 응원봉이 보라색으로 동시 변경

### 시나리오 2: 곡 전환 시 LED 변경

1. "Dynamite" 시작 → 골드(금색) LED로 변경
2. "봄날" 시작 → 핑크 LED로 변경
3. "소우주" 시작 → 보라색 LED + Pulse 효과
4. 앵콜 → Rainbow 패턴 활성화

### 시나리오 3: 추첨 이벤트

**진행 순서:**
1. MC: "지금부터 행운의 추첨을 시작합니다!"
2. 관리자가 추첨 인원 입력 (예: 5명)
3. "🎉 추첨 시작!" 버튼 클릭
4. 시스템이 연결된 응원봉 중 무작위로 5개 선정
5. **당첨자 응원봉에서:**
   - LED가 무지개 패턴으로 변경
   - "축하합니다!" 멜로디 재생
   - 스마트폰에 당첨 메시지 표시
   - 진동 알림
6. MC: "응원봉이 반짝이는 분들, 무대로 올라오세요!"

### 시나리오 4: 실시간 반응 수집

1. 관객이 앱에서 반응 버튼 클릭 (하트, 박수 등)
2. 본부 대시보드 이벤트 로그에 실시간 표시
3. 가장 많은 반응을 보인 구역 확인
4. 해당 구역 추가 이벤트 진행

### 시나리오 5: 긴급 공지

1. 관리자가 메시지 입력: "잠시 후 멤버 무대 이동이 있습니다"
2. "메시지 전송" 버튼 클릭
3. 모든 스마트폰에 알림 팝업 표시
4. 응원봉 OLED에 메시지 표시

## API 명세

### WebSocket 연결
```
ws://localhost:8090/ws/{device_id}
```

**초기 메시지 (클라이언트 → 서버):**
```json
{
  "type": "fan",
  "name": "응원봉 ABC1",
  "platform": "Android"
}
```

**서버 → 클라이언트 메시지 종류:**
```json
// 연결 확인
{"type": "connected", "message": "본부에 연결되었습니다", "device_count": 150}

// 당첨 알림
{"type": "winner", "message": "축하합니다!", "led": {"r": 255, "g": 215, "b": 0, "pattern": "rainbow"}, "melody": "winner"}

// LED 명령
{"type": "led_command", "led": {"r": 128, "g": 0, "b": 128, "pattern": "pulse"}}

// 멜로디 명령
{"type": "melody_command", "melody": "dynamite"}

// 메시지 표시
{"type": "display_message", "message": "BTS 사랑해요!"}

// 추첨 결과 발표
{"type": "lottery_result", "winners": ["fan-****", "fan-****"], "count": 2}
```

### REST API

| Method | Endpoint | 설명 |
|--------|----------|------|
| GET | /api/devices | 연결된 디바이스 목록 |
| POST | /api/lottery | 추첨 실행 |
| POST | /api/broadcast/led | 전체 LED 명령 |
| POST | /api/broadcast/melody | 전체 멜로디 재생 |
| POST | /api/broadcast/message | 전체 메시지 전송 |
| POST | /api/device/{id}/command | 특정 디바이스 명령 |
| GET | /api/winners | 당첨자 목록 |
| DELETE | /api/winners | 당첨자 목록 초기화 |

## 운영 가이드

### 대규모 운영 시 고려사항

1. **서버 인프라**
   - 1,000명 이상: 서버 CPU/메모리 확보
   - 10,000명 이상: 로드 밸런서 + 다중 서버
   - Redis를 사용한 세션 공유

2. **네트워크**
   - 안정적인 Wi-Fi 네트워크 필요
   - 5GHz 대역 권장
   - 공연장 AP 다수 배치

3. **백업 시스템**
   - 서버 장애 시 수동 모드 전환
   - BLE 직접 연결로 기본 기능 유지

### 보안 고려사항

1. 관리자 페이지 접근 제한 (IP 화이트리스트)
2. WebSocket 연결 인증 토큰 추가
3. 추첨 결과 로깅 및 감사 추적

## 문제 해결

### Q: 응원봉이 연결되지 않아요
- 네트워크 연결 확인
- 본부 URL이 올바른지 확인 (ws://...)
- 서버가 실행 중인지 확인

### Q: 추첨이 안 돼요
- 연결된 디바이스가 1개 이상인지 확인
- 브라우저 콘솔 에러 확인

### Q: LED가 변경되지 않아요
- BLE 연결 상태 확인
- ESP32 전원 확인
- 시리얼 모니터로 명령 수신 확인
