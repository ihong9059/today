## 2. 하드웨어 구성 (기존 보드 활용)

### 2.1 ESP32-C3 SuperMini 보드 사양

| 구성요소 | 사양 | GPIO | 역할 |
|----------|------|------|------|
| MCU | ESP32-C3 | - | BLE 5.0, WiFi |
| LED | WS2812 (Neopixel) | GPIO4 (DIN) | RGB 색상 표시 |
| OLED | 128x64 I2C | GPIO5(SDA), GPIO6(SCL) | 상태/메시지 표시 |
| 센서 | AHT20 (온습도) | GPIO5(SDA), GPIO6(SCL) | 환경 데이터 (옵션) |
| Buzzer | 2.7kHz | GPIO3 (SPEAKER) | 오디오 피드백 |
| Button | 택트 스위치 | GPIO2 (SWITCH) | 사용자 입력 |
| TP1-TP8 | 테스트 포인트 | 다수 | 확장/디버깅 |

### 2.2 회로 연결도 (esp32c3_ai_super 기준)

```
ESP32-C3 SuperMini
        │
        ├── GPIO4 ──────── WS2812 LED (DIN)
        │                      └── RGB 색상 출력
        │
        ├── GPIO5 (SDA) ───┬── AHT20 센서 (온습도)
        │                  └── OLED 디스플레이
        ├── GPIO6 (SCL) ───┴── I2C 버스 공유
        │
        ├── GPIO3 ──────── Buzzer (BCX56 트랜지스터 경유)
        │                      └── 2.7kHz 오디오
        │
        ├── GPIO2 ──────── Button (SW1)
        │                      └── 풀업 10K
        │
        └── 5V/GND ──────── 전원
```

### 2.3 MVP에서 사용할 기능

| 기능 | 사용 여부 | 용도 |
|------|----------|------|
| WS2812 LED | ✅ 필수 | AI 응답에 따른 색상 변경 |
| OLED | ✅ 사용 | AI 응답 텍스트 표시 |
| Buzzer | ✅ 사용 | 명령 수신 확인음 |
| Button | ✅ 사용 | 수동 곡 변경, 테스트 |
| AHT20 | ⬜ 미사용 | MVP에서 제외 (Phase 2) |
| BLE | ✅ 필수 | 스마트폰 앱 연동 |

## 5. BLE 통신 프로토콜

### 5.1 명령어 정의

| 명령 | 형식 | 예시 | 설명 |
|------|------|------|------|
| 색상 변경 | `C:R,G,B` | `C:255,0,0` | 빨간색으로 변경 |
| 패턴 실행 | `P:패턴명` | `P:rainbow` | 무지개 패턴 |
| 텍스트 표시 | `T:메시지` | `T:다음곡:좋아좋아` | OLED에 표시 |
| 버저 | `B:패턴` | `B:ack` | 확인음 |
| 밝기 조절 | `L:0-255` | `L:128` | 50% 밝기 |

### 5.2 응답 코드

| 코드 | 의미 |
|------|------|
| `OK` | 명령 성공 |
| `ERR:PARSE` | 명령 파싱 실패 |
| `ERR:RANGE` | 값 범위 초과 |

### 5.3 패턴 목록

| 패턴명 | 설명 |
|--------|------|
| `rainbow` | 무지개 색상 순환 |
| `pulse` | 현재 색상 페이드 인/아웃 |
| `blink` | 깜빡임 |
| `wave` | 파도 효과 |
| `solid` | 단색 고정 (기본) |

## 7. 서버 설정

### 7.1 로컬 서버 실행 방법

```bash
# 1. 가상환경 생성
cd 응원봉/mvp/server
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 환경변수 설정 (.env 파일)
echo "GEMINI_API_KEY=your_api_key_here" > .env

# 4. 서버 실행
uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```
