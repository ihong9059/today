## 시나리오 1: 초기 설정 및 연결

### 1.1 서버 시작

**목표:** 로컬 서버가 정상 실행되고 API가 응답함

```
[액션]
1. 터미널에서 서버 디렉토리로 이동
2. 서버 실행: uvicorn main:app --host 0.0.0.0 --port 8080
3. 브라우저에서 http://localhost:8080/docs 접속

[예상 결과]
✅ FastAPI Swagger 문서 페이지 표시
✅ 서버 로그에 "Uvicorn running on http://0.0.0.0:8080" 출력
```

### 1.2 앱-서버 연결

**목표:** 스마트폰 앱이 로컬 서버에 연결됨

```
[사전조건]
- 스마트폰과 PC가 같은 WiFi 네트워크에 연결
- PC의 로컬 IP 확인 (예: 192.168.1.100)

[액션]
1. AI FanStick 앱 실행
2. 설정 → 서버 주소 입력: http://192.168.1.100:8080
3. "연결 테스트" 버튼 터치

[예상 결과]
✅ "서버 연결 성공" 메시지 표시
✅ 콘서트 정보 (BTS, 셋리스트) 표시
```

### 1.3 BLE 응원봉 연결

**목표:** 스마트폰과 응원봉(ESP32)이 BLE로 연결됨

```
[사전조건]
- ESP32에 펌웨어 업로드 완료
- ESP32 전원 ON (LED 초기화 패턴 표시)

[액션]
1. 앱에서 "응원봉 연결" 버튼 터치
2. BLE 스캔 시작
3. "AI FanStick" 장치 선택
4. 연결 대기

[예상 결과]
✅ 앱: "응원봉 연결됨" 표시
✅ 응원봉: LED 녹색 점등 (연결 확인)
✅ 응원봉: OLED에 "Connected" 표시
✅ 응원봉: Buzzer 짧게 "삐" (확인음)
```

## 시나리오 2: 기본 AI 대화

### 2.1 "다음 곡 뭐야?" 질문

**목표:** AI가 셋리스트를 참고하여 다음 곡 정보를 정확히 안내

```
[사전조건]
- 현재 곡: 1번 Dynamite (기본 상태)

[액션]
1. 앱에서 🎤 버튼 길게 누름
2. "다음 곡 뭐야?" 말함
3. 버튼에서 손 뗌

[예상 동작 타임라인]
┌──────────────────────────────────────────────────────────────┐
│ 0.0초  │ 버튼 터치 → 녹음 시작                              │
│ 0.0-1.5초 │ 사용자: "다음 곡 뭐야?"                         │
│ 1.5초  │ 버튼 릴리스 → 녹음 종료                            │
│ 1.5-2.0초 │ STT 변환 중 (앱: "듣는 중...")                  │
│ 2.0-3.0초 │ AI 처리 중 (앱: "생각하는 중...")               │
│ 3.0초  │ 응답 수신                                          │
│ 3.0-3.5초 │ TTS 출력 + LED 변경 명령 전송                   │
│ 3.5초  │ 응원봉 LED 파란색으로 변경                         │
└──────────────────────────────────────────────────────────────┘

[예상 AI 응답]
"다음 곡은 '좋아좋아'야! 파란색으로 바꿔줄게! 💙"

[예상 결과]
✅ 앱: AI 응답 텍스트 표시
✅ 앱: TTS로 음성 출력
✅ 응원봉: LED 파란색 (RGB: 0, 0, 255)
✅ 응원봉: OLED "다음곡: 좋아좋아" 표시
✅ 응원봉: Buzzer 확인음
```

### 2.2 "이 곡 응원법 알려줘" 질문

**목표:** AI가 현재 곡의 응원법과 팬챈트를 안내

```
[사전조건]
- 현재 곡: 1번 Dynamite

[액션]
1. 🎤 버튼 누르고 "이 곡 응원법 알려줘" 말함

[예상 AI 응답]
"Dynamite 응원법! 후렴구에서 'BTS! BTS!' 외치고
점프해! 골드색 유지해줄게! ✨"

[예상 결과]
✅ 앱: 응원법 안내 표시 및 음성 출력
✅ 응원봉: LED 골드색 유지 (255, 215, 0)
✅ 응원봉: OLED "응원법: 점프!" 표시
```

### 2.3 "RM 생일 언제야?" 질문

**목표:** AI가 멤버 정보를 참고하여 정확한 생일 안내

```
[액션]
1. 🎤 버튼 누르고 "RM 생일 언제야?" 말함

[예상 AI 응답]
"남준이 생일? 9월 12일이야! 🐨
지금 색상 유지할게!"

[예상 결과]
✅ 앱: 멤버 정보 표시
✅ 응원봉: LED 색상 유지 (현재 색)
```

### 2.4 "보라해가 뭐야?" 질문

**목표:** AI가 팬덤 용어를 설명

```

1. 🎤 버튼 누르고 "보라해가 뭐야?" 말함

[예상 AI 응답]
"보라해는 '보라색처럼 영원히 사랑한다'는 뜻이야! 💜

[예상 결과]
```

## 시나리오 3: 곡 진행 시뮬레이션

### 3.1 다음 곡으로 이동

**목표:** 현재 곡 인덱스가 변경되고 AI가 새 상태를 인식

```
[액션 - 방법 A: 앱에서 변경]
1. 앱에서 "다음 곡 ▶" 버튼 터치

[액션 - 방법 B: 응원봉 버튼]
1. 응원봉의 버튼 짧게 누름 (다음 곡)

[예상 동작]
1. 서버에 POST /api/song/next 요청
2. current_song_index: 0 → 1
3. 앱에 상태 업데이트

[예상 결과]
✅ 앱: 현재 곡 "좋아좋아" 표시
✅ 응원봉: LED 자동으로 파란색 변경
✅ 응원봉: OLED "Now: 좋아좋아" 표시
```

### 3.2 곡 변경 후 "다음 곡 뭐야?" 질문

**목표:** AI가 변경된 상태를 인식하여 정확한 다음 곡 안내

```
[사전조건]
- 현재 곡: 2번 좋아좋아 (방금 변경됨)

[액션]
1. 🎤 버튼 누르고 "다음 곡 뭐야?" 말함

[예상 AI 응답]
"다음은 '봄날'이야! 🌸
분홍색으로 바꿔줄게!"

[예상 결과]
✅ AI가 셋리스트 3번 "봄날"을 정확히 안내
✅ 응원봉: LED 분홍색 (255, 182, 193)
```

### 3.3 마지막 곡에서 "다음 곡 뭐야?" 질문

**목표:** AI가 마지막 곡임을 인식하여 적절히 안내

```
[액션]
1. 🎤 버튼 누르고 "다음 곡 뭐야?" 말함

[예상 AI 응답]

[예상 결과]
```

## 시나리오 7: 성능 측정

### 7.1 응답 시간 측정

**목표:** 전체 플로우 3초 이내 완료

| 구간 | 목표 시간 | 측정 방법 |
|------|----------|----------|
| 녹음 종료 → STT 완료 | < 1.0초 | 앱 로그 |
| STT 완료 → AI 응답 | < 1.5초 | 서버 로그 |
| AI 응답 → LED 변경 | < 0.5초 | BLE 전송 |
| **총 응답 시간** | **< 3.0초** | 타이머 측정 |

### 7.2 연속 사용 테스트

**목표:** 1시간 연속 사용 시 안정성

```
[테스트 방법]
1. 30초마다 질문 (총 120회)
2. LED 색상 변경 확인
3. 에러 발생 횟수 기록

[합격 기준]
✅ 에러율 < 5% (6회 미만)
✅ BLE 연결 유지
✅ 배터리 50% 이상 유지 (500mAh 기준)
```

### 7.3 음성 인식 정확도

**목표:** 한국어 인식률 90% 이상

```
[테스트 문장 - 10개]
1. "다음 곡 뭐야"
2. "이 곡 응원법 알려줘"
3. "RM 생일 언제야"
4. "보라해가 뭐야"
5. "파란색으로 바꿔줘"
6. "남은 곡 몇 개야"
7. "지금 몇 번째 곡이야"
8. "진 오빠 포지션 뭐야"
9. "아미밤 무슨 색이야"
10. "셋리스트 다 알려줘"

[합격 기준]
✅ 9개 이상 정확히 인식 (90%)
```
