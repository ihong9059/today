## 1. 사업 개요

### 1.1 비전

**"스마트 팩토리의 핵심 통신 인프라를 제공하는 EtherCAT 전문 기업"**

### 1.2 미션

- 고성능, 저비용 EtherCAT Slave Controller 개발
- EtherCAT-CAN FD 브릿지 솔루션으로 레거시 시스템 통합
- 국내 제조업체의 스마트 팩토리 전환 지원

### 1.3 사업 목표

| 구분 | 1차년도 | 2차년도 | 3차년도 |
|------|---------|---------|---------|
| 매출 | 5억원 | 15억원 | 40억원 |
| 제품 출시 | 2개 모델 | 4개 모델 | 8개 모델 |
| 고객사 | 10개사 | 30개사 | 100개사 |

## 2. 제품 라인업

### 2.1 Model A: EtherCAT Slave Controller

**제품명**: UTTEC-ESC-100

| 항목 | 사양 |
|------|------|
| MCU | STM32H755 (Dual Core Cortex-M7/M4) |
| EtherCAT | Beckhoff ET1100 또는 LAN9252 |
| I/O | Digital 16ch, Analog 8ch, PWM 4ch |
| 통신 속도 | 100Mbps |
| 사이클 타임 | 125μs ~ 1ms |
| 전원 | DC 24V |
| 크기 | 100mm x 80mm x 30mm |

**용도**:
- 산업용 모터 드라이버 제어
- 센서 데이터 수집
- I/O 확장 모듈
- 로봇 관절 제어

**예상 판매가**: 150,000원 ~ 250,000원

### 2.2 Model B: EtherCAT to CAN-FD Gateway

**제품명**: UTTEC-ECG-200

| 항목 | 사양 |
|------|------|
| MCU | STM32H743 (Cortex-M7 480MHz) |
| EtherCAT | LAN9252 (Slave) |
| CAN-FD | 2채널 (최대 8Mbps) |
| 프로토콜 변환 | CoE ↔ CANopen |
| 버퍼 | 1024 프레임 |
| 전원 | DC 24V |
| 크기 | 120mm x 90mm x 35mm |

**용도**:
- 기존 CAN 장비의 EtherCAT 네트워크 통합
- 자동차 생산라인 연동
- 레거시 시스템 마이그레이션
- 멀티 프로토콜 환경 구축

**예상 판매가**: 300,000원 ~ 450,000원

## 3. 시장 분석

### 3.1 글로벌 시장 규모

| 연도 | 시장 규모 | 성장률 |
|------|----------|--------|
| 2024 | 45억 달러 | - |
| 2025 | 52억 달러 | 15.5% |
| 2026 | 60억 달러 | 15.4% |
| 2030 | 120억 달러 | 19.0% (CAGR) |

### 3.2 국내 시장 현황

- 스마트 팩토리 보급률: 30% (중소기업 기준)
- 정부 지원: 스마트 제조 혁신 2030 정책
- 주요 수요처: 자동차, 반도체, 디스플레이, 2차전지

### 3.3 경쟁사 분석

| 회사 | 제품 | 가격대 | 강점 | 약점 |
|------|------|--------|------|------|
| Beckhoff | EK1100 | 50만원+ | 시장 점유율 1위 | 고가격 |
| Hilscher | netX | 40만원+ | 멀티프로토콜 | 복잡한 개발 |
| Microchip | LAN9252 | 칩셋만 | 저가 칩셋 | 완제품 없음 |
| **UTTEC** | ESC-100 | 15~25만원 | 가격 경쟁력, 기술지원 | 브랜드 인지도 |

### 3.4 타겟 고객

**1차 타겟 (국내)**:
- 중소 자동화 장비 제조사
- SI 업체 (스마트 팩토리 구축)
- 로봇 스타트업
- 대학/연구소

**2차 타겟 (해외)**:
- 중국 자동화 장비 업체
- 동남아 제조업체
- OEM 고객

## 4. 기술 경쟁력

### 4.1 핵심 기술

| 기술 | 설명 | 수준 |
|------|------|------|
| EtherCAT Slave Stack | SOES 기반 최적화 스택 | 자체 개발 |
| CoE (CANopen over EtherCAT) | 객체 딕셔너리 구현 | 완료 |
| DC (Distributed Clock) | 동기화 정밀도 1μs 이하 | 개발 중 |
| CAN-FD 드라이버 | 8Mbps 고속 통신 | 완료 |
| 프로토콜 변환 엔진 | EtherCAT ↔ CAN-FD 실시간 변환 | 개발 중 |

## 10. 결론

### 10.1 사업 타당성

- **시장 기회**: 스마트 팩토리 확대로 EtherCAT 수요 급증
- **기술 경쟁력**: 40년 임베디드 경험 보유
- **가격 경쟁력**: 해외 제품 대비 50% 이상 저렴
- **차별화**: 국내 기술 지원, 커스터마이징 가능

### 10.2 성공 요인

1. **빠른 시장 진입**: 2026년 내 제품 출시
2. **파일럿 고객 확보**: 초기 레퍼런스 구축
3. **인증 획득**: EtherCAT 로고 인증으로 신뢰성 확보
4. **지속적 R&D**: 제품 라인업 확장

### 10.3 기대 효과

- 국내 EtherCAT 생태계 활성화
- 중소기업 스마트 팩토리 도입 비용 절감
- 글로벌 산업용 통신 시장 진출 기반 마련
