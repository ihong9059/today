# Model B: EtherCAT to CAN-FD Gateway 구조 설명서

**제품명**: UTTEC-ECG-200
**버전**: 1.0
**작성일**: 2026-02-15

---

## 1. 제품 개요

### 1.1 제품 설명

UTTEC-ECG-200은 EtherCAT 네트워크와 CAN-FD 네트워크를 연결하는 산업용 게이트웨이입니다. EtherCAT Master로부터 받은 데이터를 CAN-FD 프로토콜로 변환하여 기존 CAN 장비와 통합합니다.

### 1.2 주요 특징

- EtherCAT Slave로 동작
- CAN-FD 2채널 지원 (최대 8Mbps)
- CoE ↔ CANopen 프로토콜 자동 변환
- 1024 프레임 버퍼
- 실시간 프로토콜 매핑

### 1.3 적용 분야

- 자동차 생산라인 (EtherCAT PLC ↔ CAN 로봇)
- 레거시 CAN 장비 통합
- 멀티 프로토콜 환경 구축
- 테스트 벤치 시스템
