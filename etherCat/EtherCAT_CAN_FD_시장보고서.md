### 3.3 CAN FD 성장 동력

| 동력 | 설명 |
|------|------|
| **전기차/하이브리드 성장** | 배터리 관리, 충전 인프라 통신 필요 |
| **ADAS 확대** | 센서 데이터 대용량 전송 요구 |
| **ECU 증가** | 차량당 100개+ ECU 탑재 |
| **OTA 업데이트** | 빠른 소프트웨어 업데이트 필요 |
| **기존 인프라 활용** | CAN 2.0과 하위 호환성 |
