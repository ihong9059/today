## 1. EtherCAT 개요

### 1.1 EtherCAT이란?

EtherCAT (Ethernet for Control Automation Technology)은 Beckhoff Automation에서 개발한 산업용 실시간 이더넷 프로토콜입니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         EtherCAT 네트워크 구조                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│    ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐        │
│    │  Master  │────▶│  Slave 1 │────▶│  Slave 2 │────▶│  Slave N │        │
│    │   (PLC)  │◀────│ (서보)   │◀────│  (I/O)   │◀────│ (센서)   │        │
│    └──────────┘     └──────────┘     └──────────┘     └──────────┘        │
│         │                                                    │             │
│         └────────────────────────────────────────────────────┘             │
│                          (데이지 체인 토폴로지)                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 핵심 특징

| 특징 | 설명 |
|------|------|
| **고속 통신** | 100Mbps 풀 듀플렉스 |
| **저지연** | 사이클 타임 <100μs 가능 |
| **정밀 동기화** | 분산 클럭(DC)으로 <1μs 동기화 |
| **유연한 토폴로지** | 라인, 트리, 스타 구조 지원 |
| **표준 이더넷** | 표준 이더넷 케이블/커넥터 사용 |

### 1.3 동작 원리: "On the Fly" 처리

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      EtherCAT 프레임 처리 방식                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   기존 이더넷:                                                              │
│   ┌────────┐    ┌────────┐    ┌────────┐                                   │
│   │ Master │───▶│ Switch │───▶│ Slave  │  각 노드에서 프레임 수신/처리/송신│
│   └────────┘    └────────┘    └────────┘  → 지연 발생                      │
│                                                                             │
│   EtherCAT:                                                                 │
│   ┌────────┐    ┌────────┐    ┌────────┐                                   │
│   │ Master │═══▶│ Slave  │═══▶│ Slave  │  프레임이 통과하면서 데이터 처리  │
│   └────────┘    └────────┘    └────────┘  → 지연 최소화 (나노초 단위)      │
│                                                                             │
│   * Slave는 프레임을 "저장 후 전달"하지 않고 "통과하면서 처리"              │
│   * 각 Slave 통과 지연: ~1μs 이하                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. EtherCAT Master

### 2.1 Master의 역할

EtherCAT Master는 네트워크의 **유일한 능동적 참여자**로서 모든 통신을 제어합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         EtherCAT Master 역할                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                        Master Controller                            │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │                                                                     │  │
│   │   1. 네트워크 초기화 및 구성                                        │  │
│   │      • Slave 스캔 및 식별                                           │  │
│   │      • 주소 할당                                                    │  │
│   │      • ESI/XML 파일 기반 설정                                       │  │
│   │                                                                     │  │
│   │   2. 주기적 데이터 교환 (Process Data)                              │  │
│   │      • 프레임 생성 및 송신                                          │  │
│   │      • Slave 데이터 수집/배포                                       │  │
│   │      • 사이클 타임 관리                                             │  │
│   │                                                                     │  │
│   │   3. 비주기적 통신 (Mailbox)                                        │  │
│   │      • CoE (CANopen over EtherCAT)                                  │  │
│   │      • SDO 읽기/쓰기                                                │  │
│   │      • 파라미터 설정                                                │  │
│   │                                                                     │  │
│   │   4. 분산 클럭 동기화 (DC)                                          │  │
│   │      • 기준 클럭 선정                                               │  │
│   │      • 시간 오프셋 계산                                             │  │
│   │      • 동기 신호 관리                                               │  │
│   │                                                                     │  │
│   │   5. 진단 및 오류 처리                                              │  │
│   │      • 통신 상태 모니터링                                           │  │
│   │      • 오류 감지 및 복구                                            │  │
│   │      • 로그 기록                                                    │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 Master 상태 머신 (ESM - EtherCAT State Machine)

Master는 Slave들의 상태를 관리합니다:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        EtherCAT 상태 머신 (ESM)                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│                              ┌─────────┐                                    │
│                              │  INIT   │ ← 전원 ON, 기본 초기화             │
│                              └────┬────┘                                    │
│                                   │                                         │
│                                   ▼                                         │
│                              ┌─────────┐                                    │
│                              │ PRE-OP  │ ← Mailbox 통신 가능               │
│                              └────┬────┘   파라미터 설정                    │
│                                   │                                         │
│                                   ▼                                         │
│                              ┌─────────┐                                    │
│                              │ SAFE-OP │ ← 입력 데이터 유효                 │
│                              └────┬────┘   출력은 안전 상태                 │
│                                   │                                         │
│                                   ▼                                         │
│                              ┌─────────┐                                    │
│                              │   OP    │ ← 정상 동작                        │
│                              └─────────┘   입출력 모두 활성                 │
│                                                                             │
│   상태 전이 조건:                                                           │
│   • INIT → PRE-OP: Mailbox 설정 완료                                       │
│   • PRE-OP → SAFE-OP: SM/FMMU 설정, DC 동기화                              │
│   • SAFE-OP → OP: 모든 Slave 준비 완료                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 Master 하드웨어 요구사항

| 구성요소 | 최소 요구사항 | 권장 사양 |
|----------|--------------|-----------|
| **CPU** | ARM Cortex-A7 이상 | x86 멀티코어, ARM Cortex-A53+ |
| **RAM** | 256MB | 1GB 이상 |
| **이더넷** | 100Mbps NIC | 기가비트 NIC (실시간 패치) |
| **OS** | Linux (RT-PREEMPT) | Xenomai, RTAI, 또는 전용 RTOS |
| **저장장치** | 4GB | 16GB 이상 (로그 저장용) |

## 3. EtherCAT Slave

### 3.1 Slave의 역할

EtherCAT Slave는 네트워크의 **수동적 참여자**로서 Master의 명령에 응답합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          EtherCAT Slave 역할                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                         Slave Device                                │  │
│   ├─────────────────────────────────────────────────────────────────────┤  │
│   │                                                                     │  │
│   │   1. 프레임 처리 (On-the-fly)                                       │  │
│   │      • 해당 데이터 추출/삽입                                        │  │
│   │      • 프레임 다음 노드로 전달                                      │  │
│   │      • 하드웨어 기반 실시간 처리                                    │  │
│   │                                                                     │  │
│   │   2. 프로세스 데이터 교환                                           │  │
│   │      • 입력: 센서값, 상태 정보 제공                                 │  │
│   │      • 출력: 명령값, 설정값 수신                                    │  │
│   │                                                                     │  │
│   │   3. 파라미터 관리 (Object Dictionary)                              │  │
│   │      • CoE/SDO 통한 설정 변경                                       │  │
│   │      • 디바이스 프로파일 지원                                       │  │
│   │                                                                     │  │
│   │   4. 분산 클럭 동기화                                               │  │
│   │      • 로컬 클럭 유지                                               │  │
│   │      • Master 클럭과 동기화                                         │  │
│   │      • SYNC 신호 생성                                               │  │
│   │                                                                     │  │
│   │   5. 로컬 애플리케이션 실행                                         │  │
│   │      • 모터 제어 루프                                               │  │
│   │      • I/O 처리                                                     │  │
│   │      • 안전 기능                                                    │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```

### 3.5 Slave 디바이스 프로파일

EtherCAT은 CANopen 기반의 디바이스 프로파일을 사용합니다:

| 프로파일 | 코드 | 적용 장치 |
|----------|------|-----------|
| **CiA 402** | DS402 | 서보 드라이브, 스테퍼 |
| **CiA 401** | DS401 | 디지털/아날로그 I/O |
| **CiA 406** | DS406 | 엔코더 |
| **CiA 410** | DS410 | 인클리노미터 |

## 4. Master-Slave 통신 구조

### 4.1 EtherCAT 프레임 구조

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       EtherCAT 프레임 구조                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                    Ethernet Frame                                   │  │
│   ├───────┬───────┬───────┬─────────────────────────────────┬─────────┤  │

## 6. 소프트웨어 스택

### 6.1 Master 소프트웨어 개발

```c
/* SOEM (Simple Open EtherCAT Master) 예제 */

#include "ethercat.h"

char IOmap[4096];
int expectedWKC;

int main(int argc, char *argv[])
{
    /* 1. 네트워크 인터페이스 초기화 */
    if (ec_init("eth0") > 0)
    {
        printf("EtherCAT 초기화 성공\n");

        /* 2. Slave 스캔 및 설정 */
        if (ec_config_init(FALSE) > 0)
        {
            printf("%d개의 Slave 발견\n", ec_slavecount);

            /* 3. PDO 매핑 및 DC 설정 */
            ec_config_map(&IOmap);
            ec_configdc();

            /* 4. 상태 전이: SAFE-OP → OP */
            ec_slave[0].state = EC_STATE_OPERATIONAL;
            ec_writestate(0);

            /* 5. 실시간 루프 */
            while(1)
            {
                /* PDO 교환 */
                ec_send_processdata();
                expectedWKC = ec_receive_processdata(EC_TIMEOUTRET);

                if (expectedWKC >= ec_group[0].expectedWKC)
                {
                    /* 입력 데이터 처리 */
                    process_inputs(IOmap);

                    /* 출력 데이터 설정 */
                    set_outputs(IOmap);
                }

                /* 사이클 타임 대기 (예: 1ms) */
                osal_usleep(1000);
            }
        }
    }

    ec_close();
    return 0;
}
```
