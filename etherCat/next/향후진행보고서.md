# EtherCAT 시뮬레이션 프로젝트 진행 보고서

## 1. 프로젝트 개요

### 1.1 목적
실제 EtherCAT 하드웨어(ESC 칩) 없이 소프트웨어만으로 EtherCAT Master-Slave 통신을 시뮬레이션하여 프로토콜 학습 및 개발 환경 구축

### 1.2 시스템 구성
```
┌─────────────────────┐         Ethernet Cable         ┌─────────────────────┐
│   Windows PC        │◄──────────────────────────────►│    Ubuntu PC        │
│   (Master)          │                                 │    (Slave Emulator) │
│                     │                                 │                     │
│ - Intel I219-V NIC  │         EtherCAT 0x88A4        │ - USB Ethernet      │
│ - Scapy 기반 Master │◄──────────────────────────────►│ - Scapy 기반 Slave  │
│ - Python 3.14       │                                 │ - Python 3          │
└─────────────────────┘                                 └─────────────────────┘
```

#### 개발된 파일
| 파일명 | 경로 | 설명 |
|--------|------|------|
| `ethercat_slave_emulator.py` | `~/uttec/` | **최종 Slave 에뮬레이터** (v12, LRW/PDO 지원) |

#### Ubuntu Slave Emulator의 역할
1. **가상 Slave 시뮬레이션**: 3개의 Beckhoff 호환 Slave 장치 에뮬레이션
   - EK1100 (EtherCAT Coupler)
   - EL1008 (8채널 디지털 입력)
   - EL2008 (8채널 디지털 출력)

2. **EtherCAT 명령어 처리**:
   - APRD/APWR/APRW: Auto-increment 주소 기반 읽기/쓰기
   - BRD/BWR/BRW: Broadcast 읽기/쓰기
   - FPRD/FPWR/FPRW: Configured 주소 기반 읽기/쓰기
   - LRD/LWR/LRW: 논리 주소 기반 PDO 통신

3. **상태 관리**: AL Status 레지스터를 통한 상태 전이 지원
   - INIT (0x01) → PRE-OP (0x02) → SAFE-OP (0x04) → OP (0x08)

## 3. 구현된 기능 상세

### 3.1 EtherCAT Master (`ethercat_master.py`)

#### 주요 클래스 및 메서드

```python
class EtherCATMaster:
    # 초기화
    def __init__(self, adapter)         # 네트워크 어댑터 설정

    # 기본 명령어
    def brd_read(ado, length)           # Broadcast Read
    def bwr_write(ado, data)            # Broadcast Write
    def aprd_read(position, ado, len)   # Auto-increment Read
    def apwr_write(position, ado, data) # Auto-increment Write
    def fprd_read(addr, ado, length)    # Configured Address Read
    def fpwr_write(addr, ado, data)     # Configured Address Write

    # Slave 관리
    def scan_slaves()                   # Slave 스캔 (최대 63개)
    def config_slaves()                 # Slave 주소 할당
    def read_slave_state(slave)         # 개별 Slave 상태 읽기
    def write_slave_state(slave, state) # 상태 전이 요청
    def transition_to_op()              # INIT → OP 자동 전이

    # PDO 통신
    def lrw_exchange(logical_addr, data) # Logical Read/Write
    def setup_pdo_mapping()              # PDO 매핑 설정
    def cyclic_exchange(output_data)     # 사이클릭 데이터 교환
    def run_cyclic(duration, cycle_time) # 사이클릭 통신 실행
```

### 3.2 EtherCAT Slave Emulator

#### 주요 특징
- **WKC (Working Counter) 처리**: 각 명령 처리 시 적절한 WKC 증가
- **레지스터 에뮬레이션**: ESC 레지스터 0x0000~0x2000 영역
- **Loopback 필터링**: 자신이 보낸 패킷 무시
- **Broadcast 응답**: Point-to-Point 연결에서 응답 전송

### 5.2 PDO 데이터 형식

#### 출력 데이터 (Master → Slave)
```
TX: [Slave1 2bytes][Slave2 2bytes][Slave3 2bytes]
예: 630063006300 = 카운터 값 0x0063 (99) × 3
```

#### 입력 데이터 (Slave → Master)
```
RX: [Slave1 2bytes][Slave2 2bytes][Slave3 2bytes]
예: 080108020803
    08 01 = state=0x08(OP), position=1
    08 02 = state=0x08(OP), position=2
    08 03 = state=0x08(OP), position=3
```

## 7. 기술적 참고사항

### 7.1 EtherCAT 프로토콜 요약

#### 프레임 구조
```
┌──────────────┬───────────────┬──────────────────────────┐
│ Ethernet Hdr │ EtherCAT Hdr  │      Datagrams           │
│   (14 bytes) │   (2 bytes)   │   (가변 길이)            │
│              │               │                          │
│ Dst MAC      │ Length + Type │ [DG1][DG2]...[DGn]       │
│ Src MAC      │               │                          │
│ Type=0x88A4  │               │                          │
└──────────────┴───────────────┴──────────────────────────┘
```

#### Datagram 구조
```
┌─────┬─────┬─────┬─────┬─────────┬─────┬──────────┬─────┐
│ CMD │ IDX │ ADP │ ADO │ LEN+FLG │ IRQ │   DATA   │ WKC │
│ 1B  │ 1B  │ 2B  │ 2B  │   2B    │ 2B  │  nB      │ 2B  │
└─────┴─────┴─────┴─────┴─────────┴─────┴──────────┴─────┘
```

### 7.2 주요 레지스터 주소

| 주소 | 이름 | 설명 |
|------|------|------|
| 0x0000 | Type | ESC 타입 |
| 0x0001 | Revision | ESC 리비전 |
| 0x0010 | Station Address | 설정된 주소 |
| 0x0110 | DL Status | 데이터 링크 상태 |
| 0x0120 | AL Control | AL 상태 제어 |
| 0x0130 | AL Status | AL 현재 상태 |
| 0x0134 | AL Status Code | 에러 코드 |

### 7.3 WKC (Working Counter) 규칙

| 명령 | 성공 시 WKC 증가 |
|------|------------------|
| Read (APRD, FPRD, BRD, LRD) | +1 |
| Write (APWR, FPWR, BWR, LWR) | +1 |
| Read/Write (APRW, FPRW, BRW, LRW) | +3 |

## 8. 문제 해결 가이드

### 8.1 Slave를 찾지 못하는 경우

1. **Ubuntu 에뮬레이터 실행 확인**
   ```bash
   ps aux | grep ethercat
   ```

2. **네트워크 케이블 연결 확인**
   - Ethernet 케이블이 직접 연결되어 있는지 확인
   - 스위치/허브를 거치면 안 됨 (EtherCAT은 Point-to-Point)

3. **인터페이스 상태 확인**
   ```bash
   # Ubuntu
   ip link show enx00e04c680189
   # 상태가 UP인지 확인
   ```

### 8.2 PDO 통신 실패 (WKC=0)

1. **Slave가 OP 상태인지 확인**
   - LRW 명령은 OP 상태에서만 응답

2. **에뮬레이터 버전 확인**
   - v12 이상 사용 (LRW 지원)

### 8.3 응답 지연 문제

1. **사이클 타임 조정**
   - `run_cyclic()` 함수의 `cycle_time` 파라미터 증가
   - 현재: 50ms, 필요시 100ms로 조정
