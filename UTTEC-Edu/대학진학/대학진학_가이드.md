## 1. 전형 유형

### 수시 전형 (9월)
| 전형 | 특징 | 평가 요소 |
|------|------|----------|
| 학생부교과 | 내신 성적 중심 | 교과 성적, 출결 |
| 학생부종합 | 학교생활 전반 평가 | 학생부, 자기소개서, 면접 |
| 논술 | 논술 시험 중심 | 논술 성적, 학생부 |
| 실기/특기 | 예체능, 특기자 | 실기, 특기 성적 |

### 정시 전형 (12월~1월)
- 수능 성적 중심 평가
- 수능 영역별 반영 비율 대학마다 상이
- 일부 대학 면접/실기 포함

## 2. 학년별 준비사항

### 고등학교 1학년
- [ ] 진로 탐색 및 관심 분야 설정
- [ ] 내신 관리 시작 (1학년 성적도 반영됨)
- [ ] 독서 활동 시작
- [ ] 교내 활동 참여 (동아리, 봉사활동)
- [ ] 학습 습관 형성

### 고등학교 2학년
- [ ] 지원 대학/학과 범위 좁히기
- [ ] 내신 성적 집중 관리
- [ ] 심화 교과목 선택
- [ ] 전공 관련 활동 강화
- [ ] 수능 기초 학습 시작

### 고등학교 3학년
- [ ] 최종 지원 대학/학과 결정
- [ ] 수시 원서 작성 (6개 대학)
- [ ] 자기소개서 작성
- [ ] 수능 집중 대비
- [ ] 면접 준비

## 3. 학생부 관리

### 학생부 주요 항목
1. **인적사항**: 기본 정보
2. **출결상황**: 무단 결석/지각 최소화
3. **수상경력**: 교내 대회 참여
4. **진로희망사항**: 일관된 진로 방향
5. **창의적체험활동**: 동아리, 봉사, 진로활동
6. **교과학습발달상황**: 성적 + 세부능력특기사항
7. **행동특성 및 종합의견**: 담임 선생님 기록

### 세부능력특기사항(세특) 관리
- 수업 중 적극적 참여
- 발표, 토론, 프로젝트 활동
- 교과 연계 탐구 활동
- 전공 관련 심화 학습 기록

## 4. 수능 준비

### 시험 영역
| 영역 | 시간 | 문항수 | 배점 |
|------|------|--------|------|
| 국어 | 80분 | 45문항 | 100점 |
| 수학 | 100분 | 30문항 | 100점 |
| 영어 | 70분 | 45문항 | 100점 |
| 탐구 (2과목) | 과목당 30분 | 과목당 20문항 | 과목당 50점 |
| 한국사 | 30분 | 20문항 | 50점 |
| 제2외국어/한문 | 40분 | 30문항 | 50점 |

### 선택과목 (2025학년도 기준)
- **국어**: 화법과 작문 / 언어와 매체
- **수학**: 확률과 통계 / 미적분 / 기하
- **탐구**: 사회탐구(9과목) / 과학탐구(8과목) 중 2과목

### 학습 전략
1. **기본 개념 정립** (고1~고2)
2. **기출문제 분석** (고2 겨울~고3)
3. **실전 모의고사** (고3)
4. **오답 노트 정리**
5. **시간 관리 연습**

## 5. 자기소개서 작성

### 자기소개서 문항 (2024학년도 기준)
1. **1번 문항** (1,500자): 학업 역량 - 학업에 기울인 노력과 학습 경험
2. **2번 문항** (1,500자): 진로 역량 - 진로와 관련하여 노력한 과정과 배운 점
3. **3번 문항** (대학별, 800자 내외): 대학별 자율 문항

### 작성 팁
- 구체적인 사례와 경험 중심
- 과정과 배움 강조
- 학생부와 일관성 유지
- 진정성 있는 표현
- 표절 및 대필 금지

## 6. 면접 준비

### 면접 유형
| 유형 | 내용 | 준비 방법 |
|------|------|----------|
| 서류 기반 면접 | 학생부, 자소서 기반 질문 | 본인 서류 숙지 |
| 제시문 기반 면접 | 지문 읽고 답변 | 독해력, 논리력 훈련 |
| 다대다 면접 | 토론, 집단 면접 | 의사소통 능력 |

### 기본 질문 예시
- 지원 동기
- 학업 계획
- 진로 계획
- 의미 있었던 활동
- 본인의 장단점

### 면접 태도
- 단정한 복장
- 바른 자세
- 눈 맞춤
- 명확한 발음
- 적절한 답변 길이 (1~2분)

## 7. 원서 접수

### 수시 원서 접수
- **접수 시기**: 9월 중순 (약 4일간)
- **지원 횟수**: 최대 6회
- **접수처**: 대학 입학처, 유웨이어플라이, 진학사어플라이

### 정시 원서 접수
- **접수 시기**: 12월 말 ~ 1월 초
- **지원 횟수**: 가/나/다군 각 1회씩 (최대 3회)
- **수능 성적 확인 후 지원**

### 원서 접수 체크리스트
- [ ] 지원 자격 확인
- [ ] 전형료 준비
- [ ] 사진 파일 준비
- [ ] 제출 서류 확인
- [ ] 마감 시간 확인 (보통 18시)
