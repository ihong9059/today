# 교사/교육자 AI 활용 교육 커리큘럼 개선안

## 1. 현황 분석

### 기존 구성 (3개 학교급 × 5일 = 총 15일)
| 학교급 | 코스명 | 일수 | 현재 강좌 구성 |
|--------|--------|------|----------------|
| 초등 | 초등교사 코스 | 5일 | 교육학 기초 → 교수법 → AI 자료 제작 → 수업 설계 → 포트폴리오 |
| 중등 | 중등교사 코스 | 5일 | 교육학 기초 → 교수법 → AI 자료 제작 → 수업 설계 → 포트폴리오 |
| 고등 | 고등교사 코스 | 5일 | 교육학 기초 → 교수법 → AI 자료 제작 → 수업 설계 → 포트폴리오 |

### 문제점
1. **일수 부족**: 5일로는 AI 활용 역량을 충분히 기르기 어려움
2. **AI 도구 학습 부재**: AI 기초 사용법이 포함되지 않음
3. **프롬프트 교육 부족**: 효과적인 프롬프트 작성법이 없음
4. **실습 시간 부족**: 이론 위주로 실제 적용 시간이 적음
5. **학교급별 차별화 부족**: 구조가 거의 동일함
6. **UI/UX**: Claude 기본 선택, 유튜브 연동, 완료 추적 미적용

## 2. 개선된 커리큘럼 구조

## 4. UI/UX 개선 사항

### 적용할 기능
1. **AI 서비스**: Claude 기본 선택 (+ ChatGPT, Gemini)
2. **유튜브 참고 영상**: 각 레슨별 키워드로 검색 연동
3. **학습 완료 추적**: localStorage 기반 진행률 관리
4. **코스별 색상 테마**: 학교급별 차별화된 색상

### 색상 테마
| 학교급 | 배경색 | 그라디언트 | 텍스트 |
|--------|--------|-----------|--------|
| 초등 | green-50 | green-500 → emerald-600 | green-700 |
| 중등 | blue-50 | blue-500 → indigo-600 | blue-700 |
| 고등 | purple-50 | purple-500 → pink-600 | purple-700 |

## 5. 프롬프트 템플릿 예시

### Day 1: AI 시대의 교육 변화

**프롬프트 1: AI가 바꾸는 교육**
```
AI 시대에 교육이 어떻게 변화하고 있는지 설명해주세요.

다음 내용을 포함해주세요:
1. AI 시대 교육 패러다임의 변화
   - 지식 전달 → 역량 중심
   - 교사 중심 → 학습자 중심
   - 표준화 → 개인화

2. AI가 교육에 미치는 영향
   - 맞춤형 학습의 가능성
   - 교사 역할의 변화
   - 새로운 교육 도구의 등장

3. 세계 각국의 AI 교육 동향
   - 한국, 미국, 핀란드 등 사례

4. 교사에게 필요한 새로운 역량

현직 교사가 바로 이해할 수 있도록 실제 사례를 들어 설명해주세요.
```

**프롬프트 2: 교실에서의 AI 활용 사례**
```
교실에서 AI를 활용한 성공적인 수업 사례를 알려주세요.

다음 내용을 포함해주세요:
1. 국내 학교 AI 활용 사례 5가지
   - 어떤 AI 도구를 사용했는지
   - 어떤 교과/활동에 적용했는지
   - 어떤 효과가 있었는지

2. 해외 학교 AI 활용 사례 3가지

3. 학교급별 적합한 AI 활용 방법
   - 초등학교
   - 중학교
   - 고등학교

4. AI 활용 수업의 장점과 주의점

구체적인 학교명과 활동 내용을 포함해주세요.
```

## 6. 실행 계획

### 우선순위
1. **커리큘럼 문서 완성** - 현재 진행
2. **lesson_page.tsx 업데이트** - Claude 기본, 유튜브 연동, 완료 추적
3. **level_page.tsx 업데이트** - 15일 구조로 확장, 색상 테마
4. **프롬프트 데이터 확장** - 15일분 프롬프트 작성
5. **EC2 배포 및 테스트**

### 예상 작업량
- 프롬프트 작성: 각 학교급 15일 × 3개 프롬프트 = 45개 프롬프트/학교급
- 총 프롬프트: 45 × 3 = 135개 (공통 15개는 재사용)

## 7. 기대 효과

1. **체계적인 AI 역량 개발**: 5일 → 15일로 확대하여 충분한 학습 시간 확보
2. **실습 중심 학습**: 이론과 실습의 균형 있는 구성
3. **학교급별 맞춤화**: 발달 단계와 교육과정에 맞는 내용
4. **즉시 적용 가능**: 실제 수업에 바로 적용할 수 있는 프롬프트 제공
5. **지속적 성장**: 포트폴리오 작성으로 교사 성장 기록
