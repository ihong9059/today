### 1.2 현재 Edge AI Gateway 사양 (ARM Cortex-M4 기반)
| 항목 | 현재 사양 | 한계점 |
|------|----------|--------|
| MCU | ARM Cortex-M4 + DSP | 딥러닝 불가 |
| 메모리 | 512KB Flash, 256KB RAM | 모델 크기 제한 |
| 분석 | FFT, Envelope, Cepstrum | 통계적 분석만 가능 |
| AI | Rule-based 이상 탐지 | 학습 불가, 패턴 제한적 |

### 1.3 현재 AI 기능
```
현재 구현된 기능:
├── 실시간 FFT 분석 (주파수 분석)
├── Envelope 분석 (베어링 결함 검출)
├── Cepstrum 분석 (기어 결함 검출)
├── Rule-based 이상 탐지 (임계값 기반)
└── 잔여수명(RUL) 예측 (통계 기반)

미구현 기능 (GPU 필요):
├── 딥러닝 기반 이상 탐지 (Autoencoder, LSTM)
├── 비지도 학습 패턴 인식
├── 이미지 기반 품질 검사 (CNN)
├── 자연어 처리 (알림 자동 생성)
└── 멀티모달 분석 (센서 + 카메라)
```
