## 네비게이션 흐름

```
홈 → 기계 카드 클릭 → 기계 카테고리 → 전기기사 카드 클릭
   → 전기기사 페이지 → 시험 상세보기 → 필기/실기 탭
   → 각 과목 학습하기 버튼 → 학습 페이지
```
