# 자격시험 준비 안내 웹사이트 설계서

**프로젝트명**: 자격시험 가이드 (Certification Guide Korea)
**작성일**: 2026-01-03
**배포 서버**: uttec-first-ec2 (3.35.139.224)

---

## 1. 프로젝트 개요

### 1.1 목적
- 한국 자격시험 정보를 분야별로 체계적으로 제공
- 시험 준비에 필요한 참고 사항, 학습 자료, 팁 안내
- AI 기반 맞춤형 학습 가이드 제공

### 1.2 대상 사용자
- 자격증 취득을 준비하는 취업준비생
- 이직/전직을 준비하는 직장인
- 자격증 정보가 필요한 학생 및 일반인

### 1.3 핵심 기능
1. **분야별 자격시험 목록 및 상세 정보**
2. **시험 일정 캘린더**
3. **AI 학습 가이드** (Claude/ChatGPT 활용)
4. **합격 전략 및 팁**
5. **학습 자료 링크 모음**

### 5.2 데이터 구조

```typescript
// 분야 카테고리
interface Category {
  id: string;           // 'it', 'law', 'accounting'
  name: string;         // 'IT·정보통신'
  icon: string;         // '💻'
  color: string;        // 'green'
  description: string;
  certifications: Certification[];
}

// 자격시험
interface Certification {
  id: string;           // 'information-processing-engineer'
  name: string;         // '정보처리기사'
  type: 'national' | 'private';  // 국가/민간
  organization: string; // '한국산업인력공단'
  description: string;
  difficulty: 1 | 2 | 3 | 4 | 5;
  passRate: number;     // 35
  eligibility: string[];
  subjects: Subject[];
  fees: {
    written: number;
    practical: number;
  };
  passCriteria: string;
  schedule: ExamSchedule[];
  studyGuide: StudyGuide;
  aiPrompts: AIPrompt[];
}

// 시험 일정
interface ExamSchedule {
  year: number;
  round: number;        // 회차
  registrationStart: Date;
  registrationEnd: Date;
  writtenExamDate: Date;
  writtenResultDate: Date;
  practicalExamDate?: Date;
  practicalResultDate?: Date;
}

// 학습 가이드
interface StudyGuide {
  recommendedPeriod: string;  // '3개월'
  subjectStrategies: {
    subject: string;
    strategy: string;
    resources: string[];
  }[];
  recommendedBooks: string[];
  onlineCourses: string[];
  pastExamInfo: string;
}

// AI 프롬프트
interface AIPrompt {
  title: string;
  prompt: string;
  description: string;
}
```
