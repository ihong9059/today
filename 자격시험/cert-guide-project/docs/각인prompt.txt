## 금지 사항 (이전 오류 방지)

1. **퀴즈 방식 금지**: "정답 보기" 버튼으로 답 숨기지 말 것 → 정답 항상 표시
2. **onClick 클립보드 복사 금지**: AI 버튼은 반드시 \`<a href>\` 직접 링크 사용
3. **잘못된 경로 금지**: \`/자격시험/...\` 형태 절대 사용 금지
4. **헤더 누락 금지**: 모든 페이지에 네비게이션 헤더 필수
5. **export 패턴 혼용 금지**:
   - page.tsx는 export만 담당
   - 실제 컴포넌트는 별도 파일 (main-page.tsx, category-page.tsx 등)
6. **문제 개수 부족 금지**: 각 토픽당 최소 5개 이상의 문제 필수
7. **임의 문제 생성 금지**: 기출문제/출제기준 확인 없이 추측으로 문제 생성 금지

## 문제 선정 기준 (중요!)

### 문제 선정 우선순위 (반드시 순서대로 적용)

1. **기출문제 기반 (최우선)**
   - 한국산업인력공단 Q-Net에서 최근 5년간 기출문제 확인
   - 기출 빈도가 높은 문제를 우선 선정
   - 기출문제 URL: https://www.q-net.or.kr/cst006.do?id=cst00602

2. **출제기준 기반**
   - 각 자격증별 공식 출제기준표 참조
   - 출제기준에 명시된 세부항목을 문제로 변환
   - 출제기준 검색: "자격증명 + 출제기준" 웹 검색

3. **핵심 개념 기반 (보조)**
   - 해당 분야의 교과서/교재에서 핵심 개념 추출
   - 실무에서 자주 사용되는 개념 포함

### 문제 작성 시 필수 확인사항

```
□ 이 문제가 실제 기출에 나왔는가?
□ 출제기준의 어떤 항목에 해당하는가?
□ 최근 5년 내 출제 빈도는?
□ 합격에 필수적인 개념인가?
```

### 문제 품질 기준

- **정확성**: 정답이 명확하고 논란의 여지가 없어야 함
- **출제 가능성**: 실제 시험에 나올 가능성이 높은 문제
- **난이도 균형**: 기초(30%) + 중급(50%) + 고급(20%) 배분
- **최신성**: 법령/규정 변경사항 반영 (특히 안전, 환경 분야)

### 기출문제 조사 방법

```bash
# 웹 검색으로 기출문제 확인
"정보처리기사 기출문제 2024"
"정보처리기사 필기 기출 PDF"
"자격증명 + 기출문제 + 년도"
```

### 주의사항

- **추측 금지**: 기출/출제기준 확인 없이 임의로 문제 생성하지 말 것
- **검증 필수**: 생성한 문제의 정답이 정확한지 반드시 확인
- **갱신 필요**: 법령/기술 변경 시 관련 문제 업데이트 필요
