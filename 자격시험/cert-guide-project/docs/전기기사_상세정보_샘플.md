# 전기기사 (Engineer Electricity)

**자격 구분**: 국가기술자격
**주관 기관**: 한국산업인력공단 (Q-Net)
**난이도**: ★★★★☆
**연간 응시자**: 약 15만명
**종합 합격률**: 필기 20% / 실기 38%

---

## 1. 개요

### 1.1 자격 소개
전기기사는 전기에 관한 고도의 기술과 전문지식을 갖추고, 전기설비의 설계, 시공, 감리, 유지보수 등의 업무를 수행하는 국가기술자격입니다.

### 1.2 주요 업무
- 전기설비 설계 및 시공 관리
- 전력계통 운영 및 유지보수
- 전기안전관리 업무
- 전기공사 감리
- 발전소, 변전소 운영 관리

### 1.3 취업 분야
| 분야 | 기업/기관 예시 |
|------|----------------|
| 발전/송배전 | 한국전력, 발전자회사(한수원, 남동, 중부, 서부, 남부, 동서) |
| 건설/시공 | 삼성물산, 현대건설, 대림산업 등 |
| 제조업 | 삼성전자, LG전자, SK하이닉스 등 |
| 플랜트 | 삼성엔지니어링, 현대엔지니어링 등 |
| 공공기관 | 한국전기안전공사, 전력거래소 등 |
| 설계/감리 | 전기설계사무소, 감리전문업체 |

| 경력 | 실무경력 4년 이상 |

## 3. 시험 정보

### 3.1 필기시험

#### 시험 형식
| 항목 | 내용 |
|------|------|
| 문항 수 | 100문항 (과목당 20문항) |
| 시험 시간 | 2시간 30분 (과목당 30분) |
| 출제 형식 | 객관식 4지선다형 |
| 합격 기준 | 과목당 40점 이상 + 평균 60점 이상 |

#### 시험 과목 (5과목)

| 순서 | 과목명 | 난이도 | 특징 |
|------|--------|--------|------|
| 1 | 전기자기학 | ★★★★★ | 가장 어려움, 과락률 1위 |
| 2 | 전력공학 | ★★★☆☆ | 암기 위주, 고득점 가능 |
| 3 | 전기기기 | ★★★★☆ | 과락률 2위, 이론+기출 병행 |
| 4 | 회로이론 및 제어공학 | ★★★☆☆ | 기초 과목, 먼저 공부 권장 |
| 5 | 전기설비기술기준 | ★★☆☆☆ | 암기 과목, 막판 집중 |

### 3.2 실기시험

#### 시험 형식
| 항목 | 내용 |
|------|------|
| 과목명 | 전기설비 설계 및 관리 |
| 시험 시간 | 2시간 30분 |
| 출제 형식 | 필답형 (주관식) |
| 문항 수 | 약 17~20문항 |
| 합격 기준 | 100점 만점 60점 이상 |

#### 출제 분야별 비중

| 분야 | 출제 비중 | 문항 수 | 핵심 내용 |
|------|----------|---------|-----------|
| 단답형 문제 | 70~85% | 14~17문항 | 용어, 정의, 규정 |
| 수변전 설비 | 10~15% | 1~2문항 | 단선도 해석, 기기 용량 계산 |
| 시퀀스/PLC | 5~10% | 1~2문항 | 회로도 해석, 타임차트 |
| 계산 문제 | 10~15% | 2~3문항 | 고장계산, 부하계산 |

#### 실기 세부 과목
1. **전기설비 설계** - 배선 설계, 부하 계산
2. **시퀀스 제어** - PLC, 릴레이 회로
3. **조명 설비** - 조도 계산, 조명 설계
4. **수변전 설비** - 결선도, 보호계전기
5. **접지 설비** - 접지공사, 접지저항

## 4. 과목별 학습 가이드

### 4.1 회로이론 및 제어공학 (먼저 공부!)

#### 핵심 단원
| 단원 | 비중 | 중요 개념 |
|------|------|-----------|
| 직류회로 | 15% | 옴의 법칙, 키르히호프 법칙 |
| 교류회로 | 30% | RLC 회로, 임피던스, 역률 |
| 3상 교류 | 20% | Y-Δ 결선, 전력 계산 |
| 과도현상 | 10% | RL, RC 회로 |
| 제어공학 | 25% | 전달함수, 블록선도, 안정도 |

#### 공부 팁
```
✅ 복소수 계산에 익숙해지기 (j 연산)
✅ 임피던스 계산 공식 암기
✅ 3상 전력 공식 (√3 × V × I × cosθ)
✅ 제어공학은 기출 패턴이 정형화되어 있음
```

| 송전 | 25% | 송전선로, 코로나, 페란티 현상 |
| 배전 | 20% | 배전방식, 전압강하 |

#### 공부 팁
```
✅ 암기 위주 → 고득점 가능 (80점 이상 목표)

✅ 계산문제 적음 → 암기로 승부
✅ %임피던스, 단락전류 계산은 반드시 숙지
```

## 5. 추천 공부 순서
