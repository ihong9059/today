## 2. 구독 vs 단건 비교 분석

### 2.1 비교표

| 항목 | 구독 모델 (월 9,900원) | 단건 모델 (2,500원/자격증) |
|------|----------------------|--------------------------|
| **초기 진입 장벽** | 높음 | **매우 낮음** ✅ |
| **고객 심리적 부담** | 매월 결제 부담 | **한번만 결제** ✅ |
| **수익 예측성** | 높음 ✅ | 낮음 |
| **고객 생애가치(LTV)** | 높음 (평균 4개월 = 39,600원) | 낮음 (평균 2-3개 = 5,000~7,500원) |
| **해지 관리** | 필요 | **불필요** ✅ |
| **결제 시스템 복잡도** | 정기결제 필요 | **단순** ✅ |
| **고객 획득 용이성** | 보통 | **높음** ✅ |
| **운영 복잡도** | 높음 | **낮음** ✅ |

### 2.2 고객 관점 분석

#### 시나리오 A: 전기기사 1개만 준비하는 고객

| 모델 | 비용 | 고객 선호도 |
|------|------|-----------|
| 구독 (3개월 사용) | 29,700원 | 😐 부담 |
| 단건 | **2,500원** | 😊 **선호** |

#### 시나리오 B: IT 분야 3개 자격증 준비하는 고객

| 모델 | 비용 | 고객 선호도 |
|------|------|-----------|
| 구독 (4개월 사용) | 39,600원 | 😐 보통 |
| 단건 (3개) | **7,500원** | 😊 **선호** |

#### 시나리오 C: 다양한 분야 10개 이상 자격증 준비

| 모델 | 비용 | 고객 선호도 |

**결론**: 대부분의 고객은 1-3개 자격증만 준비하므로 **단건 모델이 고객에게 유리**

```sql
CREATE TABLE purchases (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) NOT NULL,
  certification_id VARCHAR(100) NOT NULL,
  amount DECIMAL(10,2) DEFAULT 2500,
  access_code VARCHAR(50) UNIQUE,
  payment_method VARCHAR(50),
  pg_transaction_id VARCHAR(255),
  status ENUM('completed', 'refunded') DEFAULT 'completed',
  created_at TIMESTAMP DEFAULT NOW(),

  INDEX idx_email (email),
  INDEX idx_certification (certification_id),
  INDEX idx_access_code (access_code)
);

-- 번들 구매 시
CREATE TABLE bundle_purchases (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) NOT NULL,
  bundle_type ENUM('5pack', '10pack', 'category', 'all'),
  certifications JSON, -- ["electric-engineer", "electric-craftsman", ...]
  amount DECIMAL(10,2),
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 9. 결론

### 단건 결제 모델(2,500원)을 권장하는 이유:

1. **고객 친화적**: 필요한 자격증만 저렴하게 구매
2. **높은 전환율**: 낮은 가격 = 낮은 구매 허들
3. **간단한 구현**: 복잡한 구독 관리 불필요
4. **빠른 수익화**: 런칭 즉시 매출 발생 가능
5. **확장성**: 추후 프리미엄 구독 추가 가능

- **1개월 차**: 월 50~100만원 매출
- **3개월 차**: 월 200~300만원 매출
