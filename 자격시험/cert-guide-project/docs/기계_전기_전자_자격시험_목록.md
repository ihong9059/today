## 8. 추천 취득 순서

### 전기 분야 로드맵
```
전기기능사 → 전기산업기사 → 전기기사 → 전기기술사
                              ↓
                    전기공사기사 (병행)
```

### 기계 분야 로드맵
```
전산응용기계제도기능사 → 기계설계산업기사 → 일반기계기사 → 기계기술사
           ↓                    ↓
    CNC기능사 계열        기계정비기사 (병행)
```

### 전자/자동화 로드맵
```
전자기기기능사 → 전자산업기사 → 전자기사
       ↓
생산자동화기능사 → 메카트로닉스기사 → 제어계측기술사
```
