## 우선순위 작업 순서

### Phase 1: 핵심 IT 자격증 (5개)
```
1. 정보처리기사 (information-processor) - 가장 인기 있는 IT 자격증
2. 정보보안기사 (information-security)
3. 전자계산기조직응용기사 (computer-organization)
4. 컴퓨터시스템응용기술사 (computer-system-pro)
5. 정보관리기술사 (information-management-pro)
```

### Phase 2: 회계·세무 (11개)
```
1. 전산회계 1급/2급 - 응시자 많음
2. 전산세무 1급/2급
3. FAT/TAT 1급/2급
4. 공인회계사, 세무사, 관세사
```

### Phase 3: 건설·안전 (13개)
```
건설 5개 + 안전 8개
```

### Phase 4: 서비스·조리 (17개)
```
조리 기능사 5종 + 제과제빵 + 미용 4종 + 기타
```

### Phase 5: 나머지 분야
```
법률, 금융, 복지, 디자인, 교육, 농업, 공무원, 사무, 무역, 의료, 보험, 운전
```
