## 자격증 유형별 패턴 (A/B 구분)

### 유형 A: 기사자격증 (필기 + 실기)
- **시험 구조**: 필기(객관식) → 실기(작업형/필답형)
- **메인 페이지**: "필기시험 과목" + "실기시험 구성" 섹션
- **study 구성**: 필기과목 5개 + practical(실기) 1개
- **예시**: 정보처리기사, 기계기사, 전기기사

### 유형 B: 전문자격사 (1차 + 2차)
- **시험 구조**: 1차(객관식) → 2차(논술형/서술형)
- **메인 페이지**: "1차 시험 과목" + "2차 시험 과목" 섹션
- **study 구성**: 1차+2차 주요 과목 5-6개 + practical 1개
- **예시**: 감정평가사, 법무사, 공인노무사, 변리사
