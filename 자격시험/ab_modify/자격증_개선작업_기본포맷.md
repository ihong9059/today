## 🚨 중요: 기존 경로 우선 원칙 (2026-01-07 추가)

> **문제 상황**: 카테고리 매핑표와 실제 서버 경로가 다를 수 있습니다!
> 예: 공인회계사는 매핑표에서 `/category/business/`이지만, 실제 서버에는 `/category/accounting/cpa/`에 존재

### 반드시 서버 경로 먼저 확인!

**작업 전 필수 실행:**
```bash
# EC2에서 자격증 슬러그로 기존 경로 검색
ssh uttec-ec2 "find ~/cert-guide/app/category/ -name '[슬러그]' -type d"

# 예: 공인회계사(cpa) 검색
ssh uttec-ec2 "find ~/cert-guide/app/category/ -name 'cpa' -type d"
```

### 경로 결정 규칙

```
1. 서버에 기존 경로가 있으면 → 해당 경로 사용 (절대 새 경로 생성 금지)
2. 서버에 없으면 → 카테고리 매핑표 참조하여 새 경로 생성
```

### 왜 중요한가?

- 홈페이지/카테고리 페이지의 링크가 **기존 경로**를 가리킴
- 새 경로에 페이지를 만들면 **직접 URL 접속만 가능**, 홈에서 이동 불가
- 결과: "홈에서 클릭하면 404" 또는 "홈에서 클릭하면 이전 버전 표시"

## 🚨 중요: 이전 버전 폴더 정리 (2026-01-08 추가)

> **문제 상황**: 슬러그가 변경된 경우, 이전 버전 폴더가 남아있어 혼란 발생
> 예: `cook-puffer` (이전) vs `cook-pufferfish` (새 버전), `pastry` (이전) vs `confectioner` (새 버전)

### 배포 전 필수 확인 3단계

**1단계: 유사한 이름의 기존 폴더 검색**
```bash
# EC2에서 유사 슬러그 검색 (예: cook 관련 모든 폴더)
ssh uttec-ec2 "find ~/cert-guide/app/category -type d -name '*cook*'"
ssh uttec-ec2 "find ~/cert-guide/app/category -type d -name '*pastry*' -o -name '*confection*' -o -name '*bak*'"

# 결과 예시 - 중복 발견:
# /home/ec2-user/cert-guide/app/category/service/cook-puffer     ← 이전 버전 (불완전)
# /home/ec2-user/cert-guide/app/category/service/cook-pufferfish ← 새 버전
```

**2단계: category-page.tsx에서 링크 확인**
```bash
# 해당 카테고리 페이지에서 어떤 경로로 링크하는지 확인
ssh uttec-ec2 "grep -E 'cook-puffer|pastry|confection' ~/cert-guide/app/category/service/category-page.tsx"

# 결과 예시:
# <Link href="/category/service/cook-puffer" ...>   ← 이전 경로로 링크됨! 문제!
```

**3단계: 이전 버전 정리 및 링크 수정**
```bash
# 1) 이전 버전 폴더 삭제
ssh uttec-ec2 "rm -rf ~/cert-guide/app/category/service/cook-puffer"
ssh uttec-ec2 "rm -rf ~/cert-guide/app/category/service/pastry"

# 2) category-page.tsx 링크 수정
ssh uttec-ec2 "sed -i 's|/category/service/cook-puffer|/category/service/cook-pufferfish|g' ~/cert-guide/app/category/service/category-page.tsx"
ssh uttec-ec2 "sed -i 's|/category/service/pastry|/category/service/confectioner|g' ~/cert-guide/app/category/service/category-page.tsx"

# 3) 빌드 및 재시작
ssh uttec-ec2 "cd ~/cert-guide && npm run build && pm2 restart cert-guide"
```
