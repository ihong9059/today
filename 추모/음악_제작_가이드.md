# 추모 음악 제작 가이드

슬픔을 음악으로 표현하는 방법을 안내해 드립니다.

---

## 1. AI 음악 생성 서비스 (추천)

### Suno AI (https://suno.ai)
- **가장 추천**: 한국어 가사 지원, 감성적인 곡 생성 가능
- 무료 크레딧 제공
- 사용법:
  1. 사이트 접속 후 회원가입
  2. "Create" 버튼 클릭
  3. 아래 프롬프트 입력

```
Style: Korean ballad, piano, soft strings, emotional, memorial
Tempo: Slow, 60-70 BPM
Mood: Reflective, comforting, peaceful

[Verse]
같은 시대를 살았고
같은 하늘 아래 웃었던
그대가 먼저 떠났네

[Chorus]
살아있는 오늘이
어제의 누군가가
간절히 원했던 내일
```

### Udio (https://udio.com)
- 고품질 음악 생성
- 다양한 장르 지원

### AIVA (https://aiva.ai)
- 클래식/오케스트라 스타일
- 배경음악에 적합

---

## 2. 추천 음악 스타일

추모 영상에 어울리는 스타일:
- **피아노 발라드**: 잔잔하고 감성적
- **어쿠스틱 기타**: 따뜻하고 포근함
- **현악 오케스트라**: 장엄하고 경건함
- **앰비언트**: 명상적이고 평화로움

---

## 3. Suno AI 추천 프롬프트

### 잔잔한 피아노 버전
```
gentle piano ballad, korean memorial song, soft and peaceful,
no drums, emotional strings, reflective mood, 70 bpm
```

### 희망적인 버전
```
hopeful korean ballad, acoustic guitar, soft piano,
comforting melody, celebrating life, warm strings, 65 bpm
```

### 클래식 버전
```
orchestral requiem style, piano and strings,
solemn and beautiful, memorial tribute, no vocals, 60 bpm
```

---

## 4. 저작권 무료 추모 음악

직접 생성이 어려우시면:
- YouTube Audio Library (무료)
- Pixabay Music (무료)
- 검색어: "memorial music", "tribute music", "peaceful piano"

---

## 5. 음악 파일 저장 위치

생성한 음악은 아래 폴더에 저장해 주세요:
```
C:\todo\today\추모\audio\
```

영상 제작 시 이 음악을 사용합니다.
