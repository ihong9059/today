### 2.2 파생 특성 (Feature Engineering)

```python
# 진동 특성
features = {
    # 시간 영역 특성
    'vib_rms': RMS(vibration),           # 진동 RMS
    'vib_peak': max(vibration),          # 최대 진폭
    'vib_crest': peak / rms,             # 크레스트 팩터
    'vib_kurtosis': kurtosis(vibration), # 첨도 (베어링 결함 지표)

    # 주파수 영역 특성
    'vib_fft_peak_freq': peak_frequency, # 주 주파수
    'vib_fft_harmonics': harmonic_ratio, # 고조파 비율
    'vib_envelope': envelope_amplitude,   # 포락선 분석

    # 전류 특성
    'curr_mean': mean(current),          # 평균 전류
    'curr_std': std(current),            # 전류 변동
    'curr_thd': THD(current),            # 고조파 왜율

    # 온도 특성
    'temp_rate': d(temp)/dt,             # 온도 상승률
    'temp_delta': temp - ambient,        # 온도 편차

    # 운전 특성
    'load_factor': current / rated,      # 부하율
    'efficiency': output / input,        # 효율
}
```

## 3. AI 모델 상세 설계

### 3.1 이상 탐지 모델 (Anomaly Detection)

#### 3.1.1 모델 선택

| 모델 | 용도 | 장점 |
|------|------|------|
| **Isolation Forest** | 다변량 이상 탐지 | 빠른 학습/추론, 비지도 학습 |
| **Autoencoder** | 복잡한 패턴 학습 | 비선형 관계 학습 가능 |
| **One-Class SVM** | 정상 데이터 경계 학습 | 적은 데이터에 효과적 |

#### 3.1.2 Autoencoder 구조

```python
# 런투페일러(Run-to-Failure) 데이터 라벨링
def create_rul_labels(sensor_data, failure_time):
    """
    failure_time: 고장 발생 시점
    RUL = failure_time - current_time
    """
    rul_labels = []
    for t in range(len(sensor_data)):
        rul = failure_time - t
        # 최대 RUL 클리핑 (예: 200일)
        rul = min(rul, 200)
        rul_labels.append(rul)
    return rul_labels

# 슬라이딩 윈도우
def create_sequences(data, labels, seq_length=100):
    X, y = [], []
    for i in range(len(data) - seq_length):
        X.append(data[i:i+seq_length])
        y.append(labels[i+seq_length])
    return np.array(X), np.array(y)
```

### 3.3 과부하 예측 모델 (Overload Prediction)

#### 3.3.1 모델 개요

| 항목 | 내용 |
|------|------|
| **목적** | 과부하 발생 2~5초 전 예측 |
| **모델** | 1D CNN + Dense |
| **입력** | 전류, 진동 (최근 1초, 100 samples) |
| **출력** | 과부하 확률 (0~1) |

#### 3.3.2 모델 구조

```
Input: (100 samples, 4 channels)  # 전류2 + 진동2
       │
       ▼
┌────────────────────────────────────┐
│  Conv1D(32, kernel=5, stride=2)   │
│  BatchNorm + ReLU                  │
│  MaxPool1D(2)                      │
├────────────────────────────────────┤
│  Conv1D(64, kernel=3, stride=1)   │
│  BatchNorm + ReLU                  │
│  MaxPool1D(2)                      │
├────────────────────────────────────┤
│  Flatten                           │
│  Dense(32, ReLU)                   │
│  Dropout(0.3)                      │
│  Dense(1, Sigmoid)                 │
└────────────────────────────────────┘
       │
       ▼
Output: Overload Probability (0~1)
```

#### 3.3.3 제어 로직

```python
def overload_protection(prediction, current_value):
    """
    과부하 보호 제어 로직
    """
    if prediction > 0.9 or current_value > 180:  # 위험
        return Action.EMERGENCY_STOP

    elif prediction > 0.7 or current_value > 150:  # 경고
        retry_count = get_retry_count()
        if retry_count >= 3:
            return Action.EMERGENCY_STOP
        else:
            return Action.REVERSE_AND_RETRY

    elif prediction > 0.5 or current_value > 120:  # 주의
        return Action.REDUCE_SPEED

    else:  # 정상
        return Action.NORMAL_OPERATION
```

│  └─────────────────────────────────────────┘   │
│                     ↑↓                          │
│  ┌─────────────────────────────────────────┐   │

#### 3.4.2 보상 함수

```python
def calculate_reward(state, action, next_state):
    """
    보상 함수 설계
    """
    # 처리량 보상 (높을수록 좋음)
    throughput_reward = next_state['throughput'] / max_throughput

    # 에너지 페널티 (낮을수록 좋음)
    energy_penalty = -0.3 * (next_state['power'] / rated_power)

    # 마모 페널티 (낮을수록 좋음)
    wear_penalty = -0.5 * calculate_wear_rate(next_state)

    # 안전 페널티 (과부하 시 큰 페널티)
    if next_state['current'] > overload_threshold:
        safety_penalty = -10
    else:
        safety_penalty = 0

    total_reward = throughput_reward + energy_penalty + wear_penalty + safety_penalty
    return total_reward
```
