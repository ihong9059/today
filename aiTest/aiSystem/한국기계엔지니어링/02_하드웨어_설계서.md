## 2. Edge AI Gateway 설계

### 2.1 하드웨어 사양

| 항목 | 사양 |
|------|------|
| **MCU** | STM32F407VGT6 (ARM Cortex-M4, 168MHz) |
| **Flash** | 1MB |
| **RAM** | 192KB SRAM |
| **외부 메모리** | 8MB SPI Flash (펌웨어 OTA) |
| **동작 온도** | -40°C ~ +85°C (산업용) |
| **전원** | 24V DC (18~30V) |
| **소비 전력** | < 5W |
| **외형** | DIN Rail 장착, IP65 |

### 2.2 인터페이스 사양

| 인터페이스 | 수량 | 용도 |
|------------|------|------|
| **RS485** | 2 port | 센서 통신, Modbus RTU |
| **Ethernet** | 1 port | 클라우드 통신 |
| **CAN** | 1 port | 인버터 통신 (옵션) |
| **4-20mA Input** | 8 ch | 아날로그 센서 |
| **Digital I/O** | 8 ch | 제어 신호 |
| **USB** | 1 port | 설정/디버깅 |

## 3. 센서 상세 사양

### 3.1 진동 센서 (4개)

| 항목 | 사양 |
|------|------|
| **모델** | 산업용 가속도 센서 |
| **측정범위** | 0~50 mm/s (RMS) |
| **주파수 범위** | 10Hz ~ 10kHz |
| **감도** | 100 mV/g |
| **출력** | 4-20mA |
| **전원** | 24V DC (Loop Power) |
| **방진등급** | IP67 |
| **온도범위** | -40°C ~ +125°C |

**설치 위치:**
| ID | 위치 | 목적 |
|----|------|------|
| VIB_1 | 축1 베어링 하우징 (DE) | 베어링 상태 감시 |
| VIB_2 | 축2 베어링 하우징 (NDE) | 베어링 상태 감시 |
| VIB_3 | 메인 모터 | 모터 불균형 감지 |
| VIB_4 | 감속기 | 기어 이상 감지 |

### 3.2 온도 센서 (3개)

| 항목 | 사양 |
|------|------|
| **타입** | PT100 RTD (3-wire) |
| **측정범위** | -40°C ~ +200°C |
| **정확도** | ±0.5°C (Class A) |
| **응답시간** | < 500ms |
| **출력** | 4-20mA (트랜스미터 포함) |

**설치 위치:**
| ID | 위치 | 경고 임계값 | 위험 임계값 |
|----|------|-------------|-------------|
| TEMP_1 | 메인 모터 권선 | 85°C | 100°C |
| TEMP_2 | 감속기 오일 | 70°C | 85°C |
| TEMP_3 | 베어링 하우징 | 60°C | 75°C |

### 3.3 전류 센서 (2개)

| 항목 | 사양 |
|------|------|
| **타입** | 홀 효과 전류 변환기 (CT) |
| **측정범위** | 0~200A |

| **대역폭** | DC ~ 1kHz |
| **출력** | 4-20mA |

**설치 위치:**
| ID | 위치 | 정격 전류 | 과부하 임계값 |
|----|------|-----------|---------------|
| CURR_1 | 모터 #1 전원선 | 100A | 150A |
| CURR_2 | 모터 #2 전원선 | 100A | 150A |

### 3.4 속도 센서 (1개)

| 항목 | 사양 |
|------|------|
