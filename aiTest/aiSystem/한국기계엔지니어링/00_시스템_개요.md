## 2. 대상 설비

### 2.1 이축 파쇄기 (Twin-Shaft Shredder)

| 항목 | 사양 |
|------|------|
| 모델 | HK-TSS-800 |
| 용량 | 2~5 ton/hr |
| 모터 | 75kW x 2 (쌍축) |
| 감속비 | 1:50 |
| 축 회전수 | 15~30 RPM |

**특징:** 두 개의 축이 교차 회전하며 재료를 파쇄. 고토크 설계로 강력한 파쇄력 확보.

### 2.2 분쇄기 (Hammer Crusher)

| 항목 | 사양 |
|------|------|
| 모델 | HK-HC-500 |
| 용량 | 1~3 ton/hr |
| 모터 | 55kW |
| 회전수 | 1000~1500 RPM |
| 입도 | 5~50mm 조절 가능 |

**특징:** 해머/임팩트 방식의 고속 분쇄. 다양한 입도 조절 가능.

### 2.3 핀밀 (Pin Mill)

| 항목 | 사양 |
|------|------|
| 모델 | HK-PM-300 |
| 용량 | 0.5~2 ton/hr |
| 모터 | 37kW |
| 회전수 | 3000~6000 RPM |
| 입도 | 10~100 mesh |

**특징:** 충격식 미분쇄기. 고속 회전 핀에 의한 충돌로 미세 분쇄.

```

│                         ↑ HTTPS/MQTT                        │
```
