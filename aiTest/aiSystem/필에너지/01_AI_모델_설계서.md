### 2.2 파생 특성 (Feature Engineering)

```python
# 이차전지 설비 특화 특성
features = {
    # 진동 특성
    'vib_rms': RMS(vibration),           # 진동 RMS
    'vib_peak': max(vibration),          # 최대 진폭
    'vib_kurtosis': kurtosis(vibration), # 첨도 (베어링 결함 지표)
    'vib_fft_peak': peak_frequency,      # 주 주파수

    # 장력 특성 (와인더 핵심)
    'tension_mean': mean(tension),       # 평균 장력
    'tension_std': std(tension),         # 장력 변동
    'tension_delta': max - min,          # 장력 편차
    'tension_rate': d(tension)/dt,       # 장력 변화율

    # 레이저 특성 (노칭 핵심)
    'laser_power_mean': mean(power),     # 평균 출력
    'laser_power_std': std(power),       # 출력 변동
    'laser_temp_delta': temp - baseline, # 온도 편차

    # 온도 특성
    'temp_rate': d(temp)/dt,             # 온도 상승률
    'temp_delta': temp - ambient,        # 환경 대비 온도차

    # 서보 특성
    'servo_current_mean': mean(current), # 평균 전류
    'servo_torque_est': current * k,     # 추정 토크

    # 품질 관련 특성
    'alignment_score': vision_alignment, # 정렬도 점수
    'notch_quality': vision_notch,       # 노칭 품질 점수
}
```

## 3. AI 모델 상세 설계

### 3.1 이상 탐지 모델 (Anomaly Detection)

#### 3.1.1 모델 선택

| 모델 | 용도 | 장점 |
|------|------|------|
| **Isolation Forest** | 다변량 이상 탐지 | 빠른 학습/추론, 비지도 학습 |
| **Autoencoder** | 복잡한 패턴 학습 | 비선형 관계 학습 가능 |
| **One-Class SVM** | 정상 데이터 경계 학습 | 적은 데이터에 효과적 |

#### 3.1.2 Autoencoder 구조 (이차전지 특화)

```
Input Layer (16 features)
       │
       ▼
┌──────────────────┐
│  Encoder         │
│  Dense(64, ReLU) │
│  BatchNorm       │
│  Dense(32, ReLU) │
│  Dense(16, ReLU) │
│  Dense(8, ReLU)  │  ← Latent Space
└──────────────────┘
       │
       ▼
┌──────────────────┐
│  Decoder         │
│  Dense(16, ReLU) │
│  Dense(32, ReLU) │
│  Dense(64, ReLU) │
│  Dense(16, Linear)│
└──────────────────┘
       │
       ▼
Output Layer (16 features)

Loss: MSE(input, output)
Anomaly Score: Reconstruction Error
```

#### 3.1.3 설비별 이상 탐지 포인트

| 설비 | 감시 대상 | 이상 유형 |
|------|-----------|-----------|
| **Stacking** | 서보 진동, 정렬도 | 서보 마모, 정렬 오차 |
| **Notching** | 레이저 출력, 온도 | 광원 열화, 광학계 오염 |
| **Winder** | 장력, 권취 속도 | 장력 불균일, 베어링 마모 |

#### 3.1.4 임계값 설정

| 상태 | Anomaly Score | 조치 |
|------|---------------|------|
| **정상** | < 0.5 | 정상 운전 |
| **주의** | 0.5 ~ 0.8 | 모니터링 강화 |
| **경고** | 0.8 ~ 1.0 | 알림 발송, 점검 권고 |
| **위험** | > 1.0 | 자동 감속/정지 |

### 3.3 품질 예측 모델 (Quality Prediction)

#### 3.3.1 모델 개요

| 항목 | 내용 |
|------|------|
| **목적** | 공정 데이터 기반 품질 사전 예측 |
| **모델** | XGBoost + Neural Network 앙상블 |
| **입력** | 장력, 속도, 온도, 습도 등 공정 변수 |
| **출력** | 품질 등급 (A/B/C/NG) |

#### 3.3.2 Stacking 정렬도 예측

```python
# 정렬도 예측 모델
class AlignmentPredictor:
    def __init__(self):
        self.model = XGBRegressor(
            n_estimators=100,
            max_depth=6,
            learning_rate=0.1
        )

    def predict(self, features):
        """
        입력: [서보 진동, 흡착 진공도, 속도, 온도, 습도]
        출력: 예측 정렬 오차 (mm)
        """
        alignment_error = self.model.predict(features)

        if alignment_error < 0.05:
            return "A등급 (우수)"
        elif alignment_error < 0.1:
            return "B등급 (양호)"
        elif alignment_error < 0.15:
            return "C등급 (주의)"
        else:
            return "NG (불량 예측)"
```

#### 3.3.3 Notching 품질 예측

```python

def predict_notch_quality(laser_power, speed, temp, humidity):

    레이저 노칭 품질 예측
    """

        'speed': speed,
        'temp_delta': temp - optimal_temp,
        'humidity': humidity
    }

    quality_score = model.predict(features)

    # 품질 등급 판정
    if quality_score > 0.95:
        return "A등급", "절단면 우수"
    elif quality_score > 0.85:
        return "B등급", "절단면 양호"
    elif quality_score > 0.70:
        return "C등급", "버(Burr) 발생 가능"
    else:
        return "NG", "재가공 필요"
```
