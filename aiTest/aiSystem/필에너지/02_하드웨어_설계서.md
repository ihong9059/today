## 2. Edge AI Gateway 설계

### 2.1 게이트웨이 사양

| 항목 | 사양 |
|------|------|
| **MCU** | STM32H743 (ARM Cortex-M7, 480MHz) |
| **메모리** | 1MB Flash, 1MB SRAM |
| **AI 가속** | CMSIS-NN 최적화 |
| **통신** | RS485 x 4, Ethernet, WiFi, 4G LTE |
| **I/O** | ADC 16ch, GPIO 32ch, PWM 8ch |
| **전원** | 24V DC (산업용) |
| **동작 온도** | -20°C ~ 70°C |
| **보호 등급** | IP65 |

### 2.3 핀 할당

| 포트 | 기능 | 연결 대상 |
|------|------|-----------|
| ADC1_CH0~3 | 진동 센서 입력 | VIB_1~4 |
| ADC1_CH4~7 | 온도 센서 입력 | TEMP_1~4 |
| ADC2_CH0~2 | 장력 센서 입력 | TENS_1~3 |
| ADC2_CH3~4 | 레이저 파워 입력 | LASER_1~2 |
| ADC3_CH0~1 | 전류 센서 입력 | CURR_1~2 |
| UART1 | RS485 #1 | PLC (Modbus RTU) |
| UART2 | RS485 #2 | 인버터 |
| UART3 | RS485 #3 | 레이저 컨트롤러 |
| UART4 | RS485 #4 | 예비 |
| ETH | Ethernet | 비전 PC, 로컬 서버 |
| SPI1 | 4G LTE 모듈 | 클라우드 연결 |
