## 2. 대상 설비

### 2.1 Stacking 설비 (고속 적층기)

| 항목 | 사양 |
|------|------|
| 공정 | Z-Folding, Stack & Folding |
| 적층 속도 | 0.5~1.0 sec/층 |
| 정렬 정밀도 | ±0.1mm |
| 비전 검사 | 실시간 정렬도 검사 |

**특징:** 전극과 분리막을 고속으로 적층하는 핵심 공정. 정렬 정밀도가 배터리 성능에 직결.

### 2.2 Notching 설비 (레이저 노칭기)

| 항목 | 사양 |
|------|------|
| 레이저 | Fiber Laser 500W~1kW |
| 가공 속도 | 300~600 mm/s |
| 절단 정밀도 | ±0.05mm |
| 탭 용접 | 통합 지원 |

**특징:** 레이저 기반 전극 노칭. 깨끗한 절단면과 고속 가공이 핵심.

### 2.3 4680 Winder (대형 원통형 와인더)

| 항목 | 사양 |
|------|------|
| 대상 셀 | 4680 원통형 셀 |
| 장력 제어 | 실시간 피드백 제어 |
| 권취 속도 | 조절 가능 |
| 정렬 검사 | 인라인 비전 검사 |

**특징:** 테슬라 4680 배터리 등 대형 원통형 셀 제조용 와인더. 균일한 장력 제어가 핵심.

### 2.4 전극 공정 설비

| 항목 | 사양 |
|------|------|
| 코팅 | 슬롯다이 코팅 |
| 건조 | 열풍 건조 |
| 압연 | 롤 프레스 |
| 슬리팅 | 정밀 슬리팅 |

**특징:** 전극 제조의 핵심 공정을 담당하는 통합 설비.

### 2.5 전고체 배터리 설비

| 항목 | 사양 |
|------|------|
| 공정 | 차세대 전고체 전용 |
| 특수 환경 | 드라이룸 대응 |
| 적층 방식 | 고정밀 적층 |

**특징:** 차세대 전고체 배터리 제조를 위한 특수 공정 장비.
