## 6. CPU 스펙 비교

| 항목 | Mac (i7-4770HQ) | Windows PC (i5-1235U) | Jetson Nano |
|:-----|:---------------:|:---------------------:|:-----------:|
| 세대 | Haswell (4세대, 2013) | **Alder Lake (12세대, 2022)** | ARM Cortex-A57 |
| 코어/스레드 | 4C/8T | **10C/12T** | 4C/4T |
| 기본 클럭 | 2.2 GHz | 1.3 GHz (P-core) | 1.43 GHz |
| 부스트 클럭 | 3.4 GHz | **4.4 GHz** | - |
| TDP | 47W | 15W | 5-10W |
| 공정 | 22nm | **Intel 7 (10nm)** | 20nm |

### CPU 세대별 성능 향상

**Windows PC (i5-1235U)가 Mac (i7-4770HQ)보다 빠른 이유:**
1. **9세대 차이**: 2013년 vs 2022년 CPU
2. **더 많은 코어**: 10코어 vs 4코어 (하이브리드 아키텍처)
3. **향상된 IPC**: 명령어당 성능 ~40% 향상
4. **더 높은 부스트 클럭**: 4.4GHz vs 3.4GHz

## 7. 결론

### 7.1 핵심 결과

| 순위 | 플랫폼 | 평균 시간 | 속도 | 특징 |
|:----:|:-------|----------:|:----:|:-----|
| 🥇 | **Windows PC (i5-1235U)** | **1.00초** | 1.00 FPS | 가장 빠름, 최신 CPU |
| 🥈 | Mac (i7-4770HQ) | 1.19초 | 0.84 FPS | 안정적, 구형 CPU |
| 🥉 | Jetson Nano | 2.28초 | 0.44 FPS | 저전력, 임베디드용 |

### 7.2 인식률 (모두 동일)

- **83% (25/30)** - 세 플랫폼 모두 동일한 결과
- **100% 일관성** - 인식 결과 완전히 동일

### 7.3 권장사항

| 용도 | 권장 플랫폼 | 이유 |
|:-----|:-----------|:-----|
| **개발/테스트** | Windows PC (i5) | 가장 빠른 속도 (1.00 FPS) |
| **휴대용 작업** | Mac | 안정적, 배터리 효율 |
| **IoT/임베디드** | Jetson Nano | 저전력, 독립 운용 가능 |
| **대량 처리** | Windows PC 또는 GPU 서버 | 속도 중요 |

### 7.4 향후 개선 방향

1. **Windows PC에 NVIDIA GPU 추가** → 5-10배 속도 향상 예상
2. **Jetson Orin 업그레이드** → 142배 AI 성능 향상
3. **plate_17~20 이미지 품질 개선** → 인식률 향상
