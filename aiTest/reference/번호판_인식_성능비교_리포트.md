### 7.4 plate_07 실패 분석 및 '오' 보정 ✅

#### 문제 분석

plate_07 이미지 분석 결과:
- **원인**: 배경 간판 글씨가 번호판과 함께 인식됨 ("잘망자용실쇼모...")
- **핵심 문제**: 한글 '오'가 숫자 '2'로 오인식됨 (9927890 → 99**2**7890)

| 분석 항목 | 결과 |
|-----------|------|
| OCR 인식 텍스트 | "9927890", "잘망자용실쇼모..." |
| 실제 번호판 | **99오7890** |
| 오인식 원인 | '오' → '2' 혼동 |

#### '오' ↔ '2' 보정 로직

```python
def extract_plate_number(text):
    """
    번호판 번호 추출 (보정 포함)
    - 숫자 7자리면 3번째 위치에 '오' 삽입
    - 숫자 8자리면 4번째 위치에 '오' 삽입
    """
    cleaned = re.sub(r'[^0-9가-힣]', '', text)

    # 표준 형식: 123가4567 또는 12가3456
    match = re.search(r'(\d{2,3})([가-힣])(\d{4})', cleaned)
    if match:
        return f"{match.group(1)}{match.group(2)}{match.group(3)}", True

    # 숫자 7자리 → '오' 보정
    digits = re.sub(r'[^0-9]', '', cleaned)
    if len(digits) == 7:  # 예: 9927890 → 99오7890
        return f"{digits[:2]}오{digits[3:]}", True
    if len(digits) == 8:  # 예: 12327890 → 123오7890
        return f"{digits[:3]}오{digits[4:]}", True

    return cleaned, False
```

### 7.6 TensorRT 테스트

#### 설치 현황

| 패키지 | 버전 | 상태 |
|--------|------|:----:|
| TensorRT | 8.2.1.9 | ✅ 설치 완료 |
| torch2trt | 0.5.0 | ✅ 설치 완료 |
| python3-libnvinfer | 8.2.1 | ✅ 설치 완료 |

#### TensorRT 적용 시도

| 방법 | 결과 | 비고 |
|:-----|:----:|:-----|
| torch2trt 직접 변환 | ❌ | EasyOCR 모델이 DataParallel 래퍼로 감싸져 있어 변환 복잡 |
| FP16 모델 변환 | ❌ | 입력/가중치 타입 불일치 오류 |
| AMP (Mixed Precision) | ❌ | EasyOCR 내부 OpenCV 연산과 호환 불가 |

#### TensorRT 적용 한계

EasyOCR은 다음 구조로 인해 TensorRT 직접 적용이 어려움:

```
EasyOCR 구조:
├── detector (CRAFT) - DataParallel 래퍼
│   └── 텍스트 영역 검출
├── recognizer (CRNN) - DataParallel 래퍼
│   └── 문자 인식
└── 후처리 (OpenCV 기반)
    └── FP16 미지원
```

#### TensorRT 적용을 위한 대안

| 대안 | 예상 효과 | 난이도 |
|:-----|:---------:|:------:|
| PaddleOCR + TensorRT | 0.5~1.0초 | 중 |
| YOLO + CRNN 커스텀 | 0.3~0.8초 | 상 |
| Jetson Orin 업그레이드 | 0.2~0.5초 | 하 (비용) |

### 7.7 PaddleOCR 테스트

TensorRT 대안으로 PaddleOCR을 Jetson Nano에서 테스트했습니다.

#### 설치 현황

| 패키지 | 버전 | 상태 |
|--------|------|:----:|
| PaddlePaddle GPU | 2.0.0 | ✅ 설치 완료 (Q-Engineering wheel) |
| PaddleOCR | 2.6 | ✅ 설치 완료 |
| PP-OCRv3 모델 | multilingual | ✅ 다운로드 완료 |

#### 실행 결과

| OCR 엔진 | 실행 | 인식률 | 평균 시간 | 비고 |
|:---------|:----:|:------:|:---------:|:-----|
| **PaddleOCR** | ❌ 실패 | - | - | 호환성 오류 |
| **EasyOCR** | ✅ 성공 | 90% | 2.02초 | 정상 작동 |

#### 호환성 문제

```
Error: module 'paddle.fluid.core_noavx' has no attribute 'is_compiled_with_rocm'
```

| 문제 | 원인 |
|------|------|
| PaddlePaddle 버전 | 2.0.0 (2020년)은 PaddleOCR 2.6+와 호환 불가 |
| Python 버전 | Jetson Nano는 Python 3.6, PaddleOCR 최신 버전은 3.7+ 필요 |
| wheel 가용성 | Jetson Nano (aarch64)용 최신 PaddlePaddle wheel 없음 |

#### PaddleOCR 사용을 위한 조건

| 조건 | 현재 상태 | 필요 조건 |
|:-----|:---------:|:---------:|
| Python | 3.6.9 | **3.7+** |
| PaddlePaddle | 2.0.0 | **2.4+** |
| JetPack | 4.6 (R32.7) | 5.0+ 권장 |

#### 결론

- **Jetson Nano에서 PaddleOCR 사용 불가** (Python 3.6 + PaddlePaddle 2.0.0 환경 제약)
- **EasyOCR이 현재 환경에서 최선의 선택**
- PaddleOCR 사용을 위해서는 **Jetson Orin** 또는 **Python 3.7+ 환경** 필요

### 7.8 실험 결론

1. **OpenCV 기반 영역 검출 + '오' 보정으로 인식률 90% 달성** (YOLO 불필요)
2. **속도 2.35x 개선**: 4.55초 → 1.94초 (이미지 크기 + cuDNN 최적화)
3. **plate_07 문제 해결**: '오' → '2' 오인식 보정 로직 적용
4. **TensorRT 직접 적용 한계**: EasyOCR 구조상 복잡
5. **PaddleOCR 사용 불가**: Jetson Nano 환경 (Python 3.6) 호환성 문제
