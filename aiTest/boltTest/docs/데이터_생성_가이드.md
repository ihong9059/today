# 볼트 학습 데이터 생성 가이드

표준 볼트 이미지 1장으로 AI 학습용 시뮬레이션 데이터를 생성하는 방법입니다.

---

## 1. 개요

### 1.1 생성되는 데이터

| 유형 | 설명 | 기본 생성 수 |
|:-----|:-----|-------------:|
| **양품 (good)** | 회전, 이동, 밝기 변화 등 | 50개 |
| **스크래치 (scratch)** | 선형 긁힘 결함 | 20개 |
| **찍힘 (dent)** | 원형 움푹 들어간 결함 | 20개 |
| **녹 (rust)** | 갈색/주황색 부식 | 20개 |
| **균열 (crack)** | 불규칙한 갈라짐 | 20개 |
| **나사산 결손 (missing_thread)** | 나사산 손상 | 20개 |
| **이물질 (contamination)** | 오염/이물 부착 | 20개 |

**기본 생성: 양품 50개 + 불량 120개 = 총 170개**

---

## 2. 사용법

### 2.1 기본 사용

```bash
cd aiTest/boltTest

# 표준 볼트 이미지로 데이터 생성
python src/generate_training_data.py --input data/raw/standard_bolt.jpg
```

### 2.2 옵션

```bash
python src/generate_training_data.py \
    --input data/raw/standard_bolt.jpg \  # 입력 이미지 (필수)
    --output data \                         # 출력 폴더 (기본: ./data)
    --good 100 \                            # 양품 생성 수 (기본: 50)
    --defect 30                             # 결함 유형당 생성 수 (기본: 20)
```

### 2.3 출력 구조

```
data/
├── train/
│   ├── good/
│   │   ├── good_0001.jpg
│   │   ├── good_0002.jpg
│   │   └── ...
│   └── defect/
│       ├── defect_scratch_0001.jpg
│       ├── defect_dent_0001.jpg
│       ├── defect_rust_0001.jpg
│       └── ...
```

## 3. 표준 이미지 촬영 가이드

### 3.1 권장 촬영 조건

| 항목 | 권장 사항 |
|:-----|:----------|
| **배경** | 단색 (검정 또는 흰색) |
| **조명** | 균일한 조명, 그림자 최소화 |
| **해상도** | 640x640 이상 |
| **포맷** | JPG 또는 PNG |
| **볼트 위치** | 이미지 중앙 |
| **볼트 방향** | 수평 또는 수직 |

### 3.2 촬영 예시

```
좋은 예:
┌────────────────┐
│                │
│    ┌──────┐    │  ← 중앙 배치
│    │ BOLT │    │
│    └──────┘    │
│                │
└────────────────┘
   균일한 배경

나쁜 예:
┌────────────────┐
│ ┌──────┐       │  ← 한쪽으로 치우침
│ │ BOLT │ ░░░░░ │  ← 복잡한 배경
│ └──────┘ ░░░░░ │
│ ▓▓▓▓▓▓▓▓░░░░░ │  ← 그림자
└────────────────┘
```

## 4. 생성되는 결함 유형

### 4.1 스크래치 (Scratch)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│      │  →   │ ───  │  ← 선형 긁힘
│      │      │   ── │
└──────┘      └──────┘
```

- 1~3개의 랜덤 선
- 길이: 20~80 픽셀
- 각도: 랜덤
- 색상: 어둡거나 밝은 선

### 4.2 찍힘 (Dent)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│      │  →   │  ●   │  ← 어두운 원형
│      │      │    ● │
└──────┘      └──────┘
```

- 1~3개의 원형 영역
- 크기: 5~15 픽셀
- 어두운 색상

### 4.3 녹 (Rust)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│      │  →   │ ▓▓   │  ← 갈색/주황 영역
│      │      │  ▓▓▓ │
└──────┘      └──────┘
```

- 불규칙한 타원형 영역
- 갈색/주황색 계열
- 블러 처리된 경계

### 4.4 균열 (Crack)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│      │  →   │ ╱╲   │  ← 불규칙한 선
│      │      │╱  ╲  │
└──────┘      └──────┘
```

- 랜덤 워크 경로
- 가는 어두운 선

### 4.5 나사산 결손 (Missing Thread)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│≡≡≡≡≡≡│  →   │▓▓≡≡≡≡│  ← 일부 영역 손상
│      │      │      │
└──────┘      └──────┘
```

- 나사산 영역 블러 + 어둡게 처리

### 4.6 이물질 (Contamination)

```
원본:          결함 생성 후:
┌──────┐      ┌──────┐
│      │  →   │ ▪    │  ← 불규칙한 어두운 점
│      │      │   ▪▪ │
└──────┘      └──────┘
```

- 불규칙한 다각형
- 어두운 색상 (기름, 먼지)

## 5. 양품 증강 기법

| 기법 | 범위 | 효과 |
|:-----|:-----|:-----|
| 회전 | ±15° | 방향 변동 대응 |
| 이동 | ±10% | 위치 변동 대응 |
| 밝기 | ±20% | 조명 변동 대응 |
| 대비 | ±10% | 카메라 설정 대응 |
| 노이즈 | 가우시안 | 센서 노이즈 대응 |
| 블러 | 약간 | 포커스 변동 대응 |

## 6. 대용량 데이터 생성

### 6.1 다양한 표준 이미지 사용

```bash
# 여러 표준 이미지로 각각 생성
for img in data/raw/*.jpg; do
    python src/generate_training_data.py -i "$img" -g 30 -d 15
done
```

### 6.2 권장 데이터 규모

| 목적 | 양품 | 불량 (유형당) | 총 합계 |
|:-----|-----:|--------------:|--------:|
| PoC/테스트 | 100 | 20 | ~220개 |
| 기본 학습 | 500 | 50 | ~800개 |
| 실제 운영 | 2,000 | 200 | ~3,200개 |

## 7. 주의사항

### 7.1 시뮬레이션 데이터의 한계

| 항목 | 설명 |
|:-----|:-----|
| **현실성** | 실제 결함과 차이가 있을 수 있음 |
| **다양성** | 실제 결함이 더 다양함 |
| **분포** | 실제 불량 분포와 다를 수 있음 |

### 7.2 권장 사항

1. **시뮬레이션 + 실제 데이터 혼합** 사용
2. **실제 불량 샘플**을 점진적으로 추가
3. **현장 테스트** 후 모델 재학습
4. **Anomaly Detection** 방식 병행 고려
