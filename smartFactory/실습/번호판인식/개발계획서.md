## 2. 숫자인식 프로젝트와의 관계

숫자인식 프로젝트에서 배운 내용이 번호판 인식의 기초가 됩니다.

| 항목 | 숫자인식 (이전 프로젝트) | 번호판인식 (이번 프로젝트) |
|------|----------------------|------------------------|
| **입력** | 28x28 흑백 이미지 1장 | 고해상도 컬러 자동차 사진 |
| **처리 단계** | 1단계 (분류만) | 2단계 (탐지 → 인식) |
| **모델** | CNN 직접 설계 | YOLOv8 (사전학습) + OCR |
| **출력** | 숫자 1개 (0~9) | 번호판 전체 문자열 (예: "12가 3456") |
| **데이터** | EMNIST 28만 장 (기성품) | 직접 수집 또는 공개 데이터 |
| **난이도** | 초보자 | 중급 |

### 번호판 인식이 더 어려운 이유

```
[숫자인식]
  입력: 깨끗한 28x28 흑백 숫자 → 출력: "3"
  (1단계: 분류)

[번호판인식]
  입력: 자동차가 찍힌 큰 사진
    ↓
  1단계: 사진에서 번호판 위치 찾기 (Object Detection)
    ↓
  2단계: 번호판 영역만 잘라내기 (Crop)
    ↓
  3단계: 잘라낸 번호판에서 글자 읽기 (OCR)
    ↓
  출력: "12가 3456"
```

## 3. 전체 시스템 구조

```
[자동차 이미지]
      ↓
[1단계: 번호판 탐지] ← YOLOv8 (Object Detection)
      ↓
  번호판 영역 좌표 (x, y, w, h)
      ↓
[2단계: 번호판 크롭] ← OpenCV (이미지 처리)
      ↓
  번호판만 잘라낸 이미지
      ↓
[3단계: 전처리] ← OpenCV (그레이스케일, 이진화, 노이즈 제거)
      ↓
  깨끗한 번호판 이미지
      ↓
[4단계: 문자 인식] ← EasyOCR 또는 Tesseract
      ↓
  "12가 3456"
```

**YOLOv8 모델 크기 비교:**

| 모델 | 파라미터 | 속도 | 정확도 | 권장 |
|------|---------|------|--------|------|
| YOLOv8n (nano) | 3.2M | 매우 빠름 | 보통 | **초보자 권장** |
| YOLOv8s (small) | 11.2M | 빠름 | 좋음 | 일반적 선택 |

> **Fine-tuning(미세 조정)이란?**
> 이미 수백만 장의 이미지로 학습된 모델(사전학습 모델)을 가져와서,
> 번호판 이미지만으로 추가 학습하는 방법입니다.
> 처음부터 학습하는 것보다 훨씬 적은 데이터와 시간으로 좋은 성능을 얻을 수 있습니다.
>
> 비유: 영어를 잘하는 사람이 프랑스어를 배울 때,
> 언어 자체의 구조는 이미 알고 있으므로 더 빨리 배우는 것과 같습니다.

### 7-5단계: 번호판 크롭 및 전처리

```python
# ============================================
# 5단계: 번호판 영역 크롭 및 전처리
# ============================================

def crop_and_preprocess(image_path, model):
    """이미지에서 번호판을 찾아 크롭하고 전처리"""
    # 원본 이미지 로드
    img = cv2.imread(image_path)
    results = model(image_path)

    plates = []
    for box in results[0].boxes:
        x1, y1, x2, y2 = map(int, box.xyxy[0].cpu().numpy())
        confidence = box.conf[0].cpu().numpy()

        if confidence > 0.5:  # 50% 이상 확신할 때만
            # 번호판 영역 크롭
            plate_img = img[y1:y2, x1:x2]

            # 전처리
            # 1. 그레이스케일 변환
            gray = cv2.cvtColor(plate_img, cv2.COLOR_BGR2GRAY)

            # 2. 크기 정규화 (가로 300px 기준)
            h, w = gray.shape
            new_w = 300
            new_h = int(h * (new_w / w))
            resized = cv2.resize(gray, (new_w, new_h))

            # 3. 대비 향상 (CLAHE)
            clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
            enhanced = clahe.apply(resized)

            # 4. 노이즈 제거
            denoised = cv2.fastNlMeansDenoising(enhanced, h=10)

            plates.append({
                'image': plate_img,
                'preprocessed': denoised,
                'confidence': confidence,
                'bbox': (x1, y1, x2, y2)
            })

    return plates

# 실행
plates = crop_and_preprocess(test_image_path, best_model)

# 결과 시각화
if plates:
    fig, axes = plt.subplots(len(plates), 2, figsize=(12, 4 * len(plates)))
    if len(plates) == 1:
        axes = [axes]
    for i, plate in enumerate(plates):
        axes[i][0].imshow(cv2.cvtColor(plate['image'], cv2.COLOR_BGR2RGB))
        axes[i][0].set_title(f"Cropped (conf: {plate['confidence']:.1%})")
        axes[i][0].axis('off')
        axes[i][1].imshow(plate['preprocessed'], cmap='gray')
        axes[i][1].set_title('Preprocessed')
        axes[i][1].axis('off')
    plt.tight_layout()
    plt.show()
else:
    print("번호판을 찾지 못했습니다.")
```

**전처리 각 단계:**

| 단계 | 처리 | 이유 |
|:----:|------|------|
| 1 | 그레이스케일 | 색상 정보 제거, OCR 성능 향상 |
| 2 | 크기 정규화 | 일관된 크기로 통일 |
| 3 | CLAHE (대비 향상) | 어두운/밝은 번호판 모두 잘 보이게 |
| 4 | 노이즈 제거 | 먼지, 흐림 등 제거 |

### 7-6단계: 문자 인식 (OCR)

```python
# ============================================
# 6단계: EasyOCR로 번호판 문자 인식
# ============================================

# EasyOCR 리더 초기화 (한국어 + 영어)
reader = easyocr.Reader(['ko', 'en'], gpu=True)
print("EasyOCR 초기화 완료 (한국어 + 영어)")

def recognize_plate(plate_image):
    """전처리된 번호판 이미지에서 문자를 인식"""
    # OCR 수행
    results = reader.readtext(plate_image)

    # 결과 정리
    texts = []
    for (bbox, text, confidence) in results:
        texts.append({
            'text': text,
            'confidence': confidence
        })
        print(f"  인식: '{text}' (확신도: {confidence:.1%})")

    # 전체 번호판 텍스트 조합
    full_text = ' '.join([t['text'] for t in texts])
    return full_text, texts

# 실행
if plates:
    for i, plate in enumerate(plates):
        print(f"\n--- 번호판 {i+1} ---")
        plate_text, details = recognize_plate(plate['preprocessed'])
```

### 7-7단계: 전체 파이프라인

```python
# ============================================
# 7단계: 전체 파이프라인 — 이미지 입력 → 번호판 텍스트 출력
# ============================================

def recognize_license_plate(image_path, yolo_model, ocr_reader):
    """
    자동차 이미지에서 번호판을 찾아 텍스트로 반환

    Args:
        image_path: 자동차 이미지 경로
        yolo_model: YOLOv8 번호판 탐지 모델
        ocr_reader: EasyOCR 리더

    Returns:
        list: 인식된 번호판 정보 목록
    """
    # 원본 이미지 로드
    img = cv2.imread(image_path)
    if img is None:
        print(f"이미지를 읽을 수 없습니다: {image_path}")
        return []

    # 1단계: 번호판 탐지
    detections = yolo_model(image_path)
    results = []

    for box in detections[0].boxes:
        x1, y1, x2, y2 = map(int, box.xyxy[0].cpu().numpy())
        det_confidence = box.conf[0].cpu().numpy()

        if det_confidence < 0.5:
            continue

        # 2단계: 번호판 크롭
        plate_img = img[y1:y2, x1:x2]

        # 3단계: 전처리
        gray = cv2.cvtColor(plate_img, cv2.COLOR_BGR2GRAY)
        clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
        enhanced = clahe.apply(gray)
        denoised = cv2.fastNlMeansDenoising(enhanced, h=10)

        # 4단계: OCR
        ocr_results = ocr_reader.readtext(denoised)
        plate_text = ' '.join([text for _, text, _ in ocr_results])
        ocr_confidence = np.mean([conf for _, _, conf in ocr_results]) if ocr_results else 0

        results.append({
            'text': plate_text,
            'detection_confidence': det_confidence,
            'ocr_confidence': ocr_confidence,
            'bbox': (x1, y1, x2, y2),
            'plate_image': plate_img,
            'preprocessed': denoised
        })

    return results


# 실행 및 시각화
image_path = 'test_images/car1.jpg'
```

### 7-8단계: 성능 평가

```python
# ============================================
# 8단계: 성능 평가
# ============================================

def evaluate_accuracy(test_dir, yolo_model, ocr_reader, ground_truth):
    """
    테스트 이미지에 대한 정확도 측정

    Args:
        test_dir: 테스트 이미지 폴더
        ground_truth: {파일명: 정답 번호판} 딕셔너리
    """
    correct = 0
    total = 0
    errors = []

    for filename, true_plate in ground_truth.items():
        image_path = os.path.join(test_dir, filename)
        if not os.path.exists(image_path):
            continue

        results = recognize_license_plate(image_path, yolo_model, ocr_reader)

        if results:
            predicted = results[0]['text'].replace(' ', '')
            true_clean = true_plate.replace(' ', '')

            total += 1
            if predicted == true_clean:
                correct += 1
            else:
                errors.append({
                    'file': filename,
                    'true': true_plate,
                    'predicted': results[0]['text'],
                })

    accuracy = correct / total * 100 if total > 0 else 0
    print(f"\n{'='*40}")
    print(f"  Total: {total} | Correct: {correct} | Accuracy: {accuracy:.1f}%")
    print(f"{'='*40}")

    if errors:
        print(f"\n  Errors ({len(errors)}):")
        for e in errors:
            print(f"    {e['file']}: '{e['true']}' → '{e['predicted']}'")

    return accuracy, errors
```

## 11. 용어 사전

| 용어 | 영어 | 설명 |
|------|------|------|
| 객체 탐지 | Object Detection | 이미지에서 물체의 위치와 종류를 찾는 기술 |
| YOLO | You Only Look Once | 실시간 객체 탐지 모델 (한 번 보고 위치+종류 판단) |
| OCR | Optical Character Recognition | 이미지에서 문자를 인식하는 기술 |
| 바운딩 박스 | Bounding Box | 탐지된 물체를 감싸는 사각형 |
| 파인튜닝 | Fine-tuning | 사전학습 모델을 특정 데이터로 추가 학습 |
| mAP | mean Average Precision | 객체 탐지 모델의 정확도 지표 |
| CLAHE | Contrast Limited Adaptive Histogram Equalization | 이미지 대비를 향상시키는 기법 |
| 크롭 | Crop | 이미지의 특정 영역만 잘라내기 |
| 파이프라인 | Pipeline | 여러 처리 단계를 순서대로 연결한 것 |
| 사전학습 | Pre-trained | 대규모 데이터로 미리 학습된 모델 |
