## 2. 데이터셋 선정

### 2-1. 데이터셋 비교

| 데이터셋 | 이미지 수 | 크기 | 특징 |
|----------|-----------|------|------|
| MNIST | 70,000장 | 28x28 px | 가장 유명한 숫자 데이터셋 |
| **EMNIST Digits** | **280,000장** | **28x28 px** | **MNIST의 4배, 다양한 필체 포함** |

### 2-2. 선정: EMNIST Digits

- **총 280,000장** (학습용 240,000 + 테스트용 40,000)
- MNIST와 동일한 28x28 흑백 포맷이라 초보자도 다루기 쉬움
- MNIST보다 4배 많은 데이터로 더 다양한 필체를 학습 가능
- TensorFlow에서 한 줄로 다운로드 가능

> **참고**: MNIST(7만 장)로 먼저 테스트 후 EMNIST(28만 장)로 확장하는 것도 좋은 전략입니다.

## 5. 단계별 상세 설명 및 코드

### 5-1단계: 데이터 준비

**목표**: EMNIST Digits 데이터셋을 다운로드하고, AI가 이해할 수 있는 형태로 변환

```python
# ============================================
# 1단계: 데이터 준비
# ============================================

import tensorflow as tf
import tensorflow_datasets as tfds
import numpy as np

# --- 방법 1: EMNIST Digits (28만 장, 권장) ---
# tensorflow_datasets 설치 (Colab에 이미 설치됨)
# EMNIST Digits 데이터셋 다운로드
emnist = tfds.load('emnist/digits', as_supervised=True)
train_ds = emnist['train']
test_ds = emnist['test']

# numpy 배열로 변환
x_train, y_train = [], []
for image, label in train_ds:
    x_train.append(image.numpy())
    y_train.append(label.numpy())
x_train = np.array(x_train)
y_train = np.array(y_train)

x_test, y_test = [], []
for image, label in test_ds:
    x_test.append(image.numpy())
    y_test.append(label.numpy())
x_test = np.array(x_test)
y_test = np.array(y_test)

# --- 방법 2: MNIST (7만 장, 더 간단) ---
# 아래 주석을 해제하면 MNIST로 대체 가능
# (x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
# x_train = x_train[..., np.newaxis]  # 채널 차원 추가
# x_test = x_test[..., np.newaxis]

# 데이터 정보 출력
print(f"학습 데이터: {x_train.shape} → {len(x_train)}장의 이미지")
print(f"테스트 데이터: {x_test.shape} → {len(x_test)}장의 이미지")
print(f"이미지 크기: {x_train.shape[1]}x{x_train.shape[2]} 픽셀")
print(f"라벨 종류: {np.unique(y_train)} → 0~9 숫자")
```

**코드 설명:**

| 코드 | 의미 |
|------|------|
| `tfds.load('emnist/digits')` | EMNIST Digits 데이터셋을 인터넷에서 다운로드 |
| `x_train` | 학습용 이미지들 (AI가 공부할 문제집) |
| `y_train` | 학습용 정답들 (문제집의 답안지) |
| `x_test` | 시험용 이미지들 (AI의 실력을 평가할 시험지) |
| `y_test` | 시험용 정답들 (시험의 답안지) |

> **비유**: AI 학습은 학생이 공부하는 것과 같습니다.
> - `x_train`/`y_train` = 연습 문제 + 해답 (공부용)
> - `x_test`/`y_test` = 시험 문제 + 해답 (실력 평가용)

### 5-2단계: 데이터 전처리 (정규화)

**목표**: 이미지 픽셀 값을 0~255에서 0~1로 변환하여 AI가 더 잘 학습하도록 함

```python
# ============================================
# 2단계: 데이터 전처리
# ============================================

# 픽셀 값을 0~1 범위로 정규화
# 원래 픽셀: 0(검정) ~ 255(흰색)
# 변환 후:   0.0 ~ 1.0
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0

print(f"정규화 전 픽셀 범위: 0 ~ 255")
print(f"정규화 후 픽셀 범위: {x_train.min()} ~ {x_train.max()}")
print(f"학습 데이터 shape: {x_train.shape}")
print(f"테스트 데이터 shape: {x_test.shape}")
```

**왜 정규화(Normalization)를 하나요?**

| 상태 | 픽셀 범위 | AI 학습 효과 |
|------|-----------|-------------|
| 정규화 전 | 0 ~ 255 | 큰 숫자 때문에 학습이 불안정하고 느림 |
| 정규화 후 | 0.0 ~ 1.0 | 작은 숫자로 학습이 안정적이고 빠름 |

> **비유**: 시험 점수를 100점 만점에서 1점 만점으로 바꾸는 것과 같습니다.
> 85점 → 0.85로 바꿔도 의미는 같지만, 계산이 더 쉬워집니다.

### 5-3단계: 데이터 탐색 (시각화)

**목표**: 데이터가 실제로 어떻게 생겼는지 눈으로 확인

```python
# ============================================
# 3단계: 데이터 탐색 - 샘플 이미지 확인
# ============================================

import matplotlib.pyplot as plt

# 학습 데이터에서 숫자 0~9 각각 1개씩 표시
fig, axes = plt.subplots(2, 5, figsize=(12, 5))

    idx = np.where(y_train == digit)[0][0]

print(f"\n  총합: {len(y_train):,}장")
```

| `imshow()` | 숫자 배열을 이미지로 화면에 표시 |

### 5-4단계: AI 모델 설계 (CNN)

**목표**: 이미지를 인식할 수 있는 AI의 "뇌 구조"를 설계

```python
# ============================================
# 4단계: CNN 모델 설계
# ============================================

from tensorflow.keras import layers, models

model = models.Sequential([
    # --- 첫 번째 특징 추출 블록 ---
    # Conv2D: 이미지에서 특징(선, 곡선, 모서리)을 찾는 필터
    layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    # MaxPooling2D: 이미지 크기를 절반으로 줄여 핵심만 남김
    layers.MaxPooling2D((2, 2)),

    # --- 두 번째 특징 추출 블록 ---
    # 더 복잡한 특징(숫자의 형태)을 찾음
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),

    # --- 세 번째 특징 추출 블록 ---
    # 가장 고수준의 특징(숫자 전체 모양)을 찾음
    layers.Conv2D(64, (3, 3), activation='relu'),

    # --- 분류기 ---
    # Flatten: 2D 이미지 특징을 1D 리스트로 변환
    layers.Flatten(),
    # Dense: 추출된 특징을 종합하여 판단
    layers.Dense(128, activation='relu'),
    # Dropout: 과적합 방지 (학습 시 일부 연결을 랜덤 차단)
    layers.Dropout(0.5),
    # 최종 출력: 0~9 각 숫자일 확률
    layers.Dense(10, activation='softmax')
])

# 모델 구조 요약 출력
model.summary()
```

**CNN(합성곱 신경망) 구조 설명:**

```
입력 이미지 (28x28)
    ↓
[Conv2D 32필터] → 선, 모서리 같은 기본 특징 추출
    ↓
[MaxPooling]    → 이미지 크기 축소 (14x14)
    ↓
[Conv2D 64필터] → 곡선, 원 같은 중간 특징 추출
    ↓
[MaxPooling]    → 이미지 크기 축소 (7x7)
    ↓
[Conv2D 64필터] → 숫자 전체 형태 파악
    ↓
[Flatten]       → 2D → 1D 변환
    ↓
[Dense 128]     → 특징들을 종합 판단
    ↓
[Dropout 0.5]   → 과적합 방지
    ↓
[Dense 10]      → 0~9 각 숫자일 확률 출력
```

**각 층(Layer) 상세 설명:**

| 층 | 역할 | 비유 |
|----|------|------|
| **Conv2D** | 이미지에서 패턴(선, 곡선)을 찾음 | 돋보기로 세부 특징 관찰 |
| **MaxPooling2D** | 이미지를 축소하여 핵심만 남김 | 요약본 만들기 |
| **Flatten** | 2D 데이터를 1D로 변환 | 표를 한 줄로 나열 |
| **Dense** | 모든 특징을 연결하여 판단 | 종합 의견 도출 |
| **Dropout** | 학습 시 뉴런 일부를 무작위로 끔 | 과도한 암기 방지 |
| **Softmax** | 각 숫자(0~9)일 확률을 출력 | "3일 확률 95%, 8일 확률 3%..." |

> **과적합(Overfitting)이란?**
> 학습 데이터를 너무 외워버려서 새로운 데이터는 못 맞추는 현상.
> 시험 범위만 달달 외운 학생이 응용 문제를 못 푸는 것과 같습니다.
> Dropout은 이를 방지하는 기법입니다.

### 5-5단계: 모델 컴파일 및 학습

**목표**: 설계한 모델을 실제로 학습시키기

```python
# ============================================
# 5단계: 모델 컴파일 (학습 방법 설정)
# ============================================

model.compile(
    optimizer='adam',              # 최적화 알고리즘 (가장 보편적)
    loss='sparse_categorical_crossentropy',  # 손실 함수
    metrics=['accuracy']           # 평가 지표: 정확도
)

# ============================================
# 모델 학습 시작
# ============================================

history = model.fit(
    x_train, y_train,          # 학습 데이터
    epochs=10,                  # 전체 데이터를 10번 반복 학습
    batch_size=128,             # 한 번에 128장씩 묶어서 학습
    validation_split=0.1,       # 학습 데이터의 10%를 검증용으로 분리
    verbose=1                   # 학습 진행 상황 표시
)
```

**용어 설명:**

| 용어 | 의미 | 비유 |
|------|------|------|
| **optimizer='adam'** | 학습 속도와 방향을 자동 조절하는 알고리즘 | 자동 기어 자동차 |
| **loss** | AI의 예측이 정답과 얼마나 다른지 측정 | 시험 오답 개수 |
| **epochs=10** | 전체 데이터를 10번 반복 학습 | 교과서를 10번 읽기 |
| **batch_size=128** | 한 번에 128장을 묶어 학습 | 128문제씩 풀고 채점 |
| **validation_split=0.1** | 학습 데이터의 10%로 중간 테스트 | 모의고사 |

> **학습 과정 이해:**
> - Epoch 1: 첫 번째 학습 → 정확도 약 90%
> - Epoch 5: 다섯 번째 학습 → 정확도 약 98%
> - Epoch 10: 열 번째 학습 → 정확도 약 99%
> - 반복할수록 AI가 점점 똑똑해집니다!

### 5-6단계: 성능 평가

**목표**: 학습된 모델이 처음 보는 데이터에서 얼마나 잘 작동하는지 확인

```python
# ============================================
# 6단계: 성능 평가
# ============================================

# 테스트 데이터로 최종 평가
test_loss, test_accuracy = model.evaluate(x_test, y_test, verbose=0)
print(f"\n{'='*40}")
print(f"  최종 테스트 정확도: {test_accuracy*100:.2f}%")
print(f"  최종 테스트 손실값: {test_loss:.4f}")
print(f"{'='*40}")

# 학습 과정 그래프 (정확도)
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 정확도 그래프
axes[0].plot(history.history['accuracy'], label='학습 정확도', linewidth=2)
axes[0].plot(history.history['val_accuracy'], label='검증 정확도', linewidth=2)
axes[0].set_title('Epoch별 정확도 변화', fontsize=14)
axes[0].set_xlabel('Epoch')
axes[0].set_ylabel('정확도')
axes[0].legend(fontsize=12)
axes[0].grid(True, alpha=0.3)

# 손실 그래프
axes[1].plot(history.history['loss'], label='학습 손실', linewidth=2)
axes[1].plot(history.history['val_loss'], label='검증 손실', linewidth=2)
axes[1].set_title('Epoch별 손실 변화', fontsize=14)
axes[1].set_xlabel('Epoch')
axes[1].set_ylabel('손실')
axes[1].legend(fontsize=12)
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

**그래프 읽는 법:**

| 그래프 | 좋은 상태 | 나쁜 상태 |
|--------|----------|----------|
| 정확도 | 학습/검증 모두 높고 비슷함 | 학습은 높은데 검증이 낮음 (과적합) |
| 손실 | 학습/검증 모두 낮고 비슷함 | 학습은 낮은데 검증이 높음 (과적합) |

### 5-7단계: 결과 시각화

**목표**: AI가 맞춘 것과 틀린 것을 눈으로 확인

```python
# ============================================
# 7단계: 예측 결과 시각화
# ============================================

# 테스트 데이터에 대한 예측
predictions = model.predict(x_test)

# --- 정답 예시 10개 ---
fig, axes = plt.subplots(2, 5, figsize=(14, 6))
fig.suptitle('AI가 맞춘 예시', fontsize=16, color='green')

correct_idx = np.where(np.argmax(predictions, axis=1) == y_test)[0]
for i, ax in enumerate(axes.flat):
    idx = correct_idx[i]
    ax.imshow(x_test[idx].squeeze(), cmap='gray')
    pred = np.argmax(predictions[idx])
    conf = np.max(predictions[idx]) * 100
    ax.set_title(f'예측: {pred} ({conf:.1f}%)', fontsize=11, color='green')
    ax.axis('off')
plt.tight_layout()
plt.show()

# --- 오답 예시 10개 ---
fig, axes = plt.subplots(2, 5, figsize=(14, 6))
fig.suptitle('AI가 틀린 예시', fontsize=16, color='red')

wrong_idx = np.where(np.argmax(predictions, axis=1) != y_test)[0]
for i, ax in enumerate(axes.flat):
    if i < len(wrong_idx):
        idx = wrong_idx[i]
        ax.imshow(x_test[idx].squeeze(), cmap='gray')
        pred = np.argmax(predictions[idx])
        true = y_test[idx]
        ax.set_title(f'예측: {pred} / 정답: {true}', fontsize=11, color='red')
    ax.axis('off')
plt.tight_layout()
plt.show()
```

### 5-8단계: 혼동 행렬 (Confusion Matrix)

**목표**: 어떤 숫자를 어떤 숫자로 잘못 인식하는지 패턴 파악

```python
# ============================================
# 8단계: 혼동 행렬
# ============================================

from sklearn.metrics import confusion_matrix, classification_report
import seaborn as sns

# 혼동 행렬 계산
y_pred = np.argmax(predictions, axis=1)
cm = confusion_matrix(y_test, y_pred)

# 히트맵으로 시각화
plt.figure(figsize=(10, 8))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
            xticklabels=range(10), yticklabels=range(10))
plt.title('혼동 행렬 (Confusion Matrix)', fontsize=16)
plt.xlabel('AI 예측값', fontsize=12)
plt.ylabel('실제 정답', fontsize=12)
plt.show()

# 상세 분류 리포트
print("\n숫자별 상세 성능:")
print(classification_report(y_test, y_pred, target_names=[str(i) for i in range(10)]))
```

**혼동 행렬 읽는 법:**
- 대각선 숫자가 클수록 좋음 (정답)
- 대각선 외의 숫자는 오답 (예: 행=4, 열=9이면 "4를 9로 잘못 인식")
- 흔한 혼동: 4↔9, 3↔8, 1↔7

### 5-10단계: 직접 그린 숫자로 테스트

**목표**: 사용자가 직접 마우스로 숫자를 그려서 AI에 입력

```python
# ============================================
# 10단계: 직접 그린 숫자 테스트
# ============================================

from google.colab import files
from PIL import Image
import io

# 방법 1: 파일 업로드로 테스트
print("숫자 이미지를 업로드하세요 (28x28 또는 자동 리사이즈)")
uploaded = files.upload()

for filename in uploaded.keys():
    # 이미지 로드 및 전처리
    img = Image.open(io.BytesIO(uploaded[filename]))
    img = img.convert('L')          # 흑백 변환
    img = img.resize((28, 28))      # 28x28로 리사이즈
    img_array = np.array(img) / 255.0
    img_array = img_array.reshape(1, 28, 28, 1)

    # 예측
    prediction = model.predict(img_array)
    predicted_digit = np.argmax(prediction)
    confidence = np.max(prediction) * 100

    # 결과 표시
    plt.figure(figsize=(4, 4))
    plt.imshow(img_array.squeeze(), cmap='gray')
    plt.title(f'예측: {predicted_digit} (확신도: {confidence:.1f}%)', fontsize=14)
    plt.axis('off')
    plt.show()

    # 각 숫자별 확률 표시
    print(f"\n각 숫자별 확률:")
    for i in range(10):
        bar = '█' * int(prediction[0][i] * 50)
        print(f"  {i}: {prediction[0][i]*100:5.1f}% {bar}")
```

## 9. 용어 사전

| 용어 | 영어 | 설명 |
|------|------|------|
| 합성곱 신경망 | CNN (Convolutional Neural Network) | 이미지 인식에 특화된 AI 구조 |
| 에폭 | Epoch | 전체 데이터를 1회 학습하는 단위 |
| 배치 | Batch | 한 번에 학습하는 데이터 묶음 |
| 과적합 | Overfitting | 학습 데이터만 잘 맞추고 새 데이터는 못 맞추는 현상 |
| 정규화 | Normalization | 데이터 값 범위를 일정하게 조정 |
| 손실 함수 | Loss Function | AI 예측의 오차를 측정하는 함수 |
| 활성화 함수 | Activation Function | 뉴런의 출력을 결정하는 함수 |
| 드롭아웃 | Dropout | 과적합 방지를 위해 뉴런을 랜덤으로 비활성화 |
| 소프트맥스 | Softmax | 출력을 확률(합=100%)로 변환하는 함수 |
| 혼동 행렬 | Confusion Matrix | 예측 결과의 정답/오답 분포를 보여주는 표 |
