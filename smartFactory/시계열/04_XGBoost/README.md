# 04. XGBoost — 칼날 마모율 예측 (슈레더 실제 적용 모델)

## 이 시뮬레이션이 보여주는 것

| 항목 | 내용 |
|------|------|
| **모델** | Gradient Boosting (XGBoost 계열) |
| **시나리오** | 센서 데이터로 칼날 마모율(0~100%)과 잔여수명(RUL) 예측 |
| **핵심 체험** | 특징 엔지니어링, 특징 중요도(해석), Edge 배포 가능한 경량 모델 |

pip install scikit-learn pandas numpy matplotlib

## XGBoost 시계열의 핵심: 특징 엔지니어링

```
원본 시계열:  [25.1, 25.3, 25.8, 26.5, 27.1, ...]

XGBoost 입력 (수동 변환):
  | 현재온도 | 1h전 | 6h전 | 24h전 | 6h평균 | 6h표준편차 | 변화율 | 시간 | 요일 |
  |  27.1   | 26.5 | 25.3 | 24.8  |  26.0  |   0.7     | +0.6  |  14 |  월  |

→ 시간 정보를 "특징"으로 변환하여 트리 모델에 입력
```

## 다른 모델과의 비교

| 비교 | Prophet | LSTM | XGBoost |
|:---:|:---:|:---:|:---:|
| 특징 생성 | 자동 | 자동 (시퀀스) | **수동 (핵심!)** |
| 해석 가능 | ✅ 분해 | ❌ 블랙박스 | **✅ 특징 중요도** |
| 추론 속도 | 느림 | 중간 | **<5ms (최고)** |
| Edge 배포 | 가능 | 가능 | **최적** |

## 핵심 교훈

- XGBoost는 **"무엇이 중요한지"** 알려줌 → 공장 현장에서 신뢰 획득
- **Edge 장비에 배포 최적** — 모델 크기 ~1MB, 추론 <5ms
- 단, **특징을 직접 만들어야** 하는 노력이 필요
