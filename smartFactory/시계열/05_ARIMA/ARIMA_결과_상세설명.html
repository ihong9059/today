0 ARIMA란?

💡 ARIMA = AI가 아닌 순수 수학 모델

딵러닝이나 머신러닝이 아닙니다. 통계학의 수식으로 예측합니다.

역할: 다른 AI 모델의 "기준선". "ARIMA보다 X% 더 정확합니다" → AI 도입 근거!

📊 ARIMA(p,d,q) = (2,1,1)의 의미
ARIMA(2, 1, 1): p=2 (Auto-Regressive) → "어제와 그제의 온도"를 참고하여 오늘 예측 → 비유: "어제 28°C, 그제 27°C였으니까 오늘은 29°C일 것" d=1 (Integrated) → 1차 차분 — "온도 자체"가 아닌 "온도의 변화량"을 사용 → 비유: "28°C"가 아니라 "어제 대비 +1°C"를 봄 → 트렌드(장기 상승/하강)를 제거하는 효과 q=1 (Moving Average) → "어제의 예측 오차"를 보정에 활용 → 비유: "어제 1°C 털렸으니까 오늘은 조금 보정"

ARIMA 예측 — 일평균 베어링 온도

위 그래프
👁️ 읽는 방법

파란 선 = Train (실제) / 초록 선 = Test (실제) / 빠간 점선 = ARIMA 예측

분홍 영역 = 불확실성 구간 (±2σ)

빠간 점선(예측)이 초록 선(실제)에 가까울수록 정확. ARIMA는 장기 예측이 거의 수평선으로 수렴하는 것이 특징! (← ARIMA의 한계)

그래프 2 ★

자기상관 함수 (ACF) — "과거 몇 일 전 데이터가 현재와 관련 있는가?"

💡 ARIMA를 이해하는 핵심 개념!

"자기상관"이란 "과거의 나와 현재의 나의 관계"입니다. 어제 온도가 높았으면 오늘도 높을 확률이 있는가?

막대 그래프 읽기: X축: Lag (일) — 1 = 1일 전, 7 = 7일 전(1주일 전), 14 = 2주일 전 Y축: 자기상관 계수 (-1 ~ +1) 막대가 높으면 (+1에 가까우면): → "그 시점의 데이터와 현재가 관련이 높다" → 예: 1일 전 높으면 오늘도 높을 가능성 큼 막대가 빠간 점선(신뢰 구간) 안에 있으면: → "통계적으로 의미 없는 상관" → 그 시점의 데이터는 예측에 도움 안 됨 이 그래프에서 관찰: Lag 1~3일: 막대가 높음 → 최근 1~3일 데이터가 예측에 유용 Lag 7일: 막대가 약간 높음 → 주간 패턴 존재 가능성 Lag 10일+: 막대가 낮아짐 → 오래전 데이터는 예측에 도움 안 됨
그래프 3

1차 차분 (d=1) — 트렌드 제거

💡 "차분"이란?

"온도 자체"가 아니라 "어제 대비 온도 변화량"을 사용하는 것입니다.

원본: [25, 26, 28, 27, 30] → 차분: [+1, +2, -1, +3]
트렌드(점점 올라가는 것)를 제거하면 "순수한 변동"만 닅게 되어 통계 방법이 작동합니다.

그래프 읽기: 보라색 선: 일간 온도 변화량 (°C/일) 검은 가로선: 0 (변화 없음) 빠간 점선: 평균 (-0.01°C/일) 대부분이 0 주변에서 위아래로 필득이면: → 트렌드가 제거되어 "정상 시계열"이 되었다는 뜻 → ARIMA가 잘 작동할 수 있는 조건 평균이 0이 아님면 (-0.01): → 약간의 잔여 트렌드가 있음 (완벽히 제거되지 않음)

★ ARIMA의 역할: Baseline (기준선)

💡 "Baseline"이란?

새 AI 모델을 도입할 때, "기본적인 방법보다 얼마나 더 좋은가?"를 비교하는 기준선입니다.
"ARIMA MAE=1.59°C인데, 우리 AI는 MAE=1.15°C입니다" → AI 도입 근거!

5개 모델 성능 비교 (이 시뮬레이션 결과): 모델 │ MAE │ 역할 ───────────┬─────────┬────────────────── ARIMA │ 1.59°C │ Baseline (기준선) Prophet │ 1.52°C │ 트렌드/계절성 분해 TFT │ 1.15°C │ 최고 성능 (다변량) XGBoost │ 4.53% │ 마모율 예측 (다른 타겟) LSTM │ 130건 │ 이상 탐지 (다른 타겟) ARIMA 대비: Prophet: 0.07°C 더 정확 (소폭) TFT: 0.44°C 더 정확 (상당한 개선!) ← AI 도입 근거
👉 결론

ARIMA는 "가장 단순한 방법으로 얼마나 할 수 있는가"를 보여줍니다. 이것보다 더 좋은 성능을 내는 AI 모델만 도입할 가치가 있습니다.
