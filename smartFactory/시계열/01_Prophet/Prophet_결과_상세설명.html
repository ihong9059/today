4개의 그래프를 하나하나 읽는 법 — 초보자용 완전 가이드

0 Prophet이란?

Prophet의 핵심 원리
y(t) = Trend + Seasonality + Noise
시계열 = 장기 방향 + 반복 패턴 + 랜덤 변동
💡 비유: 체중계에 올라가는 것처럼

체중 = 기본 체중(트렌드) + 식사 후 증가(일간 패턴) + 측정 오차(노이즈)

"기본 체중이 점점 늘고 있다"는 것을 알려면, 식사 후 증가와 측정 오차를 빼야 합니다. Prophet이 하는 일이 바로 이것입니다!

📊 이 시뮬레이션에서 사용한 데이터

센서: 베어링 온도 1개만 사용 (단변량)

기간: 90일 (2,160건, 시간 단위)

⚠️ Prophet은 온도 하나만 봅니다. 진동, 전류는 사용 불가! (단변량 모델의 한계)

그래프 1

전체 예측 그래프 — "AI가 온도를 맞춰보기"

위에서 첫 번째 그래프를 보세요
👁️ 그래프에서 보이는 것
  • 파란 점(···) = 실제 측정된 온도 데이터 (90일간)
  • 빨간 선(—) = AI가 예측한 온도
  • 분홍 영역 = 불확실성 구간 (95% 확률로 이 안에)
  • 초록 점선(│) = 학습/테스트 경계

읽는 방법

초록 점선 왼쪽 = AI가 "공부"한 영역. 이 데이터로 패턴을 학습했습니다.
초록 점선 오른쪽 = AI가 "맞춰보는" 영역. 빨간 선(예측)이 파란 점(실제)에 가까울수록 예측이 정확합니다.
파란 점이 톱니 모양으로 반복 = 일간 패턴! 낮에 가동하면 온도↑, 밤에 정지하면 온도↓
가끔 위로 튀는 점 (40~60°C) = 이상 이벤트! 배터리 발열 등으로 온도 급등
💡 MAE = 1.52°C의 의미

"평균적으로 예측이 실제와 1.52도 차이납니다". 베어링 온도 25~35°C 범위에서 1.52°C 오차는 괜찮은 수준입니다.

그래프 2

트렌드 — "칼날 마모로 온도가 서서히 상승"

💡 이 그래프가 답하는 질문

"온도가 올라가고 있는 건가, 아니면 그냥 이리저리 왔다 갔다 하는 건가?"
→ 트렌드 그래프를 보면 "아, 전체적으로 올라가고 있구나!" 확인 가능

트렌드 읽기: 1월 초: 약 25.3°C 3월 초: 약 30.5°C 90일간 약 5.2°C 상승 = 하루 약 0.06°C 상승 의미: "칼날이 마모되면서 파쇄 효율이 떨어지고, 같은 양을 파쇄하는 데 더 많은 에너지가 필요하여 베어링 온도가 서서히 올라가고 있다" → 이 트렌드가 계속되면 언제 위험 온도에 도달하는지 예측 가능! → "칼날 교체 시기"를 판단하는 근거가 됩니다
★ 왜 이것이 중요한가

실제 온도 데이터를 그냥 보면: 위아래로 계속 왔다갔다 → 올라가는 건지 모르겠

트렌드를 분리해서 보면: "아, 전체적으로 올라가고 있구나!" → 명확한 판단 가능

그래프 3

계절성 — "낮에 가동하면 온도↑, 밤에 정지하면 온도↓"

💡 비유: 출퇴근 시간의 교통량

매일 아침 8시에 교통량이 많아지고, 새벽 3시에는 택시도 없습니다. 이것이 "계절성"입니다. 슈레더도 매일 낮에 가동하면 온도가 올라가고, 밤에 내려갑니다.

막대 그래프 읽기: X축: 시간 (0시=자정, 12시=정오, 23시=밤 11시) Y축: 계절성 효과 (°C) — 평균 대비 얼마나 높거나 낮은지 양수 (+) 막대 (위쪽): 이 시간에 온도가 평균보다 "높다" 음수 (-) 막대 (아래): 이 시간에 온도가 평균보다 "낮다" 진폭: ±6.2°C → 하루 중 최대 12.4°C의 온도 차이가 "가동 패턴"에 의해 발생
★ 이것을 알면 할 수 있는 것

오전 10시에 35°C → 계절성 +5°C 포함 → 실제 기저 30°C → "정상" ✔

새벽 3시에 35°C → 계절성 -3°C인 시간 → 실제 기저 38°C! → "비정상!" ⚠️

그래프 4

잔차(노이즈) — "트렌드/계절성을 빼고 남은 것"

💡 비유: 시험 채점 후 남은 오차

시험 정답(트렌드+계절성)을 알고 있는데도 맞추지 못한 부분이 잔차입니다. 잔차가 작으면 "모델이 데이터를 잘 설명하고 있다"는 뜻입니다.

그래프 읽기: 보라색 선: 잔차 (트렌드+계절성을 뺀 나머지) 검은 가로선: 0 (잔차=0이면 완벽한 설명) 빨간 점선: ±2σ (±3.3°C) — 이 밖은 "이상" 대부분이 ±3°C 안에: → "트렌드+계절성으로 데이터의 대부분을 설명 가능" → Prophet이 잘 작동하고 있다는 증거! 가끔 크게 튀는 스파이크: → 트렌드/계절성으로 설명 못 하는 "이상 이벤트" → 배터리 발열, 이물질, 센서 오류 등
📊 잔차 표준편차 = 1.65°C의 의미

"트렌드와 계절성을 제거한 후에도 평균 1.65°C의 변동이 남아있다"

이 값을 더 줄이려면 = 다변량 모델(LSTM, TFT)이 필요 (진동, 전류 추가 활용)

∑ 4개 그래프의 관계

그래프 1 = 그래프 2 + 그래프 3 + 그래프 4 예: 3월 15일 오전 10시, 온도 35°C 트렌드 (그래프 2): 29°C (3월 중순의 기저 온도) + 계절성 (그래프 3): +5°C (오전 10시 가동 효과) + 잔차 (그래프 4): +1°C (그날의 랜덤 변동) ────────────────── = 합계 (그래프 1): 35°C ✔ 이렇게 분해할 수 있으므로: "35°C가 높은 건 가동(계절성) 때문이지, 이상은 아닙니다" 라는 판단이 가능해집니다. 만약 잔차가 +15°C라면? → "트렌드/계절성으로 설명 안 되는 이상 사건!" → 경보!

➔ Prophet의 한계 → 왜 LSTM이 필요한가

❌ Prophet이 못 하는 것

  • 온도만 봄 — 진동, 전류를 함께 볼 수 없음
  • "온도↑ + 진동↑ + 전류↑" 동시 변화 감지 불가
  • "지금 정상인가 이상인가" 판단 불가 (예측만 함)

✅ LSTM이 할 수 있는 것

  • 온도+진동+전류 3개를 동시에 분석
  • 3개 센서의 동시 변화 패턴 감지
  • "정상 패턴과 다르다" → 이상 탐지!
👉 결론

Prophet은 "내일 온도가 몇 도?"에 답하고, LSTM은 "지금 정상인가?"에 답합니다. 둘 다 필요하며, 서로 다른 목적에 사용합니다.
