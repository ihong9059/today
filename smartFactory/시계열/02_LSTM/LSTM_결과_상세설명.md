## LSTM Autoencoder란? (그래프를 읽기 전에)

```
Prophet의 목적:  "미래 온도가 몇 도일까?" → 예측
LSTM의 목적:     "지금 상태가 정상인가, 이상인가?" → 이상 탐지

LSTM Autoencoder의 원리:
  1. "정상 운전" 데이터만으로 학습 → 정상 패턴을 기억
  2. 새 데이터가 들어오면 → 기억한 정상 패턴으로 복원 시도
  3. 복원이 잘 되면 → "아, 이건 내가 아는 정상이다" ✅
  4. 복원이 안 되면 → "이건 내가 모르는 비정상이다!" 🚨

  비유:
  "평소에 친구 얼굴만 봐온 사람이,
   모르는 사람 얼굴을 보면 '어? 이건 다르다!'고 느끼는 것"
```

## 그래프 1: 원본 센서 데이터 (맨 위)

### 제목: "원본 센서 데이터 — 베어링 온도"

```
무엇이 보이는가:

  파란 선: 베어링 온도 (90일간, 2160건)
  초록 점선: 학습/테스트 경계선
```

### 읽는 방법

```
  온도
  (°C)
  60 ┤     ↑        ↑              ← 이상 고온 스파이크!
     │     │        │                (5% 확률로 발생한 이벤트)
  40 ┤     │        │
     │  ╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲          ← 일간 패턴 (톱니)
  30 ┤ ╱                 ╲╱╲╱╲
     │╱                         ╲╱
  20 ┤        ↑ 주말 (비가동 → 온도↓)
     │
     └──────────────────────────────── 시간
      1월    │    2월    │    3월
             초록 점선
          (여기서 학습/테스트 분리)

  ★ Prophet과 동일한 데이터이지만, LSTM은 이것을:
    Prophet: "미래 온도를 예측"하는 데 사용
    LSTM:    "정상 패턴을 기억"하는 데 사용
```

### 핵심 관찰 포인트

1. **초록 점선 왼쪽 (1월~3월 초)** = 학습 데이터
   - LSTM이 이 구간의 **정상 패턴을 기억**합니다
   - 일간 온도 변동, 주말 패턴 등을 학습

2. **초록 점선 오른쪽 (3월~4월)** = 테스트 데이터
   - 학습한 정상 패턴과 **비교**하여 이상을 감지
   - 위로 튀는 스파이크(40~60°C)가 이상으로 감지될 것!

3. **가끔 튀는 스파이크** (40~60°C)
   - 이것이 LSTM이 잡아내야 할 **이상 이벤트**
   - Prophet은 이걸 "노이즈"로 무시했지만, LSTM은 "이상"으로 감지!

## 그래프 2: 재구성 오차 (두 번째) ★ 가장 중요!

### 제목: "LSTM Autoencoder 재구성 오차 (높을수록 비정상)"

```
무엇이 보이는가:

  파란 선:   재구성 오차 (MSE) — 각 시점의 "이상 점수"
  빨간 점선: 임계값 (0.5498) — 이 위는 "이상"
  분홍 영역: 이상으로 감지된 구간 (임계값 초과!)
```

### 이것이 LSTM Autoencoder의 핵심 출력입니다!

```
  재구성
  오차(MSE)
  0.8 ┤    │    │       │  │           ← 높은 오차 = 비정상!
      │    │    │       │  │              (LSTM이 복원 못 함)
  0.6 ┤    │    │  │    │  │
      │────┤────┤──┤────┤──┤──── 임계값 (0.5498, 빨간 점선)
  0.5 ┤    │    │  │    │  │
      │    ↓    ↓  ↓    ↓  ↓
  0.4 ┤   분홍 영역 = "이상!" 경보
      │
  0.3 ┤ ~~~~~~~~~~~~~~~~~~~~           ← 낮은 오차 = 정상
      │  정상 범위 (오차 작음)            (LSTM이 잘 복원함)
  0.2 ┤
      └──────────────────────────── 시간
       3월 5일      3월 15일      3월 25일

  읽는 방법:

  1. 파란 선이 낮음 (0.3 이하):
     → "이 시점의 데이터는 내가 기억한 정상 패턴과 비슷하다"
     → 정상! ✅

  2. 파란 선이 빨간 점선 위로 튀어오름:
     → "이 시점의 데이터는 내가 기억한 정상과 다르다!"
     → 이상! 🚨 → 분홍 영역으로 표시

  3. 분홍 영역이 나타나는 시점:
     → 그래프 1에서 온도가 급등한 시점과 일치!
     → LSTM이 "이상 고온 이벤트"를 정확히 잡아냈다!
```

### "재구성 오차"란 무엇인가?

```
  LSTM Autoencoder의 작동 방식:

  입력 데이터 ──→ [Encoder] ──→ [압축] ──→ [Decoder] ──→ 복원 데이터
  (실제 센서값)    (패턴 추출)  (핵심만)   (패턴 복원)   (정상이면 원본과 같음)

  재구성 오차 = |입력 데이터 - 복원 데이터|²

  정상일 때:
    입력: [25.3, 2.5, 85.0]   (온도, 진동, 전류)
    복원: [25.1, 2.6, 84.8]   ← 비슷하게 복원됨!
    오차: 0.05                 ← 작음 → 정상

  이상일 때:
    입력: [55.0, 12.0, 130.0]  (온도·진동·전류 동시 급등!)
    복원: [27.0,  3.0,  87.0]  ← 정상 패턴으로 복원 시도했지만 전혀 다름
    오차: 3.85                  ← 큼! → 이상!
```

### 임계값 (0.5498)은 어떻게 정해지는가?

```
  학습 데이터(정상)의 재구성 오차 분포에서
  상위 5% 지점 (95 percentile)을 임계값으로 설정

  의미:
  "정상 데이터 중에서도 5%는 오차가 이 정도까지 올라갈 수 있다.
   하지만 이 위로 올라가면 정상이 아닐 가능성이 높다!"

  이 값을 조절하면:
  • 임계값 낮추면 → 더 민감하게 감지 (많이 잡지만 거짓 경보도 증가)
  • 임계값 높이면 → 덜 민감 (거짓 경보 줄지만 놓칠 수 있음)
```

## 그래프 3: 재구성 오차 분포 (세 번째)

### 제목: "재구성 오차 분포 — 정상 vs 테스트"

```
무엇이 보이는가:

  초록 막대: 학습(정상) 데이터의 오차 분포
  파란 막대: 테스트 데이터의 오차 분포
  빨간 점선: 임계값
```

### 읽는 방법

```
  빈도
  (건수)
     │
     │ ████
     │ ████████
     │ ██████████████
     │ ████████████████████ ← 초록: 정상 데이터 대부분이
     │ ██████████████████████   낮은 오차에 몰려 있음
     │ ████████████████████
     │ ██████████████████
     │ ████████████████           빨간
     │ ████████████████           점선│
     │ ██████████████              ↓ │
     │ ████████████    ░░░░        │ ░░░░ ← 파란: 테스트 중 일부가
     │ ████████      ░░░░░░░░     │ ░░░░░░  임계값 오른쪽에 있음
     │ ██████      ░░░░░░░░░░░░   │         = 이상으로 감지!
     └────────────────────────────┤──────────── 오차
      0.40  0.45  0.50  0.55  0.60  0.65  0.70

  핵심 해석:

  1. 초록(정상)과 파란(테스트)이 대부분 겹침
     → 테스트 데이터의 대부분도 정상!

  2. 파란 막대가 빨간 점선 오른쪽까지 퍼져 있음
     → 일부 테스트 데이터가 정상 범위를 벗어남 = 이상!
     → 총 130건(21.0%)이 이상으로 감지됨

  3. 두 분포가 완전히 분리되지는 않음
     → "정상과 이상의 경계"가 애매한 구간이 있음
     → 이 구간이 "주의" 또는 "경고" 수준
```

## 그래프 4: 다변량 동시 분석 (맨 아래) ★ LSTM의 핵심 장점!

### 제목: "★ LSTM의 강점: 다변량 동시 분석 (온도+진동+전류)"

```
무엇이 보이는가:

  빨간 선: 온도 (°C) — 왼쪽 Y축
  파란 선: 진동 × 5 (mm/s, 보기 쉽게 5배 확대) — 왼쪽 Y축
  초록 선: 전류 (A) — 오른쪽 Y축
```

### 읽는 방법

```
  이 그래프가 보여주는 핵심:

  "LSTM은 3개 센서를 동시에 보고 판단한다!"

  ┌─────────────────────────────────────────────────┐
  │                                                   │
  │  Prophet이 보는 것:                               │
  │  [온도 하나]                                      │
  │                                                   │
  │  LSTM이 보는 것:                                  │
  │  [온도] + [진동] + [전류] ← 3개를 동시에!        │
  │                                                   │
  │  왜 이것이 중요한가?                              │
  │                                                   │
  │  상황 1: 온도만 올라가고 진동/전류는 정상         │
  │  → "외부 환경 온도 상승일 뿐, 설비 이상 아님"   │
  │  → Prophet: 경보! (온도만 봐서) ← 거짓 경보      │
  │  → LSTM: 정상 (다른 센서가 정상이므로) ✅        │
  │                                                   │
  │  상황 2: 온도↑ + 진동↑ + 전류↑ 동시에            │
  │  → "베어링에 문제 발생! 3개가 동시에 변했다!"    │
  │  → LSTM: 이상! 🚨 (3개 센서의 동시 변화 감지)    │
  │                                                   │
  │  상황 3: 전류만 갑자기 치솟음                     │
  │  → "이물질 끼임 가능성!"                         │
  │  → LSTM: 전류 이상 패턴 감지! 🚨                 │
  │  → Prophet: 감지 불가 (전류를 안 봄)              │
  │                                                   │
  └─────────────────────────────────────────────────┘
```

### 그래프에서 관찰할 포인트

```
  시간 흐름 →

  정상 구간:
  온도 ~~~~~ (25~30°C 안에서 일간 패턴)
  진동 ~~~~~ (2~4 mm/s 안에서 안정)
  전류 ~~~~~ (80~100A 안에서 안정)
  → 3개 모두 안정적 → LSTM: "정상" ✅

  이상 구간 (스파이크):
  온도 ▲▲▲ (갑자기 50°C+)
  진동 ▲▲  (동시에 진동 증가)
  전류 ▲   (부하 증가)
  → 3개가 동시에 이상 → LSTM: "이상!" 🚨
  → 그래프 2에서 이 시점의 재구성 오차가 급등!
```

## Prophet vs LSTM 결과 비교 종합

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Prophet 결과:                                                   │
│  ├── 4개 그래프: 예측 + 트렌드 + 계절성 + 잔차                 │
│  ├── "미래 온도는 몇 도일까?" → 예측 (MAE 1.52°C)             │
│  ├── "왜 올라가는가?" → 트렌드 그래프로 설명                   │
│  └── 단변량: 온도 하나만 사용                                   │
│                                                                 │
│  LSTM 결과:                                                      │
│  ├── 4개 그래프: 원본 + 이상점수 + 분포 + 다변량               │
│  ├── "지금 정상인가 이상인가?" → 이상 탐지 (130건 감지)        │
│  ├── "얼마나 이상한가?" → 재구성 오차로 수치화                 │
│  └── 다변량: 온도+진동+전류 3개 동시 사용                      │
│                                                                 │
│  ★ 핵심 차이:                                                   │
│  Prophet = "내일 온도가 몇 도?" (예측)                          │
│  LSTM    = "지금 정상인가?"     (감시)                          │
│                                                                 │
│  → 둘 다 필요! 서로 다른 목적에 사용                           │
│  → 슈레더에서: Prophet(장기 트렌드) + LSTM(이상 탐지)          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 실제 슈레더에서의 활용

```
LSTM Autoencoder가 슈레더에서 하는 일:

  1. 정상 운전 28일 데이터로 학습
     → "정상일 때 온도·진동·전류의 패턴"을 기억

  2. 이후 실시간으로 매 1초마다:
     → 최근 30초 데이터를 LSTM에 입력
     → 재구성 오차 계산
     → 오차가 임계값 초과 시 경보

  3. 경보 등급:
     이상 점수 0.0~0.3: 정상 (Green)
     이상 점수 0.3~0.5: 주의 — 모니터링 강화
     이상 점수 0.5~0.7: 경고 — 정비 계획 수립
     이상 점수 0.7~0.9: 위험 — 조기 정비 권고
     이상 점수 0.9~1.0: 긴급 — 즉시 정지 권고

  → 사람이 24시간 감시할 수 없는 것을 AI가 대신!
```
