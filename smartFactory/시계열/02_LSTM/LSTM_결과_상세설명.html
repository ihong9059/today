LSTM의 질문

"지금 상태가 정상인가?"
→ 이상 탐지 (Anomaly Detection)

LSTM Autoencoder의 원리
재구성 오차 = |입력 - 복원|²
정상이면 복원 잘 됨 → 오차 작음 → 정상!
이상이면 복원 못 됨 → 오차 큼 → 이상!
💡 비유: 친구 얼굴 알아보기

평소에 친구들 얼굴만 븐온 사람이

친구가 오면: "아, 이 얼굴 알아!" → 복원 성공 → 오차 작음 = 정상 ✔

모르는 사람이 오면: "어? 이건 달라!" → 복원 실패 → 오차 큼 = 이상! 🚨

그래프 1

원본 센서 데이터 — 베어링 온도

위에서 첫 번째 그래프를 보세요
👁️ Prophet 그래프 1과 동일한 데이터!

같은 온도 데이터지만, 목적이 다릅니다:

  • Prophet: 이 데이터로 "미래 온도를 예측"
  • LSTM: 이 데이터로 "정상 패턴을 기억" → 비정상 감지
초록 점선 왼쪽 (1월~3월 초) = LSTM이 "정상이란 건 이런 것이다"라고 기억하는 구간
초록 점선 오른쪽 (3월~4월) = 기억한 정상과 비교하여 이상을 감지하는 구간
위로 튜는 스파이크 (40~60°C) = 이상 이벤트! LSTM이 "이건 내가 모르는 패턴!"이라고 감지할 것
그래프 2 ★

재구성 오차 — ★ 가장 중요한 그래프!

🔥 이것이 LSTM Autoencoder의 핵심 출력입니다!

"각 시점에서 데이터가 정상과 얼마나 다르가?"를 수치로 보여줍니다.

그래프에서 보이는 것: 파란 선(—): 재구성 오차 (MSE) — 각 시점의 "이상 점수" 빠간 점선(--): 임계값 (0.5498) — 이 위는 "이상" 분홍 영역: 이상으로 감지된 구간!

읽는 방법

파란 선이 낮음 (0.3 이하): → "이 시점의 데이터는 내가 기억한 정상 패턴과 비슷하다" → 정상! ✔ 파란 선이 빠간 점선 위로 튜어올람: → "이 시점의 데이터는 내가 기억한 정상과 다르다!" → 이상! 🚨 → 분홍 영역으로 표시 분홍 영역이 나타나는 시점: → 그래프 1에서 온도가 급등한 시점과 일치! → LSTM이 "이상 고온 이벤트"를 정확히 잡아낸다!

"재구성 오차"란 무엇인가?

💡 쉽게 설명

정상일 때:

입력: [25.3°C, 2.5mm/s, 85A] (온도, 진동, 전류)

복원: [25.1°C, 2.6mm/s, 84.8A] ← 비슷하게 복원됨!

오차: 0.05 ← 작음 = 정상 ✔

이상일 때:

입력: [55.0°C, 12.0mm/s, 130A] (3개 모두 급등!)

복원: [27.0°C, 3.0mm/s, 87A] ← 정상 패턴으로 복원 시도했지만 전혀 다름

오차: 3.85 ← 큼! = 이상! 🚨

임계값 (0.5498)은 어떻게 정해지는가?

📊 임계값 = 학습 데이터(정상)의 상위 5%

"정상 데이터 중에서도 5%는 오차가 이 정도까지 올라갔 수 있다. 하지만 이 위로 올라가면 정상이 아닐 가능성이 높다!"

임계값을 낮추면 → 더 민감하게 감지 (거짓 경보도 증가)
임계값을 높이면 → 덜 민감 (놓칠 수 있음)

그래프 3

재구성 오차 분포 — 정상 vs 테스트

그래프에서 보이는 것: 초록 막대: 학습(정상) 데이터의 오차 분포 파란 막대: 테스트 데이터의 오차 분포 빠간 점선: 임계값 읽는 방법: 초록(정상)과 파란(테스트)이 대부분 겹침 → 테스트 데이터의 대부분도 정상! 파란 막대가 빠간 점선 오른쪽까지 퍼져 있음 → 일부 테스트 데이터가 정상 범위를 벗어났 = 이상! → 총 130건(21.0%)이 이상으로 감지됨
그래프 4 ★

★ LSTM의 강점: 다변량 동시 분석 (온도+진동+전류)

🔥 이것이 Prophet과의 가장 큰 차이입니다!

Prophet은 온도 1개만 봄니다. LSTM은 온도+진동+전류 3개를 동시에 봄니다!

그래프에서 보이는 것: 빠간 선: 온도 (°C) — 왼쪽 Y축 파란 선: 진동 ×5 (mm/s, 보기 쉽게 5배) — 왼쪽 Y축 초록 선: 전류 (A) — 오른쪽 Y축

💡 핵심

LSTM은 "3개 센서의 동시 변화 패턴"을 감지합니다. 온도만 올라가면 외부 요인일 수 있지만, 온도+진동+전류가 동시에 올라가면 설비에 문제가 있다는 것입니다!

⚙ 실제 슬레더에서의 활용

LSTM Autoencoder가 슬레더에서 하는 일: 1. 정상 운전 28일 데이터로 학습 → "정상일 때 온도·진동·전류의 패턴"을 기억 2. 이후 실시간으로 매 1초마다: → 최근 30초 데이터를 LSTM에 입력 → 재구성 오차 계산 → 오차가 임계값 초과 시 경보

👉 결론

Prophet과 LSTM은 경쟁 관계가 아니라 협력 관계입니다. Prophet으로 장기 트렌드를 파악하고, LSTM으로 실시간 이상을 감지합니다. 슬레더 AI 시스템에서는 둘 다 사용합니다!
