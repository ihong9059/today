## LSTM Autoencoder가 하는 일

```
정상 데이터 입력 → Encoder(압축) → Bottleneck → Decoder(복원)
                                                    ↓
                    정상이면 복원 잘 됨 → 오차 작음 → 정상 판정
                    이상이면 복원 못 함 → 오차 큼  → 이상 판정!
```

## Prophet과의 차이

| 비교 | Prophet | LSTM |
|:---:|:---:|:---:|
| 입력 변수 | 1개 (단변량) | **여러 개 (다변량)** |
| 목적 | 미래 값 예측 | **이상 패턴 감지** |
| 학습 데이터 | 정상+이상 혼합 OK | **정상 데이터만 필요** |
| 해석 | 쉬움 (분해) | 어려움 (블랙박스) |

## 핵심 교훈

- LSTM은 **"기억력"**이 있어 시간에 따른 패턴 변화를 추적
- Autoencoder는 **이상 데이터 없이도** 이상 탐지 가능 (정상만 학습)
- **슈레더 베어링 이상 탐지**에 실제로 사용되는 모델
