고장예지 #1 베어링 이상 탐지 ★★★

한 줄 요약: 정상 진동 패턴을 학습한 AI가 "평소와 다른" 진동을 감지하면 알림을 보냅니다.
병원에서 건강검진을 받을 때, 의사가 "정상 수치"를 알기 때문에 "비정상"을 찾을 수 있는 것처럼, 이 AI도 "정상 진동"을 완벽히 학습하여 조금이라도 이상한 패턴이 나타나면 바로 감지합니다.
베어링이 갑자기 파손되면 슈레더 전체가 멈추고 수리에 수일이 걸립니다. 조기에 이상 징후를 잡으면 계획된 정비로 대체할 수 있어 다운타임과 비용을 80% 이상 줄일 수 있습니다.

고장예지 #2 칼날 마모 예측 ★★☆

한 줄 요약: 24개 센서 데이터를 종합해서 "칼날이 몇 % 마모됐고, 교체까지 몇 시간 남았는지" 예측합니다.
자동차 타이어의 마모도를 직접 보지 않고도, 주행거리, 도로 종류, 운전 습관 등 여러 정보를 종합해 "타이어 교체까지 약 5,000km 남았다"고 예측하는 것과 같습니다.
칼날이 너무 마모되면 파쇄 품질이 떨어지고, 과부하로 모터가 손상될 수 있습니다. 미리 교체 시점을 알면 비계획 정지 없이 효율적으로 관리할 수 있습니다.

고장예지 #3 축 불균형 진단 ★☆☆

한 줄 요약: 진동의 주파수 성분을 분석해서 축이 불균형한지, 정렬이 틀어졌는지 물리법칙으로 판별합니다.
세탁기가 탈수할 때 "쿵쿵" 소리가 나면 빨래가 한쪽에 쏠렸다는 뜻입니다. 소리(진동)의 패턴만으로 원인을 알 수 있는 것과 같은 원리입니다.
이것은 AI가 아닌 물리법칙 기반 진단입니다. 50년 이상 검증된 방법으로 신뢰도가 매우 높습니다. 1X(회전 주파수)가 높으면 불균형, 2X가 높으면 미스얼라인먼트입니다.
FFT 주파수 분석 — 1X, 2X 성분으로 고장 판별
패턴진단원인조치
1X 성분 증가불균형칼날 파손, 이물질 부착밸런싱, 칼날 점검
2X 성분 증가미스얼라인먼트축 정렬 불량축 재정렬
고주파 증가베어링 결함내외륜 손상베어링 교체
불규칙 충격기어 결함기어 이 손상기어박스 점검

믹서기에 단단한 얼음 덩어리가 들어가면 모터 소리가 확 커지고(전류 증가) 칼날이 느려지는(속도 감소) 것과 같습니다.

사고예방 #5 발화 감지 ★★☆

한 줄 요약: 온도 변화율 + 절대 온도 + 가스/진동 융합 — 3중 판단으로 100ms 이내에 발화를 감지합니다.
소방관이 불을 판단할 때: (1) 온도가 빠르게 올라가는지, (2) 이미 위험한 온도인지, (3) 연기 냄새가 나는지 — 3가지를 동시에 확인하는 것과 같습니다.
배터리 파쇄 시 열폭주(thermal runaway)는 수 초 만에 진행됩니다. 100ms 이내에 감지하지 못하면 대형 화재로 이어질 수 있습니다.
발화 감지 3중 판단 플로우차트

사고예방 #6 분진 폭발 예측 ★★☆

한 줄 요약: CUSUM(누적합)으로 "서서히 올라가는 위험"을 감지합니다. 일반 임계값은 놓치는 위험을 잡습니다.
체중계에서 매일 100g씩 늘면 하루하루는 무시하기 쉽지만, 한 달이면 3kg입니다. CUSUM은 이런 "느린 변화"를 누적해서 추적합니다.
CUSUM vs 일반 임계값 비교
CUSUM 공식: S(t) = max(0, S(t-1) + (x(t) - mu - k))
S(t)가 임계값 h를 초과하면 경보 발생. k는 민감도, h는 임계값.

사고예방 #7 전해액 누출 감지 ★★☆

한 줄 요약: VOC + H2 + CO 3가지 가스를 동시 분석해서, 하나만으로 판단할 때의 오판을 방지합니다.
의사가 환자를 진단할 때, 열(VOC)만 보고 "감기"라 하지 않고, 기침(H2), 콧물(CO)까지 종합해서 정확한 진단을 내리는 것과 같습니다.
Multi-gas Fusion 판정 매트릭스

품질관리 #8 파쇄 크기 예측 ★★☆

한 줄 요약: 200개 결정나무의 다수결로 파쇄 크기를 예측합니다. 고온/분진 환경에서 직접 측정이 불가해 간접 측정합니다.
날씨 예보처럼, 기온/습도/기압/풍속 같은 간접 정보를 종합해서 "비가 올 확률 80%"라고 예측하는 것과 같습니다. 200명의 기상전문가(나무)가 각자 예측하고, 다수결로 최종 결정합니다.
파쇄 크기가 규격에 맞지 않으면 후공정(재활용)에서 문제가 됩니다. 하지만 슈레더 내부는 고온 + 분진 + 진동이 심해 카메라나 레이저 센서를 직접 설치할 수 없어 간접 예측이 필수입니다.
항목내용
알고리즘Random Forest여러 결정나무가 각자 예측하고 다수결로 결정하는 앙상블 기법. 개별 나무보다 훨씬 안정적 (200 trees)
입력RPM, 전류, 진동, 재료 종류, 투입량

품질관리 #9 RPM 최적화 ★☆☆

운전할 때 네비가 "고속도로에서 100km/h"라고 알려주고(Look-up Table), 실제 도로 상황에 따라 악셀/브레이크를 조절하는 것(PID)과 같습니다.

2 OPC UA / EtherCAT 통신 방식 ▼

핵심 결론: 슈레더 단독 시스템에서 EtherCAT은 불필요합니다. 직접 연결 + Modbus + OPC UA + MQTT 조합이 비용 대비 최적입니다.

OPC UA란?

여러 나라 사람이 모인 국제회의에서 "영어"를 공용어로 쓰는 것과 같습니다. 서로 다른 제조사의 장비들이 OPC UA라는 공통 언어로 소통합니다.
  • 산업 표준 통신 프로토콜
  • 제조사 독립적 (Siemens, ABB, Rockwell 모두 지원)
  • 보안 내장 (인증서, 암호화)
  • Safety PLC와 연동에 적합

EtherCAT이란?

열차 배달 시스템과 같습니다. 데이터 패킷이 "열차"처럼 모든 장치를 한 바퀴 돌면서, 각 장치가 자기 데이터를 싣고 내립니다. 한 바퀴에 125us ~ 1ms!
  • 초고속 실시간 (125us ~ 1ms)
  • 모션 제어, 로봇팔 등에 적합
  • 전용 하드웨어 필요 → 비용 높음
  • 슈레더에는 과도한 스펙!

5 Docker 사용 이유와 방법 ▼

한 줄 요약: Docker는 앱을 "표준 상자"에 담아 어디서든 동일하게 실행하는 기술입니다. 격리, 이식성, 쉬운 업데이트, 롤백이 핵심 장점입니다.

Docker란 무엇인가?

이사할 때 모든 짐을 표준 규격의 "이삿짐 상자"에 넣으면, 어떤 트럭이든 실을 수 있고, 어떤 집이든 풀 수 있습니다. Docker 컨테이너도 마찬가지로 앱과 필요한 모든 것을 하나의 상자에 담습니다.

1. Dockerfile 예시 (ai-pdm)

Dockerfile 
# NVIDIA JetPack 기반 이미지
FROM nvcr.io/nvidia/l4t-pytorch:r36.2-pth2.1-py3

# 작업 디렉토리 설정
WORKDIR /app

# 의존성 설치
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 애플리케이션 코드 복사
COPY src/ ./src/
COPY models/ ./models/

# 환경 변수
ENV NVIDIA_VISIBLE_DEVICES=all
ENV MODEL_PATH=/app/models

# 실행
CMD ["python", "src/pdm_service.py"]

3. 자주 사용하는 명령어

bash 
# 이미지 빌드
docker build -t ai-pdm:v1.0 ./ai-pdm

# 컨테이너 실행
docker run -d --name ai-pdm --runtime nvidia ai-pdm:v1.0

# 전체 서비스 시작 (Compose)
docker compose up -d

# 상태 확인
docker ps

# 로그 확인
docker logs -f ai-pdm

# 업데이트 (무중단)
docker compose up -d --no-deps ai-pdm

# 롤백 (이전 버전으로)
docker tag ai-pdm:v1.0 ai-pdm:rollback
docker compose up -d
