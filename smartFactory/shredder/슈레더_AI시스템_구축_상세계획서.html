프로젝트 개요 — 왜, 무엇을, 어떻게

왜 슬레더 AI 시스템이 필요한가

❌ 현재 상황

  • 칼날 마모 — 육안 점검, 경험 기반 교체
  • 화재/폭발 — IR 센서 단일, 수동 대응
  • 파쇄 품질 — 수시간 간격 샘플링

비계획 정지 연 40시간+, 손실 연 1억원+

✅ AI 시스템 도입 후

  • 칼날 RUL 예측 — 마모율(%) + 잔여수명(h) 자동 예측
  • 발화 감지 <1초 — 이중화 IR + 다중 판단 + 자동 대응
  • 파쇄 크기 실시간 — AI 기반 간접 추정 + RPM 최적화

비계획 정지 70%↓, 발화 감지 <1초, 품질 편차 ±5%

왜 슬레더부터 시작하는가

이유설명
가장 높은 위험배터리 열폭주·화재·폭발이 가장 먼저 발생하는 공정
가장 큰 영향1차 공정이 멘추면 전체 라인 정지 (병목)
즉각적 효과센서 14개 + Edge 1대로 빠르게 구축, 효과 입증 가능
확장 기반슬레더에서 검증된 시스템을 2차→3차→분급으로 확장

시스템 아키텍처

4-LEVEL ARCHITECTURE ═══ Level 3: 서버/클라우드 (장기 분석 · 모델 학습) ═══ 데이터 레이크 (S3) │ AI 학습 서버 (GPU) │ 대시보드 (Grafana) │ 1GbE / MQTT ═══ Level 2: Edge AI (실시간 추론 · 현장 판단) ═══ NVIDIA Jetson Orin NX 16GB ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │고장 예지│ │사고 예방│ │품질 관리│ │연계 분석│ │ 4모델 │ │ 3모델 │ │ 2모델 │ │ 1모델 │ └────────┘ └────────┘ └────────┘ └────────┘ TimescaleDB — 30일 로컬 저장 │ OPC UA / Modbus ═══ Level 1: 제어 (Safety PLC 독립) ═══ Safety PLC (비상정지/소화/N₂) │ Process PLC (RPM/피더) ═══ Level 0: 센서 · 이축 전단 파쇄기 ═══ 진동×2 │ 온도×3 │ 전류×2 │ 속도×2 │ 안전×4 │ 품질×1 = 14개 ╔══════════════════════════════════════╗ ║ SHREDDER — 2×55kW │ 15~25RPM │ N₂ 방폭 ║ ╚══════════════════════════════════════╝
🔒 핵심 설계 원칙: Safety PLC 독립

Edge AI가 다운되어도 비상정지·소화는 Safety PLC가 독립적으로 작동합니다. 배터리 발화는 AI 오류와 무관하게 대응 필수입니다.

AI 모델 설계 — 10종

A. 고장 예지 (4종)

#1
📈

베어링 이상 탐지

LSTM Autoencoder
VIB-A/B FFT(1024 bins) → 정상 패턴 학습 → 재구성 오차 = 이상 점수 (0~1)
⏱ <10ms🎯 95%+
#2
🔨

칼날 마모 예측

Gradient Boosting (XGBoost)
전류+속도+진동 24개 특징 → 마모율(%) + 잔여수명 RUL(h)
⏱ <5ms🎯 92%+
#3
♾

축 불균형 진단

Classical DSP (FFT 1X)
VIB-A/B 1X 성분 → 불균형 레벨 (mm/s)
⏱ <1ms🎯 98%+
#4
⚠️

이물질 끼임 감지

실시간 패턴 인식
CUR 스파이크 + SPD 급변 → 끼임 확률
⏱ <5ms🎯 95%+

B. 사고 예방 (3종)

#5
🔥

발화 감지

Rate-of-Change + Anomaly Detection
TMP-IR 이중화 + 다중 판단 체계 → 발화 확률 + 위치
Safety PLC 독립 이중화
⏱ <100ms🔥 긴급
#6
💨

분진 폭발 예측

CUSUM + 트렌드
DST-1 누적 편차 감시 → 폭발 위험도 (0~1)
⏱ <500ms
#7
🧪

전해액 누출 감지

Multi-gas Fusion
GAS-1 (VOC/H₂/CO) 복합 패턴 → 누출 확률 + 가스 종류
⏱ <1s

C. 품질 관리 (2종) + 연계 분석 (1종)

#8
📏

파쇄 크기 예측

Random Forest
전류+속도+처리량 12개 특징 → 예상 크기(mm), 균일도(%)
⏱ <5ms
#9
⚙️

RPM 최적화

PID 제어 + 룰 기반
파쇄 크기 예측값 기반 → 최적 RPM 권고 (±1~2)
⏱ <100ms
#10
📊

통합 건강 점수 (Ensemble)

가중 평균 — 설비(40%) + 안전(35%) + 품질(25%)
전체 9개 모델 출력을 종합하여 슬레더 건강 점수 (0~100) 산출. 90~100: 최적(Green) / 70~89: 양호(Blue) / 50~69: 주의(Yellow) / 30~49: 경고(Orange) / 0~29: 위험(Red)
⏱ <100ms📊 대시보드 메인 지표

4단계: 실운영 전환

13~16주
  • AI 기반 알림 활성화
