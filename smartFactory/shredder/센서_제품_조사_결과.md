## 구매 시 주의사항

1. **방폭 인증**: 배터리 파쇄 환경은 가연성 분진/가스 위험. 가스 센서와 분진 센서는 반드시 ATEX/KCs 방폭 인증 확인
2. **납기**: 산업용 센서는 일반적으로 4~8주 리드타임. 사전 발주 필요
3. **교정**: 진동 센서(ISO 17025), 가스 센서(정기 교정 6개월~1년) 유지보수 계획 수립
4. **호환성**: Edge AI Gateway (Jetson Orin NX)와의 인터페이스 확인
   - IEPE 센서 → DAQ 모듈(NI 9234 등) 경유
   - 4-20mA 센서 → ADC 모듈 경유
   - 디지털 센서 → RS485/Modbus 직결
5. **환경 등급**: 슈레더 주변 온도, 분진, 수분 조건에 맞는 IP 등급 선택
6. **한국 내 대리점**: 주요 브랜드별 한국 대리점
   - PCB/IMI: 한국PCB (주)
   - Sick: 식코리아
   - Pepperl+Fuchs: 피플앤퓨스 코리아
   - Siemens: 한국지멘스
   - Draeger: 드레거코리아
   - Baumer: 바우머코리아 또는 대리점
   - LEM: 한국 대리점 (반도체 유통사 경유)
   - WIKA: 위카코리아
