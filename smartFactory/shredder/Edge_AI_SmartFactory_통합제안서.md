## 1. Executive Summary

### 1.1 제안 배경

폐배터리 재활용 산업은 전기차 보급 확대에 따라 폭발적 성장이 예상되나, 현장에서는 다음 3가지 핵심 과제에 직면하고 있습니다:

| 과제 | 현재 수준 | 목표 수준 | 핵심 위험 |
|------|:---------:|:---------:|----------|
| **설비 가동률** | 85% (비계획 정지 연 120시간) | 97% (비계획 정지 연 36시간) | 생산 손실 연 3억원 |
| **유가금속 회수율** | 92% | 98% | 원재료 손실 연 6%p |
| **안전사고** | 연 2~3건 경미사고 | Zero Accident | 열폭주·화재·폭발 위험 |

### 1.2 제안 솔루션

**Edge AI 통합 플랫폼**은 현장 설비에 직접 설치되는 엣지 컴퓨팅 기반 AI 시스템으로, 3가지 과제를 **하나의 통합 플랫폼**에서 동시에 해결합니다:

### 1.3 핵심 차별점: "왜 Edge AI인가?"

| 비교 항목 | 클라우드 AI | **Edge AI (본 제안)** |
|----------|:-----------:|:--------------------:|
| **응답 시간** | 100ms~2s (네트워크 지연) | **<10ms (실시간)** |
| **안전 기능** | 네트워크 단절 시 무력화 | **독립 작동 (Fail-safe)** |
| **데이터 보안** | 외부 전송 필요 | **현장 처리 (데이터 유출 無)** |
| **운영 비용** | 월 클라우드 비용 발생 | **초기 투자 후 추가 비용 최소** |
| **배터리 발화 대응** | 지연 가능 (치명적) | **즉시 대응 (인명 보호)** |

> **핵심**: 배터리 파쇄 공정은 **열폭주→화재→폭발**이 수초 내 발생합니다. 클라우드 왕복 100ms조차 허용되지 않는 환경에서 Edge AI는 필수입니다.

## 2. 현황 분석 및 과제 도출

### 2.1 대상 설비 현황 (한국기계엔지니어링)

| 공정 단계 | 장비 | 모델 | 주요 사양 | 현재 이슈 |
|:---------:|------|------|----------|----------|
| **1차 파쇄** | 이축 전단 파쇄기 | SHREDDER | 2×55kW, 15~25RPM | 칼날 마모 감지 어려움, 발화 위험 |
| **2차 분쇄** | 해머 크러셔 | HAMMER CRUSHER | 75kW, 600~1200RPM | 해머 탈락, 과분쇄, 미분 손실 |
| **3차 박리** | 핀밀 | PIN MILL T-18P/T-24P | 5.5~37kW, 3000~6000RPM | 핀 마모/탈락, 전해액 누출 |
| **분급/선별** | 에어 클래시파이어 | ACM | - | 분급 효율 저하, 컷포인트 편차 |

### 2.2 현재 문제점 분석

#### A. 설비 관리 (고장/정비)

| 문제 | 현재 상태 | 영향 | 연간 손실 |
|------|----------|------|:---------:|
| 비계획 정지 | 연 120시간 | 생산 중단, 긴급 수리 | **3억원** |
| 사후 정비 | 고장 후 수리 (Reactive) | 2차 손상, 긴 수리 시간 | 정비비 2억원 |
| 과잉 정비 | 시간 기반 교체 (TBM) | 수명 남은 부품 조기 교체 | 부품비 5천만원 |
| 부품 재고 | 안전재고 과다 보유 | 재고 비용 부담 | 재고비 5천만원 |

#### B. 안전 관리 (사고 예방)

| 위험 요소 | 현재 대응 | 문제점 |
|----------|----------|--------|
| **열폭주/화재** | 적외선 온도센서 + 수동 소화 | 감지 후 대응까지 지연 (수십 초) |
| **분진 폭발** | 분진센서 + 경보 | 단순 임계값 기반, 거짓 경보 빈번 |
| **전해액 누출** | 정기 점검 (1일 1회) | 점검 사이 누출 감지 불가 |
| **설비 이상 기동** | LOTO 절차 (수작업) | 휴먼 에러 가능성 |

#### C. 품질 관리

| 문제 | 현재 상태 | 영향 |
|------|----------|------|
| 회수율 저하 | 평균 92% (목표 98%) | 유가금속 6%p 손실 |
| 입도 편차 | D90 편차 ±15% | 후속 공정 효율 저하 |
| 품질 피드백 지연 | 오프라인 분석 후 2~4시간 | 불량 발생 후 늦은 대응 |
| 공정 파라미터 수동 조정 | 운전자 경험 의존 | 최적화 한계, 일관성 부족 |

## 3. 시스템 비전 및 목표

### 3.1 비전

> **"설비가 스스로 고장을 예측하고, 사고를 방지하며, 최적 품질을 달성하는 자율 운영 공장"**

### 3.2 정량 목표

| KPI | 현재 | Phase 1 (6개월) | Phase 2 (12개월) | Phase 3 (18개월) |
|-----|:----:|:--------------:|:---------------:|:---------------:|
| **비계획 정지** | 연 120시간 | 연 72시간 (40%↓) | 연 48시간 (60%↓) | **연 36시간 (70%↓)** |
| **유가금속 회수율** | 92% | 94% | 96% | **98%** |
| **안전사고** | 연 2~3건 | 연 1건 이하 | Zero Accident | **Zero 유지** |
| **정비 비용** | 연 2억원 | 연 1.6억원 | 연 1.4억원 | **연 1.2억원 (40%↓)** |
| **제품 입도 편차** | ±15% | ±10% | ±7% | **±5%** |
| **발화 감지→대응** | 수십 초 | 5초 이내 | 2초 이내 | **1초 이내** |
| **AI 모델 정확도** | - | 85%+ | 90%+ | **95%+** |

### 3.3 시스템 설계 원칙

| 원칙 | 설명 |
|------|------|
| **Safety First** | 안전 기능은 AI와 독립적으로도 작동 (Safety PLC 이중화) |
| **Edge First** | 실시간 판단은 현장 Edge에서, 장기 분석은 서버/클라우드에서 |
| **Data Driven** | 모든 의사결정은 센서 데이터 기반, 경험 의존 최소화 |
| **Open Architecture** | 표준 프로토콜 (OPC UA, MQTT) 사용, 벤더 종속 방지 |
| **Incremental Deployment** | 3단계 점진 구축, 각 단계별 검증 후 확장 |

### 4.2 핵심 설계 포인트

| 설계 항목 | 결정 사항 | 근거 |
|----------|----------|------|

| **공정 최적화** | Bayesian Optimization | 현재 품질 + 목표 | 최적 파라미터 세트 | <1s | - |

## 9. AI 모듈 4: 통합 지능

### 9.1 핵심 개념: "설비-품질-안전 삼각 상관분석"

> 기존 시스템은 고장예지·품질관리·안전관리를 **각각 독립적**으로 운영합니다.
> 본 시스템은 이 3가지를 **하나의 AI로 연결**하여, 한 영역의 변화가 다른 영역에 미치는 영향을 실시간으로 분석합니다.

```

│                                                                         │

│                        ╱     │     ╲                                   │

│         ╱                    │                     ╲                   │
│   ┌──────────┐          ┌────▼─────┐          ┌──────────┐           │
```

### 9.2 통합 상관분석 모델

| 상관 관계 | 입력 (원인) | 출력 (결과) | AI 모델 | 활용 |
|----------|------------|-----------|---------|------|
| 설비→품질 | 칼날 마모율, 전류 변화 | D50/D90 변동 예측 | Multi-output Regression | 칼날 교체 시점 최적화 (품질 기반) |
| 설비→안전 | 진동 이상, 온도 상승 | 발화/폭발 위험도 | Risk Scoring Model | 예방적 안전 조치 |
| 품질→설비 | 입도 편차 확대, 회수율 저하 | 원인 설비 특정 | Root Cause Analysis (RCA) | 품질 이상의 설비 원인 자동 추정 |
| 안전→품질 | N₂ 농도 변동, 온도 변동 | 블랙매스 산화도 | Regression | 안전 상태가 품질에 미치는 영향 |
| 복합 | 전 센서 데이터 | 종합 공장 건강 점수 | Ensemble (RF+LSTM+XGB) | 경영진 대시보드 |

### 9.3 Digital Twin 연동 (Phase 3)

Phase 3에서는 물리 공정의 Digital Twin을 구축하여:
- 파라미터 변경 전 **시뮬레이션으로 결과 예측**
- "What-if" 분석: "RPM을 10% 낮추면 회수율은 얼마나 변하나?"
- 신규 배터리 종류 투입 전 최적 파라미터 사전 도출

### 13.2 MLOps 파이프라인

```
[센서 데이터] → [Data Lake] → [Feature Engineering] → [Model Training]
                                                            │
                                                            ▼
[Edge 배포] ← [Model Registry] ← [Model Validation] ← [A/B Test]
     │
     ▼
[실시간 추론] → [성능 모니터링] → [재학습 트리거 (성능 저하 감지)]
```

| 항목 | 도구 | 주기 |
|------|------|:----:|
| 데이터 버전 관리 | DVC | 일간 |
| 모델 레지스트리 | MLflow | 모델 업데이트 시 |
| A/B 테스트 | Shadow Mode | 신규 모델 배포 시 |
| 모델 재학습 | 자동 트리거 (성능 저하 감지) | 월간 또는 자동 |
| 모델 롤백 | 버전 기반 자동 | 성능 저하 시 |
