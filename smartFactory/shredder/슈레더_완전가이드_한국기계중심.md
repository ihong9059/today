## 1. 슈레더란 무엇인가?

### 1.1 한 줄 정의

> **슈레더(Shredder)** = 큰 물체를 작은 조각으로 **찢어서** 부수는 산업용 기계

가정에서 종이를 파쇄하는 문서 파쇄기를 떠올려 보세요. 산업용 슈레더는 그것의 **수백~수천 배 규모**입니다. 자동차, 폐가전, 폐배터리, 타이어, 금속 덩어리까지 **거의 모든 것**을 잘게 부술 수 있습니다.

### 1.2 왜 슈레더가 필요한가?

```
  [큰 폐기물]                    [작은 조각들]
  ┌──────────┐                   ┌─┐┌─┐┌─┐
  │          │   슈레더 통과     │ ││ ││ │
  │  폐배터리 │  ──────────▶    ├─┤├─┤├─┤  ──▶ 재활용/재가공 가능!
  │          │                   │ ││ ││ │
  └──────────┘                   └─┘└─┘└─┘
  (처리 불가)                    (후속 공정 가능)
```

| 이유 | 설명 |
|------|------|
| **부피 감소** | 큰 폐기물을 작게 만들어 운반·보관 비용 절감 |
| **후속 공정 준비** | 분쇄·분급·선별 등 다음 공정에 들어갈 수 있는 크기로 만듦 |
| **재활용 가능** | 작은 조각으로 만들어야 유가금속(코발트, 리튬 등) 회수 가능 |
| **안전한 폐기** | 의료폐기물, 기밀문서 등을 완전 파괴 |
| **법적 의무** | 전자폐기물(E-waste) 등은 법적으로 물리적 파쇄 후 폐기 필요 |

### 1.3 일상에서의 비유

| 일상 도구 | 산업용 슈레더 |
|-----------|-------------|
| 종이 파쇄기 | 문서 슈레더 (소형) |
| 가위로 천 자르기 | 직물 슈레더 |
| 절구로 깨뜨리기 | 해머 크러셔 (타격식) |
| 믹서기의 칼날 | 고속 밀(Mill) |
| **가위 두 개를 맞물려 자르기** | **이축 전단 파쇄기 (한국기계 제품)** |

## 2. 슈레더의 작동 원리

### 2.1 기본 작동 4단계

```
┌─────────────────────────────────────────────────────────────────────┐
│                     슈레더 작동 4단계                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   [1단계: 투입(Feeding)]                                           │
│       │  폐기물을 호퍼(투입구)나 컨베이어로 투입                    │
│       ▼                                                             │
│   [2단계: 물림(Grabbing)]                                          │
│       │  칼날의 갈고리 모양이 재료를 안쪽으로 끌어당김               │
│       ▼                                                             │
│   [3단계: 절단(Cutting)]                                           │
│       │  회전하는 칼날이 3가지 힘으로 재료를 파쇄                    │
│       │  • 전단력(Shear Force) — 가위처럼 자르는 힘                 │
│       │  • 압축력(Compression) — 눌러 부수는 힘                     │
│       │  • 마찰력(Friction) — 끌어당기며 찢는 힘                    │
│       ▼                                                             │
│   [4단계: 배출/선별(Screening)]                                    │
│       스크린(체)을 통과한 작은 조각만 배출                          │
│       큰 조각은 다시 칼날로 돌아감 (재파쇄)                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 핵심 원리: 전단력(Shear Force)

**전단력**은 슈레더의 가장 핵심적인 파쇄 원리입니다.

```
  가위를 생각해 보세요:

      ╲       ╱        두 날이 서로 반대 방향으로 움직이며
       ╲     ╱         그 사이의 종이를 "밀어 자르는" 힘
        ╲   ╱          = 전단력 (Shear Force)
         ╲ ╱
          ✕  ← 절단점
         ╱ ╲
```

이축 전단 파쇄기(한국기계 제품)는 이 원리를 대형 산업용으로 구현한 것입니다:
- **두 개의 축**이 서로 **반대 방향**으로 회전
- 축에 달린 **칼날들이 서로 맞물리면서** 재료를 끌어당기고 찢고 자름
- 마치 **거대한 가위 수십 개가 동시에 작동**하는 것과 같음

### 2.3 동력 전달 과정

```
  [전기 모터]  ──▶  [감속기(기어박스)]  ──▶  [회전축(샤프트)]  ──▶  [칼날(커터)]

   고속·저토크          속도를 낮추고          칼날을 천천히         재료를
   (빠르게 회전)        토크를 높임            강하게 회전           잡아 찢음

   예: 1,500 RPM  ──▶  15 RPM              "느리지만 엄청난 힘"
```

**비유**: 자전거 기어를 낮은 단으로 바꾸면, 페달은 많이 돌려야 하지만 힘이 세져서 오르막을 오를 수 있는 것과 같은 원리입니다. 감속기가 이 역할을 합니다.

## 3. 슈레더의 종류

### 3.1 축 개수에 따른 분류

#### 단축 슈레더 (Single-Shaft Shredder)

```
  ┌─────────────────────────────────┐
  │         호퍼 (투입구)            │
  │              │                   │
  │              ▼                   │
  │    ╔══════════════════╗         │
  │    ║  ☆☆☆☆☆☆☆☆☆☆  ║  ← 회전축 1개 (칼날 장착)
  │    ╚══════════════════╝         │
  │    ────────────────────  ← 고정 칼날 (앤빌)
  │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← 스크린 (체)
  │              │                   │
  │              ▼                   │
  │          배출구                   │
  └─────────────────────────────────┘
```

| 특징 | 내용 |
|------|------|
| 축 | 1개의 회전축 + 고정 칼날(앤빌) |
| 속도 | 저속 (60~120 RPM) |
| 출력 크기 | 균일함 (스크린으로 제어, 25~50mm) |
| 용도 | 플라스틱, 목재, 직물, 경금속 |
| 장점 | 균일한 출력 크기, 소음 적음 |
| 단점 | 단단하고 큰 재료 처리 어려움 |

---

#### 이축 슈레더 (Twin-Shaft / Dual-Shaft Shredder) — ★ 한국기계 주력 제품

```
  ┌─────────────────────────────────┐
  │         호퍼 (투입구)            │
  │              │                   │
  │              ▼                   │
  │    ☆☆☆☆☆☆    ☆☆☆☆☆☆        │
  │    ═══════    ═══════           │  ← 2개의 축이 서로 반대로 회전
  │    ☆☆☆☆☆☆    ☆☆☆☆☆☆        │     칼날이 맞물림 (Intermeshing)
  │       ↻           ↺             │
  │              │                   │
  │              ▼                   │
  │          배출구                   │
  └─────────────────────────────────┘
```

| 특징 | 내용 |
|------|------|
| 축 | 2개의 회전축이 반대 방향으로 회전 |
| 속도 | **초저속·고토크** (4~25 RPM) |
| 출력 크기 | 비교적 큰 편 (25~125mm) |
| 용도 | **금속, 타이어, 산업폐기물, 폐배터리, 대형 쓰레기** |
| 장점 | 강력한 파쇄력, 거의 모든 재료 처리 가능 |
| 단점 | 출력 크기가 덜 균일 |
| 독립 구동 | 각 축마다 별도 모터+감속기 (한국기계 방식) |

> **한국기계의 이축 전단 파쇄기가 바로 이 유형**입니다.
> 각 축이 **독립 모터**로 구동되어 한쪽이 막혀도 다른 쪽이 독립 작동할 수 있습니다.

---

#### 사축 슈레더 (Quad-Shaft / Four-Shaft Shredder)

```
  ┌─────────────────────────────────┐
  │         호퍼 (투입구)            │
  │              │                   │
  │              ▼                   │
  │    ☆☆☆  ☆☆☆  ☆☆☆  ☆☆☆     │  ← 4개의 축이 쌍으로 배치
  │    ═══  ═══  ═══  ═══          │     1차 + 2차 파쇄를 동시에
  │              │                   │
  │    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓        │  ← 스크린
  │              │                   │
  │              ▼                   │
  │          배출구                   │
  └─────────────────────────────────┘
```

| 특징 | 내용 |
|------|------|
| 축 | 4개 (2쌍) |
| 장점 | 한 번에 미세한 출력 가능, 1차+2차 파쇄 동시 |
| 용도 | 전자폐기물, 의료폐기물, 기밀 문서 |
| 단점 | 구조 복잡, 고가 |

---

### 3.2 구동 방식에 따른 분류

| 구동 방식 | 전기 모터 구동 | 유압 모터 구동 |
|-----------|:------------:|:------------:|
| 원리 | 전기 모터 → 감속기 → 축 | 유압 펌프 → 유압 모터 → 축 |
| 토크 | 높음 | 매우 높음 |
| 속도 제어 | 인버터로 가변 | 유량 밸브로 가변 |
| 과부하 보호 | 전류 차단 | 압력 릴리프 밸브 (자연 보호) |
| 유지보수 | 상대적 용이 | 유압 오일 관리 필요 |
| 비용 | 중간 | 높음 |
| **한국기계** | **전기 모터 구동 채택** | - |

| 유형 | 축 수 | RPM | 토크 | 출력 크기 | 주요 용도 |
|------|:-----:|:---:|:----:|:---------:|----------|

## 4. 슈레더의 핵심 구성요소

### 4.1 전체 구조도

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        이축 전단 파쇄기 구조도                           │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│              ┌───────────────────────────────┐                         │
│              │       호퍼 (Hopper)           │  ← ① 재료 투입구       │
│              │       재료 투입구              │                         │
│              └───────────┬───────────────────┘                         │
│                          │                                              │
│   ┌──────────────────────┼──────────────────────────┐                  │
│   │                      ▼         하우징 (Housing)  │  ← ② 본체 외함  │
│   │   ┌─────────────────────────────────────────┐   │                  │
│   │   │                                         │   │                  │
│   │   │   [모터A]─[감속기A]─[베어링]─⟐칼날⟐─   │   │  ← ③~⑦        │
│   │   │                         축 A  ↻         │   │                  │
│   │   │                                         │   │                  │
│   │   │                         축 B  ↺         │   │                  │
│   │   │   [모터B]─[감속기B]─[베어링]─⟐칼날⟐─   │   │                  │
│   │   │                                         │   │                  │
│   │   └─────────────────────────────────────────┘   │                  │
│   │                      │                          │                  │
│   │          ┌───────────┴───────────┐              │                  │
│   │          │   스크린 (Screen)     │              │  ← ⑧ 크기 선별  │
│   │          └───────────┬───────────┘              │                  │
│   └──────────────────────┼──────────────────────────┘                  │
│                          │                                              │
│                          ▼                                              │
│              ┌───────────────────────────┐                             │
│              │     배출구 (Discharge)    │  ← ⑨ 파쇄물 배출          │
│              └───────────────────────────┘                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4.2 각 구성요소 상세 설명

#### ① 호퍼 (Hopper) — 재료를 넣는 곳

| 항목 | 설명 |
|------|------|
| 역할 | 파쇄할 재료를 받아들이는 투입구 (깔때기 모양) |
| 비유 | 믹서기 뚜껑을 열고 재료를 넣는 입구 |
| 투입 방식 | 수작업 투입, 컨베이어 자동 투입, 로봇 투입 등 |
| 주의사항 | 투입량 초과 시 과부하 → 장비 손상 위험 |

#### ② 하우징 (Housing) — 본체 외함

| 항목 | 설명 |
|------|------|
| 역할 | 내부 부품을 감싸고 보호하는 외부 구조물 |
| 재질 | 고강도 강판, 용접 구조 |
| 특징 | 진동·충격에 견디는 중후한 설계 |
| 배터리용 | 밀폐 설계 + 불활성 가스 주입 가능 |

#### ③ 모터 (Motor) — 동력원

| 항목 | 설명 |
|------|------|
| 역할 | 전기 에너지를 회전 에너지로 변환하는 동력원 |
| 한국기계 사양 | 2 × 55kW (각 축 독립 모터), 총 110kW |
| 비유 | 자동차 엔진에 해당 |
| 독립 구동 | 한쪽 축이 막혀도 다른 축은 독립 작동 가능 |

#### ④ 감속기 / 기어박스 (Gearbox / Reducer) — 속도를 힘으로 바꾸는 장치

| 항목 | 설명 |
|------|------|
| 역할 | 모터의 고속 회전을 **저속·고토크**로 변환 |
| 비유 | 자전거 저단 기어 — 느리지만 힘이 강해짐 |
| 변환 예시 | 모터 1,500 RPM → 감속기 → 축 15~25 RPM |
| 중요성 | 슈레더의 파쇄력을 결정하는 핵심 부품 |

```
  감속기의 역할을 숫자로 보면:

  모터 출력: 55kW, 1,500 RPM
       ↓ 감속기 (감속비 100:1)
  축 출력: 55kW, 15 RPM, 토크 100배 증가!

  → 느리지만 "엄청나게 강한" 힘으로 재료를 부숨
```

#### ⑤ 회전축 / 샤프트 (Shaft) — 칼날을 달고 회전하는 봉

| 항목 | 설명 |
|------|------|
| 역할 | 칼날을 장착하고 감속기의 동력을 전달하는 회전 봉 |
| 재질 | 고강도 합금강 (항복강도 350 MPa 이상 권장) |
| 형상 | 육각 또는 사각 단면 (칼날이 빠지지 않도록) |
| 이축 | 두 개의 축이 평행하게 배치, 반대 방향 회전 |

#### ⑥ 칼날 / 커터 (Blade / Cutter) — 실제로 재료를 자르는 부품

| 항목 | 설명 |
|------|------|
| 역할 | 재료를 직접 절단·파쇄하는 핵심 소모품 |
| 재질 | **경화 합금강** + 카바이드 코팅 (극도로 단단함) |
| 두께 | 40mm, 50mm, 75mm, 100mm (용도별 선택) |
| 형상 | 갈고리(Hook) 형태 — 재료를 안쪽으로 끌어당기는 설계 |
| 교체 주기 | 40~80 운전시간마다 연마, 200~500시간마다 교체 |
| 주의 | **반드시 전체 세트를 동시 교체** (혼용 시 진동·베어링 손상) |

```
  칼날의 맞물림 구조 (이축):

  축 A:  ─┤ ├─┤ ├─┤ ├─     ← 칼날이 번갈아 배치
  축 B:  ┤ ├─┤ ├─┤ ├─┤     ← 서로 엇갈리며 맞물림

  → 이 맞물림 사이로 재료가 끼여서 잘림 (가위 원리)
```

#### ⑦ 베어링 (Bearing) — 축을 부드럽게 회전시키는 부품

| 항목 | 설명 |
|------|------|
| 역할 | 회전축을 지지하면서 마찰을 최소화 |
| 보호 구조 | 래비린스 실드 + 립 시일 + 자동 그리스 윤활 (다중 보호) |
| 고장 시 증상 | 고주파 진동 증가, 온도 상승, 이상음 발생 |
| 중요성 | 베어링 파손 = 전체 라인 정지 → AI 예지보전의 핵심 감시 대상 |

#### ⑧ 스크린 (Screen) — 출력 크기를 결정하는 체(篩)

| 항목 | 설명 |
|------|------|
| 역할 | 원하는 크기 이하의 조각만 통과시키는 체 |
| 원리 | 스크린 구멍보다 큰 조각은 다시 칼날로 돌아감 (재파쇄) |
| 크기 조절 | 스크린 교체로 출력 크기 변경 가능 |
| 참고 | 이축 슈레더는 스크린 없이 운용하기도 함 (1차 파쇄 용도) |

## 5. 슈레더 vs 크러셔 vs 그라인더 vs 밀 — 무엇이 다른가?

이 장비들은 모두 "물체를 작게 만드는 기계"이지만, **원리와 용도가 다릅니다**.

### 5.1 비교표

| 구분 | 슈레더 (Shredder) | 크러셔 (Crusher) | 그라인더 (Grinder) | 밀 (Mill) |
|------|:-----------------:|:----------------:|:-----------------:|:---------:|
| **핵심 원리** | 찢고 자름 (전단력) | 눌러 부숨 (압축력) | 갈아냄 (마찰력) | 초미세 분쇄 (충격+마찰) |
| **비유** | 가위로 자르기 | 망치로 깨뜨리기 | 돌절구로 갈기 | 믹서기로 갈기 |
| **속도** | 저속 (4~25 RPM) | 가변 | 중~고속 | 고속 (3,000~6,000 RPM) |
| **출력 크기** | 25~125mm | 10~100mm | 1~10mm | μm~mm 수준 |
| **공정 단계** | **1차** (초기 파쇄) | **1~2차** | **2~3차** | **3~4차** (최종 미분쇄) |
| **투입물** | 크고 다양한 재료 | 단단한 재료 | 이미 작아진 재료 | 미세 분말 제조용 |
| **한국기계 제품** | 이축 전단 파쇄기 | 해머 크러셔, 조 크러셔 | - | 터보밀, 핀밀, 볼밀, ACM 등 |

### 5.2 배터리 재활용 공정에서의 순서

```
[폐배터리 투입]
      │
      ▼
┌──────────────┐
│ 1차: 슈레더  │  ← 이축 전단 파쇄기 (50~100mm로 파쇄)
│  (Shredder)  │     "큰 덩어리를 먹기 좋은 크기로"
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 2차: 크러셔  │  ← 해머 크러셔 (5~20mm로 분쇄)
│  (Crusher)   │     "작은 조각을 더 잘게"
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 3차: 밀      │  ← 핀밀 (유가금속 박리)
│  (Pin Mill)  │     "극미세하게 갈아서 금속 분리"
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 4차: 분급기  │  ← 에어 클래시파이어 (입도별 선별)
│ (Classifier) │     "크기별로 골라내기"
└──────────────┘
```

> **핵심 포인트**: 슈레더는 가장 **첫 번째 공정**을 담당합니다. 이 단계 없이는 이후 모든 공정이 불가능합니다.

## 6. 슈레더의 주요 사양 읽는 법

장비 사양표를 처음 보면 숫자와 단위가 낯설 수 있습니다. 하나씩 알아보겠습니다.

### 6.1 한국기계 이축 전단 파쇄기 사양 (예시)

| 사양 항목 | 값 | 무슨 뜻인가? |
|----------|:--:|-------------|
| **모터 출력** | 2 × 55kW | 각 축에 55킬로와트 모터, 총 110kW. 가정용 에어컨(3kW)의 약 37배 |
| **RPM** | 15~25 RPM | 축이 1분에 15~25바퀴 회전. 매우 느리지만 토크(힘)가 극대 |
| **출력 크기** | 50~100mm | 파쇄된 조각의 크기. 주먹~달걀 정도 |
| **축 구동** | 독립 구동 | 각 축이 별도 모터+감속기. 한쪽 멈춰도 다른 쪽 작동 |

### 6.2 사양표 읽기 핵심 용어

| 용어 | 단위 | 쉬운 설명 |
|------|:----:|----------|
| **kW (킬로와트)** | kW | 모터의 출력(힘). 숫자가 클수록 강력한 모터 |
| **RPM** | 회전/분 | 1분에 몇 바퀴 도는가. 슈레더는 낮을수록 강력 |
| **토크 (Torque)** | N·m | 회전하는 힘의 크기. 슈레더에서 가장 중요한 수치 |
| **처리 용량** | t/h 또는 kg/h | 시간당 처리할 수 있는 재료의 무게 |
| **절단 직경** | mm | 칼날이 회전하는 원의 지름 |
| **투입구 크기** | mm × mm | 호퍼에 넣을 수 있는 재료의 최대 크기 |

### 6.3 "느린데 왜 강한가?" — RPM과 토크의 관계

```
  ┌──────────────────────────────────────────────────────┐
  │           동일한 모터 출력(55kW)에서                    │
  │                                                        │
  │   고속·저토크                    저속·고토크             │
  │   1,500 RPM                     15 RPM                 │
  │   토크 = 350 N·m                토크 = 35,000 N·m      │
  │                                                        │
  │   빠르게 도는데                  느리게 도는데           │
  │   힘이 약함                     힘이 100배 강함         │
  │                                                        │
  │   → 선풍기처럼                  → 슈레더에 필요한 힘    │
  │     빠르게 회전                   금속도 찢을 수 있음    │
  └──────────────────────────────────────────────────────┘

  공식: 토크 = 출력(W) ÷ 각속도(rad/s)
       토크 = 55,000 ÷ (15 × 2π/60) ≈ 35,000 N·m
```

| **독립 구동** | 각 축 독립 모터+감속기 → 한쪽 막혀도 다른 쪽 정상 작동 |
| **저진동·저소음** | 저속 운전으로 진동과 소음이 적음 |
| **간단한 구조** | 구조가 단순하여 조작이 쉽고 유지보수 편리 |
| **소형 설치** | 출력 대비 설치 공간이 작음 |
| **출력 조절** | 재료에 따라 모터 출력 조정 가능 |

### 9.4 배터리 파쇄 시 특수 설계

일반 폐기물과 달리, 배터리는 **화재·폭발 위험**이 있어 특수 설계가 필요합니다:

| 안전 기능 | 설명 |
|----------|------|
| **불활성 가스 시스템** | 질소(N₂) 가스로 산소 농도를 낮춰 발화 방지 |
| **방폭 설계** | ATEX 인증 전기장치 사용 (폭발 방지 등급) |
| **밀폐형 구조** | 분진 비산 방지 + 가스 누출 차단 |
| **자동 소화 시스템** | 열감지 시 자동으로 소화제 분사 |
| **실시간 모니터링** | 온도·가스 농도·산소 농도 연속 감시 |

```
  배터리 파쇄용 안전 시스템 구조:

  [폐배터리] → [버퍼 사일로]
                    │
               [N₂ 가스 주입]  ← 산소 농도를 낮춤
                    │
               [산소 농도 모니터링]
                    │ (안전 확인)
                    ▼
               [게이트 밸브 개방]
                    │
               [밀폐 파쇄실]  ← 이축 전단 파쇄기
                    │
               [게이트 밸브 폐쇄]  ← 화재 확산 차단
                    │
                    ▼
               [파쇄물 배출]
```

## 11. 배터리 재활용에서 슈레더의 역할

### 11.1 왜 배터리 재활용이 중요한가?

| 이유 | 설명 |
|------|------|
| **자원 확보** | 코발트, 니켈, 리튬은 지구 매장량이 한정적이고, 주요 생산국이 편중됨 |
| **환경 보호** | 배터리를 매립하면 중금속이 토양·지하수를 오염시킴 |
| **경제성** | 채광 대비 재활용이 에너지 90% 절감 가능 |
| **법적 의무** | EU 배터리 규정 등 전세계적으로 재활용 의무화 추세 |
| **공급망 안보** | 특정 국가 의존도를 낮추기 위한 국가적 전략 |

### 11.2 슈레더가 핵심인 이유

> 슈레더 없이는 배터리 재활용이 **시작조차 불가능**합니다.

```
  폐배터리 내부 구조:

  ┌────────────────────────────────────┐
  │  금속 케이스 (알루미늄/스틸)        │
  │  ┌──────────────────────────────┐  │
  │  │  모듈 케이스                  │  │
  │  │  ┌──────────────────────┐    │  │
  │  │  │  셀 (Cell)           │    │  │
  │  │  │  ┌─ 양극박 (Al)     │    │  │
  │  │  │  ├─ 양극재 (NMC)    │ ← 이것이 "블랙매스"   │
  │  │  │  ├─ 분리막          │    │  │
  │  │  │  ├─ 음극재 (흑연)   │    │  │
  │  │  │  ├─ 음극박 (Cu)     │    │  │
  │  │  │  └─ 전해액          │    │  │
  │  │  └──────────────────────┘    │  │
  │  └──────────────────────────────┘  │
  └────────────────────────────────────┘

  이 모든 층을 분리하려면, 먼저 "물리적으로 부수는" 단계가 필수!
  → 그 역할을 하는 것이 바로 슈레더
```

### 11.3 전체 배터리 재활용 프로세스

| 단계 | 공정 | 설명 | 핵심 장비 |
|:----:|------|------|----------|
| 1 | **수거·분류** | 배터리 종류(NMC, LFP 등)별 분류 | 수작업/자동 |
| 2 | **방전·비활성화** | 잔류 전기 에너지 제거 (안전 확보) | 방전 저항기, 소금물 |
| 3 | **1차 파쇄 (Shredding)** | 대형 조각으로 파쇄 (50~100mm) | **이축 전단 파쇄기** |
| 4 | **2차 분쇄 (Crushing)** | 소형 조각으로 분쇄 (5~20mm) | 해머 크러셔 |
| 5 | **3차 박리 (Milling)** | 유가금속 박리·미분쇄 | 핀 밀 |
| 6 | **분급·선별 (Classification)** | 크기별 분리 + 자력/비중 선별 | ACM, 자력선별기 |
| 7 | **블랙매스 회수** | 양극·음극 활물질 분말 수집 | 집진기, 사이클론 |
| 8 | **습식제련 (Hydrometallurgy)** | 산(酸)으로 금속 용해 후 분리 | 화학 공정 |
| 9 | **정제·재생** | 배터리 급 순도로 정제 | 화학 공정 |

> **블랙매스(Black Mass)**: 배터리를 물리적으로 파쇄·분쇄한 후 얻는 **검은색 분말**. 코발트, 니켈, 리튬, 망간 등 유가금속이 농축된 상태. 이것이 배터리 재활용의 핵심 산출물입니다.

### 11.4 건식 vs 습식 파쇄

| 구분 | 건식 파쇄 (Dry Shredding) | 습식 파쇄 (Wet Shredding) |
|------|:------------------------:|:------------------------:|
| 방법 | 질소(N₂) 분위기에서 파쇄 | 물속에 잠긴 상태로 파쇄 |
| 안전성 | 높음 (N₂가 산소 차단) | 매우 높음 (물이 냉각+소화) |
| 미방전 배터리 | 위험 (자체 산소 발생 가능) | 처리 가능 |
| 블랙매스 품질 | 깨끗함 | 매우 깨끗함 |
| 환경 | 분진 관리 필요 | 폐수 처리 필요 |
| 비용 | 상대적 저렴 | 수처리 비용 발생 |

|------|------|------|
| **LOTO** | 정비 전 반드시 전원 차단 + 잠금 + 표찰 부착 | 실수로 기동 시 사망 사고 |
| **제로 에너지** | 전원 차단 후에도 잔류 에너지 확인 (유압, 관성) | 축이 여전히 회전 중일 수 있음 |
| **보호구** | 안전 장갑, 보안경, 안전모, 안전화 필수 착용 | 비산물, 분진 위험 |
| **투입 제한** | 최대 투입량 초과 금지 | 과부하 → 장비 파손, 화재 |
| **비상 정지** | 비상 정지 버튼 위치 숙지 및 접근 경로 확보 | 긴급 상황 즉시 대응 |

```
  LOTO (Lock-Out, Tag-Out) 절차:

  1. 장비 정지
  2. 전원 차단 스위치 OFF
  3. 자물쇠로 스위치 잠금 (Lock-Out)
  4. "정비 중 — 기동 금지" 표찰 부착 (Tag-Out)
  5. 잔류 에너지 확인 (축 정지 확인)
  6. 정비 작업 수행
  7. 공구/사람 철수 확인
  8. 자물쇠 해제 → 스위치 ON
```

### 13.2 배터리 파쇄 시 추가 안전 사항

배터리는 일반 폐기물보다 **훨씬 위험**합니다:

| 위험 요소 | 설명 | 대책 |
|----------|------|------|
| **열폭주 (Thermal Runaway)** | 파쇄 중 양극-음극 접촉 시 급격한 온도 상승 (수백°C) | 사전 방전, N₂ 분위기, 온도 모니터링 |
| **화재** | 전해액이 인화성 (인화점 약 30°C) | 자동 소화 시스템, 게이트 밸브 격리 |
| **폭발** | 분진 농도가 폭발 한계 초과 시 | 분진 농도 모니터링, 방폭 설계 |
| **유독 가스** | 전해액 분해 시 HF(불화수소) 등 유해가스 발생 | 가스 감지기, 환기 시스템 |
| **감전** | 잔류 전압 (EV 배터리는 400~800V) | 반드시 방전 후 투입 |

## 14. 슈레더의 유지보수

### 14.1 왜 유지보수가 중요한가?

```
  유지보수를 하지 않으면:

  칼날 마모 → 파쇄 효율 저하 → 전류 증가 → 모터 과열
                    │                              │
                    ▼                              ▼
              불균일한 출력                     장비 손상
                    │                              │
                    ▼                              ▼
              후속 공정 품질 저하              비계획 정지
                    │                         (Unplanned Downtime)
                    ▼                              │
              회수율 하락                          ▼
                                              수리비 + 생산 손실
                                              (연간 수억 원)
```

### 14.2 주요 유지보수 항목

| 부품 | 점검 주기 | 교체/정비 주기 | 점검 내용 |
|------|:---------:|:-------------:|----------|
| **칼날(커터)** | 매일 육안 점검 | 40~80시간마다 연마, 200~500시간마다 교체 | 마모, 크랙, 칩핑 확인 |
| **베어링** | 주 1회 진동/온도 점검 | 이상 감지 시 교체 | 진동, 온도, 이상음 확인 |
| **감속기** | 월 1회 오일 점검 | 3,000~5,000시간마다 오일 교환 | 오일 레벨, 색상, 금속 입자 |
| **스크린** | 주 1회 | 마모/변형 시 교체 | 구멍 막힘, 마모 상태 |
| **윤활** | 자동 급유 시스템 (연속) | 그리스 보충 주기 확인 | 과급유/부족 확인 |
| **모터** | 월 1회 | 이상 시 정비 | 전류, 온도, 절연 저항 |
| **하우징/볼트** | 월 1회 | 필요 시 조임/교체 | 볼트 풀림, 균열 확인 |

### 14.3 칼날 관리 핵심 규칙

| 규칙 | 설명 |
|------|------|
| **전체 세트 동시 교체** | 새 칼날과 마모된 칼날을 섞으면 안 됨 → 진동 발생 → 베어링 손상 |
| **연마 vs 교체 판단** | 마모만 있으면 연마, 크랙·칩핑이 있으면 반드시 교체 |
| **교체 기록** | 교체 날짜, 운전 시간, 마모 상태 기록 → 교체 주기 최적화 |
| **순정 부품** | 제조사 권장 재질과 규격의 칼날 사용 |

### 14.4 AI 예지보전 (한국기계 SmartFactory 연계)

기존의 "고장 나면 고친다" 방식에서 → "고장 나기 전에 미리 안다" 방식으로 진화:

| 구분 | 사후 보전 (기존) | 예방 보전 (개선) | **AI 예지보전 (최신)** |
|------|:---------------:|:---------------:|:---------------------:|
| 시점 | 고장 후 수리 | 정기 일정 점검 | **고장 예측 시점에 정비** |
| 비용 | 높음 (긴급 수리) | 중간 (과잉 정비 포함) | **최소 (필요할 때만)** |
| 정지 시간 | 길음 (비계획) | 계획적이나 불필요한 정지 | **최소 (정확한 시점)** |
| 정확도 | 없음 | 낮음 | **높음 (센서 기반 예측)** |

한국기계 스마트팩토리에서는 **31개 센서**로 다음을 실시간 감시합니다:

| 감시 항목 | 센서 | 감지 대상 |
|----------|------|----------|
| 진동 | 3축 가속도계 | 베어링 마모, 축 불균형, 칼날 탈락 |
| 온도 | PT100 + 적외선 | 베어링 과열, 발화 징후 |
| 전류 | CT 센서 | 과부하, 칼날 마모 |
| 회전속도 | 엔코더 | 슬립, 속도 이상 |
| 음향 | MEMS 마이크 | 파쇄음 패턴, 이상음 |
| 가스 | 복합가스센서 | 전해액 누출 |
| 분진 | 레이저 분진센서 | 폭발 위험 |

## 15. 용어 사전

초보자를 위한 이 문서에 등장하는 주요 용어를 가나다 순으로 정리했습니다.

| 용어 | 영문 | 설명 |
|------|------|------|
| 감속기 | Gearbox/Reducer | 모터의 빠른 회전을 느리고 강한 회전으로 변환하는 장치 |
| 건식 파쇄 | Dry Shredding | 질소 분위기에서 파쇄하는 방식 |
| 그라인더 | Grinder | 마찰로 재료를 갈아서 작게 만드는 장비 |
| 기어박스 | Gearbox | 감속기와 동일한 용어 |
| 날 / 칼날 | Blade/Cutter | 슈레더에서 재료를 직접 자르는 부품 (소모품) |
| 독립 구동 | Independent Drive | 각 축이 별도 모터로 작동하는 방식 |
| 밀 | Mill | 재료를 극미세하게 분쇄하는 장비 |
| 방폭 | Explosion-proof | 폭발성 분위기에서도 안전하게 작동하도록 설계된 것 |
| 배출구 | Discharge | 파쇄된 재료가 나오는 곳 |
| 베어링 | Bearing | 회전축을 지지하며 마찰을 줄이는 부품 |
| 블랙매스 | Black Mass | 배터리를 파쇄/분쇄하여 얻는 검은 분말 (유가금속 농축물) |
| 분급 | Classification | 입자를 크기별로 분리하는 공정 |
| 분체 | Powder/Particle | 가루 형태의 물질 |
| 불활성 가스 | Inert Gas | 반응을 일으키지 않는 가스 (질소 N₂ 등) |
| 사이클론 | Cyclone | 원심력으로 분진을 포집하는 장치 |
| 선별 | Sorting/Separation | 재료를 종류별로 분리하는 공정 |
| 스크린 | Screen | 특정 크기 이하만 통과시키는 체(篩) |
| 슈레더 | Shredder | 재료를 찢어서 작게 만드는 산업용 파쇄기 |
| 습식 파쇄 | Wet Shredding | 물속에서 파쇄하는 방식 |
| 열폭주 | Thermal Runaway | 배터리 내부 온도가 제어 불능으로 급상승하는 현상 |
| 유가금속 | Valuable Metals | 경제적 가치가 있는 금속 (Co, Ni, Li, Mn 등) |
| 이축 | Twin-Shaft | 회전축이 2개인 구조 |
| 전단력 | Shear Force | 가위처럼 엇갈려 자르는 힘 |
| 집진기 | Dust Collector | 공기 중 분진을 모아 제거하는 장치 |
| 크러셔 | Crusher | 압축력으로 재료를 부수는 장비 |
| 토크 | Torque | 회전하는 힘의 크기 (N·m 단위) |
| 파쇄 | Shredding/Crushing | 큰 재료를 작은 조각으로 부수는 것 |
| 피더 | Feeder | 재료를 일정 속도로 공급하는 장치 |
| 핀밀 | Pin Mill | 핀(바늘 모양) 디스크로 미분쇄하는 장비 |
| 호퍼 | Hopper | 재료를 투입하는 깔때기 모양 입구 |
| ACM | Air Classifying Mill | 분쇄와 분급을 동시에 하는 장비 |
| ATEX | ATmosphères EXplosibles | EU의 방폭 인증 규격 |
| LOTO | Lock-Out Tag-Out | 정비 시 전원 차단 후 잠금+표찰 부착 안전 절차 |
| N·m | Newton-meter | 토크의 단위 (1 N·m = 약 0.1 kgf·m) |
| RPM | Revolutions Per Minute | 1분당 회전수 |
| RUL | Remaining Useful Life | 잔여 사용 수명 |
