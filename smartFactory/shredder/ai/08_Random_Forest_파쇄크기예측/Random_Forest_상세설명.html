AI MODEL #08 - 슈레더 파쇄 크기 예측

Random Forest 파쇄 크기 예측 상세 설명

앙상블 학습으로 파쇄 크기(mm)와 균일도(%)를 정밀 예측하고, 핵심 센서를 파악합니다

0 Random Forest란?

비유: 100명의 전문가 투표

한 명의 전문가(Decision Tree)에게 물어보면 틀릴 수 있습니다. 하지만 200명의 독립적인 전문가에게 각각 물어본 뒤 평균을 내면? 개인의 실수가 상쇄되어 훨씬 정확해집니다.

이것이 바로 Random Forest입니다: 여러 Decision Tree를 만들고, 결과를 평균내는 앙상블(Ensemble) 기법입니다.

Random Forest = Bagging + Decision Tree 앙상블
  • Bagging (Bootstrap Aggregating): 원본 데이터에서 복원 추출로 여러 부분집합을 만들어 각 트리에 독립 학습
  • Random Feature Selection: 각 분기(split)마다 전체 특징 중 일부만 무작위 선택하여 트리 다양성 확보
  • Averaging: 모든 트리의 예측값을 평균 (회귀) 또는 다수결 투표 (분류)
Random Forest 구조: 원본 데이터 (2000건) | ├─ Bootstrap 샘플 1 → Decision Tree 1 → 예측 24.3mm ├─ Bootstrap 샘플 2 → Decision Tree 2 → 예측 25.1mm ├─ Bootstrap 샘플 3 → Decision Tree 3 → 예측 24.8mm │ ... └─ Bootstrap 샘플 200 → Decision Tree 200 → 예측 24.5mm | 최종 예측 = 평균 = 24.7mm

1 특징 추출 - 12개 센서 특징

슈레더에 설치된 4종 센서에서 각 3개 통계값을 추출하여 총 12개 특징을 구성합니다.

센서설명평균 (mean)표준편차 (std)최대값 (max)
CUR모터 전류 (A)CUR_meanCUR_stdCUR_max
SPD회전 속도 (RPM)SPD_meanSPD_stdSPD_max
VIB진동 RMS (mm/s)VIB_meanVIB_stdVIB_max
SCL스케일/무게 (kg)SCL_meanSCL_stdSCL_max
특징 추출 과정: CUR 센서 (A축 + B축) CUR_mean = (CUR_A + CUR_B) / 2 → 평균 전류 CUR_std = |CUR_A - CUR_B| + noise → 전류 불균형 (축간 차이) CUR_max = max(CUR_A, CUR_B) → 최대 전류 SPD 센서 (A축 + B축) SPD_mean = (SPD_A + SPD_B) / 2 → 평균 속도 SPD_std = |SPD_A - SPD_B| + noise → 속도 불균형 SPD_max = max(SPD_A, SPD_B) → 최대 속도 VIB 센서 (A축 + B축) VIB_mean = (VIB_A + VIB_B) / 2 → 평균 진동 VIB_std = |VIB_A - VIB_B| + noise → 진동 불균형 VIB_max = max(VIB_A, VIB_B) → 최대 진동 SCL 센서 (전류/속도 기반 간접 추정) SCL_mean = CUR_A * 0.4 + SPD_A * 0.8 → 부하 추정 (무게) SCL_std = CUR_std * 0.3 + SPD_std * 0.5 SCL_max = SCL_mean + offset → 총 12개 특징 → Random Forest 입력
왜 12개 특징인가?

파쇄 크기는 단일 센서로 결정되지 않습니다. 전류(힘), 속도(회전력), 진동(안정성), 무게(투입량)가 복합적으로 작용합니다. 각 센서의 평균/편차/최대값은 서로 다른 물리적 의미를 가집니다.

2 알고리즘 원리

Step 1: Bootstrap Sampling (복원 추출)

원본 데이터: 2000건 Bootstrap 샘플 1: [#5, #12, #5, #88, #12, #301, ...] ← 중복 허용, 2000건 추출 Bootstrap 샘플 2: [#1, #45, #673, #1, #99, #45, ...] ← 매번 다른 조합 Bootstrap 샘플 3: [#200, #8, #555, #200, #42, ...] ... Bootstrap 샘플 200: [#77, #3, #999, #77, #3, ...] 각 샘플은 원본의 약 63.2%를 포함 (나머지 36.8%는 OOB: Out-of-Bag) → 각 트리가 서로 다른 데이터로 학습 → 다양성 확보!

Step 2: Random Feature Selection (무작위 특징 선택)

각 분기(split)에서: 전체 특징: [CUR_mean, CUR_std, CUR_max, SPD_mean, SPD_std, SPD_max, VIB_mean, VIB_std, VIB_max, SCL_mean, SCL_std, SCL_max] → 12개 중 sqrt(12) ≈ 3~4개만 무작위 선택 Tree 1, Node 3: [CUR_mean, VIB_std, SCL_max] 중 최적 분기점 선택 Tree 1, Node 7: [SPD_mean, CUR_max, VIB_mean] 중 최적 분기점 선택 Tree 2, Node 3: [VIB_max, SCL_mean, SPD_std] 중 최적 분기점 선택 → 같은 특징이 항상 선택되는 것을 방지 → 트리 간 상관성 감소! ★ 이것이 "Random" Forest의 핵심!

Step 3: Averaging (평균 투표)

회귀 문제 (파쇄 크기 예측): 입력: CUR_mean=92A, SPD_mean=17.5RPM, VIB_mean=3.1mm/s, ... Tree 1: 24.3mm Tree 2: 25.1mm ← 각 트리가 독립적으로 예측 Tree 3: 23.8mm ... Tree 200: 24.7mm 최종 예측 = (24.3 + 25.1 + 23.8 + ... + 24.7) / 200 = 24.5mm → 개별 트리의 오차가 상쇄되어 정확도 향상! → "군중의 지혜" (Wisdom of Crowds) 효과

4 파쇄 크기 예측 & 균일도 계산

파쇄 크기 결정 요인

파쇄 크기(mm)에 영향을 주는 물리적 요인
  • 전류(CUR) 높음 → 칼날에 가해지는 힘 증가 → 파쇄 크기 감소
  • 속도(SPD) 높음 → 회전 빈도 증가 → 파쇄 크기 감소
  • 진동(VIB) 높음 → 불규칙 운전 → 파쇄 크기 불균일
  • 무게(SCL) 높음 → 투입량 과다 → 파쇄 크기 증가
파쇄 크기 계산식 (시뮬레이션): shred_size = 25.0 ← 기본 파쇄 크기 (mm) - 0.04 * (CUR_mean - 80) ← 전류 높으면 감소 - 0.15 * (SPD_mean - 17) ← 속도 높으면 감소 + 0.80 * (VIB_mean - 2.5) ← 진동 높으면 증가 (불규칙) + 0.03 * (SCL_mean - 50) ← 무게 높으면 증가 + noise ← 랜덤 변동 → 진동(VIB)의 계수가 가장 크므로 파쇄 크기에 가장 큰 영향!

균일도 계산

균일도 계산식 (시뮬레이션): uniformity = 88.0 ← 기본 균일도 (%) - 1.5 * VIB_std ← 진동 편차 크면 균일도 감소 - 0.3 * SPD_std ← 속도 편차 크면 균일도 감소 - 0.2 * CUR_std ← 전류 편차 크면 균일도 감소 + noise 균일도 = "파쇄된 조각들이 얼마나 고르게 같은 크기인가" → 센서값의 표준편차(std)가 핵심! 편차가 작을수록 균일!

그래프 2

특징 중요도 (Feature Importance)

Random Forest의 핵심 가치: 어떤 센서가 가장 중요한가?

12개 특징의 중요도 순위를 막대 그래프로 보여줍니다.

빨간 막대 = 높은 중요도, 파란 막대 = 중간, 회색 = 낮은 중요도. Random Forest는 각 특징이 분기(split)에 사용될 때의 불순도 감소량을 합산하여 중요도를 계산합니다.

특징 중요도 해석: VIB_mean (진동 평균) ████████████████████ ← 가장 중요! CUR_mean (전류 평균) ████████████ ← 2위 SPD_mean (속도 평균) ██████████ ← 3위 SCL_mean (무게 평균) ████ ← 보조 역할 ... 해석: "파쇄 크기에 가장 큰 영향을 주는 것은 진동(VIB)이다" → 진동이 불안정하면 파쇄 크기가 들쭉날쭉해진다 → 따라서 진동 관리가 파쇄 품질 향상의 핵심!

6 알고리즘 특징 / 장점 / 단점

핵심 특징

Random Forest의 3가지 핵심 특징
  • Bagging 앙상블: Bootstrap 복원 추출로 200개의 독립적인 학습 데이터셋을 생성. 각 트리는 원본의 약 63.2%만 보고 학습하여 과적합 방지
  • 병렬 트리 (Parallel Trees): 각 트리가 독립적이므로 병렬 학습/추론 가능 (n_jobs=-1). Gradient Boosting과 달리 순차적이지 않음
  • 평균 투표 (Averaging): 회귀 문제에서 200개 트리의 예측값을 평균내어 개별 트리의 분산(variance)을 효과적으로 감소

장점

  • 비선형 관계 학습: 센서 간 복잡한 상호작용을 트리 구조로 자연스럽게 포착
  • Feature Importance: "어떤 센서가 파쇄 크기에 가장 중요한가"를 수치로 제시 → 현장 운영 가이드
  • 과적합 강건: Bagging + Random Feature Selection으로 단일 트리 대비 과적합 크게 감소
  • 전처리 최소: 정규화/표준화 불필요, 결측치에 상대적으로 강건
  • OOB Score: 별도 검증셋 없이도 Out-of-Bag 데이터로 성능 추정 가능

단점

  • 큰 모델 크기: 200개 트리를 모두 저장해야 하므로 단일 트리보다 약 200배 메모리 소요
  • 단일 트리보다 느림: 추론 시 200개 트리를 모두 순회해야 하므로 단일 Decision Tree보다 느림
  • 선형 모델보다 해석 어려움: 개별 트리 시각화는 가능하지만, 200개 트리의 종합 판단 과정을 설명하기 어려움
  • 외삽(Extrapolation) 불가: 학습 데이터 범위를 벗어난 값 예측 불가 (트리의 한계)
  • Gradient Boosting 대비: 동일 조건에서 GBM/XGBoost보다 정확도가 약간 낮을 수 있음

7 슈레더 적용 시나리오

시나리오 1: 실시간 파쇄 크기 예측

10분마다 CUR, SPD, VIB, SCL 센서에서 12개 특징을 추출하여 Random Forest에 입력. 예측된 파쇄 크기가 목표 범위(20~30mm)를 벗어나면 자동으로 RPM 또는 투입량을 조절합니다.

Feature Importance를 통해 "왜 파쇄 크기가 커졌는가"를 파악: 진동이 원인이면 칼날 점검, 무게가 원인이면 투입량 조절.

실시간 파쇄 크기 모니터링 흐름: [센서 수집] [특징 추출] [RF 예측] CUR_A: 92A, CUR_B: 89A → CUR_mean: 90.5A → 파쇄 크기: 26.3mm SPD_A: 17.2, SPD_B: 16.8 → SPD_mean: 17.0RPM 균일도: 87.2% VIB_A: 3.5, VIB_B: 3.1 → VIB_mean: 3.3mm/s SCL (간접추정) → SCL_mean: 48.2kg → 정상 범위 10분 후... CUR_A: 95A, CUR_B: 88A → CUR_mean: 91.5A → 파쇄 크기: 32.1mm SPD_A: 16.5, SPD_B: 16.0 → SPD_mean: 16.3RPM 균일도: 72.5% VIB_A: 5.8, VIB_B: 4.9 → VIB_mean: 5.35mm/s SCL (간접추정) → SCL_mean: 52.1kg → 경고! 목표 초과! Feature Importance 기반 원인 분석: → VIB_mean 급증 (3.3 → 5.35) = 진동 이상이 주 원인! → 조치: 칼날 마모 점검, RPM 조절
시나리오 2: 파쇄 품질 최적화

Feature Importance 분석 결과, 진동(VIB_mean)이 파쇄 크기의 가장 큰 결정 요인임을 발견했다면:

  • 진동 감소를 위한 칼날 교체 주기 단축
  • 진동이 낮은 최적 RPM 범위를 Random Forest로 탐색
  • 투입량(SCL)과 진동의 관계를 분석하여 최적 투입량 결정
시나리오 3: 균일도 기반 품질 등급 분류
  • A등급 (균일도 90% 이상): 고부가가치 재활용 원료로 출하
  • B등급 (균일도 75~90%): 일반 재활용 원료
  • C등급 (균일도 75% 미만): 재파쇄 필요 → 자동 재투입

Random Forest가 균일도를 실시간 예측하여 자동 품질 등급 분류를 수행합니다.
