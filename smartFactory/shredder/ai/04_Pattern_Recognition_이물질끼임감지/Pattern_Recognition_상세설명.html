0패턴 인식이란?

Rule-based + Statistical Pattern Detection

패턴 인식(Pattern Recognition)은 센서 데이터에서 미리 정의된 특정 패턴을 실시간으로 탐색하는 기법입니다. 이 모델에서는 딥러닝이 아닌 규칙 기반(Rule-based) + 통계적(Statistical) 접근 방식을 사용합니다.

규칙 기반 (Rule-based)

도메인 전문가가 정의한 물리적 규칙

  • 전류 > 기준값 x 1.5배 = 스파이크
  • 속도 < 기준값 x 0.7 = 급감
  • 전류↑ + 속도↓ = 끼임
통계적 (Statistical)

데이터 분포 기반 이상 탐지

  • Z-score > 2.5σ = 주의
  • Z-score > 4.0σ = 경보
  • 슬라이딩 윈도우 기준선 갱신
왜 딥러닝이 아닌가? 이물질 끼임은 패턴이 매우 명확합니다(전류 급등 + 속도 급감). 규칙 기반으로도 95% 이상 정확도를 달성할 수 있으며, 5ms 미만의 초고속 응답과 완전한 해석 가능성(Explainability)을 보장합니다.

2.1 슬라이딩 윈도우 (Sliding Window)

기준선(baseline)을 실시간으로 갱신하는 핵심 메커니즘입니다.

윈도우 크기 = 300 samples (3초)
가드 구간 = 30 samples (0.3초) ← 최근 데이터 제외

baseline_mean = mean(buffer[0 : -30])
baseline_std = max(std(buffer[0 : -30]), 0.1)
가드 구간(Guard Band): 최근 0.3초 데이터를 기준선 계산에서 제외합니다. 이미 이상이 시작된 데이터가 기준선을 오염시키는 것을 방지하기 위함입니다.

2.2 Z-score 기반 감지

현재 값이 기준선에서 얼마나 떨어져 있는지를 표준편차 단위로 측정합니다.

Z-score = (현재값 - 기준선 평균) / 기준선 표준편차
감지 대상Z-score 주의Z-score 경보의미
전류 스파이크≥ 2.5σ≥ 4.0σ기준 대비 비정상적 상승
속도 급감≤ -2.5σ≤ -4.0σ기준 대비 비정상적 하락

2.3 비율 기반 감지

Z-score와 독립적으로, 절대적인 비율 변화도 확인합니다.

전류 스파이크: 현재 전류 > 기준 평균 × 1.5
속도 급감: 현재 속도 < 기준 평균 × 0.7

2.4 변화율 (Rate of Change) 감지

최근 50ms(5 samples) 동안의 값 변화 속도를 계산합니다.

변화율 = (최근값 - 5 samples 전 값) / (4 × 0.01초)
감지 대상주의 임계값경보 임계값
전류 상승률≥ 200 A/s≥ 500 A/s
속도 감소율≤ -150 RPM/s≤ -300 RPM/s

2.5 결합 규칙 (Combined Rules)

단독 증거는 최대 0.4의 확률만 부여하며, 전류 스파이크 + 속도 급감이 동시에 감지될 때만 0.6 이상의 높은 확률이 산출됩니다.

결합 조건: 전류 스파이크 감지 = True AND 속도 급감 감지 = True → 결합 보너스 x1.2 적용, 끼임 확률 최대 1.0
3확률 계산 로직

다중 증거 융합 (Multi-Evidence Fusion)

6개의 독립적인 증거를 가중합하여 최종 끼임 확률을 산출합니다.

#증거기여도조건
1전류 Z-score ≥ 경보+0.4Z ≥ 4.0σ
2전류 Z-score ≥ 주의+0.22.5σ ≤ Z < 4.0σ
3전류 비율 초과+0.2현재 > 기준 × 1.5
4전류 변화율+0.1~0.2≥ 200 또는 500 A/s
5속도 Z-score ≤ 경보+0.4Z ≤ -4.0σ
6속도 Z-score ≤ 주의+0.2-4.0σ < Z ≤ -2.5σ
7속도 비율 미달+0.2현재 < 기준 × 0.7
8속도 변화율+0.1~0.2≤ -150 또는 -300 RPM/s

확률 계산 공식

spike_score = Z-score 기여 + 비율 기여 + 변화율 기여 (전류)
drop_score = Z-score 기여 + 비율 기여 + 변화율 기여 (속도)

결합 감지 시: P = min(1.0, (spike_score + drop_score) × 1.2)
전류만 감지: P = min(0.4, spike_score × 0.7)
속도만 감지: P = min(0.4, drop_score × 0.7)
미감지: P = 0.0

상태 머신 (State Machine)

확률값을 누적 카운터로 변환하여 일시적 노이즈를 필터링합니다.

상태조건의미색상
NORMALjam_counter = 0정상 운전초록
CAUTION0 < jam_counter < 10주의 관찰노랑
WARNING10 ≤ jam_counter < 20경고, 대비주황
JAMMINGjam_counter ≥ 20끼임 확인, 즉시 조치빨강
카운터 로직: P ≥ 0.6이면 +1, 0.3~0.6이면 -1 (감쇠), P < 0.3이면 -3 (빠른 복귀). 이 비대칭적 감쇠로 False Positive를 빠르게 해소하면서도 실제 끼임은 놓치지 않습니다.

결과 그래프

4패널 시각화: (1) 전류 + 스파이크 감지, (2) 속도 + 급감 감지, (3) 끼임 확률, (4) 이벤트 타임라인

그래프 해석

패널 1: 전류 신호 및 스파이크 감지

  • 파란색 선: 실시간 전류값 (A), 정상 시 60A 부근 안정
  • 빨간 점: 스파이크 감지 포인트 (Z-score 또는 비율 초과)
  • 주황색 선(보조축): 전류 Z-score, 점선은 주의(2.5) 및 경보(4.0) 임계값
  • 12~14초, 28~33초 구간에서 뚜렷한 전류 스파이크 관찰

패널 2: 속도 신호 및 급감 감지

  • 초록색 선: 실시간 속도값 (RPM), 정상 시 120RPM 부근
  • 빨간 점: 급감 감지 포인트
  • 보라색 선(보조축): 속도 Z-score, 음수 방향으로 큰 값 = 급감
  • 전류 스파이크와 동기화된 속도 급감 패턴 확인

패널 3: 끼임 확률 (다중 증거 융합)

  • 빨간 영역: 끼임 확률 (0~1), 높을수록 끼임 가능성 높음
  • 이벤트 1 (12~14초): 확률 0.5~0.7 수준 → WARNING
  • 이벤트 2 (28~33초): 확률 0.9~1.0 수준 → JAMMING
  • 이벤트 3 (45초): 확률 < 0.3 → 정상 (순간 충격 올바르게 무시)

패널 4: 이벤트 감지 타임라인

  • 상태 전이 시각화: 정상(0) → 주의(1) → 경고(2) → 끼임(3)
  • 색상: 초록(정상), 노랑(주의), 주황(경고), 빨강(끼임)
  • 이벤트 2에서 JAMMING 상태까지 도달, 이벤트 3에서는 정상 유지
검증 결과: 경미한 끼임은 WARNING으로 감지, 심각한 끼임은 JAMMING으로 확인, 순간 충격(정상)은 올바르게 무시하여 오탐(False Positive) 없이 정확한 감지를 시연합니다.

특징 (Characteristics)

⚙
규칙 기반

도메인 전문가의 물리적 지식을 직접 규칙으로 인코딩. 학습 데이터 불필요.

⚡
실시간 처리

10ms 주기로 입력, 5ms 미만으로 판정 완료. 임베디드 시스템에 최적.

🔍
해석 가능

모든 판정에 대해 "왜?"를 명확히 설명. Z-score, 비율, 변화율 수치 제공.

📈
다중 증거 융합

6개 독립 증거의 가중합으로 단일 지표 의존 위험 제거.

장점 (Advantages)
  • 초고속 응답 (5ms 미만): 복잡한 연산 없이 사칙연산과 비교 연산만으로 처리
  • 학습 불필요 (No Training): 별도의 학습 데이터 수집/모델 학습 과정이 없어 즉시 배포 가능
  • 결정론적 (Deterministic): 동일 입력에 항상 동일 출력. 재현성 100%
  • 완전한 해석 가능성 (Explainable): 매 판정마다 근거(Z-score, 비율 등)를 수치로 제시
  • 저사양 하드웨어 가능: MCU(마이크로컨트롤러)에서도 실행 가능, GPU 불필요
  • 인증 용이: 규칙이 명확하여 안전 인증 심사에 유리
단점 (Limitations)
  • 수동 임계값 튜닝: 설치 환경, 재료, 계절 등에 따라 임계값을 수동 조정해야 함
  • 미지 패턴 대응 불가: 사전 정의하지 않은 새로운 유형의 이상 감지 불가능
  • 센서 드리프트에 취약: 센서 노후화/교정 오차 시 기준선이 왜곡되어 오탐/미탐 발생 가능
  • 점진적 변화 감지 어려움: 서서히 진행되는 끼임(점착성 재료)은 급변 패턴과 달라 감지 지연 가능
  • 규칙 관리 복잡도: 조건이 늘어날수록 규칙 간 충돌/중복 관리 부담 증가
  • 일반화 한계: 한 슈레더에서 튜닝한 파라미터가 다른 기종에 바로 적용 불가

배치 재활용 공정 끼임 시나리오

시나리오 1: 금속 이물질 끼임

상황: 폐배터리 파쇄 중 분리되지 않은 대형 알루미늄 케이스 조각이 칼날 사이에 끼임
전류 변화: 60A → 160A (2.7배, 0.3초 내)
속도 변화: 120 RPM → 35 RPM (71% 감소)
감지 시간: 끼임 발생 후 약 150ms
자동 대응: 즉시 정지 → 3초 대기 → 역회전 10 RPM → 해소 확인
결과: 1차 역회전에서 해소, 총 대응 시간 약 12초

시나리오 2: 점착성 재료 축적

상황: 전해액이 묻은 재료가 칼날에 점착, 점진적으로 회전 저항 증가
전류 변화: 60A → 85A (30분에 걸쳐 서서히 증가)
속도 변화: 120 RPM → 105 RPM (서서히 감소)
감지: 슬라이딩 윈도우가 기준선을 지속 갱신하므로 급변이 아닌 점진적 변화는 감지 지연 발생 가능
보완: 모델 02(칼날 마모 예측) 및 모델 10(통합 분석)과 연계하여 장기 트렌드 모니터링 필요

시나리오 3: 재료 투입 충격 (정상)

상황: 대형 폐배터리 묶음이 호퍼에서 한꺼번에 투입
전류 변화: 60A → 78A (1.3배, 0.3초간)
속도 변화: 120 RPM → 108 RPM (10% 감소)
감지 결과: 확률 0.15 미만, NORMAL 상태 유지
이유: 전류 상승폭이 임계값(1.5배) 미만, 속도 감소폭도 임계값(70%) 이상 유지, 지속 시간도 0.5초 미만
