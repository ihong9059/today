## 1. Executive Summary

### 1.1 제안 배경

폐배터리 재활용 공정의 **첫 번째이자 가장 위험한** 설비인 이축 전단 파쇄기(Shredder)는 다음과 같은 핵심 과제를 안고 있습니다:

| 과제 | 현재 상황 | 위험/손실 |
|------|----------|----------|
| **칼날 마모/파손** | 육안 점검, 경험 기반 교체 | 비계획 정지 (연 40시간+), 파쇄 품질 저하 |
| **화재/폭발 위험** | 적외선 센서 + 수동 대응 | 감지→대응 수십 초 지연, 인명 위험 |
| **파쇄 품질 불균일** | 정기 샘플링 (수시간 간격) | 후속 공정 효율 저하, 회수율 손실 1~2% |

### 1.2 제안 솔루션

### 1.3 왜 슈레더부터 시작하는가?

| 이유 | 설명 |

## 3. 현재 문제점 및 과제 도출

### 3.1 문제점 상세

#### A. 고장/정비 문제

| 문제 | 상세 | 연간 손실 |
|------|------|:---------:|
| 칼날 마모 미감지 | 육안 점검으로는 내부 마모 확인 불가. 파쇄 효율 저하 후 뒤늦게 발견 | 정비 지연 손실 3천만원 |
| 베어링 과잉 교체 | 시간 기반(TBM) 교체로 수명 남은 베어링 조기 교체 | 부품비 낭비 1천만원 |
| 비계획 정지 | 칼날 파손·이물질 끼임 등으로 연 40시간+ 비계획 정지 | 생산 손실 **1억원** |
| 감속기 이상 미감지 | 오일 열화·기어 마모를 정기 점검 외 감지 수단 없음 | 돌발 교체 시 2천만원 |

#### B. 안전 문제

| 문제 | 상세 | 위험도 |
|------|------|:------:|
| 발화 감지 지연 | 적외선 센서 단일, 감지→운전자 확인→소화 조치까지 수십 초 | **극대** |
| 거짓 경보 | 단순 임계값 방식으로 거짓 경보 빈번 (월 5회+) → 경보 무시 습관화 | 상 |
| 전해액 누출 | 1일 1회 정기 점검 사이에 발생 시 감지 불가 | 상 |
| 분진 관리 | 실시간 농도 추이 분석 없이 순간 값만 감시 | 중 |

#### C. 파쇄 품질 문제

| 문제 | 상세 | 영향 |
|------|------|------|
| 파쇄 크기 편차 | 칼날 마모에 따라 50~100mm 범위를 벗어나는 과대/과소 파쇄 발생 | 후속 크러셔 부하 증가 |
| 피드백 지연 | 파쇄물 샘플링 → 오프라인 측정까지 2~4시간 | 불량 지속 생산 |
| RPM 수동 조정 | 재료 특성에 따른 최적 RPM을 운전자 경험에 의존 | 최적화 한계 |
| 분진 손실 | 파쇄 시 비산 분진으로 유가금속 1~2% 손실 | 회수율 저하 |

| 단순 임계값 초과 시 즉시 경보 | **트렌드 분석**: 순간 스파이크 vs 지속 상승 구분 | 순간 노이즈 경보 제거 |

| 정상 변동을 이상으로 판단 | **학습 기반 정상 범위**: 재료·RPM별 정상 패턴 학습 | 운전 조건별 맞춤 임계값 |
| 전해액 가스 vs 환경 가스 혼동 | **Multi-gas Fusion**: VOC+H₂+CO 복합 패턴 분석 | 전해액 특이 패턴만 감지 |

### 9.2 파쇄 품질 간접 측정 원리

> 슈레더 단계에서는 인라인 입도 분석기 설치가 어려우므로, **센서 데이터로 파쇄 품질을 간접 추정**합니다.

| 센서 데이터 | 파쇄 품질과의 상관관계 | 활용 |
|-----------|---------------------|------|
| **전류 (CUR)** | 전류↑ = 부하↑ = 더 잘게 파쇄 / 칼날 마모 시 전류↑인데 파쇄 효율↓ | 마모 보정 후 파쇄 크기 추정 |
| **회전속도 (SPD)** | RPM↑ = 파쇄 빈도↑ = 더 잘게 | RPM-크기 상관 모델 |
| **처리량 (SCL)** | 처리량↑ = 체류시간↓ = 더 크게 파쇄 | 투입량 보정 |
| **진동 (VIB)** | 칼날 상태에 따른 파쇄 패턴 변화 | 칼날 마모 보정 |
| **배출 흐름 (PS)** | 배출물 높이/속도 = 파쇄물 크기·양 간접 추정 | 막힘·과대 파쇄 감지 |

## 10. AI 기능 4: 설비-품질-안전 연계 분석

### 10.1 슈레더 내 3가지 영역의 상관관계

| 연계 관계 | 예시 시나리오 | AI 판단 | 조치 |
|----------|-------------|---------|------|
| **설비→품질** | 칼날 마모 30%↑ → 전류 10%↑ → 파쇄 크기 과대 | "파쇄 품질 저하의 원인: 칼날 마모" | RPM 미세 조정 + 칼날 교체 계획 |
| **설비→안전** | 베어링 과열 → 윤활유 분해 가스 → 가스 감지 | "가스 감지는 전해액이 아닌 베어링 윤활유 원인" | 거짓 경보 방지 + 베어링 정비 |
| **안전→품질** | N₂ 퍼지 부족 → 산화 진행 → 블랙매스 변색 | "품질 변색의 원인: N₂ 농도 부족" | N₂ 유량 증가 |
| **품질→설비** | 파쇄 크기 갑자기 과대 → 칼날 파손/탈락 의심 | "파쇄 품질 급변은 칼날 파손 징후" | **즉시 정지 + 점검** |

| **전력** | **25W** | **2.5~3W (약 1/8)** |
| **perf/W** | 4 TOPS/W | **9~10 TOPS/W (세계 1위)** |

- 컴팩트 디바이스 필요 (소형 케이스, 추가 케이블 최소화)

#### 운영비 비교 (24/7 가동 기준, 100라인 도입 공장 가정)
