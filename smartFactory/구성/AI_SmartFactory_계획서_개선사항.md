## 1. 고장예지 AI SmartFactory 계획서 개선사항

### 1.1 센서 ID 체계 통일 및 표준화

**현재 상태:**
- VIB-1A, TMP-1B 등 개별 센서 ID는 있으나, 전체 통합 태그 명명 규칙 부재

**개선 권고:**

| 계층 | 형식 | 예시 | 설명 |
|:----:|------|------|------|
| Level 1 | 공장 코드 | BRF | Battery Recycling Factory |
| Level 2 | 공정 코드 | SHR/CRS/PIN/CLF | Shredder/Crusher/PinMill/Classifier |
| Level 3 | 장비 번호 | 01, 02 | 동일 공정 내 장비 순번 |
| Level 4 | 센서 유형 | VIB/TMP/CUR/SPD | 진동/온도/전류/속도 |
| Level 5 | 위치/채널 | A/B/C | 설치 위치 또는 채널 |

**통합 태그 예시:**
```
BRF-SHR-01-VIB-A    : 1차 파쇄기 1호 진동센서 A
BRF-CRS-01-TMP-B    : 해머 크러셔 1호 온도센서 B
BRF-PIN-01-CUR-A    : 핀밀 1호 전류센서 A
BRF-CLF-01-SPD-A    : 분급기 1호 속도센서 A
```

### 1.2 통신 프로토콜 명시

**현재 상태:**
- Edge Gateway 사양은 있으나, 센서-게이트웨이 간 통신 프로토콜 미명시

**개선 권고:**

| 센서 유형 | 출력 신호 | 통신 방식 | 샘플링 | 비고 |
|----------|----------|----------|--------|------|
| 진동 가속도계 | IEPE (100mV/g) | 아날로그 → 24bit ADC | 100kHz | 고속 DAQ 필요 |
| PT100 온도 | RTD 3-wire | 아날로그 → RTD 컨버터 | 1Hz | |
| 적외선 온도 | 4-20mA | 아날로그 → ADC | 10Hz | |
| CT 전류센서 | 0-5V | 아날로그 → ADC | 1kHz | |
| 엔코더 | 펄스 (NPN) | 디지털 GPIO | - | 카운터 입력 |
| 초음파 근접 | 4-20mA | 아날로그 → ADC | 10Hz | |
| 분진센서 | RS485 Modbus | 디지털 | 1Hz | |
| 가스센서 | RS485 Modbus | 디지털 | 1Hz | |
| MEMS 마이크 | PDM/I2S | 디지털 | 48kHz | |

**추가 권고사항:**
- 아날로그 센서는 현장 Junction Box에서 신호 컨디셔닝 후 전송
- 디지털 센서는 RS485 버스 구성 (최대 32개 디바이스/버스)
- 고속 진동/음향 데이터는 별도 고속 DAQ 채널 할당

### 1.3 안전 관련 센서 이중화 구성

**현재 상태:**
- 발화 감지, 가스 감지 등 안전 센서의 이중화 여부 미명시

**개선 권고:**

| 안전 기능 | 주 센서 | 백업 센서 | 이중화 로직 |
|----------|--------|----------|------------|
| **발화 감지** | 적외선 온도센서 (TMP-1C) | 열화상 카메라 | OR 로직 (하나라도 감지 시 경보) |
| **폭발 위험** | 분진센서 (DST-1A) | 분진센서 (DST-1B) | 투표 로직 (2 out of 2) |
| **전해액 누출** | 가스센서 (GAS-3A) | 가스센서 (GAS-3B) | OR 로직 |
| **과열 감지** | PT100 (TMP-xA) | PT100 (TMP-xB) | 교차 검증 |

**Safety PLC 연동:**
```
┌──────────────────────────────────────────────────────────────────┐
│                    Safety System Architecture                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│   [주 센서]──┐                                                   │
│              ├──▶ [Safety PLC] ──▶ [비상정지/소화/환기]         │
│   [백업센서]─┘         │                                         │
│                        │                                         │
│                        ▼                                         │
│              [Edge Gateway] ──▶ [알림/로깅]                      │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

**추가 권고사항:**
- 안전 관련 센서는 SIL 2 이상 인증 제품 사용
- Safety PLC는 Edge Gateway와 독립적으로 운영 (Fail-safe)
- 안전 이벤트 발생 시 Edge Gateway는 로깅 및 알림만 담당

## 2. 품질관리 AI SmartFactory 계획서 개선사항

### 2.1 인라인-오프라인 측정값 교정(Calibration) 절차

**현재 상태:**
- 인라인 센서와 FRITSCH 오프라인 분석기의 측정값 연계 방법 미명시

**개선 권고:**

```
┌──────────────────────────────────────────────────────────────────┐
│                  측정값 교정(Calibration) 체계                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│   [인라인 센서]                     [FRITSCH 분석기]              │
│        │                                  │                       │
│        │ (연속 측정)                      │ (시간당 1회)          │
│        │                                  │                       │
│        └────────────────┬─────────────────┘                       │
│                         │                                         │
│                         ▼                                         │
│        ┌────────────────────────────────────┐                     │
│        │       교정 알고리즘               │                     │
│        │                                    │                     │
│        │  인라인_보정값 = 인라인_측정값    │                     │
│        │                 × 교정계수        │                     │
│        │                 + 오프셋          │                     │
│        │                                    │                     │
│        │  교정계수 = f(FRITSCH 기준값)     │                     │
│        └────────────────────────────────────┘                     │
│                         │                                         │
│                         ▼                                         │
│        ┌────────────────────────────────────┐                     │
│        │       교정 주기 및 방법           │                     │
│        │                                    │                     │
│        │  • 정기 교정: 주 1회              │                     │
│        │  • 자동 교정: 매 오프라인 측정 시 │                     │
│        │  • 편차 임계: ±5% 초과 시 알림    │                     │
│        └────────────────────────────────────┘                     │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

**교정 프로세스:**

| 단계 | 내용 | 주기 |
|:----:|------|:----:|
| 1 | 인라인 센서와 동일 시점 샘플 채취 | 시간당 1회 |
| 2 | FRITSCH 분석기로 기준값 측정 | 시간당 1회 |
| 3 | 인라인 측정값과 FRITSCH 측정값 비교 | 자동 |
| 4 | 편차 5% 이상 시 교정계수 재계산 | 자동 |
| 5 | 편차 10% 이상 시 인라인 센서 점검 알림 | 자동 |

### 2.2 품질 등급 기준표

**현재 상태:**
- A/B/C/D 등급 언급만 있고, 구체적 기준값 미명시

**개선 권고:**

| 등급 | D50 (μm) | D90 (μm) | Span | 원형도 | 회수율 | 수분 | 순도 |
|:----:|:--------:|:--------:|:----:|:------:|:------:|:----:|:----:|
| **A** (우수) | 45~55 | ≤150 | ≤1.8 | ≥0.88 | ≥96% | ≤0.8% | ≥99% |
| **B** (양호) | 40~60 | ≤165 | ≤2.0 | ≥0.85 | ≥94% | ≤1.2% | ≥98% |
| **C** (보통) | 35~65 | ≤180 | ≤2.3 | ≥0.80 | ≥90% | ≤1.8% | ≥96% |
| **D** (불량) | 그 외 | >180 | >2.3 | <0.80 | <90% | >1.8% | <96% |

**등급 결정 로직:**
```
등급 = MIN(D50등급, D90등급, Span등급, 원형도등급, 회수율등급, 수분등급, 순도등급)

예시:
- D50=50μm(A), D90=155μm(B), Span=1.9(B), 원형도=0.87(B), 회수율=95%(B)
- 최종 등급 = B (가장 낮은 등급 적용)
```

### 3.2 설비-품질 상관분석 활용

| 설비 상태 | 품질 영향 | 분석 방법 | 활용 |
|----------|----------|----------|------|
| 해머 마모도 | 입도 분포폭 증가 | 전류-D90 상관분석 | 해머 교체 시점 최적화 |
| 핀 마모도 | 원형도 저하 | 진동-원형도 상관분석 | 핀 교체 시점 최적화 |
| 베어링 상태 | 입도 편차 증가 | 진동-Span 상관분석 | 베어링 교체 시점 최적화 |
| 분급기 압력 | 분급 효율 | 압력-회수율 상관분석 | 압력 최적값 도출 |

**기대 효과:**
- 설비 정비와 품질 관리의 연계로 효율 극대화
- 정비 시점 최적화 (품질 저하 전 선제 정비)
- 품질 이상의 근본 원인 빠른 특정
