# healthWiki — Schema (Claude 운영 규칙)

이 위키는 **박정훈(45세, 회사원)의 건강·운동 일지**입니다.

## 목적
1. **자기 관찰**: 운동·식단·수면을 매일 정량 기록
2. **패턴 발견**: 행동 A + 환경 B → 컨디션 C의 인과관계 추적
3. **건강 회복**: 40대 중반 체력 저하를 데이터 기반으로 개선

## 디렉토리 구조

```
2_healthWiki/
├── CLAUDE.md (이 파일)
├── index.md
├── log.md
├── me.md
├── goals.md
├── raw/        # 일일 정량 기록 (불변)
├── thoughts/   # 패턴 발견 (A+B→C)
└── entities/   # 운동 종류·식품·증상 페이지
```

## 워크플로우 (간단형)
- **Ingest**: 매일 저녁 한 줄 (raw 자동 생성)
- **Interpret**: 매주 일요일 — 7일 raw 횡단 → thought 1개 도출 시도
- **Use**: 컨디션 나쁜 날 → "비슷한 날 뭐 했지?" 위키 검색
- **Lint**: 매월 1일 — 한 달 raw 점검, 새 entity 후보 식별
