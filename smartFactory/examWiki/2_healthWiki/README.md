## 이 wiki에서 체감할 수 있는 카파시 패턴 가치

### 가장 강한 체감 포인트
**"매일의 단순 기록만 보면 안 보이지만, 일주일 모아 횡단해서 보면 패턴이 보인다."**

본 wiki에는 4일치 raw가 있습니다 (실제로는 매일 작성):
1. `2026-04-15` 운동 컨디션 좋음
2. `2026-04-17` 운동 컨디션 나쁨
3. `2026-04-19` 운동 컨디션 좋음
4. `2026-04-21` 운동 컨디션 나쁨

각 raw만 보면 단순한 일기. 그러나 thoughts/에서:
- `thoughts/2026-04-22_탄수화물과_컨디션_상관관계.md` ← 4일치 raw를 횡단해 발견한 패턴

→ **사람의 두뇌는 이런 횡단 패턴을 잘 못 보지만, 위키 + LLM은 보인다.**
