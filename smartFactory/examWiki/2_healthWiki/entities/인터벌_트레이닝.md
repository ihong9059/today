# 인터벌 트레이닝 (HIIT)

## 무엇인가
- 고강도 인터벌 트레이닝 (High-Intensity Interval Training)
- 짧은 고강도 운동 + 짧은 휴식을 반복
- 짧은 시간(15-20분)에 큰 칼로리 소모 + 심폐 강화

## 박정훈의 HIIT 실천
- **2026-04-19**: 컨디션 좋은 날 처음 시도 — 트레드밀 인터벌 15분
  - 1분 빠르게(15km/h) + 2분 천천히(7km/h) × 5세트
- **컨디션 나쁜 날에는 시도 안 함** (4-17, 4-21)
- → 컨디션 좋은 날만 보너스 운동으로 추가

## 박정훈에게 의미
- 시간 효율 운동 → 야근 잦은 IT 직군에 적합
- 다만 컨디션 의존도 높음 → [[2026-04-22_탄수화물과_컨디션_상관관계]] 데이터 활용

## 다음 시도
- 주 2회 정도로 늘리기 (현재는 1회)
- 컨디션 7/10 이상인 날만
