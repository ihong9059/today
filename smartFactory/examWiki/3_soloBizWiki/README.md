## 이 wiki에서 체감할 수 있는 카파시 패턴 가치

### 가장 강한 체감 포인트
**"성공·실패의 진짜 원인은 결과가 나온 후가 아니라, 결정 직전의 선택에 있다."**

1. `2026-04-12` 한국기계 미팅 (성공 패턴)
2. `2026-04-18` 태명과학 제안서 발송 (실패 패턴)

- `thoughts/2026-04-25_제안서_방식_매출_상관관계.md` ← 4건 raw 횡단 → 영업 패턴 발견
