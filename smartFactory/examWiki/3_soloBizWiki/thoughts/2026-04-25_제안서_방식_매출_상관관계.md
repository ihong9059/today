## A + B → C 패턴

### A (성공 사례): [[2026-04-12_한국기계_미팅]]
- **3시간 도면 분석** + **현장 문제 가설 3개** 미리 작성
- 미팅 첫 5분에 "이 위치 베어링 마모 패턴이..." 구체적 진단
- 김상무 반응: "진짜 우리 도면 봤네"
- → 즉석 800만 계약

### B (실패 사례): [[2026-04-18_태명과학_제안서]] + [[2026-04-22_위시캣_지원_결과]]
- 회사 소개·경력 어필 위주
- 현장 분석 없음
- 가격 경쟁
- → 모두 거절 또는 무응답

### C (새 통찰)
**1인 컨설팅 사업의 수주 = 사전 분석 깊이의 함수다.**
- 더 정확히: **고객 도메인의 구체적 데이터·도면 분석을 미팅 전에 해두면**, 30년 경력보다 그 한 번의 분석이 더 강력한 영업 도구가 된다.
- 일반론적 회사 소개·경력 어필은 가격 경쟁으로 빠진다.

## 어떻게 적용할까

### 즉시 행동 (2026-04-25 결심)
1. **모든 신규 영업 = 사전 분석 3시간 의무화**
   - 고객사 도면·매출·경쟁사 분석
   - 현장 문제 가설 최소 3개 작성
   - 가설을 미팅 첫 5분에 제시

2. **위시캣 비중 축소**
   - 위시캣 지원서 표준 양식이 사전 분석 어프로치 안 받음
   - 본인 강점이 안 통하는 채널 → 시간 낭비
   - 월 4-5건 → 월 1-2건으로

3. **제안서 형식 변경**
   - 회사 소개 5쪽 → 1쪽으로 축소
   - **고객사 현장 분석** 4쪽으로 확대
   - "당신 회사의 X 라인은 Y 문제가 있는 것으로 보입니다" 같은 구체성

4. **정부과제·기존 인맥 비중 ↑**
   - 본인 강점이 발휘되는 영역
   - 신뢰 기반 → 사전 분석 어프로치도 잘 통함
