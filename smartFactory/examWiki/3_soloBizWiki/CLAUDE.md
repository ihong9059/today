# soloBizWiki — Schema (Claude 운영 규칙)

이 위키는 **이상호(58세)의 1인 사업 운영 일지**입니다.

## 목적
1. **사업 판단 추적**: 영업·견적·계약의 인과관계 기록
2. **패턴 발견**: 어떤 영업 방식이 수주율 높은가
3. **고객사 이해 누적**: 고객사별 특성·이력·관계자 정보

## 디렉토리 구조

```
3_soloBizWiki/
├── CLAUDE.md (이 파일)
├── index.md
├── log.md
├── me.md
├── goals.md
├── raw/        # 미팅·제안서·매출 이벤트 (불변)
├── thoughts/   # 영업 패턴 발견
└── entities/   # 고객사·플랫폼·도구·경쟁사
```

## raw 형식

```yaml
---
title: YYYY-MM-DD 이벤트제목
type: raw
event_type: 미팅 | 제안서 | 견적 | 결제 | 거절 | 회식
created: YYYY-MM-DD
tags: [고객사, 이벤트타입]
links: [고객사entity, 관련raw]
---

# YYYY-MM-DD 이벤트 제목

## 이벤트 정보
- 일시·장소:
- 참석자(우리쪽 / 상대):
- 목적:

## 진행 내용
- ...

## 즉각 메모 (느낌·예감)
- ...

## 후속 액션
- [ ] ...
```

## 이상호의 페르소나
- 58세 남성, 산업기계 컨설팅 1인 사업
- 30년 산업 경력, 5년 전 1인 창업
- 영업·견적·실행 모두 본인이 함
- 직관·관계 기반 영업 + 데이터로 보완하고 싶어함

## 워크플로우
- **Ingest**: 미팅·제안서·계약 발생 시 그날 저녁 raw 작성
- **Interpret**: 매월 마지막 주 — 한 달 raw 횡단 → 영업 패턴 thought
- **Use**: 새 고객 미팅 전 → 비슷한 고객사 raw 검색
- **Lint**: 분기 1회 — 고객사 entity 갱신, 거절 패턴 점검
