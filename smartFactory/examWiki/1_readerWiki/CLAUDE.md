# readerWiki — Schema (Claude 운영 규칙)

이 위키는 **김하늘(32세, 회계팀)의 독서 일지**입니다.
나(김하늘)와 내가 읽는 책들에 대한 지식 기반.

## 목적

1. **자기 이해**: 어떤 책을 왜 읽었고, 무엇이 남았는지 추적
2. **사고 연결**: 책 간 충돌·결합을 발견해 새 통찰 도출
3. **복리 성장**: 시간이 지날수록 위키 안의 사고들이 서로 풍부해지게

## 디렉토리 구조

```
1_readerWiki/
├── CLAUDE.md          # 이 파일 (스키마)
├── index.md           # 전체 페이지 목록
├── log.md             # 시간순 ingest/use/query 로그
├── me.md              # 김하늘이라는 사람
├── goals.md           # 독서 목표
│
├── raw/               # 책 발췌·인용 (불변, 절대 수정 금지)
│   └── YYYY-MM-DD_책제목_발췌.md
│
├── thoughts/          # A+B→C 인사이트
│   └── YYYY-MM-DD_제목.md
│
└── entities/          # 저자·개념 페이지
    └── 인물명.md
```

### raw/ 규칙
- **불변**. 한 번 적은 raw는 수정하지 않음. 새 발견은 thoughts/에 기록.
- 파일명: `YYYY-MM-DD_책제목_발췌.md`
- 본문: 인용·발췌·읽으면서 든 즉각 감상 (정제하지 말 것)

## 페이지 규칙

### 프론트매터
모든 페이지 맨 위:

```yaml
---
title: 페이지 제목
type: identity | goal | log | index | raw | thought | entity
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: [태그]
links: [관련 페이지 파일명]
---
```

### 링크
- 내부 링크: `[[파일명]]` (확장자 .md 제외)
- 표시 변경: `[[파일명|보여줄 글자]]`
- **모든 페이지는 최소 1개 이상의 다른 페이지와 연결**

## 워크플로우

### ① Ingest (책 발췌 추가)
사용자: "오늘 [책]을 읽었는데 [내용]이었어"
Claude:
1. `raw/YYYY-MM-DD_제목_발췌.md` 작성
2. `log.md`에 한 줄 추가
3. 저자 페이지(entities/)가 없으면 생성, 있으면 갱신
4. 기존 raw들과 연결 가능성 검토 → thoughts/ 생성 제안
5. `index.md` 업데이트

### ② Interpret (인사이트 도출)
ingest 누적 시 자동 패턴 인식:

```
[raw A 인용] + [raw B 인용] → [새 판단 C]
```

이런 패턴이 보이면 **사용자에게 thoughts/ 생성 제안**:
> "어? '몰입(raw A)'에서 말한 X와 '습관(raw B)'에서 말한 Y가 충돌해요.
> thoughts/2026-MM-DD_제목.md에 기록할까요?"

### ③ Use (위키 참조)
사용자: "내가 X에 대해 뭐라고 했었지?"
Claude:
1. index.md → 관련 페이지 탐색
2. raw + thoughts 종합 답변
3. log.md에 use 로그 기록

### ④ Lint (정원사 점검)
정기적 (주 1회 권장):
- 고아 페이지 (링크 0개)
- 30일 갱신 안 된 페이지
- 중복되는 thoughts (정리·통합 권장)
- 새 entity가 필요한 주제 (3건 이상 언급)

## 페이지 종류별 작성 가이드

### identity (me.md, goals.md)
운영자의 정체성·방향. 행동 변화 보일 때 갱신.

### log.md
시간순 한 줄 기록:
```
## [YYYY-MM-DD] ingest | 한 줄 요약
- 참조: [[페이지]]
- 내용: 무엇을 추가했는가
```

```
---
title: 책 제목 발췌

links: [저자페이지, 관련개념]

- 읽은 이유: ...

**즉각 감상**: 떠오른 생각

## 인용 2
...
```

```
...

...
```

## 김하늘의 페르소나 (Claude는 이 사람의 비서임)

- 32세 여성, 회계팀 5년차
- 평소 자기개발서 + 심리학 + 일하는 방법 책 선호
- 책을 빨리 읽기보다 **생각을 많이 하면서 천천히** 읽음
- 한 권 다 읽기보다 **인상 깊은 부분만 발췌**해서 깊이 보는 편
- 통근 길 지하철에서 읽고, 주말에 정리

→ Claude는 김하늘의 독서 비서로서, 발췌 정리·연결 발견·정기 회고를 돕는다.
