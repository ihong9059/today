## 이 wiki에서 체감할 수 있는 카파시 패턴 가치

### 가장 강한 체감 포인트
**"책 1권만 읽으면 단순 정보지만, 4권을 [[링크]]로 연결하면 새 사고가 만들어진다."**

본 wiki에는 4권의 책 발췌가 raw/에 있습니다:
1. `2026-04-10` 미하이 칙센트미하이 — 「몰입(Flow)」
2. `2026-04-14` 제임스 클리어 — 「아주 작은 습관의 힘」
3. `2026-04-20` 칼 뉴포트 — 「딥워크」
4. `2026-04-25` 오스틴 클레온 — 「훔쳐라, 아티스트처럼」

각 raw는 단순 발췌입니다. 그런데 thoughts/에 있는 2개 인사이트가 **raw 4개를 가로질러 만들어진 통찰**입니다:

- `thoughts/2026-04-15_몰입과_습관의_충돌.md` ← 책1 + 책2의 충돌 발견
- `thoughts/2026-04-22_진짜_지식과_정보의_차이.md` ← 책1 + 책3의 결합

### 그래프뷰에서 확인하기
Obsidian에서 `Ctrl+G`로 그래프뷰를 열면:
- 4개 raw가 흩어져 있고
- thoughts 2개가 **여러 raw를 동시에 가리키는** 노드로 보임 (= 통찰)
- entities (저자 3명)가 raw를 묶어주는 또 다른 노드

→ **이게 카파시 패턴의 시각적 본질**

## 권장 정독 순서 (15분)

1. **README.md** (이 파일)
2. **CLAUDE.md** ← 위키의 규칙·페르소나
3. **me.md, goals.md** ← 운영자 정체성
4. **log.md** ← 4월 한 달 동안 어떻게 위키가 자라났는지 시간순 흐름
5. **raw/2026-04-10_몰입_Flow_발췌.md** ← 첫 ingest
6. **raw/2026-04-14_아주_작은_습관의_힘_발췌.md** ← 두 번째 ingest
7. **thoughts/2026-04-15_몰입과_습관의_충돌.md** ← **★ 첫 인사이트 발견 순간**
