# n8n 실행 가이드

> **한 줄 결론**: 3가지 동시 트랙 — (1) 본인 업무 자동화로 학습 → (2) 고객 데모 자료로 변환 → (3) 영업 무기로 패키징.
> Pipeline Builder의 1/100 가격으로 같은 가치 제공이 영업 차별화 포인트.

---

## 0. n8n 컨셉 (30초)

**드래그&드롭 노드 연결로 워크플로우를 만드는 오픈소스 자동화 플랫폼.** 트리거 노드(웹훅·스케줄·이벤트) → 액션 노드(API 호출·DB·AI·이메일·Slack)를 시각적으로 연결.

```
[매일 오전 9시 트리거]
        ↓
[위시캣 사이트 스크래핑]
        ↓
[새 프로젝트 필터 (어제 ID 이후)]
        ↓
[Claude API: 적합도 평가]
        ↓
[조건: 점수 7+ 인 것만]
        ↓
[Notion: "오늘 할 일" DB 추가]
        ↓
[Slack 알림: "신규 적합 프로젝트 3건"]
```

→ 위 흐름이 **15개 노드, 30분이면 구현**. 같은 걸 Python으로 만들면 200줄 + 인프라 셋업 1일.

---

## 1. 인프라 결정 (먼저 정할 것)

| 옵션 | 설치 위치 | 장단점 | 추천 |
|------|---------|--------|------|
| **A. revita 서버** | `100.73.114.75` | Tailscale로 어디서든 접속, 24h 가동, 비용 0 | ⭐⭐⭐ |
| B. 본인 PC Docker | 로컬 | 학습 편함, PC 꺼지면 워크플로우 정지 | ⭐ |
| C. n8n Cloud | n8n.io | 설치 0분, 월 $24~, Self-host 영업 메시지 약화 | ⭐⭐ |

**권장**: revita 서버에 Docker로 1회 설치 → Tailscale 통해 접근.

### 설치 명령 (revita에서 1회)

```bash
docker run -d --name n8n \
  --restart unless-stopped \
  -p 5678:5678 \
  -v ~/n8n-data:/home/node/.n8n \
  -e N8N_BASIC_AUTH_ACTIVE=true \
  -e N8N_BASIC_AUTH_USER=uttec \
  -e N8N_BASIC_AUTH_PASSWORD=*** \
  n8nio/n8n
```

→ 브라우저에서 `http://100.73.114.75:5678` 접속, 로그인.

## 2. Phase 1 — 본인 업무 자동화 3종 (1주, 학습 + 즉시 ROI)

### 워크플로우 1: 위시캣 자동 검색 (최우선)
**현재**: `/wishket-check` skill을 본인이 수동 호출
**n8n 후**: 매일 오전 9시 자동 실행 → Notion + Slack 알림

**노드 구성**:
```
1. Schedule Trigger (cron: 0 9 * * *)
2. HTTP Request (위시캣 API 또는 Puppeteer 스크래핑)
3. Function (마지막 ID 이후 필터)
4. AI Agent 노드 (Claude) — 각 프로젝트 적합도 1~10점 평가
5. IF (점수 ≥ 7)
6. Notion (DB에 행 추가)
7. Slack (요약 알림)
8. Set State (마지막 ID 저장)
```

**예상 가치**: 매일 30분 절약 + 누락 방지. **첫 주 학습 대상 1순위.**

### 워크플로우 2: 작업보고서 ↔ Notion 양방향 sync
**현재**: 스크립트로 단방향 (Notion→작업보고서)
**n8n 후**: 양방향, 충돌 감지 + 알림

```
1. File Watcher (작업보고서/*.md 변경 감지)
2. Markdown Parser (할일 테이블 추출)
3. Notion API (해당 날짜 페이지 업데이트)
+ 역방향: Notion Webhook → 파일 수정
```

### 워크플로우 3: revita Slack 통합 알림
**현재**: 알림 분산
**n8n 후**: 한 채널에 통합

```
- GitHub PR/이슈 → #dev
- AWS 서버 부하 70%+ → #ops
- 위시캣 신규 적합 → #sales
- Notion 회의록 변경 → #docs
- Claude /work-end 완료 → #personal
```

## 3. Phase 2 — 고객 데모 워크플로우 (2주, 영업 무기 제작)

### 데모 1: 태명과학 견적 자동화
이미 있는 `demo_live.html`을 n8n 백엔드로 진화:

```
[고객 폼 입력 (Webhook 트리거)]
       ↓
[Obsidian Wiki에서 부속품 호환 매트릭스 조회]
       ↓
[Claude: 추천 + 가격 산정]
       ↓
[PDF 견적서 생성 (DocuPilot/PDFMonkey 노드)]
       ↓
[Email 자동 발송]
       ↓
[Notion: 견적 이력 DB 기록]
       ↓
[Slack: 영업팀 알림]
```

**시각 캡처 → 영업 미팅 자료**. 고객에게 "이게 우리가 구축할 시스템입니다" 라고 보여줌.

### 데모 2: 한국기계 BOM 자동 생성
설계도(이미지/PDF) 입력 → Claude Vision으로 부품 추출 → BOM 표 생성 → 외주 견적 자동 요청 메일.

### 데모 3: 약국 처방 검토 (이미 wiki 있음)
처방전 입력 → DUR 검사 → 보험 코드 매칭 → 검토 결과 출력.

→ **3개 데모 화면 캡처 = 3-Stage 패키지 영업 자료의 시각 무기.**

## 4. Phase 3 — 영업 무기 패키징 (3주차)

### 4-1. 5분 데모 영상
오늘 만든 AI 도구 소개 영상의 후속편으로:
- Remotion + n8n 화면 녹화 합성
- 시나리오: "고객이 견적 문의 → n8n이 자동 처리 → 5분 안에 PDF 발송"
- 마지막 슬라이드: "이런 워크플로우를 귀사에 구축합니다"

### 4-2. 견적서 1페이지
`smartFactory/업무효율화/참고/`에 추가할 새 문서:
- "n8n 기반 자동화 패키지 — Stage 2 상세"
- 가격 (Stage 2 합 2,500만 = 위키 1,500만 + n8n 1,000만)
- 산출물 (워크플로우 N개, Slack 통합, Webhook 엔드포인트)
- 인계 자료 (운영 매뉴얼 + 동영상)

### 4-3. 첫 시범 견적 발송
태명과학 또는 한국기계에 Stage 1+2 통합 견적 (~2,800만) 발송.
**거절돼도 시장 반응 검증.**

## 5. 학습 자료 (시간 순)

### 1일차 (2시간)
- n8n 공식 튜토리얼 첫 5개 (https://docs.n8n.io/try-it-out/)
- 워크플로우 1개 직접 따라 만들기 (Email → Slack 같은 단순 흐름)

### 2~3일차 (4시간)
- AI Agent 노드 사용법 익히기 (Claude API 연결)
- HTTP Request + Function 노드로 외부 API 호출 패턴
- 실전: 위시캣 자동 검색 워크플로우 구축

### 4~5일차 (4시간)
- Webhook 트리거로 외부 호출 받기
- 에러 처리·재시도 패턴
- Sub-Workflow 분리 (재사용 가능 모듈)

### 영문 자료가 부담되면
- **유튜브 "n8n 한국어 튜토리얼"** 검색 (최근 콘텐츠 증가 중)
- 또는 **"n8n 학습 가이드"를 aiStudy/introductionAi/ 14번째 가이드로 추가**
  → 5 Track 중 Track B 자동화 영역에 자연스럽게 편입

## 8. 핵심 인사이트 (한 줄)

**n8n을 "도구"가 아니라 "영업 자산"으로 접근.** 본인 업무 자동화는 학습용이자 ROI 즉시 회수 수단이고, **진짜 가치는 고객사에 보여줄 시각적 워크플로우**. Pipeline Builder의 1/100 가격으로 같은 효과를 낸다는 메시지를 영업 미팅에서 화면으로 보여줄 수 있느냐가 차별화 포인트.
