# 보험 관련 자주 묻는 질문 (FAQ)

## 개요

환자 및 약국 직원이 자주 묻는 보험 관련 질문과 답변을 정리한다. 건강보험 청구, 본인부담금, 처방전 관련 실무 질문을 다룬다.

> 관련 문서: [[_보험_총괄]], [[DUR_점검가이드]], [[청구_오류_방지]]

---

## 1. 처방전 관련

### Q1. 처방전 유효기간은 며칠인가요?

**A**: 처방전 발행일을 포함하여 **3일**입니다.

- 예: 월요일 발행 → 수요일까지 유효
- **공휴일/일요일 연장**: 유효기간 마지막 날이 공휴일이면 그 다음 영업일까지 유효
- 예: 금요일 발행, 일요일이 3일째 → 월요일까지 유효
- 유효기간 경과 처방전은 **조제 불가** → 재발행 필요

### Q2. 처방전을 잃어버렸어요. 재발행 받을 수 있나요?

**A**: 네, 처방 의료기관에서 **재발행** 받을 수 있습니다.

- 의료기관 방문 또는 전화 문의
- 처방전 재발행 시 "재발행" 표시
- 이미 조제한 처방전의 재발행은 **중복 조제 방지**를 위해 제한될 수 있음
- 약국에서 이미 조제한 경우 조제 이력 확인 가능 (DUR 시스템)

### Q3. 처방전 없이 약을 살 수 있나요?

**A**: **OTC(일반의약품)**는 처방전 없이 구매 가능합니다. **ETC(전문의약품)**는 처방전이 필수입니다.

| 구분 | 예시 | 처방전 |
|------|------|--------|
| 일반의약품(OTC) | 타이레놀, 이부프로펜, 가비스콘, 로라타딘 | 불필요 |
| 전문의약품(ETC) | 항생제, 혈압약, 당뇨약, 수면제 | 필수 |
| 안전상비의약품 | 해열제, 소화제 일부 (편의점 판매) | 불필요 |

### Q4. 다른 약국에서 조제한 약의 남은 것을 이쪽에서 다시 받을 수 있나요?

**A**: 처방전이 있으면 **어느 약국에서든 조제 가능**합니다. 단, 이미 조제 완료된 처방전으로 중복 조제는 불가합니다.

- 분할 조제(처방 일수 중 일부만 조제)된 경우: 나머지 일수를 다른 약국에서 조제 가능
- 처방전 사본 지참 필요

### Q5. 병원에서 원외처방이 아닌 원내조제를 했는데 약값이 다른 이유는?

**A**: 원내조제와 원외처방의 비용 구조가 다릅니다.

- **원외처방(약국)**: 조제료 + 약값 + 복약지도료 별도 발생
- **원내조제(병원)**: 진료비에 포함, 조제료 체계 다름
- 결과적으로 총 비용에 차이가 날 수 있으며, 이는 제도적 차이입니다

## 2. 본인부담금 관련

### Q6. 약값의 본인부담은 몇 퍼센트인가요?

**A**: 보험 유형에 따라 다릅니다.

| 보험 유형 | 본인부담률 | 비고 |
|----------|----------|------|
| 건강보험(일반) | **30%** | 가장 일반적 |
| 건강보험(65세 이상, 처방 15,000원 이하) | **1,200원 정액** | |
| 의료급여 1종 | **0%** (무료) | |
| 의료급여 2종 | **500원 정액** | |
| 산재보험 | **0%** | 공단 전액 부담 |
| 자동차보험 | **0%** | 보험사 부담 |

> 상세: [[_보험_총괄]]

### Q7. 같은 약인데 왜 약국마다 약값이 다른가요?

**A**: 건강보험 처방약의 본인부담금은 **동일한 약품이면 약국과 무관하게 동일**합니다.

가격이 다른 경우:
- **대체조제**: 오리지널 약 → 제네릭으로 변경 시 약가 차이 (본인부담금 차이 발생)
- **비급여 약품**: 약국별 판매 가격 다를 수 있음
- **약품 변경**: 동일 성분이라도 제조사에 따라 약가가 다를 수 있음

### Q8. 비급여 약이란 무엇인가요? 왜 비싼가요?

**A**: 비급여 약물은 건강보험이 적용되지 않아 **전액 환자 부담**인 약물입니다.

| 비급여 사유 | 예시 |
|-----------|------|
| 보험 미등재 약물 | 일부 신약, 희귀질환약 |
| 보험 적응증 외 사용 | 허가 외 목적 사용 |
| 미용/생활개선 목적 | 비만약, 탈모약(일부), 발기부전약 |
| 건강기능식품 | 비타민, 유산균, 오메가3 |

비급여가 비싼 이유: 보험 적용 시 공단이 70%를 부담하는데, 비급여는 환자가 100%를 내기 때문입니다.

### Q9. 본인부담 상한제란 무엇인가요?

**A**: 1년간 본인부담금 합계가 일정 금액을 초과하면 초과분을 공단이 돌려주는 제도입니다.

- 소득 분위에 따라 상한금액이 다름 (저소득 80만 원 ~ 고소득 780만 원)
- 매년 8월경 전년도 초과분에 대해 자동 환급
- 특히 **암, 만성질환** 등으로 약값이 많은 환자에게 유리
- 확인: 국민건강보험공단 홈페이지 또는 1577-1000

## 3. 급여/비급여 구분 관련

### Q10. 종합비타민/유산균도 보험이 되나요?

**A**: **일반적으로 보험 적용이 되지 않습니다** (비급여/건강기능식품).

예외:
- **철분제**: 빈혈 진단 시 처방 → 급여 가능
- **엽산**: 임신 관련 처방 → 급여 가능
- **비타민D**: 결핍 진단(혈액검사) 시 처방 → 급여 가능 (기준 충족 시)
- **유산균(전문의약품)**: 항생제 관련 설사 등 특정 적응증 시 급여 가능

### Q11. 약이 나한테 안 맞는 것 같은데 바꿔줄 수 있나요?

**A**: 약사가 임의로 **성분을 변경할 수 없습니다.** 동일 성분 내에서의 대체조제(제네릭 변경)는 가능합니다.

- **부작용 의심**: 의사에게 연락하여 처방 변경 요청
- **제네릭 변경**: 동일 성분, 다른 제조사 → 약사가 환자 동의 후 대체 가능
- **효과 불만족**: 의사 재진료 → 약물 변경/용량 조절

## 4. 약국 이용 관련

### Q12. 약국 영업시간 외에 약이 급하게 필요하면?

**A**:

- **야간/응급 약국**: 지역별 당번 약국 운영 (건강보험공단 앱, 1644-2000 확인)
- **응급실**: 응급 상황 시 병원 응급실에서 원내 조제 가능
- **만성질환 약물**: 평소 여유분 확보 권장 (최소 3일분)

### Q13. 대리 처방/대리 조제가 가능한가요?

**A**: **대리 수령은 가능**합니다. 단, 조건이 있습니다.

- 환자 본인이 올 수 없는 정당한 사유 필요 (입원, 거동 불편 등)
- 대리인의 **신분증** 지참
- 환자와의 **관계** 확인 (가족 등)
- 복약지도는 대리인에게 실시 (가능하면 전화로 환자에게도)

### Q14. 약국에서 혈압/혈당 측정해 줄 수 있나요?

**A**: 네, 대부분의 약국에서 **무료 또는 소정의 비용**으로 측정 서비스를 제공합니다.

- 혈압 측정: 무료 (대부분)
- 혈당 측정: 혈당 스트립 비용 발생 가능
- 약사의 측정 결과는 **참고용**이며, 정확한 진단은 의료기관에서 받으세요

## 5. 제도 관련

### Q15. DUR 경고가 떴는데 약을 못 받나요?

**A**: DUR(의약품 안전사용 서비스)은 **안전성 점검 시스템**입니다.

- **1등급(금기)**: 약사가 처방의에게 연락하여 확인 후 진행 → 약간의 대기 시간 발생 가능
- **2등급(주의)**: 주의사항 안내 후 조제 가능
- **동일성분 중복**: 확인 후 처방의 판단에 따라 진행

DUR 경고는 환자 안전을 위한 것이므로, 시간이 걸리더라도 양해 부탁드립니다.

> 상세: [[DUR_점검가이드]]

### Q16. 산정특례란 무엇인가요?

**A**: 중증질환자의 본인부담금을 낮추는 제도입니다.

| 대상 질환 | 본인부담률 |
|----------|----------|
| 암 | 5% |
| 심장질환 (일부) | 5% |
| 뇌혈관질환 (일부) | 5% |
| 희귀질환 | 10% |
| 중증화상 | 5% |
| 결핵 | 0% (면제) |

등록 방법: 해당 의료기관에서 산정특례 등록 신청

### Q17. 약값 영수증으로 연말정산/의료비 공제가 되나요?

**A**: **네, 건강보험 적용 약값은 의료비 공제 대상**입니다.

- 건강보험 본인부담금: **공제 가능**
- 비급여 약값: **공제 가능**
- 건강기능식품: **공제 불가** (약국에서 구매하더라도)
- 국세청 연말정산 간소화 서비스에서 자동 조회 가능

## 6. 약물 반품/교환 관련

### Q18. 조제받은 약을 반품/환불 받을 수 있나요?

**A**: 원칙적으로 **조제 완료된 약은 반품/환불이 불가**합니다.

- 이유: 의약품 안전성 보장 불가 (보관 상태 확인 불가)
- 예외: 약사의 **조제 오류**가 확인된 경우 → 즉시 교체 + 사고 보고
- 처방 변경으로 불필요해진 경우: 안타깝지만 반품 불가 (남은 약은 약국 수거함 반납)

### Q19. 약을 많이 받아서 남았어요. 다음에 그만큼 적게 받을 수 있나요?

**A**: 처방일수는 **의사가 결정**하므로 약국에서 임의 조절은 불가합니다.

- 의사에게 "약이 남아 있다"고 말씀하시면 처방일수를 조절해 줄 수 있습니다
- **분할 조제**: 장기 처방(90일 등)을 나누어 조제하는 것은 가능 → 약사에게 요청
- 약이 남는 이유가 **복용 누락**이라면 → 순응도 개선 교육

## 7. 약사 직원 실무 FAQ

### Q20. 의료급여 환자의 본인부담이 맞는지 어떻게 확인하나요?

**A**:
1. 건보 EDI에서 **자격 확인**: 1종/2종 구분
2. 1종: 본인부담 0원 / 2종: 500원 정액
3. 의료급여증(카드) 확인
4. 자격 변동이 잦으므로 **매회 확인** 권장

### Q21. 처방전에 질병코드가 없으면 어떻게 하나요?

**A**: 질병분류기호는 처방전 필수 기재사항입니다.

- 누락 시: 처방 의료기관에 연락하여 보완 요청
- 청구 시: 질병코드 없으면 **반송/삭감** 가능성 높음
- 임시 조치: 환자 대기 중이면 전화로 확인하여 수기 기재 가능

> 오류 방지: [[청구_오류_방지]]
