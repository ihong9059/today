# 고혈압 복약 가이드

## 개요

고혈압은 국내 성인 약 30%가 이환된 대표적인 만성질환이다. 약국에서의 복약지도는 약물 순응도 향상, 부작용 관리, 생활습관 교정에 핵심적 역할을 한다.

> 관련 문서: [[_상호작용_매트릭스]], [[연령별_금기]], [[2025-A약국-고혈압환자-복약지도]]

## 혈압 분류 기준 (대한고혈압학회 2022)

| 분류 | 수축기 (mmHg) | 이완기 (mmHg) |
|------|-------------|-------------|
| 정상 | < 120 | < 80 |
| 주의 | 120-129 | < 80 |
| 고혈압 전단계 | 130-139 | 80-89 |
| 1기 고혈압 | 140-159 | 90-99 |
| 2기 고혈압 | >= 160 | >= 100 |

## 항고혈압제 약물 분류 및 특징

### 1. ACE 억제제 (안지오텐신전환효소 억제제)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 에날라프릴, 라미프릴, 페린도프릴, 캡토프릴 |
| 작용 기전 | 안지오텐신 II 생성 억제 → 혈관 확장, 알도스테론 감소 |
| 적응증 우선 | 심부전, 당뇨병성 신병증, 심근경색 후, 좌심실 비대 |
| 주요 부작용 | **마른기침**(10-20%), 고칼륨혈증, 혈관부종(드물지만 위험) |
| 금기 | 임신(전 기간), 양측 신동맥 협착, 혈관부종 기왕력 |
| 복약지도 핵심 | "마른기침이 나타나면 약사/의사에게 알려주세요. 임신 계획 시 반드시 상의" |

### 2. ARB (안지오텐신 II 수용체 차단제)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 로사르탄, 발사르탄, 칸데사르탄, 텔미사르탄, 올메사르탄, 이르베사르탄 |
| 작용 기전 | AT1 수용체 차단 → ACE억제제와 유사 효과 |
| 적응증 우선 | ACE억제제 기침 부작용 시 대체, 당뇨병성 신병증, 심부전 |
| 주요 부작용 | 고칼륨혈증, 어지러움 (기침은 거의 없음) |
| 금기 | 임신(전 기간), 양측 신동맥 협착 |
| 복약지도 핵심 | "ACE억제제보다 기침 적지만 임신 시 금기는 동일" |

### 3. 칼슘채널차단제 (CCB)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 암로디핀, 니페디핀(서방정), 펠로디핀, 딜티아젬, 베라파밀 |
| 작용 기전 | 혈관 평활근 칼슘 유입 차단 → 혈관 확장 |
| 적응증 우선 | 고령자, 단독 수축기 고혈압, 협심증 동반 |
| 주요 부작용 | **발목 부종**(DHP계), 안면 홍조, 두통, 변비(베라파밀) |
| 금기 | 심부전(베라파밀/딜티아젬), 서맥 |
| 복약지도 핵심 | "발목이 붓는 것은 부작용이지 심장 문제가 아닙니다. 자몽 회피" |

> **자몽 상호작용**: 펠로디핀, 니페디핀 특히 주의. [[음식_상호작용]] 참고

### 4. 이뇨제

| 하위분류 | 대표 약물 | 특징 | 부작용 |
|---------|----------|------|--------|
| 티아지드 | 히드로클로로티아지드, 인다파마이드, 클로르탈리돈 | 1차 선택, 고령자 유효 | 저칼륨혈증, 고요산혈증, 고혈당 |
| 루프 | 푸로세마이드, 토르세마이드 | 신기능 저하 시 | 전해질 이상, 탈수 |
| 칼륨보존 | 스피로노락톤, 에플레레논 | 심부전 병용 | **고칼륨혈증** (ACE/ARB 병용 주의) |

**복약지도 핵심:**
- 아침 복용 권고 (야간 이뇨 → 수면 방해)
- 저칼륨혈증 증상: 근육 경련, 피로, 부정맥 → 바나나, 오렌지 섭취 권고
- 탈수 주의: 고령자, 여름철 특히 주의

### 5. 베타차단제

| 항목 | 내용 |
|------|------|
| 대표 약물 | 아테놀롤, 비소프롤롤, 카르베딜롤, 네비볼롤, 프로프라놀롤 |
| 적응증 우선 | 심부전, 심근경색 후, 빈맥, 갑상선기능항진증, 편두통 |
| 주요 부작용 | 서맥, 피로, 사지 냉감, 기관지수축, 저혈당 마스킹 |
| 금기 | 천식(비선택적), 서맥, 2-3도 방실차단, 말초혈관질환 |
| 복약지도 핵심 | "갑자기 중단하지 마세요(반동성 고혈압/협심증). 당뇨 환자는 저혈당 증상 주의" |

> 당뇨 환자 주의: [[_상호작용_매트릭스]] 인슐린/설폰요소제 + 베타차단제 참고

## 환자 상황별 약물 선택 가이드

| 동반질환/상태 | 우선 약물 | 회피 약물 |
|-------------|----------|----------|
| 당뇨병 | ACE억제제/ARB | 티아지드(고용량), 비선택적 베타차단제 |
| 심부전 | ACE억제제/ARB + 베타차단제 + 이뇨제 | CCB(베라파밀/딜티아젬) |
| 만성신장병 | ACE억제제/ARB | NSAIDs, 칼륨보존이뇨제(주의) |
| 뇌졸중 후 | ACE억제제 + 이뇨제 | - |
| 관상동맥질환 | 베타차단제, ACE억제제 | - |
| 천식/COPD | CCB, ACE억제제/ARB | 비선택적 베타차단제 |
| 통풍 | 로사르탄(요산 배설 촉진), CCB | 티아지드(요산 상승) |
| 임신 | 메틸도파, 라베탈롤, 니페디핀 | ACE억제제/ARB(금기), 이뇨제 |
| 고령자 | CCB, 티아지드 | 알파차단제(기립성 저혈압) |
| 전립선비대 동반 | 알파차단제(독사조신) | - |

## OTC 약물과의 상호작용 주의

고혈압 환자가 약국에서 OTC 구매 시 주의할 약물:

| OTC 약물 | 영향 | 대안 |
|---------|------|------|
| NSAIDs (이부프로펜, 나프록센) | 혈압 상승(5-8mmHg), 이뇨제/ACE억제제 효과 감소, 신기능 악화 | 아세트아미노펜 |
| 비충혈제거제 (슈도에페드린) | 혈압 상승, 빈맥 | 생리식염수 비강세척 |
| 종합감기약 | 비충혈제거제 + NSAIDs 포함 가능 | 성분 확인 후 개별 선택 |
| 감초 추출물/한약 | 알도스테론 유사 작용 → 혈압 상승, 저칼륨 | 사용 최소화 |
| 인삼 | 혈압 상승 가능 (일부 보고) | 주의하여 사용 |

> 상세: [[_상호작용_매트릭스]], [[감기_처방가이드]]

## 복약지도 핵심 포인트

### 복약 순응도 향상

1. **매일 같은 시간 복용**: 아침 식후 권고 (이뇨제는 취침 전 회피)
2. **증상 없어도 복용 지속**: "혈압약은 평생 관리약입니다"
3. **자의 중단 금지**: 반동성 고혈압 위험 (특히 베타차단제)
4. **가정 혈압 측정 교육**:
   - 아침 기상 후 1시간 이내, 배뇨 후, 약 복용 전
   - 앉은 자세로 5분 안정 후 측정
   - 2회 측정하여 평균값 기록
   - 팔 높이: 심장 수준

### 생활습관 교정 (DASH)

| 생활습관 | 목표 | 예상 혈압 강하 |
|---------|------|-------------|
| 체중 감량 | BMI 25 미만 유지 | 5-20mmHg/10kg |
| 저염식 | 소금 6g/일 미만 | 2-8mmHg |
| DASH 식단 | 과일, 채소, 저지방 유제품 | 8-14mmHg |
| 운동 | 중등도 유산소 30분/일, 주 5일 이상 | 4-9mmHg |
| 절주 | 남성 2잔, 여성 1잔 이하/일 | 2-4mmHg |
| 금연 | 완전 금연 | 심혈관 위험 전반 감소 |

## 의뢰 기준

다음 상황 시 즉시 의료기관 의뢰:
- 혈압 180/120mmHg 이상 + 두통/시야장애/흉통 → **고혈압 응급**
- 기립성 저혈압 반복 (어지러움, 실신)
- 약물 부작용 의심 (혈관부종, 심한 부종, 서맥)
- 혈압 조절 불량 (3제 이상 사용에도 목표 미달)
- 임신 확인된 ACE억제제/ARB 복용 환자
