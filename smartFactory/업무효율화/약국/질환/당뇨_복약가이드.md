# 당뇨병 복약 가이드

## 개요

당뇨병은 국내 성인 약 15%가 이환된 주요 만성질환이다. 약국에서는 복약 순응도, 저혈당 관리, sick day rules, OTC 약물 상호작용 교육이 핵심 역할이다.

> 관련 문서: [[_상호작용_매트릭스]], [[연령별_금기]], [[고혈압_복약가이드]], [[2025-C약국-당뇨환자-약물조정]]

## 당뇨병 분류 및 혈당 목표

### 분류

| 유형 | 특징 | 치료 |
|------|------|------|
| 제1형 | 자가면역 파괴, 절대적 인슐린 결핍, 주로 소아~청년 | 인슐린 필수 |
| 제2형 | 인슐린 저항성 + 상대적 분비 부족, 주로 성인 | 생활습관 + 경구약 + 필요시 인슐린 |
| 임신성 | 임신 중 발생 | 식이 + 필요시 인슐린(메트포르민 일부 사용) |

### 혈당 조절 목표 (대한당뇨병학회 2023)

| 지표 | 일반 목표 | 고령자/합병증 | 임부 |
|------|----------|-------------|------|
| 공복혈당 | 80-130 mg/dL | 개별화 | 70-95 mg/dL |
| 식후 2시간 | < 180 mg/dL | < 200 mg/dL | < 120 mg/dL |
| HbA1c | < 6.5-7.0% | < 8.0% (개별화) | < 6.0% |

## 제2형 당뇨 경구 약물 가이드

### 약물 분류별 특징

#### 1. 메트포르민 (Biguanide) — 1차 선택

| 항목 | 내용 |
|------|------|
| 대표 약물 | 메트포르민 500/850/1000mg, 서방정(XR) |
| 작용 기전 | 간 포도당 생성 억제, 인슐린 감수성 증가 |
| HbA1c 감소 | 1.0-1.5% |
| 장점 | 저혈당 없음, 체중 증가 없음(감소 가능), 심혈관 보호, 저렴 |
| 부작용 | 위장장애(오심, 설사, 복통) — 저용량 시작하여 증량으로 최소화 |
| **심각한 부작용** | **유산산증(Lactic acidosis)** — 매우 드물지만 치명적 |
| 금기 | eGFR < 30, 중증 간부전, 심한 탈수, 급성 심부전, 알코올 중독 |
| 조영제 주의 | 조영제 사용 전 48시간 중단 → 사용 후 48시간 뒤 신기능 확인 후 재개 |
| 복약지도 | "식사와 함께 복용하면 위장장애가 줄어듭니다. 서방정은 쪼개지 마세요" |

#### 2. 설폰요소제 (Sulfonylureas)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 글리메피리드, 글리클라자이드(MR), 글리벤클라마이드 |
| 작용 기전 | 췌장 베타세포 인슐린 분비 촉진 |
| HbA1c 감소 | 1.0-1.5% |
| 장점 | 효과 확실, 저렴, 오랜 사용 경험 |
| 주요 부작용 | **저혈당**(주요 위험), 체중 증가 |
| 고령자 주의 | 글리벤클라마이드 회피(장기 작용 → 저혈당 지속). 글리클라자이드 또는 저용량 글리메피리드 선호 |
| 복약지도 | "식사를 거르면 저혈당 위험! 반드시 식사 직전 복용. 저혈당 증상 교육 필수" |

#### 3. DPP-4 억제제

| 항목 | 내용 |
|------|------|
| 대표 약물 | 시타글립틴, 빌다글립틴, 리나글립틴, 삭사글립틴, 알로글립틴 |
| 작용 기전 | 인크레틴(GLP-1) 분해 억제 → 혈당 의존적 인슐린 분비 촉진 |
| HbA1c 감소 | 0.5-0.8% |
| 장점 | 저혈당 위험 낮음, 체중 중립, 경구 1일 1회 |
| 부작용 | 비인두염, 두통, 드물게 췌장염 |
| 특이사항 | 리나글립틴: 신기능에 따른 용량 조절 불필요 |
| 복약지도 | "식사와 무관하게 매일 같은 시간 복용" |

#### 4. SGLT2 억제제

| 항목 | 내용 |
|------|------|
| 대표 약물 | 다파글리플로진, 엠파글리플로진, 카나글리플로진, 에르투글리플로진 |
| 작용 기전 | 신장 포도당 재흡수 억제 → 소변으로 포도당 배출 |
| HbA1c 감소 | 0.5-1.0% |
| 장점 | 체중 감소, 혈압 감소, **심혈관 보호**, **신장 보호** |
| 부작용 | **비뇨생식기 감염**(칸디다증), 탈수, 드물게 당뇨병성 케톤산증(DKA) |
| 금기 | eGFR < 20 (혈당 강하 효과), 1형 당뇨(DKA 위험) |
| 복약지도 | "소변량이 늘어납니다. 수분을 충분히 드세요. 생식기 위생 유지. 아침 복용 권고" |

#### 5. GLP-1 수용체 작용제 (주사)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 리라글루타이드(1일 1회), 세마글루타이드(주 1회 주사/경구), 둘라글루타이드(주 1회) |
| 작용 기전 | GLP-1 수용체 활성화 → 혈당 의존적 인슐린 분비 + 글루카곤 억제 + 위배출 지연 + 식욕 억제 |
| HbA1c 감소 | 1.0-1.8% |
| 장점 | 체중 감소(현저), 심혈관 보호 |
| 부작용 | 오심, 구토, 설사(초기에 흔함, 점차 감소), 드물게 췌장염 |
| 복약지도 | "처음 2-4주는 속이 불편할 수 있습니다. 소량씩 천천히 드세요. 주사 부위 매번 변경" |

#### 6. 티아졸리딘디온 (TZDs)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 피오글리타존 |
| 작용 기전 | PPAR-gamma 활성화 → 인슐린 감수성 증가 |
| HbA1c 감소 | 0.5-1.4% |
| 부작용 | 체중 증가, 부종, 심부전 악화, 골절 위험 증가(여성) |
| 금기 | 심부전(NYHA III-IV), 방광암 기왕력 |

## 인슐린 치료

### 인슐린 종류

| 분류 | 대표 약물 | 작용 시작 | 최대 효과 | 지속 시간 |
|------|----------|----------|----------|----------|
| 초속효성 | 리스프로, 아스파트, 글루리신 | 10-15분 | 1-2시간 | 3-5시간 |
| 속효성 | 휴먼 레귤러 | 30분 | 2-3시간 | 6-8시간 |
| 중간형 | NPH | 1-2시간 | 4-12시간 | 12-18시간 |
| 지속형 | 글라진(란투스), 데테미르 | 1-2시간 | 없음(평탄) | 20-24시간 |
| 초지속형 | 글라진 U300, 데글루덱 | 1-2시간 | 없음(평탄) | 24-42시간 |

### 인슐린 복약지도 핵심

1. **보관**: 미개봉 → 냉장(2-8도), 개봉 후 → 실온(28일/42일 이내 사용)
2. **주사 부위**: 복부 > 허벅지 > 팔 상완 > 둔부 (흡수 속도 순)
3. **부위 로테이션**: 같은 부위 반복 → 지방비대(lipohypertrophy) → 흡수 불규칙
4. **혼합 인슐린**: NPH 함유 시 부드럽게 전동 (세게 흔들지 않음)
5. **바늘 교체**: 매번 새 바늘 사용 권고

## 저혈당 관리

### 저혈당 기준
- 혈당 70 mg/dL 미만

### 저혈당 증상

| 교감신경 증상 (경고 증상) | 중추신경 증상 (위험 증상) |
|------------------------|----------------------|
| 떨림, 심계항진, 발한 | 혼란, 집중력 저하 |
| 불안, 공복감 | 시야 장애, 말 어눌함 |
| 창백, 손끝 저림 | 의식 저하, 경련, 혼수 |

> 주의: 베타차단제 복용 시 교감신경 증상 마스킹 → [[_상호작용_매트릭스]] 참고

### 저혈당 대처법 (15-15 Rule)

```
혈당 < 70 mg/dL 확인
    ↓
1단계: 속효성 당질 15g 섭취
  - 포도당 정제 3-4개 (권장)
  - 주스 또는 콜라 150mL (일반, 다이어트 X)
  - 사탕 3-4개
  - 설탕 1큰술 (물에 녹여)
    ↓
2단계: 15분 후 혈당 재측정
    ↓
혈당 70 이상? → 다음 식사까지 1시간 이상이면 간식 섭취
혈당 70 미만? → 15g 당질 재섭취 → 15분 후 재측정
    ↓
3회 반복 후에도 회복 안 되면 → 응급 의료 요청
    ↓
의식 없는 경우: 입으로 아무것도 주지 않음!
  → 글루카곤 주사(가능 시) + 119 신고
```

### 저혈당 예방 교육

- 식사를 거르지 않기 (설폰요소제, 인슐린 사용 시 특히 중요)
- 운동 전 혈당 확인, 필요시 간식 섭취
- 음주 후 저혈당 주의 (간의 포도당 생성 억제)
- 항상 **포도당 정제 또는 사탕 휴대**
- 저혈당 ID 팔찌/카드 휴대 권고

## Sick Day Rules (아플 때 관리)

감염, 발열, 구토, 설사 등 급성 질환 시:

### 일반 원칙
1. **인슐린/경구약 임의 중단 금지** (스트레스 호르몬으로 혈당 상승)
2. 혈당을 **4시간마다** 측정
3. 수분 섭취 유지 (탈수 방지)
4. 소량씩 자주 식사 시도

### 약물별 Sick Day 조치

| 약물 | 조치 |
|------|------|
| 메트포르민 | 구토/설사/탈수 시 **일시 중단** (유산산증 위험) → 회복 후 재개 |
| SGLT2 억제제 | 아플 때 **일시 중단** (DKA 위험, euglycemic DKA 가능) |
| 설폰요소제 | 식사 못 하면 **감량 또는 중단** (저혈당 위험) |
| 인슐린 (기초) | **절대 중단 금지**. 용량 조절 필요 시 의사 연락 |
| DPP-4 억제제 | 일반적으로 유지 가능 |

### 의료기관 연락 기준
- 혈당 300 mg/dL 이상이 지속
- 구토/설사 6시간 이상 지속, 수분 섭취 불가
- 의식 변화, 호흡 곤란
- 소변 케톤 양성 (제1형 당뇨)
- 발열 38.5도 이상이 24시간 이상 지속

## OTC 약물 상담 시 주의

| 상황 | 주의사항 |
|------|---------|
| 감기약 구매 | 시럽 → 당분 함량 확인, 슈도에페드린 → 혈당 상승 가능 |
| 진통제 | NSAIDs → 신기능 확인, 아세트아미노펜 권고 |
| 스테로이드 (외용제 제외) | 혈당 상승 현저 → 경구/주사 스테로이드 사용 시 혈당 모니터링 강화 |
| 건강기능식품 | 크롬, 바나바잎, 여주 → 혈당 강하 효과 주장 제품과 약물 병용 주의 |

## 발 관리 교육

당뇨발 예방을 위한 기본 교육:
1. 매일 발 검사 (상처, 물집, 변색 확인)
2. 미지근한 물로 세척, 완전 건조 (발가락 사이)
3. 보습 크림 도포 (발가락 사이 제외)
4. 맨발 보행 금지
5. 꽉 끼는 신발, 발가락 사이 끈 신발 회피
6. 발톱 일자로 자르기 (둥글게 자르면 내성발톱)
7. 이상 발견 시 즉시 의료기관 방문
