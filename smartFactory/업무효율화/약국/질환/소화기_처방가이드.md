# 소화기 질환 처방 가이드

## 개요

소화기 질환은 약국 상담의 가장 큰 비중을 차지하는 질환군 중 하나이다. GERD, 위염, IBS, 변비, 설사 등 각 질환별 약물 선택 기준과 OTC/ETC 구분, 복약지도 핵심을 정리한다.

> 관련 문서: [[_상호작용_매트릭스]], [[연령별_금기]], [[복약지도-FAQ]]

---

## 1. 위식도역류질환 (GERD)

### 증상
- **전형적**: 속쓰림(heartburn), 산 역류
- **비전형적**: 만성 기침, 쉰 목소리, 인후 이물감, 흉통

### 약물 치료 단계

| 단계 | 약물군 | 대표 약물 | 특징 |
|------|--------|----------|------|
| 1단계 (경증) | 제산제 | 알루미늄/마그네슘 수산화물(겔포스, 알마겔) | 즉각적 증상 완화, 지속 시간 짧음 |
| 1단계 | 알긴산염 | 가비스콘 | 뗏목 효과(raft), 식후 역류 방지 |
| 2단계 (중등도) | H2RA | 파모티딘, 라니티딘(회수됨→대체) | 야간 산분비 억제, 내성 발생 가능 |
| 3단계 (중증) | PPI | 오메프라졸, 에소메프라졸, 란소프라졸, 판토프라졸, 라베프라졸 | 가장 강력한 산분비 억제 |

### PPI 복약지도

| 항목 | 내용 |
|------|------|
| 복용 시점 | **아침 식전 30분** (산분비 시작 전 최대 효과) |
| 기간 | 초기 4-8주 → 이후 재평가 |
| 장기 사용 부작용 | 마그네슘 저하, 골절 위험, 비타민B12 결핍, 위축성 위염, 클로스트리디움 감염 |
| 중단 | 갑자기 중단 시 반동성 산분비 → 2-4주에 걸쳐 서서히 감량 |
| 상호작용 | 클로피도그렐(오메프라졸 회피→판토프라졸), 갑상선약/철분/칼슘 흡수 감소 |

> PPI + 클로피도그렐: [[_상호작용_매트릭스]] 참고

### 생활습관 교정

- 식후 3시간 이내 눕지 않기
- 취침 시 상체 15-20cm 높이기
- 유발 음식 회피: 카페인, 초콜릿, 기름진 음식, 알코올, 탄산음료, 토마토, 감귤류
- 금연 (하부 식도 괄약근 이완)
- 체중 감량 (복압 감소)
- 조이는 옷 피하기

## 2. 위염 / 소화성 궤양

### H. pylori 연관 위염

| 단계 | 내용 |
|------|------|
| 진단 | 요소호기검사(UBT), 대변항원검사, 내시경+조직검사 |
| 1차 제균요법 | PPI + 아목시실린 1g + 클래리스로마이신 500mg (bid, 14일) |
| 대체요법 | PPI + 비스무트 + 테트라사이클린 + 메트로니다졸 (4제요법) |
| 제균 확인 | 치료 종료 4주 후 UBT 재검 |

### 제균요법 복약지도

- **14일 완전 복용** 강조 (중도 중단 → 내성 발생)
- 메트로니다졸: **음주 절대 금지** (디설피람 유사 반응)
- 클래리스로마이신: 금속성 미각 변화 가능 → 일시적
- 아목시실린: 알레르기 기왕력 확인 필수

### 기능성 소화불량

| 약물군 | 대표 약물 | 적응 |
|--------|----------|------|
| 위장운동촉진제 | 모사프리드, 이토프리드 | 식후 팽만감, 조기 포만감 |
| PPI/H2RA | 오메프라졸, 파모티딘 | 속쓰림 우세 |
| 소화효소제 | 판크레아틴, 비오디아스타제 | 소화 보조 (근거 제한적) |
| 점막보호제 | 수크랄페이트, 레바미피드 | 점막 보호, 궤양 치유 |

## 3. 과민성 장증후군 (IBS)

### IBS 아형별 약물 선택

| 아형 | 주요 증상 | 약물 | OTC/ETC |
|------|---------|------|---------|
| IBS-D (설사형) | 잦은 묽은 변, 급박감 | 로페라마이드 (증상 시), 라모세트론 | OTC/ETC |
| IBS-C (변비형) | 배변 곤란, 잔변감 | 루비프로스톤, 리나클로타이드, 차전자피 | ETC/OTC |
| IBS-M (혼합형) | 설사/변비 교대 | 트리메부틴, 핀아베리움 | ETC |
| 복통 우세 | 복통, 경련 | 오틸로늄, 핀아베리움, 디사이클로민 | ETC |

### IBS 복약지도

- **식이 관리**: 저 FODMAP 식이 시도 (고과당, 유당, 올리고당 제한)
- **스트레스 관리**: IBS는 뇌-장 축(brain-gut axis) 관련 → 스트레스가 악화 요인
- **유산균**: 일부 균주(Bifidobacterium infantis 35624 등) 효과 근거 있음
- **식이섬유**: IBS-C에 수용성 식이섬유(차전자피) 유효. 불용성(밀기울)은 증상 악화 가능
- 의뢰 기준: 체중 감소, 혈변, 50세 이후 새로 발생, 야간 증상 → 대장내시경 권고

## 4. 변비

### 변비약 단계별 선택

| 단계 | 약물군 | 대표 약물 | 작용 시작 | 특징 |
|------|--------|----------|----------|------|
| 1단계 | 팽창성 하제 | 차전자피(무타실), 메틸셀룰로스 | 12-72시간 | 가장 자연스러운 기전. 수분 충분히 섭취 |
| 2단계 | 삼투성 하제 | 마그네슘 수산화물(마그밀), 락툴로스, PEG(폴리에틸렌글리콜) | 1-3일 | 장기 사용 비교적 안전 |
| 3단계 | 자극성 하제 | 비사코딜(둘코락스), 센나(세네시드), 피코설페이트 | 6-12시간 | 단기 사용 권고 (장기 → 대장 흑색증, 습관성) |
| 보조 | 대변연화제 | 도큐세이트 | 1-3일 | 단독 효과 미약, 보조적 |
| ETC | 분비촉진제 | 루비프로스톤, 리나클로타이드, 프루칼로프라이드 | 수일 | 만성 변비 ETC 전문약 |

### 변비 복약지도

- **생활습관 우선**: 수분 1.5-2L/일, 식이섬유 20-30g/일, 규칙적 운동
- **배변 습관**: 아침 식후 화장실 가기 (위대장 반사 활용), 배변 자세 교정 (발받침 사용)
- **자극성 하제 장기 사용 주의**: 대장 운동 의존성 → 점진적 감량
- **마그네슘 하제**: 신기능 저하자 고마그네슘혈증 주의

### 특수 상황별 변비 관리

| 상황 | 권고 |
|------|------|
| 임부 | 차전자피, 락툴로스, PEG 안전. 자극성 하제 주의 |
| 소아 | PEG, 락툴로스. 관장은 최후 수단 |
| 고령자 | 삼투성 하제 우선. 마그네슘 → 신기능 확인 |
| 오피오이드 유발 | 나록세골(ETC), PEG, 자극성 하제. 예방적 하제 동시 처방 권고 |

## 5. 설사

### 급성 설사 (< 2주)

| 원인 | 관리 |
|------|------|
| 바이러스성 (노로, 로타) | 경구수액보충(ORS) 우선, 지사제 보조 |
| 세균성 (식중독) | 수분 보충, 항생제는 의사 판단 (대부분 불필요) |
| 약물 유발 | 원인 약물 확인 (항생제, 메트포르민, NSAIDs 등) |

### 설사 약물

| 약물 | 기전 | 주의사항 |
|------|------|---------|
| 로페라마이드 | 장운동 억제 | 혈변/고열 동반 설사 시 금기, 2세 미만 금기 |
| 경구수액보충(ORS) | 수분/전해질 보충 | 가장 중요한 치료. 스포츠 음료는 삼투압 부적절 |
| 스멕타이트(스멕타) | 장점막 보호, 독소 흡착 | 비교적 안전, 소아 사용 가능 |
| 유산균 | 장내 균총 회복 | 항생제 관련 설사 예방 근거 있음 |
| 라세카도트릴(히드라섹) | 장관 분비 억제 | ORS와 병용, 소아 사용 가능(일부 국가) |

### 의뢰 기준
- 혈변, 점액변
- 고열(38.5도 이상) 동반
- 탈수 증상 (심한 구갈, 소변 감소, 어지러움)
- 2주 이상 지속 (만성 설사 → 원인 검사 필요)
- 영유아, 고령자 → 탈수 위험 높아 조기 의뢰

## 제산제와 다른 약물의 상호작용 정리

| 약물 | 제산제와의 상호작용 | 간격 |
|------|-------------------|------|
| 퀴놀론 항생제 | 흡수 감소 (킬레이트) | 2시간 전/6시간 후 |
| 테트라사이클린 | 흡수 감소 (킬레이트) | 2-3시간 간격 |
| 레보티록신 | 흡수 감소 | 4시간 간격 |
| 철분제 | 흡수 감소 | 2시간 간격 |
| 케토코나졸 | 위산 필요 → 산 억제 시 흡수 감소 | PPI/H2RA 회피 |
| 이트라코나졸 (캡슐) | 위산 필요 | 산성 음료와 복용 또는 용액 사용 |

## OTC vs ETC 구분 요약

| 질환 | OTC로 관리 가능 | ETC 처방 필요 |
|------|----------------|-------------|
| 속쓰림 (GERD) | 제산제, 파모티딘(저용량), 가비스콘 | PPI, 고용량 H2RA |
| 위염 | 제산제, 점막보호제(일부) | PPI, 제균요법 |
| IBS | 유산균, 차전자피, 로페라마이드 | 라모세트론, 리나클로타이드 |
| 변비 | 차전자피, 마그밀, 비사코딜, PEG | 루비프로스톤, 프루칼로프라이드 |
| 설사 | ORS, 로페라마이드, 스멕타, 유산균 | 항생제, 라세카도트릴 |
