# 약국 Wiki 구성 설명

## 업무효율화 Wiki 4개 업종 비교

업무효율화 시스템은 4개 업종(태명과학, 한국기계, 약국, 한의원)을 대상으로 Wiki + 데모 웹을 구축하였습니다.
각 업종의 Wiki 구성 방식에는 차이가 있으며, 그 이유를 설명합니다.

---

## 태명과학 / 한국기계 (제조업)

### 특징: 실제 제품 데이터 기반
- 태명과학: FRITSCH 분쇄/분석 장비의 실제 모델별 스펙 데이터 보유
- 한국기계: 터보밀, 핀밀 등 자사 제품의 실제 사양 데이터 보유
- 제품 카탈로그, BOM, 조달 정보 등 고유 데이터가 Wiki의 핵심

### 구성
| 항목 | 태명과학 | 한국기계 |
|------|----------|----------|
| Wiki 파일 수 | 55개 | 41개 |
| 핵심 콘텐츠 | 장비별 스펙표, 부속품 호환 매트릭스, 재질 비교 | 제품별 사양, 공정 설계, 조달/BOM |
| 사례 | 실측 데이터 포함 (D50, rpm, 입도 결과 등) | 실제 납품 사례 기반 공정 설계 |
| DB 테이블 | 6종 (장비/호환성/재질/분쇄조건/입도기준/장비상세) | 9종 (제품/공정/사례/구매품/외주가공/제작일정/BOM/용도별추천 등) |
| 엑셀 | 태명과학_DB_통합.xlsx (6탭) | 한국기계_DB_통합.xlsx (9탭) |

### 예시: 장비 문서 (P-5 Classic)
```
주요 사양: 분쇄 스테이션 4개, 최대 400rpm, 달성 입도 1~100um
호환 부속품: 재질별 x 용량별 매트릭스
비교표: Classic vs Premium 모델 차이
```

### 예시: 사례 문서 (D대학 LFP 양극재)
```
고객 요구사항 → 장비 구성 → 분쇄 조건 (rpm, 시간, 프로그램)
→ 실측 결과 (D10: 1.1um, D50: 3.2um, D90: 8.5um) → 합격 판정
```

## 약국 / 한의원 (서비스업)

### 특징: 일반 도메인 지식 기반
- 특정 약국/한의원의 자체 데이터(재고, 처방 이력, 환자 DB 등)가 없음
- 의약학/한의학 교과서 수준의 범용 지식으로 Wiki를 구성
- 실제 업체가 확보되면 해당 업체의 고유 데이터로 보강 필요

### 구성
| 항목 | 약국 | 한의원 |
|------|------|--------|
| Wiki 파일 수 | 29개 | 24개 |
| 핵심 콘텐츠 | 약물 분류, 상호작용, 질환별 복약가이드 | 처방, 약재, 경혈, 체질, 변증 |
| 사례 | 가상 시나리오 기반 서술 | 가상 시나리오 기반 서술 |
| DB 테이블 | 미완료 | 미완료 |
| 엑셀 | 미완료 | 미완료 |

### 예시: 약물 문서 (고혈압약)
```
계열별 분류 (ARB, ACEi, CCB, 이뇨제, 베타차단제)
→ 대표 약물별 상품명, 용량, 용법, 특징
→ 상호작용 매트릭스, 병용요법, 복약지도 포인트
```

### 예시: 사례 문서 (A약국 고혈압 환자)
```
환자 정보 → 상황 전개 (처방 접수 → OTC 구매 요청 → 상호작용 확인)
→ 약사 대응 과정 → 복약지도 내용 → 결과
(실측 데이터가 아닌 시나리오 서술)
```

## 차이 요약

| 비교 항목 | 태명과학/한국기계 | 약국/한의원 |
|-----------|------------------|------------|
| 데이터 출처 | 실제 제품 카탈로그/사양서 | 일반 도메인 지식 (교과서) |
| Wiki 내용 | 제품별 스펙 + 수치 데이터 | 약물/처방 분류 + 이론 설명 |
| 사례 상세도 | 실측값 포함 (입도, rpm 등) | 가상 시나리오 서술 |
| DB/엑셀 | 완료 | 미완료 |
| 문서 길이 | 짧고 구조적 (60~80줄) | 길고 설명적 (150~250줄) |
| 고유성 | 해당 업체만의 데이터 | 범용 (어느 약국에나 적용 가능) |

## 향후 보강 방향

약국/한의원 Wiki가 태명과학/한국기계 수준의 실용성을 갖추려면:

1. **실제 업체 데이터 확보**: 취급 의약품 목록, 주요 처방 패턴, 재고 현황 등
2. **DB 테이블 + 엑셀 제작**: 의약품 DB, 상호작용 DB, 보험 청구 DB 등
3. **실제 사례 축적**: 가상 시나리오를 실제 복약지도 사례로 교체
4. **업체 맞춤 커스터마이징**: 해당 약국의 주요 고객층, 빈출 처방에 맞춘 콘텐츠
