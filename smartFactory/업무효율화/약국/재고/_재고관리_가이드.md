# 약국 재고관리 가이드

## 개요

약국 재고관리는 환자에게 적시에 약물을 공급하면서도 폐기 손실을 최소화하는 것이 핵심이다. 의약품의 유효기간 관리, 적정 재고 수준 유지, 발주 최적화를 통해 경영 효율을 높인다.

> 관련 문서: [[_보험_총괄]], [[처방검토_체크리스트]]

---

## 재고관리 기본 원칙

### FEFO (First Expired, First Out)

약국 재고관리의 **최우선 원칙**은 FEFO이다. 일반 유통업의 FIFO(선입선출)와 달리, 의약품은 **유효기간이 가장 짧은 것을 먼저 출고**한다.

```
입고 시
    ↓
유효기간 확인 → 기존 재고와 비교
    ↓
유효기간 짧은 것을 앞쪽/위쪽에 배치
    ↓
조제 시 앞쪽/위쪽부터 사용 (FEFO)
```

### FEFO 실행 방법

| 단계 | 세부 내용 |
|------|----------|
| 입고 시 | 유효기간 확인 → 전산 입력 → 기존 재고와 비교 배치 |
| 진열 시 | 유효기간 짧은 것을 앞쪽/접근 쉬운 곳에 배치 |
| 조제 시 | 동일 약품 중 유효기간 가장 짧은 것부터 사용 |
| 재고 점검 시 | 유효기간 임박 약품 선별 → 우선 소진 계획 |

## 유효기간 관리

### 유효기간 관리 체계

| 잔여 기간 | 조치 | 담당 |
|----------|------|------|
| 6개월 이상 | 정상 관리 | - |
| 3-6개월 | **주의 관리** — 월간 점검 목록 등재, 소진 계획 수립 | 약사/관리자 |
| 1-3개월 | **긴급 관리** — 도매상 반품 협의, 타 약국 양도 검토, 우선 조제 | 약사 |
| 1개월 미만 | **폐기 대상** — 반품 불가 시 폐기 절차 진행 | 약사 |
| 유효기간 만료 | **즉시 격리** → 조제 불가 → 폐기 처리 | 약사 |

### 유효기간 점검 스케줄

| 주기 | 점검 내용 |
|------|----------|
| 매일 | 당일 조제 약품 유효기간 확인 (조제 전) |
| 주간 | OTC 진열대 유효기간 점검 |
| 월간 | **전수 조사** — 전체 재고 유효기간 확인, 3개월 이내 임박 목록 작성 |
| 분기별 | 유효기간 관리 현황 분석, 폐기량 통계 |

### 유효기간 임박 약품 처리 방안

| 방안 | 설명 | 우선순위 |
|------|------|---------|
| 우선 조제 | 처방 시 유효기간 임박 약품 우선 사용 | 1 |
| 도매상 반품 | 반품 가능 여부 확인 (도매상별 정책 상이) | 2 |
| 타 약국 양도 | 근처 약국에 양도/교환 | 3 |
| 할인 판매 | OTC 한정, 유효기간 명시 후 할인 | 4 |
| 폐기 | 최후 수단, 폐기 기록 작성 | 5 |

## 안전재고 설정

### 안전재고란?
갑작스러운 수요 증가나 공급 지연에 대비하여 최소한으로 유지해야 할 재고 수준.

### 안전재고 계산

```
안전재고 = 일평균 사용량 x 안전 일수

안전 일수 결정 기준:
- 필수 의약품 (고혈압, 당뇨 등 만성질환): 7-14일
- 일반 의약품: 3-7일
- OTC (비처방): 7-14일
- 계절성 약품 (감기약 등): 시즌별 조정
```

### 약품 등급별 관리 (ABC 분석)

| 등급 | 기준 | 비중 | 관리 수준 |
|------|------|------|----------|
| A등급 | 매출액 상위 20% 약품 | 전체 매출의 약 70-80% | **정밀 관리** — 주간 발주, 적정 재고 엄격 유지 |
| B등급 | 매출액 중위 30% 약품 | 전체 매출의 약 15-20% | **일반 관리** — 격주 발주, 적정 재고 유지 |
| C등급 | 매출액 하위 50% 약품 | 전체 매출의 약 5-10% | **간소 관리** — 월간 발주, 최소 재고 |

### 발주점(Reorder Point) 설정

```
발주점 = 일평균 사용량 x 리드타임(일) + 안전재고

예시:
  아토르바스타틴 10mg
  - 일평균 사용량: 5정
  - 리드타임: 1일 (도매상 익일 배송)
  - 안전재고: 5정 x 7일 = 35정
  - 발주점: 5 x 1 + 35 = 40정
  → 재고 40정 이하 시 발주
```

## 발주 최적화

### 발주 방법

| 방법 | 설명 | 장단점 |
|------|------|--------|
| 정기 발주 | 매주 정해진 요일에 전체 재고 확인 후 발주 | 체계적이나 긴급 부족 시 대응 어려움 |
| 부정기 발주 | 재고 부족 시 수시 발주 | 긴급 대응 가능하나 비효율적 |
| 자동 발주 | 전산 시스템의 발주점 도달 시 자동 알림/발주 | 효율적, 시스템 세팅 필요 |
| 혼합 방식 | 정기 발주 + 긴급 부족 시 수시 발주 (권장) | 실무적으로 가장 현실적 |

### 발주 시 고려사항

| 고려사항 | 내용 |
|---------|------|
| 최소 주문량(MOQ) | 도매상별 최소 발주 단위 확인 |
| 배송 리드타임 | 일반: 1일, 긴급: 당일(추가 비용), 공휴일 전후 여유분 |
| 도매상 할인 | 대량 구매 시 할인율 비교 → 단, 유효기간 내 소진 가능해야 |
| 계절 수요 | 감기약(겨울), 알레르기약(봄/가을), 자외선차단제(여름) |
| 신약/코드 변경 | 급여 등재/삭제 약품 수시 확인 |
| 약가 인하 | 약가 인하 예정 약품은 인하 후 발주 유리 |

## 보관 조건별 관리

### 보관 온도 분류

| 보관 조건 | 온도 범위 | 해당 약품 예시 | 관리 포인트 |
|----------|----------|-------------|-----------|
| 실온 | 1-30도 (15-25도 권장) | 대부분의 경구약, 외용제 | 직사광선 차단, 습기 주의 |
| 냉장 | 2-8도 | 인슐린, 일부 안약, 좌약, 유산균 | 냉장고 온도 매일 확인/기록 |
| 냉동 | -20도 이하 | 일부 백신 (약국 보관 드묾) | 해동 후 재냉동 금지 |
| 차광 | 빛 차단 | 니페디핀, 니트로글리세린 | 갈색 용기/차광 봉투 사용 |
| 방습 | 습기 차단 | 아스피린, 흡습성 약품 | 밀폐 용기, 실리카겔 |

### 냉장 보관 약품 관리

```
[ ] 냉장고 온도: 매일 2회 확인 (오전/오후)
[ ] 온도 기록부 작성 (2-8도 범위 유지)
[ ] 냉장고 문 자주 열지 않기
[ ] 정전 대비 알림 시스템 (온도 이탈 알림)
[ ] 냉장고 정기 청소 (월 1회)
[ ] 개봉 인슐린: 실온 보관 가능 (28일 이내 사용)
```

## 마약류 관리

| 관리 항목 | 기준 |
|----------|------|
| 보관 | 별도 **이중 잠금장치** 캐비닛 |
| 기록 | 마약류 관리부 기록 (입고, 출고, 잔량, 폐기) |
| 점검 | 매일 재고 확인, 기록 대조 |
| 처방전 | 마약류 전용 처방전 확인, 30일 이내 투여일수 |
| 폐기 | 관할 시/군/구 보건소 입회 하 폐기 |
| 분실/도난 | 즉시 관할기관 신고 |

## 재고 실사 (Stocktaking)

### 실사 주기 및 방법

| 주기 | 대상 | 방법 |
|------|------|------|
| 매일 | 마약류, 고가약 | 전수 확인 |
| 월간 | A등급 약품 | 순환 실사 (ABC 중 A등급) |
| 분기별 | 전체 재고 | 전수 실사 (1년 4회) |
| 연간 | 전체 재고 | 결산 실사 (재무 목적) |

### 재고 차이 발생 시 대응

```
전산 재고 ≠ 실물 재고
    ↓
차이 원인 분석
  - 입력 오류 (가장 빈번)
  - 조제 시 전산 미반영
  - 반품/폐기 미기록
  - 도난/분실 (드묾)
    ↓
원인별 조치
  - 입력 오류: 전산 수정 + 기록
  - 미반영: 소급 처리
  - 분실: 관리 강화, 마약류 → 신고
    ↓
재발 방지 대책 수립
```

## 폐기 절차

### 일반 의약품 폐기

1. 유효기간 만료/변질 약품 분리
2. 폐기 대상 목록 작성 (품명, 수량, 유효기간, 사유)
3. 폐기 기록부 작성 (약사 서명)
4. 전문 폐기업체를 통한 폐기 (의료폐기물 처리)
5. 전산 재고 반영

### 마약류 폐기

1. 관할 시/군/구 보건소에 폐기 신청
2. **공무원 입회 하** 폐기 진행
3. 폐기 확인서 수령 및 보관
4. 마약류 관리부에 기록

## 재고관리 KPI (핵심 성과 지표)

| KPI | 산출 | 목표 |
|-----|------|------|
| 재고회전율 | 연간 사용금액 / 평균 재고금액 | 12-24회 (월 1-2회 회전) |
| 폐기율 | 폐기금액 / 총 입고금액 x 100 | **1% 이하** |
| 결품률 | 결품 건수 / 총 조제 건수 x 100 | **0.5% 이하** |
| 재고 정확도 | 일치 품목수 / 전체 품목수 x 100 | **99% 이상** |
| 유효기간 임박율 | 3개월 내 만료 품목수 / 전체 품목수 | **5% 이하** |
