# 약국 복약지도 Wiki

## 이것은 무엇인가?

약국 업무에 필요한 의약품 정보, 복약지도, 약물 상호작용 데이터를 정리한 시뮬레이션 Wiki입니다.
Obsidian Vault + Claude AI를 결합하여, 환자 맞춤 복약지도와 약물 상호작용 검토를 자동으로 수행할 수 있습니다.

> 본 Wiki의 데이터는 시뮬레이션/교육 목적이며, 실제 의료 판단을 대체하지 않습니다.
> 약물 정보는 2025년 기준 국내 허가사항에 근거하되, 일부 내용은 교육용으로 조정되었습니다.

## 빠른 시작

1. **Obsidian** 설치 후 이 폴더(`약국/`)를 Vault로 열기
2. Dataview 플러그인 설치 (대시보드 테이블 표시용)
3. `CLAUDE.md`가 AI 복약지도 어시스턴트의 역할 정의 (시스템 프롬프트)
4. Claude에게 아래 예시처럼 질문

## 사용 예시

### 1. 복약지도 요청
```
/복약지도 타이레놀 500mg
```
-> 아세트아미노펜 500mg 복약 안내: 4~6시간 간격, 1일 최대 4000mg,
   간질환자 주의, 알코올 병용 금지 등 상세 안내

### 2. 약물 상호작용 확인
```
/상호작용 와파린 아스피린
```
-> **금기(Contraindicated)**: 출혈 위험 극대화.
   와파린 복용 중 진통제 필요 시 아세트아미노펜 권장 ([[해열진통제]] 참조)

### 3. 증상별 OTC 추천
```
/추천 두통 여성/32세/임신8주
```
-> 임산부 안전 등급 확인 후 아세트아미노펜(타이레놀) 추천.
   이부프로펜/아스피린은 임신 중 금기 ([[해열진통제]] 참조)

### 4. 보험 확인
```
/보험확인 리피토 20mg
```
-> 아토르바스타틴 20mg, 건강보험 급여 대상.
   고지혈증 진단 시 처방 가능, 본인부담금 30%

### 5. 복합 상호작용 체크
```
/상호작용 메트포르민 시메티딘
```
-> **주의(Major)**: 시메티딘이 메트포르민 신장 배설을 억제하여 혈중 농도 상승 가능.
   H2차단제 중 라니티딘(파모티딘) 대체 검토 ([[위장약]] 참조)

## Vault 구조 안내

| 폴더/파일 | 내용 | 주요 파일 |
|-----------|------|-----------|
| 의약품/ | 약효군별 의약품 상세 정보 | [[해열진통제]], [[감기약]], [[위장약]] 등 |
| 의약품/_의약품_총괄.md | 전 의약품 비교표 | 20+ 약물 성분/용법/상호작용 |
| index.md | 대시보드 | Dataview 기반 전체 현황 |
| CLAUDE.md | AI 어시스턴트 역할 정의 | 명령어, 원칙, 프로세스 |

## 활용 시나리오

### 시나리오 A: 처방전 접수
1. 환자 기본정보 확인 (나이, 기저질환, 복용 약물)
2. 처방약 상호작용 검토 (`/상호작용`)
3. 복약지도 수행 (`/복약지도`)

### 시나리오 B: OTC 구매 상담
1. 환자 증상 청취
2. 적합 OTC 추천 (`/추천`)
3. 현재 복용 약물과 상호작용 확인 (`/상호작용`)

### 시나리오 C: 만성질환자 정기 방문
1. 복용 약물 전체 목록 리뷰
2. 부작용 모니터링 포인트 안내
3. 생활습관 조언 (식이, 운동)

## 시뮬레이션 데이터 안내

- 약물 정보: 국내 허가사항 및 약학정보원 데이터 기반
- 상호작용: 주요 상호작용만 수록 (교육 목적)
- 보험 정보: 시뮬레이션 데이터 (실제 급여 기준과 다를 수 있음)
- 재고: 가상 데이터 (실제 재고 시스템 미연동)
