# 한국 약국 업무 전 과정 설명서

## 1. 약국 개설 및 허가

### 1.1 개설 요건
- **약사 면허**: 약사 국가시험 합격 + 보건복지부 면허 발급
- **약국 개설 등록**: 관할 시/군/구청에 약국 개설 신고
- **시설 기준**: 약사법 시행규칙 별표4 (조제실, 약품 보관실, 상담 공간)
- **약사 상주 의무**: 영업 시간 중 약사 1인 이상 반드시 상주

### 1.2 필수 장비/시설
| 장비 | 용도 | 필수 여부 |
|------|------|:---------:|
| 조제대 | 약품 계량, 혼합, 포장 | 필수 |
| 약품 보관 선반/냉장고 | 의약품 보관 (냉장 2~8℃) | 필수 |
| 전자저울 | 약품 정밀 계량 (0.01g) | 필수 |
| 약포기 (분포기) | 산제/가루약 개별 포장 | 필수 |
| 약봉투/라벨 프린터 | 복약 안내 인쇄 | 필수 |
| 건강보험 청구 시스템 | HIRA 전자청구 | 필수 |
| POS 시스템 | 판매/재고 관리 | 권장 |
| 혈압계/혈당계 | 환자 모니터링 서비스 | 권장 |

## 2. 의약품 분류 체계

### 2.1 의약품 분류
```
의약품
├── 전문의약품 (ETC, Ethical Drug)
│   ├── 처방전 없이 판매 불가
│   ├── 약 80% 이상의 의약품
│   └── 예: 항생제, 고혈압약, 당뇨약, 정신과약
│
├── 일반의약품 (OTC, Over The Counter)
│   ├── 처방전 없이 약국에서 구매 가능
│   ├── 약사 복약지도 필수
│   └── 예: 타이레놀, 게보린, 판콜, 소화제
│
└── 안전상비의약품
    ├── 편의점/슈퍼에서도 판매 가능
    ├── 총 13품목 지정 (2024 기준)
    └── 예: 소독약, 밴드, 해열진통제 일부
```

### 2.2 마약류/향정신성 의약품
- **별도 관리 의무**: 이중 잠금 보관, 사용 기록 장부, NIMS(마약류 통합관리 시스템) 보고
- **재고 실사**: 분기 1회 이상
- **대상**: 코데인, 졸피뎀, 트라마돌, 벤조디아제핀류 등

## 3. 의약품 입고(구매) 과정

### 3.1 입고 흐름
```
[수요 파악] ─── 재고 확인 + 처방 빈도 분석
    │
    ▼
[발주] ──────── 의약품 도매상/제약사에 주문
    │           (전화, 온라인, 도매상 영업사원)
    │
    ▼
[입고 검수] ─── 제품명, 수량, 유효기간, 포장 상태 확인
    │
    ▼
[입고 등록] ─── POS/재고 시스템에 입력
    │           (약품명, 수량, 제조번호, 유효기간, 입고가)
    │
    ▼
[진열/보관] ─── 약품별 보관 조건에 따라 배치
                실온(15~25℃) / 냉장(2~8℃) / 차광
```

### 3.2 주요 도매상
| 도매상 | 특징 |
|--------|------|
| 지오영 (GC녹십자) | 국내 최대, 전국 배송망 |
| 바이오세인트 | 전문의약품 강점 |
| 한독제약 유통 | 한독 그룹 계열 |
| 백제약품 | 지역 밀착형 |
| 온라인 플랫폼 | 팜잇, 약사닷컴 등 |

### 3.3 발주 시 확인 사항
- **유효기간**: 최소 6개월 이상 잔여 권장
- **제조번호(LOT)**: 리콜 대응용 기록 필수
- **보관 조건**: 냉장 의약품은 콜드체인 유통 확인
- **반품 정책**: 유효기간 임박 시 반품 가능 여부

## 4. 재고 관리

### 4.1 재고 관리 원칙
- **FEFO (First Expired, First Out)**: 유효기간 가까운 것부터 출고
- **안전 재고**: 주요 약품은 2~3일치 보유
- **회전율 관리**: 월 1회 이상 사장 재고 점검
- **유효기간 관리**: 3개월 전 사전 경고 → 반품/할인/폐기 결정

### 4.2 재고 실사
| 주기 | 대상 | 내용 |
|------|------|------|
| 매일 | 마약류/향정 | NIMS 수불 기록 대조 |
| 주 1회 | 고가약/냉장약 | 수량 + 보관온도 확인 |
| 월 1회 | 전 품목 | 전수 실사, 유효기간 점검 |
| 분기 1회 | 마약류 | 관할 보건소 보고용 재고 실사 |

## 5. 처방전 접수 및 조제

### 5.1 처방전 접수 흐름
```
[환자 내원] ─── 처방전 지참 (종이 또는 전자처방전)
    │
    ▼
[처방전 확인] ── 약사가 처방 내용 검토
    │           ① 환자 정보 (성명, 주민번호, 연령)
    │           ② 의약품명, 용량, 용법, 일수
    │           ③ 의료기관 정보, 의사 서명/날인
    │           ④ 처방 유효기간 (발행일 포함 3일)
    │
    ▼
[DUR 점검] ──── 의약품안전사용서비스(DUR) 자동 확인
    │           ① 약물 상호작용 (Drug Interaction)
    │           ② 연령 금기 (소아/고령자)
    │           ③ 임부 금기
    │           ④ 용량 초과
    │           ⑤ 중복 처방 (같은 약 여러 병원)
    │           ⑥ 병용 금기
    │
    ├─ DUR 경고 있음 → 의사에게 확인 (유선 연락)
    │                   → 처방 변경 또는 사유 확인 후 조제
    │
    ▼
[조제] ──────── 약사가 직접 조제
    │           ① 약품 선택 (처방전 대로)
    │           ② 정확한 용량 계량
    │           ③ 산제/시럽 혼합 (필요 시)
    │           ④ 약포기로 개별 포장
    │           ⑤ 라벨 부착 (약품명, 용법, 용량)
    │           ⑥ 최종 검수 (Double check)
    │
    ▼
[복약지도] ──── 환자에게 약 설명
    │           ① 복용 방법 (식전/식후, 1일 몇 회)
    │           ② 주의사항 (졸음, 음주, 운전 주의 등)
    │           ③ 부작용 안내
    │           ④ 보관 방법 (냉장, 차광 등)
    │           ⑤ 남은 약 처리 방법
    │
    ▼
[수납] ──────── 본인부담금 수납
    │           건강보험 적용 시: 약값의 30% (일반)
    │           의료급여: 본인부담 없음~500원
    │
    ▼
[청구] ──────── 건강보험심사평가원(HIRA)에 전자 청구
                보험 부담분 (70%) 청구 → 심사 → 지급
```

### 5.2 DUR (의약품안전사용서비스) 상세
| 점검 항목 | 내용 | 예시 |
|----------|------|------|
| 병용 금기 | 함께 복용하면 위험한 약물 | 와파린 + 아스피린 |
| 특정 연령 금기 | 소아/고령자에게 금기 | 소아 아스피린 (라이증후군) |
| 임부 금기 | 임산부에게 금기 | 이소트레티노인 (기형 유발) |
| 용량 초과 | 1일 최대 용량 초과 | 아세트아미노펜 >4g/일 |
| 투여 기간 | 장기 투여 주의 | 벤조디아제핀 >4주 |
| 중복 처방 | 동일 성분 중복 | 2개 병원에서 같은 항생제 |

### 5.3 처방전 보관
- **보관 기간**: 조제일로부터 **3년간** 보관 의무
- **보관 방법**: 원본 또는 전자 스캔 (전자처방전은 시스템 보관)
- **열람 권한**: 환자 본인, 관할 보건소, 수사기관(영장)

## 6. 일반의약품(OTC) 판매

### 6.1 판매 흐름
```
[고객 내원] ─── "감기약 주세요" / 증상 설명
    │
    ▼
[약사 상담] ─── 증상, 복용 중인 약, 알레르기 확인
    │           ① 어떤 증상인지? (두통, 콧물, 기침 등)
    │           ② 현재 복용 약이 있는지?
    │           ③ 알레르기 이력
    │           ④ 임신/수유 여부
    │           ⑤ 기저질환 (고혈압, 당뇨 등)
    │
    ▼
[약품 추천] ─── 증상에 맞는 일반의약품 선택
    │           (필요 시 병원 진료 권유)
    │
    ▼
[복약지도] ─── 복용법, 주의사항 설명
    │
    ▼
[판매/수납] ─── 건강보험 비적용 (전액 본인 부담)
                POS 매출 등록
```

### 6.2 주요 OTC 카테고리
| 카테고리 | 대표 제품 | 주의사항 |
|----------|----------|---------|
| 해열진통제 | 타이레놀, 이부프로펜 | 간질환자 아세트아미노펜 주의, 위장장애 |
| 감기약 | 판콜, 코대원 | 졸음 유발, 운전 주의, 중복 성분 확인 |
| 소화제 | 베아제, 훼스탈 | 장기 복용 시 의존성 주의 |
| 위장약 | 겔포스, 잔탁 | H2 차단제 장기복용 시 의사 상담 |
| 알레르기약 | 지르텍, 클라리틴 | 졸음(1세대), 비졸음(2세대) 구분 |
| 외용제 | 마데카솔, 후시딘 | 상처 종류에 따라 선택 |
| 안약 | 인공누액, 항히스타민 안약 | 콘택트렌즈 착용 시 주의 |
| 비타민/영양제 | 비타민C, 종합비타민 | 과량 복용 주의, 약물 상호작용 |

## 7. 건강보험 청구

### 7.1 청구 흐름
```
[조제 완료]
    │
    ▼
[청구 데이터 생성] ── 약국 시스템에서 자동 생성
    │                 (환자정보, 처방내역, 약품코드, 금액)
    │
    ▼
[전자 청구] ──────── HIRA (건강보험심사평가원) 전송
    │                 매월 청구 (익월 10일까지)
    │
    ▼
[심사] ──────────── HIRA 심사
    │                 ① 적정 처방 여부
    │                 ② 약가 기준 확인
    │                 ③ DUR 적합성
    │
    ├─ 삭감 발생 → 이의신청 가능 (90일 이내)
    │
    ▼
[지급] ──────────── 건강보험공단 → 약국 계좌 입금
                     청구 후 약 20~25일 후 지급
```

### 7.2 주요 보험 적용 기준
| 구분 | 본인부담률 | 비고 |
|------|:---------:|------|
| 건강보험 (일반) | 30% | 처방전 조제 |
| 건강보험 (65세+) | 30% (외래) | 동일 |
| 의료급여 1종 | 500원 | 정액제 |
| 의료급여 2종 | 1,000원 | 정액제 |
| 산재보험 | 0% | 전액 보험 |
| 자동차보험 | 0% | 보험사 청구 |
| 비급여 | 100% | 보험 비적용 약품 |

## 8. 약사의 법적 의무

### 8.1 필수 의무
| 의무 | 근거 법령 | 내용 |
|------|----------|------|
| 약사 상주 | 약사법 §20 | 영업시간 중 약사 상시 근무 |
| 복약지도 | 약사법 §24 | 모든 조제에 대해 환자에게 설명 |
| 처방전 보관 | 약사법 §30 | 조제일로부터 3년 |
| DUR 확인 | 약사법 §26 | 의약품안전사용 점검 의무 |
| 마약류 관리 | 마약류관리법 | NIMS 보고, 이중잠금, 기록 |
| 의약품 부작용 보고 | 약사법 §68의8 | 중대한 부작용 발견 시 식약처 보고 |
| 조제 기록 | 약사법 §28 | 조제한 의약품 기록 보관 |

### 8.2 금지 행위
- 처방전 없이 전문의약품 판매
- 의약품 쪼개팔기 (낱개 판매 제한 품목)
- 의사 처방 변경 (약사 임의 대체 불가, 동일 성분 제네릭은 가능)
- 리베이트 수수 (약사법 §47조의2)

## 9. 특수 서비스

### 9.1 약국에서 제공 가능한 서비스
| 서비스 | 내용 | 수가/비용 |
|--------|------|----------|
| 복약상담 | 만성질환 약물 관리 상담 | 무료 또는 수가 |
| 혈압/혈당 측정 | 환자 자가관리 지원 | 무료 |
| 흡연 상담 | 금연 보조제 + 상담 | 건보 적용 |
| 건강기능식품 상담 | 약물-건기식 상호작용 확인 | 무료 |
| 방문 약료 | 거동 불편 환자 방문 복약지도 | 수가 적용 |
| 예방접종 | 독감 백신 등 (일부 약국) | 유료 |

### 9.2 약국 자동화 장비
| 장비 | 기능 | 도입 현황 |
|------|------|----------|
| 자동 조제기 (ATC) | 정제/캡슐 자동 계수/포장 | 대형 약국 도입 증가 |
| 자동 산제 분포기 | 가루약 자동 분배/포장 | 보편화 |
| 전자 처방전 시스템 | 종이 처방전 대체 | 2025~ 확대 |
| 약력 관리 시스템 | 환자별 복약 이력 관리 | 보편화 |

## 10. 약국 운영의 하루 (일과)

```
[08:30] 개점 준비
        ├── 냉장고 온도 확인 (2~8℃)
        ├── 조제대/장비 점검
        └── 당일 입고 예정 약품 확인

[09:00] 영업 시작
        ├── 처방전 접수 → 조제 → 복약지도 → 수납
        ├── 일반의약품 상담 판매
        └── DUR 확인 + 의사 연락 (필요 시)

[12:00] 점심 (교대 또는 휴게)
        └── 약사 부재 시 영업 불가 (상주 의무)

[13:00] 오후 영업
        ├── 처방전 조제 (오후 피크)
        ├── 입고 약품 검수/등록
        └── 유효기간 임박 약품 확인

[17:00] 도매상 발주
        └── 내일 필요 약품 주문

[18:00] 마감 준비
```
