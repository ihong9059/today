# 복약지도 기록 템플릿

## 사용 안내

본 템플릿은 약국에서 복약지도를 실시한 후 기록을 남기기 위한 표준 양식이다. 법적 의무인 복약지도의 실시 근거를 남기고, 환자 추적 관리 및 DUR 대응 기록에 활용한다.

## 기록 작성 지침

### 작성 원칙

1. **즉시 작성**: 복약지도 직후 또는 당일 내 작성
2. **사실 기반**: 객관적 사실 위주 기록, 추측/판단은 구분
3. **구체적 기술**: "교육함" 대신 "아세트아미노펜 1일 최대 4g 초과 금지 안내" 등
4. **DUR 기록 필수**: DUR 경고 발생 시 조치 내용 반드시 기록 (법적 보호)
5. **환자 동의**: 대체조제 시 동의 사실 기록

### 보존 기간

- 복약지도 기록: **3년** (약사법)
- 처방전: **3년** (약사법)
- 마약류 관리부: **2년** (마약류관리법)

### 전산 기록

약국 전산 시스템에서 복약지도 기록 기능을 제공하는 경우:
- 전산 입력으로 대체 가능
- 단, 필수 항목 모두 포함되어야 함
- 출력/백업 가능해야 함

## 사례별 기록 예시

### 예시 1: 고혈압 환자 OTC 상담

> 상담 유형: OTC 상담
> 교육 내용: 이부프로펜 구매 요청 → 발사르탄(ARB) 복용 중 확인 → NSAIDs + ARB 상호작용(혈압강하 효과 감소, 신기능 악화) 설명 → 아세트아미노펜 500mg + 케토프로펜 겔 권고 → 환자 수용
> DUR: 해당 없음 (OTC)

> 사례 참고: [[2025-A약국-고혈압환자-복약지도]]

### 예시 2: 와파린 환자 감기약 상호작용

> 상담 유형: OTC 상담 + 상호작용 상담
> 교육 내용: 종합감기약(판콜에이) 구매 요청 → 와파린 복용 확인 → 아세트아미노펜(고용량 주의), 슈도에페드린(심방세동 위험), 클로르페니라민(고령자 부적절) 설명 → 개별 안전 성분 조합으로 변경 → INR 모니터링 권고
> DUR: 해당 없음 (OTC)

> 사례 참고: [[2025-B약국-감기약-상호작용발견]]
