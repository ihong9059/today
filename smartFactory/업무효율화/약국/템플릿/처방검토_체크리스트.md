# 처방 검토 체크리스트 템플릿

## 사용 안내

본 체크리스트는 처방전 접수 후 조제 전에 약사가 확인해야 할 사항을 표준화한 양식이다. 모든 처방에 대해 체계적인 검토를 수행하여 조제 오류, 상호작용, 부적절 처방을 사전에 방지한다.

> 관련 문서: [[DUR_점검가이드]], [[_상호작용_매트릭스]], [[청구_오류_방지]], [[복약지도_기록]]

---

## 체크리스트

### STEP 1. 처방전 형식 확인

```
날짜: ____/____/____  약사: ____________

[ ] 처방전 유효기간 확인 (발행일 포함 3일 이내)
    발행일: ____/____ 유효기한: ____/____
[ ] 환자 인적사항 확인 (성명, 주민등록번호)
[ ] 처방의 정보 확인 (의사명, 면허번호, 서명/날인)
[ ] 의료기관 정보 확인 (기관명, 전화번호)
[ ] 질병분류기호 기재 확인
[ ] 처방 내용 판독 가능 (약품명, 용량, 용법, 일수 명확)
[ ] 처방전 원본 여부 확인 (사본/재발행 표시 확인)
```

### STEP 2. 환자 정보 확인

```
[ ] 보험 자격 확인 (EDI 조회)
    유형: [ ]건보 [ ]의료급여1종 [ ]의료급여2종 [ ]산재 [ ]자보
[ ] 환자 연령 확인: ____세
    [ ] 소아(0-12) [ ] 청소년(13-18) [ ] 성인(19-64) [ ] 고령자(65+)
[ ] 성별 확인: [ ]남 [ ]여
[ ] 임신/수유 여부 확인 (가임연령 여성 시): [ ]비해당 [ ]임신(__주) [ ]수유 [ ]확인완료(비임신)
[ ] 알레르기 확인: [ ]없음 [ ]있음 → ____________
[ ] 기저질환 확인:
    [ ]고혈압 [ ]당뇨 [ ]심장질환 [ ]신장질환 [ ]간질환
    [ ]천식 [ ]위장질환 [ ]정신질환 [ ]기타: ____________
[ ] 현재 타 약물 복용 확인:
    처방약: ____________
    OTC/건기식: ____________
[ ] 체중 확인 (소아/용량 의존 약물): ____kg
```

### STEP 3. DUR 점검

```
[ ] DUR 전산 점검 실행 완료

DUR 경고 결과:
[ ] 경고 없음 → STEP 4로 진행
[ ] 경고 있음 → 아래 기록

┌────────────┬────────┬────────────────────┬───────────┐
│ 경고 유형    │ 등급    │ 약물 조합            │ 조치 결과   │
├────────────┼────────┼────────────────────┼───────────┤
│            │        │                    │           │
├────────────┼────────┼────────────────────┼───────────┤
│            │        │                    │           │
└────────────┴────────┴────────────────────┴───────────┘

경고 유형: 병용금기 / 연령금기 / 임부금기 / 용량초과 / 투여기간 / 동일성분중복 / 효능군중복

처방의 연락: [ ]필요 없음 [ ]연락 완료 (____시____분, 결과: ________)
```

> DUR 대응 절차: [[DUR_점검가이드]]

### STEP 4. 약학적 검토

#### 4-1. 용량 확인

```
[ ] 각 약물의 1회 용량이 허가 범위 내
[ ] 1일 투여량이 허가 최대 용량 이하
[ ] 소아: 체중 기반 용량 계산 확인 (mg/kg)
    계산: ____________
[ ] 고령자: 용량 감량 필요 여부 확인
[ ] 신기능 저하 시: eGFR 기반 용량 조절 확인
    eGFR: ____ → 조절 필요 약물: ____________
```

#### 4-2. 적응증 확인

```
[ ] 처방 약물이 진단명(질병코드)과 부합하는지 확인
[ ] 적응증 외 사용 의심 약물: [ ]없음 [ ]있음 → ____________
    → 확인 필요 시 처방의 문의
```

#### 4-3. 상호작용 확인

```
[ ] 처방 내 약물 간 상호작용 확인
[ ] 처방 약물 + 환자 기존 약물 간 상호작용 확인
[ ] 주요 상호작용 발견: [ ]없음 [ ]있음

발견된 상호작용:
┌──────────┬──────────┬────────┬───────────────┐
│ 약물 A    │ 약물 B    │ 등급    │ 내용/조치       │
├──────────┼──────────┼────────┼───────────────┤
│          │          │        │               │
├──────────┼──────────┼────────┼───────────────┤
│          │          │        │               │
└──────────┴──────────┴────────┴───────────────┘
```

> 상호작용 참고: [[_상호작용_매트릭스]]

#### 4-4. 특수집단 확인

```
소아 (해당 시):
[ ] 연령 금기 약물 없음
[ ] 체중 기반 용량 적정
[ ] 적절한 제형 (시럽/산제/츄어블)
→ 참고: [[연령별_금기]]

고령자 (해당 시):
[ ] Beers Criteria 해당 약물 없음
[ ] 항콜린 부하 확인 (중복 항콜린 약물 없음)
[ ] 낙상 위험 약물 최소화
[ ] 신기능 기반 용량 적정
→ 참고: [[연령별_금기]]

임부 (해당 시):
[ ] 임신 금기 약물 없음
[ ] 임신 주수별 위험 평가 완료
→ 참고: [[연령별_금기]]

수유부 (해당 시):
[ ] 수유 금기 약물 없음
[ ] 수유 시점 교육 (수유 직후 복약 권고)
→ 참고: [[연령별_금기]]
```

#### 4-5. 투여일수 확인

```
[ ] 외래 처방 최대 일수 이내 (일반: 90일)
[ ] 마약류: 30일 이내
[ ] 수면제/항불안제: 투여기간 제한 확인
[ ] 항생제: 적정 투여 기간 (과소/과다 확인)
```

### STEP 5. 보험 청구 확인

```
[ ] 약품 코드 정확성 확인 (품목코드, 제조사, 규격)
[ ] 급여/비급여 구분 확인
[ ] 급여 기준 충족 여부 확인 (특수 약물)
[ ] 본인부담률 적용 확인
[ ] 산정특례 해당 여부: [ ]비해당 [ ]해당 (____%)
[ ] 대체조제 시 절차 완료: [ ]비해당 [ ]환자동의 [ ]의사통보
```

> 청구 오류 방지: [[청구_오류_방지]]

### STEP 6. 조제 및 검수

```
[ ] 약품 선택 정확 (약품명, 함량, 제형 일치)
[ ] 수량 정확 (총 수량 = 1회량 x 횟수 x 일수)
[ ] 유효기간 확인 (유효기간 내)
[ ] 포장/라벨 부착 (환자명, 용법, 약국명)
[ ] 최종 검수 완료 (약사 확인)
```

### STEP 7. 복약지도 실시

```
[ ] 복약지도 실시 완료
[ ] 복약지도 기록 작성 완료 → [[복약지도_기록]]

교육 항목:
[ ] 용법/용량 [ ] 부작용 [ ] 상호작용 [ ] 보관법
[ ] 생활습관 [ ] 모니터링 [ ] 기타: ____________
```

## 고위험 약물 추가 체크포인트

다음 약물이 처방에 포함된 경우 추가 확인:

### 와파린/항응고제

```
[ ] INR 최근 값 확인: ____
[ ] INR 목표 범위: ____-____
[ ] 상호작용 약물 없음 (NSAIDs, 항생제, 항진균제 등)
[ ] 비타민K 식이 교육 완료
[ ] 출혈 증상 모니터링 교육
```

### 인슐린

```
[ ] 인슐린 종류/용량 확인
[ ] 주사 방법/부위 교육
[ ] 보관 방법 교육 (냉장/실온)
[ ] 저혈당 교육 완료
[ ] 바늘 교체 안내
```

### 마약류

```
[ ] 마약류 전용 처방전 확인
[ ] 투여일수 30일 이내
[ ] 마약류 관리부 기록
[ ] 이중 잠금장치 보관 확인
[ ] 환자에게 보관/폐기 교육
```

### 항암제 (경구)

```
[ ] 용량 프로토콜 확인
[ ] 혈액검사 결과 확인 (가능 시)
[ ] 부작용 모니터링 교육
[ ] 취급 주의사항 (임부/가임여성 접촉 금지 등)
```

### 면역억제제

```
[ ] 혈중농도 모니터링 여부 확인
[ ] 상호작용 확인 (특히 CYP3A4 관련)
[ ] 감염 예방 교육
[ ] 자몽 회피 교육 (사이클로스포린, 타크로리무스)
```

## 처방 검토 결과 요약

```
검토 결과:
[ ] 이상 없음 → 조제 진행
[ ] 경미한 주의사항 → 복약지도 시 안내 후 조제
[ ] 처방의 확인 필요 → 연락 후 진행
[ ] 처방 변경 필요 → 변경 확인 후 조제

처방의 연락 사항 (해당 시):
연락 일시: ____시 ____분
상대방: ____________
내용: ____________
결과: ____________

검토 약사: ____________ (서명)
검토 일시: ____년 __월 __일 __:__
```
