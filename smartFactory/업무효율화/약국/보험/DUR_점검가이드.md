# DUR (Drug Utilization Review) 점검 가이드

## 개요

DUR은 건강보험심사평가원(HIRA)이 운영하는 **실시간 의약품 안전성 점검 시스템**이다. 처방전 조제 시 약국 전산에서 자동으로 점검이 이루어지며, 약사는 DUR 경고에 대해 적절히 대응해야 한다.

> 관련 문서: [[_보험_총괄]], [[_상호작용_매트릭스]], [[청구_오류_방지]], [[처방검토_체크리스트]]

## DUR 점검 항목

### 1. 병용금기

| 항목 | 설명 | 예시 |
|------|------|------|
| 정의 | 동시 투여 시 심각한 이상반응 발생 위험이 높은 약물 조합 | 와파린 + 아스피린(고용량) |
| 등급 | 1등급(금기) / 2등급(주의) | |
| 조치 | 1등급: 조제 불가 → 처방의 연락 / 2등급: 주의하여 조제, 복약지도 | |

> 주요 병용금기 약물: [[_상호작용_매트릭스]] 참고

### 2. 특정연령대금기

| 항목 | 설명 | 예시 |
|------|------|------|
| 정의 | 특정 연령에서 사용 금기인 약물 | 아스피린 → 15세 미만 금기(라이증후군) |
| 점검 | 환자 연령과 약물의 연령 제한 자동 대조 | 퀴놀론 → 18세 미만 |
| 조치 | 경고 발생 시 처방의 확인 후 진행 | |

> 연령별 금기 상세: [[연령별_금기]]

### 3. 임부금기

| 항목 | 설명 |
|------|------|
| 정의 | 임산부에게 사용 시 태아 기형 등 심각한 위험이 있는 약물 |
| 등급 | 1등급(절대금기) / 2등급(원칙적금기) |
| 점검 | 여성 가임연령(15-50세) 환자에서 자동 점검 (실제 임신 여부 확인 필요) |
| 1등급 예시 | 이소트레티노인, 메토트렉세이트, 와파린, 발프로산 |
| 조치 | 반드시 임신 여부 확인 → 임신 시 처방의 연락 |

### 4. 용량 초과

| 항목 | 설명 |
|------|------|
| 정의 | 1일 최대 투여량 초과 처방 |
| 점검 | 약품별 허가 용량 기준 자동 점검 |
| 주의 | 신기능/간기능 저하 환자는 더 낮은 용량이 적절할 수 있음 |
| 조치 | 처방의 의도 확인 (의도적 증량인지 오류인지) |

### 5. 투여기간 제한

| 항목 | 설명 |
|------|------|
| 정의 | 장기 투여 시 부작용 위험이 높은 약물의 투여 기간 제한 |
| 예시 | 벤조디아제핀(4주), 졸피뎀(4주), 일부 NSAIDs |
| 조치 | 처방의에게 장기 투여 사유 확인 |

### 6. 동일성분 중복투여

| 항목 | 설명 |
|------|------|
| 정의 | 타 의료기관 처방과 동일 성분 약물 중복 |
| 점검 | 약국간 처방 조제 이력 기반 실시간 점검 |
| 빈도 | DUR 경고 중 가장 빈번 |
| 조치 | 환자에게 확인 → 처방의 소통 → 중복 해소 |

### 7. 효능군 중복

| 항목 | 설명 |
|------|------|
| 정의 | 동일 효능군(같은 약리작용) 약물 중복 처방 |
| 예시 | 두 가지 다른 성분의 PPI 동시 처방, 두 가지 벤조디아제핀 |
| 조치 | 의도적 병용인지 확인 (일부는 합리적 사유 있음) |

## DUR 경고 대응 절차

### 경고 등급별 대응

```
DUR 경고 발생
    ↓
등급 확인
    ↓
┌─────────────────────────────────────────────┐
│ [1등급 - 금기]                               │
│  → 조제 보류                                 │
│  → 처방의에게 즉시 전화                      │
│  → 대체약 제안                               │
│  → 처방 변경 수신 후 조제                    │
│  → DUR 사유 기록                             │
├─────────────────────────────────────────────┤
│ [2등급 - 주의]                               │
│  → 처방의 의도 확인 (필요시 전화)            │
│  → 의도적 처방인 경우: 사유 기록 후 조제     │
│  → 환자에게 주의사항 복약지도               │
│  → DUR 사유 기록                             │
├─────────────────────────────────────────────┤
│ [동일성분 중복]                              │
│  → 환자에게 타원 약 복용 여부 확인           │
│  → 중복인 경우: 처방의 연락                  │
│  → 의도적 병용인 경우: 사유 기록             │
└─────────────────────────────────────────────┘
```

### DUR 사유 기록 방법

약국 전산 시스템에서 DUR 경고 처리 시 사유 코드 입력:

| 사유 코드 | 의미 | 비고 |
|----------|------|------|
| 01 | 처방의 확인 후 그대로 조제 | 의사가 의도적 처방임을 확인 |
| 02 | 처방 변경 | 의사가 처방을 수정 |
| 03 | 환자 요청 거부 | 환자가 상담 후 구매 포기 |
| 04 | 다른 의약품으로 대체 | 대체조제 |
| 05 | 기타 | 사유 직접 입력 |

## 처방의 소통 가이드

### 전화 시 화법

DUR 경고에 대해 처방의에게 연락할 때의 표준 화법:

```
"안녕하세요, OO약국 약사 OOO입니다.
[환자명]님 처방전에 대해 확인 드릴 사항이 있습니다.

[상황 설명]
예1: "현재 와파린을 복용 중인 환자분인데,
      이번 처방에 이부프로펜이 포함되어 있어
      DUR 병용금기로 확인됩니다."

예2: "타 병원에서 같은 성분의 오메프라졸을
      이미 처방받아 복용 중인 것으로 확인됩니다."

[대안 제시]
"이부프로펜 대신 아세트아미노펜으로 변경 가능하신지요?"
"중복 처방이므로 한쪽을 삭제하시거나 의도적이신지 확인 부탁드립니다."

[처방의 답변 기록]
→ 변경/유지 결정 기록
→ 유지 시 사유 기록
```

### 소통 시 주의사항

1. **비난이 아닌 확인**: "틀렸다"가 아니라 "확인 드립니다"
2. **근거 제시**: DUR 점검 결과, 상호작용 내용 설명
3. **대안 준비**: 대체 약물을 미리 준비하여 제안
4. **기록 필수**: 통화 일시, 상대방, 결정 내용 기록
5. **환자 앞 주의**: 의사 처방을 비판하는 인상 주지 않기

## DUR 경고 빈도 TOP 10 (약국 실무 기준)

| 순위 | 경고 유형 | 빈도 | 주요 원인 |
|------|----------|------|----------|
| 1 | 동일성분 중복투여 | 매우 높음 | 복수 의료기관 방문 환자 |
| 2 | 효능군 중복 | 높음 | 유사 약물 다기관 처방 |
| 3 | 연령금기 (소아) | 중간 | 소아 처방 시 연령 제한 약물 |
| 4 | 병용금기 2등급 | 중간 | NSAIDs + 항고혈압제 등 |
| 5 | 용량 초과 | 중간 | 용량 입력 오류 또는 의도적 증량 |
| 6 | 투여기간 초과 | 중간 | 수면제/항불안제 장기 처방 |
| 7 | 임부금기 | 낮음 | 가임연령 여성 자동 경고 (실제 임신 아닌 경우 다수) |
| 8 | 병용금기 1등급 | 낮음 | 심각한 상호작용 |
| 9 | 노인주의 | 중간 | Beers Criteria 해당 |
| 10 | 식품 상호작용 | 낮음 | 일부 시스템에서 제공 |

## DUR 점검 관련 법적 근거

| 법령 | 내용 |
|------|------|
| 약사법 제26조 | 약사의 복약지도 의무 |
| 국민건강보험법 시행령 | DUR 실시 근거 |
| 의약품 안전사용서비스 운영규정 | DUR 세부 운영 기준 |

### 약사의 DUR 관련 책임

- DUR 경고를 **무시하고 조제한 경우**: 이상반응 발생 시 약사 책임 가능
- DUR 경고에 대해 **적절히 대응한 기록**이 있으면: 면책 근거
- 따라서 **DUR 사유 기록**은 법적 보호의 핵심

## DUR 시스템 활용 팁

### 1. 오경보(False Alarm) 판단

| 상황 | 판단 | 조치 |
|------|------|------|
| 가임연령 여성의 임부금기 경고 | 실제 임신이 아닐 수 있음 | 환자에게 임신 여부 확인 |
| 동일 성분 타제형 (예: 안약+경구) | 적절한 병용일 수 있음 | 전신 흡수 여부 판단 |
| 의도적 고용량 (전문의 판단) | 합리적 사유 가능 | 처방의 확인 + 사유 기록 |
| 동일 효능군이나 기전 다름 | 합리적 병용일 수 있음 | 약학적 판단 후 기록 |

### 2. 약국 전산 시스템 설정

- DUR 경고 알림 설정: 소리/팝업 → 반드시 활성화
- 경고 등급별 색상 구분: 1등급(빨강), 2등급(노랑), 정보(파랑)
- 자주 발생하는 오경보: 사유 코드 사전 등록으로 처리 시간 단축
- DUR 처리 이력 조회: 월말 정리 시 활용
