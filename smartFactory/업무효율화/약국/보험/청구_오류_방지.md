# 보험 청구 오류 방지 가이드

## 개요

건강보험심사평가원(HIRA)의 심사에서 삭감(청구 불인정)이 발생하면 약국 수익에 직접적 영향을 미친다. 본 문서는 빈번한 삭감 사유를 분석하고 사전 방지 방법을 제시한다.

> 관련 문서: [[_보험_총괄]], [[DUR_점검가이드]], [[보험-FAQ]]

---

## 삭감(조정) 유형

| 유형 | 설명 |
|------|------|
| 전액 삭감 | 해당 약품 비용 전액 불인정 |
| 일부 삭감 | 초과 투여일수/용량 부분만 불인정 |
| 조제료 삭감 | 조제료/복약지도료 불인정 |
| 청구 반송 | 오류로 인해 청구 자체가 반송 → 재청구 필요 |

## 빈도별 삭감 사유 TOP 15

### A. 처방 관련 삭감

| 순위 | 삭감 사유 | 빈도 | 방지 방법 |
|------|---------|------|----------|
| 1 | **적응증 외 사용** | 매우 높음 | 약품의 허가 적응증 확인. 처방 진단명과 약품 적응증 대조 |
| 2 | **투여일수 초과** | 높음 | 외래 최대 처방일수 확인 (일반 90일, 마약류 30일) |
| 3 | **1일 투여량 초과** | 높음 | 허가 용량 확인. 초과 시 처방의 확인 + 사유 기록 |
| 4 | **동일성분 중복 처방** | 높음 | DUR 점검으로 확인. 타기관 처방 이력 확인 |
| 5 | **급여 기준 미충족** | 중간 | 급여 기준(고시) 확인. 특히 고가약, 특수약물 |

### B. 조제 관련 삭감

| 순위 | 삭감 사유 | 빈도 | 방지 방법 |
|------|---------|------|----------|
| 6 | **약품 코드 오류** | 높음 | 약품 코드 정확히 입력. 제조사/규격 확인 |
| 7 | **대체조제 절차 미비** | 중간 | 대체조제 시 환자 동의 + 의사 통보 기록 |
| 8 | **산정 특례 미적용** | 중간 | 암, 희귀질환 등 산정특례 환자 확인 |
| 9 | **조제료 이중 산정** | 낮음 | 동일 환자 동일 처방 이중 청구 주의 |
| 10 | **수가 코드 변경 미반영** | 중간 | 연도별 수가 변경 시 즉시 업데이트 |

### C. 자격/서류 관련 삭감

| 순위 | 삭감 사유 | 빈도 | 방지 방법 |
|------|---------|------|----------|
| 11 | **보험자격 상실** | 중간 | 접수 시 자격 확인 (건보 EDI) |
| 12 | **처방전 유효기간 경과** | 낮음 | 발행일 포함 3일 (공휴일 연장 확인) |
| 13 | **처방전 기재사항 불비** | 낮음 | 필수 기재사항 확인 (의사 서명, 면허번호 등) |
| 14 | **의료급여/건보 구분 오류** | 낮음 | 보험 유형 정확히 확인 |
| 15 | **주민등록번호 오류** | 낮음 | 신분증 확인, 전산 자동 입력 활용 |

## 삭감 방지 체크리스트

### 처방전 접수 시

```
[ ] 환자 보험 자격 확인 (건보/의료급여/산재/자보)
[ ] 처방전 유효기간 확인 (발행일 포함 3일)
[ ] 처방전 필수 기재사항 확인
    - 환자 성명, 주민등록번호
    - 질병분류기호
    - 처방 의약품명, 용량, 용법, 일수
    - 의사 서명/날인, 면허번호
    - 의료기관명, 전화번호
[ ] 처방전 사본 발행 여부 확인 (분할조제 등)
```

### 조제 시

```
[ ] DUR 점검 완료 → 경고 사항 처리
[ ] 약품 코드 정확성 확인 (품목코드, 제조사, 규격)
[ ] 투여량이 허가 범위 내인지 확인
[ ] 투여일수 적정성 확인
[ ] 적응증-진단명 부합 여부 확인 (의심 시)
[ ] 대체조제 시 절차 준수 (동의, 통보, 기록)
[ ] 마약류 처방 시 마약류 관리 기록
```

### 청구 데이터 입력 시

```
[ ] 환자 인적사항 정확성 (주민번호, 성명)
[ ] 보험유형 코드 정확성
[ ] 약품코드/수가코드 최신 버전 확인
[ ] 조제료/복약지도료 산정 적정성
[ ] 산정특례 해당 여부 확인
[ ] 본인부담률 정확 적용
```

### 월말 청구 전

```
[ ] 미청구 건 확인 및 보완
[ ] 반송 건 재처리
[ ] 약품 코드 변경 사항 반영
[ ] 수가 변경 사항 반영
[ ] 전체 청구 데이터 이상 여부 검토 (금액 급변동 확인)
```

## 주요 삭감 사례 및 대응

### 사례 1: 적응증 외 사용 삭감

**상황**: 가바펜틴 → 신경병성 통증으로 처방되었으나, 진단명이 "요통(M54.5)"으로만 기재

**삭감 사유**: 가바펜틴 급여 적응증은 "간질, 대상포진 후 신경통" → 요통은 적응증 외

**대응**:
- 처방의에게 정확한 진단명 기재 요청 (예: "대상포진 후 신경통 G53.0")
- 이미 삭감된 경우: 이의신청 시 진단서 첨부

### 사례 2: 투여일수 초과 삭감

**상황**: 졸피뎀 90일분 처방

**삭감 사유**: 졸피뎀 급여 기준 "외래 최대 30일"

**대응**:
- 접수 시 30일 초과분은 비급여 처리 또는 처방의에게 일수 변경 요청
- DUR 투여기간 경고에서 사전 차단

### 사례 3: 동일성분 중복 삭감

**상황**: A병원 → 오메프라졸 20mg 처방. B병원 → 에소메프라졸 20mg 처방. 약국에서 둘 다 조제.

**삭감 사유**: 동일 효능군(PPI) 중복

**대응**:
- DUR에서 동일성분/효능군 중복 경고 확인
- 환자에게 타원 약 복용 확인 → 처방의 소통으로 중복 해소

## 이의신청 절차

삭감 통보를 받은 후 부당하다고 판단되면 이의신청 가능:

### 절차

```
삭감 통보 수신 (심사 결과 통보서)
    ↓
삭감 내용 분석
    - 삭감 사유 코드 확인
    - 처방 내용, 환자 상태 검토
    ↓
이의신청 필요성 판단
    - 정당한 삭감: 수용 (향후 방지책 마련)
    - 부당한 삭감: 이의신청 진행
    ↓
이의신청서 작성
    - 이의신청 사유 (구체적, 근거 기반)
    - 근거 자료 첨부 (학술자료, 진료기록, 가이드라인)
    ↓
HIRA에 제출
    - 통보일로부터 90일 이내
    - 온라인(심평원 포털) 또는 서면
    ↓
재심사 결과 확인
    - 인용(삭감 철회) / 기각 / 일부 인용
    ↓
기각 시 → 건강보험분쟁조정위원회 심판청구 가능
```

### 이의신청 성공률 높이는 팁

1. **학술적 근거 첨부**: 가이드라인, 논문, FDA/EMA 승인 자료
2. **환자 특수성 강조**: 대안이 없는 사유, 환자 상태의 특수성
3. **처방의 소견서**: 처방 사유를 의사가 직접 기술한 소견서
4. **구체적 사유 기술**: 코드만이 아니라 임상적 맥락 설명
5. **기한 준수**: 90일 이내 반드시 제출
