# 약국 보험 업무 총괄

## 개요

약국의 보험 업무는 건강보험 청구, 본인부담금 수납, 급여/비급여 구분, DUR 점검, 삭감 대응 등 다양한 영역에 걸쳐 있다. 본 문서는 약국 보험 업무의 전체 흐름과 핵심 개념을 총괄 정리한다.

> 관련 문서: [[DUR_점검가이드]], [[청구_오류_방지]], [[보험-FAQ]]

---

## 건강보험 청구 흐름 (Flow)

```
처방전 접수 (의료기관 발행)
    ↓
[1] 처방전 확인
    - 환자 인적사항 (성명, 주민번호, 보험자격)
    - 처방의/의료기관 정보
    - 처방 내용 (약품명, 용량, 용법, 일수)
    - 처방전 유효기간 (발행일 포함 3일 → 공휴일 제외 시 연장)
    ↓
[2] 보험자격 확인
    - 건강보험 / 의료급여 / 산재 / 자동차보험 구분
    - 자격 상실 여부 확인 (건보 EDI 조회)
    - 타공단 부담 여부 (산재, 자동차)
    ↓
[3] DUR 점검
    - 병용금기 / 연령금기 / 임부금기 / 용량초과 / 투여기간 초과
    - 동일성분 중복투여
    - → 경고 발생 시 [[DUR_점검가이드]] 절차 따름
    ↓
[4] 조제
    - 정확한 약품 선택 (대체조제 시 환자 동의 + 의사 통보)
    - 조제 내역 기록
    ↓
[5] 복약지도
    - 용법/용량, 부작용, 보관, 상호작용 안내
    - 기록 작성 [[복약지도_기록]]
    ↓
[6] 수납
    - 본인부담금 수납
    - 영수증 발행
    ↓
[7] 청구 데이터 생성
    - 처방조제 내역 전산 입력
    - 청구 코드 확인 (약품코드, 조제료, 복약지도료 등)
    ↓
[8] 건강보험심사평가원(HIRA) 청구
    - 매월 청구 (익월 10일까지)
    - EDI 또는 청구포털 이용
    ↓
[9] 심사 결과 확인
    - 삭감 통보 시 이의신청 검토
    - [[청구_오류_방지]] 참고
    ↓
[10] 지급
    - 심사 완료 후 국민건강보험공단에서 지급
    - 보통 청구 익월 20일경
```

## 본인부담률

### 건강보험 (직장/지역)

| 구분 | 본인부담률 | 비고 |
|------|----------|------|
| 처방 조제 (일반) | **30%** | 가장 일반적 |
| 65세 이상 (처방전 1만5천원 이하) | **1,200원 정액** | 저소득 고령자 부담 경감 |
| 65세 이상 (처방전 1만5천원 초과) | **30%** | 일반과 동일 |

### 의료급여

| 구분 | 본인부담률 | 비고 |
|------|----------|------|
| 1종 | **무료 (0%)** | 국민기초생활수급자 등 |
| 2종 | **500원 정액** | |

### 기타

| 보험 유형 | 본인부담 | 비고 |
|----------|---------|------|
| 산업재해보상보험 | **0%** | 공단 전액 부담 |
| 자동차보험 | **0%** | 보험회사 청구 |
| 보훈 | 감면 적용 | 유공자 등급별 |

## 급여 / 비급여 구분

### 급여 의약품
- 건강보험 적용 → 공단 부담 + 본인부담
- 약가 기준: 건강보험 약가 고시 목록에 등재된 의약품
- 허가 범위 내 적응증 사용 시 급여

### 비급여 의약품
- 건강보험 미적용 → 환자 전액 부담

| 비급여 사유 | 예시 |
|-----------|------|
| 약가 미등재 | 일부 신약, 희귀의약품 |
| 허가 외 적응증(off-label) | 급여 불인정 |
| 미용/성형 목적 | 탈모약(일부), 비만약 |
| 건강기능식품/보조제 | 종합비타민, 유산균 |
| 예방 목적 (일부) | 일부 백신 |

### 급여 제한 항목 (삭감 위험)

| 항목 | 제한 기준 |
|------|---------|
| 투여 일수 | 외래 1회 처방 최대 일수 제한 (일반: 최대 90일, 마약류: 30일) |
| 1일 투여량 | 허가 용량 초과 시 삭감 |
| 적응증 | 허가 외 적응증 사용 시 급여 불인정 |
| 동일 성분 중복 | 동일 성분 다른 제형 중복 처방 |
| 식별 불가 | 약품 코드 오류, 제조사 불명 |

## 대체조제

### 대체조제 유형

| 유형 | 설명 | 절차 |
|------|------|------|
| 함량 변경 | 동일 성분, 다른 함량 (예: 500mg → 250mg x 2) | 환자 동의 + 의사 사후 통보 |
| 제형 변경 | 동일 성분, 다른 제형 (예: 정제 → 캡슐) | 환자 동의 + 의사 사후 통보 |
| 동일 성분 제조사 변경 (제네릭) | 오리지널 → 제네릭 또는 역 | 환자 동의 + 의사 사후 통보 |
| 성분 변경 | 다른 성분으로 변경 | **의사 사전 승인 필수** |

### 대체조제 기록

- 대체조제 사유
- 환자 동의 확인
- 의사 통보 내역
- 약품 변경 전/후 기록

## 약국 관련 주요 제도

### 1. DUR (Drug Utilization Review)

실시간 약물 안전성 점검 시스템. 처방 조제 시 자동 점검.

| 점검 항목 | 설명 |
|----------|------|
| 병용금기 | 함께 사용하면 안 되는 약물 조합 |
| 연령금기 | 특정 연령에서 사용 금지 약물 |
| 임부금기 | 임산부 사용 금지 약물 |
| 용량 | 1일 최대 투여량 초과 |
| 투여기간 | 최대 투여 일수 초과 |
| 동일성분 중복 | 타 기관 처방과 동일 성분 중복 |

> 상세: [[DUR_점검가이드]]

### 2. 의약품 실거래가 상한제

- 약국이 의약품을 상한가 이하로 구매 → 차익은 약국 수익
- 상한가 = 건보 약가. 실구매가가 상한가 미만이면 차익 발생

### 3. 약사법 관련 의무

| 의무 | 내용 |
|------|------|
| 처방전 보존 | **3년간 보존** |
| 조제 기록 | 조제 내역 3년간 보존 |
| 복약지도 | 모든 조제 시 의무 |
| 의약품 적정 보관 | 온도, 습도, 차광 관리 |
| 마약류 관리 | 별도 잠금장치 보관, 마약류 관리부 기록, 폐기 시 관할기관 입회 |

## 월간 보험 업무 달력

| 시기 | 업무 |
|------|------|
| 매일 | 처방전 접수, DUR 점검, 조제, 청구 데이터 입력 |
| 주간 | 미청구 건 확인, 반송 건 처리 |
| 매월 1-10일 | 전월 청구 데이터 제출 (HIRA) |
| 매월 중순 | 전전월 심사 결과 확인 |
| 매월 20일경 | 전전월 보험 급여 수령 |
| 분기별 | 삭감 내역 분석, 이의신청 검토 |
| 반기별 | 약가 고시 변경 확인, 코드 업데이트 |
