# 연령별 및 특수집단 약물 금기

## 개요

약물의 효과와 부작용은 환자의 연령 및 생리적 상태에 따라 크게 달라진다. 본 문서는 소아, 청소년, 고령자, 임부, 수유부 등 특수집단에서 주의 또는 금기되는 약물을 정리한다.

> 관련 문서: [[_상호작용_매트릭스]], [[처방검토_체크리스트]], [[복약지도-FAQ]]

## 1. 소아 (0~12세)

### 절대 금기 약물

| 약물/약물군 | 금기 연령 | 금기 사유 | 대체 약물 |
|------------|----------|----------|----------|
| 아스피린 | 18세 미만 (특히 12세 미만) | 라이 증후군(Reye's syndrome) — 급성 간부전 + 뇌병증 | 아세트아미노펜, 이부프로펜(6개월 이상) |
| 코데인 | 12세 미만 | CYP2D6 초고속대사자에서 모르핀 과량 생성 → 호흡억제, 사망 | 덱스트로메토르판 (적정 용량) |
| 테트라사이클린 | 8세 미만 | 영구치 착색(황갈색), 골 성장 억제 | 아목시실린, 세팔로스포린 |
| 퀴놀론계 항생제 | 18세 미만 (원칙적) | 관절 연골 손상 (동물실험 근거) | 아목시실린, 세팔로스포린 |
| 로페라마이드 | 2세 미만 | 장마비, 호흡억제 위험 | 경구수액보충(ORS) |
| 메토클로프라마이드 | 1세 미만 / 주의: 소아 전체 | 추체외로 증상(근긴장이상) 발현 빈도 높음 | 돔페리돈 (주의하여 사용) |

### 용량 주의 약물

| 약물 | 주의사항 | 용량 기준 |
|------|---------|----------|
| 아세트아미노펜 | 간독성 — 과량 투여 시 간부전 | 10-15mg/kg/회, 1일 최대 60mg/kg |
| 이부프로펜 | 6개월 미만 사용 금기 | 5-10mg/kg/회, 6-8시간 간격 |
| 항히스타민제 (1세대) | 과도한 진정, 호흡억제 | 체중 기반 용량 엄수, 2세 미만 주의 |
| 종합감기약 | 다성분 중복 위험 | 2세 미만 OTC 사용 금기 (미국 FDA 기준: 4세 미만) |

### 소아 투약 핵심 원칙

1. **체중 기반 용량 계산** 필수 (연령 기반 용량은 참고 수준)
2. **제형 선택**: 시럽, 산제, 츄어블정 우선 (정제/캡슐 삼킴 어려움)
3. **보호자 교육**: 계량 도구 사용법, 복용 간격, 보관법 안내
4. **OTC 종합감기약 주의**: 성분 중복 확인 필수

## 2. 청소년 (13~18세)

### 주의/금기 약물

| 약물/약물군 | 주의사항 | 비고 |
|------------|---------|------|
| 아스피린 | 라이 증후군 위험 (수두, 인플루엔자 시 특히 위험) | 해열 목적 사용 금지 |
| 이소트레티노인 (여성 청소년) | 강력한 기형유발성 — 임신 가능성 있는 여성 | 피임 필수, 임신검사 월 1회 |
| SSRIs/SNRIs | 18세 미만에서 자살 사고/행동 증가 위험 (FDA Black Box) | 투약 초기 및 용량 변경 시 면밀 모니터링 |
| 퀴놀론계 항생제 | 연골 손상 우려 (성장판 영향) | 원칙적 금기, 대안 없을 시 주의 사용 |
| 코데인 | 12~18세에서도 주의 (비만, 수면무호흡 동반 시 위험 증가) | 편도/아데노이드 수술 후 사용 금기 |

### 청소년 투약 핵심 원칙

1. 성인 용량으로의 전환 시기 주의 (체중 50kg 이상 시 성인 용량 고려)
2. 약물 오남용 가능성 주의 (코데인, 덱스트로메토르판 등)
3. 여성 청소년: 임신 가능성 항상 고려

## 3. 고령자 (65세 이상)

### Beers Criteria 기반 부적절 약물 (주요 항목)

| 약물/약물군 | 위험 | 대체 약물/조치 |
|------------|------|---------------|
| 벤조디아제핀 (디아제팜, 알프라졸람) | 인지기능 저하, 낙상, 골절, 섬망 | 비약물 요법 우선, 저용량 단기 사용 |
| 1세대 항히스타민제 (클로르페니라민, 디펜히드라민) | 항콜린 작용 — 인지저하, 변비, 요저류, 낙상 | 2세대 항히스타민제 (세티리진, 로라타딘) |
| 근이완제 (사이클로벤자프린) | 항콜린 작용, 과도한 진정 | 비약물 요법, 물리치료 |
| 장기 작용 설폰요소제 (글리벤클라마이드) | 저혈당 지속 위험 | 글리클라자이드, 글리메피리드 저용량 |
| NSAIDs (장기 사용) | 위장관 출혈, 신기능 악화, 심혈관 위험 | 아세트아미노펜, 국소 NSAIDs |
| 삼환계 항우울제 (아미트리프틸린) | 항콜린 작용, 기립성 저혈압, 낙상 | SSRIs (세르트랄린 등) |
| 메토클로프라마이드 | 추체외로 증상, 지발성 운동이상증 | 돔페리돈 (단기), 비약물 요법 |
| 디곡신 (고용량) | 독성 위험 증가 (신기능 저하) | 0.125mg/일 이하로 제한 |
| 알파차단제 (독사조신, 테라조신) — 항고혈압 목적 | 기립성 저혈압 → 낙상 | 다른 항고혈압제 사용 |

### 고령자 투약 핵심 원칙 ("Start Low, Go Slow")

1. **신기능 평가**: eGFR 기반 용량 조절 (혈청 크레아티닌만으로 판단 금지)
2. **간기능 저하**: CYP 대사 감소 → 약물 반감기 연장 고려
3. **다약제 복용(Polypharmacy)**: 5개 이상 약물 복용 시 상호작용 위험 급증 → 정기적 약물 재검토
4. **낙상 위험**: 진정 작용 약물, 기립성 저혈압 유발 약물 최소화
5. **탈수 취약**: 이뇨제, NSAIDs 주의
6. **복약 순응도**: 제형 단순화, 복약 달력/약상자 활용

> 참고: [[고혈압_복약가이드]], [[당뇨_복약가이드]]

## 4. 임부 (임신부)

### FDA 구 분류 기반 금기 약물 (현재는 PLLR로 전환)

| 약물/약물군 | 위험 시기 | 위험 내용 | 대체 약물 |
|------------|----------|----------|----------|
| 이소트레티노인 (비타민A 유도체) | 전 임신기간 | 심각한 기형유발 (심장, 두개안면, CNS) | 국소 치료, 임신 종료 후 사용 |
| ACE억제제/ARB | 2-3분기 특히 위험 | 태아 신부전, 양수과소, 폐저형성, 사망 | 메틸도파, 라베탈롤, 니페디핀 |
| 와파린 | 1분기 특히 위험 | 와파린 배아병증 (비골저형성, 점상 연골이형성) | 저분자량 헤파린(LMWH) |
| 메토트렉세이트 | 전 임신기간 | 유산, 기형유발 | 임신 전 3개월 중단 필수 |
| 발프로산 | 1분기 특히 위험 | 신경관 결손, 인지 발달 장애 | 라모트리진 (상대적 안전) |
| 스타틴 | 전 임신기간 | 콜레스테롤은 태아 발달에 필수 — 금기 | 임신 중 중단 |
| 미소프로스톨 | 전 임신기간 | 자궁수축 → 유산/조산 | 다른 위장보호제 |
| 테트라사이클린 | 2-3분기 | 태아 치아 착색, 골 성장 억제 | 아목시실린, 세팔로스포린 |
| NSAIDs | 3분기 (특히 32주 이후) | 동맥관 조기 폐쇄, 양수과소 | 아세트아미노펜 |

### 임부 투약 핵심 원칙

1. **약물 사용 최소화**: 비약물 요법 우선 고려
2. **위험-이익 분석**: 치료하지 않았을 때의 위험 vs 약물 위험 비교
3. **안전한 약물 우선**: 아세트아미노펜(해열진통), 아목시실린(항생제), 메틸도파(항고혈압)
4. **엽산 보충**: 임신 전부터 매일 400-800mcg 권고
5. **환자 불안 관리**: 근거 기반으로 설명, 불필요한 약물 중단 방지

## 5. 수유부

### 수유 중 금기/주의 약물

| 약물/약물군 | 위험도 | 모유 이행 및 영향 | 대체 약물 |
|------------|--------|-----------------|----------|
| 항암제 (메토트렉세이트, 사이클로포스파마이드) | 금기 | 세포독성 → 영아 골수억제, 면역억제 | 수유 중단 |
| 방사성 요오드 | 금기 | 영아 갑상선 손상 | 수유 일시 중단 (방사능 소실 확인 후 재개) |
| 에르고타민 | 금기 | 영아 구토, 설사, 경련 | 수마트립탄 (단회 투여 후 수유 가능) |
| 아미오다론 | 금기 | 긴 반감기, 영아 갑상선 기능 이상 | 수유 중단 또는 대체 항부정맥제 |
| 벤조디아제핀 (장기) | 주의 | 영아 진정, 체중 감소, 수유 곤란 | 최소 용량, 단기 사용 |
| 코데인 | 주의 | 초고속대사자 모체 → 모유 내 모르핀 축적 → 영아 호흡억제 | 아세트아미노펜, 이부프로펜 |
| 아스피린 (고용량) | 주의 | 영아 라이 증후군 위험, 출혈 | 이부프로펜, 아세트아미노펜 |

### 수유부에서 비교적 안전한 약물

| 용도 | 안전한 약물 |
|------|-----------|
| 해열/진통 | 아세트아미노펜, 이부프로펜 |
| 항생제 | 아목시실린, 세팔로스포린, 에리스로마이신 |
| 항히스타민 | 로라타딘, 세티리진 |
| 항고혈압 | 라베탈롤, 니페디핀, 에날라프릴 |
| 우울증 | 세르트랄린, 파록세틴 |
| 위장약 | 오메프라졸 (단기), 란소프라졸 |
| 천식 | 흡입 스테로이드, 살부타몰 |

### 수유부 투약 핵심 원칙

1. **수유 직후 복약**: 다음 수유까지 약물 농도 최소화
2. **단기 작용 약물 선호**: 장기 작용 약물은 모유 축적 우려
3. **국소 투여 우선**: 전신 흡수 최소화
4. **LactMed 데이터베이스 활용**: NIH의 수유 중 약물 안전성 DB 참고
5. **불필요한 수유 중단 방지**: 대부분의 약물은 수유 중 안전하게 사용 가능

## 연령/집단별 처방 검토 체크리스트 요약

```
[ ] 환자 연령 확인
[ ] 소아: 체중 기반 용량 계산 완료?
[ ] 고령자: Beers Criteria 해당 약물 없는지 확인?
[ ] 고령자: 신기능(eGFR) 확인 및 용량 조절?
[ ] 임부: 임신 주수 확인, 금기 약물 제외?
[ ] 수유부: 모유 이행 확인?
[ ] 다약제 복용 여부 확인?
```
