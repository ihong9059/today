# 음식-약물 상호작용

## 개요

음식과 약물 간의 상호작용은 약물의 흡수, 대사, 효과에 상당한 영향을 미칠 수 있다. 환자에게 복약지도 시 반드시 안내해야 할 주요 음식-약물 상호작용을 정리한다.

> 관련 문서: [[_상호작용_매트릭스]], [[연령별_금기]], [[복약지도-FAQ]]

---

## 1. 자몽 / 자몽주스

### 기전
- 소장 벽의 **CYP3A4** 효소를 비가역적으로 억제
- 경구 약물의 초회통과 대사(first-pass metabolism) 감소
- 약물의 생체이용률(혈중농도) 현저히 증가
- 효과는 자몽 섭취 후 **최대 72시간**까지 지속

### 영향받는 주요 약물

| 약물군 | 대표 약물 | 영향 | 위험도 |
|--------|----------|------|--------|
| 스타틴 | 심바스타틴, 아토르바스타틴 | 혈중농도 2-15배 증가 → 횡문근융해증 | **높음** |
| 칼슘채널차단제 | 펠로디핀, 니페디핀 | 혈중농도 증가 → 저혈압, 두통 | **높음** |
| 면역억제제 | 사이클로스포린, 타크로리무스 | 혈중농도 증가 → 독성 | **높음** |
| 항부정맥제 | 아미오다론 | 혈중농도 증가 → QT 연장 | **높음** |
| 벤조디아제핀 | 미다졸람, 트리아졸람 | 과도한 진정 | 중간 |
| 항히스타민 | 터페나딘 (사용 중단됨) | QT 연장 → 부정맥 | **높음** |

### 환자 교육 포인트
- 해당 약물 복용 중 자몽, 자몽주스, 포멜로 **완전 회피** 권고
- "조금만 먹어도 괜찮다"는 오해 교정 — 자몽 1개로도 영향 발생
- 로수바스타틴, 프라바스타틴은 CYP3A4 비의존적이므로 영향 적음
- 오렌지, 레몬 등 다른 감귤류는 영향 없음 (단, 세비야 오렌지 제외)

## 2. 우유 / 칼슘 함유 식품 / 유제품

### 기전
- 칼슘(Ca2+), 마그네슘(Mg2+), 알루미늄(Al3+) 등 다가 양이온과 **킬레이트(chelate)** 형성
- 불용성 복합체 생성 → 약물 흡수 현저히 감소

### 영향받는 주요 약물

| 약물군 | 대표 약물 | 흡수 감소율 | 복용 간격 권고 |
|--------|----------|-----------|--------------|
| 퀴놀론계 항생제 | 시프로플록사신, 레보플록사신 | 최대 90% | 2시간 전 또는 6시간 후 |
| 테트라사이클린 | 독시사이클린, 미노사이클린 | 최대 80% | 2시간 전 또는 3시간 후 |
| 갑상선호르몬 | 레보티록신 | 상당한 감소 | 복용 후 4시간 이상 간격 |
| 비스포스포네이트 | 알렌드로네이트 | 흡수 거의 차단 | 기상 직후 물로만 복용, 식사 30분 전 |
| 철분제 | 황산제일철 | 흡수 감소 | 2시간 간격 (비타민C와 함께 복용 시 흡수 증가) |

### 환자 교육 포인트
- "약은 물로 드세요" — 우유, 요구르트, 두유로 복용 금지
- 철분제는 **빈속에 복용**이 흡수 최적 (위장장애 시 식후 가능)
- 레보티록신은 **아침 기상 직후** 공복에 물로 복용 → 식사 30-60분 전

## 3. 알코올

### 기전
- **약역학적**: 중추신경 억제 작용 상가/상승
- **약동학적**: 급성 음주 → CYP2E1 억제(약물 대사 감소) / 만성 음주 → CYP2E1 유도(약물 대사 증가)
- **간독성**: 아세트아미노펜 + 알코올 → NAPQI(간독성 대사물) 증가

### 영향받는 주요 약물

| 약물군 | 대표 약물 | 상호작용 | 위험도 |
|--------|----------|---------|--------|
| 아세트아미노펜 | 타이레놀 등 | 간독성 대폭 증가 (만성 음주자에서 치료 용량에서도 간손상 가능) | **높음** |
| 벤조디아제핀 | 디아제팜, 알프라졸람 | 과도한 진정, 호흡억제, 사망 | **높음** |
| 항히스타민 (1세대) | 클로르페니라민 | 졸음, 어지러움 증가 | 중간 |
| 메트포르민 | 글루코파지 등 | 유산산증 위험 증가 | 중간 |
| 메트로니다졸 | 플라질 등 | 디설피람 유사 반응 (구역, 구토, 두통, 안면홍조) | **높음** |
| 설폰요소제 | 글리메피리드 등 | 저혈당 위험 증가 + 디설피람 유사 반응 (일부) | 중간 |
| NSAIDs | 이부프로펜, 나프록센 | 위장관 출혈 위험 증가 | 중간 |
| 와파린 | 쿠마딘 등 | 급성: 항응고 효과 증가 / 만성: 효과 감소 | **높음** |
| 항우울제 (삼환계, SSRI) | 아미트리프틸린 등 | 진정 증가, 인지기능 저하 | 중간 |
| 오피오이드 | 트라마돌, 코데인 | 호흡억제, 과도한 진정, 사망 | **높음** |

### 환자 교육 포인트
- **메트로니다졸**: 투약 중 및 투약 후 **48시간** 완전 금주
- **아세트아미노펜**: 만성 음주자(매일 3잔 이상)는 1일 2g 이하로 제한
- **수면제/항불안제**: 음주와 절대 병용 금지
- "약 먹는 날만 안 마시면 된다"는 오해 교정

## 4. 카페인 (커피, 녹차, 에너지 드링크)

### 기전
- 카페인은 CYP1A2에 의해 주로 대사됨
- CYP1A2 억제 약물과 병용 시 카페인 혈중농도 증가
- 약리학적 상호작용: CNS 자극, 이뇨 작용, 위산 분비 증가

### 주요 상호작용

| 약물 | 상호작용 | 조치 |
|------|---------|------|
| 퀴놀론 항생제 (시프로플록사신) | CYP1A2 억제 → 카페인 대사 감소 → 불면, 심계항진 | 투약 중 카페인 제한 |
| 테오필린 | 구조적 유사성. 카페인이 테오필린 대사 경쟁 → 독성 증가 | 카페인 섭취 최소화 |
| 클로자핀 | CYP1A2 기질. 카페인이 대사 경쟁 → 혈중농도 변동 | 카페인 섭취 일정하게 유지 |
| 철분제 | 카페인(탄닌)이 철분 흡수 방해 | 철분제와 1시간 이상 간격 |
| 비스포스포네이트 | 흡수 방해 | 물로만 복용 후 커피는 30분 이후 |
| 리튬 | 카페인의 이뇨 작용 → 리튬 배설 증가 → 리튬 농도 저하 | 카페인 섭취 급격한 변동 주의 |

### 환자 교육 포인트
- 철분제, 갑상선약 복용 시 커피는 **최소 1시간 후** 섭취
- 불면증 약물 복용 중 카페인 과다 섭취 → 약효 저하
- 카페인 급격한 중단/변경 시 리튬 혈중농도 변동 주의

## 5. 녹색 채소 (비타민K 함유 식품)

### 기전
- 비타민K는 응고인자(II, VII, IX, X) 합성에 필수
- 와파린은 비타민K 길항제 → 비타민K 섭취 변동 시 항응고 효과 불안정

### 비타민K 고함량 식품 (100g당)

| 식품 | 비타민K 함량 (mcg) | 주의 수준 |
|------|-------------------|----------|
| 케일 | 817 | **높음** |
| 시금치 | 483 | **높음** |
| 브로콜리 | 141 | 중간 |
| 양배추 | 76 | 중간 |
| 상추 (로메인) | 174 | 중간 |
| 아스파라거스 | 42 | 낮음 |
| 녹차 (분말) | 1,428 | **매우 높음** |
| 청국장/낫토 | 1,103 | **매우 높음** |
| 김 | 약 400 | **높음** |

### 환자 교육 포인트
- **"먹지 마세요"가 아니라 "일정하게 드세요"**
- 갑자기 채소를 많이 먹거나 안 먹으면 INR 변동 → 출혈/혈전 위험
- 녹즙 다이어트 시작/중단 시 반드시 의료진에게 알리기
- **낫토(청국장)**: 비타민K2 매우 고함량 → 와파린 복용 중 제한 권고

## 6. 치즈 및 발효식품 (티라민 함유)

### 기전
- 티라민(tyramine)은 교감신경 자극 아민
- MAO(모노아민 산화효소)에 의해 분해
- MAO억제제 복용 시 티라민 분해 불가 → 체내 축적 → **고혈압 위기(hypertensive crisis)**

### 티라민 고함량 식품

| 식품 | 티라민 함량 | 위험 수준 |
|------|-----------|----------|
| 숙성 치즈 (체다, 블루치즈) | 매우 높음 | **금기** |
| 된장, 간장, 청국장 | 높음 | **금기** |
| 젓갈류, 김치 (오래 숙성) | 높음 | **주의** |
| 훈제/건조 육류 (살라미, 소시지) | 높음 | **금기** |
| 맥주 (생맥주, 수제맥주) | 중간-높음 | **주의** |
| 적포도주 | 중간 | **주의** |
| 콩 발효식품 (두부유, 템페) | 중간 | **주의** |
| 바나나 (과숙) | 낮음-중간 | 주의 |

### 관련 약물
- **MAO억제제**: 페넬진, 트라닐시프로민, 셀레길린 (고용량), 리네졸리드(항생제이나 MAO 억제 작용)
- MAO억제제 중단 후에도 **최소 2주간** 티라민 식이 제한 유지

### 고혈압 위기 증상
- 극심한 두통 (후두부)
- 구역, 구토
- 발한, 심계항진
- 시야 장애
- → **응급 상황**: 즉시 응급실 방문 필요

### 환자 교육 포인트
- MAO억제제 복용 환자에게 **티라민 식이 목록** 서면 제공
- 한국 식문화 특성상 **된장, 간장, 청국장, 젓갈, 김치** 주의 강조
- 리네졸리드(항생제) 처방 시에도 동일 교육 필요

## 복약지도 시 음식 상호작용 핵심 요약표

| 음식/음료 | 주의 약물 | 핵심 메시지 |
|----------|----------|-----------|
| 자몽 | 스타틴, CCB, 면역억제제 | 완전 회피 |
| 우유/칼슘 | 항생제, 레보티록신, 철분 | 2-4시간 간격 |
| 알코올 | 아세트아미노펜, 수면제, 메트로니다졸 | 금주 또는 제한 |
| 커피/카페인 | 철분, 테오필린, 퀴놀론 | 1시간 이상 간격 |
| 녹색채소 | 와파린 | 일정량 유지 |
| 발효식품/치즈 | MAO억제제 | 금기 (고혈압 위기) |
