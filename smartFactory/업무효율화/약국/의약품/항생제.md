# 항생제 (항균제)

> 본 자료는 교육/시뮬레이션 목적입니다. 전문의약품(ETC)으로 반드시 처방전이 필요합니다.
> **항생제는 처방된 기간 동안 끝까지 복용하는 것이 매우 중요합니다.**

항생제는 세균 감염 치료에 사용되며, 바이러스 감염(감기, 독감)에는 효과가 없습니다.
부적절한 사용은 **항생제 내성**을 유발하므로, 올바른 복약지도가 필수적입니다.

---

## 항생제 복약지도 대원칙

1. **처방된 기간 끝까지 복용**: 증상이 좋아져도 임의 중단 금지 → 내성균 발생
2. **정확한 시간 간격**: 8시간 간격(1일 3회), 12시간 간격(1일 2회) 등 혈중농도 유지
3. **감기에는 항생제 불필요**: 감기는 바이러스 → [[감기약]] 참조
4. **남은 항생제 재사용 금지**: 이전 처방 항생제를 다른 증상에 사용하지 말 것
5. **부작용 모니터링**: 설사, 발진, 알레르기 반응 주의

## 1. 페니실린계

### 개요
- **작용기전**: 세균 세포벽 합성 억제 (PBP 결합)
- **살균성**: 살균적 (bactericidal)
- **스펙트럼**: 좁은 범위 → 베타락타마제 억제제 병합으로 확장

### 대표 약물

#### 아목시실린 (Amoxicillin)
- **상품명**: 아목시실린캡슐, 아목시실린시럽(소아)
- **용량(성인)**: 1회 250~500mg, 8시간 간격 (1일 3회)
- **용량(소아)**: 20~40mg/kg/일, 8시간 간격
- **적응증**: 중이염, 부비동염, 요로감염, H.pylori 제균요법
- **특징**: 경구 흡수 우수, 식사 영향 적음

#### 아목시실린/클라불란산 (Amoxicillin/Clavulanate)
- **상품명**: 오그멘틴, 크라목스
- **용량**: 625mg(아목시실린 500mg + 클라불란산 125mg), 8시간 간격
- **용량(소아)**: 아목시실린 기준 25~45mg/kg/일
- **적응증**: 중이염, 부비동염, 하기도 감염, 피부연조직 감염, 동물 교상
- **특징**: 클라불란산이 베타락타마제 분해 방지 → 스펙트럼 확장
- **부작용**: 설사 빈도 높음(클라불란산), 간기능 이상(드물지만 보고)

### 페니실린계 공통 주의사항
- **알레르기**: 페니실린 알레르기 이력 확인 필수 (발진~아나필락시스)
  - 경미한 발진 이력: 세팔로스포린 사용 가능(교차반응 1~2%)
  - 아나필락시스 이력: 세팔로스포린도 회피, 마크로라이드/퀴놀론 대체
- **전염성 단핵구증**: 아목시실린 투여 시 특이적 발진 발생(90%) → 감별 필요
- **신기능 저하**: 감량 또는 간격 연장

### 페니실린계 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 메토트렉세이트 | 주의 | 신배설 경쟁 → 메토트렉세이트 독성 증가 |
| 와파린 | 경고 | INR 상승(장내 비타민K 생산균 감소) |
| 프로베네시드 | 참고 | 아목시실린 배설 억제 → 혈중농도 상승(의도적 병용도 가능) |
| 경구피임약 | 참고 | 효과 감소 논란(증거 불충분하나 안내 권장) |
| 알로퓨리놀 | 경고 | 아목시실린 + 알로퓨리놀 → 발진 빈도 증가 |

## 2. 세팔로스포린계

### 개요
- **작용기전**: 세포벽 합성 억제 (페니실린과 동일 메커니즘)
- **분류**: 1세대(좁은 범위) → 2세대 → 3세대(넓은 범위, 그람음성균 강화)
- **교차반응**: 페니실린 알레르기와 교차반응 약 1~2%

### 대표 약물

#### 세파클러 (Cefaclor) - 2세대
- **상품명**: 세파클러캡슐, 세파클러시럽
- **용량(성인)**: 1회 250mg, 8시간 간격
- **용량(소아)**: 20~40mg/kg/일, 8시간 간격
- **적응증**: 중이염, 상기도 감염, 요로감염
- **특징**: 국내 경구 세팔로스포린 중 가장 많이 처방

#### 세프록심 (Cefuroxime) - 2세대
- **상품명**: 세프록심정, 지나셋
- **용량**: 1회 250~500mg, 12시간 간격
- **용법**: **식후 복용**(흡수 증가)
- **적응증**: 상/하기도 감염, 요로감염, 라임병

#### 세프디니르 (Cefdinir) - 3세대
- **상품명**: 옴니세프
- **용량(성인)**: 1회 300mg, 12시간 간격 또는 600mg 1일 1회
- **용량(소아)**: 7mg/kg, 12시간 간격
- **주의**: 철분제와 동시 복용 시 흡수 감소 + 적갈색 변(무해하나 환자 불안)

#### 세프포독심 (Cefpodoxime) - 3세대
- **상품명**: 바난정
- **용량**: 1회 100~200mg, 12시간 간격
- **용법**: 식후 복용(흡수 증가)

### 세팔로스포린계 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 와파린 | 경고 | INR 상승 주의 |
| 프로베네시드 | 참고 | 배설 억제 → 혈중농도 상승 |
| 철분제(세프디니르) | 경고 | 흡수 감소 + 적갈색 변 → 2시간 간격 |
| 제산제(세프포독심) | 경고 | 흡수 감소 → 2시간 간격 |
| 알코올(일부 세파계) | 주의 | 디설피람 유사 반응(세포테탄, 세파만돌 등 - 경구용은 드묾) |

## 3. 퀴놀론계 (플루오로퀴놀론)

### 개요
- **작용기전**: DNA 자이레이스/토포이소머라제 IV 억제 → DNA 복제 차단
- **살균성**: 살균적, 농도 의존적 살균
- **스펙트럼**: 광범위 (그람음성+일부 그람양성+비정형 세균)
- **주의**: FDA 블랙박스 경고 대상 → 대체약이 있으면 사용 자제

### 대표 약물

#### 레보플록사신 (Levofloxacin)
- **상품명**: 크라비트
- **용량**: 1일 1회 500~750mg
- **적응증**: 지역사회 폐렴, 복잡성 요로감염, 부비동염(대체약 없을 때)
- **특징**: 호흡기 퀴놀론, 1일 1회 편의성

#### 시프로플록사신 (Ciprofloxacin)
- **상품명**: 시프로바이
- **용량**: 1회 250~750mg, 12시간 간격
- **적응증**: 요로감염, 위장관 감염, 골수염
- **특징**: 녹농균(Pseudomonas)에 가장 강력

#### 목시플록사신 (Moxifloxacin)
- **상품명**: 아벨록스
- **용량**: 1일 1회 400mg
- **적응증**: 지역사회 폐렴, 부비동염
- **주의**: QT 연장 위험 가장 높음, 신장 조절 불필요

### 퀴놀론계 공통 부작용/경고 (FDA 블랙박스)
| 부작용 | 내용 | 대처 |
|--------|------|------|
| **힘줄염/힘줄파열** | 아킬레스건 주, 고령자/스테로이드 병용 시 위험 증가 | 통증 시 즉시 중단, 운동 자제 |
| **말초신경병증** | 영구적 손상 가능 | 저림/통증 시 즉시 중단 |
| **중추신경계** | 경련, 혼돈, 환각, 불면 | 경련 이력자 주의 |
| **QT 연장** | 부정맥(TdP) 위험 | QT 연장 약물 병용 회피 |
| **대동맥류/박리** | 매우 드묾, 치명적 | 고령자/마르판/대동맥 질환 주의 |
| **저혈당** | 당뇨약 병용 시 심각한 저혈당 | 혈당 모니터링 강화 |

### 퀴놀론계 절대 금기
- **소아(만 18세 미만)**: 관절 연골 손상 (일부 예외: 탄저병 등)
- **임산부/수유부**: 태아/영아 연골 독성
- **QT 연장 환자**: 부정맥 위험
- **힘줄 질환 이력**: 파열 위험

### 퀴놀론계 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 제산제/칼슘/철분/마그네슘 | 금기급 | 킬레이트 형성 → 흡수 80% 이상 감소 → **2시간 전 또는 6시간 후 복용** |
| 와파린 | 주의 | INR 상승 |
| NSAIDs | 경고 | 경련 위험 증가 |
| 테오필린 | 주의 | 테오필린 혈중농도 상승(시프로 > 레보) |
| QT연장 약물(항부정맥제 등) | 금기 | QT 연장 상승작용 |
| 당뇨약(SU, 인슐린) | 경고 | 심각한 저혈당/고혈당 |
| 스테로이드 | 경고 | 힘줄파열 위험 증가 |
| 유제품(칼슘) | 경고 | 킬레이트 → 시프로플록사신 흡수 감소(레보는 영향 적음) |

## 4. 마크로라이드계

### 개요
- **작용기전**: 50S 리보솜 결합 → 단백질 합성 억제
- **정균성/살균성**: 농도에 따라 정균~살균
- **스펙트럼**: 그람양성균 + 비정형 세균(마이코플라스마, 클라미디아, 레지오넬라)
- **특징**: 페니실린 알레르기 환자의 주요 대체약

### 대표 약물

#### 아지스로마이신 (Azithromycin)
- **상품명**: 지스로맥스
- **용량**: 1일 1회 500mg x 3일 또는 500mg(1일차) → 250mg x 4일
- **용법**: 식전 1시간 또는 식후 2시간(공복이 흡수 좋음, 정제는 식사 무관)
- **적응증**: 상기도 감염, 폐렴, 성매개감염(클라미디아), 중이염
- **특징**:
  - 조직 내 농도 높고 반감기 68시간 → 3일 복용으로 5~7일 효과
  - CYP3A4 억제 약함(클래리스로마이신 대비 상호작용 적음)

#### 클래리스로마이신 (Clarithromycin)
- **상품명**: 클래리시드
- **용량**: 1회 250~500mg, 12시간 간격, 7~14일
- **용법**: 식사와 관계없이(서방정은 식후)
- **적응증**: 상기도/하기도 감염, H.pylori 제균요법, 비결핵성 마이코박테리아
- **특징**:
  - **CYP3A4 강력 억제** → 약물 상호작용 매우 많음
  - 금속성 맛(dysgeusia) 흔함

#### 에리스로마이신 (Erythromycin)
- **상품명**: 에리스로마이신정
- **용량**: 1회 250~500mg, 6시간 간격
- **특징**: 초기 마크로라이드, 위장장애 빈번, 위장운동 촉진 효과
- **현재**: 아지스로/클래리스로 대체로 사용 감소

### 마크로라이드계 공통 부작용
| 부작용 | 빈도 | 비고 |
|--------|------|------|
| 위장장애(오심, 구토, 복통, 설사) | 흔함 | 에리스로 > 클래리 > 아지스로 |
| QT 연장 | 드묾 | 아지스로마이신도 FDA 경고 |
| 간독성 | 드묾 | 클래리스로마이신 주의 |
| 미각 이상 | 클래리 흔함 | 금속성 맛 |
| 이독성(청력 손상) | 고용량 시 | 가역적 |

### 마크로라이드계 상호작용 (특히 클래리스로마이신)
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 스타틴(심바/로바/아토르바스타틴) | 금기/주의 | CYP3A4 억제 → 횡문근융해증 → 스타틴 일시 중단 |
| 콜히친 | 금기(신/간장애 시) | 콜히친 독성(치명적 가능) |
| 와파린 | 주의 | INR 상승 |
| 디곡신 | 주의 | 디곡신 혈중농도 상승 |
| 에르고타민 | 금기 | 에르고티즘(말초혈관 허혈) |
| 카바마제핀 | 주의 | 카바마제핀 독성 |
| 벤조디아제핀(미다졸람) | 주의 | 과도한 진정 |
| CCB(암로디핀, 딜티아젬) | 경고 | 저혈압, 신부전 |
| QT연장 약물 | 주의 | QT 연장 상승작용 |

> **아지스로마이신은 클래리스로마이신보다 CYP3A4 억제가 약해서 상호작용이 훨씬 적음**

## 복약지도 핵심 포인트

1. **끝까지 복용**: "증상이 나아져도 처방된 날짜까지 드세요" - 가장 중요한 안내
2. **정확한 간격**: "8시간마다" = 아침-점심-저녁이 아닌 진짜 8시간 간격
3. **제산제/유제품 간격**: 퀴놀론 복용 시 제산제/칼슘/철분과 2시간 이상 간격
4. **알레르기 확인**: "이전에 항생제 드시고 발진이나 부어오른 적 있으세요?"
5. **설사 주의**: 항생제 설사 → 유산균(프로바이오틱스) 병용 가능(항생제와 2시간 간격)
6. **클래리스로마이신 + 스타틴**: 반드시 확인, 필요시 스타틴 일시 중단
7. **소아/임부 퀴놀론 금기**: 대체 항생제 확인
8. **감기에 항생제 요청**: "감기는 바이러스이므로 항생제가 효과 없습니다" → [[감기약]] 안내
9. **보관**: 시럽제는 냉장보관, 유효기간 확인(조제 후 14일 등)
