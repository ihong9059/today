# 해열진통제

> 본 자료는 교육/시뮬레이션 목적입니다. 실제 복약지도는 약사의 전문적 판단에 따릅니다.

해열진통제는 약국에서 가장 빈번하게 상담이 이루어지는 약효군입니다.
크게 **아세트아미노펜 계열**과 **NSAIDs(비스테로이드성 소염진통제) 계열**로 구분합니다.

---

## 1. 아세트아미노펜 (Acetaminophen)

### 기본 정보
- **대표 상품명**: 타이레놀, 써스데이, 게보린(복합)
- **분류**: OTC (일반의약품)
- **약효**: 해열, 진통 (소염 효과 없음)
- **작용기전**: 중추신경계 COX 억제 (말초 소염 작용 미미)

### 용량 및 용법
| 대상 | 1회 용량 | 투여 간격 | 1일 최대 용량 |
|------|----------|-----------|---------------|
| 성인(만 12세 이상) | 500~1000mg | 4~6시간 | 4000mg (간질환자 2000mg) |
| 소아(만 6~11세) | 체중 kg x 10~15mg | 4~6시간 | 체중 kg x 60mg |
| 소아(만 2~5세) | 체중 kg x 10~15mg | 4~6시간 | 체중 kg x 60mg |
| 영아(6개월~2세) | 체중 kg x 10~15mg | 4~6시간 | 의사 지시 |

### 금기 및 주의사항
- **절대 금기**: 중증 간장애, 아세트아미노펜 과민반응
- **상대 금기/주의**:
  - 만성 알코올 사용자 (1일 3잔 이상): 간독성 위험 증가 → 1일 2000mg 이하
  - 간질환(간경변 등): 감량 필요
  - 영양불량/탈수: 글루타치온 고갈로 간독성 위험 증가
  - Gilbert 증후군: 주의 사용

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 와파린 | 경고 | 1일 2g 이상 지속 복용 시 INR 상승 |
| 카바마제핀 | 경고 | CYP 유도로 간독성 대사물 증가 |
| 이소니아지드 | 주의 | 간독성 상승 |
| 알코올 | 주의 | 간독성 위험 증가 |
| 다른 아세트아미노펜 함유 제제 | 금기 | 중복 투여로 과량 위험 ([[감기약]] 내 함유 확인) |

### 특수 환자군
- **임산부**: 전 임신기간 사용 가능 (1차 선택 해열진통제)
- **수유부**: 안전 (모유 이행 소량)
- **소아**: 체중 기반 용량, 소아용 시럽/좌약 가능
- **고령자**: 간기능 저하 고려, 필요 시 감량

### 과량 투여 시 대처
- 150mg/kg 이상 또는 7.5g 이상 섭취 시 응급
- **해독제**: N-아세틸시스테인(NAC)
- 증상: 초기 24시간 무증상 가능 → 이후 간부전 진행

## 2. 이부프로펜 (Ibuprofen)

### 기본 정보
- **대표 상품명**: 애드빌, 부루펜, 이지엔6
- **분류**: OTC
- **약효**: 해열, 진통, 소염
- **작용기전**: COX-1/COX-2 비선택적 억제

### 용량 및 용법
| 대상 | 1회 용량 | 투여 간격 | 1일 최대 용량 |
|------|----------|-----------|---------------|
| 성인 | 200~400mg | 6~8시간 | 1200mg(OTC) / 2400mg(처방) |
| 소아(6개월 이상) | 5~10mg/kg | 6~8시간 | 40mg/kg |

### 금기 및 주의사항
- **절대 금기**:
  - NSAIDs 과민반응 (아스피린 천식 포함)
  - 활동성 소화성 궤양/위장관 출혈
  - 중증 심부전(NYHA IV)
  - 임신 제3삼분기(28주 이후)
  - 관상동맥 우회술(CABG) 전후
- **주의**:
  - 위장장애 이력 → 식후 복용, PPI 병용 검토
  - 신장기능 저하(eGFR <30 금기)
  - 고혈압 → 혈압 상승 가능
  - 심혈관 질환 → 장기 사용 시 위험 증가
  - 탈수 상태 → 급성 신부전 위험

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 와파린/항응고제 | 주의 | 출혈 위험 증가 |
| 아스피린(저용량 항혈전) | 경고 | 아스피린의 항혈소판 효과 감소 → 아스피린 먼저 복용 후 30분 이후 이부프로펜 |
| ACE억제제/ARB | 경고 | 항고혈압 효과 감소, 신기능 저하 |
| 이뇨제 | 경고 | 이뇨 효과 감소, 신기능 저하 |
| 리튬 | 주의 | 리튬 혈중농도 상승 |
| 메토트렉세이트 | 주의 | 메토트렉세이트 독성 증가 |
| SSRI | 경고 | 위장관 출혈 위험 증가 |

### 특수 환자군
- **임산부**: 제1~2삼분기 단기 사용 가능(2차 선택), 제3삼분기 금기(동맥관 조기폐쇄)
- **수유부**: 단기 사용 가능 (모유 이행 극소량)
- **소아**: 6개월 이상, 체중 기반 용량
- **고령자**: 위장출혈/신장 위험 증가, 가능한 단기 저용량

## 3. 나프록센 (Naproxen)

### 기본 정보
- **대표 상품명**: 낙센, 탁센, 나프록센정
- **분류**: OTC(저용량) / ETC(고용량)
- **약효**: 해열, 진통, 소염
- **특징**: 반감기 12~17시간으로 1일 2회 복용 가능 (이부프로펜 대비 편의성)

### 용량 및 용법
| 대상 | 1회 용량 | 투여 간격 | 1일 최대 용량 |
|------|----------|-----------|---------------|
| 성인 | 250~500mg | 12시간 | 1000mg(OTC) / 1250mg(처방) |
| 소아(만 2세 이상) | 5~7mg/kg | 8~12시간 | 의사 지시 |

### 금기 및 주의사항
- NSAIDs 공통 금기사항 적용 (이부프로펜과 동일)
- 심혈관 위험: NSAIDs 중 상대적으로 낮은 심혈관 위험 보고
- 위장관 위험: 이부프로펜보다 다소 높음 (긴 반감기 영향)

### 상호작용
- 이부프로펜과 유사한 상호작용 프로파일
- 추가: 메토트렉세이트와 병용 시 독성 위험이 이부프로펜보다 높음 (긴 반감기)
- 저용량 아스피린과의 상호작용: 이부프로펜보다 적음

### 특수 환자군
- **임산부**: 이부프로펜과 동일 (제3삼분기 금기)
- **고령자**: 긴 반감기로 축적 주의

## 4. 아스피린 (Aspirin / 아세틸살리실산)

### 기본 정보
- **대표 상품명**: 바이엘아스피린, 아스피린프로텍트, 아스피린정
- **분류**: OTC
- **약효**: 해열, 진통, 소염, 항혈소판(저용량)
- **작용기전**: COX-1 비가역적 억제 (혈소판 수명 동안 지속)

### 용량 및 용법
| 용도 | 용량 | 투여법 |
|------|------|--------|
| 해열/진통 | 500~1000mg, 4~6시간 간격 | 1일 최대 4000mg |
| 항혈소판(심뇌혈관 예방) | 75~100mg, 1일 1회 | 장기 복용, 장용코팅 권장 |
| 급성 심근경색 응급 | 150~300mg | 씹어서 복용 |

### 금기 및 주의사항
- **절대 금기**:
  - 만 18세 이하 바이러스 감염 시 (**라이 증후군** 위험 - 뇌병증+간부전)
  - 활동성 소화성 궤양
  - 출혈성 질환
  - 아스피린 천식/과민반응
  - 임신 제3삼분기
  - 메토트렉세이트 고용량(>15mg/주) 병용
- **주의**:
  - 수술 전 7일 이상 중단 (항혈소판 효과)
  - 통풍: 저용량에서 요산 배설 감소
  - 고령자: 위장출혈 위험 증가

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 와파린 | 금기 | 출혈 위험 극대화 |
| 메토트렉세이트(고용량) | 금기 | MTX 배설 억제 → 독성 |
| 이부프로펜 | 경고 | 아스피린 항혈소판 효과 방해 |
| ACE억제제/ARB | 경고 | 항고혈압 효과 감소 |
| SSRI | 경고 | 위장관 출혈 위험 증가 |
| 발프로산 | 주의 | 발프로산 유리형 증가 |
| 알코올 | 주의 | 위장출혈 위험 증가 |

### 특수 환자군
- **임산부**: 저용량 항혈소판(75~100mg)은 전자간증 예방 목적으로 처방 가능, 진통 목적 사용 지양
- **수유부**: 고용량 회피, 저용량 사용 가능
- **소아**: **만 18세 이하 금기** (라이 증후군) - 대신 아세트아미노펜 또는 이부프로펜 사용
- **고령자**: 항혈소판 목적 저용량 사용 흔함, 위장보호제(PPI) 병용 권장

## 해열진통제 선택 가이드

### 증상별 1차 선택
| 증상 | 1차 선택 | 2차 선택 | 비고 |
|------|----------|----------|------|
| 단순 두통/치통 | 아세트아미노펜 | 이부프로펜 | 위장장애 적은 순 |
| 생리통 | 이부프로펜 | 나프록센 | 소염 효과 필요 |
| 근골격계 통증 | 이부프로펜/나프록센 | 아세트아미노펜 | 소염 필요 |
| 발열(감기) | 아세트아미노펜 | 이부프로펜 | |
| 편두통 | 이부프로펜 400mg | 아세트아미노펜 1000mg | 조기 복용 중요 |

### 환자 특성별 선택
| 환자 특성 | 권장 | 회피 | 이유 |
|-----------|------|------|------|
| 임산부 | 아세트아미노펜 | NSAIDs(특히 28주 이후) | 동맥관 조기폐쇄 |
| 소아(18세 미만) | 아세트아미노펜, 이부프로펜 | 아스피린 | 라이 증후군 |
| 위궤양 이력 | 아세트아미노펜 | NSAIDs | 위장출혈 |
| 간질환 | 이부프로펜(단기) | 아세트아미노펜(고용량) | 간독성 |
| 신장질환 | 아세트아미노펜 | NSAIDs | 신독성 |
| 와파린 복용 중 | 아세트아미노펜(저용량) | 아스피린, NSAIDs | 출혈 위험 |
| 천식(아스피린 유발) | 아세트아미노펜 | 모든 NSAIDs | 교차반응 |
| 고혈압 | 아세트아미노펜 | NSAIDs(장기) | 혈압 상승 |

## 복약지도 핵심 포인트

1. **중복 투여 주의**: [[감기약]]에 아세트아미노펜이 포함되어 있는지 반드시 확인
2. **공복/식후**: 아세트아미노펜은 공복 가능, NSAIDs는 식후 권장
3. **음주**: 아세트아미노펜+알코올 = 간독성, NSAIDs+알코올 = 위장출혈
4. **복용 기간**: OTC 해열진통제는 3일(해열) / 5일(진통) 초과 시 의사 상담
5. **소아 발열**: 해열제 교대 투여(아세트아미노펜↔이부프로펜) 가능하나, 혼동 위험 안내
