# 당뇨약 (경구혈당강하제)

> 본 자료는 교육/시뮬레이션 목적입니다. 전문의약품(ETC)으로 반드시 처방전이 필요합니다.

제2형 당뇨병 치료에 사용되는 경구혈당강하제를 약효군별로 정리합니다.
제1형 당뇨병은 인슐린 치료가 필수이며, 여기서 다루지 않습니다.

---

## 1. 비구아니드 (메트포르민)

### 개요
- **대표 약물**: 메트포르민 (Metformin)
- **상품명**: 글루코파지, 글루코파지XR(서방형), 다이아벡스
- **작용기전**: 간 포도당 생성 억제, 말초 인슐린 감수성 개선
- **위치**: 제2형 당뇨병 1차 치료제 (모든 가이드라인)

### 용량 및 용법
| 제형 | 시작 용량 | 유지 용량 | 최대 용량 | 복용법 |
|------|-----------|-----------|-----------|--------|
| 속방정 | 500mg 1일 1~2회 | 500~1000mg 1일 2회 | 2550mg/일 | 식사와 함께 (위장장애 감소) |
| 서방정(XR) | 500mg 1일 1회 | 1000~2000mg 1일 1회 | 2000mg/일 | 저녁 식사와 함께 |

### 장점
- 체중 증가 없음 (오히려 약간 감소)
- 저혈당 위험 매우 낮음 (단독 사용 시)
- 심혈관 보호 효과 (UKPDS 연구)
- 저렴한 가격
- 오랜 사용 경험

### 부작용
| 부작용 | 빈도 | 대처 |
|--------|------|------|
| 위장장애(설사, 복통, 오심) | 20~30% | 저용량 시작 후 점진적 증량, 식사와 함께, 서방정 전환 |
| 유산산증 | 매우 드묾(치명적) | 신기능 확인 필수, 위험인자 회피 |
| 비타민 B12 결핍 | 장기복용 시 5~10% | 정기 검사, 보충 |
| 금속성 맛 | 드묾 | 자연 호전 |

### 금기 및 주의
- **절대 금기**:
  - eGFR <30 mL/min (중증 신부전)
  - 급성 대사성 산증 (당뇨병성 케톤산증, 유산산증)
  - 중증 간부전
- **주의/일시 중단**:
  - eGFR 30~45: 감량(최대 1000mg/일), 신기능 3개월마다 모니터링
  - **조영제 검사**: 검사 당일 및 48시간 후까지 중단 → 신기능 확인 후 재개
  - 수술 전: 수술 당일 중단
  - 급성 질환(탈수, 감염, 쇼크): 일시 중단
  - 과도한 음주: 유산산증 위험 증가

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 요오드화 조영제 | 주의 | 유산산증 위험 → 48시간 중단 |
| 알코올 | 주의 | 유산산증 위험 증가, 저혈당 |
| 시메티딘 | 경고 | 메트포르민 신배설 억제 → 혈중농도 상승 |
| 토피라메이트 | 주의 | 대사성 산증 위험 증가 |
| 이뇨제 | 참고 | 탈수 시 유산산증 위험 |
| 스테로이드 | 참고 | 혈당 상승으로 용량 조절 필요 |

## 2. 설포닐우레아 (SU)

### 개요
- **작용기전**: 췌장 베타세포 K-ATP 채널 차단 → 인슐린 분비 촉진
- **특징**: 강력한 혈당 강하, 저혈당 위험, 체중 증가

### 대표 약물

#### 글리메피리드 (Glimepiride)
- **상품명**: 아마릴
- **용량**: 1mg → 2mg → 4mg (최대 8mg)
- **용법**: 1일 1회, 아침 식사 시 또는 직전
- **특징**: 3세대 SU, 1일 1회 편의성, 심혈관 안전성 양호

#### 글리클라지드 (Gliclazide)
- **상품명**: 다이아미크론MR(서방형)
- **용량**: 30mg → 60mg → 120mg
- **용법**: 1일 1회, 아침 식사 시
- **특징**: ADVANCE 연구 - 신장 보호 효과, 저혈당 위험 SU 중 가장 낮음

#### 글리벤클라미드 (Glibenclamide/Glyburide)
- **상품명**: 다오닐
- **용량**: 2.5mg → 5mg
- **용법**: 1일 1~2회
- **주의**: 저혈당 위험 가장 높음, 고령자에서 사용 지양, WHO 필수의약품이나 신규 처방 감소 추세

### SU 공통 주의사항
- **저혈당**: 가장 중요한 부작용
  - 위험 증가 인자: 고령, 신부전, 간부전, 불규칙한 식사, 알코올, 과도한 운동
  - 환자 교육: 저혈당 증상(떨림, 식은땀, 어지러움) 인지, 포도당/사탕 항시 소지
- **체중 증가**: 인슐린 분비 촉진 → 2~4kg 증가 흔함
- **식사 필수**: 식사를 거르면 저혈당 위험 → 식사와 함께 복용

### SU 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 아졸계 항진균제(플루코나졸) | 주의 | SU 대사 억제 → 저혈당 |
| 와파린 | 경고 | 상호 작용으로 효과 변동 |
| 베타차단제 | 경고 | 저혈당 증상 은폐(떨림, 빈맥 마스킹) |
| 알코올 | 주의 | 저혈당 위험 증가 + 안면홍조(disulfiram 유사 반응) |
| 퀴놀론 항생제 | 주의 | 혈당 변동(저혈당/고혈당) |
| 스테로이드 | 참고 | 혈당 상승 → 용량 조절 |

## 3. DPP-4 억제제 (글립틴)

### 개요
- **작용기전**: DPP-4 효소 억제 → 인크레틴(GLP-1, GIP) 분해 억제 → 혈당 의존적 인슐린 분비 촉진
- **특징**: 저혈당 위험 매우 낮음, 체중 중립, 내약성 우수

### 대표 약물

#### 시타글립틴 (Sitagliptin)
- **상품명**: 자누비아
- **용량**: 100mg 1일 1회
- **신장 조절**: eGFR 30~50 → 50mg, eGFR <30 → 25mg
- **특징**: 최초의 DPP-4 억제제, 가장 많은 사용 경험

#### 빌다글립틴 (Vildagliptin)
- **상품명**: 가브스
- **용량**: 50mg 1일 2회
- **주의**: 간기능 검사 권장(간독성 보고)
- **신장 조절**: eGFR <50 → 50mg 1일 1회

#### 리나글립틴 (Linagliptin)
- **상품명**: 트라젠타
- **용량**: 5mg 1일 1회
- **특징**: **신장 조절 불필요**(담즙 배설) → 신기능 저하 환자에 유리
- **대사**: CYP 비의존적

#### 삭사글립틴 (Saxagliptin)
- **상품명**: 온글라이자
- **용량**: 5mg 1일 1회
- **신장 조절**: eGFR <50 → 2.5mg
- **주의**: SAVOR-TIMI 53 연구에서 심부전 입원 증가 → 심부전 환자 주의

### DPP-4 억제제 공통 주의사항
- 비교적 안전한 약물군
- **췌장염**: 매우 드물지만 보고됨 → 심한 복통 시 즉시 중단
- **관절통**: 드물게 보고, 중단 시 호전
- **수포성 유천포창**: 매우 드묾

### DPP-4 억제제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 디곡신 | 참고 | 시타글립틴: 디곡신 농도 약간 상승 |
| 리팜핀 | 경고 | 리나글립틴 효과 감소 (P-gp 유도) |
| 설포닐우레아 | 참고 | 병용 시 SU 감량 필요 (저혈당 방지) |
| 인슐린 | 참고 | 병용 시 인슐린 감량 고려 |

## 4. SGLT2 억제제 (글리플로진)

### 개요
- **작용기전**: 신장 근위세뇨관 SGLT2 차단 → 포도당 재흡수 억제 → 당뇨(소변으로 당 배출)
- **특징**: 인슐린 비의존적 작용, 체중 감소, 혈압 감소, 심혈관/신장 보호 효과

### 대표 약물

#### 다파글리플로진 (Dapagliflozin)
- **상품명**: 포시가
- **용량**: 10mg 1일 1회
- **용법**: 아침, 식사와 관계없이
- **특징**: DAPA-HF 연구 - 심부전(당뇨 유무 무관) 사망률 감소 → 심부전 적응증 추가
- **신장**: eGFR <25 시 혈당강하 목적 시작 금지 (심부전/CKD 적응증은 별도)

#### 엠파글리플로진 (Empagliflozin)
- **상품명**: 자디앙
- **용량**: 10mg → 25mg, 1일 1회
- **특징**: EMPA-REG OUTCOME - 심혈관 사망 38% 감소 (획기적 결과)
- **신장**: eGFR <20 시 시작 금지

#### 에르투글리플로진 (Ertugliflozin)
- **상품명**: 스테글라트로
- **용량**: 5mg → 15mg, 1일 1회

### SGLT2 억제제 공통 부작용
| 부작용 | 빈도 | 대처 |
|--------|------|------|
| 비뇨생식기 감염(칸디다증) | 5~10% | 개인위생 교육, 항진균제, 여성에서 더 흔함 |
| 요로감염 | 흔함 | 수분 섭취 격려, 증상 시 항생제 |
| 정상혈당 케톤산증(euDKA) | 드묾(치명적 가능) | 수술/금식/탈수 시 중단, 증상 교육 |
| 체액 감소/탈수/기립성 저혈압 | 흔함 | 이뇨제 병용 주의, 고령자 탈수 주의 |
| 하지 절단(카나글리플로진) | 드묾 | 말초혈관질환 환자 주의 (CANVAS 연구) |

### SGLT2 억제제 공통 주의사항
- **수술 전 3일 중단**: 케톤산증 예방
- **탈수 주의**: 이뇨 효과 → 충분한 수분 섭취 교육
- **고령자**: 탈수, 기립성 저혈압 위험 증가
- **제1형 당뇨**: 국내 미승인 (케톤산증 위험)
- **반복 비뇨생식기 감염자**: 사용 재고려

### SGLT2 억제제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 이뇨제(특히 루프) | 경고 | 과도한 이뇨 → 탈수, 저혈압 |
| 인슐린/설포닐우레아 | 경고 | 저혈당 위험 → 병용 시 감량 |
| 리튬 | 참고 | 리튬 배설 증가 가능 |
| 디곡신 | 참고 | 모니터링 권장 |

## 당뇨약 선택 알고리즘 (간략)

```
제2형 당뇨 진단
    ↓
1단계: 메트포르민 + 생활습관 교정
    ↓ (3개월 후 HbA1c 목표 미달)
2단계: 메트포르민 + 2차 약물 추가
    ├─ 심혈관질환 동반 → SGLT2억제제 또는 GLP-1작용제
    ├─ 심부전 동반 → SGLT2억제제
    ├─ 신장질환 동반 → SGLT2억제제
    ├─ 저혈당 우려 → DPP-4억제제 또는 SGLT2억제제
    ├─ 체중 감소 필요 → SGLT2억제제 또는 GLP-1작용제
    └─ 비용 우선 → 설포닐우레아
    ↓ (3개월 후 HbA1c 목표 미달)
3단계: 3제 병용 또는 인슐린 추가
```

## 복약지도 핵심 포인트

1. **식사와의 관계**: 메트포르민은 식사와 함께(위장장애 감소), SU는 식전/식사 시(저혈당 방지)
2. **저혈당 교육**: SU/인슐린 사용자 → 저혈당 증상, 대처법(포도당 15g), 사탕/주스 소지
3. **조영제 검사**: 메트포르민 복용 중이면 검사 당일 중단, 48시간 후 신기능 확인 후 재개
4. **아픈 날(Sick Day) 규칙**: 식사 못할 때 SU 중단, 메트포르민 주의, 수분 섭취, 혈당 자주 체크
5. **SGLT2 억제제**: 비뇨생식기 위생 교육, 충분한 수분, 수술 3일 전 중단
6. **정기 검사**: HbA1c(3개월), 신기능, 간기능, 전해질 모니터링
7. **OTC 감기약 주의**: 슈도에페드린이 혈당에 영향 가능 → [[감기약]] 참조
