# 고혈압약 (항고혈압제)

> 본 자료는 교육/시뮬레이션 목적입니다. 전문의약품(ETC)으로 반드시 처방전이 필요합니다.

고혈압 약물은 크게 **ARB**, **ACE억제제**, **칼슘채널차단제(CCB)**, **이뇨제**, **베타차단제**로 구분합니다.
국내에서는 ARB와 CCB가 가장 많이 처방됩니다.

---

## 1. ARB (안지오텐신 II 수용체 차단제)

### 개요
- **작용기전**: 안지오텐신 II 수용체(AT1)를 선택적으로 차단 → 혈관 이완, 알도스테론 분비 감소
- **특징**: ACE억제제 대비 마른기침 부작용 거의 없음, 내약성 우수
- **국내 처방 1순위**: 단독요법 또는 CCB/이뇨제와 병용

### 대표 약물

#### 발사르탄 (Valsartan)
- **상품명**: 디오반, 발사르탄정
- **용량**: 80mg → 160mg → 320mg (단계적 증량)
- **용법**: 1일 1회, 식사와 관계없이
- **특징**: 심부전 적응증 보유, 가장 많이 처방되는 ARB
- **대사**: 간대사(CYP 의존도 낮음), 대변 배설 주

#### 로사르탄 (Losartan)
- **상품명**: 코자, 로사르탄정
- **용량**: 50mg → 100mg
- **용법**: 1일 1회
- **특징**: 최초의 ARB, 요산 배설 촉진 효과(통풍 동반 시 유리), 당뇨병성 신증 적응증
- **대사**: CYP2C9/3A4 (활성대사물 E-3174로 전환)

#### 텔미사르탄 (Telmisartan)
- **상품명**: 미카르디스, 프리토
- **용량**: 40mg → 80mg
- **용법**: 1일 1회
- **특징**: 가장 긴 반감기(24시간), PPAR-감마 활성화(대사증후군 이점), 간대사(신장 조절 불필요)

#### 칸데사르탄 (Candesartan)
- **상품명**: 아타칸
- **용량**: 8mg → 16mg → 32mg
- **용법**: 1일 1회
- **특징**: 수용체 결합력 가장 강함, 심부전 적응증

### ARB 공통 주의사항
- **임부 금기**: 태아 신장 발달 장애 → 임신 확인 즉시 중단, 대체약 전환
- **고칼륨혈증**: 특히 신기능 저하/칼륨보존이뇨제 병용 시
- **양측 신동맥 협착**: 급성 신부전 위험
- **혈압저하**: 이뇨제 병용 시 초회 저혈압 주의 (특히 고령자)

### ARB 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 칼륨보존이뇨제(스피로노락톤) | 주의 | 고칼륨혈증 위험 |
| NSAIDs(이부프로펜 등) | 경고 | 혈압강하 효과 감소 + 신기능 저하 |
| 리튬 | 주의 | 리튬 혈중농도 상승 |
| ACE억제제 | 경고 | 이중차단 금기 (ONTARGET 연구) |
| 칼륨 보충제 | 주의 | 고칼륨혈증 |
| 알리스키렌(레닌억제제) | 금기(당뇨/신장애) | 고칼륨혈증, 저혈압, 신부전 |

## 2. ACE억제제 (안지오텐신전환효소 억제제)

### 개요
- **작용기전**: ACE 차단 → 안지오텐신 II 생성 억제 + 브래디키닌 분해 억제
- **특징**: 심부전/심근경색 후/당뇨병성 신증에 강한 근거, 마른기침(10~15%)이 주요 부작용

### 대표 약물

#### 라미프릴 (Ramipril)
- **상품명**: 트리테이스
- **용량**: 2.5mg → 5mg → 10mg
- **용법**: 1일 1회
- **특징**: HOPE 연구 - 심혈관 고위험군에서 이벤트 감소 입증

#### 에날라프릴 (Enalapril)
- **상품명**: 레니텍
- **용량**: 5mg → 10mg → 20mg
- **용법**: 1일 1~2회
- **특징**: 심부전 표준치료, 프로드러그(에날라프릴라트로 전환)

#### 페린도프릴 (Perindopril)
- **상품명**: 아서틸
- **용량**: 4mg → 8mg
- **용법**: 1일 1회, 아침 식전
- **특징**: EUROPA 연구 - 안정형 관상동맥질환에서 심혈관 보호

### ACE억제제 공통 부작용
| 부작용 | 빈도 | 대처 |
|--------|------|------|
| 마른기침 | 10~15% | ARB로 전환 |
| 혈관부종 | 0.1~0.7% | 즉시 중단, 응급 대처 |
| 고칼륨혈증 | 흔함 | 칼륨 모니터링 |
| 초회 저혈압 | 흔함 | 소량 시작, 취침 전 초회 투여 |
| 미각 이상 | 드묾 | 자연 회복 |

### ACE억제제 상호작용
- ARB와 동일한 상호작용 프로파일
- 추가: **사쿠비트릴(엔트레스토)과 36시간 간격 필요** → 혈관부종 위험

## 3. CCB (칼슘채널차단제)

### 개요
- **작용기전**: L-형 칼슘채널 차단 → 혈관 평활근 이완 → 혈관 확장
- **분류**: 디하이드로피리딘계(혈관 선택적) / 비디하이드로피리딘계(심장 선택적)
- **특징**: 대사적으로 중립(혈당/지질 영향 없음), 노인/단독수축기고혈압에 효과적

### 대표 약물

#### 암로디핀 (Amlodipine) - 디하이드로피리딘계
- **상품명**: 노바스크, 암로디핀정
- **용량**: 5mg → 10mg
- **용법**: 1일 1회
- **특징**: 가장 많이 처방되는 CCB, 반감기 30~50시간(안정적 혈중농도), 복약 순응도 우수
- **부작용**: 발목부종(용량 의존적), 두통, 안면홍조, 어지러움
- **대처**: 발목부종 시 ARB 병용으로 개선 가능 (정맥 확장 보상)

#### 니페디핀 (Nifedipine) - 디하이드로피리딘계
- **상품명**: 아달라트오로스(서방형)
- **용량**: 30mg → 60mg (서방형)
- **용법**: 1일 1회 (서방형)
- **주의**: 속효형(캡슐) 사용 금지 → 반사성 빈맥, 관상동맥 허혈 위험
- **부작용**: 두통, 안면홍조, 반사성 빈맥

#### 딜티아젬 (Diltiazem) - 비디하이드로피리딘계
- **상품명**: 헤르벤, 딜티아젬서방정
- **용량**: 90~180mg (서방형)
- **용법**: 1일 1~2회
- **특징**: 심박수 감소 효과 → 빈맥 동반 고혈압에 유용
- **금기**: 서맥, 방실차단, 심부전

### CCB 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 베타차단제 + 비DHP계 CCB | 주의 | 과도한 서맥/전도장애 |
| 시메티딘 | 경고 | CCB 혈중농도 상승 |
| CYP3A4 억제제(케토코나졸 등) | 경고 | CCB 혈중농도 상승 |
| 자몽주스 | 경고 | 니페디핀/암로디핀 농도 상승 |
| 시클로스포린 | 주의 | 시클로스포린 농도 상승(딜티아젬) |
| 심바스타틴 | 주의 | 횡문근융해증(딜티아젬/베라파밀) |

## 4. 이뇨제

### 개요
- **작용기전**: 신장에서 나트륨/수분 배설 촉진 → 혈장량 감소 → 혈압 하강
- **분류**: 티아지드계, 루프이뇨제, 칼륨보존이뇨제

### 대표 약물

#### 하이드로클로로티아지드 (HCTZ) - 티아지드계
- **상품명**: 다이클로짓
- **용량**: 12.5~25mg
- **용법**: 1일 1회, 아침
- **특징**: 저용량(12.5mg)에서 혈압강하 효과 충분, 단독보다 ARB/ACEi와 병용 선호
- **부작용**: 저칼륨혈증, 고요산혈증(통풍), 혈당 상승, 저나트륨혈증
- **모니터링**: 전해질(K+, Na+), 요산, 혈당 정기 검사

#### 인다파마이드 (Indapamide) - 티아지드 유사
- **상품명**: 나트릭스SR
- **용량**: 1.5mg (서방형)
- **용법**: 1일 1회, 아침
- **특징**: 대사 영향 적음(HCTZ 대비), 혈관확장 작용 병행

#### 스피로노락톤 (Spironolactone) - 칼륨보존이뇨제
- **상품명**: 알닥톤
- **용량**: 25~50mg
- **용법**: 1일 1~2회
- **특징**: 알도스테론 길항, 저항성 고혈압 4차 약물, 심부전 표준치료
- **부작용**: 고칼륨혈증, 여성형 유방(남성), 월경 불규칙
- **금기**: 고칼륨혈증, 중증 신부전

### 이뇨제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| NSAIDs | 경고 | 이뇨 효과 감소, 신기능 악화 |
| 리튬 | 주의 | 리튬 재흡수 증가 → 독성 |
| 디곡신 | 주의 | 저칼륨혈증 시 디곡신 독성 증가 (티아지드/루프) |
| ACE억제제/ARB | 참고 | 유익한 병용이나 초회 저혈압 주의 |
| 칼륨보충제 + 스피로노락톤 | 주의 | 고칼륨혈증 |
| 메트포르민 | 참고 | 탈수 시 유산산증 위험 |

## 5. 베타차단제

### 대표 약물

#### 비소프롤롤 (Bisoprolol)
- **상품명**: 콩코르
- **용량**: 2.5mg → 5mg → 10mg
- **용법**: 1일 1회
- **특징**: 심장 선택적(베타1), 심부전/빈맥 동반 고혈압에 유용
- **주의**: 서맥, 천식/COPD(비선택적은 금기), 갑작스런 중단 금지(반동 고혈압)

#### 카르베딜롤 (Carvedilol)
- **상품명**: 딜라트렌
- **용량**: 12.5mg → 25mg
- **용법**: 1일 2회, 식사와 함께
- **특징**: 알파+베타 차단, 심부전 표준치료

## 고혈압약 병용요법

### 권장 병용 조합
| 조합 | 대표 복합제 | 특징 |
|------|-------------|------|
| ARB + CCB | 엑스포지(암로디핀/발사르탄) | 가장 흔한 병용, 부종 감소 효과 |
| ARB + 이뇨제 | 코아프로벨(이르베사르탄/HCTZ) | 부종 동반 시 |
| ARB + CCB + 이뇨제 | 3제 복합제 | 저항성 고혈압 |
| ACEi + CCB | 로트렐(암로디핀/베나제프릴) | ACEi 선호 시 |

### 금기 병용 조합
| 조합 | 이유 |
|------|------|
| ACEi + ARB | 이중 RAS 차단 → 고칼륨/저혈압/신부전 |
| 비DHP계 CCB + 베타차단제 | 과도한 서맥, 전도장애 |

## 복약지도 핵심 포인트

1. **규칙적 복용**: 고혈압약은 증상 없어도 매일 같은 시간에 복용
2. **갑자기 중단 금지**: 특히 베타차단제 → 반동 고혈압/빈맥
3. **기립성 저혈압**: 특히 초회 투여 시, 고령자 → 천천히 일어나기
4. **NSAIDs 주의**: OTC 진통제(이부프로펜 등) 복용 시 혈압 상승 가능 → [[해열진통제]] 중 아세트아미노펜 권장
5. **칼륨 식품**: ARB/ACEi 복용 시 과도한 칼륨 섭취(바나나, 오렌지주스) 주의
6. **자몽주스**: CCB(특히 니페디핀) 복용 시 회피
7. **혈압 자가측정**: 아침 기상 후 + 취침 전, 가정혈압 기록 권장
