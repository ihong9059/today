# 위장약 (소화기계 약물)

> 본 자료는 교육/시뮬레이션 목적입니다. 실제 복약지도는 약사의 전문적 판단에 따릅니다.

위장약은 **PPI(양성자펌프억제제)**, **H2수용체차단제**, **제산제**, **소화효소제**, **위장운동촉진제** 등으로 분류됩니다.
OTC와 ETC가 혼재하는 약효군입니다.

---

## 1. PPI (양성자펌프억제제, Proton Pump Inhibitor)

### 개요
- **작용기전**: 위벽세포의 H+/K+-ATPase(양성자펌프)를 비가역적으로 차단 → 위산 분비 90% 이상 억제
- **적응증**: 위궤양, 십이지장궤양, 역류성식도염(GERD), 헬리코박터 제균요법, NSAIDs 유발 궤양 예방
- **특징**: 가장 강력한 위산억제제, 식전 30분 복용 필수

### 대표 약물

#### 오메프라졸 (Omeprazole)
- **상품명**: 오메프론, 로섹
- **분류**: OTC(10mg) / ETC(20mg, 40mg)
- **용량**: 1일 1회 20mg (궤양치료 시 40mg)
- **용법**: 아침 식전 30분, 장용코팅 → 씹거나 부수지 말 것
- **대사**: CYP2C19 주요 기질 → 대사 속도 개인차 큼

#### 에소메프라졸 (Esomeprazole)
- **상품명**: 넥시움
- **분류**: ETC
- **용량**: 1일 1회 20~40mg
- **용법**: 아침 식전 30분
- **특징**: 오메프라졸의 S-이성체, CYP2C19 영향 적음 → 개인차 적은 효과

#### 란소프라졸 (Lansoprazole)
- **상품명**: 란스톤
- **분류**: ETC
- **용량**: 1일 1회 15~30mg
- **용법**: 아침 식전
- **특징**: 구강붕해정(OD정) 가능 → 연하곤란 환자 유리

#### 판토프라졸 (Pantoprazole)
- **상품명**: 판토록
- **분류**: ETC
- **용량**: 1일 1회 40mg
- **특징**: CYP 상호작용 가장 적음 → 다약제 복용 환자에 유리

#### 라베프라졸 (Rabeprazole)
- **상품명**: 파리에트
- **분류**: ETC
- **용량**: 1일 1회 10~20mg
- **특징**: 비효소적 활성화 → CYP2C19 다형성 영향 적음, 빠른 효과 발현

### PPI 공통 주의사항
- **식전 30분 복용**: 양성자펌프가 활성화되기 전에 약물이 흡수되어야 효과적
- **장기복용(>8주) 시 위험**:
  - 골다공증/골절 위험 증가 (칼슘 흡수 감소)
  - 저마그네슘혈증
  - 비타민 B12 결핍
  - 클로스트리디움 디피실 감염 위험 증가
  - 신장 질환(간질성 신염)
  - 위저부 용종(양성)
- **반동 위산과다분비**: 장기 사용 후 갑자기 중단 시 → 2~4주에 걸쳐 감량

### PPI 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 클로피도그렐(플라빅스) | 주의 | 오메프라졸이 CYP2C19 억제 → 클로피도그렐 활성화 감소 → 판토프라졸/라베프라졸 대체 |
| 메토트렉세이트 | 주의 | 메토트렉세이트 배설 지연 → 독성 증가 |
| 아타자나비르/넬피나비르 | 금기 | pH 상승으로 흡수 감소 → 항HIV 효과 소실 |
| 클로나제팜/디아제팜 | 참고 | 오메프라졸이 CYP2C19 기질 벤조디아제핀 대사 억제 |
| 철분제 | 경고 | 위산 감소 → 철분 흡수 감소 |
| 칼슘 보충제 | 경고 | 위산 감소 → 탄산칼슘 흡수 감소 (구연산칼슘 대체) |
| 디곡신 | 참고 | 디곡신 흡수 약간 증가 |
| 타크로리무스 | 주의 | 혈중농도 상승 |

## 2. H2수용체차단제 (H2 Receptor Antagonist)

### 개요
- **작용기전**: 위벽세포 히스타민 H2수용체 차단 → 위산 분비 약 70% 억제
- **특징**: PPI보다 약하지만 빠른 효과(30~60분), OTC로 접근성 높음
- **적응증**: 경증 위산 과다, 속쓰림, 가벼운 위궤양

### 대표 약물

#### 파모티딘 (Famotidine)
- **상품명**: 가스터, 파모티딘정
- **분류**: OTC(10mg) / ETC(20mg, 40mg)
- **용량**: 1회 10~20mg, 1일 2회 / 궤양: 1일 1회 40mg 취침 전
- **용법**: 식전 또는 증상 시
- **특징**: 현재 가장 많이 사용되는 H2차단제, NDMA 이슈 없음
- **신장 조절**: eGFR <50 → 감량 또는 간격 연장

#### 라니티딘 (Ranitidine) - 참고용
- **상품명**: 잔탁 (제조중단/회수)
- **상태**: NDMA(발암물질) 불순물 검출로 2020년 전 세계적 회수
- **대체**: 파모티딘으로 전환

#### 시메티딘 (Cimetidine)
- **상품명**: 시메티딘정, 타가메트
- **분류**: OTC/ETC
- **용량**: 1회 200~400mg, 1일 2~4회
- **주의**: CYP 억제 범위가 넓어 약물 상호작용 다수 → 현재 사용 감소 추세
- **상호작용 주의**: 와파린, 테오필린, 페니토인, 메트포르민, 벤조디아제핀 등 다수

### H2차단제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 아타자나비르(HIV) | 경고 | pH 상승 → 흡수 감소 |
| 케토코나졸/이트라코나졸 | 경고 | pH 상승 → 아졸계 항진균제 흡수 감소 |
| 메트포르민(시메티딘만) | 경고 | 시메티딘이 메트포르민 신배설 억제 → 혈중농도 상승 |
| 와파린(시메티딘만) | 주의 | 와파린 대사 억제 → INR 상승 |

## 3. 제산제 (Antacid)

### 개요
- **작용기전**: 위산을 직접 화학적으로 중화
- **특징**: 즉각적 증상 완화(5~15분), 지속시간 짧음(30~60분), OTC

### 대표 약물

#### 수산화알루미늄/수산화마그네슘 복합제
- **상품명**: 겔포스, 알마겔, 맥시부민
- **용법**: 식간(식후 1~2시간) 또는 취침 전, 1포/1정
- **특징**: Al(변비 유발) + Mg(설사 유발) 혼합으로 균형

#### 탄산칼슘
- **상품명**: 턱스(TUMS)
- **용법**: 증상 시 1~2정 씹어서 복용
- **특징**: 빠른 효과, 칼슘 보충 효과, 반동 위산분비(rebound) 가능

#### 알긴산나트륨
- **상품명**: 개비스콘
- **용법**: 식후/취침 전
- **특징**: 위 내용물 위에 뗏목(raft) 형성 → 역류 방지, 산중화 + 물리적 차단

### 제산제 공통 주의사항
- **다른 약물과 2시간 간격**: 흡수 방해
  - 특히: 퀴놀론계 항생제([[항생제]]), 테트라사이클린, 철분제, 갑상선호르몬제
- **신부전 환자**: 알루미늄 축적 주의, 마그네슘 축적 주의
- **장기 사용 지양**: 근본 원인 치료 필요

### 제산제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 퀴놀론 항생제 | 금기급 | 킬레이트 형성 → 항생제 흡수 80% 이상 감소 |
| 테트라사이클린 | 금기급 | 킬레이트 형성 → 흡수 감소 |
| 철분제 | 경고 | 흡수 감소 → 2시간 이상 간격 |
| 갑상선호르몬제(레보티록신) | 경고 | 흡수 감소 → 4시간 간격 권장 |
| 비스포스포네이트 | 경고 | 흡수 감소 |
| 아지스로마이신 | 참고 | 흡수 약간 감소 |

## 4. 소화효소제

### 개요
- **작용기전**: 부족한 소화효소(아밀라제, 리파아제, 프로테아제)를 외부에서 보충
- **적응증**: 소화불량, 과식, 췌장 외분비 기능부전

### 대표 약물

#### 판크레아틴 (Pancreatin)
- **상품명**: 훼스탈, 훼스탈플러스
- **분류**: OTC
- **용법**: 식후 1정
- **성분**: 아밀라제 + 리파아제 + 프로테아제 + 담즙산(훼스탈)
- **주의**: 돼지 유래 → 돼지고기 알레르기 확인, 담즙산 포함 시 담석 주의

#### 베아제 (Bearse)
- **상품명**: 베아제정
- **분류**: OTC
- **용법**: 식후 1정
- **특징**: 소화효소 + 우르소데옥시콜산(담즙산)

#### 디아스타제/판크레아틴 복합제
- **상품명**: 베나치오, 비오비타
- **분류**: OTC

### 소화효소제 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 아카보스(글루코바이) | 경고 | 아카보스는 탄수화물 분해 억제 → 소화효소가 효과 상쇄 |
| 제산제 | 참고 | 과도한 pH 상승 시 효소 활성 저하 |

## 5. 위장운동촉진제

### 대표 약물

#### 돔페리돈 (Domperidone)
- **상품명**: 모티리움
- **분류**: OTC(10mg)
- **용량**: 1회 10mg, 1일 3회, 식전 15~30분
- **작용**: 도파민 D2 수용체 길항 → 위장운동 촉진, 오심/구토 억제
- **주의**: QT 연장(심부정맥), 유즙분비(프로락틴 상승), 심장질환자 주의
- **FDA 미승인**(미국), 유럽/한국에서 사용

#### 이토프리드 (Itopride)
- **상품명**: 가나톤
- **분류**: ETC
- **용량**: 1회 50mg, 1일 3회, 식전
- **작용**: 도파민 D2 길항 + 아세틸콜린에스터라제 억제
- **특징**: 돔페리돈 대비 QT 연장 위험 낮음

#### 모사프리드 (Mosapride)
- **상품명**: 가스모틴
- **분류**: ETC
- **용량**: 1회 5mg, 1일 3회, 식전
- **작용**: 5-HT4 수용체 작용 → 위장운동 촉진
- **특징**: QT 연장 위험 매우 낮음, 심장 안전성 양호

## 6. 점막보호제

### 대표 약물

#### 수크랄페이트 (Sucralfate)
- **상품명**: 아루사루민
- **분류**: ETC
- **용량**: 1회 1g, 1일 4회 (식전 1시간 + 취침 전)
- **작용**: 궤양 부위에 보호막 형성
- **주의**: 다른 약물 흡수 방해 → 2시간 간격, 알루미늄 함유(신부전 주의)

#### 레바미피드 (Rebamipide)
- **상품명**: 무코스타
- **분류**: ETC
- **용량**: 1회 100mg, 1일 3회
- **작용**: 위점막 프로스타글란딘 증가, 점막 보호/수복
- **특징**: NSAIDs 유발 위점막 손상 예방에 사용, 부작용 적음

## 위장약 선택 가이드

### 증상별 추천

| 증상 | 1차 선택 | 2차 선택 | 비고 |
|------|----------|----------|------|
| 가끔 속쓰림/신물 | 제산제(겔포스, 개비스콘) | 파모티딘 10mg(OTC) | 즉각 완화 |
| 잦은 속쓰림(주 2회 이상) | 파모티딘 20mg | OTC PPI(오메프라졸 10mg) | 2주 사용 후 의사 상담 |
| 역류성식도염(진단) | PPI(에소메프라졸/란소프라졸) | PPI + 개비스콘 | ETC 처방 필요 |
| 위궤양(진단) | PPI 4~8주 | 레바미피드 병용 | H.pylori 양성 시 제균요법 |
| 소화불량/더부룩 | 소화효소제(훼스탈) | 위장운동촉진제(가나톤) | |
| 식후 팽만감/조기포만 | 위장운동촉진제 | 소화효소제 | |
| NSAIDs 장기 복용 | PPI 예방적 병용 | 레바미피드 | [[해열진통제]] 참조 |

### 환자 특성별 주의

| 환자 특성 | 주의 약물 | 이유 | 대안 |
|-----------|-----------|------|------|
| 클로피도그렐 복용 | 오메프라졸 | 클로피도그렐 효과 감소 | 판토프라졸, 파모티딘 |
| 신부전 | 제산제(Al/Mg), 파모티딘(고용량) | 축적 | PPI, 용량 조절 |
| 골다공증 | PPI 장기복용 | 골절 위험 | 최소 용량/기간, 칼슘/비타민D 보충 |
| 항생제 복용 중 | 제산제 | 흡수 방해 | 2시간 간격, PPI로 대체 |
| 임산부 | 제산제(1차), 파모티딘(2차) | 비교적 안전 | 오메프라졸(필요 시 사용 가능) |

## 복약지도 핵심 포인트

1. **PPI는 식전 30분**: 식사로 양성자펌프가 활성화될 때 약효 극대화
2. **제산제는 다른 약과 2시간 간격**: 특히 항생제, 철분제, 갑상선약
3. **PPI 장기복용 점검**: 8주 이상 시 필요성 재평가, 감량/중단 계획
4. **클로피도그렐 + PPI**: 오메프라졸 회피, 판토프라졸 선택
5. **소화불량과 위암 감별**: 40세 이상 새로 발생한 소화불량 → 위내시경 권유
