# 감기약 (종합감기약)

> 본 자료는 교육/시뮬레이션 목적입니다. 실제 복약지도는 약사의 전문적 판단에 따릅니다.

종합감기약은 여러 증상을 동시에 완화하기 위해 복합 성분으로 구성됩니다.
각 성분의 역할과 부작용을 이해하는 것이 복약지도의 핵심입니다.

---

## 감기약 주요 성분 분류

| 증상 | 성분 계열 | 대표 성분 | 주의사항 |
|------|-----------|-----------|----------|
| 발열/통증 | 해열진통제 | 아세트아미노펜 | [[해열진통제]]와 중복 주의 |
| 콧물/재채기 | 항히스타민제(1세대) | 클로르페니라민, 독시라민 | 졸음 유발 |
| 코막힘 | 비충혈완화제 | 슈도에페드린, 페닐에프린 | 고혈압/불면 |
| 기침(마른기침) | 진해제 | 덱스트로메토르판 | SSRI 병용 주의 |
| 기침(가래) | 거담제 | 구아이페네신, 암브록솔 | 비교적 안전 |
| 인후통 | 소염제 | 이부프로펜, 트라넥삼산 | NSAIDs 주의 |

## 1. 판콜에이 (PanCold-A)

### 성분 구성
| 성분 | 함량(1정) | 역할 |
|------|-----------|------|
| 아세트아미노펜 | 300mg | 해열/진통 |
| 클로르페니라민말레산염 | 2mg | 콧물/재채기 (항히스타민) |
| 슈도에페드린염산염 | 30mg | 코막힘 (비충혈완화) |
| 덱스트로메토르판 | 10mg | 기침 억제 |
| dl-메틸에페드린 | 12.5mg | 기관지 확장 |
| 카페인무수물 | 25mg | 졸음 경감, 진통 보조 |

### 용법
- 성인: 1회 1정, 1일 3회, 식후 30분
- 소아(만 11세 이상): 성인 용량의 2/3

### 주의사항
- **졸음 유발**: 클로르페니라민 함유 → 운전/기계 조작 주의
- **아세트아미노펜 중복**: 타이레놀 등 다른 해열진통제와 동시 복용 금지
- **고혈압 환자**: 슈도에페드린/메틸에페드린으로 혈압 상승 가능
- **전립선비대**: 항히스타민+교감신경흥분제로 배뇨곤란 악화
- **녹내장**: 항히스타민으로 안압 상승 가능
- **당뇨**: 슈도에페드린이 혈당에 영향 가능

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| MAO억제제 | 금기 | 고혈압 위기 (슈도에페드린) |
| 다른 아세트아미노펜 제제 | 금기 | 간독성 위험 |
| 항고혈압제 | 경고 | 혈압강하 효과 감소 |
| 알코올 | 주의 | 졸음 증강 + 간독성 |
| 수면제/안정제 | 주의 | 중추신경억제 증강 |

## 2. 코대원 시럽/정 (Codaewon)

### 성분 구성 (시럽 10mL 기준)
| 성분 | 함량 | 역할 |
|------|------|------|
| 덱스트로메토르판 | 10mg | 진해 |
| 슈도에페드린 | 30mg | 비충혈완화 |
| 구아이페네신 | 100mg | 거담 |
| 클로르페니라민 | 2mg | 항히스타민 |

### 용법
- 성인: 1회 10mL, 1일 3~4회
- 소아(만 6~11세): 1회 5mL, 1일 3~4회
- 소아(만 2~5세): 1회 2.5mL, 1일 3~4회

### 주의사항
- **졸음**: 클로르페니라민 포함
- **SSRI 병용 주의**: 덱스트로메토르판 + SSRI → 세로토닌 증후군 위험
- **소아 기침약 주의**: 만 2세 미만에게는 기침약 사용 자제 권고
- 시럽 제형은 당분 함유 → 당뇨 환자 안내

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| MAO억제제 | 금기 | 세로토닌 증후군 + 고혈압 위기 |
| SSRI/SNRI | 주의 | 세로토닌 증후군 (덱스트로메토르판) |
| 항고혈압제 | 경고 | 효과 감소 (슈도에페드린) |

## 3. 콘택600 (Contac 600)

### 성분 구성
| 성분 | 함량(1캡슐) | 역할 |
|------|-------------|------|
| 슈도에페드린염산염 | 120mg (서방형) | 비충혈완화 |
| 트리프롤리딘염산염 | 5mg | 항히스타민 |

### 용법
- 성인: 1회 1캡슐, 12시간 간격 (1일 2회)
- 서방형이므로 씹거나 부수지 않고 통째로 복용

### 특징
- 해열진통 성분 미포함 → 발열/통증에는 별도 약 필요
- 코감기(콧물+코막힘)에 특화
- 12시간 서방형으로 편의성 높음

### 주의사항
- **불면**: 슈도에페드린 120mg 고용량 → 취침 전 복용 시 불면 가능
- **고혈압/심장질환**: 슈도에페드린 금기
- **녹내장**: 트리프롤리딘 항콜린 작용으로 안압 상승
- **전립선비대**: 배뇨곤란 악화
- **갑상선기능항진증**: 교감신경 자극 증강

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| MAO억제제 | 금기 | 고혈압 위기 |
| 항고혈압제 | 경고 | 혈압강하 효과 감소 |
| 베타차단제 | 경고 | 상호 효과 감소 |
| 중추신경억제제 | 주의 | 졸음 증강 (트리프롤리딘) |

## 4. 화이투벤 나이트 (Whitoben Night)

### 성분 구성
| 성분 | 함량 | 역할 |
|------|------|------|
| 아세트아미노펜 | 500mg | 해열/진통 |
| 덱스트로메토르판 | 15mg | 진해 |
| 독시라민숙시네이트 | 7.5mg | 항히스타민(강한 졸음) |
| 슈도에페드린 | 30mg | 비충혈완화 |

### 용법
- 성인: 취침 전 1회 복용
- 야간 감기 증상 완화에 특화

### 주의사항
- **강한 졸음**: 독시라민은 1세대 항히스타민 중 가장 강한 진정 작용
- **아침 잔존 졸음**: 반감기 10시간 → 아침 운전 주의
- **알코올 절대 금지**: 중추신경억제 심화
- **주간용 감기약과 구분**: 낮에 복용하면 과도한 졸음

### 상호작용
| 병용약물 | 위험등급 | 내용 |
|----------|----------|------|
| 알코올 | 금기 | 심각한 중추신경 억제 |
| 수면제(졸피뎀 등) | 금기 | 과도한 진정, 호흡억제 위험 |
| SSRI | 주의 | 세로토닌 증후군 (덱스트로메토르판) |
| 다른 아세트아미노펜 제제 | 금기 | 간독성 |

## 5. 타이레놀콜드-에스 (Tylenol Cold-S)

### 성분 구성
| 성분 | 함량(1정) | 역할 |
|------|-----------|------|
| 아세트아미노펜 | 325mg | 해열/진통 |
| 덱스트로메토르판 | 10mg | 진해 |
| 페닐에프린 | 5mg | 비충혈완화 |
| 클로르페니라민 | 2mg | 항히스타민 |

### 용법
- 성인: 1회 2정, 4~6시간 간격, 1일 최대 8정
- 아세트아미노펜 총량: 최대 2600mg/일

### 특징
- 페닐에프린 사용 (슈도에페드린 대비 약한 비충혈완화 효과)
- FDA에서 경구 페닐에프린의 효과에 대한 논란 존재

## 감기약 선택 가이드

### 증상별 추천

| 증상 조합 | 추천 | 비고 |
|-----------|------|------|
| 콧물+재채기만 | 콘택600, 또는 항히스타민 단독 | 불필요한 성분 회피 |
| 콧물+두통+발열 | 판콜에이, 타이레놀콜드 | 해열진통 포함 |
| 기침(마른)+콧물 | 코대원 | 진해+항히스타민 |
| 야간 증상 심함 | 화이투벤 나이트 | 수면 도움 |
| 기침+가래 | 구아이페네신 단독 | 진해제는 가래 기침에 부적합 |

### 환자 특성별 주의

| 환자 특성 | 피해야 할 성분 | 이유 | 대안 |
|-----------|----------------|------|------|
| 고혈압 | 슈도에페드린, 페닐에프린 | 혈압 상승 | 비충혈완화제 없는 제품, 비강 스프레이(단기) |
| 녹내장 | 항히스타민(1세대), 슈도에페드린 | 안압 상승 | 2세대 항히스타민(세티리진 등) |
| 전립선비대 | 항히스타민(1세대) | 배뇨곤란 | 2세대 항히스타민 |
| 임산부 | 슈도에페드린(제1삼분기), NSAIDs | 기형/동맥관 | 아세트아미노펜 단독 + 생리식염수 코세척 |
| MAO억제제 복용 | 슈도에페드린, 덱스트로메토르판 | 고혈압위기/세로토닌증후군 | 아세트아미노펜 단독 + 생리식염수 |
| SSRI 복용 | 덱스트로메토르판 | 세로토닌 증후군 | 아세트아미노펜 + 구아이페네신 |
| 간질환 | 아세트아미노펜(고용량) | 간독성 | 이부프로펜(단기) + 비약물 요법 |
| 운전/작업 | 항히스타민(1세대) | 졸음 | 2세대 항히스타민 또는 비충혈완화제 단독 |

## 복약지도 핵심 포인트

1. **성분 중복 확인 필수**: 감기약 + 타이레놀 = 아세트아미노펜 과량 가능
2. **졸음 경고**: 1세대 항히스타민 함유 제품은 반드시 졸음 안내 (운전/기계 조작)
3. **복용 기간**: 감기약은 3~5일 이내 사용, 증상 지속 시 의사 상담
4. **항생제 불필요**: 감기는 바이러스 → 항생제 요청 시 설명 ([[항생제]] 참조)
5. **수분 섭취**: 충분한 수분 + 휴식이 가장 중요한 치료
6. **소아 주의**: 만 2세 미만 기침/감기약 사용 자제, 만 6세 미만은 의사 상담 권장
