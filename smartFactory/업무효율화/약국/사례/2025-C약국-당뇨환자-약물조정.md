## 상황 전개

### 1단계: 처방 변경 확인

환자가 내분비내과 처방전을 가지고 방문하였다. 기존 약물에 새로운 약물이 추가되었다.

**변경된 처방 내용:**

| 약물 | 용법 | 변경사항 |
|------|------|---------|
| 메트포르민 500mg | 1일 2회 → **1일 3회** (증량) | 500mg → 750mg 증량 |
| **글리메피리드 1mg** | **1일 1회 아침 식전** | **신규 추가** |
| 암로디핀 5mg | 1일 1회 | 변경 없음 |
| 로수바스타틴 10mg | 1일 1회 | 변경 없음 |

### 2단계: 환자 호소

환자: "선생님, 지난주에 아침을 못 먹고 메트포르민을 먹었는데 좀 어지럽고 속이 안 좋았어요. 새로 추가된 약은 뭔가요? 부작용은 없나요?"

### 3단계: 약사의 약학적 분석

#### DUR 점검 결과
- 상호작용 경고: 없음
- 용량 확인: 메트포르민 1,500mg/일 (적정), 글리메피리드 1mg (저용량 시작, 적절)

#### 약학적 판단

```
[확인 1] 메트포르민 증량
  - 500mg bid → 500mg tid (1,500mg/일)
  - HbA1c 8.2% → 혈당 조절 불량으로 증량 타당
  - eGFR 72 → 사용 가능 (eGFR 30 미만 시 금기)
  - 위장장애: 식사와 함께 복용으로 최소화

[확인 2] 글리메피리드 추가
  - 설폰요소제 → 인슐린 분비 촉진
  - 핵심 위험: ★저혈당★
  - 1mg 저용량 시작 → 적절
  - 환자 교육 필수: 식사 거르면 저혈당 위험!

[확인 3] 환자의 기존 증상
  - 식사 거르고 메트포르민 복용 → 위장장애 악화
  - 글리메피리드 추가 후에는 식사 거르면 저혈당 위험 더 큼
  - 음주 습관: 저혈당 위험 가중 요인
```

### 4단계: 복약지도

#### A. 메트포르민 증량 관련

> "메트포르민이 하루 2번에서 3번으로 늘었습니다.
>
> **반드시 식사 중간이나 식사 직후에 드세요.** 빈속에 드시면 속이 쓰리고 설사가 생길 수 있습니다. 지난주 어지러우셨던 것도 빈속에 드셔서 그랬을 가능성이 높습니다.
>
> 처음 며칠은 약간 속이 불편할 수 있는데, 보통 1-2주면 적응됩니다."

#### B. 글리메피리드(신규) 관련

> "새로 추가된 글리메피리드는 췌장에서 인슐린 분비를 도와주는 약입니다. 혈당을 효과적으로 낮추지만, **저혈당이 생길 수 있는 약**이에요.
>
> **가장 중요한 것**: 아침 식사 직전에 드시고, **식사를 절대 거르지 마세요.** 식사를 거르면 혈당이 너무 떨어질 수 있습니다."

#### C. 저혈당 교육

> "저혈당 증상을 알려드릴게요:"

| 초기 증상 (교감신경) | 진행 증상 (심각) |
|--------------------|-----------------|
| 손 떨림, 식은땀 | 심한 어지러움 |
| 갑작스러운 배고픔 | 말이 어눌해짐 |
| 가슴 두근거림 | 의식 저하 |
| 불안감, 초조함 | 의식 소실 |

> "이런 증상이 나타나면 **즉시 설탕물이나 주스 150mL, 또는 사탕 3-4개를 드세요.** 15분 후에도 안 나아지면 한 번 더 드시고, 그래도 안 되면 응급실에 가셔야 합니다.
>
> **포도당 정제나 사탕을 항상 주머니에 넣고 다니세요.**"

#### D. 음주 관련

> "정OO님, 술을 드시면 저혈당 위험이 더 높아집니다. 간에서 혈당을 만드는 기능을 술이 억제하거든요.
>
> 글리메피리드 드시면서 술을 드실 때는:
> - 반드시 **안주와 함께** 드세요 (빈속 음주 절대 금지)
> - 소주 1잔 이하로 줄이시는 것이 좋겠습니다
> - 음주 다음 날 아침에 저혈당이 올 수 있으니 주의하세요"

> 참고: [[음식_상호작용]] — 알코올 섹션

#### E. Sick Day Rules 교육

> "감기 등으로 아플 때 주의사항도 알려드릴게요:"

| 상황 | 조치 |
|------|------|
| 구토/설사로 식사 못 할 때 | **글리메피리드 복용 중단** (저혈당 방지), **메트포르민도 중단** (탈수 시 유산산증 위험) |
| 물/음료는 마실 수 있을 때 | 수분 충분히 섭취, 소량씩 자주 식사 시도 |
| 혈당 측정 | 아플 때 **4시간마다** 혈당 측정 |
| 병원 연락 기준 | 혈당 300 이상 지속, 구토 6시간 이상, 의식 변화 |

> 상세: [[당뇨_복약가이드]] — Sick Day Rules 섹션

#### F. CT/MRI 조영제 검사 안내

> "혹시 CT나 MRI 촬영 시 조영제를 사용하는 검사를 받게 되면, **메트포르민을 검사 48시간 전부터 중단**하셔야 합니다. 검사 후 48시간 뒤 신장 기능 확인한 후 다시 드세요. 검사 예약 시 반드시 메트포르민 복용 중이라고 말씀하세요."

### 5단계: 생활습관 권고

| 항목 | 권고 |
|------|------|
| 식사 | 3끼 규칙적 식사. 탄수화물 적정량. 채소 먼저, 밥 나중에 |
| 운동 | 식후 30분 걷기 (혈당 강하에 매우 효과적). 주 150분 이상 |
| 혈당 측정 | 자가혈당측정기 활용. 공복 + 식후 2시간 기록 |
| 금주/절주 | 주 2회 이하, 1회 소주 1잔 이하 |
| 발 관리 | 매일 발 확인, 상처 주의 |

### 6단계: 결과

1주 후 환자 전화 상담:
- 메트포르민 위장장애: 식사와 함께 복용 후 호전
- 저혈당: 경험 없음 (식사 규칙적으로 하고 있음)
- 공복혈당: 130-145mg/dL 범위 (개선 추세)
- 포도당 정제: 구매하여 휴대 중

## 학습 포인트

1. **설폰요소제 추가 시 저혈당 교육 필수**: 메트포르민 단독에서 설폰요소제가 추가되면 저혈당 위험이 새로 발생한다. 환자가 이를 모르는 경우가 많으므로 상세 교육 필수.

2. **식사와의 관계**: 메트포르민 → 식사와 함께(위장장애 감소), 설폰요소제 → 식사 직전(식사 거르면 저혈당). 이 차이를 명확히 교육.

3. **음주 + 설폰요소제**: 저혈당 위험 가중. 특히 야간/익일 조조 저혈당 위험. 한국 음주 문화 고려한 실질적 교육 중요.

4. **Sick Day Rules**: 만성질환 약물은 아플 때 "그냥 드세요"가 아니다. 약물별 중단/유지 기준을 교육해야 한다.

5. **조영제 + 메트포르민**: 의외로 환자가 모르는 경우가 많다. 건강검진 시즌에 특히 주의 교육.

6. **복약지도의 가치**: 처방 변경 시점은 약사가 가장 큰 가치를 발휘할 수 있는 순간이다. 의사가 설명하지 못한 실생활 주의사항을 약사가 보완한다.
