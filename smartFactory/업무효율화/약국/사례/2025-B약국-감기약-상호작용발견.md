# 사례: B약국 - 감기약 판매 시 상호작용 발견

## 사례 개요

| 항목 | 내용 |
|------|------|
| 약국 | B약국 |
| 일자 | 2025년 4월 10일 |
| 환자 | 박OO, 여성, 71세 |
| 상황 | OTC 종합감기약 구매 요청 |
| 핵심 이슈 | 와파린 복용 환자의 감기약 성분 상호작용 |

---

## 환자 정보

| 항목 | 내용 |
|------|------|
| 연령/성별 | 71세 여성 |
| 진단명 | 심방세동(I48), 인공판막 치환 후(Z95.2) |
| 복용약물 | **와파린 3mg** 1일 1회, 디곡신 0.125mg 1일 1회, 아테놀롤 25mg 1일 1회 |
| 알레르기 | 페니실린 알레르기 (두드러기 기왕력) |
| INR 최근 값 | 2.5 (목표 범위 2.0-3.0) |

---

## 상황 전개

### 1단계: OTC 구매 요청

환자가 "콧물, 기침이 나고 몸이 좀 으슬으슬하다"며 종합감기약 '판콜에이'를 직접 선택하여 구매를 요청하였다.

### 2단계: 약사의 초기 확인

약사가 정기적으로 방문하는 환자임을 인식하고 복용 약물을 확인하였다.

> "박OO님, 현재 드시는 약이 있으시죠? 혈액 묽게 하는 약(와파린) 드시고 계시죠?"

환자: "네, 와파린이랑 심장약 3가지 먹고 있어요."

### 3단계: 판콜에이 성분 분석

**판콜에이 주요 성분:**

| 성분 | 함량 | 역할 | 와파린 상호작용 |
|------|------|------|---------------|
| 아세트아미노펜 | 300mg | 해열/진통 | **주의** — 고용량(>2g/일) 시 INR 상승 가능 |
| 클로르페니라민 | 2mg | 항히스타민(콧물) | 안전 |
| 슈도에페드린 | 30mg | 비충혈제거 | **주의** — 고혈압 위험 + 고령자 부적절 |
| 덱스트로메토르판 | 15mg | 진해 | 안전 |
| 무수카페인 | 30mg | 각성/진통 보조 | 경미 |

### 4단계: 상호작용 분석

```
[위험 1] 아세트아미노펜 + 와파린
  → 고용량 아세트아미노펜(>2g/일)은 INR 상승 유발
  → 판콜에이 권장 복용량(1회 2캡슐, 1일 3회)으로는
     아세트아미노펜 1,800mg/일 → 주의 필요 범위

[위험 2] 슈도에페드린 + 고령자 + 심방세동
  → 교감신경 자극 → 혈압 상승, 빈맥 유발
  → 심방세동 환자에서 부정맥 악화 가능
  → 아테놀롤(베타차단제) 효과 상쇄

[위험 3] 1세대 항히스타민(클로르페니라민) + 71세 고령자
  → 항콜린 작용 → 인지기능 저하, 낙상 위험
  → Beers Criteria 해당
```

> 참고: [[_상호작용_매트릭스]] — 와파린 상호작용, [[연령별_금기]] — 고령자

### 5단계: 약사의 대응

#### 환자에게 전달한 내용

> "박OO님, 이 감기약에는 와파린과 같이 드시면 주의가 필요한 성분이 여러 개 있습니다.
>
> 첫째, 해열진통 성분이 와파린의 효과를 강하게 만들어 출혈 위험이 높아질 수 있습니다.
> 둘째, 코막힘 약 성분이 혈압을 올리고 심장에 부담을 줄 수 있습니다.
> 셋째, 콧물 약 성분이 어르신에게 어지러움을 유발할 수 있습니다.
>
> 증상에 맞게 안전한 약을 개별적으로 골라드릴게요."

#### 대안 처방 (약사 추천)

| 증상 | 추천 약물 | 용법 | 사유 |
|------|----------|------|------|
| 발열/몸살 | 아세트아미노펜 500mg | 1회 1정, 1일 3회, 식후 (1일 1.5g 이하) | 와파린 복용자에서 가장 안전한 해열진통제. 1일 2g 이하 유지 |
| 콧물 | 2세대 항히스타민(로라타딘 10mg) | 1일 1회 | 항콜린 부작용 최소, 고령자 적합 |
| 기침 | 덱스트로메토르판 시럽 또는 정제 | 1일 3회 | 와파린 상호작용 없음 |
| 코막힘 | 생리식염수 비강세척 | 수시 | 비충혈제거제 회피 (심방세동 + 고령) |

### 6단계: 추가 교육

1. **INR 모니터링**: "감기로 식사를 잘 못 하시면 INR이 변할 수 있으니, 이번 주 중에 INR 검사를 받으시는 게 좋겠습니다."
2. **비타민K 식이**: "감기 때문에 채소를 안 드시면 INR이 올라갈 수 있어요. 평소대로 드시려고 하세요."
3. **출혈 증상 관찰**: "잇몸 출혈, 코피, 피부 멍이 평소보다 많으면 바로 병원에 가세요."
4. **발열 지속 시 의뢰**: "3일 이상 열이 나면 병원 진료 받으세요. 감염 시 항생제가 필요할 수 있고, 항생제도 와파린과 상호작용이 있을 수 있어서 약사에게 꼭 확인하세요."

## 학습 포인트

1. **OTC 종합감기약의 함정**: 여러 성분이 포함되어 있어, 1개 성분은 안전해도 다른 성분이 위험할 수 있다. 반드시 **전 성분 확인** 필요.

2. **와파린 환자의 OTC 상담**: 와파린은 상호작용이 매우 많은 약물. OTC 구매 시 매번 확인 필수. [[_상호작용_매트릭스]] 숙지 필요.

3. **고령자 + 1세대 항히스타민**: Beers Criteria 해당. 2세대 항히스타민으로 대체하는 것이 원칙. [[연령별_금기]] 참고.

4. **심방세동 환자의 교감신경 자극제**: 슈도에페드린, 페닐에프린 등은 부정맥 악화 위험. 비약물적 코막힘 관리 권고.

5. **약사의 직능 발휘**: 이 사례는 약사가 OTC 판매 과정에서 잠재적으로 심각한 상호작용을 방지한 전형적 사례이다. 단순 판매가 아닌 **전문 상담**의 가치를 보여준다.
