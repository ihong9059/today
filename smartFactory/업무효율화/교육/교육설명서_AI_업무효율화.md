# AI 활용 중소기업 업무효율화 교육 제안서

---

## 1. 교육 개요

| 항목 | 내용 |
|------|------|
| 교육명 | **AI와 지식DB를 활용한 중소기업 업무효율화** |
| 대상 | 중소기업 임직원 (제조업, 서비스업, 유통업 등) |
| 인원 | 15~30명 / 회 |
| 시간 | 기본 6시간 (1일) / 심화 12시간 (2일) |

| 목표 | 자사 업무 지식을 DB화하고, AI Tool과 연동하여 즉시 활용 가능한 업무 자동화 시스템 구축 |

## 2. 교육 배경 및 필요성

### 중소기업이 직면한 문제

1. **지식의 속인화**: 핵심 업무 노하우가 특정 직원의 머릿속에만 존재
2. **반복 업무의 비효율**: 견적서, 제안서, 고객 응대 등 유사 업무를 매번 처음부터 작성
3. **신규 직원 교육 부담**: 인수인계에 수개월 소요, 퇴직 시 지식 유실
4. **AI 도입의 막막함**: AI가 좋다는 건 알지만, 우리 회사에 어떻게 적용해야 할지 모름

### 해결 방안: 지식DB + AI Tool

```
[흩어진 업무 지식] → [체계적 지식DB 구축] → [AI Tool 연동] → [업무 자동화]
```

- **지식DB**: 회사의 제품, 고객, 공정, 사례 등 업무 지식을 마크다운 문서로 체계화
- **AI Tool**: 지식DB를 참조하여 질문에 답하고, 문서를 자동 생성하는 AI 어시스턴트
- **결과**: 누구나 AI에게 물어보면 회사의 축적된 노하우를 바탕으로 답변을 받을 수 있음

## 4. 실제 구축 사례 (4개 업종)

교육에서는 실제 구축 완료된 4개 업종의 사례를 시연합니다.

### 사례 1: 분쇄장비 제조사 (태명과학)

| 항목 | 내용 |
|------|------|
| 업종 | 과학장비 수입/판매 |
| 구축 규모 | Wiki 55개 문서, DB 6종, 엑셀 통합표 |
| 핵심 기능 | 시료 특성 입력 → 장비+부속품+재질 자동 추천 |
| 효과 | 장비 추천 소요시간 30분 → 3분, 신입 직원도 전문가 수준 응대 가능 |

**시연 예시:**
```
"LFP 양극재, 2mm에서 5마이크론으로, 금속오염 불허, 건식, 100g"
→ P-7 Premium + ZrO2 80ml 용기 + 3mm ZrO2 볼 추천
→ 분쇄 조건표 + 예상 결과 + 견적서 초안 자동 생성
```

### 사례 2: 산업용 분쇄기 제조사 (한국기계)

| 항목 | 내용 |
|------|------|
| 업종 | 산업용 분쇄/파쇄 장비 제조 |
| 구축 규모 | Wiki 41개 문서, DB 9종, 조달/BOM 데이터 |
| 핵심 기능 | 고객 요구사항 → 공정도 설계 + 장비 구성 + 제안서 자동 생성 |
| 효과 | 제안서 작성 2일 → 2시간, 공정 설계 표준화 |

**시연 예시:**
```
"폐배터리 월 2,000톤, 1mm 이하 분쇄"
→ 슈레더 + 해머크러셔 + 터보밀 3단계 공정 설계
→ BOM + 납기 + 제안서 초안 자동 생성
```

### 사례 3: 약국

| 항목 | 내용 |
|------|------|
| 업종 | 약국 (복약지도/OTC 상담) |
| 구축 규모 | Wiki 29개 문서, 전과정 설명서, 데모 웹 2종 |
| 핵심 기능 | 환자 정보 + 복용약 → 상호작용 검토 + 대안 제시 |
| 효과 | 약물 상호작용 확인 즉시 완료, 복약지도 기록 자동화 |

**시연 예시:**
```
"62세 남성, 고혈압약(발사르탄) 복용 중, 이부프로펜 구매 요청"
→ NSAIDs + ARB 상호작용 경고
→ 아세트아미노펜 대안 제시 + 복약지도 기록 자동 생성
```

## 5. 교육 특장점

### 기존 AI 교육과의 차별점

| 비교 항목 | 일반 AI 교육 | 본 교육 |
|-----------|-------------|---------|
| 내용 | ChatGPT 사용법, 프롬프트 작성법 | **자사 업무 데이터 + AI 연동 시스템 구축** |
| 결과물 | 프롬프트 몇 개 | **즉시 사용 가능한 업무 자동화 시스템** |
| 데이터 | 일반 지식 (인터넷) | **우리 회사 고유 데이터** 기반 |
| 정확도 | AI 환각(Hallucination) 위험 | 검증된 자사 데이터만 참조하여 **정확한 답변** |
| 보안 | 회사 정보가 외부 서버로 전송 | **로컬 DB**로 데이터 보안 유지 |
| 지속성 | 교육 후 활용 어려움 | **시스템이 남아서** 계속 발전 가능 |

### 교육생이 가져가는 것

1. **즉시 활용 가능한 지식DB 시스템** (자사 업무 3건 이상 문서화 완료)
2. **AI Tool 연동 설정 완료** (교육 중 직접 구축)
3. **도입 로드맵** (팀/부서 확산 계획)
4. **4개 업종 참고 사례** (템플릿으로 활용 가능)
