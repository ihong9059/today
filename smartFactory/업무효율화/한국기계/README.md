# 한국기계 AI 업무효율화 시뮬레이션 Wiki

## 이것은 무엇인가?

한국기계엔지니어링의 제품/공정/사례 지식을 **Obsidian**에 체계화하고,
**Claude AI**가 이를 참조하여 고객 문의 대응, 제안서 생성, 장비 추천을
자동화하는 **시뮬레이션 시스템**입니다.

> 이 Wiki는 시뮬레이션/교육 목적으로 구성되었습니다. 실제 가격, 납기 등은 별도 확인이 필요합니다.

## 빠른 시작 (5분)

1. **Obsidian** 설치 ([obsidian.md](https://obsidian.md))
2. 이 폴더(`한국기계/`)를 Vault로 열기
3. **Claude Code** 또는 **Claude Desktop**에서 이 폴더를 작업 디렉토리로 설정
4. Claude에게 질문하기 (아래 예시 참조)

## 사용 예시

### 1. 장비 추천
```
"폐배터리 월 2,000톤, 1mm 이하 분쇄 장비 추천해줘"
```
→ [[폐배터리-재활용]] 공정도 + 장비 구성 + [[2024-A사-폐배터리-재활용라인]] 사례 자동 응답

### 2. 제안서 생성
```
"/제안서 A기업, 음식물 처리, 시간당 5톤"
```
→ [[제안서_템플릿]] 기반 초안 자동 생성

### 3. 수준별 설명
```
"/설명서 터보밀 비전문가"
```
→ 쉬운 비유로 터보밀 원리/용도 설명

### 4. 사례 검색
```
"/사례검색 폐플라스틱"
```
→ 유사 납품 사례 검색 및 요약

### 5. 견적서
```
"/견적 슈레더 SH-2000 + 해머크러셔 HC-500"
```
→ [[견적서_템플릿]] 기반 견적 초안 생성

## 데이터 업데이트 방법

- **신규 제품**: `제품/` 폴더에 새 `.md` 파일 추가 (프론트매터 형식 준수)
- **납품 사례**: `사례/` 폴더에 `YYYY-업체-산업.md` 형식으로 추가
- **FAQ 추가**: `FAQ/` 파일에 `## 질문` 섹션 추가
- **공정 추가**: `공정/` 폴더에 `산업명.md` 형식으로 추가

## 주의사항

- 이 Wiki의 모든 데이터는 **시뮬레이션용**입니다. 실제 영업에 사용 시 반드시 최신 데이터를 확인하세요.
- `CLAUDE.md`를 수정하면 AI의 행동 규칙이 변경됩니다. 수정 시 주의하세요.
- 프론트매터(`---` 사이의 YAML)는 Dataview 검색에 사용되므로 형식을 유지하세요.
- `[[링크]]`는 파일명과 정확히 일치해야 합니다 (확장자 `.md` 제외).
