# 폐플라스틱 재활용 공정

## 공정 흐름도

```
[수거/선별] ── 재질별 분류 (PE/PP/PET)
    │
    ▼
[1차 파쇄] ─── [[슈레더]] SH-1000 (2x30kW)
    │           대형 플라스틱 → 20~50mm 플레이크
    ▼
[세척] ──────── 마찰세척기 + 수조
    │           이물질, 라벨, 접착제 제거
    ▼
[2차 분쇄] ─── [[해머크러셔]] HC-300 (15kW)
    │           → 5~10mm 균일 플레이크
    ▼
[분급] ──────── [[트위스트스크린]] TS-600
    │           크기별 선별, 과대 입자 재순환
    ▼
[건조] ──────── 원심탈수 + 열풍건조
    │
    ▼
[펠릿화] ───── 압출기 → 재생 펠릿
```

## 주의사항
- **용융점 주의**: PE(130C), PP(170C), PET(260C) → 고속 분쇄 시 발열로 용융 가능
- **이물질**: 금속, 돌 등 → 슈레더 커터 손상 방지를 위한 전처리 필요
- **정전기**: 플라스틱 특성상 정전기 발생 → 제전 장치 설치
- **PVC 혼입**: 고온 시 유해가스(HCl) 발생 → 재질 선별 철저
