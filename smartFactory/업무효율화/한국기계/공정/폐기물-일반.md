# 일반 폐기물 처리 공정

## 공정 흐름도

```
[투입/선별] ── 재활용/매립/소각 분류
    │
    ▼
[1차 파쇄] ─── [[슈레더]] SH-2000 (2x75kW)
    │           혼합 폐기물 → 30~100mm
    ▼
[선별] ──────── 자력+비중+풍력 선별
    │           금속/비금속/가연물 분리
    ▼
[2차 분쇄] ─── [[해머크러셔]] HC-500 (필요시)
    │           가연물 → SRF/RDF 규격 (25~50mm)
    ▼
[에너지화/매립]
```

## 적용 분야
- **건설폐기물**: 콘크리트, 아스팔트, 벽돌 → 파쇄 후 순환골재
- **혼합 생활폐기물**: 대형 폐기물 → 파쇄 후 선별/소각
- **산업폐기물**: 고무, 목재, 섬유 → 파쇄 후 SRF 제조
- **SRF/RDF 고형연료**: 가연성 폐기물 → 규격 파쇄 → 시멘트킬른/발전소

## 주의사항
- **혼재 이물질**: 금속, 돌, 유리 → 사전 선별 또는 슈레더 과부하 보호
- **분진**: 밀폐 + 집진 필수
- **대형물**: 투입구 크기 확인 → SH-2000(2,000mm폭) 권장
