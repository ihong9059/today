# 의약/화학 분쇄 공정

## 공정 흐름도 (의약품 API)

```
[원료 투입] ── 결정/과립 원료
    │
    ▼
[분쇄] ──────── [[롤밀]] RM-300 또는 [[터보밀]] TOP 400TM
    │           → 0.5~5mm (롤밀) 또는 10~100μm (터보밀)
    ▼
[미분쇄] ────── [[핀밀]] PM T-12P (필요시)
    │           → 5~50μm (극미세 요구 시)
    ▼
[분급] ──────── [[트위스트스크린]] TS-400
    │           입도 규격 검증 + 과대 입자 재순환
    ▼
[포장] ──────── 클린룸 환경, 밀폐 포장
```

## 특수 요구사항

### GMP 준수
- 스테인리스(STS316L) 접촉면, 거울면 연마(Ra 0.8 이하)
- 세척 용이 설계 (분해/조립 30분 이내)
- 세척 검증(HPLC/TOC) 기록 유지

### 교차오염 방지
- 제품간 전환 시 완전 분해 세척
- 전용 장비 또는 교체형 접촉부 적용
- 에어샤워 + HEPA 필터 환기

### 열민감 재료 대응
- [[롤밀]] 권장 (압축식 → 저온 분쇄)
- 냉각수 순환 자켓 옵션
- 액화질소 냉각 분쇄 (극저온 필요 시)

### 방폭
- 유기 용매/분진 폭발 위험 → 방폭 모터 + 질소 퍼지
- ATEX/KCs 방폭 인증 적용
