# 음식물 처리 공정

## 공정 흐름도

```
[투입/선별] ── 이물질(비닐, 뼈, 금속) 제거
    │
    ▼
[1차 파쇄] ─── [[슈레더]] SH-1000 (2x30kW)
    │           큰 덩어리 → 20~50mm
    ▼
[2차 분쇄] ─── [[해머크러셔]] HC-300 (15kW)
    │           → 5~10mm 균일 입자
    ▼
[탈수] ──────── 스크류프레스
    │           수분 80% → 60%
    ▼
[건조] ──────── 열풍/마이크로파 건조
    │           수분 60% → 10~15%
    ▼
[퇴비화/사료화]  퇴비 또는 동물 사료 원료
```

## 공정별 추천 장비

| 단계 | 장비 | 모델 | 선정 이유 |
|------|------|------|----------|
| 1차 파쇄 | [[슈레더]] | SH-1000 | 이물질 포함 음식물 저속 파쇄 |
| 2차 분쇄 | [[해머크러셔]] | HC-300 | 균일 입자 → 탈수/건조 효율 향상 |

## 주의사항
- **높은 수분(80%+)**: 장비 부식 방지 코팅(STS316L) 필요
- **이물질**: 비닐, 뼈, 금속 → 사전 선별 필수, 커터 손상 방지
- **악취**: 밀폐형 설비 + 탈취 설비(바이오필터/활성탄) 병행
- **부식성**: 유기산에 의한 부식 → 내산성 재질 적용
