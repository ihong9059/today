# 한국기계 제품 총괄

## 전 제품 비교표

| 제품명 | 분쇄 방식 | 입도 범위 | 처리 용량 | 주요 용도 |
|--------|----------|----------|----------|----------|
| [[터보밀]] | 고속 충격식 | 10~300μm | 20~3,000kg/h | 미분쇄, 폐배터리, 광물, 화학 |
| [[핀밀]] | 핀 충격식 | 5~50μm | 50~500kg/h | 극미분, 양극재박리, 토너, 의약 |
| [[해머크러셔]] | 해머 타격식 | 1~10mm | 100~5,000kg/h | 2차 분쇄, 석회석, 폐배터리 |
| [[롤밀]] | 롤러 압축식 | 0.5~5mm | 100~2,000kg/h | 곡물, 사료, 화학원료 |
| [[조크러셔]] | 조(jaw) 압축식 | 10~100mm | 500~10,000kg/h | 1차 조쇄, 광석, 건설폐기물 |
| [[슈레더]] | 이축 전단식 | 20~100mm | 200~5,000kg/h | 1차 파쇄, 폐배터리, 타이어 |
| [[트위스트스크린]] | 회전 진동식 | 0.1~20mm | 가변 | 분급(입도별 분리) |
| [[실험용밀]] | 다목적 | 가변 | 1~50kg/h | R&D, 소량 시험, 분쇄조건탐색 |

## 장비 선정 플로차트

```
투입 원료
  │
  ├─ 1차 분쇄 (>50mm → 20~100mm)
  │    ├─ 금속/배터리/타이어/대형폐기물 → [[슈레더]]
  │    └─ 광석/콘크리트/건설폐기물 → [[조크러셔]]
  │
  ├─ 2차 분쇄 (1~50mm)
  │    ├─ 충격/타격 분쇄 → [[해머크러셔]]
  │    └─ 압축/균일 입도 → [[롤밀]]
  │
  ├─ 미분쇄 (<1mm)
  │    ├─ 대용량 (>100kg/h) → [[터보밀]]
  │    └─ 극미세 (<50μm) → [[핀밀]]
  │
  └─ 분급 (입도별 분리)
       └─ [[트위스트스크린]]
```

## 용도별 추천 장비 조합

| 용도 | 추천 조합 | 관련 공정 |
|------|----------|----------|
| 폐배터리 재활용 | [[슈레더]] → [[해머크러셔]] → [[핀밀]] → [[트위스트스크린]] | [[폐배터리-재활용]] |
| 음식물 처리 | [[슈레더]] → [[해머크러셔]] | [[음식물-처리]] |
| 광물 미분쇄 | [[조크러셔]] → [[해머크러셔]] → [[터보밀]] → [[트위스트스크린]] | [[광물-분쇄]] |
| 의약/화학 | [[롤밀]] or [[터보밀]] → [[트위스트스크린]] | [[의약-화학]] |
| 폐플라스틱 재활용 | [[슈레더]] → [[해머크러셔]] | [[폐플라스틱-재활용]] |
| 일반 폐기물 | [[슈레더]] → [[해머크러셔]] | [[폐기물-일반]] |
| R&D 시험 | [[실험용밀]] | - |
