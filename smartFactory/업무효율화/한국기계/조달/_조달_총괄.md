# 조달/외주 총괄 가이드

## 제작 흐름

```
[수주 확정]
    │
    ▼
[설계 완료] ── 도면 확정, BOM 산출
    │
    ├─ [핵심 구매품 발주] ── 모터, 베어링, 감속기, 인버터, 전장부품
    │     │                  리드타임: 2~8주
    │     ▼
    │   [입고 검수]
    │
    ├─ [외주 가공 발주] ── 케이싱, 로터, 커터, 프레임, 스크린
    │     │                리드타임: 2~6주
    │     ▼
    │   [입고 검수] ── 치수/표면 검사
    │
    └─ [내부 가공] ── 소형 부품, 조립 지그
          │
          ▼
[조립] ──── 핵심 구매품 + 외주 가공품 + 내부 가공품
    │
    ▼
[시운전/검사] ── 무부하 → 부하 시험
    │
    ▼
[출하]
```

## 핵심 구매품 목록

| 부품 | 적용 장비 | 주요 사양 | 리드타임 | 주요 공급처 |
|------|----------|----------|---------|-----------|
| 모터 | 전 장비 | 5.5~200kW, IE3 이상 | 3~6주 | 현대일렉트릭, LS일렉트릭, ABB, Siemens |
| 감속기 | 슈레더, 롤밀 | 헬리컬/유성 기어, 1:10~1:50 | 3~5주 | SEW, 삼양감속기, 대원강업 |
| 베어링 | 전 장비 | 자동조심 롤러베어링 | 1~3주 | SKF, NSK, NTN, FAG |
| 인버터 | 터보밀, 핀밀 | 7.5~200kW, 벡터 제어 | 2~4주 | LS일렉트릭, ABB, Siemens |
| 유압장치 | 조크러셔, 슈레더 | 유압 파워팩, 실린더 | 3~5주 | 보쉬렉스로스, 유압공업 |
| 전장함 | 전 장비 | PLC, HMI, 배선 | 3~4주 | 내부 전장팀 또는 협력사 |

## 검수 체크리스트

### 구매품 입고 검수
- [ ] 발주 사양서 대비 모델/용량 일치 여부
- [ ] 외관 손상 여부 (운송 중 파손)
- [ ] 인증서/시험성적서 확인 (모터: 효율 등급, 베어링: 정밀도 등급)
- [ ] 수량 확인

### 외주 가공품 입고 검수
- [ ] 도면 대비 치수 측정 (주요 부위 3점 이상)
- [ ] 표면 거칠기 확인
- [ ] 열처리 경도 측정 (경도계)
- [ ] 용접부 비파괴검사 (필요 시)
- [ ] 동밸런싱 성적서 (로터류)
