# 장비선정 FAQ

## Q1. 가장 많이 쓰는 장비 조합은?

**[[슈레더]](1차) + [[해머크러셔]](2차)** 조합이 가장 범용적입니다.
- 폐배터리, 음식물, 폐플라스틱, 일반폐기물 모두 대응
- 추가로 미분쇄 필요 시 [[터보밀]] 또는 [[핀밀]] 추가

## Q2. 처리량 기준으로 장비를 어떻게 선정하나요?

각 장비 사양표의 **중간값**을 기준으로 선정합니다.
- 예: HC-500 처리용량 500~2,000kg/h → 기준값 약 1,000kg/h
- 여유율 20~30% 확보 권장 (피크 부하 대응)
- 정확한 선정은 [[실험용밀]]로 시험 후 결정

→ [[_제품_총괄]]의 비교표와 플로차트를 참조하세요.

## Q3. 소음은 어느 정도인가요?

| 장비 유형 | 소음 수준 | 비고 |
|----------|:--------:|------|
| [[슈레더]] | 75~85 dB | 저속이라 상대적으로 조용 |
| [[해머크러셔]] | 90~100 dB | 방음실 권장 |
| [[터보밀]] | 85~95 dB | 방음실 권장 |
| [[핀밀]] | 85~95 dB | 방음실 권장 |
| [[조크러셔]] | 80~90 dB | 야외 설치 일반적 |

> 85dB 이상은 장시간 노출 시 청력 손상 위험. **방음실** 또는 **귀마개** 필수.

## Q4. 분진은 어떻게 관리하나요?

- **집진기 필수**: 모든 분쇄 장비에 집진 설비 연결
- **밀폐 설계**: 투입구/배출구 밀폐, 음압 유지
- **방폭 지역**: 방폭형 집진기 + 폭발 방지 벤트 적용
- **관리 기준**: 산업안전보건법 작업환경 측정 (6개월 주기)

## Q5. 어떤 장비를 선택해야 할지 모르겠어요.

먼저 3가지를 알려주세요:
1. **무엇을** 분쇄하나요? (재료)
2. **얼마나 곱게** 만들어야 하나요? (목표 입도)
3. **시간당 얼마나** 처리해야 하나요? (처리량)

→ [[_제품_총괄]]의 장비 선정 플로차트를 참조하거나, Claude에게 `/추천`으로 질문하세요.

## Q6. 슈레더와 해머크러셔의 차이는?

| 비교 | [[슈레더]] | [[해머크러셔]] |
|------|---------|-------------|
| 분쇄 방식 | 전단 (찢기) | 충격 (때리기) |
| 입도 범위 | 20~100mm | 1~10mm |
| 적합 재료 | 연성 (타이어, 플라스틱, 금속) | 취성 (석회석, 광물) |
| 속도 | 저속 (10~30rpm) | 고속 (1,000~1,500rpm) |
| 용도 | 1차 파쇄 | 2차 분쇄 |

## Q7. 납기는 얼마나 걸리나요?

- 표준 모델: 4~8주
- 맞춤 제작: 8~16주
- 설치/시운전: 추가 1~2주
