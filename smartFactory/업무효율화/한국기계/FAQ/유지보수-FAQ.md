# 유지보수 FAQ

## Q1. 소모품 교체 주기는?

| 소모품 | 교체 주기 | 해당 장비 |
|--------|:--------:|----------|
| 해머/핀 | 3~6개월 | [[해머크러셔]], [[핀밀]] |
| 커터 블레이드 | 6~12개월 | [[슈레더]] |
| 라이너 | 6~12개월 | [[터보밀]], [[해머크러셔]] |
| 스크린/체 | 3~6개월 | [[트위스트스크린]] |
| 베어링 | 1~2년 | 전 장비 |

> 재료 경도에 따라 교체 주기가 크게 달라집니다. 석영(Mohs 7)은 석회석(Mohs 3) 대비 수명 1/3 수준.
> 상세는 [[유지보수-가이드]] 참조.

## Q2. 비상 시 어떻게 대처하나요?

| 상황 | 즉시 조치 |
|------|----------|
| **과부하 경보** | 투입량 감량 → 역회전 시도 → 이물질 확인 |
| **이상 소음** | 즉시 정지 → 비상정지 버튼 → 내부 확인 |
| **과열 (>80C)** | 정지 → 냉각 대기 → 윤활유 확인 |
| **진동 증가** | 감속 운전 → 볼트 체결 확인 → 밸런스 점검 |

> 모든 비상 시: **1) 비상정지** → **2) 전원차단** → **3) A/S 연락 (031-356-5550)**

## Q3. 원격 A/S가 가능한가요?

**가능합니다.**
- **화상통화**: 현장 작업자가 스마트폰으로 장비 상태 촬영
- **사진 전송**: 마모 부위, 이상 현상 사진 전송
- **원격 진단**: 엔지니어가 화면을 보며 조치 방법 안내
- **한계**: 부품 교체, 정밀 조정은 현장 출장 필요

## Q5. 소모품은 재고가 있나요?

주요 소모품은 **상시 재고** 보유:
- 해머, 커터 블레이드, 라이너, 스크린
- 베어링, V벨트, 오일씰

특수 사양(내마모/방폭)은 **2~4주** 소요.
