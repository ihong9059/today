# 분쇄 원리 총론

## 4대 분쇄 메커니즘

### 1. 충격식 (Impact)
- **원리**: 고속으로 회전하는 해머/블레이드/핀이 재료를 타격
- **적합 재료**: 취성(brittle) 재료 - 광물, 세라믹, 화학원료
- **대표 장비**: [[터보밀]], [[해머크러셔]], [[핀밀]]
- **장점**: 높은 분쇄비, 대용량 처리
- **단점**: 발열, 마모 빠름

### 2. 전단식 (Shear)
- **원리**: 두 날이 맞물려 가위처럼 재료를 잘라냄
- **적합 재료**: 연성(ductile) 재료 - 플라스틱, 고무, 타이어, 금속
- **대표 장비**: [[슈레더]]
- **장점**: 연성 재료 대응, 저소음, 저분진
- **단점**: 미세 분쇄 불가

### 3. 압축식 (Compression)
- **원리**: 두 면 사이에서 재료를 눌러 깨뜨림
- **적합 재료**: 경질(hard) 재료 - 암석, 광물, 콘크리트
- **대표 장비**: [[조크러셔]], [[롤밀]]
- **장점**: 에너지 효율 높음, 발열 적음
- **단점**: 분쇄비 낮음

### 4. 마찰식 (Attrition)
- **원리**: 재료 표면을 문질러 깎아냄
- **적합 재료**: 표면 가공, 박리
- **대표 장비**: [[핀밀]] (부분적), 볼밀
- **장점**: 극미세 분쇄 가능
- **단점**: 에너지 소비 높음, 저속

## 분쇄비 (Reduction Ratio)

분쇄비 = 투입 입도 / 배출 입도

| 장비 | 일반적 분쇄비 | 비고 |
|------|:----------:|------|
| [[조크러셔]] | 5~10:1 | 1차 조쇄 |
| [[슈레더]] | 5~20:1 | 1차 파쇄 |
| [[해머크러셔]] | 10~50:1 | 2차 분쇄 |
| [[롤밀]] | 3~10:1 | 균일 분쇄 |
| [[터보밀]] | 50~500:1 | 미분쇄 |
| [[핀밀]] | 100~5,000:1 | 극미분쇄 |

## 에너지 법칙

| 법칙 | 적용 범위 | 내용 |
|------|----------|------|
| Kick의 법칙 | 조분쇄 (>50mm) | 에너지 = 크기비의 log에 비례 |
| Bond의 법칙 | 중간분쇄 (0.05~50mm) | 에너지 = 크기의 제곱근에 비례 |
| Rittinger의 법칙 | 미분쇄 (<0.05mm) | 에너지 = 새로운 표면적에 비례 |

> **핵심**: 입도가 작아질수록 에너지 소비가 기하급수적으로 증가합니다.
> 따라서 **다단계 분쇄**(각 단계에 적합한 장비 선정)가 에너지 효율의 핵심입니다.
