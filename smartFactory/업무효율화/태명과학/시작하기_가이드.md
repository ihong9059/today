# 태명과학 AI 컨설팅 시뮬레이션 - 시작하기 가이드

Obsidian + Claude Code를 사용하여 FRITSCH 장비 추천 AI 컨설턴트를 실행하는 방법입니다.

---

## 1단계: Obsidian에서 Vault 열기

1. **Obsidian** 실행
2. 왼쪽 하단 **Vault 열기** (Open another vault) 클릭
3. **폴더를 Vault로 열기** 선택
4. 아래 경로를 선택:
   ```
   C:\todo\today\smartFactory\업무효율화\태명과학
   ```
5. "신뢰하고 열기" 클릭

### Vault가 열리면 보이는 것들

왼쪽 파일 탐색기에 아래 폴더가 보입니다:

```
태명과학/
  장비/          ← FRITSCH 장비 15종 사양서
  부속품/        ← 호환 매트릭스, 재질 6종
  시료/          ← 산업별 분쇄 조건표
  입도분석/      ← 입도 기초, 산업별 기준
  사례/          ← 실제 적용 사례 3건
  템플릿/        ← 견적서, 리포트 양식
  FAQ/           ← 자주 묻는 질문
  CLAUDE.md      ← AI 행동 규칙 (시스템 프롬프트)
  index.md       ← 대시보드
```

> **확인 포인트**: `index.md`를 클릭하면 대시보드가 보입니다.
> Dataview 플러그인이 필요하므로, 설치 안내가 뜨면 설치해주세요.

---

## 2단계: Dataview 플러그인 설치 (최초 1회)

대시보드(index.md)에서 `dataview` 코드블록이 동작하려면:

1. **설정** (좌측 하단 톱니바퀴) → **커뮤니티 플러그인**
2. **커뮤니티 플러그인 켜기** (안전 모드 끄기)
3. **찾아보기** → "dataview" 검색 → **설치** → **활성화**
4. `index.md`를 다시 열면 장비/재질/시료 목록 테이블이 표시됩니다

---

## 3단계: Claude Code에서 시뮬레이션 실행

> **핵심**: Obsidian은 데이터를 보는 용도이고, AI 컨설팅은 **Claude Code**에서 실행합니다.
> Claude Code가 이 Vault의 파일들을 읽고, CLAUDE.md의 규칙에 따라 응답합니다.

### 터미널에서 Claude Code 실행

```bash
cd C:\todo\today\smartFactory\업무효율화\태명과학
claude
```

이렇게 하면 Claude Code가 이 폴더를 작업 디렉토리로 인식하고,
`CLAUDE.md`를 자동으로 읽어서 "태명과학 기술영업 전문 컨설턴트" 역할을 수행합니다.

---

## 4단계: 사용예시 1 실행 - 장비+부속품 패키지 추천

### 시나리오

> 고객이 전화로 문의합니다:
> "LFP 양극재를 5마이크론까지 분쇄하고 싶어요.
>  현재 2mm 정도인데, 100g씩 처리하고, 금속 오염이 절대 안 됩니다.
>  건식으로 하고 싶고, R&D 목적입니다."

### 실행 방법

Claude Code 프롬프트에 아래와 같이 입력합니다:

```
/추천 LFP양극재, Mohs5, 2mm→5μm, 100g, 금속오염불허, 건식, R&D
```

### Claude가 하는 일 (내부 동작)

1. **CLAUDE.md** 읽기 → "필수 확인 8가지" 체크리스트로 입력값 검증
2. **장비/_장비_총괄.md** 참조 → 플로차트에서 적합 장비 선정
   - 목표 5μm → 0.1~50μm 범위 → P-7 Premium 후보
   - 100g 소량 → P-7 (2x80ml) 적합
3. **부속품/_부속품_호환_매트릭스.md** 참조 → 재질/용량 호환 확인
   - 금속오염 불허 → ZrO2 (지르코니아) 선택
   - P-7 80ml + ZrO2 → "O" (호환 확인)
4. **부속품/분쇄볼-가이드.md** 참조 → 볼 직경 선정
   - 5μm 목표 → 3mm 볼 추천
5. **시료/배터리_분쇄조건.md** 참조 → 분쇄 조건 제안

### 예상 응답 형태

```markdown
## 장비+부속품 패키지 추천

### 시료 분석
| 항목 | 내용 |
|------|------|
| 시료 | LFP 양극재 (LiFePO4) |
| 경도 | Mohs 5 (중경도) |
| 현재 입도 | 2mm |
| 목표 입도 | 5μm |
| 처리량 | 100g/회 |
| 오염 허용 | 금속오염 불허 |
| 건/습식 | 건식 |
| 용도 | R&D |

### 추천 패키지

**장비**: [[P7-Premium]] (Planetary Micro Mill)
- 최대 95G 원심가속도, 0.1~50μm 범위
- 2mm→5μm 단일 장비로 달성 가능

**용기**: ZrO2 (지르코니아) 80ml x 2개
- [[_부속품_호환_매트릭스]] 확인: P-7 80ml + ZrO2 = O (호환)
- 금속오염 Zero (비금속 재질)

**분쇄볼**: ZrO2 3mm, 약 200g
- 5μm 목표에 3mm 볼 최적 ([[분쇄볼-가이드]] 참조)

### 추천 분쇄 조건
| 항목 | 설정값 |
|------|--------|
| 회전속도 | 700rpm |
| 분쇄시간 | 20min (5min x 4cycle) |
| 휴지시간 | 1min (과열방지) |
| 볼:시료 비 | 10:1 |
| 방향전환 | YES |

### 참고 문서
- [[배터리_분쇄조건]] - LFP/NMC/LCO별 조건표
- [[ZirconiumOxide-지르코니아]] - 재질 상세 스펙
```

## 5단계: 결과 확인 및 활용

### Obsidian에서 교차 확인

Claude가 응답에서 언급한 문서를 Obsidian에서 직접 열어 확인할 수 있습니다:

1. `Ctrl+O` → 파일 이름 검색 (예: "P7-Premium")
2. 해당 문서 열기 → 상세 사양 확인
3. `[[링크]]`를 클릭하면 관련 문서로 이동

### 추가 질문 예시

추천 결과를 받은 후, 이어서 질문할 수 있습니다:

```
/부속품 P-7 80ml 질화규소
```
→ 대안 재질 호환 확인

```
/견적 P-7 Premium + ZrO2 80ml x2 + ZrO2 볼 3mm 200g
```
→ 견적서 초안 생성

```
/입도해석 D10=2.3, D50=5.1, D90=12.8 배터리
```
→ 분쇄 결과 합격 여부 판정

## 다른 사용예시 빠른 참조

### 예시 2: 부속품 호환 확인
```
/부속품 P-5 Classic 500ml 질화규소
```
→ 비호환 안내 + 대안 제시

### 예시 3: 재질 추천
```
/재질 배터리양극재, 금속오염불허
```
→ ZrO2 추천 + 의사결정 트리

### 예시 4: 시료테스트 설계
```
/테스트설계 탄산칼슘 D50<5μm
```
→ 장비/조건 자동 설계

### 예시 5: 입도분석 결과 해석
```
/입도해석 D10=2.3, D50=15.2, D90=45.8 제약API
```
→ 산업별 기준 대비 합격/불합격 판정

## 문제 해결

| 증상 | 해결 |
|------|------|
| index.md에 dataview 테이블이 안 보임 | 설정 → 커뮤니티 플러그인 → dataview 설치/활성화 |
| Claude가 CLAUDE.md를 인식 안 함 | `cd` 명령으로 태명과학 폴더에서 claude 실행 확인 |
| [[링크]]가 빨간색 (파일 없음) | 왼쪽 파일탐색기에서 해당 파일 존재 여부 확인 |
| 그래프 뷰가 비어있음 | 좌측 사이드바 → 그래프 아이콘 클릭 |

## Vault 그래프 뷰 활용

Obsidian 좌측 사이드바에서 **그래프 뷰** 아이콘을 클릭하면,
48개 문서 간의 연결 관계가 시각화됩니다:

- 중심 노드: `_장비_총괄`, `_부속품_호환_매트릭스`, `_재질_총괄_비교`
- 장비 → 부속품 → 재질로 이어지는 추천 흐름이 보입니다
- 노드를 클릭하면 해당 문서로 바로 이동
