# 태명과학 장비 컨설팅 Wiki

## 이것은 무엇인가?

FRITSCH 분쇄/분석 장비에 대한 시뮬레이션 Wiki입니다.
Obsidian Vault + Claude AI를 결합하여, 시료 특성에 맞는 장비/부속품/재질을 자동 추천하고
입도분석 결과를 해석하며, 견적서 초안까지 생성할 수 있습니다.

> 본 Wiki의 데이터는 시뮬레이션 목적이며, 실제 판매 가격은 포함되어 있지 않습니다.
> 장비 사양은 FRITSCH 실제 카탈로그에 근거하되, 일부 수치는 교육/데모용으로 조정되었습니다.

## 빠른 시작

1. **Obsidian** 설치 후 이 폴더를 Vault로 열기
2. `CLAUDE.md`가 AI 컨설턴트의 역할 정의 (시스템 프롬프트)
3. Claude에게 아래 예시처럼 질문

## 사용 예시

### 1. 장비+부속품 패키지 추천
```
/추천 LFP양극재, Mohs5, 2mm→5μm, 100g, 금속오염불허, 건식, R&D
```
→ [[P7-Premium]] + ZrO2 80ml 용기 + 3mm ZrO2 볼 추천, 조건표 제시

### 2. 부속품 호환 확인
```
/부속품 P-5 Classic 500ml 질화규소
```
→ [[_부속품_호환_매트릭스]] 확인 결과: **비호환** (P-5 500ml에 Si3N4 없음)
→ 대안: ZrO2 500ml 또는 Si3N4 250ml(P-6/P-7)

### 3. 재질 추천
```
/재질 배터리양극재, 금속오염불허
```
→ ZrO2 추천 (높은 경도 + 금속오염 없음) → [[ZirconiumOxide-지르코니아]]

### 4. 시료테스트 설계
```
/테스트설계 탄산칼슘 D50<5μm
```
→ 장비: P-6 Premium, 재질: ZrO2 250ml, 볼: 3mm, 500rpm, 15min 조건 제안

### 5. 입도분석 결과 해석
```
/입도해석 D10=2.3, D50=15.2, D90=45.8 제약API
```
→ [[산업별_입도기준]] 참조: D50 적합(5~25μm), D90 적합(<75μm), Span=2.86 적합(<3.0) → **합격**

## 시뮬레이션 데이터 안내

- 장비 사양: FRITSCH 공식 카탈로그 기반 (2024~2025)
- 분쇄 조건/결과: 실험실 경험 기반 시뮬레이션 값
- 가격: 실제 판매 가격 미포함 (견적서 템플릿에 "XX만원" 표기)
- 사례: 가상의 고객 시나리오 (교육/데모 목적)
