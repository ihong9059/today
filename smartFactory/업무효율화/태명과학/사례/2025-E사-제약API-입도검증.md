# E사 - 제약 API 입도검증

## 고객 요구사항

| 항목 | 내용 |
|------|------|
| 고객 | E제약 품질관리(QC)팀 |
| 용도 | API 원료 입고검사 (일상 검증) |
| 시료 | 경구용 API (정제 원료) |
| 기준 | D50 5~25μm, D90 <75μm (USP <429>) |
| 빈도 | 매 입고 로트(Lot)마다 측정 |
| 요구 | 재현성 CV <3%, 규격 적합 |

## 장비 구성

| 항목 | 선택 | 사유 |
|------|------|------|
| 장비 | [[A22-Nano]] | 레이저 회절, 높은 재현성 |
| 분산 | 습식분산유닛 (정제수) | API 습식 분산 표준 |

## 측정 조건

| 파라미터 | 설정 |
|----------|------|
| 분산매 | 정제수 + 0.1% Tween 80 (습윤제) |
| 초음파 | 30초 (응집 해소) |
| 측정 시간 | ~1분 |
| 반복 | 3회 측정 → 평균 |

## 결과 (3개 로트 검증)

| 로트 | D10 | D50 | D90 | Span | 판정 |
|------|-----|-----|-----|------|------|
| Lot-A | 3.5μm | 12.8μm | 38.2μm | 2.71 | 합격 |
| Lot-B | 4.1μm | 14.5μm | 42.1μm | 2.62 | 합격 |
| Lot-C | 3.2μm | 11.9μm | 35.8μm | 2.74 | 합격 |

**재현성:** D50 CV = 1.8% → USP <429> 적합 (**CV < 3% 통과**)

→ [[산업별_입도기준]] 제약 API(경구) 기준 전 로트 **합격**

## 고객 피드백
- 기존 장비(타사) 대비 재현성 2배 향상
- 측정 시간 3분 → 1분으로 단축
- QC 일상검사 표준 장비로 채택
- 연간 유지보수 계약 체결

## 핵심 포인트
1. **A-22 Nano** 높은 재현성 (CV <2%)
2. 습식 분산 + 초음파로 응집 해소
3. USP <429> 규격 완벽 충족
4. 3분 → 1분 측정 시간 단축 → QC 효율 향상
