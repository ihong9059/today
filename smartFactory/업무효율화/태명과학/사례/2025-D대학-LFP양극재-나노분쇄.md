# D대학 - LFP 양극재 나노분쇄

## 고객 요구사항

| 항목 | 내용 |
|------|------|
| 고객 | D대학 에너지소재공학과 |
| 시료 | LFP (LiFePO4) 양극재 |
| 현재 입도 | ~2mm (합성 후 분말) |
| 목표 입도 | D50 < 5μm |
| 처리량 | 100g/batch |
| 금속 오염 | **절대 불가** (Fe/Cr/Ni) |
| 분쇄 방식 | 건식 |
| 용도 | R&D (논문 투고용) |

## 장비 구성

| 항목 | 선택 | 사유 |
|------|------|------|
| 장비 | [[P7-Premium]] | 95G 고에너지, 나노 도달 |
| 용기 | ZrO2 80ml | 금속오염 없음, P-7 최적 |
| 볼 | ZrO2 3mm | 목표 ~3μm에 적합 |
| BPR | 10:1 (무게비) | 표준 고에너지 조건 |

## 분쇄 조건

| 파라미터 | 설정 |
|----------|------|
| rpm | 700 |
| 시간 | 15분 |
| 방식 | 건식 |
| 프로그램 | 5분 분쇄 → 1분 휴지 → 5분 분쇄 → 1분 휴지 → 5분 분쇄 |

> 연속 분쇄 대신 간헐 분쇄(Interval)로 온도 상승 억제

## 결과

| 지표 | 값 | 기준 | 판정 |
|------|-----|------|------|
| D10 | 1.1μm | - | - |
| D50 | 3.2μm | <5μm | **합격** |
| D90 | 8.5μm | <30μm | **합격** |
| Span | 2.3 | <2.5 | **합격** |

→ [[산업별_입도기준]] 배터리 양극재 기준 **전 항목 합격**

## 측정 장비
[[A22-Nano]] (습식 분산, 에탄올)

## 고객 피드백
- 논문 투고용 데이터로 활용
- 추가로 NMC622 양극재 분쇄 의뢰 예정
- P-7 Premium + ZrO2 80ml + A-22 Nano 패키지 구매 진행

## 핵심 포인트
1. **ZrO2 재질**로 금속오염 Zero 달성
2. **간헐 분쇄**(5분+1분 휴지)로 열민감 시료 대응
3. 95G 고에너지로 15분 내 D50 3.2μm 달성
4. 습식 입도 측정(에탄올)으로 재현성 확보
