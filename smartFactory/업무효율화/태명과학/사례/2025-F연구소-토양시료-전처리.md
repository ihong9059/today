# F연구소 - 토양 시료 전처리

## 고객 요구사항

| 항목 | 내용 |
|------|------|
| 고객 | F국가환경연구소 |
| 시료 | 토양 (건조, 자갈 제거 후) |
| 현재 입도 | ~5mm (건조+1차 체별 후) |
| 목표 입도 | <75μm (#200 mesh 통과) |
| 처리량 | 200g/batch |
| 목적 | XRF 중금속 분석 전처리 |
| 빈도 | 일 20~50 시료 |

## 장비 구성

| 항목 | 선택 | 사유 |
|------|------|------|
| 장비 | [[P14-로터밀]] | 고속 전단, 대량 처리, 빠름 |
| 체링 | SS 0.08mm | 75μm 이하 배출 |

## 분쇄 조건

| 파라미터 | 설정 |
|----------|------|
| rpm | 14,000 |
| 시간 | 3분 |
| 체링 | SS 0.08mm |
| 투입 | 호퍼 투입 (~200g) |

## 결과

| 지표 | 값 | 기준 | 판정 |
|------|-----|------|------|
| 통과율 | 95% (<75μm) | >90% | **합격** |
| 처리 시간 | 3분/batch | <5분 | **합격** |
| 회수율 | 95% | >90% | **합격** |

→ [[산업별_입도기준]] 광물분석(XRF) 기준 **합격**

## 고객 피드백
- 기존 수동 유발(Mortar) 전처리 대비 10배 속도
- 일 50시료 처리 가능 (기존 10시료 한계)
- 회수율 95%로 시료 손실 최소
- P-14 로터밀 2대 + 여분 체링 5세트 구매

## 핵심 포인트
1. **P-14 로터밀** 고속(14,000rpm) → 3분 내 완료
2. SS 0.08mm 체링으로 75μm 이하 직접 배출
3. 대량 시료(200g) 한 번에 처리
4. XRF 전처리 자동화 → 일일 처리량 5배 향상
