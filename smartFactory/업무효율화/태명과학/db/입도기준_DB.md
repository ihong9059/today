# 산업별 입도 기준 데이터베이스

각 산업/용도별 입도 합격 기준(D50, D90, Span)과 불합격 시 개선 방안을 정리한 테이블입니다.

## 합격 기준 테이블

| 산업 | 용도 | D50 기준 | D90 기준 | Span | 비고 |
|------|------|----------|----------|------|------|
| 제약 API (경구) | 정제/캡슐 | 5~25um | <75um | <3.0 | USP <429> |
| 제약 API (흡입) | 흡입제 | 1~5um | <10um | <2.0 | 폐 도달 입도 |
| 배터리 양극재 | LFP/NMC | 3~15um | <30um | <2.5 | 금속오염 불가 |
| 배터리 전해질 | 전고체 | <5um | <15um | <3.0 | 가능한 미세하게 |
| 세라믹 분말 | 소결용 | 0.5~5um | <15um | <3.0 | 소결밀도 영향 |
| 식품 분말 | 미분말 | 10~50um | <100um | - | 식감/용해도 |
| 광물 분석 | XRF 전처리 | <75um | <150um | - | #200 mesh |
| 광물 분석 | XRD 전처리 | <45um | <100um | - | #325 mesh |
| 시멘트 | 제조 | 15~25um | <45um | <2.0 | 강도/수화 |
| 안료/도료 | 코팅 | 1~10um | <25um | <2.5 | 광택/은폐력 |
| 화장품 | 파운데이션 | 5~15um | <30um | <2.5 | 피부 촉감 |
| 토너 | 프린터 | 5~10um | <20um | <2.0 | 해상도 |

## 불합격 시 개선 방안

| 문제 | 원인 | 대책 |
|------|------|------|
| D50 너무 큼 | 분쇄 부족 | rpm 증가, 시간 연장, 볼 크기 감소 |
| D50 너무 작음 | 과분쇄 | rpm 감소, 시간 단축 |
| D90 너무 큼 | 조대입자 잔류 | 단계적 분쇄, 체 분급 |
| Span 너무 큼 | 불균일 분포 | 볼 크기 단일화, 분급 |
| 이봉분포 | 재응집/혼합 | PCA 첨가, 습식 전환 |
