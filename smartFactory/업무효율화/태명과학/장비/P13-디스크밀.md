# PULVERISETTE 13 - 디스크밀 (Disc Mill)

## 개요
2개의 디스크 사이에서 마찰+전단으로 분쇄하는 방식.
연속 투입이 가능하여 대량 전처리에 적합합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 방식 | 마찰 + 전단 |
| 달성 입도 | 50~500μm |
| 처리량 | ~500g/batch, 연속 투입 가능 |
| 디스크 재질 | Al2O3(코런덤), WC, SS |
| Gap 조절 | 0~25mm |

## 적합 용도
- 곡물/곡분 전처리
- 광물 전처리 (XRF/XRD)
- 화학원료 분쇄
- 중경도 이하 시료의 연속 분쇄

## 디스크 재질별 용도

| 재질 | 추천 시료 |
|------|-----------|
| Al2O3 (코런덤) | 광물, 세라믹, 화학원료 |
| WC (초경합금) | 경질 광석 |
| SS (스테인리스) | 식품, 의약 |
