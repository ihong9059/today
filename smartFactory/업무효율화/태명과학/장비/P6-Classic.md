# PULVERISETTE 6 Classic Line

## 개요
1개 분쇄 스테이션의 소형 유성볼밀.
소량 시료 연구에 최적화된 경제적 모델입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 1개 |
| 사용 가능 용기 | 80ml, 250ml, 500ml |
| 최대 회전속도 | 400rpm |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 1~100μm |
| 최대 처리량 | 1 x 500ml |
| 에너지 등급 | 표준 |

## 적합 용도
- 소량 연구 분쇄
- 시료 전처리
- 교육/실습용
- 단일 시료 반복 테스트
