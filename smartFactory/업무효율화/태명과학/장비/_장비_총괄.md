## 장비 선정 플로차트

```
시료 투입 크기 확인
│
├─ 조쇄 필요 (>10mm)
│  └─ [[P1-조크러셔]] (압축파쇄, gap 조절)
│
├─ 연성/섬유질 시료?
│  ├─ YES → 절단 가능?
│  │        ├─ YES → [[P15-컷팅밀]] (플라스틱/고무/목재)
│  │        └─ NO  → [[P14-로터밀]] (토양/식품/사료)
│  └─ NO ↓
│
├─ 목표 입도?
│  ├─ 50~500μm (조분쇄) → [[P13-디스크밀]]
│  ├─ 1~100μm (범용 미세분쇄)
│  │  ├─ 대용량(4스테이션) → [[P5-Classic]] 또는 [[P5-Premium]]
│  │  └─ 소용량(1스테이션) → [[P6-Classic]] 또는 [[P6-Premium]]
│  ├─ 0.1~10μm (고에너지 미세)
│  │  └─ [[P5-Premium]], [[P6-Premium]]
│  └─ <1μm (나노)
│     └─ [[P7-Premium]] (최고 95G) 또는 [[P7-Classic]]
│
└─ 입도 측정
   ├─ 나노~mm 범위 → [[A22-Nano]] (레이저회절)
   ├─ 마이크로 QC → [[A22-Micro]]
   ├─ 형상 분석 필요 → [[A28-이미지사이저]]
   └─ 체분석(ISO/ASTM) → [[A3-체분석기]]
```

## Classic vs Premium 비교

| 항목 | Classic | Premium |
|------|---------|---------|
| 최대 회전속도 | 400rpm | 800~1,100rpm |
| 에너지 | 표준 | 고에너지 |
| 프로그래밍 | 기본 | 고급(다단계 프로그램) |
| 가격대 | 보급형 | 고급형 |
| 추천 | 일반 연구/QC | 나노분쇄/기계적 합금화 |
