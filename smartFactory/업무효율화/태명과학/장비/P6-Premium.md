# PULVERISETTE 6 Premium Line

## 개요
1개 분쇄 스테이션, 최대 800rpm의 고에너지 소형 유성볼밀.
소량 시료의 고에너지 분쇄에 최적화되었습니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 1개 |
| 사용 가능 용기 | 80ml, 250ml, 500ml |
| 최대 회전속도 | 800rpm |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 0.5~100μm |
| 최대 처리량 | 1 x 500ml |
| 에너지 등급 | 고에너지 |
| 프로그래밍 | 다단계 프로그램 |

## 적합 용도
- 고에너지 소량 분쇄
- 기계적 합금화 (소규모)
- 배터리 소재 연구
- 서브마이크론 분쇄
