# ANALYSETTE 28 ImageSizer

## 개요
동적 이미지 분석(Dynamic Image Analysis) 방식의 입도/형상 분석기.
개별 입자의 크기뿐 아니라 형상(원형도, 종횡비)까지 측정합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 측정 원리 | 동적 이미지 분석 |
| 측정 범위 | 20~20,000μm |
| 형상 파라미터 | 원형도(Circularity), 종횡비(Aspect Ratio), Convexity 등 |
| 분산 방식 | 건식 (진동 피더) |
| 카메라 | 고속 CCD |
| 규격 준거 | ISO 13322-2 |

## 적합 용도
- 형상 분석이 필요한 시료
- 비구형 입자 (섬유, 바늘형, 판상 등)
- 펠릿/과립 QC
- 레이저 회절로 정확도가 떨어지는 시료

## 레이저 회절 vs 이미지 분석

| 항목 | 레이저 회절 (A-22) | 이미지 분석 (A-28) |
|------|--------------------|--------------------|
| 측정 범위 | 0.01~4,000μm | 20~20,000μm |
| 형상 정보 | X | O (원형도, 종횡비) |
| 나노 측정 | O (A-22 Nano) | X |
| 비구형 정확도 | 낮음 (구 가정) | 높음 (실제 형상) |
| 속도 | 빠름 | 중간 |
