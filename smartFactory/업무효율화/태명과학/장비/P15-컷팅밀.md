# PULVERISETTE 15 - 컷팅밀 (Cutting Mill)

## 개요
회전 블레이드로 시료를 절단하는 방식.
충격으로 파괴할 수 없는 연성(Ductile) 시료 전용 장비입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 방식 | 절단 (Cutting) |
| 회전속도 | 300~3,000rpm |
| 달성 입도 | 250~5,000μm |
| 최대 처리량 | ~3,000ml |
| 입도 조절 | 바닥 체(Bottom Sieve) 교체 |
| 투입구 크기 | 대형 호퍼 |

## 적합 용도
- 플라스틱 (PE, PP, PVC 등)
- 고무/엘라스토머
- 목재/칩
- 식품 (건조)
- 종이/판지
- 섬유/직물

## P-14 로터밀 vs P-15 컷팅밀

| 항목 | P-14 로터밀 | P-15 컷팅밀 |
|------|-------------|-------------|
| 방식 | 충격+전단 | 절단 |
| rpm | 4,000~20,000 | 300~3,000 |
| 입도 | 40~3,000μm | 250~5,000μm |
| 적합 | 취성~중경도 | 연성/탄성 |
| 예시 | 토양, 식품 | 플라스틱, 고무 |

## 사용 시 주의사항
- 경질 시료(금속, 세라믹) 투입 금지 - 블레이드 손상
- 극저온 분쇄(Cryogenic): 액질소로 취화시킨 후 절단 가능
- 블레이드 교체 주기: 사용량에 따라 6개월~2년
