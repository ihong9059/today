# PULVERISETTE 1 - 조크러셔 (Jaw Crusher)

## 개요
압축 파쇄 방식의 조쇄기(Primary Crusher).
대형 경질 시료의 1차 분쇄(전처리)용 장비입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 방식 | 압축 파쇄 |
| 투입 크기 | 최대 ~95mm (모델에 따라) |
| 출구 Gap | 0~15mm 조절 가능 |
| 달성 입도 | 0.3~15mm |
| 처리량 | ~500g/batch |
| 조(Jaw) 재질 | 망간강, SS, WC, ZrO2 |

## 적합 용도
- 광석/광물 전처리
- 슬래그 분쇄
- 세라믹/유리 전처리
- 콘크리트/건축재
- 볼밀 투입 전 조쇄

## 전형적 워크플로
```
대형 시료 (>10mm)
  → P-1 조크러셔 (Gap 1~3mm)
    → 볼밀 (P-5/P-6/P-7)
      → 목표 입도 달성
```

## Jaw 재질 선택

| 재질 | 경도 | 추천 시료 |
|------|------|-----------|
| 망간강 | 표준 | 범용 |
| SS | GMP | 식품/의약 |
| WC | 최고 | 초경질 광석 |
| ZrO2 | 고경도+무오염 | 순수성 필요 시료 |
