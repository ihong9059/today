# ANALYSETTE 22 MicroTec Plus - 레이저 입도분석기

## 개요
레이저 회절 방식의 산업용 입도분석기.
마이크로 영역(0.5~4,000μm) 측정에 최적화된 QC 전용 모델입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 측정 원리 | 레이저 회절 (Mie/Fraunhofer) |
| 측정 범위 | 0.5~4,000μm |
| 분산 방식 | 습식 + 건식 가능 |
| 재현성 | <1% (CV) |
| 측정 시간 | ~1분 |
| 규격 준거 | ISO 13320 |

## 적합 용도
- 산업용 QC 일상 검사
- 시멘트/광물 입도 관리
- 식품 분말 품질 검사
- 화학원료 입도 모니터링

## A-22 Nano 대비 포지셔닝
- 나노 영역 불필요 시 경제적 선택
- 산업 현장 QC에 특화
- 조작 간편, 유지보수 용이
