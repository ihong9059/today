# ANALYSETTE 3 - 진동 체분석기 (Vibratory Sieve Shaker)

## 개요
진동 방식의 체분석기.
ASTM/ISO 규격 시험체를 사용하여 입도 분포를 측정합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분석 원리 | 진동 체분석 (Sieve Analysis) |
| 사용 가능 체 | 20μm~25mm (표준 시험체) |
| 체 적층 | 최대 8~10단 |
| 진동 방식 | 전자기 진동 |
| 진폭 조절 | 가변 (0~3mm) |
| 규격 준거 | ASTM E11, ISO 3310 |

## 적합 용도
- 규격 시험 (ASTM/ISO/KS 입도 시험)
- 골재/모래 입도 분석
- 식품 분말 체별
- 의약품 체별 시험
- 분쇄 결과 확인 (1차 스크리닝)
