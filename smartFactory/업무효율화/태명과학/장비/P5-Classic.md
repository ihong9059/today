# PULVERISETTE 5 Classic Line

## 개요
4개 분쇄 스테이션을 갖춘 범용 유성볼밀(Planetary Ball Mill).
연구실에서 가장 널리 사용되는 표준 모델입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 4개 |
| 사용 가능 용기 | 80ml, 250ml, 500ml |
| 최대 회전속도 | 400rpm |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 1~100μm |
| 최대 처리량 | 4 x 500ml |
| 에너지 등급 | 표준 |
| 프로그래밍 | 기본 (시간/rpm 설정) |

## 적합 용도
- 범용 연구 분쇄
- 혼합(Mixing)
- 콜로이드(Colloidal) 분쇄
- 기계적 합금화 (저에너지)
- QC 시료 전처리
