# PULVERISETTE 5 Premium Line

## 개요
4개 분쇄 스테이션, 최대 800rpm의 고에너지 유성볼밀.
프로그래밍 가능한 다단계 분쇄로 정밀 제어가 가능합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 4개 |
| 사용 가능 용기 | 80ml, 250ml, 500ml |
| 최대 회전속도 | 800rpm |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 0.5~100μm |
| 최대 처리량 | 4 x 500ml |
| 에너지 등급 | 고에너지 |
| 프로그래밍 | 다단계 프로그램 (가속/감속/휴지) |

## 적합 용도
- 고에너지 분쇄
- 기계적 합금화 (Mechanical Alloying)
- 서브마이크론 분쇄
- 나노 복합재 제조
- 반응성 분쇄 (Reactive Milling)

## Classic 대비 장점
- 2배 회전속도 (400 → 800rpm) = 4배 에너지
- 다단계 프로그래밍으로 온도 제어
- 0.5μm까지 도달 가능
