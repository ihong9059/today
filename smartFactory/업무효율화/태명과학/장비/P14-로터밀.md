# PULVERISETTE 14 Classic - 로터밀 (Rotor Mill)

## 개요
충격+전단 복합 방식의 고속 로터밀.
체링(Sieve Ring) 교체로 출구 입도를 조절합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 방식 | 충격 + 전단 (고속 로터) |
| 회전속도 | 4,000~20,000rpm (가변) |
| 달성 입도 | 40~3,000μm |
| 최대 처리량 | ~1,000ml |
| 입도 조절 | 체링 교체 (0.08~6.0mm) |
| 투입 방식 | 호퍼 투입 |

## 적합 용도
- 토양 시료 전처리
- 식품/사료 분쇄
- 섬유질 시료
- 건조 식물체
- 의약 부형제

## 체링 크기별 출구 입도

| 체링 개구부 | 예상 출구 입도 |
|-------------|----------------|
| 0.08mm | ~80μm |
| 0.12mm | ~120μm |
| 0.2mm | ~200μm |
| 0.5mm | ~500μm |
| 1.0mm | ~1,000μm |
| 2.0mm | ~2,000μm |

## 사용 시 주의사항
- 수분 함량 높은 시료: 건조 후 투입 권장
- 유지 함량 높은 시료: 냉동 후 투입 (초콜릿, 치즈 등)
- 체링 재질: SS(스테인리스) 표준, Ti(티타늄) 옵션
