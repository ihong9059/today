# PULVERISETTE 7 Premium Line

> FRITSCH 최고 모델. 95G의 원심가속도로 0.1μm 나노 영역 도달.

## 개요
2개 분쇄 스테이션, 최대 1,100rpm, 95G 원심가속도의 최고급 유성볼밀.
배터리 양극재, 세라믹 나노입자, 기능성 소재 연구의 표준 장비입니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 2개 |
| 사용 가능 용기 | 20ml, 45ml, 80ml |
| 최대 회전속도 | 1,100rpm |
| 최대 원심가속도 | 95G |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 0.1μm (100nm) |
| 최대 처리량 | 2 x 80ml |
| 에너지 등급 | 최고 에너지 |
| 프로그래밍 | 고급 다단계 (가속/감속/휴지/반복) |

## 적합 용도
- 나노 분쇄 (0.1μm 도달)
- 기계적 합금화 (Mechanical Alloying)
- 배터리 양극재 (LFP, NMC, 전고체전해질)
- 세라믹 나노입자 제조
- 기능성 소재 합성
- 반응성 분쇄 (Reactive Milling)

## 왜 P-7 Premium인가?

1. **95G** - 경쟁사 대비 최고 원심가속도
2. **나노 도달** - 0.1μm(100nm)까지 분쇄 가능
3. **프로그래밍** - 다단계 온도 제어로 열민감 시료 대응
4. **재현성** - 디지털 제어로 동일 조건 반복
5. **최고 인기** - 배터리/세라믹 연구 분야 1위 판매 모델
