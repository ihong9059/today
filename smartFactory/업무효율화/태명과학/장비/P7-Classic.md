# PULVERISETTE 7 Classic Line

## 개요
2개 분쇄 스테이션, 최대 800rpm의 나노 분쇄 전용 유성볼밀.
소용량(20~80ml) 용기로 높은 에너지 밀도를 구현합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 분쇄 스테이션 | 2개 |
| 사용 가능 용기 | 20ml, 45ml, 80ml |
| 최대 회전속도 | 800rpm |
| 분쇄 방식 | 충격 + 마찰 (유성 운동) |
| 달성 입도 | 0.1~50μm |
| 최대 처리량 | 2 x 80ml |
| 에너지 등급 | 고에너지 |

## 적합 용도
- 나노 분쇄
- 기계적 합금화
- 소량 고에너지 연구
- 세라믹/배터리 소재
