# ANALYSETTE 22 NanoTec - 레이저 입도분석기

## 개요
레이저 회절(Laser Diffraction) 방식의 입도분석기.
0.01μm(10nm)부터 3,800μm까지 초광범위 측정이 가능합니다.

## 주요 사양

| 항목 | 사양 |
|------|------|
| 측정 원리 | 레이저 회절 (Mie/Fraunhofer) |
| 측정 범위 | 0.01~3,800μm |
| 분산 방식 | 습식 + 건식 가능 |
| 자동 정렬 | Yes |
| 재현성 | <1% (CV) |
| 측정 시간 | ~1분 |
| 규격 준거 | ISO 13320 |

## 적합 용도
- 나노~밀리미터 전 범위 입도 측정
- 배터리 소재 QC
- 세라믹 분말 분석
- 제약 API 입도 검증
- 연구 개발 전반

## 습식 vs 건식 분산

| 방식 | 분산매 | 장점 | 단점 |
|------|--------|------|------|
| 습식 | 물/에탄올 | 정확도 높음, 응집 해소 | 수용성 시료 불가 |
| 건식 | 압축공기 | 시료 변성 없음, 빠름 | 미세분말 응집 가능 |

## A-22 Nano vs A-22 Micro

| 항목 | A-22 Nano | A-22 Micro |
|------|-----------|------------|
| 측정 범위 | 0.01~3,800μm | 0.5~4,000μm |
| 나노 측정 | O | X |
| 추천 | 연구/R&D | 산업 QC |
| 가격 | 고급 | 보급 |

## 출력 데이터
- D10, D50, D90 (체적 기준)
- 입도 분포 곡선 (빈도/누적)
- Span = (D90-D10)/D50
- 모드(Mode), 평균(Mean)
