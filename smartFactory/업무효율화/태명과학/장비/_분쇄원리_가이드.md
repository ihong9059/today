# 분쇄 원리 가이드

## 4대 분쇄 메커니즘

### 1. 충격 (Impact) - 볼밀 계열
**대표 장비:** [[P5-Classic]], [[P5-Premium]], [[P6-Classic]], [[P6-Premium]], [[P7-Classic]], [[P7-Premium]]

- 분쇄볼이 시료에 고속 충돌하여 파괴
- 유성 운동(공전+자전)으로 볼에 원심력 부여
- 에너지 = 볼 질량 x 속도^2 → rpm과 볼 크기가 핵심
- 경질(Britite) 시료에 최적
- 나노 영역까지 도달 가능 (P-7 Premium: 0.1μm)

**에너지 전달 순서:**
모터 → 회전판(공전) → 용기(자전, 반대방향) → 볼 → 시료

**핵심 파라미터:**
- 회전속도(rpm): 높을수록 에너지 증가
- Ball-to-Powder Ratio: 5:1~10:1 (무게비)
- 볼 직경: 작을수록 미세, 클수록 조분쇄
- 시간: 과도시 재응집(agglomeration) 주의

### 2. 전단/마찰 (Shear/Friction) - 로터밀, 디스크밀
**대표 장비:** [[P14-로터밀]], [[P13-디스크밀]]

- 고속 회전체와 고정체 사이의 전단력으로 분쇄
- 로터밀: 4,000~20,000rpm 고속 회전 로터
- 디스크밀: 2개 디스크 사이 마찰
- 중경도 이하 시료에 적합
- 연속 투입 가능 (디스크밀)

**적합 시료:** 토양, 식품, 사료, 곡물, 화학원료

### 3. 절단 (Cutting) - 컷팅밀
**대표 장비:** [[P15-컷팅밀]]

- 회전 블레이드가 시료를 절단
- 연성(Ductile) 시료 전용 - 충격으로 파괴 불가한 시료
- 300~3,000rpm, 체(sieve)로 입도 조절

**적합 시료:** 플라스틱, 고무, 목재, 섬유, 식품(건조), 종이

### 4. 압축 (Compression) - 조크러셔
**대표 장비:** [[P1-조크러셔]]

- 2개의 조(jaw) 사이에서 시료를 압축 파쇄
- 대형 시료의 1차 분쇄(조쇄)용
- Gap 조절로 출구 입도 설정 (0~15mm)
- 경질, 취성 시료에 적합

**적합 시료:** 광석, 슬래그, 세라믹, 유리, 콘크리트

## 분쇄 방식 선택 가이드

| 시료 특성 | 추천 방식 | 추천 장비 |
|-----------|-----------|-----------|
| 경질 + 취성 (세라믹, 광물) | 충격 | 볼밀 (P-5/6/7) |
| 경질 + 대형 (>10mm) | 압축 → 충격 | [[P1-조크러셔]] → 볼밀 |
| 중경도 + 건조 (토양, 곡물) | 전단/마찰 | [[P14-로터밀]], [[P13-디스크밀]] |
| 연성 + 탄성 (플라스틱, 고무) | 절단 | [[P15-컷팅밀]] |
| 섬유질 (식품, 사료) | 전단 | [[P14-로터밀]] |
| 나노 목표 (<1μm) | 고에너지 충격 | [[P7-Premium]] |
