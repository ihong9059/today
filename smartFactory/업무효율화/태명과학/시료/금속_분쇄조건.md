## 핵심 주의사항

> 금속은 연성(Ductile)이 높아 볼밀로 분쇄가 어렵습니다.

1. **냉동분쇄 (Cryogenic Milling) 권장**
   - 액질소(LN2)로 시료를 취화(Embrittlement)시킨 후 분쇄
   - 연성 → 취성으로 전환 → 분쇄 효율 대폭 향상
   - P-7 Premium에 냉동 옵션 사용 가능

2. **재질 선택:** 금속 시료는 경도가 높으므로
   - WC (Mohs 9.5) 1순위
   - SS는 연질 금속(Al, Cu)에만 사용

3. **폭발 위험:** 미세 금속 분말은 분진 폭발 위험
   - 불활성 가스(Ar, N2) 분위기 필요
   - 습식 분쇄 고려

4. **용접/소결:** 연성 금속은 분쇄 중 용착(Cold Welding) 발생
   - Process Control Agent (PCA) 첨가: 스테아르산 1~3wt%
