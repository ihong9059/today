# 입도분석 기초

## D값의 의미

입도분석 결과는 보통 **D10, D50, D90**으로 표현합니다.

| 지표 | 의미 | 설명 |
|------|------|------|
| D10 | 10% 누적 입도 | 전체 입자의 10%가 이 크기 이하 |
| D50 | 50% 누적 입도 (중앙값) | 전체의 절반이 이 크기 이하 = **대표 입도** |
| D90 | 90% 누적 입도 | 전체의 90%가 이 크기 이하 = **굵은 입자 상한** |

**예시:** D10=2μm, D50=10μm, D90=30μm
→ 대부분의 입자가 2~30μm, 대표 크기 10μm

## Span (분포폭)

```
Span = (D90 - D10) / D50
```

| Span | 해석 |
|------|------|
| <1.5 | 매우 균일 (좁은 분포) |
| 1.5~2.5 | 보통 |
| 2.5~3.5 | 넓은 분포 |
| >3.5 | 매우 넓은 분포 (이봉 의심) |

**Span이 작을수록** 입도 분포가 균일 → 품질 좋음

## 체적분포 vs 개수분포

| 구분 | 체적(Volume) 분포 | 개수(Number) 분포 |
|------|-------------------|-------------------|
| 기준 | 입자의 부피 비율 | 입자의 개수 비율 |
| 특성 | 큰 입자에 가중치 | 작은 입자에 가중치 |
| 주 사용 | 레이저 회절 (표준) | 이미지 분석, 현미경 |
| D50 비교 | 상대적으로 큼 | 상대적으로 작음 |

> 대부분의 산업 기준은 **체적 기준 D50**을 사용합니다.

## 분포 형태

### 정규분포 (Normal/Gaussian)
- 단일 피크, 좌우 대칭
- 이상적인 분쇄 결과
- D50 부근에 입자 집중

### 이봉분포 (Bimodal)
- 2개 피크 존재
- 원인: 불균일 분쇄, 재응집, 시료 혼합
- 대책: 분쇄 시간 연장, 볼 크기 변경, 단계적 분쇄

### 꼬리분포 (Skewed)
- 한쪽으로 치우침
- 양(+) 꼬리: 큰 입자 잔류 → 분쇄 시간 부족
- 음(-) 꼬리: 미세 입자 과다 → 과분쇄

## 측정 단위

| 단위 | 범위 | 사용 |
|------|------|------|
| mm (밀리미터) | >1mm | 조쇄물, 과립 |
| μm (마이크로미터) | 1~1,000μm | 일반 분말 (가장 보편) |
| nm (나노미터) | <1μm | 나노 소재 |

환산: 1mm = 1,000μm = 1,000,000nm
