# 산업별 입도 기준표

> 이 기준표는 각 산업의 일반적인 합격 기준입니다.
> 개별 고객/제품의 스펙은 다를 수 있습니다.

## 합격 기준 테이블

| 산업 | 용도 | D50 기준 | D90 기준 | Span | 비고 |
|------|------|----------|----------|------|------|
| 제약 API (경구) | 정제/캡슐 | 5~25μm | <75μm | <3.0 | USP <429> |
| 제약 API (흡입) | 흡입제 | 1~5μm | <10μm | <2.0 | 폐 도달 입도 |
| 배터리 양극재 | LFP/NMC | 3~15μm | <30μm | <2.5 | 금속오염 불가 |
| 배터리 전해질 | 전고체 | <5μm | <15μm | <3.0 | 가능한 미세하게 |
| 세라믹 분말 | 소결용 | 0.5~5μm | <15μm | <3.0 | 소결밀도 영향 |
| 식품 분말 | 미분말 | 10~50μm | <100μm | - | 식감/용해도 |
| 광물 분석 | XRF 전처리 | <75μm | <150μm | - | #200 mesh |
| 광물 분석 | XRD 전처리 | <45μm | <100μm | - | #325 mesh |
| 시멘트 | 제조 | 15~25μm | <45μm | <2.0 | 강도/수화 |
| 안료/도료 | 코팅 | 1~10μm | <25μm | <2.5 | 광택/은폐력 |
| 화장품 | 파운데이션 | 5~15μm | <30μm | <2.5 | 피부 촉감 |
| 토너 | 프린터 | 5~10μm | <20μm | <2.0 | 해상도 |

## 합격 판정 방법

1. **D50 확인:** 기준 범위 내에 있는가?
2. **D90 확인:** 상한 이하인가? (굵은 입자 없는가?)
3. **Span 확인:** 기준 이하인가? (분포 균일한가?)
4. **종합 판정:**
   - 3가지 모두 통과 → **합격**
   - D50 통과, D90 초과 → "조대 입자 잔류, 추가 분쇄 필요"
   - D50 통과, Span 초과 → "분포 불균일, 분급(Classification) 필요"
   - D50 미달 → "과분쇄, rpm/시간 줄이기"

## 개선 방안 (불합격 시)

| 문제 | 원인 | 대책 |
|------|------|------|
| D50 너무 큼 | 분쇄 부족 | rpm 증가, 시간 연장, 볼 크기 감소 |
| D50 너무 작음 | 과분쇄 | rpm 감소, 시간 단축 |
| D90 너무 큼 | 조대입자 잔류 | 단계적 분쇄, 체 분급 |
| Span 너무 큼 | 불균일 분포 | 볼 크기 단일화, 분급 |
| 이봉분포 | 재응집/혼합 | PCA 첨가, 습식 전환 |
