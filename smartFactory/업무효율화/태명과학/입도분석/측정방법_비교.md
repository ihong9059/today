# 입도 측정방법 비교

## 3종 방법 비교표

| 항목 | 레이저 회절 | 체분석 | 이미지 분석 |
|------|------------|--------|------------|
| 장비 | [[A22-Nano]] / [[A22-Micro]] | [[A3-체분석기]] | [[A28-이미지사이저]] |
| 원리 | 레이저 빛 회절 패턴 | 물리적 체 통과 | 카메라 촬영+분석 |
| 측정 범위 | 0.01~4,000μm | 20μm~25mm | 20~20,000μm |
| 나노 측정 | O (A-22 Nano) | X | X |
| 형상 정보 | X (구 가정) | X | O (원형도/종횡비) |
| 속도 | 빠름 (~1분) | 느림 (10~30분) | 중간 (~5분) |
| 재현성 | 높음 (CV<1%) | 보통 (CV 2~5%) | 높음 (CV<2%) |
| 시료량 | 0.1~5g | 50~500g | 1~50g |
| 규격 | ISO 13320 | ASTM E11, ISO 3310 | ISO 13322-2 |
| 가격 | 고가 | 저가 | 중가 |
| 추천 | R&D, 미세분석 | 규격시험, QC | 비구형, 형상분석 |

## 선택 가이드

```
입도 범위?
├── <1μm (나노) → 레이저 회절 (A-22 Nano) [유일한 선택]
├── 1~100μm (미세) → 레이저 회절 (A-22) [최적]
├── 100μm~25mm (조분) → 체분석 (A-3) 또는 이미지 (A-28)
│   ├── 형상 정보 필요? → 이미지 분석 (A-28)
│   └── 규격 시험 (ISO/ASTM)? → 체분석 (A-3)
└── 전 범위 필요 → 레이저 회절 (A-22 Nano: 0.01~3,800μm)
```
