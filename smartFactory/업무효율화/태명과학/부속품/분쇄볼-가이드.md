# 분쇄볼 선택 가이드

## 볼 직경별 적합 입도

| 볼 직경 | 적합 목표 입도 | 용도 | 비고 |
|---------|----------------|------|------|
| 0.1mm | ~0.1μm (100nm) | 나노 분쇄 | 습식 전용, ZrO2만 |
| 0.3mm | ~0.3μm | 서브마이크론 | 습식 권장 |
| 0.5mm | ~0.5μm | 서브마이크론 | ZrO2/Si3N4/WC/SS |
| 1mm | ~1μm | 초미세 분쇄 | 범용 미세볼 |
| 3mm | ~5μm | 미세 분쇄 | 가장 범용적 |
| 5mm | ~10μm | 일반 분쇄 | 표준 연구 |
| 10mm | ~50μm | 조분쇄/혼합 | 1차 분쇄 |
| 15mm | ~100μm | 조분쇄 | 경질 시료 |
| 20~40mm | ~200μm | 1차 분쇄 | 대형 경질 시료 |

## 볼 크기 선택 규칙

1. **목표 입도의 ~100배** 볼을 선택 (경험적 가이드)
   - 목표 5μm → 0.5mm(500μm) 볼 또는 3mm 볼
   - 목표 0.1μm → 0.1mm 볼

2. **단계적 분쇄** (권장)
   - 1단계: 큰 볼(10~20mm)로 조분쇄 → D50 ~50μm
   - 2단계: 작은 볼(1~3mm)로 미세분쇄 → D50 ~5μm
   - 3단계: 초미세볼(0.1~0.5mm)로 나노 → D50 <1μm

3. **볼 혼합 사용** (선택적)
   - 큰 볼 + 작은 볼 혼합 → 분쇄 효율 향상
   - 예: 10mm + 3mm 혼합 (무게비 1:1)

## 재질별 가용 크기

[[_부속품_호환_매트릭스]]의 분쇄볼 가용 크기 표 참조.

- **ZrO2:** 0.1~20mm (나노용 0.1mm 가능, 최다 크기)
- **Agate:** 5~40mm (미세볼 불가)
- **Si3N4:** 0.5~15mm
- **WC:** 0.5~20mm
- **SS:** 0.5~40mm (전 범위)

## 볼 충전량 계산

```
볼 무게 = 시료 무게 x BPR

예: 시료 10g, BPR 10:1
→ 볼 무게 = 10g x 10 = 100g
→ ZrO2 3mm 볼 1개 ~0.08g
→ 필요 볼 수 ~1,250개
```
