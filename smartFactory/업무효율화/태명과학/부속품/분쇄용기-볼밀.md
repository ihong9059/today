# 분쇄 용기 선택 가이드 (볼밀)

## 최적 투입량 규칙

- **시료 투입량:** 용기 용량의 **1/3** (최적)
- **시료 + 볼:** 용기 용량의 **2/3** (최대)
- **나머지 1/3:** 공간 확보 (볼 운동 공간)

| 용기 용량 | 최적 시료량 | 시료+볼 합계 |
|-----------|-------------|-------------|
| 20ml | ~7ml | ~13ml |
| 45ml | ~15ml | ~30ml |
| 80ml | ~27ml | ~53ml |
| 250ml | ~83ml | ~167ml |
| 500ml | ~167ml | ~333ml |

## Ball-to-Powder Ratio (BPR)

| BPR (무게비) | 용도 |
|-------------|------|
| 5:1 | 일반 분쇄, 혼합 |
| 10:1 | 미세 분쇄 (표준) |
| 15:1~20:1 | 고에너지, 기계적 합금화 |

## 용기 크기 선택 기준

| 시료량 | 추천 용기 | 추천 장비 |
|--------|-----------|-----------|
| <5g | 20ml | P-7 |
| 5~15g | 45ml | P-7 |
| 15~25g | 80ml | P-5/P-6/P-7 |
| 25~80g | 250ml | P-5/P-6 |
| 80~170g | 500ml | P-5/P-6 |

## 고에너지 분쇄 팁

- **작은 용기 + 작은 볼 + 높은 rpm** = 최대 에너지 밀도
- 예: P-7 Premium + ZrO2 45ml + 1mm 볼 + 800rpm → 나노 도달
- 큰 용기는 에너지 밀도가 분산됨 → 미세 분쇄에 불리

## 모델별 사용 가능 용기 크기

| P-6 Premium/Classic | - | - | O | O | O |
| P-5 Premium/Classic | - | - | O | O | O |
