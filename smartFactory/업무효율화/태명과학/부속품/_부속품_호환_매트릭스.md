# FRITSCH 부속품 호환성 매트릭스

> 이 매트릭스는 장비x재질x용량 조합의 호환 여부를 정의합니다.
> O = 호환, - = 비호환 (해당 조합 불가)

## P-7 Premium / Classic (20ml, 45ml, 80ml)

| 용량 | Agate | ZrO2 | Si3N4 | Al2O3 | WC | SS | PTFE |
|------|-------|------|-------|-------|----|----|------|
| 20ml | O | O | O | O | O | O | - |
| 45ml | O | O | O | O | O | O | - |
| 80ml | O | O | O | O | O | O | O |

> P-7은 전 재질 호환성이 가장 높음. 80ml PTFE까지 지원.

## P-6 Premium / Classic (80ml, 250ml, 500ml)

| 용량 | Agate | ZrO2 | Si3N4 | Al2O3 | WC | SS | PTFE |
|------|-------|------|-------|-------|----|----|------|
| 80ml | O | O | O | O | O | O | - |
| 250ml | O | O | - | O | O | O | - |
| 500ml | O | O | - | O | - | O | - |

> 500ml에서 Si3N4, WC, PTFE 비호환 주의.

## P-5 Premium / Classic (80ml, 250ml, 500ml)

| 용량 | Agate | ZrO2 | Si3N4 | Al2O3 | WC | SS | PTFE |
|------|-------|------|-------|-------|----|----|------|
| 80ml | O | O | O | O | O | O | O |
| 250ml | O | O | - | O | O | O | - |
| 500ml | O | O | - | O | - | O | - |

> P-5 80ml은 PTFE 포함 전 재질 호환. 250ml/500ml 대용량은 제한 있음.

## 분쇄볼 가용 크기 (mm)

| 재질 | 0.1 | 0.3 | 0.5 | 1 | 3 | 5 | 10 | 15 | 20 | 30 | 40 |
|------|-----|-----|-----|---|---|---|----|----|----|----|----|
| Agate | - | - | - | - | O | O | O | O | O | O | O |
| ZrO2 | O | O | O | O | O | O | O | O | O | - | - |
| Si3N4 | - | - | O | O | O | O | O | O | - | - | - |
| Al2O3 | - | - | - | O | O | O | O | O | O | O | - |
| WC | - | - | O | O | O | O | O | O | O | - | - |
| SS | - | - | O | O | O | O | O | O | O | O | O |
| 경화강 | - | - | O | O | O | O | O | O | O | O | O |

> ZrO2는 0.1mm 초미세볼까지 가용 → 나노 분쇄 최적.
> Agate는 5mm 이상만 가용 → 미세볼 불가.

## 호환성 확인 방법

1. 장비 모델 확인 (P-5/P-6/P-7)
2. 필요 용량 확인 (ml)
3. 위 매트릭스에서 해당 행의 재질 열 확인
4. O이면 호환, -이면 비호환
5. 비호환 시 → 같은 재질의 다른 용량, 또는 같은 용량의 다른 재질 대안 검색

## 자주 실수하는 비호환 조합

| 조합 | 결과 | 대안 |
|------|------|------|
| P-5 500ml + Si3N4 | 비호환 | ZrO2 500ml 또는 Si3N4 250ml |
| P-5 500ml + WC | 비호환 | WC 250ml 또는 SS 500ml |
| P-6 500ml + Si3N4 | 비호환 | ZrO2 500ml 또는 Si3N4 80ml(P-7) |
| P-5 250ml + PTFE | 비호환 | PTFE 80ml(P-5/P-7) |
| P-7 any + PTFE(20/45ml) | 비호환 | PTFE 80ml(P-7) |
