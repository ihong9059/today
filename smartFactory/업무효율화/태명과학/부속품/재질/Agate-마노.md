# Agate (마노) - SiO2

## 기본 특성

| 항목 | 값 |
|------|-----|
| 화학식 | SiO2 (99.9%) |
| 경도 | Mohs 6.5 |
| 밀도 | 2.65 g/cm3 |
| 순수성 | 최고 (★★★★★) |
| 내화학성 | 양호 (산에 강함, 알칼리에 약함) |
| 가격 | 고가 (★★★★) |

## 장점
- **순수성 최고** - SiO2 99.9%, 금속 오염 Zero
- 미량원소 분석(ppm 이하)에 필수
- XRF/XRD/ICP 전처리에 최적
- 환경시료, 지질시료 표준 재질

## 단점
- **취성(Brittleness)** - 충격에 깨짐 주의
- 경질 시료(Mohs 7+) 분쇄 시 마모/파손 위험
- 고에너지 분쇄(고rpm) 부적합
- 미세볼 없음 (5mm 이상만 가용)
- 고가

## 적합 시료
- 환경 시료 (토양, 수질 잔류물)
- 지질 시료 (암석, 광물 미량분석)
- 미량원소 분석 전처리
- 순수 화학 시료

## 부적합 시료
- 경질 세라믹 (SiC, Al2O3 등) → 용기 파손 위험
- 고에너지 분쇄 필요 시료 → ZrO2 권장
- 나노 분쇄 (미세볼 불가) → ZrO2 권장
