# Si3N4 (질화규소) - Silicon Nitride

## 기본 특성

| 항목 | 값 |
|------|-----|
| 화학식 | Si3N4 |
| 경도 | Mohs 9 |
| 밀도 | 3.2 g/cm3 (경량) |
| 순수성 | 우수 (★★★★) |
| 내화학성 | 우수 (★★★★) |
| 가격 | 고가 (★★★★) |

## 장점
- 높은 경도 (Mohs 9) - ZrO2보다 높음
- 경량 (3.2 g/cm3) - 취급 용이
- 금속 오염 없음
- 고경도 세라믹/금속간화합물 분쇄에 최적

## 단점
- 호환 용량 제한 (P-5/P-6 250ml, 500ml 비호환)
- 볼 크기 범위 좁음 (0.5~15mm)
- ZrO2 대비 가격 높음
- 나노 분쇄용 초미세볼(0.1mm) 없음

## 적합 시료
- 고경도 세라믹 (SiC, B4C)
- 금속간화합물
- 경질 합금
- Mohs 8~9 경질 시료

## 호환성

- P-5/P-6: 80ml만 호환 (250ml, 500ml 비호환)
