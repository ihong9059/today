# SS (스테인리스) - Stainless Steel

## 기본 특성

| 항목 | 값 |
|------|-----|
| 화학식 | STS304 (Fe-Cr-Ni) 또는 STS316 (Fe-Cr-Ni-Mo) |
| 경도 | Mohs 5.5 |
| 밀도 | 7.9 g/cm3 |
| 순수성 | 보통 (★★) - Fe/Cr/Ni 오염 |
| 내화학성 | 보통 (★★) |
| 가격 | 저가 (★) |

## 장점
- **GMP/HACCP 준수** - 식품/의약 표준 재질
- 세척 용이 (표면 매끄러움)
- 전 모델, 전 용량 호환
- 볼 크기 전 범위 (0.5~40mm)
- 경제적

## 단점
- **낮은 경도** (Mohs 5.5) - 마모 빠름
- **Fe/Cr/Ni 금속 오염** - 순수분석 부적합
- 경질 시료 분쇄 시 용기/볼 마모 심함
- 산성 시료에 부식 가능

## 적합 시료
- 식품 분말
- 의약 원료 (API, 부형제)
- 사료
- 화장품 원료
- GMP 요구 환경
