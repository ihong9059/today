# ZrO2 (지르코니아) - Yttria-stabilized Tetragonal Zirconia Polycrystal

## 기본 특성

| 항목 | 값 |
|------|-----|
| 화학식 | ZrO2 (Y2O3 안정화) |
| 경도 | Mohs 8.5 |
| 밀도 | 6.0 g/cm3 |
| 순수성 | 우수 (★★★★) - 금속 오염 없음 |
| 내화학성 | 우수 (★★★★) |
| 가격 | 중간 (★★★) |

## 장점
- **범용 최고 인기** - 가장 많이 사용되는 재질
- 높은 경도 (Mohs 8.5) + 높은 인성(깨지지 않음)
- **금속 오염 없음** - 배터리/세라믹에 필수
- 낮은 마모율 - 장수명
- **0.1mm 초미세볼 가용** - 나노 분쇄 최적
- 전 모델/전 용량 호환

## 단점
- Agate 대비 순수성 약간 낮음 (Zr 미량 혼입 가능)
- Mohs 9 이상 시료에는 Si3N4 또는 WC 권장
- 가격은 SS/경화강보다 높음

## 적합 시료
- **배터리 양극재** (LFP, NMC, 전고체) - 1순위
- 세라믹 분말 (알루미나, 지르코니아 등)
- 의약 API
- 화학 원료 전반
- 나노 소재 연구
