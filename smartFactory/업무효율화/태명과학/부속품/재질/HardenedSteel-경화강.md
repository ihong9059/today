# 경화강 (Hardened Steel)

## 기본 특성

| 항목 | 값 |
|------|-----|
| 화학식 | Fe (열처리 경화) |
| 경도 | Mohs 6 |
| 밀도 | 7.8 g/cm3 |
| 순수성 | 낮음 (★) - Fe 오염 큼 |
| 내화학성 | 낮음 (★) |
| 가격 | 최저가 (★) |

## 장점
- **최저가** - 가장 경제적
- 범용 분쇄에 충분
- 순수성 불필요한 시료에 적합

## 단점
- **마모 빠름** - 수명 짧음
- **Fe 오염 큼** - 순수분석/미량분석 부적합
- 부식에 약함
- GMP 부적합

## 적합 시료
- 건설재 (콘크리트, 벽돌)
- 토양 (일반 분석)
- 일반 화학 분석 (순수성 불필요)
- 교육/실습용
