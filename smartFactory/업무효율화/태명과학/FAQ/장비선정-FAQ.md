# 장비 선정 FAQ

## Q1. P-5와 P-7의 차이는 무엇인가요?

**핵심 차이: 용량 vs 에너지**

| 항목 | P-5 | P-7 |
|------|-----|-----|
| 스테이션 | 4개 | 2개 |
| 용기 크기 | 80~500ml | 20~80ml |
| 최대 rpm | 400(C)/800(P) | 800(C)/1,100(P) |
| 최대 G-force | ~30G | 95G (Premium) |
| 처리량 | 대량 (4x500ml) | 소량 (2x80ml) |
| 달성 입도 | ~1μm | ~0.1μm (나노) |

- **P-5:** 대용량 범용 분쇄 → "많이, 보통 크기로"
- **P-7:** 소량 나노 분쇄 → "적게, 극미세로"

## Q2. Classic과 Premium의 차이는?

| 항목 | Classic | Premium |
|------|---------|---------|
| rpm | 표준 (400~800) | 고속 (800~1,100) |
| 에너지 | 표준 | 고에너지 (2~4배) |
| 프로그래밍 | 기본 | 다단계 (가속/감속/휴지) |
| 가격 | 보급형 | 고급형 |

**추천:**
- 일반 연구/QC → Classic (비용 효율)
- 나노 분쇄/기계적 합금화 → Premium (고에너지 필수)

## Q3. 볼밀과 로터밀, 어떤 걸 써야 하나요?

| 항목 | 볼밀 (P-5/6/7) | 로터밀 (P-14) |
|------|-----------------|---------------|
| 방식 | 충격 (볼 충돌) | 전단 (고속 로터) |
| 적합 시료 | 경질, 취성 | 중경도, 섬유질 |
| 입도 범위 | 0.1~100μm | 40~3,000μm |
| 처리 속도 | 10~30분 | 1~5분 |
| 예시 | 세라믹, 배터리, 광물 | 토양, 식품, 사료 |

→ 상세: [[_분쇄원리_가이드]]

## Q4. 어떤 모델이 가장 인기 있나요?

**1위: [[P7-Premium]]** - 배터리/세라믹 연구
- 95G 최고 에너지, 나노 도달
- 대학/연구소 표준 장비

**2위: [[P5-Classic]]** - 범용 연구
- 4개 스테이션 대용량
- 가장 범용적

**3위: [[A22-Nano]]** - 입도 분석
- 나노~밀리미터 전 범위
- R&D 필수 장비

## Q5. 입도분석기는 꼭 필요한가요?

- **R&D:** 필수. 분쇄 최적화에 입도 데이터 필요
- **QC:** 필수. 제품 입도 합격/불합격 판정
- **1차 전처리만:** 선택. 체분석기([[A3-체분석기]])로 대체 가능
