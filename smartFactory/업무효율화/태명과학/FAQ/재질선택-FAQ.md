# 재질 선택 FAQ

## Q1. 가장 안전한(순수한) 재질은?

**1순위: Agate (마노)** - SiO2 99.9%, 금속 오염 Zero
- 미량원소 분석(ppm 이하)에 필수
- 단, 경질 시료에 취약 (깨짐 위험)

**2순위: ZrO2 (지르코니아)** - 금속 오염 없음 + 높은 경도
- Agate보다 튼튼하고 범용적
- Zr 미량 혼입 가능 (대부분 허용 범위)

→ 상세: [[Agate-마노]], [[ZirconiumOxide-지르코니아]]

## Q2. 가장 저렴한 재질은?

**가격 순서 (저 → 고):**
경화강 → SS → Al2O3 → ZrO2 → PTFE → Agate → Si3N4 → WC

- **경화강:** 최저가, 순수성 불필요 시
- **SS:** 저가 + GMP 적합
- **Al2O3:** 중저가 + 양호한 경도

## Q3. 배터리 소재에는 어떤 재질?

**ZrO2 (지르코니아) 1순위**
- 금속 오염 없음 (Fe, Cr, Ni, Co = Zero)
- 높은 경도 (Mohs 8.5) → 양극재 분쇄 충분
- 0.1mm 초미세볼 가용 → 나노 분쇄 가능

**절대 사용 금지:**
- SS (Fe/Cr/Ni 오염)
- 경화강 (Fe 오염)
- WC (Co 오염)

→ 상세: [[배터리_분쇄조건]], [[ZirconiumOxide-지르코니아]]

## Q4. 식품/의약(GMP)에는?

**SS (스테인리스) 표준**
- STS304/316 = GMP/HACCP 인증 재질
- 세척 용이, 검증 기반 확립
- 전 모델/전 용량 호환

**ZrO2도 가능** (금속오염 우려 시)
- 제약 API: ZrO2 사용 증가 추세
- 단, GMP 문서화 별도 필요

→ 상세: [[StainlessSteel-스테인리스]], [[제약_분쇄조건]]

## Q5. 오염이 걱정될 때 어떻게 판단하나요?

[[_재질_총괄_비교]]의 **의사결정 트리** 참조:

```
금속 오염 허용?
├── NO → 시료 경도 Mohs 7+?
│         ├── YES → ZrO2 또는 Si3N4
│         └── NO  → Agate
└── YES → GMP 필요?
          ├── YES → SS
          └── NO  → 경화강 (최저가)
```

**핵심 원칙:**
1. 오염 허용도가 최우선 판단 기준
2. 그 다음 시료 경도 매칭
3. 마지막으로 예산 고려

## Q6. PTFE(테프론)은 언제 쓰나요?

**산/알칼리 시료** 전용
- 강산(HCl, H2SO4) 또는 강알칼리(NaOH) 접촉 시료
- 화학적으로 완전히 불활성
- 단점: 매우 부드러움 (Mohs 2) → 경질 시료 불가
- 호환: P-5 80ml, P-7 80ml만
