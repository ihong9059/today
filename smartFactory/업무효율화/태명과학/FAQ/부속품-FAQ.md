# 부속품 FAQ

## Q1. 용기 수명은 얼마나 되나요?

| 재질 | 예상 수명 | 비고 |
|------|-----------|------|
| SS (스테인리스) | 1~2년 | 경질 시료 시 마모 빠름 |
| ZrO2 (지르코니아) | 3~5년 | 내마모 우수, 가장 긴 수명 |
| Agate (마노) | 2~3년 | 취급주의 (충격 시 깨짐) |
| WC (초경합금) | 3~5년 | 내마모 최고 |
| Si3N4 (질화규소) | 2~4년 | |
| PTFE (테프론) | 1~2년 | 경질 시료 시 변형 |

> 수명은 사용 빈도, 시료 경도, rpm에 따라 크게 다릅니다.

## Q2. 볼 충전량은 어떻게 계산하나요?

**기본 규칙:**
1. 시료 + 볼 = 용기 용량의 **2/3**
2. Ball-to-Powder Ratio (BPR) = **5:1 ~ 10:1** (무게비)

**예시 계산:**
- 용기: ZrO2 80ml
- 시료: 10g (약 27ml 중 ~10ml)
- BPR: 10:1
- 필요 볼 무게: 10g x 10 = 100g
- ZrO2 3mm 볼 1개: ~0.08g
- 필요 볼 수: ~1,250개

→ 상세: [[분쇄볼-가이드]], [[분쇄용기-볼밀]]

## Q3. 용기 세척은 어떻게 하나요?

**표준 세척법:**
1. 용기에서 시료+볼 제거
2. 에탄올 + 초음파 세척 (5~10분)
3. 정제수 린스
4. 건조 (오븐 또는 자연 건조)

**교차오염 방지:**
- 시료별 전용 용기/볼 세트 권장
- 특히 제약(GMP): 세척 검증(Cleaning Validation) 필수
- 색 시료(안료 등) 후: 알루미나 분말로 공회전 세척

## Q4. 호환되지 않는 조합은 어떤 것이 있나요?

대표적 비호환 조합:

| 조합 | 결과 | 대안 |
|------|------|------|
| P-5 500ml + Si3N4 | 비호환 | ZrO2 500ml |
| P-5 500ml + WC | 비호환 | WC 250ml |
| P-5 250ml + PTFE | 비호환 | PTFE 80ml |
| P-7 20/45ml + PTFE | 비호환 | PTFE 80ml |

→ 반드시 [[_부속품_호환_매트릭스]] 확인 후 주문

## Q5. 볼 크기는 어떻게 선택하나요?

**간단 규칙:** 목표 입도의 ~100배 직경

| 목표 입도 | 추천 볼 직경 |
|-----------|-------------|
| ~0.1μm (나노) | 0.1mm |
| ~1μm | 1mm |
| ~5μm | 3mm |
| ~10μm | 5mm |
| ~50μm | 10mm |

→ 상세: [[분쇄볼-가이드]]
