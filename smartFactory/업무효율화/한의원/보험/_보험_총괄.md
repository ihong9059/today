# 보험 총괄

한의원 건강보험 적용 범위, 급여/비급여 분류, 추나 횟수 제한, 급여한약 56종 및 청구 흐름을 정리합니다.

> **주의**: 보험 기준은 수시 변경됩니다. 최신 건강보험심사평가원(HIRA) 고시를 반드시 확인하세요.

## 보험 청구 흐름

### 일반 진료 청구

```
1. 환자 내원 → 건강보험증 확인
   │
2. 진찰 (초진/재진)
   ├── 초진: AA111 (의원급)
   └── 재진: AA211
   │
3. 시술 결정
   ├── 침 → HA111 (단순) / HA112 (복잡)
   ├── 뜸 → HA201
   ├── 부항 → HA301
   ├── 전침 → HA121
   └── 추나 → JX211~JX224
   │
4. 급여한약 처방 (해당 시)
   ├── 과립제: 56종 코드
   └── 탕제: 56종 코드 (탕전료 별도)
   │
5. EDI 전송 → 심사평가원
   │
6. 심사 → 지급
```

### 비급여 한약(보약) 청구

```
1. 환자 내원 → 체질 진단 + 변증
   │
2. 비급여 한약 처방 (보약, 환제, 고제 등)
   │
3. 처방전 작성 ([[템플릿/처방전_템플릿]])
   │
4. 비급여 수납 (원내 약국 또는 원외 탕전원)
   │
5. 비급여 증명서 발행 (환자 요청 시)
```

## 첩약건보 시범사업

### 대상 질환 (주요)
- 안면신경마비 (벨마비)
- 뇌혈관질환 후유증
- 월경통
- 기능성 소화불량
- 알레르기 비염

### 특징
- 급여한약 56종과 별도
- 한의사가 개별 첩약 처방 가능
- 본인부담률: 약 30%
- 시범사업 참여 기관에서만 가능

---

## 청구 시 주의사항

1. **중복 청구 금지**: 같은 날 양방+한방 동일 질환 중복 급여 불가
2. **추나 횟수 확인**: 연간 20회 한도, 타 기관 이용 횟수 포함
3. **급여한약 적응증**: 급여한약 56종은 해당 적응증에만 청구 가능
4. **진단코드 일치**: 시술/처방과 진단코드가 일치해야 삭감 방지
5. **진료기록부 필수**: [[템플릿/진료기록_템플릿|진료기록]] 상세 기재 (삭감 방어)
