# 이기제 (理氣劑)

기(氣)의 울체를 소통시키는 처방군입니다. 간기울결(肝氣鬱結), 비위기체(脾胃氣滯) 등에 사용합니다.

---

## 1. 반하사심탕 (半夏瀉心湯)

### 기본 정보
- **출전**: 상한론 (張仲景)
- **분류**: 화비개결제 (조화한열)
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 심하비경(心下痞硬): 명치 부위 답답함, 그득함
- 구역, 구토, 복명(복부 소리)
- 기능성 소화불량, 만성 위염
- 한열착잡(寒熱錯雜)형 소화기 질환

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 반하(半夏) | 12g | 강역지구, 소비산결 |
| 臣 | 황금(黃芩) | 9g | 청열조습 |
| 臣 | 황련(黃連) | 3g | 청열조습 |
| 佐 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 보기건비 |
| 佐 | 건강(乾薑) | 9g | 온중거한 |
| 佐 | 대조(大棗) | 4매 | 보비화중 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 9g | 조화제약 |

### 변방
- **생강사심탕**: 건강 → 생강 (수기 더 많은 경우)
- **감초사심탕**: 감초 증량 (비위허 더 심한 경우)

### 주의사항
- 음허화왕 환자 주의
- [[약재/상극_금기|반하는 오두(烏頭)와 십팔반]] — 동시 처방 금기
- [[약재/상극_금기#임부금기|반하는 임부금기]] 약재

### 임상 사례
- [[사례/2025-소화불량-소음인|소음인 만성 소화불량 사례]] 참조

## 2. 향사육군자탕 (香砂六君子湯)

### 기본 정보
- **출전**: 의방집해
- **분류**: 보기이기제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 비위기허 + 기체: 식욕 부진, 복부 팽만, 트림
- 담습(痰濕) 겸한 소화불량
- 식후 복부 그득함, 오심

### 처방 구성 (군신좌사)
[[처방/보기제#육군자탕|육군자탕]] + 향부자, 사인

| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 6g | 보기건비 |
| 臣 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비조습 |
| 臣 | 복령(茯苓) | 9g | 건비삼습 |
| 佐 | 반하(半夏) | 6g | 조습화담 |
| 佐 | [[약재/_약재_총괄#진피\|진피(陳皮)]] | 6g | 이기화담 |
| 佐 | 향부자(香附子) | 6g | 소간이기 |
| 佐 | 사인(砂仁) | 3g | 화습행기 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 3g | 조화제약 |

### 주의사항
- 실열증에는 부적합
- 음허(陰虛) 동반 시 가감 필요

## 3. 소요산 (逍遙散)

### 기본 정보
- **출전**: 태평혜민화제국방
- **분류**: 소간건비제
- **적합 체질**: [[체질/_체질_총괄#소양인|소양인]], [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 간울비허(肝鬱脾虛): 스트레스성 소화불량
- 양협동통(兩脇疼痛): 옆구리 답답함, 통증
- 월경전증후군(PMS): 유방창통, 과민, 식욕변화
- 자율신경실조, 갱년기

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 시호(柴胡) | 9g | 소간해울 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 9g | 보혈양간 |
| 臣 | 백작약(白芍藥) | 9g | 양혈유간 |
| 佐 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비 |
| 佐 | 복령(茯苓) | 9g | 건비삼습 |
| 佐 | 박하(薄荷) | 3g | 소풍산열 |
| 佐 | 생강(生薑) | 3g | 온위 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 5g | 조화제약 |

### 변방
- **가미소요산**: + 치자, 목단피 → 간울화화(간기울결+화) 동반 시
- **단치소요산**: = 가미소요산 (동의어)

### 주의사항
- 음허화왕(陰虛火旺) 환자에는 가미소요산 선택
- 간양상항(肝陽上亢) 시 시호 용량 조절

## 4. 시호소간산 (柴胡疏肝散)

### 기본 정보
- **출전**: 경악전서 (張景岳)
- **분류**: 소간이기제
- **적합 체질**: [[체질/_체질_총괄#소양인|소양인]]

### 적응증
- 간기울결(肝氣鬱結): 양협통, 우울, 짜증
- 기체(氣滯) 위주: 복부 팽만감, 트림, 방귀
- 스트레스성 위장 장애

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 시호(柴胡) | 6g | 소간해울 |
| 臣 | 향부자(香附子) | 5g | 소간이기 |
| 臣 | 천궁(川芎) | 5g | 활혈행기 |
| 佐 | 백작약(白芍藥) | 5g | 양혈유간 |
| 佐 | 지각(枳殼) | 5g | 이기관흉 |
| 佐 | [[약재/_약재_총괄#진피\|진피(陳皮)]] | 6g | 이기화담 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 3g | 조화제약 |

### 주의사항
- 간양상항(頭痛, 面紅, 怒) 주의
- 음허(陰虛) 동반 시 보음약 가미

## 5. 억간산 (抑肝散)

### 기본 정보
- **출전**: 보영촬요 (薛鎧)
- **분류**: 평간식풍제
- **적합 체질**: [[체질/_체질_총괄#소양인|소양인]]

### 적응증
- 간풍내동(肝風內動): 경련, 틱, 야제(야간 울음)
- 불면, 과민, 공격성 (정신과 영역)
- 신경증, 불안장애
- 치매 행동심리증상(BPSD)

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 조구등(釣鉤藤) | 9g | 평간식풍 |
| 臣 | 시호(柴胡) | 6g | 소간해울 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 9g | 보혈양간 |
| 佐 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 12g | 건비 |
| 佐 | 복령(茯苓) | 12g | 건비안신 |
| 佐 | 천궁(川芎) | 6g | 활혈행기 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 5g | 조화제약 |

### 변방
- **억간산가진피반하**: + 진피, 반하 → 담이 동반된 경우 (일본에서 다용)

### 주의사항
- 장기 복용 시 간기능, 전해질 모니터링
- 감초 함량 주의 (위알도스테론증)

### 임상 사례
- [[사례/2025-불면-스트레스|불면+스트레스 사례]] 참조

## 6. 평위산 (平胃散)

### 기본 정보
- **출전**: 태평혜민화제국방
- **분류**: 조습운비제
- **적합 체질**: [[체질/_체질_총괄#태음인|태음인]]

- 설태 백후니(白厚膩)
- 습성 설사

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 창출(蒼朮) | 12g | 조습건비 |
| 臣 | 후박(厚朴) | 9g | 행기소만 |
| 佐 | [[약재/_약재_총괄#진피\|진피(陳皮)]] | 6g | 이기화담 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 3g | 조화제약 |

## 이기제 선택 가이드

```
기체(氣滯) / 기울(氣鬱) 확인
├── 비위기체 (소화불량 위주)
│   ├── 한열착잡 (명치 비만) → 반하사심탕
│   ├── 비기허+기체+담습 → 향사육군자탕
│   └── 습곤비위 → 평위산
├── 간기울결 (스트레스, 옆구리 답답)
│   ├── 간울+비허 → 소요산
│   ├── 간울+기체 위주 → 시호소간산
│   └── 간풍+불면+과민 → 억간산
└── 복합형
    ├── PMS → 가미소요산
    └── 간울+담 → 억간산가진피반하
```
