# 보기제 (補氣劑)

기(氣)가 부족한 기허(氣虛) 증상을 치료하는 처방군입니다. 비기허, 폐기허, 기허하함 등에 사용합니다.

---

## 1. 보중익기탕 (補中益氣湯)

### 기본 정보
- **출전**: 비위론 (李東垣)
- **분류**: 보기승양제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 비위기허로 인한 만성 피로, 식욕 부진
- 기허하함: 위하수, 자궁하수, 탈항, 탈장
- 기허발열: 오후 미열, 자한
- 만성 설사 (비허형)

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 18g | 보기승양 |
| 臣 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 6g | 대보원기 |
| 臣 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비익기 |
| 佐 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 3g | 보혈화영 |
| 佐 | [[약재/_약재_총괄#진피\|진피(陳皮)]] | 6g | 이기화담 |
| 佐 | 승마(升麻) | 3g | 승거양기 |
| 佐 | 시호(柴胡) | 3g | 승거양기 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 5g | 조화제약 |

### 변방
- **가미보중익기탕**: + 반하, 죽여 (구역 동반 시)
- **보중익기탕가감방**: + 오미자, 맥문동 (기음양허 시)

### 주의사항
- 실열증(實熱證) 환자에게 금기
- 음허화왕(陰虛火旺) 주의
- [[약재/상극_금기|배합 금기]] 확인 필수

## 2. 사군자탕 (四君子湯)

### 기본 정보
- **출전**: 태평혜민화제국방
- **분류**: 보기건비제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 비기허(脾氣虛): 식욕 부진, 복부 팽만, 연변
- 안색 창백, 기력 저하
- 만성 소화불량의 기본방

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 대보원기, 건비 |
| 臣 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비조습 |
| 佐 | 복령(茯苓) | 9g | 건비삼습 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 6g | 익기화중 |

### 변방
- **육군자탕(六君子湯)**: 사군자탕 + 반하, 진피 → 비허담습 겸한 경우
- **향사육군자탕**: 육군자탕 + 향부자, 사인 → 비허기체 겸한 경우 ([[처방/이기제#향사육군자탕|상세]])

### 주의사항
- 기체(氣滯)가 주된 경우 단독 사용 부적합
- 실증(實證) 환자 주의

## 3. 생맥산 (生脈散)

### 기본 정보
- **출전**: 의학계원 (李東垣)
- **분류**: 보기양음제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]], [[체질/_체질_총괄#태음인|태음인]]

### 적응증
- 기음양허(氣陰兩虛): 만성 기침, 구건, 피로
- 서상맥허(暑傷脈虛): 여름철 탈수, 열사병
- 심폐기음허: 심계, 단기(短氣), 자한/도한

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 보기생진 |
| 臣 | 맥문동(麥門冬) | 9g | 양음청열 |
| 佐使 | 오미자(五味子) | 6g | 렴폐지한 |

### 주의사항
- 한증(寒證)이 주된 경우 부적합
- 외감 초기(발열, 오한)에는 사용 주의

---

## 4. 이중탕 (理中湯)

### 기본 정보
- **출전**: 상한론 (張仲景)
- **분류**: 온중보기제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 비위허한(脾胃虛寒): 복통, 설사, 구토
- 수양성 설사, 복부 냉감
- 한토한리(寒吐寒利)

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 건강(乾薑) | 9g | 온중거한 |
| 臣 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 보기건비 |
| 佐 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비조습 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 9g | 조화제약 |

### 변방
- **부자이중탕**: + 부자 → 양허한이 더 심한 경우
- **연리탕**: 이중탕 + 평위산 → 한습 겸한 경우

### 주의사항
- 열증(熱證) 환자 금기
- 음허(陰虛) 환자 주의
- [[약재/상극_금기|부자 추가 시 십팔반 확인 필수]]

## 5. 옥병풍산 (玉屛風散)

### 기본 정보
- **출전**: 의방류취
- **분류**: 보기고표제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]], [[체질/_체질_총괄#태음인|태음인]]

### 적응증
- 표허자한(表虛自汗): 평소 땀이 많고 감기 잘 걸리는 경우
- 기허감모(氣虛感冒) 예방
- 알레르기 비염의 근본 치료

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 30g | 보기고표 |
| 臣 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 15g | 건비익기 |
| 佐使 | 방풍(防風) | 15g | 거풍해표 |

### 주의사항
- 외감 급성기에는 단독 사용 부적합
- 자한이 아닌 도한(盜汗)에는 부적합 (음허 감별 필요)

## 보기제 선택 가이드

```
기허(氣虛) 확인
├── 비기허 주증
│   ├── 단순 비기허 → 사군자탕
│   ├── 비허+담습 → 육군자탕
│   └── 비허+기체 → 향사육군자탕 (→ 이기제)
├── 기허하함 (장기하수)
│   └── 보중익기탕
├── 기음양허 (피로+구건)
│   └── 생맥산
├── 비위허한 (복냉+설사)
│   └── 이중탕
└── 표허자한 (감기 잦음)
    └── 옥병풍산
```
