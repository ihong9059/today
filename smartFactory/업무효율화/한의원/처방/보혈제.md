# 보혈제 (補血劑)

혈(血)이 부족한 혈허(血虛) 증상을 치료하는 처방군입니다. 안면 창백, 어지러움, 심계, 불면, 월경 불순 등에 사용합니다.

---

## 1. 사물탕 (四物湯)

### 기본 정보
- **출전**: 태평혜민화제국방
- **분류**: 보혈기본방
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]], [[체질/_체질_총괄#소양인|소양인]]

### 적응증
- 혈허(血虛): 안면 창백, 어지러움, 심계, 입술건조
- 월경 부조: 월경량 감소, 월경통, 무월경
- 산후 조리: 산후 혈허

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 숙지황(熟地黃) | 12g | 자음보혈 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 9g | 보혈활혈 |
| 佐 | 백작약(白芍藥) | 9g | 양혈렴음 |
| 使 | 천궁(川芎) | 6g | 활혈행기 |

### 변방
- **궁귀교애탕**: 사물탕 + 아교, 애엽 → 자궁 출혈
- **도홍사물탕**: 사물탕 + 도인, 홍화 → 혈어 겸한 경우
- **소영활혈탕**: 사물탕 가감 → 타박상, 어혈

### 주의사항
- 비허(脾虛)로 인한 설사 시 단독 사용 주의 (숙지황이 체할 수 있음)
- 기허가 심하면 [[처방/보기제#사군자탕|사군자탕]]과 합방 (→ 팔물탕)

## 2. 십전대보탕 (十全大補湯)

### 기본 정보
- **출전**: 태평혜민화제국방
- **분류**: 기혈쌍보제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 기혈양허(氣血兩虛): 극심한 피로, 창백, 어지러움
- 수술 후 회복, 만성 소모성 질환
- 암환자 보조 치료 (기력 회복)
- 산후 조리

### 처방 구성 (군신좌사)
사군자탕(보기) + 사물탕(보혈) + 황기, 육계

| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 대보원기 |
| 君 | 숙지황(熟地黃) | 12g | 자음보혈 |
| 臣 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비익기 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 9g | 보혈활혈 |
| 佐 | 복령(茯苓) | 9g | 건비삼습 |
| 佐 | 백작약(白芍藥) | 9g | 양혈렴음 |
| 佐 | 천궁(川芎) | 6g | 활혈행기 |
| 佐 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 12g | 보기고표 |
| 佐 | 육계(肉桂) | 3g | 온양보화 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 5g | 조화제약 |

### 주의사항
- 실열증(實熱證) 금기
- 감기 중에는 사용 보류
- 소화 기능이 매우 약한 경우 위장 부담 가능

## 3. 당귀보혈탕 (當歸補血湯)

### 기본 정보
- **출전**: 내외상변혹론 (李東垣)
- **분류**: 보기생혈제
- **적합 체질**: 전체질 가능

### 적응증
- 혈허발열: 기가 혈을 통솔하지 못하여 발생하는 열감
- 출혈 후 혈허 회복
- 산후 발열

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 30g | 대보기 → 기생혈 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 6g | 보혈화영 |

> **배합 특징**: 황기:당귀 = 5:1 비율. "기를 크게 보하여 혈을 생하게 한다(氣旺生血)"는 원리.

### 주의사항
- 음허발열과 감별 필수 (음허 시 부적합)
- 실열(實熱) 발열과 구분 필요

---

## 4. 귀비탕 (歸脾湯)

### 기본 정보
- **출전**: 제생방 (嚴用和)
- **분류**: 심비쌍보제
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]]

### 적응증
- 심비양허(心脾兩虛): 불면, 건망, 심계, 식욕 부진
- 비불통혈(脾不統血): 자반, 기능성 자궁출혈, 변혈
- 과로/과사(過思)로 인한 신경쇠약

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | [[약재/_약재_총괄#인삼\|인삼(人蔘)]] | 9g | 보기건비 |
| 君 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 12g | 보기 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 9g | 보혈양심 |
| 臣 | 용안육(龍眼肉) | 9g | 보혈안신 |
| 佐 | [[약재/_약재_총괄#백출\|백출(白朮)]] | 9g | 건비 |
| 佐 | 복신(茯神) | 9g | 안신 |
| 佐 | 산조인(酸棗仁) | 12g | 양심안신 |
| 佐 | 원지(遠志) | 6g | 안신익지 |
| 佐 | 목향(木香) | 3g | 이기성비 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 5g | 조화제약 |
| 引 | 생강 3편, 대조 2매 | | 조화영위 |

### 변방
- **가미귀비탕**: + 치자, 시호 → 간울화 동반 시

### 주의사항
- 실열(實熱) 불면에는 부적합
- 담열(痰熱) 불면과 감별 필요

## 5. 쌍화탕 (雙和湯)

### 기본 정보
- **출전**: 향약집성방
- **분류**: 기혈쌍보제 (한국 고유)
- **적합 체질**: [[체질/_체질_총괄#소음인|소음인]], [[체질/_체질_총괄#태음인|태음인]]

### 적응증
- 기혈양허로 인한 전신 권태
- 산후 조리, 병후 회복
- 근골통, 관절통 동반한 허증

### 처방 구성 (군신좌사)
| 역할 | 약재 | 용량 | 효능 |
|------|------|------|------|
| 君 | 숙지황(熟地黃) | 8g | 자음보혈 |
| 君 | 백작약(白芍藥) | 8g | 양혈렴음 |
| 臣 | [[약재/_약재_총괄#황기\|황기(黃芪)]] | 6g | 보기 |
| 臣 | [[약재/_약재_총괄#당귀\|당귀(當歸)]] | 6g | 보혈 |
| 佐 | 천궁(川芎) | 4g | 활혈행기 |
| 佐 | 계피(桂皮) | 4g | 온양 |
| 使 | [[약재/_약재_총괄#감초\|감초(甘草)]] | 4g | 조화제약 |
| 引 | 생강 3편, 대조 2매 | | 조화영위 |

### 주의사항
- 감기 기간 중 복용 주의 (보약 특성상 병사를 가둘 수 있음)
- 열이 있는 경우 복용 중단

## 보혈제 선택 가이드

```
혈허(血虛) 확인
├── 단순 혈허 (창백, 어지러움, 월경이상)
│   └── 사물탕
├── 기혈양허 (피로+혈허)
│   ├── 중증 → 십전대보탕
│   └── 경증 / 산후 → 쌍화탕
├── 혈허발열 (출혈 후 열감)
│   └── 당귀보혈탕
├── 심비양허 (불면+건망+혈허)
│   └── 귀비탕
└── 기허 겸한 (기허>혈허)
    └── 팔물탕 (사군자+사물)
```
