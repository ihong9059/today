변증 진단: 풍한표증(風寒表證)

진단 항목분석
변증 결과풍한표증(風寒表證)
표리(表裏)표증(表證) — 오한·발열 동반, 사기(邪氣)가 체표에 위치
한열(寒熱)한증(寒證) — 오한 위주, 맑은 콧물(청체, 清涕)은 한사(寒邪)의 증거
맥상 근거부긴맥(浮緊脈) — 부(浮)=표증, 긴(緊)=한사. 풍한표증의 전형적 맥상

치법 및 처방

항목내용
치법(治法)해표산한(解表散寒) — 사기를 발산시켜 표증을 해소
추천 처방마황탕(麻黃湯) — 오한 심하고 땀이 안 나는 표실증(表實證)
계지탕(桂枝湯) — 오한+자한(自汗)이 있는 표허증(表虛證)
감별 포인트무한(無汗) → 마황탕 / 자한(自汗) → 계지탕

의사결정 과정

단계판단근거
1. 표리 판별표증오한+발열 동반 = 표증의 기본 조건
2. 한열 판별한증맑은 콧물(청체) = 한사, 오한이 발열보다 우세
3. 맥진 확인부긴부=표, 긴=한 → 풍한표증 확진
4. 치법 결정해표산한표한(表寒) → 신온해표(辛溫解表)가 정법
2 "안면홍조, 구갈, 불면, 맥 세삭"

변증 진단: 음허내열증(陰虛內熱證)

진단 항목분석
변증 결과음허내열증(陰虛內熱證)
표리(表裏)이증(裏證) — 외감 증상 없이 내부 장부의 음허로 인한 내열
한열(寒熱)열증(熱證) — 안면홍조, 구갈(口渴)은 허열(虛熱)의 증거
허실(虛實)허증(虛證) — 음액(陰液)이 부족하여 상대적으로 열이 떠오르는 허열
맥상 근거세삭맥(細數脈) — 세(細)=음혈부족, 삭(數)=열. 음허내열의 전형적 맥상

치법 및 처방

항목내용
치법(治法)자음강화(滋陰降火) — 음액을 보충하여 허열을 내림
추천 처방육미지황환(六味地黃丸) — 간신음허(肝腎陰虛)의 기본 처방
지백지황환(知柏地黃丸) — 음허화왕(陰虛火旺)이 심한 경우
보조 치법불면 심하면 천왕보심단(天王補心丹) 가감 고려

의사결정 과정

단계판단근거
1. 표리 판별이증외감 증상(오한·발열 동반) 없음 → 이증
2. 한열 판별열증안면홍조+구갈 = 열상(熱象)
3. 허실 판별허증세맥(음혈부족) + 불면(심음부족) = 허열, 실열이 아님
4. 종합 변증음허내열이(裏)+열(熱)+허(虛) = 음허내열증
5. 치법 결정자음강화음허 → 보음(補陰), 내열 → 강화(降火)
3 "피로, 식욕부진, 사지무력, 맥 허약"

변증 진단: 기허증(氣虛證)

진단 항목분석
변증 결과기허증(氣虛證) — 비기허(脾氣虛) 위주

치법 및 처방

항목내용
치법(治法)보기(補氣) — 비위의 기를 보충하여 후천지본(後天之本) 강화
추천 처방사군자탕(四君子湯) — 기허의 기본 처방 (인삼+백출+복령+감초)

식이 처방산약(山藥)죽, 대추차, 인삼차 등 비위를 보하는 식이 병행

의사결정 과정

단계판단근거
1. 주소 분석전신 기허피로+무력감 = 기(氣)의 기본 기능(추동·온후·고섭) 약화
2. 장부 귀속비(脾)식욕부진+사지무력 = "비주사지(脾主四肢)" "비주운화(脾主運化)" 기능 실조
3. 허실 판별허증허약맥+부족 증상 → 명확한 허증. 사기(邪氣) 실증 아님
4. 치법 결정보기건비비기허 → 보기(補氣)+건비(健脾)가 정법
