# 한국 한의원 업무 전 과정 설명서

## 1. 한의원 개설 및 허가

### 1.1 개설 요건
- **한의사 면허**: 한의과대학 졸업 + 한의사 국가시험 합격 + 보건복지부 면허 발급
- **한의원 개설 신고**: 관할 시/군/구 보건소에 신고
- **시설 기준**: 의료법 시행규칙 (진료실, 조제실, 대기실)
- **한의사 상주 의무**: 진료 시간 중 한의사 1인 이상 상주

### 1.2 필수 시설/장비
| 장비 | 용도 | 필수 여부 |
|------|------|:---------:|
| 진료실 | 진맥, 문진, 진료 | 필수 |
| 조제실 | 한약 조제 (탕전실) | 필수 |
| 탕전기 | 한약 달이기 (자동/반자동) | 필수 |
| 침 시술 장비 | 호침, 전침기, 부항기 | 필수 |
| 뜸 장비 | 직접구, 간접구, 전자뜸 | 권장 |
| 약재 보관실/선반 | 한약재 보관 (방습/방충) | 필수 |
| 전자저울 | 약재 정밀 계량 | 필수 |
| EMR 시스템 | 전자의무기록 + 보험청구 | 필수 |
| 추나 치료대 | 추나요법 시행 | 권장 |
| 적외선 조사기 | 물리치료 보조 | 권장 |

## 2. 한의학 진료 체계

### 2.1 사상체질 분류
```
사상체질 (四象體質)
├── 태양인 (太陽人) — 약 5%
│   ├── 폐대간소 (肺大肝小)
│   ├── 특징: 창의적, 진취적, 상체 발달
│   └── 취약: 간, 하체, 소화기
│
├── 태음인 (太陰人) — 약 50%
│   ├── 간대폐소 (肝大肺小)
│   ├── 특징: 체격 건장, 인내심, 식욕 왕성
│   └── 취약: 폐, 호흡기, 피부
│
├── 소양인 (少陽人) — 약 30%
│   ├── 비대신소 (脾大腎小)
│   ├── 특징: 활발, 열성, 상체 발달
│   └── 취약: 신장, 비뇨기, 하체
│
└── 소음인 (少陰人) — 약 15%
    ├── 신대비소 (腎大脾小)
    ├── 특징: 섬세, 소화력 약, 추위 많이 탐
    └── 취약: 소화기, 비위
```

| 표리 | 표증/리증 | 병의 위치 (겉/속) |

| 허실 | 허증/실증 | 정기 부족/사기 과다 |

## 3. 진료 과정

### 3.1 진료 흐름
```
[환자 내원] ─── 접수 (초진/재진)
    │
    ▼
[문진 (問診)] ── 증상, 병력, 생활습관, 가족력
    │           ① 주소 (主訴): 가장 불편한 증상
    │           ② 현병력: 발생 시기, 경과
    │           ③ 기왕력: 과거 질환, 수술력
    │           ④ 생활습관: 식사, 수면, 운동, 스트레스
    │           ⑤ 대소변, 수면, 한열, 땀
    │
    ▼
[망진 (望診)] ── 시각적 관찰
    │           ① 안색 (얼굴 색)
    │           ② 설진 (혀 색, 태, 형태)
    │           ③ 체형, 자세, 피부 상태
    │
    ▼
[문진 (聞診)] ── 청각/후각 관찰
    │           ① 음성 (크기, 맑음/탁함)
    │           ② 호흡음, 기침 소리
    │           ③ 체취, 구취
    │
    ▼
[절진 (切診)] ── 촉진
    │           ① 맥진 (脈診): 촌관척 맥박 촉진
    │           ② 복진 (腹診): 복부 압통점, 경결
    │           ③ 경혈 압통 확인
    │
    ▼
[변증 (辨證)] ── 진단
    │           ① 팔강변증 (음양/표리/한열/허실)
    │           ② 장부변증 (어떤 장부 문제인지)
    │           ③ 체질변증 (사상체질 고려)
    │           ④ 기혈변증 (기허/혈허/기체/혈어)
    │
    ▼
[치료 계획] ─── 한약, 침, 뜸, 부항, 추나 등 복합 처방
    │
    ▼
[치료 시행]
    ├── 한약 처방 → 조제 (탕전/환/산/고)
    ├── 침 치료 → 경혈 선택 + 시술
    ├── 뜸 치료 → 직접구/간접구
    ├── 부항 → 건식/습식
    ├── 추나 → 근골격 교정
    └── 물리치료 → 적외선, 전기자극 등
    │
    ▼
[수납] ──────── 본인부담금 수납
    │
    ▼
[경과 관찰] ─── 다음 내원 일정, 생활 관리 안내
```

## 4. 한약 처방 및 조제

### 4.1 한약 제형
| 제형 | 한자 | 설명 | 용도 |
|------|------|------|------|
| 탕제 | 湯劑 | 약재를 물에 달인 것 | 급성 질환, 맞춤 처방 |
| 환제 | 丸劑 | 약재 분말을 꿀/물로 뭉친 것 | 만성 질환, 장기 복용 |
| 산제 | 散劑 | 약재를 분말로 만든 것 | 급성, 간편 복용 |
| 고제 | 膏劑 | 약재를 농축한 엑기스/시럽 | 보약, 장기 보관 |
| 첩약 | 貼藥 | 1일분 약재를 포장한 것 | 환자 직접 탕전 |
| 과립제 | 顆粒劑 | 엑기스를 과립으로 만든 것 | 간편, 휴대 |

### 4.2 한약 조제 흐름
```
[처방 결정] ─── 한의사가 처방전 작성
    │           (약재명, 용량, 제형, 일수)
    │
    ▼
[약재 계량] ─── 전자저울로 정밀 계량
    │           각 약재별 g 단위 (예: 황기 12g, 당귀 8g)
    │
    ▼
[조제]
    ├── 탕전: 탕전기에 약재 + 물 투입 → 2~3시간 달이기
    │         1첩 = 1일분 (보통 2회 복용)
    │         15~30첩 단위 조제
    ├── 환제: 분말 → 반죽 → 환 성형 → 건조
    ├── 산제: 분말 → 개별 포장
    └── 고제: 장시간 달이기 → 농축 → 용기 담기
    │
    ▼
[포장] ──────── 1회분씩 파우치 포장 (탕제)
    │           라벨: 환자명, 복용법, 날짜
    │
    ▼
[복약지도] ─── 복용법, 보관법, 주의사항 안내
    │           ① 식전/식후/공복
    │           ② 냉장 보관 (탕제)
    │           ③ 양약 복용 간격 (최소 1시간)
    │           ④ 음식 주의 (돼지고기, 녹두 등 상극)
    │
    ▼
[수납] ──────── 한약 비용 수납
                (비급여가 대부분, 일부 급여 처방 있음)
```

## 5. 침 치료

### 5.1 침 치료 흐름
```
[경혈 선택] ─── 변증에 따른 경혈 결정
    │           ① 근위취혈: 통증 부위 근처 경혈
    │           ② 원위취혈: 먼 부위 경혈 (반대쪽)
    │           ③ 특정혈: 사관혈, 원혈, 오수혈 등
    │
    ▼
[시술 준비] ─── 소독 (피부+손), 호침 선택 (굵기/길이)
    │
    ▼
[자침] ──────── 혈위에 침 삽입
    │           깊이: 부위별 상이 (5mm~50mm)
    │           수기법: 보법(보하기)/사법(빼기)
    │
    ▼
[유침] ──────── 15~30분 유지
    │           전침 연결 (필요 시)
    │
    ▼
[발침] ──────── 침 제거 + 지혈
    │
    ▼
[시술 후 관찰] ── 출혈, 어지러움, 이상반응 확인
```

### 5.2 주요 경혈
| 경혈 | 위치 | 주요 적응증 |
|------|------|-----------|
| 합곡 (LI4) | 엄지-검지 사이 | 두통, 치통, 감기, 안면마비 |
| 족삼리 (ST36) | 무릎 아래 3촌 | 소화불량, 위통, 보양, 피로 |
| 태충 (LR3) | 발등 1~2지 사이 | 스트레스, 두통, 고혈압, 간기능 |
| 백회 (GV20) | 정수리 | 두통, 어지러움, 집중력, 불면 |
| 삼음교 (SP6) | 내측 복숭아뼈 위 3촌 | 부인과, 소화, 불면, 비뇨기 |
| 곡지 (LI11) | 팔꿈치 외측 | 고혈압, 피부질환, 면역 |

| 풍지 (GB20) | 뒷머리 아래 오목 | 두통, 어지러움, 목뻣뻣, 감기 |
| 관원 (CV4) | 배꼽 아래 3촌 | 보양, 냉증, 비뇨기, 부인과 |
| 중완 (CV12) | 배꼽 위 4촌 | 위통, 소화불량, 구역 |

### 7.3 청구 흐름
```

    │
    ▼
[수가 산정] ─── EMR에서 행위별 수가 자동 계산
    │           (진찰+침+뜸+부항+물리+한약)
    │
    ▼
[청구 데이터 생성] ── 건강보험심사평가원(HIRA) 형식
    │
    ▼
[전자 청구] ─── 매월 익월 10일까지
    │
    ▼
[심사] ──────── HIRA 심사
    │           ① 진료 적정성
    │           ② 추나 횟수 제한 확인
    │           ③ 급여 한약 적응증 부합 여부
    │
    ▼
[지급] ──────── 건보공단 → 한의원 계좌
                청구 후 약 20~25일 지급
```

## 8. 한약재 관리

### 8.1 약재 분류
| 분류 | 예시 | 보관 |
|------|------|------|
| 보기약 (補氣) | 인삼, 황기, 백출 | 실온, 방습 |
| 보혈약 (補血) | 당귀, 숙지황, 작약 | 실온, 차광 |
| 해표약 (解表) | 마황, 계지, 갈근 | 실온 |
| 청열약 (清熱) | 황금, 황련, 치자 | 실온 |
| 화담약 (化痰) | 반하, 진피, 복령 | 실온, 방습 |
| 활혈약 (活血) | 도인, 홍화, 천궁 | 실온 |
| 이수약 (利水) | 택사, 저령, 의이인 | 실온, 방습 |
| 독성/귀중약 | 부자, 초오, 사향, 우황 | 별도 보관, 이중잠금 |

### 8.2 약재 입고/관리
```
[발주] ──── 한약재 도매상/제약사에 주문
    │       (한약재 유통 허가 업체만 가능)
    ▼
[입고 검수]
    │   ① 외관 검사 (색, 형태, 냄새)
    │   ② 이물질 확인
    │   ③ 포장 상태, 유통기한
    │   ④ 의약품 적합 판정서 확인 (잔류농약, 중금속, SO₂)
    ▼
[입고 등록] ── 약재명, 수량, LOT, 유통기한, 공급처 기록
    ▼
[보관] ──── 방습/방충/방서 환경
    │       온습도 관리 (15~25℃, 50~60%)
    │       직사광선 차단
    ▼
[재고 관리]
    ├── 선입선출 (FIFO)
    ├── 월 1회 재고 실사
    ├── 유통기한 3개월 전 사전 경고
    └── 독성 약재: 별도 보관 + 사용 기록
```

```
[08:30] 개점 준비

[13:00] 오후 진료
        ├── 진료 + 시술
        ├── 한약 포장/라벨링

[17:00] 약재 발주
        └── 부족 약재 주문

[18:00] 마감
        ├── 매출 정산 (현금/카드/보험)

[18:30] 월간 업무
        ├── HIRA 보험 청구 (월 1회)
        ├── 약재 재고 실사 (월 1회)
        └── 의료 폐기물 처리 (침, 부항 등)
```
