---

## 현병력

- 3개월 전부터 식후 상복부 더부룩함, 그득함 지속
- 식사량 줄었으나 복부 팽만감 호소
- 간헐적 구역감 (구토는 없음)
- 최근 직장 스트레스 증가 후 악화
- 양방 검사(위내시경): 만성 표재성 위염, 특별한 기질적 병변 없음
- 소화제(양약) 복용 중이나 효과 미미

## 한의학적 소견

### 사진(四診)

| 진단 | 소견 |
|------|------|
| 망진(望診) | 안면 창백, 체형 마른 편, 피로한 인상 |
| 문진(聞診) | 목소리 가늘고 힘없음, 복명(腹鳴) 청취 |
| 문진(問診) | 식욕부진, 복창, 구역, 대변 1일 1~2회 연변, 수족냉증, 피로 |
| 절진(切診) | 맥: 세약(細弱), 설: 담백, 백니태(白膩苔), 복진: 심하비경(心下痞硬) |

### 변증 분석

[[변증/_변증_가이드|변증 가이드]]에 따른 분석:

1. **팔강변증**: 리증, 한증+열증 착잡, 허증 → 리한허+한열착잡
2. **기혈변증**: 비기허 + 비위기체
3. **장부변증**: 비위허약, 한열착잡형 비만(痞滿)
4. **체질**: 소음인 — 비위 취약 확인

### 최종 변증
**비위기허 + 한열착잡형 심하비만(脾胃氣虛 + 寒熱錯雜型 心下痞滿)**

## 치료 계획

### 1차 치료 (1~2주): 급성 증상 개선

#### 한약 처방
**[[처방/이기제#반하사심탕|반하사심탕(半夏瀉心湯)]] 가감**

| 약재 | 용량 | 역할 | 비고 |
|------|------|------|------|
| 반하 | 12g | 君 — 소비산결, 강역지구 | [[약재/상극_금기\|임부금기 확인]] → 비임부 |
| 황금 | 9g | 臣 — 청열 | |
| 황련 | 3g | 臣 — 청열 | |
| 인삼 | 9g | 佐 — 보기건비 | |
| 건강 | 9g | 佐 — 온중거한 | |
| 대조 | 4매 | 佐 — 보비 | |
| 감초 | 6g | 使 — 조화 | [[약재/상극_금기#십팔반\|십팔반 확인]] → 해당없음 |
| 사인 | 3g | 가미 — 화습행기 | 기체 동반 |
| 진피 | 6g | 가미 — 이기화담 | 복창 완화 |

- **[[약재/상극_금기|안전성 확인]]**: 십팔반 해당 없음, 십구외 해당 없음, 임부 아님
- **복용법**: 1일 2첩 3회, 식전 30분 온복
- **급여**: 급여한약 56종 해당 ([[보험/_보험_총괄|보험 참조]])

#### 침 치료
[[경혈/배혈법#소화불량|소화불량 배혈법]] 적용

| 경혈 | 코드 | 적용 |
|------|------|------|
| 족삼리 | ST36 | 건비화위 (양측) |
| 중완 | CV12 | 위의 모혈 |
| 내관 | PC6 | 화위강역, 지구 (양측) |
| 비수 | BL20 | 비의 배수혈 (양측) |
| 위수 | BL21 | 위의 배수혈 (양측) |
| 태충 | LR3 | 소간 — 스트레스 대응 (양측) |

- **시술**: 주 3회, 20분 유침, 전침 병행 (ST36-CV12)

### 2차 치료 (3~4주): 근본 체질 보강

증상 호전 후 비기허 근본 치료로 전환

#### 한약 처방 변경
**[[처방/이기제#향사육군자탕|향사육군자탕(香砂六君子湯)]]**

| 약재 | 용량 | 역할 |
|------|------|------|
| 인삼 | 6g | 君 — 보기건비 |
| 백출 | 9g | 臣 — 건비조습 |
| 복령 | 9g | 臣 — 삼습건비 |
| 반하 | 6g | 佐 — 조습화담 |
| 진피 | 6g | 佐 — 이기화담 |
| 향부자 | 6g | 佐 — 소간이기 |
| 사인 | 3g | 佐 — 화습행기 |
| 감초 | 3g | 使 — 조화 |

#### 침 치료
- 주 2회로 감소, 보법(補法) 위주

## 경과

| 시점 | 상태 |
|------|------|
| 1주 후 | 구역감 50% 감소, 복부 그득함 다소 완화 |
| 2주 후 | 식욕 회복 시작, 복명 감소, 대변 성상 호전 |
| 3주 후 | 향사육군자탕 전환, 식후 불편감 70% 개선 |
| 4주 후 | 소화 기능 대폭 개선, 수족냉증 완화, 피로 감소 |
| 6주 후 | 정상 식사 가능, 재발 방지 위해 월 1회 관리 |

---

## 총평

- 소음인 체질의 비위 취약성을 고려한 단계적 치료
- 1단계(반하사심탕): 한열착잡 해소 → 급성 증상 완화
- 2단계(향사육군자탕): 비기허 근본 보강 → 재발 방지
- 침 치료 병행으로 치료 효과 상승
- 식이 지도([[체질/체질별_음식#소음인|소음인 음식]]) 병행이 중요
