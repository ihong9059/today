# 사례: 직장인 불면+스트레스

## 환자 정보

| 항목 | 내용 |
|------|------|
| 성별/나이 | 남성 / 34세 |
| 체질 | [[체질/_체질_총괄#소양인\|소양인]] |
| 주소(主訴) | 불면증 2개월, 과민/짜증 |
| 직업 | IT 회사 팀장 |
| 초진일 | 2025-09-22 |

---

## 현병력

- 2개월 전 팀장 승진 후 업무량 급증
- 입면 곤란: 잠들기까지 1~2시간 소요
- 천면(淺眠): 자다가 2~3회 깸, 꿈 많음
- 총 수면시간 3~4시간/일
- 낮 시간 피로, 집중력 저하, 업무 실수 증가
- 짜증, 과민 반응 빈번 (직원들과 갈등 증가)
- 두통 (측두부 위주), 어깨/목 결림
- 양방 수면제(졸피뎀) 처방받았으나 의존성 우려로 한방 치료 희망

## 한의학적 소견

### 사진(四診)

| 진단 | 소견 |
|------|------|
| 망진 | 안면 홍조 경향, 눈 충혈, 다소 마른 체형, 표정 경직 |
| 문진 | 말 빠르고 짜증 섞인 어조 |
| 문진 | 불면, 다몽, 두통(측두부), 구건, 대변 1일 1회 경변, 소변 황, 식욕 보통, 음주 주 3~4회 |
| 절진 | 맥현삭(弦數), 설홍(舌紅) 태박황(薄黃苔), 경항부 근긴장(++), 태양혈 압통(+) |

### 변증 분석

1. **팔강**: 리증, 열증, 실허 착잡 (실 > 허)
2. **기혈**: 간기울결 → 울화(鬱火), 심혈부족 겸
3. **장부**: 간화상염(肝火上炎) + 심신불교(心腎不交)
4. **체질**: 소양인 — 화(火)가 쉽게 오름, 비대신소

### 최종 변증
**간울화화 + 심신불교형 불면(肝鬱化火 + 心腎不交型 不眠)**

- 양측 교대 부착, 3~4일 유지 후 교체
- 취침 전 각 이혈 1분씩 자가 압박 지도

## 생활 지도

### 수면 위생 교육
1. 취침/기상 시간 고정 (23:00 / 07:00)
2. 취침 2시간 전 스마트폰/PC 사용 중단
3. 침실 환경: 어둡고, 조용하고, 서늘하게
4. 카페인 오후 2시 이후 금지
5. 음주 절제 (수면의 질 악화)
6. 운동: 오전~오후 유산소 운동 권장 (취침 3시간 전까지)

### 식이 지도
- [[체질/체질별_음식#소양인|소양인 식이]] 참조
- 매운 음식, 카페인, 음주 절제
- 돼지고기, 오이, 보리 등 시원한 성질의 음식 권장
- 취침 전 따뜻한 대추차 또는 캐모마일차

### 스트레스 관리
- 복식 호흡 연습 (4-7-8 호흡법)
- 점진적 근이완법 (취침 전 15분)
- 업무 시간 관리 (칼퇴근 실천)

## 총평

- 간울화화형 불면에 억간산가진피반하 + 산조인/치자 가미 → 효과적
- 이침(왕불유행자 압환법): 야간 자가 관리로 지속적 안신 효과
- 체침 + 이침 + 한약 삼중 접근이 양약(수면제) 감량/중단에 기여
- 소양인 체질의 화(火) 경향 → 매운 음식/음주 절제 교육 필수
- 수면 위생 교육이 치료 효과 유지에 핵심적 역할
- 직장 스트레스가 근본 원인 → 장기적으로 스트레스 관리 기법 병행 권장
