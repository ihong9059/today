# 사례: 요추 디스크 환자

## 환자 정보

| 항목 | 내용 |
|------|------|
| 성별/나이 | 남성 / 45세 |
| 체질 | [[체질/_체질_총괄#태음인\|태음인]] |
| 주소(主訴) | 좌측 요통 + 좌하지 방사통 2주 |
| 직업 | 택배 기사 |
| 초진일 | 2025-06-10 |

---

## 현병력

- 2주 전 중량물 들다가 "뚝" 소리와 함께 요통 발생
- 좌측 둔부~대퇴 후면~하퇴 외측으로 방사통
- 기침/재채기 시 통증 악화
- 좌측 하지 저림감
- 보행 시 파행(跛行)
- 양방 MRI: L4-5 추간판 탈출증 (좌측 후외방)
- 양방에서 수술 권유받았으나 보존적 치료 원함

---

## 한의학적 소견

### 사진(四診)

| 진단 | 소견 |
|------|------|
| 망진 | 체격 좋으나 과체중(BMI 27), 좌측으로 치우쳐 서 있음(항통체위) |
| 문진 | 신음(呻吟), 동작 시 고통 표현 |
| 문진 | 요통 NRS 8/10, 하지방사통 NRS 7/10, 좌하지 저림, 대변 보통 |
| 절진 | 맥현긴(弦緊), 설담홍태박백, L4-5 극돌기 주변 압통(+), SLR test 좌측 40도(+) |

### 이학적 검사

| 검사 | 결과 |
|------|------|
| SLR (직거상) | 좌측 40도 양성 |
| 교차 SLR | 음성 |
| 하지 근력 | L5 분절: 좌측 장무지신근 4/5로 약화 |
| 감각 | 좌측 L5 피부분절 감각 저하 |
| 반사 | 슬개건 반사 정상, 아킬레스건 반사 정상 |

### 변증 분석

1. **팔강**: 리증, 한실 겸허
2. **기혈**: 기체혈어(氣滯血瘀) + 신허(腎虛) 기저
3. **장부**: 신기부족 + 한습비조(寒濕痹阻)

### 최종 변증
**기체혈어 + 한습비조형 요통(氣滯血瘀 + 寒濕痹阻型 腰痛)**

## 치료 계획

### 1단계: 급성기 (1~2주) — 통증 완화

#### 추나요법
- 요추 관절신연추나 (JX213) — 주 3회
- 골반 도수추나 (JX224) — 주 2회
- 목적: 추간판 압력 감소, 신경 감압, 골반 교정

> **보험**: [[보험/_보험_총괄#추나요법-급여-기준|연간 20회 한도]] 내에서 급여 적용

#### 침 치료
[[경혈/배혈법#요통|요추 디스크 배혈법]] 적용

| 경혈 | 코드 | 적용 |
|------|------|------|
| 환도 | GB30 | 좌골신경통 요혈 (좌측) |
| 위중 | BL40 | 요배 사총혈 (양측) |
| 신수 | BL23 | 보신, 배수혈 (양측) |
| 대장수 | BL25 | L4-5 수준 (양측) |
| 양릉천 | GB34 | 근회, 하지 (좌측) |
| 곤륜 | BL60 | 원위취혈 (좌측) |
| 아시혈 | — | L4-5 극돌기 주변 압통점 |

- 전침: BL23-BL25 (2Hz, 20분)
- 부항: 요추부 습부항 (어혈 배출)
- 빈도: 주 3회

### 2단계: 아급성기 (3~4주) — 기능 회복

#### 추나
- 주 2회로 감소
- 관절가동술 + 근에너지기법 병행

#### 침 치료
- 주 2회, 통증 부위 중심 + 보신혈 추가
- 태계(KI3) 보법 추가 — 신허 보강

#### 한약
- 독활기생탕 유지, 통증약 감량, 보신약 증량

---

### 3단계: 회복기 (5~8주) — 재발 방지

#### 추나
- 주 1회, 유지 치료

#### 운동 처방
- 코어 근력 강화: 플랭크, 브릿지
- 맥켄지 신전 운동
- 수영 권장
- 중량물 들기 자세 교정 교육

#### 한약
- 육미지황환(六味地黃丸) 전환 — 신음허 보강

## 총평

- 추나(감압) + 침(통증/순환) + 한약(거풍습/보신) 복합 치료로 수술 회피
- 급성기 통증 관리 → 기능 회복 → 재발 방지의 단계적 접근
- 태음인 체질 고려: 체중 감량 병행 필요 (BMI 27 → 24 목표)
- 직업적 위험 요인(중량물) 교육 필수
- 추나 연간 횟수 관리 (20회 한도 내 16회 사용)
