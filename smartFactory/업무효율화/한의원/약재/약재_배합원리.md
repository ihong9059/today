# 약재 배합 원리 — 군신좌사 (君臣佐使)

한약 처방은 단순히 약재를 모아놓은 것이 아니라, 각 약재가 정해진 역할을 맡아 유기적으로 구성됩니다. 이 원리를 **군신좌사(君臣佐使)**라 합니다.

---

## 군신좌사의 정의

### 군약 (君藥)

- **역할**: 처방의 주된 치료 목표를 담당하는 핵심 약재
- **특징**: 용량이 가장 많거나, 약효가 가장 강함
- **수량**: 보통 1~2종
- **비유**: 임금 — 국가의 방향을 결정

**예시**: [[처방/보기제#보중익기탕|보중익기탕]]에서 **황기(18g)**가 군약. 보기승양이라는 주 치료 목표를 담당.

---

### 신약 (臣藥)

- **역할**: 군약의 치료 작용을 보조하고 강화
- **특징**: 군약과 같은 방향의 효능을 가지되, 보조적
- **수량**: 1~3종
- **비유**: 신하 — 임금의 뜻을 따라 실행

**예시**: 보중익기탕에서 **인삼(6g), 백출(9g)**이 신약. 황기와 함께 보기건비 작용을 보조.

---

### 좌약 (佐藥)

- **역할**: 세 가지 기능
  1. **좌조(佐助)**: 군신약의 치료 효과를 도움
  2. **좌제(佐制)**: 군신약의 독성이나 편성(偏性)을 제어
  3. **반좌(反佐)**: 약성이 반대되는 약재를 소량 넣어 격거(格拒)를 방지

- **수량**: 1~4종
- **비유**: 참모 — 다양한 보조 역할 수행

**예시**:
- 보중익기탕에서 **당귀(3g)**: 좌조 — 혈을 보하여 기혈 균형
- 보중익기탕에서 **승마(3g), 시호(3g)**: 좌조 — 양기를 끌어올림
- [[처방/이기제#반하사심탕|반하사심탕]]에서 **인삼, 건강**: 좌제 — 황금/황련의 한성을 중화

---

### 사약 (使藥)

- **역할**: 두 가지 기능
  1. **인경(引經)**: 약효를 특정 경락이나 부위로 이끔
  2. **조화(調和)**: 전체 약재의 약성을 조화

- **수량**: 1종 (없는 경우도 있음)
- **비유**: 사신/안내자 — 약을 목적지로 인도

**예시**:
- 대부분의 처방에서 **감초(甘草)**가 사약 — 제약 조화
- 우슬: 하행 인경 (아래로 이끔)
- 길경: 상행 인경 (위로 이끔)

---

## 배합의 일곱 가지 관계 (七情)

약재 간의 상호 관계를 **칠정(七情)**이라 하며, 이를 이해해야 안전하고 효과적인 처방이 가능합니다.

| 관계 | 한자 | 설명 | 임상 의미 |
|------|------|------|----------|
| 단행 | 單行 | 한 약재만 단독 사용 | 독삼탕 (인삼 단독) |
| 상수 | 相須 | 효능이 유사한 약재가 서로 강화 | 대황+망초 (사하력 증강) |
| 상사 | 相使 | 한 약재가 다른 약재의 효능 보조 | 황기+복령 (보기+이수) |
| 상외 | 相畏 | 한 약재가 다른 약재의 독성 감소 | 반하 → 생강이 독성 감소 |
| 상살 | 相殺 | 한 약재가 다른 약재의 독성 제거 | 생강 → 반하 독성 제거 |
| 상오 | 相惡 | 두 약재가 서로 약효 감소 | [[약재/상극_금기#십구외\|십구외]] |
| 상반 | 相反 | 두 약재가 독성/부작용 증강 | [[약재/상극_금기#십팔반\|십팔반]] |

> **안전 원칙**: 상수/상사 → 적극 활용, 상외/상살 → 필요 시 활용, 상오/상반 → 금기

---

## 용량 배합 원칙

### 군약 > 신약 > 좌약 > 사약

일반적으로 역할이 클수록 용량이 많습니다.

```
군약: 전체의 30~50%
신약: 전체의 20~30%
좌약: 전체의 10~20%
사약: 전체의 5~10%
```

### 예외 사항
- **당귀보혈탕**: 황기(30g) > 당귀(6g) — 군약(황기)이 "보혈"이 아닌 "보기생혈" 목적이므로 기약이 군약
- 질환의 경중에 따라 용량 가감 가능
- 소아/노인/임부는 전반적으로 감량

---

## 배합의 실제 적용

### 예시 1: 사군자탕 분석

| 약재 | 역할 | 용량 | 목적 |
|------|------|------|------|
| 인삼 | 君 | 9g | 보기건비 — 주 치료 목표 |
| 백출 | 臣 | 9g | 건비조습 — 인삼 보기 작용 보조 |
| 복령 | 佐 | 9g | 삼습건비 — 비습 제거로 보기 효과 강화 |
| 감초 | 使 | 6g | 조화제약, 익기 |

**배합 의미**: 보기(인삼) + 건비(백출) + 거습(복령) + 조화(감초) → 비기를 보하면서 습을 제거

### 예시 2: 반하사심탕 분석

| 약재 | 역할 | 용량 | 목적 |
|------|------|------|------|
| 반하 | 君 | 12g | 소비산결, 강역지구 — 비경(痞硬) 치료 |
| 황금+황련 | 臣 | 9g+3g | 청열조습 — 열(상부) 제거 |
| 인삼+건강+대조 | 佐 | 9g+9g+4매 | 보비온중 — 한(하부) 치료 + 황금/련의 한성 제어 |
| 감초 | 使 | 9g | 조화 |

**배합 의미**: 한열착잡(寒熱錯雜)을 동시 치료 — 위는 열을 내리고(黃芩/連), 아래는 한을 치료(乾薑/人蔘)

## 가감 원칙

기본 처방에서 환자 상태에 따라 약재를 추가(加)하거나 제거(減)하는 원칙:

| 상황 | 가감 방법 |
|------|----------|
| 기허 동반 | + 인삼 또는 황기 |
| 혈허 동반 | + 당귀, 숙지황 |
| 담습 동반 | + 반하, 진피, 복령 |
| 열 동반 | + 황금, 치자 / 온약 감량 |
| 한 동반 | + 건강, 부자 / 한약 감량 |
| 기체 동반 | + 향부자, 진피 |
| 어혈 동반 | + 도인, 홍화 (임부 확인) |
| 통증 심함 | + 연호색(활혈지통) |
| 불면 동반 | + 산조인, 원지 |
| 식욕부진 | + 산사, 신곡, 맥아 (소식) |

> **중요**: 가감 시에도 [[약재/상극_금기|십팔반/십구외]] 확인 필수

## 포제(炮製)와 배합

일부 약재는 포제 방법에 따라 효능과 독성이 달라지므로, 배합 시 포제 상태를 반드시 고려합니다.

| 약재 | 생약 | 포제품 | 차이점 |
|------|------|--------|--------|
| 반하 | 生半夏 (유독) | 강반하/법반하/청반하 | 포제로 독성 감소, 임상에서는 반드시 포제품 사용 |
| 부자 | 生附子 (대독) | 포부자/흑순편 | 포제로 아코니틴 독성 대폭 감소 |
| 대황 | 生大黃 | 주대황/초대황 | 생용: 사하력 강, 주용: 활혈 위주 |
| 지황 | 生地黃 (寒) | 熟地黃 (溫) | 생용: 청열양음, 숙용: 자음보혈 |
