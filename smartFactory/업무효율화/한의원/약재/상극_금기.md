# 상극 금기

약재 배합 시 반드시 확인해야 하는 금기 사항을 정리합니다. 모든 처방에 앞서 이 문서의 내용을 점검해야 합니다.

---

## 십팔반 (十八反) {#십팔반}

**상반(相反)**: 두 약재를 함께 사용하면 독성이 증가하거나 심각한 부작용이 발생하는 배합. **절대 병용 금기**.

> 구결(口訣): 본초명언십팔반, 반하과루급패모, 백렴백급공오두, 藻戟遂芫구전초(해조대극감수원화는 감초와 상반)

### 감초(甘草)와 상반하는 약재

| 약재 | 한자 | 상반 이유 |
|------|------|----------|
| **대극** | 大戟 | 감초와 합용 시 독성 증강, 격렬한 사하 작용으로 탈수/쇼크 위험 |
| **원화** | 芫花 | 감초와 합용 시 독성 증폭, 구토/설사 심화 |
| **감수** | 甘遂 | 감초와 합용 시 사하 독성 증가, 복통/설사 격심 |
| **해조** | 海藻 | 감초와 합용 시 상호 작용으로 약효 감소 및 부작용 발생 |

### 오두(烏頭, 부자 포함)와 상반하는 약재

| 약재 | 한자 | 상반 이유 |
|------|------|----------|
| **반하** | 半夏 | 오두의 독성(아코니틴) 증강, 심부정맥/심정지 위험 |
| **과루** | 瓜蔞 | 오두 독성 증강 |
| **패모** | 貝母 | 오두 독성 증강 |
| **백렴** | 白蘞 | 오두 독성 증강 |
| **백급** | 白及 | 오두 독성 증강, 상호 약효 길항 |

> **주의**: 부자(附子), 천오(川烏), 초오(草烏)는 모두 오두류에 해당하므로 동일하게 적용됩니다.

### 여로(藜蘆)와 상반하는 약재

| 약재 | 한자 | 상반 이유 |
|------|------|----------|
| **인삼** | 人蔘 | 여로의 구토 독성 증강, 보기 작용 길항 |
| **사삼** | 沙蔘 | 여로 독성 증강 |
| **단삼** | 丹蔘 | 여로 독성 증강 |
| **현삼** | 玄蔘 | 여로 독성 증강 |
| **세신** | 細辛 | 여로 독성 증강 |
| **작약** | 芍藥 | 여로 독성 증강 (백작약, 적작약 모두) |

## 십구외 (十九畏) {#십구외}

**상외(相畏/相惡)**: 두 약재를 함께 사용하면 약효가 감소하거나 부작용이 발생하는 배합. **원칙적으로 병용 금기**.

> 구결: 유황원시방초전, 수은원시비상견, 낭독원시밀타승, 파두원시견우자, 정향원시울금번, 아초원시삼릉군, 관계원시석지련, 인삼원시오령지

| 약재 1 | 한자 | 약재 2 | 한자 | 상외 이유 |
|--------|------|--------|------|----------|
| 유황 | 硫黃 | 박초 | 朴硝 | 상호 약효 길항, 화학적 반응 |
| 수은 | 水銀 | 비상 | 砒霜 | 독성 합산, 극독 생성 |
| 낭독 | 狼毒 | 밀타승 | 密陀僧 | 독성 증강 |
| 파두 | 巴豆 | 견우자 | 牽牛子 | 격렬한 사하, 탈수 위험 |
| 정향 | 丁香 | 울금 | 鬱金 | 약효 상쇄 (온vs량) |
| 아초 | 牙硝 | 삼릉 | 三稜 | 약효 길항 |
| 관계 | 官桂 | 석지 | 赤石脂 | 약효 상쇄 |
| 인삼 | 人蔘 | 오령지 | 五靈脂 | 인삼의 보기 효능 감소, 부작용 가능 |

### 십구외 관련 임상 참고사항
- 정향-울금: 온리약(정향)과 활혈양혈약(울금)의 성질이 반대
- 인삼-오령지: 고전적으로 금기이나, 일부 의가는 특수 상황에서 병용 (논란 있음)
- 파두-견우자: 둘 다 강한 사하약으로 합용 시 위험

## 임부금기 (姙婦禁忌) {#임부금기}

임신 중 사용이 금지되거나 신중히 사용해야 하는 약재입니다.

### 절대 금기약 (禁用藥)

| 약재 | 한자 | 금기 이유 |
|------|------|----------|
| 수은 | 水銀 | 극독, 태아 기형 |
| 비상 | 砒霜 | 극독, 유산/기형 |
| 대극 | 大戟 | 격하(激下), 유산 위험 |
| 감수 | 甘遂 | 격하, 유산 위험 |
| 원화 | 芫花 | 격하, 유산 위험 |
| 파두 | 巴豆 | 격렬한 사하, 유산 위험 |
| 견우자 | 牽牛子 | 사하, 유산 위험 |
| 삼릉 | 三稜 | 파혈(破血), 유산 위험 |
| 아출(봉출) | 莪朮 | 파혈, 유산 위험 |
| 사향 | 麝香 | 개규통경, 유산 위험 (향수 포함 주의) |
| 수질 | 水蛭 | 파혈, 유산 위험 |
| 망충 | 虻蟲 | 파혈, 유산 위험 |
| 오공 | 蜈蚣 | 독성, 유산 위험 |
| 전갈 | 全蠍 | 독성, 유산 위험 |
| 웅황 | 雄黃 | 독성(비소 함유) |
| 경분 | 輕粉 | 수은 화합물, 독성 |

### 신중 투여약 (愼用藥)

| 약재 | 한자 | 신중 이유 | 사용 조건 |
|------|------|----------|----------|
| 도인 | 桃仁 | 활혈거어 → 유산 가능 | 어혈 동반 시 소량 |
| 홍화 | 紅花 | 활혈통경 → 유산 가능 | 어혈 동반 시 소량 |
| 반하 | 半夏 | 독성+강역 → 태동불안 | 임신오조 시 강반하 소량 |
| 대황 | 大黃 | 사하 → 자궁 수축 | 변비 심할 때 소량 단기 |
| 망초 | 芒硝 | 사하 → 자궁 수축 | 원칙적 회피 |
| 부자 | 附子 | 독성(아코니틴) | 양허한 극심 시 포제품 소량 |
| 건강 | 乾薑 | 온열성 강 → 태열 | 한증 심할 때 소량 |
| 계지 | 桂枝 | 온열성 → 태동불안 | 소량 |
| 우슬 | 牛膝 | 활혈하행 → 유산 가능 | 하지 어혈 시 소량 |
| 통초 | 通草 | 이수통림 → 진액 소모 | 원칙적 회피 |
| 의이인 | 薏苡仁 | 이수 + 근육 이완 | 대량 사용 회피 |
| 목단피 | 牡丹皮 | 활혈양혈 → 유산 가능 | 소량 |
| 지각 | 枳殼 | 이기 → 하강 작용 | 소량 단기 |

## 안전 확인 체크리스트

처방 전 아래 사항을 반드시 확인하세요:

- [ ] 처방 내 약재 간 십팔반 해당 여부
- [ ] 처방 내 약재 간 십구외 해당 여부
- [ ] 환자가 임부인 경우, 임부금기약 포함 여부
- [ ] 복용 중인 다른 한약/양약과의 상호작용
- [ ] 알레르기 이력 확인
- [ ] 포제(법제) 여부 확인 (부자, 반하 등 유독 약재)
