# 약재 총괄표

> 배합 원리는 [[약재/약재_배합원리|군신좌사 배합 원리]]를 참조하세요.

## 약재 검색 팁

- 성미로 검색: 寒/涼 → 청열 계열, 溫/熱 → 보양/거한 계열
- 귀경으로 검색: 肝 → 소간/활혈/보혈, 脾 → 보기/건비, 腎 → 보양/보음
- 배합 전 반드시 [[약재/상극_금기|상극 금기]] 확인
