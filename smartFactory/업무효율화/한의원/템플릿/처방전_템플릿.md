## 예시: 작성된 처방전

| 순번 | 약재명 | 한자 | 역할 | 용량(1첩) | 비고 |
|------|--------|------|------|----------|------|
| 1 | 반하 | 半夏 | 君 | 12g | 법반하 사용 |
| 2 | 황금 | 黃芩 | 臣 | 9g | |
| 3 | 황련 | 黃連 | 臣 | 3g | |
| 4 | 인삼 | 人蔘 | 佐 | 9g | |
| 5 | 건강 | 乾薑 | 佐 | 9g | |
| 6 | 대조 | 大棗 | 佐 | 4매 | |
| 7 | 감초 | 甘草 | 使 | 6g | |
| 8 | 사인 | 砂仁 | 가미 | 3g | 기체 동반 |
| 9 | 진피 | 陳皮 | 가미 | 6g | 복창 완화 |
