# 체질별 음식 가이드

사상체질별로 이로운 음식과 해로운 음식을 상세히 정리합니다. 환자 상담 시 체질 판별 후 식이 지도에 활용하세요.

---

## 태양인 (太陽人) {#태양인}

> 폐대간소(肺大肝小) — 간을 보하고 기를 내리는 음식이 좋음

### 이로운 음식

| 분류 | 음식 |
|------|------|
| 곡류 | 메밀, 냉면(메밀면) |
| 채소 | 순채(蓴菜), 솔잎, 포도잎 |
| 과일 | 포도, 머루, 다래, 모과, 감 |
| 해산물 | 조개류(전복, 소라, 굴), 새우, 게, 해삼, 멍게 |
| 육류 | 해산물 위주 (육류보다 해산물 선호) |
| 차/음료 | 모과차, 오가피차, 솔잎차, 포도즙 |
| 건강식품 | 오가피, 모과, 다래, 송이버섯 |

### 해로운 음식

| 분류 | 음식 | 이유 |
|------|------|------|
| 매운 음식 | 고추, 생강, 마늘, 겨자 | 상열(上熱)을 악화 |
| 기름진 음식 | 삼겹살, 튀김류 | 간에 부담 |
| 뜨거운 음식 | 보신탕류, 삼계탕 | 열을 조장 |
| 보양식 | 인삼, 녹용, 꿀 | 열체질에 부적합 |

## 태음인 (太陰人) {#태음인}

> 간대폐소(肝大肺小) — 폐를 돕고 기를 소통시키는 음식이 좋음

### 이로운 음식

| 분류 | 음식 |
|------|------|
| 곡류 | 밀, 콩(두부, 두유), 현미, 율무, 수수 |
| 채소 | 무, 도라지, 연근, 토란, 콩나물, 당근, 우엉, 마 |
| 과일 | 배, 살구, 자두, 밤, 잣, 호두, 은행, 매실 |
| 해산물 | 대구, 명태, 조기, 미역, 다시마, 해조류 |
| 육류 | **소고기**, 우유, 치즈, 계란 |
| 차/음료 | 율무차, 들깨차, 녹차, 칡차 |
| 건강식품 | 녹용(태음인용), 율무, 들깨, 호두, 잣 |

### 해로운 음식

| 분류 | 음식 | 이유 |
|------|------|------|
| 닭고기 | 삼계탕, 치킨 | 간열 조장 |
| 인삼 | 인삼차, 홍삼 | 간열 조장 (태음인에 부적합) |
| 꿀 | 벌꿀, 프로폴리스 | 열을 조장 |
| 개고기 | 보신탕 | 간열 조장 |
| 돼지고기 | 삼겹살 등 (과다 시) | 습담 조장, 비만 악화 |
| 고칼로리 | 패스트푸드, 튀김 | 비만 직결 |

### 태음인 식이 포인트
- **절식이 건강의 핵심**: 과식 방지, 규칙적 소량 식사
- 고단백 저칼로리 위주
- 섬유질 풍부한 채소 충분히
- 음주 절제 (지방간 위험)

## 소양인 (少陽人) {#소양인}

> 비대신소(脾大腎小) — 신을 보하고 열을 내리는 음식이 좋음

### 이로운 음식

| 분류 | 음식 |
|------|------|
| 곡류 | **보리**, 팥, 녹두, 메밀 |
| 채소 | 오이, 가지, 호박, 배추, 양배추, 상추, 시금치, 우엉 |
| 과일 | **수박**, 참외, 딸기, 바나나, 파인애플, 키위 |
| 해산물 | 굴, 전복, 해삼, 멍게, 새우, 게, 복어 |
| 육류 | **돼지고기**, 오리고기, 계란 |
| 차/음료 | 녹차, 구기자차, 산수유차, 보리차 |
| 건강식품 | 구기자, 산수유, 복분자, 알로에 |

### 해로운 음식

| 분류 | 음식 | 이유 |
|------|------|------|
| 인삼 | 인삼, 홍삼 | 열을 조장, 상열 악화 |
| 닭고기 | 삼계탕, 치킨 | 열을 조장 |
| 꿀 | 벌꿀 | 열 조장 |
| 매운 음식 | 고추, 후추, 생강, 마늘 | 상열 악화, 피부질환 유발 |
| 열성 식품 | 염소고기, 개고기 | 화(火) 조장 |
| 카페인 | 커피 과다 | 상열, 불면 악화 |

### 소양인 식이 포인트
- **시원하고 담백한 음식**이 적합
- 채소/과일을 충분히
- 매운 음식과 술 절제
- 수분 섭취 충분히

## 소음인 (少陰人) {#소음인}

> 신대비소(腎大脾小) — 비위를 따뜻하게 보하는 음식이 좋음

### 이로운 음식

| 분류 | 음식 |
|------|------|
| 곡류 | **찹쌀**, 차조, 감자, 고구마 |
| 채소 | 시금치, 양배추, 미나리, 쑥, 부추, **파**, **마늘** |
| 과일 | 사과, 귤, 토마토, 대추, 복숭아 |
| 해산물 | 명태, 민어, 조기 (따뜻한 성질의 생선) |
| 육류 | **닭고기**, 개고기, 양고기, 염소고기 |
| 차/음료 | **생강차**, 대추차, 계피차, 인삼차, 꿀물 |
| 양념 | 생강, 마늘, 파, 고추, 후추, 계피 |
| 건강식품 | **인삼/홍삼**, 꿀, 대추, 생강 |

### 해로운 음식

| 분류 | 음식 | 이유 |
|------|------|------|
| 냉면 | 물냉면, 비빔냉면 | 한성, 비위 손상 |
| 보리 | 보리밥, 보리차 | 한성, 소화 부담 |
| 수박 | 수박, 참외 | 한성 과일, 설사 유발 |
| 돼지고기 | 삼겹살, 족발 | 한성 육류, 소화 부담 |
| 맥주 | 맥주, 냉음료 | 한성, 비위 냉각 |
| 밀가루 | 빵, 면, 과자 | 습담 조장, 소화 부담 |
| 생채소/과일 | 샐러드, 냉과일 | 찬 성질, 비위 부담 |
| 우유 | 찬 우유 | 설사 유발 가능 |

### 소음인 식이 포인트
- **따뜻한 음식이 핵심**: 차가운 음식/음료 회피
- 소량씩 자주 먹기 (과식 금지)
- 소화하기 쉬운 음식 선택
- 양념(파, 마늘, 생강)을 적극 활용
- 인삼/홍삼은 소음인의 보약
- 찬물 대신 따뜻한 물

## 계절별 체질 음식 팁

### 여름
- **소양인**: 수박, 오이, 냉콩국수 → OK
- **소음인**: 수박/냉면 대신 삼계탕, 따뜻한 국물 → 보양

### 겨울
- **소음인**: 생강차, 계피차, 따뜻한 국물 → 적극 권장
- **태음인**: 과식/야식 주의, 체중 관리 → 절제
