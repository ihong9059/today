# 한의원 업무효율화 Wiki — Quick Start Guide

## 개요

본 Wiki는 한의원의 진료, 처방, 보험 청구 업무를 체계적으로 관리하기 위한 Obsidian 기반 지식 베이스입니다. AI 어시스턴트([[CLAUDE]])와 연동하여 실시간 의사결정을 지원합니다.

> **용도**: 교육 및 시뮬레이션 목적

---

## 빠른 시작

### 1단계: Obsidian에서 이 폴더를 Vault로 열기

```
파일 > Vault 열기 > C:\todo\today\smartFactory\업무효율화\한의원\
```

### 2단계: Dataview 플러그인 설치

- 설정 > 커뮤니티 플러그인 > Dataview 검색 후 설치
- [[index|대시보드]]의 자동 집계 기능에 필요

### 3단계: AI 어시스턴트 명령어 사용

## 사용 예시

### 예시 1: 소화불량 환자 진료

```
/처방추천 만성소화불량+소음인
```

결과로 반하사심탕, 향사양위탕 등이 추천되며, 군신좌사 구성과 주의사항이 함께 제공됩니다. 상세 처방 정보는 [[처방/이기제]]에서 확인하세요.

### 예시 2: 두통 환자 침 치료

```
/경혈추천 편두통
```

풍지(GB20), 태양(EX-HN5), 합곡(LI4), 태충(LR3) 등의 배혈 조합이 추천됩니다. 배혈 원리는 [[경혈/배혈법]]을 참조하세요.

### 예시 3: 약재 안전성 확인

```
/약재확인 부자
```

부자의 성미, 귀경, 효능과 함께 십팔반/십구외/임부금기 해당 여부가 자동 확인됩니다.

```
/상극확인 반하+오두
```

반하와 오두가 십팔반에 해당하여 배합 금기임을 경고합니다.

### 예시 4: 체질 분석

```
/체질분석 체격큼+더위잘탐+땀많음+식욕왕성
```

태음인 가능성이 높다는 분석 결과와 함께 [[체질/체질별_음식|권장/주의 음식]]이 안내됩니다.

## 주의사항

1. 본 시스템은 **교육/시뮬레이션 목적**으로 제작되었습니다
2. 실제 진료 시 최종 판단은 반드시 **한의사**가 수행해야 합니다
3. 약재 배합 시 반드시 [[약재/상극_금기|십팔반/십구외]] 확인을 거쳐야 합니다
4. 보험 청구 기준은 수시로 변경되므로 [[보험/_보험_총괄|최신 기준]]을 확인하세요
