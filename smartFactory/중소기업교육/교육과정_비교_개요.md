## 1. 교육 목표

```
[중소기업 현장 과제]                    [교육 후 역량]

 설비 고장 → 사후 대응               →  센서 데이터로 이상 조기 감지
 수작업 품질 검사                     →  카메라 AI로 자동 불량 판정
 생산 데이터 수기 기록                →  자동 수집 + 대시보드 시각화
 자동화 = 비싸다는 인식               →  Raspberry Pi로 저비용 구현 체험
```

### 핵심 교육 성과
1. **Raspberry Pi로 센서 데이터 수집** - 온도, 진동, 전류 등
2. **간단한 자동 제어 구현** - 릴레이, 모터, 알림
3. **AI 모델로 이상탐지/불량판정** - TensorFlow Lite, OpenCV
4. **실시간 모니터링 대시보드 구축** - 웹 기반 시각화
5. **ChatGPT/Claude API 활용** - 자연어로 설비 상태 질의

## 3. 두 가지 교육 형태 비교

| 항목 | A안: 대면교육 | B안: 원격교육(Zoom) |
|------|-------------|-------------------|
| **총 시간** | 5일 x 6시간 = 30시간 | 8주 x 2회 x 2시간 = 32시간 |
| **일정** | 집중 1주 (월~금) | 주 2회, 2개월 |
| **장소** | 교육장 (20명 기준) | 각자 사무실/자택 |
| **교재 배포** | 교육 당일 현장 배포 | 택배 사전 배포 (교육 1주 전) |
| **실습 지원** | 강사 순회 + 보조강사 1명 | 화면 공유 + 원격 접속(VNC) |
| **질의응답** | 즉시 현장 해결 | Zoom 채팅 + 슬랙 채널 |
| **장점** | 즉각 피드백, 하드웨어 문제 즉시 해결 | 업무 병행 가능, 이동 불필요 |
| **단점** | 5일 연속 업무 공백 | 자기주도 필요, HW 문제 원격 해결 어려움 |
| **수강료(안)** | 450,000원/인 (키트 포함) | 380,000원/인 (키트+배송 포함) |
| **적정 인원** | 15~20명 | 10~30명 |
| **수료 기준** | 출석 80% + 최종 프로젝트 | 출석 80% + 과제 6회 + 최종 프로젝트 |

## 4. 커리큘럼 구조 (공통)

### 4단계 학습 경로

```
Phase 1            Phase 2            Phase 3            Phase 4
[기초]      →     [센서/제어]   →    [AI 적용]     →   [종합 프로젝트]

Pi 세팅            GPIO 제어          이상탐지 AI        스마트 팩토리
Linux 기초         센서 데이터 수집   비전 AI (불량검사)  미니 라인 구축
Python 기초        릴레이/모터 제어   예측 모델           대시보드 통합
                   OLED 표시          AI API 활용        발표/공유
```

### 세부 커리큘럼 (16개 모듈)

| 모듈 | 주제 | 실습 내용 | Phase |
|:----:|------|----------|:-----:|
| M01 | Raspberry Pi 시작하기 | 부팅, 네트워크, 원격접속(VNC) | 1 |
| M02 | Linux 명령어 & 파일관리 | 터미널 기초, 파일 조작, 권한 | 1 |
| M03 | Python 프로그래밍 기초 | 변수, 조건문, 반복문, 함수 | 1 |
| M04 | GPIO와 LED 제어 | LED 점멸, PWM 밝기 조절 | 2 |
| M05 | 센서 데이터 수집 | 온습도, 진동, 조도 센서 읽기 | 2 |
| M06 | 모터 & 릴레이 제어 | DC모터 속도제어, 릴레이 ON/OFF | 2 |
| M07 | OLED 디스플레이 & 알림 | 센서값 표시, 부저 경고 | 2 |
| M08 | 데이터 저장 & 시각화 | CSV 저장, 그래프 그리기 | 2 |
| M09 | 이상탐지 AI 기초 | 통계 기반 이상치 탐지, Z-score | 3 |
| M10 | 머신러닝 이상탐지 | Isolation Forest, 센서 이상 판별 | 3 |
| M11 | 카메라 AI - 불량 검사 | OpenCV 이미지 처리, 색상/형상 판별 | 3 |
| M12 | TensorFlow Lite 모델 | 사전학습 모델 배포, 추론 실행 | 3 |
| M13 | AI API 활용 (Claude/GPT) | 자연어로 설비 상태 질의, 보고서 생성 | 3 |
| M14 | 웹 대시보드 구축 | Flask + Chart.js 실시간 모니터링 | 4 |
| M15 | MQTT IoT 통신 | 센서 → 브로커 → 대시보드 파이프라인 | 4 |
| M16 | 종합 프로젝트 | 미니 스마트팩토리 구축 + 발표 | 4 |

## 6. 기대 효과

### 교육 수료 후 즉시 활용 가능 역량

| 역량 | 현장 적용 예시 |
|------|---------------|
| 센서 데이터 수집 | 설비 온도/진동 모니터링 시스템 자체 구축 |
| 이상탐지 AI | 설비 고장 조기 경보 → 다운타임 30% 감소 |
| 비전 AI | 간단한 외관 검사 자동화 → 검사 시간 50% 단축 |
| 대시보드 | 생산현황 실시간 공유 → 의사결정 속도 향상 |
| AI API 활용 | 보고서 자동 생성, 데이터 분석 자동화 |

### 비용 효과

```
기존 스마트팩토리 구축: 수천만원~수억원 (PLC + SCADA + MES)
    ↓
Raspberry Pi 기반:    20~50만원으로 핵심 기능 프로토타입
    ↓
검증 후 본격 투자 의사결정 → 실패 리스크 최소화
```
