## 카테고리별 분류

### 1. 분쇄기 (Crusher/Mill)

| 제품명 | 분쇄 방식 | 특징 |
|--------|----------|------|
| TURBO MILL | 고속 충격식 | D50 10~500μm, 수평형 터보 블레이드 |
| ROLL MILL | 압축 전단식 | 저온 분쇄, 열 민감 원료용 |
| HAMMER CRUSHER | 충격식 | 조분쇄, 분쇄비 1:20 |
| JAW CRUSHER | 압축식 | 1차 파쇄, 경질 재료 |
| BALL MILL | 볼 미디어 | 습식/건식, 20~10000L |
| POT MILL | 볼 미디어 | 다품종 소량, POT 교체식 |
| PIN MILL | 충격 전단식 | 저에너지, 습식/건식 |
| HAMMER MILL | 충격식 | 중간 분쇄, 해머 교체 가능 |
| AIR JET MILL | 공기 충돌식 | 초미분, 기계적 접촉 없음 |
| A.C.M | 분쇄+분급 통합 | 단일 시스템, 원터치 분해 |

### 2. 혼합기 (Mixer)

| 제품명 | 혼합 방식 | 용량 |
|--------|----------|------|
| HIGH SPEED MIXER | 고속 전단 | 110~1050L |
| V-MIXER | 무력 회전 | 5~3000L |
| DOUBLE CONE MIXER | 원추 회전 | 사각지대 없음 |
| RIBBON MIXER | 이중 나선 리본 | 100~3000L |
| LAB MIXER | V형/고속 선택 | 연구실용 |

### 3. 분급기 (Classifier)

| 제품명 | 분급 방식 | 특징 |
|--------|----------|------|
| ULTRASONIC TWIST SCREEN | 초음파+트위스트 진동 | 45μm 이하 초미세 분급 |

### 4. 재활용 시스템 (Recycling System)

| 제품명 | 처리 대상 | 특징 |
|--------|----------|------|
| WASTE RECYCLING SYSTEM | 폐리튬전지, 전자폐기물, 의료폐기물 | 전 공정 통합 |
| WASTE Li-ion BATTERY | 폐리튬이온 배터리 | 유가금속(Co, Ni, Li) 회수 |
| L.I.B RECYCLING LAB SYSTEM | 배터리 (연구실용) | 모듈식, R&D용 |
| E.V BATTERY RECYCLING SYSTEM | 전기차 배터리 | 상업 규모, 26m×3m×5.5m |
