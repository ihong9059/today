## 1. PCS(Power Conversion System) 개요

### 1.1 정의

PCS(Power Conversion System, 전력 변환 시스템)는 배터리 시스템과 전력망(또는 부하) 사이에 연결되어 **양방향 전력 변환(AC↔DC)**을 수행하는 핵심 장치입니다.

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   배터리    │◄───►│     PCS     │◄───►│   전력망    │
│  시스템(DC) │     │  (AC↔DC)    │     │    (AC)     │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 1.2 핵심 기능

| 기능 | 설명 |
|------|------|
| **충방전 제어** | 배터리 충전/방전 프로세스 제어 |
| **AC/DC 변환** | 양방향 전력 변환 수행 |
| **유효/무효 전력 제어** | 전력 품질 및 역률 관리 |
| **계통 연계/독립 전환** | 그리드 연계 ↔ 독립 운전 모드 전환 |

## 4. 1500V 시스템의 기술적 장점

### 4.1 효율 향상

| 항목 | 1000V 시스템 | 1500V 시스템 | 개선율 |
|------|-------------|-------------|--------|
| 전류 (동일 출력) | I | I × 0.67 | 33% 감소 |
| 전력 손실 (I²R) | P | P × 0.44 | **56% 감소** |
| 케이블 손실 | 기준 | 1/4 수준 | **75% 감소** |

**줄의 법칙 (Joule's Law):** Q = I²R
- 전류가 절반으로 감소하면 손실은 1/4로 감소

### 4.2 비용 절감

| 항목 | 절감 효과 |
|------|----------|
| 케이블 비용 | 얇은 케이블 사용으로 30~40% 절감 |
| PCS 대수 | 동일 용량 대비 50% 감소 |
| 설치 면적 | 20~30% 감소 |
| BOS(Balance of System) | 전체적으로 15~25% 절감 |
| 유지보수 포인트 | 장비 수 감소로 단순화 |

### 4.3 시스템 단순화

```
1000V 시스템 (1MW 구현):
┌─────────────┐     ┌─────────────┐
│ 500kW PCS   │     │ 500kW PCS   │
└──────┬──────┘     └──────┬──────┘
       │                   │
       └───────┬───────────┘
               ▼
        병렬 제어 필요

1500V 시스템 (1MW 구현):
┌─────────────┐
│  1MW PCS    │ ← 단일 장치로 구현
└─────────────┘
```
