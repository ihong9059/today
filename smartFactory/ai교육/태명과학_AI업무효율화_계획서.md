## 1. 현황 분석

### 1.1 태명과학 사업 특성

태명과학은 **독일 FRITSCH사의 공식 파트너**로서, 분쇄 장비와 측정/분석 장비를 공급합니다. 한국기계엔지니어링이 대형 산업용 분쇄기를 직접 생산하는 것과 달리, 태명과학은 **수입 정밀 장비 + 컨설팅 + 시료 테스트 서비스**가 핵심입니다.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    태명과학 vs 한국기계 비교                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   태명과학                          한국기계                        │
│   ─────────                        ─────────                       │
│   • 수입 정밀 장비 (FRITSCH)        • 자체 생산 산업용 장비         │
│   • 실험실/연구용 중심               • 공장/생산라인용 중심          │
│   • 장비 종류 매우 다양 (30+)        • 장비 종류 집중 (8종)         │
│   • 부속품/소모품 수백 종             • 부속품 상대적 단순           │
│   • 시료 테스트 서비스 핵심           • 현장 설치/시운전 핵심        │
│   • 재질 선택이 중요 (오염 방지)     • 용량/토크가 중요             │
│   • 연구원/QC 담당자 대상             • 공장장/엔지니어 대상         │
│                                                                     │
│   [공통점]                                                          │
│   • 고객 산업/응용 분야가 매우 다양                                │
│   • 고객 전문성 수준이 천차만별                                    │
│   • 장비 선정에 전문 지식 필요                                     │
│   • 현장 방문/시연이 빈번                                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2 현재 업무의 핵심 어려움

```
┌─────────────────────────────────────────────────────────────────────┐
│                 태명과학 고객 문의 대응 현황                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   [고객 문의 유형]                                                  │
│                                                                     │
│   ① 장비 선정 문의 (가장 빈번)                                    │
│      "세라믹 분말을 10μm 이하로 분쇄하고 싶은데 뭐가 좋을까요?"   │
│      → 시료 특성(경도/습도/취성) × 목표 입도 × 처리량              │
│        × 오염 허용도 = 수십 가지 조합 가능                         │
│                                                                     │
│   ② 부속품/소모품 문의 (가장 복잡)                                 │
│      "P-7 볼밀에 쓸 수 있는 80ml 지르코니아 용기 있나요?"          │
│      → 장비별 × 용량별 × 재질별 = 수백 가지 부속품 조합           │
│      → 호환성 확인 필수 (잘못 주문하면 사용 불가)                  │
│                                                                     │
│   ③ 시료 테스트 문의                                               │
│      "우리 시료가 이 장비로 원하는 입도까지 되는지 확인하고 싶어요" │
│      → 시료 특성 파악 → 적합 장비 선정 → 테스트 조건 설계         │
│                                                                     │
│   ④ 입도 분석 결과 해석                                            │
│      "D50이 15μm인데, 이게 좋은 건가요? 나쁜 건가요?"             │
│      → 산업별/용도별 기준이 다름 → 맞춤 해석 필요                 │
│                                                                     │
│   ⑤ 유지보수/AS                                                    │
│      "장비 청소 방법은?", "칼날 교체 시기는?"                      │
│                                                                     │
│   [현재 문제점]                                                     │
│                                                                     │
│   ❌ 부속품 호환 확인에 카탈로그 수십 페이지 뒤적임                │
│   ❌ 재질별 특성을 매번 설명 (Agate? ZrO₂? WC? 차이가 뭔가요?)   │
│   ❌ 장비 모델 × 용기 크기 × 재질 조합이 너무 많음               │
│   ❌ 고객의 시료 특성을 파악하는 데만 30분~1시간 소요              │
│   ❌ 영문 카탈로그를 한국어로 설명하는 번역 부담                   │
│   ❌ 담당자 경험에 100% 의존 — 부재 시 답변 불가                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 핵심 과제

| 과제 | 현재 | 목표 | 핵심 난점 |
|------|:----:|:----:|----------|
| **장비 추천** | 30분~1시간/건 | 5분/건 (AI 분석) | 시료×입도×용량×재질 조합 폭발 |
| **부속품 선정** | 카탈로그 대조 20분 | 즉시 (DB 검색) | 수백 종 부속품 호환성 매트릭스 |
| **재질 가이드** | 매번 구두 설명 | 자동 추천 + 문서 제공 | 8종+ 재질별 특성/용도 매칭 |
| **시료 테스트 설계** | 경험 기반 1~2시간 | AI 사전 분석 10분 | 시료 특성→테스트 조건 자동 매핑 |
| **입도 데이터 해석** | 전문가만 가능 | AI 자동 해석 + 리포트 | 산업별 기준 DB 필요 |
| **영문→한글 기술 자료** | 수작업 번역 | AI 즉시 번역 + 한국 맞춤 | FRITSCH 원문 카탈로그 대량 |

```markdown
# 태명과학 AI 장비 컨설턴트 규칙

## 역할
당신은 태명과학의 기술영업 전문 컨설턴트입니다.
FRITSCH 분쇄/분석 장비와 MJ Research 실험 장비에 대한

## 핵심 원칙
1. 장비 추천 시 반드시 시료 특성(경도/수분/취성/열민감성)을 먼저 확인
2. 부속품 추천 시 반드시 호환성 매트릭스를 참조하여 검증

4. 입도 데이터 해석 시 해당 산업의 기준값을 함께 제시
5. 영문 전문 용어는 한글(영문) 병기

- /추천: 시료 특성 입력 → 장비 + 부속품 + 재질 패키지 추천
- /부속품: 장비 모델 입력 → 호환 부속품 전체 조회
- /재질: 시료 특성 입력 → 최적 재질 추천 + 이유
- /테스트설계: 시료 정보 → 시료 테스트 조건 자동 설계
- /입도해석: D50/D90 값 + 산업 → 합격 여부 + 개선 방안
- /견적: 장비 + 부속품 구성 → 견적서 초안
- /번역: 영문 카탈로그 → 한글 기술자료 변환

## 장비 추천 필수 확인 사항
1. 처리 대상 시료는 무엇인가? (명칭, 종류)
2. 시료의 경도는? (Mohs 기준 또는 "단단한/보통/부드러운")
3. 시료의 수분 함량은? (건조/습윤)
4. 목표 최종 입도는? (μm 또는 mesh)
5. 1회 처리량은? (ml 또는 g)
6. 금속 오염이 허용되는가? (순수성 요구)
7. 건식/습식 분쇄 중 선호는?
8. 용도는? (R&D/QC/생산)
```

## 한국기계 시스템과의 시너지

태명과학과 한국기계의 시스템을 함께 운영하면 강력한 시너지가 발생합니다:

```
┌─────────────────────────────────────────────────────────────────────┐
│                   두 시스템의 시너지                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   [한국기계]                       [태명과학]                       │
│   산업용 대형 분쇄기                실험실/연구용 정밀 장비          │
│   (공장 생산라인)                   (R&D, QC, 시료 전처리)          │
│                                                                     │
│              ↕  상호 보완 관계  ↕                                  │
│                                                                     │
│   고객이 한국기계 장비를 도입하기 전,                               │
│   태명과학의 실험실 장비로 사전 테스트 가능                         │
│                                                                     │
│   한국기계 장비로 분쇄한 결과물을                                   │
│   태명과학의 입도분석기로 품질 검증 가능                            │
│                                                                     │
│   → 두 회사의 Obsidian Vault를 연결하면                            │
│     "시료 전처리 → 분쇄 → 분석"                                   │
│     전체 워크플로우를 AI가 통합 컨설팅 가능                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
