1.2 현재 업무의 핵심 어려움

문의 유형현재 상황난점
장비 선정
(가장 빈번)		 "세라믹을 10μm 이하로 분쇄하려면?" 시료 특성 × 입도 × 처리량 × 오염 허용도 = 수십 가지 조합
부속품 주문
(가장 복잡)		 "P-7에 80ml 지르코니아 용기 있나요?" 장비별 × 용량별 × 재질별 = 수백 가지, 호환 확인 필수
재질 선택
(가장 빈번 질문)		 "Agate? ZrO₂? 뭐가 다른가요?" 8종 재질의 특성/용도를 매번 구두 설명
시료 테스트 "우리 시료가 이 장비로 되나요?" 시료 특성 파악 → 장비 선정 → 테스트 조건 설계
입도 데이터 해석 "D50이 15μm인데, 괜찮은 건가요?" 산업별/용도별 기준이 다름
영문 카탈로그 FRITSCH 원문을 한글로 설명 번역 + 한국 시장 맞춤 자료 필요
가장 심각한 문제: 부속품 오주문 장비 모델 × 용기 크기 × 재질 조합이 너무 많아, 카탈로그를 수십 페이지 대조해야 합니다. 잘못 주문하면 사용 불가 → 반품 → 재주문 → FRITSCH 리드타임 4~8주 추가 대기.

AI 장비 컨설팅 프로세스

1
시료 정보 수집 (AI 가이드, 3분)

Claude가 구조화된 질문: 시료명 → 경도 → 현재/목표 입도 → 처리량 → 오염 허용도 → 건식/습식 → 용도

2
AI 자동 분석 (30초)

시료DB 검색 → 장비DB 매칭 → 부속품 호환 매트릭스 → 재질 의사결정 트리 → 유사 사례 검색

3
추천 패키지 생성 (1분)

추천 장비 + 추천 용기 (재질/용량) + 추천 볼 (크기/재질) + 분쇄 조건 + 예상 결과 + 대안 + 개략 견적

4
시료 테스트 연결 (옵션)

확인이 필요하면 시료 테스트 신청서 자동 생성 → Notion에 테스트 일정 등록

3 핵심 DB — 부속품 호환성 매트릭스

태명과학 시스템의 가장 중요한 차별점 수백 종 부속품의 호환성을 DB화하여, "이 장비에 이 용기/볼을 쓸 수 있는가?"를 AI가 즉시 검증합니다. 부속품 오주문을 원천 차단합니다.

3.3 재질 선택 의사결정 트리

시료에 금속 오염이 허용되는가?
NO (분석용, 고순도) → 시료 경도가 Mohs 7 이상인가?
YES (고경도) → ZrO₂ (지르코니아) 또는 Si₃N₄ (질화규소)
NO (보통/연질) → Agate (마노) — 최고 순수성
YES (오염 허용) → 예산이 제한적인가?
YES (저예산) → 경화강 또는 스테인리스강
NO (예산 여유) → WC (초경합금) — 최고 경도

시나리오 1: 신규 장비 문의

BEFORE 기존 방식
  1. 고객 전화 — 시료 설명 (10분)
  2. 카탈로그 검토 (20분)
  3. 재질/용기 호환 확인 (15분)
  4. 내부 확인 — 모델/재고 (10분)
  5. 견적서 수작업 (30분)
  6. 고객 재문의 → 반복
총 소요: 2~3시간/건
AFTER AI 적용 후
  1. 고객 전화 (5분)
  2. Claude에 시료 정보 입력 (2분)
  3. AI 자동 패키지 추천 (30초)
  4. 호환성 자동 검증 (즉시)
  5. 견적서 초안 자동 생성 (1분)
  6. 담당자 검토 + 발송 (5분)
총 소요: 15분/건 (90% 단축)

시나리오 2: 부속품 주문 (가장 빈번)

BEFORE
  • 고객: "P-5에 250ml ZrO₂ 용기 있나요?"
  • 카탈로그 확인 — Classic? Premium? (5분)
  • 250ml ZrO₂ 호환 여부 확인 (10분)
  • 품번 → 재고 → 가격 확인 (10분)
총 소요: 25분
AFTER
  • Claude: "/부속품 P-5 Classic 250ml ZrO₂"
  • 즉시 응답: "P-5 Classic 250ml ZrO₂ 용기"
  • 품번: XX-XXXX, 가격: XX만원, 재고: 1개
  • 대안: "P-5 Premium은 250ml ZrO₂ 미지원"
총 소요: 30초 (97% 단축)

태명과학의 가장 큰 자산은 "어떤 시료에 어떤 장비와 부속품을 조합하면 최적인가"를 아는 것입니다.

태명과학은 "장비 판매 회사"에서 "AI 기반 분쇄/분석 토탈 솔루션 기업"으로 진화합니다.
