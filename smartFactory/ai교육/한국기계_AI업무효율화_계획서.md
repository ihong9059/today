### 1.2 핵심 과제

| 과제 | 현재 | 목표 | 영향 |
|------|------|------|------|
| **고객 초기 대응** | 2~3일 (방문 후 파악) | 30분 이내 (AI 사전 분석) | 수주율 향상 |
| **기술 문서 작성** | 3~5일/건 | 1시간/건 (AI 초안 생성) | 생산성 5배↑ |

| **견적/제안서** | 매번 새로 작성 | 템플릿 + AI 자동 생성 | 일관성 + 속도 |

### 3.2 제품 페이지 작성 표준

각 제품 페이지는 다음 구조를 따릅니다:

```markdown

type: product

links: [_제품_총괄, 폐배터리-재활용, 의약-화학]
---

# 터보밀 TM-800

## 한줄 설명
> 고속 충격식 미분쇄기. 100메시 이하 초미세 분쇄에 최적화.

## 사양표
| 항목 | 값 |
|------|-----|
| 분쇄 방식 | 고속 충격식 (임팩트 밀) |
| 처리 입도 | 투입 ~10mm → 배출 10~100μm |
| 모터 출력 | 5.5~75kW |
| 회전 속도 | 3,000~6,000 RPM |
| 처리 용량 | 50~3,000 kg/h |
| 적용 재료 | 화학, 식품, 광물, 배터리 양극재 |

## 적합한 고객/공정
- 폐배터리 양극재 미분쇄 (3차 공정)
- 의약품 원료 미분쇄
- 식품 분말 제조

## 선정 기준 (이 장비를 추천하는 경우)
1. 최종 입도 100μm 이하가 필요한 경우
2. 열에 민감하지 않은 재료 (고속 회전으로 발열)
3. 연속 대량 처리가 필요한 경우

## 비교 장비
- vs 핀밀: 핀밀은 더 미세(~50μm), 터보밀은 대용량에 유리
- vs 볼밀: 볼밀은 배치식, 터보밀은 연속식

## 납품 사례 링크
- [[2024-A사-폐배터리]] — 양극재 분쇄 라인
- [[2025-C사-화학]] — 안료 미분쇄

## 동영상
- [[터보밀_동영상]]
```

## 역할
당신은 (주)한국기계엔지니어링의 기술 영업 어시스턴트입니다.

- /추천: 고객 요구사항 입력 → 장비 추천 + 근거

## 맺음말

이 시스템의 핵심은 **사람의 머릿속에만 있는 지식을 디지털 자산으로 전환**하는 것입니다.

```
[담당자의 20년 경험]
       ↓
[Obsidian에 체계적 기록]
       ↓
[Claude가 학습하여 24시간 활용]
       ↓
[고객에게 빠르고 정확한 서비스 제공]
```

Obsidian은 **지식의 그릇**, Claude는 **지식을 활용하는 두뇌**, Notion은 **업무의 흐름**을 담당합니다. 이 세 가지가 유기적으로 연결되면, 한국기계엔지니어링의 기술 영업 역량이 개인에서 조직으로, 수작업에서 자동화로 전환됩니다.
