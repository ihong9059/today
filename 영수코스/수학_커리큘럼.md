# 수학 코스 커리큘럼

## 개요

AI와 함께하는 수학 학습 코스입니다. 초등학교부터 대학입시까지 체계적인 커리큘럼으로 구성되어 있으며, 각 단계별로 AI 프롬프트를 활용한 맞춤형 학습을 제공합니다.

---

## 코스 구조

```
/course/math (수학 코스 메인)
├── /elementary (초등)
│   ├── /1-2 (1~2학년) - 5일 과정
│   ├── /3-4 (3~4학년) - 5일 과정
│   └── /5-6 (5~6학년) - 5일 과정
│
├── /middle (중등)
│   ├── /1 (중1) - 5일 과정
│   ├── /2 (중2) - 5일 과정
│   └── /3 (중3) - 5일 과정
│
└── /high (고등)
    ├── /common (공통수학) - 5일 과정
    ├── /math1 (수학Ⅰ) - 5일 과정
    ├── /math2 (수학Ⅱ) - 5일 과정
    ├── /calculus (미적분) - 5일 과정
    ├── /geometry (기하) - 5일 과정
    └── /probability (확률과 통계) - 5일 과정
```

**프롬프트 1-1: 구구단 완벽 암기 전략**
```

다음 내용을 포함해주세요:
1. 구구단 외우기 순서
   - 2단, 5단, 9단 먼저 (규칙 발견 쉬움)
   - 그 다음 3단, 4단, 6단
   - 마지막 7단, 8단

2. 각 단별 외우기 팁
   - 2단: 짝수가 나와요 (2, 4, 6, 8...)
   - 5단: 0과 5로 끝나요
   - 9단: 십의 자리 +1, 일의 자리 -1 규칙
   - 손가락으로 9단 계산하는 방법

3. 곱셈표 활용하기
```

```
고등학교 수학1에서 로그(log)의 정의와 성질을 설명해주세요.

【로그의 정의】
log_a(b) = c ⟺ a^c = b (a > 0, a ≠ 1, b > 0)

- a: 밑
- b: 진수 (항상 양수!)
- c: 로그값

【로그의 성질 (증명 포함)】
1. log_a(MN) = log_a(M) + log_a(N)
   증명: M = a^m, N = a^n이면
   MN = a^m × a^n = a^(m+n)
   ∴ log_a(MN) = m + n = log_a(M) + log_a(N)

2. log_a(M/N) = log_a(M) - log_a(N)

3. log_a(M^n) = n·log_a(M)

4. log_a(1) = 0, log_a(a) = 1

【밑 변환 공식】
log_a(b) = log_c(b) / log_c(a)

【상용로그와 자연로그】
- 상용로그: log_10(x) = log(x)
- 자연로그: log_e(x) = ln(x)

```

```
고등학교 수학2에서 미분계수와 도함수의 개념을 설명해주세요.

【평균변화율】
Δy/Δx = [f(b) - f(a)] / (b - a)
- 두 점 사이의 변화율
- 그래프에서 할선의 기울기

【순간변화율과 미분계수】
f'(a) = lim(Δx→0) [f(a+Δx) - f(a)] / Δx
      = lim(x→a) [f(x) - f(a)] / (x - a)
- x = a에서의 순간변화율
- 그래프에서 접선의 기울기

【도함수】
f'(x) = lim(h→0) [f(x+h) - f(x)] / h

【미분 공식】
1. (c)' = 0 (c는 상수)
2. (x^n)' = nx^(n-1)
3. (cf)' = cf'
4. (f ± g)' = f' ± g'

예제: f(x) = x³ - 3x + 2
f'(x) = 3x² - 3

연습 문제 10개를 풀어주세요.
```
