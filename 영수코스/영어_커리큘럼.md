**프롬프트 1-2: 파닉스 기초 (모음)**
```

【짧은 모음 소리 (Short Vowel)】
- a: cat, bat, hat → "애" 소리
- e: bed, red, pen → "에" 소리
- i: pig, big, sit → "이" 소리
- o: dog, hot, top → "오/아" 소리
- u: cup, bus, sun → "어" 소리

【긴 모음 소리 (Long Vowel)】
- a: cake, make → "에이" 소리
- e: me, we → "이" 소리
- i: like, kite → "아이" 소리
- o: home, nose → "오우" 소리
- u: cute, use → "유" 소리

각 소리가 나는 단어 예시 5개씩 알려주세요.
발음 연습 문장도 만들어주세요.
```

**프롬프트 1-1: am, are, is 사용법**
```
초등학교 5학년인데 be동사(am, are, is)를 배우고 싶어요.

【be동사란?】
"~이다, ~있다"를 의미하는 동사

【주어에 따른 be동사】
| 주어 | be동사 | 예문 |
|------|--------|------|
| I | am | I am a student. |
| You | are | You are tall. |
| He/She/It | is | She is pretty. |
| We/They | are | They are friends. |

【축약형】
- I am = I'm
- You are = You're
- He is = He's
- She is = She's
- It is = It's
- We are = We're
- They are = They're

연습 문제 10개를 만들어주세요. (빈칸에 am/are/is 넣기)
```

| 순서 | 프롬프트 제목 | 설명 |
|------|--------------|------|
| 1 | 동사 현재형 | 3인칭 단수 -s |

| 3 | don't/doesn't 부정문 | 부정문 만들기 |

**프롬프트 2-1: 동사 현재형**
```
초등학교 5학년인데 일반동사의 현재형을 배우고 싶어요.

【일반동사란?】
be동사를 제외한 모든 동사 (run, eat, play, study...)

【3인칭 단수 (He/She/It) - s 붙이기】
- I play → He plays
- I run → She runs
- I go → It goes

【-s 붙이는 규칙】
1. 대부분: 그냥 s (play → plays)
2. s, x, ch, sh, o로 끝나면: es (go → goes, watch → watches)
3. 자음+y로 끝나면: y → ies (study → studies)

【예문】
- I like pizza. (나는 피자를 좋아해)
- He likes pizza. (그는 피자를 좋아해)
- They play soccer. (그들은 축구를 해)
- She plays soccer. (그녀는 축구를 해)

연습 문제 15개를 만들어주세요.
```

```
【불규칙 동사란?】
과거형이 -ed가 아닌 특별한 형태로 변하는 동사

【패턴별 정리】
1. A-B-B형 (과거=과거분사)
   - have → had → had
   - make → made → made
   - buy → bought → bought
   - teach → taught → taught

2. A-B-A형
   - come → came → come
   - run → ran → run

3. A-A-A형 (변화 없음)
   - put → put → put
   - cut → cut → cut
   - read → read(레드) → read(레드)

4. 완전 불규칙
   - go → went → gone
   - is/am → was → been
   - are → were → been
   - eat → ate → eaten
   - see → saw → seen
   - do → did → done

【자주 쓰는 불규칙 동사 30개 표】
| 현재형 | 과거형 | 뜻 |
|--------|--------|-----|

| see | saw | 보다 |
| eat | ate | 먹다 |
| drink | drank | 마시다 |
| give | gave | 주다 |
| take | took | 가져가다 |
| make | made | 만들다 |
| get | got | 얻다 |
| have | had | 가지다 |
... (20개 더 추가)

암기 팁과 연습 문장 10개를 만들어주세요.
```

```
주어 + 동사 + 목적어 + 목적보어
```

**프롬프트 1-1: 현재완료 개념**
```
중학교 2학년 영어에서 현재완료 시제를 설명해주세요.

【형태】
have/has + 과거분사(p.p.)
- I have finished.
- She has gone.

【4가지 용법】

① 완료: ~했다 (just, already, yet)
- I have just finished my homework.
  (나는 방금 숙제를 끝냈다)

② 경험: ~한 적이 있다 (ever, never, before)
- Have you ever been to Japan?
  (일본에 가 본 적 있니?)

③ 계속: ~해 왔다 (since, for)
- I have lived here for 5 years.
  (나는 여기에 5년간 살아왔다)

④ 결과: ~해서 지금 ~하다
- He has lost his key. (그래서 지금 없다)
  (그는 열쇠를 잃어버렸다)

【vs 단순과거】

- I have lost my key. (잃어버려서 지금도 없다 - 현재와 연결)

각 용법별 예문 5개씩 만들어주세요.
```

```
- If I had money, I could buy it.
  (돈이 있다면 살 수 있을 텐데 - 지금 돈 없음)
- If she were here, she would help us.
  (그녀가 여기 있다면 도와줄 텐데 - 지금 없음)
```
