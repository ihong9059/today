## 1. 앱 소개

### 1.1 앱의 목적

**세주FA 영업관리 앱**은 영업사원이 거래처 방문 시 현장에서 바로 방문 기록을 등록하고 관리할 수 있는 모바일 애플리케이션입니다.

### 1.2 주요 기능

| 기능 | 설명 |
|:-----|:-----|
| **GPS 자동 기록** | 방문 시 위치 정보가 자동으로 수집됩니다 |
| **방문 유형 분류** | 영업/납품/AS/수금/미팅/기타 6가지 유형으로 분류 |
| **거래처 정보 관리** | 거래처명, 담당자, 연락처 정보 저장 |
| **현장 사진 촬영** | 카메라로 현장 사진을 촬영하여 첨부 |
| **방문 이력 조회** | 과거 방문 기록 검색 및 조회 |
| **실시간 동기화** | 서버와 실시간으로 데이터 동기화 |

### 1.3 앱 화면 구성

앱은 하단 탭 메뉴를 통해 3개의 주요 화면으로 구성됩니다:

```

│         서버: sejufa.co.kr:90       │
├─────────────────────────────────────┤
│                                     │

│                                     │
├─────────────────────────────────────┤
│  ✏️ 방문등록  │  🔍 조회  │  ⚙️ 설정  │
└─────────────────────────────────────┘
```

## 2. 설치 방법

### 2.1 APK 파일 다운로드

1. `SejuSales-v1.0.apk` 파일을 태블릿/스마트폰에 복사합니다
2. 파일 관리자 앱에서 APK 파일을 찾습니다

### 2.2 설치 허용 설정

1. **설정** > **보안** 메뉴로 이동
2. **알 수 없는 출처** (또는 **알 수 없는 앱 설치**) 허용
3. 최신 Android는 설치 시 자동으로 허용 여부를 묻습니다

### 2.3 앱 설치

1. APK 파일을 탭하여 설치 시작
2. **설치** 버튼 클릭
3. 설치 완료 후 **열기** 버튼 클릭

### 2.4 권한 허용

앱 최초 실행 시 다음 권한을 허용해야 합니다:

| 권한 | 용도 |
|:-----|:-----|
| **위치** | GPS 기반 방문 위치 기록 |
| **카메라** | 현장 사진 촬영 |
| **저장소** | 사진 저장 및 업로드 |

> ⚠️ **중요:** 모든 권한을 허용해야 앱이 정상 작동합니다.

## 4. 방문 기록 등록

### 4.1 등록 절차

#### Step 1: 앱 실행
- 앱을 실행하면 자동으로 GPS 위치가 수집됩니다
- 화면 상단에 현재 위도/경도와 정확도가 표시됩니다

#### Step 2: 거래처 정보 입력
1. **거래처명** 입력
   - 직접 입력하거나 최근 거래처 태그를 탭하여 선택
2. **담당자명** 입력 (선택)
3. **연락처** 입력 (선택)

#### Step 3: 방문 유형 선택
6가지 유형 중 하나를 탭하여 선택합니다:

| 아이콘 | 유형 | 언제 사용하나요? |
|:------:|:----:|:----------------|
| 💼 | **영업** | 신규 고객 발굴, 견적 상담, 계약 상담 |
| 🚚 | **납품** | 제품 인도, 설치, 시운전 |
| 🔧 | **AS** | 장비 수리, 정기 점검, A/S |
| 💰 | **수금** | 대금 수금, 미수금 회수 |
| 🤝 | **미팅** | 기술 회의, 프로젝트 협의, 상담 |
| 📝 | **기타** | 위 유형에 해당하지 않는 경우 |

#### Step 4: 방문 내용 입력
- **상담 내용**: 방문 목적, 상담 내용, 특이사항 등
- **다음 방문 예정일**: 후속 방문이 필요한 경우 날짜 선택

#### Step 5: 사진 촬영 (선택)
1. 사진 영역을 탭합니다
2. **카메라 촬영** 또는 **갤러리에서 선택**
3. 촬영/선택한 사진이 미리보기로 표시됩니다

#### Step 6: 저장
- **[방문 기록 저장]** 버튼을 탭합니다
- "방문 기록이 저장되었습니다!" 메시지가 표시되면 완료

### 4.2 입력 팁

#### 거래처명 작성 요령
```
✅ 좋은 예
- (주)세주FA
- 삼성전자 수원사업장
- A공장 3라인

❌ 나쁜 예
- 세주
- 삼성
- 공장
```

#### 방문 내용 작성 요령
```
✅ 좋은 예
"신규 컨베이어 설비 견적 상담. 8m x 2라인 요청.
다음 주 화요일 도면 가져가기로 함.
담당자: 김공장장 (010-1234-5678)"

❌ 나쁜 예
"상담함"
"방문"
```

## 5. 방문 이력 조회

### 5.1 조회 방법

1. 하단 탭에서 **🔍 조회**를 탭합니다
2. 검색창에 거래처명을 입력합니다
3. **[검색]** 버튼을 탭합니다

### 5.2 검색 결과 확인

- **전체**: 전체 방문 기록 수
- **오늘**: 당일 방문 기록 수
- **이번주**: 최근 7일 방문 기록 수

### 5.3 상세 정보 보기

검색 결과 목록에서 항목을 탭하면 상세 정보가 표시됩니다:

│ ┌─────────────────────────────────┐ │
│ │         [첨부 사진]            │ │
│ └─────────────────────────────────┘ │
│ 거래처    │ (주)A기업               │

## 6. 설정

### 6.1 설정 항목

#### 서버 주소
- 기본값: `http://sejufa.co.kr:90`
- 서버 주소가 변경된 경우에만 수정

#### 기기 ID
- 기본값: `seju-tablet-001`
- 기기별로 고유한 ID 설정 (예: seju-tablet-002, seju-phone-001)

#### 영업사원명
- 본인 이름 입력
- 방문 기록에 영업사원명으로 표시됩니다

### 6.2 설정 저장

1. 설정 값을 입력합니다
2. **[설정 저장]** 버튼을 탭합니다
3. "설정이 저장되었습니다" 메시지 확인

> ⚠️ **주의:** 영업사원명은 반드시 설정하세요. 미설정 시 기기 ID로 표시됩니다.

## 7. 관리자 대시보드

### 7.1 접속 방법

#### 방법 1: 앱에서 접속
1. 방문등록 화면 하단의 **[관리자 대시보드]** 버튼 탭
2. 앱 내에서 웹 대시보드가 열립니다

#### 방법 2: 웹 브라우저로 접속
- PC 또는 다른 기기의 웹 브라우저에서 접속
- URL: `http://sejufa.co.kr:90`

### 7.2 대시보드 기능

| 기능 | 설명 |
|:-----|:-----|
| **통계 현황** | 전체/오늘/주간/월간 방문 건수 |
| **지도 보기** | 모든 방문 위치를 지도에 마커로 표시 |
| **검색** | 거래처명, 영업사원, 방문 유형으로 검색 |
| **상세 보기** | 방문 기록 상세 정보 및 사진 확인 |

## 8. 자주 묻는 질문

### Q1. GPS가 작동하지 않습니다
**A:**
1. 앱 권한에서 **위치** 권한이 허용되어 있는지 확인
2. 기기 설정에서 **위치 서비스**가 켜져 있는지 확인
3. 실내에서는 GPS 정확도가 떨어질 수 있습니다

### Q2. 사진 촬영이 되지 않습니다
**A:**
1. 앱 권한에서 **카메라**, **저장소** 권한이 허용되어 있는지 확인
2. 기기 저장 공간이 부족하지 않은지 확인

### Q3. 방문 기록 저장 시 오류가 발생합니다
**A:**
1. 인터넷(Wi-Fi 또는 모바일 데이터)에 연결되어 있는지 확인
2. 설정 화면에서 서버 주소가 올바른지 확인
3. 거래처명은 필수 입력 항목입니다

### Q4. 최근 거래처 목록이 표시되지 않습니다
**A:**
- 최근 거래처는 앱에서 방문 기록을 저장할 때 자동으로 추가됩니다
- 최대 10개까지 표시됩니다

### Q5. 다른 영업사원의 기록이 보입니다
**A:**
- 조회 화면에서는 모든 영업사원의 기록이 표시됩니다
- 특정 영업사원의 기록만 보려면 관리자 대시보드에서 필터 기능을 사용하세요

### Q6. 오프라인에서도 사용 가능한가요?
**A:**
- 현재 버전은 인터넷 연결이 필요합니다
- 오프라인 모드는 향후 업데이트 예정입니다
