## 4. 예제 프로젝트: 실시간 얼굴 필터

### 4.1 개요

웹캠에서 얼굴을 인식하고 실시간으로 필터를 적용하는 프로그램

### 4.2 기능

1. 실시간 얼굴 검출
2. 얼굴에 필터 적용 (선글라스, 모자 등)
3. 배경 블러 처리
4. 스냅샷 저장

### 4.3 기술

- OpenCV: 얼굴 검출 (Haar Cascade 또는 DNN)
- CUDA 커널: 필터 적용, 블러
- TensorRT (옵션): 딥러닝 얼굴 검출

### 4.4 구조

```
face_filter/
├── main.py           # 메인 프로그램
├── detector.py       # 얼굴 검출
├── filters.py        # 필터 적용
├── cuda_kernels/     # CUDA 커널
│   ├── blur.cu
│   └── overlay.cu
├── assets/           # 필터 이미지
│   ├── sunglasses.png
│   └── hat.png
└── README.md
```
