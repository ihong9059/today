## 코드 분석

### 소벨 필터란?

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   소벨 X (수평 엣지)          소벨 Y (수직 엣지)            │
│                                                             │
│   ┌────┬────┬────┐           ┌────┬────┬────┐              │
│   │ -1 │  0 │ +1 │           │ -1 │ -2 │ -1 │              │
│   ├────┼────┼────┤           ├────┼────┼────┤              │
│   │ -2 │  0 │ +2 │           │  0 │  0 │  0 │              │
│   ├────┼────┼────┤           ├────┼────┼────┤              │
│   │ -1 │  0 │ +1 │           │ +1 │ +2 │ +1 │              │
│   └────┴────┴────┘           └────┴────┴────┘              │
│                                                             │
│   좌우 차이를 강조            상하 차이를 강조              │
│   (수직선 검출)               (수평선 검출)                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### GPU 커널

```c
// 상수 메모리에 필터 저장 (빠른 접근)
__constant__ int d_sobelX[9] = {-1, 0, 1, -2, 0, 2, -1, 0, 1};
__constant__ int d_sobelY[9] = {-1, -2, -1, 0, 0, 0, 1, 2, 1};

__global__ void sobelEdge(unsigned char* input, unsigned char* output,
                          int width, int height) {
    int x = blockIdx.x * blockDim.x + threadIdx.x;
    int y = blockIdx.y * blockDim.y + threadIdx.y;

    if (x > 0 && x < width - 1 && y > 0 && y < height - 1) {
        float gx = 0, gy = 0;

        // 3×3 컨볼루션
        for (int dy = -1; dy <= 1; dy++) {
            for (int dx = -1; dx <= 1; dx++) {
                int idx = (y + dy) * width + (x + dx);
                int kidx = (dy + 1) * 3 + (dx + 1);

                float pixel = input[idx];
                gx += pixel * d_sobelX[kidx];  // 수평 그래디언트
                gy += pixel * d_sobelY[kidx];  // 수직 그래디언트
            }
        }

        // 그래디언트 크기 (엣지 강도)
        float magnitude = sqrtf(gx * gx + gy * gy);

        output[y * width + x] = (unsigned char)fminf(255.0f, magnitude);
    }
}
```

## 핵심 포인트

### 1. 그래디언트 계산

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Gx = 소벨 X 필터 적용 결과 (좌우 변화량)                  │
│   Gy = 소벨 Y 필터 적용 결과 (상하 변화량)                  │
│                                                             │
│   엣지 강도 = √(Gx² + Gy²)                                  │
│                                                             │
│   예시:                                                     │
│   - 수직선: Gx 큼, Gy 작음                                  │
│   - 수평선: Gx 작음, Gy 큼                                  │
│   - 대각선: Gx ≈ Gy                                         │
│   - 평탄한 영역: Gx ≈ 0, Gy ≈ 0                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. 상수 메모리 (__constant__)

```c
__constant__ int d_sobelX[9] = {...};
__constant__ int d_sobelY[9] = {...};
```

**상수 메모리의 장점:**
- 모든 스레드가 동일한 값을 읽음
- 캐시되어 매우 빠른 접근
- 읽기 전용 데이터에 적합

### 3. 엣지 검출 과정

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   1. RGB → Grayscale                                        │
│      (색상 정보 제거, 밝기만 사용)                          │
│                                                             │
│   2. 소벨 X 적용 → Gx                                       │
│                                                             │
│   3. 소벨 Y 적용 → Gy                                       │
│                                                             │
│   4. magnitude = √(Gx² + Gy²)                               │
│                                                             │
│   5. 결과: 엣지가 밝게, 평탄한 영역이 어둡게                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
