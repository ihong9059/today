```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   3×3 박스 블러: 주변 9픽셀의 평균                          │
│                                                             │
│   ┌───┬───┬───┐                                             │
│   │ 1 │ 1 │ 1 │                                             │
│   ├───┼───┼───┤    결과 = (모든 값의 합) / 9                │
│   │ 1 │ X │ 1 │                                             │
│   ├───┼───┼───┤                                             │
│   │ 1 │ 1 │ 1 │                                             │
│   └───┴───┴───┘                                             │
│                                                             │
│   X 위치의 새 값 = 주변 9픽셀 평균                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### GPU 커널

```c
#define BLUR_SIZE 1  // 반경 1 = 3×3 필터

__global__ void boxBlur(unsigned char* input, unsigned char* output,
                        int width, int height, int channels) {
    int x = blockIdx.x * blockDim.x + threadIdx.x;
    int y = blockIdx.y * blockDim.y + threadIdx.y;

    if (x < width && y < height) {
        for (int c = 0; c < channels; c++) {
            float sum = 0;
            int count = 0;

            // 주변 픽셀 순회
            for (int dy = -BLUR_SIZE; dy <= BLUR_SIZE; dy++) {
                for (int dx = -BLUR_SIZE; dx <= BLUR_SIZE; dx++) {
                    int nx = x + dx;
                    int ny = y + dy;

                    // 경계 체크
                    if (nx >= 0 && nx < width && ny >= 0 && ny < height) {
                        sum += input[(ny * width + nx) * channels + c];
                        count++;
                    }
                }
            }

            // 평균 계산
            output[(y * width + x) * channels + c] = (unsigned char)(sum / count);
        }
    }
}
```

### 3. 블러 강도 조절

```c
#define BLUR_SIZE 1  // 3×3 (약한 블러)
#define BLUR_SIZE 2  // 5×5 (중간 블러)
#define BLUR_SIZE 3  // 7×7 (강한 블러)
```

블러 크기가 커질수록:
- 더 흐릿한 효과
- 더 많은 연산 필요 (O(n²))
