# 테스트 설명: 5천만 개 데이터 (cpu_vs_gpu_50M.cu)

## 이 테스트의 목적

> **"GPU는 대량 데이터에서 진가를 발휘한다"**를 직접 체험하게 합니다.

1만 개 테스트에서 GPU가 느렸다면, 이 테스트에서는 **GPU가 왜 존재하는지** 이해하게 됩니다.


## 왜 GPU가 빠른가?

### CPU vs GPU 병렬 처리 능력

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Jetson Nano 하드웨어 비교                                 │
│                                                             │
│   CPU: ARM Cortex-A57 (4코어)                               │
│   ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐                          │
│   │  1  │ │  2  │ │  3  │ │  4  │                          │
│   └─────┘ └─────┘ └─────┘ └─────┘                          │
│   → 4개 작업 동시 처리                                      │
│                                                             │
│   GPU: Maxwell (128 CUDA 코어)                              │
│   ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐        │
│   ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐        │
│   ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐        │
│   ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐        │
│   ... (총 128개 코어)                                       │
│   → 128개 작업 동시 처리 (실제로는 수천 개 스레드)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5천만 개 처리 과정

| 항목 | CPU (4코어) | GPU (128코어 + 수천 스레드) |
|------|-------------|---------------------------|
| 동시 처리 | 4개 | 50,000개+ |
| 반복 횟수 | 1,250만 회 | ~1,000회 |
| 소요 시간 | 1,667 ms | 126 ms |

## 강조하고자 하는 핵심 포인트

### ❶ GPU는 "대량 병렬 처리" 전문가

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   CPU의 처리 방식 (순차)                                    │
│                                                             │
│   시간 →                                                    │
│   ├──[1]──[2]──[3]──[4]──[5]──[6]──[7]──[8]──...──[5천만]   │
│   │        느림 (하나씩 처리)                               │
│                                                             │
│   ─────────────────────────────────────────────────         │
│                                                             │
│   GPU의 처리 방식 (병렬)                                    │
│                                                             │
│   시간 →                                                    │
│   ├──[1,2,3,...,50000]──[50001,...,100000]──...──           │
│   │        빠름 (수만 개씩 동시 처리)                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### ❷ 데이터가 클수록 GPU 효과 증가

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   데이터 크기별 GPU 효과                                    │
│                                                             │
│   1만 개:     GPU 274배 느림  ❌                            │
│   10만 개:    GPU 비슷         -                            │
│   100만 개:   GPU 2배 빠름    ✅                            │
│   1000만 개:  GPU 5배 빠름    ✅✅                          │
│   5000만 개:  GPU 13배 빠름   ✅✅✅                        │
│                                                             │
│   → 데이터가 5000배 늘면, GPU 효과는 기하급수적 증가!       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### ❸ 메모리 전송은 "필요한 비용"

딥러닝, 이미지 처리 등에서 GPU가 효과적인 이유:

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   딥러닝 학습 시나리오                                      │
│                                                             │
│   [데이터 전송]                                             │
│        ↓                                                    │
│   [GPU 연산] × 1000 에폭 ← 반복!                            │
│        ↓                                                    │
│   [결과 전송]                                               │
│                                                             │
│   전송: 1회                                                 │
│   연산: 1000회                                              │
│                                                             │
│   → 전송 비용은 1회, 연산 이득은 1000회!                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 실제 활용 사례

### GPU가 빛나는 영역

| 분야 | 데이터 규모 | GPU 속도 향상 |
|------|------------|--------------|
| 딥러닝 학습 | 수백만~수억 파라미터 | 10~100x |
| 이미지 처리 (4K) | 800만 픽셀 | 10~50x |
| 물리 시뮬레이션 | 수백만 입자 | 20~100x |
| 비디오 인코딩 | 수천만 픽셀/초 | 5~20x |
| 과학 계산 | 대규모 행렬 | 10~50x |

### 왜 딥러닝에서 GPU가 필수인가?

```
신경망 학습 1회 = 수백만 개 파라미터 × 수십만 개 데이터
             = 수천억 번의 연산

CPU: 수 시간 ~ 수 일
GPU: 수 분 ~ 수 시간

→ GPU 없이는 현대 AI가 불가능!
```

## 코드 분석

### 핵심 커널 코드

```c
__global__ void gpu_compute(float *a, float *b, float *c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) {
        float temp = a[idx] + b[idx];  // 덧셈
        temp = temp * temp;             // 제곱
        temp = sqrtf(temp);             // 제곱근
        c[idx] = temp;
    }
}
```

### GPU 스레드 구성

```
그리드 크기: 195,313 블록
블록 크기: 256 스레드
총 스레드: 50,000,128개

→ 5천만 개 데이터를 5천만 개 스레드가 "동시에" 처리!
  (실제로는 SM 단위로 스케줄링되어 처리)
```
