# 예제 5: cpu_vs_gpu_10K.cu

## 목적
**작은 데이터에서 GPU가 오히려 느리다는 것을 체험한다.**

많은 사람들이 "GPU = 무조건 빠르다"고 생각하지만, 이 예제는 그 **오해를 깨뜨립니다**.

---

## 실행 방법

```bash
cd ~/cuda/week1/code
nvcc cpu_vs_gpu_10K.cu -o cpu_vs_gpu_10K
./cpu_vs_gpu_10K
```

## 이 결과의 의미

### 시간 분석

| 항목 | 시간 | 비율 |
|------|------|------|
| GPU 메모리 할당 | 91.564 ms | 99.3% |
| CPU → GPU 복사 | 0.295 ms | 0.3% |
| **GPU 커널 실행** | **0.114 ms** | **0.1%** |
| GPU → CPU 복사 | 0.248 ms | 0.3% |
| **GPU 전체** | **92.221 ms** | 100% |
| **CPU** | **0.337 ms** | - |

**실제 연산 시간은 0.1%에 불과!** 99.9%가 준비 시간입니다.

### GPU 커널은 빠르다

```
CPU 연산:     0.337 ms
GPU 커널:     0.114 ms  ← CPU보다 3배 빠름!

하지만...
GPU 전체:    92.221 ms  ← CPU보다 274배 느림!
```

## 코드의 특징

### 단계별 시간 측정

```c
// 1단계: GPU 메모리 할당
double step1_start = get_time_ms();
cudaMalloc(&d_a, N * sizeof(float));
cudaMalloc(&d_b, N * sizeof(float));
cudaMalloc(&d_c, N * sizeof(float));
double step1_time = get_time_ms() - step1_start;

// 2단계: CPU → GPU 복사
double step2_start = get_time_ms();
cudaMemcpy(d_a, h_a, ...);
cudaMemcpy(d_b, h_b, ...);
double step2_time = get_time_ms() - step2_start;

// ... 이하 동일
```

이렇게 단계별로 측정하면 **어디서 시간이 소요되는지** 정확히 알 수 있습니다.
