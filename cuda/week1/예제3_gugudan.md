# 예제 3: gugudan.cu

## 목적
**스레드와 블록을 활용하여 실제 계산을 수행한다.**

이 예제는 친숙한 구구단을 GPU로 출력하면서 **스레드/블록 인덱스가 실제 값으로 어떻게 변환되는지** 보여줍니다.

---

## 실행 방법

```bash
cd ~/cuda/week1/code
nvcc gugudan.cu -o gugudan
./gugudan
```

## 코드 분석

### 1. 단일 단 출력 (특정 단)

```c
__global__ void gugudan(int dan) {
    int num = threadIdx.x + 1;  // 스레드 0~8 → 곱할 수 1~9
    printf("%d x %d = %2d\n", dan, num, dan * num);
}

// 호출: 3단 출력
gugudan<<<1, 9>>>(3);  // 1개 블록, 9개 스레드
```

**작동 원리:**
```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   gugudan<<<1, 9>>>(3)                                      │
│                                                             │
│   스레드 0: threadIdx.x = 0 → num = 1 → "3 x 1 = 3"        │
│   스레드 1: threadIdx.x = 1 → num = 2 → "3 x 2 = 6"        │
│   스레드 2: threadIdx.x = 2 → num = 3 → "3 x 3 = 9"        │
│   ...                                                       │
│   스레드 8: threadIdx.x = 8 → num = 9 → "3 x 9 = 27"       │
│                                                             │
│   → 9개 스레드가 동시에 3단 전체를 출력!                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. 전체 단 출력 (2~9단)

```c
__global__ void gugudanAll() {
    int dan = blockIdx.x + 2;   // 블록 0~7 → 2~9단
    int num = threadIdx.x + 1;  // 스레드 0~8 → 곱할 수 1~9

    printf("%d x %d = %2d\n", dan, num, dan * num);
}

// 호출: 2~9단 전체
gugudanAll<<<8, 9>>>();  // 8개 블록, 각 9개 스레드
```

**작동 원리:**
```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   gugudanAll<<<8, 9>>>()                                    │
│                                                             │
│   블록 0 (2단):  9개 스레드 → 2x1, 2x2, ..., 2x9           │
│   블록 1 (3단):  9개 스레드 → 3x1, 3x2, ..., 3x9           │
│   블록 2 (4단):  9개 스레드 → 4x1, 4x2, ..., 4x9           │
│   ...                                                       │
│   블록 7 (9단):  9개 스레드 → 9x1, 9x2, ..., 9x9           │
│                                                             │
│   총 8 × 9 = 72개 스레드가 동시에 실행!                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 핵심 포인트

### 1. 인덱스를 실제 값으로 변환

CUDA 인덱스는 항상 0부터 시작하므로, 실제 값으로 변환이 필요합니다:

```c
int dan = blockIdx.x + 2;   // 0,1,2,...,7 → 2,3,4,...,9
int num = threadIdx.x + 1;  // 0,1,2,...,8 → 1,2,3,...,9
```

### 2. 블록 = "단", 스레드 = "곱할 수"

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   구구단 표의 구조                                          │
│                                                             │
│        곱할 수 (스레드)                                     │
│        1   2   3   4   5   6   7   8   9                   │
│      ┌───┬───┬───┬───┬───┬───┬───┬───┬───┐                │
│   2단│ 2 │ 4 │ 6 │ 8 │10 │12 │14 │16 │18 │  블록 0        │
│      ├───┼───┼───┼───┼───┼───┼───┼───┼───┤                │
│   3단│ 3 │ 6 │ 9 │12 │15 │18 │21 │24 │27 │  블록 1        │
│      ├───┼───┼───┼───┼───┼───┼───┼───┼───┤                │
│   ...│   │   │   │   │   │   │   │   │   │                │
│      ├───┼───┼───┼───┼───┼───┼───┼───┼───┤                │
│   9단│ 9 │18 │27 │36 │45 │54 │63 │72 │81 │  블록 7        │
│      └───┴───┴───┴───┴───┴───┴───┴───┴───┘                │
│   (블록)                                                    │
│                                                             │
│   → 2차원 데이터를 블록과 스레드로 자연스럽게 매핑!         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3. 병렬 처리의 위력

CPU로 구구단을 출력하면:
```c
for (int dan = 2; dan <= 9; dan++) {
    for (int num = 1; num <= 9; num++) {
        printf("%d x %d = %d\n", dan, num, dan * num);
    }
}
// → 72회 순차 반복
```

GPU로 구구단을 출력하면:
```c
gugudanAll<<<8, 9>>>();
// → 72개 동시 실행!
```
