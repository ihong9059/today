# 테스트 설명: 1만 개 데이터 (cpu_vs_gpu_10K.cu)

## 이 테스트의 목적

> **"GPU가 항상 빠른 것은 아니다"**를 직접 체험하게 합니다.

많은 사람들이 "GPU = 빠르다"라고 생각합니다. 하지만 이 테스트는 **작은 데이터에서는 GPU가 오히려 느리다**는 것을 보여줍니다.

---

## 테스트 실행

```bash
cd ~/cuda/week1/code
./cpu_vs_gpu_10K
```

## 이 결과가 의미하는 것

### 1. GPU 커널 자체는 빠르다

```
CPU 연산 시간:    0.337 ms
GPU 커널 시간:    0.114 ms  ← 3배 빠름!
```

GPU 커널만 보면 CPU보다 3배 빠릅니다. **GPU의 병렬 처리 능력은 실제로 뛰어납니다.**

### 2. 하지만 "준비 시간"이 너무 길다

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   GPU를 사용하려면 반드시 거쳐야 하는 단계들                │
│                                                             │
│   ┌──────────────────┐                                      │
│   │ 1. GPU 메모리 할당 │ ← 91.564 ms (99%)                  │
│   └────────┬─────────┘                                      │
│            ▼                                                │
│   ┌──────────────────┐                                      │
│   │ 2. 데이터 복사    │ ← 0.295 ms                          │
│   │    (CPU → GPU)   │                                      │
│   └────────┬─────────┘                                      │
│            ▼                                                │
│   ┌──────────────────┐                                      │
│   │ 3. GPU 연산 실행  │ ← 0.114 ms ⭐ 실제 일하는 시간      │
│   └────────┬─────────┘                                      │
│            ▼                                                │
│   ┌──────────────────┐                                      │
│   │ 4. 결과 복사      │ ← 0.248 ms                          │
│   │    (GPU → CPU)   │                                      │
│   └──────────────────┘                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**실제 연산 시간: 0.114ms (0.1%)**
**준비 시간: 92.107ms (99.9%)**

## 강조하고자 하는 핵심 포인트

### ❶ GPU 초기화 비용은 무시할 수 없다

첫 번째 CUDA 호출 시 GPU 드라이버 초기화, 컨텍스트 생성 등이 발생합니다.

```
첫 번째 실행: GPU 메모리 할당에 ~90ms 소요
두 번째 실행: GPU 메모리 할당에 ~1ms 소요 (캐시됨)
```

이것은 "콜드 스타트" 문제입니다.

### ❷ 데이터 전송은 병목이 된다

CPU와 GPU는 물리적으로 분리되어 있습니다.

```
┌─────────┐         PCIe 버스          ┌─────────┐
│   CPU   │ ◀═══════════════════════▶ │   GPU   │
│  메모리  │      (대역폭 제한)         │  메모리  │
└─────────┘                            └─────────┘

전송 속도: ~12 GB/s (PCIe 3.0 x4 기준)
39 KB 전송: ~0.003 ms (이론값)
실제 전송:  ~0.5 ms (오버헤드 포함)
```

작은 데이터는 전송 오버헤드가 실제 전송 시간보다 큽니다.

### ❸ "손익분기점"을 알아야 한다

```
         비용/이득
            ▲
            │
   GPU 비용 │━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   (고정)   │
            │                    ╱
            │                  ╱
            │                ╱
   CPU 비용 │              ╱
   (가변)   │            ╱
            │          ╱
            │        ╱
            │      ╱
            │    ╱
            │  ╱  ← 손익분기점
            │╱
            └────────────────────────────────▶ 데이터 크기
                   ↑
               1만 개는 여기
            (손익분기점 훨씬 이전)
```

## 언제 GPU를 사용하지 말아야 하는가?

| 상황 | GPU 사용? | 이유 |
|------|----------|------|
| 데이터 1만 개 이하 | ❌ | 오버헤드 > 이득 |
| 단발성 작은 계산 | ❌ | 초기화 비용이 큼 |
| 분기가 많은 코드 | ❌ | GPU는 분기 처리에 약함 |
| 순차적 의존성 | ❌ | 병렬화 불가 |
