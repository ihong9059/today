# 예제 6: cpu_vs_gpu_50M.cu

## 목적
**대량 데이터에서 GPU의 진정한 성능을 체험한다.**

1만 개에서 GPU가 느렸다면, 5천만 개에서는 **GPU가 왜 존재하는지** 이해하게 됩니다.

---

## 실행 방법

```bash
cd ~/cuda/week1/code
nvcc cpu_vs_gpu_50M.cu -o cpu_vs_gpu_50M
./cpu_vs_gpu_50M
```

## 결과 분석

### 1만 개 vs 5천만 개 비교

| 항목 | 1만 개 | 5천만 개 |
|------|--------|---------|
| 데이터 크기 | 39 KB | 190 MB |
| CPU 시간 | 0.34 ms | 1,667 ms |
| GPU 커널 | 0.11 ms | 126 ms |
| GPU 전체 | 92 ms | 672 ms |
| **결과** | GPU **274배 느림** | GPU **2.5배 빠름** |

**같은 코드, 같은 GPU인데 데이터 크기만으로 결과가 완전히 역전!**

## 코드의 특징

### 상세한 시간 분석 출력

```c
// 시간 구성 시각화

for(int i = 0; i < (int)(step1_time / gpu_total_time * 30); i++) printf("█");
printf("\n");
// ... 각 단계별 막대 그래프 출력
```

### 그리드 정보 출력

```c
printf("   [3] GPU 커널 실행...\n");
printf("       - 그리드 크기: %d 블록\n", gridSize);
printf("       - 블록 크기: %d 스레드\n", blockSize);
printf("       - 총 스레드: %d개\n", gridSize * blockSize);
```
