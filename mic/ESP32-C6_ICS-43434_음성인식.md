# ESP32-C6 + ICS-43434 음성 인식 방법

## 하드웨어 연결

ICS-43434는 I2S 디지털 MEMS 마이크입니다. ESP32-C6와 연결:

| ICS-43434 | ESP32-C6 |
|-----------|----------|
| SCK | GPIO 6 (I2S_CLK) |
| WS | GPIO 7 (I2S_WS) |
| SD | GPIO 8 (I2S_DIN) |
| VDD | 3.3V |
| GND | GND |
| L/R | GND (Left) 또는 VDD (Right) |

---

## 음성 인식 구현 방법

### 1. ESP-SR (온디바이스, 권장)

Espressif 공식 음성 인식 라이브러리

- **WakeNet**: 웨이크 워드 감지 ("Hi Lexin" 등)
- **MultiNet**: 명령어 인식 (100개 이상 명령)
- **AFE**: 노이즈 제거, 에코 캔슬링

```bash
# ESP-IDF 프로젝트에 추가
idf.py add-dependency "espressif/esp-sr"
```

**장점**: 인터넷 불필요, 빠른 응답
**단점**: ESP32-C6는 PSRAM 없어 모델 크기 제한

---

### 2. 클라우드 API 연동

오디오를 WiFi로 전송하여 처리

- **Google Cloud Speech-to-Text**
- **OpenAI Whisper API**
- **Azure Speech Services**

```
[마이크] → [I2S 캡처] → [WiFi] → [클라우드 API] → [텍스트]
```

**장점**: 높은 정확도, 다국어 지원
**단점**: 인터넷 필수, 지연시간

---

### 3. Edge Impulse (커스텀 ML)

자신만의 음성 모델 학습

1. Edge Impulse Studio에서 데이터 수집
2. 모델 학습 (키워드, 명령어 등)
3. ESP32용 라이브러리로 내보내기

**장점**: 맞춤형 키워드 가능
**단점**: 학습 데이터 필요

---

### 4. VAD (Voice Activity Detection)

단순히 "사람 목소리 유무"만 감지

```c
// 간단한 에너지 기반 VAD
float rms = calculate_rms(audio_buffer, samples);
if (rms > VOICE_THRESHOLD) {
    // 음성 감지됨
}
```

## 추천 조합

| 목적 | 추천 방식 |
|------|----------|
| 웨이크 워드만 | ESP-SR WakeNet |
| 간단한 명령어 (10개 미만) | ESP-SR MultiNet |
| 자유로운 대화/STT | 클라우드 API (Whisper) |
| 특정 키워드 감지 | Edge Impulse |
