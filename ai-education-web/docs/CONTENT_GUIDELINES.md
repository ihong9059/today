### 1.1 핵심 목표

### 1.2 교육 철학

#### 원칙 1: 외우지 말고 이해하라
- 문법은 잊어버려도 된다 (AI에게 물어보면 된다)

#### 원칙 2: AI 맥락에서 설명하라
- 모든 개념은 AI에서 어떻게 활용되는지 연결
- 추상적 개념 → 실제 AI 적용 사례
- "이것이 신경망에서 어떻게 쓰이나요?" 질문에 답할 수 있어야 함

#### 원칙 3: 문제 해결 능력을 기르라
- 에러가 발생하면 AI 챗봇에게 물어보는 습관
- 코드를 외우는 것이 아니라, 문제를 해결하는 방법을 익히기
- 스스로 탐구하는 자세

## 학습 목표
- 반복문이 AI 학습에서 어떤 역할을 하는지 **이해**한다
- 조건문으로 학습을 제어하는 방법을 파악한다
- Epoch, Batch, Early Stopping의 원리를 안다

## 핵심 메시지

> 조건문은 학습을 언제 멈출지, 어떻게 조절할지 결정합니다.

## 1. 반복문: AI 학습의 심장

### 딥러닝의 모든 것은 반복이다

```python
# 이것이 AI 학습의 핵심 구조입니다!
for epoch in range(100):        # 100번 반복 학습
    for batch in dataloader:    # 데이터를 조금씩 나눠서
        output = model(batch)   # 예측하고
        loss = loss_fn(output)  # 손실 계산하고
        loss.backward()         # 역전파하고
        optimizer.step()        # 가중치 업데이트
```

#### 왜 반복이 필요할까?
- 한 번에 모든 데이터를 처리할 수 없음 (메모리 한계)
- 조금씩 여러 번 학습해야 패턴을 제대로 학습
- Epoch: 전체 데이터를 한 번 다 보는 것
- Batch: 한 번에 처리하는 데이터 묶음

### Early Stopping - 과적합 방지

## 7. 예시: 좋은 vs 나쁜 콘텐츠

### 나쁜 예시
```
### for 반복문
for i in range(5):
    print(i)

# 출력: 0, 1, 2, 3, 4
```

### 좋은 예시
```
### for 반복문 - AI 학습의 핵심 구조

AI는 어떻게 학습할까요? 바로 **반복**입니다!

```python
# 모든 딥러닝 학습은 이 구조입니다
for epoch in range(100):  # 100번 반복 학습
    loss = train_one_epoch(model, data)
    print(f"Epoch {epoch}: Loss = {loss:.4f}")
```

- `epoch`: 전체 데이터를 한 번 보는 단위
- `100`: 총 100번 전체 데이터를 학습
- 반복할수록 `loss`가 줄어듦 (학습이 되는 것!)

> 💡 for 문법을 외울 필요 없어요.
> "AI는 반복으로 학습한다"는 것만 기억하세요!
```
