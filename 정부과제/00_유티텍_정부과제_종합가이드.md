## 2. 보유 플랫폼 현황

### 2.1 UTTEC Edu (AI 진로교육 플랫폼)
- **URL:** https://uttec-edu.duckdns.org/
- **기능:** AI 기반 맞춤형 진로교육
- **대상:** 학부형, 사회초년생, 진로전환자
- **특징:**
  - MBTI/MMTIC 기반 성향 파악
  - 8개 교육 트랙 (대학진학, 회화, 코딩전문가, 교사/교육자 등)
  - 5단계 학습 프로세스 (성향파악 → 탐색 → 집중학습 → 결과물 → 진로결정)
  - 포트폴리오 기반 실무역량 개발

### 2.2 Factory Sensor Monitor (산업용 IoT 모니터링)
- **URL:** https://uttec-sensor.duckdns.org/
- **기능:** 산업용 설비 실시간 모니터링
- **핵심 기술:**
  - 진동/회전/기울기 센서 데이터 수집
  - Three.js 기반 3D 시각화
  - WebSocket 실시간 통신
  - 3점 캘리브레이션 시스템
- **활용:** 예방정비, 설비진단, 현장점검

### 2.3 C/ESP32 교육 플랫폼
- **기능:** 마이크로컨트롤러 프로그래밍 교육
- **대상:** 임베디드 개발자 양성
- **특징:** 실습 중심 firmware 교육

## 6. 유티텍 핵심 경쟁력 (공통 활용)

### 기술적 강점
```
┌─────────────────────────────────────────────────────┐
│  HW 역량                    SW 역량                  │
├─────────────────────────────────────────────────────┤
│  • Firmware 10년           • AI 교육 플랫폼          │
│  • BLE Mesh 통신           • 3D 시각화 (Three.js)    │
│  • 센서 융합               • 실시간 통신 (WebSocket)  │
│  • 저전력 설계             • 반응형 웹 시스템         │
└─────────────────────────────────────────────────────┘
                      ↓
            HW + SW 원스톱 개발 역량
```

### 시장 검증
- 일본 수출 실적 (B2B)
- 군납 실적 (신뢰성 검증)
- 국내 B2B 다수 납품

### 차별화 포인트
1. **IoT 교구재 + AI 플랫폼** 동시 개발 가능
2. **실습형 교육** (이론 + 실제 HW 연동)
3. **산업현장 경험** 기반 실무 교육 콘텐츠
