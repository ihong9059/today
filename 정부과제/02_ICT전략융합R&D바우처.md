# ICT전략융합R&D바우처 과제 신청 전략

## 1. 과제 개요

### 기본 정보
| 항목 | 내용 |
|------|------|
| **사업명** | ICT전략융합R&D바우처지원사업 |
| **주관부처** | 과학기술정보통신부 |
| **전담기관** | 정보통신기획평가원(IITP) |
| **지원금액** | 과제당 최대 **8억원** |
| **지원대상** | 국내 중소기업(초기창업자·벤처기업 포함), 중견기업 |
| **신청방법** | IRIS (https://www.iris.go.kr) |

### 사업 목적
- ICT 기술의 타 산업 융합을 통한 신시장 창출
- 중소·중견기업의 ICT 융합 R&D 역량 강화
- ICT 기반 혁신 제품/서비스 사업화 지원

### 사업 특징
- **바우처 방식:** 기업이 필요한 R&D 서비스를 직접 선택하여 활용
- **유연한 활용:** 기술개발, 시제품 제작, 인증, 마케팅 등 다양한 용도

---

## 2. 유티텍 신청 전략

### 과제명 (제안)
> **"산업현장 예지보전을 위한 AI-IoT 융합 센서 모니터링 및 기술인력 양성 통합 솔루션 개발"**

### 과제 요약
```
Factory Sensor Monitor (IoT 모니터링) + AI 분석 + 기술교육 플랫폼
                              ↓
    설비 데이터 수집 → AI 이상 예측 → 현장 기술자 교육 → 예방정비 실행
```

### 핵심 가치
- **제조 현장:** 설비 고장 사전 예측으로 비용 절감
- **기술 인력:** AI/IoT 기반 스마트공장 운영 역량 확보
- **기업:** 모니터링 + 교육 원스톱 솔루션 판매

---

## 3. 사업계획서 핵심 내용

### 3.1 개발 목표

#### 최종 목표
AI 기반 설비 예지보전 시스템과 현장 기술자 교육을 연동한 스마트공장 통합 솔루션 개발

#### 세부 목표
| 구분 | 목표 | 성과지표 |
|------|------|----------|
| AI 분석 | 설비 이상 예측 모델 | 예측 정확도 90% |
| IoT 시스템 | Factory Sensor Monitor 고도화 | 동시 모니터링 100대 |
| 교육 플랫폼 | 현장 기술자 교육 시스템 | 교육 이수 500명 |
| 사업화 | B2B 납품 | 매출 8억원 |

### 3.2 기술 개발 내용

#### 핵심 기술 1: AI 예지보전 엔진
```
현재: 실시간 센서 데이터 시각화
  ↓
개발 내용:
  • 진동 패턴 기반 이상 징후 감지 AI
  • 베어링/모터 수명 예측 알고리즘
  • 다중 센서 데이터 융합 분석
  • 알람 및 자동 보고서 생성
```

#### 핵심 기술 2: IoT 모니터링 고도화
```
현재: 단일 기기 모니터링
  ↓
개발 내용:
  • 다중 설비 동시 모니터링 (100대+)
  • 엣지 컴퓨팅 기반 실시간 처리
  • BLE Mesh 기반 센서 네트워크
  • 클라우드/온프레미스 하이브리드
```

#### 핵심 기술 3: 기술인력 교육 연동
```
현재: 별도 운영되는 교육 플랫폼
  ↓
개발 내용:
  • 실제 설비 데이터 기반 교육 콘텐츠
  • AR/VR 정비 시뮬레이션
  • AI 튜터 기반 맞춤형 학습
  • 자격증 연계 커리큘럼
```

## 4. 기존 기술 활용

### Factory Sensor Monitor 현황
| 기능 | 현재 수준 | 고도화 목표 |
|------|-----------|-------------|
| 센서 지원 | 진동, 회전, 기울기 | +온도, 전류, 압력 |
| 시각화 | Three.js 3D | +AR/VR 연동 |
| 통신 | WebSocket | +MQTT, LoRa |
| 분석 | 실시간 표시 | +AI 예측 |
| 교육 | 미연동 | 실데이터 연동 |

### 기술적 강점 활용
```
유티텍 10년 기술 자산
├── BLE Mesh 통신 → 공장 내 센서 네트워크
├── 저전력 설계 → 배터리 센서 노드
├── Firmware 역량 → 엣지 디바이스 개발
└── 센서 융합 → 다중 센서 데이터 처리
```

## 5. 추진 체계

| 단계 | 기간 | 주요 내용 | 산출물 |
|------|------|-----------|--------|
