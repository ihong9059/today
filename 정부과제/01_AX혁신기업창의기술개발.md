# AX혁신기업창의기술개발 과제 신청 전략

## 1. 과제 개요

### 기본 정보
| 항목 | 내용 |
|------|------|
| **사업명** | AX혁신기업창의기술개발사업 |
| **주관부처** | 과학기술정보통신부 |
| **전담기관** | 정보통신기획평가원(IITP) |

### 사업 목적
- AI 전환(AX: AI Transformation)을 통한 혁신기업 육성
- 중소·벤처기업의 AI 기술 기반 신제품·서비스 개발 지원
- AI 융합 기술의 사업화 촉진

---

## 2. 유티텍 신청 전략

### 과제명 (제안)
> **"AI 기반 맞춤형 진로교육 플랫폼과 IoT 센서 교구재 연동 스마트 STEM 교육 시스템 개발"**

### 과제 요약
```
UTTEC Edu (AI 진로교육) + Factory Sensor Monitor (IoT 실습) + ESP32 교육
                              ↓
    학생이 AI로 직업 탐색 → IoT 센서 교구재로 실습 → 포트폴리오 완성
```

---

## 3. 사업계획서 핵심 내용

### 3.1 개발 목표

#### 최종 목표
AI 기반 개인 맞춤형 진로교육과 IoT 실습을 연동한 통합 STEM 교육 플랫폼 개발

#### 세부 목표
| 구분 | 목표 | 성과지표 |
|------|------|----------|
| AI 플랫폼 | UTTEC Edu 고도화 | 학습자 1,000명 확보 |
| IoT 교구재 | BLE Mesh 센서 키트 개발 | 교구재 500세트 판매 |
| 연동 시스템 | AI-IoT 실시간 학습 피드백 | 학습 완료율 80% |
| 사업화 | B2B 교육기관 납품 | 매출 5억원 |

### 3.2 기술 개발 내용

#### Phase 1: AI 교육 플랫폼 고도화 (6개월)
```
현재: UTTEC Edu 기본 기능
  ↓
목표:
  • AI 기반 학습 경로 자동 추천
  • 실시간 학습 분석 대시보드
  • 개인별 취약점 진단 및 보완 학습
  • LLM 기반 1:1 튜터링 시스템
```

#### Phase 2: IoT 교구재 개발 (6개월)
```
기존 기술: BLE Mesh, 센서 융합, Firmware
  ↓
개발 교구재:
  • ESP32 기반 IoT 센서 키트
  • BLE Mesh 통신 실습 모듈
  • 진동/온도/조도 센서 통합 보드
  • 모바일 앱 연동 실습 환경
```

#### Phase 3: AI-IoT 연동 시스템 (6개월)
```
AI 플랫폼 ←→ IoT 교구재 연동
  • 실습 데이터 자동 수집 → AI 분석
  • 학습자 행동 패턴 분석
  • 실시간 피드백 및 힌트 제공
  • 포트폴리오 자동 생성
```

### 3.3 기술적 차별성

| 기존 교육 | 유티텍 솔루션 |
|-----------|---------------|
| 이론 중심 온라인 강의 | AI 맞춤형 + 실습 연동 |
| 단순 시뮬레이션 | 실제 IoT HW 실습 |
| 일방향 콘텐츠 제공 | 양방향 AI 튜터링 |
| 개별 학습 관리 어려움 | 실시간 학습 분석 |

