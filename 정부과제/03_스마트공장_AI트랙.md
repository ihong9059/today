# 제조AI특화 스마트공장 (AI트랙) 과제 신청 전략

## 1. 과제 개요

### 기본 정보
| 항목 | 내용 |
|------|------|
| **사업명** | 제조AI특화 스마트공장 (자율형공장 AI트랙) |
| **주관부처** | 중소벤처기업부 |
| **전담기관** | 중소기업기술정보진흥원(TIPA) |
| **지원비율** | 정부 **50~70%** (기업 규모별 차등) |
| **지원대상** | AI 스마트공장 구축 희망 국내 중소·중견기업 |
| **신청방법** | 스마트공장 사업관리 시스템 (smart-factory.kr) |

### 사업 목적
- 중소제조업에 적합한 AI 기술 활용 공장 구축
- AI에이전트, 온디바이스AI 등 최신 기술 적용
- 공정최적화, 예지보수 등 제조혁신 실현

### 지원 내용
- AI 기반 공정최적화, 품질관리, 예유지보수 시스템 구축
- 제조생산·업무데이터의 AI 실시간 학습·분석 시스템
- 제조혁신이 가능한 AI 공장 시스템 구축

## 2. 유티텍 신청 전략

### 2.1 공급기업으로 참여

유티텍은 **스마트공장 공급기업**으로 등록하여 참여하는 것이 유리합니다.

```
┌─────────────────────────────────────────────────┐
│              참여 방식 비교                      │
├─────────────────────────────────────────────────┤
│  수요기업 (도입기업)                            │
│  • 스마트공장을 구축하려는 제조기업             │
│  • 유티텍 해당 없음 (제조업 아님)               │
├─────────────────────────────────────────────────┤
│  공급기업 (유티텍 적합)                         │
│  • 스마트공장 솔루션을 제공하는 기업            │
│  • Factory Sensor Monitor 기반 솔루션 공급      │
│  • AI 모니터링 시스템 구축 서비스               │
└─────────────────────────────────────────────────┘
```

### 2.2 공급 솔루션 제안

#### 솔루션명
> **"모바일 기반 온디바이스 AI 설비진단 시스템"**

#### 솔루션 개요
```
Factory Sensor Monitor 기반
        ↓
┌─────────────────────────────────────────────────┐
│  모바일 센서 → 엣지 AI 분석 → 이상 감지 알람    │
│       ↓              ↓              ↓           │
│  진동/회전/기울기    실시간 분석    즉시 대응     │
│  데이터 수집        패턴 학습      예방정비       │
└─────────────────────────────────────────────────┘
```

## 3. 솔루션 상세

### 3.1 핵심 기능

| 기능 | 설명 | 기술 |
|------|------|------|
| **센서 데이터 수집** | 진동, 회전, 기울기, 온도 | 모바일 센서 + 외부 센서 |
| **3D 시각화** | 설비 상태 실시간 표시 | Three.js |
| **AI 이상 감지** | 패턴 기반 이상 징후 예측 | TensorFlow Lite |
| **캘리브레이션** | 3점 자동 캘리브레이션 | 자체 알고리즘 |
| **알람 시스템** | 이상 감지 시 즉시 알림 | Push, SMS, Email |
| **보고서 생성** | 일간/주간/월간 리포트 | 자동 생성 |

### 3.2 온디바이스 AI 특징

```
┌─────────────────────────────────────────────────┐
│              온디바이스 AI 장점                  │
├─────────────────────────────────────────────────┤
│  • 실시간 처리: 네트워크 지연 없음               │
│  • 보안: 데이터가 외부로 전송되지 않음           │
│  • 비용: 클라우드 비용 절감                      │
│  • 신뢰성: 네트워크 장애 시에도 동작             │
├─────────────────────────────────────────────────┤
│              유티텍 기술 적용                    │
├─────────────────────────────────────────────────┤
│  • ESP32 기반 엣지 디바이스                      │
│  • TensorFlow Lite 모델 탑재                    │
│  • BLE Mesh 센서 네트워크 연동                   │
│  • 저전력 설계로 배터리 구동 가능                │
└─────────────────────────────────────────────────┘
```

### 3.3 시스템 구성도

```
[제조 현장]
    │
    ├── 모바일 센서 (스마트폰/태블릿)
    │       │
    │       └── 내장 센서 활용
    │           • 가속도계 (진동)
    │           • 자이로스코프 (회전)
    │           • 중력센서 (기울기)
    │
    ├── 외부 센서 노드 (BLE Mesh)
    │       │
    │       └── 전용 센서 모듈
    │           • 온도 센서
    │           • 전류 센서
    │           • 압력 센서
    │
    └── 엣지 게이트웨이
            │
            ├── 온디바이스 AI
            │   • 이상 패턴 감지
            │   • 예측 모델 실행
            │
            └── 클라우드 연동 (선택)
                • 대시보드
                • 분석 리포트
                • 원격 모니터링
```

## 4. 도입 기업 혜택

### 4.1 정량적 효과

| 항목 | 도입 전 | 도입 후 | 개선율 |
|------|---------|---------|--------|
| 설비 고장 빈도 | 월 5회 | 월 1회 | 80% 감소 |
| 비계획 정지시간 | 월 20시간 | 월 4시간 | 80% 감소 |
| 정비 비용 | 월 500만원 | 월 200만원 | 60% 절감 |
| 품질 불량률 | 3% | 1% | 67% 개선 |

### 4.2 정성적 효과
- 현장 기술자의 데이터 기반 의사결정 역량 강화
- 설비 이력 관리를 통한 체계적 자산 관리
- 안전사고 예방 (설비 이상 조기 감지)

### 5.2 등록 절차

```
1. 스마트공장 포털 가입
   └── smart-factory.kr

2. 공급기업 등록 신청
   └── 기업 정보, 솔루션 정보 입력

3. 서류 심사
   └── 사업자등록증, 솔루션 설명서 등

4. 현장 실사 (필요시)
   └── 기술역량 확인

5. 등록 완료
   └── 스마트공장 사업 참여 가능
```
