# 에듀테크 시장 진출 전략

## 1. 에듀테크 시장 현황

### 1.1 국내 시장 규모

| 연도 | 시장 규모 | 성장률 |
|------|-----------|--------|
| 2024년 | 8.5조원 | - |
| 2025년 | 10.2조원 | 20% |
| 2026년 | 12.2조원 | 20% |
| 2028년 | 17.6조원 | 연평균 20% |

### 1.2 정부 정책 방향

#### 교육부 2026년 주요 정책
- **AI 디지털교과서:** 2025년부터 단계적 도입
- **AI 중점학교:** 2026년 1,000개교 → 2028년 2,000개교 확대
- **K-교육 AI:** 수업·행정 범용 AI 개발
- **에듀테크 소프트랩:** 9개소로 확대

#### 유티텍 기회 요인
```
┌─────────────────────────────────────────────────┐
│           정부 정책과 유티텍 매칭               │
├─────────────────────────────────────────────────┤
│  AI 디지털교과서 ←→ UTTEC Edu AI 학습 기능     │
│  AI 중점학교    ←→ IoT 교구재 + 코딩 교육      │
│  에듀테크 소프트랩 ←→ 소프트랩 입주 추진        │
│  K-에듀테크 수출 ←→ 일본 수출 경험 활용        │
└─────────────────────────────────────────────────┘
```

## 2. 유티텍 에듀테크 포트폴리오

### 2.1 현재 보유 시스템

| 시스템 | 대상 | 핵심 기능 |
|--------|------|-----------|
| **UTTEC Edu** | 학부형, 사회초년생, 진로전환자 | AI 진로교육, 8개 트랙 |
| **C/ESP32 교육** | 개발자 지망생 | 마이크로컨트롤러 프로그래밍 |
| **자격시험 가이드** | 자격증 준비생 | 시험 대비 학습 |

### 2.2 시스템별 상세

#### UTTEC Edu (https://uttec-edu.duckdns.org/)

**교육 트랙:**
```
┌─────────────────────────────────────────────────┐
│  1. 대학진학 코스 (영어·수학·탐구)              │
│  2. 회화 코스                                   │
│  3. 학부형 트랙                                 │
│  4. 사회초년생 트랙                             │
│  5. 코딩 전문가                                 │
│  6. 교사/교육자 (30일 과정)                     │
│  7. 진로전환자                                  │
│  8. 무료 체험                                   │
└─────────────────────────────────────────────────┘
```

**학습 프로세스 (5단계):**
```
성향 파악 → 탐색 → 집중 학습 → 결과물 제작 → 진로 결정
(MBTI)    (3~5개)  (초→중→고급)  (포트폴리오)   (실무적용)
```

### 4.1 단계별 전략

```
┌─────────────────────────────────────────────────┐

## 5. K-에듀테크 해외수출 전략

### 5.1 해외 시장 기회

```
