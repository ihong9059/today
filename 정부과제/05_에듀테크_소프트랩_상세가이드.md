# 에듀테크 소프트랩 상세 가이드

## 1. 에듀테크 소프트랩이란?

### 정의
에듀테크 소프트랩은 **학교 현장과 에듀테크 기업을 연결**하여 공교육에 적합한 에듀테크가 개발되고 활용될 수 있도록 지원하는 **교육부 지정 전문기관**입니다.

### 운영 주체
| 구분 | 기관 |
|------|------|
| **주관** | 교육부 |
| **전담기관** | 한국교육학술정보원(KERIS) |
| **운영** | 전국 9개 지역 소프트랩 |

### 사업 목적
```
┌─────────────────────────────────────────────────────────────┐
│                    에듀테크 소프트랩 목적                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   교육 현장 ←──────── 연결 ────────→ 에듀테크 기업          │
│      │                                      │               │
│      ▼                                      ▼               │
│   • 품질 검증                         • 제품 개선           │
│   • 실증 테스트                       • 현장 피드백         │
│   • 교사 의견 수렴                    • 공교육 적합성 확보  │
│                                                             │
│                         ↓                                   │
│              공교육 맞춤형 에듀테크 생태계 조성              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 실증 프로그램 운영

| 프로그램 | 내용 | 대상 |
|----------|------|------|
| **품질 검증** | 교사가 에듀테크 품질 및 공교육 적합성 검증 | 교사 + 기업 |
| **현장 테스트** | 실제 학교 현장에서 제품/서비스 테스트 | 학생 + 교사 |
| **피드백 수집** | 사용자 피드백 수집 및 개선 방향 제시 | 기업 |
| **개선 협력** | 기업과 교사가 함께 제품 개선 | 교사 + 기업 |

## 4. 기업 참여 방법

### 4.1 실증 참여 기업 모집

#### 모집 시기
- **연 1~2회** 정기 모집 (지역별 상이)
- KERIS 및 각 지역 소프트랩 공고 확인 필요

#### 자격 요건 (일반)
| 요건 | 내용 |
|------|------|
| 사업자 | 국내 법인 또는 개인사업자 |
| 제품/서비스 | 초중고 대상 교육용 에듀테크 솔루션 보유 |
| 세금 | 국세 및 지방세 완납 |
| 결격사유 | 부정당업자 제재 중이 아닐 것 |

#### 경기도 SW미래채움 사업 예시 (2025년)
| 항목 | 내용 |
|------|------|
| **자격** | 경기도 내 에듀테크 기업 (본사/연구소/공장 소재) |
| **대상 제품** | AI·SW 교육 목적의 제품 및 서비스 |
| **지원 내용** | 교육환경 매칭, 실증 수행지원, 피드백 보고서, 교구 구입 지원 |
| **신청** | 이메일 접수 (hongyh@gbsa.or.kr) |
| **문의** | 경기경제과학진흥원 031-259-6083 |

| **공교육 보급 지원** | 검증 후 학교 보급·확산 지원 |

## 7. 유티텍 참여 전략

### 7.1 참여 적합성 분석

| 평가 항목 | 유티텍 현황 | 적합성 |
|-----------|-------------|--------|
