# 서울대학교 2025학년도 vs 2026학년도 입시요강 비교

> **작성일**: 2026년 1월 16일
> **출처**: [서울대학교 입학본부](https://admission.snu.ac.kr), [진학사](https://www.jinhak.com), [넥스트플레이](https://www.nextplay.kr)

---

## 전체 기조

2026학년도 서울대 입시는 **2025학년도와 큰 틀에서 유사**하게 유지됩니다.
서울대는 2028대입개편 전인 2027학년도까지 비슷한 전형구조를 유지할 것이라 밝혔습니다.

## 주요 변경사항

### 1. 간호학과 면접 방식 변경

| 항목 | 2025학년도 | 2026학년도 |
|------|-----------|-----------|
| 면접 유형 | 제시문 면접 | **MMI형 면접** |
| 면접 구성 | 제시문 기반 | 상황/제시문 기반 + 서류 기반 |
| 면접 장소 | 단일 면접실 | **복수의 면접실** |
| 소요시간 | - | **30분 내외** |
| 평가 내용 | - | 간호학 전공 자질, 적성, 인성 |

> 의예과, 치의학과, 수의예과와 동일한 MMI 형식으로 변경

---

### 2. 식품영양학과 지원자격 확대

| 항목 | 2025학년도 | 2026학년도 |
|------|-----------|-----------|
| 수능 수학 | 미적분 또는 기하 **필수** | **제한 없음** |
| 수능 탐구 | 과학탐구 **필수** | **사회탐구 가능** |
| 면접 제시문 | 자연계열 | 인문/자연 **택1** |
| 지원 가능 계열 | 자연계열만 | **문·이과 모두 가능** |

> 생활과학대학 전체가 문·이과 구분 없이 지원 가능한 모집단위가 됨

---

### 3. 학부/학과 명칭 및 조직 변경

| 구분 | 2025학년도 | 2026학년도 |
|------|-----------|-----------|
| 공과대학 | 건설환경공학부 | **건설환경도시공학부** |
| 농업생명과학대학 | - | **스마트시스템과학과** 신설 |
| 학부대학 | 광역 모집단위 신설 (36명) | 유지 |
| 자유전공학부 | 독립 운영 | **학부대학 편입** |

---

### 4. 수시 기회균형전형 음악대학

| 항목 | 2025학년도 | 2026학년도 |
|------|-----------|-----------|
| 1단계 선발배수 | 2배수 | **3배수** |

---

### 5. 학교폭력 반영

| 항목 | 2025학년도 | 2026학년도 |
|------|-----------|-----------|
| 반영 방식 | - | 모든 전형에서 학교폭력 관련 기재사항 **정성평가** |
| 반영 단계 | - | 서류평가에 반영 |

## 유지 사항 (변경 없음)

### 수시모집 전형구조

| 전형 | 전형방법 | 비고 |
|------|---------|------|
| **지역균형** | 1단계 서류 100% (3배수) → 2단계 1단계70%+면접30% | 수능최저 적용 |
| **일반** | 1단계 서류 100% (2배수) → 2단계 1단계50%+면접50% | 수능최저 미적용 (일부 제외) |
| **기회균형** | 1단계 서류 100% (2배수) → 2단계 1단계70%+면접30% | 수능최저 미적용 |

### 수능최저학력기준 (지역균형)

| 항목 | 기준 |
|------|------|
| 적용 영역 | 국어, 수학, 영어, 탐구 |
| 기준 | **3개 영역 등급합 7 이내** |

### 정시모집 전형구조

| 전형 | 전형방법 |
|------|---------|
| **지역균형** | 수능 60% + 교과평가 40% |
| **일반** | 수능 100% (의/치/수 적성·인성면접) |

### 수능 반영방법

| 영역 | 반영비율 | 산출방식 |
|------|---------|---------|
| 국어 | 33.3% | 표준점수 |
| 수학 | 40% | 표준점수 × 1.2 |
| 탐구 | 26.7% | 표준점수 합 × 0.8 |
| 영어/한국사 | - | 감점 |

## 2026학년도 대입 전반의 변화 (참고)

| 변화 요인 | 내용 |
|---------|------|
| 고3 재학생 인원 | 증가 |
| 의대 정원 | 회귀 (증원분 일부 조정) |
| 무전공 확대 | 전국적 확대 추세 |
| 수능 지정과목 | 폐지 추세 → 사탐 선택 증가 |
| 학교폭력 | 대입 필수 반영 |

## 결론

2026학년도 서울대 입시의 **핵심 변경사항**:

1. **간호학과**: 제시문 면접 → MMI형 면접
2. **식품영양학과**: 문·이과 모두 지원 가능
3. **컴퓨터공학부/산업공학과**: 첨단분야 정원 증원
4. **건설환경공학부**: 명칭 변경 (건설환경도시공학부)
5. **학교폭력**: 전 전형 서류평가 반영

> 전체적인 전형구조는 2025학년도와 동일하게 유지됩니다.
