# ESP32-DevKitC 회로 연결 분석서

**문서 정보**
- 회로도 파일: esp32wroom_250806
- 버전: V1.0
- 작성일: 2025-08-06
- 설계 도구: EasyEDA

---

## 1. 개요

이 회로는 ESP32-DevKitC (38핀)를 중심으로 다양한 주변 장치를 연결한 IoT 개발 보드입니다.

### 주요 구성 요소
| 구분 | 부품 | 수량 | 용도 |
|------|------|------|------|
| MCU | ESP32-DevKitC (U15) | 1 | 메인 컨트롤러 |
| 디스플레이 | OLED (U9) | 1 | 정보 표시 |
| 센서 | AHT20 (U10) | 1 | 온습도 측정 |
| LED | XL-1004SURD (U6, U7, U8) | 3 | 상태 표시 |
| 부저 | Buzzer (BUZ1, BUZ2) | 2 | 알림음/멜로디 |
| 스위치 | TS-1088 (SW1) | 1 | 사용자 입력 |
| 무선통신 | LoRa 모듈 (H2) | 1 | 장거리 무선 통신 |

## 2. ESP32-DevKitC 핀 연결 상세

### 2.1 I2C 버스 (OLED + AHT20 센서)

```
ESP32-DevKitC          OLED (U9)           AHT20 (U10)
    │                     │                    │
IO21 (SDA) ──────────────┼────────────────────┤
    │        ┌─[R5 10K]──┤                    │
    │        │  (Pull-up) │                    │
   VCC ──────┘            │                    │
    │                     │                    │
IO22 (SCL) ──────────────┼────────────────────┤
    │        ┌─[R6 10K]──┤                    │
    │        │  (Pull-up) │                    │
   VCC ──────┘            │                    │
    │                     │                    │
   VCC ───────────────────┼────────────────────┤
   GND ───────────────────┴────────────────────┘
```

| ESP32 핀 | 신호명 | 연결 장치 | 비고 |
|----------|--------|-----------|------|
| IO21 (Pin 25) | SDA | U9, U10 | I2C 데이터, 10K 풀업 |
| IO22 (Pin 22) | SCL | U9, U10 | I2C 클럭, 10K 풀업 |

**특이사항**: OLED와 AHT20이 동일 I2C 버스 공유 (서로 다른 I2C 주소 사용)

---

### 2.2 LED 출력 (3색 LED)

```
ESP32-DevKitC              LED
    │
IO25 ────[R1 100Ω]────►|──── GND   (RED, U6)
IO26 ────[R2 100Ω]────►|──── GND   (YELLOW, U7)
IO27 ────[R3 100Ω]────►|──── GND   (BLUE, U8)
```

| ESP32 핀 | 신호명 | LED 색상 | 저항 | 부품번호 |
|----------|--------|----------|------|----------|
| IO25 (Pin 9) | RED | 빨강 | R1 (100Ω) | U6 |
| IO26 (Pin 10) | YELLOW | 노랑 | R2 (100Ω) | U7 |
| IO27 (Pin 11) | BLUE | 파랑 | R3 (100Ω) | U8 |

**LED 사양**: XL-1004SURD (SMD LED)

---

### 2.3 부저 출력 (2채널)

#### BUZ1 - BEEP (직접 구동)
```
   VCC
    │
   (+)
  [BUZ1]
   (-)
    │
IO14 (BEEP)
```

#### BUZ2 - MELODY (트랜지스터 구동)
```
   VCC
    │
   (+)
  [BUZ2]
   (-)
    │
    C (콜렉터)
   [Q1 BCX56]
    E (이미터)──── GND
    B (베이스)
    │
 [R4 10K]
    │
IO33 (MELODY)
```

| ESP32 핀 | 신호명 | 부저 | 구동 방식 | 용도 |
|----------|--------|------|-----------|------|
| IO14 (Pin 12) | BEEP | BUZ1 | 직접 구동 | 단순 비프음 |
| IO33 (Pin 8) | MELODY | BUZ2 | Q1 트랜지스터 | PWM 멜로디 |

**트랜지스터**: BCX56 (NPN, SOT-89 패키지)

---

### 2.4 스위치 입력

```
   VCC
    │
  [내부 풀업]
    │
IO32 (SWITCH) ────┬──── SW1 ──── GND
                  │
                [C1 100nF]
                  │
                 GND
```

| ESP32 핀 | 신호명 | 부품 | 비고 |
|----------|--------|------|------|
| IO32 (Pin 7) | SWITCH | SW1 | 100nF 디바운싱 캐패시터 |

**스위치 사양**: TS-1088-AR02016 (택트 스위치)
**동작**: 버튼 누름 시 LOW, 평상시 HIGH (풀업)

---

### 2.5 LoRa 모듈 (7핀 커넥터)

```
ESP32-DevKitC              LoRa Module (H2)
    │                           │
IO34 (AUX) ─────────────────── AUX (Pin 1)
IO17 (TXD2) ────────────────── RXD (Pin 2)  ← ESP TX → LoRa RX
IO16 (RXD2) ────────────────── TXD (Pin 3)  ← ESP RX ← LoRa TX
IO15 (M0) ──────────────────── M0  (Pin 4)
IO4  (M1) ──────────────────── M1  (Pin 5)
VCC ────────────────────────── VCC (Pin 6)
GND ────────────────────────── GND (Pin 7)
```

| ESP32 핀 | 신호명 | LoRa 핀 | 기능 |
|----------|--------|---------|------|
| IO34 (Pin 5) | AUX | Pin 1 | 모듈 상태 표시 |
| IO17 (Pin 30) | TXD2 | Pin 2 | UART2 TX (데이터 송신) |
| IO16 (Pin 31) | RXD2 | Pin 3 | UART2 RX (데이터 수신) |
| IO15 (Pin 35) | M0 | Pin 4 | 모드 설정 비트 0 |
| IO4 (Pin 32) | M1 | Pin 5 | 모드 설정 비트 1 |

**LoRa 모드 설정표**:
| M1 | M0 | 모드 | 설명 |
|----|----|----|------|
| 0 | 0 | 일반 모드 | 정상 송수신 |
| 0 | 1 | Wake-Up 모드 | 저전력 수신 |
| 1 | 0 | 절전 모드 | 설정 변경 가능 |
| 1 | 1 | Sleep 모드 | 최저 전력 |

---

### 2.6 SPI 인터페이스 (확장용)

```
ESP32-DevKitC              SPI 장치 (미연결)
    │
IO23 (MOSI) ─────────────── MOSI (Master Out)
IO19 (MISO) ─────────────── MISO (Master In)
IO18 (SCK)  ─────────────── SCK  (클럭)
IO5  (SS)   ─────────────── SS   (Chip Select)
```

| ESP32 핀 | 신호명 | 기능 |
|----------|--------|------|
| IO23 (Pin 21) | MOSI | Master Out Slave In |
| IO19 (Pin 27) | MISO | Master In Slave Out |
| IO18 (Pin 28) | SCK | SPI 클럭 |
| IO5 (Pin 29) | SS | Slave Select |

**참고**: SPI 핀은 외부 확장용으로 노출되어 있음
