## Part 1: 프로그래밍이란? (3분)

### 장면 3: 프로그래밍 개념 설명

**화면 구성**:
- 로봇과 사람이 대화하는 귀여운 애니메이션
- 말풍선으로 명령과 동작 표현

**나레이션**:
```
프로그래밍이 뭘까요?

쉽게 말하면, 컴퓨터에게 할 일을 알려주는 거예요!

여러분이 강아지한테 "앉아!", "손!", "기다려!" 라고 말하면
강아지가 그 명령을 따르죠?

프로그래밍도 똑같아요!

우리가 컴퓨터에게
"LED를 켜!", "잠깐 기다려!", "LED를 꺼!" 라고 말하면
컴퓨터가 그대로 따라 하는 거예요.

단, 컴퓨터는 우리말을 못 알아들으니까
컴퓨터가 이해할 수 있는 특별한 언어로 말해줘야 해요.
그게 바로 프로그래밍 언어예요!
```

### 장면 4: 우리말 vs 프로그래밍 언어

**화면 구성**:
- 화면 분할: 왼쪽에 우리말, 오른쪽에 코드
- 대응하는 내용을 선으로 연결하는 애니메이션

```
┌─────────────────────┬─────────────────────────┐
│      우리말         │    프로그래밍 언어       │
├─────────────────────┼─────────────────────────┤
│  "LED를 켜줘!"      │  digitalWrite(8, HIGH); │
│  "1초 기다려!"      │  delay(1000);           │
│  "LED를 꺼줘!"      │  digitalWrite(8, LOW);  │
└─────────────────────┴─────────────────────────┘
```

**나레이션**:
```
자, 이렇게 우리말과 프로그래밍 언어를 비교해볼까요?

"LED를 켜줘!"는 영어로 digitalWrite(8, HIGH)라고 써요.
digital은 '디지털', Write는 '쓰다'라는 뜻이에요.
8번 핀에 HIGH, 즉 '켜짐'을 쓴다는 의미예요.

"1초 기다려!"는 delay(1000)이라고 써요.
delay는 '지연하다', 1000은 1000밀리초, 즉 1초예요.

"LED를 꺼줘!"는 digitalWrite(8, LOW)예요.
LOW는 '꺼짐'이라는 뜻이죠.

어때요? 생각보다 어렵지 않죠?
```

## Part 2: Arduino 프로그램 구조 이해하기 (4분)

### 장면 5: 프로그램의 두 부분

**화면 구성**:
- Arduino IDE 화면
- setup()과 loop() 영역을 다른 색으로 구분
- 각 영역에 캐릭터 아이콘 (시작 깃발, 반복 화살표)

**나레이션**:
```
Arduino 프로그램은 크게 두 부분으로 나뉘어요.

첫 번째는 setup() 함수예요.
setup은 '설정'이라는 뜻이에요.
이 부분은 프로그램이 시작할 때 딱 한 번만 실행돼요.
처음에 필요한 준비를 여기서 해요.

예를 들면, "8번 핀을 출력으로 사용할 거야!"라고
알려주는 거죠.
```

### 장면 6: setup과 loop 비유

**화면 구성**:
- 아침 일과 애니메이션
- setup: 알람 끄기, 세수하기 (한 번만)
- loop: 숨쉬기, 눈 깜빡이기 (계속 반복)

**나레이션**:
```
두 번째는 loop() 함수예요.
loop는 '반복'이라는 뜻이에요.
이 부분은 계속해서 무한 반복돼요!

우리 일상으로 비유해볼까요?

아침에 일어나서 알람을 끄고, 세수하는 건
한 번만 하죠? 이게 setup이에요.

하지만 숨 쉬기, 눈 깜빡이기는
하루 종일 계속 반복하잖아요? 이게 loop예요!

LED 깜빡이기도 마찬가지예요.
처음에 핀을 설정하는 건 한 번만 하고,
LED를 켜고 끄는 건 계속 반복하는 거예요!
```

### 장면 7: 기본 코드 구조

**화면 구성**:
- Arduino IDE에서 기본 코드 구조 표시
- 각 부분을 하이라이트하며 설명

```cpp
void setup() {
  // 한 번만 실행되는 코드
}

void loop() {
  // 계속 반복되는 코드
}
```

**나레이션**:
```
자, 이제 Arduino IDE를 열어볼까요?

기본 구조는 이렇게 생겼어요.

void setup() 그리고 중괄호.
이 중괄호 안에 처음 한 번 실행할 코드를 넣어요.

void loop() 그리고 중괄호.
이 중괄호 안에 반복할 코드를 넣어요.

void는 "아무것도 돌려주지 않는다"는 뜻인데,
지금은 그냥 "이건 함수다!"라고 표시하는 거라고
이해하면 돼요.

중요한 건 setup과 loop! 이 두 가지만 기억하세요!
```

### 장면 9: setup 함수 작성

**화면 구성**:
- 코드를 한 줄씩 타이핑하는 화면
- 각 줄마다 말풍선으로 설명

**나레이션**:
```
자, 이제 코드를 작성해볼게요.
천천히 따라 해보세요!

먼저 setup 함수 안에 이 코드를 넣어요.

pinMode, 괄호 열고, 8, 쉼표, OUTPUT, 괄호 닫고, 세미콜론.

pinMode(8, OUTPUT);

이게 무슨 뜻일까요?

pinMode는 '핀 모드'라는 뜻이에요.
8은 GPIO 8번 핀을 말해요.
ESP32C3 보드에는 작은 LED가 하나 있는데,
이 LED가 8번 핀에 연결되어 있어요.

OUTPUT은 '출력'이라는 뜻이에요.
"8번 핀을 출력용으로 사용할 거야!"라고
컴퓨터에게 알려주는 거예요.

마지막 세미콜론은 문장의 마침표 같은 거예요.
모든 명령문 끝에는 세미콜론을 붙여야 해요!
```

### 장면 10: loop 함수 작성 (켜기)

**화면 구성**:
- loop 함수 안에 코드 입력
- LED가 켜지는 애니메이션 삽입

**나레이션**:
```
이제 loop 함수 안에 반복할 코드를 넣어볼게요.

첫 번째 줄!
digitalWrite(8, HIGH);

digitalWrite는 '디지털 신호를 쓴다'는 뜻이에요.
8번 핀에 HIGH, 즉 높은 신호를 보내요.
높은 신호가 가면 LED가 켜져요!

두 번째 줄!
delay(1000);

delay는 '지연'이라는 뜻이에요.
1000은 1000밀리초, 즉 1초예요.
이 명령을 만나면 1초 동안 아무것도 안 하고 기다려요.

왜 기다릴까요?
기다리지 않으면 너무 빨라서 깜빡이는 게 안 보여요!
```

```
켜고, 1초 기다리고, 끄고, 1초 기다리고,

이렇게 무한 반복! LED가 깜빡깜빡!
```

### 장면 12: 전체 코드 확인

**화면 구성**:
- 완성된 전체 코드 표시
- 주석 추가 설명

```cpp
// 내장 LED 깜빡이기
void setup() {
  pinMode(8, OUTPUT);  // 8번 핀을 출력으로 설정
}

void loop() {
  digitalWrite(8, HIGH);  // LED 켜기
  delay(1000);            // 1초 기다리기
  digitalWrite(8, LOW);   // LED 끄기
  delay(1000);            // 1초 기다리기
}
```

**나레이션**:
```
자, 완성된 코드를 한번 볼까요?

보이시나요? 아주 간단하죠?

setup에서 8번 핀을 출력으로 설정하고,
loop에서 켜고, 기다리고, 끄고, 기다리고를 반복해요.

참, 코드 앞에 슬래시 두 개 (//)가 보이죠?
이건 '주석'이라고 해요.
컴퓨터는 이 부분을 무시하고,
우리가 메모하는 용도로 쓰는 거예요.

나중에 코드를 다시 볼 때
"아, 이 부분이 LED 켜는 부분이구나!"
하고 알 수 있도록 적어두는 거예요.

코드를 다 작성했으면, 한번 저장해주세요!
Ctrl + S를 누르거나,
파일 메뉴에서 저장을 클릭하면 돼요.
```

## Part 5: 코드 수정하며 실험하기 (5분)

### 장면 16: 깜빡이는 속도 바꾸기

**화면 구성**:
- delay 값을 500으로 수정하는 화면
- 더 빠르게 깜빡이는 LED

**나레이션**:
```
여기서 끝내면 아쉽죠?
코드를 조금 바꿔서 실험해볼까요?

delay(1000)에서 1000을 500으로 바꿔보세요.
1000밀리초는 1초, 500밀리초는 0.5초, 즉 반 초예요.

두 개의 delay 값을 모두 500으로 바꾸고,
다시 업로드 버튼을 눌러보세요!

어때요? LED가 더 빠르게 깜빡이죠?

이번엔 2000으로 바꿔볼까요?
2000밀리초는 2초예요.

와, 이번엔 천천히 깜빡이네요!

이렇게 숫자만 바꿔도 동작이 달라져요.
```

| 폰트 | 나눔스퀘어라운드 Bold |

### 코드 표시 스타일

| 구분 | 설정 |
|------|------|
| 폰트 | D2Coding 또는 Consolas |
| 배경 | 진한 회색 (#1E1E1E) |
| 키워드 색상 | 파란색 (void, int 등) |
| 문자열 색상 | 주황색 |
| 주석 색상 | 초록색 |

### 주요 키워드 강조

다음 단어가 나올 때 자막에 하이라이트:
- **프로그래밍** (노란색)
- **setup** (파란색)
- **loop** (초록색)
- **pinMode** (보라색)
- **digitalWrite** (주황색)
- **delay** (빨간색)

### 실습 장면 촬영

1. **손 클로즈업**: 키보드 타이핑 장면

4. **와이드 샷**: 학생 시점 전체 화면
