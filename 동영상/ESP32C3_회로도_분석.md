## 1. 회로 개요

이 회로는 **ESP32C3-SuperMini** 마이크로컨트롤러를 중심으로 다양한 센서와 출력 장치를 연결한 교육용 IoT 보드입니다.

### 1.1 주요 부품 목록

| 부품 | 모델명 | 용도 |
|------|--------|------|
| U1 | ESP32C3-SuperMini | 메인 컨트롤러 (WiFi/BLE 내장) |
| U2 | AHT20 | 온습도 센서 (I2C) |
| U3 | OLED | 디스플레이 (I2C) |
| U4 | WS2812 | RGB LED (NeoPixel) |
| SW1 | TS-1088-AR02016 | 택트 스위치 (버튼) |
| BUZZER1 | 2.7kHz | 피에조 부저 (스피커) |
| Q1 | BCX56 | NPN 트랜지스터 (부저 드라이버) |

## 3. 디바이스별 연결 관계

### 3.1 AHT20 온습도 센서 (U2)

```
┌─────────────────────────────────────────────────────────┐
│                    AHT20 연결도                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   AHT20 (U2)              ESP32C3                       │
│   ┌─────────┐            ┌─────────┐                   │
│   │ 1 (VCC) │────────────│ 3V3     │  전원 (3.3V)      │
│   │ 2 (GND) │────────────│ GND     │  접지             │
│   │ 3 (SCL) │──┬─[10K]──│ GPIO6   │  I2C 클럭         │
│   │ 4 (SDA) │──┼─[10K]──│ GPIO5   │  I2C 데이터       │
│   └─────────┘  │         └─────────┘                   │
│                └──── VCC (풀업 저항)                    │
│                                                         │
│   통신 방식: I2C                                        │
│   I2C 주소: 0x38                                        │
│   풀업 저항: R1, R2 = 10KΩ                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| AHT20 핀 | ESP32C3 핀 | 기능 |
|----------|------------|------|
| Pin 1 (VCC) | 3V3 | 전원 공급 |
| Pin 2 (GND) | GND | 접지 |
| Pin 3 (SCL) | GPIO6 | I2C 클럭 |
| Pin 4 (SDA) | GPIO5 | I2C 데이터 |

**특징:**
- I2C 통신 (주소: 0x38)
- 온도 측정 범위: -40°C ~ 85°C
- 습도 측정 범위: 0% ~ 100% RH
- R1, R2 (10KΩ): I2C 풀업 저항

### 3.2 OLED 디스플레이 (U3)

```
┌─────────────────────────────────────────────────────────┐
│                    OLED 연결도                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   OLED (U3)               ESP32C3                       │
│   ┌─────────┐            ┌─────────┐                   │
│   │ 1 (VCC) │────────────│ 3V3     │  전원 (3.3V)      │
│   │ 2 (GND) │────────────│ GND     │  접지             │
│   │ 3 (SCL) │────────────│ GPIO6   │  I2C 클럭         │
│   │ 4 (SDA) │────────────│ GPIO5   │  I2C 데이터       │
│   └─────────┘            └─────────┘                   │
│                                                         │
│   통신 방식: I2C                                        │
│   I2C 주소: 0x3C (일반적)                               │
│   해상도: 128x64 또는 128x32                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| OLED 핀 | ESP32C3 핀 | 기능 |
|---------|------------|------|
| Pin 1 (VCC) | 3V3 | 전원 공급 |
| Pin 2 (GND) | GND | 접지 |
| Pin 3 (SCL) | GPIO6 | I2C 클럭 (AHT20과 공유) |
| Pin 4 (SDA) | GPIO5 | I2C 데이터 (AHT20과 공유) |

**특징:**
- I2C 통신 (주소: 0x3C)
- AHT20과 I2C 버스 공유 (동일한 SCL, SDA 사용)
- 화면에 온도, 습도 등 정보 표시 가능

### 3.3 WS2812 RGB LED (U4)

```
┌─────────────────────────────────────────────────────────┐
│                   WS2812 연결도                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   WS2812 (U4)             ESP32C3                       │
│   ┌─────────┐            ┌─────────┐                   │
│   │ 1 (VDD) │────────────│ 5V      │  전원 (5V)        │
│   │ 2 (DOUT)│            │         │  (다음 LED로)     │
│   │ 3 (VSS) │────────────│ GND     │  접지             │
│   │ 4 (DIN) │────────────│ GPIO4   │  데이터 입력      │
│   └─────────┘            └─────────┘                   │
│                                                         │
│   통신 방식: 단일 와이어 (NeoPixel 프로토콜)            │
│   전원: 5V (RGB LED는 5V 필요)                          │
│   데이터: GPIO4 (DIN)                                   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| WS2812 핀 | ESP32C3 핀 | 기능 |
|-----------|------------|------|
| Pin 1 (VDD) | 5V | 전원 공급 (5V) |
| Pin 2 (DOUT) | - | 데이터 출력 (체인 연결용) |
| Pin 3 (VSS) | GND | 접지 |
| Pin 4 (DIN) | GPIO4 | 데이터 입력 |

**특징:**
- 단일 와이어 통신 (NeoPixel 프로토콜)
- RGB 풀컬러 제어 가능 (16,777,216 색상)
- 여러 개 체인 연결 가능 (DOUT → 다음 LED의 DIN)

### 3.4 택트 스위치 (SW1)

```
┌─────────────────────────────────────────────────────────┐
│                   스위치 연결도                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    VCC (3.3V)                           │
│                      │                                  │
│                    [100nF] C1 (노이즈 필터)             │
│                      │                                  │
│   SW1 ──────┬────────┴─────────── GPIO3 (SWITCH)       │
│             │                                           │
│            GND                                          │
│                                                         │
│   동작: 버튼 누름 → LOW, 버튼 놓음 → HIGH (풀업)        │
│   디바운싱: C1 (100nF) 커패시터                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 스위치 핀 | ESP32C3 핀 | 기능 |
|-----------|------------|------|
| Pin 1 | GPIO3 | 스위치 입력 (SWITCH) |
| Pin 2 | GND | 접지 |

**특징:**
- 내부 또는 외부 풀업 저항 사용
- C1 (100nF): 디바운싱 커패시터 (채터링 방지)
- 버튼 누르면 LOW, 놓으면 HIGH

### 3.5 부저/스피커 (BUZZER1)

```
┌─────────────────────────────────────────────────────────┐
│                   부저 연결도                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    VCC (3.3V/5V)                        │
│                      │                                  │
│                   BUZZER1                               │
│                   (2.7kHz)                              │
│                      │                                  │
│                      C (Collector)                      │
│                    ┌─┴─┐                               │
│                    │Q1 │ BCX56 (NPN)                   │
│                    │   │                               │
│                    └─┬─┘                               │
│           R3 (10K)   B (Base)                          │
│              │       │                                  │
│   GPIO2 ─────┴───────┘                                  │
│   (SPEAKER)          E (Emitter)                        │
│                      │                                  │
│                     GND                                 │
│                                                         │
│   GPIO2 HIGH → Q1 ON → 부저 울림                        │
│   GPIO2 LOW  → Q1 OFF → 부저 정지                       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 부품 | 연결 | 기능 |
|------|------|------|
| GPIO2 | R3 (10K) → Q1 Base | PWM 신호 출력 |
| Q1 (BCX56) | 트랜지스터 | 부저 전류 스위칭 |
| BUZZER1 | VCC ↔ Q1 Collector | 소리 출력 |

**특징:**
- NPN 트랜지스터(BCX56)로 부저 구동
- GPIO2에서 PWM 신호로 다양한 음 생성 가능
- 공진 주파수: 2.7kHz

### 3.6 테스트 포인트 (TP1~TP8)

| 테스트 포인트 | 연결 신호 | 용도 |
|--------------|----------|------|
| TP1 | VCC | 전원 확인 |
| TP2 | GND | 접지 확인 |
| TP3 | TX (GPIO21) | UART 송신 |
| TP4 | RX (GPIO20) | UART 수신 |
| TP5 | SCK (GPIO7) | SPI 클럭 |
| TP6 | MISO (GPIO8) | SPI 데이터 입력 |
| TP7 | MOSI (GPIO9) | SPI 데이터 출력 |
| TP8 | SS (GPIO10) | SPI 칩 선택 |
