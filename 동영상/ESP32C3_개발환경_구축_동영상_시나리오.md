- Preferences 창
- 추가 보드 매니저 URLs 입력란

>

#### 화면에 표시할 URL

```
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
```

> 이 주소는 ESP32 보드 정보가 들어있는 곳이에요.
>
> 주소를 붙여넣었으면 **OK** 버튼을 클릭해주세요.
>
> 그리고 Preferences 창도 **OK**를 눌러서 닫아주세요.

#### 화면 동작
1. File → Preferences 클릭

4. OK 클릭 (두 번)

#### 화면에 표시할 코드

```cpp
// ESP32C3 테스트 프로그램
// LED를 1초마다 깜빡이기

void setup() {
  pinMode(8, OUTPUT);  // GPIO8을 출력으로 설정
  Serial.begin(115200);
  Serial.println("ESP32C3 준비 완료!");
}

void loop() {
  digitalWrite(8, HIGH);  // LED 켜기
  Serial.println("LED ON");
  delay(1000);  // 1초 기다리기

  digitalWrite(8, LOW);   // LED 끄기
  Serial.println("LED OFF");
  delay(1000);  // 1초 기다리기
}
```

#### 나레이션 (계속)

> 이 코드는 ESP32C3 보드에 있는 **LED를 1초마다 깜빡이게** 하는 프로그램이에요.
>
> `setup()` 함수는 처음 한 번만 실행되고,
>
> `loop()` 함수는 계속 반복 실행돼요.
>
> 코드를 다 입력했으면, 이제 보드에 업로드해볼게요!
