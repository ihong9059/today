ESP32 개발환경 설치하기 - 나레이션 스크립트

=== 오프닝 ===

안녕하세요! 오늘은 ESP32 보드로 프로그래밍을 시작하기 위한 준비를 해볼 거예요.

이 영상을 끝까지 따라하면, 여러분도 이렇게 LED를 깜빡이게 만들 수 있어요!

자, 그럼 시작해볼까요?

=== 1장. 준비물 확인 ===

먼저, 필요한 준비물을 확인해볼게요.

오늘 필요한 것은 세 가지예요.

첫 번째, ESP32 개발 보드입니다.

두 번째, USB 케이블이에요. 그런데 여기서 중요한 게 있어요!

USB 케이블에는 '데이터 케이블'과 '충전 전용 케이블'이 있어요.

충전 전용 케이블은 데이터 전송이 안 돼서, 꼭 데이터 케이블을 사용해야 해요.

연결했을 때 컴퓨터에서 '띵동' 소리가 나면 데이터 케이블이에요!

세 번째, Windows 컴퓨터입니다. Windows 10이나 11이면 좋아요.

=== 2장. USB 드라이버 설치 ===

이제 USB 드라이버를 설치할 거예요. 드라이버는 컴퓨터와 보드가 대화할 수 있게 해주는 통역사 같은 거예요.

인터넷 브라우저를 열어주세요.

주소창에 이 주소를 입력해요. silabs.com... 영상 설명란에도 링크를 넣어둘게요.

사이트에 들어왔어요. 여기서 Downloads 탭을 클릭해주세요.

그리고 'CP210x Universal Windows Driver'를 찾아서...

다운로드 버튼을 클릭해요!

다운로드가 완료될 때까지 잠시 기다려주세요.

다운로드 폴더를 열어볼게요.

다운로드된 파일을 오른쪽 클릭하고, '압축 풀기'를 선택해요.

압축을 풀어줍니다.

압축이 풀린 폴더를 열어요.

여기서 'CP210xVCPInstaller_x64.exe' 파일을 찾아주세요.

이 파일을 더블클릭해서 실행해요.

이런 창이 나오면 '예'를 클릭해주세요.

'다음'을 클릭하고...

설치가 완료됐어요! '마침'을 클릭해주세요.

설치가 잘 됐는지 확인해볼까요? 키보드에서 Windows 키와 X를 동시에 눌러주세요.

'장치 관리자'를 클릭해요.

'포트' 항목을 펼쳐보면... 'Silicon Labs CP210x'가 보이면 성공이에요!

=== 3장. Arduino IDE 설치 ===

이제 프로그램을 만들 도구, Arduino IDE를 설치할 거예요.

브라우저에서 arduino.cc를 입력해주세요.

Arduino 공식 사이트에 들어왔어요.

위쪽 메뉴에서 'SOFTWARE'를 클릭해요.

여기서 Windows 버전을 다운로드할 거예요.

'Windows 10 and newer, 64 bit'를 클릭해주세요.

이런 화면이 나오면 'JUST DOWNLOAD'를 클릭하면 돼요.

다운로드가 시작됐어요. 파일 크기가 좀 크니까 잠시 기다려주세요.

다운로드하는 동안 팁 하나! Arduino IDE는 전 세계 많은 사람들이 사용하는 무료 프로그램이에요.

다운로드가 완료됐어요!

다운로드된 파일을 더블클릭해서 실행해요.

'예'를 클릭해주세요.

'I Agree'를 클릭해요. 이건 '동의합니다'라는 뜻이에요.

그냥 'Next'를 클릭하면 돼요.

설치 위치도 그대로 두고 'Install'을 클릭해요.

설치가 진행되고 있어요. 2-3분 정도 걸릴 수 있어요.

설치되는 동안 팁! Arduino IDE에서는 C언어와 비슷한 코드를 작성해요.

설치가 완료됐어요! 'Finish'를 클릭하면 Arduino IDE가 실행돼요.

이런 창이 나오면 '액세스 허용'을 클릭해주세요.

짜잔! Arduino IDE가 실행됐어요!

=== 4장. ESP32 보드 추가 ===

Arduino IDE에 ESP32 보드를 추가해줘야 해요. 조금만 더 힘내요!

위쪽 메뉴에서 'File'을 클릭하고, 'Preferences'를 선택해요.

설정 창이 열렸어요.

아래쪽에 'Additional boards manager URLs'라는 긴 칸이 있어요. 여기를 클릭해주세요.

이 주소를 복사해서 붙여넣어요. 영상 설명란에 있으니까 거기서 복사하세요!

'OK'를 클릭해요.

이제 'Tools' 메뉴를 클릭하고, 'Board'를 선택한 다음, 'Boards Manager'를 클릭해요.

보드 매니저 창이 열렸어요.

검색창에 'esp32'를 입력해주세요.

'esp32 by Espressif Systems'가 나왔어요!

'INSTALL' 버튼을 클릭해요.

설치가 진행되고 있어요. 파일이 좀 크니까 3-5분 정도 걸릴 수 있어요.

잠시 기다리는 동안... ESP32는 Wi-Fi와 블루투스가 내장된 아주 강력한 보드예요!

'INSTALLED'라고 표시되면 설치 완료! 창을 닫아주세요.

=== 5장. 보드 연결 및 테스트 ===

드디어 마지막 단계예요! 보드를 연결하고 테스트해볼게요.

USB 케이블로 ESP32 보드를 컴퓨터에 연결해주세요.

보드에 빨간 불이 들어오면 전원이 잘 들어온 거예요!

컴퓨터에서 '띵동' 소리가 들리죠? 보드가 인식된 거예요.

Arduino IDE로 돌아와서, 보드를 설정할 거예요.

'Tools' 메뉴에서 'Board'를 클릭하고, 'esp32'를 펼쳐주세요.

'ESP32 Dev Module'을 선택해요.

다시 'Tools' 메뉴에서 'Port'를 클릭해요.

'COM'으로 시작하는 포트를 선택해주세요. 저는 COM3이네요.

이제 테스트 프로그램을 열어볼게요. 'File', 'Examples', '01.Basics', 'Blink'를 선택해요.

LED를 깜빡이게 하는 코드가 열렸어요!

여기서 한 가지만 바꿔줄 거예요. LED_BUILTIN 숫자를 2에서 25로 바꿔주세요.

25번이 우리 보드의 빨간 LED 핀이에요.

이제 이 화살표 버튼을 클릭해서 보드에 프로그램을 보낼 거예요!

클릭!

먼저 코드를 확인하고...

'Connecting'이라고 나오고, 업로드가 진행돼요.

'Done uploading'이라고 나오면 성공!

보세요! 빨간 LED가 깜빡이고 있어요!

1초마다 켜졌다 꺼졌다 하고 있죠?

=== 문제 해결 팁 ===

혹시 안 되는 분들을 위한 팁이에요!

포트가 안 보이면? 드라이버를 다시 설치하거나, 다른 USB 케이블로 바꿔보세요.

업로드할 때 'Connecting'에서 멈추면? 보드의 'BOOT' 버튼을 꾹 눌러보세요.

여기 이 작은 버튼이에요. 업로드할 때 이걸 누르고 있으면 돼요.

LED가 안 깜빡이면? 코드에서 숫자가 25로 잘 바뀌었는지 확인해보세요.
