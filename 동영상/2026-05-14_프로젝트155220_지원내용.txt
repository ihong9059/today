============================================================
프로젝트 핵심 이해
============================================================

본 프로젝트는 1호기의 PC(C#) 기반 제어의 한계(유지보수·확장
어려움)를 산업 표준 PLC + SCADA로 전환하여 해결하는 2호기
전면 재개발 사업입니다. 핵심 가치는 다음 4가지로 정리됩니다.

(1) **산업 안정성** — PC(C#)의 OS/드라이버 의존성과 단일 PC
    장애 위험 → PLC의 결정론적 사이클·전원 단속 견고성으로 전환
    → IP 등급 / EMI / EMC 환경에서 24/7 무인 운영 신뢰성 확보

(2) **운영자 편의성 (SCADA HMI)** — 비숙련 작업자가 터치
    패널로 Recipe 선택 / 알람 인지 / 데이터 조회를 직관적으로
    수행 → 생산 라인 가동률 향상

(3) **Recipe 관리** — 제품 종류별(용기 사이즈/두께 기준/측정
    포인트) 파라미터 셋을 PLC + SCADA 통합 DB에 저장/호출 →
    품종 변경 시 1-Click 전환

(4) **데이터 로깅 신뢰성** — PC 기반 파일 시스템의 손상 위험 →
    SCADA 표준 히스토리언(Historian) + 시계열 DB 저장 → 품질
    트레이스 + 검사 성적서 자동 생성

당사는 PLC/Modbus/서보 모션 양산 + 데이터 로깅 인프라 + 산업
양산 EMI/EMC 대응 경험으로 위 4가지 가치를 모두 직접 구현
가능합니다.

============================================================
지원 사유
============================================================

안녕하세요. 임베디드 + 공장자동화 + AI 2인 팀의 홍광선/임호균
입니다.

본 프로젝트는 저희 팀의 핵심 양산 영역과 정조준 매칭됩니다.
다음 네 가지 자산이 직접 연결됩니다.

(1) **PLC + Modbus 양산 — 산업 표준 검증** — STM32F756 기반
    RS-485 Modbus RTU 컴프레서 밸브 컨트롤러를 양산 판매 중이며
    KC 인증을 보유합니다. 또한 Raspberry Pi CM4 + EtherCAT
    MFC 컨트롤러를 산업 양산 중입니다. 본 프로젝트의 PLC 선정
    후보인 LS/Cimon/Mitsubishi/Siemens는 모두 Modbus(또는 자사
    프로토콜)로 데이터 송수신하며, 저희가 보유한 산업 통신
    실전 경험으로 1주 내 PLC 환경 적응이 가능합니다.

(2) **공장자동화 + 모터 제어 38년 (협업자 임호균)** — 협업자
    임호균은 삼성전자 Video/Motor Controller Board, AuthenTec
    (미국) ARM CPU 설계 + ASIC, QuickLogic(미국) FPGA, 대한전선
    WINDER CONTROLLER(CAN/RS485 + 모터 제어)를 거쳐 공장자동화
    분야 38년 경력입니다. 본 프로젝트의 서보 모션 제어 + 전장
    배선 + 산업 패널 설계가 그의 양산 도메인입니다.

(3) **데이터 로깅 + Recipe 관리 + 대시보드 인프라** — 스마트
    팩토리 센서 모니터링 라이브(uttec-sensor.duckdns.org)를
    실시간 운영하여 분체/파쇄/혼합 산업 모니터링을 검증한
    자산을 보유합니다. FastAPI + PostgreSQL + TimescaleDB +
    Three.js 3D 대시보드로 SCADA 상용 패키지(Cimon/iX/WinCC)의
    Historian + Recipe + 알람 기능을 동등 수준으로 구현 가능
    하며, 클라이언트 선호 시 상용 SCADA(Cimon Ultimate Access
    또는 iX Developer)에도 즉시 적응 가능합니다.

(4) **2호기 재개발 패턴 — 일본 양산 1차/2차 경험** — 일본
    하네다공항 자전거주차장 1차 500대 양산 → 2023년 나고야
    사카에역 3,300대 2차 양산의 리비전 사이클을 직접 수행한
    경험이 있습니다. 1호기 학습(C# 한계 분석)을 2호기 PLC/SCADA
    개선으로 전환하는 작업의 통제 위험을 사전에 식별·관리하는
    노하우를 보유합니다.

저희가 인지하는 SCADA 상용 패키지 직접 양산 경험은 없음을
사전 명시드립니다. 다만 SCADA의 핵심 5요소(Tag Server / HMI /
Recipe / Historian / Alarm)는 모두 저희 라이브 모니터링 시스템에
구현·운영 중이며, Cimon/iX/WinCC의 표준 인터페이스(OPC UA,
Modbus TCP, SQL Historian)는 동일 패턴으로 1주 내 적응 가능
합니다. 클라이언트가 선호하는 SCADA 플랫폼을 알려주시면 사전
학습 + 라이선스 확보 후 본격 착수 가능합니다.
