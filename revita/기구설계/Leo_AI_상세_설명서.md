# Leo AI 상세 설명서

*작성일: 2026-04-11*

---

## 1. Leo AI란?

**Leo AI**는 기계 엔지니어를 위해 만들어진 **세계 최초의 엔지니어링 설계 AI 코파일럿**이다.
텍스트, 스케치, 사양서, CAD 제약 조건을 입력하면 **DFMA 최적화된 3D CAD 모델(어셈블리 포함)**을 생성해준다.

- **개발사**: Leo AI (이스라엘 스타트업)
- **공식 사이트**: [https://www.getleo.ai](https://www.getleo.ai)
- **앱 접속**: [https://app.getleo.ai](https://app.getleo.ai)
- **핵심 기술**: Large Mechanical Model (LMM) — 기계 부품/어셈블리/엔지니어링 로직 전용 AI 모델

> 엔지니어링 시간·비용을 최대 **70% 절감**, 엔지니어 1인당 주 **5~8시간 절약** 보고

## 2. 핵심 기능

### 2-1. 텍스트 → 3D CAD 생성

자연어로 설계 의도를 입력하면 3D 모델을 자동 생성한다.

```
입력 예시:
  "500kg 하중을 지지하는 서스펜션 시스템,
   이 섀시에 맞게, 사내 부품 라이브러리 사용"

  → Leo AI가 어셈블리 전체를 자동 생성
```

| 입력 방식 | 설명 |
|----------|------|
| 텍스트 프롬프트 | 자연어로 부품/어셈블리 설명 |
| 스케치 | 손 그림, 러프 스케치 업로드 |
| 사양서/스펙 | 기술 문서 기반 설계 |
| CAD 제약 조건 | 기존 CAD에서 조건 지정 |

### 2-2. 부품 검색 (Part Search)

기존 설계 자산에서 필요한 부품을 자연어로 검색한다.

```
예시: "M6 스테인리스 스프링 와셔"
  → 사내 라이브러리 + 표준 부품 DB에서 즉시 검색
  → 형상, 재질, 기능, 용도별 랭킹
  → 10초 이내 결과 반환
```

**기존 방식과 비교:**
- 기존: 파일명/폴더 뒤져서 수동 검색 → 못 찾으면 다시 설계 (주 8.3시간 낭비)
- Leo AI: 자연어 설명 → 기하학적 유사도까지 분석하여 즉시 검색

### 2-3. 엔지니어링 계산

스트레스 분석, 재료 선정 등 엔지니어링 계산을 AI가 수행한다.

```
예시: "AL6061 브래킷, 500N 하중, 안전계수 2.0 기준 최소 두께는?"
  → 적절한 공식 자동 선택
  → 계산 수행
  → 신뢰할 수 있는 출처 인용 (100만+ 엔지니어링 소스)
```

### 2-4. 설계 검증 (Design Validation)

설계 기준 위반, 과거 이슈 등을 자동으로 체크한다.

```
  → 조직의 설계 표준과 비교
  → 과거 설계 이력에서 유사 실패 사례 경고
  → 제조 전 잠재적 문제 플래그
  → 재작업·후기 변경 감소
```

### 2-5. 표준 부품 검색

벤더 카탈로그에서 규격 부품을 자연어로 찾는다.

```
예시: "내경 30mm, 외경 55mm, SUS304 볼 베어링"
  → McMaster-Carr, Misumi 등 벤더 DB에서 매칭
  → 스펙 비교 + 호환성 확인
```

## 3. 기술 구조

### 3-1. Large Mechanical Model (LMM)

Leo AI의 핵심은 **LMM (대규모 기계 모델)**이다. 일반 LLM(ChatGPT 등)과 다르다.

```
┌─────────────────────────────────────────────────┐
│          Large Mechanical Model (LMM)           │
│                                                 │
│  학습 데이터:                                    │
│  ├─ 100만+ 엔지니어링 소스                       │
│  ├─ 고객 CAD 모델 및 문서                        │
│  └─ 기계 부품/어셈블리/설계 로직                  │
│                                                 │
│  이해 능력:                                      │
│  ├─ CAD 형상 (피처, 치수, 메이트)                 │
│  ├─ 공차, 관계, 제약 조건                        │
│  ├─ 제조 공정 및 DFM 규칙                        │
│  └─ 조직의 설계 표준/이력                        │
│                                                 │
│  정확도: 엔지니어링 쿼리 96%                      │
└─────────────────────────────────────────────────┘
```

### 3-2. 지원 CAD 파일 형식

| 형식 | 지원 여부 |
|------|---------|
| SOLIDWORKS (.sldprt, .sldasm) | ✅ |
| STEP (.step, .stp) | ✅ |
| IGES (.iges, .igs) | ✅ |
| CATIA | ✅ |
| Autodesk Inventor | ✅ |
| Onshape | ✅ |

### 3-3. PLM/PDM 연동

| 시스템 | 지원 |
|--------|------|
| SOLIDWORKS PDM | ✅ |
| Autodesk Vault | ✅ |
| PTC Windchill | ✅ |
| Siemens Teamcenter | ✅ |

## 4. 출력물 특성

| 항목 | 설명 |
|------|------|
| 출력 형태 | **메쉬 기반 3D 모델** (컨셉 단계용) |
| 편집 | CAD 도구로 내보내 후 정밀 편집 필요 |
| 어셈블리 | ✅ 전체 어셈블리 생성 가능 (업계 최초, 특허 보유) |
| 목적 | CAD 소프트웨어를 대체하는 것이 아닌, **컨셉→초기 모델링을 가속**하는 도구 |

> **참고**: Leo AI는 메쉬(컨셉 형상)를 생성하고, 이를 SOLIDWORKS 등 CAD에서 열어 파라메트릭 모델로 정밀화하는 워크플로우이다.

## 5. 설치 및 사용 방법

### 5-1. 방법 A: 브라우저 (설치 불필요)

가장 빠른 시작 방법. 설치 없이 웹 브라우저에서 바로 사용.

```
1. https://app.getleo.ai 접속

2. 회원가입
   - 이메일 입력
   - 비밀번호 설정
   - 회사/직함 정보 입력 (선택)

3. 14일 무료 체험 시작
   - 신용카드 없이 시작 가능

4. 로그인 후 바로 사용
   - 채팅창에 설계 의도 입력
   - CAD 파일 업로드하여 분석
   - 부품 검색, 계산 등 활용
```

### 5-2. 방법 B: 데스크톱 앱 설치 (CAD 연동)

SOLIDWORKS 등 CAD 도구와 직접 연동하려면 데스크톱 앱을 설치한다.

```
1. https://www.getleo.ai/getting-started 접속

2. "Download Leo" 클릭
   - Windows용 .exe 파일 다운로드

3. 다운로드된 .exe 파일 실행
   - 설치 마법사 진행
   - CAD 도구 자동 감지 및 통합

4. 설치 완료 후
   - SOLIDWORKS / Inventor 등 CAD 실행
   - Leo AI 패널이 CAD 내에 나타남
   - CAD 작업 중 바로 Leo AI 활용 가능
```

### 5-3. 첫 사용 가이드

#### Step 1: 부품 생성해보기

```
채팅창에 입력:
  "Create a mounting bracket for M8 bolts,
   4 holes, 100x60x5mm, aluminum"

  → Leo AI가 3D 브래킷 모델 생성
  → 결과물 확인 및 다운로드
```

#### Step 2: 기존 CAD 파일 분석

```
1. CAD 파일 업로드 (드래그 앤 드롭)
   - .sldprt, .step 등

2. 질문하기:
   "이 부품의 예상 무게는?"
   "이 형상에서 응력 집중이 우려되는 부분은?"
   "DFM 관점에서 개선할 점은?"

   → Leo AI가 형상을 분석하여 답변
```

#### Step 3: 유사 부품 검색

```
채팅창에 입력:
  "이 브래킷과 비슷한 기존 설계가 있나?"

  → 사내 PDM/Vault에서 기하학적으로 유사한 부품 검색
  → 형상 유사도 순위로 결과 표시
```

#### Step 4: 어셈블리 생성

```
채팅창에 입력:
  "Design a gripper mechanism with
   2 fingers, pneumatic actuator,
   max grip force 50N"

  → 전체 어셈블리 (그리퍼+핑거+액추에이터) 생성
  → STEP으로 내보내기 가능
```

## 6. 사용 팁

### 좋은 프롬프트 작성법

```
❌ 나쁜 예:
  "브래킷 만들어줘"

✅ 좋은 예:
  "L자형 마운팅 브래킷, AL6061, 두께 3mm,
   M6 체결홀 4개, 50N 하중 지지,
   CNC 밀링 가공, 모서리 R2 필렛"
```

| 포함하면 좋은 정보 | 예시 |
|------------------|------|
| 형태/크기 | L자형, 100x60x40mm |
| 재질 | AL6061, SUS304, ABS |
| 체결 | M6 볼트홀 4개, 스냅핏 |
| 하중/조건 | 500N, 진동 환경, IP67 |
| 제조 방법 | CNC, 사출성형, 판금 |
| 마감 | 아노다이징, 도장, 도금 |

### 워크플로우 권장 순서

```
1. Leo AI로 컨셉 생성 (텍스트 → 3D 메쉬)
     ↓
2. STEP으로 내보내기
     ↓
3. SOLIDWORKS/Fusion에서 파라메트릭 모델로 정밀화
     ↓
4. Leo AI로 DFM 검토 요청
     ↓
5. Leo AI로 유사 기존 설계 검색 → 재사용 가능한 부품 확인
     ↓
6. 최종 도면/CAM 작업
```
