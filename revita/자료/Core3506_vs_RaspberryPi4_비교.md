# Luckfox Core3506 vs Raspberry Pi 4 성능 비교

## 하드웨어 사양 비교

| 항목 | Luckfox Core3506 | Raspberry Pi 4 Model B |
|------|------------------|------------------------|
| **SoC** | Rockchip RK3506B | Broadcom BCM2711 |
| **공정** | 22nm | 28nm |
| **CPU 코어** | Triple-core ARM Cortex-A7 | Quad-core ARM Cortex-A72 |
| **CPU 아키텍처** | ARMv7 (32-bit) | ARMv8-A (64-bit) |
| **CPU 클럭** | 1.2GHz | 1.5GHz (1.8GHz 오버클럭 가능) |
| **추가 프로세서** | Cortex-M0 MCU 내장 | VideoCore VI GPU |
| **RAM** | 512MB DDR3L | 1GB / 2GB / 4GB / 8GB LPDDR4 |
| **스토리지** | 8GB eMMC (Core35060808) | microSD / USB Boot |
| **보드 크기** | 32mm × 32mm | 85mm × 56mm |

## CPU 성능 비교

### 아키텍처 차이

| 구분 | Cortex-A7 (Core3506) | Cortex-A72 (Pi 4) |
|------|---------------------|-------------------|
| **세대** | 2011년 (구세대) | 2015년 (신세대) |
| **파이프라인** | 8단계 In-order | 15단계 Out-of-order |
| **IPC (클럭당 명령어)** | ~1.0 | ~2.5~3.0 |
| **DMIPS/MHz** | 1.9 | 4.7 |
| **SIMD** | NEON (128-bit) | NEON (128-bit) |

### 예상 성능 비교 (벤치마크 추정)

| 벤치마크 | Core3506 (추정) | Raspberry Pi 4 | 성능 비율 |
|----------|-----------------|----------------|-----------|
| **Dhrystone (DMIPS)** | ~6,840 | ~28,200 | **1 : 4.1** |
| **CoreMark (싱글)** | ~2,400 | ~8,000 | **1 : 3.3** |
| **CoreMark (멀티)** | ~7,200 | ~32,000 | **1 : 4.4** |
| **Sysbench CPU** | ~400 | ~1,800 | **1 : 4.5** |

> **계산 근거**:
> - Core3506: 3코어 × 1.2GHz × 1.9 DMIPS/MHz = 6,840 DMIPS
> - Pi 4: 4코어 × 1.5GHz × 4.7 DMIPS/MHz = 28,200 DMIPS

## 결론

### Core3506 선택 권장 상황
- 극소형 폼팩터 필수 (32×32mm)
- 저전력/배터리 구동 필요
- 듀얼 100Mbps 이더넷 필요
- 단순 제어/IoT 용도
- 대량 생산 시 비용 절감

### Raspberry Pi 4 선택 권장 상황
- 범용 컴퓨팅 성능 필요
- 영상/오디오 처리
- 충분한 RAM 필요 (2GB 이상)
- WiFi/Bluetooth 필요
- 기가비트 이더넷 필요
- 풍부한 커뮤니티/소프트웨어 지원 필요

---

**핵심 요약**: Raspberry Pi 4는 Core3506 대비 **CPU 성능 약 4배**, **메모리 대역폭 약 2.7배** 우수하지만, Core3506은 **크기 1/7**, **전력 1/4**, **가격 1/2** 수준으로 임베디드/IoT 특화 용도에 적합합니다.
