# Luckfox Core3506 vs Raspberry Pi 3 B+ 성능 비교

## 하드웨어 사양 비교

| 항목 | Luckfox Core3506 | Raspberry Pi 3 B+ |
|------|------------------|-------------------|
| **SoC** | Rockchip RK3506B | Broadcom BCM2837B0 |
| **공정** | 22nm | 40nm |
| **CPU 코어** | Triple-core ARM Cortex-A7 | Quad-core ARM Cortex-A53 |
| **CPU 아키텍처** | ARMv7 (32-bit) | ARMv8-A (64-bit) |
| **CPU 클럭** | 1.2GHz | 1.4GHz |
| **추가 프로세서** | Cortex-M0 MCU 내장 | VideoCore IV GPU |
| **RAM** | 512MB DDR3L | 1GB LPDDR2 |
| **스토리지** | 8GB eMMC (Core35060808) | microSD |
| **보드 크기** | 32mm × 32mm | 85mm × 56mm |

## 결론

### Core3506 선택 권장 상황
- 극소형 폼팩터 필수 (32×32mm)
- 저전력/배터리 구동 필요
- **듀얼 이더넷 필요 (라우터/브릿지)**
- 빠른 부팅/안정적 스토리지 필요 (eMMC)
- 단순 제어/IoT 용도
- 유선 네트워크만 사용

### Raspberry Pi 3 B+ 선택 권장 상황
- WiFi/Bluetooth 무선 연결 필수
- 더 많은 RAM 필요 (1GB)
- HDMI 디스플레이 출력 필요
- 4개 USB 포트 필요
- 풍부한 커뮤니티/소프트웨어 지원 필요
- PoE 전원 공급 필요
