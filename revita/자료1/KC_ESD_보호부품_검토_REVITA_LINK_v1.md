# REVITA_LINK_v1 ESD 보호 부품 검토 보고서

> **작성일**: 2026-04-03
> **대상 회로**: REVITA_LINK_v1 main_board (EasyEDA, V1.0)
> **배터리**: EVE IFR40135 LiFePO4 4S (12.8V 공칭, 14.6V 최대 충전)
> **MCU**: RAK4630 (nRF52840 + SX1262), 3.3V 동작
> **적용 규격**: KN 61000-4-2 (IEC 61000-4-2) 정전기 방전 내성 시험

---

## 1. 검토 대상 부품

### 1.1 SS14 — Schottky Barrier Rectifier

| 항목 | 값 |
|------|-----|
| **종류** | 쇼트키 정류 다이오드 (ESD 부품 아님) |
| **역방향 내전압 (VR)** | 40V |
| **순방향 전류 (IF)** | 1A |
| **순방향 전압 (VF)** | 0.50V @ 1A |
| **서지 전류 (IFSM)** | 25~40A (8.3ms) |
| **접합 커패시턴스** | ~60pF |
| **패키지** | SMA (DO-214AC) |

### 1.2 SMAJ16A — TVS Diode (단방향)

| 항목 | 값 |
|------|-----|
| **종류** | TVS 다이오드 (서지/ESD 보호용) |
| **동작 전압 (VWM)** | 16V |
| **항복 전압 (VBR)** | 17.8V ~ 19.7V |
| **클램핑 전압 (VC)** | 26V @ IPP=15.4A |
| **피크 펄스 전력** | 400W (10/1000μs) |
| **응답 시간** | < 1ns |
| **역방향 누설** | < 1μA @ VWM |
| **패키지** | SMA (DO-214AC) |

## 3. 외부 단자별 ESD 보호 검토

### 3.1 전원 커넥터 (POWER_PORT) — BAT1 단자

| 항목 | 판정 | 상세 |
|------|:----:|------|
| **SMAJ16A 적용** | **적합** | VWM(16V) > 최대 충전전압(14.6V), 정상 동작 시 오동작 없음 |
| **클램핑 레벨** | **주의** | VC=26V는 후단 12V 레귤레이터의 절대 최대 정격 이내인지 확인 필요 |
| **SS14 적용** | **적합 (역할 한정)** | 역접속 보호 또는 다이오드 OR-ing 용도로는 적합. ESD 보호 목적이면 부적합 |

### 3.2 Solar 입력 단자

| 항목 | 판정 | 상세 |
|------|:----:|------|
| **SMAJ16A 적용** | **조건부** | 솔라 패널 OCV가 16V 이하면 적합. 18V 패널이면 상시 도통 위험 → SMAJ18A로 교체 필요 |
| **SS14 적용** | **적합 (역류 방지)** | 야간 배터리→패널 역류 차단용으로 적합 |

### 3.3 RS485 단자 (A, B, GND)

| 항목 | 판정 | 상세 |
|------|:----:|------|
| **SMAJ16A 적용** | **부적합** | RS485 신호 레벨 대비 VWM(16V)이 너무 높음. 17.8V 이상에서야 클램핑 시작 → RS485 트랜시버(보통 절대 최대 정격 ±15V)가 먼저 손상될 수 있음 |
| **SS14 적용** | **부적합** | 쇼트키 정류 다이오드는 ESD 보호 기능 없음. VR=40V까지 도통하지 않아 보호 불가 |

### 3.4 모터 제어 단자 (X/Y축, 12V 측)

| 항목 | 판정 | 상세 |
|------|:----:|------|
| **SMAJ16A 적용** | **적합** | 12V 구동 라인에 적합 |
| **SS14 적용** | **적합 (프리휠링)** | 모터/인덕티브 부하의 역기전력 보호용으로 적합한 사용법 |

### 3.5 MCU 3.3V 신호 라인 (DIO_X, DIO_Y, VIB_SENSE, BTN 등)

| 항목 | 판정 | 상세 |
|------|:----:|------|
| **SMAJ16A 적용** | **부적합** | VWM(16V) >> 3.3V. 클램핑 전압 26V에서 nRF52840 GPIO(절대 최대 ~3.6V)는 이미 파괴됨 |
| **SS14 적용** | **부적합** | VR=40V, 보호 기능 없음 |

## 4. 종합 판정

```
                    외부 단자
                       │
                  ┌────┴────┐
                  │ SMAJ16A │ ← 16V TVS
                  └────┬────┘
                       │
              ┌────────┴────────┐
              │                 │
         12V 전원 라인        3.3V 신호 라인
              │                 │
         ✅ 적합              ❌ 부적합
         (VWM > 14.6V)       (클램핑 26V >> 3.6V 절대정격)
                               → MCU 파괴 위험
```

### 4.1 판정 요약

| 적용 위치 | SS14 | SMAJ16A | 종합 판정 |
|----------|:----:|:-------:|:---------:|
| 전원 (BAT) 단자 | ✅ 역접속 보호 | ✅ 서지 보호 | **적합** |
| Solar 입력 | ✅ 역류 차단 | ⚠️ 패널 OCV 확인 | **조건부** |
| RS485 (A, B) | ❌ | ❌ 전압 불일치 | **부적합** |
| 모터 12V 라인 | ✅ 프리휠링 | ✅ 서지 보호 | **적합** |
| 3.3V 신호 라인 | ❌ | ❌ 전압 불일치 | **부적합** |
| ST-Link 디버그 | ❌ | ❌ | **미보호** |

### 4.2 핵심 문제

| # | 문제 | 심각도 |
|---|------|:------:|
| 1 | **SS14는 ESD 보호 부품이 아님** — 정류/역접속 보호 용도로는 적합하나, ESD 클램핑 기능 없음 | **높음** |
| 2 | **SMAJ16A(16V)는 3.3V 라인에 부적합** — 클램핑 전압 26V에서 MCU GPIO(3.6V max)는 이미 파괴됨 | **높음** |
| 3 | **RS485 라인 보호 부재** — RS485 트랜시버 절대 최대 정격(±15V) 대비 SMAJ16A 클램핑(26V)이 너무 높음 | **높음** |
| 4 | **외부 노출 3.3V 신호 라인 ESD 미보호** — DIO_X, DIO_Y, VIB_SENSE 등 외부 커넥터 연결 신호 | **중간** |

## 5. 개선 권장사항

### 5.1 인터페이스별 권장 TVS 부품

| 적용 위치 | 현재 부품 | 권장 부품 | VWM | VC | 사유 |
|----------|----------|----------|:---:|:---:|------|
| **전원 (BAT)** | SMAJ16A | SMAJ16A (유지) | 16V | 26V | 14.6V 시스템에 적합 |
| **Solar 입력** | SMAJ16A | SMAJ18A | 18V | 29.2V | 18V OCV 패널 대응 |
| **RS485 (A, B)** | 없음/부적합 | **SM712** 또는 **PESD1CAN** | 7V/12V | ~24V | RS485 전용 양방향 TVS |
| **3.3V 신호 라인** | 없음 | **PRTR5V0U2X** 또는 **ESD5Z3.3T1G** | 3.3V~5V | ~9V | 저전압 고속 ESD 보호 |
| **디버그 포트** | 없음 | **USBLC6-2** | 5V | ~8V | 저용량 ESD 어레이 |

### 5.2 SS14 사용법 정리

SS14는 ESD 보호가 아닌 아래 용도로 사용하는 것이 적합합니다:

| 용도 | 적합 여부 |
|------|:---------:|
| 역접속(역극성) 보호 | ✅ |
| 다이오드 OR-ing | ✅ |
| 프리휠링 다이오드 (모터) | ✅ |
| 솔라 역류 방지 | ✅ |
| **ESD 보호** | **❌ 부적합** |

### 5.3 KC ESD 시험 대비 회로 수정 권장

```
[외부 커넥터]──┬──[TVS to GND]──[GND]     ← TVS는 커넥터에 최대한 가깝게
               │
              [직렬 저항 100Ω~1kΩ]         ← 선택적: ESD 전류 제한
               │
              [IC 입력핀]
```

1. **모든 외부 노출 단자**에 해당 전압 레벨에 맞는 TVS 배치
2. TVS는 **커넥터 바로 옆**에 배치 (PCB 배선 최소화)
3. 3.3V 신호 라인은 **직렬 저항 + TVS** 이중 보호 권장
4. **GND plane 면적 최대화** — 배터리 제품의 기생 커패시턴스 확보 (ESD 귀환 경로)

## 6. 결론

| 항목 | 판정 |
|------|------|
| **SS14** | ESD 보호 부품으로 사용되었다면 **부적합**. 정류/역접속 보호 용도라면 적합 |
| **SMAJ16A** | **12V 전원 라인에만 적합**. 3.3V 신호 라인과 RS485에는 클램핑 전압이 너무 높아 보호 불가 |
| **KC ESD 시험 통과 가능성** | 현재 상태로는 **3.3V 신호 라인 및 RS485 단자에서 불합격 위험** |
| **필수 조치** | RS485 전용 TVS(SM712) 추가, 3.3V 라인 전용 TVS(PRTR5V0U2X) 추가 |
