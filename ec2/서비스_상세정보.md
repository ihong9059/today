```bash

# 빌드만 (재시작 없이)
ssh uttec-ec2 "cd ~/cert-guide && npm run build"
```

### 데이터베이스 (PostgreSQL)

```bash
# PostgreSQL 접속
ssh uttec-ec2 "psql -U sensoruser -d sensordb"

# 테이블 확인
ssh uttec-ec2 "psql -U sensoruser -d sensordb -c '\dt'"

# 데이터 조회
ssh uttec-ec2 "psql -U sensoruser -d sensordb -c 'SELECT COUNT(*) FROM sensor_data'"
```

### 배포 명령어


### 이미지 관리


## 3. PostgreSQL 데이터베이스

### 접속 정보

| 항목 | 값 |
|------|-----|
| 호스트 | localhost |
| 포트 | 5432 |
| 데이터베이스 | sensordb |
| 사용자 | sensoruser |

### 테이블 구조

```sql
-- sensor_data 테이블
CREATE TABLE sensor_data (
    id SERIAL PRIMARY KEY,
    timestamp BIGINT,
    device VARCHAR(100),
    data JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);
```

### 자주 사용하는 쿼리

```bash
# 최근 데이터 10건
ssh uttec-ec2 "psql -U sensoruser -d sensordb -c 'SELECT * FROM sensor_data ORDER BY id DESC LIMIT 10'"

# 디바이스별 데이터 수
ssh uttec-ec2 "psql -U sensoruser -d sensordb -c 'SELECT device, COUNT(*) FROM sensor_data GROUP BY device'"

# 오래된 데이터 삭제 (7일 이상)
ssh uttec-ec2 "psql -U sensoruser -d sensordb -c \"DELETE FROM sensor_data WHERE created_at < NOW() - INTERVAL '7 days'\""
```

## 4. PM2 관리

### 현재 서비스 상태

```bash
ssh uttec-ec2 "pm2 list"
```

예상 출력:
```
┌────┬───────────────────┬─────────┬──────────┬────────┐
│ id │ name              │ mode    │ status   │ cpu    │
├────┼───────────────────┼─────────┼──────────┼────────┤
│ 0  │ cert-guide        │ fork    │ online   │ 0%     │
│ 1  │ sensor-monitor    │ fork    │ online   │ 0%     │
└────┴───────────────────┴─────────┴──────────┴────────┘
```

### PM2 설정 저장/복원

```bash
# 현재 상태 저장
ssh uttec-ec2 "pm2 save"

# 서버 재부팅 후 자동 시작 설정
ssh uttec-ec2 "pm2 startup"

# 로그 파일 위치
# ~/.pm2/logs/cert-guide-out.log
# ~/.pm2/logs/cert-guide-error.log
# ~/.pm2/logs/sensor-monitor-out.log
# ~/.pm2/logs/sensor-monitor-error.log
```
