오늘 할일 목록을 보여주는 스킬입니다.

작업 절차:
1. 오늘 날짜를 YYYY-MM-DD 형식으로 확인
2. 작업보고서/ 폴더에서 오늘 날짜의 작업보고서 파일 읽기
   - 파일 형식: YYYY-MM-DD_작업보고서.md
   - 예: 2026-02-09_작업보고서.md
3. "## 오늘 할일" 섹션에서 할일 테이블 추출
4. 테이블을 아래 형식으로 정리하여 출력:

출력 형식:
```
## 오늘 할일 (YYYY-MM-DD)

### 미완료 (⬜)
| 순번 | 할일 |
|:----:|------|
| 1 | 할일 내용 |
| 2 | 할일 내용 |

### 완료 (✅)
| 순번 | 할일 |
|:----:|------|
| 3 | 완료된 할일 |

---
총 N개 중 M개 완료 (진행률: X%)
```

주의사항:
- 파일이 없으면 "오늘 날짜의 작업보고서가 없습니다" 메시지 출력
- 미완료(⬜)와 완료(✅)를 분리하여 표시
- 진행률을 백분율로 계산하여 표시
