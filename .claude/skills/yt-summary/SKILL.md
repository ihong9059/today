# YouTube 영상 요약 Skill

YouTube URL을 받아 영상 내용을 분석하고, 유투브/ 폴더에 **상세본** 마크다운 파일을 생성합니다.

## 사용법
```
/yt-summary [YouTube URL]
```

## 출력 파일

| 파일 유형 | 파일명 규칙 | 용도 |
|-----------|-------------|------|
| 상세본 | `[제목]_상세.md` | 구간별 분석, 구체적 사례, 인용구, 심층 분석 |

## 실행 절차

### 1단계: 영상 정보 추출
yt-dlp를 사용하여 영상 메타데이터를 추출합니다:
```bash
yt-dlp --print "%(title)s" --print "%(channel)s" --print "%(duration_string)s" --print "%(description)s" "URL"
```

### 2단계: 자막 추출
한국어 자막을 다운로드합니다 (없으면 자동 생성 자막 사용):
```bash
yt-dlp --write-auto-subs --sub-lang ko --skip-download -o "유투브/transcript" "URL"
```

### 3단계: 자막 파일 읽기
다운로드된 VTT 파일을 읽어 전체 내용을 파악합니다.
- 파일 위치: 유투브/transcript.ko.vtt
- 긴 영상은 offset/limit 파라미터로 나눠서 읽기

### 4단계: 내용 분석
자막 내용을 기반으로 다음을 분석합니다:
- 핵심 주제 파악
- 주요 내용 정리
- 숫자/데이터 기반 인사이트 추출
- 구간별 내용 정리
- **구체적 사례 및 에피소드 추출**
- **주요 인용구 전체 수집**

### 5단계: 카테고리 폴더 결정 (2026-06-13 도입)

유투브/ 폴더는 **주제별 카테고리 폴더**로 운영한다. 상세본은 루트가 아니라 반드시 해당 카테고리 폴더 안에 생성한다.

**절차:**
1. `유투브/` 하위 폴더 목록을 조회한다 (`.obsidian` 제외)
2. 영상 주제가 기존 카테고리에 해당하면 그 폴더를 사용
3. 해당하는 폴더가 없으면 **새 카테고리 폴더를 신설** — 번호 연속 규칙 `NN_주제명` (예: `05_로컬LLM_온디바이스` 다음은 `06_...`). 시리즈물은 시리즈명 폴더 허용 (예: `3Blue1Brown_딥러닝_시리즈`)
4. 분류가 모호하면 파일 생성 전 사용자에게 카테고리를 질문한다

**현재 카테고리 (2026-06-13 기준 — 실제 폴더 목록이 항상 우선):**

| 폴더 | 주제 |
|---|---|
| `01_LLM위키_지식관리` | LLM 위키·옵시디언·개인 RAG·지식 시스템 |
| `02_Claude_Code` | Claude Code 사용법·스킬·플러그인·워크플로우 |
| `03_AI_영상제작` | AI 영상·이미지 생성 제작 |
| `04_AI_이론` | AI 이론·온톨로지·산업 분석 (팔란티어 등) |
| `05_로컬LLM_온디바이스` | 로컬 LLM 실행·하드웨어·오프라인 환경 (OpenClaude·Ollama·MLX 등) |
| `3Blue1Brown_딥러닝_시리즈` | 3B1B 딥러닝 시리즈 (시리즈 전용) |

### 6단계: 상세본 파일 생성
결정된 카테고리 폴더에 `유투브/[카테고리]/[제목]_상세.md` 파일을 생성합니다.

## 주의사항
- 유투브/ 폴더가 없으면 먼저 생성합니다
- **상세본은 반드시 카테고리 폴더 안에 생성** (루트 직접 생성 금지 — 5단계 참조). 루트에 미분류 파일이 보이면 분류 이동을 함께 수행합니다
- 자막이 없는 영상은 분석이 제한될 수 있습니다
- 긴 영상(1시간 이상)은 자막 파일을 나눠서 읽습니다
- 작업 후 임시 자막 파일(transcript.ko.vtt 등)은 삭제하거나 정리합니다
