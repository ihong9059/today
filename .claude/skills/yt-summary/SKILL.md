# YouTube 영상 요약 Skill

YouTube URL을 받아 영상 내용을 분석하고, 유투브/ 폴더에 **요약본**과 **상세본** 두 개의 마크다운 파일을 생성합니다.

## 사용법
```
/yt-summary [YouTube URL]
```

## 출력 파일

| 파일 유형 | 파일명 규칙 | 용도 |
|-----------|-------------|------|
| 요약본 | `[제목]_요약.md` | 핵심 내용 빠르게 파악 |
| 상세본 | `[제목]_상세.md` | 구체적 사례, 인용구, 심층 분석 |

## 실행 절차

### 1단계: 영상 정보 추출
yt-dlp를 사용하여 영상 메타데이터를 추출합니다:
```bash
yt-dlp --print "%(title)s" --print "%(channel)s" --print "%(duration_string)s" --print "%(description)s" "URL"
```

### 2단계: 자막 추출
한국어 자막을 다운로드합니다 (없으면 자동 생성 자막 사용):
```bash
yt-dlp --write-auto-subs --sub-lang ko --skip-download -o "유투브/transcript" "URL"
```

### 3단계: 자막 파일 읽기
다운로드된 VTT 파일을 읽어 전체 내용을 파악합니다.
- 파일 위치: 유투브/transcript.ko.vtt
- 긴 영상은 offset/limit 파라미터로 나눠서 읽기

### 4단계: 내용 분석
자막 내용을 기반으로 다음을 분석합니다:
- 핵심 주제 파악
- 주요 내용 정리
- 숫자/데이터 기반 인사이트 추출
- 구간별 내용 요약
- **구체적 사례 및 에피소드 추출** (상세본용)
- **주요 인용구 전체 수집** (상세본용)

### 5단계: 요약본 파일 생성
유투브/ 폴더에 `[제목]_요약.md` 파일을 생성합니다.

### 6단계: 상세본 파일 생성
유투브/ 폴더에 `[제목]_상세.md` 파일을 생성합니다.

## 주의사항
- 유투브/ 폴더가 없으면 먼저 생성합니다
- 자막이 없는 영상은 요약이 제한될 수 있습니다
- 긴 영상(1시간 이상)은 자막 파일을 나눠서 읽습니다
- **요약본을 먼저 생성한 후 상세본을 생성합니다**
- 상세본에는 요약본 링크를 포함하여 연결합니다
