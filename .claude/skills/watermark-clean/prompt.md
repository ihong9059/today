# NotebookLM Watermark Remover

NotebookLM에서 생성한 콘텐츠의 워터마크를 제거할 때 이 스킬을 사용합니다. "NotebookLM 워터마크", "노트북LM 브랜딩 제거" 요청 시 사용.

## 서비스 정보

- **URL**: https://www.notebooklmwatermark.com/
- **용도**: NotebookLM 브랜딩/워터마크 제거
- **처리 방식**: 브라우저 로컬 처리 (파일이 서버에 저장되지 않음)
- **비용**: 무료

## 지원 파일 형식

1. **PDF 슬라이드 덱**
   - 최대 파일 크기: 50MB
   - NotebookLM에서 생성한 PDF 슬라이드의 워터마크 제거

2. **MP4 비디오**
   - NotebookLM 비디오의 마지막 2.5초 아웃트로 자동 제거

## 사용 방법

1. https://www.notebooklmwatermark.com/ 접속
2. 파일 형식 선택 (PDF 또는 Video)
3. 파일 업로드 (드래그 앤 드롭 또는 클릭)
4. 브라우저에서 자동 처리
5. 정리된 파일 다운로드
