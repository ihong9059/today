# 세션 저장 Skill

현재 작업 세션의 상태를 파일로 저장하여 다음 세션에서 이어서 작업할 수 있도록 합니다.

## 실행 절차

### 1. 현재 날짜/시간 확인
```bash
powershell -Command "Get-Date -Format 'yyyy-MM-dd_HHmmss'"
```

### 2. 세션 파일 생성
저장 위치: `C:\todo\today\.claude\sessions\session_[날짜시간].md`

### 3. 저장할 내용 구성

다음 형식으로 세션 파일을 작성:

```markdown
# Session Report - [날짜 시간]

## 작업 요약
[오늘 수행한 작업들을 간략히 요약]

## 완료된 작업
- [완료된 작업 목록]

## 진행 중인 작업
- [아직 완료되지 않은 작업]

## 다음에 할 일
- [다음 세션에서 해야 할 작업]

## 중요 정보
- [기억해야 할 중요한 설정, 경로, 변수 등]

## 관련 파일
- [작업한 파일 경로들]

## 메모
[추가 메모사항]
```

### 4. 저장 완료 안내

저장 후 사용자에게 안내:
- 저장된 파일 경로
- 다음 세션에서 `/session-restore` 또는 "세션 복원해줘"로 복원 가능

## 트리거 키워드
