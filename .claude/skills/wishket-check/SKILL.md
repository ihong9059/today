위시캣 프로젝트 검토 절차:

## 1. 마지막 검토 ID 확인

위시캣/ 폴더에서 가장 최근 가능프로젝트.md 파일을 찾아 "다음 검색 시작 ID" 값을 확인합니다.

```
위시캣/YYYY-MM-DD_가능프로젝트.md
```

파일 내에서 확인할 항목:
- "마지막 검토 ID": 이전에 검토 완료된 마지막 ID
- "다음 검색 시작 ID": 이번 검색 시작점

## 2. 이력서/역량 자료 확인

지원서류/ 폴더에서 다음 파일들을 확인합니다:
- 이력서_홍광선.pdf
- 경력서 - 임호균.pdf
- 보유기술.pdf

주요 역량 요약:
- 홍광선: ARM, RTOS, Zigbee, LoRaWAN, Factory Automation (40년)
- 임호균: ARM CPU/FPGA/ASIC 설계, CAN/RS485, Motor Controller (38년)
- 보유기술: EtherCAT 컨트롤러 양산, STM32 FreeRTOS, 회로설계 25년

## 3. 신규 프로젝트 검색

https://www.wishket.com/project/ 에서 신규 프로젝트를 확인합니다.

검색 범위: "다음 검색 시작 ID" ~ 최신 ID

### 검색 방법 (중요 - 누락 방지)

**반드시 1개씩 순차 검색해야 합니다. 건너뛰기 금지!**

이전에 5~50 간격으로 건너뛰며 검색하여 적합 프로젝트(#153552 등)를 놓친 사례가 있습니다.

1. 위시캣 프로젝트 목록 페이지에서 최신 프로젝트 ID 확인하여 검색 끝점 파악
2. "다음 검색 시작 ID"부터 **1씩 증가하며** 모든 ID를 확인
3. WebFetch를 **병렬로 최대 8개씩** 호출하여 속도 확보
   - 예: 시작 ID가 153966이면 153966~153973을 동시에 요청
   - 완료 후 153974~153981을 동시에 요청
   - 이렇게 반복
4. 로그인 리다이렉트(auth.wishket.com) → 비공개 프로젝트 (기록만 하고 넘어감)
5. 프로젝트 목록 페이지가 반환됨 → 해당 ID 미존재 (아직 등록 안 됨)
6. 연속 5개 이상 미존재(목록 페이지 반환)이면 → 최신 ID에 도달한 것으로 판단, 검색 종료

### 검색 효율화 팁
- 공개 프로젝트가 나오면 반드시 상세 내용을 확인하고 매칭 분석
- 비공개(로그인 리다이렉트)는 "비공개"로만 기록
- 한 번에 최대 8개 병렬 요청으로 속도와 정확성 모두 확보

## 4. 매칭 분석 기준

참가 가능 프로젝트 선별 기준:

### ✅ 적합 분야 (지원 추천)
- 임베디드/펌웨어 개발 (STM32, ARM, MCU)
- PCB/회로 설계
- EtherCAT, CAN, RS485 산업용 통신
- IoT 센서/모니터링 시스템
- FreeRTOS, RTOS 기반 시스템
- Python + Raspberry Pi 조합
- 모터 제어, 공장자동화

### ⚠️ 검토 필요 (부분 매칭)
- PC 어플리케이션 + 임베디드 연동 (C#/C++ 혼합)
- 웹 백엔드 + IoT 연동

### ❌ 불가 분야 (제외)
- 순수 웹/앱 프론트엔드 개발
- ERP, SAP, 회계 시스템
- 보안관제, EDR, SIEM
- AI/ML 모델 개발 (단순 연동 제외)
- 디자인, 기획 중심

## 6. 결과 보고

검토 완료 후 사용자에게 보고:

1. 검토 범위 (시작 ID ~ 마지막 ID)
2. 신규 프로젝트 수
3. 지원 추천 프로젝트 요약
4. 검토 필요 프로젝트 요약
5. 다음 검색 시작 ID 안내

## 7. ID 추적 방법 (중요)

### 마지막 검토 ID 찾기

```
위시캣/ 폴더에서 가장 최근 *_가능프로젝트.md 파일 확인
→ "다음 검색 시작 ID" 값 추출
→ 해당 ID부터 검색 시작
```

### 최신 ID 탐색

1. 위시캣 프로젝트 목록 페이지에서 첫 번째(최신) 프로젝트 ID 확인
2. "다음 검색 시작 ID"부터 최신 ID까지 **1씩 증가하며 빠짐없이** 검색
3. 연속 5개 이상 미존재(목록 페이지 반환)이면 검색 종료

### 검토 완료 후 기록

```markdown
**마지막 검토 ID**: #XXXXX (이번에 확인한 가장 높은 ID)
**다음 검색 시작 ID**: #XXXXX (마지막 검토 ID + 1)
```

이렇게 기록하면 다음 검색 시 "다음 검색 시작 ID"부터 시작하면 됩니다.
