# 작업 시작 Skill

## 실행 순서

### 1. Git 동기화
```bash
cd C:/todo/today
git pull
```

### 2. 최근 작업보고서 확인
- `작업보고서/` 폴더에서 가장 최근 보고서 읽기
- 어제 완료 사항 및 미완료 사항 파악

### 3. 오늘 작업보고서 확인/생성
- 오늘 날짜: `!date +%Y-%m-%d`
- 파일명 형식: `YYYY-MM-DD_작업보고서.md`
- 오늘 보고서가 없으면 새로 생성 (어제 미완료 항목 + 오늘 할일 포함)

### 4. 오늘 할일 표시
사용자에게 다음 형식으로 표시:

```
## 오늘 할일 (YYYY-MM-DD)

| 순번 | 할일 | 상태 |
|:----:|------|:----:|
| 1 | ... | ⬜ |
| 2 | ... | ⬜ |
```

### 5. 작업 시작 안내
- 어떤 작업부터 시작할지 사용자에게 질문
