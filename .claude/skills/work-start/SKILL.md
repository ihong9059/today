작업 시작 절차:
1. git pull로 저장소 동기화
2. 작업보고서/ 폴더에서 최근 보고서 확인 (어제 완료/미완료 파악)
3. 오늘 작업보고서(YYYY-MM-DD_작업보고서.md) 확인 또는 생성
4. 오늘 할일 테이블 형식으로 표시
5. 위시캣 프로젝트 체크 (위시캣/ 폴더 참고)
   - 최근 가능프로젝트.md에서 마지막 검토 ID 확인
   - https://www.wishket.com/project/ 에서 신규 프로젝트 확인
   - 이력서(홍광선, 임호균) 기준으로 참가 가능 프로젝트 선별
   - YYYY-MM-DD_가능프로젝트.md 파일 생성/업데이트
   - 지원 추천 프로젝트가 있으면 사용자에게 알림
6. 어떤 작업부터 시작할지 사용자에게 질문
