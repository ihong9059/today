# 작업 종료 Skill

## 실행 순서

### 1. 오늘 작업 내용 정리
- 이번 세션에서 진행한 작업 목록 정리
- 완료된 항목과 미완료 항목 구분

### 2. 작업보고서 업데이트
- 파일: `작업보고서/YYYY-MM-DD_작업보고서.md`
- 업데이트 내용:
  - 오늘 할일 상태 변경 (⬜ → ✅ 또는 유지)
  - 작업 내용 섹션에 상세 내용 추가
  - 세션 요약 테이블 업데이트

### 3. Git 커밋 절차 (반드시 순서대로)

| 순서 | 명령어 | 설명 |
|:----:|--------|------|
| 1 | `git status` | 변경/추가 파일 목록 확인 |
| 2 | `git diff --stat` | 변경 내용 확인 |
| 3 | `git log --oneline -3` | 최근 커밋 스타일 확인 |
| 4 | **사용자 확인 요청** | 커밋할 내용 보여주고 승인받기 |
| 5 | `git add` → `git commit` → `git push` | 승인 후 순차 실행 |

### 4. 커밋 메시지 형식
```
작업: {주요 작업 내용 요약}
```

예시:
- `작업: Travel English 시나리오 생성 속도 개선 분석`
- `작업: 자격시험 물류관리사 50문항 추가`

### 5. 종료 안내
- 오늘 완료율 표시
- 내일 이어서 할 작업 안내
