# SlideDeck Cleaner

NotebookLM에서 생성한 슬라이드 PDF의 워터마크를 제거할 때 이 스킬을 사용합니다. "슬라이드 워터마크", "PDF 워터마크 제거" 요청 시 사용.

## 서비스 정보

- **URL**: https://www.slidedeckcleaner.com/
- **용도**: NotebookLM 슬라이드 PDF 워터마크 제거
- **처리 방식**: AI 기반 온라인 처리
- **비용**: 무료

## 지원 파일 형식

- **PDF 슬라이드 덱**
  - NotebookLM에서 생성한 슬라이드 PDF 파일

## 사용 방법

1. https://www.slidedeckcleaner.com/ 접속
2. PDF 파일 업로드
3. AI가 자동으로 워터마크 제거
4. 정리된 파일 다운로드

## 특징

- 무료 사용
- AI 기반 자동 처리
- 웹 브라우저에서 바로 사용 가능
- JavaScript 활성화 필요

## 비교: watermark-clean vs slidedeck-clean

| 항목 | watermark-clean | slidedeck-clean |
|------|-----------------|-----------------|
| URL | notebooklmwatermark.com | slidedeckcleaner.com |
| PDF 지원 | O (50MB) | O |
| 비디오 지원 | O (MP4) | X |
| 처리 방식 | 로컬 브라우저 | AI 온라인 |
