# Wiki 작업 기록 Skill

Wiki 관련 작업을 수행할 때 작업일지에 기록하고, 생성된 파일을 날짜 폴더에 관리합니다.

## 실행 절차

### 1. 오늘 날짜 폴더 확인/생성

```bash
mkdir -p "C:/todo/today/myWiki/작업보고서/$(date +%Y-%m-%d)"
```

### 2. 작업일지 확인/생성

파일 경로: `C:\todo\today\myWiki\작업보고서\YYYY-MM-DD\작업일지.md`

파일이 없으면 아래 템플릿으로 생성:

```markdown
# Wiki 작업일지 - YYYY-MM-DD

## 작업 내용

(이후 작업은 아래에 추가)
```

### 3. 작업 내용 기록

사용자가 전달한 작업 내용 또는 현재 수행 중인 wiki 작업을 작업일지.md 하단 `(이후 작업은 아래에 추가)` 위에 추가:

```markdown
### N. {작업 제목}
- **시간**: {오전/오후/저녁}
- **내용**: {수행한 작업 설명}
  - {세부 사항}
- **산출물**: `{생성된 파일명}` (있는 경우)
```

순번(N)은 기존 작업 다음 번호로 자동 부여.

### 4. 특별 생성 파일 저장

wiki 작업 중 생성되는 분석 보고서, 새 wiki 페이지 사본 등은 같은 날짜 폴더에 저장:
- `myWiki/작업보고서/YYYY-MM-DD/{파일명}.md`

### 5. 기록 완료 안내

사용자에게 간단히 안내:
- 작업일지 업데이트 완료
- 생성 파일 목록 (있는 경우)

## 사용 예시

### 인자 없이 호출 (현재 작업 자동 기록)
```
/wiki-log
```
→ 현재 진행 중인 wiki 작업을 자동으로 판단하여 기록

### 작업 내용 지정
```
/wiki-log experience.md 4월 활동 업데이트
```
→ 지정된 내용으로 작업일지에 기록

### wiki 작업 완료 후 기록
```
/wiki-log Lint 실행 완료 - 고아링크 3건 발견, 모순 0건
```
→ 결과 포함하여 기록
