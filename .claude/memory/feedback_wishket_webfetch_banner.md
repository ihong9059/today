위시캣 프로젝트 페이지(`wishket.com/project/{ID}/`)를 WebFetch로 읽을 때, 사이트 공통 배너 안내문("기간제(상주) 프로젝트 희망 근무 시작일을 등록해 주시면 ...")을 해당 프로젝트의 근무형태로 잘못 추출하는 사고가 발생했음. 실제 프로젝트의 근무형태는 페이지 내 카테고리 아이콘 라벨("외주" 또는 "상주")로만 판단해야 함.

**Why**: 2026-05-14 #155235 지원서 작성 시 1차 WebFetch가 "상주 (기간제)"로 반환 → 가능프로젝트.md의 "외주" 정보와 모순 → 지원서에 불필요한 "하이브리드 협의 요청" 섹션 작성 → 사용자가 "어디에 상주라는 말이 있지요?"로 지적 → 재검증 결과 사이트 배너 안내문(모든 프로젝트 공통)을 프로젝트 메타로 오인한 것 확인. 프로젝트는 "외주" 카테고리였음.

**How to apply**:
1. 위시캣 페이지 WebFetch 시 근무형태는 반드시 **프로젝트 카테고리 아이콘 라벨**로 추출 ("외주"/"상주" 단일 단어)
2. "기간제(상주)" 같이 괄호 표기가 섞인 문구는 사이트 공통 안내문일 가능성 高 → 두 번째 검증 WebFetch로 "배너 vs 프로젝트 분류" 명시 질문
3. WebFetch 결과가 가능프로젝트.md / 어제 검토 노트와 모순되면 즉시 재검증 (모순은 사고 신호)
4. 추출이 불확실하면 사용자에게 확인 요청 — 추측해서 지원서에 반영 금지
