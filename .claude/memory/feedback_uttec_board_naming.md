description: aiHardStudy 내에서 ESP32 보드를 UTTEC 보드로 명칭 통일
type: feedback
---

aiHardStudy 폴더 내 문서에서는 "ESP32 보드" 대신 "UTTEC 보드"로 명칭 통일.

**Why:** 자체 브랜딩. 단, 사용자가 ESP32로 특정 지정하면 ESP32로 표기.

**How to apply:** aiHardStudy 하위 문서 작성/수정 시 보드 명칭을 "UTTEC 보드"로 사용. 기술 사양 설명 등에서 ESP32 칩을 언급해야 할 때는 "UTTEC 보드 (ESP32 기반)" 정도로 표기.
