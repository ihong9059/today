**삼환전기** = UTTEC와 오래전부터 거래해 온 조명(전기공사) 회사. 협력·리드 유입 채널.

- 2026-07-23 첫 리드: **광안 지역주택조합 공동주택 신축공사**(부산 수영구 광안동 971) 야간경관 조명제어 문의. 건축위원회 심의(2020.01) + 도면(E13 보안등 조명제어 상세도, E2 옥외인입/보안등 배치도) 전달.
  - 요구: **보안등 27EA 시간대별 디밍 제어**(점등 9HR), 볼라드 26·수옥 4.
  - UTTEC LoRa 조명제어([[project_lora_vault]], 한림용인CC 14노드 실증)와 직결.
  - 대응: 제안서 2종(기술 설계본 + 비전문가용 쉬운본 with 관제 대시보드 목업) PDF 제작 → Downloads. 삼환 회신(진행단계·관로유무·조광규격·요청범위 4항목) 대기.
