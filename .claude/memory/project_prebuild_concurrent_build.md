여러 학생이 동시에 사전빌드에 없는 새로운 요청을 하면 AI 빌드가 동시에 발생하여 충돌할 수 있다.

**Why:** 교육 현장에서 30명 학생이 동시 사용. 사전빌드 매칭으로 대부분 해결되지만, 새로운 요청이 동시에 들어오면 Arduino CLI가 같은 빌드 디렉토리를 공유하여 충돌.

**How to apply:**
- 방안 1: 각 빌드 요청마다 독립 빌드 디렉토리 (build_tmp/job_id/) 사용 → 병렬 빌드 가능 (동시 2~3개)
- 방안 2: 초과 요청은 큐로 순차 처리
- 방안 3: 사전빌드 카탈로그를 최대한 확충하여 AI 빌드 필요성 자체를 최소화
- 현재 build_server_arduino.py의 `_build_lock` 기반 직렬 처리를 개선해야 함
- 사용자 결정: 반드시 해결해야 하는 사항 (2026-04-18 기록)
