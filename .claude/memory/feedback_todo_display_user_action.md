**적용 범위**: 할일/잔여 작업 테이블 + **모든 응답·프롬프트·확인 요청·다음 단계 안내** (2026-05-18 사용자 확장 지시).

다음 규칙으로 구분:

| 구분 | 표기 prefix | 적용 대상 |
|---|---|---|
| 🔴 👤 | 시급 + 사용자 직접 행동 (D-day 등) | 한림용인CC D-1, 결제·서명 등 |
| 👤 | 사용자 직접 행동 (Claude 대신 못 함) | 발주·결제·미팅 참석·물리 검증·외부 회신·승인·결정 |
| 🤖 | Claude가 처리 가능 | 코드·문서·박제·sync 등 |
| (prefix 없음) | 일반 (mixed/미분류 / 단순 상태 보고) | — |

추가로: 사용자 직접 행동 항목은 가능하면 **노란 인용 블록(>)** 으로 묶어 한 번에 모아서 표시.

**Why:** 화면에 표시되는 양이 많아서 무엇이 사용자 본인이 해야 하는 일인지 구분이 어려움 (2026-05-18 사용자 피드백). 시급한 사용자 액션이 Claude 작업·시스템 출력 사이에 묻혀 누락 위험. 응답 본문(프롬프트 질문, 확인 요청, 다음 단계 안내)에서도 동일.

**How to apply:**
- **할일 테이블/리스트**: 모든 항목 앞에 prefix 적용
- **응답 본문 — 사용자에게 액션 요청·확인·결정 요구 시**: 해당 문장이나 bullet 앞에 👤 (또는 🔴+👤)
  - 예: "👤 ssh 키 등록해주세요", "👤 발주 결정 부탁드립니다", "🔴 👤 5/19 미팅 시간 회신 필요"
- **응답 본문 — Claude가 처리할 다음 단계 안내 시**: 🤖
  - 예: "🤖 다음으로 SD 카드 마운트 확인합니다", "🤖 작업보고서 자동 추가"
- mixed 항목은 분할하거나 prefix 생략하고 본문에 역할 명시
- 단순 상태 보고·결과 출력에는 prefix 생략 (혼란 방지, 액션 요청 시만 사용)
