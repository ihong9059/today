name: 기존 코드 먼저 참조하기
description: 이미 동작하는 코드가 있으면 반드시 먼저 읽고 동일한 패턴을 사용할 것
type: feedback
---

기존에 동작하는 코드가 있을 때 새로 작성하지 말고 반드시 기존 코드를 참조하여 동일한 패턴을 사용할 것.

**Why:** Python Vibe 서버의 Claude CLI 호출을 새로 작성하다가 5번의 시행착오(인자 방식, --verbose 누락, 경로, 인코딩, async 래핑)를 거쳤음. 기존 build_server_mini.py에 이미 검증된 코드가 있었는데 참조하지 않았음.

**How to apply:** 새 기능 구현 시 기존 코드베이스에 유사한 기능이 있는지 먼저 확인. 특히 사용자가 "이전에 했던 것을 참고하라"고 하면 반드시 해당 파일을 먼저 읽고 동일한 호출 방식/패턴을 복사하여 사용.
