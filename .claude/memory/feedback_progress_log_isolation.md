매 응답에서 **이번 prompt에 대한 진행 내용만** 화면에 표시한다. 이전 prompt에서 이미 다룬 내용을 재서술·재요약·재인용하지 않는다.

**Why:** 사용자가 화면 위로 스크롤할 때 "이번 prompt의 응답이 어디서 시작해서 어디서 끝나는지" 시각적으로 구분 안 되어, 이번 작업 결과만 찾기 어려움. 응답 자체는 자세해도 좋지만, 이전 내용이 섞이면 식별 어려움.

**How to apply:**

### 화면 표시 규칙
- 이번 prompt에서 한 일 → **자세하게** 표시 (지금처럼, 길이 자체는 OK)
- 이전 prompt에서 이미 보고한 내용 → **재서술 금지**
- "지금까지 진행 요약", "전체 그림", "복습" 같은 섹션 → 사용자가 명시적으로 요청한 경우에만
- 매 응답 끝에 임시 파일 경로 1줄 안내 (선택, 사용자 도움이 될 때만)

### 임시 진행 로그 파일 (누적 보관용)
- 위치: `C:\todo\today\.claude\sessions\_current_progress.md`
- 매 응답 직후 다음 형식으로 append (Edit 도구):
  ```markdown
  ## [HH:MM] 사용자 prompt 요약 (1줄)
  - 한 일 1
  - 한 일 2
  - 결과
  ```
- 기록 내용은 화면 응답과 동일 수준 (전체 진행 내역 보관용)

### 세션 라이프사이클
- `/work-start` 시: `_current_progress.md` 새로 생성 또는 비움 (새 세션 시작)
- `/work-end` 시: `_current_progress.md`를 정식 `session_*.md`로 변환 후 삭제 또는 보관

### 자주 하는 실수 (피할 것)
- ❌ "앞서 진행한 X에 이어, 이번에 Y를..." (앞서 진행한 X 반복 안 됨)
- ❌ "전체 진행 결과 정리:" 섹션 + 모든 단계 나열 (이전 내용 반복)
- ❌ 표나 다이어그램에 이전 단계까지 포함
- ✅ "이번 prompt 결과:" 또는 바로 본론
- ✅ 이번 prompt에 대한 모든 진행 단계는 자세히
- ✅ 다음 액션은 1~2줄로
