# Raspberry Pi 4 멀티코어 Claude 교육 시스템

## 1. 시스템 개요

Raspberry Pi 4의 4개 코어를 활용하여 3명의 학생이 동시에 웹 브라우저로 접속,
각자 독립된 터미널에서 Claude Code를 사용할 수 있는 교육 플랫폼.

## 3. 핵심 기술 스택

### 3-1. 하드웨어
```
Raspberry Pi 4 Model B
├── CPU: BCM2711, Quad-core Cortex-A72 (ARM v8) 1.8GHz
├── RAM: 4GB 또는 8GB (8GB 권장)
├── Storage: microSD 32GB+ 또는 SSD (USB 부팅)
├── Network: Gigabit Ethernet 또는 WiFi
└── OS: Raspberry Pi OS 64-bit (Debian Bookworm)
```

### 3-2. 소프트웨어 스택

### CPU 고정 명령어
```bash
# 학생 1의 Claude를 Core 1에 고정
taskset -c 1 claude --dangerously-skip-permissions

# 학생 2의 Claude를 Core 2에 고정
taskset -c 2 claude --dangerously-skip-permissions

# 학생 3의 Claude를 Core 3에 고정
taskset -c 3 claude --dangerously-skip-permissions
```

## 5. 데이터 흐름

```
[학생 브라우저]
      │
      │ 1. HTTP GET /  (웹 페이지 로드)
      │ 2. WebSocket 연결 (ws://pi-ip:port)
      ▼
[Nginx :80]
      │
      │ 프록시 (학생별 포트로 분배)
      ▼
[Node.js 서버]
      │
      │ 3. 학생 식별 (세션/토큰)
      │ 4. node-pty로 가상 터미널 생성
      │ 5. taskset으로 특정 코어에 고정
      │ 6. 터미널에서 Claude Code 실행
      ▼
[PTY 터미널] ←→ [Claude Code CLI] ←→ [Anthropic API]
      │
      │ 7. Claude 출력을 WebSocket으로 학생에게 전송
      ▼
[학생 브라우저 - 출력 창]
```

## 7. 리소스 요구사항

### RAM 사용 예상
```
OS + 시스템 서비스        : ~300 MB
Nginx                    :  ~10 MB
Node.js 웹 서버          : ~100 MB
Claude Code CLI × 3      : ~150 MB × 3 = 450 MB
node-pty × 3             :  ~30 MB
여유                      : ~500 MB+
──────────────────────────────────
총 필요                   : ~1.4 GB (4GB 모델 OK, 8GB 권장)
```

### 네트워크
```
Claude API 호출: 학생당 ~50KB/요청 (텍스트 기반)
동시 3명: ~150KB/요청
인터넷 속도: 10Mbps 이상 권장
```

## 8. 보안 고려사항

| 항목 | 대책 |
|------|------|
| API Key 보호 | 서버 환경변수로만 관리, 학생에게 노출 안됨 |
| 학생 간 격리 | 각 학생별 Linux 사용자 + 별도 홈 디렉토리 |
| 파일 시스템 | chroot 또는 제한된 디렉토리만 접근 |
| 명령어 제한 | Claude의 --disallowedTools로 위험 명령 차단 |
| 네트워크 | 학생 프로세스는 외부 네트워크 접근 차단 (선택) |
| 접속 제한 | 간단한 토큰/비밀번호 인증 |
