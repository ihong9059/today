### 리소스 한계

- RAM 2GB는 동시 3명 사용 시 빠듯함
  - Claude Code CLI 1개당 ~150MB (Node.js 프로세스)
  - 3명 동시: ~450MB + OS ~300MB + 웹서버 ~100MB = ~850MB
  - 여유: ~1GB (swap 미사용 상태에서)
- 계획서에서 권장한 4GB/8GB 대비 절반 이하
- 장시간 사용 시 swap 발생 가능성 있음

## 5. 디렉토리 구조

```
/home/
├── uttec/                    # 관리자
│   ├── .claude/              # Claude Code 설정
│   │   └── .credentials.json # OAuth 토큰 (학생들이 symlink로 공유)
│   ├── .claude.json          # Claude Code 상태
│   └── resource_web/         # 리소스 웹 서버 (server.py)
│
├── student1/                 # 학생 1
│   ├── .claude/              # Claude 설정 (credentials → uttec symlink)
│   ├── .claude.json          # 독립 파일 (symlink 아님!)
│   ├── .hushlogin            # MOTD 배너 제거
│   ├── claude_launcher.exp   # expect 자동 실행 스크립트
│   └── workspace/            # 작업 디렉토리
│       └── .claude/settings.local.json
│
├── student2/                 # 학생 2 (student1과 동일 구조)
│   └── test/                 # 학생이 생성한 테스트 디렉토리
│
└── student3/                 # 학생 3

/opt/
└── claude-education/         # 웹 기반 터미널 서버
    ├── server.js
    ├── package.json
    ├── node_modules/
    └── public/
        ├── index.html        # 학생 선택 페이지
        └── student.html      # 채팅형 터미널 페이지
```
