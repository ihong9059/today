## Phase 1: 환경 준비

### 1-1. Raspberry Pi 설정
```bash
# Raspberry Pi OS 64-bit 설치 (Bookworm)
# SSH 활성화, WiFi/Ethernet 설정

# 시스템 업데이트
sudo apt update && sudo apt upgrade -y

# 필수 패키지 설치
sudo apt install -y nginx nodejs npm git build-essential
```

### 1-2. Node.js 최신 버전 설치
```bash
# Node.js 20 LTS 설치 (ARM64)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
sudo apt install -y nodejs
node -v  # v20.x 확인
```

### 1-3. Claude Code CLI 설치
```bash
# Claude Code 설치
npm install -g @anthropic-ai/claude-code

# API Key 설정 (서버 환경변수)
echo 'export ANTHROPIC_API_KEY="sk-ant-xxxxx"' >> /etc/environment
```

### 1-4. 학생 Linux 사용자 생성
```bash
# 학생 3명의 사용자 계정 생성
sudo useradd -m -s /bin/bash student1
sudo useradd -m -s /bin/bash student2
sudo useradd -m -s /bin/bash student3

# 각 학생 홈 디렉토리에 작업 폴더 생성
sudo mkdir -p /home/student1/workspace
sudo mkdir -p /home/student2/workspace
sudo mkdir -p /home/student3/workspace

sudo chown student1:student1 /home/student1/workspace
sudo chown student2:student2 /home/student2/workspace
sudo chown student3:student3 /home/student3/workspace
```

## Phase 4: 코어 할당 및 프로세스 관리

### 4-1. taskset을 이용한 코어 고정
```bash
# node-pty에서 프로세스 생성 시 taskset 래핑
# 예: 학생 1을 Core 1에 고정
taskset -c 1 su - student1 -c "cd ~/workspace && claude"
```

### 4-2. cgroups로 리소스 제한 (선택)
```bash
# 학생별 메모리 제한 (예: 1GB)
sudo cgcreate -g memory,cpu:student1
sudo cgset -r memory.limit_in_bytes=1073741824 student1
sudo cgset -r cpu.cfs_quota_us=250000 student1  # 25% CPU (1코어)

# 프로세스를 cgroup에 넣기
sudo cgexec -g memory,cpu:student1 su - student1 -c "claude"
```

### 4-3. 프로세스 모니터링
```bash
# 코어별 사용률 확인
mpstat -P ALL 1

# 학생별 프로세스 확인
ps -eo pid,psr,user,comm | grep -E "student[1-3]|claude"

# 실시간 모니터링
htop  # F2 → Display → CPU count 표시
```

## Phase 5: Nginx 설정

### 5-1. Nginx 리버스 프록시 설정
```nginx
# /etc/nginx/sites-available/claude-education

upstream student1_ws {
    server 127.0.0.1:8001;
}
upstream student2_ws {
    server 127.0.0.1:8002;
}
upstream student3_ws {
    server 127.0.0.1:8003;
}

server {
    listen 80;
    server_name _;

    # 정적 파일
    location / {
        root /opt/claude-education/public;
        index index.html;
    }

    # 학생별 WebSocket 프록시
    location /ws/student1 {
        proxy_pass http://student1_ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }

    location /ws/student2 {
        proxy_pass http://student2_ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }

    location /ws/student3 {
        proxy_pass http://student3_ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }
}
```

## Phase 6: 테스트 및 배포

### 6-1. 단계별 테스트
```
□ Step 1: RPi에 Node.js + Claude Code CLI 설치 확인
□ Step 2: 1명 접속으로 터미널 + Claude 동작 확인
□ Step 3: 3명 동시 접속 테스트
□ Step 4: 코어 할당 확인 (htop으로 모니터링)
□ Step 5: 장시간 안정성 테스트 (1시간+)
□ Step 6: 네트워크 외부 접속 테스트
```

### 6-2. systemd 서비스 등록
```ini
# /etc/systemd/system/claude-education.service
[Unit]
Description=Claude Education Web Terminal
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/claude-education
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production
Environment=ANTHROPIC_API_KEY=sk-ant-xxxxx

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable claude-education
sudo systemctl start claude-education
```

## 대안 검토

### 방안 A: node-pty + xterm.js (권장)
- 가장 가벼움, RPi에 적합
- Claude Code의 터미널 UI 그대로 전달
- 커스터마이징 자유도 높음

### 방안 B: ttyd 사용
```bash
# ttyd: 웹 기반 터미널 공유 도구
sudo apt install ttyd

# 학생별 포트로 실행
taskset -c 1 ttyd -p 8001 -c student1 su - student1 -c "claude"
taskset -c 2 ttyd -p 8002 -c student2 su - student2 -c "claude"
taskset -c 3 ttyd -p 8003 -c student3 su - student3 -c "claude"
```
- 장점: 코드 작성 거의 불필요, 바로 사용 가능
- 단점: UI 커스터마이징 제한적
