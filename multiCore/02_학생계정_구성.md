## 2. 홈 디렉토리 구조

각 학생의 홈 디렉토리는 동일한 구조를 가진다:

```
/home/studentN/
├── .bash_aliases          # Armbian 기본 (326B)
├── .bash_history          # 사용 이력
├── .bash_logout           # 기본
├── .bashrc                # "# empty" (의도적으로 비움)
├── .profile               # 기본
│
├── .hushlogin             # 빈 파일 - MOTD 배너 제거용 (필수)
├── .claude.json           # Claude Code 상태 (독립 파일, symlink 아님!)
├── claude_launcher.exp    # expect 스크립트 (자동 실행 시도용)
│
├── .claude/               # Claude Code 내부 디렉토리
│   ├── .credentials.json  # → /home/uttec/.claude/.credentials.json (symlink)
│   ├── settings.json      # {"skipDangerousModePermissionPrompt": true}
│   ├── backups/
│   ├── cache/
│   ├── history.jsonl
│   ├── plugins/
│   ├── projects/
│   ├── session-env/
│   ├── sessions/
│   ├── shell-snapshots/
│   └── telemetry/
│
├── .npm/                  # npm 캐시
├── .cache/                # 시스템 캐시
│   └── claude-cli-nodejs/ # Claude Code Node.js 캐시
│
└── workspace/             # 학생 전용 작업 디렉토리
    └── .claude/
        └── settings.local.json  # workspace별 Claude 설정
```

## 3. 핵심 파일 상세

### 3-1. .bashrc

```bash
# empty
```

- 의도적으로 비워둠
- 이유: Claude Code 자동 실행을 넣으면 MOTD 배너와 TUI 렌더링이 충돌
- 학생은 SSH 접속 후 수동으로 `claude` 입력

**참고**: 계획서에서는 `.bashrc`에 taskset alias를 추가하는 방안이 있었으나 미적용 상태:
```bash
# 계획서 내용 (미적용)
alias claude='taskset -c N claude'
```

### 3-2. .hushlogin

```
빈 파일 (0 bytes)
```

- SSH 접속 시 Armbian MOTD 배너를 제거하는 역할
- 배너가 Claude Code TUI(Ink/React 기반)와 충돌하여 화면이 깨지는 문제 방지
- **필수 파일** — 삭제하면 Claude Code 화면이 깨짐

### 3-3. .claude.json

```json
{
  "numStartups": 10,
  "tipsHistory": { ... },
  "hasCompletedOnboarding": true,
  "projects": {
    "/home/student1/workspace": {
      "hasTrustDialogAccepted": true
    }
  }
}
```

- **반드시 학생별 독립 파일**이어야 함 (symlink 금지!)
- symlink로 공유하면 여러 학생이 동시에 쓰기 시 파일 충돌 발생
- `hasTrustDialogAccepted: true` — workspace 신뢰 대화상자 건너뛰기
- `hasCompletedOnboarding: true` — 첫 실행 온보딩 건너뛰기
- `numStartups` — 실행 횟수 (student1: 10회, student2: 유사)

### 3-4. .claude/settings.json

```json
{
  "skipDangerousModePermissionPrompt": true
}
```

- `--dangerously-skip-permissions` 프롬프트를 건너뛰는 설정
- 교육 환경에서 매번 확인 대화상자가 뜨는 것을 방지

### 3-5. .claude/.credentials.json (symlink)

```
lrwxrwxrwx student1 -> /home/uttec/.claude/.credentials.json
```

- uttec 관리자 계정의 OAuth 토큰을 symlink로 공유
- 원본 파일 권한: `-rw-r--r--` (644) — 다른 사용자가 읽을 수 있도록 설정
- **주의**: Claude가 토큰을 갱신하면 권한이 600으로 바뀔 수 있음
  - 계획서에서 cron으로 1분마다 644 유지하는 방안 제시 (현재 미구현)

### 3-6. claude_launcher.exp

```expect
#!/usr/bin/expect -f
set timeout 30
spawn claude --dangerously-skip-permissions
expect {
    "Enter to confirm" {
        send ""
        exp_continue
    }
    ">" {
        interact
    }
    eof
}
```

- expect 스크립트로 Claude Code 자동 실행 시도
- "Enter to confirm" 프롬프트를 자동 통과
- 현재 학생들은 이 스크립트 대신 직접 `claude` 명령 사용 (bash_history 기준)

### 3-7. workspace/.claude/settings.local.json

```
student1에만 존재 (87B)
workspace별 Claude Code 로컬 설정
```

## 5. 계정 생성 명령어 (재현용)

```bash
# 학생 계정 생성
sudo useradd -m -s /bin/bash studentN
echo "studentN:비밀번호" | sudo chpasswd

# workspace 생성
sudo mkdir -p /home/studentN/workspace
sudo chown studentN:studentN /home/studentN/workspace

# .bashrc 비우기
echo "# empty" | sudo tee /home/studentN/.bashrc

# .hushlogin 생성 (필수)
sudo touch /home/studentN/.hushlogin
sudo chown studentN:studentN /home/studentN/.hushlogin

# .claude.json 생성 (독립 파일)
sudo cat > /home/studentN/.claude.json << 'EOF'
{
  "hasCompletedOnboarding": true,
  "numStartups": 1,
  "projects": {
    "/home/studentN/workspace": {
      "hasTrustDialogAccepted": true
    }
  }
}
EOF
sudo chown studentN:studentN /home/studentN/.claude.json

# credentials symlink (OAuth 방식)
sudo mkdir -p /home/studentN/.claude
sudo ln -sf /home/uttec/.claude/.credentials.json /home/studentN/.claude/.credentials.json
sudo chown -R studentN:studentN /home/studentN/.claude

# settings.json
echo '{"skipDangerousModePermissionPrompt": true}' | sudo tee /home/studentN/.claude/settings.json
sudo chown studentN:studentN /home/studentN/.claude/settings.json
```
