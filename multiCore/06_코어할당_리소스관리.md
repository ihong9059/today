# 코어 할당 및 리소스 관리

> taskset/cgroups를 이용한 학생별 CPU 코어 격리 및 리소스 제한

---

## 1. 코어 할당 전략

### Odroid C2 (4코어)

```
Core 0: 시스템 (OS, SSH, Nginx 등)
Core 1: 학생 1 전용
Core 2: 학생 2 전용
Core 3: 학생 3 전용
```

### AWS EC2 c7g.8xlarge (32코어, 스케일업 시)

```
Core 0:     시스템
Core 1~20:  학생 1~20 전용
Core 21~31: 여유
```

## 2. taskset 명령어

### 기본 사용법

```bash
# 특정 코어에서 프로세스 실행
taskset -c 1 claude    # Core 1에서 Claude 실행

# 실행 중인 프로세스의 코어 확인
taskset -p <PID>

# 실행 중인 프로세스의 코어 변경
taskset -cp 2 <PID>    # PID를 Core 2로 이동
```

### 학생별 적용

```bash
# 방법 1: 직접 실행
taskset -c 1 su - student1 -c "claude"

# 방법 2: .bashrc alias (계획서 제안, 현재 미적용)
# student1의 .bashrc에 추가:
alias claude='taskset -c 1 claude'

# 방법 3: 서버 코드에서 (server.js)
spawn('taskset', ['-c', String(core), 'su', '-s', '/bin/bash', student, '-c', cmd])
```

### 현재 상태

| 방식 | 상태 | 비고 |
|------|------|------|
| server.js에서 taskset | 구현됨 | 웹 서버 통해서만 작동 |
| .bashrc alias | **미적용** | 학생이 SSH로 직접 `claude` 실행 시 코어 고정 안 됨 |
| 수동 taskset | 사용 안 함 | 학생이 직접 taskset 입력해야 함 |

## 3. .bashrc alias 적용 방법 (권장)

현재 `.bashrc`가 비어있으므로 alias를 추가하면 SSH 직접 접속 시에도 코어가 고정됨:

```bash
# student1
echo 'alias claude="taskset -c 1 claude"' | sudo tee -a /home/student1/.bashrc

# student2
echo 'alias claude="taskset -c 2 claude"' | sudo tee -a /home/student2/.bashrc

# student3
echo 'alias claude="taskset -c 3 claude"' | sudo tee -a /home/student3/.bashrc
```

### 확인

```bash
# student1으로 접속
ssh student1@100.89.56.69
which claude         # → /usr/bin/claude (또는 npm global 경로)
type claude          # → claude is aliased to 'taskset -c 1 claude'
claude               # → Core 1에서 실행됨
```

## 4. 코어 모니터링

### 실시간 코어별 사용률

```bash
# mpstat (sysstat 패키지)
sudo apt install -y sysstat
mpstat -P ALL 1

# 출력 예시:
# CPU    %usr   %sys  %idle
# all    12.5   3.2   84.3
#  0      5.1   2.0   92.9    ← 시스템
#  1     45.2   4.1   50.7    ← 학생 1 (사용 중)
#  2      0.0   0.0  100.0    ← 학생 2 (미사용)
#  3     20.1   3.5   76.4    ← 학생 3 (사용 중)
```

### 학생별 프로세스 확인

```bash
# 학생별 프로세스 + 코어 확인
for i in 1 2 3; do
  echo -n "Student $i: "
  ps -u student$i -o pid,psr,comm --no-headers 2>/dev/null | grep -E "node|claude" || echo "offline"
done

# 출력 예시:
# Student 1: 1234  1 node
# Student 2: offline
# Student 3: 5678  3 node
```

### htop (시각적 모니터링)

```bash
htop
# F2 → Display → Show CPU usage per core
# 각 코어별 막대 그래프로 사용률 확인
```

## 5. cgroups 리소스 제한 (선택사항)

### 왜 필요한가

- 한 학생이 과도한 메모리 사용 시 다른 학생에게 영향
- OOM Killer가 다른 학생의 프로세스를 죽일 수 있음
- 특히 RAM 2GB인 Odroid C2에서 중요

### cgroups v1 설정

```bash
# cgroup 유틸리티 설치
sudo apt install -y cgroup-tools

# 학생별 cgroup 생성
for i in 1 2 3; do
  sudo cgcreate -g memory,cpu:student$i

  # 메모리 제한 (500MB)
  sudo cgset -r memory.limit_in_bytes=524288000 student$i

  # CPU 제한 (25% = 1코어)
  sudo cgset -r cpu.cfs_quota_us=250000 student$i
  sudo cgset -r cpu.cfs_period_us=1000000 student$i
done
```

### cgroups v2 설정 (최신 커널)

```bash
# cgroup v2 확인
mount | grep cgroup2

# 학생별 슬라이스 생성
sudo mkdir -p /sys/fs/cgroup/student1
echo "500M" | sudo tee /sys/fs/cgroup/student1/memory.max
echo "250000 1000000" | sudo tee /sys/fs/cgroup/student1/cpu.max
```

### cgroup에서 프로세스 실행

```bash
# cgroup 안에서 Claude 실행
sudo cgexec -g memory,cpu:student1 su - student1 -c "taskset -c 1 claude"

# 또는 .bashrc alias에 통합
alias claude='sudo cgexec -g memory,cpu:student1 taskset -c 1 claude'
```

### 현재 상태

| 항목 | 상태 |
|------|------|
| cgroups 설치 | 미확인 |
| 학생별 cgroup | **미구현** |
| 메모리 제한 | **없음** |
| CPU 제한 | taskset만 (코어 고정은 되나 사용률 제한은 없음) |

## 6. Odroid C2 리소스 예산

```
총 RAM: 2GB (실사용 ~1.9GB)

배분:
  OS + 시스템:       ~300MB
  SSH 데몬:          ~10MB
  Claude CLI x 3:    ~450MB (150MB x 3)
  여유:              ~1,140MB

권장 cgroup 제한:
  학생당 메모리: 500MB (swap 포함)
  학생당 CPU: Core 1개 (25%)
```
