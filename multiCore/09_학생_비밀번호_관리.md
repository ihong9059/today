# 학생 비밀번호 관리 (자율 변경 + 관리자 초기화)

> 학생이 스스로 비밀번호를 변경하고, 교육 종료 후 관리자가 일괄 초기화하는 방법

---

## 1. 개요

```
수업 시작 전:  관리자가 초기 비밀번호 설정 (student1/student1 등)
수업 중:      학생이 자신의 비밀번호를 자율 변경
수업 종료 후:  관리자가 전체 비밀번호 일괄 초기화
다음 수업:    새 학생에게 초기 비밀번호 배포
```

---

## 2. 학생이 자신의 비밀번호 변경

### 방법

학생이 SSH 접속 후 `passwd` 명령으로 변경:

```bash
student1@odroidc2:~$ passwd
Changing password for student1.
Current password:          ← 현재 비밀번호 입력
New password:              ← 새 비밀번호 입력
Retype new password:       ← 새 비밀번호 재입력
passwd: password updated successfully
```

### 필요 조건

- `passwd` 명령은 Linux 기본 내장 — 추가 설치 불필요
- 일반 사용자는 **자신의 비밀번호만** 변경 가능 (다른 사용자 불가)
- sudo 권한 불필요

### 비밀번호 정책 설정 (선택)

너무 단순한 비밀번호를 방지하려면:

```bash
# PAM 설정으로 최소 길이 등 제한
sudo apt install -y libpam-pwquality

# /etc/security/pwquality.conf 수정
sudo tee /etc/security/pwquality.conf << 'EOF'
minlen = 6
minclass = 1
maxrepeat = 3
EOF
```

비밀번호 정책을 **완전히 끄려면** (교육 환경에서 단순 비밀번호 허용):

```bash
# /etc/pam.d/common-password 에서 pam_pwquality 줄 주석 처리
sudo sed -i 's/^password.*pam_pwquality/#&/' /etc/pam.d/common-password
```

## 3. 관리자가 학생 비밀번호 초기화

### 개별 초기화

```bash
# uttec 관리자 계정에서
sudo passwd student1
New password:          ← 새 비밀번호 입력
Retype new password:   ← 재입력
passwd: password updated successfully
```

### 일괄 초기화 (전체 학생)

```bash
# 방법 1: chpasswd (비대화형, 스크립트에 적합)
echo "student1:student1" | sudo chpasswd
echo "student2:student2" | sudo chpasswd
echo "student3:student3" | sudo chpasswd

# 방법 2: 루프로 일괄 처리
for i in 1 2 3; do
  echo "student$i:student$i" | sudo chpasswd
  echo "student$i 비밀번호 초기화 완료"
done
```

### 20명 일괄 초기화 (AWS 스케일업 시)

```bash
for i in $(seq 1 20); do
  echo "student$i:student$i" | sudo chpasswd
done
echo "전체 학생 비밀번호 초기화 완료"
```

## 4. 초기화 스크립트

### reset_passwords.sh

```bash
#!/bin/bash
#============================================
# 학생 비밀번호 일괄 초기화 스크립트
# 사용법: sudo ./reset_passwords.sh [학생수]
#============================================

STUDENT_COUNT=${1:-3}

echo "=== 학생 비밀번호 초기화 ==="
echo "대상: student1 ~ student$STUDENT_COUNT"
echo ""

for i in $(seq 1 $STUDENT_COUNT); do
    PASS="student$i"
    echo "student$i:$PASS" | chpasswd

    # 활성 세션 강제 종료 (선택)
    pkill -9 -u student$i 2>/dev/null

    echo "  student$i → 비밀번호: $PASS (세션 종료됨)"
done

echo ""
echo "=== 초기화 완료 ==="
echo "  초기 비밀번호: 계정명과 동일 (student1/student1)"
```

### 사용법

```bash
# 스크립트 생성
sudo tee /opt/claude-education/reset_passwords.sh << 'SCRIPT'
#!/bin/bash
STUDENT_COUNT=${1:-3}
echo "=== 학생 비밀번호 초기화 (student1 ~ student$STUDENT_COUNT) ==="
for i in $(seq 1 $STUDENT_COUNT); do
    echo "student$i:student$i" | chpasswd
    pkill -9 -u student$i 2>/dev/null
    echo "  student$i 초기화 완료"
done
echo "=== 완료 ==="
SCRIPT

sudo chmod +x /opt/claude-education/reset_passwords.sh

# 실행 (3명)
sudo /opt/claude-education/reset_passwords.sh 3

# 실행 (20명, AWS)
sudo /opt/claude-education/reset_passwords.sh 20
```

## 5. 다음 로그인 시 비밀번호 강제 변경 (선택)

학생이 초기 비밀번호로 접속하면 **반드시 새 비밀번호를 설정하도록** 강제:

```bash
# 개별 설정
sudo passwd --expire student1

# 일괄 설정
for i in 1 2 3; do
  sudo passwd --expire student$i
done
```

### 학생이 보는 화면

```
$ ssh student1@100.89.56.69
student1@100.89.56.69's password: student1

WARNING: Your password has expired.
You must change your password now and login again!
Changing password for student1.
Current password:          ← student1
New password:              ← 새 비밀번호
Retype new password:       ← 재입력

Connection to 100.89.56.69 closed.
```

변경 후 새 비밀번호로 재접속하면 정상 사용 가능.

### 초기화 + 강제 변경 통합 스크립트

```bash
#!/bin/bash
#============================================
# 학생 비밀번호 초기화 + 첫 로그인 시 변경 강제
#============================================

STUDENT_COUNT=${1:-3}

for i in $(seq 1 $STUDENT_COUNT); do
    # 비밀번호 초기화
    echo "student$i:student$i" | chpasswd

    # 다음 로그인 시 변경 강제
    passwd --expire student$i

    # 활성 세션 종료
    pkill -9 -u student$i 2>/dev/null

    echo "student$i: 초기화 완료 (첫 로그인 시 변경 필수)"
done
```

## 6. 전체 운영 시나리오

### 시나리오 A: 단순 운영 (비밀번호 변경 자율)

```
교육 시작 전:
  1. 관리자: sudo ./reset_passwords.sh 3
  2. 학생에게 안내: "ID: student1, PW: student1"

교육 중:
  3. 학생: passwd 명령으로 자율 변경 (안 해도 됨)

교육 종료 후:
  4. 관리자: sudo ./reset_passwords.sh 3
     → 비밀번호 원복 + 활성 세션 종료
```

### 시나리오 B: 보안 강화 (첫 로그인 시 변경 강제)

```
교육 시작 전:
  1. 관리자: 초기화 + --expire 스크립트 실행
  2. 학생에게 안내: "첫 접속 후 비밀번호를 변경하세요"

교육 중:
  3. 학생: 첫 SSH 접속 시 강제 변경 → 재접속 → claude 사용
  4. 이후 passwd로 추가 변경 가능

교육 종료 후:
  5. 관리자: 초기화 스크립트 실행
```

### 시나리오 C: 기수별 운영 (반복 교육)

```
1기 시작: sudo ./reset_passwords.sh 3 → 학생 배포
1기 종료: sudo ./reset_passwords.sh 3 → 초기화
          + workspace 정리: sudo rm -rf /home/student*/workspace/*

2기 시작: sudo ./reset_passwords.sh 3 → 새 학생 배포
...
```

## 7. workspace 초기화 (교육 종료 시 함께 수행)

비밀번호와 함께 작업 디렉토리도 초기화:

```bash
#!/bin/bash
#============================================
# 전체 초기화 스크립트 (비밀번호 + workspace + 세션)
# 사용법: sudo ./full_reset.sh [학생수]
#============================================

STUDENT_COUNT=${1:-3}

echo "=== 전체 초기화 시작 ==="

for i in $(seq 1 $STUDENT_COUNT); do
    echo "--- student$i ---"

    # 1. 활성 세션 종료
    pkill -9 -u student$i 2>/dev/null
    echo "  세션 종료"

    # 2. 비밀번호 초기화
    echo "student$i:student$i" | chpasswd
    echo "  비밀번호 → student$i"

    # 3. workspace 정리 (숨김 파일 제외)
    rm -rf /home/student$i/workspace/*
    echo "  workspace 정리"

    # 4. Claude 세션/히스토리 정리
    rm -f /home/student$i/.claude/history.jsonl
    rm -rf /home/student$i/.claude/sessions/*
    rm -rf /home/student$i/.claude/backups/*
    echo "  Claude 히스토리 정리"

    # 5. bash_history 정리
    rm -f /home/student$i/.bash_history
    echo "  bash 히스토리 정리"
done

echo ""
echo "=== 전체 초기화 완료 ==="
echo "  비밀번호: 계정명과 동일"
echo "  workspace: 비어있음"
echo "  Claude 히스토리: 삭제됨"
```

## 8. 요약

| 기능 | 명령어 | 권한 |
|------|--------|------|
| 학생이 자기 비밀번호 변경 | `passwd` | 일반 사용자 |
| 관리자가 특정 학생 초기화 | `sudo passwd studentN` | root/sudo |
| 관리자가 전체 일괄 초기화 | `sudo ./reset_passwords.sh` | root/sudo |
| 첫 로그인 시 변경 강제 | `sudo passwd --expire studentN` | root/sudo |
| 전체 초기화 (PW + workspace) | `sudo ./full_reset.sh` | root/sudo |

### Linux 기본 기능만으로 구현 가능

- 추가 소프트웨어 설치 불필요
- `passwd`, `chpasswd`, `pkill` — 모두 기본 명령어
- `--expire` 옵션으로 첫 로그인 변경 강제도 가능
