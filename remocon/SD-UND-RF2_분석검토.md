## 5. 분석 절차

### Step 1: 신호 캡처
```
URH 설정:
- Device: RTL-SDR
- Frequency: 447925000 (447.925 MHz)
- Sample Rate: 2000000 (2 MSps)
- Bandwidth: 2000000
- Gain: 30~40 dB (조절 필요)
```
리모컨 버튼을 누르면서 녹화

### Step 2: 코드 방식 판별
같은 버튼을 **3회 이상** 눌러서 캡처한 후 비교:
- 매번 **같은 패턴** → 고정 코드 (분석/리플레이 가능)
- 매번 **다른 패턴** → 롤링 코드 (단순 리플레이 불가)

### Step 3: 변조/프로토콜 분석
URH Interpretation 탭에서:
- 변조 방식 확인 (ASK/OOK, FSK 등)
- 비트 길이, 펄스 길이 측정
- 프리앰블, 싱크워드, 데이터 영역 구분

### Step 4: 디코딩
- 비트 패턴에서 주소(ID)와 명령(Command) 분리
- 알려진 프로토콜(EV1527, PT2262 등)과 비교

### Step 5: 리플레이 (고정 코드인 경우)
- URH Generator → HackRF로 전송
- 또는 Arduino + CC1101로 코드 전송
- 또는 Flipper Zero로 리플레이

---

## 6. 주의사항

### 롤링 코드 가능성
건물 출입용 리모컨은 보안을 위해 롤링 코드(HCS301 등)를 사용할 가능성이 있음.
이 경우 신호 분석은 가능하지만 리플레이는 불가.

### 법적 사항
- 자신의 리모컨 신호 수신/분석: 교육 목적으로 허용
- 타인의 시설에 무단 접근: 불법 (전파법 제19조)
- 송신 시 전파법 준수 필요

1. **RTL-SDR 구매** (쿠팡 제품 스펙 확인 후 결정)
