## 1. HW 구성

### 1.1 PCB 구성 (3종 분리)
- **MAIN CONTROL PCB** — STM32Fx 계열 사용
- **SUB PROTOCOL PCB** — 사양에 따라 다름
  - PIO + RS485
  - DeviceNet
  - EtherCAT
- **SENSOR PCB** — Pressure, Thermal, Coriolis 포함
  - ※ 두 타입(Thermal/Coriolis)이 공존이 어려울 시 **분리 개발**

### 1.2 PART
- ACTUATOR
- GAS LINE (BYPASS, SENSING, ACT)

## 2. OPERATION FUNCTION

### 2.1 응답 시간
- **Target Time 설정 범위**: 0.1 ~ 1.0초
- **EX**: 1초 이내 제어
- ※ 1초 이내는 **확실하게 제어**해야 함
- ※ 그 이하 세팅 시 제어 어려울 시 해당 기능 삭제 가능

### 2.2 유량 제어
- Target 유량 설정 기능
- **EX**: 10SLM 세팅 시 **0.5초 이내** 10SLM 제어 유지
- **소수점 2자리까지 제어를 목표**로 하되, 불가 시 소수점 1자리로 대체

## 3. DISPLAY

| 동작 | 표시/기능 |
|------|----------|
| 전원 인가 시 | XERiX LOGO 1초 유지 후 현재 유량 값 표현 |
| FUNCTION BUTTON1 1회 | 세팅된 유량 값 표현 |
| FUNCTION BUTTON1 2회 | 현재 유량 값 표현 (반복 토글) |
| FUNCTION BUTTON2 1회 | ZERO CAL 진행 → "ZERO CAL ING" → "ZERO CAL OK" → 현재 유량 |
| FUNCTION BUTTON2 길게 | AUTO PID 진행 → "AUTO PID ING" → "AUTO PID OK" → 현재 유량 |
| 상태 표시 | **GREEN/RED STATUS BLOCK ADD** |

## 4. MAIN PCB (DIP SW 구성)

| DIP SW | OFF | ON |
|--------|-----|-----|
| SENSOR SELECT (1CH) | THERMAL TYPE | CORIOLI TYPE |
| ANALOG SELECT (1CH) | 0~5VDC 입출력 | 4~20mA 입출력 |
| PROTOCOL SELECT (2CH) | ALL OFF: PIO+RS485 | 1CH ON: DEVICENET / 2CH ON: ETHERCAT |

### PID Algorithm
- **SENSOR DATA 기반 ACTUATOR 조정 + PRESSURE로 보정**

## 6. UART / PROTOCOL 구성

> ※ Protocol은 Hex로 대체 예정 — 참고만

### DEBUGGING UART1
- `"HIX"` 쿼리 → `"XERIX"` reply
- ZERO Calibration Function
- PID Manual / Auto 조정 가능
- **GAS량 및 성분 선택에 따른 연산 적용 기능 (MGMR)**
- 유량 설정 (MFC SV) 및 모니터링 (MFC PV, TEMP PV, PRESS PV 등)
- 그 외 Protocol 추가

### CUSTOMER UART2
- `"HIC"` 쿼리 → `"CUSTOMER"` reply
- ZERO Calibration Function
- PID Manual / Auto 조정 가능
