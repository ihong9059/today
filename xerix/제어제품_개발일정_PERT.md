# 일반 제어 제품 개발 일정 — PERT 분석 자료

## 1. PERT 개요

**PERT (Program Evaluation and Review Technique)** 는 프로젝트 작업(Activity)의 소요 시간을 확률적으로 추정하여 일정·임계경로를 산출하는 기법이다.

### 1.1 3점 추정법

각 작업에 대해 세 가지 시간을 추정한다.

| 기호 | 의미 | 설명 |
|---|---|---|
| **O (Optimistic)** | 낙관치 | 모든 것이 순조롭게 진행될 때 |
| **M (Most Likely)** | 최빈치 | 가장 가능성 높은 소요 시간 |
| **P (Pessimistic)** | 비관치 | 문제 발생 시 최악 소요 시간 |

### 1.2 기대값 및 분산

$$TE = \frac{O + 4M + P}{6}, \quad \sigma^2 = \left(\frac{P - O}{6}\right)^2$$

## 4. 경로 분석 (임계경로 산출)

각 경로별 총 소요 시간(TE 합)을 계산한다.

| 경로 | 구성 | 합계(주) |
|---|---|---|
| Path 1 (H/W) | A→B→C→D→E→F→K→L→M→N | 2.17+2.00+3.33+2.17+2.17+2.00+2.17+3.17+2.17+2.00 = **23.35** |
| Path 2 (제어) | A→B→G→H→K→L→M→N | 2.17+2.00+4.17+3.33+2.17+3.17+2.17+2.00 = **21.18** |
| Path 3 (통신/UI) | A→B→G→I→J→K→L→M→N | 2.17+2.00+4.17+2.17+3.00+2.17+3.17+2.17+2.00 = **23.02** |

### ★ 임계경로(Critical Path): **Path 1 (H/W 경로)**
- **총 기대기간: 약 23.4주 (≈ 5.9개월)**
- H/W 경로가 가장 길어 일정 지연에 직결됨 → H/W 일정 리스크 집중 관리 필요

### 4.1 임계경로의 표준편차

$$\sigma_{CP} = \sqrt{\sum \sigma^2} = \sqrt{0.25+0.11+0.44+0.25+0.25+0.11+0.25+0.25+0.25+0.11} = \sqrt{2.27} \approx 1.51\text{주}$$

### 4.2 완료 확률 (정규분포 근사)

| 목표 일정 | Z 값 | 완료 확률 |
|---|---|---|
| 22주 이내 | (22-23.35)/1.51 = -0.89 | 약 **19%** |
| 23.4주(기대치) | 0 | **50%** |
| 25주 이내 | (25-23.35)/1.51 = +1.09 | 약 **86%** |
| 26주 이내 | (26-23.35)/1.51 = +1.76 | 약 **96%** |
