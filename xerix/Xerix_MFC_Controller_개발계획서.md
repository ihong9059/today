## 1. 프로젝트 개요

### 1.1 목적
반도체 공정(식각/증착/세정 등)에서 사용되는 공정 가스 및 유체의 질량유량을
**Coriolis 방식으로 측정**하고, **Piezo 또는 Solenoid 비례 밸브**로 정밀 제어하며,
상위 제어기와 **EtherCAT 실시간 통신**으로 연동되는 고정밀 Mass Flow Controller 개발.

### 1.2 최종 확정 사양

| 항목 | 사양 | 비고 |
|---|---|---|
| **측정 원리** | Coriolis Mass Flow | 직접 질량 측정, T/P 보상 불필요 |
| **밸브 구동** | Piezo Stack (기본) / Solenoid 비례 (저가 라인) | 선택 옵션 |
| **응답 시간** | **≤ 300 ms** (1%→99%) | |
| **제어 MCU** | **STM32F446 / F429 / F407** | F4 시리즈 확정 |
| **ESC (EtherCAT Slave Controller)** | **LAN9252** | SPI PDI, 2포트 |
| **EtherCAT 제어 주기** | 1 ms (DC SYNC0) | 프리미엄 500 μs 옵션 |
| **정밀도** | ±0.5% of Reading + ±0.1% F.S. | 목표 |
| **히스테리시스** | < 0.2% F.S. | |
| **재현성** | < 0.2% F.S. | |
| **내압** | 3~5 MPa (공정 가스 기준) | |
| **Gas Wetted 재질** | 316L EP / Hastelloy C-22 / Elgiloy | Zero Dead Volume |

### 1.3 제품 라인업 전략
| 라인 | 밸브 | 응답 τ | 원가 (자재비) | 타겟 시장 |
|---|---|:---:|:---:|---|
| **Standard** | Solenoid 비례 | ~300 ms | 약 45만원 | 유틸리티/저가 장비 |
| **Premium** ⭐ | Piezo Stack | < 150 ms | 약 75만원 | 반도체 공정 챔버 |

## 2. STM32F4 선정 근거 (F3/H7 대비)

| 항목 | STM32F3 | **STM32F4** ⭐ | STM32H7 |
|---|:---:|:---:|:---:|
| 클럭 | 72 MHz | **168~180 MHz** | 550 MHz |
| FPU | SP | **SP** | DP |
| ADC | 12bit | **12bit (최대 7.2 Msps)** | 16bit |
| DAC | 12bit | **12bit 2ch** | 12bit 2ch |
| CORDIC | ✓ | ✗ | ✗ |
| Ethernet MAC | ✗ | **F407/F429 ✓** | ✓ |
| SPI 속도 (LAN9252) | ~18 MHz | **최대 45 MHz (F429/F446)** | 최대 100 MHz |
| X-CUBE-ECAT 지원 | ✓ | **✓ (공식)** | ✓ |
| 가격 (단가 100개) | $4~6 | **$5~8** | $12~18 |
| 개발 리소스 | 중 | **최상** | 상 |
| 한국어 자료 | 중 | **최상** | 중 |
| Xerix 적합도 | △ | **◎** | ○ |

### F4 선택의 핵심 이유
1. **성능/가격 밸런스가 가장 우수** — 300ms 응답 요구에 충분히 여유 있음
2. **X-CUBE-ECAT + LAN9252 조합의 공식 레퍼런스가 F4(특히 F429)**
3. **한국 내 개발자 풀/자료/커뮤니티가 가장 두터움** → 유지보수/인력 수급 유리
4. **F446은 SPI 45 MHz** → LAN9252 고속 통신에 충분
5. **F429/F407은 Ethernet MAC 내장** → EoE 진단 웹 구현 가능

### 권장 MCU
- **F429ZI** (LQFP144, 2MB Flash, 256KB RAM, Ethernet MAC, SPI 45MHz) — **제1 후보**
- **F446RE** (LQFP64, 512KB Flash, 128KB RAM, SPI 45MHz) — 소형 보드용 대안

### 3.1 전체 블록 다이어그램

```
 ┌────────────────────────────────────────────────────────────────┐
 │                    EtherCAT Master (TwinCAT3)                    │

                ▼                              ▼
  ┌──────────────────────────┐    ┌──────────────────────────┐
  │   Xerix MFC Slave #1     │    │   Xerix MFC Slave #N     │
  │ ┌──────────┐ ┌────────┐  │    │                           │
  │ │ LAN9252  │ │STM32F4 │  │    │       (동일 구조)          │
  │ │   ESC    │◀│(F429)  │  │    │                           │
  │ │  2 Port  │ │  SPI   │  │    │                           │
  │ └────┬─────┘ └───┬────┘  │    │                           │
  │   Phy│PHY    SYNC0│      │    │                           │
  │                   ▼      │    │                           │
  │              ┌────────┐  │    │                           │
  │              │  PID   │  │    │                           │
  │              │  1ms   │  │    │                           │
  │              └─┬────┬─┘  │    │                           │
  │          DAC12 │    │ ADC│    │                           │
  │                ▼    ▼    │    │                           │
  │          ┌─────────┐ ┌───────┐│                           │
  │          │ Valve   │ │Coriolis││                          │
  │          │ Driver  │ │ AFE    ││                          │
  │          └────┬────┘ └───▲────┘│                          │
  │               ▼          │     │                          │
  │         Piezo/Solenoid   │     │                          │
  │               ↓          │     │                          │
  │            Gas Flow ─────┘     │                          │
  └──────────────────────────┘    └──────────────────────────┘
```

### 3.2 주요 모듈

| 모듈 | 구성 | 핵심 IC |
|---|---|---|
| **MCU** | STM32F429ZI | STMicro |
| **ESC** | LAN9252 + 2× Ethernet Jack (RJ45) | Microchip |
| **Coriolis AFE** | 24bit ΔΣ ADC + Driver Coil AMP | ADS1263 / AD7768-1 |
| **Valve Driver (Piezo)** | HV Amp 0~150V | PiezoDrive PDU150 / TI DRV2700 |
| **Valve Driver (Solenoid)** | 전류원 PWM | DRV8251A / 커스텀 |
| **전원** | 24V 입력 → 12V/5V/3.3V/1.2V + 150V(Piezo) | TPS54xxx 계열 + LT8580 Boost |
| **진단/보조** | 온도 센서(PT1000), 압력 센서 옵션, 절연 UART | - |
| **IO** | DIN 2ch (Alarm/Valve Close), DOUT 2ch (Status) | - |
