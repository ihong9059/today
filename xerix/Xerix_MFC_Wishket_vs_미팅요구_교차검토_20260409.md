## 0. Executive Summary

1. **Wishket 단계**는 *"견적 Range + 구현 가능 여부"*만 요구한 **초기 구상 단계**. 2~3억원짜리 상세 개발계획서는 **과잉 진행**.
2. **EtherCAT / DeviceNet은 Wishket 원안 범위 밖**. 미팅 시 추가된 신규 요구사항으로 **별도 견적 분리** 필요.
3. **PCB 사이즈 110×70mm 엄수 규정을 어제 계획서가 위반** (100×150mm 설계).
4. **±15VDC 전원, D-SUB 09P 커넥터, +24V 입력단 탄탈륨 금지** — 중요 전원 사양 3건이 어제 v1.0과 오늘 v2.0 양쪽 모두에서 누락.
5. **납품 기한 2.5개월 (시제품)** vs v2.0 8개월 — **극단적 일정 불일치**. Coriolis 센서 헤드 OEM 조달은 2.5개월 일정에 불가능.
6. **Wishket은 센서 "타당성 검토"** 단계인데 v1.0은 Coriolis 확정 + 1,050만원 OEM 조달 BOM — 과잉 진행.
7. **설계 툴: Wishket은 OR-CAD/Allegro 지정**, v1.0은 KiCad/Altium 기술 — 불일치.
8. **산출물 지식재산권 클라이언트 귀속** 조항이 v1.0/v2.0에 반영 없음.

## 1. 치명적 모순 (Critical Mismatch)

### 1.1 프로젝트 단계/규모/일정 전면 불일치 ⚠️⚠️⚠️

| 항목 | Wishket 원본 | 어제 v1.0 | 오늘 v2.0 |
|---|---|---|---|
| **단계** | "기획/예산 미확정 **초기 구상 단계**" | 2억 650만 **상세 계획서** | 2억 7,900만 **재산정** |
| **요청 수준** | **시장 평균 견적 Range + 구현 가능 여부** | 상세 견적 제안서 | 상세 재검토 |
| **납품 기한** | **2.5개월 시제품** 납품 | 6개월 (24~26주) | ~8개월 (33~34주) |
| **주요 마일스톤** | 회로도 2주 / PCB 5주 / FW 통합 8주 | Phase 6단계 | Phase 7단계 |
| **매니저 요청** | "상세 제안서보다 Range + 구현 가능 여부 위주" | 상세 BOM + Phase 상세 | 상세 BOM + Phase 상세 |

**문제 분석**:
- Wishket 매니저는 *"상세한 제안서 작성보다는, 시장 평균 견적 Range와 구현 가능 여부 위주"* 라고 명시
- 현재까지 작성한 2~3억원짜리 상세 문서는 **이 지시를 초과**
- 2.5개월 납품에 Coriolis 센서 헤드 + ET1100 + 3프로토콜 보드는 **물리적으로 불가능**
  - Coriolis 센서 헤드 OEM 리드타임만 4~8주
  - ET1100 개발 리소스 부족 (한국어 자료 없음)
  - 3프로토콜 Sub-Board 각각 설계 + 시험 = 병렬 작업해도 10주+ 소요

**대응 방향**:
- (A) Wishket 응답 단계라면 → **견적 Range 표만 제출**, 상세 문서는 내부 참고용
- (B) 미팅 완료 후 계약 단계라면 → **일정/범위 재협의** 공식 요청

### 1.2 PCB 사이즈 규격 위반 📏

| 항목 | Wishket 원본 | 어제 v1.0 |
|---|---|---|
| PCB 사이즈 | **110 × 70 mm 엄수** | 100 × 150 mm (6층) |
| 내부 분할 | 센서부 / 제어부 / 조작부 / 전원부 **4영역 분할** (제어+전원 병합 가능) | - |
| 층수 | 미지정 | 6층 |

**문제 분석**:
- 110×70mm = 7,700 mm² (100×150 = 15,000 mm²의 **약 절반**)
- 이 면적에 STM32F429ZI (20×20mm LQFP144) + OLED + Button + DIP SW + Actuator Driver + Sensor AFE 전체 탑재는 **매우 빡빡**
- 추가로 ET1100 (BGA128) + KSZ8041NL ×2 + H1102NL ×2 + RJ45 ×2 까지 넣으면 **불가능**

**대응 방향**:
- Wishket 원안 (RS485 only) 기준에서는 **110×70mm 단일 PCB 가능**
- 미팅 확장안(EtherCAT 포함) 기준에서는 **SubProtocol Sub-Board 분리가 불가피** → v2.0 3-Board 구조가 오히려 적합
- **양쪽 구조를 옵션으로 제시**: 기본(단일 PCB) / 확장(3-Board)

### 1.3 전원 사양 3건 누락 ⚡

| 항목 | Wishket 원본 | v1.0 / v2.0 | 비고 |
|---|---|---|---|
| 입력 전원 | **+24VDC 및 ±15VDC** | 24V 단일만 언급 | ❌ ±15V 누락 |
| 커넥터 | **D-SUB 09P Male** | 미지정 | ❌ 핀맵 규정 있음 |
| 부품 제한 | **+24V 입력단 탄탈륨 커패시터 사용 배제** | 미언급 | ❌ 특수 조건 |

**문제 분석**:
- ±15V는 **Analog AFE 초정밀 계측용** 표준 공급원 (Brooks/MKS/Horiba MFC도 동일)
- 탄탈륨 금지는 **과거 소손 경험** 또는 **신뢰성 정책**에 따른 특수 조건 → 반드시 준수
- D-SUB 09P Male 핀맵은 Xerix 장비/장착 현장과의 **물리적 호환성** 문제 — 미준수 시 현장 설치 불가

**대응 방향** (BOM/회로 반영):
- ±15V 입력단 보호회로 (TVS + 역극성 보호 다이오드)
- +24V 입력단 콘덴서: **알루미늄 폴리머 + MLCC 조합** (탄탈륨 제외)
- D-SUB 09P Male 핀 배열 Xerix로부터 **공식 도면 요청** 필요

### 1.4 EtherCAT / DeviceNet 범위 초과 🎯

| 항목 | Wishket 원본 | 미팅 추가 (Xerix 메일) |
|---|---|---|
| 통신 인터페이스 | **RS485 Serial 단일** ("RS485 Serial 디버깅 Port + RS485 Serial Protocol") | **PIO+RS485 / DeviceNet / EtherCAT** 3종 DIP SW 전환 |
| EtherCAT ESC | 없음 | **BECKHOFF ET1100** 지정 |
| DeviceNet | 없음 | **ODVA 규정 + EDS 파일** |

**문제 분석**:
- Wishket 원안은 **RS485 + Debug Port 만** 명시
- 미팅에서 DeviceNet + EtherCAT 추가 → **본래 견적 범위 외 추가 개발 작업**
- 재견적 시 **Sub-Board 2종 추가 (DeviceNet + EtherCAT) + 스택/프로토콜 개발** 별도 비용 계상 필수

**대응 방향**:
- **견적을 3단계 옵션으로 분리**:
  - **기본**: RS485 only (Wishket 원안) — 2.5~3개월 / 6~8천만원
  - **확장1**: + DeviceNet — +1.5개월 / +3천만원
  - **확장2**: + EtherCAT (ET1100) — +2개월 / +5천만원
- Xerix와 **계약 시점에 옵션 선택** 확정

### 1.5 센서 단계 불일치 🔬

| 항목 | Wishket 원본 | Xerix 메일 | v1.0 |
|---|---|---|---|
| Thermal / Coriolis | **"타당성 검토 및 테스트"** (미확정 단계) | **2종 DIP SW 전환** (확정) | **Coriolis 확정** + 1,050만원 OEM BOM |

**문제 분석**:
- Wishket 원안은 센서 방식이 **아직 검토 단계**
- 어제 v1.0은 Coriolis 확정 + 센서 헤드 OEM 조달 예산까지 계상 → **단계 건너뜀**
- 미팅에서 2종 지원으로 확장 → v2.0의 "Sensor PCB 2종 분리"가 현재로서는 가장 합리적

**대응 방향**:
- Phase 0에 **센서 타당성 검토 단계 명시적 재추가**
- Coriolis OEM 조달 비용은 **Phase 후반 옵션**으로 분리
- 기본 시제품 2.5개월 일정 내에서는 **Thermal 방식으로 우선 검증**, Coriolis는 후속 Phase

| 항목 | Wishket 원본 | v1.0 |
|---|---|---|
| 회로/PCB 툴 | **OR-CAD / Allegro** 지정 | KiCad / Altium 기술 |

## 2. 부분 모순 / 보완 필요 사항

### 2.1 PID 제어: Auto PID 의미 재확인

| 항목 | Wishket | Xerix 메일 | v1.0/v2.0 |
|---|---|---|---|
| PID 모드 | *"환경 변화에 **적응하는** Auto PID Function"* | Button Long Press → AUTO PID 실행 | 1ms 폐루프 PID |

**확인 필요**:
- "환경 변화 적응"이 **온/압 변화 시 자동 재튜닝**을 의미하는지, 단순 **1회 Auto-Tuning**인지
- 고도화 수준에 따라 개발 공수 차이 **1주 vs 4주+**

### 2.2 RS485 Protocol 규격서 미수령

- Wishket: *"RS485 Serial Protocol 상세 규격서 **(개발 착수 시 제공)**"*
- 현재: **미수령** 상태
- 어제 v1.0의 "HIX / XERIX" 커맨드셋은 **임의 초안** — Xerix 공식 프로토콜 수령 시 대체

**대응**:
- 계약 착수 조건에 *"RS485 Protocol 규격서 제공일 = 개발 D-day"* 명시

### 2.3 지식재산권 귀속

- Wishket: *"산출물 지식재산권은 **클라이언트에게 귀속**"*
- v1.0/v2.0: 귀속 조항 명시 없음 (GitHub private repo 언급만)

**반영 사항**:
- 계약서에 **IP 전부 Xerix 귀속** 조항 명시
- GitHub repo는 **개발 중 협업용**, 납품 후 소유권 이전
- 소스코드 주석/파일 내 저작권 표기: "Copyright Xerix Co., Ltd."

### 2.4 탄탈륨 금지 (재강조)

- Wishket 특수 조건: **+24V 입력단 탄탈륨 배제**
- **BOM 설계 시 반드시 반영** — MLCC + Aluminum Polymer + Aluminum Electrolytic 조합

### 2.5 EMI/EMC 범위

- Wishket: *"양산을 위한 기본 전자파(EMI/EMC) **고려 설계**"*
- v1.0: EMI 사전 시험 외주 250만원
- 일치하지만 **정식 인증이 아닌 설계 단계 고려** 수준 — 외주 비용 축소 가능 (100~150만원)

### 2.6 시제품 수량

- Wishket: "조립 완료된 시제품 보드 (**수량 협의**)"
- v1.0: Rev.A 3장 + Rev.B 3장 = 6장 SMT 조립 계상
- → Xerix와 **정확한 납품 수량** 협의 필요 (일반적으로 3~5대)

### 2.7 클라이언트 투입 인력

- Wishket: "하드웨어 사양 협의 및 검수 **담당자 1명**"
- 실제: **유진기 선임 (jkyu@xerix.co.kr)** 창구 명확
- → 협의 효율은 양호

### 2.8 Main PCB 내부 4영역 분할 해석

Wishket 원문: *"센서부, 제어부, 조작부, 전원부 분할 설계 (제어부/전원부 병합 가능)"*

**두 가지 해석 가능**:
| 해석 | 내용 | 적용 단계 |
|---|---|---|
| **(a) 단일 PCB 내 4영역** | 110×70mm 1장 안에 4개 영역 구획 | Wishket 원안 (RS485 only) |
| **(b) 보드 분리도 허용** | 기능별 보드 분리 가능 | 미팅 확장안 (3종 프로토콜) |

→ **Xerix 재확인 필요**. 확장 사양이면 3-Board 구조 불가피.

## 4. 권장 대응 전략

### 4.1 상황별 대응

#### 🅐 Wishket 응답 단계 (아직 파트너 선정 전)
→ **견적 Range 표만 제출**. 상세 문서는 내부 참고용.

**제출할 Range 구조**:

| 옵션 | 범위 | 기간 | 견적 Range (VAT 별도) |
|---|---|---|---|
| **A. Wishket 원안 (Base)** | PIO+RS485 단일, Thermal/Coriolis 검토, 110×70mm 단일 PCB, Auto PID, OLED | **2.5~3개월** | **6,000만 ~ 8,500만원** |
| **B. 미팅 확장 Lv.1** | Base + DeviceNet Sub-Board | **4~5개월** | **9,000만 ~ 1억 2,000만원** |
| **C. 미팅 확장 Lv.2** | Base + DeviceNet + **EtherCAT (ET1100)** Sub-Board | **5~6개월** | **1억 4,000만 ~ 1억 8,000만원** |
| **D. Premium Full** | C + **Coriolis 센서 헤드 OEM 조달** + Auto PID 고도화 | **7~8개월** | **2억 5,000만 ~ 3억원** |

- **구현 가능 여부**: 모두 가능. 단 A 옵션은 2.5개월 마일스톤 준수 가능, D 옵션은 불가.
- **권장**: **옵션 B 또는 C** (현실성 + 확장성 균형)

### 4.3 Xerix에 공식 확인 필요 질의 (통합 Q1~Q13)

#### 범위/일정
- **Q1.** Wishket 원안 2.5개월 시제품 납품 일정 vs 미팅 추가 요구(EtherCAT/DeviceNet/Coriolis)의 **현실성 재협의**
- **Q2.** EtherCAT/DeviceNet은 **Phase 1(기본 시제품)에 포함?** 아니면 **Phase 2(확장)로 분리?**
- **Q3.** 3종 프로토콜 중 **첫 양산 우선순위** (PIO+RS485 우선 시 EtherCAT 후순위 가능)

#### 하드웨어
- **Q4.** **PCB 110×70mm 엄수** 여부 (3-Board 분리 허용 시 각 보드 사이즈)
- **Q5.** **±15V 공급원 / D-SUB 09P Male 핀맵** 공식 도면 요청
- **Q6.** **ET1100 지정 이유** (Beckhoff 상호운용성? 단순 선호?) — LAN9252 대안 허용 여부
- **Q7.** **설계 툴** — OR-CAD/Allegro 엄수 vs KiCad 허용
- **Q8.** **Coriolis 센서 헤드 조달 주체** (Xerix? UTTEC?)

#### 기능/사양
- **Q9.** **정밀도 "소수점 2자리"** 기준 (SLM 절대값 vs F.S.%)
- **Q10.** **0.5초 @ 10SLM 응답** — 가스라인 물리 구성(배관/밸브/체적) 확정 여부
- **Q11.** **Auto PID "환경 변화 적응"** — 1회 튜닝 vs 온/압 변화 시 재튜닝
- **Q12.** **IGS Type** — SEMI F81 등 준수 표준
- **Q13.** **MGMR 대상 가스 리스트** (N₂/He/Ar/H₂/O₂/CO₂/SF₆ 외 추가?)

#### 계약/산출물
- **Q14.** **RS485 Protocol 상세 규격서** 전달 예정일
- **Q15.** **시제품 납품 수량** (3대/5대/기타)
- **Q16.** **산출물 IP 귀속** 조항 계약서 반영 확인
- **Q17.** **EMI/EMC** — 설계 고려 수준 vs 정식 인증 수준
- **Q18.** **Display 형태** 재확인 (OLED 1인치 이하 vs 7-Seg vs LCD 캐릭터)
