## 3. 톱 5 — 즉시 진입 가능 채널 상세

### 3-1. 인프런 (B1) — 1순위 ★★★★★ (23/25)

#### 핵심 데이터
- **정산 비율**: 강사 70% (일반), 사업자 시 +부가세 10%, 원천세 3.3% 자동 처리
- **정산 일정**: 매월 익월 7~8 영업일 확정 후 지급
- **자격**: 인프런 계정 → 지식공유자 등록 (자격 제한 없음, 강의 검수만 통과)
- **수수료 외**: 금융수수료, 매년 5월 종합소득세 강사 직접 신고

#### UTTEC 적합도
- ✅ **콘텐츠**: 13가이드 Track A(Claude Code/Obsidian) + Track F(Ollama/TinyML) → 모두 인프런 핫 카테고리
- ✅ **자격**: 즉시 가능, 강의 시연 1건이면 등록
- ✅ **반복 매출**: 1회 등록 → 영구 판매 (Stage 1 교육 영상이 그대로 자산화)
- ✅ **영업 자료**: 인프런 강의 = "공인 강사" 신뢰 자료 (정부지원 가산점 + 기업 영업)
- ⚠️ **초기 노력**: 영상 편집·자막 작업 필요 (단, 강사양성 파일럿 40h 영상이 그대로 활용 가능)

#### 시작 행동 (이번 주)
1. 인프런 지식공유자 등록 (5분)
2. 첫 강의 1건 — "Claude Code + Obsidian 입문 (8시간 코스)" 강의 계획서 제출
3. 검수 통과 후 강사양성 파일럿 영상 편집본 업로드 (5/19 시범 후)

#### 출처
- [인프런 지식공유자 가이드](https://inflab-1.gitbook.io/inflearn/course-operating/incomes)
- [수익 100% 정산 안내](https://www.facebook.com/hyungjoooo/posts/3904757679843306/)

### 3-2. 호오컨설팅 (C1) — 1순위 ★★★★★ (22/25)

#### 핵심 데이터
- **단가**: 전문강사 시간당 ~150만원 이하, 인지도 높은 강사·MC 그 이상
- **연간 강연**: 2,000여건 (국내 1위 강사 섭외 플랫폼)
- **AI 호오봇**: 강사료 자동 견적 시스템
- **유사 채널**: 강사인, 강사야, 와이즈캐스팅, 아이엠강사 (병행 등록 가능)

#### UTTEC 적합도
- ✅ **단가**: 시간당 100만+ 가능 (uttec-edu 13가이드를 단발 강연 형태로 압축 시)
- ✅ **콘텐츠**: "AI 시대 1인 사업자의 7대 도구" 강연 콘텐츠로 즉시 변환 가능
- ✅ **반복 매출**: 1회 강연 → 후기 누적 → 단가 인상 + 추가 의뢰
- ⚠️ **자격**: 사진·소개 영상·이력서 정비 필요 (호오봇 검수 통과 조건)

#### 시작 행동 (이번 주)
1. 호오컨설팅 강사 등록 페이지에서 프로필 작성
2. 동시에 강사인·와이즈캐스팅 병행 등록 (1시간 내)
3. 강연 주제 3건 등록: ① AI 시대 1인 사업자 도구 ② Claude Code 실무 ③ On-Device AI 트렁크

#### 출처
- [호오컨설팅 (강사 섭외 플랫폼)](https://www.hooh.kr/)
- [강사인](https://www.gangsain.co.kr/) / [와이즈캐스팅](https://www.wisecasting.com/)
