### 1.2 서비스별 핵심 기능

#### 영어 단어 학습 (English Words)
- 레벨별 단어 학습 (초급~고급)
- 플래시카드 + 퀴즈 모드
- **자동 발음 재생 (TTS)**
- XP/레벨업 게이미피케이션
- 학습 통계 및 진행률 관리
- 모바일 반응형 디자인

#### 다국어 학습 (Universal)
- 일본어, 중국어, 영어, 스페인어, 프랑스어, 독일어 지원
- **MP3 원어민 발음 파일**
- 플래시카드 + 퀴즈
- 한국어 → 외국어 / 외국어 → 한국어 모드
- 레벨별 단어 분류

#### 운전면허시험
- 500+ 문제은행
- 모의시험 모드
- 오답 노트 기능
- 카테고리별 학습

#### 자격시험 가이드
- 30개+ 자격증 지원 (물류관리사, 무역영어, 국제무역사 등)
- 과목별 50문항 객관식
- 정답 및 해설 제공
- 시험 정보 안내

#### 메타인지 테스트
- 학생 자기인식 정확도 측정
- 학습전략 진단
- 5대 영역 분석 (계획, 점검, 조절, 평가, 자기인식)
- 맞춤형 학습 코칭 기초 자료

5. **커스터마이징**: 학원별 맞춤 단어장 구성 가능
6. **클라우드 기반**: 설치 없이 웹으로 즉시 사용
