## 1. 제품 개요

### 1.1 시스템 소개

**UTTEC 영업사원관리 시스템**은 외근 영업사원의 활동을 실시간으로 모니터링하고 관리할 수 있는 클라우드 기반 SaaS 솔루션입니다.

### 1.2 핵심 기능

| 기능 | 설명 |
|------|------|
| **방문 기록 관리** | 거래처 방문 일시, 담당자, 상담 내용, 사진 기록 |
| **GPS 위치 추적** | 영업사원 실시간 위치 확인 및 이동 경로 기록 |
| **거래처 관리** | 고객사 정보, 담당자, 연락처 통합 관리 |
| **관리자 대시보드** | 지도 기반 영업사원 현황 모니터링 |
| **모바일 앱** | 영업사원용 모바일 웹앱 (Android/iOS 호환) |
| **통계 리포트** | 일간/주간/월간 방문 통계, 영업 성과 분석 |

### 1.3 기술 스펙

- **서버**: Node.js + Express
- **데이터베이스**: SQLite (경량) / MySQL 확장 가능
- **프론트엔드**: 반응형 웹 (PC/태블릿/모바일)
- **지도**: Leaflet (OpenStreetMap)
- **배포**: 클라우드 서버 (DigitalOcean, AWS 등)

- **관리자 대시보드**: http://178.128.90.37:91
- **모바일 앱**: http://178.128.90.37:91/mobile

## 3. 경쟁 분석

### 3.1 경쟁 제품 비교

| 제품 | 가격 (월) | 장점 | 단점 |
|------|-----------|------|------|
| **Salesforce** | 25만원+/인 | 강력한 기능 | 고가, 복잡 |
| **영업관리 앱** | 5-10만원/인 | 전용 앱 | 커스터마이징 어려움 |
| **엑셀/구글시트** | 무료 | 익숙함 | GPS 불가, 분석 어려움 |
| **UTTEC** | **3-5만원/인** | 심플, GPS, 저렴 | 고급 기능 제한 |

### 3.2 UTTEC 차별점

1. **저렴한 가격**: 대기업 솔루션 대비 1/5 가격
2. **심플한 UI**: 교육 없이 바로 사용 가능
3. **GPS 기반 관리**: 실시간 위치 확인
4. **사진 첨부**: 방문 증빙 간편
5. **클라우드 기반**: 설치 불필요, 즉시 사용
