## 1. 시장 지형 & 의사결정 구조

### 1.1 시장 규모
- 국내 운영 골프장 **약 500개소 이상**(회원제 + 대중제). → 조명/수조 2대 시스템의 잠재 모수 충분.
- [리서치] 한국골프장경영협회(KGBA) 회원사 리스트·산악/야간운영 골프장 분류 → T3/T4 롱리스트 소스.

### 1.2 누가 결정하는가 (매우 중요 — 접점을 틀리면 진도 안 나감)

| 시스템 | 1차 접점(pain 보유) | 예산 승인 | 셀링 앵글 |
|---|---|---|---|
| **수조·급수** | **코스관리팀장/부장** (잔디 관수가 핵심 업무) | 총지배인(GM)·대표 | 인건비·야간 급수·오지 pond 자동화 |
| **조명** | **시설관리팀·야간운영 책임자** | 총지배인·대표 | 야간 영업 차질 방지·노후 AS |

> **실전 포인트**: 골프장 코스관리팀은 "잔디를 살리는 관수"가 생명이라 **수조/급수 자동화 pain이 실질적으로 가장 크다.** 수조를 선봉으로 문을 열고, 조명은 교차판매하는 순서가 유리.

## 2. 영업 파이프라인 (7단계 퍼널)

```
① 발굴(List)  →  ② 접촉(Outreach)  →  ③ 미팅(Discovery)  →  ④ 무료 RF 서베이/진단
   →  ⑤ 맞춤 제안·견적  →  ⑥ 계약  →  ⑦ 시공·레퍼런스화(→ 다음 발굴로 순환)
```

**각 단계의 게이트(다음으로 넘기는 기준)와 사용 자료:**

| 단계 | 목표 | 사용 자료 | 전환 게이트 |
|:--:|---|---|---|
| ① 발굴 | 타깃 리스트업 | 타깃전략 T1~T6 | 프로스펙트 명단 확보 |
| ② 접촉 | 관심 유발·미팅 약속 | **소개 동영상(141초)** + 1-page 후크 | 회신·미팅 수락 |
| ③ 미팅 | pain 확인·신뢰 구축 | 범용 제안서 + track record | 현장 방문 동의 |
| ④ 서베이 | **무료** 현장 RF/급수 진단 | 서베이 체크리스트 | 진단 리포트 수용 |
| ⑤ 제안 | 맞춤 견적 제시 | **인스턴스화 제안서**(현장명·홀·노드) | 견적 검토 착수 |
| ⑥ 계약 | 수주 | 계약서·3-tier 견적 | 서명 |
| ⑦ 시공 | 납품·만족 | 시공 SOP | **레퍼런스 확보** → ① 재투입 |

> **핵심 무기 = ④ 무료 RF 서베이/급수 진단**. "당장 사라"가 아니라 "무료로 현장을 봐드린다"가 문턱을 극적으로 낮춘다. 진단 리포트 자체가 다음 제안의 근거가 되고, UTTEC의 컨설팅 신뢰도를 증명.

## 3. 채널 전략 (4채널, 비용·전환율 순)

| 우선 | 채널 | 방식 | 전환율 | 비용 | 대상 |
|:-:|---|---|:-:|:-:|---|
| **1** | **Warm 레퍼런스 소개** | 광릉·용인 담당 라인 → 그룹 내 소개 | 🔥🔥🔥 | 무료 | T1 한림그룹 |
| **2** | **기설치 현장 재접촉** | UTTEC 조명 현장 AS 명분 방문 | 🔥🔥🔥 | 무료 | T2 노후조명 |
| **3** | **디지털 아웃리치** | 동영상 링크 + 이메일/문자 콜드 | 🔥 | 저 | T3~T4 신규 |
| **4** | **협회·전시회·파트너** | KGBA·잔디관리 업계·조경 시공사 제휴 | 🔥🔥 | 중 | 확산기(6개월+) |

**전략 요지**: 1인 조직은 **채널 1·2(warm)에 90% 집중**해 초기 레퍼런스를 빠르게 쌓고, 그 성공 사례로 채널 3·4(cold·확산)를 나중에 연다. 콜드부터 시작하면 소진된다.

## 4. 실행 웨이브 (순차 — 1인 부하 관리)

### 🌊 Wave 1 (0~2개월) — 한림그룹 warm + 필로스 클로징
- **한림안성CC** (T1, 미접촉 warm 1순위): 안성 조명/급수 현황 `[리서치]` → 그룹 레퍼런스로 **수조+조명 동시 제안**.
- **한림용인CC** 마무리 점검 방문 시 → **조명 교차판매** 타진 + 수조 만족도 확보(레퍼런스 강화).
- **필로스CC** 전체 교체 개선제안 클로징(별도 A트랙, live).
- 목표: warm 미팅 3건 / 무료 서베이 1~2건.

### 🌊 Wave 2 (2~5개월) — 노후 조명 재고 AS킷 확산
- UTTEC 기설치 현장(하나금융·광릉) 상태·AS 이력 `[리서치]` → "5년 노화기" 후크로 전체 교체 제안.
- 재사용 자산: 필로스 개선제안 구조(문제 4 + 개선 5원리 + AS 시나리오 + 견적) → 현장명·홀수만 교체.
- 목표: 재고 AS킷 표준 제안 2~3건.

### 🌊 Wave 3 (5~12개월) — 신규 골프장 콜드 + 확산
- T3(산악·야간조명)·T4(급수 수동운영 수조) 롱리스트 `[리서치]` → 동영상 디지털 아웃리치.
- 협회/전시회/조경 시공사 제휴 채널 개시 판단.
- T5(사옥·캠퍼스)·T6(비-골프 수조) 인접시장 cross-pitch.
- 목표: 콜드 파이프라인 10건 → 미팅 3건 → 수주 1~2건.

## 5. 아웃리치 템플릿 (즉시 사용)

### 5.1 디지털 콜드 (이메일/문자) — 4문장 룰
```
[후크]   야간 조명 고장 한 번이 곧 영업 차질입니다. / 여름철 야간·오지 급수, 아직 사람이 돌리십니까?
[신뢰]   UTTEC는 국내 최초 LoRa 조명 상용화(2018) 이래 한림그룹 다현장에서 8년 운영했습니다.
[차별]   서버·전기 없이 자율 제어 + 표준 케이스 공용 재고로 긴급 AS를 현장 1탭 복구로 전환합니다.
[제안]   90초 소개 영상 링크 → 관심 있으시면 무료 현장 진단 한 번 보내드리겠습니다. [동영상 URL]
```

### 5.2 Warm 소개 요청 (기존 담당 라인에게)
```
"한림용인 수조 잘 운영되고 있습니다. 같은 그룹 안성CC 쪽 코스관리 담당분 소개 한 번
 부탁드릴 수 있을까요? 조명·급수 무선 자동화 무료 진단만 먼저 보여드리려 합니다."
```

### 5.3 미팅 오프너 (현장)
- 소개 동영상 141초 재생 → track record 1페이지 → "무료로 현장 RF/급수 한 번 봐드리겠다".
- **판매하지 말고 진단을 판다.**

## 6. 반론 대응 (Objection Handling)

| 고객 반론 | 대응 |
|---|---|
| "무선은 자꾸 끊기지 않나?" | 산악 두절은 거리가 아니라 차폐(NLOS) 문제 → **hop↑ 설계**로 해결. lamp=공짜 중계기. 8년 운영 실적. |
| "통신 끊기면 펌프·조명 어떻게 되나?" | **자율 폐루프 + fail-safe**(두절 시 안전 정지). 서버 의존 최소. |
| "기존 업체·유선이 있다" | 유선 신설/보수 비용 vs 무선 무공사 + **재고 AS킷 긴급 복구** 경제성 비교. |
| "노후 AS가 걱정" | "1홀=1표준케이스" → 공용 재고로 **현장 1탭 교체**. SPOF 제거. |
| "가격이…" | 3-tier(초경제형/표준/산업급) + **2회차부터 개발비 절감** = 가격 경쟁력. ROI 회수 1~2년 근거 제시. |

## 7. 가격·제안 전략
- **3-tier 견적**(초경제형/표준/산업급 — 수명·하자보증 차등)으로 고객이 "살까 말까"가 아니라 "어느 등급"을 고르게.
- 단위 증분(조명 ≈40만/홀, 수조 노드 구성별) + 공통 고정비(게이트웨이·관제SW·용역) 프레임.
- **ROI 슬라이드**(제안서 3p) 필수 첨부: 조명 ~2년 / 수조 ~11개월 / 통합 ~1.1년 회수.
- 무료 서베이 → 실측 기반 정밀 견적으로 신뢰 확보(짐작 견적 금지).

## 10. 즉시 실행 액션 (다음 2주) ⭐
