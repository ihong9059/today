## 1. 무엇을 팔 것인가 — 2대 시스템 (prompt.txt 확정)

### 시스템 A. 무선 수조 관리
- 수원·pump가 tank(고지대)와 **원거리**에 분산 → 매번 수위 확인·수동 pump 조작 필요.
- **자동 수위 판단 + pump 자동 제어 + 원격 monitoring**으로 무인화. (한림용인CC 11노드 실증)

### 시스템 B. 무선 야간 조명 제어 ⭐ (핵심 신규 소구)
- 야간 개장 시 **마지막 팀 진행에 따라 미사용 hole 조명을 순차 소등**.
- 효과: ① **야간 조명 전력비 절감** ② 운영자가 직접 switch 끄러 가는 불편 제거 ③ **야간 이동 중 사고 최소화**.

### 공통 소구 — 안전(인적 사고 예방) ★
- 두 시스템 모두 골프장 지형상 **사고 위험 위치의 차단기/switch를 원격 제어** → 야간·우천·경사지 수동 조작 사고 예방. (전력비·편의를 넘는 **안전 가치** = 시설관리부서 설득 핵심)

## 2. 제안서 presentation 자료 (산출물 ①)

### 2.1 대상·톤
- 대상: 골프장 **시설관리부서**(비전문가 포함) — 기술 과시 금지, **운영 pain·비용·안전** 언어.
- 형식: 16:9 와이드 슬라이드(python-pptx) + PDF export. 범용본(고객사명 공란) + 프로스펙트별 표지 커스터마이즈.

### 2.2 슬라이드 구성(안) — 14매
| # | 슬라이드 | 핵심 |

| 3 | UTTEC 소개 | **국내 최초 LoRa 조명 상용화(2018)** + 한림그룹 다현장 8년 |
| 4 | 2대 시스템 개요 | 수조 + 야간조명 = 하나의 무선 제어 인프라 |
| 5 | 시스템 A 수조 | 자동 수위→pump 제어+monitoring (한림용인 11노드 실증 사진) |
| 6 | 시스템 B 조명 | 마지막 팀 추적 순차 소등 다이어그램 + 전력비 절감 |
| 7 | ★ 안전 가치 | 위험 위치 원격 차단 = 야간 이동·수동 조작 사고 예방 |

### 2.3 제작 방법 (기존 자산 재사용)

- 다이어그램: 순차 소등·수조 cascade는 도식 이미지(간단 SVG/PNG). lora vault 토폴로지·스냅샷 참조.
- PDF export(맑은고딕) — 기존 ReportLab/변환 스크립트 패턴.

## 3. 쉬운 설명 동영상 (산출물 ②)

### 3.1 컨셉
- **3~5분 내레이션 슬라이드 영상**(비전문가용). 스토리: pain → 이렇게 작동 → 효과(비용·편의·안전) → UTTEC 신뢰.
- 톤: 시설관리 담당자가 "우리 골프장 얘기네" 공감하도록 야간 라운드·수조 급수 실장면 언어.

### 3.2 스토리보드(안) — 6컷
| 컷 | 장면 | 내레이션 요지 |
|:-:|---|---|
| 1 | 야간 골프장, 꺼야 할 조명 | "마지막 팀이 지나간 홀, 누가 끄러 갑니까?" |
| 2 | 순차 소등 애니메이션 | "팀 진행 따라 자동으로 하나씩 꺼집니다 — 전기요금·수고 절감" |
| 3 | 고지대 수조·원거리 pump | "물탱크 수위, 매번 확인하고 펌프 켜셨죠" |
| 4 | 자동 급수+대시보드 | "이제 스스로 판단해 급수하고, 폰으로 봅니다" |
| 5 | ★ 안전 | "위험한 경사지 차단기, 밤에 가지 않아도 원격으로" |
| 6 | UTTEC 신뢰·CTA | "2018 국내 최초, 한림그룹 다현장 8년 — 무료 현장 진단" |

### 3.3 제작 방법 (기존 자산 재사용)
- **내레이션 TTS**: `ko-KR-InJoonNeural`(edge-tts, 동아정밀 mp4 SOP 재사용, rate +5%).
- **영상 합성**: 슬라이드/도식 이미지 + TTS → ffmpeg 합성 (또는 `remotion-project`/`ai-lesson` 스킬 파이프라인).
- 1920×1080 30fps, 한글 자막 옵션.
