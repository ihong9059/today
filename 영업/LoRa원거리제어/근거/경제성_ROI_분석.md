# LoRa 무선 통합 제어 — 경제성(ROI) 분석

> **작성**: 2026-07-05 | **용도**: 제안서 경제성 슬라이드 + 고객 ROI 설득 근거
> **원칙**: 도입 비용은 사용자 제시 기준값(확정), 요금은 공개 자료(web), 운영량은 **현장별 조정 가정**으로 명시 구분. 지어낸 확정치 없음.

## 2. 시스템 ② 야간 조명 ROI (18홀 예시)

**핵심 논리**: 마지막 팀이 코스를 빠져나가는 데 5시간이 걸리면, 순차 소등 시 각 홀은 평균 절반(2.5시간)만 켜져 있음 → 야간 마감 구간 조명 전력 **평균 50% 절감** + 수동 소등 인건비 제거.

### 투자
- 조명 제어 18홀 × 50만 = 900만
- 현장 검토비 50만 + 설치비 350만
- **합계 1,300만원**

### 연간 절감
| 항목 | 계산 | 금액 |
|---|---|---|
| 전력 | 36 kW × 2.5h × 150일 × 160원 = 13,500 kWh | **216만원** |
| 인건비 | 1.5h × 150일 × 20,000원 | **450만원** |
| **연간 절감 합계** | | **666만원/년** |

### 결과
- **회수기간 ≈ 1.95년 (약 23개월)**
- 5년 순이익 = 666만×5 − 1,300만 = **2,030만원**
- 연 ROI ≈ **51%**

---

## 3. 시스템 ① 수조 관리 ROI (2 set 예시)

**핵심 논리**: 원거리·고지대 수조 수위를 사람이 순회 점검하던 인건비 제거 + 물 부족으로 비싼 긴급 상수도를 끌어 쓰던 비용 회피.

### 투자
- 수조 2 set × 150만 = 300만
- 현장 검토비 50만 + 설치비 350만
- **합계 700만원**

### 연간 절감
| 항목 | 계산 | 금액 |
|---|---|---|
| 인건비(수위 순회 점검) | 1.0h × 300일 × 20,000원 | **600만원** |
| 긴급 상수도 회피 | 1,500㎥ × 1,300원 | **195만원** |
| **연간 절감 합계** | | **795만원/년** |

### 결과
- **회수기간 ≈ 0.88년 (약 11개월)**
- 5년 순이익 = 795만×5 − 700만 = **3,275만원**
- 연 ROI ≈ **114%**

## 4. 통합 도입 (18홀 조명 + 수조 2set)

검토비·설치비를 한 번만 부담 → 통합 시 회수 더 빠름.
| 항목 | 값 |
|---|---|
| 투자 | 조명 900 + 수조 300 + 검토 50 + 설치 350 = **1,600만원** |
| 연간 절감 | 666 + 795 = **1,461만원/년** |
| 회수기간 | **약 1.1년 (13개월)** |
| 5년 순이익 | 1,461만×5 − 1,600만 = **5,705만원** |

---

## 5. 민감도 / 주의

- 절감액은 **조명 부하·야간 개장일수·인건비 단가·긴급 상수도 사용량**에 비례. 위 예시는 보수적 중간값. 야간 개장이 많거나(200일+) 조명 부하가 크면 회수기간은 더 짧아짐.
- 도입 비용은 제어점(홀/set) 수에 선형. 규모가 커질수록 검토·설치 공통비가 희석되어 단위 ROI 개선.
- 실제 제안 시 ① 해당 골프장 전기·수도 고지서 단가 ② 실제 야간 개장일수·조명 부하 ③ 현재 수동 점검·소등 투입 인력으로 파라미터 대체 → 현장 맞춤 ROI 확정.
