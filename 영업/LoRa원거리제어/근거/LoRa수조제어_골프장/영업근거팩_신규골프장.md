## 0. 한 줄 세일즈 메시지

> **"게이트웨이·본부 서버 없이 자율 동작하는 저비용 무인 LoRa 수조 제어망을, 실제 운영 골프장(한림용인CC 14노드)에서 양산 적용·현장 실증까지 검증했습니다."**

경쟁 대비 차별점 = ① **인프라 투자 없이 도입**(서버/통신망 불요) ② **전기 인입 없는 오지 수조까지**(솔라 무전원) ③ **센서→제어→가시화 턴키** ④ **실측 데이터로 커버리지 보증**.

---

## 1. 핵심 판매 포인트 5 (검증된 근거)

### ① 실증 레퍼런스 — "이미 운영 중인 골프장 현장"
- 한림용인CC **14노드 2단 cascade**(pond → 하수조 → 고수조 → 스프링쿨러). 루비 1유닛 + 사파이어 2유닛(고수조 공유).
- 현장 flash·설치·통신 검증 완료. → **레퍼런스 세일즈**: "데모가 아니라 운영 현장"이라는 신뢰 근거.
- 한림그룹 재거래 이력(2020 한림광릉CC 무선 조명제어 → 2026 한림용인CC 무선 수조제어)도 "무선 인프라 다목적 활용" 스토리로 동반.

### ② 자율 제어 아키텍처 — 서버·게이트웨이 의존 최소
- **각 센서가 자기 목표수위(NVS 저장)로 자기 수위를 판단** → PUMP_ON/OFF를 LoRa broadcast → 로컬 펌프가 즉시 추종.
- 본부 능동 제어 없이 **현장 노드끼리 폐루프 자율 운전**, 통신 두절에도 fail-safe(펌프 OFF).
- **세일즈 함의**: 통신망·서버 인프라 투자 0 → 신규 고객 **진입장벽↓·유지비↓**.

### ③ 저전력 + 솔라 무전원 — 전원 없는 오지 수조 대응
- `-DLOW_POWER` duty-cycle 절전 → **소비전류 12mA 수준 실측**(ESB 절전 버그 수정 22→12mA). 추가 절감 진행 중.
- battery + solar 전원체인 → **상용 전원 없는 원격 수조에 무선·무전원 설치**. 솔라 패널 용량 산정 근거 확보.
- **세일즈 함의**: 전기 인입 불가/고비용 지점(외곽 pond·중계 노드)까지 사업 커버리지 확장.

### ④ 통합 제품 스택 — 센서·통신·제어·모니터링 턴키
- RS485 수위센서(Modbus) + LoRa 백홀(장거리) + 2.4G 로컬링크(그룹 내 펌프 즉시제어)를 **단일 nRF52832 펌웨어**로 통합(UARTE PSEL time-mux).
- **현장 BLE 프로비저닝 앱**: 단일 펌웨어 이미지 + 앱으로 역할·주소·목표수위 현장 설정 → 노드별 재빌드 불요, 설치·유지보수 단순.
- **원격 모니터링**: RPi 웹 대시보드(수위/배터리 2일 차트) + nRF9160 LTE 게이트웨이(원격 백홀·GPS 옵션).
- **세일즈 함의**: "센서→제어→가시화" 턴키 = 다업체 조합 없이 단일 책임.

### ⑤ RF 링크 실증 데이터 — 커버리지 보증
- CH72 공유, **PER 0% RF 링크 실측**(통신점검 도구), RSSI 마진 데이터 확보.
- **폐쇄공간(문 닫힘)에서 2.4G 로컬링크 통과 실증**(설계 우려점을 현장 데이터로 해소).
- **세일즈 함의**: "실측으로 커버리지 보증" + 경계 지점은 **안테나 배치 컨설팅** 포함.

## 2. 정직 고지 3건 → 컨설팅 강점으로 전환

lora-claude가 기술 단일출처로서 과장 없이 고지한 3가지. **약점이 아니라 "제대로 설계·시공하면 해결되는 엔지니어링 변수"** → 영업 시 오히려 기술 신뢰도·컨설팅 역량으로 전환.

| 기술 한계 | 영업 프레이밍 (제안 반영) |
|---|---|
| **LoRa 채널 충돌** — CH72 단일채널·TDMA 미구현, 노드 수↑ 시 loss%↑ (14노드에서 관측) | 대형 현장은 "**규모 상한·중계 설계·트래픽 절감/TDMA**"를 제안에 명시. 현장 규모별 토폴로지 설계 = 우리 컨설팅 가치 |
| **커버리지 경계 마진** — 안테나 제거 시 두절되는 경계 지점 존재 | "**현장 사전 RF 서베이 + 안테나 배치**"가 도입 품질을 좌우 → 사전 서베이를 제안 표준 단계로 |
| **RS485 센서 개체·결선 편차** — 현장 하드웨어/결선에 따라 무응답 사례 | "**설치 SOP + 현장 점검 도구**(보드점검·RF 링크 점검) 동반" → 시공 품질 보증 프로세스 보유 |

→ 3건 모두 **"우리는 이 변수를 알고, 도구·SOP로 관리한다"**는 메시지로 = 검증 안 하고 제안만 하는 경쟁 대비 차별화.

## 3. 타깃 고객 & 접근 시나리오

| 타깃 | 매칭 근거 | 접근 |
|---|---|---|
| **한림그룹 산하 타 골프장** | 재거래 신뢰 + 동일 솔루션 복제 | 한림용인CC 만족도 확인 → 그룹 내 레퍼런스 소개 요청 |
| **NLOS·오지 수조 보유 골프장** | 솔라 무전원 + 자율제어 결정타 | "전기 없는 외곽 pond까지 무선 관수" 소구 |
| **급수·관수 수동 운영 골프장** | 인건비·야간 운전 절감 | 자율 폐루프 = 무인화 소구 |
| **비-골프 무인 수조**(농업 저수조·양식·상수도 소규모) | 동일 아키텍처 재사용 | 노지관리 신사업([[revita]] 위성 fusion)과 cross-pitch |

## 4. 제안서 스켈레톤 (프로스펙트별 커스터마이즈)

> 실제 미팅/제안 발생 시 아래 목차로 문서 생성. §1·§2를 근거로 채운다.

1. **표지** — {고객사}_무선 수조 제어망 제안 / UTTEC
2. **문제 정의** — 고객 현장의 급수 운영 pain (수동 운전·야간 인건비·오지 전원·정전 리스크)
3. **솔루션 개요** — 자율 LoRa 제어망 1페이지 다이어그램 (pond→저수조→고수조→관수)
4. **실증 레퍼런스** — 한림용인CC 14노드 사진/토폴로지 + "운영 중 현장" 신뢰 근거
5. **핵심 가치 5** — §1의 5 포인트를 고객 현장 언어로 (인프라 0·오지 솔라·턴키·커버리지 보증)
6. **현장 적용 설계** — 고객 부지 규모 → 노드 수·중계 배치·RF 서베이 계획 (§2 규모 상한 반영)
7. **품질 보증 프로세스** — RF 서베이 → 설치 SOP → 점검 도구 → 하자보증 (§2 컨설팅 강점)
8. **견적** — §5 규모별 프레임 (초경제형/표준/산업급 3-tier)
9. **일정 & 책임범위** — 답사→개발→시공→점검, 하자보증 한계 명시
10. **UTTEC 자격** — 한림광릉/한림용인 이력 + LoRa 4종 모듈 풀스택 + 양산 인증 경험

## 5. 견적 프레임 (규모별 3-tier — 한림 초경제형 기준선)

한림용인CC = **초경제형 1,000만원**(VAT 별도, 산업급의 28% 자재) 기준선. 신규 현장은 규모·환경으로 스케일.

| tier | 자재 등급 | 수명/하자 | 적용 |
|---|---|---|---|
| **초경제형** | 산업급 28%(RPi4 산업형·Heltec·저가 압력센서) | 5~7년 / 6개월 | 소규모·예산 제약 (한림용인 기준) |
| **표준** | 산업급 LoRa·4-20mA 센서·솔라 중계 | 8~10년 / 1년 | 중규모·NLOS 다수 |
| **산업급** | 임베디드 컨트롤러·태블릿 HMI·풀 제어반 | 10~15년 / 1~2년 | 대형·무인 안정성 최우선 |

- 규모 확대 시 **TDMA·중계 설계** 추가공수를 별도 라인으로 (§2 채널 충돌 대응).
- 개발비(펌웨어)는 통합펌웨어·BLE 프로비저닝 재사용으로 **2회차부터 절감** = 가격 경쟁력.
