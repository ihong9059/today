## 0. 한 줄 세일즈 메시지

> **"게이트웨이·본부 서버에 최소 의존하는 저비용·무인 LoRa 원거리 제어 인프라를, 국내 최초 상용화(2018) 이래 조명·수조 두 분야 실제 현장에서 8년간 양산·운영 검증했습니다."**

경쟁 대비 차별점 = ① **8년 track record·국내 최초**(단발 벤더 아님) ② **표준 단일 케이스 + 현장 앱 설정**(재고로 긴급 AS 현장 즉시 복구) ③ **인프라 투자 최소**(자율제어·상시전원 lamp-as-relay) ④ **실측 데이터 커버리지 보증** ⑤ **수위 변화 추적으로 누수·이상 조기 진단**(수조, 플로트식 불가).

## 2. 공유 플랫폼 — 두 시스템이 같은 기술 스택

조명·수조는 **동일한 LoRa 원거리 제어 플랫폼** 위의 두 응용. 한 번 검증한 스택을 재사용하므로 신규 응용의 개발비·리스크가 낮다.

| 플랫폼 요소 | 내용 | 조명 | 수조 |
|---|---|:-:|:-:|
| **단일 binary 통합 펌웨어** | 모든 케이스가 완전히 동일한 펌웨어, 부팅 시 NVS role 분기 | ✅ | ✅ |
| **BLE 현장 프로비저닝 앱** | 스마트폰 앱으로 담당 홀·주소·목표치 현장 설정(케이블·노트북 불요) | ✅ | ✅ |
| **자율 제어(폐루프)** | 노드가 스스로 판단·구동, 통신 두절에도 fail-safe | (스케줄/명령) | (수위 폐루프) |
| **multi-hop relay** | 지형 우회 hop 체인(수조 ACK 도청·listen-before-forward·turnaround guard) | ✅ (lamp=relay) | ✅ (중계 2단) |
| **원격 모니터링** | RPi 웹 대시보드 + LTE 게이트웨이(원격 백홀·GPS 옵션) | ✅ | ✅ |
| **저전력·솔라** | 배터리+솔라 전원체인(무전원 오지) | (상시전원) | ✅ (12mA 실측) |

→ **"조명으로 8년 검증한 통신·프로비저닝 스택을 수조에 그대로 얹었다"** = 신규 응용도 검증된 기반 위에서 안전.

## 3. 시스템 A — LoRa 무선 조명 제어

### 3.1 세일즈 포인트
- **국내 최초(2018) + 다현장 코스 전체 운영 실적**(필로스·광릉·하나금융).
- **산악 골프장 야간 조명 = LoRa 최적 응용**: lamp는 AC 상시전원 → **모든 lamp가 공짜 중계기**(lamp-as-relay). 별도 중계기 최소화. (`기술/망구성/1_산악골프장_야간lamp_제어망_검토.md`)
- **지형 우회 설계 노하우**: 산악 두절은 "거리"가 아니라 "차폐(NLOS)" 문제 → 출력↑이 아니라 **hop↑**(카트로 따라 짧은 hop 체인 + 능선 backbone 2계층). "흔히 틀리는 부분을 우리는 안다" = 컨설팅 신뢰도.

### 3.2 ⭐ live 기회 — 필로스CC 전체 교체 (개선제안 초안 완료)
- **상황**: 2020년 설치 5년 경과 → 부품 노화기 진입. hole 2(서3)·hole 13(동7) lamp 불안 → 출장 예정.
- **현 시스템 문제(고객 확인)**: "1 LoRa 노드 = 다(多)홀" 구조 → 노드별 비표준(프로토콜·펌웨어·매핑 제각각) → **AS 시 노드별 펌웨어·재방문, 공용 예비품 불가, 단일 고장이 여러 홀 동시 정전(SPOF)**.
- **개선안**: **"1홀 = 1 표준 케이스"** 전체 교체 — 동일 펌웨어 + 현장 앱으로 담당 홀 설정 → **공용 재고 예비품으로 긴급 AS 현장 1탭 복구**(출장 1회·수십 분).
- **견적(초안, 27홀 가정)**: 하드웨어 1,820만 + 용역 450만 = 공급가 2,270만 / **총 24,970,000원(VAT 포함)**. 홀당 증분 ≈ 40만원/홀(케이스, 설치공사 별도). → 상세 `lora:현장/필로스CC/개선제안_AS재고킷_2026-06-26.md`.
- **확정 전 미결**: 실제 제어점 수 / 중앙 제어부 교체 범위 / 배전반 부하 / 중계기 수(RSSI 실측) / hole 2·13 원인.

### 3.3 조명 세일즈의 핵심 무기 = "재고 AS킷"
> "야간 조명 고장 = 즉시 영업 차질." → **표준 케이스 + 공용 재고**로 현장 즉시 교체. 골프장 운영 긴급성에 정확히 대응하는 차별화. **이 논리는 노후 LoRa 조명 보유 다른 골프장·사옥에 그대로 재사용**.

## 4. 시스템 B — LoRa 무선 수조 제어

### 4.1 세일즈 포인트
- **실증 레퍼런스**: 한림용인CC **14노드 2단 cascade**(pond→하수조→고수조→스프링쿨러), 설치 완료·다음주 마무리 점검. "운영 현장" 신뢰 근거.
- **자율 제어**: 각 센서가 자기 목표수위(NVS)로 판단 → PUMP_ON/OFF broadcast → 로컬 펌프 즉시 추종. 서버 없이 폐루프, 통신 두절에도 안전(펌프 OFF).
- **저전력·솔라 무전원**: 12mA 실측 + battery/solar → **전기 없는 외곽 pond·중계 노드**까지 커버.
- **통합 스택 턴키**: RS485 수위센서 + LoRa 백홀 + 2.4G 로컬링크 단일 펌웨어 + RPi 대시보드.
- ⭐ **수위 변화 추적 → 누수 조기 진단**(2026-07-11 용인 실증): 플로트(오뚜기)식 max/min 이산 감지와 달리 수위를 연속 추적 → **관수 미작동 중 수위 하강 = 배관 누수** 조기 포착. 증상 대응이 아닌 **원인 진단**(예방정비). 상세 = 수조 근거팩 §1-⑥.

### 4.2 타깃
한림그룹 산하 타 골프장 / NLOS·오지 수조 보유 골프장 / 급수 수동운영 골프장 / 비-골프 무인 수조(농업 저수조·양식·소규모 상수도, 노지관리 신사업 cross-pitch).
