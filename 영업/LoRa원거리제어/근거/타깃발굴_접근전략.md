# UTTEC LoRa 원거리 제어 — 타깃 발굴 & 접근 전략 (2대 시스템 마케팅 확산)

> **작성**: 2026-07-05 | **상위**: `영업/LoRa원거리제어/근거/영업근거팩_2대시스템.md`
> **목적**: 조명+수조 2대 시스템 근거 팩 + 8년 track record + "재고 AS킷" 논리를 무기로 **신규 타깃을 발굴·접근**한다.

## 0. 확산 논리 (왜 지금 확산인가)

- UTTEC는 단발이 아니라 **8년 LoRa 원거리 제어 track record**(2018 국내최초 → 조명 다현장 → 2026 수조). → "검증된 회사"로 신규 타깃 설득력 확보.
- **재고 AS킷 논리**(1홀=1표준케이스 + 앱 설정 + 공용 재고 → 긴급 AS 현장 1탭)는 필로스CC 개선제안에서 정립 → **노후 LoRa 조명을 가진 모든 현장에 그대로 재사용 가능한 세일즈 무기**.
- 두 레퍼런스(조명 필로스/광릉, 수조 한림용인)로 **같은 고객에게 교차 판매**(조명 하는 곳에 수조, 수조 하는 곳에 조명) 가능.

## 2. T1 — 한림그룹 계열 (가장 따뜻함) ⭐

한림그룹 계열 골프장 (웹 확인 2026-07-05):

| 골프장 | 위치 | UTTEC 관계 | 액션 |
|---|---|---|---|
| 한림광릉CC | 경기 남양주 진접읍 팔야로 280 | **2020 LoRa 조명 설치**(기존) | 노후 AS 재고킷 전체 교체 제안 (5년 경과) |
| 한림용인CC | 경기 용인 처인구 경기동로 628 | **2026 수조 설치**(진행) | 점검 후 **조명 교차 판매** + 수조 만족도 레퍼런스 |
| **한림안성CC** | 경기 안성 양성면 산정리 산163-22 | **미접촉 추정** ⭐ | **신규 접근 1순위** — 그룹 레퍼런스로 조명/수조 동시 제안 |
| 필로스CC | 경기 포천 일동면 운악청계로 1507 | **2020 LoRa 조명**(개선 live) | 전체 교체 개선제안 확정(별도 A트랙) |

- [리서치] **한림안성CC의 야간 조명/급수 인프라 현황** 확인(자체 확인 or 그룹 채널) → 제안 시나리오 확정.
- [리서치] 한림그룹 계열 추가 골프장/리조트 유무(레저 계열사 전체) 확인.
- **접근 경로**: 용인·광릉 담당 라인을 통한 그룹 내 소개가 콜드콜보다 우선.

## 3. T2 — 노후 LoRa 조명 현장 (재고 AS킷 확산) ⭐

필로스CC와 동일 pain(2018~2020 설치 → 5년+ 노후 → 부품 단종·AS 긴급성)을 가진 현장에 **전체 교체 + 재고 AS킷**을 표준 제안으로.

- **1차 후보 = UTTEC 자체 기설치 현장** (track record §1): 하나금융 글로벌캠퍼스('19)·광릉('20)·필로스('20). → [리서치] 각 현장 조명 시스템 현 상태(노후·AS 이력) 확인.
- **후크 메시지**: *"설치 5년 경과 부품 노화기 — 노드별 비표준 구성은 AS 비용·야간 정전 리스크가 비선형 증가. 표준 케이스+공용 재고로 긴급 AS를 현장 1탭 복구로 전환."*
- 재사용 자산: 필로스 개선제안 구조(문제점 4 + 개선 5원리 + AS 시나리오 + 견적 프레임) → 현장명·홀수만 교체.

---

## 4. T3~T4 — 신규 골프장 (조명 / 수조)

- **T3 조명**: 산악·야간 운영 골프장. 후크 = "야간 조명 두절 = 즉시 영업 차질 → lamp-as-relay 무선 제어 + 재고 AS". 지형 우회(hop↑) 설계 노하우로 차별화.
- **T4 수조**: 급수 수동운영·오지 pond 보유 골프장. 후크 = "서버·전기 없이 자율 급수 + 한림용인 14노드 실증". 솔라 무전원이 결정타.
- [리서치] 산악/퍼블릭 골프장 리스트 + 야간 라운드 운영 여부(공개 정보) → T3/T4 롱리스트 작성.

---

## 5. T5~T6 — 인접 시장

- **T5 사옥·캠퍼스·산업단지 조명**: 하나금융 레퍼런스로 골프장 밖 확산. 무선 조명 관제 + 재고 AS.
- **T6 비-골프 무인 수조**: 농업 저수조·양식장·소규모 상수도. [[revita]] 노지관리 신사업(위성 fusion)과 cross-pitch. 자율제어+솔라 무전원 = 무인 관제.

---

## 6. 세그먼트별 아웃리치 템플릿 (1-page)

각 접근 시 근거 팩 §해당 시스템 + 아래 3요소:

1. **후크(1문장)** — 고객 pain 직격 (야간 조명 고장 / 수동 급수 / 노후 AS).
2. **신뢰(1문장)** — "국내 최초 LoRa 조명 상용화(2018), 한림그룹 다현장, 8년 운영."
3. **차별(1문장)** — "표준 케이스+공용 재고로 긴급 AS 현장 1탭 / 서버·전기 없는 자율제어."
4. **제안** — 무료 현장 RF 서베이 or 개선 진단 미팅 → 견적.

> 실제 발송 문서는 프로스펙트별 제안서 스켈레톤(근거팩 §6)으로 인스턴스화.

## 7. 실행 순서 (권장)

1. **[즉시] T1 한림안성CC** — 그룹 레퍼런스 가장 강함. 안성 조명/급수 현황 확인 → 조명+수조 동시 제안서 인스턴스화.
2. **[병행] T2 재고 AS킷** — UTTEC 기설치 노후 현장(광릉·하나금융) 상태 확인 → 전체 교체 제안 표준화.
3. **[누적] T3~T6 롱리스트** — 리서치로 후보 축적 후 우선순위 재평가.
4. **[지원] lora 역요청** — 도달거리·BOM·loss 곡선·솔라 용량으로 제안 수치 보강(근거팩 §8).
