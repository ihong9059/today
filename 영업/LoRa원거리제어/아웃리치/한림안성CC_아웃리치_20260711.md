## 1. 셀링 앵글 (한림안성 맞춤)

**한 문장**: "같은 한림 그룹 용인CC에 이번 주 무선 수조제어를 설치합니다. 서버·전기공사 없이 조명과 급수를 **한 대의 컨트롤러**로 자율 제어하는 시스템을, 안성CC도 **무료 현장 진단**부터 보여드리고 싶습니다."

- **그룹 레퍼런스**: 한림용인 14노드 LoRa 수조제어 실증(다음 주 설치) → "같은 그룹, 검증된 시스템"으로 신뢰 문턱 제거.
- **공용 시스템 보드 강점**(7/9 흡수): 조명·수조를 별개 업체 2곳이 아니라 **UTTEC 단일 HW 플랫폼**으로 통합 → 재고·AS·관제 일원화. 조명 선(先) 또는 수조 선(先) 어느 쪽으로도 문 열고 교차판매.
- **9홀 퍼블릭** = 대형 대비 의사결정 단순·도입 규모 부담 적음. 소규모 파일럿→그룹 확산 레퍼런스로 이상적.

## 6. 참고 ROI (9홀 기준 illustrative — 파라미터는 현장 진단 확정) `[리서치]`

> 아래는 근거팩 `../근거/경제성_ROI_분석.md` 모델을 9홀로 스케일한 **예시**. 실제 수치는 무료 서베이로 야간 개장일수·조명 부하·수조 유무·고지서 단가 확정 후 대체. **콜드 단계에서 확정치로 제시 금지.**

| 구성 | 투자(예시) | 비고 |
|---|---|---|
| 조명 9홀 제어 | 9홀×50만 = 450만 + 검토50 + 설치350 = **850만** | 야간 개장 시. 순차소등 절감+인건비 |
| 수조 2 set | 2×150만 = 300만 + 검토50 + 설치350 = **700만** | 원거리/고지대 수조 있을 때 |
| **통합**(검토·설치 1회) | 450+300+50+350 = **1,150만** | 회수기간 조명~2년/수조~1년 수준(18홀 모델 기준, 9홀은 개장일수·부하로 변동) |
