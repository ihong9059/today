## 사업 전환 배경

UTTEC은 2016년 설립 이래 **BLE Mesh 기반 LED 무선 조명제어** 사업을 영위해왔으나,
중국 저가 공세(동일 기술 1/3~1/5 가격)와 국내 조명제어 인프라 시장 소멸로
2026년 4월 **AI 3대 사업으로 전환**을 선언했습니다.

```
[과거] LED 무선 조명제어 (BLE Mesh → LoRa)
  ↓  중국 저가 + 인프라 소멸
[현재] AI 3대 사업 기반 구축
  ↓
[중기] AI 교육 상용화 + 스마트팩토리 첫 고객 + AI 제품 MVP
  ↓
[장기] "AI + 하드웨어 통합 솔루션" 전문 기업
```

**핵심 역량(무선 통신 + 임베디드 + 시스템 통합)은 보존, 적용 시장만 전환.**

## AI 3대 사업 라인

### 1. AI 프로그래밍 교육 (1순위 — 수익화 거리 짧음)

| 항목 | 내용 |
|------|------|
| **정의** | AI와 협업하는 코딩 교육 + 하드웨어 키트 + 영상 강의 패키지 |
| **타겟 고객** | 중소기업 종업원, 초중고 학생, 성인 교육, 기업 연수 |
| **수익 모델** | 교육 과정 수강료 + 하드웨어 키트 판매 |
| **핵심 차별점** | "하드웨어 연동 AI 교육" = 경쟁자 희소 |

**보유 자산:**

| 자산 | 상태 | 상세 |
|------|------|------|
| AI 교육 커리큘럼 | 운영 중 | Level 0~9, 4 Track, 765일 분량 |
| 사전빌드 시스템 | 운영 중 | WROOM 155개 + Mini 117개 + C6-LCD 105개 = 377개 항목 |
| 교육 웹 플랫폼 | 운영 중 | ai-education-web (DigitalOcean 배포) |
| Remotion 레슨 비디오 | 제작 중 | 30편+ 완성 |
| Python Vibe 교육앱 | 완성 | 100개 예시, AI 코드 생성+실행+설명 |
| RPi 공장자동화 교육 | 신규 | 8일 32시간 커리큘럼 + 교육자료 8종 완성 |
| multiCore 교육 시스템 | 검증 완료 | Odroid C2에서 3명 동시 Claude Code 사용 |

**세부 사업 영역:**

#### 1-A. 중소기업 AI 공장자동화 교육

| 항목 | 내용 |
|------|------|
| 대상 | 용인 중소기업진흥원 등 지역 교육 기관 |
| 과정 | RPi 3B+ + UTTEC Shield, 8일 x 4시간 = 32시간 |
| 내용 | Python → 센서 → LED/부저 → LoRa → 웹 → AI(CNN) → 종합 프로젝트 |
| 키트 단가 | 약 12만원/인 (교육 후 가져감) |
| 산출물 | 커리큘럼, 포트맵, 기능목록, 동영상 시나리오, 대사, 설명자료, LoRa 매뉴얼 |

#### 1-B. ESP32 바이브코딩 교육

| 항목 | 내용 |
|------|------|
| 대상 | 초중고 학생, 코딩 교실, 방과후 학교 |
| 과정 | ESP32 + UTTEC 보드, AI와 함께 코딩 |
| 내용 | 사전빌드 즉시 체험 → AI 코드 생성 → 하드웨어 제어 |
| 차별점 | 문법 암기 X, AI 활용 O |

#### 1-C. 온라인 AI 교육 플랫폼

| 항목 | 내용 |
|------|------|
| 대상 | 개인 학습자, 성인 |
| 과정 | 웹 기반 자기주도 학습 |
| 내용 | 37개 코스, Level 0~9 커리큘럼, 레슨 비디오 |
| 플랫폼 | ai-education-web (Next.js, DigitalOcean) |
