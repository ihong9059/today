### 2.1 Quizlet (퀴즐렛)

#### 기본 정보

| 항목 | 내용 |
|------|------|
| **본사** | 미국 샌프란시스코 |
| **설립** | 2005년 |
| **사용자** | 전 세계 6억+ 사용자 |
| **플랫폼** | 웹, iOS, Android |
| **웹사이트** | [quizlet.com](https://quizlet.com/kr) |

#### 서비스 개요

- 처음 간단한 플래시카드 도구로 시작
- 현재는 플래시카드, 연습 퀴즈, AI 기반 튜터링까지 제공
- 글로벌 최대 학습 플랫폼 중 하나

#### 가격 정책

| 플랜 | 가격 | 주요 기능 |
|------|------|----------|
| **무료** | $0 | 플래시카드, 연습문제 (광고 포함, 35문제 제한) |
| **Quizlet Plus** | 월 ~$3 (연간) | 광고 제거, 무제한 학습, 오프라인 모드 |
| **Quizlet Plus for Teachers** | 연간 $35.99 | Class Progress, Quizlet Live, 학생 진도 추적 |
| **단체 플랜** | 수량별 할인 | 2개 이상 구매 시 할인 적용 |

#### 주요 기능

**무료 기능**:
- 플래시카드 생성 및 학습
- 연습 문제 (5라운드 35문제 제한)
- 대화형 다이어그램

**유료 기능 (Quizlet Plus)**:
- 고급 세트 생성
- 학습 도우미 및 스마트 채점
- 학습 진행률 확인
- 오프라인 학습 모드
- 광고 제거

**교사용 기능**:
- Class Progress: 학생 학습 활동 및 최고 점수 확인
- Quizlet Live: 실시간 게임 기반 학습
- 학생 진도 추적 리포트

#### 강점 및 약점

| 강점 | 약점 |
|------|------|
| 글로벌 최대 사용자 기반 | 한국어 지원 부족 |
| 다양한 사용자 생성 콘텐츠 | 무료 버전 기능 제한 |
| AI 기반 학습 기능 | 한국 교육과정 연계 부족 |
| Quizlet Live 게임 | 원화 결제 불편 |

#### 기본 정보

| 항목 | 내용 |
|------|------|
| **운영사** | (주) 클래스카드 |
| **대표** | 김준수 |
| **위치** | 서울 강남구 테헤란로 63길 11 이노센스빌딩 12층 |
| **플랫폼** | 웹, iOS, Android |
| **웹사이트** | [classcard.net](https://www.classcard.net) |

#### 시장 점유율

- **"대한민국 영어쌤 1/3이 선택한 스마트 단어장"**
- 11만명의 영어 선생님 사용
- 230만 학생 이용

#### 서비스 특징

- 선생님이 만들어 우리반이 함께 공부하는 스마트 플래시카드
- 영어뿐 아니라 국어, 사회, 기술가정, 체육 등 다양한 교과 활용
- NE능률, 웅진 등 국내 No.1 출판사 교재 700권 수록

#### 주요 기능

**선생님용**:
1. 과학적인 3단계 암기학습
2. 700권 교재 공식 단어장 무료 제공
3. 자동 출제 시험 기능 '테스트'
4. 학생 학습기록/시험결과 실시간 리포트
5. 스피킹, 연습문제, 듣기연습, 딕테이션
6. 성적표/녹음결과 카카오톡 전송

**학생용**:
1. 선생님 세트로 암기 및 테스트 제출
2. 한 손 플래시카드 학습
3. 목표점수 도전 테스트
4. 오프라인 학습모드 (세트 다운로드)

**수업용 (클래스카드 배틀)**:
- 100만개 퀴즈 중 선택
- 실시간 배틀 게임

   - 실시간 발음/억양/유창성 평가

   - 여행, 비즈니스, 인터뷰 등

#### 강점 및 약점

| 강점 | 약점 |
|------|------|

- **타겟 시장**: 스픽은 회화 학습, UTTEC은 단어 암기로 **직접 경쟁 아님**

| 3억건 데이터 기반 | 학원용 솔루션 부재 |

#### UTTEC 대비 분석

- **타겟 시장**: 산타토익은 토익 종합 학습, UTTEC은 범용 단어 암기로 **부분 경쟁**
- **차별화**: UTTEC은 다양한 시험/학습 목적 커버 가능

## 6. 영업 전략 제안

### 6.1 경쟁사 대비 강조 포인트

**클래스카드 대비**:
```
"클래스카드는 좋은 서비스지만,
- 다국어는 지원하지 않습니다
- 자동 발음 재생이 없습니다
- XP/레벨업 같은 동기부여 시스템이 약합니다

UTTEC은 이 모든 것을 제공하면서
가격도 투명하게 공개합니다."
```

**해커스/워드마스터 대비**:
```
"해커스, 워드마스터는 교재를 사야 합니다.
그리고 개인 학습용이라 선생님이 관리할 수 없습니다.

UTTEC은 원장님이 직접 만든 단어장으로
학생들의 학습 현황을 실시간 확인할 수 있습니다."
```

**Quizlet 대비**:
```
"Quizlet은 글로벌 서비스라 한국어 지원이 부족하고,
한국 교재와 연계가 어렵습니다.
달러 결제도 불편하고요.

UTTEC은 한국 학원을 위해 만든 서비스입니다.
원화 결제, 카카오톡 알림, 맞춤 단어장 모두 지원합니다."
```

### 6.2 블루오션 공략

| 시장 | 전략 |
|------|------|
| **메타인지 테스트** | 경쟁사 거의 없음 → 입시학원 집중 공략 |
| **자격시험 가이드** | 30개+ 통합 플랫폼 → 직업훈련원 공략 |
| **다국어 학습** | 7개 언어 통합 → 어학원 공략 |
