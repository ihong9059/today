한눈에 보는 전체 그림

복잡해 보이지만, 이 시스템은 결국 "경비실 컴퓨터 한 대로 단지 전체 보안등 41개의 켜짐·꺼짐과 밝기를 자동으로 조절한다"는 것입니다. 아래 4단계만 이해하시면 됩니다.

① 경비실 컴퓨터 (CCMS)
사람이 보는 관제 화면입니다. "밤 11시부터 밝기 절반" 같은 규칙(스케줄)을 여기서 설정하고, 어느 등이 고장 났는지도 여기서 봅니다.
🏠 비유 — 집 전체를 조절하는 월패드(홈 화면)와 같습니다.
② 중계 장치 (SCU)
컴퓨터의 명령을 아래 장비로 전달하는 통신 중계기입니다. 컴퓨터와 현장 장비 사이에서 말을 전달합니다.
📡 비유 — 사무실의 인터넷 공유기(라우터)처럼, 명령을 여러 장비에 나눠 보냅니다.
③ 조광 장치 (0-10V 디밍모듈)
실제로 보안등을 켜고 끄고, 밝기를 조절하는 손발 역할입니다. 8개 회로까지 각각 따로 조절할 수 있습니다.
🎚️ 비유 — 오디오의 볼륨 조절기처럼, 밝기를 0~100%로 부드럽게 올리고 내립니다.
④ 보안등 41개 (6개 그룹)
단지 곳곳의 실제 가로등·보안등입니다. 위치별로 6개 묶음(회로)으로 나눠 그룹 단위로 제어합니다.
💡 비유 — 거실·주방·침실 구역별 조명 스위치를 나눠 둔 것과 같습니다.
핵심 요약 — 경비실 컴퓨터(①)가 규칙을 정하면 → 중계기(②)가 전달하고 → 조광장치(③)가 실행하여 → 보안등(④)의 밝기가 자동으로 바뀝니다. 뒤에서는 이 4가지에 등장하는 세부 용어를 하나씩 풀어 설명합니다.

조명제어 기본 개념

보안등
단지·도로변의 안전과 방범을 위한 옥외 조명등입니다. 본 현장은 총 41개입니다.
디밍 Dimming / 조광(調光)
조명의 밝기를 단계적으로 조절하는 것입니다. 그냥 켜고 끄는 것(ON/OFF)이 아니라, 30%·50%·100%처럼 중간 밝기로도 맞출 수 있습니다.
🔆 비유 — 스마트폰 화면 밝기를 손가락으로 밀어 조절하는 것과 같습니다.
시간대별(타이머) 디밍
시간에 따라 밝기를 자동으로 바꾸는 것입니다. 예: 초저녁 100% → 심야(23시) 50% → 새벽 소등. 사람이 매번 조작할 필요가 없습니다.
⏰ 비유 — 예약 기능이 있는 보일러가 시간에 맞춰 알아서 켜지는 것과 같습니다. 심야 감광으로 전기요금 절감 효과가 있습니다.
회로 Circuit
여러 등을 한 묶음으로 묶어 함께 제어하는 전기 단위입니다. 본 현장은 41개 보안등을 위치별로 6개 회로(OL1~OL6)로 나눕니다.
🔌 비유 — 집에서 "거실 등 스위치 하나로 거실 전등 3개가 같이 켜지는" 것과 같습니다.
그룹 / 씬 제어 Group / Scene
그룹 = 여러 회로를 묶어 한 번에 제어. 씬(장면) = "축제 모드 100%", "심야 모드 40%"처럼 미리 저장해 둔 밝기 조합을 버튼 하나로 불러오는 것.
🎬 비유 — 사진 앱의 "필터"처럼, 미리 만들어 둔 설정을 한 번에 적용합니다.
0~254 단계
밝기를 얼마나 정밀하게 나눌 수 있는지를 뜻합니다. 0(꺼짐)부터 254(최대)까지 255단계로, 아주 미세하게 밝기를 조절할 수 있습니다.
📶 비유 — 밝기 조절 눈금이 촘촘할수록 부드럽게 어두워집니다(뚝뚝 끊기지 않음).

핵심 장비 용어

SCU (중앙전송장치) System Communication Unit
경비실 컴퓨터의 명령을 현장 장비로 전달·중계하는 통신 장치입니다. 컴퓨터와 조광장치 사이의 연결 다리입니다.
📡 비유 — 인터넷 공유기. 명령을 받아 여러 장비에 나눠 전달합니다.
0-10V 디밍모듈 Dimming Module
실제로 보안등의 ON/OFF와 밝기를 조절하는 장치입니다. 한 대로 8개 회로를 각각 따로 제어합니다(본 현장 6회로 사용 + 2회로 예비).
🎚️ 비유 — 8채널 믹서(볼륨 조절판). 각 채널(회로)의 밝기를 독립적으로 올리고 내립니다.
전원공급장치 Power Supply Unit
위 장비들이 작동하도록 알맞은 전기(24V)를 만들어 공급하는 장치입니다. 가정용 220V를 장비가 쓰는 낮은 전압으로 바꿔줍니다.
🔋 비유 — 휴대폰 충전기(어댑터)가 220V를 5V로 바꿔주는 것과 같습니다.
조명제어반 (LCP) Lighting Control Panel
위 장비들(SCU·디밍모듈·전원장치)을 한 철제 함(외함) 안에 모아 놓은 제어 캐비닛입니다. 본 현장은 LCP-0, 경비실에 설치되며 크기는 400×1600×180mm입니다.
🗄️ 비유 — 집의 두꺼비집(배전함)처럼, 제어 장비를 한곳에 모은 통제함입니다.
CCMS (중앙감시반) Central Control & Monitoring System
경비실에 두는 관제용 컴퓨터 세트(PC + 모니터 + 프린터 + 전용 프로그램)입니다. 여기서 전체 보안등을 보고·조작합니다.
🖥️ 비유 — 아파트 관리실의 통합 관제 모니터와 같은 역할입니다.
HMI (관제 소프트웨어) Human-Machine Interface
컴퓨터 화면에서 사람이 보고 조작하는 프로그램입니다. 단지 지도 위에 보안등을 그려 놓고, 클릭으로 켜고·끄고·밝기·스케줄을 설정합니다.
📱 비유 — 스마트홈 앱 화면. 사람과 기계를 이어주는 '조작 화면'을 뜻합니다.

제어 기능 · 방식 용어

0-10V 방식
밝기를 전압의 크기(0~10볼트)로 지시하는 표준 조광 방식입니다. 0V면 최소, 10V면 최대 밝기. 조명업계에서 가장 널리 쓰입니다.
🎚️ 비유 — 수도꼭지를 조금 열면(낮은 전압) 물이 졸졸, 많이 열면(높은 전압) 콸콸 나오는 것과 같습니다.
DALI 디지털 조명제어 통신 규격
0-10V보다 더 똑똑한 디지털 조광 방식입니다. 등마다 주소가 있어 개별 제어·고장 확인이 가능합니다. 본 시스템 장비는 이 방식에도 대응합니다.
🏷️ 비유 — 0-10V가 '전체 방송'이라면, DALI는 '개인별 문자메시지'처럼 등 하나하나에 지시할 수 있습니다.
래칭 릴레이 Latching Relay
회로를 켜고 끄는 자동 스위치입니다. '래칭'은 한번 켜면 전기가 없어도 그 상태를 유지한다는 뜻(전력 절약).
🔘 비유 — 한번 누르면 계속 켜져 있는 침대 옆 푸시 스위치와 같습니다.
스케줄 제어 Schedule
시간·요일·계절에 따라 미리 정한 규칙대로 자동 실행하는 기능입니다. 예: 평일/주말 다르게, 여름/겨울 점등시간 다르게.
📅 비유 — 알람·예약 기능. 정한 시각에 알아서 작동합니다.
자기진단 Self-diagnosis
시스템이 스스로 이상을 점검하는 기능입니다. 통신 끊김·장비 오류를 자동으로 찾아 알려줍니다.
🩺 비유 — 자동차 계기판의 경고등이 문제를 스스로 알려주는 것과 같습니다.
경보 / 데이터 로깅 Alarm / Logging
경보 = 고장·이상 시 화면에 알림을 띄우는 것. 로깅 = 언제 무슨 일이 있었는지 기록으로 저장하는 것.
🧾 비유 — CCTV 녹화처럼, 지난 일을 나중에 되짚어 볼 수 있게 남겨둡니다.
상태변경(COS) · 타임딜레이 · 부하재설정
COS=상태가 바뀌면(켜짐↔꺼짐) 감지·기록. 타임딜레이=명령 후 일정 시간 뒤 실행(동시 점등 부담 분산). 부하재설정=정전 복구 후 원래 상태로 자동 복원.

통신 방식 용어

장비들이 서로 '대화'하는 방법(통신 규격)입니다. 사람으로 치면 '어떤 언어로 말하느냐'에 해당합니다.

RS-485
공장·건물에서 널리 쓰는 유선 통신 방식입니다. 전선 한 쌍으로 멀리(수백 m)·여러 대를 안정적으로 연결합니다.
🔗 비유 — 여러 사람이 한 줄로 이어진 전화선을 나눠 쓰는 것과 비슷합니다.
Ethernet (TCP/IP)
우리가 흔히 쓰는 인터넷 랜(LAN) 통신입니다. 경비실 컴퓨터와 SCU를 랜선으로 빠르게 연결합니다.
🌐 비유 — 컴퓨터에 꽂는 인터넷 랜선 그대로입니다.
MODBUS
산업 장비들이 쓰는 표준 대화 규칙(약속)입니다. 서로 다른 회사 장비끼리도 이 규칙을 지키면 대화가 됩니다.
🤝 비유 — 국제회의의 공용어(영어)처럼, 장비 간 공통 언어입니다.
ELC Network
이 조명제어 장비들끼리 연결되는 전용 통신망의 이름입니다(RS-485 기반). 제어반과 스위치·모듈을 잇습니다.
WiFi
잘 아시는 무선 인터넷입니다. 이 SCU 장비에는 WiFi 기능도 있어, 무선으로도 접속·점검할 수 있습니다.

배선 · 전기 용어

전선 기호 (F-CVVS · AWG18 · HFIX · F-CV)
전선의 종류·굵기·용도를 나타내는 규격 이름입니다. 신호용·전원용·통신용 전선이 각각 다릅니다.
📏 F-CVVS 1.5㎟=제어 신호선(가는 통신선) · AWG18=밝기 신호 통신선 · HFIX 2.5㎟=전원선 · F-CV=전력선. 숫자(㎟)가 클수록 굵은 전선입니다.
배관 (22C · 16C) · 강제전선관
전선을 보호하기 위해 넣는 파이프(관)입니다. 숫자(22C·16C)는 관의 굵기(지름 mm). '강제(鋼製)전선관'은 철로 만든 튼튼한 관.
🛡️ 비유 — 전선을 감싸는 보호 호스. 옥외에서 전선이 상하지 않게 지켜줍니다.
(조광) 안정기 Ballast / LED Driver
등기구(조명) 안에 들어가 전기를 알맞게 조절해 LED를 켜주는 부품입니다. '조광 안정기'는 밝기 조절(디밍)까지 되는 안정기.
⚙️ 비유 — 조명의 심장(전원 조절기). 이게 0-10V/DALI를 지원해야 밝기 조절이 됩니다. 등기구 업체가 공급합니다.
분전반 Distribution Board
건물로 들어온 전기를 여러 갈래로 나눠 보내는 배전함입니다. 각 회로로 전기를 분배합니다.
🔌 비유 — 집의 두꺼비집. 전기를 방마다 나눠주는 함입니다.
차단기 (MCCB · ELB)
전기 사고를 막는 안전 스위치입니다. MCCB=과부하·합선 차단, ELB(누전차단기)=감전·누전 시 자동 차단.
⚡ 비유 — 집 두꺼비집에서 '딱' 내려가는 그 스위치. 위험하면 스스로 전기를 끊습니다.
3상 4선 (3Ø4W) · 380/220V · 22.9kV
건물에 들어오는 전기의 형태·전압입니다. 22.9kV=한전에서 오는 고압, 건물에서 380V/220V로 낮춰 사용. '3상 4선'은 대형 건물용 전기 공급 방식.
🏢 비유 — 고압(22.9kV)으로 멀리 보내고, 아파트에서 우리가 쓰는 220V로 변압해 나눠주는 구조입니다.
접지 Earth / Ground
누전 시 전기를 안전하게 땅으로 흘려보내는 선입니다. 감전 사고를 예방하는 필수 안전장치입니다.

인증 · 공사 구분 용어

GS 인증
국가가 인정하는 소프트웨어 품질 인증입니다(Good Software). HMI 프로그램이 안정적으로 검증됐다는 표시입니다.
✅ 비유 — 식품의 HACCP 마크처럼, 공인기관이 품질을 보증한 것입니다.
BTL 인증
건물 자동제어 분야에서 서로 다른 장비끼리 잘 연동됨을 검증한 국제 인증입니다. 표준을 지켜 호환성이 보장됩니다.
🔗 비유 — 여러 브랜드 기기가 다 되는 블루투스 인증과 비슷한 개념입니다.
KC · TELEC · CE 인증
제품의 안전·전파 적합성을 나라별로 인증한 마크입니다. KC=한국, TELEC=일본, CE=유럽. UTTEC 제품이 보유한 인증입니다.
