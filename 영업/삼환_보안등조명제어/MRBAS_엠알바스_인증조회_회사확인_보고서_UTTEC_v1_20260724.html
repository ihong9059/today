조회 목적 및 방법

광안 지역주택조합 보안등 조명제어 도면(E13)의 조명제어 시스템 표기 "Excellent Lighting Controls(ELC)" 및 HMI 요구사항 "GS 인증 및 BTL 인증 제품"이, ㈜엠알바스(MRBAS)의 ELC SYSTEM 및 관제 소프트웨어 Smartrol과 일치하는지, 그리고 해당 인증이 실재하는지를 확인.

조회 방법웹 공개자료 조회 — 기업정보(사람인), 제조사 공식 홈페이지(mrbas.co.kr / mreng.com) 제품·인증 페이지, BACnet BTL 관련 검색, TTA GS인증 제도 확인
한계공식 등록부 직접 레코드 조회는 미완 (BTL 목록 URL 이전·GS 목록 검색 미노출). 아래 인증은 제조사 공식 게시 + 검색 교차확인 수준. 최종 확정은 인증서 사본·공식 DB 대조 필요(4장).

인증 조회 결과

확인 상태: ● 확인 제조사 공식 게시 + 검색 교차확인   ◐ 제조사 주장 공식 등록부 미대조   ○ 미확인 근거 못 찾음

인증내용 / 근거확인상태
BTL 인증
(BACnet)		 관제 SW Smartrol v3.1 — 2013년 BTL Listing 취득 명시(제조사 공식 제품페이지). 독립 검색결과도 "Smartrol v.3.1 certified with BTL Listing at 2013"로 교차확인. 적용: ELC/DALI/무선/0-10V/TLC 시스템. 설비계열(O3/enteliBUS/PLC)은 BACnet KS X 6909 + BTL 표기. ● 확인
현재 등재유지 최종확인 권장
GS 인증
(Good SW)		 제조사가 "SCADA 소프트웨어 GS인증 및 BTL인증 보유"로 게시. 그러나 제품명·등급·인증번호·유효기간이 확인 안 되고, TTA GS 공식목록에서 미노출. 현재 유효성 불명. ◐ 주장
BACnet
(프로토콜)		 개방형 BACnet(KS X 6909) 적용 게시 — BTL과 연동되는 기술 근거. ● 확인
우수조달
제품		 "IoT 조명제어 기반 냉난방 자동화기기" 우수조달제품 인증 게시(조달청). ◐ 주장
DALI / CE / ISO 제품·시스템 CE·DALI·ISO 인증 보유 게시(빌딩자동/조명제어용). 릴레이 CE 표기 확인. ◐ 주장
BTL은 실질 확인 — 도면 요구 2개 인증 중 BTL은 Smartrol v3.1로 2013년 취득이 공식·교차 확인됩니다. (다만 BTL Listing은 갱신·만료 개념이 있어 현재도 등재 유지 중인지는 btl.org 목록에서 제품명으로 최종 확인 권장.)
GS는 아직 미확정 — 제조사 주장만 있고 공식 TTA 목록·인증번호·유효기간 미확인. GS는 제품·버전·유효기간 종속이므로, 반드시 인증서 사본으로 실재·현재유효 확인 필요. (도면이 GS를 명시 요구하므로 이 항목이 핵심 리스크.)

광안 프로젝트 적용 판단 & 확정 근거 확보 액션

쟁점판단
도면 시스템 = MRBAS?도면 'Excellent Lighting Controls(ELC)' 명칭 + SCU 999모듈·0-10V 254단계·래칭릴레이 스펙이 MRBAS ELC와 일치 → 지정 시스템이 MRBAS일 개연성 높음 (단정 아님)
도면 HMI 인증요구 충족?BTL ● 확인 / GS ◐ 확인필요 → 1안(MRBAS 인증제품 공급)으로 충족 가능성 높으나, GS 실증이 전제
인증 = 현장별 재취득?아니오. 제품 인증은 1회성, 현장은 설정(Configuration)으로 대응 → 광안 건 UTTEC 신규 인증 불요
확정 근거 확보를 위한 잔여 액션 (발주 전 필수)
  • ① MRBAS에 「GS 인증서(제품명·등급·인증번호·유효기간) + BTL 등재 증빙」 사본 정식 요청
  • ② 공식 등록부 대조 — TTA GS인증 목록(gs.tta.or.kr) · BTL 제품 리스트(btl.org)에서 제품명 직접 조회
  • ③ 광안 도면 지정 HMI = Smartrol(또는 해당 ELC HMI) 동일성 확인 (다른 제품이면 인증 무관)
  • ④ BTL 2013 등재의 현재 유지/갱신 여부 및 GS 현재 유효 버전 확인
