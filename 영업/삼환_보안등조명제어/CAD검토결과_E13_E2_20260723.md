## 5. UTTEC 제안 포지셔닝 (제안서·회신 반영 포인트)

1. **차별점 = 무배관·무배선 (결정적)**
   심의 스펙은 F-CVVS 22C·AWG18 16C **신호선 배관/배선/결선 공사**가 필수. **옥외 41등이 넓게 분산**된 지역주택조합 단지 특성상, UTTEC LoRa 무선이면 이 통신 배관·포설·결선 공수 전체가 소거 → 원가·공기 우위가 큼. (심의 최종본도 24.09.25에 간선을 다시 변경할 만큼 배선이 부담 요소.)

2. **기능 동등성 매핑 (반드시 제안서에 표로)**
   심의 요구(0~254단계 디밍 / 16 Group·Scene / 스케쥴·타임딜레이 / 중앙감시 CCMS / 자기진단 / 경보 로깅)을 **UTTEC LoRa로 동등 구현** 가능함을 1:1 매핑. 실증 근거 = [[한림용인cc-고가수조]] 14노드 LoRa 실증.

3. **규모 확정**: 보안등 41등 / 6회로 그룹 / 중앙감시 501동 경비실 1개소. 견적 산정 기준.

4. **DALI/0-10V 게이트웨이 옵션**: 심의 모듈이 DALI 대응 → 등기구가 0-10V 또는 DALI 조광 안정기라면, UTTEC LoRa 노드 ↔ 0-10V/DALI 게이트웨이 구성으로 **기존 등기구 그대로 활용** 가능 (등기구 재선정 리스크 회피).

5. **경쟁 구도 인지**: 심의본은 이미 "Excellent Lighting Controls" 계열 유선 시스템으로 견적서까지 첨부(24.09)됨. UTTEC는 이를 **대체 제안**하는 입장 → "동등 기능 + 배선공사 대폭 절감"을 핵심 카피로.
