### 2회차 — 공장의 눈과 귀 (센서·표시·제어 첫 통합)
- **목표**: 온습도 읽기 + OLED 표시 + LED 신호등.

| 시간 | 구분 | 내용 |
|---|:--:|---|
| 13:00~13:15 | 복습 | 1회차 퀴즈·Q&A |
| 13:15~13:45 | 이론 | GPIO·디지털 입출력·I2C (쉽게) |
| 13:45~14:40 | 실습 | LED 신호등(R/Y/B)·부저·스위치 |
| 14:50~15:20 | 이론 | 센서 신호 → 숫자, 공장 활용 사례 |
| 15:20~16:20 | 실습 | AHT20 → OLED 표시 → WS2812 색 연동 |
| 16:20~16:35 | 체험 | 손으로 센서 데우면 숫자·색 변화 |
| 16:35~16:55 | 현업노트 | 장비/부품 카드 (AHT20·OLED …) |

- **핵심 코드**:
```python
# 핀: LED_RED=17, LED_YELLOW=27, LED_BLUE=22, BUZZER=5, SWITCH=4 · AHT20 I2C(SDA=Pin3,SCL=Pin5)
import board, busio, adafruit_ahtx0, time
i2c = busio.I2C(board.SCL, board.SDA); sensor = adafruit_ahtx0.AHTx0(i2c)
while True:
    t, h = sensor.temperature, sensor.relative_humidity
    print(f"온도 {t:.1f}C 습도 {h:.1f}%")   # → OLED 표시로 확장
    time.sleep(2)
```
- **강사노트**: I2C 미검출 → `i2cdetect -y 1`로 0x38(AHT20)·0x3C(OLED) 확인. OLED 드라이버 = **sh1106**(ssd1306 아님, 화면깨짐). WS2812 = 데몬으로 sudo 없이(NOPASSWD SOP, uttec-factory 박제).

### 3회차 — 자동으로 위험을 알리는 시스템
- **목표**: 기준값 + 부저 경보 + 정상/주의/위험 자동 판단 + CSV 저장.

| 시간 | 구분 | 내용 |
|---|:--:|---|
| 13:00~13:15 | 복습 | 2회차·Q&A |
| 13:15~13:45 | 이론 | 기준값(임계값)이란 |
| 13:45~14:40 | 실습 | 경보음 + 정상→주의→위험 판단 로직 |
| 14:50~15:30 | 실습 | 측정값 CSV 저장 → 엑셀 확인 |
| 15:30~16:30 | 실습 | 통합: 온도 기준 LED+부저+OLED 자동 경고 |
| 16:30~16:40 | 체험 | 손난로로 데워 자동 경보 작동 |
| 16:40~16:55 | 현업노트 | 결정 메모("기준값 왜 30도?") + CSV 보관함 |

- **핵심 코드**:
```python
GPIO.output(LED_BLUE,   t < 28)        # 정상
GPIO.output(LED_YELLOW, 28 <= t < 35)  # 주의
GPIO.output(LED_RED,    t >= 35)       # 위험
GPIO.output(BUZZER,     t >= 35)       # 경고음
import csv, datetime
with open("factory_log.csv","a",newline="") as f:
    csv.writer(f).writerow([datetime.datetime.now().isoformat(), t, h])
```
- **강사노트**: 기준값(28/35)은 손난로·손바닥 도달 범위로 조정(실제 공장값과 다름 설명). 부저=능동(GPIO5)/스피커(GPIO13 SW-PWM). LED·부저 = **LOW ACTIVE**(active_high=False, 현장 실측).

### 4회차 — 스마트폰으로 우리 공장 보기 (무선통신)
- **목표**: 웹 대시보드 + Wi-Fi + 실시간 그래프 + LoRa 장거리 + 보드간 통신.

| 시간 | 구분 | 내용 |
|---|:--:|---|
| 13:00~13:15 | 복습 | 3회차·Q&A |
| 13:15~13:45 | 이론 | "내 폰에서 공장 보기" 웹서버·Wi-Fi |
| 13:45~14:40 | 실습 | Flask 대시보드 → 폰 접속 |
| 14:50~15:30 | 실습 | 실시간 온도 그래프(Chart.js) 폰 확인 |
| 15:30~16:20 | 실습 | LoRa 장거리 무선 데이터 수신 |
| 16:20~16:35 | 실습 | 옆 보드와 무선 통신 |
| 16:35~16:55 | 현업노트 | 공유·열람(폰/PC·동료 인계) |

- **핵심**: 웹 대시보드 = Flask + Chart.js (로컬 호스팅, 외부 인터넷 0). Flask `host="0.0.0.0"` 필수. 장거리 무선 = UTTEC Shield **LoRa** — 설정·SOP 단일 출처 = **lora vault**.
- **강사노트**: 20명 동시 Wi-Fi → 공유기 1~2대 분산, 폰 접속 IP 안내 화면. LoRa는 사전 설정·검증 모듈 배포. 무선 질문은 lora vault 근거로. ⚠️ **매트릭스↔LoRa 동일 핀(GPIO21) 공유 → 동시 사용 불가**(현장 실측). ⚠️ **강의안 표기 E22 ↔ 현장 실물 E32** 정합 확인(계획서 정합 메모).

| 시간 | 구분 | 내용 |

| 13:20~14:10 | 실습 | 손글씨 숫자 인식 AI 체험/제작 |
| 14:20~15:40 | 프로젝트 | 통합: 센서→판단→경보→대시보드 |
| 15:40~16:10 | 프로젝트 | 마무리 + (선택) AI 이상탐지·보고서 |

- **미니 스마트팩토리 구성**:
```
[AHT20]→온습도  [스위치]→시작/정지
   ↓
[Raspberry Pi]→기준값/이상 판단(Z-score·이동평균, 선택 AI 보고서)
   ├→[LED R/Y/B]+[WS2812 ×4]  ├→[부저/스피커]  ├→[OLED]  └→[웹 대시보드](+LoRa 원격)
```
- **AI 파트(수준별)**: 기본 = 손글씨 인식 데모(체험, onDevice_AI 근거) / 심화 = Z-score 이상탐지 → Claude API 보고서 자동생성.
- **강사노트**: 통합+성취감이 핵심 → 조별+순회, 미완성 조도 부분 시연으로 마무리.

## 8. 검증된 기술 함정 (용인 3차 실측 → 광주 재발 방지)
- OLED = **sh1106** / LED·부저 = **LOW ACTIVE** / WS2812 = 데몬(sudo 없이)
- 매트릭스 DIN = LoRa M0 = **GPIO21 공유 → 동시 사용 불가**
- LoRa **실물 E32**(강의안 E22 표기 정합 확인) / Flask `host=0.0.0.0` / 폰 USB = 데이터 케이블+localhost
