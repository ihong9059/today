| 항목 | 내용 |
|---|---|
| 교육명 | **AI·IoT 기반 스마트팩토리 실습 과정** (초급, 오프라인) |
| 목적 | 제조기업 임직원·예비창업자에게 AI·IoT 스마트 제조 기술 기본 개념·활용을 **손으로 만들며** 체득 → 디지털 전환·공장 자동화 역량 제고 |
| 대상 | 광주·전남 제조기업 임직원 및 예비창업자 (비전공자 눈높이) |

### 왜 UTTEC인가 (차별화 3축)

1. **UTTEC 자체 설계·제작 실습 kit** — 시중 조립 kit가 아닌 자사 UTTEC Shield 보드. 교육 후 수강생 자산으로 잔존 → 재구매·후속 교육·현업 확산 연결.
2. **기술 + 방법론 이중 자산** — 배운 것을 현업에서 기록·재현·인계하는 **현업 노트(Obsidian + AI)** 운영법까지 take-home.
3. **38년 임베디드 양산·인증 신뢰성** — 검증된 실물 기술(LoRa 실증·AI 이상탐지·공장자동화 kit)을 가르침. 이론이 아닌 현장.

### ★ 진정한 교육 목표 — 무엇을 남기는가 (우선순위 3)

운영계획의 표면 목표(온습도 모니터링·자동경보·무선·통합·현업노트)는 **수단**이다. 용인 3차 실제 진행(현장 wiki)과 커리큘럼 강화 방향(0회차 현업위키 맨 앞 배치·비전공 눈높이 전면화)을 되돌아보면, **진짜 목표는 다음 3가지**이며 이 순서가 곧 중요도다.

**① (최우선) 디지털 효능감 전환 — "나도 직접 만들 수 있다"**
- 제조 현장 비전공자의 **심리적 진입장벽 제거**가 전부의 토대. 손으로 센서를 붙이고 화면에 값이 뜨는 성공 경험 → "AI·IoT는 남의 일"에서 "내가 다룰 수 있다"로 전환. (1회차 목표 자체가 "작은 컴퓨터에 내가 명령을 내린다는 자신감".) 이 전환이 없으면 기술 산출물은 일회성으로 휘발된다.

**② 현업 이전(transfer)·지속 — 현업 노트로 평생 자산화**
- 교실 실습에서 끝나지 않고 **자기 공장·업무에 적용·기록·재현·인계·개선**하는 능력. 강화 트랙(현업 노트)을 핵심으로 격상하고 take-home 템플릿을 배포하는 이유. 교육이 끝나도 **남는 것** = UTTEC의 이중 자산(기술 + 방법론).

**③ AI 협업·자기주도 문제해결 역량 — AI를 도구로 부린다**
- 막히면 에러를 그대로 AI(Claude)에 붙여넣어 스스로 이해·해결하고, 필요한 것을 스스로 만들어 보는 습관. **AI 시대의 평생 학습 엔진**을 심는 것. (현장 wiki 전반이 "Claude로 배우고 고친" 기록.)

> 광주 제안·영상의 메시지는 이 3대 목표(효능감 → 현업 이전 → AI 협업)를 축으로 잡는다. "센서를 켠다"가 아니라 "**비전공 직원이 5주 만에 스스로 만들고, 현업에 남기고, AI로 계속 성장한다**"가 핵심 카피.

## 3. 커리큘럼 상세 (회차별)

각 회차 = **기술 실습(약 3h) + 현업노트 세그먼트(25~30분 누적)** + 정리.

### 0회차 — 나만의 현업위키 만들기 (오리엔테이션, 1회차와 통합)
- 목표: 기록 습관 + Claude로 위키 쓰기. 교육 후 평생 자산이 될 노트 시작.
- 산출물: `작업일지/` 첫 기록.

### 1회차 — 라즈베리파이와 친해지기
- 내용: 전원·화면·부팅·Wi-Fi, 첫 파이썬(`print`, 변수, `input/int`), 간단 계산기.
- 목표: "작은 컴퓨터에 내가 명령을 내린다"는 자신감.
- 산출물: 첫 파이썬 코드 + 작업일지 1.

### 2회차 — 공장의 눈과 귀 (센서·화면)
- 내용: GPIO/I2C 개념, AHT20 온습도 센서 읽기 → OLED(0.96") 실시간 표시 → 온도에 따라 네오픽셀(WS2812×4) 색 변경.
- 목표: 센서 데이터를 읽어 사람이 보게 만드는 기본 신호체인.
- 산출물: 온습도-OLED-네오픽셀 코드 + 장비카드(AHT20·OLED).
- 검증 함정(교보재화): OLED 드라이버 = **sh1106**(ssd1306 아님), 네오픽셀은 데몬 필요(sudo 없이).

### 3회차 — 자동으로 위험을 알리는 시스템
- 내용: 기준값(임계값) 개념, `if/elif/else`로 정상/주의/위험 자동 판단 → LED 색 + 부저 + OLED 표시, 측정값 CSV 저장, 기준값 결정 메모.
- 목표: "숫자를 보고 스스로 판단·경보하는" 자동화 첫 경험 + 데이터 기록.
- 산출물: 자동경보 코드 + `factory_log.csv` + 결정메모.
- 검증 함정: LED/부저 = **LOW ACTIVE**(active_high=False). 위험 경보 체험은 손난로로 온도 상승.

### 4회차 — 스마트폰으로 우리 공장 보기 (무선통신)
- 내용: Flask 웹 대시보드(폰 접속) → 실시간 온도 그래프(Chart.js) → **LoRa 장거리 무선**으로 데이터 수신 → 옆 보드와 통신.
- 목표: 원격 모니터링 + 무선 IoT 개념.
- 검증 사항: LoRa 실물 = **E32**(강의안 E22 표기는 정정 대상), 7/7 3대 통신 실증(왕복 1초). 매트릭스와 LoRa가 **동일 핀(GPIO21) 공유 → 동시 사용 불가**(안전 순서: 매트릭스 시연 → 뽑기 → LoRa). Flask는 `host="0.0.0.0"` 필수.

### 5회차 — AI 체험 및 미니 스마트팩토리 제작
- 내용: AI 학습 원리 + 손글씨 숫자 인식 데모 + 전 회차 통합(센서→판단→기록→무선→AI).
- 목표: "AI가 어떻게 배우나"를 체감 + 완성형 미니 스마트팩토리.
- 산출물: 통합 완성 + **현업 적용 1페이지**(take-home) + 현업노트 템플릿 배포.

## 4. 실습 kit (핵심 사업 자산)

- **베이스**: Raspberry Pi (학생기 = Pi 3 B+ / 강사 시연기 = Pi 4B) + **UTTEC Shield Board**
- **탑재 부품**: AHT20 온습도 · OLED 0.96"(sh1106) · 3색 LED 신호등 · 부저 · 스피커 · 택트 스위치 · WS2812 네오픽셀 ×4 · ESP32-C3 보조 MCU · **LoRa 모듈(실물 E32, 4회차 장거리 무선)**
- hardware 핀맵·검증 단일 출처 = `uttec-factory` vault (본 계획서는 참조). BOM·셋업 SOP = `uttec-academy/_공통/kit_BOM_SOP/`
- ⭐ **kit는 교육 종료 후 수강생/기관 자산** → 재구매·후속 교육·확산의 수익 구조.

## 7. 검증된 기술 자산·함정 인벤토리 (품질 보증 근거)

용인 3차 현장에서 **실측·해결 완료**된 항목 (광주에서 재발 방지):

| 항목 | 실측/해결 |
|---|---|
| OLED 드라이버 | **sh1106** (ssd1306 시 화면 깨짐) |
| LED·부저 | **LOW ACTIVE** (active_high=False) |
| 네오픽셀 | 데몬(uttec-neopixel-daemon)으로 sudo 없이 구동 |
| 매트릭스↔LoRa | DIN = LoRa M0 = **GPIO21 공유 → 동시 사용 불가** (안전 순서 정립) |
| LoRa 모듈 | 실물 **E32** (3대 통신 실증, 왕복 1초) — 강의안 E22 표기 정정 |
| 폰 USB 연동 | 데이터 케이블 필수 + ADB 승인 + `adb reverse` + localhost만 센서 허용 |
| ESP32 보조 MCU | WROOM-32D "UTTEC Lab AI" 별도 노드, 펌웨어 백업·복제 SOP 확보 |
| WS2812 매트릭스 | 8x64 원점·좌표식·속도(50fps) 실측 — 심화/시연 옵션 자산 |

> ⭐ 이 인벤토리 자체가 "실제로 돌려본 검증 교육"임을 증명하는 영업 자산.
