라즈베리파이가 뭐예요?

라즈베리파이는 손바닥만 한 작은 컴퓨터입니다. 우리가 쓰는 노트북과 하는 일은 같은데, 크기가 작고 옆구리에 40개의 금색 다리(핀)가 있어서 전등·센서·부저 같은 부품을 직접 연결할 수 있다는 점이 다릅니다.

일반 컴퓨터라즈베리파이
크기큼손바닥
부품 직접 연결어려움쉬움 (40핀)
공장 현장에 두기부담딱 좋음 (싸고 작음)
UTTEC 키트 = 라즈베리파이 + UTTEC Shield. Shield(실드)는 라즈베리파이 위에 딱 끼우는 판인데, 여기에 온습도 센서·화면(OLED)·LED 3색·부저·스피커·버튼·네오픽셀이 이미 붙어 있습니다. 그래서 배선을 직접 안 해도 바로 실습할 수 있습니다. (2회차부터 사용)
실습①켜고 연결하기

실습 ①: 켜고 · Wi-Fi 확인 · 원격 접속

  1. 전원(USB-C)만 꽂기 → 빨간 불이 들어오면 켜진 것입니다. (모니터·키보드 필요 없음!)
  2. 내 노트북을 Wi-Fi uttec200 에 연결 (비번도 uttec200).
  3. 노트북에서 원격 접속 — 자세한 방법은 「노트북 VSCode 접속 설명서」 참고.

접속되면 아래 명령으로 지금 라즈베리파이가 네트워크에 잘 붙었는지 확인할 수 있습니다.

터미널에 입력 (내 파이의 주소 확인)
hostname -I     # 내 라즈베리파이의 IP 주소가 나옵니다 (예: 192.168.200.17)
"라즈베리파이 처음 켤 때 순서를 알려줘." "화면이 안 나오는데 뭘 확인해야 해?" 안 되면 "뭘 확인해?"라고 물으면 Claude가 하나씩 짚어 줍니다.
실습②첫 프로그램

실습 ②: 화면에 글자 띄우기 — 첫 파이썬

컴퓨터에게 "이 글자를 보여줘"라고 시키는 명령이 print 입니다. 딱 한 줄로 첫 프로그램이 됩니다.

파이썬 — hello.py
print("Hello Factory!")   # 화면에 Hello Factory! 라고 출력
"화면에 Hello Factory! 라고 출력하는 파이썬 코드를 알려줘." "이 코드가 한 줄씩 무슨 뜻인지 쉽게 설명해줘." '따라치기'가 아니라 각 줄의 뜻을 이해하는 게 목표입니다.
실습③변수와 계산기

실습 ③: 변수 이해하고 · 간단한 계산기 만들기

변수는 값을 담아두는 이름표 붙은 상자입니다. 예: name 이라는 상자에 "홍길동"을 넣어 둡니다.

파이썬 — 변수
name = "홍길동"       # name 상자에 글자를 담기
age  = 30            # age 상자에 숫자를 담기
print(name, age)     # 홍길동 30

간단한 계산기 (숫자 입력받아 더하기)

파이썬 — calculator.py
a = int(input("첫 번째 숫자: "))   # 키보드로 숫자 입력 (int=숫자로 바꾸기)
b = int(input("두 번째 숫자: "))
print("합계 =", a + b)              # 두 수를 더해 출력
왜 int() 가 필요할까? 키보드로 친 값은 컴퓨터가 처음엔 글자로 받습니다. "3"+"5"는 "35"가 되어버려요. int() 로 숫자로 바꿔줘야 3+5=8 이 됩니다. (숫자와 글자의 차이!)
"변수가 뭔지 쉬운 비유로 설명해줘." "두 숫자를 더하는 아주 간단한 계산기를 초보용으로 만들어줘." "이 계산기 코드를 「코드·설정값」에 저장해줘."
