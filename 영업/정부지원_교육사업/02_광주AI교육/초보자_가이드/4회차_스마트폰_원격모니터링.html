개념쉬운 말로

"폰에서 공장 보기"가 어떻게 가능해요?

라즈베리파이가 작은 웹사이트(서버)를 하나 띄웁니다. 그러면 같은 Wi-Fi에 있는 내 폰이 그 주소로 접속해, 공장 상태를 볼 수 있습니다. 인터넷 없이 교육장 Wi-Fi 안에서만 동작합니다.

1파이 = 작은 웹사이트온습도를 보여주는 페이지를 띄움
2주소(IP)파이의 주소 예: 192.168.200.17:5000
3폰으로 접속같은 Wi-Fi 폰 브라우저로 열기
실습①핵심

실습 ①: 웹 대시보드 띄우고 폰으로 접속

Flask 라는 도구로 아주 작은 웹사이트를 만듭니다.

파이썬 — dashboard.py
from flask import Flask
import board, busio, adafruit_ahtx0
sensor = adafruit_ahtx0.AHTx0(busio.I2C(board.SCL, board.SDA))
app = Flask(__name__)

@app.route("/")
def home():
    t = sensor.temperature
    h = sensor.relative_humidity
    return f"<h1>온도 {t:.1f}C / 습도 {h:.1f}%</h1>"

app.run(host="0.0.0.0", port=5000)   # 0.0.0.0 = 폰에서도 접속 허용
터미널 — 내 파이 주소 확인 후 폰에서 접속
hostname -I          # 예: 192.168.200.17  →  폰 브라우저에 192.168.200.17:5000 입력
폰에서 안 열릴 때. ① 폰과 파이가 같은 Wi-Fi(uttec200) 인지 ② 코드에 host="0.0.0.0" 이 있는지 ③ 주소 뒤 :5000 을 붙였는지 확인. 막히면 그대로 Claude에게 물어보세요.
"온습도를 보여주는 웹 대시보드를 Flask로 띄우는 코드를 초보용으로 알려줘." "내 파이의 주소(IP) 확인법과, 폰에서 접속하는 법을 알려줘." "폰에서 접속이 안 돼. 뭘 확인해야 해?"

실습③장거리 무선

실습 ③: 장거리 무선 — LoRa

LoRa는 멀리(수백 m~km)까지 조금씩 데이터를 보내는 무선입니다. Wi-Fi가 안 닿는 넓은 공장·야외에 쓰기 좋습니다.

Wi-FiLoRa
거리수십 m수백 m ~ km
속도빠름느림(조금씩)
쓰임대시보드·영상멀리 있는 센서값
/lora — LoRa 모듈이 통신되는지 먼저 확인 "LoRa가 Wi-Fi와 뭐가 다른지 쉽게 설명하고 「배운것」에 정리해줘." "옆 사람 보드가 보낸 데이터를 내 파이에서 받아 화면·대시보드에 보여주는 법을 알려줘."
참고. LoRa 모듈(E22)은 설정이 예민해서 강사가 미리 검증한 모듈을 씁니다. 무선 기술 상세는 담당 자료(lora)를 따릅니다. 우리 키트에서 LoRa 제어 핀은 TX 14 · RX 15 · M0 21 · M1 20 · AUX 7 로 이미 정해져 있습니다.
