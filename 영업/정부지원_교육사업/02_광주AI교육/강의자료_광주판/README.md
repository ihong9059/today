# 광주판 강의 슬라이드 (교육생 투사용)

용인 미래창의 3차 강의 슬라이드를 **광주 브랜딩으로 재생성**한 정품 교재. 실물 사진(키트·라즈베리파이) + 일러스트 포함, 16:9.

## 산출물 (보여줄 자료)
| 회차 | PDF / PPTX | 장수 |
|:-:|---|:-:|
| 0 | 0회_나만의_현업위키_만들기 | 9 |
| 1 | 1회_라즈베리파이_친해지기 | 12 |
| 2 | 2회_공장의_눈과_귀 | 8 |
| 3 | 3회_자동_경보_시스템 | 8 |
| 4 | 4회_스마트폰_원격모니터링 | 8 |
| 5 | 5회_AI_미니스마트팩토리 | 8 |

- **PDF** = 교육자에게 바로 보여주는 자료 (Type3 폰트 0, 모든 뷰어 호환).
- **PPTX** = 편집용 원본 (PowerPoint).

## 광주판 변경 사항 (용인 3차 대비)
- 브랜드: "미래창의 아카데미" → **광주 AI·IoT 스마트팩토리 실습** / footer "· 광주"
- 표지 슬로건 추가: **百見不如一習 · 직접 익히는 교육**
- 일자: 확정 전이라 **"제N주차 · 13:00~17:00"** placeholder (기관 협의 후 확정)
- 강사: "홍광선 대표 · UTTEC 교육팀" (홍광삼 팀장명 확인 후 반영)

## 재생성 방법
```bash
python _rebrand.py     # (이미 적용됨) 용인→광주 재브랜딩
python build_00.py     # 회차별 PPTX 생성 (build_01~05 동일)
```
PPTX → PDF 변환: PowerPoint COM (`SaveAs(path, 32)`), 본 PDF는 그 결과.

## 확정 후 할 일
- 일정 확정 → 각 `build_0N.py`의 "제N주차" → 실제 날짜로 교체 후 재빌드
- 실습 진행 후 실제 수업 사진이 생기면 `assets/`의 일러스트 교체 가능
- 원천: `uttec-academy/…/3차_2026-07/강의자료_PPT/` (편집 원본)
