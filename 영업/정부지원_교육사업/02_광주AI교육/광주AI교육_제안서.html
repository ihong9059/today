02 — TRUE GOALS

이 교육이 남기는 것 (우선순위 3)

①

디지털 효능감 — "나도 직접 만들 수 있다"

제조 현장 비전공자의 심리적 진입장벽 제거. 손으로 만든 것이 실제로 반응하는 성공 경험 → 모든 학습·적용의 토대.

②

현업 이전·지속 — 현업 노트로 평생 자산화

교실에서 끝나지 않고 자기 공장·업무에 적용·기록·재현·인계. 교육이 끝나도 남는 것 = 기술 + 방법론 이중 자산.

③

AI 협업 — AI를 도구로 부린다

막히면 AI에게 물어 스스로 이해·해결하는 습관. AI 시대의 평생 학습 엔진을 심는다.

"센서를 켠다"가 아니라 — 비전공 직원이 5주 만에 스스로 만들고 · 현업에 남기고 · AI로 성장한다.
03 — PROBLEM

1

라즈베리파이와 친해지기

부팅·Wi-Fi·첫 파이썬(변수·계산기). "내가 명령을 내린다"

→ 첫 프로그램 + 현업노트 시작
2

공장의 눈과 귀

AHT20 온습도 → OLED 표시 → 온도별 네오픽셀 색변경

→ 센서 신호체인 완성
3

자동 경보 시스템

기준값 정상/주의/위험 자동 판단 + 부저 + CSV 기록

→ 스스로 판단·경보 + 데이터
4

스마트폰 원격 모니터링

웹 대시보드·실시간 그래프 + LoRa 장거리 무선

→ 폰으로 우리 공장 보기
5

AI 미니 스마트팩토리 (종합)

AI 손글씨 인식 + 전 회차 통합(센서→판단→기록→무선→AI). "우리 공장에 어떻게 적용할까" 토론 + 현업 적용 1페이지

→ 완성 시연 + 현업 적용 계획서 + take-home 템플릿
