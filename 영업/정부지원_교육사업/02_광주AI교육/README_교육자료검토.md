## 3. 커리큘럼 개요 (박상현·광주 관계자 설명용)

- **교육명**: AI·IoT 기반 스마트팩토리 실습 과정 (초급, 오프라인)
- **대상**: 제조기업 임직원 및 예비창업자 (비전공자 눈높이)
- **구성**: 총 5회 20시간 (회당 4h) — 실제 운영 검증 중 (용인 3차 7/15~8/12 진행 중, 수강생 16명)
- **회차**: ① 라즈베리파이 친해지기 → ② 온습도센서+OLED+LED(공장의 눈과 귀) → ③ 기준값 자동경보 → ④ 스마트폰 원격모니터링(Wi-Fi·LoRa 무선) → ⑤ AI 손글씨 인식 + 미니 스마트팩토리 완성
- **차별화**:
  1. **UTTEC 자체 제작 실습 kit**(Pi3 + UTTEC Shield: 온습도·OLED·LED·부저·WS2812·ESP32C3·LoRa) — 교육 후 수강생 자산으로 잔존 → 재구매·후속 교육 연결
  2. **현업 노트(Obsidian+Claude) 운영 트랙** — 기술뿐 아니라 "현업 기록·재현·인계" 방법론까지 take-home (이중 자산 패키지)
  3. 38년 임베디드 양산·인증 신뢰성 + 검증 자산(LoRa 실증·AI 이상탐지) 기반
