# 디지털배움터 강사 신청 절차 — Step-by-Step 가이드

> **목적**: 디지털배움터 강사 등록부터 첫 강의 + 첫 정산까지 모든 단계를 누락 없이 진행.
>
> **예상 소요 시간**: 4~8주 (등록 → 첫 강의 발주 → 첫 강의 → 첫 정산)

---

## 단계 개요 (Phase 0 ~ Phase 6)

```
[Phase 0] 사전 준비 (Day 1~3)
          ↓
[Phase 1] 공식 사이트 가입 + 강사 권한 신청 (Day 1~7)
          ↓
[Phase 2] 지역사업자 컨택 (Day 4~14)
          ↓
[Phase 3] 강사 등록 서류 제출 (Day 7~21)
          ↓
[Phase 4] 시범 강의 + 강사 위촉 (Day 21~35)
          ↓
[Phase 5] 첫 정식 강의 (Day 28~56)
          ↓
[Phase 6] 정산 + 다음 강의 (Day 35~70)
```

## Phase 0 — 사전 준비 (Day 1~3)

### 0-1. 자격 검증 자가 체크
**5분 안에 확인**:
- [ ] IT 분야 학사 이상 (또는 동등 경력 1년+)
- [ ] 정보처리기사·SQL·리눅스 마스터 등 자격증 1개+ (없으면 "관련 경력 38년"으로 대체 가능)
- [ ] 강의·교육 경력 6개월+ 또는 강의 시연 가능
- [ ] 본인 PC + Claude Code + Obsidian 등 도구 능숙 사용

→ 사용자(홍광선) 38년 IT 경력 + uttec-edu 자체 콘텐츠 = **모두 충족**.

### 0-2. 필요 자료 준비
**이번 주 내 확보**:
- [ ] **이력서** (1~2페이지, [05번 파일](./05_강사_지원서류_세트.md) 템플릿 사용)
- [ ] **자기소개서** (1페이지, 강사 지원 동기 + 강점)
- [ ] **강의계획서** (예: Claude Code + Obsidian 8시간, [06번 파일](./06_시범강의안_Track_A_8시간.md))
- [ ] **자격증·경력증명서 사본** (PDF)
- [ ] **신분증 사본** (주민등록증 또는 운전면허증)
- [ ] **최근 사진** (반명함판 사이즈 디지털 파일)
- [ ] **사업자등록증 사본** (UTTEC 사업자 등록 시)

### 0-3. 사이트 + 정보 사전 조사
- [ ] 디지털배움터 공식 사이트 접속 (https://www.xn--2z1bw8k1pjz5ccumkb.kr/)
- [ ] "강사 권한신청" 메뉴 위치 확인
- [ ] 거주 지역(예: 서울)의 운영사업자 명단 검색
- [ ] 2026 AI디지털배움터 모집 공고 검색

## Phase 1 — 공식 사이트 가입 + 강사 권한 신청 (Day 1~7)

### 1-1. NIA 통합 회원가입
1. 디지털배움터 공식 (https://www.xn--2z1bw8k1pjz5ccumkb.kr/)
2. 우측 상단 "회원가입" 클릭
3. 본인 인증 (휴대폰 또는 공인인증서)
4. 일반 회원으로 가입 → 이후 강사 권한 추가 신청

### 1-2. 강사 권한 신청
1. 로그인 → 마이페이지
2. "강사 권한신청" 메뉴 (https://www.xn--2z1bw8k1pjz5ccumkb.kr/edc/tcr/req/apply.do)
3. 양식 작성:
   - 기본 정보 (이름·연락처·주소)
   - 학력·경력
   - 자격증
   - 강의 가능 분야 (체크박스 다수 선택)
   - 활동 지역 (다중 선택 가능)
4. 첨부 파일 업로드 (이력서·자격증 사본)
5. 제출 → 자동으로 NIA 검토 단계 진입

### 1-3. 권한 승인 대기
- **검토 기간**: 보통 1~2주
- **결과 통지**: 이메일 + SMS
- **승인 시**: 강사 마이페이지 접속 가능 + 지역사업자별 강사 풀에 자동 등록

### ⚠️ 주의사항
- 권한 신청만으로는 **강의 발주 보장 X** → 다음 Phase에서 사업자에 직접 컨택 필수
- 거짓 정보 기재 시 영구 자격 박탈 가능

## Phase 3 — 강사 등록 서류 제출 (Day 7~21)

### 3-1. 사업자 양식 확인
사업자별로 자체 양식이 있을 수 있음:
- 사업자 자체 강사 신청서
- 강의계획서 (사업자가 원하는 형식)
- 보안 서약서·개인정보 동의서

### 3-2. 본인 자료 + 사업자 양식 통합 제출
- **이메일 첨부**: 모든 PDF 한 폴더에 ZIP으로 묶어서
- **파일명 규칙**: `[홍광선]_강사신청서_2026.pdf`, `[홍광선]_이력서.pdf` 등
- **메일 본문**: 첨부 자료 목록 명시

### 3-3. 제출 후
- 사업자 검토 기간: 1~2주
- 추가 자료 요청 시: 즉시 회신 (24시간 내)
- 합격 시: 시범 강의 또는 강사 풀 등재 확정

## Phase 4 — 시범 강의 + 강사 위촉 (Day 21~35)

### 4-1. 시범 강의 (사업자 요청 시)
- **소요 시간**: 보통 30분 ~ 1시간
- **장소**: 사업자 사무실 또는 강의실
- **참석자**: 사업자 담당자 + 평가위원 1~3명
- **준비물**:
  - 노트북 + 빔 프로젝터 (필요 시)
  - 시연 자료 (Claude Code · Obsidian 라이브 데모)
  - 인쇄 자료 (강의안 요약 1~2장)

### 4-2. 시범 강의 시 점검 사항
- [ ] 발음·전달력 명확
- [ ] 시간 엄수 (예정 시간 ±5분)
- [ ] 청중 눈높이 맞추기 (전문 용어 풀어 설명)
- [ ] 기술 시연 무난 진행 (사전 리허설 필수)
- [ ] Q&A 즉답 능력

### 4-3. 위촉 결과
- **합격**: 강사 풀 등재 + 강의 발주 대기
- **조건부 합격**: 보강 후 재시연
- **불합격**: 다른 사업자 시도 또는 보강 후 재지원

---

## Phase 5 — 첫 정식 강의 (Day 28~56)

### 5-1. 강의 발주 통보
- 사업자가 강의 일정 + 장소 + 수강생 정보 통보
- 확정 시점: 강의 시작 1~3주 전
- 강의 정보:
  - 일자 / 시간
  - 장소 / 교통편
  - 수강생 수 / 연령대 / 사전 지식 수준
  - 강의 주제 / 강의안 검토 의견

### 5-2. 강의 준비 (1~3주)
- [ ] 강의안 최종 확정 + 인쇄
- [ ] 실습 자료 USB 또는 클라우드 링크 준비
- [ ] 노트북·전원 어댑터·HDMI 케이블 등 장비 점검
- [ ] 강의장 사전 답사 (가능 시)
- [ ] 수강생 사전 안내 (사업자에 메일 전달 요청):
  - 노트북 지참 안내
  - 사전 설치 권장 도구 (Obsidian 등)
  - 사전 가입 권장 (Claude.ai 무료 계정)

### 5-3. 강의 당일
- **출발 1시간 전**: 모든 장비 재점검
- **도착 30분 전**: 강의장 도착 + 장비 셋업 + 인터넷 연결 테스트
- **강의 진행**: 강의안 따라 진행 + 수시 Q&A
- **강의 종료**: 출석부 작성 + 만족도 설문 (사업자가 제공)

### 5-4. 강의 후
- [ ] 출석부·강의일지 사업자에 즉시 제출
- [ ] 정산 청구 (사업자 양식 사용)
- [ ] 강의 자료 업로드 (사업자 요청 시)
- [ ] 수강생 후속 질문 대응 (1주 정도)

---

## Phase 6 — 정산 + 다음 강의 (Day 35~70)

### 6-1. 정산 흐름
1. **출석부·강의일지 제출** → 사업자 확인
2. **사업자 → NIA 정산 청구** → NIA 검토
3. **NIA → 사업자 → 강사 입금** (3.3% 원천징수 후)
4. **소요 시간**: 강의 후 2~4주

### 6-2. 첫 정산 시 점검
- [ ] 입금액 확인 (시간당 단가 × 강의 시간 × 0.967)
- [ ] 원천징수 영수증 보관 (연말정산 + 종소세용)
- [ ] 출장비·교통비 별도 청구 누락 없는지 확인

### 6-3. 다음 강의 발주 유지
- 첫 강의 만족도가 높으면 같은 사업자에서 추가 발주 가능
- 만족도 낮으면 사업자에 피드백 요청 + 보강

### 6-4. 다중 사업자 운영
- 한 사업자에서 안정 발주 후 → 다른 지역 사업자 추가
- 강의 일정이 겹치지 않도록 캘린더 통합 관리 (Google Calendar + Notion)

## 추가 팁

### 강의 품질 향상
- 첫 5회 강의: 모두 녹화 (본인 검토용)
- 수강생 만족도 설문 = 강의안 개선의 핵심 자료
- 같은 강의를 사업자별로 5~10회 반복 = 강의안 점진 개선

### 영업 자료 활용
- 디지털배움터 강의 = "정부 공식 강사" 명함
- Stage 0 견적서·소개 자료에 추가
- LinkedIn·블로그에 강의 후기 게시

### 확장 전략
- 디지털배움터 1년 경력 → KDT 외부 강사 진입 시 가산점
- 디지털배움터 + 평생학습관 + 서울시 강사 = 3중 지지대
- 6개월 후 본인 운영기관 등록 검토 (KDT 운영 진입)

## ❌ 자주 하는 실수 (피하기)

1. **권한 신청만 하고 끝**: 사업자 직접 컨택 안 하면 발주 0
2. **자격증 부풀리기**: 검증 시 영구 자격 박탈
3. **시간 약속 미지킴**: 강의 지각 = 사업자 신뢰 즉시 손실
4. **강의안 사전 검토 누락**: 시연 도중 도구 작동 안 됨
5. **수강생 수준 무시**: 너무 어렵거나 너무 쉬우면 평가 추락
6. **정산 청구 누락**: 강의일지·출석부 미제출 시 정산 지연
