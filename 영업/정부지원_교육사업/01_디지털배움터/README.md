## 🎯 핵심 결정 사항

### 채택 콘텐츠
- **Track A 8시간 입문 코스**: "Claude Code + Obsidian + AI 도구로 디지털 역량 키우기"
  - 일반 시민·경력단절·시니어 대상

  - 본인의 13가이드 콘텐츠 직접 활용

### 백업 콘텐츠 (요청 시)
- **AI 입문 4시간**: ChatGPT·Claude 기본 + 안전한 사용
- **Obsidian 단독 4시간**: 디지털 노트정리 입문
- **AI 그림·동영상 입문 4시간**: 생성형 AI 시각 콘텐츠 (Welch Labs 영상 분석 활용)

### 1차 컨택 대상 (이번 주)
- 서울 디지털재단 (서울 지역사업자 가능성)
- 경기도 평생교육진흥원
- NIA 지정 권역별 운영기관 1~2곳
