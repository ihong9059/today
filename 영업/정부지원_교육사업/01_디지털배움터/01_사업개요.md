# 디지털배움터 사업 개요

## 1. 사업 정체성

**디지털배움터(Digital Baeumter, "디지털 배움의 터")** = 전국민 무료 디지털 교육 사업.

- **운영 주체**: 한국지능정보사회진흥원(NIA) + 17개 광역지자체
- **시작**: 2020년 (코로나19 디지털 격차 해소 명목)
- **2026년 전환**: **AI디지털배움터** — AI 교육 비중 대폭 확대
- **규모**: 전국 강의장, 연간 수십만 명 수강
- **수강료**: 전액 무료 (정부 100% 지원)

### 슬로건
> "디지털 세상, 누구나 누리는 평생교육"

---

## 2. 2026년 AI디지털배움터 전환 — 핵심 변화

### 변화 포인트
1. **명칭 변경**: 디지털배움터 → AI디지털배움터
2. **AI 교육 비중 50%+** 확대 (기존 디지털 입문 + AI 기초·실습 신설)
3. **연간 예산 증액**: 정확한 수치는 NIA 공고 확인 필요
4. **강사 수요 증가**: AI 도구·LLM·자동화 분야 강사 부족 → **UTTEC 진입 골든 윈도우**
5. **온라인 자율 학습 확장**: 메타버스·동영상 강의 등 비대면 비중 증가

### UTTEC 시너지 (★★★★)
| AI디지털배움터 신규 수요 | UTTEC 보유 콘텐츠 |
|------------------------|------------------|
| ChatGPT·Claude 입문 | Track A 13가이드의 Claude Code 부분 |
| AI로 일상 효율화 | 사용자 myWiki·작업보고서 자동화 사례 |
| 생성형 AI 시각·음성 | Welch Labs 영상 분석 + Remotion 제작 경험 |
| 디지털 노트 정리 | Obsidian + Memory MCP 운영 모델 |
| AI 안전·윤리 | 사용자 영업 자료의 "데이터 영구 소유권" 메시지 |
| **On-Device AI / SLM** | **Track F 14가이드 (UTTEC 독점 강점)** |

→ Track F의 "Ollama 노트북 SLM" 콘텐츠는 **AI디지털배움터에서 거의 유일한 강사**가 될 가능성.

## 3. 강사 트랙 구조

| 트랙 | 역할 | 자격 | 단가 |
|------|------|------|------|
| **전문강사** | 정규 과목 단독 강의 | IT 분야 경력·자격증 | 5~10만/시간 |
| **보조강사** | 전문강사 보조 + 실습 지도 | 기본 IT 활용 능력 | 3~5만/시간 |
| **가이드** | 수강생 출입·환경 안내 | 기본 디지털 활용 | 2~3만/시간 |

→ **UTTEC 진입 트랙: 전문강사 (38년 경력으로 충분)**.

---

## 4. 자격 요건 (전문강사)

### 일반적 기준 (지역사업자별 상이)
1. IT·전산 분야 학사 이상 **또는** 동등 경력 1년 이상
2. 강의 경력 6개월 이상 **또는** 강의 시연 평가 통과
3. 관련 자격증(정보처리기사·SQL·리눅스마스터 등) 1개 이상 권장
4. 디지털 활용 능력 자체 검증 (간단한 IT 도구 시연)

### 사용자(홍광선) 충족 상태
| 기준 | 충족 여부 | 근거 |
|------|:--------:|------|
| IT 분야 학사+ | ✅ | (사용자 이력 확인 필요) |
| 강의 경력 | ✅ | uttec-edu 13가이드 + Track F 자체 콘텐츠 |
| 자격증 | ⚠️ | 정보처리기사·관련 자격증 보유 여부 확인 필요 |
| IT 도구 시연 | ✅✅ | Claude Code·Obsidian·n8n·Remotion 모두 능숙 |
| 양산 제품 5건 + 38년 경력 | ✅✅ | 압도적 강점 |

→ **즉시 신청 가능 + 자격 충족 압도적**.

---

## 5. 단가·정산 구조

### 표준 단가
- **시간당 5~8만원** (지역·과정 난이도별)
- 출장비·교통비·식비 별도 (지역에 따라)
- 강의안 작성비 + 자료 인쇄비 별도 청구 가능

### 정산 흐름
1. 강의 종료 → 출석부·강의일지 제출
2. 사업자가 NIA에 정산 청구
3. NIA → 사업자 → 강사 입금 (보통 강의 후 2~4주)

### 세금
- 강사료는 **3.3% 원천징수** (사업소득)
- 연 수입에 따라 종합소득세 신고 (5월)

---

## 6. 강의 운영 형태

### 정기 과정
- 4~16시간 1과정 (1일 4시간 × 1~4일)
- 평일 오전·오후 / 주말 운영
- 수강생 10~30명 한 반

### 비정기 워크숍
- 단발 2~4시간 특강
- 지자체 행사·축제 연계

### 온라인 강의 (2026 확대)
- 줌·구글미트 + 메타버스 일부
- 사전 녹화 영상 + 실시간 Q&A 세션

---

## 7. 운영 사이클 (연간)

| 시기 | 사업자 활동 | 강사 활동 |
|------|----------|----------|
| 1월 | 연간 사업계획 수립 + 예산 확보 | (대기) |
| 2월 | 강사 모집 시작 | **신규 등록·신청** |
| 3월 | 강의 일정 확정 + 수강생 모집 | 강의안 준비 |
| 4월 | 첫 강의 시작 | 강의 진행 |
| 5월 | 중간 평가 | 강의 진행 |
| 6월 | 1학기 종료 | 정산 |
| 7월 | 2학기 사업자 모집 | (휴식) |
| 8월 | 2학기 시작 | 강의 진행 |
| 9~11월 | 운영 + 신규 과정 추가 | 강의 진행 |
| 12월 | 결산 + 익년 계획 | 정산 + 평가 보고 |

→ **2026-05 시점 진입 = 1학기 후반 + 2학기 모집 직전 = 적절한 타이밍**.

## 8. 지역사업자 (Operator) 구조

NIA가 직접 강사를 위촉하는 것이 아니라, **17개 광역지자체별 운영 사업자**가 강사를 채용.

### 주요 운영 사업자 형태
1. **공공기관**: 서울디지털재단·경기도평생교육진흥원 등
2. **민간 위탁기관**: SK하이닉스·NH농협 등 CSR 사업
3. **NPO**: 디지털배움터 운영 전문 비영리법인
4. **교육기관**: 평생교육원·지역대학 산하

### 진입 전략
- **여러 사업자에 동시 등록**: 한 사업자에서 강의 발주 없을 수도 있음
- **서울 + 경기 + 인천 = 수도권 3곳 우선**: 거리·일정 효율
- **거주 지역 우선**: 출장비 절감

## 10. 본 사업의 본질적 가치 (UTTEC 관점)

### 직접 가치 (단기)
- 월 50~200만 안정 매출
- 1년 누적 강사 경력 = 다른 채널 가산점

### 간접 가치 (중기)
- **uttec-edu Track A·F 시장 검증**: 어떤 콘텐츠가 실제 수강생에게 효과적인지 데이터 누적
- **Stage 0~1 영업 자료 보강**: "정부 등록 강사" 명함
- **추후 KDT·NIPA 진입 가산점**: 디지털배움터 강사 경력은 정부 채널 신뢰도 ↑

### 전략 가치 (장기)
- 2026 AI디지털배움터 전환기에 **선점 효과**
- Track F (On-Device AI) 강사 풀 매우 협소 → 거의 독점 가능
- 6~12개월 후 사업자 자체 등록 검토 가능 (KDT 운영기관 진입 발판)
