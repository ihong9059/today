## 1. 제품 개요

### 1.1 시스템 소개

**UTTEC 스마트팩토리 센서 모니터링 시스템**은 분체(분쇄/파쇄/혼합) 산업 설비를 위한 AI 기반 예지정비(PdM) 플랫폼입니다. 비계획 정지를 예방하고 운영 비용을 획기적으로 절감합니다.

**슬로건**: "분쇄/파쇄/혼합 설비의 예지정비 혁신"

### 1.2 핵심 기능

| 기능 | 설명 |
|------|------|
| **진동 분석** | 고속 회전체 FFT, Envelope 기법 기반 분석 |
| **온도 모니터링** | 모터 온도 상승 추세 실시간 분석 |
| **전류 패턴 감시** | 분쇄기 전류 패턴 이상 감지 |
| **차압/분진 모니터링** | 집진 시스템 실시간 감시 |
| **AI 예지정비 엔진** | 베어링 잔여수명(RUL), 마모 진행률 예측 |
| **품질 관리** | 입도분포 실시간 측정 |
| **안전 관리** | 분진 폭발 위험 사전 차단, 필터 교체 예측 |

### 1.3 기술 스펙

- **엣지 디바이스**: 산업용 IoT 센서 + 엣지 AI 컴퓨팅
- **통신**: LoRa, WiFi, 4G/5G, 이더넷
- **서버**: 클라우드/온프레미스 선택 가능
- **대시보드**: 웹 기반 실시간 모니터링
- **알림**: SMS, 이메일, 카카오톡 알림

### 1.4 데모 URL

- **한국 타이어 데모**: https://uttec-sensor.duckdns.org/demo/hankook/
