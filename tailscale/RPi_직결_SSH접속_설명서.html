SD 굽기 단계에서 SSH·계정 심기 (신품 필수 — 실패 1위 원인)

라즈베리파이 OS는 기본적으로 SSH가 꺼져 있다. 화면 없이 접속하려면 SD에 미리 심어야 한다.

방법 ① Imager로 구울 때 (권장) — Raspberry Pi Imager → ⚙️ 고급 설정:

  • 호스트네임 지정 (예: rpi4-bins)
  • SSH 사용 체크 + 사용자/비밀번호 지정 (예: uttec / uttec)

방법 ② 이미 구운 카드 — SD를 노트북에 꽂으면 boot 드라이브가 보인다:

  • 빈 파일 ssh 생성 (확장자 없음) → SSH 켜짐
  • 최신 OS는 계정 파일도: userconf.txt 에 사용자명:암호해시 1줄
1

케이블 직결 + 전원 ON

RPi 이더넷 ↔ 노트북 이더넷 포트를 일반 랜케이블로 직결하고 RPi 전원을 켠다.

Get-NetAdapter        # Status=Up 확인 (어느 포트든 OK — 포트 이름 기억)
💡 첫 부팅은 1~2분 걸린다 (파일시스템 확장). 링크가 안 뜨면 RPi LED(초록 깜빡임)부터 확인.
2

인터넷 공유(ICS) 켜기 — 노트북이 공유기가 된다

노트북이 DHCP 서버(192.168.137.1) + 인터넷 게이트웨이가 되어, RPi 쪽 설정은 0이다.

# 관리자 승인(UAC) 1회 — RPi를 꽂은 포트를 -Private로 지정
Start-Process powershell -Verb RunAs -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass',
  '-File','C:\todo\today\tailscale\enable-ics.ps1'   # USB 포트면: 뒤에 ,'-Private','이더넷 9'

# 확인: 꽂은 포트가 192.168.137.1 이면 성공
ipconfig
💡 GUI로 할 때: ncpa.cpl → Wi-Fi 우클릭 → 속성 → 공유 탭 → 체크 + 대상 포트 선택.
💡 RPi를 꽂은 뒤에 ICS를 켰다면 관리자 PowerShell에서 Restart-NetAdapter -Name "포트명" 한 번 (링크를 껐다 켜면 RPi가 즉시 IP를 다시 받는다).
3

RPi 찾기 — IP 스캔

# 브로드캐스트로 ARP 테이블 채우고 RPi MAC(B8-27-EB/DC-A6-32/E4-5F-01/D8-3A-DD)을 찾는다
ping -n 1 192.168.137.255 ; arp -a | findstr 192.168.137

→ 192.168.137.xxx  b8-27-eb-… 처럼 나오는 주소가 RPi다. (30초~2분 내)

🚨 ping raspberrypi.local(mDNS)은 RPi가 Wi-Fi에도 붙어 있으면 엉뚱한 IP를 돌려줄 수 있다 — ARP 스캔이 확실하다.
4

SSH 접속 + 키 등록

ssh uttec@192.168.137.xxx        # 0단계에서 정한 계정/비밀번호

접속되면 공개키를 등록해 다음부터 비밀번호 없이 들어간다 (비밀번호 마지막 1회 입력):

type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh uttec@192.168.137.xxx `
  "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

인터넷도 이미 공유되고 있으므로 그 자리에서 바로:

sudo apt update                  # 인터넷 확인 (sudo는 비밀번호 요구)
curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up
# → Tailscale 등록 후에는 직결 없이 어디서나 접속 가능
