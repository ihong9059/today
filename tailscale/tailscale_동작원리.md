# Tailscale 동작 원리 및 데이터 흐름

## 기존 SSH가 안 되는 이유

```
[내 PC] ---> [공유기/NAT] ---> [인터넷] ---> [공유기/NAT] ---> [대상 PC]
                 ↑                               ↑
            외부에서 접근 불가              외부에서 접근 불가
```

- 대부분의 PC는 **공유기(NAT) 뒤에** 있어서 사설 IP(192.168.x.x)를 사용
- 외부에서 직접 접근하려면 **포트포워딩** 또는 **공인 IP**가 필요
- 방화벽이 외부 → 내부 연결을 차단

---

## Tailscale의 해결 방법

### 1. 중앙 조정 서버 (Coordination Server)

```
[내 PC] ----→ [Tailscale 서버] ←---- [대상 PC]
   ↑              (클라우드)              ↑
   └── 둘 다 "나가는" 연결 (아웃바운드) ──┘
```

- 모든 기기가 Tailscale 서버에 **아웃바운드 연결**
- 아웃바운드(나가는 연결)는 공유기/방화벽이 허용
- 서버가 각 기기의 공인 IP, 포트 정보를 교환해줌

### 2. NAT 홀펀칭 (NAT Hole Punching)

```
[내 PC] ←────── 직접 연결 (P2P) ──────→ [대상 PC]
   ↑                                        ↑
공유기가 "응답"으로 인식        공유기가 "응답"으로 인식
```

- 양쪽이 동시에 서로에게 패킷을 보냄
- 공유기는 이를 "내가 보낸 요청의 응답"으로 착각
- 결과적으로 **방화벽을 통과**하여 직접 연결 성립

### 3. 릴레이 서버 (DERP - 최후의 수단)

```
[내 PC] --→ [Tailscale DERP 서버] --→ [대상 PC]
```

- 홀펀칭이 실패하면 Tailscale의 릴레이 서버를 경유
- 속도는 느리지만 **어떤 환경에서도 연결 가능**

## 데이터 흐름

```
┌─────────────────────────────────────────────────────────┐
│                    Tailscale 네트워크                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [내 PC]                              [대상 PC]          │
│  100.82.193.50                       100.x.x.x          │
│      │                                   │              │
│      │    ┌─────────────────────┐       │              │
│      └───→│  WireGuard 암호화   │←──────┘              │
│           │  (P2P 직접 연결)     │                      │
│           └─────────────────────┘                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 단계 | 설명 |
|:-----|:-----|
| 1 | 내 PC에서 `ssh 100.x.x.x` 실행 |
| 2 | Tailscale이 패킷을 WireGuard로 암호화 |
| 3 | NAT 홀펀칭으로 뚫린 경로를 통해 P2P 전송 |
| 4 | 대상 PC의 Tailscale이 복호화 |
| 5 | 대상 PC의 SSH 서버(localhost:22)로 전달 |

## 핵심 차이점 요약

| 항목 | 기존 SSH | Tailscale + SSH |
|:-----|:---------|:----------------|
| 연결 방향 | 외부 → 내부 (차단됨) | 양쪽 → 외부 (허용됨) |
| 공인 IP 필요 | 필요 | 불필요 |
| 포트포워딩 | 필요 | 불필요 |
| 방화벽 통과 | 불가 | 가능 (홀펀칭) |
| 암호화 | SSH만 | WireGuard + SSH |

---

## 한마디로

> **"둘 다 밖으로 나가서 만난다"**

공유기/방화벽은 **나가는 연결은 허용**하므로, 양쪽이 먼저 밖으로 나가서 Tailscale 서버의 도움으로 서로를 찾아 직접 연결합니다.
