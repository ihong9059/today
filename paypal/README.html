AI Productivity Timer & Task Tracker — 수익형 Micro-SaaS 웹 애플리케이션

🎯 프로젝트 개요

FocusFlow는 포모도로 타이머, 할 일 관리, 생산성 통계를 제공하는 수익형 Micro-SaaS 웹 애플리케이션입니다.

  • 수익 모델: Freemium (무료 기본 기능 + Pro 플랜 $4.99/월)
  • 타겟: 글로벌 프리랜서, 원격 근무자, 학생
  • UI 언어: 영어 (글로벌 시장 타겟)
  • 디자인: Silicon Valley Quality — 다크 모드 퍼스트, 모던 UI

✨ 주요 기능

⏱️ 포모도로 타이머

Focus (25분), Short Break (5분), Long Break (15분) 모드. 시작/일시정지/리셋. 진행률 원형 프로그레스 바.

📋 할 일 관리

할 일 추가/완료/삭제. 예상 포모도로 수 설정. Free 플랜은 5개 제한.

📊 생산성 통계

세션 수, 집중 시간(분), 완료 작업, 연속 사용일(스트릭) 실시간 표시.

PayPal MCP 연동 준비 완료. Pro 업그레이드 모달 및 결제 플로우.

🔥 Phase 3: Firebase 연동 안내

현재 Firebase Management API 활성화가 필요합니다. 다음 단계를 수행해주세요:

  1. Google Cloud Console에서 Firebase Management API 활성화
  2. Firebase 프로젝트 생성 (또는 기존 프로젝트 사용)
  3. Firestore 및 Auth 초기화

활성화 후, app.js에 표시된 "Firebase Auth Integration Point" 및 "Firebase Firestore Integration Point" 주석 위치에서 실제 Firebase SDK 코드를 연결합니다.

💰 Phase 4: PayPal 연동 안내

app.js의 handlePayPalCheckout() 함수에 PayPal MCP 연동 포인트가 준비되어 있습니다.

PayPal MCP create_order 도구를 사용하여 실제 결제 주문을 생성할 수 있습니다:

// PayPal MCP Order 생성 예시
{
  currencyCode: "USD",
  items: [{
    name: "FocusFlow Pro Monthly",
    description: "Unlimited tasks, analytics, cloud sync",
    itemCost: 4.99,
    itemTotal: 4.99,
    quantity: 1
  }]
}

🎨 디자인 특징

  • Dark Mode First: 눈의 피로를 줄이는 다크 테마 기본 적용
  • Glassmorphism Navigation: 블러 배경 + 반투명 네비게이션 바
  • Gradient Accents: 보라색 계열 그라데이션으로 브랜드 아이덴티티 강화
  • Micro-animations: 호버 효과, 페이드인, 슬라이드업 애니메이션
  • Inter Font: Google Fonts의 Inter 폰트로 모던한 타이포그래피
  • Mobile-first Responsive: 768px, 480px 브레이크포인트 반응형 레이아웃
