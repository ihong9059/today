# Slack 설명서

## Slack이란?

Slack은 **비즈니스용 실시간 메시징 및 협업 플랫폼**입니다. 팀 커뮤니케이션을 채널 단위로 정리하여 이메일 대신 빠르고 체계적으로 소통할 수 있게 해줍니다.

- 공식 사이트: https://slack.com
- 2013년 출시, 2021년 Salesforce가 약 27.7조원(277억 달러)에 인수
- 전 세계 75만+ 기업에서 사용

---

## 핵심 특징

### 1. 채널 기반 커뮤니케이션
- 주제/프로젝트/팀별로 채널 생성 (예: #개발, #마케팅, #일반)
- 공개 채널: 누구나 참여 가능
- 비공개 채널: 초대받은 사람만 참여
- 대화가 주제별로 정리되어 이메일보다 효율적

### 2. 다이렉트 메시지 (DM)
- 1:1 또는 소규모 그룹 메시지
- 채널에 올리기 애매한 개인적 대화에 사용

### 3. 스레드 (Thread)
- 메시지에 답글을 달아 하위 대화 생성
- 채널이 지저분해지지 않고 주제별 토론 가능

### 4. 검색
- 모든 메시지, 파일, 채널을 강력한 검색으로 찾기
- 필터: `from:`, `in:`, `before:`, `after:`, `has:` 등
- 예: `from:김철수 in:#개발 has:link` → 김철수가 #개발에서 보낸 링크 포함 메시지

### 5. 연동 (Integration)
- 2,600개 이상의 앱/서비스 연동
- GitHub, Jira, Google Drive, Figma, Notion 등
- 봇과 자동화 워크플로우 구축 가능

## 주요 기능

### 메시징
| 기능 | 설명 |
|------|------|
| **텍스트 포맷** | 굵게, 기울임, 코드블록, 목록 지원 |
| **이모지 반응** | 메시지에 이모지로 빠른 반응 |
| **파일 공유** | 이미지, 문서, 코드 등 드래그앤드롭 |
| **음성/영상 통화** | Huddle(허들) 기능으로 즉석 음성/영상 회의 |
| **화면 공유** | Huddle 중 화면 공유 가능 |
| **예약 메시지** | 특정 시간에 메시지 발송 예약 |
| **리마인더** | `/remind` 명령으로 알림 설정 |
| **북마크** | 중요 메시지 저장 |
| **핀** | 채널 내 중요 메시지 고정 |

### Slack Connect
- 외부 회사/파트너와 채널을 공유하여 조직 간 협업
- 이메일 대신 실시간 소통

### 워크플로우 빌더
- 코딩 없이 자동화 워크플로우 생성
- 예: 신입사원 온보딩, 요청 양식, 승인 프로세스

### Slack AI (유료)
- 채널 요약: 안 읽은 대화 핵심 정리
- 검색 답변: 질문하면 대화 내역에서 답변 생성
- 스레드 요약: 긴 스레드 핵심 요약

## Slack vs 다른 도구 비교

| 항목 | Slack | Microsoft Teams | Discord |
|------|-------|-----------------|---------|
| 주 용도 | 비즈니스 협업 | 비즈니스 협업 (MS 생태계) | 커뮤니티/게이밍 |
| 무료 플랜 | 90일 이력 | 제한적 | 무제한 이력 |
| 앱 연동 | 2,600+ | MS 앱 중심 | 봇 중심 |
| 화상 회의 | Huddle (간편) | 본격 화상회의 | 음성/영상 채널 |
| 파일 저장 | 워크스페이스별 | OneDrive 연동 | 채널별 |
| 외부 협업 | Slack Connect | Teams Connect | 서버 초대 |
| 강점 | 개발자 생태계, 연동 | Office 365 통합 | 무료, 커뮤니티 |

## 개발자 관점에서의 활용

### 1. GitHub/GitLab 연동
- PR 생성, 코드 리뷰, 머지, CI/CD 알림을 채널에서 수신
- 채널에서 바로 PR 승인/댓글 가능

### 2. 배포/모니터링 알림
- 서버 장애, 배포 완료, 에러 로그를 Slack 채널로 수신
- PagerDuty, Datadog, Sentry 등 연동

### 3. Slack Bot 개발
- Slack API (Bolt framework)로 커스텀 봇 제작
- Python, JavaScript, Java SDK 제공
- 자동 응답, 데이터 조회, 작업 자동화

### 4. Webhook
- **Incoming Webhook**: 외부 시스템 → Slack 메시지 전송
- **Outgoing Webhook**: Slack 메시지 → 외부 시스템 트리거

```bash
# Incoming Webhook 예시
curl -X POST -H 'Content-type: application/json' \
  --data '{"text":"배포 완료!"}' \
  https://hooks.slack.com/services/T.../B.../xxx
```

### 5. Slack API
- Web API: 메시지 전송, 채널 관리, 사용자 정보 조회
- Events API: 실시간 이벤트 수신
- Socket Mode: WebSocket 기반 이벤트 처리

## 시작하기

1. https://slack.com 에서 워크스페이스 생성 또는 초대 링크로 참여
2. 채널 둘러보기 → 관심 채널 참여
3. 프로필 설정 (사진, 이름, 역할)
4. 데스크톱/모바일 앱 설치 (선택)
5. 알림 설정 조정 (업무 시간, 키워드 알림 등)
6. 자주 쓰는 앱 연동 (GitHub, Google Drive 등)
