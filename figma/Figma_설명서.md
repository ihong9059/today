# Figma 설명서

## Figma란?

Figma는 **웹 브라우저 기반의 UI/UX 디자인 협업 도구**입니다. 별도 설치 없이 브라우저에서 바로 사용할 수 있으며, 여러 사람이 동시에 같은 파일을 편집할 수 있는 것이 가장 큰 특징입니다.

- 공식 사이트: https://www.figma.com
- 2012년 출시, 2022년 Adobe가 인수 시도했으나 규제로 철회

---

## 핵심 특징

### 1. 웹 기반 (클라우드)
- 설치 불필요, 브라우저에서 바로 작업
- Windows, Mac, Linux 모두 사용 가능
- 데스크톱 앱도 제공 (선택사항)

### 2. 실시간 협업
- Google Docs처럼 여러 사람이 동시 편집
- 커서가 실시간으로 보임
- 댓글/피드백 기능 내장

### 3. 컴포넌트 시스템
- 재사용 가능한 UI 컴포넌트 생성
- 마스터 컴포넌트 수정 시 모든 인스턴스에 자동 반영
- 디자인 시스템 구축에 적합

### 4. 프로토타이핑
- 디자인 화면 간 인터랙션/전환 효과 설정
- 클릭, 호버, 드래그 등 사용자 상호작용 시뮬레이션
- 코딩 없이 앱/웹 동작을 미리 체험

### 5. 개발자 핸드오프
- Dev Mode: 개발자가 CSS, iOS, Android 코드 스니펫 확인
- 간격, 크기, 색상 등 정확한 수치 자동 추출
- 에셋(이미지, 아이콘) 직접 내보내기

## 주요 제품군

| 제품 | 용도 |
|------|------|
| **Figma Design** | UI/UX 디자인, 와이어프레임, 목업 제작 |
| **FigJam** | 온라인 화이트보드, 브레인스토밍, 플로우차트 |
| **Figma Slides** | 프레젠테이션 제작 |
| **Dev Mode** | 개발자용 디자인 스펙 확인 도구 |

---

## 사용 분야

- **앱 디자인**: 모바일/웹 앱 UI 설계
- **웹 디자인**: 랜딩 페이지, 대시보드 레이아웃
- **와이어프레임**: 초기 구조/흐름 설계
- **디자인 시스템**: 회사/프로젝트 공통 UI 가이드라인
- **프로토타입**: 클릭 가능한 시제품으로 사용성 테스트
- **아이콘/일러스트**: 벡터 그래픽 제작

## Figma vs 다른 도구 비교

| 항목 | Figma | Adobe XD | Sketch |
|------|-------|----------|--------|
| 플랫폼 | 웹 + 데스크톱 | 데스크톱 | Mac 전용 |
| 실시간 협업 | O | 제한적 | X |
| 무료 플랜 | O | 종료됨 | X |
| 프로토타이핑 | 내장 | 내장 | 플러그인 |
| 플러그인 생태계 | 매우 풍부 | 보통 | 풍부 |
| 개발자 핸드오프 | Dev Mode | 제한적 | 외부 도구 |

## 기본 용어

| 용어 | 설명 |
|------|------|
| **Frame** | 디자인 영역 (아트보드). 화면 단위로 사용 |
| **Component** | 재사용 가능한 UI 요소 (버튼, 카드 등) |
| **Instance** | 컴포넌트의 복사본. 원본 수정 시 함께 변경 |
| **Variant** | 컴포넌트의 상태별 변형 (활성/비활성, 크기 등) |
| **Auto Layout** | 내용에 따라 자동 크기 조절 (CSS Flexbox와 유사) |
| **Style** | 색상, 텍스트, 효과를 저장하여 재사용 |
| **Plugin** | 커뮤니티가 만든 확장 기능 |
| **Prototype** | 화면 간 연결/전환을 설정한 인터랙티브 미리보기 |

## 개발자 관점에서의 활용

1. **디자인 스펙 확인**: Dev Mode에서 CSS 속성, 간격, 색상 코드 확인
2. **에셋 추출**: SVG, PNG 등 원하는 포맷으로 아이콘/이미지 내보내기
3. **API 연동**: Figma REST API로 디자인 데이터를 프로그래밍적으로 접근
4. **코드 생성 플러그인**: Figma → React, Flutter, HTML/CSS 코드 자동 변환
5. **디자인 토큰**: 색상, 폰트, 간격을 JSON으로 추출하여 코드에 반영

## 시작하기

1. https://www.figma.com 에서 무료 계정 생성
2. "New design file" 클릭하여 새 파일 생성
3. 상단 도구 모음에서 Frame(F) 선택 → 디바이스 프리셋 선택 (iPhone, Android 등)
4. 좌측 도구로 도형, 텍스트, 이미지 배치
5. 우측 패널에서 속성 (색상, 크기, 정렬 등) 조정
6. 공유 버튼으로 팀원에게 링크 전달
