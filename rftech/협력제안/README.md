# (주)알에프텍 스마트팩토리 예지정비 솔루션 제안서

## 개요

UTTEC에서 (주)알에프텍에 제안하는 스마트팩토리 예지정비 솔루션 웹 제안서입니다.

## 실행 방법

### 방법 1: 직접 HTML 열기
`index.html` 파일을 웹 브라우저에서 직접 열어볼 수 있습니다.

### 방법 2: 웹 서버 실행
```bash
# 의존성 설치
npm install

# 서버 실행
npm start

# 브라우저에서 접속
# http://localhost:8080
```

## 파일 구조

```
협력제안/
├── index.html      # 메인 제안서 HTML
├── server.js       # Express 웹 서버
├── package.json    # Node.js 패키지 설정
└── README.md       # 이 파일
```
