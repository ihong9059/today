개발 제안서

Military Smart Charging System (MSCS)

문서번호: RFTECH-MCS-PROPOSAL-2025-001 | 버전: 1.1 | 작성일: 2025년 12월 30일

📋 프로젝트 개요

군부대 내 휴대전화 충전 관리를 위한 스마트 시스템 개발로, RFID 인증, BLE 스마트폰 연동, 근무시간 기반 자동 제어 기능을 구현합니다.

핵심 요구사항

⏰ 시간 제어

근무시간 외 충전 허용, 근무시간 중 충전 차단

🔑 RFID 인증

3종 키 (휴일/평일/Unlock) 기반 관리자 제어

📱 BLE 연동

스마트폰 앱을 통한 원격 제어 및 모니터링

📟 디스플레이

4-digit 7-segment로 시간/상태 표시

🛡️ 안전 시스템

이상 상태 감지 센서 및 알람 시스템

🔒 잠금 제어

전자식 Lock Driver를 통한 Chamber 제어

🔧 개발 범위

1. 하드웨어 개발

항목 내용 비고
MCU STM32 또는 ESP32 계열 시스템 제어
RTC DS3231 (배터리 백업 포함) 시간 관리
RFID RC522 (13.56MHz Mifare) 태그 인식
BLE ESP32 내장 또는 별도 모듈 스마트폰 연동
회로 설계 메인 컨트롤러, 드라이버 보드 회로도 제공
PCB 설계 2~4층 PCB 아트웍 Gerber 제공

2. 펌웨어 개발

모듈 기능
시스템 코어 RTOS 기반 태스크 관리
RTC 드라이버 시간 관리, 배터리 백업
RFID 모듈 태그 인식, 키 판별, 인증 처리
BLE 모듈 GAP/GATT 프로파일, 데이터 통신
7-Segment 드라이버 다이나믹 구동, 문자 표시
Lock/센서/알람 잠금 제어, 이상 감지, 경보 출력
스케줄러 근무시간표 관리, 자동 전환

3. 스마트폰 앱 개발

🛠️ 개발 플랫폼

Flutter 또는 React Native (크로스 플랫폼)

📱 지원 OS

Android 10+ / iOS 14+

기능 설명
BLE 연결 장치 검색, 페어링, 연결 관리
시간 동기화 스마트폰 시간 → RTC 전송
근무시간 설정 평일/휴일 시간표 편집 UI
모드 전환 평일/휴일 모드 원격 전환
상태 모니터링 실시간 상태 표시, Push 알림
이력 조회 잠금/해제, 알람 이력 표시

📅 개발 단계

1

Phase 1: 기획 및 설계 (3주)

  • 요구사항 분석 및 상세 기능 정의
  • 시스템 아키텍처 설계
  • 하드웨어 회로 설계
  • 펌웨어 구조 설계
  • 앱 UI/UX 설계
2

Phase 2: 핵심 기능 개발 (6주)

  • 메인 보드 PCB 설계
  • 펌웨어 코어 모듈 개발
  • RFID/BLE 모듈 개발
  • 앱 기본 기능 개발
  • 시뮬레이션 테스트
3

Phase 3: 기능 완성 및 통합 (5주)

  • 센서 및 알람 시스템 개발
  • 스케줄러 및 자동화 기능 개발
  • 앱 전체 기능 개발
  • 시스템 통합 테스트
