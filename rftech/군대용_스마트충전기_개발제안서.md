## 1. 프로젝트 개요

### 1.1 프로젝트명
**Military Smart Charging System (MSCS) 개발**

### 1.2 개발 목표
군부대 내 휴대전화 충전 관리를 위한 스마트 시스템 개발로,
RFID 인증, BLE 스마트폰 연동, 근무시간 기반 자동 제어 기능을 구현합니다.

### 1.3 핵심 요구사항

| 구분 | 요구사항 |
|------|----------|
| **시간 제어** | 근무시간 외 충전 허용, 근무시간 중 충전 차단 |
| **RFID 인증** | 3종 키 (휴일/평일/Unlock) 기반 관리자 제어 |
| **BLE 연동** | 스마트폰 앱을 통한 원격 제어 및 모니터링 |
| **디스플레이** | 4-digit 7-segment로 시간/상태 표시 |
| **안전 시스템** | 이상 상태 감지 센서 및 알람 시스템 |
| **잠금 제어** | 전자식 Lock Driver를 통한 Chamber 제어 |

## 2. 개발 범위

### 2.1 하드웨어 개발

#### 2.1.1 메인 컨트롤러 보드 설계
| 항목 | 내용 |
|------|------|
| MCU | STM32 또는 ESP32 계열 |
| RTC | DS3231 (배터리 백업 포함) |
| RFID | RC522 (13.56MHz Mifare) |
| BLE | ESP32 내장 BLE 또는 별도 BLE 모듈 |
| 7-Segment | 4-digit 공통 캐소드/애노드 LED |
| Lock Driver | 릴레이 또는 MOSFET 드라이버 |
| 센서 인터페이스 | 온도, 연기, 진동 센서 연결부 |
| 알람 출력 | 부저 + LED 드라이버 |

#### 2.1.2 PCB 설계
- 2층 또는 4층 PCB
- 메인 컨트롤러 보드 설계
- EMI/EMC 고려 설계

> **참고:** 시제품 PCB 제작, 부품 구매, 외함 설계/제작은 본 개발 범위에서 제외됩니다.

### 2.2 펌웨어 개발

| 모듈 | 기능 |
|------|------|
| **시스템 코어** | RTOS 기반 태스크 관리 |
| **RTC 드라이버** | 시간 관리, 배터리 백업 |
| **RFID 모듈** | 태그 인식, 키 판별, 인증 처리 |
| **BLE 모듈** | GAP/GATT 프로파일, 데이터 통신 |
| **7-Segment 드라이버** | 다이나믹 구동, 문자 표시 |
| **Lock 제어** | 잠금/해제 제어, 타임아웃 관리 |
| **센서 처리** | 이상 상태 감지, 임계값 관리 |
| **알람 제어** | 다단계 알람 출력 |
| **스케줄러** | 근무시간표 관리, 자동 전환 |
| **EEPROM/Flash** | 설정값 저장, 이력 관리 |

### 2.3 스마트폰 앱 개발

#### 2.3.1 플랫폼
- **크로스 플랫폼**: Flutter 또는 React Native
- **지원 OS**: Android 10+ / iOS 14+

#### 2.3.2 앱 기능
| 기능 | 설명 |
|------|------|
| BLE 연결 | 장치 검색, 페어링, 연결 관리 |
| 시간 동기화 | 스마트폰 시간 → RTC 전송 |
| 근무시간 설정 | 평일/휴일 시간표 편집 UI |
| 모드 전환 | 평일/휴일 모드 원격 전환 |
| 상태 모니터링 | 실시간 상태 표시, Push 알림 |
| 이력 조회 | 잠금/해제, 알람 이력 표시 |
| 관리자 인증 | PIN 또는 생체 인증 |

### 2.4 통신 프로토콜 개발

| 항목 | 내용 |
|------|------|
| BLE 프로파일 | Custom GATT 서비스 정의 |
| 명령 체계 | 요청/응답 패킷 구조 설계 |
| 보안 | AES-128 암호화, 페어링 인증 |
| 오류 처리 | CRC 검증, 재전송 메커니즘 |
