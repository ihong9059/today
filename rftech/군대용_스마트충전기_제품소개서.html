Military Smart Charging System

군대용 스마트 충전 관리 시스템 (MSCS)

문서번호: RFTECH-MCS-2025-001 | 버전: 1.0 | 작성일: 2025년 12월 30일

📋 제품 개요

군부대 내 휴대전화 및 전자기기의 체계적인 충전 관리를 위한 스마트 시스템으로, 근무시간에는 충전을 차단하고 휴식시간에만 충전을 허용하여 병력 집중력 향상 및 보안 강화를 실현합니다.

🔒 보안 강화

근무시간 중 휴대전화 사용 원천 차단

🎯 효율적 관리

RFID 기반 관리자 인증 시스템

⚙️ 유연한 운영

평일/휴일 근무시간 개별 설정

📱 스마트 연동

BLE 기반 스마트폰 앱 제어

🛡️ 안전 보장

이상 상태 감지 및 알람 시스템

주요 하드웨어 사양

구성요소 사양 기능
MCU ARM Cortex-M 계열 시스템 제어 및 연산
RTC DS3231 또는 동급 정확한 시간 유지 (배터리 백업)
RFID Reader 13.56MHz (Mifare) 관리자 태그 인식
7-Segment 4-Digit LED 현재 시간 / 상태 표시
BLE Module BLE 5.0 스마트폰 앱 연동
Lock Driver 전자식 솔레노이드 Chamber 잠금/해제
이상감지 센서 온도/연기/진동 비정상 상태 감지
알람 부저 + LED 경고음 및 시각 경보

🔑 RFID 키 시스템

3종의 RFID 키를 통해 시스템을 간편하게 제어할 수 있습니다.

🟢

KEY 1 - 휴일 설정

휴일 근무시간 모드로 전환
7-Segment에 "HOLi" 표시

🔵

KEY 2 - 평일 설정

평일 근무시간 모드로 전환
7-Segment에 "dAY" 표시

🔴

KEY 3 - Chamber Unlock

긴급 잠금 해제 (관리자 전용)
7-Segment에 "oPEn" 표시
