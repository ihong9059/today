# 군대용 스마트 충전기 시스템 제품 소개서

**문서번호:** RFTECH-MCS-2025-001
**작성일:** 2025년 12월 30일
**버전:** 1.0

---

## 1. 제품 개요

### 1.1 제품명
**Military Smart Charging System (MSCS)**
군대용 스마트 충전 관리 시스템

### 1.2 제품 목적
군부대 내 휴대전화 및 전자기기의 체계적인 충전 관리를 위한 스마트 시스템으로,
근무시간에는 충전을 차단하고 휴식시간에만 충전을 허용하여 **병력 집중력 향상** 및
**보안 강화**를 실현합니다.

### 1.3 핵심 가치
| 구분 | 내용 |
|------|------|
| **보안 강화** | 근무시간 중 휴대전화 사용 원천 차단 |
| **효율적 관리** | RFID 기반 관리자 인증 시스템 |
| **유연한 운영** | 평일/휴일 근무시간 개별 설정 |
| **스마트 연동** | BLE 기반 스마트폰 앱 제어 |
| **안전 보장** | 이상 상태 감지 및 알람 시스템 |

## 2. 시스템 구성

### 2.1 하드웨어 구성도

```
┌─────────────────────────────────────────────────────────────┐
│                    MSCS 메인 컨트롤러                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│  │  MCU Core   │  │     RTC     │  │  BLE Module │          │
│  │             │  │  (시간관리)  │  │ (스마트폰)   │          │
│  └─────────────┘  └─────────────┘  └─────────────┘          │
│         │                │                │                  │
│  ┌──────┴────────────────┴────────────────┴──────┐          │
│  │              시스템 버스                        │          │
│  └──────┬────────────────┬────────────────┬──────┘          │
│         │                │                │                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│  │ RFID Reader │  │ 7-Segment   │  │ Lock Driver │          │
│  │  (인증)     │  │ (시간표시)   │  │ (잠금제어)   │          │
│  └─────────────┘  └─────────────┘  └─────────────┘          │
│         │                                    │               │
│  ┌─────────────┐                     ┌─────────────┐        │
│  │ 이상감지    │                     │   알람      │        │
│  │  센서      │                     │  (경보)     │        │
│  └─────────────┘                     └─────────────┘        │
└─────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              │      Charger Chamber          │
              │   (충전 보관함 - 다수 슬롯)     │
              └───────────────────────────────┘
```

### 2.2 주요 하드웨어 사양

| 구성요소 | 사양 | 기능 |
|----------|------|------|
| **MCU** | ARM Cortex-M 계열 | 시스템 제어 및 연산 |
| **RTC** | DS3231 또는 동급 | 정확한 시간 유지 (배터리 백업) |
| **RFID Reader** | 13.56MHz (Mifare) | 관리자 태그 인식 |
| **7-Segment** | 4-Digit LED | 현재 시간 / 상태 표시 |
| **BLE Module** | BLE 5.0 | 스마트폰 앱 연동 |
| **Lock Driver** | 전자식 솔레노이드 | Chamber 잠금/해제 |
| **이상감지 센서** | 온도/연기/진동 | 비정상 상태 감지 |
| **알람** | 부저 + LED | 경고음 및 시각 경보 |

## 3. RFID 키 시스템

### 3.1 키 구성 (3종)

| 키 번호 | 용도 | 색상 권장 | 기능 설명 |
|---------|------|-----------|-----------|
| **KEY 1** | 휴일 설정 | 🟢 녹색 | 휴일 근무시간 모드 전환 |
| **KEY 2** | 평일 설정 | 🔵 청색 | 평일 근무시간 모드 전환 |
| **KEY 3** | Chamber Unlock | 🔴 적색 | 긴급 잠금 해제 (관리자 전용) |

### 3.2 키 동작 시나리오

```
┌─────────────────────────────────────────────────────────┐
│  KEY 1 (휴일)                                            │
│  ├─ 태그 → 휴일 모드 활성화                               │
│  ├─ 휴일 근무시간표 적용                                   │
│  └─ 7-Segment에 "HOLi" 표시 후 시간 표시                  │
├─────────────────────────────────────────────────────────┤
│  KEY 2 (평일)                                            │
│  ├─ 태그 → 평일 모드 활성화                               │
│  ├─ 평일 근무시간표 적용                                   │
│  └─ 7-Segment에 "dAY" 표시 후 시간 표시                   │
├─────────────────────────────────────────────────────────┤
│  KEY 3 (Unlock)                                          │
│  ├─ 태그 → Chamber 즉시 잠금 해제                         │
│  ├─ 타임아웃 후 자동 재잠금 (설정 가능)                    │
│  └─ 7-Segment에 "oPEn" 표시                              │
└─────────────────────────────────────────────────────────┘
```

## 4. 근무시간 관리

### 4.1 운영 모드

| 모드 | 충전 상태 | Chamber 상태 | 설명 |
|------|-----------|--------------|------|
| **근무시간** | ❌ 충전 차단 | 🔒 잠금 | 휴대전화 보관만 가능 |
| **휴식시간** | ✅ 충전 허용 | 🔓 해제 | 충전 및 사용 가능 |
| **비상모드** | ✅ 충전 허용 | 🔓 해제 | 관리자 KEY 3 사용 시 |

### 4.2 시간표 예시

**평일 (KEY 2 모드)**
| 시간대 | 상태 | 비고 |
|--------|------|------|
| 06:00 - 07:00 | 충전 허용 | 기상 후 |
| 07:00 - 12:00 | 충전 차단 | 오전 근무 |
| 12:00 - 13:00 | 충전 허용 | 점심시간 |
| 13:00 - 18:00 | 충전 차단 | 오후 근무 |
| 18:00 - 22:00 | 충전 허용 | 휴식시간 |
| 22:00 - 06:00 | 충전 차단 | 취침시간 |

**휴일 (KEY 1 모드)**
| 시간대 | 상태 | 비고 |
|--------|------|------|
| 06:00 - 22:00 | 충전 허용 | 종일 휴식 |
| 22:00 - 06:00 | 충전 차단 | 취침시간 |

## 6. 안전 시스템

### 6.1 이상 상태 감지

| 감지 항목 | 센서 | 대응 동작 |
|-----------|------|-----------|
| **과열** | 온도 센서 | 충전 차단 + 알람 |
| **연기** | 연기 감지 | 충전 차단 + 알람 + 자동 해제 |
| **물리적 충격** | 진동 센서 | 알람 + 관리자 알림 |
| **비인가 접근** | RFID 미등록 태그 | 알람 + 이력 기록 |
| **강제 개방 시도** | 도어 센서 | 알람 + 관리자 알림 |

### 6.2 알람 동작

| 알람 레벨 | 동작 | 상황 |
|-----------|------|------|
| **Level 1** | 부저 단음 | 일반 알림 (태그 인식 등) |
| **Level 2** | 부저 연속음 + LED 점멸 | 비인가 접근 시도 |
| **Level 3** | 부저 사이렌 + LED 점멸 + 앱 알림 | 화재/과열 감지 |

## 7. 제품 사양 요약

| 항목 | 사양 |
|------|------|
| **입력 전원** | AC 220V, 50/60Hz |
| **충전 슬롯** | 10~20개 (모델별 상이) |
| **충전 출력** | 5V 2A (USB Type-A) / 9V 2A (QC 3.0) |
| **RFID 주파수** | 13.56MHz (ISO 14443A) |
| **BLE 버전** | Bluetooth 5.0 BLE |
| **RTC 정밀도** | ±2ppm (연간 1분 이내 오차) |
| **동작 온도** | -10°C ~ +50°C |
| **외함 재질** | 강화 스틸 (분체 도장) |
| **크기** | 600mm x 400mm x 150mm (20슬롯 기준) |
| **중량** | 약 15kg (20슬롯 기준) |
