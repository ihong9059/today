## 2. 최적화 전략

### 2.1 사전 생성 방식 (권장)

**개념:** 30개 도착지 × 3개 예산 × 8개 목적 = 720개 시나리오 사전 생성

**장점:**
- 즉시 응답 (0초)
- 품질 보장
- 서버 부하 없음

**단점:**
- 초기 생성 시간 필요
- 저장 공간 필요 (~50MB)

**실행 계획:**
```
1. 30개 도시 시나리오 템플릿 생성 (도시별 특화 장면)
2. 예산별 변형 생성 (공통 장면 + 예산별 장면)
3. 목적별 변형 생성 (공통 장면 + 목적별 장면)
4. JSON 파일로 저장
```

### 2.2 하이브리드 방식

**개념:** 공통 템플릿(20개) + 실시간 생성(10개)

**구조:**
```
공통 템플릿 (사전 생성, 20개 scene)
├── 공항 출발 (4개): 체크인, 보안, 탑승, 기내
├── 공항 도착 (3개): 입국심사, 수하물, 환전
├── 호텔 (3개): 체크인, 문제해결, 체크아웃
├── 식당 (3개): 예약, 주문, 계산
├── 길찾기 (3개): 방향, 거리, 대중교통
├── 사고대응 (2개): 분실, 의료
└── 예산별 (2개): 비행기변경, 환불

실시간 생성 (Claude, 10개 scene)
├── 도착지 특화 관광지 (5개)
└── 여행 목적별 (5개)
```

**예상 시간:** 30초 ~ 1분

### 2.3 완전 템플릿 방식 (가장 빠름)

**개념:** 모든 scene을 템플릿화, 변수만 교체

**템플릿 예시:**
```javascript
{
  location: "{{city}} 국제공항 체크인 카운터",
  dialogues: [
    { speaker: "staff", english: "May I see your passport and ticket to {{city}}?" }
  ],
  choices: [
    { text: "Here you go.", correct: true },
    { text: "I don't have it.", correct: false }
  ]
}
```

**장점:** 즉시 생성 (0.1초)
**단점:** 다양성 부족, 도시별 특색 없음

## 4. 시나리오 조합 로직

```javascript
function generateScenario(destination, budget, purpose) {
  const scenes = [];

  // 1. 공항 출발 (4개)
  scenes.push(...commonScenes.departure);

  // 2. 예산별 추가 scene (최저가/절감형인 경우)
  if (budget === 'budget' || budget === 'economy') {
    scenes.push(...commonScenes.budget_specific);
  }

  // 3. 공항 도착 (3개)
  scenes.push(...commonScenes.arrival);

  // 4. 호텔 체크인 (1개)
  scenes.push(commonScenes.hotel_checkin);

  // 5. 길찾기 (2개)
  scenes.push(...commonScenes.directions.slice(0, 2));

  // 6. 도시별 관광지 (5개)
  scenes.push(...cityScenes[destination].tourist);

  // 7. 식당 (3개)
  scenes.push(...commonScenes.restaurant);

  // 8. 목적별 (5개)
  scenes.push(...purposeScenes[purpose]);

  // 9. 사고대응 (2개)
  scenes.push(...commonScenes.emergency);

  // 10. 호텔 체크아웃 (1개)
  scenes.push(commonScenes.hotel_checkout);

  // 11. 공항 귀국 (4개)
  scenes.push(...commonScenes.return);

  return scenes; // 총 30개+
}
```
