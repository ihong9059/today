## 2. 개선 방안 상세

### 2.1 사전 생성 (Pre-generation)

**개념:** 인기 여행 경로의 시나리오를 미리 생성해두고 즉시 제공

**구현 방법:**
```python
# 사전 생성할 경로 목록
POPULAR_ROUTES = [
    {"departure": "서울", "destination": "도쿄", "purpose": "tourism"},
    {"departure": "서울", "destination": "파리", "purpose": "tourism"},
    {"departure": "서울", "destination": "뉴욕", "purpose": "business"},
    {"departure": "서울", "destination": "방콕", "purpose": "backpacking"},
    {"departure": "서울", "destination": "런던", "purpose": "study"},
    # ... 총 20-30개 경로
]

# 각 경로별 3개 레벨 × 8개 목적 = 최대 24개 시나리오
```

**장점:**
- 즉시 응답 (0초)
- 서버 부하 없음
- 안정적인 품질

**단점:**
- 저장 공간 필요 (약 50MB)
- 커스텀 여행지 불가
- 정기 업데이트 필요

**예상 효과:** 80% 사용자 즉시 제공 가능

---

### 2.2 템플릿 기반 생성

**개념:** 공통 장면은 템플릿으로, 목적지 특화 장면만 Claude 생성

**템플릿 구조:**
```json
{
  "common_scenes": {
    "airport_checkin": { /* 공항 체크인 - 모든 여행 공통 */ },
    "inflight_service": { /* 기내 서비스 */ },
    "immigration": { /* 입국 심사 */ },
    "hotel_checkin": { /* 호텔 체크인 */ },
    "restaurant_order": { /* 식당 주문 */ },
    "taxi_ride": { /* 택시 이용 */ },
    "shopping": { /* 쇼핑 */ },
    "emergency": { /* 긴급 상황 */ }
  },
  "destination_specific": {
    /* Claude가 생성할 부분 - 5-10개 장면 */
  }
}
```

**장점:**
- 생성 시간 70% 단축 (5-10개 장면만 생성)
- 공통 장면 품질 보장
- 목적지 특성 반영 가능

**단점:**
- 템플릿 제작 초기 비용
- 다양성 일부 감소

**예상 효과:** 생성 시간 30초-1분

---

### 2.3 Claude API 직접 호출

**개념:** CLI 대신 API 직접 호출로 오버헤드 제거

**현재 (CLI):**
```python
result = subprocess.run(
    ['claude', '-p', prompt, '--output-format', 'text'],
    capture_output=True, timeout=600
)
```

**개선 (API):**
```python
import anthropic

client = anthropic.Anthropic(api_key="...")

response = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=8000,
    messages=[{"role": "user", "content": prompt}]
)
```

**장점:**
- CLI 프로세스 생성 오버헤드 제거
- 스트리밍 응답 가능
- 모델 선택 가능 (Haiku로 속도 향상)

**단점:**
- API 키 관리 필요
- 비용 발생 (현재 CLI는 무료?)

**예상 효과:** 20-30% 속도 향상

### 2.4 장면 수 축소

**개념:** 30개 → 10-15개로 축소

**비교:**
| 장면 수 | 생성 시간 | 학습 시간 | 사용자 경험 |
|:--------|:----------|:----------|:------------|
| 30개 | 3-5분 | 30-40분 | 긴 대기, 풍부한 콘텐츠 |
| 15개 | 1-2분 | 15-20분 | 적당한 대기 |
| 10개 | 30초-1분 | 10-15분 | 빠른 시작 |
| 5개 | 15-30초 | 5-7분 | 즉시 시작, 짧은 학습 |

**권장:** 10개 기본 + "더 학습하기" 버튼으로 추가 생성

**예상 효과:** 3배 속도 향상

---

### 2.5 스트리밍 생성

**개념:** 장면을 하나씩 생성하면서 바로 표시

**구현:**
```javascript
// 프론트엔드
const eventSource = new EventSource('/generate-stream');
eventSource.onmessage = (event) => {
    const scene = JSON.parse(event.data);
    addSceneToUI(scene);  // 즉시 화면에 표시
};
```

```python
# 백엔드 (SSE)
def generate_stream():
    for i in range(10):
        scene = generate_single_scene(i)
        yield f"data: {json.dumps(scene)}\n\n"
```

**장점:**
- 첫 장면 5-10초 내 표시
- 체감 대기 시간 대폭 감소
- 생성하면서 학습 시작 가능

**단점:**
- 구현 복잡도 높음
- 전체 스토리 일관성 유지 어려움

**예상 효과:** 체감 대기 시간 90% 감소

### 2.6 비동기 생성 + 알림

**개념:** 생성 요청 후 완료되면 알림

**흐름:**
```
1. 사용자 요청 → "생성 시작됨" 응답 (즉시)
2. 백그라운드 생성 진행
3. 완료 시 알림 (이메일/푸시/페이지 새로고침)
4. 사용자가 편할 때 학습 시작
```

**장점:**
- 사용자 대기 없음
- 서버 부하 분산 가능
- 여러 시나리오 동시 요청 가능

**단점:**
- 알림 시스템 필요
- 사용자 이탈 가능성

**예상 효과:** 대기 시간 0초 (체감)
