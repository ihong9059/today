## 4. 개인 특성 분석

### 4.1 MBTI 분석: INTJ-T (전략가형)

```
┌─────────────────────────────────────────────────────────────┐
│                    INTJ-T 전략가형                          │
├─────────────────────────────────────────────────────────────┤
│  I (내향) : 깊은 사고와 독립적 작업 선호                     │
│  N (직관) : 미래 비전과 가능성 중시                         │
│  T (사고) : 논리적 분석과 객관적 판단                        │
│  J (판단) : 체계적 계획과 목표 지향                         │
│  -T (격동): 완벽주의, 자기 개선 추구                        │
└─────────────────────────────────────────────────────────────┘
```

**INTJ-T의 사업적 강점:**

| 특성 | 사업 적용 |
|:-----|:---------|
| 전략적 사고 | 장기 비전 수립과 체계적 실행 |
| 독립성 | 소규모 기업 운영에 적합 |
| 분석력 | 기술 트렌드 파악과 시장 분석 |
| 완벽주의 | 높은 품질의 제품/서비스 제공 |
| 혁신 지향 | 새로운 기술 도입과 사업 전환 |

**INTJ-T 유의점:**
- 지나친 완벽주의로 실행 지연 가능 → **빠른 MVP 출시 후 개선** 전략 권장
- 대인관계 에너지 소모 → **파트너십/아웃소싱** 적극 활용
- 스트레스 관리 필요 → **단계적 목표 설정**으로 성취감 유지
