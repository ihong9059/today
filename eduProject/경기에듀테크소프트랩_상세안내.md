## 1. 기관 개요

### 1.1 경기에듀테크소프트랩이란?

경기에듀테크소프트랩은 **학교 현장과 에듀테크 기업을 연결**하여 공교육에 적합한 에듀테크가 개발되고 활용될 수 있도록 지원하는 전문기관입니다.

```
┌─────────────────────────────────────────────────────────────┐
│              경기에듀테크소프트랩 미션                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  "에듀테크를 통한 교육혁신을 선도하고,                        │
│   학생·교사·기업이 만나는 열린 공간에서                       │
│   학교 현장 수요에 기반한 우수 솔루션 발굴"                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 기본 정보

| 항목 | 내용 |
|:-----|:-----|
| **운영기관** | 경기대학교 |
| **공동운영** | 경기도, 경기도교육청, 한국교육학술정보원(KERIS) |
| **주관부처** | 교육부 |
| **설립연도** | 2021년 9월 |
| **담당권역** | 수도권 (경기도 중심) |

| 단계 | 내용 | 비고 |

- 설문 플랫폼과 E-mail **모두** 제출기한 내 접수 필수

**성공 요인:**
- AI 기술력
