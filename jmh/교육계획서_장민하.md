##### Claude Code Skill 사용법
Claude Code에서는 `/skill명령어`로 반복 업무를 자동화할 수 있습니다.

**작업 시작 Skill: `/work-start`**
- [ ] 매일 업무 시작 시 `/work-start` 실행
- [ ] 실행 시 자동으로 수행되는 작업:
  - git pull로 저장소 동기화
  - 이전 세션 파일 복원 (어제 작업 내용 확인)
  - 작업보고서 확인 (어제 미완료 + 오늘 할일)
  - 오늘 할일 목록 테이블로 정리

**작업 종료 Skill: `/work-end`**
- [ ] 매일 퇴근 전 `/work-end` 실행
- [ ] 실행 시 자동으로 수행되는 작업:
  - 세션 파일 저장 (오늘 작업 내용 기록)
  - 작업보고서 업데이트 (완료/미완료 사항 정리)
  - git commit & push (변경사항 저장소에 반영)

##### 일일 업무 기록 워크플로우

```
[출근] /work-start 실행
    ↓
어제 작업 내용 확인 & 오늘 할일 파악
    ↓
[업무 진행] 작업 수행
    ↓
[퇴근 전] /work-end 실행
    ↓
작업보고서 자동 업데이트 & GitHub 커밋
```

##### 작업보고서 구조
```markdown
# 작업보고서 - YYYY-MM-DD

## 오늘 할일
| 순번 | 할일 | 출처 | 상태 |
|:----:|------|------|:----:|
| 1 | 작업 내용 | 세션/이월 | ⬜/✅ |

## 오늘 완료 사항
1. **완료한 작업명**: 상세 내용

## 작업 상세 내용
### 작업1
- 진행 내용
- 결과
```

**실습**:
1. `/work-start`로 오늘 업무 시작해보기
2. 간단한 학습 내용 정리
3. `/work-end`로 업무 종료하고 작업보고서 확인하기
