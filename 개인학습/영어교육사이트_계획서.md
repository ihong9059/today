# 개인 맞춤형 영어 교육 웹앱 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트 명
**MetaCognitive English Learning Platform (MCELP)**

### 1.2 핵심 목표
- 학습자의 **메타인지 능력** 진단 및 향상
- **개인 성향** 기반 맞춤형 학습 전략 제공
- 현재 영어 학습의 **부족한 영역** 정밀 분석
- 진학 목표에 따른 **분기별 학습 방향** 제시

### 1.3 대상 사용자
- 중/고등학생 (진학 준비)
- 대학생 (유학, 편입 준비)
- 성인 학습자 (자격증, 커리어 개발)

## 2. 핵심 기능 설계

### 2.1 메타인지 진단 시스템

#### 진단 영역
| 영역 | 측정 항목 | 진단 방법 |
|------|----------|----------|
| 자기 인식 | 학습 강점/약점 인지도 | 자기평가 설문 + 실제 성과 비교 |
| 계획 능력 | 학습 목표 설정 능력 | 목표 달성률 추적 |
| 모니터링 | 학습 중 점검 습관 | 학습 로그 분석 |
| 조절 능력 | 전략 수정 유연성 | A/B 테스트 기반 분석 |
| 평가 능력 | 학습 결과 분석력 | 예측 vs 실제 점수 비교 |

#### 메타인지 점수 산출
```
메타인지 지수 = (자기인식×0.25) + (계획×0.20) + (모니터링×0.25) + (조절×0.15) + (평가×0.15)
```

### 2.2 개인 성향 분석 시스템

#### 학습 스타일 진단
- **감각적 선호도**: 시각형 / 청각형 / 읽기-쓰기형 / 운동감각형 (VARK 모델)
- **인지 스타일**: 분석형 / 전체형
- **동기 유형**: 내재적 / 외재적 동기
- **학습 환경 선호**: 개인 학습 / 협동 학습

#### 성격 기반 분석
- 완벽주의 성향 (정확성 vs 유창성 균형)
- 위험 감수 성향 (새로운 표현 시도 의지)
- 불안 수준 (언어 불안 측정)

|------|--------|------|----------|------------|

| **Listening** | 20문항 | 25분 | 이해력, 세부파악, 추론 | 속도 조절 |
| **Writing** | 2문항 | 40분 | 문법, 구성, 논리, 어휘 | 주제 난이도 |
| **Speaking** | 4문항 | 15분 | 발음, 유창성, 정확성 | AI 채점 |
| **Grammar** | 30문항 | 20분 | 문법 규칙, 적용력 | Adaptive |
| **Vocabulary** | 30문항 | 15분 | 어휘력, 활용력 | 레벨별 |

#### 분기별 평가 일정
| 분기 | 평가 명칭 | 평가 목적 | 시험 구성 |
|------|----------|----------|----------|
| **Q1** | 진단 평가 | 현재 수준 파악, 기준점 설정 | 전 영역 종합 (Full Test) |
| **Q2** | 중간 평가 | 학습 진행 확인, 방향 조정 | 취약 영역 집중 (Focused Test) |
| **Q3** | 성장 평가 | 향상도 측정, 목표 재설정 | 전 영역 + 심화 (Extended Test) |
| **Q4** | 종합 평가 | 연간 성취도 확인 | 전 영역 종합 + 모의시험 |

#### 점수 체계
```
┌─────────────────────────────────────────────────────────────┐
│                      점수 산출 체계                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 영역별 원점수 (Raw Score)                               │
│     └─> 정답률 기반 산출                                    │
│                                                             │
│  2. 표준 점수 (Scaled Score)                                │
│     └─> 0-100점 척도 변환 (난이도 보정)                      │
│                                                             │
│  3. 등급 (Grade)                                            │
│     ┌─────┬─────┬─────┬─────┬─────┬─────┐                 │
│     │ A+  │  A  │  B+ │  B  │  C  │  D  │                 │
│     │95-100│90-94│85-89│80-84│70-79│60-69│                 │
│     └─────┴─────┴─────┴─────┴─────┴─────┘                 │
│                                                             │
│  4. CEFR 레벨 매핑                                          │
│     ┌─────┬─────┬─────┬─────┬─────┬─────┐                 │
│     │ C2  │ C1  │ B2  │ B1  │ A2  │ A1  │                 │
│     │95-100│85-94│70-84│55-69│40-54│20-39│                 │
│     └─────┴─────┴─────┴─────┴─────┴─────┘                 │
│                                                             │
│  5. 향상도 지수 (Growth Index)                              │
│     └─> (현재 점수 - 이전 점수) / 목표 향상폭 × 100          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 향상도 분석 지표
| 지표 | 계산 방식 | 의미 |
|------|----------|------|
| **절대 향상** | 현재점수 - 이전점수 | 실제 점수 변화량 |
| **상대 향상** | (현재-이전) / 이전 × 100% | 성장 비율 |
| **목표 달성률** | (현재-시작) / (목표-시작) × 100% | 목표 대비 진척도 |
| **예상 도달일** | 현재 향상 속도 기반 추정 | 목표 달성 예측 |
| **영역별 밸런스** | 영역 간 점수 편차 분석 | 균형 발전 여부 |

#### 시험 문제 출제 원칙
1. **문항 은행 시스템**: 난이도별 대규모 문항 풀 구축
2. **IRT 기반 난이도 보정**: 문항반응이론 적용
3. **정기 문항 갱신**: 분기별 신규 문항 추가
4. **오류 문항 제거**: 변별도/난이도 분석 후 부적합 문항 제거
5. **유형별 균형 배치**: 지식, 이해, 적용, 분석 문항 균등 배분

#### 부정행위 방지
- 문항 랜덤 출제
- 시간제한 엄격 적용
- 브라우저 이탈 감지
- IP/기기 중복 접속 차단
- 화면 녹화 방지 (선택적)

## 3. 기술 스택 제안

```
Framework: Next.js 14 (App Router)

```

```
진단 분석: Python (scikit-learn, TensorFlow)

```

## 5. 화면 구성 (Wireframe 개요)

### 5.1 주요 페이지
1. **랜딩 페이지**: 서비스 소개, 회원가입 유도
