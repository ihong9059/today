# 무선 충전기 + 외장 HDD 일체형 제품 사업계획서

## 1. 제품 개요

### 1.1 제품명 (가칭)
**PowerDock Pro** - 무선 충전 스마트 스토리지 허브

### 1.2 제품 컨셉
스마트폰 무선 충전과 대용량 외장 스토리지를 하나로 통합한 올인원 데스크 액세서리.
PC와 USB 케이블 하나로 연결하여 다양한 기능을 구현.

### 1.3 핵심 가치
- **공간 효율성**: 2개 이상의 장치를 하나로 통합
- **케이블 정리**: USB 케이블 하나로 모든 기능 구현
- **스마트 연동**: 충전과 동시에 자동 백업

## 2. 제품 기능 상세

### 2.1 기본 기능
| 기능 | 설명 |
|------|------|
| **무선 충전** | Qi 규격 15W 급속 무선 충전 지원 |
| **외장 HDD/SSD** | 1TB ~ 4TB 선택 가능, USB 3.2 Gen2 (10Gbps) |

### 2.2 추가 기능 아이디어 (USB 케이블 연결 시 구현 가능)

#### A. USB 허브 기능
- **USB-A 포트 2~3개**: 키보드, 마우스, USB 메모리 등 연결
- **USB-C 포트 1개**: 추가 장치 연결 또는 패스스루 충전

#### B. SD/MicroSD 카드 리더
- 사진작가, 영상 제작자를 위한 빠른 미디어 전송
- UHS-II 지원으로 고속 전송

#### C. 스마트폰 자동 백업
- PC 소프트웨어 연동으로 충전 시 자동 사진/동영상 백업
- 증분 백업으로 효율적 스토리지 관리

#### D. 유선 충전 패스스루
- USB-C PD (Power Delivery) 지원
- 노트북이나 태블릿 충전 가능 (최대 60W)

#### E. 오디오 출력
- 3.5mm AUX 출력 포트
- USB DAC 내장으로 고음질 오디오 지원

#### F. 네트워크 기능 (고급형)
- 기가비트 이더넷 포트
- NAS 기능 (PC 없이 네트워크 스토리지로 활용)

#### G. 디스플레이 출력 (프리미엄형)
- HDMI 또는 DisplayPort 출력
- 미러링 또는 확장 디스플레이 지원

#### H. LED 상태 표시
- 충전 상태 표시 (충전 중/완료)
- 데이터 전송 상태 표시
- 스토리지 용량 표시 (LED 바)

#### I. 2-in-1 접이식 스탠드 (무선 충전 겸용)
- **평면 모드**: 스마트폰을 눕혀서 무선 충전 (일반 충전 패드처럼 사용)
- **스탠드 모드**: 힌지를 세워 스마트폰 거치 + 무선 충전 동시 지원
- 충전 코일이 힌지 패널에 내장되어 세운 상태에서도 충전 가능
- 각도 조절: 0° (평면) ~ 70° (스탠드)
- 가로/세로 모드 지원
- 영상 시청, 화상회의, FaceTime 통화에 최적화

```
[평면 모드]                    [스탠드 모드]
┌─────────────┐               ┌─────────┐
│  📱 충전중  │               │ 📱     /│
│ ═══════════ │     →        │   ────/ │ ← 충전 코일 내장
│   [SSD]     │               │  [SSD]  │
└─────────────┘               └─────────┘
```

| 무게 | 약 380g (SSD 미포함) |
| 스탠드 | 2-in-1 접이식 힌지 (0°~70° 조절) |

### 3.2 PC 연결 시 작동 방식
```
[PC] ─── USB-C 케이블 (1개) ─── [PowerDock Pro]
                                      │
                    ┌─────────────────┼─────────────────┐
                    │                 │                 │
              [외장 SSD]        [USB 허브]        [무선 충전]
                              [SD 카드 리더]     (별도 전원)
                              [오디오 출력]
```

**참고**: 무선 충전은 USB 전력만으로는 부족하므로 별도 DC 어댑터 필요 (또는 USB-C PD 100W 입력)

#### 소비자 행동 변화
- **DRAM 조달 문제 및 가격 상승**: 글로벌 반도체 공급망 이슈로 DRAM 가격이 지속 상승
- **PC 가격 인상**: 메모리, CPU 등 핵심 부품 가격 상승으로 신규 PC 구매 비용 증가
- **경기 불확실성**: 소비자들의 대형 IT 투자(PC 교체) 지연 경향

#### 트렌드
1. **PC 교체 주기 연장**: 기존 3~5년에서 5~7년으로 확대
2. **외장 스토리지 활용 증가**: PC 내장 용량 부족 시 외장 HDD/SSD로 용량 확장
3. **비용 효율적 업그레이드 선호**: 전체 PC 교체보다 부분 업그레이드(스토리지, 메모리) 선택

#### 본 제품의 기회 요인
- **PC 수명 연장 솔루션**: 외장 스토리지 추가로 기존 PC의 활용도 극대화
- **멀티 기능 통합 가치**: PC 교체 비용(100~200만원) 대비 본 제품(15~40만원)으로 스토리지 확장 + 무선 충전 + USB 허브 기능 동시 확보
- **데스크 셋업 최적화**: 여러 장치 구매 비용을 절감하면서 깔끔한 데스크 환경 구축
- **점진적 투자 가능**: PC 전체 교체 없이 필요한 기능만 추가하는 합리적 소비 트렌드에 부합

> **시장 전망**: PC 가격 상승 추세가 지속됨에 따라, 외장 스토리지 시장은 향후 3년간 연평균 15% 이상 성장할 것으로 예상되며, 본 제품과 같은 복합 기능 제품의 수요가 더욱 높아질 전망입니다.

## 6. 경쟁 분석

### 6.1 경쟁 제품
| 제품 | 장점 | 단점 |
|------|------|------|

- **2-in-1 접이식 디자인**: 평면 충전 ↔ 스탠드 충전 모드 전환
- 충전과 동시에 자동 백업하는 스마트 기능
- 깔끔한 데스크 환경을 위한 올인원 솔루션
