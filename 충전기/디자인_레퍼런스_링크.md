## 디자인 체크포인트

### 재질 & 마감
- [ ] 알루미늄 (프리미엄 감, 방열 우수)
- [ ] 플라스틱 (가성비, 경량)
- [ ] 가죽/패브릭 (충전 패드 상단)
- [ ] 무광 vs 유광 마감

### 포트 배치
- [ ] 전면: 자주 사용하는 포트 (USB-A, SD카드)
- [ ] 측면: 케이블 연결 포트
- [ ] 후면: PC 연결 메인 케이블

### LED 인디케이터
- [ ] 충전 상태 표시
- [ ] 데이터 전송 표시
- [ ] 저장 용량 바
- [ ] 은은한 라이팅 (눈부심 방지)

### 스탠드/거치대
- [ ] 각도 조절 가능 여부
- [ ] 가로/세로 모드 지원
- [ ] 케이스 호환성

### 케이블 관리
- [ ] 케이블 은닉 홈
- [ ] 분리형 케이블
- [ ] 케이블 길이 (1m / 1.5m)
