## Leonardo.AI 사용 방법

### 1. 접속 및 로그인
- https://leonardo.ai 접속
- Google/Apple/Email로 가입 (무료)

### 2. 이미지 생성
1. 좌측 메뉴에서 **"AI Image Generation"** 클릭
2. **Model 선택**: `Leonardo Kino XL` 또는 `PhotoReal`
3. **Prompt** 입력창에 위 프롬프트 붙여넣기
4. **Negative Prompt** 토글 켜고 입력
5. **Generate** 버튼 클릭

### 3. 설정 팁
- **Number of Images**: 4 (한 번에 4장 생성)
- **PhotoReal**: ON (더 사실적인 결과)
- **Alchemy**: ON (품질 향상, 크레딧 더 소모)

### 4. 다운로드
- 생성된 이미지 클릭 → 우측 상단 다운로드 버튼
