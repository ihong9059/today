## 1. Hailo란?

### 개요

Hailo는 **이스라엘의 AI 칩 전문 회사**로, 엣지 디바이스용 AI 가속기(NPU)를 만듭니다.

| 항목 | 설명 |
|------|------|
| **제품 유형** | NPU (Neural Processing Unit) |
| **역할** | GPU 없이 AI 모델 추론 가속 |
| **특징** | 저전력, 소형, 실시간 처리 |
| **경쟁 제품** | NVIDIA Jetson, Intel Movidius, Google Coral |

### NPU vs GPU vs CPU

```
┌─────────────────────────────────────────────────────────────────┐
│  CPU (Central Processing Unit)                                  │
│  ├─ 범용 연산 장치                                               │
│  ├─ AI 연산: 느림 (직렬 처리)                                    │
│  └─ 모든 컴퓨터에 있음                                           │
├─────────────────────────────────────────────────────────────────┤
│  GPU (Graphics Processing Unit)                                 │
│  ├─ 그래픽 + 병렬 연산 장치                                      │
│  ├─ AI 연산: 빠름 (병렬 처리)                                    │
│  └─ 전력 소모 높음 (수십~수백W)                                  │
├─────────────────────────────────────────────────────────────────┤
│  NPU (Neural Processing Unit)                                   │
│  ├─ AI 전용 연산 장치                                            │
│  ├─ AI 연산: 매우 빠름 (AI에 최적화)                             │
│  └─ 전력 소모 낮음 (수W)                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 왜 라즈베리파이에서 사용하나?

### 핵심 이유: 일반 PC는 이미 GPU가 있음

| 환경 | AI 처리 방식 | Hailo 필요성 |
|------|-------------|:------------:|
| **일반 PC (NVIDIA GPU 있음)** | CUDA로 GPU 직접 사용 | ❌ 불필요 |
| **일반 PC (CPU만)** | CPU로 처리 (느림) | △ 가능하지만 비효율 |
| **라즈베리파이** | CPU만 있음 (매우 느림) | ✅ 필수 |
| **임베디드/엣지** | 저전력 필요 | ✅ 필수 |

### 비유로 이해하기

```
일반 PC = 대형 트럭
├─ 엔진(GPU)이 강력함
├─ 무거운 짐(AI 연산)도 거뜬히 처리
└─ Hailo(추가 엔진) 필요 없음

라즈베리파이 = 자전거
├─ 엔진(GPU) 없음, 사람 힘(CPU)만 있음
├─ 무거운 짐(AI 연산) 처리 불가
└─ Hailo = 전동 모터 추가 → 가능해짐!
```

### 환경별 AI 처리 흐름

```
┌─────────────────────────────────────────────────────────────┐
│  일반 PC (GPU 있음)                                          │
│                                                             │
│  이미지 → NVIDIA GPU (CUDA) → AI 추론 → 결과                 │
│           └─ 빠름, 전력 높음                                 │
│                                                             │
│  * Hailo 필요 없음                                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  라즈베리파이 (GPU 없음)                                      │
│                                                             │
│  [Hailo 없이]                                               │
│  이미지 → CPU → AI 추론 → 결과                               │
│           └─ 매우 느림 (1~2 FPS)                             │
│                                                             │
│  [Hailo 추가]                                               │
│  이미지 → Hailo NPU → AI 추론 → 결과                         │
│           └─ 빠름 (30+ FPS), 저전력                          │
└─────────────────────────────────────────────────────────────┘
```

## 3. 주요 제품

### Hailo 제품 라인업

| 제품 | 성능 (TOPS) | 전력 | 주요 용도 |
|------|:-----------:|:----:|----------|
| **Hailo-8** | 26 TOPS | ~2.5W | 자율주행, 고성능 엣지 |
| **Hailo-8L** | 13 TOPS | ~1.5W | 라즈베리파이 AI Kit |
| **Hailo-15** | 20 TOPS | ~2W | 스마트 카메라 (ISP 내장) |

> **TOPS** = Tera Operations Per Second (초당 1조 연산)

### 라즈베리파이 AI Kit

라즈베리파이 공식 AI 확장 보드:

```
┌─────────────────────────────────────────┐
│  Raspberry Pi AI Kit                    │
│  ├─ Hailo-8L 칩 (13 TOPS)               │
│  ├─ M.2 HAT+ 보드                       │
│  └─ 가격: 약 $70                        │
└─────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Raspberry Pi 5                         │
│  ├─ M.2 슬롯으로 연결                    │
│  └─ 실시간 AI 가능!                     │
└─────────────────────────────────────────┘
```

## 4. 성능 비교

### YOLO 객체 검출 기준

| 장치 | 처리 속도 | 전력 소모 | 비용 |
|------|:---------:|:---------:|:----:|
| PC + RTX 4090 | 200+ FPS | ~450W | ~$1,600 |
| PC + RTX 3080 | 100+ FPS | ~320W | ~$700 |
| PC + CPU만 (i7) | 5~10 FPS | ~65W | - |
| Jetson Orin Nano | 30+ FPS | ~15W | ~$200 |
| **라즈베리파이 5 + Hailo-8L** | **30+ FPS** | **~8W** | **~$140** |
| 라즈베리파이 5 (CPU만) | 1~2 FPS | ~5W | ~$80 |

### 전력 효율 비교

```
성능/와트 (FPS per Watt)

RTX 4090:       200 FPS / 450W = 0.44 FPS/W
RTX 3080:       100 FPS / 320W = 0.31 FPS/W
RPi5 + Hailo:    30 FPS /   8W = 3.75 FPS/W  ← 가장 효율적!
```

## 5. 사용 시나리오

### Hailo가 적합한 경우

| 시나리오 | 이유 |
|----------|------|
| **라즈베리파이 AI 프로젝트** | GPU 없음, 저전력 필요 |
| **스마트 CCTV** | 24시간 실시간 처리, 저전력 |
| **자율주행 / ADAS** | 차량 내 제한된 공간과 전력 |
| **드론** | 경량 + 저전력 필수 |
| **산업용 IoT** | 공장 내 실시간 품질 검사 |
| **스마트 홈** | 얼굴 인식, 동작 감지 |

### Hailo가 불필요한 경우

| 시나리오 | 이유 |
|----------|------|
| **일반 PC (GPU 있음)** | CUDA가 더 빠르고 편리 |
| **클라우드/서버** | GPU 서버 사용 |
| **학습/훈련** | Hailo는 추론 전용, 학습 불가 |
| **개발/프로토타입** | PC에서 개발 후 Hailo로 배포 |

## 6. 번호판 인식 프로젝트 적용

### 현재 프로젝트 상황

| 환경 | 현재 상태 |
|------|----------|
| **Colab** | Tesla T4 GPU로 학습/추론 |
| **로컬 PC** | CPU로 추론 (느림, 5~10 FPS) |
| **라즈베리파이** | 적용 안 됨 |

### Hailo로 배포하려면

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 모델 변환                                          │
│  ├─ YOLO (.pt) → ONNX (.onnx)                               │
│  └─ ONNX → Hailo HEF (.hef)                                 │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 하드웨어 준비                                       │
│  ├─ Raspberry Pi 5                                          │
│  └─ Hailo-8L AI Kit                                         │
├─────────────────────────────────────────────────────────────┤
│  Step 3: 배포 및 실행                                        │
│  └─ HailoRT 런타임으로 실시간 추론                           │
└─────────────────────────────────────────────────────────────┘
```

### 변환 명령어 예시

```bash
# 1. YOLO → ONNX 변환
yolo export model=plate_detector.pt format=onnx imgsz=640

# 2. ONNX → Hailo HEF 변환 (Hailo Dataflow Compiler 필요)
hailo parser onnx plate_detector.onnx
hailo optimize plate_detector.har
hailo compiler plate_detector.har --hw-arch hailo8l

# 3. 라즈베리파이에서 실행
python run_detection.py --model plate_detector.hef --source camera
```

### 예상 결과

| 항목 | PC (CPU) | RPi5 + Hailo-8L |
|------|:--------:|:---------------:|
| 처리 속도 | 5~10 FPS | 30+ FPS |
| 전력 소모 | ~65W | ~8W |
| 실시간 가능 | △ | ✅ |
| 휴대성 | ❌ | ✅ |
