## 3. Step 2: 문자 분할

### 목표
검출된 번호판 영역에서 개별 문자를 분리합니다.

### 입출력

| 구분 | 내용 |
|------|------|
| 입력 | 번호판 이미지 (크롭된 영역) |
| 출력 | 개별 문자 이미지 리스트 |

### 예시

```
입력 (번호판 크롭):
┌────────────────────┐
│  12 가 3456        │
└────────────────────┘

출력 (개별 문자):
[1] [2] [가] [3] [4] [5] [6]
```

### 처리 과정 (OpenCV)

```
1. 그레이스케일 변환
   RGB → Gray

2. 이진화 (Thresholding)
   Gray → Black/White

3. 컨투어 검출 (findContours)
   문자 영역 찾기

4. 컨투어 필터링
   노이즈 제거, 크기 기준 필터

5. 정렬
   왼쪽 → 오른쪽 순서로 정렬

6. 개별 문자 크롭
   각 컨투어 영역 추출
```

### 참고 코드

```python
import cv2

def segment_characters(plate_image):
    # 그레이스케일
    gray = cv2.cvtColor(plate_image, cv2.COLOR_BGR2GRAY)

    # 이진화
    _, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

    # 컨투어 검출
    contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    # 문자 영역 추출
    char_images = []
    for contour in sorted(contours, key=lambda c: cv2.boundingRect(c)[0]):
        x, y, w, h = cv2.boundingRect(contour)

        # 크기 필터링 (너무 작거나 큰 것 제외)
        if 10 < w < 100 and 20 < h < 100:
            char_img = binary[y:y+h, x:x+w]
            char_images.append(char_img)

    return char_images
```

## 6. 방법 B: OCR 라이브러리 사용

### 장점
- 빠른 구현 (30분)
- 한글 포함 다국어 지원
- 검증된 성능

### 단점
- 내부 동작 이해 어려움
- 라이브러리 의존성
- 커스터마이징 제한

### 추천 라이브러리

| 라이브러리 | 특징 | 한글 지원 |
|------------|------|:---------:|
| **EasyOCR** | 간단한 API, PyTorch 기반 | ✅ |
| PaddleOCR | 빠른 속도, 높은 정확도 | ✅ |
| Tesseract | 오픈소스 표준, 설치 복잡 | ✅ |

### 전체 파이프라인 (YOLO + EasyOCR)

```python
from ultralytics import YOLO
import easyocr
import cv2

# 모델 로드
detector = YOLO('models/plate_detector.pt')
reader = easyocr.Reader(['ko', 'en'])

def recognize_plate(image_path):
    # 이미지 로드
    image = cv2.imread(image_path)

    # Step 1: 번호판 검출
    results = detector(image)

    plates = []
    for box in results[0].boxes:
        x1, y1, x2, y2 = map(int, box.xyxy[0].tolist())

        # 번호판 영역 크롭
        plate_img = image[y1:y2, x1:x2]

        # Step 2+3: OCR로 문자 인식
        ocr_results = reader.readtext(plate_img)

        # 텍스트 합치기
        plate_text = ' '.join([text for _, text, _ in ocr_results])
        plates.append(plate_text)

    return plates

# 실행
result = recognize_plate('car.jpg')
print(f"번호판: {result}")
```
