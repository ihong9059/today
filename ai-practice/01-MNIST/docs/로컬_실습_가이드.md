## 7. Colab에서 학습한 모델을 로컬에서 사용

### 7.1 모델 다운로드

**방법 1: Google Drive 데스크톱 앱**
- [Google Drive 다운로드](https://www.google.com/drive/download/)
- 설치 후 자동 동기화

**방법 2: 웹에서 수동 다운로드**
1. [drive.google.com](https://drive.google.com) 접속
2. `ai-practice/01-MNIST/models/` 폴더 이동
3. `baseline_cnn.pt` 파일 다운로드
4. 로컬 `models/` 폴더에 저장

### 7.2 로컬에서 모델 로드

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 모델 구조 정의 (Colab과 동일해야 함)
class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(64 * 7 * 7, 128)
        self.fc2 = nn.Linear(128, 10)
        self.dropout = nn.Dropout(0.25)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 64 * 7 * 7)
        x = self.dropout(F.relu(self.fc1(x)))
        x = self.fc2(x)
        return x

# 모델 생성 및 가중치 로드
model = CNN()
model.load_state_dict(torch.load('models/baseline_cnn.pt', map_location='cpu'))
model.eval()

print("모델 로드 완료!")
```

## 9. 문제 해결

### 가상환경 활성화 오류 (PowerShell)

```bash
# 실행 정책 변경
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 다시 활성화
venv\Scripts\activate
```

### torch 설치 오류

```bash
# pip 업그레이드
python -m pip install --upgrade pip

# 다시 설치
pip install torch torchvision
```

### 모델 로드 오류

```python
# GPU로 저장된 모델을 CPU에서 로드
model.load_state_dict(torch.load('model.pt', map_location='cpu'))

# 또는 device 자동 감지
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.load_state_dict(torch.load('model.pt', map_location=device))
```

### 폰트 경로 오류

```python
# Windows 폰트 경로 확인
import os
FONT_DIR = 'C:/Windows/Fonts'
print(os.listdir(FONT_DIR)[:10])  # 처음 10개 폰트 출력
```
