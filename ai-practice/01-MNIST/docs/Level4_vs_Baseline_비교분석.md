# Level 4 vs Baseline 실습 비교 분석

**왜 Level 4에서는 오판이 많았고, 현재 실습에서는 거의 100% 성공하는가?**

---

## 핵심 차이점 요약

| 항목 | Level 4 (ai-education-web) | Baseline 실습 (현재) |
|------|---------------------------|---------------------|
| **모델 구조** | MLP (다층 퍼셉트론) | CNN (합성곱 신경망) |
| **정확도** | ~98% | ~99.5% |
| **파라미터 수** | 535,818개 | ~421,642개 |
| **공간 정보** | 손실됨 (Flatten) | 보존됨 (Conv) |
| **위치 불변성** | 없음 | 있음 (MaxPool) |

---

## 1. 모델 구조의 차이

### Level 4: MLP (다층 퍼셉트론)

```
입력 (28x28)
    ↓ Flatten (공간 정보 손실!)
[784] → [512] → [256] → [10]
         ReLU     ReLU    출력
       Dropout  Dropout
        (0.2)    (0.2)
```

```python
class MNISTClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 512)   # 784 = 28x28
        self.fc2 = nn.Linear(512, 256)
        self.fc3 = nn.Linear(256, 10)
        self.dropout = nn.Dropout(0.2)

    def forward(self, x):
        x = x.view(-1, 784)  # ← 여기서 공간 정보 손실!
        x = torch.relu(self.fc1(x))
        x = self.dropout(x)
        x = torch.relu(self.fc2(x))
        x = self.dropout(x)
        x = self.fc3(x)
        return x
```

**문제점:**
- `x.view(-1, 784)`에서 2D 이미지를 1D 벡터로 펼침
- 픽셀 간의 공간적 관계(위치, 인접성) 완전히 손실
- 숫자의 "형태"를 인식하기 어려움

---

### Baseline: CNN (합성곱 신경망)

```
입력 (1, 28, 28)
    ↓ Conv1 (32 필터)
(32, 28, 28)
    ↓ MaxPool
(32, 14, 14)
    ↓ Conv2 (64 필터)
(64, 14, 14)
    ↓ MaxPool
(64, 7, 7)
    ↓ Flatten
[3136] → [128] → [10]
          ReLU    출력
        Dropout
         (0.25)
```

```python
class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(64 * 7 * 7, 128)
        self.fc2 = nn.Linear(128, 10)
        self.dropout = nn.Dropout(0.25)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))  # 공간 정보 보존!
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 64 * 7 * 7)
        x = self.dropout(F.relu(self.fc1(x)))
        x = self.fc2(x)
        return x
```

**장점:**
- 합성곱 레이어가 공간적 특징(엣지, 곡선, 모서리) 추출
- MaxPool로 위치 변화에 강건함 획득
- 더 적은 파라미터로 더 좋은 성능

## 2. 공간 정보 보존의 중요성

### MLP의 문제: 위치 민감성

```
MLP가 학습한 것:
"784번째 픽셀이 밝으면 숫자 3일 확률 높음"

문제:
숫자가 조금만 이동하면 완전히 다른 예측
```

```
┌─────────────┐    ┌─────────────┐
│      3      │    │    3        │
│   (중앙)    │    │  (왼쪽)     │
└─────────────┘    └─────────────┘
    MLP: 3 ✅         MLP: 8 ❌ (위치 달라서 오인식)
    CNN: 3 ✅         CNN: 3 ✅ (형태 인식)
```

### CNN의 장점: 위치 불변성

```
CNN이 학습한 것:
"둥근 곡선 위에 작은 곡선이 있으면 숫자 3"

장점:
숫자가 어디에 있든 형태로 인식
```

---

## 3. 폰트 인식에서의 차이

### 왜 폰트 테스트에서 차이가 크게 나는가?

| 요소 | MLP | CNN |
|------|-----|-----|
| **폰트 스타일** | 민감 | 강건 |
| **위치 변화** | 민감 | 강건 |
| **크기 변화** | 민감 | 강건 |
| **굵기 변화** | 민감 | 상대적 강건 |

### 실제 예시

```
Arial 폰트 "5"
┌─────────────┐
│  ███████    │
│  █          │
│  ██████     │
│       █     │
│  ██████     │
└─────────────┘

MLP: "5"를 784개 픽셀 위치로 기억
     → MNIST 손글씨 "5"와 위치가 다르면 오인식

CNN: "5"의 특징(위에 가로선, 아래에 곡선) 인식
     → 위치와 상관없이 형태로 판단
```

## 4. 수치 비교

### 테스트 정확도

| 모델 | MNIST 테스트 | 폰트 테스트 (추정) |
|------|:-----------:|:-----------------:|
| MLP (Level 4) | ~98% | 60~80% |
| CNN (Baseline) | ~99.5% | 90~100% |

### 오차 분석

```
MNIST 테스트 1만장 기준:

MLP 98%  → 200장 오답
CNN 99.5% → 50장 오답

차이: 150장 (4배 차이!)
```

## 5. 파라미터 수 비교

### MLP

```
fc1: 784 × 512 = 401,408 + 512 (bias) = 401,920
fc2: 512 × 256 = 131,072 + 256 (bias) = 131,328
fc3: 256 × 10  = 2,560 + 10 (bias) = 2,570

총: 535,818개
```

### CNN

```
conv1: 1 × 32 × 3 × 3 = 288 + 32 (bias) = 320
conv2: 32 × 64 × 3 × 3 = 18,432 + 64 (bias) = 18,496
fc1: 3136 × 128 = 401,408 + 128 (bias) = 401,536
fc2: 128 × 10 = 1,280 + 10 (bias) = 1,290

총: 421,642개
```

**결과:**
- CNN이 파라미터 수가 더 적음 (약 21% 감소)
- 그럼에도 성능은 더 좋음
- 합성곱의 가중치 공유 덕분

---

## 6. 합성곱의 원리

### 왜 CNN이 더 효과적인가?

```
3x3 필터가 이미지 전체를 스캔
┌───┬───┬───┐
│ 1 │ 0 │-1 │  ← 세로 엣지 검출 필터
│ 2 │ 0 │-2 │
│ 1 │ 0 │-1 │
└───┴───┴───┘

이 하나의 필터로 이미지 어디에 있는 세로선이든 검출 가능!
```

### 가중치 공유

```
MLP: 각 픽셀마다 별도의 가중치 필요
     → 784 × 512 = 401,408개

CNN: 하나의 3×3 필터가 전체 이미지에 적용
     → 9개 가중치로 모든 위치 처리
```

---

## 7. 결론

### 오판이 많았던 이유 (Level 4 MLP)

1. **공간 정보 손실**: 2D 이미지를 1D로 펼치면서 구조 파괴
2. **위치 민감성**: 픽셀 위치가 조금만 달라도 다른 예측
3. **일반화 부족**: MNIST 손글씨에만 최적화, 폰트에 약함

### 성공률이 높은 이유 (Baseline CNN)

1. **공간 정보 보존**: 합성곱이 이미지 구조 유지
2. **위치 불변성**: MaxPool로 위치 변화에 강건
3. **효율적 학습**: 가중치 공유로 적은 파라미터, 높은 성능
4. **특징 추출**: 엣지, 곡선 등 의미있는 특징 학습

## 9. 학습 포인트

### MLP가 적합한 경우

- 정형 데이터 (테이블 데이터)
- 순서가 중요하지 않은 데이터
- 간단한 분류 문제

### CNN이 적합한 경우

- 이미지 데이터
- 공간적 구조가 중요한 데이터
- 위치 불변성이 필요한 경우
