## 3. 각 시나리오 구성 (3단계) - 총 20~30분

| 단계 | 내용 | 소요 시간 |
|------|------|----------|
| 1단계 | 📚 단어 학습 | 7~10분 |
| 2단계 | 💬 회화 진행 | 8~12분 |
| 3단계 | 🎮 퀴즈/게임 | 5~8분 |

### 3-1. 📚 단어 학습 페이지 (7~10분)
- 해당 상황에 필요한 핵심 단어 25~35개
- 일본어 + 히라가나/카타카나 + 한국어 뜻
- 🔊 발음 듣기 (TTS)
- 플래시카드 형식 (카드당 약 15~20초)
- 단어 암기 체크 기능
- **미니 퀴즈**: 5문제 빠른 복습 (2분)

### 3-2. 💬 회화 진행 페이지 (8~12분)
- 실제 상황을 시뮬레이션
- **4~6개 씬(Scene)**으로 구성
- 각 씬당 3~5개 대화 턴
- NPC(상대방) 대사 + 학습자 선택지
- 각 대화에 해설/팁 제공
- 롤플레이 형식 (예: 캐디와 대화, 웨이터와 대화)
- **중간 체크포인트**: 핵심 표현 복습

### 3-3. 🎮 퀴즈/게임 페이지 (5~8분)
- **4지선다 퀴즈**: 단어 뜻 맞추기 (10문제, 3분)
- **빈칸 채우기**: 대화문 완성 (5문제, 2분)
- **순서 맞추기**: 문장 순서 배열 (3문제, 2분)
- **매칭 게임**: 일본어-한국어 연결 (1라운드, 1분)
- 점수/별점 시스템 (★★★ 만점)

## 4. 기술 스택

```
Frontend: HTML5, CSS3, JavaScript (Vanilla 또는 React)
```

## 6. 1차 구현 범위 (골프장 & 식사)

### 상황 설정
1. **골프장 도착** - 접수, 캐디 인사
2. **라운딩 중** - 캐디와 대화, 샷 관련 표현
3. **클럽하우스 식사** - 메뉴 주문, 음료 주문
4. **정산/귀가** - 계산, 인사

### 포함 단어 (예시)
- ゴルフ場 (ごるふじょう) - 골프장
- キャディー - 캐디
- ティーショット - 티샷
- バンカー - 벙커
- グリーン - 그린
- クラブハウス - 클럽하우스
- ランチ - 점심
- ビール - 맥주
- お会計 (おかいけい) - 계산
