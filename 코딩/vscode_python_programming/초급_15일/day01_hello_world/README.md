## 실행 방법

### 1. AI 응답 저장하기

AI가 출력한 코드를 `===== 파일:` 구분자로 나누어 각 파일로 저장합니다.

### 2. VSCode에서 실행

```bash
# 터미널에서 실행
cd "C:/todo/today/코딩/vscode_python_programming/초급_15일/day01_hello_world"
python main.py
```

### 3. 코드 이해하기

각 파일의 역할:
- `main.py`: 프로그램 진입점, 사용자 입력 처리
- `greeting.py`: 다국어 인사 함수들
- `utils.py`: 박스 그리기 등 유틸리티 함수
