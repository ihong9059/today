## 1. AI 인식 파이프라인 개요

### 1.1 전체 흐름도

```
┌──────────────────────────────────────────────────────────────────────┐
│                        AI 인식 파이프라인                             │
└──────────────────────────────────────────────────────────────────────┘

  [카메라 입력]
       │
       ▼
┌─────────────────┐
│  1. 이미지 획득  │  ← 카메라에서 프레임 읽기
│     (Capture)   │     RGB/BGR 이미지 배열
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  2. 전처리      │  ← 노이즈 제거, 대비 향상
│  (Preprocess)   │     그레이스케일 변환
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  3. 객체 검출   │  ← 번호판 영역 찾기 (AI 핵심 1)
│   (Detection)   │     컨투어/딥러닝 기반
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  4. ROI 추출    │  ← 검출된 영역 잘라내기
│  (ROI Extract)  │     크기 정규화
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  5. OCR 전처리  │  ← 이진화, 기울기 보정
│ (OCR Preprocess)│     문자 인식에 최적화
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  6. 문자 인식   │  ← 텍스트 추출 (AI 핵심 2)
│     (OCR)       │     Tesseract/딥러닝 OCR
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  7. 후처리      │  ← 결과 검증, 형식 확인
│ (Postprocess)   │     정규식 필터링
└────────┬────────┘
         │
         ▼
  [결과 출력]
```

### 1.2 AI가 관여하는 핵심 단계

| 단계 | AI 기술 | 역할 | 사용 알고리즘 |
|------|---------|------|---------------|
| **3. 객체 검출** | 컴퓨터 비전 / 딥러닝 | 이미지에서 번호판 위치 찾기 | Haar Cascade, 컨투어, YOLO, SSD |
| **6. 문자 인식** | OCR (광학 문자 인식) | 이미지에서 텍스트 추출 | Tesseract (LSTM), EasyOCR |

## 2. 각 단계별 상세 설명

### 2.1 이미지 획득 (Image Capture)

**무엇을 하는가:**
- 카메라로부터 이미지 데이터를 읽어옴
- 픽셀 배열 형태로 메모리에 저장

**기술적 의미:**
```python
# 카메라가 반환하는 것
frame = camera.read()  # numpy 배열: (높이, 너비, 채널)

# 예: 640x480 컬러 이미지
# frame.shape = (480, 640, 3)
# - 480: 세로 픽셀 수
# - 640: 가로 픽셀 수
# - 3: BGR 채널 (파랑, 초록, 빨강)
```

### 2.2 전처리 (Preprocessing)

**무엇을 하는가:**
- 이미지 품질 개선
- AI 모델이 처리하기 좋은 형태로 변환

**주요 작업:**

```python
# 1. 그레이스케일 변환 (3채널 → 1채널)
#    컬러 정보가 필요 없는 경우, 처리 속도 3배 향상
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
# (480, 640, 3) → (480, 640)

# 2. 가우시안 블러 (노이즈 제거)
#    작은 점/얼룩 제거, 엣지 검출 정확도 향상
blur = cv2.GaussianBlur(gray, (5, 5), 0)

# 3. 히스토그램 평활화 (대비 향상)
#    어두운/밝은 영역의 차이를 명확하게
equalized = cv2.equalizeHist(blur)

# 4. 엣지 검출 (경계선 추출)
#    물체의 윤곽선만 추출
edges = cv2.Canny(equalized, 100, 200)
```

**테스트 시 확인 사항:**
- 전처리 후 번호판이 더 명확하게 보이는가?
- 노이즈가 적절히 제거되었는가?
- 문자와 배경의 구분이 명확한가?

### 2.3 객체 검출 (Object Detection) - AI 핵심 1

**무엇을 하는가:**
- 이미지 전체에서 "번호판이 어디에 있는지" 찾음
- 좌표 (x, y, 너비, 높이)를 반환

**AI가 하는 일:**
```
[원본 이미지]                    [검출 결과]
┌────────────────────┐          ┌────────────────────┐
│                    │          │                    │
│    🚗              │    →     │    🚗              │
│   ┌──────┐         │   AI     │   ┌──────┐         │
│   │12가34│         │  검출    │   │▓▓▓▓▓▓│← 검출됨  │
│   └──────┘         │          │   └──────┘         │
│                    │          │   bbox: (x,y,w,h)  │
└────────────────────┘          └────────────────────┘
```

**검출 방법 비교:**

| 방법 | 원리 | 장점 | 단점 |
|------|------|------|------|
| **컨투어 기반** | 윤곽선의 모양(사각형)으로 판단 | 빠름, 간단 | 정확도 낮음 |
| **Haar Cascade** | 학습된 특징 패턴 매칭 | 빠름 | 각도/크기 제한 |
| **딥러닝 (YOLO)** | CNN으로 객체 학습 | 정확도 높음 | 느림, 메모리 많이 사용 |

**컨투어 기반 검출 원리:**
```python
# 1. 엣지 이미지에서 윤곽선(컨투어) 찾기
contours, _ = cv2.findContours(edges, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

# 2. 각 컨투어를 분석
for contour in contours:
    # 면적 계산 (너무 작거나 큰 것 제외)
    area = cv2.contourArea(contour)
    if area < 500 or area > 50000:
        continue

    # 바운딩 박스 (사각형으로 감싸기)
    x, y, w, h = cv2.boundingRect(contour)

    # 종횡비 확인 (번호판은 가로로 긴 형태)
    aspect_ratio = w / h
    if 2.0 < aspect_ratio < 6.0:  # 번호판 비율
        # 후보로 추가
        candidates.append((x, y, w, h))
```

**테스트 시 확인 사항:**
- 번호판이 정확히 검출되는가? (위치, 크기)
- 오검출(False Positive)이 많은가?
- 미검출(False Negative)이 발생하는가?

### 2.4 ROI 추출 (Region of Interest)

**무엇을 하는가:**
- 검출된 영역만 잘라내어 별도 이미지로 만듦
- OCR에 필요한 크기로 조정

```python
# 바운딩 박스 좌표로 이미지 자르기
x, y, w, h = bbox
roi = image[y:y+h, x:x+w]

# 크기 정규화 (OCR 입력 크기에 맞춤)
roi_resized = cv2.resize(roi, (200, 60))
```

### 2.5 OCR 전처리 (OCR Preprocessing)

**무엇을 하는가:**
- 문자 인식에 최적화된 이미지로 변환
- 이진화(흑백)로 문자와 배경 명확히 구분

**주요 작업:**
```python
# 1. 이진화 (Otsu 알고리즘)
#    자동으로 최적의 임계값을 찾아 흑백으로 변환
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 결과:
# - 문자: 검은색 (0)
# - 배경: 흰색 (255)

# 2. 모폴로지 연산 (노이즈 제거)
kernel = np.ones((2, 2), np.uint8)
cleaned = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

# 3. 기울기 보정 (Deskew)
#    기울어진 텍스트를 수평으로 맞춤
```

**이진화 전후 비교:**
```
[원본 ROI]                    [이진화 후]
┌────────────────────┐        ┌────────────────────┐
│ ████ ██ █████      │        │                    │
│ █  █  █ █   █      │   →    │ 12 가 1234         │
│ ████  █ █████      │        │                    │
│ (회색 배경, 노이즈) │        │ (깨끗한 흑백)       │
└────────────────────┘        └────────────────────┘
```

### 2.6 문자 인식 (OCR) - AI 핵심 2

**무엇을 하는가:**
- 이미지에 있는 문자를 텍스트로 변환
- "그림 → 글자" 변환

**Tesseract OCR 원리:**
```
[이진화 이미지]
    │
    ▼
┌─────────────────┐
│ 1. 레이아웃 분석 │  ← 텍스트 영역, 줄, 단어 구분
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. 문자 분할    │  ← 개별 문자 단위로 분리
│   (Segmentation)│     "12가1234" → "1","2","가",...
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 문자 인식    │  ← LSTM 신경망으로 문자 판별
│   (Recognition) │     각 문자의 확률 계산
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 4. 언어 모델    │  ← 문맥상 가능한 조합 선택
│  (Language Model)│    "12가1234" vs "I2가I234"
└────────┬────────┘
         │
         ▼
  [텍스트 출력: "12가1234"]
```

**LSTM 신경망의 역할:**
- Long Short-Term Memory (장단기 기억 네트워크)
- 시퀀스 데이터 처리에 특화
- 이전 문자의 맥락을 고려하여 다음 문자 예측

```python
# Tesseract OCR 호출
import pytesseract

result = pytesseract.image_to_string(
    binary_image,
    lang='kor+eng',      # 한국어 + 영어
    config='--psm 7'     # 단일 텍스트 라인으로 처리
)

# PSM (Page Segmentation Mode) 옵션:
# --psm 6: 균일한 텍스트 블록
# --psm 7: 단일 텍스트 라인 (번호판에 적합)
# --psm 8: 단일 단어
# --psm 13: Raw line (문자 그대로)
```

**테스트 시 확인 사항:**
- 인식 결과가 실제 번호판과 일치하는가?
- 신뢰도(Confidence)가 적절한가? (일반적으로 70% 이상)
- 어떤 문자가 잘못 인식되는가? (0↔O, 1↔I 등)

### 2.7 후처리 (Postprocessing)

**무엇을 하는가:**
- OCR 결과 정리 및 검증
- 번호판 형식에 맞는지 확인

```python
import re

# 1. 불필요한 문자 제거
text = re.sub(r'[^0-9가-힣]', '', ocr_result)

# 2. 번호판 형식 검증 (정규식)
patterns = [
    r'^\d{2,3}[가-힣]\d{4}$',      # 12가1234, 123가1234
    r'^[가-힣]{2}\d{2}[가-힣]\d{4}$'  # 서울12가1234
]

for pattern in patterns:
    if re.match(pattern, text):
        return True, text  # 유효한 번호판

return False, text  # 형식 불일치
```

#### 체크 3: 객체 검출 테스트
```python
def test_detection(frame, edges):
    """검출 결과 확인"""
    contours, _ = cv2.findContours(edges, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

    candidates = []
    debug_frame = frame.copy()

    for contour in contours:
        area = cv2.contourArea(contour)
        if area < 500:
            continue

        x, y, w, h = cv2.boundingRect(contour)
        aspect_ratio = w / h

        # 모든 후보 시각화 (파란색)
        cv2.rectangle(debug_frame, (x, y), (x+w, y+h), (255, 0, 0), 1)

        if 2.0 < aspect_ratio < 6.0:
            # 번호판 후보 (녹색)
            cv2.rectangle(debug_frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
            candidates.append((x, y, w, h))

            print(f"후보: bbox=({x},{y},{w},{h}), 면적={area}, 비율={aspect_ratio:.2f}")

    cv2.imwrite('debug_05_detection.jpg', debug_frame)

    # 확인: 녹색 박스가 번호판을 정확히 감싸는가?

    return candidates
```

#### 체크 4-5: ROI 및 OCR 전처리 테스트
```python
def test_roi_and_ocr_preprocess(frame, bbox):
    """ROI 추출 및 OCR 전처리 확인"""
    x, y, w, h = bbox

    # ROI 추출
    roi = frame[y:y+h, x:x+w]
    cv2.imwrite('debug_06_roi.jpg', roi)

    # 그레이스케일
    roi_gray = cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY)

    # 이진화
    _, binary = cv2.threshold(roi_gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    cv2.imwrite('debug_07_binary.jpg', binary)

    # 확인:
    # - ROI가 번호판 전체를 포함하는가?
    # - 이진화 후 문자가 명확하게 보이는가?
    # - 문자가 검은색, 배경이 흰색인가?

    return binary
```

## 4. 인식 방식의 의미

### 4.1 "인식"이란 무엇인가?

```
┌──────────────────────────────────────────────────────────────────┐
│                         "인식"의 의미                            │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [입력]              [AI 처리]              [출력]               │
│                                                                  │
│  픽셀 데이터    →    패턴 매칭    →    의미있는 정보             │
│  (숫자 배열)         (학습된 모델)        (텍스트)               │
│                                                                  │
│  ┌─────────┐        ┌─────────┐        ┌─────────┐              │
│  │ 255 0 0 │        │         │        │         │              │
│  │ 0 255 0 │   →    │ 신경망  │   →    │ "12가"  │              │
│  │ 0 0 255 │        │         │        │ "1234"  │              │
│  └─────────┘        └─────────┘        └─────────┘              │
│                                                                  │
│  인간에게는         AI가 학습한          인간이 이해할           │
│  의미없는 숫자      패턴과 비교          수 있는 텍스트          │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 4.2 Tesseract가 "1"과 "I"를 구분하는 방법

```
[학습 데이터]
┌─────────────────────────────────────────────────────┐
│  "1" 이미지 수만 장  →  특징 추출  →  "1" 패턴     │
│  "I" 이미지 수만 장  →  특징 추출  →  "I" 패턴     │
└─────────────────────────────────────────────────────┘

[인식 시]
┌─────────────────────────────────────────────────────┐
│  입력 이미지  →  특징 추출  →  패턴 비교  →  확률  │
│                                                      │
│                              "1" 패턴: 95% 유사     │
│                              "I" 패턴: 85% 유사     │
│                              "l" 패턴: 80% 유사     │
│                                                      │
│                              결과: "1" (가장 높음)  │
└─────────────────────────────────────────────────────┘
```

### 4.3 왜 전처리가 중요한가?

```
[전처리 없이]                    [전처리 후]
┌────────────────┐              ┌────────────────┐
│ 노이즈 있음    │              │ 깨끗한 이미지  │
│ 그림자 있음    │      →       │ 균일한 조명    │
│ 기울어짐       │  전처리      │ 수평 정렬      │
└────────────────┘              └────────────────┘
        │                               │
        ▼                               ▼
   인식률 30%                      인식률 95%

이유:
- AI 모델은 "깨끗한" 학습 데이터로 훈련됨
- 입력이 학습 데이터와 비슷할수록 정확도 높음
```

## 5. 테스트 코드 및 실행

### 5.1 통합 테스트 스크립트

```python
#!/usr/bin/env python3
# 파일명: test_ai_pipeline.py
"""AI 인식 파이프라인 단계별 테스트"""

import cv2
import numpy as np
import pytesseract
import os
import sys

class PipelineTester:
    def __init__(self, output_dir='debug_output'):
        self.output_dir = output_dir
        os.makedirs(output_dir, exist_ok=True)
        self.step = 0

    def save_debug(self, name, image):
        """디버그 이미지 저장"""
        self.step += 1
        filename = f"{self.step:02d}_{name}.jpg"
        path = os.path.join(self.output_dir, filename)
        cv2.imwrite(path, image)
        print(f"  저장: {filename}")

    def test_full_pipeline(self, image_path):
        """전체 파이프라인 테스트"""
        print("=" * 60)
        print("AI 인식 파이프라인 테스트")
        print("=" * 60)

        # 1. 이미지 로드
        print("\n[1단계] 이미지 로드")
        frame = cv2.imread(image_path)
        if frame is None:
            print(f"  오류: 이미지를 열 수 없습니다 - {image_path}")
            return
        print(f"  크기: {frame.shape}")
        self.save_debug('input', frame)

        # 2. 전처리
        print("\n[2단계] 전처리")
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        self.save_debug('gray', gray)

        blur = cv2.GaussianBlur(gray, (5, 5), 0)
        self.save_debug('blur', blur)

        edges = cv2.Canny(blur, 100, 200)
        self.save_debug('edges', edges)
        print("  그레이스케일 → 블러 → 엣지 검출 완료")

        # 3. 객체 검출
        print("\n[3단계] 객체 검출 (AI 핵심)")
        contours, _ = cv2.findContours(edges, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
        print(f"  발견된 컨투어: {len(contours)}개")

        candidates = []
        debug_detect = frame.copy()

        for contour in contours:
            area = cv2.contourArea(contour)
            if area < 500 or area > 50000:
                continue

            x, y, w, h = cv2.boundingRect(contour)
            aspect_ratio = w / h

            if 2.0 < aspect_ratio < 6.0:
                cv2.rectangle(debug_detect, (x, y), (x+w, y+h), (0, 255, 0), 2)
                cv2.putText(debug_detect, f"AR:{aspect_ratio:.1f}",
                           (x, y-5), cv2.FONT_HERSHEY_SIMPLEX, 0.4, (0, 255, 0), 1)
                candidates.append((x, y, w, h, area))

        self.save_debug('detection', debug_detect)
        print(f"  번호판 후보: {len(candidates)}개")

        if not candidates:
            print("  경고: 번호판 후보가 없습니다!")
            return

        # 면적 기준 정렬 (가장 큰 것 선택)
        candidates.sort(key=lambda c: c[4], reverse=True)
        best = candidates[0]
        x, y, w, h, area = best
        print(f"  선택된 후보: ({x}, {y}, {w}, {h}), 면적={area}")

        # 4. ROI 추출
        print("\n[4단계] ROI 추출")
        roi = frame[y:y+h, x:x+w]
        self.save_debug('roi', roi)
        print(f"  ROI 크기: {roi.shape}")

        # 5. OCR 전처리
        print("\n[5단계] OCR 전처리")
        roi_gray = cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY)

        # 이진화
        _, binary = cv2.threshold(roi_gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

        # 배경이 어두우면 반전
        if np.mean(binary) < 127:
            binary = cv2.bitwise_not(binary)

        self.save_debug('binary', binary)
        print("  이진화 완료")

        # 크기 조정 (OCR 정확도 향상)
        scale = 2
        binary_large = cv2.resize(binary, None, fx=scale, fy=scale, interpolation=cv2.INTER_CUBIC)
        self.save_debug('binary_scaled', binary_large)

        # 패딩 추가
        binary_padded = cv2.copyMakeBorder(binary_large, 10, 10, 10, 10,
                                           cv2.BORDER_CONSTANT, value=255)
        self.save_debug('binary_padded', binary_padded)

        # 6. OCR (문자 인식)
        print("\n[6단계] OCR - 문자 인식 (AI 핵심)")

        # 인식 설정
        config = '--psm 7 --oem 3'

        # 인식 실행
        text = pytesseract.image_to_string(binary_padded, lang='kor+eng', config=config)
        text = text.strip()
        print(f"  인식 결과: '{text}'")

        # 상세 정보
        data = pytesseract.image_to_data(binary_padded, lang='kor+eng',
                                         config=config, output_type=pytesseract.Output.DICT)

        print("\n  문자별 상세:")
        confidences = []
        for i, char in enumerate(data['text']):
            if char.strip():
                conf = int(data['conf'][i])
                if conf > 0:
                    confidences.append(conf)
                    print(f"    '{char}': 신뢰도 {conf}%")

        if confidences:
            avg_conf = sum(confidences) / len(confidences)
            print(f"\n  평균 신뢰도: {avg_conf:.1f}%")

        # 7. 후처리
        print("\n[7단계] 후처리")
        import re

        # 특수문자 제거
        cleaned = re.sub(r'[^0-9가-힣]', '', text)
        print(f"  정리된 결과: '{cleaned}'")

        # 번호판 형식 검증
        patterns = [
            (r'^\d{2,3}[가-힣]\d{4}$', '일반 번호판'),
            (r'^[가-힣]{2}\d{2}[가-힣]\d{4}$', '신형 번호판'),
        ]

        is_valid = False
        for pattern, name in patterns:
            if re.match(pattern, cleaned):
                print(f"  형식 검증: 통과 ({name})")
                is_valid = True
                break

        if not is_valid:
            print(f"  형식 검증: 실패 (표준 번호판 형식 아님)")

        # 최종 결과
        print("\n" + "=" * 60)
        print("최종 결과")
        print("=" * 60)
        print(f"  인식된 텍스트: {cleaned}")
        print(f"  평균 신뢰도: {avg_conf:.1f}%" if confidences else "  신뢰도: 측정 불가")
        print(f"  유효한 번호판: {'예' if is_valid else '아니오'}")
        print(f"  디버그 이미지: {self.output_dir}/")

        return cleaned, avg_conf if confidences else 0, is_valid


def main():
    if len(sys.argv) < 2:
        print("사용법: python test_ai_pipeline.py <이미지경로>")
        print("예: python test_ai_pipeline.py test_car.jpg")
        return

    image_path = sys.argv[1]

    if not os.path.exists(image_path):
        print(f"파일이 존재하지 않습니다: {image_path}")
        return

    tester = PipelineTester()
    tester.test_full_pipeline(image_path)


if __name__ == "__main__":
    main()
```
