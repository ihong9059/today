## 하드웨어 사양 비교

### CPU 성능

| 항목 | Raspberry Pi 4 | Raspberry Pi 5 | AWS t3.small |
|------|----------------|----------------|--------------|
| **프로세서** | Broadcom BCM2711 | Broadcom BCM2712 | Intel Xeon (가변) |
| **아키텍처** | ARM Cortex-A72 | ARM Cortex-A76 | x86-64 |
| **코어 수** | 4코어 | 4코어 | 2 vCPU |
| **클럭 속도** | 1.5GHz (1.8GHz OC) | 2.4GHz | 2.5GHz (베이스라인) |
| **공정** | 28nm | 16nm | - |
| **IPC 성능** | 기준 (1.0x) | ~1.5x 향상 | 높음 (버스트 시) |

### 메모리

| 항목 | Raspberry Pi 4 | Raspberry Pi 5 | AWS t3.small |
|------|----------------|----------------|--------------|
| **RAM 용량** | 4GB / 8GB | 4GB / 8GB | 2GB |
| **RAM 타입** | LPDDR4-3200 | LPDDR4X-4267 | DDR4 ECC |
| **메모리 대역폭** | 약 25.6 GB/s | 약 34 GB/s | 고성능 |

### 저장소 & I/O

| 항목 | Raspberry Pi 4 | Raspberry Pi 5 | AWS t3.small |
|------|----------------|----------------|--------------|
| **기본 저장소** | microSD | microSD | EBS (SSD) |
| **고속 저장소** | USB 3.0 SSD | NVMe SSD (PCIe 2.0) | EBS gp3 (최대 16,000 IOPS) |
| **네트워크** | 1Gbps | 1Gbps | 최대 5Gbps |
| **USB** | USB 3.0 x2, 2.0 x2 | USB 3.0 x2, 2.0 x2 | - |
| **PCIe** | ❌ | ✅ PCIe 2.0 x1 | - |

## 🏆 웹서버 성능 우선순위

### 1위: AWS t3.small ⭐⭐⭐⭐⭐

**종합 점수: 95/100**

| 장점 | 설명 |
|------|------|
| **안정적인 네트워크** | AWS 글로벌 인프라, 고가용성 |
| **탄력적 확장** | 트래픽 증가 시 즉시 인스턴스 업그레이드 |
| **버스트 성능** | CPU 크레딧으로 일시적 고성능 |
| **고속 스토리지** | EBS gp3 최대 16,000 IOPS |
| **전용 IP** | Elastic IP로 고정 공인 IP |
| **보안** | Security Group, VPC 등 엔터프라이즈급 |

| 단점 | 설명 |
|------|------|
| **월 비용** | 약 $15~20/월 (Free Tier 종료 후) |
| **메모리** | 2GB로 제한적 (t3.medium 필요 시 비용 증가) |
| **데이터 전송 비용** | 월 100GB 초과 시 추가 비용 |

**적합한 용도**:
- ✅ 프로덕션 웹서비스
- ✅ 다수 사용자 동시 접속
- ✅ 24/7 안정적 운영 필수
- ✅ SSL/HTTPS 서비스
- ✅ 도메인 연결 서비스

---

### 2위: Raspberry Pi 5 ⭐⭐⭐⭐

**종합 점수: 80/100**

| 장점 | 설명 |
|------|------|
| **강력한 CPU** | Cortex-A76 2.4GHz, Pi 4 대비 2~3배 성능 |
| **NVMe 지원** | PCIe 2.0으로 고속 SSD 연결 가능 |
| **넉넉한 RAM** | 8GB 모델로 충분한 메모리 |
| **일회성 비용** | 초기 구매 후 전기세만 발생 (~$3/월) |
| **물리적 소유** | 데이터 완전 통제, 오프라인 사용 가능 |

| 단점 | 설명 |
|------|------|
| **공인 IP** | DDNS 또는 ngrok/Cloudflare Tunnel 필요 |
| **네트워크 안정성** | 가정용 인터넷 의존 (ISP 장애 영향) |
| **전원/냉각** | 별도 전원 관리, 발열 주의 (쿨러 권장) |
| **확장성** | 수직 확장 불가, 추가 Pi 필요 |

**적합한 용도**:
- ✅ 개발/테스트 서버
- ✅ 소규모 프로덕션 (동시 접속 100 이하)
- ✅ 내부망 서비스
- ✅ IoT 게이트웨이 + 웹 대시보드
- ✅ 개인 프로젝트

---

### 3위: Raspberry Pi 4 ⭐⭐⭐

**종합 점수: 65/100**

| 장점 | 설명 |
|------|------|
| **안정성** | 4년 이상 검증된 하드웨어 |
| **커뮤니티** | 풍부한 자료, 문제 해결 용이 |
| **저전력** | 최대 15W, 전기세 월 ~$2 |
| **저렴한 가격** | 중고 시장에서 $30~40 구매 가능 |

| 단점 | 설명 |
|------|------|
| **CPU 성능** | Cortex-A72 1.5GHz, 현대 기준 부족 |
| **I/O 병목** | NVMe 미지원, USB 3.0 SSD가 최선 |
| **발열** | 부하 시 쓰로틀링 발생 (쿨러 필수) |
| **성능 한계** | 동시 접속 50 이상 시 응답 지연 |

**적합한 용도**:
- ✅ 경량 웹서버 (정적 사이트, 간단한 API)
- ✅ 개발 환경 테스트
- ✅ 홈 오토메이션 대시보드
- ✅ 백업/보조 서버
- ⚠️ Next.js 등 무거운 프레임워크 (제한적)

## 시나리오별 추천

### 시나리오 1: 프로덕션 웹서비스 (고객 대상)
**추천: AWS t3.small** (또는 t3.medium)
- 이유: 안정성, 확장성, SLA 보장, 24/7 가용성

### 시나리오 2: 개발/테스트 환경
**추천: Raspberry Pi 5**
- 이유: 충분한 성능, 일회성 비용, 로컬 제어

### 시나리오 3: 사이드 프로젝트/포트폴리오
**추천: Raspberry Pi 5 + Cloudflare Tunnel**
- 이유: 무료 HTTPS, 무료 도메인 프록시, 비용 최소화

### 시나리오 4: 백업/보조 서버
**추천: Raspberry Pi 4**
- 이유: 저렴한 비용, 낮은 전력, 검증된 안정성

### 시나리오 5: 예산 제한 없음
**추천: AWS t3.medium + CloudFront**
- 이유: 최고 성능, 글로벌 CDN, 자동 확장
