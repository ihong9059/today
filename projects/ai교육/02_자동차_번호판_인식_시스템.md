# 자동차 번호판 인식 시스템 (ANPR)

## 개요

자동차 번호판 인식(ANPR: Automatic Number Plate Recognition)은 **컴퓨터 비전**과 **딥러닝**을 결합한 대표적인 AI 응용 시스템입니다.

---

```
┌─────────────────────────────────────────────────────────────┐
│                    ANPR 시스템 구성도                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   [카메라]  →  [컴퓨터/서버]  →  [데이터베이스]              │
│      │              │                 │                     │
│   영상촬영      AI 처리           결과 저장                  │

│   - 고해상도 카메라 (1080p 이상)                             │

└─────────────────────────────────────────────────────────────┘
```

## 2. AI 동작 원리

### 2.1 처리 파이프라인

```
┌──────────────────────────────────────────────────────────────────┐
│                        ANPR 처리 과정                             │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [1단계]        [2단계]        [3단계]        [4단계]            │
│  이미지 입력 → 번호판 탐지 → 문자 분할 → 문자 인식              │
│                                                                  │
│  ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐          │
│  │ 원본   │    │ 번호판 │    │ 개별   │    │ 인식   │          │
│  │ 사진   │ →  │ 영역   │ →  │ 문자   │ →  │ 결과   │          │
│  │        │    │ 추출   │    │ 분리   │    │        │          │
│  └────────┘    └────────┘    └────────┘    └────────┘          │
│                                                                  │
│     Input      Detection    Segmentation   Recognition           │
│                 (YOLO)       (OpenCV)       (CNN/OCR)            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 각 단계별 상세

#### 단계 1: 이미지 입력 및 전처리
```python
import cv2
import numpy as np

# 이미지 로드
image = cv2.imread('car_image.jpg')

# 전처리
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)  # 그레이스케일
blur = cv2.GaussianBlur(gray, (5, 5), 0)        # 노이즈 제거
resized = cv2.resize(blur, (640, 480))          # 크기 정규화
normalized = resized / 255.0                     # 0~1 정규화
```

#### 단계 2: 번호판 탐지 (Object Detection)
```python
# YOLO 모델 사용 예시
from ultralytics import YOLO

model = YOLO('license_plate_detector.pt')
results = model(image)

# 번호판 영역 좌표 추출
for box in results[0].boxes:
    x1, y1, x2, y2 = box.xyxy[0]  # 바운딩 박스 좌표
    plate_region = image[int(y1):int(y2), int(x1):int(x2)]
```

#### 단계 3: 문자 분할
```python
# 이진화 및 윤곽선 검출
_, binary = cv2.threshold(plate_gray, 127, 255, cv2.THRESH_BINARY)
contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 각 문자 영역 추출
characters = []
for contour in sorted(contours, key=lambda c: cv2.boundingRect(c)[0]):
    x, y, w, h = cv2.boundingRect(contour)
    if h > 20:  # 높이 필터
        char_img = plate_region[y:y+h, x:x+w]
        characters.append(char_img)
```

#### 단계 4: 문자 인식 (OCR)
```python
# EasyOCR 사용 예시
import easyocr

reader = easyocr.Reader(['ko', 'en'])  # 한국어, 영어
result = reader.readtext(plate_region)

# 또는 학습된 CNN 모델 사용
model = load_model('char_classifier.h5')
for char_img in characters:
    prediction = model.predict(char_img)
    recognized_char = decode(prediction)
```

## 3. 딥러닝 모델 구조

### 3.1 번호판 탐지 모델 (YOLO 기반)

```
입력: 640 x 640 x 3 (RGB 이미지)
      │
      ▼
┌─────────────────────────────────────┐
│         Backbone (CSPDarknet)        │
│  Conv → BN → SiLU → Pool             │
│  특징 추출: 저수준 → 고수준           │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│           Neck (PANet)               │
│  다중 스케일 특징 결합                │
│  작은 번호판도 탐지 가능              │
└─────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────┐
│         Head (Detection)             │
│  바운딩 박스 + 클래스 확률            │
│  출력: (x, y, w, h, confidence)      │
└─────────────────────────────────────┘

출력: 번호판 위치 좌표
```

### 3.2 문자 인식 모델 (CNN)

```
입력: 32 x 32 x 1 (흑백 문자 이미지)
      │
      ▼
┌────────────────────────────┐
│  Conv2D (32 filters, 3x3)  │  → 특징 추출
│  MaxPool (2x2)             │
└────────────────────────────┘
      │
      ▼
┌────────────────────────────┐
│  Conv2D (64 filters, 3x3)  │  → 더 복잡한 특징
│  MaxPool (2x2)             │
└────────────────────────────┘
      │
      ▼
┌────────────────────────────┐
│  Flatten                   │
│  Dense (128, ReLU)         │  → 분류 준비
│  Dropout (0.5)             │
└────────────────────────────┘
      │
      ▼
┌────────────────────────────┐
│  Dense (36, Softmax)       │  → 0-9, A-Z (36개 클래스)
└────────────────────────────┘

출력: 문자 클래스 확률
```

## 4. 학습 과정

### 4.1 데이터셋 준비

```
dataset/
├── images/
│   ├── train/          # 학습용 (80%)
│   │   ├── img001.jpg
│   │   └── ...
│   └── val/            # 검증용 (20%)
│       ├── img501.jpg
│       └── ...
├── labels/
│   ├── train/          # YOLO 형식 라벨
│   │   ├── img001.txt  # class x_center y_center width height
│   │   └── ...
│   └── val/
│       └── ...
└── classes.txt         # license_plate
```

### 4.2 라벨링 형식

```
# YOLO 형식 (img001.txt)
# class_id  x_center  y_center  width  height (모두 0~1로 정규화)
0 0.5 0.7 0.2 0.08

# 의미: 번호판이 이미지 중앙(0.5, 0.7)에
#       가로 20%, 세로 8% 크기로 존재
```

### 4.3 학습 코드

## 6. 도전 과제와 해결책

### 6.1 일반적인 문제

| 문제 | 원인 | 해결책 |
|:---|:---|:---|
| **야간 인식 실패** | 조명 부족 | IR 조명 추가, 히스토그램 평활화 |
| **기울어진 번호판** | 각도 문제 | 어파인 변환, 데이터 증강 |
| **오염/손상** | 물리적 훼손 | 이미지 복원, 노이즈 제거 |
| **빠른 속도** | 모션 블러 | 고속 셔터, 디블러링 |

### 6.2 한국 번호판 특이사항

```
한국 번호판 형식:
┌─────────────────────────────────┐
│  12가 3456  (일반 자가용)        │
│  서울12가3456 (지역명 포함)       │
│  12가3456  (신형 7자리)          │
│  배달12가3456 (영업용)           │
└─────────────────────────────────┘

고려사항:
- 한글 인식 필요 (가~히)
- 다양한 형식 지원
- 지역명 처리
```
