# AI 동작원리 이해를 위한 실험 가이드

## 개요

이 문서는 AI 초보자가 실험을 통해 인공지능의 동작 원리를 이해할 수 있도록 작성되었습니다.
두 가지 실험 시스템을 비교하며 AI의 핵심 개념을 학습합니다.

---

## 1. AI란 무엇인가?

### 1.1 인공지능의 정의
인공지능(AI)은 컴퓨터가 인간처럼 **학습하고, 판단하고, 예측**하는 기술입니다.

```
[입력 데이터] → [AI 모델] → [출력 결과]
   이미지         학습된 뇌      "자동차 번호판: 12가 3456"
   센서값         학습된 뇌      "넘어짐 감지!"
```

### 1.2 AI의 핵심 과정

```
┌─────────────────────────────────────────────────────────────┐
│                      AI 학습 파이프라인                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 데이터 수집    →   2. 전처리    →   3. 모델 설계         │
│    (이미지/센서)        (정규화)         (신경망 구조)        │
│                                                             │
│  4. 학습(Training) →  5. 평가    →    6. 배포(Deploy)       │
│    (가중치 조정)       (정확도)         (실제 사용)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 두 실험 시스템 소개

### 시스템 A: 자동차 번호판 인식 (ANPR)
- **하드웨어**: PC/서버 + 카메라
- **AI 유형**: 컴퓨터 비전 (Computer Vision)
- **모델 크기**: 대형 (수십~수백 MB)
- **처리 위치**: 클라우드 또는 고성능 PC

### 시스템 B: ESP32 + MPU6050 + AHT20
- **하드웨어**: 초소형 마이크로컨트롤러
- **AI 유형**: TinyML (초소형 머신러닝)
- **모델 크기**: 초소형 (수십 KB)
- **처리 위치**: 엣지 디바이스 (현장에서 바로)

---

## 3. 두 시스템의 핵심 차이점

### 3.1 비교 테이블

| 구분 | 번호판 인식 (ANPR) | ESP32 TinyML |
|:---|:---|:---|
| **입력 데이터** | 이미지 (2D 픽셀) | 센서값 (숫자 시계열) |
| **데이터 크기** | 큼 (수 MB/장) | 작음 (수십 바이트) |
| **모델 크기** | 10~500MB | 10~100KB |
| **연산 능력** | GPU 권장 | CPU만으로 가능 |
| **전력 소비** | 높음 (수십~수백W) | 매우 낮음 (mW 단위) |
| **처리 속도** | 0.1~1초 | 실시간 (ms 단위) |
| **인터넷 필요** | 선택적 | 불필요 (오프라인) |
| **비용** | 높음 | 매우 낮음 ($10 이하) |
| **학습 난이도** | 중상 | 중하 |

### 3.2 AI 모델 구조 차이

#### 번호판 인식 (Deep Learning)
```
입력층          은닉층 (수십~수백 개)           출력층
[이미지]  →  [CNN] → [CNN] → ... → [FC]  →  [문자 인식]
640x480       특징 추출                       "12가 3456"
= 307,200개   수백만 개의 파라미터
```

#### ESP32 TinyML (Lightweight Model)
```
입력층        은닉층 (2~3개)      출력층
[센서값]  →  [Dense] → [Dense] → [분류]
6개 값       16~64개 뉴런        3개 클래스
             수천 개의 파라미터   "정상/넘어짐/충격"
```

### 3.3 학습 데이터 차이

#### 번호판 인식
```python
# 이미지 데이터 (복잡)
data_shape = (batch, height, width, channels)
# 예: (32, 480, 640, 3) = 약 29MB per batch

# 라벨: 문자열
labels = ["12가3456", "34나7890", ...]
```

#### ESP32 센서
```python
# 센서 데이터 (단순)
data_shape = (batch, time_steps, features)
# 예: (32, 50, 6) = 약 38KB per batch

# 라벨: 정수
labels = [0, 1, 2]  # 정상, 넘어짐, 충격
```

## 5. 실험을 통해 이해할 AI 핵심 개념

### 5.1 공통 개념
1. **데이터 전처리**: 원시 데이터를 AI가 이해할 수 있는 형태로 변환
2. **모델 학습**: 데이터로부터 패턴을 학습
3. **추론(Inference)**: 학습된 모델로 새로운 데이터 예측
4. **정확도 평가**: 모델 성능 측정

### 5.2 시스템별 특화 개념

#### 번호판 인식
- **이미지 증강(Augmentation)**: 데이터 다양화
- **객체 탐지(Object Detection)**: 번호판 위치 찾기
- **OCR(Optical Character Recognition)**: 문자 인식
- **후처리**: 인식 결과 보정

#### ESP32 TinyML
- **양자화(Quantization)**: 모델 경량화
- **시계열 데이터 처리**: 연속된 센서값 분석
- **실시간 추론**: 지연 없는 예측
- **전력 최적화**: 배터리 수명 관리
