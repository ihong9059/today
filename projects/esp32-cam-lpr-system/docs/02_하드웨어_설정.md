| GPIO 2 | - | 예 | 일반 IO |

| GPIO 12 | - | 예* | SD카드 사용시 불가 |
| GPIO 13 | - | 예* | SD카드 사용시 불가 |
| GPIO 14 | - | 예 | 일반 IO |
| GPIO 15 | - | 예* | SD카드 사용시 불가 |

## 4. 하드웨어 연결

### 4.1 ESP32-CAM 프로그래밍 연결 (ESP32-CAM-MB 사용)

```
┌─────────────────┐
│  ESP32-CAM-MB   │
│                 │
│  ┌───────────┐  │
│  │ ESP32-CAM │  │    USB 케이블
│  │  모듈     │  │ ──────────────► PC
│  │  삽입     │  │
│  └───────────┘  │
│                 │
│  [BOOT] [RST]   │
└─────────────────┘
```

> **참고**: ESP32-CAM-MB 사용 시 별도 배선 없이 USB로 직접 연결 가능

### 4.2 FTDI 사용시 연결 (ESP32-CAM-MB 없을 경우)

```
ESP32-CAM          FTDI/USB-TTL
─────────          ───────────
   5V      ◄────►     VCC (5V)
   GND     ◄────►     GND
   U0T     ◄────►     RX
   U0R     ◄────►     TX
   GPIO0   ◄────►     GND (업로드 모드)
```

> **중요**: 업로드 완료 후 GPIO0과 GND 연결 해제 필요

### 4.3 전원 연결 권장사항

#### ESP32-CAM 전원
```
┌─────────────────────────────────────────┐
│  권장 구성                               │
```

## 5. 네트워크 설정

### 5.1 권장 네트워크 구성

```
┌─────────────────────────────────────────────────────────┐
│                   WiFi 공유기                           │
│               (2.4GHz 대역 사용)                        │
│                  192.168.1.1                           │
└─────────────────────────────────────────────────────────┘
                    │           │
                    │           │
        ┌───────────┴───┐   ┌───┴───────────┐
        │   ESP32-CAM   │   │ Raspberry Pi   │
        │ 192.168.1.100 │   │ 192.168.1.200  │
        │ (고정 IP 권장) │   │ (고정 IP 권장)  │
        └───────────────┘   └────────────────┘
```

### 5.2 고정 IP 설정 방법

#### Raspberry Pi 고정 IP 설정
```bash
# /etc/dhcpcd.conf 편집
sudo nano /etc/dhcpcd.conf

# 아래 내용 추가
interface wlan0
static ip_address=192.168.1.200/24
static routers=192.168.1.1
static domain_name_servers=192.168.1.1 8.8.8.8
```

#### ESP32-CAM 고정 IP 설정 (코드에서)
```cpp
// Arduino 코드에서
IPAddress local_IP(192, 168, 1, 100);
IPAddress gateway(192, 168, 1, 1);
IPAddress subnet(255, 255, 255, 0);
WiFi.config(local_IP, gateway, subnet);
```

```
                    측면도

                    ┌─────┐ ESP32-CAM
                    │ 📷  │
                    └──┬──┘
                       │ 각도: 15-30도
                       │
                       │  거리: 1-5m
                       │
        ───────────────┼───────────────
                  ┌────┴────┐
                  │  🚗     │ 차량 번호판
                  │ 12가3456│ 높이: 40-60cm

```

### 6.2 권장 설치 조건

| 조건 | 권장값 | 비고 |
|------|--------|------|
| 거리 | 1~5m | 너무 가까우면 왜곡, 멀면 해상도 부족 |
| 높이 | 1~1.5m | 번호판과 비슷하거나 약간 높게 |
| 각도 | 15~30도 | 정면에 가깝게 |
| 조명 | 균일 조명 | 역광 피할 것 |

### 6.3 야간 촬영 설정

```

│     - 조명 각도는 카메라와 동일하게       │
```
