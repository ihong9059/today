AI 예지정비 핵심 기능

UTTEC의 Edge AI 기술로 협동로봇 고장을 사전에 예측합니다

📊

실시간 FFT 분석

토크센서 및 진동 데이터를 주파수 영역으로 변환하여 이상 패턴을 실시간으로 탐지합니다.

  • 감속기(하모닉 드라이브) 마모 감지
  • 베어링 BPFO/BPFI/BSF 분석
  • 모터 전류 THD 분석
  • 토크 리플 패턴 분석
🧠

Edge AI 처리

ARM Cortex-M4 + DSP 기반 온디바이스 AI로 지연 없는 실시간 분석을 수행합니다.

  • 180MHz 고속 처리
  • 8채널 동시 ADC 샘플링
  • CAN/EtherCAT 실시간 연동
  • FreeRTOS 실시간 OS
⏱️

RUL 예측

LSTM 딥러닝 모델로 각 부품의 잔여수명(Remaining Useful Life)을 예측합니다.

  • 감속기: 잔여 수명(일) 예측
  • 베어링: 교체 권장 시점
  • 모터: 이상 확률(%)
  • 케이블: 열화 상태 분석
