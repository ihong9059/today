Edge AI Gateway 사양

현장에서 실시간 분석을 수행하는 핵심 장비

🖥️ 하드웨어 사양

  • MCUARM Cortex-M4 + DSP
  • 메모리512KB Flash, 256KB RAM
  • 아날로그 입력8ch (4-20mA, 0-10V)
  • 디지털 I/O8ch 입력, 4ch 출력
  • 통신RS-485, Ethernet, WiFi
  • 전원24VDC, 10W

📊 분석 기능

  • FFT 분석실시간 주파수 분석
  • Envelope 분석베어링 결함 검출
  • Cepstrum 분석기어 결함 검출
  • 이상 탐지AI 기반 자동 감지
  • RUL 예측잔여수명 예측
  • 샘플링최대 25.6 kHz

🔌 통신 프로토콜

  • Modbus RTU/TCP지원
  • MQTTAWS IoT, Azure
  • HTTP RESTAPI 제공
  • OPC-UA옵션
  • 데이터 저장로컬 24시간
  • 보안TLS 1.3

🛡️ 환경 사양

  • 동작 온도-20~60°C
  • 보호 등급IP65
  • 방폭Ex ia IIC T4 옵션
  • 인증KC, CE, FCC
  • MTBF> 100,000 시간
  • 보증2년
