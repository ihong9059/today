분쇄기 예지정비 (PdM)

Pin Mill, Hammer Mill, Roll Mill의 실시간 상태 모니터링 및 고장 예측으로 비계획 정지 최소화

  • FFT 스펙트럼 분석으로 베어링 결함 조기 감지
  • BPFO/BPFI 분석으로 내륜/외륜 결함 진단
  • 전류 파형 분석으로 모터 부하 이상 감지
  • 온도 추이 분석으로 과열 예측
70% 정지시간 감소
🔄

혼합기 모니터링

Ribbon Mixer, V-Mixer, Double Cone Mixer의 혼합 품질 및 설비 상태 실시간 감시

  • 전류 패턴 분석으로 혼합 완료 시점 자동 감지
  • 진동 분석으로 균일 혼합 여부 판정
  • 시간-전류 곡선으로 최적 혼합 시간 도출
  • 씰 부위 분진 누출 조기 감지
품질 균일성 향상
🌿

환경 모니터링

작업장 분진/소음 실시간 감시로 산업안전보건법 및 환경 규제 준수

  • PM2.5/10 분진 농도 실시간 모니터링
  • 작업장 소음 레벨 연속 측정 (90dB 기준)
  • 기준치 초과 시 즉시 알림 발송
  • 환경 보고서 자동 생성
규제 대응 완벽
📊

생산이력 관리 (MES)

LOT별 생산이력 추적 및 품질관리로 식품/의약 고객 대응력 강화

  • 작업지시서 생성 및 레시피 관리
  • 공정 데이터 자동 수집 (가동시간, 처리량)
  • LOT별 생산이력으로 불량 원인 역추적
  • OEE(설비종합효율) 실시간 관리
완벽한 추적성

원격 A/S 플랫폼

  • 실시간 설비 상태 원격 모니터링
  • 이상 감지 시 선제적 A/S 제안
  • 월간/분기 설비 상태 보고서 자동 생성
