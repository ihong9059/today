프로젝트 상세

Project A: 밸브 상태 모니터링

투자: 4,000만원 | 기간: 3개월

  • 핵심 공정 밸브 20대 모니터링
  • 밸브당 5개 센서 (총 100pt)
  • 밸브 시그니처 분석 (토크 프로파일)
  • 내부/외부 누설 감지
  • AI 기반 이상 탐지
  • 정비 권고 시점 제안

Project B: MRO 고객 원격 지원

투자: 3,000만원 | 기간: 2.5개월

  • 멀티테넌트 SaaS 플랫폼
  • 고객사별 밸브 현황 대시보드
  • 원격 진단 및 기술 지원
  • 부품 수명 관리 및 예측
  • 자동 알림 서비스
  • 부품 자동 발주 연동

Project C: 액추에이터 진단

투자: 2,000만원 | 기간: 2개월

  • F89 공압 액추에이터 전용
  • 공압 효율 분석 (누설 감지)
  • 응답 성능 분석
  • 스프링 상태 진단
  • 포지셔너 진단
  • 예방 정비 권고
