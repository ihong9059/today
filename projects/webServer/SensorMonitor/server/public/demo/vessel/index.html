Oven 온도 예지정비

히터 전류, 온도 균일성, 팬 진동을 실시간 분석하여 히터 열화/단선을 사전 예측합니다.

✓ 히터 전류 패턴 분석 (열화 예측)
✓ 존별 온도 균일성 모니터링
✓ 순환팬 베어링 진동 분석
✓ RUL 예측 (잔여수명)
💧

Dispenser 품질 관리

토출 압력, 토출량, 밸브 응답시간을 분석하여 노즐 막힘/밸브 마모를 사전 감지합니다.

✓ 토출 압력 실시간 모니터링
✓ 토출량 편차 분석
✓ 밸브 응답시간 추적
✓ 노즐 막힘 사전 경고
⚙️

In-Line 컨베이어 관리

컨베이어 모터 토크/진동, 위치센서 상태를 분석하여 연속 공정 안정성을 확보합니다.

✓ 모터 토크/전류 분석
✓ 벨트 마모 예측
✓ 위치센서 드리프트 감지
✓ 동기화 오류 사전 감지
📊

통합 분석 대시보드

전체 장비 상태를 한눈에 파악하고, AI 기반 정비 스케줄을 자동 생성합니다.

✓ 장비 건강도 통합 모니터링
✓ AI 정비 스케줄 최적화
✓ 이상 분류 및 원인 분석
