로봇 유형별 모니터링 포인트

각 로봇 유형에 최적화된 예지정비 모니터링 항목

🤖

EFEM / WTR

반도체 이송 로봇

  • 진동 3축 가속도
  • 위치 정밀도 ±0.01mm
  • 진공 누설 압력 센서
  • 예측 지표 핸들링 정밀도, RUL
🔄

SCARA

4축 수평다관절

  • 관절 토크 토크 센서
  • 모터 전류 전류 센서
  • 백래시 위치 피드백
  • 예측 지표 반복 정밀도, 고장 확률
🦾

6축 다관절

Articulated Robot

  • 축별 진동 6축 독립 분석
  • 감속기 온도 열화상 분석
  • 브레이크 토크 변화
  • 예측 지표 축별 RUL, 마모 상태
🤝

협동 로봇

Cobot

  • 토크 센서 6축 토크
  • 충돌 감지 힘 피드백
  • 관절 온도 열화상
  • 예측 지표 안전 성능, 협업 정밀도
📐

리니어 로봇

Cartesian Robot

  • 가이드 마모 진동 분석
  • 벨트 장력 장력 센서
  • 위치 오차 엔코더
  • 예측 지표 직진도, 교체 시점
