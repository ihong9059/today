## 1. 배경 및 필요성

### 한국의 스마트폰 교체 현황

| 항목 | 현황 |
|------|------|
| 평균 교체 주기 | 약 2~3년 |
| 연간 폐휴대폰 발생량 | 약 1,600톤 이상 |
| 실제 재활용률 | **2% 미만** (27톤/1,631톤) |
| 보유 중인 폐휴대폰 | 가구당 평균 2~3대 |

### 폐스마트폰의 가치

- 금, 은, 구리 등 **30가지 이상의 희귀 금속** 포함
- 휴대폰 1대당 금 약 **0.034g** (1톤에서 300~400g 추출 가능)
- 고성능 센서, 카메라, 디스플레이, 통신 모듈 내장
- Raspberry Pi보다 **더 많은 기능**을 더 저렴하게 보유

### 왜 재활용 대신 "재사용"인가?

| 비교 | 재활용 (Recycle) | 재사용 (Reuse/Upcycle) |
|------|-----------------|----------------------|
| 가치 | 원자재 추출 | 기기 그대로 활용 |
| 환경 영향 | 분해/처리 과정 필요 | 추가 폐기물 없음 |
| 경제적 가치 | 낮음 | **높음** |
| 난이도 | 전문 시설 필요 | 소프트웨어만으로 가능 |

### 프로젝트 1: 식당 테이블 주문 시스템 (Table Ordering System)

#### 개요
한국 식당에서 널리 사용되는 테이블 주문 태블릿을 폐스마트폰으로 대체

#### 시장 현황
- 한국 테이블 주문 시장 규모: 현재 약 **1,000억원** → 중장기 **1조원** 예상
- 테이블 주문 시스템 도입률: **10% 미만** (성장 여지 큼)
- 직원 1명 월급 200만원 vs 태블릿 월 3만원

#### 기술 구현

```
┌─────────────────────────────────────────────────┐
│              테이블 주문 시스템 구조              │
├─────────────────────────────────────────────────┤
│                                                 │
│  ┌─────────┐     WiFi     ┌─────────────┐      │
│  │ 폐스마트폰 │ ─────────→ │  주문 서버   │      │
│  │ (테이블) │             │ (Raspberry Pi)│      │
│  └─────────┘             └─────────────┘      │
│       │                         │              │
│       │ 메뉴 표시               │ 주문 전송    │
│       │ 주문 입력               │              │
│       ▼                         ▼              │
│  ┌─────────┐             ┌─────────────┐      │
│  │   고객   │             │  주방 디스플레이 │      │
│  └─────────┘             │  (폐태블릿)   │      │
│                          └─────────────┘      │
└─────────────────────────────────────────────────┘
```

#### 필요 기술
- **프론트엔드**: React/Vue.js 웹앱 (또는 Android 앱)
- **백엔드**: Node.js / Python Flask
- **데이터베이스**: SQLite / PostgreSQL
- **네트워크**: 내부 WiFi (인터넷 불필요)

#### 구현 방법

**방법 1: 웹앱 기반 (권장)**
```bash
# 폐스마트폰에서
# Chrome 키오스크 모드로 주문 페이지 표시
# 서버는 Raspberry Pi 또는 다른 스마트폰
```

**방법 2: Android 앱 기반**
```bash
# 전용 앱 개발
# APK 설치 후 키오스크 모드 설정
```

#### 비용 분석

| 항목 | 기존 솔루션 (t'order) | 폐스마트폰 솔루션 |
|------|---------------------|------------------|
| 태블릿 비용 | 월 3만원/대 (렌탈) | **0원** (재사용) |
| 서버 비용 | 클라우드 월 5만원+ | Raspberry Pi 일회성 8만원 |
| 10테이블 1년 | **360만원+** | **8만원** |

#### 장점
- 비용 절감 90% 이상
- 환경 보호 (전자폐기물 감소)
- 커스터마이징 자유로움
- 인터넷 불필요 (내부망 운영)

#### 단점/과제
- 초기 개발 필요
- 배터리 관리 (상시 충전)
- AS/유지보수 자체 해결

#### 사업화 가능성: ⭐⭐⭐⭐⭐
- 소규모 식당 대상 저가 솔루션
- 폐스마트폰 수거 + 소프트웨어 패키지 판매
- 프랜차이즈 대상 대량 납품

### 프로젝트 2: 보안 카메라 / CCTV 시스템

#### 개요
폐스마트폰을 IP 카메라로 변환하여 가정/사무실/매장 보안 시스템 구축

#### 추천 앱

| 앱 이름 | 가격 | 특징 |
|--------|------|------|
| **AlfredCamera** | 무료/프리미엄 | 가장 인기, 양방향 오디오, 모션 감지 |
| **Haven** | 무료 (오픈소스) | Edward Snowden 개발, 보안 특화 |

| **Presence** | 무료 | 간단한 설정, iOS/Android |

#### Haven 앱 특징 (보안 특화)
- 마이크: 소리 감지
- 카메라: 움직임 감지
- 조도 센서: 빛 변화 감지
- 가속도계: 기기 이동 감지
- **기압계**: 문/창문 열림 감지
- **오프라인 작동**: WiFi 없이도 로컬 저장

```
│  │  (현관)   │  │  (거실)   │  │  (주차장)  │     │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘     │
│       │             │             │           │
│       └──────┬──────┴──────┬──────┘           │
│              │    WiFi     │                  │
│              ▼             ▼                  │
│       ┌─────────────────────────┐             │
```

### 프로젝트 4: IoT 센서 허브

#### 개요
스마트폰의 다양한 센서를 활용하여 IoT 데이터 수집 허브로 활용

#### 스마트폰 내장 센서 (Galaxy M53 5G 기준: 26개)

| 센서 유형 | 용도 | 샘플링 |
|----------|------|:------:|
| 가속도계 | 진동/움직임 감지 | 500Hz |
| 자이로스코프 | 회전/기울기 감지 | 500Hz |
| 자기장 센서 | 나침반/금속 감지 | 125Hz |
| 조도 센서 | 밝기 측정 | 5Hz |
| 근접 센서 | 물체 접근 감지 | - |
| 기압계 | 기압/고도 측정 | - |
| GPS | 위치 추적 | - |
| 마이크 | 소리/소음 측정 | 44.1kHz |
| 카메라 | 이미지 인식 | - |

#### 활용 사례

**1. 공장 진동 모니터링**
```
스마트폰 가속도계 → 기계 진동 측정 → 이상 감지 → 알림
```

**2. 환경 모니터링**
```
조도 + 마이크 + GPS → 환경 데이터 수집 → 서버 전송
```

**3. 스마트 농업**
```
조도 + 카메라 → 작물 상태 모니터링 → AI 분석
```

#### JanOS 프로젝트
- Firefox OS 기반 IoT 전용 OS
- 스마트폰을 임베디드 보드처럼 사용
- GPIO 포트를 통해 외부 전자 부품 연결 가능

#### 비교: 스마트폰 vs Raspberry Pi

| 항목 | 폐스마트폰 | Raspberry Pi 4 |
|------|----------|---------------|
| 가격 | **$0** (재사용) | $55+ |
| 센서 | **26개 내장** | 별도 구매 필요 |
| 디스플레이 | **내장** | 별도 구매 ($30+) |
| 카메라 | **내장 (고화질)** | 별도 구매 ($25+) |
| 배터리 | **내장** | 별도 구매 |
| 통신 | **LTE/5G/WiFi** | WiFi만 |
| GPIO | 제한적 | 40핀 |

#### 사업화 가능성: ⭐⭐⭐⭐
- 중소기업 설비 모니터링 솔루션
- 스마트팜 센서 네트워크

### 프로젝트 7: 경량 웹서버 (Termux 기반)

#### 개요
Termux를 활용하여 폐스마트폰을 웹서버로 운영

#### 설치 방법

```bash
# Termux 설치 후
pkg update && pkg upgrade

# Node.js 웹서버
pkg install nodejs
npm install -g http-server
http-server -p 8080

# Python Flask 서버
pkg install python
pip install flask
python app.py

# 외부 접속 (Cloudflare Tunnel)
pkg install cloudflared
cloudflared tunnel --url http://localhost:8080
```

```python
# AI 튜터 질의응답 예시
import anthropic

client = anthropic.Anthropic(api_key="your-api-key")

def ask_ai_tutor(question, subject, grade):
    prompt = f"""당신은 {grade}학년 {subject} 과목 튜터입니다.
    학생이 이해하기 쉽게 친절하게 설명해주세요.

    학생 질문: {question}
    """

    response = client.messages.create(
        model="claude-3-haiku-20240307",  # 저비용 모델
        max_tokens=1024,
        messages=[{"role": "user", "content": prompt}]
    )
    return response.content[0].text
```
