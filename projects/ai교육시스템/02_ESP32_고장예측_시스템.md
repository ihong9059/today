## 1. 시스템의 필요성 (교육 목적 포함)

### 1.1 왜 이 시스템을 배워야 할까요?

**산업 현장에서의 활용**

| 활용 분야 | 예시 |
|-----------|------|
| 공장 설비 | 모터, 컨베이어, 펌프 고장 예측 |
| 발전소 | 터빈, 발전기 이상 감지 |
| 엘리베이터 | 이상 진동, 소음 감지 |
| 자동차 | 엔진, 베어링 상태 모니터링 |
| 가전제품 | 세탁기, 에어컨 고장 예방 |

**왜 중요할까?**
```
❌ 기계가 갑자기 고장나면...
   → 생산 중단 💸
   → 수리 비용 증가 💸💸
   → 안전 사고 위험 ⚠️

✅ 미리 고장을 예측하면...
   → 계획된 정비 가능 🔧
   → 비용 절감 💰
   → 안전 확보 ✅
```

### 1.2 교육적 목적

| 학습 목표 | 설명 |
|-----------|------|
| 센서 원리 이해 | 물리 현상을 데이터로 변환하는 방법 |
| 데이터 수집 | 실시간 센서 데이터 획득 |
| 패턴 분석 | 정상/비정상 패턴 구분 |
| 예측 AI 이해 | 머신러닝 기초 개념 학습 |
| IoT 개념 | 사물인터넷 기초 체험 |

### 1.3 이 프로젝트로 배울 수 있는 것

```
✅ 센서로 진동과 소리를 측정하는 방법
✅ 측정된 데이터를 분석하는 방법
✅ 정상 상태와 이상 상태를 구분하는 AI 원리
✅ 고장을 미리 예측하는 방법
```

### 3.2 센서 상세 설명

#### 📐 MPU6050 - 6축 모션 센서

**MPU6050이란?**
> 움직임을 감지하는 센서예요. 스마트폰을 기울이면 화면이 돌아가죠? 그것도 이런 센서 덕분이에요!

**측정하는 것:**

```
┌─────────────────────────────────────────┐
│           MPU6050 센서                  │
├─────────────────────────────────────────┤
│                                         │
│  🔹 가속도계 (Accelerometer)            │
│     → X, Y, Z 방향의 움직임 감지        │
│     → 단위: g (중력가속도)              │
│                                         │
│  🔹 자이로스코프 (Gyroscope)            │
│     → X, Y, Z 축의 회전 감지            │
│     → 단위: °/s (초당 각도)             │
│                                         │
└─────────────────────────────────────────┘
```

**3축이란?**

```
        Y축 (위/아래)
         ↑
         │
         │
         │──────────→ X축 (좌/우)
        /
       /
      ↙
    Z축 (앞/뒤)
```

**쉬운 비유:**
```
기계에 MPU6050을 붙이면...

정상 작동 시:  ~~~~~~  (작은 진동)
이상 발생 시:  ∿∿∿∿∿∿  (큰 진동, 불규칙)

마치 청진기로 심장 소리를 듣는 것처럼,
센서로 기계의 "건강 상태"를 체크해요! 🏥
```

---

#### 🎤 마이크 모듈 (MAX9814)

**마이크란?**
> 소리를 전기 신호로 바꿔주는 장치예요.

**왜 소리를 측정할까?**

```
기계 소리로 알 수 있는 것:

🔊 정상:  "윙~" (일정한 소리)
⚠️ 이상:  "끼익~" 또는 "덜컹덜컹" (비정상 소리)

예시)
- 선풍기: 정상 = 부드러운 바람 소리
          이상 = 삐걱거리는 소리

- 자동차: 정상 = 부드러운 엔진 소리
          이상 = 쇠 긁는 소리
```

**MAX9814의 특징:**
- 자동 이득 조절 (소리 크기 자동 조정)
- 잡음 감소 기능
- 아날로그 출력 → ESP32 ADC로 읽기

### 3.3 각 단계 상세 설명

#### 📊 1단계: 센서 측정

**데이터 수집 주기:**
```
1초에 100번 측정 (100Hz)
        ↓
1분 = 6,000개의 데이터
        ↓
풍부한 정보로 정확한 분석 가능!
```

**측정되는 데이터 예시:**

```
시간     가속도X  가속도Y  가속도Z  자이로X  자이로Y  자이로Z  소리
─────────────────────────────────────────────────────────────────
0.00초    0.02    0.98    0.05    0.1     0.0     0.2     120
0.01초    0.03    0.99    0.04    0.2     0.1     0.1     118
0.02초    0.02    0.97    0.06    0.1     0.0     0.3     122
  ...      ...     ...     ...     ...     ...     ...     ...
```

---

#### 🔢 2단계: 데이터 변환 (아날로그 → 디지털)

**왜 변환이 필요할까?**
> 센서가 측정하는 것은 전기 신호(아날로그)인데, 컴퓨터는 숫자(디지털)만 이해해요!

**변환 과정:**

```
실제 진동 ──▶ 전기 신호 ──▶ 숫자 데이터
  ∿∿∿         ~~~~~~       [0.02, 0.98, ...]
 (물리)       (전압)        (디지털)
```

**ADC (Analog to Digital Converter):**
```
ESP32의 ADC는 12비트
→ 0 ~ 4095 사이의 숫자로 표현
→ 0V = 0, 3.3V = 4095
```

---

#### 🔍 3단계: 특징 추출 (Feature Extraction)

**특징이란?**
> 데이터의 "성격"을 나타내는 숫자들이에요.

**주요 특징:**

| 특징 | 설명 | 의미 |
|------|------|------|
| **평균값** | 데이터의 중심값 | 기본 상태 |
| **표준편차** | 흔들림 정도 | 진동 크기 |
| **최댓값** | 가장 큰 값 | 충격 감지 |
| **주파수** | 진동 빠르기 | 패턴 분석 |
| **RMS** | 제곱평균제곱근 | 에너지 크기 |

**쉬운 비유 - 음악으로 설명:**
```
🎵 노래의 특징:
   - 빠르기 (BPM) = 주파수
   - 소리 크기 = 진폭
   - 음의 높낮이 = 음고

🔧 기계의 특징:
   - 진동 빠르기 = 회전 속도
   - 진동 크기 = 마모/불균형
   - 소음 패턴 = 부품 상태
```

**특징 추출 예시:**

```
원본 데이터: [0.02, 0.03, 0.02, 0.04, 0.01, ...]
                      ↓ 특징 추출
추출된 특징:
├─ 평균: 0.024
├─ 표준편차: 0.011
├─ 최댓값: 0.04
├─ RMS: 0.026
└─ 주파수 피크: 50Hz
```

---

#### 🧠 4단계: AI 분석

**AI가 하는 일:**
> 추출된 특징들을 보고 "정상인가? 비정상인가?" 판단해요.

**분류 방법 (머신러닝):**

```
학습 단계:
┌─────────────────────────────────────────┐
│  정상 데이터  →  특징  →  "정상 패턴"   │
│  이상 데이터  →  특징  →  "이상 패턴"   │
└─────────────────────────────────────────┘
         AI가 패턴을 기억해요!

판단 단계:
┌─────────────────────────────────────────┐
│  새 데이터  →  특징  →  패턴 비교       │
│                      →  "정상" or "이상"│
└─────────────────────────────────────────┘
```

**쉬운 비유 - 의사와 비슷해요:**
```
👨‍⚕️ 의사가 환자를 진단할 때:
   1. 증상을 관찰 (데이터 수집)
   2. 검사 결과 분석 (특징 추출)
   3. 경험과 비교 (AI 분석)
   4. 진단 내리기 (상태 판단)

🤖 AI도 똑같이:
   1. 센서로 측정 (데이터 수집)
   2. 숫자로 변환 (특징 추출)
   3. 학습한 패턴과 비교 (AI 분석)
   4. 결과 출력 (상태 판단)
```

**간단한 AI 알고리즘 예시 (임계값 방식):**

```
IF 진동_표준편차 > 0.5 THEN
    상태 = "이상"
ELSE IF 소음_레벨 > 80dB THEN
    상태 = "이상"
ELSE
    상태 = "정상"
```

## 4. 학습 후 예상 결과

### 4.1 학생들이 이해하게 될 내용

```
✅ Level 1: 기초 이해
   - 센서가 물리량을 어떻게 측정하는지
   - 아날로그 → 디지털 변환 원리
   - ESP32 기본 사용법

✅ Level 2: 중급 이해
   - 데이터에서 특징을 추출하는 방법
   - 정상/비정상 패턴 구분 원리
   - 간단한 임계값 기반 판단

✅ Level 3: 심화 이해
   - 머신러닝 기초 개념
   - 시계열 데이터 분석
   - 예측 모델의 원리
```

### 4.2 실습 후 할 수 있는 것

| 실습 내용 | 기대 결과 |
|-----------|-----------|
| 센서 연결 | I2C, ADC 통신 이해 |
| 데이터 수집 | 실시간 진동/소음 측정 |
| 특징 추출 | 통계적 특징 계산 |
| 상태 판단 | 정상/이상 자동 분류 |
| 시각화 | 그래프로 데이터 표시 |

### 4.3 실험 시나리오

**실험 1: 선풍기 이상 감지**
```
1. 정상 작동하는 선풍기에 센서 부착
2. 정상 상태 데이터 수집 (학습 데이터)
```

### Arduino IDE 설정

```cpp
// 라이브러리 설치 (Arduino IDE)
// 1. Wire (내장)
// 2. MPU6050 (라이브러리 매니저에서 설치)

#include <Wire.h>
#include <MPU6050.h>

MPU6050 mpu;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  mpu.initialize();
}

void loop() {
  int16_t ax, ay, az, gx, gy, gz;
  mpu.getMotion6(&ax, &ay, &az, &gx, &gy, &gz);

  // 데이터 출력
  Serial.print("가속도: ");
  Serial.print(ax); Serial.print(", ");
  Serial.print(ay); Serial.print(", ");
  Serial.println(az);

  delay(10);  // 100Hz 샘플링
}
```
