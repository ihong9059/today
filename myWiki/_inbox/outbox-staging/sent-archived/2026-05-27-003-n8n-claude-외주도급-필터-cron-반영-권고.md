## §4. n8n cron 09:00 워크플로 반영 권고

### 권고 1 — 외주(도급) 필터 페이지 1차 노드 추가

기존 cron 09:00 워크플로 (ID sequential 검색만)에 **HTTP Request 노드 1개 선행 추가**:

```
[Schedule 09:00]
  ↓
[HTTP Request] GET https://www.wishket.com/project/?employee_type=projc_term  ⭐NEW (1차)
  ↓
[HTML Extract] 첫 페이지 ID·제목·단가·기간·근무 추출  ⭐NEW
  ↓
[Code/Function] 외주 후보 카테고리 분리
  ↓
[기존 ID sequential 검색 노드]  ← 2차/보조
  ↓
[Notion 입력 + Email 발송]
```

### 권고 2 — 비공개 redirect 인지 처리

HTTP Request 응답이 PRIME/PRO/BOOST 한정 매칭이면 **목록 페이지로 우회 검색** + Notion 메모 필드에 "비공개 본문 — 목록만 노출" 박제.

### 권고 3 — ID 채번 패턴 검증 로그

n8n 워크플로 측에서 매일 외주 풀 첫 페이지 ID 시계열을 SQLite/Notion에 박제 → ID 비단조 가설 검증:
- 외주 풀 별도 채번 가설
- 비공개→공개 전환 시 옛 ID 재노출 가설

→ 1주~1개월 데이터 축적 후 mywiki에 패턴 인계 카드 발송.
