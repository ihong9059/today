## §2. 신규 gotcha (3건)

### gotcha 1: 모니터 직접 작업 ↔ ssh 자동 인증은 별개
- 증상: 사용자가 rpi4 모니터·키보드 앞에서 직접 작업했다고 해서 Windows PC ↔ rpi4 ssh가 자동 인증되지 않음.
- 원인: Windows PC의 공개키가 rpi4 `authorized_keys`에 등록되지 않으면 publickey 인증 실패. password 인증은 ssh의 non-interactive 환경에서 자동 전달 불가.
- 대응: 사용자가 PowerShell에서 password 1회 입력해서 공개키 등록. 그 후 자동.
- → myWiki/`gaps.md` 또는 `gotchas/` "원격 작업 = ssh + 모니터 직접 별도 셋업" 1줄 박제 권장.

### gotcha 2: PowerShell `<` 리다이렉트 함정 (큰따옴표 안에서도 검사)
- 증상: `ssh host "echo OK_$(wc -l < ~/.ssh/authorized_keys)"` → PowerShell이 `<`를 자기 stdin redirect로 해석해서 파싱 에러 (`'<' 연산자는 나중에 사용하도록 예약되어 있습니다`).
- 원인: PowerShell 5.1의 `<` reserved operator. 큰따옴표 내부도 검사.
- 대응: `wc -l file`(인자 전달) 또는 `cat file | wc -l` 사용. ssh remote 명령에서 `<` 절대 사용 금지.
- → myWiki `gaps.md` 또는 `gotchas/PowerShell-함정.md`에 박제 권장 (PowerShell 일반 워크플로우에 영향).

### gotcha 3: ARMv8.2-A SIMD 옵션은 rpi5만, rpi4 빌드 실패
- 증상: rpi5 06 후보의 `-march=armv8.2-a+dotprod`는 rpi4에서 illegal instruction.
- 원인: rpi4 Cortex-A72는 ARMv8-A baseline, asimddp(INT8 dotprod) 없음.
- 대응: rpi4 최대 `-march=armv8-a`. asimddp 활용 측정은 rpi5/tablet/smartphone 전용.
- → myWiki는 ARM 일반 패턴이라 박제 불요. 본 vault 내부 함정으로 보존.

## §3. 신규 decision (4건)

### decision 1: W5 일정 1개월 앞당김 — 5 보드 중 3 보드 5/19 완료

### decision 2: ⭐⭐ Round 6 가설 — "같은 gcc 환경 ARM 1세대 = 1.75×, CNN cache +0.41×"
- 본 vault에서 5/18 시작 이래 Round 1~6 가설 변천:

- 의미: 본 vault 측정의 진짜 변수 = 컴파일러 + ARM 세대 + (CNN 한해) L3 cache. 6-way 환경 7.8× 차이 모두 분해.
