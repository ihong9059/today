# [done] 누수 자동 알림 룰 — 기술 로드맵 평가

요청(2026-07-12-001) 검토 완료. 단일출처 = `수조제어_펌웨어/11_누수자동알림룰_기술로드맵.md`.

## 5포인트 답

1. **연산 위치 = RPi 대시보드(golf_bridge) 후처리. 확실.** 판정에 필요한 원자료(수위 시계열 `/level` CSV 3일 영속 + 펌프 ON/OFF `/pump`)가 이미 RPi에 모임. **노드 펌웨어 무변경**(저전력·현장 배포 이미지·재flash 리스크 0) = 결정적 이득. 노드는 자기 수조·자기 pump만 알아 부적합. LTE 게이트웨이는 경보 전송만.

2. **판정 로직**: `(펌프 OFF & 관수 OFF)` 구간만, 슬라이딩 관측창 W(30~60분) Δ수위/Δt > R_th & 지속 T_min & 유효샘플 N → 경보. 오탐 분리 = RS485 0cm 글리치 필터(기존 dry-run 디바운스 선례 재사용)·증발은 관측창 크게·하강만 평가. **⚠️ 결정적 한계 = 관수(스프링클러) 살수 여부 미계측**이면 OFF 구간에 구멍 → 관수 스케줄/컨트롤러 상태/유량계로 선결 필요. **이 선결 없이 "무오탐 완전 자동"은 과장** — "SW 로드맵" 문구 유지 정당.

3. **임계값**: 1단계 고정 임계(부피율 L/h = 단면적×하강률로 현장편차 정규화) → 2단계 baseline 자가학습(OFF 구간 정상 하강률 분포 평균+Nσ). **CSV 이력 이미 축적 중** → 후향 분석으로 baseline 산출 가능(추가 계측 불요).

4. **경보 채널**: 대시보드 시각경보(즉시) + 서버 push 이메일/Telegram(소공수, 현 스택 재사용, 비용 0). SMS는 외부 유료 API 필요.

5. **난이도·우선순위 = 양산 단계 착수 권장**(즉시착수 아님). MVP(고정임계+대시보드 경보)=공수 **소**(순수 후처리 함수, 노드 무변경). 기존 golf_bridge `/level`·`/pump` 자산 재사용. **양산 단계인 이유 = 관수 상태 계측 선결**이 오탐 없는 "자동 예방정비" 클레임의 전제.

## 영업 자료 정합
- "누수 자동 알림 룰 = SW 추가개발 로드맵" 문구 **유지 정당**(현=육안 판단).
- 승격 조건 = ① 관수 상태 계측 확보 ② 고정임계 MVP 배포 → 이후 "자동 예방정비" 클레임 승격.
- 기술 실현성 = **높음**(RPi 후처리·자산 재사용) / 유일 리스크 = **관수 상태 미계측 오탐**.
