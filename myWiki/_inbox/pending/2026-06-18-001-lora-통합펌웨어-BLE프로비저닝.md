# LoRa 기술 근거 — 단일 binary 통합 펌웨어 + BLE 프로비저닝 (사업방향 흡수 요청)

본 vault(lora)에서 한림 수조망 **최종 시스템 구성 확정 + 통합 펌웨어 + 스마트폰 BLE 프로비저닝 앱**을 실보드 실증. 사업방향에 흡수할 재사용 기술 역량·결정 근거 cascade.

## 신규 기술 역량 (decision 근거)

1. **단일 binary 통합 펌웨어** — 중계기·sensor·on/off 3역할을 1개 펌웨어에 통합, 부팅 시 NVS의 role 읽어 분기. 보드별 재빌드 0. nRF52832에 **BLE+NVS+LoRa 통합 빌드 적합 실증**(FLASH 27.6%·RAM 66.1%). → `검토/16_통합펌웨어_BLE설정/`
2. **BLE 프로비저닝으로 OTA 설정** — 스마트폰 앱이 BLE GATT로 role+address 주입 → LoRa addr-set(동시충돌 함정) 폐기. **부팅 분기·역할 진입·폰 재프로비저닝 실보드 end-to-end 실증**. Native Android(Kotlin) 앱 빌드·설치(SM-M536S) 완료.
3. **한림 최종 시스템 아키텍처 3패턴** (공장 자동화 재사용 가능):
   - **폐쇄공간 단말 → open 단말 intra-relay** (on/off 펌프실 RF 약함 → sensor가 청취·재발신, 2단 중계)
   - **ACK-도청 명령전달** (master→sensor 명령, sensor ACK가 opcode echo, on/off가 청취 실행 — 메시지·링크 절약)
   - **로컬 자율제어 우선** (현장 단말이 스스로 판단, 원격은 보조 override — 통신두절에도 안전)

## 사업 함의

"단일 펌웨어 + BLE 현장 설정" = **양산·현장 배포 비용 최소화**(보드 1종 굽고 앱으로 역할 지정). "폐쇄공간 intra-relay + ACK-도청 + 로컬우선"은 **밀폐 설비 내 액추에이터 제어**(공장 자동화) 그대로 재사용 가능한 패턴. UTTEC LoRa 제어망 제품화 narrative 근거.
