# LoRa 표준단말 시스템 구성 확정 — 사업방향 흡수 요청

## 컨텍스트

JLCPCB 발주한 "lora relay module"(RAK4630) 기반 전체 LoRa 시스템 구성을 사용자가 확정했다. 단일 제품을 넘어 **다현장 배포 플랫폼**으로 방향이 굳어져, 사업방향에 반영할 근거가 생겼다. 기술 상세·검토 단일출처 = `표준단말_플랫폼/10_시스템구성_검토.md`.

## 요청 / 정보 (사업 함의 있는 확정 사항)

1. **시스템 = 3계층 체인**: 현장 LoRa 센서 → RAK gateway 모듈(RS485+릴레이+배터리+솔라) → 백홀(실내=RPi wifi / 실외=Thingy:91 LTE+GNSS) → 클라우드. 백홀 Thingy는 자체 검증 완료(LTE+GNSS+BLE 무선중계).
2. **사용자 확정 3건**:
   - **고정 설치** → 위치는 커미셔닝 1회 확보(상시 측위 불요).
   - **전부 RAK로 통일** → 전 노드 동일 플랫폼(SX1262), 기존 E22 사이트는 사이트 단위 일괄 교체.
   - **사이트 수십 개 규모** → 단일 설치가 아닌 fleet 운영.
3. **사업방향 신호(myWiki 흡수 대상)**:
   - **국내 M2M SIM 대량조달 필요**(SKT LTE-M Cat.M1, 단일 계약·대시보드·청구) — 수십 LTE 회선은 trial SIM 불가. 양산 전제 조달 트랙 착수 시점.
   - **Fleet 관리 인프라 필요**(중앙 대시보드·원격 OTD·사이트별 config) — 제품 외 운영 역량이 수익/유지보수 구조에 직결.
   - 표준단말이 UTTEC LoRa 사업의 **범용 플랫폼**으로 수렴 중(한림 수조·조명 등 기존 현장을 이 플랫폼으로 통합 가능).

## 기대 처리

myWiki 측에서 위 신호를 사업방향 노트(제품 플랫폼화·M2M 통신 조달·fleet 운영 역량)에 흡수. 기술 상세는 본 vault가 단일출처로 유지하므로, 사업 레벨 결정·우선순위만 cascade 바란다.
