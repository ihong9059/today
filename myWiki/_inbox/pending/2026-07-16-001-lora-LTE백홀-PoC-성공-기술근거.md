# LTE 백홀 게이트웨이 PoC 성공 — 영업 기술 근거

## 요청
아래 기술 실증 결론을 myWiki **영업/사업방향 근거**로 흡수 요청. (신규 골프장 영업 시 "인터넷 없는 원거리 현장도 커버" 판매포인트의 기술 backing.)

## 무엇을 실증했나 (2026-07-16, lora vault)
- **Thingy:91 X**(Nordic nRF9151 완제 셀룰러 보드)로 **LoRa 센서 데이터를 LTE로 원격 서버에 전송하는 경로를 end-to-end 실증.**
- 경로: `LoRa 센서 → master → RPi → (USB) → Thingy:91 X → LTE-M(KT Korea 로밍) → 인터넷 → 서버(HELLO/IMEI 파싱 확인)`.
- 국내 **KT LTE-M 망 로밍 등록·데이터 통신·서버 수신** 전부 확인 (RSRP −80dBm).

## 영업 함의 (사업방향)
1. **인터넷 없는 원거리 골프장 현장(고수조·pond·외곽)도 커버** — Wi-Fi/유선이 안 닿는 곳에 **셀룰러 백홀**로 모니터링·제어 데이터 상납 가능. = LoRa 자율제어 + 원격 가시성.
2. **완제 보드(Thingy:91 X)로 빠른 PoC** — 커스텀 PCB 없이 배터리·안테나·SIM 내장 보드로 즉시 실증. 양산은 nRF9151 SiP.
3. **비용 최적 = Wi-Fi/LTE failover** — AP 있으면 RPi가 직접 인터넷(셀룰러 데이터 0), 없을 때만 LTE. 요금 최소.
4. **데이터량 극소**(1h 소량 업링크=월 수십MB) → 국내 IoT 최저 요금 구간으로 저렴.

## 정직 고지 (한계)
- 현재 **PoC 단계**(프리빌트 펌웨어·트라이얼 SIM). 양산 = 국내 **SKT LTE-M M2M 회선**(사업자등록·단말인증·MFF2) 필요.
- GNSS는 부팅 1회 위치 태깅용(고정 게이트웨이라 실시간 불요).
