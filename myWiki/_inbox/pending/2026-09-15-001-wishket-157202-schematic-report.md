# #157202 회로도 실사 완결 + 기술검토보고서 PDF 완성 — RK3588 1순위 전환

## 변경 내용 (본 vault에서 한 일)

3세션 대기하던 **#157202 전자교탁(보은전자통신 BSC-2000-A) 회로도가 수령**되어, 당일 실사 + 송부용 보고서까지 완결했다. 미팅(9/3) 합의 절차의 2·3단계 이행.

1. **실사 67면 전량**: 회로도 6종 26면 + 사양서 5면 + 매뉴얼 36면. 확정 = DM8148 + DDR3 1GB 단일채널 + STM32F207ZET6/F105RC 2칩 제어 축 + 1080p60 상한.
2. **핵심 발견**: ① 방송·녹화(DM8148) 보드 = **옵션 모듈** → 재개발이 "전면 재설계"가 아니라 **"보드 1장 교체"**로 축소 확정. ② 단종 5칩(DM8148·MDIN380·Sil9135A×2·Sil9134)이 병렬 YCbCr 인터페이스에 묶인 체인 — 교체 정당성 강화.
3. **보고서 진화**: md 상세판 → 사용자 "직관적이지 않음" 피드백 → **HTML 시각화판**(색상 코드 블록도: 유지/개정/교체/신규 + before/after 신호 흐름도) → **PDF 6p** (Type3 0·마스킹 0·색상 보존). 송부 대기.
4. **사용자 결정: SoC 1순위 i.MX 8M Plus → RK3588 전환.** 전제 조건 명문화 = 공급보증 10년+ 산업용 SOM 계약 + 전략 재고. 조달 소싱 제약 확인 시 i.MX 대안 전환 조항을 확인 요청 5번에 내장 (조달 방어선이 보고서 안에 있음).
5. 확인 요청 5건 동봉 — 회신 = 최종 보고서(견적·일정) 착수 트리거. 절충안(1단계 SW로 특허·조달 먼저 → 2단계 보드 스왑) 정식 권고.
