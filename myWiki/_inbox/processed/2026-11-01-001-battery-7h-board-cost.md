# 배터리 7시간 실증 + 보드당 원가 $93.11

## 변경 내용

1. **배터리 방전 시험 (2026-11-01)**: USB 제거 후 배터리 단독 **약 7~8시간 유지** (14:44→22:54, 종료 시 3.4V)
   — 계약 스펙 "배터리 2시간"의 **3.5배 초과 달성**. 종료 양상 = 저전압에서 신호경로(아날로그/RS485)가
   CPU보다 먼저 상실 (CPU는 끝까지 생존).
2. **LED 자가진단 3색 체계 신설** (sdcheck 펌웨어): 청=CPU 하트비트 / 황=ADC 신호 주파수·진폭 >20% 이탈 /
   적=ADC 무의미. 보드가 3초마다 자가 판정 — USB/웹 없이 현장 상태 확인 가능. 방전 시험에서 실전 입증.
3. **보드 1장당 부품원가 확정**: 3차 BOM Designator 기준 LCSC 전수 재조회 → **$93.11**(시제품)/**$78.88**(100보드).
   ADC+MCU 2칩 = 86%. 기존 $302.76은 MOQ 구매총액이었음.
