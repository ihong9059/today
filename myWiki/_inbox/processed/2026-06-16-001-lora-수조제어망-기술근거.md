# LoRa 기술 근거 — 골프장 수조 control·monitoring 제어망 (사업방향 흡수 요청)

본 vault(lora)에서 골프장 수조 LoRa 제어망의 **프로토콜 설계 + 실보드 송수신 실증 + 배터리 모니터링**을 확보. 사업방향에 흡수할 기술 역량·결정 근거 cascade.

## 신규 기술 역량 (decision 근거)

1. **수조 제어망 프로토콜 설계 완성** — 단일채널·1바이트 주소(master=00·중계=01·센서/동작=10/11~50/51·broadcast=0xFF)·**고정 8바이트 frame**(STX·SRC·DST·TYPE·DATA1·DATA2·DATA3=SEQ·CRC8)·3종 category(status/cmd/addr-set)·일일 sync TDMA. → `망구성/한림_수조_LoRa_프로토콜.md`
2. **LoRa 8B frame 실보드 송수신 실증** — TX(PCA10056, 배터리 ADC→frame→E22 송신)↔RX(PCA10100, 수신·CRC검증·display). SEQ 일치·CRC OK 무손실 확인. → 양산 제어망 PoC 검증 1호.
3. **무인 노드 배터리 모니터링** — nRF52832 SAADC 절대측정으로 Li-ion 4.2V 측정 기술 확보 (status frame DATA2 통합).

## gotcha (재사용 자산)

- **⭐ SW-UART 115200 + LoRa HW UART 동시 → main 스택 오버플로우** (hang, fault dump 없음). `CONFIG_MAIN_STACK_SIZE` 증설 필수. 오진(SPIM↔UARTE 충돌) 주의 — 실제는 스택.
- **⭐ 배터리 4.2V 측정 = 내부 0.6V 절대기준 + 1/2 분압 + ×2 필수.** VDD/4 ratiometric(~3.3V)·VDD 직접읽기(3.6V)는 천장이라 불가.
- **nRF52832 4.2V VCC 직결 금지** (동작 1.7~3.6V·절대최대 3.9V 초과, nRF52840 VDDH 5.5V와 다름) → 레귤레이터 경유.
- **flash = nrfjprog 직결** (JLink.exe 미설치 시 `west flash --runner jlink` 실패).

## ⭐ 사업방향 매칭 패턴 (전략 함의)

**저비용 LoRa 제어망 아키텍처가 양산 직전 단계까지 검증됨.** 함의:
- 단일채널 + 1바이트 주소 + 일일 sync TDMA = **게이트웨이 의존 최소화한 자율 제어망** — 센서가 동작(pump)을 그룹 폐루프로 직접 제어, master는 monitoring(rpi3)만. 한림 외 SI 시공·공장 자동화에 재사용 가능한 토폴로지.
- 8B frame + SEQ = **PER 실측 + 중계 dedup** 기반 마련 (이전 CubeCell 스니퍼의 PER 산출 불가 교훈 반영·교정).
- 무인 노드 배터리 모니터링 + 솔라 전원체인([[검토/11]]) = **원격 무인 노드 사업** 기술 근거.
- → 차기: E22 config 하드닝 + 다중 노드 TDMA 실증 + 실배터리 분압 적용.
