# 한림 조명 pole 개별제어 영업 트랙 — 사업방향 흡수 요청

## 무엇이 생겼나 (신규 decision/entity)

한림용인CC가 조명제어를 **pole 단위 개별제어로 전환 검토 중** (전기료 절감 목적). 전제 = 380V 3상 · LED 투광등 · pole당 6kW · **약 200 pole**. lora vault에서 기술검토 → 제출 세트 2종 발행 완료 (2026-10-25):

1. **견적서** — LoRa Terminal Box(표준단말 RAK4630 + 전자접촉기 MC-22b + SMPS + IP66 외함, 조립검사 완료품) 200대: **A안 대당 20만=4,000만 / B안(MC-32a+MCB+SPD) 대당 26만=5,200만** (VAT·설치 별도).
2. **ROI 검토서** — 마지막 팀 단계소등 모델: **기준 연 절감 ≈4,620만원(조명 전력량요금 ~20%) → 투자 회수 ≈1.2년, 5년 순효익 +1.76억**. 추가 이점 = lamp 수명 ~20% 연장 + 전류측정 이상감지·고장예측(확장 옵션).

## 사업 함의 (myWiki 흡수 포인트)

- **표준단말("LoRa Relay Module") 첫 대량(200대) 수주 후보** — 기존 fleet 3계층 체인(2026-10-17 흡수 완료분)의 현장 적용 1호 규모. 수주 시 JLCPCB 2차 발주 = **RS485 /RE 개정판**으로 진행(기정 결정), RAK4630(재고 118)·HFD3(재고 70) 선확보 필수.
- 골프장 조명 pole 개별제어 = **수조·조명에 이은 표준단말 제3 응용** — 타 골프장(필로스 등) 횡전개 가능한 패키지(견적·ROI 양식 재사용 가능).
- 200노드 단일 사이트 = 기존 조명 mesh 설계 대비 규모 20배 → LoRa 망구성(채널·중계) 설계 과제 발생 (lora vault 후속).
