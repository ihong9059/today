# mac 자산 신규 역량: 스마트폰 원격 접속·세션 (C8)

스마트폰(Galaxy SM-M536S, Android 16, Tailscale 100.109.177.107)에서 mac(uttec@100.90.158.36)으로 **passwordless SSH** 접속 구축. 전과정을 **Windows 콕핏 PC에서 adb로 원격 설정**(폰 화면 터치 없이).

- 폰 Termux: `ssh mac` → 비번 없이 mac 셸, `cm` → `~/vault` tmux claude-vault attach.
- 키: 폰 네이티브 ed25519 생성, 공개키만 mac authorized_keys 등록(SHA256:hYdGmwNB…).
- 검증: mac auth.log `Accepted publickey from 100.109.177.107`.

**횡단 교훈(재현·타 기기 적용 시 유효)**:
1. mac OS 유저 = `uttec` (`ssh mac`=`ssh ubuntu`는 콕핏 PC의 config 별칭일 뿐).
2. adb `input text`는 큰따옴표(`"`)를 누락 → 따옴표/heredoc 든 작업은 **스크립트를 `/sdcard`에 `adb push` 후 `bash` 실행**. Termux는 /sdcard 읽기·쓰기 가능.
3. Windows ssh-keygen 키를 Termux openssh가 거부(`contents do not match public`, 바이트 동일에도) → 키는 **접속 기기에서 직접 생성**해야 호환.

자산 변화: 콕핏 PC에 adb(platform-tools) 상주(gitignore). mac authorized_keys에 phone-termux 키 추가.
