# 자동검토 Gmail 메일 본문 한글 깨짐 수정

어제 보낸 `2026-11-11-001`(위시캣 자동검토→Gmail 스케줄러 구축) 후속. 첫 09:00 실행 메일에서 **본문 한글이 전부 깨져(mojibake)** 도착 → 당일 오전 원인 규명·수정·재발송·검증 완료. 추가 액션 불필요(info/done).

## 변경 내용 (본 vault에서 한 일)
- **증상**: 메일 제목·푸터는 정상, **본문만** 한글 깨짐(`?꾨즺`="완료").
- **원인**: PowerShell 5.1이 claude CLI 출력을 `& cmd /c ... | Out-String` **파이프 캡처**할 때, raw UTF-8 바이트를 **스케줄 작업 콘솔의 OEM 코드페이지(한국어 Windows=CP949)로 오디코딩**. 본문만 깨진 건 제목·푸터가 Python 소스에 직접 쓴 UTF-8이었기 때문. 대화형 콘솔은 CP65001(UTF-8)이라 평소 재현 안 됨.
- **수정**: `run_wishket_check.ps1` 파이프 캡처 → **파일 리다이렉트**(`> rawFile`) 후 `Get-Content -Encoding UTF8` 읽기(콘솔 인코딩 무관), 본문은 BOM 없는 UTF-8 저장. `send_mail.py` 읽기 `utf-8-sig`.
- **검증**: CP949 콘솔 강제 + 코드포인트 비교(파일 리다이렉트 원본 완전 일치, 파이프는 깨짐 재현) + 테스트 메일 사용자 육안 확인 + 실제 `/wishket-check` 재발송(exit0·치환문자 0건).
