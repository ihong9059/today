# 영업용 LoRa 수조제어 기술 근거 팩 (신규 골프장/신규 고객)

## 컨텍스트

사용자가 지금까지의 한림용인CC field 경험·정리사항을 바탕으로 **신규 고객/타 골프장 영업**을 진행하려 함. 영업 활동 자체는 범 사업(myWiki 담당)이므로, 본 vault(lora)는 **영업의 무기가 될 실증된 기술 근거만** 정리해 cascade한다. (vault scope: lora=기술 단일출처 / 영업·제안서=myWiki.)

핵심 메시지: **"게이트웨이·본부 서버 없이 자율 동작하는 저비용 무인 LoRa 수조 제어망이 실제 골프장(한림용인CC 14노드 2단 cascade)에서 양산 적용·현장 실증 단계까지 검증됨."**

## 요청 / 정보 — 영업에 쓸 검증된 판매 포인트

### 1. ⭐ 실증 레퍼런스: 한림용인CC 14노드 2단 cascade (양산 적용 중)
- 2단 cascade: pond → 하수조(저수조) → 고수조(상수조) → 스프링쿨러. 루비 1유닛 + 사파이어 2유닛(고수조 공유) = **14노드**.
- 실제 골프장 현장에 flash·설치·통신 검증 완료 (사파이어 5/9 노드 flash·검증, 나머지 pond는 공사 진행 중).
- **레퍼런스 세일즈**: "이미 운영 중인 골프장 현장"이라는 신뢰 근거.

### 2. ⭐ 자율 제어 아키텍처 — 본부 서버·게이트웨이 의존 최소
- **각 센서가 자기 목표수위(NVS 저장)로 자기 수위를 판단** → 명시적 PUMP_ON/OFF 명령을 LoRa broadcast → 로컬 펌프(onoff)가 즉시 추종.
- 본부의 능동 제어 없이 **현장 노드끼리 폐루프 자율 운전**. 통신 두절에도 fail-safe(펌프 OFF)로 안전.
- **세일즈 함의**: 통신망·서버 인프라 투자 없이 도입 가능 → 신규 고객 진입장벽↓, 유지비↓.

### 3. ⭐ 저전력 + 솔라 무전원 운용 (배관/전원 없는 오지 수조 대응)
- `-DLOW_POWER` duty-cycle 절전으로 **소비전류 12mA 수준까지 실측 최적화** (ESB 절전 버그 수정 22→12mA). 추가 절감(DCDC/UARTE 서스펜드) 진행 중.
- battery + solar 전원체인 → **상용 전원 없는 원격 수조에 무선·무전원 설치 가능**. solar 패널 용량 산정 근거 확보.
- **세일즈 함의**: 전기 인입 공사 불가/고비용 지점도 커버 → 골프장 외곽 pond·중계 노드 사업성.

### 4. 통합 제품 스택 — 센서·통신·제어·모니터링 일괄
- **RS485 수위센서(Modbus)** 읽기 + **LoRa 백홀**(장거리) + **2.4G 로컬링크**(그룹 내 펌프 즉시제어)를 단일 nRF52832 펌웨어로 통합 (UARTE PSEL time-mux).
- **현장 BLE 프로비저닝 앱**: 단일 펌웨어 이미지 + 앱으로 역할·주소·목표수위 현장 설정 → 노드 종류별 재빌드 불필요, 설치·유지보수 단순.
- **원격 모니터링**: RPi 웹 대시보드(수위/배터리 2일 차트 실시간) + nRF9160 LTE 게이트웨이(원격지 백홀, GPS 위치보고 옵션).
- **세일즈 함의**: 센서→제어→가시화까지 "턴키" 제공 가능.

### 5. RF 링크 실증 데이터 (신뢰성 근거)
- CH72 공유, PER 0% RF 링크 검증(통신점검 도구로 실측), RSSI 마진 데이터 확보.
- **폐쇄공간(문 닫힘) 조건에서 2.4G 로컬링크 통과 실증** (설계 우려점을 현장 데이터로 해소).
- **세일즈 함의**: "실측 데이터로 커버리지 보증" 가능. 단, 마진 얇은 경계 지점 존재 → 안테나 배치 컨설팅 포함 필요.

## ⚠️ 정직 고지 (영업 리스크 — myWiki가 제안 범위 판단 시 반영)

기술 단일출처로서 과장 없이 전달:
- **LoRa 채널 충돌 한계**: CH72 단일채널 공유·TDMA 미구현 → 노드 수 증가 시 프레임 충돌로 loss% 상승(사파이어 14노드 = 루비보다 심함). 대규모 현장은 **트래픽 절감/TDMA 적용이 선결**. → 신규 대형 현장 영업 시 "규모 상한·중계 설계"를 제안에 반영해야 함.
- **커버리지 경계 마진**: 안테나 제거 시 즉시 두절되는 경계 지점 존재 → 현장 사전 RF 서베이·안테나 배치가 도입 품질을 좌우.
- **RS485 센서 개체·결선 편차**: 현장 센서 하드웨어/결선에 따라 무응답 사례 있었음 → 설치 SOP·현장 점검 도구(bleModule 보드점검·RF 링크 점검) 필수 동반.

이 3가지는 **약점이 아니라 "제대로 설계·시공하면 해결되는 엔지니어링 변수"**로, 영업 시 오히려 기술 신뢰도(정직·컨설팅 역량)로 전환 가능.

## 처리 후 응답 형식

myWiki에서 흡수 후:
- 이 기술 근거를 신규 골프장/신규 고객 **영업 자료·제안서 톤**으로 재구성 (범 사업 관점).
- 필요 시 추가 기술 근거(특정 수치·도달거리 실측·BOM/원가·타 골프장 적용 시나리오)를 본 vault에 `request` 카드로 역요청 → lora가 기술 상세 회신.
