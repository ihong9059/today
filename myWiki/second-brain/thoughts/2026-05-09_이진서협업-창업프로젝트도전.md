# 이진서 협업 — 「모두의 창업 프로젝트」 도전

## 핵심 인사이트

> **사업년수 10년의 한계를 협업으로 돌파한다.**
> UTTEC이 못 받는 청년창업 지원사업을, 이진서 명의 신규 법인으로 받는다.
> 단순 명의 빌리기가 아니라, **응원단장 출신 + 영상 풀세트 + 마케팅 인턴** 강점이
> AI FanStick의 부족한 부분(사용자 인사이트·콘텐츠·B2C 마케팅)을 정확히 보완한다.

## A + B → C 패턴

### A. UTTEC의 갭 (gaps.md 기존 항목)
- **사업년수 10년 → 청년창업 지원사업 거의 모두 자격 미달** (예비창업패키지·청년창업사관학교·초기창업패키지)
- B2C 마케팅·콘텐츠 유통·SNS 운영 역량 부족
- 1인 의존 구조 (교육·제품·팩토리 3개 사업)
- AI FanStick 특허·MVP는 있지만 D2C 채널 미구축

### B. 이진서의 자산 (포트폴리오 분석)
- **만 25세 + 사업자등록 없음 = 청년창업 지원사업 자격 100%**
- **응원단장 9년 운영** (7대 단장 + 6대 기획단장 + 공대 홍보전략국장)
- 수학 강사 8건 + **수학대왕 그로스 마케팅 인턴**
- Adobe CC 풀세트 + AI 영상툴(Suno·Luma·Higgsfield) + 영상팀장 2회 + 인스타 스낵툰
- 서울대 전 단과대 인맥 (음악대·미술대·엔터)
- 본인 비전 = "락 기반 미디어 커뮤니티 회사" (응원봉 사업과 직접 정렬)

### C. 새로운 판단
> **AI FanStick = "양산 정지선 잠금 + 신규 법인 창업 도전" 두 트랙 분리 운영.**
> 양산은 스마트폰 Gemma 2B 하이브리드 (5/8 결정 유지),
> **창업 트랙은 응원봉 본체 + 팬덤 미디어 플랫폼**으로 신규 법인 도전 (5/9 결정).

**A안 채택 이유:**
1. 이진서 매칭 + UTTEC 자산 + 시장 차별성 + 임팩트 모두 만점
2. 특허 + MVP 보유 → 1R 즉시 시연 가능
3. 블루오션 (검토서 검증 완료)
4. 4R 대국민 IR에서 응원봉 라이브 시연 = 화제성 폭발

## 검토서가 놓친 핵심 발견 4가지

(2026-05-02 작성 협업 검토서가 미반영한 강점)

1. **응원단장 직접 운영 경력** — 검토서는 "음악 관심"으로만 평가. 실제는 9년 운영 + 단장 + 기획단장 + 홍보전략국장
2. **수학 교육 + EdTech 마케팅 인턴** — 검토서 누락. 수학대왕 그로스 마케팅 인턴은 B안의 결정적 자산
3. **영상·콘텐츠 풀세트** — Adobe CC + AI 영상툴 + 영상팀장 2회 + 인스타 스낵툰 = 외주비 0원으로 모든 콘텐츠 자체 생산
4. **본인 최종 비전** — "락 기반 미디어 커뮤니티 회사" 명시 → A안과 직접 정렬, 장기 몰입 보장
