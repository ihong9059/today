# 산업 PLC 통신 역량 = 해자 → 데이터로거 외주의 제어시스템 격상

> [사실 A] #157744는 "산업 센서 3종 읽어 로컬 DB 저장하는 PC 프로그램"(제어 배제, Tier 1급 로거)으로 지원한 건이었다.
> [사실 B] 8/31 대면 미팅에서 발주사 실물이 미쓰비시 FX3U-16M + FX2N-1HC(고속카운터)로 드러났고, UTTEC가 **FX3U MC Protocol로 카운트를 직접 읽는 산업 통신 역량**을 제시하자 스코프가 **PLC 전면 대체(PC제어+HMI, 최대 5,000만)**로 3단계 확장됐다.
> → [판단 C] **산업 PLC 프로토콜·전기 안전·현장 검증은 순수 SW 외주업체가 못 넘는 해자다. 데이터로거·모니터링 요구가 들어오면 "제어까지 대행"으로 객단가를 10배(2,000만→5,000만) 확장할 수 있다.**
> → [행동 D] PC 프로그램/데이터 수집/HMI 요구 외주는 **처음부터 "PLC 연동·대체 가능"을 제안 카드로 준비**한다. 단, 자체 실시간 제어부·현장 안전은 리스크가 크므로 벤치/현장 2단계 분리 견적으로 격리한다.

## 왜 해자인가

| 계층 | 순수 SW 외주업체 | UTTEC |
|---|---|---|
| PC앱·DB·GUI | ✅ 가능 | ✅ (C#/C++ 데스크톱앱 양산 자산) |
| 산업 PLC 통신(MC Protocol·Modbus·EtherCAT) | ❌ 도메인 밖 | ✅ [[uttec-plc]] 자산 |
| 센서 FW·회로·계측 | ❌ | ✅ 38년 임베디드 |
| 전기 안전·KC·현장 시운전 | ❌ | ✅ 양산 인증 트랙 |

= **수직통합(센서→FW→PLC통신→PC앱→HMI→안전검증)이 그 자체로 진입장벽**. 발주사가 "SW만 하는 곳"과 비교할 수 없는 지점.

## upsell 패턴 (일반화)

데이터 가시성 요구 → 제어 대행 제안의 사다리:
1. **로거**(읽기·표시·저장) = 진입 (Tier 1)
2. **모니터링 + 기존 PLC 연동**(축1, 2,000만) = 통신 역량 증명
3. **PLC 대체 PC제어 + HMI**(축2, 5,000만) = 해자 실현

핵심 = 미팅에서 **실물 PLC/설비를 규명**하는 순간 사다리를 제시. "산업용 PC/HMI = OS 개방성 우선"(개방형 Windows여야 C#/C++ 구동, Advantech TPC 권장)이 재사용 선정 기준.
