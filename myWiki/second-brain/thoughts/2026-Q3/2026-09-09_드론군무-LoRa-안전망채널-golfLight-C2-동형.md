# 드론군무 LoRa — "안전망 채널" 포지션 + golfLight C2 동형 이식

## 복리 패턴

```
[사실 A] golfLight 스택 = 1 master → N단말 broadcast + ACK재전송 + fail-safe (한림·필로스 양산 검증)
[사실 B] 드론쇼 통신 = 사전 안무 + 자율비행 → "적은 데이터를 멀리 확실하게" (시간동기 = GPS 시각 → 레이턴시 무관)
[판단 C] 드론 관제 C2 계층 = golfLight와 동형 → 개발량 최소로 신규 시장 진입 가능 (ai-direction 결정 65)
[행동 D] 옵션 B "비상 안전망 전용 채널"로 조대홍 client 협의 게이트 진행 (설명자료 PDF 전달 완료)
```

## 핵심 인사이트 1 — 포지션: 주 스택과 싸우지 않는다

기존 드론쇼 사업자는 자체 주 통신 스택을 보유 — 정면 대체 제안은 교체 비용·검증 부담으로 진입장벽이 높다. **옵션 B = 주 통신 장애 시 독립 "전체 착륙" 명령을 보장하는 비상 안전망 전용 채널**은 기존 스택과 경쟁하지 않고 **보완**한다. "안전"이라는 명확한 셀링포인트 + 독립 채널이라 기존 시스템 무수정 = **"돌아가는 것 무수정 + 부족한 부분만 추가" 문법(결정 64 노후 설비 현대화 클러스터)과 동일한 진입 문법**이 신규 응용에서도 재현된다.

## 핵심 인사이트 2 — 검증된 스택의 응용 도메인 횡단 이식

수조(한림) → 조명(필로스) → 드론 C2 후보까지, 동일 뼈대(broadcast·ACK·fail-safe)가 세 번째 도메인으로 이식 시도되는 사례. [[lora]] hub가 기술 근거 단일 출처로 있어 "응용마다 재개발"이 아니라 "포지션·규제만 재검토"로 진입 비용이 수렴한다 — vault 전략(결정 51~65 누적)의 복리 효과.

## 게이트 (확정 전 금지 조건)

1. **조대홍 client 협의** — 실수요 검증 (PDF 전달 완료, 결과 대기)
2. 🔴 **KR920 EIRP/LBT 정식 조사** — 드론 고도 = 간섭 footprint 폭증, E22 22dBm 초과 가능성 ([[gaps]] § 2026-09-09). 조사 전 사업 확정 금지.
3. 항공 규제는 운영사 영역으로 계약상 선긋기.

## 후속

- 협의 긍정 시: KR920 조사 → 옵션 B PoC 범위 정의 (lora vault 소관)
- 인맥 접점(드론쇼·방제드론 수요) 역방향 공유 = 사용자 결정 대기
