# STM32 프로세서 선정 영업논리 (재사용 자산)

> **A(#157208 발주사 우대 "N6 수준 듀얼코어 HW가속") + B(#157235 담당자 "H723 100Hz → V863 검토")
> → C(프로세서 선정은 스펙 숫자가 아니라 application class로 판단) → D(검증된 H7 1순위 + 최적화 우선 영업 카피 표준화)**

위시캣 계측/DAQ 2건(#157208·#157235)에서 발주사·담당자가 **상위 실리콘 = 성능 향상**이라는 개념 혼재를 보였다. 이를 정정하는 논리가 재사용 가능한 영업 자산이라 박제한다. [[ai-fanstick]] "AI 가속 칩 = application class 판단"([[2026-05-22_npu-vendor-광고-실측-격차]]) 논리의 계측 도메인 연장.

## 1. "N6 수준 듀얼코어 HW가속" 개념 혼재 (#157208)

| 오해 | 정정 |
|---|---|
| N6 = 듀얼코어 고성능 | N6 = **단일 Cortex-M55 + Neural-ART NPU**(AI 추론 전용, 듀얼코어 아님, 내장 Flash 없음) |
| 듀얼코어 = 우리에게 필요 | 진짜 듀얼코어(M7+M4) = **STM32H745**(UTTEC 실적) |
| 고속 무손실 수집에 NPU 필요 | **무손실 수집엔 NPU 불필요** → 검증된 **H7 1순위** |

**결정축** = "상위단에서 데이터를 어떻게 쓰나"(단순 수집 vs on-device 추론). AI 추론이 없으면 NPU는 놀고, 검증된 H7이 이긴다.

## 2. "상위 실리콘 교체 = 알고리즘 속도 향상" 오해 (#157235)

담당자 문의: H723 100Hz 처리 → STM32V863 검토. 결론:

- **H745/H747 교체 ≠ 속도 향상** — M7 480MHz < H723 550MHz + H7의 **CORDIC/FMAC 가속기 상실**. 듀얼코어는 단일코어 연산을 빠르게 하지 않는다(오프로드일 뿐).
- **진짜 연산 도약 = Helium(MVE) 벡터엔진** — Cortex-**M55**(STM32N6) / **M85**(STM32V863). N6는 NPU까지 내장·양산中(즉시 구매). V863은 OEM Q1 2026·보드 coming soon·가격 미공개·NPU 없음 = **조달 리스크**.

## 3. 성능 향상 3레버 (권장 순서)

1. **코드 최적화** — CORDIC/FMAC · CMSIS-DSP · TCM 배치 (**1.5~3배**, 실리콘 교체 없이). 1순위.
2. **듀얼코어 오프로드** — M7 연산 / M4 I/O·수집 분리.
3. **상위 실리콘** — Helium(M55/M85) 또는 NPU(N6). 조달·비용·재검증 리스크 동반, 최후.

## 재사용 카피

- "듀얼코어/NPU/상위 MCU가 곧 성능이 아니다 — **application class(수집 vs 추론)와 병목(연산 vs I/O)**을 먼저 규정한다."
- "검증된 실리콘(H745/H7) + 코드 최적화가 미검증 상위 실리콘 교체보다 빠르고 싸고 안전하다."
- 계측·DAQ·엣지AI MCU 선정 공고의 표준 카피로 재사용. 근거 자산 = [[양산제품]] STM32H7 고속 DAQ + [[stm32h745-disco]].
