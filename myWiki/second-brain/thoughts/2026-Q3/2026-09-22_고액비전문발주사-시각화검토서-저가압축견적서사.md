# 고액·비전문 발주사 설득 문법 (#157202 전자교탁 재개발에서 정립)

## 사실 A — 비전문 발주사는 "기술 상세"가 아니라 "결론 구조"를 읽는다

보은전자통신(#157202) 기술검토보고서 초판(md 상세판)에 사용자가 **"직관적이지 않다"** 피드백. 발주사는 전자교탁 제조사지만 SoC·SDK·EOL 체인의 기술 판단 주체가 아니다. 상세 근거를 나열할수록 **의사결정자가 결론을 못 집는다**. → 당일 **HTML 시각화판**으로 전환: 색상 블록도(유지/개정/교체/신규) + before/after 신호 흐름도 + 한 장 요약 배너. 색상 = 결론 그 자체.

## 사실 B — 저가는 "깎았다"가 아니라 "분석이 낮췄다"로 제시해야 신뢰된다

#157202 최종제안서: 내부 산정 1억750만 상당 → **1단계 4,000만**으로 압축. 그냥 낮추면 "품질 의심 / 나중에 증액" 우려를 부른다. 대신 **"SDK 소스 분석 완료 → 실 로직 3.1만 라인 확인(폰트 16.4만 라인 착시 해소) → 60% 재사용 확인 → 리스크 제거"**로 서사화 → 저가가 **분석 투자의 결과**로 정당화된다. 할인이 아니라 근거.

## 판단 C — "결론 시각화 + 근거 서사 + 제3자 설명자료" 3종이 고액·비전문 발주사 계약의 표준 세트

세 산출물이 각기 다른 독자를 겨냥한다:

| 산출물 | 독자 | 역할 |
|---|---|---|
| **HTML 시각화 검토서** | 발주사 실무 담당 | 기술 판단을 색상 블록도로 대신 내려줌 |
| **최종제안서(저가 압축 서사)** | 발주사 의사결정자 | "분석의 결과인 4,000만" = 승인 명분 |
| **소스 구조 제3자 설명자료** | 발주사 내부 품의 라인 | "60% 재사용" 서사를 제3자가 검증하도록 5계층 구조도·용어집 제공 |

여기에 **killer 2축 구도**(체감 킬러 = A 자동추적 시연 차별화 vs 특허 킬러 = D 자가진단 F1 0.995 실증)를 사분면 차트 한 장으로 = 기능 우선순위를 발주사가 직관적으로 정렬.

## 행동 D — 향후 고액·비전문 발주사 건에 3종 세트 + 저가압축 서사를 기본 채택

- **적용 대상**: 발주사가 기술 판단 주체가 아니면서 금액이 크고 내부 품의가 필요한 건 (임베디드 재개발·레거시 현대화·PLC 대체 클러스터 전반).
- **자산 재사용**: 이 패턴 자체가 [[onDevice-ai]] F1 0.995 이상탐지 실증을 "특허 킬러 D"로 재활용하는 등 **cross-vault 실측 자산을 영업 킬러로 승격**하는 통로. → [[ai-direction]] 결정 67 + [[위시캣활동]] 2026-09-22 § + [[skills]] 영업 산출물 패턴.
- **PDF 파이프라인 표준 확장**: print-color-adjust:exact(색상 블록 보존) + page-break-inside:avoid(tr·card) — 시각화판의 색상이 PDF에서 유지되도록. Type3 0·마스킹 grep 0 유지([[feedback_pdf_local_font_no_type3|로컬 폰트]] 정책).
