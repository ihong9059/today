# 미팅 후 클라이언트 기술 반론 = 호재 신호 + 3단 방어 SOP

## 복리 패턴

```
[사실 A] #159474 미팅 완료·판가 제시 후 클라이언트가 전문가 자문을 받아 ToF 한계 3지적 반론 (2026-11-12)
[사실 B] 반론 내용 = 일반론적 기술 한계(빛 흡수 소재·어두운 색·강한 빛) — 본 응용 조건과 괴리
[판단 C] 미팅 후 기술 반론 = 이탈 신호가 아니라 "돈을 쓰기 전 마지막 검증" = 진지 검토 호재 신호
[행동 D] 3단 방어 SOP 정형화 → 향후 모든 "미팅 후 반론" 국면에 재사용
```

## 3단 방어 SOP (#159474 1례에서 추출)

1. **조건 재프레임** — 반론의 일반론을 "그 한계가 성립하는 조건"으로 분해하고, 본 응용 조건이 그 구조와 다름을 보임. (#159474: "원거리 정밀 측정 + 야외 직사광" 한계 ↔ 본 응용 = **근거리 수십 cm + 밀폐 암실 + 유무 판정 + 64칸 다수결**. 940nm 적외선 ≠ 눈에 보이는 색.)
2. **이종(비광학) 백업 개방** — 같은 축의 반박 대신 **원리가 다른 상호보완 수단**을 백업으로 제시해 리스크 자체를 구조적으로 해소. (#159474: 하중(무게) 감지 = 색·소재·빛 무관.)
3. **실측 검증 약속** — 최악 케이스를 시제품 실측 수치로 검증 후 양산 진행을 약속 = 논쟁을 "말"에서 "측정"으로 이동. (벤더 선언값 불신 원칙([[gaps]] 2026-11-03)의 영업 버전 — 측정이 신뢰의 화폐.)

## 의미

- 클라이언트가 **외부 전문가 자문 비용까지 쓰며 검증**한다는 것은 발주 의사의 방증 — 반론 대응 품질이 수주 전환을 좌우하는 분기점.
- 결정 39(미팅 자료 SOP)·결정 67(저가 압축 = 분석의 결과 서사)과 같은 계보: **영업 국면마다 재사용 가능한 문법을 추출**해 두면 다음 건에서 준비 비용이 0에 수렴.
- 적용 트리거: 위시캣·직접 계약 불문, "미팅/제안 후 클라이언트가 기술적 의문 제기" 국면 전부.
