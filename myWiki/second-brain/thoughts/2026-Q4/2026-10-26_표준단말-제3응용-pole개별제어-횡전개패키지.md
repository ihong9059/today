# 표준단말 제3 응용 — pole 개별제어 + 견적·ROI 횡전개 패키지

> 계기: lora-claude 카드 `2026-10-25-001` 흡수 (한림 조명 pole 개별제어 200 pole 영업 트랙 개시)

## 복리 패턴

```
[사실 A] 표준단말 "LoRa Relay Module" 플랫폼 수렴 + fleet 3계층 체인 확정 (2026-10-17 흡수)
[사실 B] 한림용인CC pole 개별제어 200대 — 견적(4,000만~5,200만) + ROI(회수 1.2년) 제출 세트 발행 (2026-10-25)
  → [판단 C] 표준단말 응용이 ① 수조 제어(한림, 완료) → ② 조명 시스템 교체(필로스, 협상) → ③ pole 개별 전력제어(한림, 제안)로
             확장 — 응용마다 새 보드가 아니라 "같은 단말 + 다른 부속(MC·센서) + 다른 서사(ROI)"
  → [행동 D] 견적·ROI 양식 = 재사용 가능한 영업 패키지로 자산화 → 타 골프장 횡전개
```

## 왜 중요한가

1. **영업 서사의 전환 — "기술 제안"에서 "투자 회수 제안"으로.** 수조(안전·무인화)·조명 교체(고장 복구)와 달리 pole 개별제어는 **전기료 절감 = 돈의 언어**로 제안됨. ROI 검토서(연 절감 ≈4,620만 → 회수 ≈1.2년, 5년 순효익 +1.76억)가 견적서와 짝을 이루는 **2종 세트 양식** — 골프장 의사결정자(경영진)에게 직접 닿는 포맷. 필로스 "사장 경영보고용 설명서"(9/8)와 같은 계보의 진화형.
2. **표준단말 전략의 검증 가속.** 제3 응용이 **같은 고객(한림) 안에서** 나왔다 — 플랫폼 하나로 응용을 늘릴 때 신규 고객 발굴보다 **기존 사이트 내 수평 확장**이 먼저 터진다는 신호. 골프장 1곳 = 수조 + 조명 + pole 전력 + (향후 관수·카트) 다계통 잠재 사이트.
3. **200대 = fleet 운영론의 첫 실전 후보.** 10/17 흡수한 fleet 사업방향(M2M SIM 조달·중앙 대시보드·OTD)이 가설이 아니라 **눈앞의 단일 수주로 현실화될 수 있는 규모**. 수주 시 RAK4630 재고 118 → 200대 부족분 선조달 + JLCPCB 2차 발주(RS485 /RE 개정판)가 즉시 트리거.

## 횡전개 체크 (타 골프장 재사용 조건)

- 재사용 가능: 견적 구조(Terminal Box 단가 × pole 수) · ROI 모델(마지막 팀 단계소등) · 제안 포맷
- 사이트별 교정 필요: 한전 실단가 · 영업일수 · 라운드 시간 · pole 전력/회로 구성 (한림 회신 대기 4전제와 동일 항목 = **교정 질문지 자체가 재사용 자산**)
- 선행 관문: 한림 1호 수주·설치가 레퍼런스 — 수조 때와 같은 "실증 → 근거팩 → 횡전개" 순서 ([[한림용인cc-고가수조]] 수조 근거팩 전례)
