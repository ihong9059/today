## 일반화 패턴 — 검색 통로 다양화 원칙

| sequential 검색 | 필터 검색 |
|---|---|
| ID 1씩 증가 | 카테고리/필터 페이지 |
| 비공개 redirect 함정 | 목록 페이지 = 비로그인 노출 |
| 시간순 | 영역순 (본 vault 영업 정조준) |

→ **본 vault 영업 정조준 검색 = sequential ID 보다 카테고리 필터 페이지 우선**. ID는 채번 패턴이 비단조라면 정확한 catch-up 보장 불가. 카테고리/필터는 plat 측 화면 노출 정책이라 안정적.
