# 원격 모니터링 풀스택 = 사업 라인 발견

## 한 줄 결론

> **revita Solar Monitor와 한림용인CC 골프수조는 측정 대상만 다른 동일 아키텍처. 같은 풀스택이 농업·양식·산업 시설로 확장 가능한 사업 라인.**

## 매칭 패턴 발견 — 두 사실의 충돌

```
[사실 A: revita Solar Monitor — 2026-05-11~12 실 운영 진입]
RAK4631 + INA219 + LoRa SF12(922.1MHz) → Flask Web UI(Chart.js+systemd)

+

[사실 B: 한림용인CC 골프수조 — 2026-05-10 시공 직전, 1,000만원 매출]
펌프·중계기·고가수조 + 수위센서 + LoRa(0.3kbps) → RPi 게이트웨이 + Web UI

↓ 매칭

[새 판단 C: "원격 모니터링 풀스택"은 단일 사업 라인]
"센서 → LoRa → RPi Flask Web UI → 현장 운용" 공통 아키텍처.
→ 측정 대상만 바꾸면 다른 산업 적용 가능.

↓ 행동 변화 D

[D-1] 한림용인CC 시공 시 Solar의 운용 자산 즉시 재사용 (systemd / Chart.js 로컬 / 5분 평균 / data.json)
[D-2] 향후 영업 시 "검증된 풀스택 보유 1인 기업" 카피로 차별화
[D-3] 잠재 응용 5종에 동일 솔루션 제안 가능
```

## 공통 아키텍처 (실측 검증)

```
┌─────────────────────────────────────────────────────────────┐
│  [현장 센서]                                                  │
│   INA219 (전류·전압) / 수위센서 / 토양·수질 등              │
└───────────────────────┬─────────────────────────────────────┘
                        │ LoRa (922 MHz / 433 MHz, SF12~7)
                        │ 거리 1~15km, NLOS 1~3km
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  [중계기 (필요 시)]                                           │
│   상시전원 자체조립 또는 솔라+배터리                          │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  [게이트웨이 RPi 4]                                           │
│   Flask Web UI                                              │
│   - Chart.js 로컬 호스팅 (CDN 의존 X)                        │
│   - 5분 평균 / data.json 영속화                              │
│   - Y축 고정 / Serial Log 패널                               │
│   systemd 서비스 자동 실행·재시작                            │
│   pyserial → /dev/ttyUSB* (udev rule ID_PATH 매핑)          │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ↓
                  [발주자 PC/스마트폰 브라우저]
```

## 적용 영역 매트릭스

| 영역 | 측정 대상 | 행위 (펌프/밸브) | 현 상태 | 매출 가능성 |
|---|---|---|:-:|:-:|
| ✅ **revita Solar** | 태양광 전류·전압 | (모니터링만) | 실 운영 중 | 자체 검증용 |
| ⏳ **한림용인CC 골프수조** | 수위 / 펌프 상태 | 펌프 ON/OFF | 시공 직전 | **1,000만원** + 한림그룹 확장 |
| 🎯 **농업 IoT (스마트팜)** | 토양 수분·온도·습도 | 관수 밸브 | 잠재 | 위시캣 #153090 활용 가능 |
| 🎯 **양식장 모니터링** | 수질 (pH·DO·온도) | 산소·급수 펌프 | 잠재 | 신규 채널 개척 |
| 🎯 **산업 시설 모니터링** | 진동·온도·전류 | 알람·차단 | 잠재 | [[smartFactory]] 연계 |
| 🎯 **자전거주차장 운영** | 거치율·전원·문 상태 | 알람·통계 | 잠재 | 일본 [[일본-시장]] 재진입 |
| 🎯 **태양광 발전소 운영** | 전류·전압·발전량 | 알람 | 잠재 | Solar Monitor 확장 형태 |

→ 7개 영역 중 **이미 2개에 동일 풀스택 적용 가능 (실 운영 + 시공 직전)** 검증.

## 차별화 카피 (영업용)

> **"검증된 풀스택 보유 — 데모는 누구나 / 운용은 1인 기업이 직접 한다"**

- 다른 외주: PoC 만들고 인계 → 운용은 고객이 알아서
- UTTEC: Flask + systemd + udev + Chart.js 로컬 + 현장 함정 회피 패턴 모두 검증 완료 → 시공 + 운용 인수까지 단일 책임
