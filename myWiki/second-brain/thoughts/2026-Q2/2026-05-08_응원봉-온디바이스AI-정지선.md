# 응원봉 ↔ onDevice_AI 정지선

## 인사이트 요약

> microGPT 4,192 파라미터로는 응원봉 본체 사용자 경험을 만들 수 없다. **이 검증은 "제품의 일부"가 아니라 "회사의 기술 자산·B2B 영업 무기·PR 콘텐츠"로 위치시켜야 한다.** 양산 BOM·펌웨어를 건드리는 단계 직전(Phase 2 종료)에서 멈추는 것이 마케팅 ROI 최대화 지점.

## 복리 패턴 (사실 A + 사실 B → 판단 C → 행동 D)

**[사실 A]** 응원봉 newMvp/온디바이스_AI_검토서(2026-02-27) 결론 = **"스마트폰 Gemma 2B + Cloud 하이브리드"**. 응원봉 본체는 BLE 명령 수신만.

**[사실 B]** onDevice_AI vault Phase 1A·1B(2026-05-08) 결론 = **microGPT 4,192 params, ESP32-S3 SRAM의 0.4~3%만 사용**. 압도적 여유. 그러나 4K 파라미터로 답변 가능한 영역은 "음절 패턴 흉내"뿐.

**→ [판단 C]** 두 사실을 합치면: **"같은 'AI'라는 단어를 쓰지만 체급이 6~7자릿수 다르다"**. microGPT를 응원봉 양산에 넣으면 사용자 만족 0, 마케팅 마이너스. 그러나 PR·특허·B2B 영업 자산으로는 강력함.

**→ [행동 D]**
1. onDevice_AI의 정지선을 **Phase 2(보드 1대 데모) 종료**로 명시
2. 응원봉 양산 방향은 "스마트폰 Gemma 2B 하이브리드" 유지·잠금
3. microGPT 산출물은 PR 영상 1편 + Stage 4 영업 사례 + 강사양성 Day 5 사례로만 활용

## 왜 중요한가

### 1. 한 트랙의 결과를 다른 트랙에 잘못 적용하면 안 된다
"검증이 잘 됐다"고 해서 그것이 양산 적용을 의미하지 않는다. **검증 트랙과 제품 트랙은 분리되어야 한다.**

### 2. 마케팅 카피의 청자(audience)를 분리해야 한다
같은 "응원봉에 GPT" 카피라도:
- B2B 영업/PR/강의 청자에게는 "기술 깊이 어필" → ✅
- C2C 응원봉 사용자에게는 "기대 격차 → 클레임" → ❌

### 3. 양산 BOM은 5만 대 단위에서 +1,500원/대 = +7,500만
사용자가 인지·지불할 가치가 미입증인 비용은 마이너스 결정.

## 정지선 재검토 트리거

다음 중 하나라도 발생하면 정지선 재검토:
- ESP32-S3 가격이 ESP32-C3 수준으로 하락 (BOM 부담 해소)
- 1B+ 모델이 ESP32-S3에 탑재 가능해짐 (체급 격차 해소)
- 응원봉 사용자가 "오프라인 응답"을 강하게 요구 (니즈 입증)
- 경쟁사가 응원봉 자체 AI 탑재 출시 (선점 압박)
