## 핵심 기술

| 기술 | 설명 |
|------|------|
| BLE Mesh Network | RF → 암호화 + 외부안테나(200m+) + 저전력 |
| LoRa | 국내 최초 상용화 (2018), 클라우드 서버 연동 |
| 시스템 구조 | Node(무선+태양전지+배터리+센서) → Gateway → Server → User |

## 기술 진화 스토리

```
General RF (100m 미만, 암호화 없음)
  → BLE Mesh (암호화, 200m+, 저전력)
    → LoRa (장거리, 클라우드 서버)
      → LoRa + AI (REVITA: 농업 IoT + 센서 + 제어)
```
