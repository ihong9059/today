# Python Vibe 교육앱

## 한 줄 정의
AI가 Python 코드를 생성 → 실행 → 설명하는 **바이브 코딩 교육 앱**.

## 왜 중요한가
- [[ai-direction|AI 방향]]에서 "바이브 코딩 교육" 선점의 핵심 제품
- 문법 교육이 아닌 **AI와 협업하는 능력** 교육
- 프롬프트만 입력하면 AI가 코드를 만들고, 학생은 실행하며 배운다

## 현재 상태
- 100개 예시 (10개 카테고리 × 10개: A~J)
- 4탭 구조 (홈/학습/실행/설정)
- 서버 v2.0 (포트 8094)
- 선생님용/학생용 사용설명서 완성

## 카테고리 구성
| 코드 | 주제 | 예시 |
|------|------|------|
| A | 첫걸음 | Hello, 시간, 구구단, 가위바위보 |
| B | 숫자/계산 | 소수, 피보나치, 복리 계산 |
| C | 조건문 | 성적, 윤년, 자판기, 신호등 |
| D | 반복문 | 카운트다운, 다이아몬드, 야구 |
| E | 함수 | 재귀, 람다, 데코레이터 |
| F | 문자열 | 회문, 시저암호, 애너그램 |
| G | 리스트 | 행렬, 버블정렬, 스택큐 |
| H | 센서 | 주사위, 만보기, 수평계 |
| I | 카메라/소리 | 촬영, QR코드, 색상선택 |
| J | 게임 | 공굴리기, 틱택토, 스네이크 |

## 아키텍처
```
[Flutter 앱 (4탭)]
       ↓ 프롬프트 / 예시 선택
[Python 서버 (server.py v2.0)]
  ├── Python sandbox 실행 (5초 제한)
  ├── AI Q&A (Claude CLI)
  └── AI 코드 생성 (코드 + 설명 + 핵심 개념)
```

## 핵심 기술
- [[claude-code]]: AI 코드 생성 엔진
- Flutter: 네이티브 앱 (sensors_plus, vibration, qr_flutter, torch_light)
- Python: sandbox 실행 환경
