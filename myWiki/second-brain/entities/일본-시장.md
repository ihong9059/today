# 일본 시장

## 한 줄 정의
UTTEC의 일본 영업 트랙. **BLE Mesh nRF52832 기반 주차장 LED 제어 3,800대 양산 실적**을 보유한 검증된 진입 시장.

## 왜 중요한가
- 일본 양산 실적 = [[strengths|강점]] "양산 5종 → 6종" 핵심 근거
- 한국에서 보기 드문 **일본 직거래 양산** 트랙 레코드
- 향후 [[ai-fanstick|AI FanStick]] 일본 진출 시 베이스 인프라

## 진행 트랙 (3건)

### 1. AMANO (주차장 LED 제어) — ★ 양산 완료
- **제품**: nRF52832 BLE Mesh 주차장 천장 LED Dimmer
- **수량**: 약 3,800대 양산 납품 (일본)
- **상태**: 양산 완료, 유지보수 중
- **자료**: `oldProject/일본/AMANO/` (62 files / 12.5 MB)
  - PCB 최종: `pcb_0814/whybiz_amano_BOM/` (Gerber + BOM + DXF)
  - 출장 보고: 2024-09-25 일본 현장
  - AMANO Dimmer Setting 가이드
  - 핵심부품: HFD2/TQ2-3V (릴레이) + SK6812/WS2812B (LED)
- **확장 시나리오**: AMANO 後續 발주, BLE Mesh 응용 사례 (응원봉/스마트시티)

### 2. 동해기연 (도카이) — 진행 중
- **제품**: 자전거 주차장 시스템 + Solar Cell 적용 제안
- **상태**: 제안·견적 단계, BLE Mesh re-mesh 기술 설명 진행
- **자료**: `oldProject/일본/도카이/` (30 files / 50.4 MB)
  - 자전거 주차장 System pptx (한·일)
  - 東海技研様 ご質問 v1(2024-12-01)·v2(2024-12-02) — 일본 측 질문 이력
  - gateway 일본어 사양서
  - Mesh Network re-mesh 설명 자료 (KOR)
  - RFTech 협력 자료 — 한국 파트너 RFTech 경유 영업

### 3. Patron (Win365 제안) — 제안 완료
- **제품**: 스마트시티/팩토리/로지스틱스 BLE Mesh 통합 제안
- **상태**: 2025-10-23 제안서 제출
- **자료**: `oldProject/일본/도카이/타사제안서/`
  - UTTEC_to_Patron_Proposal_Win365_20251023.pptx (10.4MB, 메인 제안서)
  - **AI 생성 이미지 14장** (smart city/factory/farm/logistics/security/lamp/소방/blueMergency) — 향후 영업 자료 재사용 자산
  - smartBle/ HTML 시연 페이지 5건 (Factory/Farm/Logistic/Security/조명)
