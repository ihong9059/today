## 핵심 통찰

### 1. 4-Agent emergent 시스템
- Substrate (Obsidian, LLM-친화 마크다운)
- Schema (CLAUDE.md, 보이지 않는 시스템 프롬프트)
- Agent (Claude, 묵시적 ontology + 합성)
- Director (사용자, 방향 + 피드백)
- → 4가지 모두 강해야 "자연스러운 정리" emergent 발생

### 2. ontology와 obsidian 관계
- Obsidian = ontology가 아님 (무타입 wiki 그래프)
- 그러나 substrate(LLM-친화 형식) 제공
- Claude가 LLM 훈련에서 흡수한 묵시적 ontology로 보완
- 사용자는 myWiki(L2) + Memory MCP(L3)로 4계층 중 거의 최적 운영
- L4 정식 ontology(SNOMED CT 등)는 REVITA 의료 진입 시 검토

### 3. 자영업·중소기업 AI 플랫폼 가능성 23/25
- 사용자 사업 후보 1위 (디지털배움터 22, 강사양성 21 보다 상위)
- "사장님의 두 번째 두뇌" — 카톡 음성 1~3분 → 주간 인사이트 자동
- Phase 0 비용 거의 0 (강사양성 파일럭과 병행 가능)
- 매출 잠재: 1년 1천만~3.6천만, 3년 5억~15억

### 4. 다업종 표준화 (10개 업종)
- 음식점·**소규모 학원**·**자동차 정비소**·미용실·카페·농업·편의점·세탁소·꽃집·부동산
- 새 업종은 30분 청취로 schema 작성 가능
- 6개월 후 30개 업종 확장 로드맵

### 5. 통합 가치 명제 (3축)
1. 별도 단기 모듈 2~3h (호오컨설팅 단발 강연 / 인프런 강의 / 강사양성 2차 차수 통합 검토) — **옵션 D 결정 (5/7)**
2. 자영업 AI 플랫폼 (새 사업 라인)
3. Foundry 무료 재현 모델 (Stage -1 funnel 입구)

## 외부 검증 (2026-05-09 추가)

### 카파시 LLM-Wiki 영상의 반대측 데이터 (`유투브/01_LLM위키_지식관리/카파시도_못_말한_LLM-Wiki의_진실_상세.md`)
시장 회의론을 정면으로 다룬 30분 분석 영상. 본 사업화 명제와 충돌하는 게 아니라 **차별화 포인트를 더 좁힐 단서** 제공.

| 영상이 진단한 PKM 시장 한계 | 본 사업화에 주는 함의 |
|---------------------------|------------------------|
| **PKM 90%가 3개월 안에 사망** (입력 마찰 > 검색 가치) | 도구 판매가 아니라 ***운영 코칭 + 자동 큐레이션***이 IP가 되어야 함 |
| 한국어 RAG 함정 (BGE-M3, KoNLPy 청킹, 키워드/RAG 하이브리드) | 자영업 음성 1~3분 → 주간 인사이트 모델은 영어 PKM과 다른 *짧은 한국어 발화 특화*로 차별화 가능 |
| Karpathy도 결국 "**직접 큐레이션**한다" — 자동화는 수집만 | 4-Agent 시스템의 가치는 수집이 아니라 *Director(사용자 피드백) + Schema*가 자동 큐레이션을 흉내낸다는 점 |
| 결론 3원칙: 시스템보다 습관, 지속성 ∝ 1/마찰, ROI = 검색 횟수 | Phase 0의 "수동 시뮬레이션 1명"이 정확히 이 3원칙을 따라가는 설계 — 영상이 본 진행 계획의 정당성을 사후 보강 |
| Garry Tan G-Brain (SaaS) vs Karpathy DIY 양극 | 본 사업은 **Coach + 매월 인사이트 발송 = 둘의 중간** — 사용자가 도구를 만들지 않고도 데이터 주권을 유지 |

→ **차별화 메시지 재정의**: "PKM이 아니다. 사장님 대신 매주 큐레이션하는 *AI 비서* 다."
