# 정부 R&D 실증사업 — PLC 4축 GMC 1억 직접 수행

## 한 줄 정의

UTTEC이 **정부 R&D 1억 사업을 직접 수행한 실증 사례** (2016~2017, 99.1% 집행률 완료). 특허 출원 + 기업부설연구소 등록 + ARM/FPGA/PROFINET 멀티프로토콜 통합 검증. **2026-05-20 wishket-claude megasession 흡수**로 본 vault 첫 정식 박제.

## 사업 정보

| 항목 | 값 |
|---|---|
| 사업명 | **PLC 기반 4축 GMC (General Motion Control) 개발** |
| 기간 | 2016-11-01 ~ 2017-10-31 (12개월) |
| 총 사업비 | **101,070,700원** (정부 84.8M + 기업 15.4M) |
| 집행률 | **99.1%** ✅ |
| 협업 | [[세주에프에이]] + UTTEC 공동 수행 |
| 특허 출원 | **10-2017-0138381** (2017.10.24) |
| 기업부설연구소 | **C0442235** (인정번호) |
| 산출물 | ARM Cortex-M7 + FPGA 모션 컨트롤러 + 펌웨어 + 통합 GUI |

## 기술 스택

- **MCU**: ARM Cortex-M7 200MHz
- **PLD**: FPGA (모션 제어 가속)
- **모션 제어**: E-CAM (Electronic Cam) + G-CODE 인터프리터
- **통신 프로토콜**: EtherNet/IP + PROFINET + Modbus TCP (3-protocol multi-master)
- **응용**: 4축 동기 제어 (X·Y·Z·회전)

## 영업 가치 (Tier 3 정부 R&D 입찰 결정적 자산)

### 가치 1 — 정부 R&D 직접 수행 자격 입증

- 1억 규모 정부 사업 직접 수행 (99.1% 집행률 = 무리 없이 완수 검증)
- 위탁·하청이 아닌 **공동 수행 주관 자격**
- 정부 R&D 노임단가 검증 (실제 수령 단가 자료 보유) → Tier 3 입찰 시 정확한 단가 산정 가능

### 가치 2 — 특허 + 기업부설연구소 자산

- 특허 출원 1건 (10-2017-0138381) — 본 vault 첫 박제
- 기업부설연구소 등록 (C0442235) — 정부 R&D 자격 요건 입증

### 가치 3 — 멀티프로토콜 통합 검증

- ARM + FPGA + 3-protocol 동시 통합 = 산업 자동화 영역 차별화 자산
- 양산 6종 ([[양산제품]]) + 본 사례 = **7종 또는 정부 R&D 별도 카테고리**
