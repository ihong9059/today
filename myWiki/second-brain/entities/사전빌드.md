# 사전빌드 교육 시스템

## 한 줄 정의
학생이 항목을 선택하면 **미리 빌드된 펌웨어**를 BLE OTA로 즉시 전송하여 체험하는 교육 시스템.

## 왜 중요한가
- [[ai-direction|AI 방향]]에서 가장 강력한 차별화 요소
- AI가 코드를 생성해도 **하드웨어 전송/체험**은 물리적 시스템이 필요
- 교육 현장에서 **대기 시간 제로** = 학생 집중도 유지

## 현재 상태
| 보드 | 항목 수 | 포트 | 상태 |
|------|---------|------|------|
| ESP32 WROOM | 155개 | 8095 (사전빌드), 8092 (커스텀) | 완료 ✅ |
| ESP32-C3 Mini | 117개 | 8096 (사전빌드), 8093 (커스텀) | 완료 ✅ |
| ESP32-C6-LCD | - | - | 구축 예정 ⬜ |

## 아키텍처
```
[웹 UI / Flutter 앱]
       ↓ 선택
[Python 빌드 서버 (prebuild.py)]
       ↓ 사전빌드 DB에서 바이너리 조회
[BLE OTA 전송]
       ↓
[ESP32 보드에 즉시 적용]
```

## 핵심 기술
- [[claude-code]]: 펌웨어 코드 자동 생성 (Claude CLI)
- Arduino-CLI: 자동 빌드
- NimBLE: BLE OTA 전송
- Flutter: 모바일 앱 (com.uttec.prebuild, com.uttec.mini)
- FastAPI: 빌드 서버
