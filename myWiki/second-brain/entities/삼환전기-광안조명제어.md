# 삼환전기 — 광안 지역주택조합 보안등 조명제어

## 한 줄 정의

**오래된 거래 조명회사 삼환전기**가 유입시킨 **LoRa 조명제어 신규 영업 리드**. 부산 수영구 광안동 **광안 지역주택조합 공동주택 신축공사**의 옥외 보안등 시간대별 디밍제어 건. 심의 승인 도면은 유선 0-10V 디밍 시스템으로 확정돼 있어, UTTEC는 **무선(LoRa) 대체 제안** 포지션.

## 프로젝트 스펙 (도면 판독)

- **현장**: 광안 지역주택조합 공동주택 (부산 수영구 광안동 971)
- **보안등**: **41등 / 6회로(OL1~6)**, 조명제어반 **LCP-0**(400×1600×180) @ 501동 경비실
- **심의 제어방식(경쟁)**: 유선 **0-10V 디밍모듈 8ch**(0~254단계, DALI 대응) + **SCU**(RS485/Ethernet/MODBUS) + **CCMS PC**(HMI GS·BTL 인증) @ 501동 경비실
- **배선 부담**: 데이터 F-CVVS 1.5㎟×2C(22C), 안정기 AWG18(16C) — 옥외 41등 분산 포설
- 상세: → today `영업/삼환_보안등조명제어/CAD검토결과_E13_E2_20260723.md`

## UTTEC 포지셔닝

1. **무배관·무배선** — 옥외 41등 분산 → LoRa 무선이 통신 배선공사 전체 소거 (원가·공기 우위). 결정적 차별점.
2. **기능 동등성** — 0~254단계 디밍·그룹/씬·스케쥴·중앙감시·자기진단을 LoRa로 1:1 매핑. 근거 = [[한림용인cc-고가수조]] 14노드 실증.
3. **DALI/0-10V 게이트웨이** — 심의 모듈이 DALI 대응 → 기존 등기구 활용형 게이트웨이 옵션.
4. **경쟁 인지** — 심의본은 "Excellent Lighting Controls" 계열 유선 시스템 + 견적서 첨부(24.09). UTTEC는 대체 제안.

## 벤더 확인 — ㈜엠알바스(MRBAS) ⭐

도면 'Excellent Lighting Controls(ELC)' = **㈜엠알바스(MRBAS)** ELC SYSTEM으로 특정(SCU 999모듈·0-10V 254단계·래칭릴레이 스펙 일치). 공개자료 조회 결과:

- **회사**: ㈜엠알바스, 대표 **윤창로**, 설립 1990.11.07(조명제어 1997~), 24명, 매출 약 71.5억, 서울 송파구 문정동. 배전반·전기자동제어반 제조. 실적=롯데타워·대전/대구지하철·김포골드라인·에버랜드 등. → **실존 30년+ 조명제어 벤더**.
- **인증**: **BTL = 관제SW Smartrol v3.1 2013 등재**(● 제조사 공식+검색 교차확인, 현재 등재유지 최종확인 권장) / **GS = 제조사 주장만**(◐ TTA 공식목록 미확인·인증번호 불명 → **인증서 사본 필수**, 도면이 GS 요구하므로 핵심 리스크) / BACnet(●) / 우수조달·DALI·CE·ISO(◐ 주장).
- **판단**: 1안(MRBAS 인증제품 공급)으로 도면 GS·BTL 요구 충족 **가능성 높으나 GS 실증이 전제**. 인증=제품 1회성·현장 무관(UTTEC 신규인증 불요).
- 산출물: `MRBAS_엠알바스_인증조회_회사확인_보고서_UTTEC_v1_20260724.pdf`(내부용 2p).
