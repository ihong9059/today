## AI 공장자동화 교육 (2026-05-03 신규)

RPi 3B+ + UTTEC Shield + E22-900T30D LoRa 기반 중소기업 대면교육 커리큘럼.

### 교육 과정
- **8일 x 4시간 = 총 32시간** (기존 5일 15시간에서 확대)
- 대상: 중소기업 종업원 (프로그래밍 초보자 가능)
- 키트 단가: 약 12만원/인

### 8일 커리큘럼
1일차 환경구축(Python+RPi) → 2일차 센서+OLED → 3일차 LED+부저+스위치 →
4일차 통합자동제어 → 5일차 LoRa무선통신 → 6일차 Flask웹대시보드 →
7일차 AI숫자인식(CNN/Colab) → 8일차 종합프로젝트(미니스마트팩토리)

### 주요 기술 이슈

- WS2812: 5V 구동, GPIO12 데이터, 4개 데이지체인

## 팔란티어 파운드리 시리즈 학습 — 적용 가능 인사이트 (2026-05-04 추가)

Kelly Ontology Hub 채널 시리즈 4편(#0~#3) 학습 후 우리 사업에 직접 적용 가능한 핵심 개념 정리.
원본 상세본: `유투브/04_AI_이론/팔란티어_파운드리_*_상세.md`

### 우리 제안서/교육에 즉시 활용 가능한 5가지

| # | 개념 | 출처 | 우리 적용 영역 |
|---|------|------|---------------|
| 1 | **닫힌 피드백 루프(Closed Feedback Loop)** | #0 | 예지정비 → 알림 → 조치 → 데이터 재학습 사이클 설명 |
| 2 | **Operational Feedback Loop / 양방향 흐름(Writeback)** | #1 | MES/SCADA 통합 시 "분석 → 현장 명령" 양방향 가치 제안 |
| 3 | **온톨로지 = 디지털 쌍둥이** | #3 | 디지털 트윈 사업 설명서 첫 장에 그대로 인용 가능 |
| 4 | **분석 툴(BI) vs 운영 앱** | #3 | 기존 대시보드 도입 고객사 업셀 메시지 — "보여주기에서 해결로" |
| 5 | **객체(명사) + 액션(동사)** | #3 | PLC/SCADA "버튼 한 번에 현장 변경" 메시지로 변환 |

### M&A/시스템 통합 4단계 청사진 (시리즈 #3)
스마트팩토리 시스템 통합 컨설팅 제안 시 그대로 슬라이드화 가능:
```
Step 1: 데이터 수집(Plug & Load)        — Data Connection
Step 2: 통합 데이터 세트(SSOT)          — Pipeline Builder (정제·결합·변환)
Step 3: 디지털 트윈(온톨로지)            — Ontology Manager
Step 4: 운영 앱(드래그+드롭 + 액션)      — Workshop
```

### "진짜_최종_V3" 비유 (시리즈 #3)
온톨로지 가치를 한 문장으로 전달하는 최고의 마케팅 카피:
> "더 이상 '주문_테이블_언더바_최종_언더바_진짜_최종_언더바_V3' 같은 파일명으로 고민하지 않고, 그냥 '주문', '고객' 같은 비즈니스 단어로 사고하게 된다."

→ 우리 디지털 트윈 영업 자료에 한국형 사례로 변형 ("센서_데이터_v17_최종.csv → 진동, 온도, 회전수")
