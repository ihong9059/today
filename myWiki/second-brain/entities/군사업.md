# 군 사업

## 한 줄 정의
UTTEC의 군·방산 시장 진입 IP. RF 통신기 + 군용 충전기 + 함상통신기 + 지뢰감시 센서 등 **검증된 군용 시스템 자료** 보유.

## 왜 중요한가
- 군 시장은 **진입장벽 높지만 안정 매출**
- RF 테스트·통신기 IP는 [[skills|통신 프로토콜 강점]]의 군 분야 확장
- 정부지원 R&D·국방벤처 공모 시 즉시 인용 가능
- 1인 사업 한계(매출 변동성)를 군 단가 계약으로 완충 가능

## 보유 IP (4건)

### 1. ITM-G3 Program (군 통신기 RF 테스트 — 핵심)
- **위치**: `oldProject/rfTech/ITM-G3_Program/` (433 files / 46.7 MB)
- **내용**:
  - **RadioControlConsole**: Windows 콘솔 프로그램 (424 files / 34 MB) — RF 통신기 제어 SW
  - **PTCDriverWrapper_for_C**: C 래퍼 라이브러리 + CLI 예제
  - **GP_P008/P864 PDF 매뉴얼**: Programming IF UART, PTC Driver Wrapper User Manual (Qorvo QPG6105)
  - **RF_TEST_메뉴얼_230208.pptx** (11 MB): RF 테스트 절차서
  - ITM G2 RF Test Command.xlsx
- **칩**: Qorvo QPG6105 (Multi-protocol radio: 802.15.4 + BLE + Thread)
- **활용**: 군 RF 통신 모듈 신규 개발 시 즉시 베이스 라인

### 2. 군대 충전기 (60Channel)
- **위치**: `oldProject/rfTech/군대_충전기/` (211 files / 61.4 MB)
- **내용**:
  - 1차 + 2차 수정사항 (revision 이력)
  - **PCB 설계자료** + 회로도 (15 files)
  - **Software** (49 files / 3.8 MB) — 펌웨어
  - **Spec** (37 files / 29.3 MB) — 사양서
  - **RFID** (75 files) — 사용자 인증 모듈
  - **Manual / 생산 / 개발견적서**

- **활용**: 군 다채널 충전 시스템 ([[충전기|PowerDock Pro]]와 별개 — 군용 60채널)

### 3. 2차 군대 충전기 (개량판)
