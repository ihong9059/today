# 건물 통합 관제 플랫폼 — Tier 3 영업 패턴

## 한 줄 정의

OTIS·LG 에어컨·자동문·주차 LPR·실내 주행 로봇·CCTV·BLE Mesh·DALI·Zigbee 등 **다중 이기종 장비 통합 관제**. 정부 R&D 실증사업 표준 양식 + Node-RED + Grafana 단순화 아키텍처로 풀스택 외주 대비 ~3,000만 절감. 위시캣 #155360(2.4억·120일·17명 경쟁) 첫 Tier 3 사례.

## 영업 패턴 핵심 (위시캣 #155360 박제)

### 1. Node-RED + Grafana 단순화 아키텍처 (4-Layer)

- Layer 1: 이기종 장비 (OTIS·LG·LPR·로봇·CCTV·BLE Mesh·DALI·Zigbee)
- Layer 2: Node-RED 통합 (프로토콜 변환·이벤트 라우팅)
- Layer 3: 데이터 저장 (InfluxDB / PostgreSQL)
- Layer 4: Grafana 시각화 + Alert

**가치**: 풀스택 외주 ~3,000만 절감 + 옵션 A/B/C 분리 견적 = 클라이언트 비용 효율·선택권 부여.

### 2. 양산 5종 BOM = 정부 R&D 정산 양식 매칭 ⭐ (결정적 차별화)

UTTEC 양산 5종 BOM·중국 수출 견적 작성 경험 = 정부 R&D 항목별 정산 양식과 **95% 일치**. 17명 경쟁 시 정밀 견적서 = 차별화 핵심.

- 4 대항목 + **22 BOM 세부 항목** + 옵션 A/B/C 분리
- 정부 표준 양식 100% 충족

### 3. 일본 BLE Mesh 3,800대 = IoT 인프라 매칭 자산 (2회 활용 확인)

- 5/17 #155381 부스바 entity (X/Y 좌표·산업 자동화)
- 5/18 #155360 IoT 모션 센서·게이트웨이 인프라 (Tier 3)
- TELEC 인증 = 정부 표준 인증 절차 직접 경험 = 정부 R&D 사업 신뢰성 보증
