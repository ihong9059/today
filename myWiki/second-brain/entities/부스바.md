# 부스바 (busbar)

## 한 줄 정의

배전반·차단기·MCC·UPS·ESS·태양광·전기차 충전기·데이터센터 등 **고전류 전력 분배의 핵심 부품** (구리·알루미늄 평판 도체). UTTEC 양산 자산 6종(V-Cut + Three.js + Canvas 2D + STM32 5종 + EtherCAT + Modbus)이 부스바 가공 PC 응용에 직접 활용 가능.

## 형태·재질·규격

- 재질: 구리 (CU) 또는 알루미늄 (AL)
- 형태: 평판 도체 (두께 3~10mm, 폭 20~100mm, 길이 가변)
- 가공: 펀칭(천공, M6~M16) + 절곡 + 절단
- 표면: 무도금/주석 도금/은 도금/니켈 도금

## 사용처

| 도메인 | 사례 |
|---|---|
| 배전반 / 차단기 / MCC | 산업용 표준 |
| UPS / ESS | 무정전·에너지 저장 |
| 태양광 / 전기차 충전기 / 데이터센터 | 신재생 + 신산업 |

## UTTEC 양산 자산 매핑 (5/17 위시캣 #155381 박제)

| 자산 | 부스바 응용 |
|---|---|
| **V-Cut PCB** | 좌표 비전 측정·자동 절단 |
| **Three.js 3D 시각화** | 3D 배전반 디지털 트윈 |
| **Canvas 2D X-Y 좌표** | 펀칭 좌표 입력·검증 (자동화) |
| **STM32 5종** | 안전 인증 양산 자산 |
| **EtherCAT** | 자동 펀칭기 마스터 통신 |
| **Modbus RTU** | PLC·HMI 통합 |

## 시장 규모

- 국내: 연 1조원+
- 글로벌: 수십조원 (배전반·ESS 중심)

## 후속 외주 6 시나리오 (Tier 2·3 후보)

1. 자동 좌표 펀칭 (Canvas 2D + STM32) — 800만 ~ 2,000만
2. 3D 배전반 디지털 트윈 (Three.js) — 1,500만 ~ 5,000만
3. PLC 통합 부스바 가공 라인 — Tier 3 (5,000만+)
4. EtherCAT 마스터 부스바 인터페이스 — Tier 3
5. 부스바 비전 검증 (V-Cut 자산) — Tier 2
6. 부스바 양산 BOM·QC 컨설팅 — Tier 2

## 표준 규격

- 한국: KS C 8550 (배전반)
- 국제: IEC 60439, NEMA, JIS
