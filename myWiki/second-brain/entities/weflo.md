# Weflo (WEFLO Inc.)

## 한 줄 정의

위시캣 **#157235**(고정밀 24bit ADC·MCU RPM 회전체 진단 보드) 발주사. **드론·UAM·전기차 비접촉 AI 진단** 스타트업으로, UTTEC의 **STM32H7 고속 DAQ·진동/음향 계측 양산 자산**([[양산제품]] 계측/DAQ)과 직결되는 신규 클라이언트 도메인.

## 사업

- **비접촉 AI 진단** — verti-Pit(10초 점검) 등 드론·UAM·전기차 대상 비접촉 계측·진단.
- 플랫폼: **VAIS / FloOne**(국방 드론 AI).

## UTTEC 정합 (왜 강매칭인가)

- **#157235 보드** = 24bit 동시샘플 ADC + 차동 AFE(진동/음향 신호체인) + RPM 알고리즘(회전체 특징량) + 소형 배터리 보드 → Weflo **비접촉 진단장비의 계측·연산 모듈**로 해석.
- UTTEC **STM32H745 고속 DAQ / 자동차 진동·소리 계측 양산 자산**([[양산제품]])이 정확히 대응.
- **후속 물량 가능성** — 국방/UAM 고객 + 한화 출신 = 단발 외주를 넘는 반복 발주 잠재. 수주 도달 시 **Tier 승격·sub-vault** 검토 후보.

## 진행 상태 (2026-10-25) — 2차보드 검토의견 수신 + 설계오류 2건 추가 확정 (weflo-claude 카드 `2026-10-25-001`)

- **Weflo HW 담당자 검토의견서 수신(10-24)**: 필수 수정 5 + 권장 9 + 생산문서 4 + 심층 7건. ⭐ **고객이 flying-probe 넷 분석까지 수행한 밀도 높은 검토 = 클라이언트 기술 관여도 매우 높음** — 한화시스템 출신 HW 조직이 실질 품질 게이트 역할. 커뮤니케이션·산출물 품질 기준을 이 수준에 맞춰야 함.
- **설계오류 확정 3건 누적** (기존 SWD 미연결 + 신규 2건): ① **VSS–DGND 넷 분리** → 샘플 전원 인가 전 와이어 브리지 3~4점 필수 ② **VCAP C37/C38 부유** → 고클럭 전 점퍼 권장. **넷 라벨 누락 동일 유형이 4계열 반복** — 패턴은 [[gaps]] § 2026-10-25 + thought [[2026-10-25_넷라벨누락-반복패턴-고객검토-품질게이트]].
- 3문서 통합 **종합보고서 HTML** 박제(weflo vault): 이슈 매트릭스 27건·샘플 디버깅 Phase 0~5·리워크 R1~R6·차기 리비전 필수 8건·양산 대비.
- 영향: 샘플 브링업은 리워크 전제로 가능(DFU+SWD 점퍼 경로 유효). **차기 리비전 수정 범위 "넷 라벨 2개" → 회로 필수 8건+권장 다수로 확대** — 3차 설계 일정 반영 필요. **양산 조달 리스크**: STM32H745ZIT6(C730193) LCSC 재고 소진 → 대체 채널 선구매 검토.

### 당일 후속 (2026-10-25 오후, weflo-claude 카드 `2026-10-25-002`) — 3차 설계 필수 8건 전부 반영·검증 PASS ⭐

- 오전 검토의견의 **필수 8건을 당일 전부 설계 반영 완료·v2 재검토 PASS**(홍광선 `3rd_수정.eprj2` 작성 → v1에서 L1/L2 미반영 1건 지적 → 즉시 수정): SWD·VSS=DGND·VCAP 핀별 캡·디커플링·SMPS LDO-only·VDD 100nF·L 470nH·R37=105k.
- 부수 확정: H1 I2C=PB6/PB7 + H2 확장헤더 10핀 전연결, X1 크리스털 C9006 정합(M9 종결), R36 931k → R37 105k 교체안(5.148V), VBAT 결선 정상 실측.
- **전략 효과**: 2차 샘플 배송중 상태에서 설계 수정 선완료 → **샘플 리워크 검증 통과 즉시 3차 발주 가능(리드타임 압축)**. 크리티컬 패스 = 샘플 검증으로 단일화. 발주 전 잔여 관문 = ERC/DRC·넷리스트 기계검증([[gaps]] § 2026-10-25 게이트 첫 적용 대상)·PCB 레이아웃(길이매칭·내층 GND)·샘플 리워크 실증·BOM 정합.

## 진행 상태 (2026-10-27) — delivery 정리 cascade (활성 축 3건 중 1)

- **상태 변화 없음**: 2차 샘플 **배송 중 대기** — 도착 즉시 순서 = 무전원 Phase 0 관문판정 → **R2 와이어 브리지 3~4점 시공(전원 인가 전 필수)** + R3 VCAP 점퍼 → Phase 1~5 검증 → 통과 즉시 3차 발주(리드타임 압축 전략 유지).
- 샘플 도착 전 데스크 작업(Gerber M8 판정·내층 GND CAM·검토의견 27건 회신표·ERC/DRC 기계검증·리워크 자재 준비)은 weflo vault 소관으로 병렬 진행 가능.
- 차단 사항 없음 — 크리티컬 패스 = 샘플 입수(외부 대기) 단일.
