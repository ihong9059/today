# GSD 워크플로우 (gsd)

## 개요
Get-Shit-Done 프로젝트 관리 프레임워크 학습 프로젝트. Claude Code의 GSD 스킬을 실습하기 위한 간단한 Task Tracker CLI 구현.

## 구성
- **CLI 앱**: Commander.js 기반 태스크 관리
- **계획 문서**: PROJECT.md, ROADMAP.md, REQUIREMENTS.md, STATE.md
- **단계별 실습**: phases/ 폴더에 페이즈별 문서화

## GSD 스킬 (Claude Code 연동)
- /gsd:new-project, /gsd:plan-phase, /gsd:execute-phase
- /gsd:progress, /gsd:verify-work, /gsd:ship
- 총 40+ 스킬 명령어 보유
