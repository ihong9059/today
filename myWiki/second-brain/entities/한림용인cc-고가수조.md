## ⭐ 영업 인사이트 — 한림그룹 재거래 + 영역 확장

**기존 고객 신규 사업장 + 새 사업 영역**:

```
2020년: 한림광릉CC — 무선 조명제어  (UTTEC 기존 거래)
                        │
                        │ 6년 후
                        ↓
2026년: 한림용인CC — 고가수조 자동급수 무선제어  (UTTEC 신규 거래, 영역 확장)
                        ↑
                  한림그룹 산하 다른 골프장
```

→ 매출 차원: **단발 수주가 아닌 한림그룹 내 골프장 확장 가능성**. 한림그룹 산하 다수 골프장 → 추후 같은 솔루션 복제 가능.
→ 기술 차원: **무선 조명제어 → 무선 수조제어** 영역 확장 = LoRa 무선 인프라 기술의 다목적 활용 사례.

## 시스템 사양

### 인프라 (3개 코스 / 2개 급수 노선)

| 노선 | 색 | 경로 |
|---|---|---|
| 노선1 | 파랑 | 사파이어 1·8번 연못 → 펌프1A → 중계기1 → 고가수조1 |
| 노선2 | 빨강 | 루비 6번 연못 → 펌프2 → 중계기2 → 고가수조2 |

총 노드: 펌프 ×2, 중계기 ×2, 고가수조 ×2 (+저장탱크 3개소 별도)

### 거리·통신

- 부지 직경: 약 1.5~2 km
- 노선2 거리: ~1~2 km (코스 가로지름, NLOS 환경)
- **LoRa 0.3k air rate** 사용 (LOS 15~20km / NLOS 1~3km 커버)
- 920 MHz 대역 (한국 인증)

## UTTEC 자산 매칭 — 즉시 활용 가능

### 좀 전 완성된 펌웨어 자산 (2026-05-10)

`oldProject/test/bleModule/`:
- nRF52832 + E22 LoRa config read/write 펌웨어 완성
- C1 00 09 register read 검증 / C0 03 01 [val] write 검증
- AT_COMMANDS.md mode mapping 정정 (Config = M0=0, M1=1)
- E22-400T·900T 4 모듈 air rate 0.3k 통일

→ 본 프로젝트의 LoRa 노드/중계기 펌웨어 베이스 그대로 사용 가능.
