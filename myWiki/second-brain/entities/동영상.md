# ESP32 교육 동영상 (동영상)

## 개요
ESP32 마이크로컨트롤러 교육용 영상 제작 자료. 초등 4~6학년 대상 임베디드 프로그래밍 교육.

## 콘텐츠
- **ESP32 개발환경 설치 가이드** — Arduino IDE 설정
- **ESP32 DevKitC 회로연결 분석서** — 핀 배치, 회로도
- **ESP32 프로그래밍 교육계획서** — 초등 4~6학년 대상 C/C++ 커리큘럼
- **Vrew 동영상 제작 절차서** — AI 기반 영상 편집 워크플로우
- **나의 첫 코딩: ESP32C3 준비하기** — 완성 레슨 영상 (MP4)

## 대상
- 초등학생 (4~6학년)
- Arduino IDE + C/C++ 기초
