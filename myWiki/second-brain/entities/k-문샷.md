# K-문샷 (Korea Moonshot R&D)

## 한 줄 정의
2026년 3월 11일 출범한 한국 정부의 국가 거대 미션 R&D 프로그램. **2035년까지 12대 국가 난제 해결**, AI 3강(미·중·한) 진입이 목표. 2026년 AI 단일 예산 ₩10.1조(전년 +206%).

## 거버넌스
| 항목 | 내용 |
|------|------|
| 주관 부처 | **과학기술정보통신부 (MSIT)** |
| 총괄 | **배경훈 부총리** |
| 협력 부처 | MOTIE(산업) / MSS(중기벤) / NRF(연구재단) / IITP(IT기획평가) |
| 참여 기업 | **161개사** (삼성·SK·현대차·LG·네이버·카카오·한화 + AI 스타트업 Rebellions·FuriosaAI·Upstage) |
| 출범일 | 2026-03-11 |
| 목표 연도 | 2035 |

## AI Co-Scientist — 6대 분야 (2027~2031, ₩4,640억)
"AI로 연구생산성 2배" 직접 실현 도구. 분야별 파운데이션 모델 + 특화 모델 자체 개발 → 연구자 무료 보급.

| 분야 | 적용 |
|------|------|
| 바이오 | 신약·단백질 |
| 소재 | 신소재 발굴 |
| 이차전지 | 배터리 화학 |
| 반도체 | 칩 설계·공정 |
| 디스플레이 | 패널·재료 |
| 지구과학·수학 | 기후·기초과학 |

**Google DeepMind MOU 체결** (2026), Google Seoul AI Campus 구축.

## 제도 변화 (실패 허용 R&D)
- 단기 성과 평가 면제
- 미션 PM에게 예산·인사 자율권
- 5~10년 장기 과제 트랙 신설
- 부처 칸막이 해체 (One-Team)

## UTTEC 사업 활용 가능성

### 직접 응모 — 비현실적
12개 미션은 ₩수백억~수천억 단위 거대 컨소시엄. 1인 사업자 직접 응모 불가능.

### 간접 진입 경로 — 현실적 무기
| 경로 | UTTEC 매칭 |
|------|-----------|
| **하위 발주 참여** | 컨소시엄 참여사 외주 (스마트팩토리 데모·UI·자동화) |
| **AI Co-Scientist 도입 컨설팅** | **3.5-Stage 패키지의 정확한 시장 적합** — 6대 분야 모델이 중소기업까지 보급될 때 도입 컨설팅 |
| **휴머노이드 양산 인프라** | 미션 6 (연 3만대) → 임베디드·BLE·LoRa 외주 수요 (UTTEC 38년 경력) |
| **AI 가속기 검증** | 미션 11 → 양산용 PCB·펌웨어 개발 (양산 5개 실적) |
| **인재양성 (미션 10)** | 2만 명 AI 전문가 양성 → **교육 콘텐츠 정부조달** ([[uttec-edu]] 13가이드·5 Track 영상 직결) |

### 즉시 검토 액션
1. **NTIS(국가R&D통합공고)** 가입 → K-문샷 하위 과제·미션 PM 공고 모니터링
2. **인재 양성 미션 (#10)** → uttec-edu 13가이드 정부조달 등록 검토
3. **AI Co-Scientist 출시(2027~)** 대비 영업 메시지 미리 준비 → "K-문샷이 만든 AI를 우리가 1/100 가격에 도입시켜드립니다"
