# 양산 제품 (5개 운영 중)

## 왜 중요한가
- [[strengths|강점]]의 핵심 근거: 프로토타입이 아닌 **실제 판매 중인 제품**
- [[위시캣활동|위시캣]] 지원서의 #1 셀링 포인트

## 제품 목록

### 1. STM32F756 컴프레서 밸브 컨트롤러
- MCU: STM32F756
- 기능: PID 제어, 밸브 개폐
- 통신: RS485
- 상태: 양산 판매 중

### 2. STM32F407 세탁기 컨트롤러
- MCU: STM32F407
- 기능: 세탁 프로그램 제어
- 상태: 양산 판매 중

### 3. Raspberry Pi CM4 EtherCAT 컨트롤러
- 플랫폼: Raspberry Pi CM4
- 기능: EtherCAT 산업 통신 제어
- 상태: 양산 판매 중

### 4. Raspberry Pi 3 V-Cut 컨트롤러
- 플랫폼: Raspberry Pi 3
- 기능: V-Cut 장비 제어
- 상태: 양산 판매 중

### 5. nRF52832 BLE 온도 컨트롤러
- MCU: nRF52832
- 기능: BLE 무선 온도 모니터링/제어
- 상태: 양산 판매 중

## 공통 특징

- 설계→프로토타입→양산→유지보수 전체 사이클 경험
