# 견적대장 (Quote Ledger)

UTTEC이 발행한 **모든 견적서의 중앙 인덱스**. 견적서 파일 자체는 각 프로젝트 vault에 있고(분산 저장, `feedback_vault_scope_isolation` 준수), 본 대장은 **번호·발주처·금액·상태·유효기간을 한곳에서** 추적한다. myWiki(main vault)가 sibling vault의 영업 상태를 인지하는 채널 (`feedback_cross_vault_status_awareness`).

## 규칙

- **번호 규칙**: `UTQ-YYYYMMDD-NN` (발행일 + 그날의 순번 2자리). 발번은 `today/templates/견적서/render.py` 가 본 대장을 스캔해 자동 부여.
- **금액**: 공급가액(VAT 별도) 기준 기록. 견적서 표면 총액이 VAT 포함이면 별도 환산.
- **상태**: `발송` → `수주` / `거절` / `만료`(유효기간 경과) / `보류`.
- **템플릿**: `today/templates/견적서/` 표준 렌더 엔진 사용 (LiveCow 스타일 = 표준). 신규 견적은 반드시 이 경로 사용.
- **유효기간**: 별도 명시 없으면 발행일 + 30일. 경과 시 상태 `만료`로 갱신.
