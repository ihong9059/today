# PowerDock Pro

## 한 줄 정의
Qi 무선충전기 + 외장 SSD + USB 허브를 하나로 합친 **3-in-1 데스크 액세서리**. 블루오션 확인.

## 왜 중요한가
- [[ai-fanstick]]과 함께 **AI+HW 제품화** 시도의 일환
- 시장에 3-in-1 통합 제품 없음 (Satechi, Anker, ZAGG 모두 분리 제품)
- DRAM 가격 1800% 폭등 → PC 교체주기 5~7년 연장 → 외장 스토리지 수요 증가

## 현재 상태
- 사업계획서 완성
- 경쟁 제품 시장조사 완료
- 디자인 레퍼런스 + AI 이미지 프롬프트 (DALL-E, Midjourney, Leonardo.AI)
- 프레젠테이션 + 홍보 영상 제작
- **프로토타입 미착수**

## 제품 라인업
| 모델 | 가격 | 특징 |
|------|------|------|
| Lite | 89,000원 | 15W 충전 + 256GB SSD |
| Standard | 149,000원 | 15W + 512GB + USB 허브 |
| Pro | 249,000원 | 15W + 1TB + USB 3.2 + 접이식 |
| Max | 399,000원 | 15W + 2TB + Thunderbolt |

## 핵심 수치
- 개발비: 약 2억원
- 시장 점유 목표: 1년차 1%, 3년차 5%

## 기술 스택
- Qi 1.3 무선충전
- M.2 NVMe SSD
- USB 3.2 Gen2, USB-C PD
