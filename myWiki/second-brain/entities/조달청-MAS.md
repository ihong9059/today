# 조달청 MAS — 다수공급자계약

## 한 줄 정의

**조달청 다수공급자계약** (MAS, Multiple Award Schedule) = 정부·공공기관 일괄 등록 → 수요기관 카탈로그 직접 구매 진입 채널. **공공 조달 진입 표준 패턴** (입찰 없이 진입 가능). 2026-06-06 ponet-claude 카드로 mywiki 신설 — UTTEC × Ponet cross-매칭 가설 1 (결정타) 핵심 채널.

## 본질

단가·납기·품질 일괄 등록 후 수요기관이 카탈로그에서 직접 선택·발주. 입찰 없이 진입 가능 = **공공 조달 진입 표준 패턴**.

| 단계 | 본질 |
|---|---|
| 1. **등록 신청** | 조달청 MAS 등록 신청 (제품·서비스 단가·납기·품질 일괄) |
| 2. **심사·등록** | 조달청 심사 통과 → MAS 카탈로그 등록 |
| 3. **수요기관 직접 구매** | 정부·공공기관이 카탈로그에서 직접 선택·발주 |
| 4. **납품** | OEM 공급 / 직접 납품 / 시공 통합 패키지 |

## 연계 자격 매트릭스

| 자격 | 의미 |
|---|---|
| **나라장터 등록** | 조달청 공공 조달 표준 입찰·계약 플랫폼 |
| **직접생산확인서** | 관급 직접 납품 자격 — 중소기업 우대 + 외주 의존 제거 |
| **시설공사 원가계산 적용기준** | 입찰·계약 표준 (토목공사 + 정보통신 + 가로등 등 영역별 기준) |
| **품질매뉴얼·안전관리** | 등록 심사 자격 요건 |
