# Remotion 영상 제작 (remotion-project)

## 개요
React 기반 프로그래매틱 영상 생성 프레임워크. AI 교육 레슨 동영상을 코드로 제작.

## 기술 스택
- **Remotion** — React 컴포넌트로 영상 렌더링
- **TTS** — generate_voice.py (Python 음성 합성)
- **Node.js** — 빌드/렌더 파이프라인

## 제작 실적
- AI 교육 레슨 영상 (Level 1 시리즈)
- AI 소개 영상 (AI_첫걸음_소개영상_v3)
- 스마트팩토리 제안 영상 (UTTEC, Xerix)
- 여행/관광 영상 (두물머리)
- 30+ 영상 제작 완료

## 워크플로우
1. src/에 React 컴포넌트 작성
2. Python TTS로 음성 생성
3. Remotion 렌더로 MP4 출력 (out/)
