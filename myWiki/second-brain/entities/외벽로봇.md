# 외벽청소로봇

## 한 줄 정의
건물 외벽 청소용 로봇 시스템. 원본 컨셉 분석 → 8가지 결함 발견 → 개선 설계 완료.

## 현재 상태
- 컨셉 분석보고서 완료
- 개선시스템 설계서 완료
- 개선설계 제안 영상 제작
- ESP32-C3 모바일 펌웨어 개발 리서치 완료
- **구현 미착수**

## 원본 컨셉의 8가지 결함 → 개선

| # | 원본 문제 | 개선 설계 |
|---|----------|----------|
| 1 | 드론 스프레이 (바람 취약) | 로봇 내장 노즐 (드론 제거) |
| 2 | 흡착컵 부착 (젖은 면 실패) | 스프링 가이드 휠 (연속 주행) |
| 3 | 단일 로프 (안전 부족) | 이중 로프 + 독립 안전와이어 |
| 4 | 고정 H빔 레일 (설치 90분+) | 모듈 클램프 레일 (90% 시간 절감) |
| 5 | 폐수 회수 없음 | 3단계 세척 + 폐수 회수 시스템 |
| 6 | 단일 CPU | 듀얼 CPU (FreeRTOS + Linux) |
| 7 | 단일 통신 | RS485 + CAN + Ethernet 삼중 통신 |
| 8 | 날씨 대응 없음 | LiDAR + 풍속/강우/온도 센서 |

## 기술 스택
- 듀얼 CPU: Sub CPU (FreeRTOS 실시간 모터 제어) + Main CPU (Embedded Linux AI/비전)
- RS485 + CAN bus + Ethernet (삼중 통신)
- Edge AI: 장애물 감지 <50ms
- IP65~IP67 방수등급
- 100bar 고압 노즐, 300RPM 브러시

## ESP32-C3 모바일 개발 리서치
- 스마트폰에서 펌웨어 편집→GitHub Actions 빌드→BLE OTA 전송 워크플로우
- MicroPython + Termux가 가장 실용적
- 신뢰도: MEDIUM (완성된 솔루션 없음)
