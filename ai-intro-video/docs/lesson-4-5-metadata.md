## 설명
```
PyTorch에서 데이터를 효율적으로 불러오는 방법을 배웁니다.

📚 이번 강의에서 배우는 내용:
• Dataset 클래스 - __len__과 __getitem__ 구현
• DataLoader - batch_size, shuffle, num_workers 설정
• transforms - ToTensor, Normalize, Resize, Compose
• 내장 데이터셋 - MNIST, CIFAR-10, ImageNet 활용
• 커스텀 Dataset 구현 방법

🎯 핵심 개념:
1. Dataset: 데이터를 정의하는 컨테이너
2. DataLoader: 배치 단위로 데이터 공급
3. transforms: 이미지 전처리 파이프라인

📁 데이터 파이프라인:
Raw Data → Dataset → DataLoader → Model

💡 실무 팁:
• batch_size는 GPU 메모리에 맞게 설정
• num_workers로 병렬 로딩 활성화
• shuffle=True로 학습 데이터 섞기
• Normalize로 모델 학습 안정화
```
