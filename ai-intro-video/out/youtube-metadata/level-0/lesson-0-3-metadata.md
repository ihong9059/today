AI 학습은 반복문 안에서 일어나는 마법입니다! 🔄

이 영상에서는 AI 학습의 핵심인 조건문과 반복문을 배웁니다.
Epoch, Batch, Early Stopping - 이 모든 것이 for와 while 루프로 구현됩니다!

━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━

✅ for 반복문과 range()
   • for epoch in range(100): → 100번 학습 반복
   • Epoch = 전체 데이터를 한 번 학습하는 단위

✅ 중첩 for 루프 - Batch 처리
   • 바깥 for: Epoch 반복
   • 안쪽 for: Batch 처리
   • 대량의 데이터를 조각내서 학습!

✅ if 조건문 - Early Stopping
   • if val_loss < best_loss: 모델 저장
   • if patience > 10: break → 조기 종료
   • 과적합을 방지하는 핵심 기술!

✅ 학습률 스케줄링
   • if epoch > 50: lr *= 0.1
   • 학습 후반에 섬세하게 조정

✅ while 반복문
   • while accuracy < 0.95: 목표 달성까지 학습
   • 강화학습에서 자주 사용

✅ PyTorch 실제 코드
   • 실제 학습 루프 구조 이해
   • 어디서 forward, backward, step이 일어나는지

## 핵심 학습 포인트

1. **for + range = Epoch**: `for epoch in range(100):` → 100번 반복 학습
2. **중첩 for = Batch 처리**: 대량 데이터를 조각내서 처리
3. **if = 조건부 저장**: `if val_loss < best_loss:` → 최고 모델 저장
4. **break = Early Stopping**: 과적합 방지를 위한 조기 종료
5. **while = 목표 기반 학습**: 정확도 95% 달성까지 학습
6. **PyTorch 학습 루프**: forward → loss → backward → step
