# Lesson 8-1: GPU vs CPU

## 제목
[AI 기초] Lesson 8-1: GPU vs CPU - 왜 딥러닝에 GPU가 필수일까? | Level 8

## 설명
Level 8 GPU 프로그래밍의 첫 번째 강의입니다!

GPU와 CPU의 근본적인 차이점을 이해하고, 왜 딥러닝에서 GPU가 필수적인지 알아봅니다.

4:05 정리 및 다음 강의 예고

📊 핵심 학습 내용:
✅ CPU: 적은 수(4~16개)의 강력한 코어, 복잡한 순차 작업에 적합
✅ GPU: 수천 개의 작은 코어, 대량의 병렬 연산에 특화
✅ SIMT (Single Instruction Multiple Threads): 하나의 명령으로 수천 스레드 실행
✅ 행렬 곱셈에서 GPU가 CPU보다 100배 이상 빠름
✅ GPU 메모리 대역폭: CPU 대비 약 20배 (HBM2 vs DDR4)

💡 왜 딥러닝에 GPU가 필수인가?
딥러닝의 핵심 연산인 행렬 곱셈은 완벽한 병렬 작업입니다.
신경망 학습에서 이런 연산이 수백만 번 반복되기 때문에,
GPU 없이는 현대 AI 모델 학습이 사실상 불가능합니다!
