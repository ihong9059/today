### 설명
```
신경망의 핵심 요소인 활성화 함수(Activation Functions)를 완벽하게 정리합니다!

이번 강의에서 배우는 내용:
- 왜 활성화 함수가 필요한가? (비선형성의 중요성)
- Sigmoid: 0~1 출력, 확률 해석, 기울기 소실 문제
- Tanh: -1~1 출력, 0 중심, Sigmoid보다 나은 점
- ReLU: 현대 딥러닝의 기본! 빠르고 기울기 소실 없음
- Softmax: 다중 분류 출력층에 필수
- 언제 어떤 활성화 함수를 써야 할까?

핵심 가이드:
- 은닉층 → ReLU (기본 선택!)
- 이진 분류 출력 → Sigmoid
- 다중 분류 출력 → Softmax
- 특수 경우 → Tanh, Leaky ReLU
```
