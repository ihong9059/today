## 설명
LLM(대형 언어 모델)이 어떻게 텍스트를 이해하고 생성하는지 내부 작동 원리를 완벽하게 이해할 수 있는 강의입니다!

이 영상에서 다루는 내용:
- 토큰화(Tokenization)의 원리와 필요성
- BPE(Byte Pair Encoding) 알고리즘 이해
- 서브워드(Subword) 토큰화의 장점
- 임베딩(Embedding): 토큰 ID를 벡터로 변환
- LLM 추론 과정: 입력 → Transformer → 출력
- Greedy Decoding: 가장 확실한 토큰 선택
- Temperature Sampling: 다양성 조절하기
- Top-k Sampling: 상위 k개 후보에서 선택
- Top-p (Nucleus) Sampling: 누적 확률 기반 선택
- KV Cache 최적화로 추론 속도 향상
