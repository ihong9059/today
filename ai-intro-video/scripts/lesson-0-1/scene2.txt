먼저 파이썬을 설치해보겠습니다.
웹 브라우저를 열고 python.org에 접속합니다.
Downloads 메뉴를 클릭하면, 운영체제에 맞는 최신 버전이 자동으로 표시됩니다.
다운로드 버튼을 클릭해서 설치 파일을 받습니다.
설치 파일을 실행하면 설치 화면이 나타납니다.
여기서 중요한 점이 있습니다.
반드시 "Add Python to PATH" 옵션을 체크해주세요.
이 옵션을 체크하지 않으면, 나중에 터미널에서 파이썬을 실행할 수 없습니다.
Install Now를 클릭하면 설치가 시작됩니다.
설치가 완료되면 터미널을 열어서 확인해볼게요.
python --version 또는 python3 --version을 입력합니다.
버전 정보가 나타나면 설치가 성공한 겁니다.
