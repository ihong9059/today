## 총 예상 시간: 약 6분 (360초)

## Scene 1: 인트로 (0-20초)

안녕하세요, AI 첫걸음입니다.
오늘은 AI 학습의 첫 번째 단계, 파이썬 환경 설정에 대해 알아보겠습니다.
파이썬은 AI와 머신러닝 분야에서 가장 많이 사용되는 프로그래밍 언어입니다.
지금부터 차근차근 설치해볼게요.

## Scene 2: Python 설치 (20-90초)

먼저 파이썬을 설치해보겠습니다.
웹 브라우저를 열고 python.org에 접속합니다.
Downloads 메뉴를 클릭하면, 운영체제에 맞는 최신 버전이 자동으로 표시됩니다.

다운로드 버튼을 클릭해서 설치 파일을 받습니다.
설치 파일을 실행하면 설치 화면이 나타납니다.
여기서 중요한 점이 있습니다.
반드시 "Add Python to PATH" 옵션을 체크해주세요.
이 옵션을 체크하지 않으면, 나중에 터미널에서 파이썬을 실행할 수 없습니다.

Install Now를 클릭하면 설치가 시작됩니다.
설치가 완료되면 터미널을 열어서 확인해볼게요.
python --version 또는 python3 --version을 입력합니다.
버전 정보가 나타나면 설치가 성공한 겁니다.

## Scene 3: IDE 소개 (90-150초)

이제 파이썬 코드를 작성할 도구, IDE를 선택해보겠습니다.
IDE는 통합 개발 환경의 약자로, 코드 작성, 실행, 디버깅을 한 곳에서 할 수 있는 프로그램입니다.

세 가지 인기 있는 선택지를 소개해드릴게요.

첫 번째는 VS Code입니다.
마이크로소프트에서 만든 무료 에디터로, 가볍고 확장성이 뛰어납니다.
파이썬뿐만 아니라 다양한 언어를 지원합니다.
초보자부터 전문가까지 가장 많이 사용하는 도구입니다.

두 번째는 PyCharm입니다.
JetBrains에서 만든 파이썬 전용 IDE입니다.
무료 Community 버전과 유료 Professional 버전이 있습니다.
파이썬에 특화된 강력한 기능들을 제공합니다.

세 번째는 Jupyter Notebook입니다.
웹 브라우저에서 실행되는 대화형 환경입니다.
코드를 셀 단위로 실행하고, 결과를 바로 확인할 수 있어서
데이터 분석과 머신러닝 실습에 아주 유용합니다.

## Scene 4: VS Code 설치 (150-210초)

이 강좌에서는 VS Code를 기준으로 진행하겠습니다.
code.visualstudio.com에 접속해서 다운로드 버튼을 클릭합니다.
설치 파일을 실행하고 기본 설정으로 설치를 진행합니다.

설치가 완료되면 VS Code를 실행합니다.
왼쪽 사이드바에서 확장 아이콘을 클릭합니다.
검색창에 Python을 입력하고, Microsoft에서 만든 Python 확장을 설치합니다.
이 확장은 코드 자동완성, 문법 검사, 디버깅 등 필수 기능을 제공합니다.

새 파일을 만들고 hello.py로 저장합니다.
print("Hello, AI!")를 입력하고 실행해보세요.
오른쪽 상단의 재생 버튼을 클릭하거나, 터미널에서 python hello.py를 실행합니다.
Hello, AI!가 출력되면 성공입니다.

## Scene 5: Jupyter Notebook 설치 (210-270초)

이제 Jupyter Notebook을 설치해보겠습니다.
터미널을 열고 다음 명령어를 입력합니다.
pip install jupyter

설치가 완료되면, jupyter notebook 명령어로 실행합니다.
웹 브라우저가 자동으로 열리면서 Jupyter 인터페이스가 나타납니다.

오른쪽 상단의 New 버튼을 클릭하고 Python 3를 선택합니다.
새 노트북이 생성되었습니다.

첫 번째 셀에 print("Hello from Jupyter!")를 입력합니다.
Shift + Enter를 누르면 코드가 실행되고 결과가 바로 아래에 표시됩니다.
이렇게 셀 단위로 코드를 실행하면서 결과를 확인할 수 있어서
학습할 때 매우 편리합니다.

## Scene 6: 가상환경 (270-340초)

마지막으로 가상환경에 대해 알아보겠습니다.
가상환경은 프로젝트별로 독립적인 파이썬 환경을 만드는 기능입니다.
왜 필요할까요?

프로젝트마다 필요한 라이브러리 버전이 다를 수 있습니다.
예를 들어, 프로젝트 A는 텐서플로우 2.0이 필요하고,
프로젝트 B는 텐서플로우 1.5가 필요할 수 있습니다.
가상환경을 사용하면 이런 충돌을 방지할 수 있습니다.

가상환경을 만드는 방법을 알아볼게요.
터미널에서 python -m venv myenv를 입력합니다.
myenv는 가상환경 이름으로, 원하는 이름으로 바꿀 수 있습니다.

가상환경을 활성화하려면,
윈도우에서는 myenv\Scripts\activate를 입력하고,
맥이나 리눅스에서는 source myenv/bin/activate를 입력합니다.

활성화되면 터미널 앞에 (myenv)가 표시됩니다.
이제 이 환경에서 설치하는 라이브러리는 이 프로젝트에만 적용됩니다.
비활성화하려면 deactivate를 입력하면 됩니다.
