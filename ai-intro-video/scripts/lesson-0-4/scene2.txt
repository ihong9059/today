먼저 함수의 기본 구조를 알아보겠습니다.

함수는 입력을 받아서, 처리하고, 출력을 반환하는 블랙박스입니다.

파이썬에서는 def 키워드로 함수를 정의합니다.

def 함수이름, 괄호 안에 입력, 그리고 콜론.
안쪽에서 처리를 하고,
return으로 출력을 반환합니다.

예를 들어, 두 수를 더하는 함수를 봅시다.

def add(a, b): return a + b

add 3, 5를 호출하면 8이 반환됩니다.

이게 바로 함수의 핵심입니다.
입력, 처리, 출력.

신경망도 완전히 똑같습니다!

이미지를 입력하면, 특징을 추출하고, 활성화하고, 분류해서,
예측 결과를 출력합니다.

고양이 사진을 넣으면 "고양이"라는 결과가 나오는 거죠.

결국 AI 모델도 하나의 거대한 함수입니다.
