다음은 딕셔너리입니다.
딕셔너리는 키와 값의 쌍으로 데이터를 저장합니다.

중괄호로 감싸고, 키 콜론 값 형태로 작성합니다.
person 이콜 중괄호, 따옴표 name 따옴표 콜론 따옴표 홍길동 따옴표,
따옴표 age 따옴표 콜론 삼십, 중괄호.

딕셔너리는 AI에서 구조화된 데이터를 다룰 때 사용됩니다.

예를 들어, 모델 설정을 저장할 때 유용합니다.
config 이콜 중괄호,
따옴표 learning 언더바 rate 따옴표 콜론 영점 영영일,
따옴표 epochs 따옴표 콜론 백,
따옴표 batch 언더바 size 따옴표 콜론 삼십이,
중괄호.

이렇게 모델의 학습 설정을 한눈에 볼 수 있습니다.
값을 가져올 때는 키를 사용합니다.
config 대괄호 따옴표 learning 언더바 rate 따옴표 대괄호.
이렇게 하면 영점 영영일이 반환됩니다.
