## 1. 최근 수능 국어 출제 경향 분석 (2023~2025)

### 1.1 전체적인 변화 흐름

| 연도 | 특징 | 난이도 |
|------|------|--------|
| 2023학년도 | 킬러문항 존재, 극단적 난이도 분포 | 1등급 컷 촘촘 |
| 2024학년도 | 킬러문항 배제 시작, 문학 변별력 강화 | 독서 평이, 문학 어려움 |
| 2025학년도 | 안정화, 중간 난이도 문항 증가 | 전반적으로 평이 |

### 1.2 킬러문항 배제 이후 변화

- **독서(비문학)**: 초고난도 추론 문항 감소, EBS 연계율 상승 (51.1%)
- **문학**: 변별력 확보를 위해 난이도 상승
  - 현대시: 길이가 긴 시, 해석 난이도 높은 작품 출제
  - 현대소설: 의도적 맥락 생략으로 이해 난이도 상승
- **준킬러/비킬러 강화**: 극단적 난이도보다 중상 수준 문항 증가

### 1.3 영역별 출제 경향

#### 독서 (비문학) - 4지문 17문항
| 지문 유형 | 문항 수 | 특징 |
|----------|---------|------|
| 독서론 | 3문항 | 2022학년도부터 신유형 추가 |
| 인문/예술 | 4문항 | 논리학 출제 시 고난도 |
| 법/경제/사회 | 4문항 | 안정적 출제 |
| 과학/기술 | 6문항 | (가)(나) 복합형 지문 |

#### 문학 - 4지문 17문항
| 갈래 | 출제 형태 | EBS 연계 |
|------|----------|----------|
| 현대시 | 복합지문 (시+수필 등) | 1편 연계 + 1편 비연계 |
| 고전시가 | 복합지문 | 1편 연계 + 1편 비연계 |
| 현대소설 | 단독 지문 | 비연계/작가연계 (2022 이후) |
| 고전소설 | 단독 지문 | 연계 (다른 부분 출제) |

#### 선택과목
| 과목 | 구성 | 1등급 컷 (2025) |
|------|------|----------------|
| 화법과 작문 | 화법 3문항 + 작문 5문항 + 복합 3문항 | 100점 |
| 언어와 매체 | 언어 5문항 + 매체 5문항 + 복합 1문항 | 97점 |

## 2. 커리큘럼 설계 제안

### 2.1 코스 구조 (기존 영어/수학/탐구 형식 참고)

UTTEC Edu의 기존 코스처럼 **AI 프롬프트 기반 학습 + 유튜브 참고 영상** 형식으로 구성

```
국어 코스 구조
├── 독서 (비문학) - 45일
├── 문학 - 45일
├── 화법과 작문 (선택) - 30일
├── 언어와 매체 (선택) - 30일
└── 수능 국어 실전 - 45일
```

| 단원 | 일수 | 주요 내용 |

| 2. 인문 | 8일 | 철학, 윤리, 역사, 논리학 지문 |
| 3. 사회 | 8일 | 법, 경제, 정치, 사회 현상 지문 |
| 4. 과학 | 8일 | 물리, 화학, 생명과학, 지구과학 지문 |
| 5. 기술 | 8일 | 공학, IT, 기술 원리 지문 |
| 6. 예술 | 3일 | 미술, 음악, 건축, 문학론 지문 |

