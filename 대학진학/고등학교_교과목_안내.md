### 선택과목 체계
> 고2부터 계열에 따라 선택과목 이수

```
선택과목
├── 일반선택 : 교과별 기본 심화 과목
├── 진로선택 : 진로/적성에 따른 과목
```

## 5. 계열별 선택과목 가이드

### 인문·사회계열

#### 어문/인문학
```
필수: 문학, 독서와 작문, 화법과 언어
추천: 주제 탐구 독서, 세계사, 윤리와 사상
수능: 생활과윤리/윤리와사상/사회문화
```

#### 경영/경제학
```
필수: 확률과 통계, 경제, 사회문화 탐구
추천: 대수, 금융과 경제생활
수능: 경제/사회문화/생활과윤리
```

#### 법학/정치외교
```
필수: 정치, 법과 사회, 세계사
추천: 동아시아 역사, 윤리와 사상
수능: 정치와법/사회문화/생활과윤리
```

#### 사회과학
```
필수: 사회문화 탐구, 한국지리/세계지리
추천: 정치, 경제, 통계
수능: 사회문화/한국지리/생활과윤리
```

### 자연·공학계열

#### 공학 (기계/전기전자/컴퓨터)
```
필수: 미적분Ⅰ,Ⅱ, 기하, 물리학
추천: 화학, 확률과 통계
수능: 물리학/화학/지구과학
```

#### 자연과학 (수학/물리/화학)
```
필수: 미적분Ⅰ,Ⅱ, 기하, 해당 과학 심화
추천: 수학과제 탐구, 과학 Ⅱ과목
수능: 해당 Ⅱ과목 + 관련 과목
```

#### 생명/화학공학
```
필수: 화학, 생명과학, 미적분Ⅰ
추천: 물질과 에너지, 세포와 물질대사
수능: 화학/생명과학
```

#### 건축/토목
```
필수: 미적분Ⅰ,Ⅱ, 물리학, 기하
추천: 화학, 지구과학
수능: 물리학/화학/지구과학
```

### 의약계열

#### 의대/치대/한의대
```
필수: 미적분Ⅰ,Ⅱ, 화학, 생명과학
추천: 물질과 에너지, 세포와 물질대사
수능: 화학/생명과학 (Ⅱ과목 권장)
```

#### 약학/수의학
```
필수: 화학, 생명과학, 미적분Ⅰ
추천: 화학 심화, 생명과학 심화
수능: 화학/생명과학
```

#### 간호학
```
필수: 생명과학, 화학
추천: 미적분Ⅰ, 확률과 통계
수능: 생명과학/화학 또는 생명과학/지구과학
```

### 예체능계열

#### 음악
```
필수: 음악 전공 실기, 음악 이론
추천: 문학, 세계사
수능: 인문계 조합 (내신형 많음)
```

#### 미술/디자인
```
필수: 미술 전공 실기, 미술 이론
추천: 문학, 미디어
수능: 인문계 조합 + 실기
```

#### 체육
```
필수: 체육 전공 실기, 스포츠 과학
추천: 생명과학, 확률과 통계
수능: 인문계 또는 자연계 + 실기
```

## 6. 대입과 교과목 연계

### 학생부교과전형
| 요소 | 반영 방법 |
|------|----------|
| 내신 등급 | 주요 교과 평균 등급 |
| 반영 교과 | 국영수 + 계열 관련 교과 |
| 가산점 | 진로선택과목 성취도 |

### 학생부종합전형
| 요소 | 평가 내용 |
|------|----------|
| 교과 성적 | 전체적인 학업 역량 |
| 세부능력특기사항 | 수업 참여도, 탐구 활동 |
| 선택과목 | 진로 연계 과목 선택 |
| 성적 추이 | 상승세 긍정 평가 |

### 수능과 선택과목

#### 2025학년도 수능 (2015 개정)
| 영역 | 선택과목 |
|------|----------|
| 국어 | 화법과 작문 / 언어와 매체 |
| 수학 | 확률과 통계 / 미적분 / 기하 |
| 탐구 | 사탐 9과목 / 과탐 8과목 중 2과목 |

#### 2028학년도 수능 (2022 개정, 예정)
| 영역 | 변경 사항 |
|------|----------|
| 국어 | 선택과목 폐지, 공통 출제 |
| 수학 | 선택과목 폐지, 공통 출제 |
| 탐구 | 사탐/과탐 통합 가능성 |

### 선택과목과 대입 전략

#### 수시 중심
- 내신 관리 가능한 과목 선택
- 진로 연계 과목으로 일관성
- 세특 기재 유리한 과목

#### 정시 중심
- 수능 선택과목과 일치
- 본인 적성에 맞는 과목
- 표준점수 유리한 조합 고려
