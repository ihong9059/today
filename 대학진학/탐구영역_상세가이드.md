## 1. 탐구영역 개요

### 기본 정보
| 항목 | 내용 |
|------|------|
| 시험 시간 | 과목당 30분 (총 60분, 쉬는 시간 2분 포함) |
| 문항 수 | 과목당 20문항 |
| 배점 | 과목당 50점 (2점 문항 12개, 3점 문항 8개) |
| 선택 과목 수 | 최대 2과목 |
| 응시 가능 조합 | 사탐+사탐, 과탐+과탐, 사탐+과탐 |

### 대학별 반영 방식
| 계열 | 주요 대학 요구사항 |
|------|-------------------|
| 인문계열 | 사회탐구 2과목 또는 사탐+과탐 |
| 자연계열 | 과학탐구 2과목 (서로 다른 분야 권장) |
| 의약계열 | 과학탐구 2과목 (Ⅱ과목 필수인 경우 多) |
| 교차지원 | 대학마다 상이 (요강 확인 필수) |

## 2. 사회탐구 과목별 분석

### 2-1. 생활과 윤리

| 항목 | 내용 |
|------|------|
| 학습량 | ★★☆☆☆ (적음) |
| 난이도 | ★★☆☆☆ (쉬움) |
| 1등급 컷 | 보통 47~50점 |
| 선택 비율 | 매우 높음 (1위) |

**주요 내용**
- 현대 생활의 윤리적 문제
- 생명윤리, 환경윤리, 정보윤리
- 사회정의, 평화와 공존

**특징**
- 암기량 적음, 개념 이해 중심
- 윤리 사상가별 입장 비교 중요
- 적용형 문제 출제

**추천 대상**: 암기가 부담스러운 학생, 시간이 부족한 학생

## 4. 과목 선택 가이드

### 계열별 추천 조합

#### 인문계열
| 조합 | 특징 | 추천 대상 |
|------|------|----------|
| 생활과윤리 + 사회문화 | 학습량 적음, 1등급 유리 | 시간 부족, 안정 추구 |
| 생활과윤리 + 한국지리 | 균형 잡힌 조합 | 지리 관심 있는 학생 |
| 윤리와사상 + 동아시아사 | 역사+철학 연계 | 인문학 관심 학생 |
| 정치와법 + 사회문화 | 사회과학 계열 | 법대/정치외교 지망 |

#### 자연계열 (일반)
| 조합 | 특징 | 추천 대상 |
|------|------|----------|
| 생명과학Ⅰ + 지구과학Ⅰ | 암기 위주, 접근 쉬움 | 물화 어려워하는 학생 |
| 화학Ⅰ + 생명과학Ⅰ | 가장 보편적 조합 | 대부분의 자연계열 |
| 물리Ⅰ + 화학Ⅰ | 공학 계열 최적 | 공대 지망생 |
| 화학Ⅰ + 지구과학Ⅰ | 균형 조합 | 화학 좋아하는 학생 |

#### 의약계열
| 조합 | 특징 | 추천 대상 |
|------|------|----------|

| 화학Ⅱ + 생명과학Ⅱ | 최상위권 | 서울권 의대 |
| 물리Ⅰ + 화학Ⅱ | 물리 필수 대학 | 일부 의대 |
| 화학Ⅰ + 생명과학Ⅱ | Ⅱ과목 1개 필요시 | 상위권 의대 |

### 선택 시 고려사항

1. **대학별 지정과목 확인**
   - 일부 대학은 Ⅱ과목 필수
   - 동일 분야 2과목 불가인 경우 있음
   - 특정 과목 가산점 부여 대학 확인

2. **본인 적성 고려**
   - 암기형 vs 이해형
   - 계산 선호 vs 기피
   - 고교 내신 과목과 연계

3. **표준점수/백분위 유불리**
   - 선택자 수에 따른 유불리
   - 상위권 집중 과목 주의
   - 매년 난이도 변동 고려
