## 1단계: 빌드 (PC에서 1회만 수행)

### 무엇을 만드나?

105개 항목 각각에 대해 **3가지 파일**을 생성합니다:

```
firmware_db/A01/
  ├── firmware.bin    ← 컴파일된 펌웨어 (보드에 올릴 바이너리)
  ├── code.ino        ← Arduino 소스코드 (학생이 볼 코드)
  └── guide.json      ← 학습 가이드 (설명, 퀴즈, 개념)
```

### 빌드 과정

```
catalog_source.json          prebuild.py / batch_compile.py
  (105개 항목 정의)     ──▶   항목별로:
  - no: A01                    1. code.ino 생성 (Claude 또는 내장 코드)
  - user_prompt               2. base firmware + code.ino 머지
  - tags, difficulty           3. arduino-cli 컴파일 → firmware.bin
  - components                 4. guide.json 생성 (학습 자료)
                               5. catalog.json 재생성 (전체 목록)
```

### 결과물

```
firmware_db/
  ├── catalog.json          ← 전체 105개 항목 메타정보 (검색/필터용)
  ├── A01/
  │   ├── firmware.bin      ← 745KB (LED 빨간색)
  │   ├── code.ino          ← Arduino 소스코드
  │   └── guide.json        ← 학습 가이드
  ├── A02/ ...
  ├── ...
  └── O06/
```

## 2단계: SD 카드 준비 (1회 복사)

### SD 카드에 넣을 내용

SD 카드는 **모든 데이터의 오프라인 저장소**입니다.
인터넷 없이도 교육이 가능하도록 firmware + 소스코드 + 학습자료를 모두 담습니다.

```
SD 카드 (MicroSD)
  ├── /firmware/              ← 펌웨어 바이너리 (보드 플래시용)
  │   ├── A01.bin
  │   ├── A02.bin
  │   ├── ...
  │   └── O06.bin
  │
  ├── /code/                  ← Arduino 소스코드 (학습용)
  │   ├── A01.ino
  │   ├── A02.ino
  │   ├── ...
  │   └── O06.ino
  │
  ├── /guide/                 ← 학습 가이드 JSON (설명, 퀴즈)
  │   ├── A01.json
  │   ├── A02.json
  │   ├── ...
  │   └── O06.json
  │
  └── catalog.json            ← 전체 목록 (앱에서 읽기)
```

### SD 카드 복사 스크립트 (1회 실행)

```
PC의 firmware_db/     ──복사──▶    SD 카드
  A01/firmware.bin                /firmware/A01.bin
  A01/code.ino                   /code/A01.ino
  A01/guide.json                 /guide/A01.json
  catalog.json                   /catalog.json
```

### 왜 SD 카드에 코드와 가이드도 넣나?

| 파일 | 용도 | 왜 SD에? |
|------|------|----------|
| firmware.bin | 보드에 즉시 플래시 | BLE OTA 없이 **3~5초** 만에 로드 |
| code.ino | 학생이 "어떤 코드인지" 확인 | 인터넷 없이도 소스 열람 가능 |
| guide.json | 동작 설명, 핵심 개념, 퀴즈 | 교실에서 오프라인 학습 가능 |
| catalog.json | 항목 검색, 필터링 | 앱이 서버 없이 목록 표시 |

## 3단계: 수업 중 사용 흐름

### 흐름 A — 사전빌드 예시 즉시 체험 (가장 빠름)

```
학생이 앱에서 예시 선택 (예: "경찰차 사이렌")
         │
         ▼
┌─────────────────────┐
│ 앱: catalog.json에서 │
│ C05 항목 찾기        │
│ 설명/코드 표시       │
└───────���┬────────────┘
         │ BLE 명령: SDLOAD:C05
         ▼
┌─────────────────────┐
│ 보드: SD 카드에서     │
│ /firmware/C05.bin    │
│ 읽어서 자체 플래시    │
└────────┬────────────┘
         │ 자동 재부팅 (3~5초)
         ▼
┌─────────────────────┐
│ 보드: 경찰차 사이렌   │
│ LED 빨파 깜빡!       │
│ (바로 동작 확인)      │
└─────────────────────┘
         │
         ▼
┌─────────────────────┐
│ 앱: guide.json 표시  │
│ - "이 코드가 하는 일" │
│ - "핵심 개념 설명"    │
│ - "퀴즈 풀어보기"     │
│ - "소스코드 보기"     │
└─────────────────────┘
```

**소요 시간: 선택 → 동작 확인 → 학습까지 약 10초**

### 흐름 B — AI로 새 코드 생성 (창의적 학습)

```
학생이 앱에서 직접 입력: "무지개색 하트 그려줘"
         │
         ▼
┌─────────────────────┐
│ 앱 → 빌드서버(:8097) │
│ Claude가 코드 생성    │
│ arduino-cli 컴파일    │
└────────┬────────────┘
         │ BLE OTA 전송 (~40초)
         ▼
┌─────────────────────┐
│ 보드: 새 펌웨어 실행  │
│ LCD에 무지개 하트!    │
└─────────────────────┘
```

**소요 시간: 약 1~2분 (코드생성 + 컴파일 + OTA)**

### 흐름 비교

| | 사전빌드 (SD) | AI 생성 (OTA) |
|:---:|:---:|:---:|
| 속도 | **3~5초** | 1~2분 |
| 인터넷 | 불필요 | 필요 (Claude API) |
| 내용 | 105개 고정 예시 | 무제한 자유 입력 |
| 학습자료 | guide.json 포함 | 없음 (코드만) |
| 용도 | 수업 시연, 기초 학습 | 창의적 실험 |

## 5단계: 보드 내부 동작 (SDLOAD 명령)

```
BLE 수신: "SDLOAD:C05"
    │
    ▼
SD 카드 열기: /firmware/C05.bin
    │
    ▼
파일 크기 확인 (예: 745KB)
    │
    ▼
Update.begin(745KB)
    │
    ▼
4KB 단위로 읽기 → Update.write()
    │  (약 186회 반복)
    ▼
Update.end(true) → 검증
    │
    ▼
ESP.restart() → 새 펌웨어로 재부팅
    │
    ▼
경찰차 사이렌 동작! 🚨
```

## 파일별 역할 정리

| 파일 | 위치 | 역할 | 누가 사용 |
|------|------|------|----------|
| catalog_source.json | PC/prebuild/ | 105개 항목 원본 정의 | prebuild.py |
| firmware.bin | SD:/firmware/ | 컴파일된 바이너리 | 보드 (SDLOAD) |
| code.ino | SD:/code/ | Arduino 소스코드 | 앱 (학생이 코드 학습) |
| guide.json | SD:/guide/ | 학습가이드/퀴즈 | 앱 (학생이 개념 학습) |
| catalog.json | SD:/ | 전체 목록+메타정보 | 앱 (목록 표시/검색) |
| merged.ino | PC만 (SD에 안 넣음) | base+user 머지 코드 | 디버깅용 |
| system_prompt.txt | PC만 | Claude 프롬프트 | 디버깅용 |

## 핵심 포인트

1. **SD 카드 = 오프라인 교육의 핵심**
   - 인터넷 없는 교실에서도 105개 예시를 즉시 체험 가능
   - firmware뿐 아니라 소스코드와 학습자료도 SD에 저장

2. **3가지 학습 ���계**
   - [로드] → "와, 이렇게 동작하는구나!" (체험)
   - [코드] → "이 코드가 이렇게 만드는구나!" (이해)
   - [설명] → "이 개념은 이런 뜻이구나!" (학습)

3. **속도가 핵심**
   - SD 로드: 3~5초 (수업 흐름 끊기지 않음)
   - BLE OTA: 40초~2분 (AI 생성 시에만 사용)

4. **확장성**
   - 사전빌드 105개로 기초~고급 커버
   - AI 생성으로 학생의 창의적 요청 대응
   - 커스텀 빌드도 Z카테고리로 SD에 추가 가능
