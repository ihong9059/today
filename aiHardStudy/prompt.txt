가능성

software 바이브 코딩을 실시하는 앱을 만들려고 합니다.
전체적인 절차는,
client에게는 esp32c3가 smartphone(android phone)과 ble로 ota를 할수있도록 되어있어요.
client가 esp32c3가 수행할 기능을, 
cloud server에 prompt할수있도록 하는 app이 준비되어있어요.
이 app에 수행할 기능을 입력하면, cloud server가 claude에게,
해당 기능을 수행할수있도록 요구하고, 
claude는 그에따라 수행할 image(bin file)를 만들어,
client의 smartphone에 download해줍니다.
그 app은 download받은 image를 ota를 통하여 esp32c3에 flash합니다.
이렇게 진행하기 위해서, cloud server는  Claude Code CLI (claude -p)를 사용합니다.
