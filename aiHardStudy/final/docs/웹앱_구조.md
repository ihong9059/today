## 4. API 통신

| API | Method | 용도 |
|-----|--------|------|
| `/api/v1/health` | GET | 서버 상태 확인 |

| `/api/v1/chat` | POST | 코딩 질문 AI 답변 |

## 5. BLE 통신

**서비스 UUID**: `0000fe00-...`

| Characteristic | UUID 끝 | 용도 |
|----------------|---------|------|
| OTA_CTRL | fe01 | OTA 시작(0x01)/완료(0x02)/중단(0x03) 제어 |
| OTA_DATA | fe02 | 펌웨어 바이너리 전송 (240B 청크) |
| OTA_STATUS | fe03 | OTA 상태 알림 (Notification) |
| OTA_CMD | fe04 | 직접 명령 전송 (LED, 부저, OLED 등) |
| OTA_SENSOR | fe05 | 센서 데이터 수신 (스위치 상태) |

**OTA 전송 흐름**:
```
CTRL(0x01 + 4B size) → DATA(240B × N청크) → CTRL(0x02 완료)
```

**직접 명령 프로토콜** (OTA_CMD에 텍스트 전송):
```
LED_RED_ON, LED_RED_OFF, LED_YELLOW_ON, LED_ALL_OFF
BEEP, NOTE_0~NOTE_7
OLED:{텍스트}, TEMP, SETNAME:{이름}
```
