## 웹앱 칩 배치 제안

현재 5개 → 카테고리별 대표 프롬프트로 확장 가능:

```
[LED 기초]  빨간 LED 켜기 | LED 깜빡이기 | LED 5번 깜빡이고 멈추기
[다중 LED]  신호등 만들기 | LED 순서대로 켜기 | 비상등 만들기
[부저]      부저 3번 울리기 | 도레미파솔라시도 | 학교종 멜로디
[OLED]      OLED에 내 이름 표시 | 카운트다운 표시 | 숫자 세기
[센서]      온도 측정하기 | 온도 OLED 표시 | 온도 높으면 LED 켜기
[스위치]    스위치로 LED 켜기 | 누른 횟수 세기 | LED 색 바꾸기
[게임]      반응속도 테스트 | 주사위 | 룰렛
[생활]      라면 타이머 | 현관 벨 | 교실 온도 모니터
```
