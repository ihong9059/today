## 1. 준비물 확인하기

수업을 시작하기 전에 아래 3가지가 있는지 확인하세요.

```
  ✅ 1. UTTEC 보드                   ✅ 2. USB 케이블             ✅ 3. 스마트폰
  ┌──────────────────┐              ┌───────────┐             ┌──────────────┐
  │  📟               │              │  ═══════   │             │  📱            │
  │  LED 🔴🟡🔵       │              │  USB-C     │             │  Chrome       │
  │  화면 📺          │              │  또는      │             │  브라우저      │
  │  부저 🔔🎵        │              │  Micro-USB │             │               │
  │  센서 🌡️         │              │            │             │  Wi-Fi 연결    │
  │  스위치 🔘        │              └───────────┘             │  블루투스 ON   │
  └──────────────────┘                                        └──────────────┘
```

| 준비물 | 왜 필요한가요? |
|--------|--------------|
| **UTTEC 보드** | LED, 부저, 센서 등이 달린 작은 컴퓨터. 내가 만든 프로그램이 여기서 실행됩니다 |
| **USB 케이블** | 보드에 전원을 공급합니다. 보조배터리나 컴퓨터 USB에 연결하세요 |
| **스마트폰** | 프롬프트를 입력하고, 블루투스로 보드에 프로그램을 보냅니다 |

## 2. 보드 살펴보기

UTTEC 보드에는 6가지 부품이 달려 있습니다. 각 부품이 어디에 있는지 찾아보세요.

```
  ┌────────────────────────────────────────────────────┐
  │                 UTTEC 보드 (앞면)                    │
  │                                                     │
  │   🔴 빨간 LED      🟡 노란 LED      🔵 파란 LED     │
  │                                                     │
  │   🔔 부저 (삐!)      🎵 멜로디 부저                  │
  │                                                     │
  │   ┌──────────────────────────┐                     │
  │   │  📺 OLED 화면             │                     │
  │   │  (작은 디스플레이)         │                     │
  │   └──────────────────────────┘                     │
  │                                                     │
  │   🌡️ 온습도 센서              🔘 스위치 (버튼)       │
  │                                                     │
  │               [ ═══ USB 포트 ═══ ]                  │
  └────────────────────────────────────────────────────┘
```

### 각 부품은 뭘 할 수 있나요?

| 부품 | 모양 | 할 수 있는 것 |
|------|------|-------------|
| **🔴🟡🔵 LED 3개** | 작은 불빛 | 켜기, 끄기, 깜빡이기, 색깔 패턴 만들기 |
| **🔔 부저 (BEEP)** | 작은 스피커 | "삐!" 소리 내기 |
| **🎵 멜로디 부저** | 작은 스피커 | 도레미 음계, 동요 연주하기 |
| **📺 OLED 화면** | 작은 화면 | 글자, 숫자 표시하기 |
| **🌡️ 온습도 센서** | 작은 칩 | 지금 온도와 습도 측정하기 |
| **🔘 스위치** | 누르는 버튼 | 버튼을 누르면 무언가 동작하게 만들기 |

> **참고:** OLED 화면에는 영어와 숫자만 표시됩니다. 한글은 아직 표시할 수 없어요.

## 3. 앱 시작하기

### 보드 전원 켜기

1. USB 케이블을 보드에 연결합니다
2. 케이블 반대쪽을 보조배터리 또는 컴퓨터 USB에 연결합니다
3. OLED 화면에 **"UTTEC Firmware"**이라고 뜨면 준비 완료!

```
  보조배터리           USB 케이블           UTTEC 보드
  ┌──────┐          ═══════════          ┌──────────────┐
  │ 🔋   │─────────────────────────────▶│ 📺 UTTEC      │
  └──────┘                              │    Firmware   │
                                        │    BLE Ready! │
                                        └──────────────┘
```

### 스마트폰에서 앱 열기

**방법 1: 웹 브라우저 (추천)**

1. 스마트폰에서 **Chrome** 브라우저를 엽니다
2. 주소창에 아래 주소를 입력합니다:

```
https://uttec-ai.duckdns.org/firmware
```

3. 화면에 **"UTTEC Firmware"**가 나오면 성공!

> **팁:** 자주 쓴다면, Chrome 메뉴(⋮) → **"홈 화면에 추가"**를 누르면
> 앱처럼 바로 실행할 수 있습니다.

**방법 2: 앱 설치 (APK)**

선생님이 APK 파일을 보내주시면, 설치 후 앱 아이콘을 눌러 실행합니다.

## 4. 첫 번째 명령 보내기

### 4.1 화면 구성

앱을 열면 아래쪽에 5개의 탭이 있습니다.

```
┌───────────────────────────────────────┐
│                                       │
│         (현재 탭의 내용이 여기 표시)     │
│                                       │
├───────────────────────────────────────┤
│  🏠홈    🔧HW    💻SW    🎮패드    ⚙설정  │
└───────────────────────────────────────┘
```

| 탭 | 하는 일 |
|----|--------|
| 🏠 **홈** | 명령을 적고 보드에 보내는 곳 **(가장 많이 씀)** |
| 🔧 **HW** | 보드 부품(LED, 부저 등)의 설명을 보는 곳 |
| 💻 **SW** | 프로그래밍 기초를 배우는 곳 |
| 🎮 **패드** | 버튼을 눌러서 보드를 바로 제어하는 곳 |
| ⚙ **설정** | 서버 주소, 블루투스 설정 |

### 4.2 명령 보내기 (따라해 보세요!)

**🏠 홈 탭**에서 시작합니다.

```
  ┌─────── 따라하기 ──────────────────────────────────────┐
  │                                                       │
  │  Step 1. 예시 프롬프트 중 하나를 터치하세요               │
  │                                                       │
  │  [LED 깜빡이기] [학교종 연주] [온도 표시]  ...            │
  │      ↑                                                │
  │      여기를 터치!                                       │
  │                                                       │
  │  Step 2. 입력창에 글이 자동으로 채워집니다                 │
  │                                                       │
  │  ┌─────────────────────────────────────────┐          │
  │  │ 빨간 LED 1초마다 깜빡이기                 │          │
  │  └─────────────────────────────────────────┘          │
  │                                                       │
  │  Step 3. 아래 버튼을 누릅니다                            │
  │                                                       │
  │  [ 🚀 위 명령을 UTTEC 펌웨어로 만들기 ]                  │
  │      ↑                                                │
  │      이 버튼을 터치!                                    │
  │                                                       │
  └───────────────────────────────────────────────────────┘
```

### 4.3 기다리기

버튼을 누르면 화면에 진행 상태가 표시됩니다. **약 30~60초** 기다려 주세요.

```
  진행 과정:

  ① 🤖 AI 코드 생성 ········ (약 8초)
     → AI가 내 명령을 읽고 코드를 만드는 중

  ② 🔨 펌웨어 빌드 ·········· (약 25초)
     → 코드를 보드가 이해하는 프로그램으로 바꾸는 중

  ③ ✅ 완료! ···················
     → 블루투스로 보드에 보내기 시작!
```

> **주의:** 기다리는 동안 **앱을 닫거나 다른 페이지로 이동하지 마세요!**
> 중간에 끊기면 처음부터 다시 해야 합니다.

### 4.4 보드에 전송하기

빌드가 완료되면 블루투스(BLE)로 보드에 프로그램을 보냅니다.

- 이미 블루투스가 연결되어 있으면 **자동으로 전송**됩니다
- 연결되어 있지 않으면 **"BLE 연결"** 팝업이 뜹니다 → 5장 참고

```
  📡 BLE 전송 중...  ▓▓▓▓▓▓▓▓░░░  78%     ← 약 17초
          │
          ▼
  🎉 전송 완료! 보드가 재부팅됩니다.
          │
          ▼
  🔴 깜빡깜빡!                              ← 성공!
```

## 5. 블루투스 연결하기

보드에 프로그램을 보내려면 **블루투스(BLE) 연결**이 필요합니다.

### 5.1 연결 방법

```
  ┌─────── 블루투스 연결하기 ────────────────────────────┐
  │                                                     │
  │  Step 1. 스마트폰의 블루투스를 켜세요                  │
  │         (설정 → 블루투스 → ON)                       │
  │                                                     │
  │  Step 2. 앱 상단의 BLE 배지를 터치하세요               │
  │                                                     │
  │         UTTEC Firmware    [🔴 BLE 미연결]            │
  │                                ↑                    │
  │                           여기를 터치!               │
  │                                                     │
  │  Step 3. 목록에서 내 보드 이름을 선택하세요             │
  │                                                     │
  │         ┌─ BLE 기기 선택 ──────────┐                │
  │         │  📡 UTTEC-OTA            │ ← 이것을 터치  │
  │         │  📡 UTTEC-01             │                │
  │         │  📡 UTTEC-02             │                │
  │         └──────────────────────────┘                │
  │                                                     │
  │  Step 4. 배지가 초록색으로 바뀌면 연결 성공!            │
  │                                                     │
  │         UTTEC Firmware    [🟢 UTTEC-OTA]            │
  │                                                     │
  └─────────────────────────────────────────────────────┘
```

### 5.2 연결 상태 확인

앱 오른쪽 위의 배지 색깔로 연결 상태를 알 수 있습니다.

| 배지 | 상태 | 의미 |
|------|------|------|
| 🔴 **빨간색** | 미연결 | 블루투스가 연결되지 않았습니다. 터치해서 연결하세요 |
| 🟡 **노란색** | 연결 중 | 연결을 시도하고 있습니다. 잠시 기다려 주세요 |
| 🟢 **초록색** | 연결됨 | 연결 성공! 프로그램을 보낼 수 있습니다 |

### 5.3 연결이 안 될 때

| 증상 | 해결 방법 |
|------|----------|
| 목록에 내 보드가 안 보여요 | 보드의 전원(USB)이 켜져 있는지 확인하세요 |
| 목록에 보드가 안 보여요 (2) | 스마트폰의 블루투스가 켜져 있는지 확인하세요 |
| 연결을 눌러도 실패해요 | 보드 가까이(2m 이내)에서 다시 시도하세요 |
| 계속 실패해요 | 보드의 USB를 뽑았다 다시 꽂고 시도하세요 |
| 다른 친구의 보드가 보여요 | 보드 이름을 확인하세요. 선생님이 알려주신 이름과 같은 것을 선택하세요 |

> **중요:** 블루투스 거리는 약 **10미터** 이내입니다.
> 보드에서 너무 멀리 떨어지면 연결이 끊어질 수 있습니다.

## 6. 패드로 직접 제어하기

**🎮 패드 탭**에서는 프롬프트를 적지 않고, **버튼을 눌러서 바로** 보드를 제어할 수 있습니다.

> **조건:** 블루투스가 연결되어 있어야 합니다 (🟢 초록색 배지)

### 6.1 패드 화면

```
  ┌─── 🎮 패드 탭 ──────────────────────────────────────┐
  │                                                     │
  │  LED 제어                                           │
  │  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────────┐       │
  │  │🔴빨강│  │🟡노랑│  │🔵파랑│  │🔄전체끄기│       │
  │  └──────┘  └──────┘  └──────┘  └──────────┘       │
  │  → 버튼을 누르면 바로 LED가 켜지거나 꺼집니다          │
  │                                                     │
  │  부저                                               │
  │  ┌──────┐  ┌──────┐                                │
  │  │🔔삐! │  │🎵멜로디│                                │
  │  └──────┘  └──────┘                                │
  │  → "삐!"는 짧은 경고음, "멜로디"는 도레미 연주         │
  │                                                     │
  │  피아노 건반                                         │
  │  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐                │
  │  │도││레││미││파││솔││라││시││도'│                │
  │  └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘                │
  │  → 건반을 누르면 해당 음이 보드에서 울립니다            │
  │                                                     │
  │  센서 / 디스플레이                                    │
  │  ┌──────────┐  ┌──────────────────────────────┐    │
  │  │🌡️온도읽기│  │ 📺 OLED: [입력창      ] [전송]│    │
  │  └──────────┘  └──────────────────────────────┘    │
  │  → 온도 버튼: OLED에 현재 온도/습도가 표시됩니다       │
  │  → OLED 입력: 원하는 글자를 OLED에 바로 표시합니다     │
  │                                                     │
  │  스위치 모니터                                       │
  │  ┌──────────────────────────────────────────┐      │
  │  │ 🔘 스위치 상태: 해제 (또는: 눌림!)         │      │
  │  └──────────────────────────────────────────┘      │
  │  → 보드의 스위치를 누르면 여기에 실시간으로 표시됩니다   │
  │                                                     │
  └─────────────────────────────────────────────────────┘
```

### 6.2 패드 vs 홈 — 언제 뭘 쓸까?

| 상황 | 사용할 탭 | 이유 |
|------|----------|------|
| 빨간 LED가 잘 켜지는지 시험해 보고 싶을 때 | 🎮 패드 | 바로 확인 가능 (즉시!) |
| 피아노 건반을 눌러서 소리를 들어보고 싶을 때 | 🎮 패드 | 실시간 소리 가능 |
| "빨간 LED 3번 깜빡이고 멜로디 연주해줘" | 🏠 홈 | 복잡한 동작은 프롬프트로 |
| "온도가 30도 넘으면 경보 울려줘" | 🏠 홈 | 조건부 동작은 프롬프트로 |
| 지금 교실 온도가 몇 도인지 보고 싶을 때 | 🎮 패드 | 온도읽기 버튼으로 즉시 확인 |

## 7. 좋은 프롬프트 작성법

프롬프트는 **AI에게 보내는 주문서**입니다. 잘 적을수록 내가 원하는 대로 동작합니다.

### 7.1 좋은 프롬프트 규칙

```
  ❌ 나쁜 예                        ✅ 좋은 예
  ─────────────────                ─────────────────────────────
  "뭔가 멋진 거 해줘"               "빨간 LED 1초마다 깜빡여줘"
  "LED"                           "빨강, 노랑, 파랑 LED 순서대로 켜기"
  "소리 내줘"                      "학교종 멜로디 연주해줘"
  "온도"                           "온도를 OLED에 표시하고 30도 넘으면 빨간 LED 켜줘"
```

### 7.2 프롬프트 작성 공식

```
  [무엇을]  +  [어떻게]  +  [추가 조건]

  예시:
  ┌──────────┬────────────────┬─────────────────────┐
  │ 무엇을    │ 어떻게          │ 추가 조건              │
  ├──────────┼────────────────┼─────────────────────┤
  │ 빨간 LED  │ 깜빡여줘        │ 0.5초마다              │
  │ 학교종    │ 연주해줘        │ 2번 반복               │
  │ 온도     │ OLED에 표시해줘  │ 3초마다 업데이트        │
```

## 8. 코드 읽어보기

프로그램이 만들어지면, **"🎓 생성된 코드 학습하기"** 버튼이 나타납니다.
여기를 터치하면 AI가 만든 코드를 볼 수 있습니다.

```
  ┌─ 코드 학습 카드 ──────────────────────────────────────┐
  │                                                       │
  │  🎓 생성된 코드 학습하기                                │
  │  ▶ 코드와 설명 보기                                    │
  │                                                       │
  │  ┌───────────────────────────────────────────────┐   │
  │  │ // [LED 깜빡이기] 빨간 LED를 1초 간격으로 깜빡    │   │
  │  │                                               │   │
  │  │ void ledTask(void *param) {                   │   │
  │  │   while (1) {                                 │   │
  │  │     digitalWrite(LED_RED, LOW);  // LED 켜기    │   │
  │  │     delay(500);                 // 0.5초 대기   │   │
  │  │     digitalWrite(LED_RED, HIGH); // LED 끄기    │   │
  │  │     delay(500);                 // 0.5초 대기   │   │
  │  │   }                                           │   │
  │  │ }                                             │   │
  │  └───────────────────────────────────────────────┘   │
  │                                                       │
  │  ┌─ 학습 포인트 ─────────────────────────────────┐   │
  │  │  💡 LED 깜빡이기 — 빨간 LED를 1초 간격으로 깜빡  │   │
  │  │  💡 LED 켜기 — digitalWrite로 LED를 제어        │   │
  │  └───────────────────────────────────────────────┘   │
  │                                                       │
  └───────────────────────────────────────────────────────┘
```

### 코드에서 자주 보이는 것들

| 코드 | 뜻 |
|------|-----|
| `digitalWrite(LED_RED, LOW)` | 빨간 LED를 **켠다** |
| `digitalWrite(LED_RED, HIGH)` | 빨간 LED를 **끈다** |
| `delay(500)` | **0.5초** 기다린다 (500 = 500밀리초 = 0.5초) |
| `delay(1000)` | **1초** 기다린다 |
| `while (1) { ... }` | 중괄호 안의 동작을 **계속 반복**한다 |
| `tone(33, 262, 300)` | 멜로디 부저에서 **도** 음을 0.3초 동안 낸다 |
| `oled.drawString(0, 0, "Hi")` | OLED 화면에 **"Hi"**를 표시한다 |
| `aht20_read(temp, humi)` | 온도(temp)와 습도(humi)를 **측정**한다 |
| `// [주제] 설명` | 주석 — 사람이 읽으라고 적은 메모 (실행되지 않음) |

> 코드를 외울 필요는 없어요! 프롬프트를 적으면 AI가 대신 만들어 줍니다.
> 하지만 코드를 읽어보면 **"아, 이렇게 동작하는구나"**를 이해할 수 있어요.

## 10. 문제가 생겼을 때

### 빌드 실패

```
  화면에 "빌드 실패"가 나왔을 때:

  원인 1: 프롬프트가 너무 모호함
  → 해결: 더 구체적으로 다시 적기
     ❌ "재미있는 거 해줘"
     ✅ "빨간 LED 3번 깜빡이고 부저 울려줘"

  원인 2: 서버가 바쁨
  → 해결: 30초 뒤에 다시 시도

  원인 3: 인터넷 연결 끊김
  → 해결: Wi-Fi 연결 확인 후 다시 시도
```

### BLE 전송 실패

```
  전송 중 끊겼을 때:

  1. 보드 가까이(2m 이내)로 이동
  2. 상단 BLE 배지를 눌러 다시 연결
  3. 🏠 홈 탭에서 다시 빌드 시작
```

### 보드가 반응이 없을 때

```
  1. USB 케이블을 뽑았다 다시 꽂기 (재부팅)
  2. 10초 기다린 후 OLED에 "UTTEC Firmware"가 뜨는지 확인
  3. 블루투스 다시 연결 후 시도
```

### 원하는 대로 동작하지 않을 때

```
  예: "빨간 LED 켜줘"를 했는데 안 켜져요

  1. 블루투스가 연결되어 있는지 확인 (🟢 초록색 배지)
  2. 🎮 패드 탭에서 🔴빨강 버튼을 눌러서 LED가 동작하는지 확인
  3. 패드에서도 안 되면 → USB를 뽑았다 다시 꽂기
  4. 패드에서는 되는데 프롬프트로 안 되면 → 프롬프트를 바꿔서 다시 시도
```
