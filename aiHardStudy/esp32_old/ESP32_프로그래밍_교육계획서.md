# ESP32 프로그래밍 교육 계획서

## AI와 함께하는 신나는 코딩 교실

**대상**: 초등학교 4, 5, 6학년
**개발환경**: Arduino IDE + C/C++
**교육방식**: AI 활용 코딩 학습
**하드웨어**: ESP32-DevKitC 기반 교육용 보드

---

## 1. 교육 개요

### 1.1 교육 목표
- 프로그래밍의 기본 개념 이해
- 하드웨어와 소프트웨어의 연결 원리 학습
- AI를 활용한 문제 해결 능력 배양
- 창의적 사고력과 논리력 향상

### 1.2 사용 장비

| 부품 | 용도 | 활용 단계 |
|------|------|-----------|
| LED 3개 (빨강/노랑/파랑) | 빛으로 표현하기 | 초급 |
| 부저 2개 (BEEP/MELODY) | 소리로 표현하기 | 초급~중급 |
| 스위치 1개 | 입력 받기 | 초급 |
| OLED 디스플레이 | 화면에 표시하기 | 중급 |
| AHT20 온습도 센서 | 환경 측정하기 | 중급 |
| LoRa 무선 모듈 | 멀리 통신하기 | 고급 |

### 1.3 AI 활용 코딩 5단계

| 단계 | 활동 | 예시 |
|------|------|------|
| 1단계 | 만들고 싶은 것을 말로 설명하기 | "빨간 LED가 1초마다 깜빡이게 하고 싶어" |
| 2단계 | AI에게 코드 요청하기 | Claude/ChatGPT에 질문 |
| 3단계 | 코드 이해하기 | AI가 만든 코드를 한 줄씩 읽어보기 |
| 4단계 | 코드 수정해보기 | 숫자나 동작을 바꿔보기 |
| 5단계 | 나만의 아이디어 추가하기 | 새로운 기능을 AI에게 요청하기 |

# 초급 과정 (4학년 권장)

## "빛과 소리로 놀자!"

### 학습 목표
- Arduino IDE 사용법 익히기
- 기본 명령어 이해하기 (pinMode, digitalWrite, delay)
- AI에게 질문하는 방법 배우기

### 차시별 내용

| 차시 | 주제 | 학습 내용 | 결과물 |
|------|------|----------|--------|
| 1 | 첫 만남 - LED 켜기 | 출력 핀 설정, HIGH/LOW 이해 | LED 손전등 |
| 2 | 깜빡깜빡 | delay() 함수로 시간 조절 | 비상등 |
| 3 | 신호등 만들기 | 여러 LED 순차 제어 | 교통 신호등 |
| 4 | 삐~ 소리내기 | tone() 함수, 음계 주파수 | 도레미 연주 |
| 5 | 버튼 반응 | 입력 핀 설정, if 조건문 | 초인종 |
| 6 | **최종 프로젝트** | 종합 활용 | **전자 피아노** |

### 초급 최종 프로젝트: 전자 피아노

**기능**: 버튼을 누를 때마다 도→레→미 순서로 소리가 나고, 해당 색상의 LED가 켜짐

**학습 포인트**:
- 배열(array) 개념 맛보기
- 여러 부품 동시 제어
- 순환(%) 연산자 활용

# 중급 과정 (5학년 권장)

## "센서와 화면으로 표현하자!"

### 학습 목표
- 변수와 조건문 활용하기
- I2C 통신 이해하기
- OLED 디스플레이에 표시하기
- 센서 데이터 활용하기

### 차시별 내용

| 차시 | 주제 | 학습 내용 | 결과물 |
|------|------|----------|--------|
| 1 | 화면에 글자 쓰기 | I2C 통신, 라이브러리 사용 | 전자 이름표 |
| 2 | 카운터 만들기 | 변수, 증가 연산 | 버튼 점수판 |
| 3 | 온도계 만들기 | 센서 읽기, 소수점 표시 | 디지털 온도계 |
| 4 | 반응 속도 게임 | millis(), random() | 빠른 손 게임 |
| 5 | 전자 주사위 | 랜덤 함수, 애니메이션 효과 | 주사위 게임 |
| 6 | **최종 프로젝트** | 센서 + 디스플레이 + LED | **날씨 스테이션** |

### 중급 최종 프로젝트: 미니 날씨 스테이션

**기능**:
- 온도/습도 실시간 측정 및 OLED 표시
- 불쾌지수 자동 계산
- 온도에 따라 LED 색상 변화 (파랑: 추움, 노랑: 쾌적, 빨강: 더움)

**학습 포인트**:
- 수식을 이용한 계산 (불쾌지수)
- 조건문으로 상태 판단
- 복합 출력 (화면 + LED)

# 고급 과정 (6학년 권장)

## "무선으로 세상과 연결하자!"

### 학습 목표
- 함수 만들기
- 무선 통신 이해하기 (LoRa)
- 복합 시스템 설계하기
- 팀 프로젝트 수행하기

### 차시별 내용

| 차시 | 주제 | 학습 내용 | 결과물 |
|------|------|----------|--------|
| 1 | 나만의 함수 만들기 | 함수 정의, 매개변수 | 코드 정리 |
| 2 | LoRa 통신 시작 | UART 통신, 모듈 설정 | 메시지 송신기 |
| 3 | 무선 메시지 받기 | 문자열 처리 | 메시지 수신기 |
| 4 | 무선 센서 전송 | 데이터 포맷팅 | 원격 모니터링 |
| 5 | 무선 리모컨 | 명령어 파싱 | LED 리모컨 |
| 6 | **최종 프로젝트** | 팀 프로젝트 | **스마트 알림 시스템** |

### 고급 최종 프로젝트: 스마트 알림 시스템

**시스템 구성**:
```
[센서 노드]                    [알림 노드]
 • AHT20 센서     ──LoRa──►    • OLED 디스플레이
 • 버튼                         • LED 3색
 • LoRa 송신                    • 부저
```

**기능**:
- 온도/습도 실시간 무선 전송
- 버튼 누르면 긴급 알림 발송
- 온도 30도 이상 시 자동 경고
- LED와 소리로 알림 표시

**학습 포인트**:
- 2개 이상의 장치 연동
- 송신/수신 역할 분담 (팀워크)
- 실생활 응용 시스템 설계
