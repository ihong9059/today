## 🏠 홈 탭 — AI에게 코드 만들어달라고 하기

### Python 코드 만들기

1. 상단 입력창에 **만들고 싶은 프로그램**을 적습니다
   - 예: "1부터 10까지 합하기"
   - 예: "별로 피라미드 그리기"
   - 예: "가위바위보 게임"
2. **보내기 버튼 (▶)** 을 누릅니다
3. AI가 Python 코드를 만들어줍니다 (10~15초 대기)
4. 결과가 나오면:
   - **설명**: 코드가 하는 일
   - **Python 코드**: 실제 코드
   - **[실행]**: 코드를 실행하여 결과 확인
   - **[코드 수정]**: 실행탭으로 가서 코드를 직접 수정
   - **핵심 개념**: 이 코드에서 배울 수 있는 것

## 📚 학습 탭 — 100개 예시로 배우기

### 카테고리 선택

상단에서 원하는 카테고리를 선택합니다:

| 카테고리 | 배우는 것 | 난이도 |
|----------|----------|:------:|
| **A. 첫걸음** | print, 변수, 입출력 | 기초 |
| **B. 숫자/계산** | 덧셈, 뺄셈, 소수 찾기 | 기초 |
| **C. 조건문** | if/else, 참/거짓 판단 | 기초 |
| **D. 반복문** | for, while, 반복 실행 | 기초~중급 |
| **E. 함수** | 나만의 명령 만들기 | 중급 |
| **F. 문자열** | 글자 다루기 | 중급 |
| **G. 리스트** | 여러 데이터 관리 | 중급 |
| **H. 센서** | 흔들기, 기울기, 진동 | 중급 |
| **I. 카메라/소리** | 사진, 손전등, QR코드 | 중급 |
| **J. 게임** | 공굴리기, 틱택토, 스네이크 | 고급 |

### 예시 보는 방법

1. 카테고리를 선택합니다
2. 예시를 탭합니다
3. 화면 구성:
   - **📖 설명**: 이 프로그램이 하는 일
   - **동작 순서**: 1, 2, 3 단계로 설명
   - **Python 코드**: 실제 프로그래밍 코드
   - **[코드 수정하기]**: 실행탭에서 코드를 바꿔볼 수 있어요!
   - **[실행]**: 코드를 실행하여 결과 확인 (텍스트 예시)
   - **인터랙티브 영역**: 센서/카메라/게임 직접 체험 (H~J)
   - **학습 개념**: 이 코드에서 배우는 핵심 개념 3개
   - **퀴즈**: 배운 내용을 확인하는 문제

### 추천 학습 순서

```
처음이라면:  A01 → A03 → A05 → A10
숫자 배우기: B01 → B05 → B06
조건문:     C01 → C03 → C08
반복문:     D01 → D03 → D10
센서 체험:  H01 → H03 → H05
게임 체험:  J01 → J05 → J07
```

## ▶ 실행 탭 — 코드 수정하고 실행하기

### 사용 방법

1. 학습탭이나 홈탭에서 **[코드 수정]** 버튼을 누릅니다
2. 코드가 실행탭에 자동으로 로드됩니다
3. 코드를 **직접 수정**합니다
   - 예: 구구단에서 `dan = 3`을 `dan = 7`로 바꾸기
   - 예: print 메시지 바꿔보기
4. **[실행]** 버튼을 누릅니다
5. 아래에 실행 결과가 표시됩니다

### 코드 수정 팁

- 숫자를 바꿔보세요 (변수 값 변경)
- print() 안의 글자를 바꿔보세요
- 새로운 줄을 추가해보세요
- 실수해도 괜찮아요! 다시 실행하면 됩니다

## 자주 묻는 질문

**Q: 서버 연결이 안 돼요!**
A: 설정 탭에서 서버 주소를 확인하세요. 선생님에게 주소를 다시 물어보세요.

**Q: 실행 버튼을 눌렀는데 아무 반응이 없어요.**
A: 서버가 연결되어 있어야 합니다. 설정 탭에서 연결 테스트를 해보세요.

**Q: 센서가 동작 안 해요.**
A: 센서 예시(H~J)는 서버 없이도 동작합니다. 앱을 껐다 다시 켜보세요.

**Q: 코드를 수정하고 싶어요.**
A: 예시 화면에서 [코드 수정하기] 버튼을 누르면 실행탭에서 수정할 수 있어요.

**Q: AI가 만든 코드가 이상해요.**
A: AI도 가끔 실수해요! 코드를 수정하거나 다시 요청해보세요.

## Python 기초 용어

| 용어 | 쉬운 설명 |
|------|----------|
| **print()** | 화면에 글자를 보여주는 명령 |
| **변수** | 데이터를 담는 상자. `name = '민수'` |
| **if** | "만약 ~이면" 조건 확인 |
| **for** | "~번 반복해" 같은 동작 여러 번 |
| **함수 (def)** | 나만의 명령을 만드는 것 |
| **리스트** | 여러 값을 순서대로 담는 통. `[1, 2, 3]` |
| **import** | 다른 사람이 만든 도구를 가져오는 것 |
