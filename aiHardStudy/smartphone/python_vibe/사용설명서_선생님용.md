## 1. 시스템 구성

```
교사 PC (서버)                        학생 스마트폰 (앱)
┌────────────────────┐               ┌────────────────────┐
│ server.py          │    WiFi       │ UTTEC Python 앱     │
│ Port 8094          │ ←──────────→  │ (com.uttec.python   │
│                    │               │  _vibe)             │
│ - Python 코드 실행  │               │                    │
│ - AI 코드 생성      │               │ - 100개 예시        │
│ - 코딩 질문 답변    │               │ - 센서/카메라 체험   │
└────────────────────┘               └────────────────────┘
```

### 필요한 것
- 교사 PC: Python 3 설치, WiFi 연결
- 학생 스마트폰: Android, 같은 WiFi 네트워크
- (선택) Claude Code 설치 — AI Q&A 및 코드 생성용

## 2. 서버 시작 방법

### 최초 설정 (1회만)

```bash

pip install fastapi uvicorn pydantic

# 2. 방화벽 포트 열기 (관리자 권한)
netsh advfirewall firewall add rule name=VibeFW8094 dir=in action=allow protocol=TCP localport=8094
```

### 수업 시작 시

```bash
# 서버 폴더로 이동
cd C:\todo\today\aiHardStudy\smartphone\python_vibe

# 서버 시작
python server.py
```

서버가 정상 시작되면 아래 메시지가 표시됩니다:

## 4. 앱 구성 (4탭)

### 탭 1: 홈

| 기능 | 설명 | 서버 필요 |
|------|------|:---------:|
| **Python 만들기** | 프롬프트 입력 → AI가 Python 코드 생성 → 실행 + 설명 | O |
| **대표 예시 7개** | 카테고리별 대표 예시 바로 실행 | X |
| **코딩 질문** | Python 관련 질문 → AI 답변 | O |

**수업 활용**:
- "1부터 100까지 합하기" → AI가 코드 생성 → 학생이 실행하며 학습
- "for문이 뭐예요?" → AI가 쉽게 설명

### 탭 2: 학습

| 카테고리 | 개수 | 내용 | 서버 필요 |
|----------|:----:|------|:---------:|
| A. 첫걸음 | 10 | print, 변수, 입출력, 구구단 | X |
| B. 숫자/계산 | 10 | 사칙연산, 소수, 피보나치 | X |
| C. 조건문 | 10 | if/elif/else, 윤년, 자판기 | X |
| D. 반복문 | 10 | for, while, 야구게임 | X |
| E. 함수 | 10 | def, 재귀, 람다 | X |
| F. 문자열 | 10 | 슬라이싱, 시저암호 | X |
| G. 리스트 | 10 | 컴프리헨션, 정렬, 스택/큐 | X |
| H. 센서 | 10 | 주사위, 만보기, 수평계 | X |
| I. 카메라/소리 | 10 | 촬영, 셀카, QR코드, 시계 | X |
| J. 게임 | 10 | 공굴리기, 틱택토, 스네이크 | X |

**수업 활용**:
- 카테고리 필터로 오늘 배울 주제만 선택
- 각 예시: 설명 → 코드 → 실행 → 개념 → 퀴즈 순서
- "코드 수정하기" 버튼 → 실행탭에서 코드 변경 후 재실행

### 탭 3: 실행

| 기능 | 설명 |
|------|------|
| **코드 에디터** | 학습탭/홈탭에서 가져온 코드를 수정 |
| **실행 버튼** | 서버에서 실제 Python 실행 → 결과 표시 |

**수업 활용**:
- 예시 코드를 가져와서 변수를 바꿔보기 (구구단의 dan=3 → dan=7)
- AI가 만든 코드를 수정하며 학습

### 탭 4: 설정

- 서버 URL 입력: `http://192.168.0.20:8094`
- 연결 테스트 버튼

## 6. 문제 해결

| 문제 | 해결 |
|------|------|
| 앱에서 "서버 연결 실패" | 설정탭에서 서버 IP 확인, 서버 실행 여부 확인 |
| Python 실행 안 됨 | 서버 PC에 Python 설치 확인, 서버 재시작 |
| Q&A 답변이 기본 답변만 나옴 | Claude Code 설치 필요 (`npm install -g @anthropic-ai/claude-code`) |
| 센서 예시 동작 안 함 | 센서 예시는 앱 내 직접 실행 (서버 불필요) |
| 앱 설치 안 됨 | "알 수 없는 앱 설치" 허용 필요 (설정 → 보안) |
| 서버 시작 시 포트 사용 중 | `netstat -ano | grep 8094` → 해당 PID 종료 |
