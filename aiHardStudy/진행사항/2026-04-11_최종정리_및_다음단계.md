## 미구현 메모 (나중에 구현)

### 🎮 패드 탭 실제 동작
```
방법: ESP32에 "명령 수신 펌웨어" 상주
  - PC에서 시리얼(COM20)로 명령 전송: "LED_RED_ON", "BEEP_50", "NOTE_262"
  - ESP32가 즉시 실행 (<1초)
  - 패드 버튼 → Flask API → 시리얼 명령 → ESP32 동작

구현 항목:
  1. ESP32 명령 수신 펌웨어 (UART 파싱 + GPIO/PWM/I2C 제어)
  2. Flask 시리얼 API (/api/serial/send)
  3. 패드 UI 버튼 → API 연결
```

### LoRa 테스트
```
미테스트 항목:
  - UART2 (TX=17, RX=16) 통신
  - M0 (GPIO15), M1 (GPIO4) 모드 설정
  - AUX (GPIO34) 상태 읽기
  - 모듈 미연결 상태이므로 모듈 구매/연결 후 테스트
```

### SPI 테스트
```
미테스트 항목:
  - MOSI=23, MISO=19, SCK=18, SS=5
  - 디바이스 미연결 (확장용 예약)
  - SD카드 모듈 등 연결 시 테스트
```
