# Claude AI 질문 웹서버 개발 계획서

## 프로젝트 개요

웹 브라우저에서 Claude AI에게 질문하고 답변을 받는 웹 애플리케이션.
**API 키 없이**, 이 PC에 설치된 Claude Code CLI를 직접 호출하여 동작한다.

```
[사용자] → 질문 입력 → [Flask 웹서버] → claude -p "질문" → [Claude Code CLI]
                                                                  ↓
[사용자] ← 답변 표시 ← [Flask 웹서버] ← stdout 출력 ←──── [Claude Code CLI]
                                                                  ↓
                                                            [연결 종료]
                                                                  ↓
                                                            [완료 표시]
```

## 시스템 구성

### 기술 스택

| 구분 | 기술 | 역할 |
|------|------|------|
| Backend | Python + Flask | 웹서버 |
| Frontend | HTML + CSS + JavaScript | 질문/답변 UI |
| AI | Claude Code CLI (`claude -p`) | 질문 처리 및 답변 생성 |
| 통신 | REST API (fetch) | 프론트↔백엔드 통신 |

### 핵심 방식: Claude Code CLI

```bash
# API 키 없이, 이 PC의 Claude Code가 직접 답변
claude -p "GitHub Actions란 무엇인가요?"
```

- API 키 불필요 (이미 로그인된 Claude Code 사용)
- `subprocess.run()`으로 CLI 호출
- stdout으로 답변 수신

## Phase 1: 백엔드 (Flask 웹서버)

### 1-1. API 엔드포인트

| 엔드포인트 | 메서드 | 기능 |
|------------|--------|------|
| `/` | GET | 메인 페이지 (질문/답변 UI) |
| `/connect` | POST | Claude CLI 연결 확인 (`claude --version`) |
| `/ask` | POST | 질문 전송 → `claude -p` 실행 → 답변 반환 |
| `/disconnect` | POST | 연결 상태 종료 |

### 1-2. 핵심 코드

```python
from flask import Flask, render_template, request, jsonify
import subprocess

app = Flask(__name__)
connected = False

# 연결: claude CLI 존재 확인
@app.route('/connect', methods=['POST'])
def connect():
    global connected
    result = subprocess.run(['claude', '--version'],
                          capture_output=True, text=True, timeout=10)
    if result.returncode == 0:
        connected = True
        return jsonify({"status": "connected", "version": result.stdout.strip()})

# 질문: claude -p로 CLI 호출
@app.route('/ask', methods=['POST'])
def ask():
    question = request.json.get('question')
    result = subprocess.run(['claude', '-p', question],
                          capture_output=True, text=True, timeout=120)
    return jsonify({"status": "ok", "answer": result.stdout})

# 연결 종료
@app.route('/disconnect', methods=['POST'])
def disconnect():
    global connected
    connected = False
    return jsonify({"status": "disconnected"})
```

## Phase 2: 프론트엔드 (질문/답변 UI)

### 2-1. 화면 구성

```
┌─────────────────────────────────────────┐
│         Claude AI 질문 시스템            │
├─────────────────────────────────────────┤
│  [연결] 버튼          상태: ● 미연결     │
├─────────────────────────────────────────┤
│                                         │
│  질문 입력창                             │
│  ┌─────────────────────────────────┐    │
│  │  (여기에 질문 입력)              │    │
│  └─────────────────────────────────┘    │
│                        [질문하기] 버튼   │
├─────────────────────────────────────────┤
│                                         │
│  답변 수신창                             │
│  ┌─────────────────────────────────┐    │
│  │  (Claude의 답변이 여기에 표시)    │    │
│  └─────────────────────────────────┘    │
├─────────────────────────────────────────┤
│  [연결 종료] 버튼      상태: ● 완료      │
└─────────────────────────────────────────┘
```

### 2-2. UI 동작 흐름

```
1. 페이지 로드 → 상태: "미연결"
       ↓
2. [연결] 클릭 → /connect → claude --version 확인 → 상태: "연결됨" (초록색)
       ↓
3. 질문 입력 → [질문하기] 클릭 → /ask → claude -p 실행 → 답변 표시
       ↓  (반복 가능)
4. [연결 종료] 클릭 → /disconnect → 상태: "완료" (파란색)
```

### 2-3. JavaScript 핵심 로직

```javascript
// 연결 - Claude CLI 확인
async function connect() {
    const res = await fetch('/connect', { method: 'POST' });
    const data = await res.json();
    // 상태를 "연결됨"으로 변경, 버전 표시
}

// 질문하기 - claude -p 호출
async function ask() {
    const question = document.getElementById('question').value;
    const res = await fetch('/ask', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ question })
    });
    const data = await res.json();
    // 답변 수신창에 data.answer 표시
}

// 연결 종료
async function disconnect() {
    await fetch('/disconnect', { method: 'POST' });
    // 상태를 "완료"로 변경, 질문 비활성화
}
```

## API 방식 vs CLI 방식 비교

| 항목 | Claude API | Claude Code CLI (채택) |
|------|-----------|------------------------|
| API 키 | 별도 발급 필요 | 불필요 (이미 로그인) |
| 비용 | API 크레딧 소모 | Claude 구독 사용 |
| 추가 설치 | anthropic 패키지 | 없음 |
| 속도 | 빠름 (직접 통신) | 약간 느림 (CLI 프로세스) |
| 도구 사용 | 불가 | 가능 (파일 읽기 등) |
