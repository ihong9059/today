# UTTEC 사전빌드 시스템 - 전체 흐름 설명

## 1. 시스템 개요

사전빌드 시스템은 **AI가 생성한 Arduino 코드를 미리 컴파일**하여,
사용자가 선택만 하면 BLE OTA로 ESP32 보드에 즉시 전송할 수 있는 교육용 플랫폼입니다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    사전빌드 시스템 전체 흐름                        │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [1단계: 빌드]        [2단계: 배포]        [3단계: 전송]           │
│                                                                  │
│  catalog_source.json  prebuild_server.py   Web/App               │
│       │                    │                   │                  │
│       ▼                    ▼                   ▼                  │
│  prebuild.py ──────► firmware_db/ ──────► BLE OTA ──► ESP32 보드  │
│  (Claude AI +         (firmware.bin        (웹/앱에서              │
│   Arduino CLI)         guide.json           선택 후 전송)          │
│                        code.ino)                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 2. 1단계: 펌웨어 빌드 (prebuild.py)

### 흐름

```
catalog_source.json (178개 프롬프트)
        │
        ▼
┌─────────────────────────┐
│   prebuild.py 실행      │
│   --all / --only A05    │
└────────┬────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│  1. Claude AI에 프롬프트 전송               │
│     시스템 프롬프트 (하드웨어 스펙)          │
│     + 사용자 프롬프트 ("빨간 LED 깜빡이기") │
│                                             │
│  2. AI 응답에서 Arduino 코드 추출           │
│     - Markdown 코드펜스 제거                │
│     - #include 문 제거 (베이스에 포함)      │
│                                             │
│  3. 베이스 펌웨어와 병합                    │
│     base(ble_ota_arduino.ino) + 사용자 코드 │
│                                             │
│  4. Arduino CLI로 컴파일                    │
│     FQBN: esp32:esp32:esp32                 │
│     파티션: min_spiffs                      │
│                                             │
│  5. 교육 가이드 생성 (Claude AI)            │
│     코드 설명, 개념, 퀴즈 등               │
└────────┬────────────────────────────────────┘
         │
         ▼
firmware_db/{번호}/
├── firmware.bin        ← 컴파일된 바이너리 (~650KB)
├── code.ino            ← AI가 생성한 사용자 코드
├── merged.ino          ← 베이스 + 사용자 코드 합본
├── guide.json          ← 교육 가이드 (한국어)
└── system_prompt.txt   ← Claude에 보낸 전체 프롬프트
```

### 주요 명령어

```bash
# 전체 빌드
python prebuild.py --all

# 특정 항목만
python prebuild.py --only A05

# 카테고리 단위
python prebuild.py --category B

# 실패한 것만 재시도
python prebuild.py --retry-failed

# 현재 상태 확인
python prebuild.py --dry-run

# 카탈로그만 재생성
python prebuild.py --catalog
```

## 4. 3단계: BLE OTA 전송 (Web/App → ESP32)

### 전체 흐름

```
┌──────────┐     HTTP      ┌──────────────┐     BLE      ┌──────────┐
│ 사용자가  │ ──────────► │  서버에서     │ ──────────► │  ESP32   │
│ 항목 선택 │  firmware.bin │  바이너리    │  OTA 패킷   │  보드    │
│ (Web/App) │   다운로드   │  수신        │  240B 청크  │  재부팅  │
└──────────┘              └──────────────┘              └──────────┘
```

### BLE OTA 프로토콜

```
BLE Service UUID: 0000fe00-...
├── OTA_CTRL   (fe01) ← 제어 명령 (시작/종료/취소)
├── OTA_DATA   (fe02) ← 펌웨어 데이터 전송
└── OTA_STATUS (fe03) ← 진행 상태 알림

전송 순서:
1. BLE 연결 (디바이스 스캔 → GATT 연결)
2. OTA_CTRL에 START 명령 + 파일 크기 (리틀엔디안 4바이트)
3. OTA_DATA로 240바이트 청크 전송
   - writeWithoutResponse 사용
   - 20청크마다 30ms 딜레이
4. OTA_CTRL에 END 명령
5. 보드 자동 재부팅 → 새 펌웨어 실행
```

## 6. 교육 가이드 구조 (guide.json)

각 펌웨어에는 학습 가이드가 포함됩니다:

```
guide.json
├── result_description   ← 실행하면 어떻게 되는지 설명
├── what_happens[]       ← 단계별 동작 설명
├── concepts[]           ← 프로그래밍 개념 설명
│   ├── term             ← 용어
│   └── explanation      ← 초등학생 수준 설명
├── code_highlights[]    ← 중요 코드 라인별 설명
│   ├── line             ← 코드 라인
│   └── comment          ← 의미 설명
├── try_next[]           ← 다음에 시도해볼 것
└── quiz                 ← 이해도 확인 퀴즈
    ├── question
    ├── options[]
    ├── answer (인덱스)
    └── explanation
```

## 7. 하드웨어 스펙 (ESP32-WROOM-32 DevKitC)

### GPIO 핀 매핑

```
LED_RED    = GPIO25  (Active LOW — LOW=켜짐, HIGH=꺼짐)
LED_YELLOW = GPIO26  (Active LOW)
LED_BLUE   = GPIO27  (Active LOW)
BUZZER     = GPIO14  (Active LOW)
MELODY     = GPIO33  (PWM/tone())
SWITCH     = GPIO32  (INPUT_PULLUP, Active LOW)
OLED SDA   = GPIO21  (I2C, 0x3C)
OLED SCL   = GPIO22  (I2C)
AHT20      = GPIO21/22 (I2C, 0x38)
```

### 베이스 펌웨어에 포함된 기능

- BLE OTA (무선 펌웨어 업데이트)
- 하드웨어 초기화 (initHardware)
- BLE 초기화 (initBLE)
- OLED 드라이버 (SSD1306)
- AHT20 센서 드라이버

## 10. 사용자 시나리오 (End-to-End)

```
1. 사용자가 웹/앱에서 카탈로그를 열람한다
      │
      ▼
2. "빨간 LED 1초마다 깜빡이기" (A05)를 선택한다
      │
      ▼
3. 코드와 교육 가이드를 확인한다
   - 이 코드가 무엇을 하는지 이해
   - 개념 학습 (digitalWrite, delay, xTaskCreate)
   - 퀴즈로 이해도 확인
      │
      ▼
4. "전송" 버튼을 누른다
      │
      ▼
5. BLE로 ESP32 보드에 연결한다
   - 디바이스 스캔 → "UTTEC-OTA" 선택
      │
      ▼
6. firmware.bin이 BLE OTA로 전송된다
   - 서버에서 650KB 바이너리 다운로드
   - 240바이트 청크로 BLE 전송
   - 진행률 표시
      │
      ▼
7. 보드가 자동 재부팅되고 새 펌웨어가 실행된다
   - 빨간 LED가 1초마다 깜빡이기 시작!
      │
      ▼
8. 사용자는 가이드의 "다음에 시도해볼 것"을 참고하여
   다른 항목을 선택하거나 응용 학습을 진행한다
```
