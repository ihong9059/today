## 2. CPU 상세 비교

### i5-1235U (현재)
- 10코어: 2P(성능) + 8E(효율)
- 12스레드
- 모바일 저전력 (15W)
- 빌드 1개당 ~68초

### Ryzen 9 9955HX (후보)
- 16코어: 모두 성능 코어 (Zen 5)
- 32스레드
- 모바일 고성능 (55W)
- 예상 빌드 1개당 ~20초

### Ryzen 9 7945HX (대안)
- 16코어: 모두 성능 코어 (Zen 4)
- 32스레드
- 모바일 고성능 (55W)
- 예상 빌드 1개당 ~22초

### 9955HX vs 7945HX 비교

| 항목 | 9955HX (Zen 5) | 7945HX (Zen 4) |
|------|:-:|:-:|
| 코어/스레드 | 16C/32T | 16C/32T |
| 최대 클럭 | 5.4GHz | 5.4GHz |
| IPC (클럭당 성능) | ~10~15% 향상 | 기준 |
| 전력 효율 | 더 좋음 | 보통 |
| 캐시 | L3 64MB | L3 64MB |
| 사전빌드 체감 차이 | 빌드당 ~5초 단축 | 기준 |
| 결론 | 가격 차이 적으면 선택 | 가성비 좋음 |

## 3. 교육 시나리오별 처리 능력

### 10명 동시 새 요청 (최악의 경우)

```
현재 PC (i5-1235U, 동시 3개):
  ┌ 학생1,2,3 → 빌드 → 1분 완료
  ├ 학생4,5,6 → 대기 → 빌드 → 2분 완료
  ├ 학생7,8,9 → 대기 → 빌드 → 3분 완료
  └ 학생10    → 대기 → 빌드 → 4분 완료  ← 최대 4분

Mini PC (R9 9955HX, 동시 6개):
  ┌ 학생1~6  → 빌드 → 1분 완료
  └ 학생7~10 → 대기 → 빌드 → 2분 완료  ← 최대 2분
```

### 30명 동시 새 요청

```
현재 PC: 불가능 (10분+ 대기)

Mini PC (R9 9955HX, 동시 6개):
  ┌ 학생1~6   → 1분
  ├ 학생7~12  → 2분
  ├ 학생13~18 → 3분
  ├ 학생19~24 → 4분
  └ 학생25~30 → 5분  ← 최대 5분
```

## 5. 권장 사항

### 현재 (10명 교육)
- **현재 PC로 충분** — 사전빌드 카탈로그 확충이 우선
- 대부분 사전빌드 매칭 (0.1초) → 동시 빌드 자체가 드묾

### 확장 (20~30명 교육)
- **Mini PC (R9 9955HX) 권장**
  - 교실 환경에 적합 (소형, 저소음)
  - 96GB RAM → 동시 빌드 6개 여유
  - 30명 최악의 경우에도 5분 내 처리

### 가성비 우선
- R9 7945HX 모델 (9955HX 대비 10~15% 느리지만 가격 저렴)
- 둘 다 현재 PC 대비 3~3.5배 성능

### 핵심 전략
```
사전빌드 카탈로그 확충 (155개 + 수업 중 축적)
  → AI 빌드 필요성 최소화
  → PC 성능에 대한 의존도 감소
  → 어떤 PC에서든 안정적 교육 가능
```
