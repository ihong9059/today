# Arduino + AI 바이브 코딩 교육 홍보 동영상 시나리오

---

## 영상 정보

| 항목 | 내용 |
|------|------|
| 제목 | 말하면 동작한다 — Arduino + AI 바이브 코딩 |
| 길이 | 3분 30초 ~ 4분 |
| 용도 | 용인시 중소기업진흥원 교육 제안 / 교육 홍보 |

**[화면]** 밝아지는 톤, 스마트폰 화면 클로즈업

**[내레이션]**
> 만약, 이렇게만 하면 된다면요?

**[화면]** 스마트폰에 타이핑하는 손

```
"빨간 LED를 1초마다 깜빡여줘"
```

**[화면]** 3초 카운트다운 → Arduino 보드의 LED가 실제로 깜빡이기 시작

**[내레이션]**
> 30초. 그게 전부입니다.
> 코드를 쓰지 않았습니다. C언어를 모릅니다.
> USB 케이블도 연결하지 않았습니다.
> 그런데 LED가 깜빡이고 있습니다.

**[화면]** "바이브 코딩" 타이틀 등장 (오렌지색 + 글로우 효과)

**[내레이션]**
> 이것이 **바이브 코딩**입니다.
> 한국어로 말하면, AI가 코드를 만들고,
> 무선으로 보드에 보내고,

### Scene 3: 시스템 설명 (1:15 ~ 1:45)

**[화면]** 애니메이션 플로우 차트

```
학습자 → 스마트폰 앱 → AI Tool → 코드 생성 + 컴파일 → 무선 전송 → 보드 동작
```

**[내레이션]**
> 어떻게 가능할까요?

> 첫째, 학습자가 **스마트폰 앱**에서 원하는 동작을 한국어로 입력합니다.

> 둘째, **AI Tool**이 Arduino 코드를 자동으로 생성하고 컴파일합니다.

> 셋째, 완성된 프로그램을 **무선(BLE)**으로 보드에 전송합니다.

> 이 전체 과정이 **30초**입니다.

### Scene 4: 다양한 시연 (1:45 ~ 2:30)

**[화면]** 실제 시연 영상들, 빠른 컷 전환

#### Scene 4-1: LED (1:45 ~ 1:55)
**[화면]** 스마트폰 → "신호등 만들어줘" → 빨강→노랑→초록 LED 순차 점등

> "신호등 만들어줘" — 3색 LED가 순서대로 바뀝니다.

**[내레이션]**

**[내레이션]**
> "온도를 보여줘" — 센서가 측정하고 화면에 표시합니다.

**[내레이션]**

### Scene 5: 교육 소개 (2:30 ~ 3:10)

**[화면]** 5단계 레벨 순차 등장 (컬러풀하게)

> **Level 1**에서 성공 경험을 먼저 합니다.

### 핵심 시각적 장면

1. **WOW 모먼트 (Scene 2)**: 스마트폰에 한국어 입력 → 실제 LED가 깜빡이는 순간을 **한 컷으로** 보여주는 것이 가장 중요. 편집 없이 실시간으로 촬영하여 "정말 30초에 되는구나"를 느끼게 함.

2. **빠른 시연 몽타주 (Scene 4)**: 4가지 시연을 각 5~10초씩 빠르게 컷 전환. "이것만 되는 게 아니라 이것도, 저것도, 이것까지" 느낌.

3. **보드 클로즈업**: LED가 깜빡이는 보드를 매크로 촬영하여 오프닝/엔딩에 사용.

### 실제 촬영 필요 장면

| 장면 | 촬영 내용 |
|------|-----------|
| 스마트폰 입력 | 손가락으로 프롬프트 타이핑하는 클로즈업 |
| LED 깜빡임 | 보드의 LED가 깜빡이는 매크로 촬영 |
| 신호등 | 3색 LED 순차 점등 |
| 멜로디 | 부저에서 소리 나는 보드 (실제 소리 녹음) |
| OLED 표시 | 디스플레이에 온도가 뜨는 화면 |
| 교육 현장 | 여러 명이 보드를 들고 실습하는 장면 (연출) |

### 필수 확인사항

- Arduino 보드를 "UTTEC 보드" 또는 "교육용 보드"로 칭함
- 특정 AI 서비스 로고 노출 금지 (AI Tool로 통칭)
- 실제 30초 시연은 편집 없이 1컷으로 촬영하여 신뢰감 확보
- BGM은 시연 시 볼륨 낮추어 부저 소리가 들리도록 함
