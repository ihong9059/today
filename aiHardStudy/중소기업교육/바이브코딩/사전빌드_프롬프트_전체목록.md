# UTTEC 사전 빌드 프롬프트 전체 목록

> **보드:** ESP32-WROOM-32 DevKitC (38핀)
> **하드웨어:** LED 3색(25,26,27) / 부저 2종(14,33) / OLED SSD1306 / AHT20 센서 / 스위치(32) / BLE(NimBLE)
> **BLE 특성:** CMD(FE04, Write) — 스마트폰→보드 명령 / SENSOR(FE05, Notify) — 보드→스마트폰 데이터
> **등급:** 기초(★) / 중급(★★) / 고급(★★★) / 프로(★★★★)

---

| 등급 | 대상 | 부품 수 | 프로그래밍 개념 | BLE 연동 |
|:----:|------|:------:|---------------|:-------:|
| **기초 ★** | 입문자 | 1개 | 켜기/끄기, delay, for | X |

| **프로 ★★★★** | 종합 단계 | 3개+ | 멀티태스크, 프로토콜, 데이터 처리 | 양방향 |

## 기초 ★ — 하나씩 배우기

## BLE 통신 프로토콜 확장 (참고)

### SENSOR 특성(FE05) Notify 데이터 형식

현재 정의된 타입:
```
[0x01, 값]         → 스위치 상태 (0=해제, 1=눌림)   ← 기존
```

사전 빌드 프롬프트에서 확장할 타입:
```
[0x02, temp_int, temp_dec]       → 온도 (정수부, 소수부)
[0x03, humi_int, humi_dec]       → 습도 (정수부, 소수부)
[0x04, score_hi, score_lo]       → 게임 점수 (16비트)
[0x05, mode]                     → 현재 모드 (1~N)
[0x06, led_r, led_y, led_b]      → LED 상태 (0=OFF, 1=ON)
[0x07, react_hi, react_lo]       → 반응시간 (밀리초, 16비트)
[0x08, count_hi, count_lo]       → 카운트 값 (16비트)
[0x09, minutes, seconds]         → 타이머 남은 시간
[0x0A, status]                   → 상태 (0=정상, 1=주의, 2=위험)
[0x10, len, char1, char2, ...]   → 문자열 데이터 (가변 길이)
```

### CMD 특성(FE04) 확장 명령어

기존 명령어 (유지):
```
LED_RED_ON, LED_RED_OFF, LED_YELLOW_ON, ...
LED_ALL_OFF, BEEP, NOTE_0~7, OLED:{text}, TEMP, SETNAME:{name}
```

사전 빌드 프롬프트에서 추가할 명령어:
```
MODE:{n}           → 모드 전환
SPEED:{ms}         → LED 속도 변경
BLINK:{count}:{ms} → LED 깜빡 (횟수:간격)
MELODY:{name}      → 멜로디 선택 재생 (school/birthday/star)
READ               → 센서 읽기 요청
STATUS             → 전체 상태 조회
ALARM:{seconds}    → 타이머 시작
GUESS:{number}     → 온도 맞추기 게임 답
ANSWER:{letter}    → 퀴즈/타이핑 게임 답
SPIN               → 룰렛 시작
RESET              → 게임 리셋
```
