# 출석체크 인증 웹 시스템 계획서

## 1. 개요

교육생 PC에 설치된 Claude Code의 사용을 강사가 제어하는 시스템.
교육생이 인증을 신청하면 강사가 승인하고, 토큰 파일을 발급하여 Claude 실행을 허용한다.
토큰은 당일만 유효하므로 매일 출석 인증이 필요하다.

## 2. 시스템 구성

```
[교육생 PC - Raspberry Pi]              [강사 PC - 웹 서버]
                                         (192.168.0.20:5000)
1. 브라우저로 인증 신청 ──────────────▶ 2. 강사가 승인
3. 토큰 파일 저장 (~/.claude_auth)  ◀── (토큰 = 이름+날짜+서명)

4. claude 실행
5. Hook → 토큰 파일 확인
   - 유효 → 정상 실행
   - 없음/만료 → 차단
```

## 3. 주요 기능

### 3.1 교육생 (브라우저)
- 강사 PC URL 접속 → 이름 입력 → 인증 신청
- 강사 승인 후 "토큰 다운로드" 버튼 표시
- 토큰 파일을 `~/.claude_auth` 에 저장

### 3.2 강사 (관리 페이지)
- 인증 대기 목록: 신청한 교육생 표시 (이름, IP)
- 승인/거부 버튼
- 출석 현황: 인증 완료된 교육생 목록 (이름, IP, 시간)
- 전체 초기화: 새 교육 시작 시 리셋

### 3.3 Claude Hook (교육생 PC)
- Claude 시작 시 `~/.claude_auth` 토큰 파일 확인
- 토큰 내용: `{"name": "홍길동", "date": "2026-05-01", "sig": "..."}`
- 오늘 날짜와 일치 + 서명 유효 → 통과
- 그 외 → Claude 실행 차단 (에러 메시지 출력)

## 5. 기술 스택

| 구분 | 기술 | 이유 |
|------|------|------|
| 강사 서버 | Python Flask | 단일 파일, 설치 용이 |
| 프론트엔드 | HTML + CSS (인라인) | 빌드 불필요 |
| 토큰 | JSON + HMAC-SHA256 서명 | 위변조 방지 |
| 데이터 저장 | 메모리 (dict) | DB 불필요, 매일 초기화 |
| Hook | Bash 스크립트 | Claude Code PreToolUse hook |

## 6. API 설계

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/` | 교육생 인증 신청 페이지 |
| POST | `/request-auth` | 인증 신청 (이름 전송) |
| GET | `/check-status?name=X` | 승인 상태 확인 (polling) |
| GET | `/download-token?name=X` | 토큰 파일 다운로드 |
| GET | `/admin` | 강사 관리 페이지 |
| POST | `/admin/approve` | 교육생 승인 |
| POST | `/admin/deny` | 교육생 거부 |
| POST | `/admin/reset` | 전체 초기화 |

## 7. 토큰 구조

```json
{
  "name": "홍길동",
  "date": "2026-05-01",
  "sig": "hmac_sha256(name+date, SECRET_KEY)"
}
```

- 날짜가 오늘과 다르면 만료 → 매일 새로 인증 필요
- HMAC 서명으로 위변조 방지 (SECRET_KEY는 강사 서버에만 보관)

## 8. 파일 구조

```
강사 PC (192.168.0.20):
  출석체크/
  ├── 출석체크_시스템_계획서.md   (본 문서)
  └── app.py                     (Flask 웹 서버)

교육생 PC (Raspberry Pi):
  ~/.claude_auth                  (토큰 파일 - 인증 후 저장)
  ~/.claude/settings.json         (hook 설정)
  ~/.claude/hooks/check_auth.sh   (토큰 확인 스크립트)
```
