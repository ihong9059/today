# Claude 출석체크 인증 시스템 - 사용방법

## 강사용

### 1. 서버 실행

```bash
cd aiHardStudy/중소기업교육/출석체크
python app.py
```

서버가 시작되면 아래 주소로 접속 가능:
- 교육생 페이지: http://192.168.0.20:5000
- 관리 페이지: http://192.168.0.20:5000/admin

### 2. 교육생 승인

1. 관리 페이지(`/admin`) 접속
2. "인증 대기" 목록에 교육생 이름/IP 표시됨
3. [승인] 또는 [거부] 버튼 클릭
4. 승인된 교육생은 "인증 완료" 목록으로 이동

### 3. 전체 초기화

새 교육 회차 시작 시 관리 페이지 하단의 [전체 초기화] 클릭.
모든 대기/승인 목록이 초기화됨.

### 4. 서버 종료

서버를 종료하면 신규 인증 신청 불가.
기존 토큰은 당일까지 유효하며, 다음날 자동 만료.

## 교육생용

### 방법 A: 터미널에서 인증 (추천)

터미널에서 아래 명령 한 줄로 인증 신청부터 토큰 저장까지 자동 처리:

```bash
claude-auth
```

실행하면:
1. 이름 입력
2. 자동으로 서버에 인증 신청
3. 강사 승인 대기 (자동 폴링)
4. 승인되면 토큰 자동 저장 → 바로 Claude 사용 가능

```
============================
  Claude 출석 인증 신청
============================

이름을 입력하세요: 홍길동

인증 신청 중...
신청 완료! 강사 승인 대기 중...
(승인되면 자동으로 토큰이 저장됩니다)
....
승인되었습니다! 토큰 다운로드 중...

토큰이 /home/uttec/.claude_auth 에 저장되었습니다.
이제 claude 를 실행할 수 있습니다.
```

### 방법 B: 브라우저에서 인증

1. 브라우저에서 `http://192.168.0.20:5000` 접속
2. 이름 입력 후 [인증 신청] 클릭
3. 강사 승인 대기
4. 승인 후 [토큰 다운로드] 클릭
5. 터미널에서 토큰 파일 이동:
   ```bash
   mv ~/Downloads/claude_auth ~/.claude_auth
   ```

### Claude 사용

인증 완료 후 Claude를 정상적으로 사용 가능:

```bash
claude
```

### 주의사항

- 토큰은 **당일만 유효**. 매일 새로 인증 필요.
- 토큰이 없거나 만료되면 Claude 실행 시 아래 메시지 표시:
  ```
  인증 토큰이 없습니다. 먼저 출석 인증을 받으세요.
  브라우저에서 http://192.168.0.20:5000 접속 후 인증 신청
  ```
