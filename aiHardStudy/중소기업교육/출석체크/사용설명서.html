UTTEC 출석체크 시스템

교육생 Claude 접속 관리를 위한 사용설명서

어떻게 동작하나요? 교육 시작하기 학생 승인하기 출석부 관리 교육 종료일 학생 화면 자주 묻는 질문

이 시스템은 어떻게 동작하나요?

학생들의 PC에는 AI 도구(Claude)가 설치되어 있습니다.
하지만 선생님이 승인하지 않으면 Claude를 사용할 수 없습니다.

매일 수업이 시작되면 다음과 같은 순서로 진행됩니다:

학생이
출석 신청
→
선생님이
승인
→
학생 PC에서
Claude 사용 가능
핵심 포인트 • 승인은 하루만 유효합니다. 다음날이면 다시 승인이 필요합니다.
• 출석부에 등록된 학생만 신청할 수 있습니다.
• 선생님이 프로그램을 끄면 새로운 승인은 불가능합니다.

교육 시작하기 (매일 수업 전)

  1. 출석체크 프로그램을 실행합니다
    바탕화면 또는 폴더에서 출석체크 폴더를 찾아 들어갑니다.
    그 안의 app.py 파일을 더블클릭하거나, 터미널에서 아래와 같이 입력합니다:
    $ python app.py
  2. 관리 화면을 엽니다
    프로그램이 실행되면 화면에 주소가 표시됩니다.
    인터넷 브라우저(Chrome 등)를 열고 주소창에 아래와 같이 입력합니다:
    http://내컴퓨터IP:5000/admin
    (예: http://192.168.0.20:5000/admin)
  3. 학생들에게 선생님 컴퓨터의 IP 주소를 알려줍니다
    학생들이 처음 한 번만 이 번호를 입력하면 됩니다.
    내 컴퓨터 IP 확인 방법 프로그램을 실행하면 화면에 자동으로 표시됩니다.
    (예: [출석체크 서버] http://192.168.0.20:5000 → IP는 192.168.0.20)
  4. 학생들에게 uttecEdu를 실행하라고 안내합니다
    학생은 자기 PC의 터미널에서 uttecEdu 라고 입력하면 됩니다.

학생 승인하기

학생이 출석 신청을 하면, 관리 화면의 "인증 대기" 목록에 학생 이름이 나타납니다.

http://192.168.0.20:5000/admin
인증 대기 (2명)
#이름IP시간
1홍길동192.168.0.2309:01 승인 거부
2김철수192.168.0.2409:02 승인 거부
  1. [승인] 버튼을 누르면 학생의 PC에서 Claude가 바로 실행됩니다
  2. [거부] 버튼을 누르면 해당 학생의 신청이 거부됩니다

승인된 학생은 "인증 완료" 목록으로 이동합니다:

http://192.168.0.20:5000/admin
인증 완료 2명
#이름IP시간
1홍길동192.168.0.2309:01
2김철수192.168.0.2409:02
관리 화면은 5초마다 자동 갱신됩니다 새로운 신청이 들어오면 자동으로 목록에 나타나므로 새로고침할 필요가 없습니다.

출석부 관리

관리 화면 상단에 출석부가 있습니다. 여기서 누가 출석했고, 누가 아직 안 했는지 한눈에 볼 수 있습니다.

http://192.168.0.20:5000/admin
출석부 3/5명 (미출석: 2명)
#이름상태
1홍길동출석삭제
2김철수출석삭제
3이영희미출석삭제
4박민수대기중삭제
5정수진미출석삭제
추가

학생 추가하기

  1. 출석부 아래의 입력란에 학생 이름을 입력합니다
  2. [추가] 버튼을 클릭합니다

학생 삭제하기

  1. 해당 학생 오른쪽의 [삭제] 버튼을 클릭합니다
  2. 확인 창이 나타나면 [확인]을 클릭합니다
출석부에 없는 학생은 신청할 수 없습니다 수업 전에 미리 학생 이름을 출석부에 등록해 주세요.

출석 초기화

같은 날 다른 반 수업을 시작할 때, 관리 화면 하단의 [출석 초기화] 버튼을 누르면 출석 현황만 초기화됩니다. 학생 명단은 그대로 유지됩니다.

교육 종료일 설정

관리 화면 상단에 교육 종료까지 남은 일수가 표시됩니다.

http://192.168.0.20:5000/admin
교육 종료까지 30일 남음 (2026-05-31)
변경

종료일을 바꾸려면

  1. 날짜를 클릭하여 원하는 종료일을 선택합니다
  2. [변경] 버튼을 클릭합니다

남은 일수 표시 색상

남은 기간색상의미
8일 이상초록색여유 있음
1~7일주황색곧 종료
0일 이하빨간색교육 기간 종료
교육 기간이 끝나면 어떻게 되나요? 교육 종료일이 지나면, 학생 PC에서 Claude가 자동으로 삭제됩니다.
별도로 학생 PC를 수거하거나 직접 삭제할 필요가 없습니다.

학생은 이렇게 사용합니다

학생에게 안내할 내용은 아주 간단합니다:

학생 안내 사항

1. 터미널을 열고 uttecEdu 를 입력하세요

2. 처음 한 번만 선생님이 알려준 IP 번호를 입력하세요

3. 이름을 입력하고 기다리면 됩니다

학생 화면 예시

$ uttecEdu

서버 IP: 192.168.0.20 ← 처음 1회만 입력

  UTTEC 교육에 오신것을 환영합니다.
  교육 종료까지 30일 남았습니다.

이름: 홍길동
..........
(선생님이 승인하면 Claude가 자동으로 실행됩니다)
학생이 알아야 할 것 • 매일 수업 시작 시 uttecEdu를 실행해야 합니다
• 선생님이 승인하면 Claude가 바로 실행됩니다
• 20초 안에 승인이 안 되면 "timeout"이 표시되며, 다시 실행하면 됩니다

수업 끝나면

프로그램이 실행 중인 터미널에서 Ctrl + C 를 누르면 프로그램이 종료됩니다.

프로그램을 끄면 • 새로운 출석 신청은 받을 수 없습니다
• 이미 승인받은 학생은 오늘 하루 동안 Claude를 계속 사용할 수 있습니다
• 내일이 되면 자동으로 만료되어 다시 승인이 필요합니다

자주 묻는 질문

질문 답변
학생이 "timeout"이 나온다고 합니다 프로그램이 실행 중인지 확인하세요. 프로그램이 꺼져 있으면 학생이 접속할 수 없습니다.
출석부에 없는 학생이 신청하면? 자동으로 거부됩니다. 먼저 출석부에 학생을 추가해 주세요.
어제 승인한 학생이 오늘 안 된다고 합니다 정상입니다. 매일 새로 승인해야 합니다.
다른 반 수업을 시작하려면? [출석 초기화] 버튼을 누르세요. 출석 현황만 리셋되고 학생 명단은 유지됩니다. 필요하면 학생 명단을 추가/삭제하세요.
컴퓨터 IP가 바뀌면? 학생에게 새 IP를 알려주세요. 학생은 저장된 IP를 지우고(rm ~/.uttec_server) 다시 실행하면 됩니다.
교육이 끝나면 학생 PC를 회수해야 하나요? 아닙니다. 교육 종료일이 지나면 학생 PC에서 Claude가 자동으로 삭제됩니다.
학생 이름 입력 중에 글자가 사라집니다 입력란을 클릭한 상태에서는 화면이 새로고침되지 않습니다. 입력 후 바로 [추가]를 누르세요.
