## 1. 교육 목표

```
[중소기업 현장 과제]                    [교육 후 역량]

 설비 고장 → 사후 대응               →  센서 데이터로 이상 조기 감지
 수작업 품질 검사                     →  카메라 AI로 자동 불량 판정
 생산 데이터 수기 기록                →  자동 수집 + 대시보드 시각화
 자동화 = 비싸다는 인식               →  Raspberry Pi로 저비용 구현 체험
```

### 핵심 교육 성과
1. **Raspberry Pi로 센서 데이터 수집** - 온도, 진동, 전류 등
2. **간단한 자동 제어 구현** - 릴레이, 모터, 알림
3. **AI 모델로 이상탐지/불량판정** - TensorFlow Lite, OpenCV
4. **실시간 모니터링 대시보드 구축** - 웹 기반 시각화
5. **ChatGPT/Claude API 활용** - 자연어로 설비 상태 질의

### 2.3 Shield 포트 연결 정리 (raspberry_esp32c3.pdf 기준)

Shield는 **Raspberry Pi 40핀 헤더(CN1)**에 장착되며, **ESP32C3-SuperMini(U1)**가 탑재되어 듀얼 프로세서로 동작합니다.

```
┌─────────────────────────────────────────────────────────┐
│                    시스템 구성도                           │
│                                                         │
│  [Raspberry Pi 4B] ←── CN1 (40핀) ──→ [Shield Board]    │
│       │                                    │            │
│       ├─ I2C (SDA/SCL) ──────────→ AHT20 온습도센서     │
│       │                   └──────→ OLED 디스플레이       │
│       │                   └──────→ 확장커넥터 (U12)      │
│       │                                                 │
│       ├─ UART (TX/RX) ──────────→ ESP32C3-SuperMini     │
│       │                                                 │
│       ├─ GPIO 직접제어 ─────────→ WS2812 LED x4 (체인)  │
│       │                  ├──────→ 신호등 LED (R/Y/B)     │
│       │                  ├──────→ 택트 스위치 (SW1)      │
│       │                  ├──────→ 부저 (2.7kHz)         │
│       │                  └──────→ 스피커 (Q1 트랜지스터) │
│       │                                                 │
│       └─ SPI (MOSI/MISO/SCLK) ─→ 확장용 (예비)         │
└─────────────────────────────────────────────────────────┘
```

#### 통신 버스 구성

```
[I2C 버스] (공유 - RPi + ESP32C3 동시 접속)
  ├── AHT20 (U5) ─── 온습도 센서 (Addr: 0x38)
  ├── OLED (U3) ──── 0.96" 디스플레이 (Addr: 0x3C)
  └── 확장 (U12) ─── 5핀 커넥터 (추가 I2C 디바이스)
  * 풀업: R1(SDA), R2(SCL) = 10KΩ → 3.3V

[UART] (RPi ↔ ESP32C3 크로스 연결)
  Pin 8  (RX, GPIO14) ←── ESP32C3 TX (GPIO20)
  Pin 10 (TX, GPIO15) ──→ ESP32C3 RX (GPIO21)
  * 3.3V 레벨
  * 회로도상 RX/TX 명칭은 ESP32C3 관점 기준

[SPI 버스] (공유 - RPi + ESP32C3)
  MOSI: RPi GPIO10 (Pin19) / ESP32C3 GPIO1
  MISO: RPi GPIO9  (Pin21) / ESP32C3 GPIO2
  SCLK: RPi GPIO11 (Pin23) / ESP32C3 GPIO3

[WS2812 LED 체인] (데이지 체인)
  DIN → U4 → U8 → U9 → U10 (4개 직렬)
  * RPi GPIO12 (Pin32) 또는 ESP32C3 GPIO8에서 제어 가능
```

```

  [온도센서]──┼──[Raspberry Pi]──[MQTT]──[웹 대시보드]
  [전류센서]──┤       │                      │
  [카메라]────┘       │                      ├ 실시간 그래프

                      ├──[AI 이상탐지]        ├ AI 판정 결과
                      ├──[AI 비전검사]        └ 일일 보고서
                      ├──[릴레이 제어]──[경고등/부저]
                      └──[Claude API]──[자연어 보고서]
```

### 평가 기준

| 항목 | 배점 | 기준 |
|------|:----:|------|
| 센서 데이터 수집 | 20점 | 3종 이상 센서 정상 동작 |
| 자동 제어 | 20점 | 임계값 초과 시 릴레이/알림 동작 |
| AI 이상탐지 | 20점 | 이상 상황 자동 판별 |
| 대시보드 | 20점 | 웹 기반 실시간 모니터링 |
| 발표/문서화 | 20점 | 구현 내용 설명 + 현장 적용 아이디어 |

## 6. 기대 효과

### 교육 수료 후 즉시 활용 가능 역량

| 역량 | 현장 적용 예시 |
|------|---------------|
| 센서 데이터 수집 | 설비 온도/진동 모니터링 시스템 자체 구축 |
| 이상탐지 AI | 설비 고장 조기 경보 → 다운타임 30% 감소 |
| 비전 AI | 간단한 외관 검사 자동화 → 검사 시간 50% 단축 |
| 대시보드 | 생산현황 실시간 공유 → 의사결정 속도 향상 |
| AI API 활용 | 보고서 자동 생성, 데이터 분석 자동화 |

### 비용 효과

```
기존 스마트팩토리 구축: 수천만원~수억원 (PLC + SCADA + MES)
    ↓
Raspberry Pi 기반:    20~50만원으로 핵심 기능 프로토타입
    ↓
검증 후 본격 투자 의사결정 → 실패 리스크 최소화
```
