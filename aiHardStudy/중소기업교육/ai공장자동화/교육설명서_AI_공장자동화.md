## 2. 왜 AI 공장자동화인가?

### 2-1. 중소기업 제조 현장의 과제

| 과제 | 현실 | AI 자동화 적용 시 |
|------|------|------------------|
| **설비 고장** | 고장 후 수리 (사후 대응) | 진동/온도 이상 사전 감지 → 예방 정비 |
| **품질 검사** | 육안 검사 (피로, 오류) | 카메라 AI가 24시간 자동 판별 |
| **환경 관리** | 작업자가 주기적 확인 | 센서가 실시간 모니터링 + 자동 알림 |
| **데이터 활용** | 수기 기록, 엑셀 관리 | 자동 수집 → 분석 → 대시보드 시각화 |
| **비용** | 대기업용 시스템 (수천만원) | Raspberry Pi 기반 (수십만원) |

### 2-2. Raspberry Pi가 적합한 이유

```
[대기업 공장자동화 시스템]
  PLC + SCADA + MES = 수천만원~수억원
  → 도입 기간: 수개월
  → 유지보수: 전문 업체 의존

[Raspberry Pi 기반 시스템]
  Pi + Shield + Python = 수십만원
  → 도입 기간: 수일~수주
  → 유지보수: 내부 인력 가능 (Python 기반)
  → 확장: 필요한 만큼 점진적 확대
```

Raspberry Pi는 **"완전한 컴퓨터"**입니다. Linux 운영체제, Python 프로그래밍, 네트워크 통신, GPIO 하드웨어 제어를 하나의 보드에서 수행합니다. 이것이 Arduino 같은 단순 마이크로컨트롤러와의 핵심 차이입니다.

### 2-3. Google Colab의 교육적 가치

| 항목 | 설명 |
|------|------|
| **무료 GPU** | AI 모델 학습에 필요한 GPU를 무료로 사용 |
| **설치 불필요** | 브라우저만 있으면 즉시 시작, 환경 설정 제로 |
| **공유 가능** | 교육 자료를 링크 하나로 배포 |
| **실시간 실행** | 코드를 한 줄씩 실행하며 결과 즉시 확인 |
| **영구 저장** | Google Drive에 자동 저장 |

> **교육 현장에서의 활용**: 4회차 AI 실습 시 Colab에서 모델을 학습시키고,

### 3-2. UTTEC Shield Board

UTTEC Shield는 Raspberry Pi에 장착하여 공장자동화 실습에 필요한 센서와 제어장치를 통합 제공합니다. **별도 배선 없이** 장착만으로 즉시 실습 가능합니다.

```
┌────────────────────────────────────────┐
│         UTTEC Shield Board             │
│                                        │
│  [RED] [YEL] [BLU]     [WS2812 x4]   │
│   LED   LED   LED      RGB NeoPixel   │
│                                        │
│  ┌────────┐  ┌────────┐   [SW1]      │
│  │  OLED  │  │ AHT20  │   택트스위치  │
│  │ 128x64 │  │ 온습도  │              │
│  └────────┘  └────────┘              │
│                                        │
│  [BUZZER]  [SPEAKER]   [ESP32C3]      │
│   경고음     멜로디     보조MCU(UART)  │
│                                        │
│  I2C / SPI / UART 확장 지원           │
└────────────────────────────────────────┘
```

### 3-3. Shield 부품 상세

| 부품 | GPIO 핀 | 용도 | 사용 회차 |
|------|:-------:|------|:---------:|
| AHT20 온습도 센서 | SDA(3), SCL(5) | 공장 환경 모니터링 | 2~5 |
| OLED 0.96" 디스플레이 | SDA(3), SCL(5) | 실시간 데이터 표시 | 2~5 |
| 빨간 LED | GPIO17 | 위험 경고등 | 2~5 |
| 노란 LED | GPIO27 | 주의 경고등 | 2~5 |
| 파란 LED | GPIO22 | 정상 표시등 | 2~5 |
| 부저 | GPIO5 | 경고음 출력 | 2~5 |
| 택트 스위치 | GPIO4 | 시작/정지 입력 | 2~5 |
| WS2812 RGB LED x4 | GPIO12 | 다색 상태 표시 | 2~5 |
| 스피커 | GPIO13 | 음성/멜로디 출력 | 3~5 |
| ESP32C3 (UART) | GPIO14/15 | Wi-Fi/BLE 게이트웨이 | 3~5 |

#### 핵심 실습 코드: 공장 신호등

```python
# factory_signal.py - UTTEC Shield Board 핀 배치 기준
import RPi.GPIO as GPIO
import time
import board, busio, adafruit_ahtx0

# UTTEC Shield 핀 설정
LED_RED = 17     # Pin 11 - 위험
LED_YELLOW = 27  # Pin 13 - 주의
LED_BLUE = 22    # Pin 15 - 정상
BUZZER = 5       # Pin 29 - 경고음

GPIO.setmode(GPIO.BCM)
for pin in [LED_RED, LED_YELLOW, LED_BLUE, BUZZER]:
    GPIO.setup(pin, GPIO.OUT)

# AHT20 센서 (I2C)
i2c = busio.I2C(board.SCL, board.SDA)
sensor = adafruit_ahtx0.AHTx0(i2c)

try:
    while True:
        temp = sensor.temperature
        humi = sensor.relative_humidity
        print(f"온도: {temp:.1f}C, 습도: {humi:.1f}%")

        # 신호등 로직
        GPIO.output(LED_BLUE, temp < 28)       # 정상
        GPIO.output(LED_YELLOW, 28 <= temp < 35)  # 주의
        GPIO.output(LED_RED, temp >= 35)        # 위험
        GPIO.output(BUZZER, temp >= 35)         # 경고음

        time.sleep(2)
except KeyboardInterrupt:
    GPIO.cleanup()
```

#### 핵심 실습 코드: 이상탐지 + AI 보고서

```python
# ai_anomaly_report.py - 이상탐지 + AI API 보고서
import numpy as np
import board, busio, adafruit_ahtx0
import RPi.GPIO as GPIO
import time, requests

# 센서 및 GPIO 초기화
i2c = busio.I2C(board.SCL, board.SDA)
sensor = adafruit_ahtx0.AHTx0(i2c)
LED_RED = 17; BUZZER = 5
GPIO.setmode(GPIO.BCM)
GPIO.setup(LED_RED, GPIO.OUT)
GPIO.setup(BUZZER, GPIO.OUT)

# 1단계: 정상 데이터 수집 (30초)
print("정상 데이터 수집 중...")
normal = [sensor.temperature for _ in range(30)]
mean, std = np.mean(normal), np.std(normal)
print(f"기준값: 평균 {mean:.1f}C, 표준편차 {std:.2f}")

# 2단계: 실시간 감시 + 이상 시 AI 보고서
while True:
    temp = sensor.temperature
    z_score = abs(temp - mean) / std if std > 0 else 0
    status = "이상!" if z_score > 2 else "정상"

    GPIO.output(LED_RED, z_score > 2)
    GPIO.output(BUZZER, z_score > 2)
    print(f"온도: {temp:.1f}C, Z-score: {z_score:.2f} -> {status}")

    if z_score > 2:
        # AI API로 보고서 자동 생성
        report = generate_ai_report(temp, mean, std, z_score)
        print(f"\n[AI 보고서]\n{report}\n")

    time.sleep(1)
```

### 5-2. Google Colab

| 항목 | 설명 |
|------|------|
| **무료 GPU** | T4 GPU로 AI 모델 학습 (CPU 대비 10~50배 빠름) |
