## 장면 구성

### Scene 1: 중소기업 현장의 고민 (0:00 ~ 0:35)

**[화면]** 공장 내부, 설비가 돌아가는 모습. 작업자가 수기로 온도를 기록하는 장면.

**[내레이션]**
> 공장 온도, 지금도 사람이 돌아다니며 확인하고 계신가요?
> 설비가 갑자기 멈추면, 원인을 찾느라 반나절.
> 불량품이 나가면, 그때서야 알게 됩니다.

**[화면]** 텍스트 순차 등장 (공장 배경 위에)

```
설비 고장: 사후 대응 (이미 늦음)
품질 검사: 육안 검사 (피로, 실수)
환경 관리: 수기 기록 (누락, 지연)
데이터 활용: 엑셀 정리 (시간 소모)
```

**[내레이션]**
> 스마트 팩토리를 도입하고 싶지만,
> 수천만원짜리 시스템은 부담스럽습니다.

**[화면]** "수천만원" 텍스트에 X 표시 → 페이드아웃

### Scene 2: 반전 -- Raspberry Pi 등장 (0:35 ~ 1:15)

**[화면]** 밝아지는 톤. 손바닥 위의 Raspberry Pi + UTTEC Shield 클로즈업.

**[내레이션]**
> 이 작은 보드 하나가, 여러분의 공장을 바꿀 수 있습니다.

**[화면]** Pi + Shield를 테이블에 놓고 전원 연결 → 부팅 → OLED에 온습도 표시

**[내레이션]**
> Raspberry Pi. 신용카드 크기의 **완전한 컴퓨터**입니다.
> 여기에 센서, LED, 부저가 탑재된 UTTEC Shield를 장착하면,
> 바로 공장자동화 시스템의 시작입니다.

**[화면]** 핵심 수치 등장

```
보드 가격: 12만원
프로그래밍: Python (가장 쉬운 언어)
AI 학습: Google Colab (무료 GPU)
구축 기간: 수일
```

**[내레이션]**
> 비용은 12만원. 프로그래밍은 Python. AI 학습은 무료.
> 5일이면 직접 만들 수 있습니다.

---

### Scene 3: 실습 시연 -- 공장 신호등 (1:15 ~ 1:50)

**[화면]** 모니터에 Python 코드가 보이고, 옆에 Pi + Shield가 놓여 있음

**[내레이션]**
> 실제로 만들어 보겠습니다.
> Python 코드 20줄이면, 공장 신호등 시스템이 완성됩니다.

**[화면]** 코드 실행 → Shield의 동작

1. OLED에 "온도: 26.5C" 표시 → 파란 LED 점등 (정상)
2. 센서에 열을 가함 → "온도: 32.1C" → 노란 LED로 변경 (주의)
3. 온도 계속 상승 → "온도: 36.8C" → 빨간 LED + 부저 울림 (위험!)

**[내레이션]**
> 26도, 정상. 파란불.
> 32도, 주의. 노란불.
> 37도, 위험! 빨간불과 경고음이 울립니다.
> 이 모든 것이 Python 코드 20줄입니다.

### Scene 4: 웹 대시보드 + AI (1:50 ~ 2:30)

#### Scene 4-1: 대시보드 (1:50 ~ 2:05)

**[화면]** 노트북 브라우저에 Flask 대시보드 화면

**[내레이션]**
> 센서 데이터는 자동으로 웹 대시보드에 표시됩니다.
> 사무실에서, 스마트폰에서, 실시간으로 공장 상태를 확인합니다.

**[화면]** Chart.js 그래프가 실시간 업데이트되는 모습

#### Scene 4-2: Google Colab AI (2:05 ~ 2:15)

**[화면]** Colab 화면 - AI 모델 학습 진행 바 → 정확도 99% 결과

**[내레이션]**
> Google Colab에서는 AI를 직접 학습시킵니다.
> 무료 GPU로 5분이면 숫자를 읽는 AI가 완성됩니다.
> 같은 원리로 설비 이상을 감지하는 AI를 만듭니다.

#### Scene 4-3: 이상탐지 (2:15 ~ 2:30)

**[화면]** 터미널에서 이상탐지 프로그램 실행

```
온도: 26.3C, Z-score: 0.12 -> 정상
온도: 26.5C, Z-score: 0.31 -> 정상
온도: 38.7C, Z-score: 4.82 -> 이상 감지!

[AI 보고서]
설비 과열 경고: 현재 온도 38.7C (평균 26.4C 대비 +12.3C)
원인 추정: 냉각 시스템 이상 또는 과부하 운전
조치 권고: 즉시 설비 점검 및 냉각 상태 확인
```

**[내레이션]**
> 온도가 갑자기 올라가면, AI가 자동으로 감지합니다.
> 원인 분석과 조치 방법까지 AI가 보고서를 작성합니다.
> 사람이 24시간 지켜보지 않아도 됩니다.

### 핵심 시각적 장면

1. **WOW 모먼트 (Scene 3)**: 코드 실행 → 실제 LED 색상 변화 + 부저 울림을 **한 컷으로** 촬영. 편집 없이 실시간으로 "코드 20줄이 공장 신호등이 된다"를 보여줌.

2. **AI 순간 (Scene 4-3)**: 터미널에서 "정상... 정상... 이상 감지!"가 뜨는 순간 + AI 보고서가 자동 출력되는 장면. "사람 대신 AI가 지켜본다"는 메시지.

3. **대시보드**: 브라우저에서 차트가 실시간 업데이트되는 화면. "이걸 내가 만들었다"는 성취감.

### 실제 촬영 필요 장면

| 장면 | 촬영 내용 |
|------|-----------|
| 공장 현장 | 설비 가동 + 수기 기록하는 손 (또는 스톡 영상) |
| Pi 클로즈업 | Pi + Shield 보드 매크로 촬영 (OLED, LED 확인) |
| 코딩 화면 | 모니터에 Python 코드 + 옆에 보드 동작 |
| 신호등 시연 | 온도 변화 → LED 색 변경 + 부저 울림 (실제 소리) |
| 대시보드 | 브라우저 그래프 실시간 업데이트 |
| Colab | AI 학습 진행 → 결과 확인 화면 |
| 교육 현장 | 여러 명이 Pi를 다루는 장면 (연출) |

### 필수 확인사항

- Raspberry Pi의 확장 보드를 "UTTEC Shield" 또는 "UTTEC 보드"로 칭함
- 특정 AI 서비스 로고 노출 금지 (AI API, AI Tool로 통칭)
- 코드 실행 → 하드웨어 동작 시연은 편집 없이 1컷으로 촬영하여 신뢰감 확보
- BGM은 시연 시 볼륨 낮추어 부저 소리, Colab 실행 소리가 들리도록 함
- 공장 현장 영상은 실제 촬영 또는 로열티 프리 스톡 영상 사용
