> **[필수] RPi 3B+ UART 설정**
>
> RPi 3B+에서는 Bluetooth가 기본 UART(PL011)를 점유합니다.
> LoRa 통신(5일차)을 위해 **1일차에 미리 설정**해야 합니다.
>
> ```bash
> # 1. config.txt에 UART 설정 추가
> sudo nano /boot/config.txt
> # 파일 맨 아래에 다음 2줄 추가:
> #   dtoverlay=miniuart-bt
> #   enable_uart=1
>
> # 2. 시리얼 콘솔 비활성화
> sudo raspi-config
> # → Interface Options → Serial Port
> # → "login shell over serial?" → No
> # → "serial port hardware enabled?" → Yes
>
> # 3. 재부팅
> sudo reboot
>
> # 4. 설정 확인 (ttyAMA0이면 성공)
> ls -la /dev/serial0
> # → /dev/ttyAMA0 링크 확인
> ```

## 5일차: LoRa 무선 통신 (4시간)

> **목표**: LoRa 모듈(E22-900T30D)로 센서 데이터를 원격 전송/수신한다

### 1교시 (60분) — LoRa 통신 기초

| 시간 | 내용 | 방식 |
|------|------|------|
| 00~15 | LoRa 기술 소개 (장거리, 저전력, 915MHz) | 강의 |
| 15~25 | E22-900T30D 모듈 사양 (30dBm, 10km, UART) | 강의 |
| 25~40 | 핀 연결 확인 (TX/RX 크로스 연결 주의) | 강의 |
| 40~60 | UART 시리얼 통신 기초, pyserial 설치 | 실습 |

**TX/RX 연결 주의사항**:
```
[중요] 회로도 CN1 라벨 vs RPi 실제 GPIO

  CN1 Pin 8  → 회로도 "RX" → 실제 GPIO14 (TXD) → LoRa RXD로 전송
  CN1 Pin 10 → 회로도 "TX" → 실제 GPIO15 (RXD) → LoRa TXD에서 수신

  라벨이 LoRa 모듈 관점이므로 혼동 주의!
```

> **[RPi 3B+ UART 확인]**
>
> 1일차에 설정한 UART가 정상인지 확인:
> ```bash
> ls -la /dev/serial0
> # → /dev/ttyAMA0 링크 확인 (PL011 UART)
> ```
> 설정이 안 되어 있으면 1일차 UART 설정 절차를 다시 수행합니다.
>
> RPi 3B+에서는 반드시 `/dev/serial0` 사용 (RPi 4B의 `/dev/ttyS0`와 다름)

### 2교시 (60분) — LoRa 송수신 실습

| 시간 | 내용 | 방식 |
|------|------|------|
| 00~10 | 1일차 UART 설정 재확인 (미설정자 보완) | 실습 |
| 10~30 | LoRa 모드 설정 (M0, M1 핀 제어) | 실습 |
| 30~45 | 2인 1조: 보드 간 텍스트 메시지 송수신 | 실습 |
| 45~60 | 센서 데이터 패킷 설계 (JSON 포맷) | 실습 |

**실습 코드**:
```python

# RPi 3B+: /dev/serial0 사용 (1일차 UART 설정 필수)

# 송신 (센서 노드)
data = {
    "node": 1,
    "temp": sensor.temperature,
    "humi": sensor.relative_humidity,
    "status": get_status(sensor.temperature, sensor.relative_humidity)
}
ser.write((json.dumps(data) + '\n').encode())

# 수신 (게이트웨이)
line = ser.readline().decode().strip()
if line:
    received = json.loads(line)
    print(f"Node {received['node']}: {received['temp']}°C")
```
