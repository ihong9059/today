## 1. 환경 모니터링 기능

### 1-1. 온습도 실시간 측정
- **부품**: AHT20 센서 (I2C, 0x38)
- **기능**: 공장 내 온도/습도를 주기적으로 측정
- **Python**: `adafruit_ahtx0` 라이브러리 사용
- **활용**: 온도 ±0.3°C, 습도 ±2% 정밀 측정

```python
import board
import adafruit_ahtx0

i2c = board.I2C()
sensor = adafruit_ahtx0.AHTx0(i2c)
print(f"온도: {sensor.temperature:.1f}°C")
print(f"습도: {sensor.relative_humidity:.1f}%")
```

### 1-2. OLED 실시간 데이터 표시
- **부품**: OLED 디스플레이 (I2C, 0x3C)
- **기능**: 센서 데이터, 시스템 상태, 경고 메시지를 화면에 표시
- **Python**: `adafruit_ssd1306` + `Pillow` 라이브러리

```python
import adafruit_ssd1306
from PIL import Image, ImageDraw, ImageFont

oled = adafruit_ssd1306.SSD1306_I2C(128, 64, i2c)
image = Image.new("1", (128, 64))
draw = ImageDraw.Draw(image)
draw.text((0, 0), f"Temp: {sensor.temperature:.1f}C", fill=255)
oled.image(image)
oled.show()
```

### 1-3. 임계값 기반 환경 이상 감지
- **조합**: AHT20 + LED + 부저 + OLED
- **기능**: 온도/습도가 설정 범위를 벗어나면 자동 경고
- **시나리오**:
  - 정상: 파란 LED + OLED 정상 표시
  - 주의: 노란 LED + OLED 주의 표시
  - 위험: 빨간 LED + 부저 알람 + OLED 경고 표시

## 2. 신호등 / LED 제어 기능

### 2-1. 공장 신호등 시스템
- **부품**: RED/YELLOW/BLUE LED (GPIO17, GPIO27, GPIO22)
- **기능**: 공장 라인 상태를 신호등으로 표시
- **활용**: 정상(파랑) → 주의(노랑) → 위험/정지(빨강)

```python
import RPi.GPIO as GPIO

GPIO.setmode(GPIO.BCM)
for pin in [17, 27, 22]:
    GPIO.setup(pin, GPIO.OUT)

# 신호등 제어
GPIO.output(17, True)   # RED ON
GPIO.output(27, False)  # YELLOW OFF
GPIO.output(22, False)  # BLUE OFF
```

### 2-2. WS2812 다색 상태 표시
- **부품**: WS2812 NeoPixel x4 (GPIO12)
- **기능**: 4개 LED를 개별 RGB 색상으로 제어하여 다채널 상태 표시
- **활용**:
  - 각 LED를 개별 설비/센서 상태로 매핑
  - 색상 그라데이션으로 온도 수치 시각화
  - 경고 시 빨간색 깜빡임 애니메이션

```python
import board
import neopixel

pixels = neopixel.NeoPixel(board.D12, 4, brightness=0.3)
pixels[0] = (0, 255, 0)    # 1번 설비: 정상 (녹색)
pixels[1] = (255, 255, 0)  # 2번 설비: 주의 (노랑)
pixels[2] = (255, 0, 0)    # 3번 설비: 위험 (빨강)
pixels[3] = (0, 0, 255)    # 4번 설비: 대기 (파랑)
```

### 2-3. LED 패턴 제어
- **기능**: 순차 점등, 깜빡임, 페이드 인/아웃 등 다양한 패턴
- **활용**: 시스템 부팅 시퀀스, 작업 진행률 표시, 알람 패턴

## 3. 경고 / 알림 기능

### 3-1. 알람 부저
- **부품**: BUZ1 (GPIO5)
- **기능**: ON/OFF 방식의 단순 경고음
- **활용**: 임계값 초과 시 즉시 알람

```python
GPIO.setup(5, GPIO.OUT)
GPIO.output(5, True)   # 알람 ON
time.sleep(1)
GPIO.output(5, False)  # 알람 OFF
```

### 3-2. 스피커 멜로디/톤 출력
- **부품**: BUZZER1 (GPIO13, BCX56 트랜지스터 경유)
- **기능**: PWM으로 주파수를 변경하여 다양한 톤/멜로디 출력
- **활용**: 상태별 다른 경고음, 시작/종료 알림 음악

```python
buzzer = GPIO.PWM(13, 2700)  # 2.7kHz
buzzer.start(50)              # 듀티비 50%
time.sleep(0.5)
buzzer.ChangeFrequency(1000)  # 1kHz로 변경
time.sleep(0.5)
buzzer.stop()
```

### 3-3. 복합 알림 시스템
- **조합**: 부저 + 스피커 + LED + OLED
- **기능**: 위험도에 따라 단계별 알림
  - Level 1 (주의): 노란 LED + OLED 메시지
  - Level 2 (경고): 빨간 LED + 부저 단속음
  - Level 3 (위험): 빨간 LED 깜빡임 + 스피커 사이렌 + OLED 경고

## 4. 사용자 입력 기능

### 4-1. 스위치 입력 감지
- **부품**: SW1 택트 스위치 (GPIO4)
- **기능**: 버튼 누름 감지 (풀업/풀다운)
- **활용**:
  - 알람 해제 (부저/LED 끄기)
  - 수동 데이터 기록 트리거
  - OLED 화면 전환 (온도↔습도↔상태)
  - 시스템 모드 전환

```python
GPIO.setup(4, GPIO.IN, pull_up_down=GPIO.PUD_UP)

def button_callback(channel):
    print("스위치 눌림!")

GPIO.add_event_detect(4, GPIO.FALLING, callback=button_callback, bouncetime=300)
```

### 4-2. 장단 누름 구분
- **기능**: 짧게 누르기(화면 전환) vs 길게 누르기(모드 변경) 구분
- **활용**: 다기능 단일 버튼 인터페이스

## 5. LoRa 무선 통신 기능

### 5-1. 원격 센서 데이터 전송
- **부품**: E22-900T30D LoRa 모듈 (UART, 915MHz)
- **기능**: 센서 데이터를 최대 10km 거리까지 무선 전송
- **활용**: 원격 공장 모니터링, 다중 센서 노드 구축

```python
import serial

ser = serial.Serial('/dev/ttyS0', 9600, timeout=1)

# 데이터 전송
data = f"T:{sensor.temperature:.1f},H:{sensor.relative_humidity:.1f}\n"
ser.write(data.encode())

# 데이터 수신
received = ser.readline().decode().strip()
```

### 5-2. LoRa 모드 제어
- **부품**: M0(GPIO21), M1(GPIO20), AUX(GPIO7)
- **기능**: 소프트웨어로 LoRa 동작 모드 전환

```python
GPIO.setup(21, GPIO.OUT)  # M0
GPIO.setup(20, GPIO.OUT)  # M1
GPIO.setup(7, GPIO.IN)    # AUX

def set_lora_mode(mode):
    """LoRa 동작 모드 설정"""
    modes = {
        'transmit':  (0, 0),  # 투명 전송
        'wor':       (0, 1),  # 공중 웨이크업 (저전력)
        'config':    (1, 0),  # 설정 모드
        'sleep':     (1, 1),  # 딥슬립
    }
    m1, m0 = modes[mode]
    GPIO.output(20, m1)
    GPIO.output(21, m0)
    while GPIO.input(7) == 0:  # AUX가 HIGH될 때까지 대기
        time.sleep(0.01)
```

### 5-3. 다중 노드 LoRa 네트워크
- **기능**: 여러 UTTEC 보드를 LoRa로 연결하여 메시 네트워크 구성
- **활용**:
  - 공장 내 다수 측정 지점에 센서 노드 배치
  - 중앙 게이트웨이에서 통합 모니터링
  - 릴레이 모드로 전송 거리 확장

### 5-4. LoRa 원격 제어
- **기능**: 원격에서 명령을 보내 LED/부저/설비 제어
- **활용**: 관리자 PC에서 LoRa로 공장 설비 원격 ON/OFF

## 7. AI / 지능형 기능

### 7-1. 이상 감지 (Anomaly Detection)
- **조합**: AHT20 데이터 + 통계/ML 모델
- **기능**: 온습도 패턴의 이상을 자동 감지
- **방법**:
  - Z-Score 기반 통계적 이상 감지
  - 이동 평균/표준편차 기반 동적 임계값
  - scikit-learn Isolation Forest

```python
import numpy as np

# 간단한 Z-Score 이상 감지
def detect_anomaly(data, threshold=2.0):
    mean = np.mean(data)
    std = np.std(data)
    z_score = abs(data[-1] - mean) / std
    return z_score > threshold
```

### 7-2. AI 보고서 자동 생성
- **조합**: 센서 데이터 + Claude API
- **기능**: 이상 감지 시 AI가 원인 분석 보고서 자동 작성
- **활용**: "13시 온도 급등 원인: 냉각 팬 정지 추정" 등 자동 보고

### 7-3. 예지 정비 (Predictive Maintenance)
- **기능**: 센서 데이터 추세를 분석하여 설비 고장 예측
- **활용**: "온도 상승 추세 감지 → 48시간 내 냉각 점검 필요" 알림

## 통합 시나리오 예시

### 시나리오: 스마트 공장 환경 모니터링 시스템

```
[센서 수집] AHT20 → 온도/습도 측정 (1초 주기)
     ↓
[데이터 표시] OLED → 실시간 수치 표시
     ↓
[상태 판단] Python → 임계값 비교
     ├── 정상: 파란 LED + WS2812 녹색
     ├── 주의: 노란 LED + WS2812 노랑 + OLED 주의 메시지
     └── 위험: 빨간 LED + WS2812 빨강 + 부저 + 스피커 사이렌
     ↓
[원격 전송] LoRa → 원격 모니터링 서버로 데이터 전송
     ↓
[웹 대시보드] Flask → 브라우저에서 실시간 차트 확인
     ↓
[AI 분석] Claude API → 이상 감지 시 원인 분석 보고서 자동 생성
```
