# AI 공장자동화 교육 커리큘럼 - 동영상 시나리오

## 영상 개요

| 항목 | 내용 |
|------|------|
| **영상 제목** | AI 공장자동화 프로그래밍 - 8일 완성 교육 과정 소개 |
| **목적** | 교육 담당자/수강 희망자에게 교육 전체 과정을 시각적으로 소개 |
| **총 길이** | 약 5분 30초 |
| **톤** | 전문적이면서도 친근, "초보자도 할 수 있다"는 자신감 전달 |
| **배경 음악** | 테크놀로지 느낌의 경쾌한 BGM (볼륨 낮게) |

## 씬 구성

### 씬 1: 오프닝 — 왜 AI 공장자동화인가? (0:00~0:40)

| 항목 | 내용 |
|------|------|
| 길이 | 40초 |
| 화면 | 공장 생산라인 영상 → 수작업 검사 장면 → 고장난 설비 → 화면 전환 |
| 텍스트 오버레이 | "설비 고장, 수기 기록, 수천만 원의 시스템 도입 비용" |
| 전환 | 어두운 화면에서 밝은 화면으로 전환 |
| 핵심 메시지 | 문제 제기 → 해결책 암시 |

**화면 흐름**:
```
[0:00~0:10] 공장 라인 전경 (B-roll)
  → 자막: "중소기업 제조 현장의 현실"

[0:10~0:20] 작업자 수기 기록 장면, 엑셀 화면
  → 자막: "육안 검사, 수기 기록, 인적 오류"

[0:20~0:30] 설비 고장, 정지된 라인
  → 자막: "사후 수리, 긴 다운타임, 막대한 손실"

[0:30~0:40] 화면 전환 (밝아지며)
  → 자막: "12만 원의 보드와 8일의 시간으로 바꿀 수 있습니다"
```

### 씬 2: 교육 소개 — 무엇을 배우는가 (0:40~1:20)

| 항목 | 내용 |
|------|------|
| 길이 | 40초 |
| 화면 | RPi 3B+ + UTTEC Shield 보드 클로즈업 → 8일 로드맵 인포그래픽 |
| 텍스트 오버레이 | 교육명, 대상, 일정 |
| 핵심 메시지 | 교육 전체 구조를 한눈에 보여줌 |

**화면 흐름**:
```
[0:40~0:50] UTTEC 보드 + RPi 조립 장면 (핸즈온 느낌)
  → 자막: "Raspberry Pi 3 B+ + UTTEC Shield"
  → 자막: "장착만으로 즉시 실습 환경 완성"

[0:50~1:00] 교육 정보 카드
  → "대상: 중소기업 종업원 (초보자 가능)"
  → "일정: 4시간/일 × 8일 = 총 32시간"
  → "인원: 15~20명"

[1:00~1:20] 8일 로드맵 애니메이션 (순차 등장)
  1일차 환경 구축 → 2일차 센서 → 3일차 제어 →
  4일차 통합 → 5일차 LoRa → 6일차 웹 →
  7일차 AI → 8일차 프로젝트
```

### 씬 3: 1~2일차 — 기반 구축과 센서 (1:20~2:10)

| 항목 | 내용 |
|------|------|
| 길이 | 50초 |
| 화면 | RPi 부팅 화면 → 터미널 코딩 → 센서 데이터 → OLED 표시 |
| 핵심 메시지 | "코딩 경험이 없어도 첫날부터 하드웨어를 제어합니다" |

**화면 흐름**:
```
[1:20~1:35] 1일차: 환경 구축
  → RPi 부팅 화면, 데스크탑
  → 터미널에서 Python 코드 입력하는 손 클로즈업
  → 자막: "1일차: Python 기초 + Raspberry Pi 설정"
  → 코드 화면: print("Hello Factory!")

[1:35~1:50] 2일차: 센서와 표시
  → AHT20 센서 클로즈업 → 온습도 수치가 터미널에 출력
  → OLED 디스플레이에 "온도 26.3°C / 습도 52%" 표시
  → 자막: "2일차: 센서 데이터 수집 + OLED 실시간 표시"

[1:50~2:10] 코드 하이라이트
  → 화면에 실제 Python 코드 3~4줄 표시
  → sensor.temperature, sensor.relative_humidity
  → 자막: "단 4줄의 코드로 온습도를 측정합니다"
```

### 씬 4: 3~4일차 — 제어와 자동화 (2:10~3:00)

| 항목 | 내용 |
|------|------|
| 길이 | 50초 |
| 화면 | LED 점등 → WS2812 색상 변화 → 부저 알람 → 통합 자동제어 |
| 핵심 메시지 | "센서가 감지하면, 시스템이 자동으로 반응합니다" |

**화면 흐름**:
```
[2:10~2:25] 3일차: LED + 부저 + 스위치
  → 신호등 LED 순차 점등 (빨강→노랑→파랑)
  → WS2812 4개 LED가 무지개색으로 변화
  → 스위치 누르면 부저 울림
  → 자막: "3일차: GPIO로 공장 신호등과 경보 시스템 구현"

[2:25~2:40] 4일차: 통합 자동 제어
  → 손으로 센서를 감싸 온도 상승 시뮬레이션
  → LED가 파랑→노랑→빨강으로 자동 변경
  → 부저가 울리고 OLED에 "DANGER" 경고 표시
  → 자막: "4일차: 온도가 오르면 자동으로 경고!"

[2:40~3:00] 상태 다이어그램 애니메이션
  → 정상(파랑) → 주의(노랑) → 위험(빨강) 순환 화살표
  → 자막: "상태 머신 기반 지능형 자동 제어 시스템"
```

### 씬 5: 5~6일차 — 통신과 웹 (3:00~3:50)

| 항목 | 내용 |
|------|------|
| 길이 | 50초 |
| 화면 | LoRa 모듈 → 원격 데이터 수신 → 웹 대시보드 화면 |
| 핵심 메시지 | "10km 밖에서도, 스마트폰에서도 공장을 모니터링합니다" |

**화면 흐름**:
```
[3:00~3:15] 5일차: LoRa 무선 통신
  → LoRa 모듈(E22-900T30D) 클로즈업 + 안테나
  → 두 대의 보드가 떨어진 거리에서 데이터 주고받는 장면
  → 수신 측 터미널에 JSON 데이터 출력
  → 자막: "5일차: LoRa로 10km 원격 데이터 전송"

[3:15~3:30] LoRa 네트워크 인포그래픽
  → 공장 내 여러 센서 노드 → 중앙 게이트웨이 → 서버
  → 자막: "다중 노드 LoRa 네트워크 구축"

[3:30~3:50] 6일차: 웹 대시보드
  → PC 브라우저에 Flask 대시보드 (차트, 게이지, LED 버튼)
  → 스마트폰에서 같은 대시보드 접속
  → 웹 버튼 클릭 → 실제 보드의 LED가 켜짐
  → 자막: "6일차: 스마트폰으로 실시간 모니터링 + 원격 제어"
```
