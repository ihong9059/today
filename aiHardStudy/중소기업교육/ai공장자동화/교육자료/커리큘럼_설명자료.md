## 1. 교육 비전

### 왜 이 교육이 필요한가?

중소기업 제조 현장은 세 가지 치명적 문제를 안고 있습니다.

**문제 1: 사후 수리 (Reactive Maintenance)**
설비가 고장난 후에야 수리합니다. 긴 다운타임과 막대한 생산 손실이 발생합니다.
→ **해결**: 센서로 온도/진동을 실시간 감시하여 고장 전에 이상을 감지합니다.

**문제 2: 수기 관리 (Manual Inspection)**
작업자가 육안으로 품질을 검사하고 엑셀에 수기 기록합니다. 인적 오류가 불가피합니다.
→ **해결**: 자동 데이터 수집 + 웹 대시보드로 실시간 디지털 모니터링합니다.

**문제 3: 비용의 장벽 (Financial Barrier)**
기존 스마트 팩토리 시스템은 수천만 원 규모의 구축 비용이 필요합니다.
→ **해결**: 12만 원의 오픈소스 키트로 동일한 기본 기능을 구현합니다.

### 교육 후 달성 목표

| 목표 | 설명 |
|------|------|
| 센서 데이터 자동 수집 | AHT20으로 온습도를 주기적으로 측정하고 기록 |
| 자동 경고 시스템 | 임계값 초과 시 LED + 부저 + OLED 자동 알림 |
| 원격 무선 모니터링 | LoRa로 10km 거리 센서 데이터 전송 |
| 웹 기반 관제 | 스마트폰/PC에서 실시간 대시보드 확인 + 원격 제어 |
| AI 이상 감지 | 통계/딥러닝 기반 이상 패턴 자동 탐지 |

## 2. 하드웨어 플랫폼

### Raspberry Pi 3 B+ — 차세대 코어 엔진

단순한 장난감이 아닌 완전한 컴퓨터입니다.
Linux OS, Python 프로그래밍, 네트워크 통신, 하드웨어 제어를
단 하나의 보드에서 완벽히 수행합니다.

| 항목 | 기존 엔터프라이즈 서버 | RPi DIY 시스템 |
|------|---------------------|---------------|
| **비용** | 수천만 원의 막대한 예산 | **12만 원**의 혁신적 비용 |
| **도입 기간** | 수개월의 복잡한 절차 | **단 며칠** 내 구현 |
| **유연성** | 폐쇄형 벤더 종속 | 오픈소스 기반 무한 커스터마이징 |

### UTTEC Shield — 올인원 실습 환경

Raspberry Pi에 장착만 하면 복잡한 배선 없이 즉시 실습할 수 있습니다.

| 구성요소 | 부품 | 역할 |
|---------|------|------|
| 온습도 센서 | AHT20 | 공장 내 환경 실시간 감시 (I2C) |
| OLED 디스플레이 | 128x64 | 실시간 데이터 표시 (I2C) |
| 신호등 LED | RED / YELLOW / BLUE | 공장 라인 상태 표시 (GPIO) |
| RGB LED | WS2812 x 4 | 다채널 설비 상태 시각화 |
| 택트 스위치 | SW1 | 사용자 입력 (알람 해제, 모드 전환) |
| 알람 부저 | BUZ1 | 위험 경보 알림 |
| 스피커 | BUZZER1 (PWM) | 다양한 경고음/멜로디 |

### E22-900T30D — LoRa 무선 통신 모듈

| 항목 | 사양 |
|------|------|
| 주파수 | 850~930 MHz (915MHz 사용) |
| 송신 출력 | 30dBm (1W) |
| 통신 거리 | 최대 10km (개활지) |
| 인터페이스 | UART (3.3V TTL) |
| 동작 전압 | 5V (30dBm 출력 시) |
| 동작 모드 | 전송 / WOR(저전력) / 설정 / 딥슬립 |

**LoRa 모듈 핀 연결 (UTTEC Shield → E22-900T30D)**:

| RPi GPIO | UTTEC CN1 | 회로도 라벨 | LoRa 모듈 | 기능 |
|----------|-----------|-----------|-----------|------|
| GPIO14 (TXD) | Pin 8 | "RX"* | Pin 3 (RXD) | RPi → LoRa 데이터 전송 |

| GPIO7 | Pin 26 | AUX | Pin 5 (AUX) | 상태 (LOW=busy) |

> *회로도 라벨은 LoRa 모듈 관점 표기. RPi 관점과 반대이므로 주의!

**CNN 모델 구조**:
```
입력 이미지 (28x28)
    ↓
[Conv2D 32필터 3x3] → 선, 모서리 특징 추출
    ↓
[MaxPooling 2x2]    → 14x14로 축소
    ↓
[Conv2D 64필터 3x3] → 곡선, 원 특징 추출
    ↓
[MaxPooling 2x2]    → 7x7로 축소
    ↓
[Conv2D 64필터 3x3] → 숫자 전체 형태 파악
    ↓
[Flatten]           → 2D → 1D 변환
    ↓
[Dense 128 + ReLU]  → 특징 종합 판단
    ↓
[Dropout 0.5]       → 과적합 방지
    ↓
[Dense 10 + Softmax]→ 0~9 각 숫자일 확률 출력
```

**핵심 용어 (초보자 비유)**:

| 용어 | 설명 | 비유 |
|------|------|------|
| CNN | 이미지 인식 전문 AI 구조 | 눈(시각 처리) |
| Epoch | 전체 데이터 1회 학습 | 교과서 1번 읽기 |
| Batch | 한 번에 학습하는 묶음 | 128문제씩 풀기 |
| Overfitting | 외우기만 하고 응용 못 함 | 벼락치기 학생 |
| Dropout | 일부 뉴런 무작위 비활성화 | 과도한 암기 방지 |
| Softmax | 확률 합계 100%로 출력 | "3일 확률 95%, 8일 확률 3%..." |
