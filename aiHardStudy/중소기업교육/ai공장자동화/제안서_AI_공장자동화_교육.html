04 -- TOOLS

교육 핵심 도구 3가지

💻

Raspberry Pi

하드웨어 제어의 핵심
  • Linux OS가 탑재된 완전한 컴퓨터
  • GPIO로 센서, LED, 모터 직접 제어
  • Python으로 프로그래밍
  • Flask 웹서버로 대시보드 구축
  • 교육 후 현장에서 즉시 활용 가능
🐍

Python

가장 쉽고 강력한 언어
  • 문법이 영어와 유사하여 초보자 친화적
  • AI/데이터 분석 분야 1위 언어
  • 풍부한 하드웨어 제어 라이브러리
  • 코드 20줄로 공장 신호등 완성
  • 산업 현장에서 실제 사용
☁️

Google Colab

무료 AI 학습 환경
  • 브라우저만으로 AI 모델 학습
  • 무료 GPU (CPU 대비 10~50배 빠름)
  • 설치/환경 설정 불필요
  • 교육 자료를 링크 하나로 공유
  • 학습된 모델을 Pi에 적용

→ Pi 원격접속 + "Hello Factory!" 출력
2

GPIO 제어 + 센서

LED 신호등, 스위치 입력, AHT20 온습도 읽기, OLED 표시, 자동 경고

→ 공장 신호등 시스템 완성
3

데이터 관리 + 통신

→ 브라우저 실시간 모니터링

AI 적용

Colab에서 MNIST AI 학습, 통계 이상탐지(Z-score), AI API 보고서 자동 생성

→ AI 이상탐지 + 자동 보고서
5

종합 프로젝트 -- 미니 스마트팩토리

조별 스마트팩토리 구축: 센서 수집 + 신호등 제어 + AI 이상탐지 + 웹 대시보드. 시연 발표 + "우리 공장에 어떻게 적용할까?" 토론
