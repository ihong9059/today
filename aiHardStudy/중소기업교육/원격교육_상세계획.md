## 2. 키트 사전 배포 프로세스

### 2.1 배포 구성품

| 구성품 | 사양 | 상태 |
|--------|------|------|
| Raspberry Pi 4B 4GB | 케이스+방열판 조립 완료 | 조립 완료 |
| 공장자동화 Shield | Pi에 장착 완료 | 장착 완료 |
| Pi Camera v2 | 케이블 연결 완료 | 연결 완료 |
| microSD 32GB | OS + 실습환경 설치 완료 | **부팅만 하면 됨** |
| 전원 어댑터 5V 3A | USB-C | |
| micro HDMI → HDMI 케이블 | 1.5m | |
| USB 키보드 + 마우스 | 소형 | 옵션 (있으면 안 보냄) |
| 퀵스타트 가이드 (A5 4장) | 컬러 인쇄, 라미네이팅 | |
| 교재 (A4 바인딩 200p) | 전체 8주분 | |

> **핵심**: 수강생이 전원만 꽂고 켜면 바로 사용 가능하도록 **완전 조립+설치 상태로 발송**

### 2.2 사전 세팅 가이드 (퀵스타트)

```
┌─────────────────────────────────────────────────────┐
│              퀵스타트 가이드 (4단계)                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│  STEP 1: 전원 연결                                   │
│  ┌──────┐                                           │
│  │ Pi   │← USB-C 전원 꽂기                          │
│  │[===] │← HDMI 케이블로 모니터/TV 연결              │
│  └──────┘                                           │
│  → 빨간불 + 초록불 깜빡이면 성공                      │
│                                                     │
│  STEP 2: Wi-Fi 연결                                  │
│  → 바탕화면 Wi-Fi 아이콘 클릭                         │
│  → 집/사무실 Wi-Fi 선택 → 비밀번호 입력               │
│                                                     │
│  STEP 3: VNC 원격접속 (PC에서 Pi 화면 보기)           │
│  → PC에서 VNC Viewer 설치 (다운로드 링크 QR코드)       │
│  → Pi IP 주소 입력 (Pi 바탕화면에 표시됨)              │
│  → ID: pi / PW: factory2026                         │
│                                                     │
│  STEP 4: 테스트                                      │
│  → 바탕화면의 "테스트" 아이콘 더블클릭                 │
│  → LED 4개 순차 점멸 + OLED에 "READY" 표시 = 성공     │
│                                                     │
│  문제 발생 시: 슬랙 #help 채널에 사진과 함께 질문       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 4. 원격 실습 지원 체계

### 4.1 실시간 지원 (수업 중)

```
[수강생 막힘 발생]
    │
    ├──→ Zoom 채팅에 질문 작성
    │        → 보조강사가 채팅으로 답변 (간단한 경우)
    │
    ├──→ Zoom "손들기" 기능
    │        → 강사가 호명 → 수강생 화면 공유 → 같이 해결
    │
    └──→ 원격 접속 (심각한 경우)
             → 강사가 VNC로 수강생 Pi에 접속하여 직접 확인
             → 수강생 Pi IP: Zoom 채팅에 입력
```

### 4.2 비동시 지원 (수업 외)

| 채널 | 용도 | 응답 시간 |
|------|------|----------|
| 슬랙 #general | 공지사항, 자료 배포 | - |
| 슬랙 #help | 실습 질문, 에러 해결 | 24시간 내 |
| 슬랙 #show | 과제 완료 인증샷 공유 | - |
| 이메일 | 개인 문의, 과제 제출 | 48시간 내 |
| Zoom 오피스아워 | 주 1회 (토 10:00~11:00) 자유 질문 | 실시간 |

### 4.3 하드웨어 문제 대응

| 상황 | 대응 |
|------|------|
| Shield 접촉 불량 | 슬랙에 사진 → 강사 판단 → 재장착 가이드 |
| 센서 고장 | 택배로 교체 부품 발송 (익일 도착) |
| Pi 자체 고장 | 여분 Pi 택배 발송 + 불량 Pi 회수 |
| SD카드 손상 | 이미지 파일 다운로드 링크 제공 → 재설치 가이드 |
| 카메라 인식 불가 | 원격 접속으로 설정 확인 + 케이블 재연결 가이드 (사진) |

> **여분 확보**: 키트 총 수량의 15%를 여분으로 보유 (20명 → 3세트 여분)

## 7. Zoom 수업 운영 팁

### 7.1 화면 구성 (강사)

```
┌─────────────────────────────────────┐
│          강사 Zoom 화면              │
├──────────────────┬──────────────────┤
│                  │                  │
│  Pi 바탕화면     │  실물 카메라      │
│  (VNC로 공유)    │  (Shield 확대)    │
│                  │                  │
│  → 코드 입력,    │  → LED 점등,     │
│    터미널 실행    │    센서 반응을    │
│    을 실시간으로  │    실시간으로     │
│    보여줌        │    보여줌         │
│                  │                  │
├──────────────────┴──────────────────┤
│  하단: Zoom 채팅 (질문/답변)         │
└─────────────────────────────────────┘
```

### 7.2 참여 유도

| 방법 | 구현 |
|------|------|
| 출석 체크 | Zoom 입장 시 채팅에 "출석" 입력 |
| 실시간 퀴즈 | 매 회차 시작 시 Google Forms 퀴즈 (5분) |
| 인증샷 | 실습 완료 후 Pi 화면 캡처 → 슬랙 #show |
| 소그룹 토론 | Breakout Room (4~5인) → 실습 → 복귀 발표 |
| 우수 과제 발표 | 매주 1~2명 과제 시연 (보너스 점수) |

### 7.3 네트워크 문제 대응

| 상황 | 대응 |
|------|------|
| 수강생 Zoom 끊김 | 녹화 영상으로 보충 |
| Pi 인터넷 불안정 | 수업 중 Pi는 인터넷 불필요 (로컬 실습), VNC만 필요 |
| 강사 연결 끊김 | 보조강사가 즉시 대체 진행 |

## 9. 대면 vs 원격 최종 비교

| 항목 | 대면 (A안) | 원격 (B안) | 비고 |
|------|-----------|-----------|------|
| 총 비용 (20명) | 10,255,000 | 10,744,000 | 원격이 약 5% 높음 |
| 인당 비용 | 512,750 | 537,200 | 택배+영상 제작비 |
| 교육 효과 | ★★★★★ | ★★★★ | 대면이 즉각 피드백 유리 |
| 접근성 | ★★★ | ★★★★★ | 원격이 이동 부담 없음 |
| 업무 영향 | 5일 공백 | 최소 (저녁 시간) | 원격이 업무 병행 가능 |
| HW 문제 해결 | ★★★★★ | ★★★ | 대면이 즉시 해결 |
| 자기주도 학습 | ★★★ | ★★★★ | 원격은 복습 영상 제공 |

### 권장 사항

- **소규모(15명 이하) + 일정 확보 가능**: A안 (대면) 권장
- **다수(20명+) + 업무 병행 필요**: B안 (원격) 권장
- **혼합 방식**: Week 1, 4, 8만 대면 (3일), 나머지 원격 → 가장 효과적 (별도 견적)
