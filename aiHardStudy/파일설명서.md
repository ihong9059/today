## 1. cloud/ — 클라우드 서버 코드 + Web App (★ 현재 운영)

> Digital Ocean 서버(178.128.90.37)에 배포된 코드. 실제 교육에 사용되는 운영 서버.

### 2-1. 빌드 서버

| 파일 | 설명 | 상태 |
|------|------|:----:|
| `build_server_cloud_arduino.py` | **현재 운영 중인 메인 빌드 서버.** FastAPI, 포트 8092. Claude AI로 Arduino 코드 생성 → arduino-cli로 빌드 → .bin 생성. 코딩 질문 API(`/api/v1/chat`)도 포함. systemd 서비스명: `uttec-arduino` | ★ 운영 |
| `build_server_arduino.py` | 로컬 Windows PC용 Arduino 빌드 서버. 포트 8092. cloud 버전과 동일 구조이나 로컬 경로 사용. UTTEC Local 앱이 연결하는 서버. | 로컬용 |
| `build_server.py` | ESP-IDF 기반 빌드 서버 (레거시). Arduino 전환 전에 사용. idf.py 호출. | 사용 안 함 |
| `build_server_local.py` | ESP-IDF 로컬 빌드 서버 (레거시). build_server.py의 로컬 버전. | 사용 안 함 |

### 2-2. Web App (PWA)

| 파일 | 설명 |
|------|------|
| `web_ui_server.py` | **Web App을 서빙하는 FastAPI 서버.** 포트 8094. 정적 파일 서빙 + 빌드 서버(8092)로 API 프록시. systemd 서비스명: `uttec-webui` |
| `web/index.html` | **Web App 본체.** 단일 HTML 파일, 약 1200줄. 다크 테마, 5탭(홈/HW/SW/패드/설정). Web Bluetooth API로 BLE OTA 전송. 코딩 질문 AI 포함. |

| `web/icon-192.png` | PWA 아이콘 (192x192). 홈 화면 아이콘용. |
| `web/icon-512.png` | PWA 아이콘 (512x512). 스플래시 화면용. |

## 2. firmware/ — ESP32 펌웨어 소스코드

### 3-1. ble_ota_arduino/ (★ 현재 사용)

> Arduino 프레임워크 기반 BLE OTA 펌웨어. 교육에 사용되는 현재 버전.

| 파일 | 설명 |
|------|------|
| `ble_ota_arduino.ino` | **메인 펌웨어 소스코드 (444줄).** BLE OTA 서비스(NimBLE), LED/부저/OLED/AHT20 센서 제어, CMD 핸들러(FE04), 스위치 모니터(FE05), BLE 이름 영구 저장(NVS). 빌드 서버가 이 파일의 marker 이후에 AI 생성 코드를 병합. |
| `ssd1306.h` | **SSD1306 OLED 디스플레이 드라이버 (140줄).** I2C, 128x64, 주소 0x3C. `ble_ota_arduino.ino`에서 include. |

### 3-2. ble_ota/ (레거시 — ESP-IDF 버전)

> ESP-IDF 프레임워크 기반 BLE OTA 펌웨어. Arduino 전환 전에 사용. 더 복잡하지만 동일 기능.

| 파일 | 설명 |
|------|------|
| `main/main.c` | ESP-IDF 메인 소스. FreeRTOS 태스크 기반. |
| `main/ble_ota.c` | BLE OTA 로직 (NimBLE ESP-IDF 버전). |
| `main/ble_ota.h` | BLE OTA 헤더 파일. UUID, 상수 정의. |
| `main/ssd1306.h` | OLED 드라이버 (ESP-IDF 버전). |
| `main/korean_bitmaps.h` | 한글 비트맵 폰트 데이터. OLED에 한글 표시용. |
| `main/CMakeLists.txt` | ESP-IDF 컴포넌트 빌드 설정. |
| `CMakeLists.txt` | ESP-IDF 프로젝트 루트 빌드 설정. |
| `partitions.csv` | ESP32 파티션 테이블. 듀얼 OTA 파티션 정의. |
| `sdkconfig` / `sdkconfig.defaults` / `sdkconfig.old` | ESP-IDF 빌드 설정. NimBLE 활성화, 파티션 설정 등. |
| `ota_test_client.py` | PC에서 BLE OTA 테스트하는 Python 스크립트. Bleak 라이브러리 사용. |
| `ble_ota_v2.bin` | 빌드된 펌웨어 바이너리 (ESP-IDF 버전). |
| `cloud_firmware.bin` | 클라우드에서 빌드된 펌웨어 바이너리. |

### 3-3. led_blink/ (테스트용)

> LED 점멸 테스트 펌웨어. 하드웨어 검증용.

| 파일 | 설명 |
