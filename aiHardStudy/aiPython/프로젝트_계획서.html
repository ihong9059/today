💡 aiHardStudy (기존)

  • C / Arduino 코드 생성
  • ESP32 보드 필요 (추가 구매)
  • LED, 부저, OLED 물리 제어

  • Arduino 빌드 필요 (~25초)
  • 보드에서 결과 확인 (LED 깜빡임)
  • 총 35~120초 소요
  • USB 케이블 + 충전기 필요

  • 카메라, 센서, GPS 활용

  • Python 실행만 (1~10초)
