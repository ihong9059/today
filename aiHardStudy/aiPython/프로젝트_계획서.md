## 1. 프로젝트 개요

### 1.1 한 줄 정의

> 학생이 스마트폰에서 **한국어로 원하는 동작을 입력**하면, AI가 **Python 코드**를 생성하고,
> 클라우드에서 실행하여 **스마트폰의 카메라·센서 데이터를 처리**한 결과를
> **스마트폰 화면에 즉시 표시**하는 Python 교육 플랫폼.

### 1.2 aiHardStudy와의 비교

| 항목 | aiHardStudy (기존) | aiPython (신규) |
|:-----|:-------------------|:----------------|
| **교육 언어** | C/Arduino | **Python** |
| **하드웨어** | ESP32 외부 보드 (LED, 부저, OLED) | **스마트폰 내장 하드웨어** (카메라, 센서, 마이크) |
| **코드 실행** | ESP32 보드에서 실행 | **클라우드 서버에서 실행** |
| **결과 확인** | 보드에서 물리적으로 확인 (LED 깜빡임) | **스마트폰 화면에 시각적으로 표시** |
| **전송 방식** | BLE OTA (펌웨어 바이너리 전송) | **HTTP (데이터 업로드 + 결과 수신)** |
| **추가 장비** | ESP32 보드 + USB 케이블 필요 | **스마트폰만으로 완결** (추가 장비 불필요) |
| **프롬프트/AI 질문** | 동일 | **동일** |
| **클라우드 서버 역할** | AI 코드 생성 + Arduino 빌드 | **AI 코드 생성 + Python 실행 + 결과 반환** |

### 1.3 핵심 가치

| 가치 | 설명 |
|:-----|:-----|
| **추가 장비 제로** | 스마트폰 1대로 완결. 보드/케이블/전원 불필요 |
| **Python 학습** | 가장 인기 있는 프로그래밍 언어 직접 체험 |
| **내 폰이 실험 도구** | 카메라, GPS, 가속도 센서 등 스마트폰 하드웨어 활용 |
| **즉시 시각적 결과** | 차트, 그래프, 이미지 처리 결과를 화면에 표시 |
| **AI/데이터 과학 입문** | 얼굴 인식, 이미지 분석, 데이터 시각화 체험 |

```
│  │ 카메라 캡처      │ │                         │  │ Web UI   │            │
│  │ 센서 데이터 수집  │ │                         │  │ (8094)   │            │
```

### 2.2 동작 흐름 (6단계)

```
Step 1           Step 2           Step 3           Step 4           Step 5           Step 6
프롬프트 입력 ──▶ 센서 데이터 ──▶ AI 코드 생성 ──▶ Python 실행 ──▶ 결과 반환 ──▶ 화면 표시
(한국어)         수집/업로드      (Claude)         (서버에서)       (이미지/JSON)    (스마트폰)

사용자 0초      자동 ~2초        12~30초          1~10초          ~1초            즉시
```

**총 예상 소요: 15~45초** (aiHardStudy 대비 빠름 — Arduino 빌드 24초 제거)

## 3. 스마트폰 하드웨어 활용

### 3.1 활용 가능한 센서/하드웨어

| 센서 | Web API | 교육 활용 | 난이도 |
|:-----|:--------|:---------|:------:|
| **카메라** | MediaDevices.getUserMedia() | 사진 촬영 → 이미지 처리, 얼굴 인식, 색상 분석 | 초급~중급 |
| **가속도계** | DeviceMotionEvent | 흔들기 감지, 기울기 측정, 만보기 | 초급 |
| **자이로스코프** | DeviceOrientationEvent | 3D 회전 추적, 나침반 | 중급 |
| **GPS 위치** | Geolocation API | 현재 위치 표시, 거리 계산 | 초급 |
| **마이크** | MediaRecorder API | 음성 녹음, 주파수 분석, 음량 측정 | 중급 |
| **화면 터치** | Touch Events | 그림 그리기, 터치 좌표 수집 | 초급 |
| **밝기 센서** | AmbientLightSensor | 조도 측정, 자동 밝기 | 초급 |
| **진동** | Vibration API | 패턴 진동 (출력 장치로 활용) | 초급 |

## 4. 소프트웨어 아키텍처

### 4.1 Web App (PWA) — 5탭 구조

| 탭 | 기능 | aiHardStudy 대비 변경 |
|:---|:-----|:---------------------|
| **홈** | 프롬프트 입력 → Python 코드 생성 → 실행 → 결과 표시 + 코딩 질문 AI | 구조 동일, 결과 표시 영역 확장 (이미지/차트/텍스트) |
| **센서** | 스마트폰 센서 실시간 모니터 + 데이터 수집 | **신규** (패드 탭 대체) |
| **HW** | 스마트폰 하드웨어 학습 (카메라 원리, 가속도 센서 원리 등) | 내용 교체 (ESP32 → 스마트폰) |
| **SW** | Python 레슨 (변수, 조건문, 반복문, 함수, 라이브러리) | 내용 교체 (C → Python) |
| **설정** | 서버 URL, 센서 권한 관리, 앱 정보 | 간소화 (BLE 설정 삭제) |

### 4.2 홈 탭 상세

#### 프롬프트 → 결과 흐름

```
1. 프롬프트 입력 (한국어)
   └── 예시 칩: "사진 흑백 변환", "만보기", "주사위 게임" 등

2. 센서 데이터 자동 수집 (프롬프트 분석 후)
   ├── 카메라 프롬프트 → 카메라 캡처 UI 표시
   ├── 센서 프롬프트 → 가속도/자이로 데이터 수집 시작
   ├── GPS 프롬프트 → 위치 정보 요청
   └── 순수 계산 프롬프트 → 센서 불필요, 즉시 실행

3. 서버 전송
   └── {prompt, sensor_type, sensor_data (base64/json)}

4. 서버 처리
   ├── Claude AI → Python 코드 생성
   ├── 샌드박스에서 Python 실행
   ├── 결과물 생성 (이미지, JSON, HTML)
   └── 반환: {code, result_type, result_data, explanation}

5. 결과 표시
   ├── 이미지 결과 → <img> 또는 <canvas>로 표시
   ├── 차트 결과 → matplotlib PNG 또는 Chart.js로 표시
   ├── 텍스트 결과 → 포맷팅된 텍스트 표시
   ├── HTML 결과 → iframe으로 표시 (지도 등)
   └── 코드 + 한국어 설명 → 구문 강조 + 설명 카드
```

#### 결과 표시 영역 (aiHardStudy 대비 확장)

| 결과 타입 | 표시 방식 | 예시 |
|:---------|:---------|:-----|
| **image** | `<img>` 태그 (base64 PNG/JPEG) | 흑백 변환된 사진, 얼굴 인식 결과 |
| **chart** | matplotlib → PNG 또는 Chart.js | 막대그래프, 파이차트, 선그래프 |
| **text** | 포맷팅된 텍스트 박스 | 계산 결과, 데이터 분석 요약 |
| **html** | `<iframe>` sandbox | 인터랙티브 지도 (folium), 테이블 |
| **animation** | 연속 프레임 또는 Canvas | 공 굴리기 게임, 시뮬레이션 |
| **code** | 구문 강조 + 한국어 설명 | 생성된 Python 코드 + 줄별 설명 |

### 4.5 Python 실행 환경 (샌드박스)

| 항목 | 방식 |

| **금지 항목** | os.system, subprocess, socket, __import__ 동적 import |

```
[샌드박스 실행 과정]

1. Docker 컨테이너 생성 (사전 빌드된 이미지)
2. 센서 데이터를 /tmp/input/ 에 저장
3. 생성된 Python 코드를 /tmp/run.py 에 저장
4. `python /tmp/run.py` 실행 (타임아웃 30초)
5. /tmp/output/ 에서 결과물 수집 (PNG, JSON, HTML)
6. 결과물을 base64로 인코딩하여 응답
7. 컨테이너 삭제
```

## 8. 보안 고려사항

### 8.1 Python 코드 실행 보안 (핵심)

학생이 작성하지 않은 AI 생성 코드를 서버에서 실행하므로, 보안이 aiHardStudy보다 중요합니다.

| 위협 | 대책 | 우선순위 |
|:-----|:-----|:--------:|
| 악의적 코드 실행 (rm -rf) | Docker 컨테이너 격리 + 읽기 전용 파일시스템 | 필수 |
| 무한 루프 | 실행 타임아웃 30초 | 필수 |
| 메모리 폭탄 | Docker 메모리 제한 256MB | 필수 |
| 네트워크 악용 | Docker 네트워크 차단 | 필수 |
| 시스템 프롬프트 우회 | import 화이트리스트 + AST 검증 | 필수 |
| 대용량 업로드 | 이미지 크기 제한 (5MB) | 높음 |
| 서버 리소스 고갈 | 동시 실행 수 제한 + 큐 | 높음 |

### 8.2 시스템 프롬프트 보안 규칙

```
1. 허용 import: numpy, matplotlib, PIL, cv2, pandas, scipy, json, math, random
2. 금지 import: os, sys, subprocess, socket, http, urllib, shutil, ctypes
3. 금지 함수: exec(), eval(), compile(), __import__(), open() (쓰기 모드)
4. 입력 데이터: /tmp/input/ 경로에서만 읽기
5. 출력 데이터: /tmp/output/ 경로에만 쓰기
6. 결과물 형식: PNG 이미지, JSON 데이터, HTML 파일만 허용
```
