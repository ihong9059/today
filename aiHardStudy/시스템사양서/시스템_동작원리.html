BLE 특성 (Characteristics)

UUID이름방향설명
FE01 OTA Control 📱→💡 0x01(START), 0x02(END), 0x03(ABORT) — OTA 흐름 제어
FE02 OTA Data 📱→💡 펌웨어 바이너리 청크 전송 (MTU=256 bytes)
FE03 OTA Status 💡→📱 [상태코드, 진행률%] Notify — 실시간 진행 표시
FE04 CMD 📱→💡 패드 실시간 제어 (LED_RED_ON, BEEP, NOTE_0, OLED:text, TEMP ...)
FE05 Sensor 💡→📱 스위치 상태 Notify (PRESSED / RELEASED)

📊 OTA 성능

  • MTU: 256 bytes
  • 펌웨어 크기: ~650KB
  • 전송 시간: ~14초
  • 전송 속도: ~46KB/s
  • ESP32 재부팅: ~3초

🎮 CMD 명령어 (FE04)

  • LED_RED_ON/OFF — 빨간 LED 제어
  • LED_YELLOW_ON/OFF — 노란 LED 제어
  • LED_BLUE_ON/OFF — 파란 LED 제어
  • BEEP — 비프음 100ms
  • NOTE_0~7 — 도레미파솔라시도
  • OLED:{text} — OLED 텍스트 표시
  • TEMP — 온습도 읽기
  • SETNAME:{name} — BLE 이름 변경

📱 8. Flutter 앱 vs Web App 비교
두 클라이언트의 핵심 차이점

📱 Flutter 앱 (APK)

  • BLE 자동 연결 — MAC 주소 저장, 앱 열면 자동 재연결
  • 코드 자동 설명 — 키워드 분석 → 한국어 설명
  • 히스토리 저장 — 최근 10개 프롬프트
  • 빌드 후 자동 OTA — 원클릭 완료
  • APK 설치 필요 (Android만)
  • 2회차 수업: 10초 시작
  • 오프라인 앱 자체 동작

🌐 Web App (PWA)

  • 설치 불필요 — Chrome URL 접속 즉시
  • 코딩 질문 AI — 전용 질문 카드
  • 빌드 타이밍 표시 — 단계별 소요 시간
  • BLE 매번 Chrome 팝업 선택
  • HTTPS 필수 (Web Bluetooth)
  • 업데이트 즉시 반영 (서버 파일 교체)
  • PC Chrome에서도 접속 가능 (BLE 제외)
