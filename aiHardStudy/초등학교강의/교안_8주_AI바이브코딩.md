# 초등학교 AI 바이브코딩 교안 (8주)

## 과정 개요

| 항목 | 내용 |
|------|------|
| **대상** | 초등학교 4, 5, 6학년 |
| **기간** | 8주 (주 1회, 40분) |
| **교구** | UTTEC 보드 + 사전빌드 앱 (학생 스마트폰) |
| **방식** | 사전빌드 시스템 — 앱에서 선택 → BLE 전송 → 즉시 실행 |
| **목표** | AI 시대의 하드웨어를 직접 체험하고, "생각 → 결과"의 흐름을 경험 |

## 수업 구조 (매회 40분)

| 시간 | 활동 | 내용 |
|:---:|------|------|
| 0~5분 | 복습 + 오늘 소개 | 지난주 핵심 한 줄 복습 + 오늘 할 것 미리보기 |
| 5~25분 | 실습 (3개) | 사전빌드 앱으로 선택 → 전송 → 결과 확인 |
| 25~35분 | "왜 그럴까?" | 방금 한 것의 원리를 쉽게 설명 + 질문 시간 |
| 35~40분 | 정리 + 예고 | 오늘 배운 것 한 줄 + 다음 주 기대감 |

## 1주차: 빛의 세계 — "내가 선택하면 LED가 켜진다!"

### 학습 목표
- 사전빌드 앱 사용법 익히기
- "선택 → 전송 → 결과"의 흐름 체험
- LED(발광다이오드)가 무엇인지 이해

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 소개 | "오늘부터 여러분이 하드웨어를 조종합니다!" 앱 설치 확인, UTTEC 보드 나눠주기 |
| 5~10분 | **실습 1: A01 — 빨간 LED 켜기** | 앱에서 "빨간 LED 켜기" 선택 → 전송 → 보드에서 빨간 불이 켜짐! 첫 성공의 감동 |
| 10~15분 | **실습 2: A03 — 노란 LED 켜기** | 같은 방법으로 노란 LED 켜기. "빨간 불은 어떻게 됐지?" → 꺼짐 확인 |
| 15~25분 | **실습 3: A07 — 빨간 LED 1초마다 깜빡이기** | 깜빡이는 LED 보기. "왜 깜빡일까?" → 켜기-끄기를 반복하니까! |
| 25~35분 | 원리 설명 | LED란? → 전기가 흐르면 빛나는 작은 전구. 색마다 다른 LED가 있다. 컴퓨터가 "켜!" "꺼!" 명령을 반복하면 깜빡임 |
| 35~40분 | 정리 | "오늘 LED 3개를 제어했습니다. 다음 주에는 여러 개를 동시에 켜봅시다!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| A01 | 빨간 LED 켜기 | ★ |
| A03 | 노란 LED 켜기 | ★ |
| A07 | 빨간 LED 1초마다 깜빡이기 | ★ |

### 핵심 질문 (아이들에게)
- "LED가 왜 켜질까?" → 전기가 흐르니까!
- "깜빡이는 건 어떻게 하는 걸까?" → 켜고 끄기를 빠르게 반복!

## 2주차: 여러 개의 빛 — "신호등을 만들자!"

### 학습 목표
- 여러 LED를 동시에/순서대로 제어하는 개념
- 순서(시퀀스)의 개념 이해
- 신호등의 원리 체험

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "지난주에 LED 1개를 켰죠? 오늘은 3개를 동시에 다룹니다!" |
| 5~10분 | **실습 1: B01 — 빨강, 노랑, 파랑 LED 모두 켜기** | 3개 동시에 켜짐! "우와 밝다!" |
| 10~17분 | **실습 2: B03 — 빨강→노랑→파랑 순서대로 1초씩 켜기** | 순서대로 바뀌는 것 관찰. "이거 뭔가 닮지 않았나요?" |
| 17~25분 | **실습 3: H01 — 신호등 만들기 (빨강3초, 노랑1초, 파랑3초)** | 진짜 신호등! 시간이 다른 이유 토론 |
| 25~35분 | 원리 설명 | 컴퓨터는 "순서"를 기억한다. 1번 켜고 → 기다리고 → 2번 켜고... 이것이 "프로그램". 신호등도 컴퓨터가 순서를 기억해서 동작하는 것 |
| 35~40분 | 정리 | "순서대로 실행하는 것이 프로그램의 시작! 다음 주에는 소리를 만들어봅시다" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| B01 | 빨강, 노랑, 파랑 LED 모두 켜기 | ★ |
| B03 | 빨강→노랑→파랑 순서대로 1초씩 | ★ |
| H01 | 신호등: 빨강3초, 노랑1초, 파랑3초 반복 | ★★ |

### 핵심 질문
- "신호등은 누가 바꿔주는 걸까?" → 컴퓨터가 순서대로!
- "노란불은 왜 짧을까?" → 준비하라는 뜻이니까 짧게!

## 3주차: 소리의 세계 — "부저로 음악을 만들자!"

### 학습 목표
- 부저(스피커)로 소리를 만드는 원리 이해
- 음의 높낮이 = 주파수 개념 체험
- 익숙한 멜로디를 하드웨어로 연주

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "지난주 신호등 기억나죠? 오늘은 눈이 아니라 귀로 느껴봅시다!" |
| 5~10분 | **실습 1: C01 — 부저 한번 울리기** | 삐! 소리 확인. "이 소리가 어디서 나는 거지?" 부저 위치 찾기 |
| 10~17분 | **실습 2: D01 — 도레미파솔라시도 연주** | 음계가 올라가는 것 듣기. "음이 높아지는 게 느껴지나요?" |
| 17~25분 | **실습 3: I02 — 반짝반짝 작은별 연주** | 아이들이 아는 노래! 따라 부르기. "우리 보드가 피아노가 됐어요!" |
| 25~35분 | 원리 설명 | 소리 = 떨림(진동). 빨리 떨면 높은 소리, 느리게 떨면 낮은 소리. 컴퓨터가 "도=262번, 레=294번, 미=330번 떨어!" 하고 명령함 |
| 35~40분 | 정리 | "소리도 숫자로 만들 수 있다! 다음 주에는 눈+귀 동시에!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| C01 | 부저 한번 울리기 | ★ |
| D01 | 도레미파솔라시도 연주 | ★ |
| I02 | 반짝반짝 작은별 연주 | ★★ |

### 핵심 질문
- "높은 도와 낮은 도는 뭐가 다를까?" → 떨리는 횟수(주파수)!
- "피아노 건반을 오른쪽으로 가면?" → 소리가 높아진다!

## 4주차: 빛 + 소리 = 합체! — "LED 쇼 + 멜로디"

### 학습 목표
- 두 가지 출력(빛 + 소리)을 동시에 제어
- "조합"의 개념 — 단순한 것을 합치면 복잡한 것이 된다
- 화면(OLED 디스플레이) 출력 체험

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "LED도 했고, 소리도 했고... 오늘은 둘 다 동시에!" |
| 5~12분 | **실습 1: J03 — LED 순서대로 켜면서 도레미 연주** | 빨강=도, 노랑=레, 파랑=미! 빛과 소리의 조합 |
| 12~18분 | **실습 2: E01 — OLED에 "Hello" 표시하기** | 작은 화면에 글자가 나타남! "이것도 컴퓨터가 하는 거예요" |
| 18~25분 | **실습 3: M01 — OLED에 "빨강!" 표시하고 빨간 LED 켜기** | 화면 + LED 동시 제어. 정보를 "보여주는" 것 |
| 25~35분 | 원리 설명 | 컴퓨터는 여러 가지를 동시에 할 수 있다. LED 켜기 + 소리 내기 + 화면 표시를 한꺼번에! 이것이 "멀티태스킹" |
| 35~40분 | 정리 | "단순한 것들을 합치면 멋진 것이 된다! 다음 주에는 센서로 주변을 느껴봅시다" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| J03 | LED 순서대로 켜면서 도레미 연주 | ★★ |
| E01 | OLED에 "Hello" 표시하기 | ★ |
| M01 | OLED에 "빨강!" 표시 + 빨간 LED 켜기 | ★★ |

### 핵심 질문
- "컴퓨터는 한번에 하나만 할 수 있을까?" → 아니! 동시에 여러 개!
- "화면에 글자가 뜨는 것도 프로그램이야?" → 네!

## 5주차: 감각의 세계 — "보드가 온도를 느낀다!"

### 학습 목표
- 센서(sensor)의 개념 — 기계가 환경을 "느끼는" 방법
- 온도/습도 측정 체험
- 입력(센서) → 출력(화면/LED)의 흐름 이해

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "지금까지는 우리가 선택했죠? 오늘부터는 보드가 스스로 느낍니다!" |
| 5~12분 | **실습 1: F03 — 온도를 OLED에 표시하기** | 현재 교실 온도가 화면에! "진짜 온도가 맞는지 확인해볼까?" |
| 12~18분 | **실습 2: F05 — 온도+습도 OLED 표시 + 30도 넘으면 LED 경고** | 손으로 센서 감싸기 → 온도 올라감 → LED 켜짐! |
| 18~25분 | **실습 3: K02 — 온도에 따라 LED 색 바꾸기** | 낮으면 파랑, 보통 노랑, 높으면 빨강. "우리가 안 해도 보드가 알아서!" |
| 25~35분 | 원리 설명 | 센서 = 기계의 감각기관. 우리 피부가 온도를 느끼듯, 센서도 온도를 숫자로 느낀다. 컴퓨터는 그 숫자를 보고 판단한다: "25도보다 높으면 빨간 LED 켜!" |
| 35~40분 | 정리 | "기계도 느끼고 판단할 수 있다! 다음 주에는 버튼으로 직접 조종해봅시다" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| F03 | 온도를 OLED에 표시하기 | ★ |
| F05 | 온도+습도 OLED + 30도 넘으면 LED 경고 | ★ |
| K02 | 온도에 따라 LED 색 바꾸기 | ★★ |

### 핵심 질문
- "기계가 뜨거운 걸 어떻게 알까?" → 센서!
- "에어컨은 어떻게 알아서 꺼질까?" → 센서가 온도를 느끼고, 컴퓨터가 판단!

## 6주차: 스위치 + 자동화 — "만약 ~하면 ~해라!"

### 학습 목표
- 스위치(버튼) 입력 처리
- 조건문(if-then) 개념의 직관적 체험
- 자동화 = "조건 → 동작" 패턴 이해

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "센서는 자동으로 느꼈죠? 오늘은 여러분이 직접 버튼으로!" |
| 5~12분 | **실습 1: G01 — 스위치 누르면 빨간 LED 켜기** | 버튼 누르면 켜짐! "내가 누르니까 반응한다!" |
| 12~18분 | **실습 2: L01 — 스위치 누를 때마다 LED 토글** | 한번 누르면 ON, 또 누르면 OFF. 방 전등 스위치와 같은 원리 |
| 18~25분 | **실습 3: K03 — 온도 28도 넘으면 부저 울리기** | 자동 경보! 손으로 센서 잡아서 온도 올리기 → 삐! "자동으로 알려준다!" |
| 25~35분 | 원리 설명 | 프로그램의 핵심 = "만약(if) ~하면, ~해라". 예: "만약 버튼 눌리면 → LED 켜라", "만약 28도 넘으면 → 부저 울려라". 이것이 프로그래밍의 가장 중요한 생각! |
| 35~40분 | 정리 | "조건 → 동작, 이것이 모든 프로그램의 핵심! 다음 주에는 진짜 프로젝트를!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| G01 | 스위치 누르면 빨간 LED 켜기 | ★ |
| L01 | 스위치 누를 때마다 LED 토글 | ★★ |
| K03 | 온도 28도 넘으면 부저 울리기 | ★★ |

### 핵심 질문
- "자동문은 어떻게 열릴까?" → "사람 오면(if) → 문 열어(then)!"
- "화재 경보기는?" → "연기 감지하면(if) → 알람 울려(then)!"

## 7주차: 종합 프로젝트 — "스마트 교실을 만들자!"

### 학습 목표
- 지금까지 배운 모든 요소를 종합
- "설계 → 실행 → 확인"의 프로젝트 경험
- 실생활 문제를 기술로 해결하는 사고

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "6주 동안 LED, 소리, 센서, 스위치를 배웠습니다. 오늘은 전부 합쳐서 쓸모있는 것을 만듭니다!" |
| 5~12분 | **실습 1: Q01 — 라면 타이머** | 3분 카운트다운 OLED + 끝나면 멜로디 + LED. "실제로 쓸 수 있는 것을 만들었어요!" |
| 12~18분 | **실습 2: Q03 — 반응속도 테스트 게임** | 랜덤 시간 후 LED 켜짐 → 버튼 빨리 누르기 → 반응시간 OLED 표시. "누가 제일 빠를까?" |
| 18~25분 | **실습 3: N01 — 신호등 + 보행 알림** | 파란불일 때 "WALK" OLED 표시 + 보행 알림음. "진짜 신호등처럼!" |
| 25~35분 | 토론 | "우리 교실에 어떤 스마트 기기가 있으면 좋겠어?" 아이디어 발표. "너무 더우면 알려주는 기기", "쉬는시간 알려주는 타이머" 등 |
| 35~40분 | 정리 | "여러분이 생각한 아이디어, 다음 주에 직접 골라서 만들어봅시다!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| Q01 | 라면 타이머 (3분 카운트다운 + 멜로디 + LED) | ★★★ |
| Q03 | 반응속도 테스트 게임 | ★★★ |
| N01 | 신호등 + 보행 알림 OLED + 알림음 | ★★★ |

### 핵심 질문
- "지금까지 배운 것만으로 뭘 만들 수 있을까?" → 타이머, 게임, 경보기...
- "우리 일상에서 이런 것들이 어디에 쓰이고 있을까?" → 신호등, 에어컨, 화재경보기, 엘리베이터...
