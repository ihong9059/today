사전빌드 교육 시스템 — 초등학생 맞춤 체험 교육

학생이 스마트폰 앱에서 원하는 동작을 선택하면, AI가 자동으로 코드를 생성하고, BLE 무선 전송으로 ESP32 보드에 즉시 업로드됩니다. 학생은 코딩을 몰라도 눈앞에서 LED가 켜지고, 센서가 반응하는 것을 직접 체험합니다.

학생이 선택 → AI가 코드 생성 → BLE 무선 전송 → ESP32 보드에서 실행!
초등학생 적합 이유

  • 즉각적 피드백 — 선택 후 3초 내 결과 확인
  • 안전한 저전압 하드웨어 (3.3V/5V USB 전원)
  • 스마트폰 앱으로 친숙한 인터페이스
  • 단계별 난이도 — LED 켜기부터 AI 음성인식까지
