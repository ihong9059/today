# 초등학교 AI 바이브코딩 교안 (4주)

## 과정 개요

| 항목 | 내용 |
|------|------|
| **대상** | 초등학교 4, 5, 6학년 |
| **기간** | 4주 (주 1회, 40분) |
| **교구** | UTTEC 보드 + 사전빌드 앱 (학생 스마트폰) |
| **방식** | 사전빌드 시스템 — 앱에서 선택 → BLE 전송 → 즉시 실행 |
| **목표** | AI 시대의 하드웨어를 직접 체험하고, "생각 → 결과"의 흐름을 경험 |

## 수업 구조 (매회 40분)

| 시간 | 활동 | 내용 |
|:---:|------|------|
| 0~5분 | 복습 + 오늘 소개 | 지난주 핵심 한 줄 복습 + 오늘 할 것 미리보기 |
| 5~25분 | 실습 (3~4개) | 사전빌드 앱으로 선택 → 전송 → 결과 확인 |
| 25~35분 | "왜 그럴까?" | 방금 한 것의 원리를 쉽게 설명 + 질문 시간 |
| 35~40분 | 정리 + 예고 | 오늘 배운 것 한 줄 + 다음 주 기대감 |

---

## 1주차: 빛과 소리 — "LED를 켜고, 음악을 연주하자!"

### 학습 목표
- 사전빌드 앱 사용법 익히기
- "선택 → 전송 → 결과"의 흐름 체험
- LED(빛)와 부저(소리) 두 가지 출력 체험

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 소개 | "오늘부터 여러분이 하드웨어를 조종합니다!" 앱 설치 확인, UTTEC 보드 나눠주기 |
| 5~10분 | **실습 1: A01 — 빨간 LED 켜기** | 앱에서 "빨간 LED 켜기" 선택 → 전송 → 보드에서 빨간 불이 켜짐! 첫 성공의 감동 |
| 10~15분 | **실습 2: A07 — 빨간 LED 1초마다 깜빡이기** | 깜빡이는 LED 보기. "왜 깜빡일까?" → 켜기-끄기를 반복하니까! |
| 15~20분 | **실습 3: H01 — 신호등 만들기 (빨강3초, 노랑1초, 파랑3초)** | 진짜 신호등! "이거 어디서 봤지?" → 순서대로 실행 = 프로그램 |
| 20~25분 | **실습 4: I02 — 반짝반짝 작은별 연주** | 보드가 피아노가 됐다! 따라 부르기 |
| 25~35분 | 원리 설명 | LED = 전기가 흐르면 빛나는 작은 전구. 부저 = 떨림으로 소리 발생. 컴퓨터가 "켜! 꺼! 떨어!" 명령을 순서대로 실행하는 것이 "프로그램" |
| 35~40분 | 정리 | "LED와 소리를 만들었습니다. 다음 주에는 화면에 글자도 띄우고, 합체시켜봅시다!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| A01 | 빨간 LED 켜기 | ★ |
| A07 | 빨간 LED 1초마다 깜빡이기 | ★ |
| H01 | 신호등: 빨강3초, 노랑1초, 파랑3초 반복 | ★★ |
| I02 | 반짝반짝 작은별 연주 | ★★ |

### 핵심 질문 (아이들에게)
- "LED가 왜 켜질까?" → 전기가 흐르니까!
- "신호등은 누가 바꿔주는 걸까?" → 컴퓨터가 순서대로!
- "높은 도와 낮은 도는 뭐가 다를까?" → 떨리는 횟수(주파수)!

## 2주차: 합체 + 감각 — "화면도 띄우고, 온도도 느끼자!"

### 학습 목표
- 빛 + 소리 + 화면(OLED)을 동시에 제어하는 "합체" 체험
- 센서(sensor)의 개념 — 기계가 환경을 "느끼는" 방법
- 입력(센서) → 출력(화면/LED)의 흐름 이해

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "지난주에 LED, 신호등, 음악을 만들었죠? 오늘은 합체 + 센서!" |
| 5~10분 | **실습 1: J03 — LED 순서대로 켜면서 도레미 연주** | 빨강=도, 노랑=레, 파랑=미! 빛과 소리의 조합 |
| 10~15분 | **실습 2: E01 — OLED에 "Hello" 표시하기** | 작은 화면에 글자가 나타남! "이것도 컴퓨터가 하는 거예요" |
| 15~20분 | **실습 3: F03 — 온도를 OLED에 표시하기** | 현재 교실 온도가 화면에! "진짜 온도가 맞는지 확인해볼까?" |
| 20~25분 | **실습 4: K02 — 온도에 따라 LED 색 바꾸기** | 낮으면 파랑, 보통 노랑, 높으면 빨강. 손으로 센서 감싸서 온도 올리기! |
| 25~35분 | 원리 설명 | 컴퓨터는 여러 가지를 동시에 할 수 있다 = "멀티태스킹". 센서 = 기계의 감각기관. 우리 피부가 온도를 느끼듯, 센서도 온도를 숫자로 느낀다. 컴퓨터는 그 숫자를 보고 판단한다 |
| 35~40분 | 정리 | "기계도 느끼고 판단할 수 있다! 다음 주에는 버튼으로 직접 조종하고 자동화해봅시다" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| J03 | LED 순서대로 켜면서 도레미 연주 | ★★ |
| E01 | OLED에 "Hello" 표시하기 | ★ |
| F03 | 온도를 OLED에 표시하기 | ★ |
| K02 | 온도에 따라 LED 색 바꾸기 | ★★ |

### 핵심 질문
- "컴퓨터는 한번에 하나만 할 수 있을까?" → 아니! 동시에 여러 개!
- "기계가 뜨거운 걸 어떻게 알까?" → 센서!
- "에어컨은 어떻게 알아서 꺼질까?" → 센서가 온도를 느끼고, 컴퓨터가 판단!

## 3주차: 스위치 + 자동화 + 프로젝트 — "만약 ~하면 ~해라!"

### 학습 목표
- 스위치(버튼) 입력 처리
- 조건문(if-then) 개념의 직관적 체험
- 배운 요소를 종합한 미니 프로젝트 체험

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 복습 | "센서는 자동으로 느꼈죠? 오늘은 버튼 + 자동화 + 진짜 프로젝트!" |
| 5~10분 | **실습 1: G01 — 스위치 누르면 빨간 LED 켜기** | 버튼 누르면 켜짐! "내가 누르니까 반응한다!" |
| 10~15분 | **실습 2: L01 — 스위치 누를 때마다 LED 토글** | 한번 누르면 ON, 또 누르면 OFF. 방 전등 스위치와 같은 원리 |
| 15~20분 | **실습 3: K03 — 온도 28도 넘으면 부저 울리기** | 자동 경보! 손으로 센서 잡아서 온도 올리기 → 삐! "자동으로 알려준다!" |
| 20~25분 | **실습 4: Q01 — 라면 타이머** | 3분 카운트다운 OLED + 끝나면 멜로디 + LED. "실제로 쓸 수 있는 것을 만들었어요!" |
| 25~35분 | 원리 설명 | 프로그램의 핵심 = "만약(if) ~하면, ~해라(then)". 예: "만약 버튼 눌리면 → LED 켜라", "만약 28도 넘으면 → 부저 울려라". 단순한 것을 합치면 라면 타이머처럼 쓸모있는 것이 된다! |
| 35~40분 | 정리 | "조건 → 동작, 이것이 모든 프로그램의 핵심! 다음 주에는 여러분이 직접 골라서 만들어봅시다!" |

### 사용 예제
| 번호 | 예제 | 난이도 |
|------|------|:------:|
| G01 | 스위치 누르면 빨간 LED 켜기 | ★ |
| L01 | 스위치 누를 때마다 LED 토글 | ★★ |
| K03 | 온도 28도 넘으면 부저 울리기 | ★★ |
| Q01 | 라면 타이머 (3분 카운트다운 + 멜로디 + LED) | ★★★ |

### 핵심 질문
- "자동문은 어떻게 열릴까?" → "사람 오면(if) → 문 열어(then)!"
- "화재 경보기는?" → "연기 감지하면(if) → 알람 울려(then)!"
- "지금까지 배운 것만으로 뭘 만들 수 있을까?" → 타이머, 게임, 경보기...

## 4주차: 나만의 작품 + 발표 — "내가 만든 스마트 기기!"

### 학습 목표
- 스스로 예제를 선택하고 조합하는 창의적 경험
- 발표를 통해 자기 생각을 표현
- 4주 과정 총정리

### 수업 흐름

| 시간 | 활동 | 상세 |
|:---:|------|------|
| 0~5분 | 안내 | "오늘은 여러분이 직접 선택합니다! 155개 예제 중에서 가장 마음에 드는 것을 골라보세요" |
| 5~20분 | **자유 실습** | 학생마다 원하는 예제 2~3개 선택 실행. 강사는 돌아다니며 도움. 추천 예제 제시: |
| | | - 재미 추구: Q03 반응속도 게임, U02 주사위 게임 |
| | | - 실용 추구: Q01 라면 타이머, O01 온도계 |
| | | - 도전 추구: N03 모스부호 SOS, Y01 디지털 애완동물 |
| 20~30분 | **발표** (1인 1~2분) | "내가 고른 예제는 ○○이고, 이유는 ○○입니다." 시연 포함 |
| 30~38분 | 총정리 | 4주간 배운 것 돌아보기: LED+소리 → 합체+센서 → 자동화+프로젝트 → 나만의 작품. "여러분은 이미 AI 시대의 메이커입니다!" |
| 38~40분 | 마무리 | 수료 인사 + 사진 촬영 |

### 추천 예제 (학생 선택용)
| 유형 | 예제 | 설명 | 난이도 |
|------|------|------|:------:|
| 재미 | Q03 | 반응속도 테스트 게임 | ★★★ |
| 재미 | U02 | 주사위 게임 (BLE) | ★★★★ |
| 실용 | Q01 | 라면 타이머 | ★★★ |
| 실용 | O01 | 온도계 (OLED 막대그래프) | ★★★ |
| 도전 | N03 | 모스부호 SOS (LED+부저+OLED) | ★★★ |
| 도전 | Y01 | 디지털 애완동물 | ★★★★ |

### 핵심 질문
- "4주 동안 배운 것으로 뭘 만들 수 있을까?" → 타이머, 게임, 경보기, 신호등...
- "우리 일상에서 이런 것들이 어디에 쓰이고 있을까?" → 신호등, 에어컨, 화재경보기, 엘리베이터...
