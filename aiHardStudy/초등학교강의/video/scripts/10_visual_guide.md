# 슬라이드 비주얼 가이드 (Remotion 구현용)

각 Scene마다 온스크린 텍스트 + 비주얼 요소 명시. Remotion 컴포넌트(`gimpo-najin/Scene*.tsx`) 구현 시 참조.

---

## Scene 1 — 환영 인사 (30초)

### 비주얼 요소
- 상단: 학교 마크 자리 (placeholder) + "김포나진초등학교" 텍스트
- 중앙 큰 텍스트: **"5·6학년 친구들, 안녕!"** + 손 흔드는 이모지 👋
- 하단: "AI 바이브코딩 4주 여행" 부제
- 배경: 하늘색→연노랑 그라데이션 + 작은 별 파티클 흩날림 ✨
- 오른쪽 아래: 강사 이름 카드 "홍광선 선생님 (㈜유티텍)" 작게

### 애니메이션
- 0~0.5초: 학교 이름 fade-in (위에서 아래)
- 0.5~1.5초: 중앙 텍스트 slide-up + 손 흔들기 wiggle
- 4~5초: 첫 질문 텍스트 "신호등은 누가 바꿀까요?" 큰 말풍선 등장
- 8~9초: "에어컨은 어떻게 알아서 꺼질까요?" 두 번째 말풍선
- 15~17초: "비밀은 작은 컴퓨터!" 펑! 효과 + 보드 일러스트 등장 🧠
- 25~30초: "4주 동안 함께해요!" fade out

### 온스크린 키워드
- 김포나진초등학교 / 5·6학년 / AI 바이브코딩 4주 / 함께해요!

## Scene 2 — 1주차: 빛과 소리 (35초)

### 비주얼 요소
- 상단 헤더: "Week 1" 큰 숫자 + "빛과 소리" 부제
- 중앙: 보드 일러스트 (네모난 PCB) + 빨간 LED 깜빡임 애니메이션
- 4개 활동 카드 순차 등장:
  1. 💡 빨간 LED 켜기
  2. ✨ 깜빡깜빡 LED
  3. 🚦 진짜 신호등 (빨강 3초 / 노랑 1초 / 파랑 3초)
  4. 🎵 반짝반짝 작은별 연주
- 배경: 1주차 컬러 = 따뜻한 노랑 그라데이션

### 애니메이션
- 헤더 fade-in
- 카드 1~4 순차 slide-in (각 5초 간격 sliding)
- 신호등 카드 활성 시 실제 빨강→노랑→파랑 색 변화 미니 애니메이션
- 마지막 5초: "벌써 이만큼!" 별 폭죽

### 온스크린 키워드
- Week 1 / 빛과 소리 / LED · 부저 · 신호등 · 작은별

## Scene 3 — 2주차: 합체와 감각 (35초)

### 비주얼 요소
- 상단 헤더: "Week 2" + "합체와 감각"
- 중앙: 보드 + OLED 화면 mockup (작은 검은 사각형에 "Hello!" 글씨 깜빡)
- 4개 활동 카드:
  1. 🎵+💡 LED 도레미 (빨강=도, 노랑=레, 파랑=미)
  2. 📺 OLED에 Hello!
  3. 🌡️ 화면에 온도 표시
  4. 🔥 손으로 잡으면 LED 색 변화 (파랑→노랑→빨강)
- 배경: 2주차 컬러 = 시원한 청록 그라데이션

### 애니메이션
- 카드 4 활성 시 손 이모지가 센서 잡는 모션 + LED 색이 슬로우 모션으로 파랑→노랑→빨강 진행
- OLED 화면에 실제 "온도: 25°C" 같은 글자 타이핑 효과

### 온스크린 키워드
- Week 2 / 합체와 감각 / OLED · 온도 센서 · 멀티태스킹

## Scene 4 — 3주차: 버튼과 자동화 (35초)

### 비주얼 요소
- 상단 헤더: "Week 3" + "버튼과 자동화"
- 중앙 마법 주문 큰 텍스트: **"만약 ___ 하면, ___ 해라!"** + 마법사 모자 🎩 + 별 ✨
- 4개 활동 카드:
  1. 🔘 버튼 누르면 LED 켜기
  2. 🔄 누를 때마다 ON / OFF 토글
  3. 🌡️🔔 28도 넘으면 자동 경보
  4. ⏱️ 라면 타이머 (3분 + 멜로디 + LED)
- 배경: 3주차 컬러 = 보라 그라데이션 (마법 느낌)

### 애니메이션
- "만약 ~하면 ~해라!" 빈 칸이 차례로 채워짐 ("버튼 눌리면" → "LED 켜라")
- 라면 타이머 카드 활성 시 실제 카운트다운 03:00 → 02:59 → ... 빨리감기 후 띠리리리~ 표시
- 마법 별가루 흩날림

### 온스크린 키워드
- Week 3 / 버튼과 자동화 / 만약 ~하면 ~해라! / 라면 타이머

## Scene 5 — 4주차: 나만의 작품 (35초)

### 비주얼 요소
- 상단 헤더: "Week 4" + "나만의 작품"
- 중앙: 큰 카드 그리드 (6개) — 각각 다른 작품
  - 🎮 반응속도 게임
  - 🎲 주사위 게임
  - ⏱️ 라면 타이머
  - 🌡️ 디지털 온도계
  - 📡 모스부호 SOS
  - 🐣 디지털 애완동물
- 하단 큰 글자: **"155개 예제 중 마음대로!"** + 🎨 팔레트
- 마지막: 발표하는 학생 일러스트 + 🎤 마이크 (다양한 표정)
- 배경: 4주차 컬러 = 무지개 그라데이션 (창의성 강조)

### 애니메이션
- 카드들이 한꺼번에 회전하면서 등장 (3D flip)
- 각 카드 hover 시 살짝 확대 (시각적 흥미)
- 마지막 발표 학생 일러스트 등장 + 박수 이모지 👏👏👏

### 온스크린 키워드
- Week 4 / 나만의 작품 / 155개 예제 / 발표 / 작은 발명가
