## 장 1. 제품 소개 — "코딩 없이 하드웨어를 움직이다"

### 내용

#### 1-1. 한 줄 소개
> "학생이 스마트폰 앱에서 **한국어로 원하는 동작을 말하면**, AI가 코드를 만들고, 무선으로 보드에 전송해서 **1분 안에 LED가 깜빡입니다.** 한 번 연결한 보드는 앱이 자동으로 기억합니다."

#### 1-2. 핵심 가치 3가지 (큰 아이콘 + 한 줄 설명)

| 아이콘 | 가치 | 설명 |
|:------:|------|------|
| 말풍선 | 자연어 입력 | 코딩 언어를 몰라도 한국어로 명령 |
| 번개 | 1분 완성 | 입력부터 보드 동작까지 35~70초 |
| 자석 | 자동 연결 | 앱을 열면 내 보드가 자동으로 연결 |

#### 1-3. "Before vs After" 비교

| 항목 | 기존 코딩 교육 | UTTEC 바이브코딩 |
|------|--------------|----------------|
| 준비 시간 | IDE 설치 + 라이브러리 세팅 (30분~1시간) | 앱 아이콘 터치 → 자동 연결 (10초) |
| 코드 작성 | C/C++ 직접 타이핑 | 한국어로 "LED 깜빡여" |
| 업로드 방식 | USB 케이블 연결 | 무선(BLE) 자동 전송 |
| 에러 대응 | 학생 혼자 디버깅 | AI가 자동 재시도 + 코드 자동 설명 |
| 수업 진행 | 코드 치느라 설명 못 듣는 학생 발생 | 모두 동시에 결과 확인 |
| 2회차 수업 | 또 설정, 또 연결 | 앱만 열면 즉시 시작 |

## 장 3. 앱 설치 가이드

### 내용

#### 3-1. 앱 종류

| 앱 이름 | 용도 | 기본 서버 | 언제 사용 |
|---------|------|----------|----------|
| **UTTEC Cloud** | 인터넷 환경 교육 | 클라우드 서버 | **일반적으로 이것만 설치** |
| UTTEC Local | 인터넷 없는 환경 | 교사 PC (같은 Wi-Fi) | 특수 환경에서만 |

> "일반적으로 **UTTEC Cloud**만 설치하면 됩니다."

#### 3-2. 설치 방법 A — QR코드 (학생이 직접 / 권장)

1. 안내 카드의 **APK 다운로드 QR코드** 스캔
2. Chrome에서 APK 파일 다운로드
3. "알 수 없는 앱" 경고 → **설정 이동** → Chrome에 "허용" 터치
4. 다시 APK 파일 → **설치** 터치
5. 홈 화면에 **UTTEC Cloud** 아이콘 생성 → 완료!

#### 3-3. 설치 방법 B — USB 전송 (교사가 배부)

1. PC에서 APK 파일을 USB로 스마트폰에 전송
2. 스마트폰 파일 관리자 → APK 파일 터치
3. **설치** 터치 → 완료

#### 3-4. 설치 방법 C — 카카오톡/메신저 공유

1. 교사가 APK 파일을 단체 채팅방에 전송
2. 학생이 파일 다운로드 → 터치 → 설치

#### 3-5. "알 수 없는 소스" 설정 안내 (학생용 간단 카드)

```
① 설정 → 앱 → 특별한 액세스 → 알 수 없는 앱 설치
② Chrome (또는 파일 관리자) 선택 → 허용
③ APK 파일 터치 → 설치
④ 완료 후 위 설정을 다시 꺼두면 안전합니다
```

#### 3-6. 교사용 일괄 설치 (ADB)

```
PC에 ADB 설치 후:
1. 스마트폰을 USB로 연결
2. 명령어: adb install uttec-cloud.apk
3. 학생당 약 30초 소요
```

## 장 4. 시작하기 — 5분 만에 첫 실습

### 내용

#### Step 1: 보드 전원 켜기 (30초)
1. USB 케이블로 보드에 전원 연결
2. OLED에 "UTTEC Ready" 표시 확인
3. 파란 LED가 천천히 깜빡이면 BLE 대기 상태

#### Step 2: 앱 실행 + 자동 BLE 연결 (30초)
1. 홈 화면에서 **UTTEC Cloud** 아이콘 터치
2. 첫 실행 시 권한 요청 팝업 3개 → 모두 **허용**
   - "블루투스 스캔 허용" → 허용
   - "블루투스 연결 허용" → 허용
   - "위치 권한" → "앱 사용 중에만 허용"
3. 앱이 **자동으로 주변 보드를 검색** 시작
4. 우측 상단 BLE 상태 확인:
   - 🟡 **"스캔 중..."** → 자동 검색 진행
   - 🟢 **"UTTEC-OTA"** → **자동 연결 완료!**

> **포인트**: "팝업이나 기기 선택 없이, 앱이 알아서 보드를 찾아 연결합니다."

#### Step 3: 첫 번째 명령 — "LED 깜빡이기" (90초)
1. 홈 탭(🏠)에서 프롬프트 입력란에 **"빨간 LED 깜빡이기"** 입력
2. **[실행]** 버튼 터치
3. 스낵바: "AI가 코드를 생성하고 있어요..."
4. 화면에 빌드 진행 표시:
   - 진행률 바: 0% → 30% (AI 코드 생성) → 60% (컴파일) → 100% (완료)
   - 경과 시간: "0:23" → "0:38" → ...
   - 상태: "AI가 코드를 생성 중..." → "컴파일 중..." → "완료! 펌웨어 준비됨"
5. 빌드 완료 → **자동으로 BLE OTA 전송 시작**
   - 전송 진행률: "45% (292/650 KB)"
6. 전송 100% → 보드 자동 재부팅 → **LED가 깜빡이기 시작!**
7. 5초 후 앱이 자동으로 보드에 재연결

> **포인트**: "[실행] 버튼 한 번으로 코드 생성 → 빌드 → 전송 → 동작까지 한 번에 처리됩니다."

#### Step 4: 코드 확인하기
- 빌드 완료 후 화면을 아래로 스크롤
- AI가 만든 코드가 **구문 강조**(syntax highlighting)로 표시됨
- 코드 아래에 **자동 한국어 설명**:
  - 📌 "25번 핀을 출력 모드로 설정합니다"
  - 💡 "25번 핀에 LOW(0V)를 보내 LED를 켭니다 (Active LOW)"
  - ⏱ "500밀리초(0.5초) 동안 기다립니다"

#### Step 5: 직접 명령 입력해보기
- "부저 3번 울리기" → 부저가 삐삐삐
- "학교종 멜로디 연주" → 멜로디 재생
- "온도 측정해서 화면에 보여줘" → OLED에 온습도 표시
- 이전 명령은 **히스토리 카드**에 시간순으로 자동 저장 (최근 10개)

## 장 5. 화면별 기능 설명

### 내용

#### 5-1. 홈 탭 — 펌웨어 만들기

**"원하는 동작을 한국어로 적으면 AI가 코드를 만들어 보드에 자동 전송합니다"**

- **BLE 상태 배너** (우측 상단, 항상 표시)
  - 🟢 초록점 + 기기 이름 → 연결됨 (터치하면 연결 해제)
  - 🟡 노란점 + "스캔 중..." → 자동 검색 중
  - 🔴 빨간점 + "BLE 연결" → 미연결 (터치하면 수동 연결)

- **프롬프트 입력 카드**
  - 텍스트 입력란 (자유 문장)
  - [실행] 버튼

- **빌드 진행 카드**
  - 진행률 바 (0~100%)
  - 경과 시간 (분:초)
  - 상태 메시지 ("AI가 코드를 생성 중..." → "컴파일 중..." → "완료!")
  - 빌드 완료 시 자동 OTA 전송 시작

- **코드 카드** (빌드 완료 후 표시)
  - 구문 강조된 Arduino 코드
  - 키워드 자동 분석 → 한국어 설명 생성
    - `pinMode` → "핀 모드 설정" 설명
    - `digitalWrite(25, LOW)` → "LED를 켭니다 (Active LOW)" 설명
    - `delay(500)` → "0.5초 대기" 설명
    - `initBLE()` → "블루투스 초기화" 설명
    - `Wire.begin()` → "I2C 통신 시작" 설명

- **히스토리 카드** (하단)
  - 최근 10개 프롬프트 + 시간(HH:MM) 표시
  - 이전 수업에서 뭘 했는지 바로 확인

- **6단계 인디케이터** (화면 하단)
  - ① BLE 미연결 → ② 명령 대기 → ③ 생성 중 → ④ OTA 대기 → ⑤ 전송 중 → ⑥ 완료

**핵심 포인트 (영업용)**:
> "실행 버튼 하나로 코드 생성 → 빌드 → 보드 전송까지 한 번에 처리됩니다. 학생은 기다리기만 하면 됩니다. AI가 만든 코드를 한국어로 자동 설명해줘서 코드 공부도 됩니다."

#### 5-2. HW 탭 — 하드웨어 학습

**"보드에 어떤 부품이 있는지, 각 부품이 무슨 역할인지 배웁니다"**

- **보드 정보 카드**: ESP32-WROOM-32, 듀얼코어 240MHz, 4MB Flash
- **3x3 그리드**: 9개 부품 카드 (이모지 + 이름)
- 카드 터치 → 상세 설명 페이지:
  - "이게 뭐야?" — 부품 설명
  - "회로 연결" — ASCII 회로도
  - "💡 팁" — 실용 팁 (파란 박스)
  - "핀 정보" — 테이블 (라벨 | 값)
- 뒤로가기 → 다시 그리드

**9개 부품**: LED(빨/노/파), 부저(능동/멜로디), OLED, 온습도센서, 스위치, ESP32, LoRa, NeoPixel, SPI, 전원

**핵심 포인트 (영업용)**:
> "실물 보드를 보면서 화면의 설명을 읽으면, 하드웨어의 원리를 자연스럽게 이해합니다."

#### 5-3. SW 탭 — 소프트웨어 학습

**"AI가 만든 코드를 줄 단위로 터치하면 설명이 나옵니다"**

- **6개 레슨**:
  - ✅ C언어 기초 (변수, 타입, printf)
  - ✅ GPIO 제어 (LED blink, digitalRead/Write)
  - ✅ 반복과 조건 (if/for/while/delay)
  - 🔒 함수 (준비 중)
  - 🔒 I2C 통신 (준비 중)
  - 🔒 PWM과 타이머 (준비 중)
- 난이도별 별점 표시 (★★★★★ / ★★☆☆☆)
- 잠긴 레슨: "다음 단계에서 공개됩니다"

- **인터랙티브 코드 뷰어** (LED Blink 예시):
  - 17줄 코드, 구문 강조 (전처리기=빨강, 함수=보라, 호출=주황, 주석=회색)
  - 아무 줄이나 터치 → 파란 하이라이트 + 해당 줄 설명 박스
  - 예: `gpio_set_level(LED_PIN, 1)` 터치 → "LED_PIN(25번)에 HIGH(3.3V)를 보내서 LED를 켭니다"

- **퀴즈**: "LED를 켜려면 gpio_set_level의 두 번째 인자로 무엇을 넣어야 할까요?"
  - A/B/C/D 선택 → 정답/오답 + 설명 스낵바

**핵심 포인트 (영업용)**:
> "코딩을 몰라도 시작할 수 있지만, 원하는 학생은 코드를 터치해가며 실력을 키울 수 있습니다."

#### 5-4. 패드 탭 — 실시간 제어

**"스마트폰을 리모컨처럼 사용해서 보드를 직접 조종합니다"**

BLE 미연결 시: 토스트 "BLE 연결이 필요합니다 (홈 탭에서 연결)"

- **LED 컨트롤**
  - 🔴RED / 🟡YELLOW / 🔵BLUE 토글 버튼
  - ON 상태: 초록 테두리 + "ON" / OFF 상태: 회색 테두리 + "OFF"
  - ✨ "전체점멸" → 3개 LED 동시 ON → 500ms 후 자동 OFF
  - 🔄 "전체 끄기" → 모든 LED OFF

- **부저**
  - 🔔 "삐!" → 비프음 1회
  - 🎵 "멜로디" → 도레미파솔라시도 순차 재생 (350ms 간격)

- **피아노**
  - 8개 건반: 도/레/미/파/솔/라/시/도
  - 터치 즉시 보드에서 해당 음 재생

- **센서/디스플레이**
  - 🌡 "온도읽기" → 보드 AHT20 센서 읽기 → OLED 표시
  - 📺 "OLED표시" → "Hello Vibe!" 메시지 표시

- **스위치 모니터** (양방향 통신!)
  - 보드의 스위치(GPIO32) 상태를 실시간 표시
  - 🟢 "PRESSED" (초록 테두리) / 🔘 "RELEASED" (회색)
  - BLE FE05 특성으로 자동 알림 수신

- **콤보** (준비 중)
  - 🎉 파티모드, 🚨 경보모드, 🌡 온도계, 📡 LoRa전송

**핵심 포인트 (영업용)**:
> "스마트폰에서 LED를 켜면 보드에서 바로 켜지고, 보드의 스위치를 누르면 스마트폰에 바로 표시됩니다. 양방향 실시간 통신을 체험할 수 있습니다."

#### 5-5. 설정 탭 — 기기 관리

**"학생마다 보드에 이름을 붙여서 '내 보드'를 쉽게 찾습니다"**

- **서버 설정**: 서버 URL 입력 (기본값 사용, 변경 즉시 반영)

- **보드 설정** (읽기 전용): ESP32-WROOM 38핀, ESP-IDF v5.5, 4MB Flash, 240MHz

- **BLE 기기 설정**:
  - 저장된 기기: 현재 기기 이름
  - MAC 주소: 예) 78:1C:3C:F4:AD:02
  - 연결 상태: "연결됨" / "미연결"
  - **이름 변경**: 입력란 + [저장] → 앱(SharedPreferences) + 보드(NVS) 동시 저장
  - **[주변 BLE 기기 스캔]** → 5초 스캔 → 앱 내 목록 표시:
    ```
    ✓ UTTEC-OTA     78:1C:3C:F4:AD:02  -42dBm  ← 현재 선택 (굵은 글씨)
    🔵 UTTEC-A반2번  AA:BB:CC:DD:EE:FF  -58dBm
    🔵 ESP32-Test   11:22:33:44:55:66  -71dBm
    ```
  - 기기 터치 → 선택 + 영구 저장 → 스낵바 "영구 저장됨"
  - **다음부터 앱 열면 이 기기에 자동 연결**

- **교육 모드**: 토글 (상세 설명 ON/OFF)
- **핀 라벨 표시**: 토글 (회로도에 핀 번호 표시)
- **앱 정보**: 버전 1.0.0, 빌드 2026.04.11

**핵심 포인트 (영업용)**:
> "한 번 보드를 선택하고 이름을 지으면, 다음 수업에는 앱만 열면 자동으로 내 보드에 연결됩니다. MAC 주소까지 기억해서 이름이 같아도 정확히 내 보드만 찾습니다."

| 한 보드에 여러 학생이 연결되나요? | 아닙니다. BLE는 1:1 연결이라 한 번에 한 학생만 연결됩니다. |
| 보드를 집에 가져가서 써도 되나요? | 인터넷이 되면 어디서든 사용 가능합니다. |

#### 기술 관련 (영업용 간단 답변)

| Q | A |
|---|---|
| BLE가 뭔가요? | 블루투스 이어폰과 같은 원리의 무선 통신입니다. |
| OTA가 뭔가요? | 무선으로 프로그램을 전송하는 기술입니다. |
| ESP32가 뭔가요? | IoT 교육에 가장 많이 쓰이는 소형 컴퓨터 칩입니다. |
| MAC 주소가 뭔가요? | 블루투스 기기의 고유 번호입니다. 사람의 주민등록번호처럼, 모든 기기가 다릅니다. |
