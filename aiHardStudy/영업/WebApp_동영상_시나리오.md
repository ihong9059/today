# UTTEC 바이브코딩 교육 플랫폼 — Web App 동영상 시나리오

**사용 방식**: Web App (PWA) — Chrome 브라우저에서 URL 접속
**목적**: 제품 소개 및 시연 영상 제작을 위한 상세 시나리오
**대상 시청자**: 학교/학원 교육 담당자, 투자자, 파트너사
**동영상 종류**: 3종 (티저 30초 / 제품소개 3분 / 상세시연 8분)

---

## 동영상 1: 티저 영상 (30초)

**용도**: SNS, 전시회 부스, 초기 관심 유도
**분위기**: 빠른 편집, 임팩트 있는 음악, 텍스트 오버레이 중심

### 타임라인

| 10~14초 | BLE 전송 애니메이션 (스마트폰 → 보드 파동 효과) | **"무선으로 전송하면"** | 전송 효과음 |

## 촬영 장비 및 환경 가이드

### 최소 장비

| 장비 | 용도 | 비고 |
|------|------|------|
| 스마트폰 카메라 (촬영용) | 보드/환경 촬영 | 삼각대 필수 |
| 스마트폰 (시연용) | Web App 조작 | 화면 녹화 앱 병행 |
| 삼각대 | 흔들림 방지 | 스마트폰용 거치대 |
| 조명 (데스크 램프) | 보드 클로즈업 | 자연광도 가능 |
| 마이크 (선택) | 나레이션 녹음 | |

### 촬영 팁

1. **보드 촬영 시**: 약간 어두운 환경에서 LED가 선명하게 보임
2. **스마트폰 화면**: 밝기 최대, 알림/배너 OFF, 방해 금지 모드
3. **소리**: 부저/멜로디 촬영 시 주변 소음 최소화
4. **동시 촬영**: 스마트폰 화면 + 보드 반응을 같은 프레임에 담기 권장
5. **여러 테이크**: 빌드 시간이 있으므로 프롬프트별 2~3회 촬영
