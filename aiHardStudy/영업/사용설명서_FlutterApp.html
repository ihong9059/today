시작하기 — 5분 만에 첫 실습

1

보드 전원 켜기 30초

  • USB 케이블로 보드에 전원 연결
  • OLED에 "UTTEC Firmware" / "BLE OTA Ready!" 표시 확인
2

앱 실행 + 자동 BLE 연결 30초

  • 홈 화면에서 UTTEC Cloud 아이콘 터치
  • 첫 실행 시 권한 팝업 3개 → 모두 허용
  • 앱이 자동으로 주변 보드를 검색 시작
  • 우측 상단 BLE 상태 확인
"스캔 중..." → 자동 검색 중
"UTTEC-OTA" → 자동 연결 완료!

핵심: 팝업이나 기기 선택 없이, 앱이 알아서 보드를 찾아 연결합니다.

3

첫 번째 명령 — "LED 깜빡이기" 90초

  • 홈 탭에서 프롬프트 입력란에 "빨간 LED 깜빡이기" 입력
  • [실행] 버튼 터치
  • 빌드 진행 표시:
    • 진행률 바: 0% → 30% (AI 생성) → 60% (컴파일) → 100%
    • 경과 시간 실시간 표시
  • 빌드 완료 → 자동으로 BLE OTA 전송 시작
  • 전송 100% → 보드 자동 재부팅
  • LED가 깜빡이기 시작!
  • 5초 후 앱이 자동으로 보드에 재연결
4

코드 확인하기

  • 빌드 완료 후 화면을 아래로 스크롤
  • AI가 만든 코드가 구문 강조(syntax highlighting)로 표시
  • 코드 아래에 자동 한국어 설명이 나타납니다:
    • 📌 "25번 핀을 출력 모드로 설정합니다"
    • 💡 "25번 핀에 LOW(0V)를 보내 LED를 켭니다 (Active LOW)"
    • ⏱ "500밀리초(0.5초) 동안 기다립니다"
5

여러 가지 명령 시도해보기

  • "부저 3번 울리기" → 부저가 삐삐삐
  • "학교종 멜로디 연주" → 멜로디 재생
  • "온도 측정해서 화면에 보여줘" → OLED에 온습도 표시
  • 이전 명령은 히스토리 카드에 자동 저장 (최근 10개)

✅ 축하합니다! 5분 만에 첫 실습을 완료했습니다. 2회차부터는 앱 아이콘 터치 한 번으로 10초 안에 수업을 시작할 수 있습니다.

5

화면별 기능 설명

Flutter 앱은 5개 탭으로 구성됩니다. 하단 탭 바로 전환합니다.

🏠 홈 탭

펌웨어 만들기

  • 프롬프트 입력 → AI 코드 생성 → 빌드 → 자동 BLE 전송
  • 빌드 진행률 + 경과 시간 실시간 표시
  • 코드 자동 한국어 설명
  • 프롬프트 히스토리 (최근 10개)
  • 코딩 질문 AI

🔧 HW 탭

하드웨어 학습

  • 보드 정보 (ESP32-WROOM-32)
  • 3x3 그리드로 9개 부품 카드
  • 카드 터치 → 상세 설명 + 회로도

💻 SW 탭

소프트웨어 학습

  • 6개 레슨 (3개 열림 + 3개 잠김)
  • 인터랙티브 코드 뷰어
  • 코드 줄 터치 → 한국어 설명
  • 퀴즈 (A/B/C/D)

🎮 패드 탭

실시간 제어 (리모컨)

  • LED 3색 ON/OFF 토글
  • 부저 (비프음 + 멜로디)
  • 피아노 8건반
  • 온도 읽기 / OLED 메시지
  • 스위치 모니터 (양방향)

⚙ 설정 탭

기기 관리 + 자동 연결 설정

  • 서버 URL 설정
  • BLE 기기 스캔 (앱 내 목록)
  • MAC 주소 자동 저장
  • 보드 이름 변경 (영구 저장)
  • 교육 모드 ON/OFF
  • 핀 라벨 표시 ON/OFF

🏠 홈 탭 상세

BLE 상태 배너 (우측 상단, 항상 표시)

초록점 + 기기 이름 → 연결됨 (터치하면 연결 해제)
노란점 + "스캔 중..." → 자동 검색 중
빨간점 + "BLE 연결" → 미연결 (터치하면 수동 연결)

펌웨어 만들기

기능설명

[실행] 버튼코드 생성 → 빌드 → 자동 OTA 전송까지 원클릭

코드 키워드자동 설명 예시

⚙ 설정 탭 상세

학생마다 보드에 이름을 붙여서 '내 보드'를 쉽게 찾습니다.

기능설명
서버 URL기본값: http://178.128.90.37:8092 (변경 즉시 반영)
BLE 기기 스캔5초 스캔 → 앱 내 목록 표시 (기기명, MAC, 신호강도)
기기 선택터치 → 선택 + MAC 주소 영구 저장 → 다음부터 자동 연결

핀 라벨회로도에 핀 번호 표시 ON/OFF

🔑 핵심: 한 번 보드를 선택하고 이름을 지으면, 다음 수업에는 앱만 열면 자동으로 내 보드에 연결됩니다. MAC 주소까지 기억해서 이름이 같아도 정확히 내 보드만 찾습니다.

자주 묻는 질문 (FAQ)

일반

인터넷이 필요한가요?
네. AI 코드 생성과 빌드가 클라우드에서 이루어집니다.
아이폰도 되나요?
현재는 안드로이드만 지원됩니다.
UTTEC Cloud와 UTTEC Local의 차이는?
Cloud는 인터넷으로 서버 접속, Local은 같은 Wi-Fi의 교사 PC 접속. 일반적으로 Cloud만 사용합니다.
앱 업데이트는 어떻게 하나요?
새 APK를 받아서 기존 앱 위에 덮어 설치합니다. 설정(보드 이름, MAC)은 유지됩니다.

설치 관련

"알 수 없는 소스" 경고가 떠요
안드로이드 보안 기능입니다. 설정에서 한 번만 허용하면 됩니다. 설치 후 다시 꺼두면 안전합니다.
블루투스 권한을 거부했어요
설정 → 앱 → UTTEC Cloud → 권한 → 블루투스/위치 허용으로 변경하세요.
위치 권한은 왜 필요한가요?
안드로이드에서 BLE 스캔에 위치 정보를 요구합니다. 실제 위치를 수집하지는 않습니다.

교육 현장

학생이 잘못된 명령을 넣으면?
AI가 안전한 범위 내에서만 코드를 생성합니다. 빌드 실패 시 최대 3회 자동 재시도합니다.
학생들 보드가 섞이지 않나요?
각 보드에 이름을 지정하고, 앱이 MAC 주소까지 기억해서 정확히 내 보드만 연결합니다.
2회차 수업에 또 설정해야 하나요?
아닙니다. 앱만 열면 자동으로 내 보드에 연결됩니다. 10초면 수업 시작.
한 보드에 여러 학생이 연결되나요?
아닙니다. BLE는 1:1 연결이라 한 번에 한 학생만 연결됩니다.

용어 설명

용어쉬운 설명
BLE블루투스 이어폰과 같은 원리의 무선 통신입니다.
OTA무선으로 프로그램을 전송하는 기술입니다.
ESP32IoT 교육에 가장 많이 쓰이는 소형 컴퓨터 칩입니다.
MAC 주소블루투스 기기의 고유 번호입니다. 주민등록번호처럼 모든 기기가 다릅니다.
APK안드로이드 앱 설치 파일입니다.
GPIO보드의 입출력 핀 번호입니다. LED, 부저 등을 제어합니다.

증상원인해결

앱 실행 시 크래시Android 버전 낮음Android 6.0 이상 필요

빌드/전송 문제

증상원인해결
빌드 요청 시 무한 대기서버 과부하 또는 이전 빌드 멈춤잠시 기다렸다 재시도
OTA 전송 0%에서 멈춤BLE 연결 불안정스마트폰을 보드 1m 이내로 접근, 재연결
OTA 전송 중간 실패전파 간섭재전송 시도, Wi-Fi 2.4GHz 간섭 최소화
OTA 성공 후 보드 동작 안 함생성 코드 오류다른 프롬프트로 재시도 (예: "LED 깜빡이기")
"CRC_FAIL" 상태전송 중 데이터 손상BLE 재연결 후 OTA 재전송

보드 하드웨어 문제

증상원인해결
OLED에 아무것도 표시 안 됨I2C 연결 불량USB 재연결, 보드 교체
LED가 켜지지 않음핀 번호 불일치 가능"빨간 LED 깜빡이기"처럼 색상명으로 프롬프트
