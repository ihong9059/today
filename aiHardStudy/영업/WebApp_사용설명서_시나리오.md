## 장 1. 제품 소개 — "코딩 없이 하드웨어를 움직이다"

### 내용

#### 1-1. 한 줄 소개
> "학생이 스마트폰에 **한국어로 원하는 동작을 말하면**, AI가 코드를 만들고, 무선으로 보드에 전송해서 **1분 안에 LED가 깜빡입니다.** 앱 설치 없이 Chrome 브라우저만 있으면 됩니다."

#### 1-2. 핵심 가치 3가지 (큰 아이콘 + 한 줄 설명)

| 아이콘 | 가치 | 설명 |
|:------:|------|------|
| 말풍선 | 자연어 입력 | 코딩 언어를 몰라도 한국어로 명령 |
| 번개 | 1분 완성 | 입력부터 보드 동작까지 35~70초 |
| 스마트폰 | 앱 설치 불필요 | 크롬 브라우저에서 URL 접속만으로 시작 |

#### 1-3. "Before vs After" 비교

| 항목 | 기존 코딩 교육 | UTTEC 바이브코딩 |
|------|--------------|----------------|
| 준비 시간 | IDE 설치 + 라이브러리 세팅 (30분~1시간) | URL 접속 즉시 시작 (0분) |
| 코드 작성 | C/C++ 직접 타이핑 | 한국어로 "LED 깜빡여" |
| 업로드 방식 | USB 케이블 연결 | 무선(BLE) 자동 전송 |
| 에러 대응 | 학생 혼자 디버깅 | AI가 자동 재시도 + 코딩 질문 AI |
| 수업 진행 | 코드 치느라 설명 못 듣는 학생 발생 | 모두 동시에 결과 확인 |

```
보드 정면 번호 매기기:
① 빨간 LED    ② 노란 LED    ③ 파란 LED
④ 능동 부저(비프음)  ⑤ 멜로디 부저(음계)
⑥ OLED 화면 (0.96인치)
⑦ 온습도 센서 (AHT20)
⑧ 스위치 버튼
⑨ USB 전원 포트
```

## 장 3. 시작하기 — 5분 만에 첫 실습

### 내용

#### Step 1: 보드 전원 켜기 (30초)
1. USB 케이블로 보드에 전원 연결
2. OLED에 "UTTEC Ready" 표시 확인
3. 파란 LED가 천천히 깜빡이면 BLE 대기 상태

#### Step 2: 스마트폰에서 Web App 접속 (30초)
1. **Chrome 브라우저** 열기 (반드시 Chrome!)
2. URL 입력: `uttec-ai.duckdns.org/firmware`
3. 또는 안내 카드 QR코드 스캔
4. (선택) 메뉴(⋮) → "홈 화면에 추가" → 앱처럼 사용 가능

#### Step 3: BLE 연결 (30초)
1. 설정 탭(⚙) 이동
2. [주변 BLE 기기 스캔] 버튼 터치
3. **Chrome 팝업**에서 "UTTEC-OTA" 선택 → 연결 완료
4. 설정 탭에 "연결됨" 표시 확인

#### Step 4: 첫 번째 명령 — "LED 깜빡이기" (60초)
1. 홈 탭(🏠)으로 이동
2. 예시 프롬프트 칩 중 **"LED 깜빡이기"** 터치 → 자동 입력
3. **[위 명령을 UTTEC 펌웨어로 만들기 🚀]** 버튼 터치
4. 화면에 단계별 진행 표시:
   - ② AI 코드 생성 중 (시도 1/3)... (약 15초)
   - ③ 펌웨어 빌드 중... (약 25초)
5. "빌드 성공!" 메시지 + 소요 시간 요약
6. BLE로 보드에 전송 → 진행률 표시
7. **보드의 LED가 깜빡이기 시작!**

#### Step 5: 직접 명령 입력해보기
- "부저 3번 울리기" → 부저가 삐삐삐
- "학교종 멜로디 연주" → 멜로디 재생
- "온도 측정해서 화면에 보여줘" → OLED에 온습도 표시

#### Step 6: 코딩 질문해보기
1. 홈 탭 하단 **코딩 질문하기** 카드로 이동
2. 예시 질문 칩 "for문이 뭐야?" 터치 또는 직접 입력
3. **[질문하기 💬]** 버튼 터치
4. AI가 한국어로 답변 + 코드 예시 포함

## 장 4. 화면별 기능 설명

### 내용

#### 4-1. 홈 탭 — 펌웨어 만들기 + 코딩 질문

**"원하는 동작을 한국어로 적으면 AI가 코드를 만들어 보드에 전송합니다"**

**상단 카드 — 펌웨어 만들기**
- 프롬프트 입력란 (자유 문장)
- 예시 프롬프트 칩 (터치하면 자동 입력)
- [위 명령을 UTTEC 펌웨어로 만들기 🚀] 버튼
- 빌드 진행 시: 단계별 표시
  - ① 시스템 프롬프트 합성 중...
  - ② AI 코드 생성 중 (시도 1/3)... — 실시간 경과 시간
  - ③ 펌웨어 빌드 중... — 실시간 경과 시간
- 빌드 완료 시: 소요 시간 요약 테이블 (AI 생성 / 빌드 / 전체)
- BLE 연결 상태에서 자동 OTA 전송 + 진행률 표시

**하단 카드 — 코딩 질문하기**
- 예시 질문 칩: "for문이 뭐야?", "GPIO란?", "FreeRTOS 태스크 만드는 법"
- 자유 질문 입력란
- [질문하기 💬] 버튼
- AI 답변 표시: 마크다운 + 코드 블록 + 응답 시간

**핵심 포인트 (영업용)**:
> "프로그래밍 언어를 몰라도, 한국어로 '부저 3번 울리기'라고 적으면 됩니다. 궁금한 점은 같은 화면에서 AI에게 바로 질문할 수 있습니다."

#### 4-2. HW 탭 — 하드웨어 학습

**"보드에 어떤 부품이 있는지, 각 부품이 무슨 역할인지 배웁니다"**

- 3x3 그리드로 9개 부품 카드 표시
- 카드 터치 → 상세 설명 페이지 이동
- 각 부품 상세:
  - "이게 뭐야?" — 부품 설명
  - "회로 연결" — ASCII 회로도
  - "💡 팁" — 실용 팁
  - "핀 정보" — GPIO 번호, 통신 주소 등

**9개 부품**: LED(빨/노/파), 부저(능동/멜로디), OLED, 온습도센서, 스위치, ESP32, LoRa, NeoPixel, SPI, 전원

**핵심 포인트 (영업용)**:
> "실물 보드를 보면서 화면의 설명을 읽으면, 하드웨어의 원리를 자연스럽게 이해합니다."

#### 4-3. SW 탭 — 소프트웨어 학습

**"AI가 만든 코드를 줄 단위로 터치하면 설명이 나옵니다"**

- 6개 레슨: 변수와 데이터 타입, 조건문, 반복문, 함수, I2C 통신, PWM과 타이머
  - 처음 3개 열림 (✅), 나머지 3개 잠김 (🔒 "다음 단계에서 공개됩니다")
  - 별점 표시 (난이도)
- 인터랙티브 코드 뷰어 (LED Blink 예시):
  - 구문 하이라이팅 (전처리기=빨강, 함수=보라, 호출=주황, 주석=회색)
  - 코드 줄 터치 → 파란 하이라이트 + 해당 줄 설명 팝업
- 퀴즈: "LED를 켜려면 gpio_set_level의 두 번째 인자로 무엇을 넣어야 할까요?" (A/B/C/D)

**핵심 포인트 (영업용)**:
> "코딩을 몰라도 시작할 수 있지만, 원하는 학생은 AI가 만든 코드를 학습해서 실력을 키울 수 있습니다."

#### 4-4. 패드 탭 — 실시간 제어

**"스마트폰을 리모컨처럼 사용해서 보드를 직접 조종합니다"**

- **LED 컨트롤**: 빨/노/파 개별 ON/OFF 토글 + "전체 켜기" + "전체 끄기"
- **부저**: "삐!" (비프음 1회) + "멜로디" (도레미파솔라시도 순차 재생)
- **피아노**: 8개 건반 (도/레/미/파/솔/라/시/도)
- **센서/디스플레이**:
  - "온도읽기" → 보드 온습도 센서 읽기
  - "OLED표시" → 고정 데모 메시지 표시
  - **커스텀 OLED 입력**: 최대 20자 텍스트 직접 입력 → 보드 OLED에 표시
- **스위치 모니터**: 보드 스위치(GPIO32) 눌림 상태 실시간 표시 (🟢PRESSED / 🔘RELEASED)
- **콤보**: 파티모드, 경보모드 (준비 중)

**핵심 포인트 (영업용)**:
> "스마트폰이 리모컨이 됩니다. LED를 켜고 끄고, 피아노를 치고, OLED에 자기 이름을 보내는 게 실시간으로 이뤄집니다."

#### 4-5. 설정 탭 — 기기 관리

**"학생마다 보드에 이름을 붙여서 '내 보드'를 쉽게 찾습니다"**

- **서버 설정**: 서버 URL (기본값 사용, 변경 가능) + 서버 상태 확인 (OK/ERROR)
- **BLE 기기 설정**:
  - 저장된 기기 이름 + 연결 상태 (연결됨/미연결)
  - 이름 변경 입력란 + [저장] 버튼
  - [주변 BLE 기기 스캔 🔍] → Chrome 팝업에서 선택
- **보드 설정** (읽기 전용): ESP32-WROOM 38핀, Arduino + NimBLE, 4MB Flash
- **앱 정보**: Web 1.0, Web Bluetooth 지원 상태, 빌드 서버 상태

**핵심 포인트 (영업용)**:
> "30명이 동시에 수업해도, 각 학생이 자기 보드 이름을 정해서 혼동이 없습니다."

## 장 6. 자주 묻는 질문 (FAQ)

### 내용

#### 일반

| Q | A |
|---|---|
| 인터넷이 필요한가요? | 네. AI 코드 생성과 빌드가 클라우드에서 이루어집니다. Wi-Fi 또는 LTE 필요합니다. |
| 아이폰도 되나요? | 아이폰에서는 BLE 전송이 지원되지 않습니다. 안드로이드 스마트폰 + Chrome이 필요합니다. |
| 앱을 설치해야 하나요? | 아닙니다. Chrome 브라우저에서 URL 접속만으로 사용 가능합니다. "홈 화면에 추가"로 앱처럼 쓸 수도 있습니다. |
| PC에서도 사용할 수 있나요? | PC Chrome에서 Web App 접속은 가능하지만, BLE 전송은 안드로이드 Chrome에서만 됩니다. PC에서는 코드 생성 + 코딩 질문만 활용 가능합니다. |
| 매번 URL을 입력해야 하나요? | "홈 화면에 추가"를 하면 앱 아이콘이 생깁니다. 다만 BLE 연결은 매번 기기 선택이 필요합니다. |
