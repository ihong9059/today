# UTTEC 바이브코딩 교육 플랫폼 — Flutter 앱 동영상 시나리오

**사용 방식**: Flutter 네이티브 앱 (APK 설치)
**목적**: 제품 소개 및 시연 영상 제작을 위한 상세 시나리오
**대상 시청자**: 학교/학원 교육 담당자, 투자자, 파트너사
**동영상 종류**: 3종 (티저 30초 / 제품소개 3분 / 상세시연 10분)

### 촬영 팁

1. **보드 촬영 시**: 약간 어두운 환경에서 LED가 선명하게 보임
2. **앱 화면**: 밝기 최대, 알림/배너 OFF, 방해 금지 모드
3. **소리**: 부저/멜로디 촬영 시 주변 소음 최소화
4. **동시 촬영**: 앱 화면 + 보드 반응을 같은 프레임에 담기 권장
5. **자동 연결 장면**: 앱 종료 후 보드 전원 켜진 상태에서 재실행 → 🟡→🟢 전환 순간 캡처
6. **여러 테이크**: 빌드 시간이 있으므로 프롬프트별 2~3회 촬영
