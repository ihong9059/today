시작하기 — 5분 만에 첫 실습

1

보드 전원 켜기 30초

  • USB 케이블로 보드에 전원 연결
  • OLED에 "UTTEC Firmware" / "BLE OTA Ready!" 표시 확인
  • 파란 LED가 천천히 깜빡이면 BLE 대기 상태
2

Chrome에서 Web App 접속 30초

  • Chrome 브라우저 열기 (반드시 Chrome!)
  • URL 입력: https://uttec-ai.duckdns.org/firmware
  • 또는 안내 카드 QR코드 스캔
  • (선택) 메뉴(⋮) → "홈 화면에 추가" → 앱처럼 사용 가능
3

BLE 연결 30초

  • 설정 탭(⚙) 이동
  • [주변 BLE 기기 스캔] 버튼 터치
  • Chrome 팝업에서 "UTTEC-OTA" 선택 → 연결 완료
  • 설정 탭에 "연결됨" 표시 확인

참고: Web App은 BLE 연결 시 매번 Chrome 팝업에서 기기를 선택해야 합니다.

4

첫 번째 명령 — "LED 깜빡이기" 60초

  • 홈 탭으로 이동
  • 예시 프롬프트 칩 중 "LED 깜빡이기" 터치 → 자동 입력
  • [위 명령을 UTTEC 펌웨어로 만들기 🚀] 버튼 터치
  • 진행 상태가 단계별로 표시됩니다:
    • ② AI 코드 생성 중 (약 15초)
    • ③ 펌웨어 빌드 중 (약 25초)
  • "빌드 성공!" 메시지 → BLE로 보드에 자동 전송
  • 진행률: 0% → 25% → 50% → 75% → 100%
  • 보드의 LED가 깜빡이기 시작!
5

여러 가지 명령 시도해보기

  • "부저 3번 울리기" → 부저가 삐삐삐
  • "학교종 멜로디 연주" → 멜로디 재생
  • "온도 측정해서 화면에 보여줘" → OLED에 온습도 표시
6

코딩 질문해보기

  • 홈 탭 하단 코딩 질문하기 카드로 이동
  • 예시 질문 칩 "for문이 뭐야?" 터치 또는 직접 입력
  • [질문하기] 버튼 터치
  • AI가 한국어로 답변 + 코드 예시를 보여줍니다

✅ 축하합니다! 5분 만에 첫 실습을 완료했습니다. 이제 학생들에게 동일한 과정을 안내해주세요.

화면별 기능 설명

Web App은 5개 탭으로 구성됩니다. 하단 탭 바로 전환합니다.

🏠 홈 탭

펌웨어 만들기 + 코딩 질문

  • 프롬프트 입력 → AI 코드 생성 → 빌드 → BLE 전송
  • 예시 프롬프트 칩 (터치로 자동 입력)
  • 빌드 진행 단계별 표시 + 소요 시간
  • 코딩 질문 AI (하단 카드)

🔧 HW 탭

하드웨어 학습

  • 3x3 그리드로 9개 부품 카드
  • 카드 터치 → 상세 설명
  • "이게 뭐야?" / 회로 연결 / 핀 정보

💻 SW 탭

소프트웨어 학습

  • 6개 레슨 (3개 열림 + 3개 잠김)
  • 인터랙티브 코드 뷰어
  • 코드 줄 터치 → 한국어 설명
  • 퀴즈 (A/B/C/D)

🎮 패드 탭

실시간 제어 (리모컨)

  • LED 3색 ON/OFF 토글
  • 부저 (비프음 + 멜로디)
  • 피아노 8건반
  • 온도 읽기 / OLED 메시지
  • 스위치 모니터 (양방향)

⚙ 설정 탭

기기 관리

  • 서버 URL 설정
  • BLE 기기 스캔 → Chrome 팝업 선택
  • 보드 이름 변경 (예: "A반-1번")
  • 보드 정보 / 앱 정보

🏠 홈 탭 상세

자주 묻는 질문 (FAQ)

일반

인터넷이 필요한가요?
네. AI 코드 생성과 빌드가 클라우드에서 이루어집니다. Wi-Fi 또는 LTE가 필요합니다.
아이폰도 되나요?
아이폰에서는 BLE 전송이 지원되지 않습니다. 안드로이드 스마트폰 + Chrome이 필요합니다.
앱을 설치해야 하나요?
아닙니다. Chrome 브라우저에서 URL 접속만으로 사용 가능합니다. "홈 화면에 추가"로 앱처럼 쓸 수도 있습니다.
PC에서도 사용할 수 있나요?
PC Chrome에서 Web App 접속은 가능하지만, BLE 전송은 안드로이드 Chrome에서만 됩니다. PC에서는 코드 생성 + 코딩 질문만 활용 가능합니다.
매번 URL을 입력해야 하나요?
"홈 화면에 추가"를 하면 앱 아이콘이 생깁니다. 다만 BLE 연결은 매번 기기 선택이 필요합니다.

교육 현장

학생이 잘못된 명령을 넣으면 어떻게 되나요?
AI가 안전한 범위 내에서만 코드를 생성합니다. 빌드 실패 시 자동으로 최대 3회 재시도합니다. 보드가 고장날 걱정은 없습니다.
한 반에 30명도 가능한가요?
가능합니다. 5명씩 조별로 순차 진행을 권장합니다.
학생들 보드가 섞이지 않나요?
설정 탭에서 각 보드에 이름을 지정합니다 (예: "A반-1번"). BLE 이름은 보드에 영구 저장됩니다.
보드를 집에 가져가서 써도 되나요?
인터넷이 되면 어디서든 사용 가능합니다.
