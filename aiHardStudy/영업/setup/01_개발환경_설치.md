# STEP 1 — 개발 환경 설치 (Arduino-CLI + ESP32)

**작업일**: 2026-04-13
**작업 PC**: Windows 11 Pro

---

## 1. Arduino-CLI 설치

winget이 사용 불가하여 직접 다운로드 방식으로 설치.

```powershell
# 다운로드
Invoke-WebRequest -Uri 'https://downloads.arduino.cc/arduino-cli/arduino-cli_latest_Windows_64bit.zip' -OutFile 'C:\temp\arduino-cli.zip'

# 압축 해제
Expand-Archive -Path 'C:\temp\arduino-cli.zip' -DestinationPath 'C:\arduino-cli' -Force
```

### 설치 결과

| 항목 | 값 |
|:-----|:---|
| 설치 경로 | `C:\arduino-cli\arduino-cli.exe` |
| 버전 | **1.4.1** (2026-01-19) |

---

## 2. ESP32 보드 패키지 설치

```bash
# ESP32 보드 매니저 URL 추가
arduino-cli config add board_manager.additional_urls \
  https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

# ESP32 코어 설치
arduino-cli core install esp32:esp32@3.2.0
```

### 결과
- `esp32:esp32@3.2.0` — 이미 설치되어 있음 (이전 작업에서 설치됨)

---

## 3. NimBLE-Arduino 라이브러리 설치

```bash
arduino-cli lib install "NimBLE-Arduino@2.3.7"
```

### 결과
- `NimBLE-Arduino@2.3.7` — 이미 설치되어 있음
