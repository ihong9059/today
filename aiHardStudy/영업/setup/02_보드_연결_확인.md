# STEP 2 — ESP32 보드 연결 확인

**작업일**: 2026-04-13

---

## 1. USB 연결 확인

Windows 장치 관리자에서 USB 시리얼 디바이스 검색:

```powershell
Get-CimInstance Win32_PnPEntity | Where-Object { $_.Name -match 'COM|Serial|USB|CP210|CH340' }
```

### 결과

| 항목 | 값 |
|:-----|:---|
| 디바이스 | **Silicon Labs CP210x USB to UART Bridge** |
| 포트 | **COM20** |
| VID:PID | 10C4:EA60 |
| 상태 | 정상 연결 |

---

## 2. Arduino-CLI 보드 인식 확인

```bash
C:\arduino-cli\arduino-cli.exe board list
```

### 결과

```
포트    Protocol 타입                Board Name FQBN Core
COM20  serial   Serial Port (USB)  Unknown
```

- ESP32는 arduino-cli 자동 감지가 안 되므로 FQBN을 수동 지정 필요: `esp32:esp32:esp32`

---

## 3. 시리얼 통신 확인 (기존 펌웨어)

보드에 이전에 설치된 펌웨어가 실행 중이었으며, 115200 baud로 시리얼 출력 확인:

```
Temperature: 22.65 C, Humidity: 34.82 %
Temperature: 22.65 C, Humidity: 34.85 %
Temperature: 22.65 C, Humidity: 34.86 %
Temperature: 22.67 C, Humidity: 34.81 %
Temperature: 22.67 C, Humidity: 34.86 %
Playing melody...
```

### 결과

| 항목 | 값 |
|:-----|:---|
| 보드 상태 | 기존 펌웨어 실행 중 |
| 시리얼 Baud Rate | 115200 |
| 온습도 센서 | AHT20 정상 동작 (22.65°C / 34.8%) |
