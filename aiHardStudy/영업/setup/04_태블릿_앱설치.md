## 4. 태블릿 사용 시 참고 사항

### 장점 (스마트폰 대비)
- **9인치 화면**: 5탭 UI, 코드 뷰어, 학습 카드가 더 잘 보임
- **교실 공유**: 학생 2~3명이 한 화면을 같이 볼 수 있음
- **고정 사용**: 거치대에 놓고 사용 가능 (스마트폰보다 안정적)

### 주의 사항
- **BLE 범위**: 태블릿과 ESP32 보드 간 거리 1~3m 이내 권장
- **권한 허용**: 최초 실행 시 "위치(근처 기기)" + "Bluetooth" 권한 필수 허용
- **Wi-Fi 연결**: 클라우드 서버 접속을 위해 인터넷 연결 필요
