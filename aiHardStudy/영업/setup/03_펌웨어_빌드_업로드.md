## 2. 빌드 (컴파일)

```bash
C:\arduino-cli\arduino-cli.exe compile \
  --fqbn esp32:esp32:esp32 \
  --build-property build.partitions=min_spiffs \
  C:/todo/today/aiHardStudy/firmware/ble_ota_arduino/
```

### 빌드 결과

```
스케치는 프로그램 저장 공간 650570 바이트(49%)를 사용. 최대 1310720 바이트.
전역 변수는 동적 메모리 38236바이트(11%)를 사용, 289444바이트의 지역변수가 남음. 최대는 327680 바이트.
```

## 3. 업로드 (플래싱)

```bash
C:\arduino-cli\arduino-cli.exe upload \
  --fqbn esp32:esp32:esp32 \
  --port COM20 \
  C:/todo/today/aiHardStudy/firmware/ble_ota_arduino/
```
