🔴 LED (발광다이오드)
이게 뭐야?

LED는 전기를 흘리면 빛나는 작은 전구예요.
이 보드에는 3개가 달려 있어요:

🔴 빨강   🟡 노랑   🔵 파랑
어떻게 연결돼 있어?
ESP32 저항 LED
GPIO33 ──[100Ω]──▶|── GND
GPIO25 ──[100Ω]──▶|── GND
GPIO26 ──[100Ω]──▶|── GND
💡 저항이 왜 필요해?
LED에 전류가 너무 많이 흐르면 타버려요.
저항이 전류를 적당히(13mA) 줄여줍니다.

계산: (3.3V - 2.0V) / 100Ω = 13mA ✅ 안전
어떻게 켜고 꺼?

GPIO33에 HIGH (3.3V)를 주면
→ 전류가 흘러 → LED가 켜짐 💡

GPIO33에 LOW (0V)를 주면
→ 전류가 안 흘러 → LED가 꺼짐 ⚫

이것을 "Active HIGH"라고 해요
(HIGH 신호 = 켜짐)
핀 정보
빨강 LEDGPIO33
노랑 LEDGPIO25
파랑 LEDGPIO26
방향출력 (Output)
극성Active HIGH
저항100Ω (직렬)
전류13mA
board.hPIN_LED_RED

🔔 부저 (Buzzer)
이게 뭐야?

부저는 전기 신호를 소리로 바꿔주는 부품이에요.
이 보드에는 2개가 있어요:

🔔 BEEP 부저 — 단순 삐~ 소리 (능동 부저)
🎵 MELODY 부저 — 음계 연주 가능 (수동 부저)
BEEP — 직접 구동 (Active LOW)
VCC ──[BUZ1 +]──[BUZ1 -]── GPIO27

GPIO27 = LOW → 전류 흐름 → 소리 남 🔔
GPIO27 = HIGH → 전류 안흐름 → 소리 안남
💡 Active LOW: LOW 신호가 "켜짐"이에요.
LED(Active HIGH)와 반대!
MELODY — 트랜지스터 구동 (PWM)
GPIO32 ──[R4=10KΩ]── Q1(BCX56) Base
VCC ──[BUZ2]── Q1 Collector
Q1 Emitter ── GND

GPIO32에 PWM 주파수를 주면
→ 그 주파수의 음이 납니다
→ 262Hz = 도, 440Hz = 라
핀 정보
BEEP 부저GPIO27 (Active LOW)
MELODY 부저GPIO32 (PWM, Active HIGH)
board.hPIN_BUZZER_BEEP
PIN_BUZZER_MELODY

🔘 스위치 (Switch)
이게 뭐야?

버튼을 누르면 신호가 바뀌는 부품이에요.
문 초인종 버튼과 같아요.

회로
GPIO35 ──[SW1]── GND
──[C1=100nF]── GND (디바운스)

누르면 → GPIO35 = LOW (0V)
안 누르면 → GPIO35 = HIGH (3.3V)
💡 Active LOW: 버튼을 누르면 LOW!
C1 캐패시터가 버튼의 떨림(바운스)을 잡아줘요.
핀 정보
핀GPIO35 (입력 전용)
극성Active LOW (누름=LOW)
board.hPIN_SWITCH

📺 OLED 디스플레이
이게 뭐야?

0.96인치 작은 화면이에요. 128x64 픽셀.
I2C 통신으로 데이터를 보내면 화면에 표시됩니다.

연결
SDA: GPIO21 (데이터) ──[10KΩ 풀업]── VCC
SCL: GPIO22 (클럭) ──[10KΩ 풀업]── VCC

I2C 주소: 0x3C
컨트롤러: SSD1306

🌡 AHT20 온습도 센서
이게 뭐야?

공기의 온도와 습도를 측정하는 디지털 센서예요.
정밀도: 온도 ±0.3°C, 습도 ±2%RH

연결
OLED과 같은 I2C 버스 공유!
SDA: GPIO21 / SCL: GPIO22
I2C 주소: 0x38

측정 명령 전송 → 80ms 대기 → 데이터 읽기

코드 분석: LED 깜빡이기 ✕
코드를 한 줄씩 탭하면 설명이 나와요!
#include "board.h"
📎 board.h 파일을 가져와요. PIN_LED_RED=33 같은 이름들을 쓸 수 있게 됩니다.
 
void app_main(void) {
🚀 프로그램이 여기서 시작돼요! ESP32가 켜지면 이 함수를 제일 먼저 실행합니다.
  gpio_set_direction(
    PIN_LED_RED, GPIO_MODE_OUTPUT);
⚡ GPIO33번 핀을 "출력" 모드로 설정해요. LED를 제어하려면 출력이어야 해요!

🔧 LED 하드웨어 보기 →
 
  while (1) {
🔄 "계속 반복해!" while(1)은 "영원히"라는 뜻이에요. 이 안의 코드가 계속 반복됩니다.
    gpio_set_level(PIN_LED_RED, LED_ON);
💡 빨간 LED를 켜요! PIN_LED_RED=33, LED_ON=1(HIGH=3.3V)
    vTaskDelay(500 / portTICK_PERIOD_MS);
⏱️ 500밀리초(0.5초) 동안 기다려요. 이 시간이 깜빡이는 속도를 결정해요!

🎮 숫자를 바꿔 실행해보기 →
    gpio_set_level(PIN_LED_RED, LED_OFF);
⚫ 빨간 LED를 꺼요! LED_OFF=0(LOW=0V)
    vTaskDelay(500 / portTICK_PERIOD_MS);
⏱️ 또 0.5초 기다리고, 다시 while 맨 위로!
  }
}
코드 구조 요약
┌── #include (준비물)
├── app_main() {
│   ├── 핀 설정 (1회)
│   └── while(1) {
│       ├── LED 켜기
│       ├── 기다리기
│       ├── LED 끄기
│       └── 기다리기
│     } ← 반복!
└── }
