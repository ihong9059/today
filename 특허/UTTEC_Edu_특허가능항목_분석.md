# UTTEC Edu 플랫폼 특허 가능 항목 분석

**작성일:** 2025년 12월 30일
**대상 서비스:** https://uttec-edu.duckdns.org/
**분석 목적:** 특허 출원 가능성 검토 및 선행기술조사 준비

---

## 1. 플랫폼 개요

UTTEC Edu는 AI 기반 진로교육 플랫폼으로, 다양한 대상(학부형, 사회초년생, 진로전환자 등)에게 맞춤형 교육을 제공하며, 특히 다국어 회화 학습과 코딩 교육을 핵심 콘텐츠로 운영함.

---

## 2. 특허 가능 항목 분류

### 항목 1: 트랙 기반 적응형 진로교육 시스템

**기술 분야:** 교육 시스템, 인공지능, 추천 시스템

**발명의 명칭(안):**
"사용자 유형별 트랙 선택 및 단계적 역량 강화를 위한 적응형 진로교육 시스템"

**기술적 특징:**
1. 사용자를 7개 트랙으로 분류 (영수코스, 회화코스, 학부형, 사회초년생, 코딩전문가, 교사/교육자, 진로전환자, Free)
2. 각 트랙별 맞춤형 커리큘럼 자동 제공
3. 초급 → 중급 → 고급 단계별 학습 경로 설정
4. 학습 완료 시 다음 단계 자동 추천

**구성 요소:**
```
[사용자 입력] → [트랙 분류 모듈] → [커리큘럼 매칭 엔진] → [단계별 콘텐츠 제공] → [진도 추적] → [다음 단계 추천]
```

**차별화 포인트:**
- 진로교육에 특화된 트랙 시스템
- 학부형-자녀 연계 학습 모델
- 실무 포트폴리오 연계 학습 경로

**특허 가능성:** ★★★☆☆ (중간)
- 개별 기술은 일반적이나, 진로교육 특화 시스템으로서의 결합은 신규성 있을 수 있음

---

### 항목 2: AI 프롬프트 자동 생성 언어학습 시스템

**기술 분야:** 자연어처리, 언어교육, AI 연동 시스템

**발명의 명칭(안):**
"학습 주제 기반 AI 대화 프롬프트 자동 생성 및 외부 AI 연동 언어학습 시스템"

**기술적 특징:**
1. 레슨별 학습 주제와 핵심 표현을 분석
2. ChatGPT용 롤플레이 프롬프트 자동 생성
3. 학습자가 프롬프트를 복사하여 외부 AI에서 회화 연습
4. 다국어 지원 (영어, 일본어, 중국어, 스페인어)

**시스템 구성:**
```
[레슨 데이터]
    ↓
[표현 추출 모듈] → 핵심 표현, 문법 포인트 추출
    ↓
[프롬프트 생성 엔진]
    - 역할 설정 (선생님 역할)
    - 주제 컨텍스트 주입
    - 표현 목록 포함
    - 롤플레이 시나리오 구성
    ↓
[프롬프트 출력] → 클립보드 복사 → [외부 AI (ChatGPT)]
```

**프롬프트 생성 예시:**
```
당신은 [언어] 회화 선생님입니다. 오늘의 주제는 "[주제]"입니다.

다음 표현들을 사용하여 학생과 롤플레이 연습을 해주세요:
- [표현1]: [번역1]
- [표현2]: [번역2]
...

학생이 한국어로 말하면 [언어]로 어떻게 표현하는지 알려주고,
학생이 [언어]로 말하면 발음과 문법을 교정해주세요.
```

**차별화 포인트:**
- 학습 콘텐츠와 AI 프롬프트의 자동 연동
- 외부 AI 활용을 통한 무제한 회화 연습
- 다국어 프롬프트 템플릿 시스템

**특허 가능성:** ★★★★☆ (높음)
- AI 프롬프트 자동 생성과 언어학습의 결합은 비교적 신규성 있음
- 단, ChatGPT 의존성으로 인한 한계 존재

### 항목 3: TTS 연동 다국어 발음 학습 시스템

**기술 분야:** 음성합성, 언어교육

**발명의 명칭(안):**
"웹 음성 합성 API 기반 다국어 발음 학습 시스템"

**기술적 특징:**
1. Web Speech API를 활용한 TTS 구현
2. 언어별 최적 음성 속도 설정 (0.8~0.9)
3. 개별 표현 및 대화문 음성 출력
4. 4개 언어 지원 (en-US, ja-JP, zh-CN, es-ES)

**시스템 구성:**
```
[텍스트 입력] → [언어 감지] → [TTS 엔진 (Web Speech API)]
                                    ↓
                           [음성 속도 조절]
                                    ↓
                           [음성 출력]
```

**특허 가능성:** ★★☆☆☆ (낮음)
- Web Speech API 활용은 일반적 기술
- 단독 특허보다는 다른 항목과 결합 필요

---

### 항목 4: MBTI/MMTIC 기반 진로 추천 시스템

**기술 분야:** 심리검사, 추천 시스템, 진로교육

**발명의 명칭(안):**
"성격유형 검사 결과 기반 적합 직업군 및 학습 트랙 추천 시스템"

**기술적 특징:**
1. MBTI/MMTIC 검사 실시 또는 결과 입력
2. 성격 유형별 적합 직업군 데이터베이스 매칭
3. 추천 직업에 필요한 역량 분석
4. 역량 강화를 위한 학습 트랙 자동 추천

**시스템 흐름:**
```
[MBTI 검사/입력] → [성격유형 분석] → [직업군 매칭 DB]
                                            ↓
                                    [적합 직업 추천]
                                            ↓
                                    [필요 역량 분석]
                                            ↓
                                    [학습 트랙 추천]
```

**차별화 포인트:**
- 성격검사 → 직업추천 → 학습추천의 일관된 파이프라인
- 추천에서 끝나지 않고 실제 학습까지 연계

**특허 가능성:** ★★★☆☆ (중간)
- MBTI 기반 직업 추천은 기존에 존재
- 학습 트랙 연계 부분에서 차별화 가능

---

### 항목 5: 하드웨어 연동 임베디드 코딩 교육 시스템

**기술 분야:** 임베디드 시스템, 교육 플랫폼, IoT

**발명의 명칭(안):**
"실습 보드 연동 단계별 임베디드 프로그래밍 교육 시스템"

**기술적 특징:**
1. ESP32 실습 보드와 연동된 커리큘럼 제공
2. 웹 기반 코드 에디터 및 시뮬레이터 (향후 구현 가능)
3. UTTEC Shield 보드와 Python 연동 학습
4. 단계별 프로젝트 기반 학습

**시스템 구성:**
```
[웹 플랫폼]
    ↓
[커리큘럼 엔진] → 이론 학습 → 코드 예제 → 실습 과제
    ↓
[하드웨어 연동 모듈]
    ↓
[ESP32/UTTEC Shield] → 실제 하드웨어 동작 확인
```

**차별화 포인트:**
- 웹 기반 이론 + 실제 하드웨어 실습의 결합
- 자체 개발 보드(UTTEC Shield)와의 연동
- 초급→고급 단계별 프로젝트 기반 학습

**특허 가능성:** ★★★★☆ (높음)
- 특히 UTTEC Shield 보드가 자체 개발품이라면 높은 가능성
- 웹 플랫폼과 하드웨어의 연동 시스템으로 특허 가능

---

### 항목 6: 통합 진로교육 플랫폼 시스템 (결합 발명)

**기술 분야:** 교육 플랫폼, AI, 추천 시스템

**발명의 명칭(안):**
"AI 기반 성격유형 분석 및 맞춤형 진로학습 경로 제공 통합 교육 플랫폼"

**기술적 특징:**
위 1~5번 항목을 통합한 시스템으로:

1. **진단 단계:** MBTI/MMTIC 성격유형 검사
2. **추천 단계:** 성격유형 기반 적합 직업군 추천
3. **학습 단계:** 추천 직업에 필요한 역량 트랙 제공
4. **실습 단계:** AI 프롬프트 기반 회화 연습 / 하드웨어 연동 코딩 실습
5. **평가 단계:** 학습 진도 추적 및 포트폴리오 생성
6. **취업 연계:** 완성된 포트폴리오 기반 취업 지원

**전체 시스템 아키텍처:**
```
┌─────────────────────────────────────────────────────────────┐
│                    UTTEC Edu 통합 플랫폼                      │
├─────────────────────────────────────────────────────────────┤
│  [1. 진단]        [2. 추천]        [3. 학습]        [4. 평가]  │
│  MBTI 검사   →   직업 추천   →   트랙 학습   →   포트폴리오   │
│     ↓              ↓              ↓              ↓         │
│  성격분석        역량분석       콘텐츠제공      진도추적      │
├─────────────────────────────────────────────────────────────┤
│                      핵심 기술 모듈                          │
├──────────────┬──────────────┬──────────────┬────────────────┤
│ AI 프롬프트  │ TTS 발음    │ 하드웨어     │ 적응형        │
│ 생성 엔진   │ 학습 모듈   │ 연동 모듈   │ 추천 엔진     │
└──────────────┴──────────────┴──────────────┴────────────────┘
```

**차별화 포인트:**
- 진단 → 추천 → 학습 → 평가 → 취업의 End-to-End 파이프라인
- 단순 학습 플랫폼이 아닌 진로교육 종합 솔루션
- AI, TTS, 하드웨어의 유기적 결합

**특허 가능성:** ★★★★★ (가장 높음)
- 개별 기술보다 전체 시스템의 결합에서 신규성 확보
- BM(비즈니스 방법) 특허로 접근 가능
