무작위 선택

시험 시작 순서

1. 타이어 확인 2. 안전벨트 착용 3. 미러 조절 4. 시동 5. 주차브레이크 해제 6. 좌측 방향지시등 7. 출발!

감점 항목

감점 항목 설명
-10점 안전미확인 진로변경, 출발 시 주변 확인 안 함
-10점 서행위반 서행 구간에서 속도 미감속
-10점 핸들조작 미숙 급핸들, 불안정한 조향
-5점 방향지시등 미작동 차로변경, 회전 시
-5점 진로변경 미숙 갑작스러운 차로변경
-3점 과속 지정속도 초과 시 3초당 1회

즉시 실격 사유

  • 신호위반 (지정 코스 이탈)
  • 중앙선 침범
  • 보행자 보호 의무 위반
  • 안전벨트 미착용
합격 팁
  • 항상 방향지시등을 먼저 켜고 3초 후 진로변경
  • 교차로 진입 전 반드시 좌우 확인
  • 보행자 발견 시 무조건 양보
  • 긴장하지 말고 천천히, 안전하게!
