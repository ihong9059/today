# HRD-Net (직업훈련포털) 상세 안내

## 1. HRD-Net 개요

### 1.1 정의
**HRD-Net**(Human Resources Development Network, 직업훈련포털)은 고용노동부와 한국고용정보원이 운영하는 대한민국 대표 직업훈련 지원 플랫폼입니다. 국민들이 필요로 하는 직업능력개발훈련 정보를 통합적으로 제공하는 온라인 포털 서비스입니다.

### 1.2 운영 기관
| 구분 | 내용 |
|------|------|
| 주관 부처 | 고용노동부 |
| 운영 기관 | 한국고용정보원 |
| 서비스 시작 | 2003년 |
| 통합 플랫폼 | 고용24 (2024년 통합) |

### 1.3 고용24 통합
2024년 9월부터 HRD-Net은 **고용24**라는 통합 플랫폼으로 완전히 통합되었습니다:
- 기존 9개 고용 관련 정보시스템 통합
- 워크넷, 고용보험, HRD-Net, 국민취업지원제도, 외국인고용관리시스템(EPS) 등
- 하나의 로그인으로 모든 고용 서비스 이용 가능

## 3. 지원 가능한 훈련 유형

### 3.1 국민내일배움카드 훈련
| 항목 | 내용 |
|------|------|
| 지원 대상 | 구직자, 재직자, 자영업자, 특수형태근로종사자 등 |
| 지원 한도 | 5년간 300~500만원 |
| 자부담 | 과정에 따라 0~55% |
| 훈련 분야 | IT, 제조, 서비스, 디자인 등 전 분야 |

### 3.2 K-디지털 트레이닝 (KDT)
| 항목 | 내용 |
|------|------|
| 목적 | 디지털 신기술 분야 전문인력 양성 |
| 대상 | 청년 구직자 중심 |
| 훈련 분야 | AI, 빅데이터, 클라우드, 반도체, 로봇 등 |
| 특징 | 혁신 훈련기관, 선도기업, 우수대학 참여 |
| 훈련비 | 전액 국비 지원 (자부담 없음) |

### 3.3 K-디지털 기초역량훈련
| 항목 | 내용 |
|------|------|
| 목적 | 디지털 기초역량 개발 지원 |
| 대상 | 디지털 역량이 부족한 청년, 중장년 |
| 훈련 내용 | 기초 프로그래밍, 데이터 활용, 디지털 도구 사용 등 |
| 훈련 기간 | 단기 과정 (1~3개월) |

### 3.4 실업자 훈련
| 구분 | 내용 |
|------|------|
| 대상 | 구직급여 수급자, 실업자 |
| 지원 내용 | 훈련비 전액 + 훈련수당 |
| 훈련수당 | 월 최대 316,000원 |
| 특징 | 취업연계 프로그램 포함 |

### 3.5 재직자 훈련
| 구분 | 내용 |
|------|------|
| 대상 | 현재 재직 중인 근로자 |
| 목적 | 직무능력 향상, 이직/전직 준비 |
| 지원 방식 | 국민내일배움카드 활용 |
| 특징 | 야간/주말 과정 다수 |

### 3.6 사업주 훈련
| 구분 | 내용 |
|------|------|
| 대상 | 고용보험 가입 사업장 |

## 4. 이용 방법

### 4.1 접속 방법
| 방법 | 주소/앱 |
|------|---------|
| PC 웹사이트 | https://www.work24.go.kr |
| 직업훈련 전용 | https://hrd.work24.go.kr |
| 모바일 앱 | 고용24 앱 (iOS/Android) |
| 기존 주소 | https://www.hrd.go.kr (고용24로 자동 연결) |

### 4.2 회원가입 및 로그인
**인증 방법**
1. 공동인증서 (구 공인인증서)
2. 간편인증 (카카오, 네이버, PASS, 토스 등)
3. 휴대폰 본인인증
4. 금융인증서

### 4.3 훈련과정 신청 절차
```
[1단계] 회원가입/로그인
    ↓
[2단계] 훈련과정 검색
    ↓
[3단계] 과정 상세정보 확인
    ↓
[4단계] 수강신청
    ↓
[5단계] 내일배움카드 발급 (미발급 시)
    ↓
[6단계] 훈련기관 연락 및 등록 완료
```

### 4.4 국민내일배움카드 발급 절차
```
[1단계] 고용24 로그인
    ↓
[2단계] 국민내일배움카드 메뉴 선택
    ↓
[3단계] 발급 신청서 작성
    ↓
[4단계] 온라인 상담 (필요 시)
    ↓
[5단계] 카드 발급 승인 (약 3~7일)
    ↓
[6단계] 카드 수령 (우편 또는 모바일)
```

## 9. 자주 묻는 질문 (FAQ)

### Q1. HRD-Net과 고용24의 차이점은?
**A.** 2024년 9월부터 HRD-Net이 고용24로 완전 통합되었습니다. 기존 HRD-Net 주소(www.hrd.go.kr)로 접속해도 자동으로 고용24(www.work24.go.kr)로 연결됩니다. 기능은 동일하며, 오히려 더 많은 고용 서비스를 한 곳에서 이용할 수 있습니다.

### Q2. 회원가입 없이도 이용할 수 있나요?
**A.** 훈련과정 검색과 채용정보 열람은 비회원도 가능합니다. 단, 수강신청, 내일배움카드 발급, 실업급여 신청 등은 회원가입과 본인인증이 필요합니다.

### Q3. 국민내일배움카드 발급에 얼마나 걸리나요?
**A.** 온라인 신청 후 약 3~7일 소요됩니다. 추가 서류 제출이나 상담이 필요한 경우 더 길어질 수 있습니다.

### Q4. 모바일 출결은 어떻게 하나요?
**A.** 고용24 앱을 설치한 후, 훈련 시작 시 앱에서 출석 체크를 합니다. GPS 또는 Wi-Fi 기반으로 훈련기관 위치가 확인되어야 정상 출석 처리됩니다.

### Q5. 훈련과정 중도 포기 시 불이익이 있나요?
**A.** 정당한 사유 없이 중도 포기할 경우, 지원받은 훈련비를 반환해야 할 수 있으며, 일정 기간 국비훈련 수강이 제한될 수 있습니다.

## 10. 유의사항

### 10.1 훈련 수강 시 주의점
- 출석률 80% 이상 유지 필수
- 정당한 사유 없는 결석 시 훈련비 환수 가능
- 동시에 2개 이상의 국비훈련 수강 불가
- 동일·유사 과정 재수강 제한

### 10.2 내일배움카드 사용 시 주의점
- 카드 발급 후 1년 이내 1회 이상 훈련 수강 필요
- 미사용 시 카드 효력 상실 가능
- 타인에게 카드 대여 금지
- 허위 출석 시 부정수급으로 처벌
