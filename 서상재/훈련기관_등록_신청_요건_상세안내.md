# 직업훈련기관 등록 및 신청 요건 상세 안내

## 1. 개요

### 1.1 훈련기관이란?
직업능력개발훈련기관은 정부(고용노동부)의 지원을 받아 국민내일배움카드, K-디지털 트레이닝 등 직업훈련을 실시할 수 있는 기관입니다. 훈련기관으로 인정받기 위해서는 법적 요건을 갖추고 심사평가를 통과해야 합니다.

### 1.2 관련 법령
| 법령 | 내용 |
|------|------|
| 근로자직업능력개발법 제16조 | 직업능력개발훈련시설 기본 요건 |
| 근로자직업능력개발법 제28조 | 지정직업훈련시설 지정 요건 |
| 근로자직업능력개발법 시행령 제24조 | 지정 세부 요건 |
| 지정직업훈련시설의 인력, 시설·장비 요건 등에 관한 규정 | 구체적 시설/인력 기준 |

### 1.3 관련 기관
| 기관명 | 역할 | 연락처 |
|--------|------|--------|
| 고용노동부 | 정책 총괄, 최종 인가 | 1350 |
| 직업능력심사평가원 | 훈련기관/과정 심사평가 | 1644-5113 |
| 한국고용정보원 | HRD-Net 시스템 운영 | 1577-7114 |
| 관할 고용센터 | 관리번호 발급, 현장 확인 | 지역별 상이 |

## 2. 훈련기관 유형

### 2.1 기관 설립 형태별 분류
| 유형 | 설명 | 예시 |
|------|------|------|
| 지정직업훈련시설 | 고용노동부장관 지정 | 직업전문학교, 훈련원 |
| 학교 | 초·중등교육법, 고등교육법 기관 | 대학교, 전문대학 |
| 평생교육시설 | 평생교육법에 따른 시설 | 평생교육원 |
| 학원 | 학원법에 따른 시설 | 컴퓨터학원, 직업훈련학원 |
| 사업주 훈련시설 | 기업 내 전용 훈련시설 | 기업연수원 |
| 사업주단체 훈련시설 | 협회/조합 운영 시설 | 협회 교육센터 |

### 2.2 훈련 방식별 분류
| 유형 | 특징 | 시설 요건 |
|------|------|----------|
| 집체훈련 | 대면 교육, 실습 위주 | 강의실, 실습실 필수 |
| 원격훈련 | 온라인 교육 | 사무실 66㎡ 이상 |
| 혼합훈련 | 집체 + 원격 병행 | 양쪽 요건 충족 |

## 3. 훈련기관 등록 절차 (Step by Step)

### 3.1 전체 프로세스
```
[1단계] 기관 설립/등록
    ↓
[2단계] HRD-Net 회원가입 (훈련기관)
    ↓
[3단계] 행정지원시스템 이용권한 신청
    ↓
[4단계] 훈련기관 관리번호 발급
    ↓
[5단계] 실시가능직종 승인
    ↓
[6단계] NCS확인강사 등록
    ↓
[7단계] 시설·장비·교재 등록
    ↓
[8단계] 훈련기관 인증평가 신청
    ↓
[9단계] 훈련과정 심사 신청
    ↓
[10단계] 훈련 운영 개시
```

### 3.2 단계별 상세 설명

#### [1단계] 기관 설립/등록
**지정직업훈련시설 신청 시 필요 서류:**
| 서류 | 설명 |
|------|------|
| 직업능력개발훈련시설 지정 신청서 | 정부24에서 양식 다운로드 |
| 훈련교사 자격증 사본 | 직업능력개발훈련교사 자격증 |
| 직업상담인력 자격증/경력증명서 | 직업상담사 또는 관련 경력자 |
| 대표자 교육훈련실시 경력증명서 | 교육 분야 경력 증빙 |
| 건축물대장 등본 | 시설 소유/임차 확인 |
| 시설 평면도 및 위치도 | 훈련실 배치도 |
| 임대차계약서 사본 | 임차건물인 경우 |
| 사업자등록증 또는 법인등기부등본 | 법인/개인사업자 증빙 |
| 훈련과정별 훈련실시계획서 | 교육과정 개요 |
| 장비목록 (구매계약서 등) | 훈련장비 보유 증빙 |

#### [2단계] HRD-Net 회원가입
1. 고용24 (www.work24.go.kr) 접속
2. 회원가입 → "훈련기관" 유형 선택
3. 사업자등록번호 입력
4. 대표자 정보 입력 및 본인인증
5. 기관 기본정보 등록

#### [3단계] 행정지원시스템 이용권한 신청
- HRD-Net 로그인 후 "마이서비스" 메뉴
- "전자서비스 이용권한 신청" 클릭
- 필요 서류 첨부 (전자파일)
- 직업능력심사평가원 1차 검토
- 관할 고용센터 최종 승인/반려

#### [4단계] 훈련기관 관리번호 발급
| 항목 | 내용 |
|------|------|
| 발급 기관 | 관할 고용센터 |
| 소요 기간 | 약 7~14일 |
| 필요 조건 | 기관 설립 완료 + 전자서비스 승인 |
| 결과 | 훈련기관 고유 관리번호 부여 |

#### [5단계] 실시가능직종 승인
- NCS(국가직무능력표준) 소분류 단위로 직종 신청
- 훈련 가능한 직종을 사전에 승인받아야 함
- 미승인 직종은 훈련과정 심사 신청 불가
- 심사평가 접수 기간 전까지 승인 완료 필요

#### [6단계] NCS확인강사 등록 (아래 상세 설명)

#### [7단계] 시설·장비·교재 등록
- HRD-Net에 보유 시설/장비 정보 등록
- 훈련직종별 필요 장비 목록 확인
- 장비 구매 영수증/임대계약서 준비

#### [8단계] 훈련기관 인증평가
- 직업능력심사평가원에서 실시
- 1단계: 기관건전성평가
- 2단계: 역량평가
- 인증 등급에 따라 훈련과정 인정 범위 결정

#### [9단계] 훈련과정 심사 신청
- 인증평가 통과 후 개별 과정 심사
- 과정별 NCS 기반 교육과정 구성
- 교강사 배정, 장비 확보 현황 확인

#### [10단계] 훈련 운영 개시
- 과정 심사 통과 후 훈련생 모집 가능
- HRD-Net에 과정 공개
- 국민내일배움카드 훈련생 수강 가능

## 6. 훈련교강사(NCS확인강사) 요건

### 6.1 NCS확인강사란?
국비지원 훈련과정(NCS 학습모듈 기반)의 강의를 진행하는 훈련 교강사로서, 최소 기준요건을 검토하여 훈련품질을 보장하기 위한 제도입니다.

### 6.2 등록 필수 요건
- NCS확인강사로 등록(승인)되지 않으면 훈련과정 심사 시 교과목 배정 불가
- 훈련기관에서 활용하고자 하는 교강사는 반드시 사전 등록 필요

### 6.3 NCS확인강사 등록 방법
1. HRD-Net (www.hrd.go.kr 또는 www.work24.go.kr) 로그인
2. [마이서비스] → [강사신청] → [NCS확인강사신청]
3. 자격 증빙 서류 첨부
4. 직업능력심사평가원 심사
5. 승인 완료 후 교과목 배정 가능

### 6.4 직업능력개발훈련교사 자격 등급
| 등급 | 주요 자격요건 |
|------|--------------|
| 1급 | 2급 취득 후 5년 이상 교육훈련 경력 + 향상훈련 이수 |
| 2급 | 3급 취득 후 3년 이상 교육훈련 경력 + 향상훈련 이수 |
| 3급 | 아래 조건 중 1가지 충족 |

### 6.5 3급 자격 취득 조건 (7가지 중 택1)

| 조건 | 학력/자격 | 경력 | 교직훈련 |
|------|----------|------|----------|
| 1 | 기술교육대학 졸업 + 산업기사 이상 | - | 양성과정 이수 |
| 2 | 관련 학사학위 이상 | 3년 이상 교육/실무 | 필요 |
| 3 | 기사 자격증 | 1년 이상 교육/실무 | 필요 |
| 4 | 산업기사 자격증 | 3년 이상 교육/실무 | 필요 |
| 5 | 기능사 자격증 | 5년 이상 교육/실무 | 필요 |
| 6 | 해당 직종 경력자 | 7년 이상 교육/실무 | 필요 |
| 7 | 전문대학 관련학과 졸업 | 4년 이상 교육/실무 | 필요 |

### 6.6 교직훈련과정 이수 인정 대상
- 기능대학 졸업자로 재학 중 6학점 이상 교직과목 이수자
- 중등학교 정교사 2급 이상 자격증 소지자
- 대학 교원 경력자 (고용노동부 고시 기준)
- 직업능력개발훈련교사 양성훈련과정 이수자

### 6.7 자격증 발급 신청
| 방법 | 절차 |
|------|------|
| 온라인 | HRD-Net 로그인 → 자격증 발급신청 메뉴 |
| 오프라인 | 관할 고용센터 방문 신청 |

### 6.8 보수교육 의무
- 매년 「직업능력개발훈련 교·강사의 보수교육에 관한 운영규정」에 따라 보수교육 이수 필수
- 미이수 시 강사 자격 유지에 불이익

## 8. 훈련기관 인증평가

### 8.1 평가 개요
| 항목 | 내용 |
|------|------|
| 평가 기관 | 직업능력심사평가원 |
| 평가 대상 | 신규기관 및 실적보유기관 |
| 평가 주기 | 정기평가 (연 1회) + 수시평가 |
| 근거 법령 | 근로자직업능력개발법 제53조 |

### 8.2 평가 절차
```
[1단계] 기관건전성평가
    - 재무 건전성
    - 법적 요건 충족 여부
    - 부정수급 이력 확인
    ↓
[2단계] 역량평가
    - 훈련실시능력
    - 훈련인프라
    - 훈련성과
    ↓
[결과] 인증등급 부여
```

### 8.3 평가 항목
| 평가 영역 | 세부 항목 |
|----------|----------|
| 기관 건전성 | 재무상태, 법령 준수, 부정수급 여부 |
| 훈련 인프라 | 시설, 장비, 교재 적정성 |
| 훈련 인력 | 교강사 전문성, 행정인력 확보 |
| 훈련 운영 | 교육과정 설계, 품질관리 |
| 훈련 성과 | 수료율, 취업률, 만족도 |

### 8.4 인증등급 및 효력
| 등급 | 유효기간 | 특징 |
|------|----------|------|
| 5년 인증 | 5년 | 최우수 기관, 과정심사 간소화 |

5. **심사**: 서면심사 → 인터뷰심사 → 심의위원회
6. **결과 발표**: 선정/탈락 통보
