## 1. 제도 개요

### 1.1 국민내일배움카드란?

| 항목 | 내용 |
|------|------|
| **주관 기관** | 고용노동부 |
| **운영 플랫폼** | HRD-Net (직업훈련포털) |
| **목적** | 국민의 직업능력개발을 위한 훈련비 지원 |
| **유효기간** | 발급일로부터 **5년** |
| **카드 형태** | 신용카드 또는 체크카드 |
| **발급 카드사** | 신한카드 / NH농협카드 중 선택 |

### 1.2 도입 배경

```
기존 제도                      통합 제도 (2020년~)
    ↓                              ↓
[실업자 내일배움카드]           [국민내일배움카드]
[재직자 내일배움카드]     →     (구직자 + 재직자 통합)
[취업성공패키지]
```

### 1.3 핵심 특징

| 특징 | 내용 |
|------|------|
| **통합 지원** | 구직자/재직자 구분 없이 통합 지원 |
| **장기 유효** | 5년간 사용 가능 (기존 1-3년에서 확대) |
| **높은 지원금** | 최대 500만원까지 지원 |
| **다양한 과정** | IT, 디자인, 자격증, 외국어 등 |
| **온/오프라인** | 온라인 과정도 지원 |

## 2. 신청 자격

### 2.1 신청 가능 대상

| 대상 | 설명 |
|------|------|
| **구직자** | 취업준비생, 실직자, 경력단절자 |
| **재직자** | 중소기업 근로자, 비정규직 근로자 |
| **자영업자** | 연 매출 1억 5천만원 미만 |
| **특수형태근로종사자** | 보험설계사, 학습지교사, 배달기사 등 |
| **프리랜서** | 고용보험 미가입 프리랜서 |
| **대학 졸업예정자** | 졸업예정 학기 재학생 |
| **청년** | 만 15세 ~ 34세 |
| **중장년** | 만 35세 이상 |

### 2.2 신청 불가 대상

| 대상 | 사유 |
|------|------|
| 현직 공무원 | 공무원 자체 교육 제도 존재 |
| 사립학교 교직원 | 별도 연수 제도 |
| 대기업 정규직 | 기업 자체 교육 (예외 있음) |
| 만 75세 이상 | 연령 제한 |
| 월 임금 300만원 이상 대기업 근로자 | 고소득 근로자 제외 |
| 연 매출 1억 5천만원 이상 자영업자 | 고매출 자영업자 제외 |

### 2.3 연령 조건

| 연령 | 신청 가능 여부 |
|------|:-------------:|
| 만 15세 미만 | ❌ |
| 만 15세 ~ 74세 | ✅ |
| 만 75세 이상 | ❌ |

## 3. 지원 금액

### 3.1 기본 지원 한도

| 구분 | 지원 금액 |
|------|----------|
| **기본 지원** | 300만원 |
| **추가 지원** | 최대 200만원 |
| **총 한도** | **최대 500만원** |

### 3.2 자부담 비율

| 대상 | 지원율 | 자부담 |
|------|:------:|:------:|
| **일반 훈련생** | 45% ~ 85% | 15% ~ 55% |
| **취약계층** | 최대 100% | 0% |
| **K-디지털트레이닝** | 최대 100% | 0% |

### 3.3 추가 지원 대상 (최대 500만원)

| 대상 | 추가 지원액 |
|------|-----------|
| 기간제 근로자 | +200만원 |
| 단시간 근로자 | +200만원 |
| 파견 근로자 | +200만원 |
| 일용 근로자 | +200만원 |
| 고용위기지역 근로자 | +200만원 |
| 자영업자 (영세) | +100만원 |
| 특수형태근로종사자 | +100만원 |

### 3.4 지원금 계산 예시

```
예시 1: 일반 재직자
┌─────────────────────────────────────────┐
│ 훈련비: 1,000만원                        │
│ 지원율: 75%                             │
│ 지원금: 750만원 → 한도 300만원 적용       │
│ 자부담: 1,000만원 - 300만원 = 700만원     │
└─────────────────────────────────────────┘

예시 2: 취약계층 (K-디지털트레이닝)
┌─────────────────────────────────────────┐
│ 훈련비: 2,000만원                        │
│ 지원율: 100%                            │
│ 지원금: 2,000만원 (K-디지털 별도 한도)    │
│ 자부담: 0원                             │
└─────────────────────────────────────────┘
```

## 4. 훈련장려금

### 4.1 훈련장려금이란?

훈련에 참여하는 동안 생계 지원을 위해 지급되는 수당입니다.

### 4.2 지급 기준

| 구분 | 지급액 | 조건 |
|------|--------|------|
| **일 지급액** | 5,800원 | 1일 5시간 이상 수강 |
| **월 최대** | 116,000원 | 월 140시간 이상 수강 |
| **특별 지원** | 월 최대 30만원 | 구직자 (조건 충족 시) |

### 4.3 지급 조건

| 조건 | 내용 |
|------|------|
| **출석률** | 80% 이상 필수 |
| **훈련시간** | 월 140시간 이상 권장 |
| **실업급여** | 실업급여 수급자는 제외 |
| **중복 수급** | 타 장려금과 중복 불가 |

### 4.4 훈련장려금 계산 예시

```
예시: 월 160시간 수강, 출석률 90%
┌─────────────────────────────────────────┐
│ 기본 장려금: 5,800원 × 20일 = 116,000원  │
│ 출석률 충족: ✅ (90% > 80%)             │
│ 지급액: 116,000원                        │
└─────────────────────────────────────────┘
```

#### STEP 7: 훈련 수강 (훈련 기간)

**출석 관리:**
| 항목 | 기준 |
|------|------|
| 최소 출석률 | 80% 이상 |
| 지각/조퇴 | 3회 = 결석 1회 |
| 결석 사유서 | 병원 진단서 등 제출 |

**훈련장려금 수령:**
| 조건 | 지급 |
|------|------|
| 출석률 80% 이상 | ✅ 지급 |
| 출석률 80% 미만 | ❌ 미지급 |

**훈련 중 주의사항:**
- 출석 체크 철저히 하기
- 과제/평가 성실히 참여
- 중도 포기 시 불이익 발생 (환수 등)

| 국비지원 자격증 과정 | 대학교 정규 학점 |

### 7.2 결제 방법

| 방법 | 설명 |
|------|------|
| **자동 결제** | 훈련기관에서 HRD-Net으로 청구 |
| **수강생 결제** | 자부담금만 카드로 결제 |

### 7.3 잔액 확인

- **HRD-Net**: My서비스 → 카드잔액조회
- **카드사 앱**: 신한/농협 앱에서 확인

## 9. 자주 묻는 질문

### Q1. 재직 중에도 신청 가능한가요?
**A**: 네, 가능합니다. 다만 대기업 정규직(월 300만원 이상)은 제외될 수 있습니다.

### Q2. 카드 발급까지 얼마나 걸리나요?
**A**: 온라인 신청 후 심사 2-7일, 카드 배송 약 1주일로 총 2-3주 소요됩니다.

### Q3. 여러 과정을 동시에 들을 수 있나요?
**A**: 동시 수강은 불가하며, 한 과정 수료 후 다른 과정 신청 가능합니다.

### Q4. 중도 포기하면 어떻게 되나요?
**A**: 훈련비 환수 및 일정 기간 재신청 제한이 있을 수 있습니다.

### Q5. 유효기간 5년이 지나면?
**A**: 재신청 및 재발급이 가능합니다.

### Q6. 온라인 과정도 지원되나요?
**A**: 네, HRD-Net에 등록된 원격훈련 과정은 지원됩니다.

### Q7. 훈련장려금은 언제 받나요?
**A**: 매월 훈련 종료 후 익월에 지급됩니다.

### Q8. 자부담금은 어떻게 내나요?
**A**: 내일배움카드로 결제하거나 훈련기관에 직접 납부합니다.
