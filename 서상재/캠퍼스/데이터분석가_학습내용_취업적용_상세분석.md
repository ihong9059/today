### 3.2 취업 적용 및 필요성

#### SQL - 데이터 분석가의 필수 언어

| 관점 | 설명 |
|------|------|
| **업계 필수** | 데이터 분석가 채용의 100%가 SQL 요구 |
| **데이터 접근** | 회사의 모든 데이터는 DB에 저장 |
| **협업** | 개발자, DBA와의 커뮤니케이션 필수 |
| **면접 필수** | SQL 코딩 테스트가 거의 모든 회사에서 진행 |

#### SQL 실무 활용 예시

```sql
-- 일별 활성 사용자 수 (DAU) 계산
SELECT
    DATE(created_at) as date,
    COUNT(DISTINCT user_id) as dau
FROM user_events
WHERE event_type = 'login'
GROUP BY DATE(created_at)
ORDER BY date;

-- 7일 리텐션 분석
WITH first_login AS (
    SELECT user_id, MIN(DATE(created_at)) as first_date
    FROM user_events
    GROUP BY user_id
)
SELECT
    first_date,
    COUNT(DISTINCT f.user_id) as day0_users,
    COUNT(DISTINCT CASE WHEN DATEDIFF(e.created_at, f.first_date) = 7
                        THEN e.user_id END) as day7_users,
    ROUND(COUNT(DISTINCT CASE WHEN DATEDIFF(e.created_at, f.first_date) = 7
                              THEN e.user_id END) * 100.0 /
          COUNT(DISTINCT f.user_id), 2) as retention_rate
FROM first_login f
LEFT JOIN user_events e ON f.user_id = e.user_id
GROUP BY first_date;
```

#### A/B 테스트 - 데이터 기반 의사결정의 핵심

| 실무 적용 | 설명 |
|----------|------|
| **제품 개선** | 버튼 색상, 레이아웃, 카피 변경 효과 측정 |
| **가격 최적화** | 가격 변경이 매출에 미치는 영향 |
| **추천 알고리즘** | 새 알고리즘 vs 기존 알고리즘 비교 |
| **마케팅 캠페인** | 캠페인 효과 측정 |

#### 비즈니스 지표 - 회사 언어 이해하기

| 지표 | 설명 | 활용 |
|------|------|------|
| **DAU/MAU** | 일간/월간 활성 사용자 | 서비스 건강도 측정 |
| **Retention** | 사용자 재방문율 | 제품 품질 측정 |
| **ARPU** | 사용자당 평균 매출 | 수익성 분석 |
| **LTV** | 고객 생애 가치 | 마케팅 비용 결정 |
| **CAC** | 고객 획득 비용 | 마케팅 효율 측정 |
| **Churn Rate** | 이탈률 | 고객 유지 전략 |

#### 주요 기업의 프로덕트 분석

| 기업 | 분석 사례 |
