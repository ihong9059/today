| **31주** | - | 취업 준비 |

### 2.2 학습 흐름 비교

#### 데이터 분석가 학습 흐름

```
Python 기초 → 데이터 처리 → 시각화 → SQL → 비즈니스 분석
    ↓
A/B 테스트 → 머신러닝 기초 → 클라우드 → 파이프라인 자동화
    ↓
종합 프로젝트 (데이터 수집 → 분석 → 시각화 → 리포트)
```

#### AI 엔지니어 학습 흐름

```
Python 기초 → ML 기초 → 딥러닝 → 컴퓨터 비전 (CNN)
    ↓
자연어 처리 → LLM/RAG → 프롬프트 엔지니어링
    ↓
모델 배포 → Docker/K8s → MLOps → 서비스화
```
