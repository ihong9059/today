| 기술 | 세부 내용 |

| **모델 최적화** | 양자화, 프루닝, ONNX 변환 |

### 7.2 취업 적용 및 필요성

#### MLOps - AI 엔지니어의 핵심 차별화 역량

| 관점 | 설명 |
|------|------|
| **모델 개발 vs 배포** | 모델 개발은 전체 AI 프로젝트의 20%, 배포/운영이 80% |
| **취업 경쟁력** | MLOps 역량 보유자는 공급 대비 수요가 매우 높음 |
| **연봉 프리미엄** | MLOps 엔지니어는 일반 ML 엔지니어 대비 20-30% 높은 연봉 |

#### Docker - 현대 개발의 필수 기술

| 실무 적용 | 설명 |
|----------|------|
| **환경 일관성** | 개발/테스트/운영 환경 동일하게 유지 |
| **배포 자동화** | CI/CD 파이프라인의 핵심 |
| **의존성 관리** | Python 패키지 버전 충돌 해결 |

#### FastAPI - AI 서비스의 표준 API 프레임워크

| 실무 적용 | 설명 |
|----------|------|
| **모델 서빙** | 학습된 모델을 API로 제공 |
| **비동기 처리** | 대용량 요청 처리에 최적화 |
| **자동 문서화** | Swagger/OpenAPI 자동 생성 |

#### Kubernetes - 대규모 서비스 운영

| 실무 적용 | 설명 |
|----------|------|
| **오토스케일링** | 트래픽에 따른 자동 확장/축소 |
| **고가용성** | 서비스 중단 없는 배포 |
| **리소스 관리** | GPU 리소스 효율적 활용 |

#### 주요 기업의 MLOps 스택

| 기업 | MLOps 스택 |
|------|-----------|
| **네이버** | Kubernetes, Kubeflow, MLflow |
| **카카오** | Kubernetes, Argo, Seldon |
| **쿠팡** | AWS SageMaker, Kubernetes |
| **배달의민족** | Kubernetes, Airflow, MLflow |
