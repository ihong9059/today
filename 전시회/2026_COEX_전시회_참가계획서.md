## 4. 전시 콘텐츠

### 4.1 전시 솔루션: 스마트 파쇄기 모니터링 시스템

> "AI 기반 실시간 모니터링으로 과부하를 예방하고, 설비 수명을 연장하며, 다운타임을 최소화"

#### 핵심 기능

| 기능 | 설명 | 효과 |
|------|------|------|
| **자동 과부하 보호** | 전류/토크 실시간 감시, 과부하 시 자동 감속 | 과부하 감지 → 자동 감속 → 역회전 재시도 → 3회 실패 시 비상정지 |
| **AI 예지정비** | 진동/온도 패턴 분석으로 마모 사전 예측 | 베어링 및 블레이드 마모 사전 예측 |
| **데이터 기반 최적화** | 재료별 최적 운전 조건 자동 학습 | 에너지 효율 20% 향상 |
| **원격 모니터링** | 스마트폰/PC에서 실시간 상태 확인 | 이상 알림 즉시 수신 |

#### 모니터링 대상 설비

| 설비 | 특징 | 적용 산업 |
|------|------|----------|
| **이축 파쇄기 (SHREDDER)** | 교차 회전하는 두 축으로 강력한 파쇄 | 폐플라스틱, 폐금속, 폐타이어, 폐배터리 |
| **분쇄기 (CRUSHER)** | 해머/임팩트 방식의 고속 분쇄 | 금속, 광물, 건설폐기물 |
| **핀밀 (PIN MILL)** | 충격식 미분쇄기 | 양극재, 음극재, 화학원료 |

#### 센서 구성

| 센서 종류 | 측정 항목 | 분석 목적 |
|----------|----------|----------|
| **전류/토크 센서** | 모터 전류, 토크 변화 | 과부하 감지, 재료 투입량 추정 |
| **진동 센서 (3축)** | 베어링/축 진동 | 베어링 마모, 블레이드 불균형 감지 |
| **온도 센서** | 모터/베어링 온도 | 과열 예방, 윤활 상태 확인 |

#### 성과 지표 (ROI)

| 지표 | Before | After | 개선율 |
|------|--------|-------|-------|
| 다운타임 | 100% (기준) | 30% | **70% 감소** |
| 정비비용 | 100% (기준) | 70% | **30% 절감** |
| 에너지 효율 | 100% (기준) | 120% | **20% 향상** |
| 장비 수명 | 100% (기준) | 120% | **20% 연장** |
| **투자회수 기간** | - | **4.9개월** | - |
| **평균 ROI** | - | **145%** | - |

## 10. 전시 콘텐츠 상세

### 10.1 소개 영상 (3분)

**구성:**

```
[인트로 - 10초]
"파쇄기 과부하, 이제 AI가 예방합니다"

[문제 제기 - 30초]
"갑작스러운 파쇄기 정지, 막대한 손실"
- 과부하로 인한 비계획 정지
- 블레이드 마모로 인한 품질 저하
- 베어링 고장으로 인한 장기 다운타임

[솔루션 소개 - 60초]
"스마트 파쇄기 모니터링 시스템"
- 전류/토크 실시간 감시 → 자동 과부하 보호
- 진동/온도 AI 분석 → 마모 사전 예측
- 원격 모니터링 → 스마트폰에서 실시간 확인

[적용 사례 - 40초]
"한국기계엔지니어링 파쇄기 적용 사례"
- 이축 파쇄기 모니터링 화면
- Before/After 비교

[결과 강조 - 20초]
"다운타임 70% 감소"
"투자회수 4.9개월"
"ROI 145%"

[아웃트로 - 20초]
"UTTEC & 한국기계엔지니어링"
"부스 방문을 환영합니다"
연락처, QR 코드
```

### 10.2 브로셔 내용 (A4, 3단 접지)

**1면 (표지)**
- 로고 (UTTEC + 한국기계엔지니어링)
- "스마트 파쇄기 AI 모니터링 시스템"
- 핵심 비주얼 (파쇄기 + 대시보드)

**2면 (문제 제기)**
- "파쇄기 과부하, 얼마나 잃고 계십니까?"
- 비계획 정지 비용 통계
- 파쇄기 고장 패턴 (과부하, 블레이드 마모, 베어링 손상)

**3면 (솔루션)**
- 핵심 기능 4가지 아이콘 + 설명
- 자동 과부하 보호
- AI 예지정비
- 데이터 기반 최적화
- 원격 모니터링

**4면 (적용 설비)**
- 이축 파쇄기 (SHREDDER)
- 분쇄기 (CRUSHER)
- 핀밀 (PIN MILL)

**5면 (사례/ROI)**
- 적용 사례
- 성과 수치 (다운타임 70% 감소, ROI 145%)

**6면 (연락처)**
- 회사 정보 (UTTEC, 한국기계엔지니어링)
- 담당자 연락처
- QR 코드 (데모 사이트)

### 10.3 실시간 데모 시스템

**데모 시나리오:**

1. **대시보드 개요**
   - 전체 파쇄기 상태 한눈에 보기
   - 정상/주의/경고 현황
   - 실시간 전류/토크 모니터링

2. **과부하 보호 데모**
   - 전류 상승 시 경고 표시
   - 자동 감속 → 역회전 재시도 로직 설명
   - 비상정지 연동

3. **진동 분석 데모**
   - 베어링 진동 FFT 분석 화면
   - 블레이드 불균형 감지
   - 마모 예측 트렌드

4. **AI 예측 데모**
   - 잔여수명(RUL) 예측 그래프
   - 정비 권고 알림 시연

5. **히스토리 조회**
   - 과거 운전 데이터 트렌드
   - 과부하 발생 이력
