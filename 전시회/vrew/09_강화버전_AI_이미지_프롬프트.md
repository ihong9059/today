## 이미지 스타일 가이드

### 전체 스타일
- 다크 모드 배경 (검정/남색 계열)
- 네온 블루/시안 악센트
- 산업용 기계 느낌
- 미래지향적, 하이테크

### 문제 제기 장면 (장면 3~7)
- **분위기**: 어둡고 위협적, 긴장감
- **색상**: 빨강, 주황, 검정
- **조명**: 비상등, 경고등
- **키워드**: crisis, emergency, danger, alarm, failure

### 솔루션 장면 (장면 8~23)
- **분위기**: 밝고 희망적, 기술적
- **색상**: 파랑, 시안, 녹색
- **조명**: 깨끗한 LED, 글로우 효과
- **키워드**: protection, solution, smart, AI, technology

### 성과 장면 (장면 24~30)


### 일관된 스타일
```
--style raw --no text --no watermark
```
