## 빠른 시작 가이드

### 1단계: Vrew 설치
1. https://vrew.ai 접속
2. 무료 다운로드 및 설치
3. 계정 생성 (Pro 플랜 권장: 월 12,900원)

### 2단계: 스크립트 준비
1. `02_Vrew_나레이션_스크립트.txt` 파일 열기
2. 스크립트 전체 복사

### 3단계: 영상 제작
1. Vrew 실행 → "새로 만들기" → "텍스트로 비디오 만들기"
2. 스크립트 붙여넣기
3. AI 음성 선택: 한국어 → 준서(남) → 속도 0.95
4. 각 장면에 AI 이미지 생성 (프롬프트는 `03_AI_이미지_프롬프트.md` 참조)
5. 자막, 전환효과, 배경음악 설정
6. 내보내기: 1920x1080 Full HD

상세한 가이드는 `04_Vrew_사용_가이드.md` 참조
