## 1. Vrew 설치 및 설정

### 1.1 다운로드 및 설치
1. https://vrew.ai 접속
2. "무료 다운로드" 클릭
3. Windows용 설치 파일 다운로드
4. 설치 파일 실행하여 설치 완료

### 1.2 계정 생성
1. Vrew 실행
2. "로그인" 클릭
3. 이메일 또는 Google 계정으로 가입
4. 무료 플랜으로 시작 (Pro 업그레이드 권장: 월 12,900원)

### 1.3 초기 설정 확인
- 언어: 한국어
- 기본 해상도: 1920x1080 (Full HD)

## 2. 프로젝트 생성

### 2.1 새 프로젝트 시작
```
1. Vrew 메인 화면에서 "새로 만들기" 클릭
2. "텍스트로 비디오 만들기" 선택
   - 이 옵션이 스크립트 기반 영상 제작에 가장 적합
```

### 2.2 프로젝트 설정
```
화면 비율: 16:9 (가로) ← 전시회 대형 화면용
해상도: 1920x1080 (Full HD) 또는 3840x2160 (4K)
```

### 2.3 "다음" 클릭하여 스크립트 입력 화면으로 이동

---

## 3. 스크립트 입력

### 3.1 스크립트 복사/붙여넣기
```
1. "02_Vrew_나레이션_스크립트.txt" 파일 열기
2. "스크립트 시작" ~ "스크립트 끝" 사이의 텍스트만 복사
3. Vrew 스크립트 입력창에 붙여넣기
4. 자동으로 문장 단위로 분리됨 (총 32개 장면)
```

### 3.2 장면 확인
- 각 문장이 하나의 장면(클립)이 됨
- 문장이 너무 길면 두 개로 나눠질 수 있음
- 필요시 수동으로 분리/병합 가능

### 3.3 "다음" 클릭하여 음성 설정으로 이동

## 4. AI 음성 생성

### 4.1 음성 선택
```
언어: 한국어
목소리: "준서" (남성, 전문적 톤) ← 권장
대안: "서연" (여성, 친근한 톤)
```

### 4.2 음성 스타일 설정
```
스타일: "뉴스" 또는 "프레젠테이션"
속도: 0.95 (기본 1.0보다 약간 천천히)
피치: 기본값 유지
```

### 4.3 미리듣기
- "미리듣기" 버튼으로 일부 문장 확인
- 자연스러운지, 속도가 적절한지 확인
- 부자연스러우면 다른 목소리로 변경

### 4.4 "생성" 클릭
- AI가 전체 나레이션 음성 생성
- 완료까지 1~3분 소요

## 5. 배경 이미지 설정

### 5.1 방법 A: Vrew AI 이미지 (권장)
```
각 장면에 대해:
1. 장면 클릭하여 선택
2. 화면 좌측 "AI 이미지" 버튼 클릭
3. "03_AI_이미지_프롬프트.md" 파일에서 해당 프롬프트 복사
4. 프롬프트 입력 후 "생성" 클릭
5. 생성된 4개 이미지 중 가장 적합한 것 선택
6. "적용" 클릭
7. 모든 32개 장면에 대해 반복
```

### 5.2 방법 B: 외부 이미지 가져오기
```
이미 준비된 이미지가 있는 경우:
1. 장면 클릭하여 선택
2. "미디어" → "이미지 가져오기"
3. 컴퓨터에서 이미지 파일 선택
4. "열기" 클릭
```

### 5.3 방법 C: 비디오 클립 삽입
```
대시보드 녹화 영상 등:
1. 장면 클릭하여 선택
2. "미디어" → "비디오 가져오기"
3. MP4 파일 선택
4. 시작/끝 지점 조절
5. "적용"
```

### 5.4 Ken Burns 효과 (이미지 움직임)
```
정적 이미지에 움직임 추가:
1. 장면 선택
2. "효과" → "Ken Burns"
3. 시작 프레임: 100% 줌
4. 끝 프레임: 110% 줌 (천천히 줌 인 효과)
5. "적용"
```

## 6. 자막 스타일 설정

### 6.1 전체 자막 스타일 설정
```
1. 상단 메뉴 "자막" → "자막 스타일"
2. 다음과 같이 설정:

   폰트: Pretendard Bold (없으면 "본고딕" 또는 "맑은 고딕")
   크기: 52pt
   색상: 흰색 (#FFFFFF)
   외곽선: 2px 검정
   그림자: 있음 (부드러운 그림자)
   배경: 없음 (또는 반투명 검정 50%)
   위치: 하단 중앙 (화면 아래 10%)

3. "전체 적용" 클릭
```

### 6.2 특정 장면 자막 강조 (선택사항)
```
성과 수치 강조 (장면 26~28):
1. 해당 장면 선택
2. 자막 크기: 72pt로 증가
3. 색상: 녹색 (#00DFA2) 또는 파랑 (#3498db)
4. 굵기: Extra Bold
```

## 7. 전환 효과 추가

### 7.1 기본 전환 효과 설정
```
1. 장면과 장면 사이 "+" 버튼 클릭
2. 전환 효과 선택:
   - 페이드 (Fade): 부드러운 전환
   - 디졸브 (Dissolve): 겹치며 전환
   - 슬라이드: 섹션 전환 시
   - 컷: 빠른 전환
3. 지속시간: 0.3~0.5초
```

### 7.2 권장 전환 효과
| 구간 | 전환 효과 | 지속시간 |
|------|----------|---------|
| 장면 2→3 (인트로→문제) | 페이드 (검정) | 0.5초 |
| 장면 3~7 (문제 제기) | 컷 | 0.2초 |
| 장면 7→8 (문제→솔루션) | 슬라이드 | 0.5초 |
| 장면 8~21 (솔루션) | 디졸브 | 0.3초 |
| 장면 21→22 (솔루션→사례) | 페이드 | 0.5초 |
| 장면 26~28 (성과 강조) | 줌 | 0.3초 |
| 장면 29~32 (아웃트로) | 페이드 | 0.5초 |

### 7.3 전체 적용
- "전체 적용" 옵션으로 기본 전환 일괄 설정 후
- 특정 구간만 개별 수정

## 8. 배경음악 추가

### 8.1 Vrew 내장 음악 사용
```
1. 하단 타임라인에서 "오디오" 트랙 선택
2. "배경음악" 버튼 클릭
3. 카테고리 선택: "Corporate" 또는 "Technology"
4. 미리듣기 후 적절한 음악 선택
5. "적용" 클릭
```

### 8.2 외부 음악 가져오기
```
저작권 무료 음악 사이트:
- Pixabay: https://pixabay.com/music/
- Mixkit: https://mixkit.co/free-stock-music/

1. MP3 파일 다운로드
2. "오디오" → "파일 가져오기"
3. 음악 파일 선택
```

### 8.3 볼륨 조절 (중요!)
```
1. 오디오 트랙의 배경음악 선택
2. 볼륨 조절:
   - 전체: 20~30%
   - 나레이션이 있는 구간: 15~20%
   - 인트로/아웃트로: 40~50%

3. 페이드 인/아웃 설정:
   - 시작: 2초 페이드 인
   - 끝: 2초 페이드 아웃
```

## 9. 최종 편집 및 내보내기

### 9.1 최종 검토 체크리스트
```
□ 전체 재생하며 확인
□ 나레이션과 자막 싱크 맞는지
□ 배경 이미지 32개 모두 설정됨
□ 전환 효과 자연스러운지
□ 배경음악 볼륨 적절한지
□ 총 재생시간 약 3분 (2분 50초~3분 10초)
□ 오탈자 없는지
□ 로고/QR코드 표시 정상인지
```

### 9.2 미세 조정
```
장면 길이 조절:
1. 타임라인에서 장면 가장자리 드래그
2. 늘리거나 줄이기
3. 나레이션보다 0.5초 정도 여유 두기

음성 속도 부분 조절:
1. 특정 장면 선택
2. "음성" → "속도 조절"
3. 해당 구간만 속도 변경
```

### 9.3 내보내기
```
1. 상단 "내보내기" 버튼 클릭
2. 설정:
   - 해상도: 1920x1080 (Full HD)
   - 또는 3840x2160 (4K) ← 65인치 대형 화면용
   - 품질: 높음 (Bitrate 15~20 Mbps)
   - 형식: MP4 (H.264)
   - 프레임: 30fps

3. 저장 위치: vrew 폴더 선택
4. 파일명: UTTEC_스마트파쇄기_홍보영상_v1_1080p.mp4
5. "내보내기" 클릭
6. 완료까지 대기 (5~15분)
```

### 9.4 최종 테스트
```
1. 생성된 MP4 파일 재생
2. PC에서 전체 재생 테스트
3. 가능하면 실제 65인치 TV/모니터에서 테스트
4. 자막 가독성 확인
5. 음향 밸런스 확인
```

## 문제 해결 FAQ

### Q1. AI 음성이 부자연스럽습니다
```
해결방법:
1. 문장에 쉼표(,)와 마침표(.) 적절히 사용
2. 긴 문장은 두 개로 분리
3. 다른 목소리로 변경 (준서 → 민준)
4. 속도를 0.9로 낮추기
```

### Q2. Vrew AI 이미지 품질이 낮습니다
```
해결방법:
1. 프롬프트를 더 구체적으로 작성
2. "8k quality, photorealistic" 추가
3. 여러 번 생성하여 최선 선택
4. Midjourney/DALL-E 외부 생성 후 가져오기
```

### Q3. 영상 길이가 3분을 초과합니다
```
해결방법:
1. 나레이션 속도 1.05로 약간 빠르게
2. 일부 문장 축약
3. 장면 전환 시간 0.2초로 단축
4. 불필요한 여백 제거
```

### Q4. 내보내기가 너무 오래 걸립니다
```
해결방법:
1. 먼저 1080p로 테스트 내보내기
2. 백그라운드 프로그램 종료
3. SSD 저장 공간 확보
4. 야간에 내보내기 실행
```

### Q5. 자막이 대형 화면에서 잘 안 보입니다
```
해결방법:
1. 폰트 크기 60pt 이상으로 증가
2. 굵은 폰트 (Bold 또는 Black)
3. 외곽선 두께 3px로 증가
4. 그림자 강하게
```
