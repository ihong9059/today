## 문서 정보
- **작성일**: 2026-02-10
- **목적**: 60인치 대형 화면용 3분 소개 영상 제작 (Vrew 활용)

| **플랫폼** | Windows, Mac, Web |

| 장점 | 설명 |
|------|------|
| **한국어 TTS 우수** | 자연스러운 한국어 AI 음성 지원 |

## 2. 제작 전 준비사항

### 2.1 필수 준비물

```
□ Vrew 프로그램 설치 (https://vrew.ai 다운로드)
□ Vrew 계정 생성 및 로그인
□ 나레이션 스크립트 (아래 3장 참조)
□ 로고 파일 (UTTEC, 한국기계엔지니어링 PNG)
□ 대시보드 화면 캡처/녹화 영상
□ 센서 실물 사진 (보유 시)
□ 배경음악 (저작권 Free)
```

### 2.2 영상 사양 설정

| 항목 | 설정값 |
|------|--------|
| **해상도** | 1920 x 1080 (Full HD) 또는 3840 x 2160 (4K) |
| **화면비율** | 16:9 |
| **프레임** | 30fps |
| **영상 길이** | 3분 (180초) |
| **출력 형식** | MP4 (H.264) |

### 2.3 Vrew 설정

```
1. Vrew 실행
2. 새 프로젝트 생성
3. 설정 → 프로젝트 설정
   - 해상도: 1920x1080 또는 3840x2160
   - 프레임 레이트: 30fps
4. 저장
```

## 4. Vrew 제작 단계별 가이드

### 4.1 Step 1: 프로젝트 생성

```
1. Vrew 실행
2. "새로 만들기" 클릭
3. "텍스트로 비디오 만들기" 선택
4. 프로젝트 설정:
   - 화면 비율: 16:9 (가로)
   - 해상도: 1920x1080 또는 4K
5. "다음" 클릭
```

### 4.2 Step 2: 스크립트 입력

```
1. 스크립트 입력창에 위 3.1의 스크립트 전체 복사/붙여넣기
2. 문장 단위로 자동 분리됨
3. 각 문장 = 하나의 장면
4. "다음" 클릭
```

### 4.3 Step 3: AI 음성 설정

```
1. 음성 선택 화면
2. 언어: 한국어
3. 목소리 선택:
   - 남성 추천: "준서" 또는 "민준" (전문적, 신뢰감)
   - 여성 추천: "서연" 또는 "수아" (친근, 명확)
4. 음성 스타일: "뉴스/프레젠테이션" 또는 "비즈니스"
5. 속도: 1.0 (기본) ~ 0.9 (약간 천천히)
6. 미리듣기로 확인
7. "생성" 클릭
```

**추천 음성 조합**:
| 목적 | 음성 | 스타일 | 속도 |
|------|------|--------|------|
| 신뢰/전문성 | 준서 (남) | 뉴스 | 0.95 |
| 친근/설득력 | 서연 (여) | 프레젠테이션 | 1.0 |

### 4.4 Step 4: 배경 이미지/영상 설정

Vrew에서 각 장면에 배경을 설정하는 방법:

#### 방법 1: Vrew AI 이미지 생성 (가장 간편)

```
1. 해당 장면 클릭
2. "AI 이미지" 버튼 클릭
3. 프롬프트 입력 (영어 권장)
4. 생성 후 적용
```

**장면별 AI 이미지 프롬프트**:

| 장면 | Vrew AI 이미지 프롬프트 |
|------|------------------------|
| 1 | Industrial twin-shaft shredder machine in modern factory, blue LED lights, cinematic |
| 3 | Factory production line stopped, red warning lights, workers looking worried |
| 4 | Digital display showing "OVERLOAD" warning with red lights flashing |
| 5 | Close-up of worn shredder blade with visible damage, compared to new blade |
| 6 | Overheated industrial bearing with thermal imaging overlay, red hot spots |
| 8 | IoT sensor network diagram, sensors connected to cloud, blue glow |
| 10 | Real-time current monitoring graph, green line trending upward |
| 14 | FFT vibration analysis screen, frequency spectrum with peaks |
| 20 | Multiple devices showing monitoring dashboard, phone tablet laptop |
| 25 | Large "70%" text with downward arrow, green background |
| 26 | "4.9" text with calendar icon, payback period visualization |
| 27 | "145%" text with ROI graph, green profit zone |
| 30 | QR code in center with contact information, corporate ending |

#### 방법 2: 외부 이미지 가져오기

```
1. 해당 장면 클릭
2. "미디어" → "이미지 가져오기"
3. AI_이미지_프롬프트_가이드.md 참조하여 Midjourney/DALL-E로 생성한 이미지 선택
4. 적용
```

#### 방법 3: 비디오 클립 가져오기

```
대시보드 데모 화면 등 녹화 영상:
1. 해당 장면 클릭
2. "미디어" → "비디오 가져오기"
3. 녹화 파일 선택
4. 시작/끝 지점 조절
5. 적용
```

### 4.5 Step 5: 자막 스타일 설정

```
1. 자막 설정 메뉴
2. 폰트: Pretendard, Noto Sans KR, 본고딕
3. 크기: 48~60pt (60인치 TV 가독성)
4. 색상: 흰색 (#FFFFFF)
5. 배경: 반투명 검정 (#000000, 60%)
6. 위치: 하단 중앙
7. 전체 적용
```

**자막 스타일 권장**:
```
폰트: Pretendard Bold
크기: 52pt
색상: #FFFFFF (흰색)
외곽선: 2px 검정
그림자: 있음 (부드러운 그림자)
배경: 없음 또는 반투명
위치: 화면 하단 10% 지점
```

### 4.6 Step 6: 장면 전환 효과

```
1. 장면 사이 "+" 버튼 클릭
2. 전환 효과 선택:
   - 페이드 (Fade): 부드러운 장면 전환 (기본)
   - 디졸브 (Dissolve): 자연스러운 겹침
   - 슬라이드 (Slide): 섹션 전환 시
3. 지속시간: 0.3~0.5초
4. 전체 적용 또는 개별 적용
```

**섹션별 권장 전환**:
| 구간 | 전환 효과 |
|------|----------|
| 인트로 → 문제 제기 | 페이드 (검정으로) |
| 문제 제기 장면들 | 컷 (빠른 전환) |
| 문제 제기 → 솔루션 | 슬라이드 (왼쪽으로) |
| 솔루션 장면들 | 디졸브 |
| 솔루션 → 사례 | 페이드 |
| 성과 강조 | 줌 인 |
| 아웃트로 | 페이드 |

### 4.7 Step 7: 로고/텍스트 오버레이

```
1. "텍스트" 도구 선택
2. 텍스트 추가:
   - 인트로: 로고 이미지 삽입
   - 성과 수치: 큰 숫자 강조 ("70%", "4.9개월", "145%")
   - 아웃트로: QR 코드 + 연락처
3. 위치/크기 조절
4. 애니메이션 효과 추가 (페이드인, 줌 등)
```

### 4.8 Step 8: 배경음악 추가

```
1. "오디오" → "배경음악"
2. Vrew 제공 무료 음악 또는 외부 파일 가져오기
3. 권장 스타일: Corporate, Technology, Inspiring
4. 볼륨: 나레이션 대비 20~30%
5. 페이드 인/아웃 설정
```

**배경음악 볼륨 조절**:
```
나레이션 구간: 배경음악 15~20%
장면 전환 순간: 배경음악 30~40%
인트로/아웃트로: 배경음악 50~60%
```

### 4.9 Step 9: 최종 검토

```
체크리스트:
□ 전체 재생하며 음성/자막 싱크 확인
□ 자막 오탈자 수정
□ 장면 전환 부드러움 확인
□ 배경음악 볼륨 밸런스
□ 총 재생시간 3분 확인
□ 로고/텍스트 위치 확인
```

### 4.10 Step 10: 내보내기

```
1. "내보내기" 클릭
2. 설정:
   - 해상도: 1920x1080 (Full HD) 또는 3840x2160 (4K)
   - 품질: 높음 (Bitrate 15~20 Mbps)
   - 형식: MP4 (H.264)
   - 프레임: 30fps
3. 저장 위치 선택
4. "내보내기" 시작
5. 완료 후 파일 확인
```

## 5. 고급 기능 활용

### 5.1 Vrew AI 이미지 효과적 활용

Vrew 내장 AI 이미지 생성 팁:

```
좋은 프롬프트 예시:
✓ "Industrial shredder machine, blue LED lights, factory setting, photorealistic"
✓ "Dashboard UI showing graphs and charts, dark theme, technology"
✓ "Warning lights flashing on control panel, red glow, dramatic"

피해야 할 프롬프트:
✗ "파쇄기" (한국어 인식 불안정)
✗ "nice machine" (너무 모호함)
✗ 긴 문장 (핵심 키워드로 압축)
```

### 5.2 Ken Burns 효과 (이미지 움직임)

정적 이미지에 움직임 추가:

```
1. 이미지 장면 선택
2. "효과" → "Ken Burns"
3. 시작 프레임 설정 (줌 레벨, 위치)
4. 끝 프레임 설정
5. 예: 줌 인 (100% → 120%), 패닝 (좌→우)
```

**장면별 권장 효과**:
| 장면 유형 | Ken Burns 효과 |
|----------|---------------|
| 파쇄기 전경 | 천천히 줌 인 |
| 센서 클로즈업 | 좌→우 패닝 |
| 대시보드 | 우측 하단→좌측 상단 |
| 성과 수치 | 줌 아웃 (강조→전체) |

### 5.3 화면 분할 (Before/After)

```
1. "효과" → "화면 분할"
2. 좌우 분할 선택
3. 왼쪽: Before 이미지
4. 오른쪽: After 이미지
5. 분할선 스타일 설정
```

### 5.4 텍스트 애니메이션 (숫자 강조)

성과 수치 강조를 위한 텍스트 효과:

```
1. 텍스트 추가: "70%"
2. 애니메이션: "타이핑" 또는 "카운트업"
3. 폰트: 굵은 산스세리프
4. 크기: 화면의 30~40%
5. 색상: 강조색 (녹색 #00DFA2)
```

## 10. 문제 해결 (FAQ)

### Q1. AI 음성이 부자연스럽습니다

```
해결방법:
1. 문장을 더 짧게 분리
2. 쉼표(,) 마침표(.) 적절히 사용
3. 다른 목소리로 변경
4. 속도 0.9로 조절
```

### Q2. Vrew AI 이미지 품질이 낮습니다

```
해결방법:
1. 프롬프트를 영어로, 더 구체적으로
2. 여러 번 생성하여 최선 선택
3. Midjourney/DALL-E 외부 생성 후 삽입
```

### Q3. 영상이 3분보다 길거나 짧습니다

```
해결방법:
1. 각 장면 길이 조절 (드래그)
2. 나레이션 속도 조절
3. 장면 추가/삭제
4. 전환 효과 시간 조절
```

### Q4. 내보내기 시간이 너무 오래 걸립니다

```
해결방법:
1. 해상도 1080p로 먼저 테스트
2. 불필요한 프로그램 종료
3. SSD 저장 공간 확보
4. 야간에 내보내기 실행
```

### Q5. 자막이 TV에서 잘 안 보입니다

```
해결방법:
1. 폰트 크기 60pt 이상
2. 굵은 폰트 사용
3. 외곽선 또는 그림자 추가
4. 배경 박스 추가
```
