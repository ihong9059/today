# AI 품질 판정 프로세스 설명 동영상 시나리오

## 영상 정보
- **제목**: 폐배터리 재활용 공정의 AI 품질 판정 프로세스
- **부제**: AI는 어떻게 학습하고, 무엇을 최적화하는가?
- **대상**: 전시회 방문 고객 (공정 관련 의사결정자, 기술 담당자)
- **총 길이**: 약 10분
- **목표**: AI 학습의 현실적 범위와 적용 방법을 명확히 이해시킴

---

## Scene 1: 오프닝 (0:00 ~ 0:40)

### 화면 구성
- 폐배터리 재활용 공정 전체 조감도 (3D 렌더링 또는 실제 공정 영상)
- 타이틀 애니메이션: "AI 품질 판정 프로세스"
- 하단 자막: "AI는 정말 모든 것을 알아서 할 수 있을까요?"

### 핵심 메시지
- AI의 현실적인 역할과 한계를 명확히 이해
- 사람의 역할과 AI의 역할 구분

### 시각 요소
- 로봇 팔과 분석 장비가 함께 있는 이미지
- "사람 + AI = 최적화"를 표현하는 도식

---

## Scene 2: 공정 개요 - 폐배터리에서 블랙매스까지 (0:40 ~ 1:40)

### 화면 구성
- 공정 흐름도 애니메이션
  ```
  [폐배터리셀] → [1차 파쇄] → [2차 파분쇄] → [박리] → [블랙매스]
  ```
- 각 단계별 설비 이미지와 설명

### 핵심 메시지
- 폐배터리에서 유가금속(리튬, 코발트, 니켈 등)이 포함된 블랙매스를 추출
- 공정의 목표: **높은 회수율**과 **균일한 품질**의 블랙매스 생산

### 시각 요소
| 공정 단계 | 설비 | 산출물 |
|-----------|------|--------|
| 1차 파쇄 | 이축 전단 파쇄기 | 50~100mm 조각 |
| 2차 파분쇄 | 해머 크러셔 | 5~20mm 조각 |
| 박리 | 임팩트 밀 | 블랙매스 (분말) |

---

## Scene 3: 품질의 핵심 - 회수율과 성분 순도 (1:40 ~ 2:40)

### 화면 구성
- ICP 분석 장비 이미지
- 성분분석 결과표 (Li, Co, Ni, Mn, Cu, Al 함량)
- 회수율 계산 공식

### 핵심 메시지
- **회수율**: 투입된 유가금속 대비 실제로 회수된 비율
- **성분 순도**: 블랙매스 내 각 유가금속의 농도
- 이 값들은 **ICP(유도결합플라즈마) 분석기**로만 정확히 측정 가능

### 시각 요소
```
[블랙매스 샘플] → [ICP 분석기] → [성분분석 결과]
                                   ├── 리튬(Li): 6.8%
                                   ├── 코발트(Co): 12.5%
                                   ├── 니켈(Ni): 18.2%
                                   └── 회수율: 94.3%
```

### 강조점
> "이 화학적 분석은 **반드시 사람이** ICP 장비를 통해 수행해야 합니다.
> AI가 실시간으로 화학 성분을 측정할 수는 없습니다."

## 부록: 기술 용어 설명

| 용어 | 설명 |
|------|------|
| ICP (Inductively Coupled Plasma) | 유도결합플라즈마 분광분석, 원소 함량을 정밀 측정하는 화학 분석 방법 |
| 블랙매스 (Black Mass) | 폐배터리를 분쇄/박리한 후 얻어지는 유가금속 함유 분말 |
| D10, D50, D90 | 입도 분포의 누적 10%, 50%, 90% 지점의 입자 크기 |
| 회수율 | 투입 대비 회수된 유가금속의 비율 (%) |
| 설비조건 | 칼날 규격, 회전 속도, 투입 속도 등 기계적 파라미터 |
| 환경조건 | 온도, 습도, 압력 등 주변 환경 파라미터 |
