UTTEC (유티텍)

UTTEC은 산업 설비의 AI 기반 예지정비 솔루션을 제공하는 기술 기업입니다. Edge AI 기술과 빅데이터 분석을 통해 산업 현장의 설비 고장을 사전에 예측하고, 다운타임을 최소화하여 생산성을 극대화합니다.

2020년 설립 이래, 자동차 부품, 2차전지, 화학, 식품 등 다양한 산업 분야에서 AI 모니터링 시스템을 성공적으로 구축해왔습니다.

한국기계엔지니어링과의 협력을 통해 파쇄기, 분쇄기, 핀밀 등 산업용 분쇄설비에 특화된 AI 예지정비 솔루션을 제공합니다.

핵심 기술

UTTEC의 차별화된 기술력

🧠

Edge AI Gateway

현장에서 직접 AI 분석을 수행하는 Edge Computing 솔루션입니다. 네트워크 지연 없이 실시간 이상 감지가 가능하며, 데이터 보안이 필요한 산업 현장에 최적화되어 있습니다.

실시간 처리 오프라인 운영 데이터 보안
📊

Load Analysis

전력 데이터 기반 부하 분석 기술입니다. 모터 전류, 전압, 전력량을 분석하여 설비의 부하 상태를 실시간으로 모니터링하고 과부하를 방지합니다.

전류 분석 부하 패턴 과부하 예방
🤖

AI PdM (예지정비)

딥러닝 기반 예지정비 알고리즘입니다. 진동, 온도, 전류 데이터를 학습하여 베어링 마모, 날 손상 등 고장을 30일 전에 예측합니다.

딥러닝 RUL 예측 이상 탐지
☁️

Cloud Platform

AWS 기반 클라우드 플랫폼입니다. 다수의 설비 데이터를 통합 관리하고, 웹/모바일에서 언제 어디서나 모니터링이 가능합니다.

AWS 기반 통합 대시보드 모바일 지원
