AI 모델 학습 과정 (Training Process)

0.1 AI는 어떻게 "배우는가"?

AI가 고장을 예측하고 품질을 판정하려면 먼저 "정상 상태가 무엇인지"와 "이상 상태가 무엇인지"를 학습해야 합니다. 이 학습 과정은 시스템 도입 초기에 수행되며, 이후 지속적으로 개선됩니다.

0.2 1단계: 데이터 수집 (Data Collection)

AI 학습의 첫 번째 단계는 충분한 양의 고품질 데이터를 수집하는 것입니다. 최소 2~4주간의 정상 운전 데이터가 필요합니다.

📊

데이터 수집 상세

필수 단계

✓ 정상 상태 데이터

  • • 정상 운전 시 진동 패턴
  • • 정상 온도 범위 (40~55°C)
  • • 정상 전류 파형
  • • 정상 RPM 변동 범위
  • • 다양한 부하 조건 데이터
수집 기간: 최소 2주 (권장 4주)

✗ 이상 상태 데이터 (있는 경우)

  • • 과거 고장 발생 시 데이터
  • • 베어링 마모 진행 데이터
  • • 과부하 발생 시 패턴
  • • 정비 직전 상태 데이터
  • • 비정상 진동/온도 기록
※ 없어도 학습 가능 (비지도 학습)
💡

데이터 수집량 기준

센서당 약 100만 개 이상의 데이터 포인트 권장. 샘플링 주파수 1kHz 기준, 24시간 운전 시 약 8,600만 포인트 수집.

수집된 원시 데이터를 AI가 학습할 수 있는 형태로 가공합니다. 이 단계에서 데이터 품질이 AI 성능을 좌우합니다.

0.4 3단계: 모델 학습 (Model Training)

전처리된 데이터로 AI 모델을 훈련시킵니다. 비지도 학습과 지도 학습 두 가지 방식을 병행합니다.

🔄 비지도 학습 (Unsupervised)

정상 데이터만으로 학습 - 이상 데이터가 없어도 가능

LSTM Autoencoder
정상 패턴을 압축 → 복원하는 방식으로 학습.
이상 데이터는 복원이 잘 안 됨 → 이상 탐지
학습 원리:
1. 정상 진동 패턴 입력
2. Encoder가 핵심 특징 압축
3. Decoder가 원본 복원 시도
4. 복원 오차(Reconstruction Error) 최소화 학습
장점: 고장 데이터 없이 학습 가능

🎯 지도 학습 (Supervised)

정상/이상 라벨 데이터로 학습 - 더 정확한 분류 가능

CNN + LSTM 분류기
라벨링된 데이터로 정상/이상 분류 학습.
과거 고장 이력이 있으면 정확도 향상
학습 원리:
1. "정상" 라벨 데이터 입력 → 정상 예측
2. "이상" 라벨 데이터 입력 → 이상 예측
3. 예측과 실제 라벨 비교
4. 오차 줄이는 방향으로 가중치 조정
장점: 구체적 고장 유형 분류 가능

1.1 고장 예지의 목표

AI 고장 예지 시스템의 핵심 목표는 "고장이 발생하기 전에 미리 감지"하여 계획된 정비를 가능하게 하는 것입니다. 이를 통해 예기치 않은 다운타임을 방지하고, 정비 비용을 최적화합니다.

AI 분석 과정 (Timeline)

D-30일 (정상 상태)
기준선 데이터 수집

진동 1.2g, 온도 52°C, BPFO 피크 없음. AI가 정상 패턴을 학습 완료.

D-14일 (초기 이상 감지)
AI 조기 경보: "베어링 열화 시작 감지"

진동 1.8g (+50%), BPFO 피크 +5dB 출현. LSTM Autoencoder 재구성 오차 증가.
→ AI 판정: "주의 관찰 필요" (Yellow Alert)

D-7일 (열화 진행)
AI 경고: "베어링 교체 권고"

진동 2.8g (+133%), 온도 68°C, BPFO 피크 +15dB. RUL 예측: 168시간 (7일).
→ AI 판정: "1주 내 정비 필요" (Red Alert)

D-5일 (계획 정비)
계획된 베어링 교체 수행

운전 중지 예정 시간에 맞춰 베어링 교체 완료. 분해 결과 외륜에 피팅(Pitting) 확인.
→ 비계획 다운타임 0시간, 2차 손상 방지 성공

✅

예지 정비 효과

AI가 14일 전 이상을 감지하여 계획 정비 수행. 만약 고장 후 정비였다면 예상 다운타임 48시간, 긴급 부품 비용 3배 추가 발생.

3.4 통합 품질 관리 체계

📊 1단계: 실시간 모니터링

인라인 센서 + AI가 100% 생산물을 실시간 검사. 이상 발생 시 즉각 알림 및 자동 보정.

🔬 2단계: 샘플링 검증

배치당 FRITSCH 정밀 분석으로 인라인 데이터 검증. 품질 성적서 발급.

🔄 3단계: 지속적 개선

실측 데이터 축적 → AI 모델 재학습 → 정확도 향상의 선순환 구조.

4.1 두 가지 핵심 목표 달성

🔧 목표 1: 고장 예지

  • 방법: 진동, 온도, 전류 센서 데이터 AI 분석

  • 방법: 인라인 센서 + FRITSCH 정밀 분석 연계

  • 성과: 불량률 95% 감소, 100% 추적성 확보
  • 경제적 효과: 연간 원재료 손실 2천만원 절감
