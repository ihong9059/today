## 4. 일괄 생성 워크플로우

### Step 1: Midjourney 일괄 생성

```
1. Discord에서 Midjourney 봇 채널 접속
2. 프롬프트 하나씩 입력
3. 4개 변형 중 최적 이미지 선택 (U1~U4)
4. 업스케일 (U) 후 다운로드
5. 폴더별 정리
```

### Step 2: 파일 명명 규칙

```
A1_파쇄기_전경_v1.png
A2_파쇄기_측면_v1.png
B1_과부하_경고_v1.png
B2_블레이드_마모_v1.png
...
```

### Step 3: 영상 변환 순서

```
1. 정적 이미지 → Pika/Runway로 4초 영상화
2. 영상 클립 편집 소프트웨어로 임포트
3. 나레이션 타이밍에 맞춰 배치
4. 트랜지션 추가
5. 최종 렌더링
```
