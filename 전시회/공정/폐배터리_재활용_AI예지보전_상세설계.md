### 1.2 공정 단계별 목적

| 공정 | 장비 | 목적 | 산출물 |
|------|------|------|--------|
| 1단계 | 1차 파쇄기 (이축 전단 파쇄기) | 폐배터리를 50~100mm 크기로 1차 분쇄 | 대형 조각 |
| 2단계 | 2차 파분쇄기 (해머 크러셔) | 1차 파쇄물을 5~20mm 크기로 미세 분쇄 | 소형 조각 |

### 1.3 추출 대상 유가금속

- **리튬 (Li)**: 양극재 핵심 소재
- **코발트 (Co)**: 양극재 안정성 확보
- **니켈 (Ni)**: 에너지 밀도 향상
- **망간 (Mn)**: 구조 안정화
- **구리 (Cu)**: 음극 집전체
- **알루미늄 (Al)**: 양극 집전체

## 2. 1차 파쇄기 (Primary Shredder) 상세 설계

### 2.1 장비 사양

| 항목 | 사양 |
|------|------|
| 장비 유형 | 이축 전단 파쇄기 (Twin-Shaft Shear Shredder) |
| 모터 출력 | 2 x 55kW (총 110kW) |
| 회전 속도 | 15~25 RPM (저속 고토크) |
| 파쇄 크기 | 50~100mm |
| 처리 용량 | 2~3 ton/hour |
| 투입구 크기 | 1,200 x 800mm |


### 2.4 AI 예지보전 기능

#### 2.4.1 이상 탐지 알고리즘

| 기능 | 입력 데이터 | 알고리즘 | 출력 | 임계값 |
|------|-----------|----------|------|--------|
| 베어링 이상 탐지 | VIB-1A/1B FFT 스펙트럼 | Envelope Analysis + LSTM | 이상 확률 (0~100%) | 경고: 70%, 위험: 90% |
| 축 불균형 감지 | VIB 1X 성분 분석 | Order Analysis | 불균형 레벨 (mm/s) | 경고: 4.5mm/s, 위험: 7.1mm/s |
| 과부하 예측 | CUR-1A/1B 패턴 | Moving Average + 임계값 | 과부하 위험도 | 정격의 120% |
| 발화 위험 감지 | TMP-1C 급상승률 | Rate of Change | 발화 경보 | 10°C/s 이상 |
| 칼날 마모 감지 | CUR + VIB 복합 | Fusion ML Model | 잔여 수명 (시간) | 100시간 미만 교체 권고 |

### 2.5 주요 고장 모드 및 감지 방법

| 고장 모드 | 증상 | 감지 센서 | 감지 방법 | 조치 사항 |
|----------|------|----------|----------|----------|

## 4. 박리기 (Separator/Impact Mill) 상세 설계

### 4.1 장비 사양

| 항목 | 사양 |
|------|------|
| 장비 유형 | 핀밀 / 임팩트 밀 (Pin Mill / Impact Mill) |
| 모터 출력 | 45kW |
| 회전 속도 | 3000~6000 RPM (초고속) |
| 처리 목적 | 조각 표면 유가금속 박리 |
| 처리 용량 | 0.5~1 ton/hour |
| 핀 배열 | 고정핀 + 회전핀 복합 |

### 4.2 센서 구성

## 부록 C. 용어 정의

| 용어 | 정의 |
|------|------|
| RUL (Remaining Useful Life) | 잔여수명, 장비가 고장 나기까지 남은 예상 시간 |
| BPFO (Ball Pass Frequency Outer) | 베어링 외륜 결함 주파수 |
| BPFI (Ball Pass Frequency Inner) | 베어링 내륜 결함 주파수 |
| GMF (Gear Mesh Frequency) | 기어 맞물림 주파수 |
| FFT (Fast Fourier Transform) | 고속 푸리에 변환, 시간 영역→주파수 영역 변환 |
| 1X, 2X | 회전 주파수의 1배, 2배 성분 |
| Envelope Analysis | 엔벨로프 분석, 베어링 결함 주파수 추출 기법 |
| ISO 10816 | 기계 진동 평가 국제 표준 |
