활용 시나리오

1. 문제점 추이 분석

월별 이슈 발생 건수, 위치별 분포, 이슈 유형 분류를 통해 빈발하는 문제점을 도출하고 예방 대책을 수립합니다.

2. 시스템 상태 추적

장비별 점검 이력, 교체 주기 분석, 사진을 통한 시각적 변화 추적으로 예방 정비 계획을 수립합니다.

3. 영업 활동 지원

고객별 방문 이력, 이슈 해결 실적을 바탕으로 서비스 품질을 입증하고 데이터 기반의 개선 방안을 제시합니다.

주요 API

POST /api/data
// 데이터 제출 (multipart/form-data)
- device_id: 기기 식별자
- title: 제목
- category: 카테고리 (store/facility/equipment/issue/other)
- content: 내용
- photo: 사진 파일
- latitude, longitude: GPS 좌표
GET /api/data?keyword=&category=&device_id=
// 데이터 조회 (JSON 응답)
- keyword: 검색어
- category: 카테고리 필터
- device_id: 기기 필터
- limit: 조회 개수 (기본 100)
