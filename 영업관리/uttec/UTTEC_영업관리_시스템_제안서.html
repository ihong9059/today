1. 도입 배경

현재 문제점

  • 방문 기록이 개인별로 관리되어 공유가 어려움
  • 거래처 방문 이력 추적이 체계적이지 않음
  • GPS 기반 위치 정보가 없어 방문 현황 파악 어려움
  • 현장 사진 등 시각적 자료가 기록되지 않음
  • 영업사원 활동 현황 실시간 모니터링 불가

시스템 도입 효과

목적기대 효과
방문 기록 체계화모든 현장 활동이 GPS 위치, 사진, 텍스트로 기록됨
거래처 관리 강화거래처별 방문 이력 및 담당자 정보 통합 관리
영업 활동 모니터링영업사원별 방문 현황 실시간 파악
데이터 기반 의사결정축적된 데이터를 기반으로 영업 전략 수립

4. 사용 방법

접속 URL

관리자 대시보드: http://178.128.90.37:91
모바일 웹 (영업사원용): http://178.128.90.37:91/mobile/

모바일 웹 접속 방법

  1. 스마트폰 브라우저(Chrome, Safari) 실행
  2. 주소창에 http://178.128.90.37:91/mobile/ 입력
  3. 위치 권한 허용
  4. 설정 탭에서 영업사원명 입력
  5. 방문등록 탭에서 방문 기록 입력

홈 화면에 앱처럼 추가

iPhone (Safari)

  1. 공유 버튼(□↑) 탭
  2. "홈 화면에 추가" 선택
  3. "추가" 탭

Android (Chrome)

  1. 메뉴(⋮) 탭
  2. "홈 화면에 추가" 선택
  3. "추가" 탭

5. 방문 기록 입력 절차

  1. 앱/웹 실행 - GPS 정보가 자동으로 수집되어 화면 상단에 표시됩니다
  2. 설정 탭에서 영업사원 이름 입력 - 본인 이름 입력 (예: 홍길동)
  3. 방문등록 탭으로 이동
  4. 방문 유형 선택 - 영업/납품/AS/수금/미팅/기타 중 선택
  5. 거래처 정보 입력 - 거래처명, 담당자, 연락처
  6. 방문 내용 입력 - 상담 내용, 후속 조치 등
  7. 다음 방문 예정일 선택 (선택사항)
  8. 사진 촬영 (선택사항) - 현장 사진 촬영 또는 선택
  9. "방문 기록 저장" 버튼 클릭 - 서버로 데이터 전송
