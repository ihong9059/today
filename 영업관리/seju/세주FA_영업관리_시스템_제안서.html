* 주요 기능

1

방문 기록 입력

  • GPS 위치 자동 수집 및 표시

  • 6가지 방문 유형 선택

활용 시나리오

1. 영업 활동 분석

영업사원별 일/주/월 방문 건수, 방문 유형별 분포, 지역별 영업 현황을 분석하여 영업 전략을 수립합니다.

2. 거래처 관리

거래처별 방문 이력, 담당자 정보, 방문 주기를 관리하여 체계적인 고객 관계 관리(CRM)를 실현합니다.

3. 성과 지표 관리

방문 효율성, 거래처 확보율, AS 대응 시간 등 핵심 성과 지표(KPI)를 관리합니다.

주요 API

POST /api/visit
// 방문 기록 저장 (multipart/form-data)
- device_id: 기기 식별자
- sales_name: 영업사원명
- customer_name: 거래처명
- contact_person: 담당자
- contact_phone: 연락처
- visit_type: 방문 유형 (sales/delivery/service/collect/meeting/other)
- notes: 방문 내용
- next_visit_date: 다음 방문일
- latitude, longitude: GPS 좌표
- photo: 사진 파일
GET /api/visit?keyword=&visit_type=&device_id=
// 방문 기록 조회 (JSON 응답)
- keyword: 검색어 (거래처명, 메모)
- visit_type: 방문 유형 필터
- device_id: 기기 필터
- start_date, end_date: 기간 필터
GET /api/stats
// 통계 조회 (JSON 응답)
- total: 전체 방문 수
- today: 오늘 방문 수
- week: 주간 방문 수
- month: 월간 방문 수
- customers: 거래처 수
- byType: 유형별 현황
