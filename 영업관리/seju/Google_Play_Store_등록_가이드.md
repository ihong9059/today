## 1. 개요

### 1.1 Play Store 등록이란?

Google Play Store에 앱을 등록하면:
- 전 세계 Android 사용자가 앱을 검색하고 설치 가능
- 자동 업데이트 기능 제공
- 앱의 신뢰성 향상 (Google 검증)
- 설치 통계 및 사용자 피드백 확인 가능

### 1.2 등록 요약

| 항목 | 내용 |
|:-----|:-----|
| 소요 비용 | $25 (약 33,000원, 1회성) |
| 소요 시간 | 준비 1~2일 + 검토 1~3일 |
| 필요 계정 | Google 계정 |
| 검토 기간 | 신규 앱 1~3일, 업데이트 수 시간 |

### 1.3 세주FA 앱 현황

| 항목 | 상태 | 비고 |
|:-----|:-----|:-----|
| 패키지명 | com.seju.sales | 변경 불가 |
| 버전 코드 | 1 | 업데이트 시 증가 필요 |
| 버전명 | 1.0 | 사용자에게 표시 |
| 서명 키 | seju-release-key.jks | **분실 시 업데이트 불가** |
| Release APK | SejuSales-v1.0.apk | 완료 |

## 2. 사전 준비 사항

### 2.1 필수 준비물 체크리스트

| 항목 | 필수 | 상태 | 설명 |
|:-----|:----:|:----:|:-----|
| Google 계정 | O | - | Play Console 가입용 |
| 신용카드/체크카드 | O | - | $25 결제용 |
| 서명된 AAB/APK | O | ✅ | Release 빌드 완료 |
| 앱 아이콘 (512x512) | O | ✅ | PNG 형식 |
| 그래픽 이미지 (1024x500) | O | - | 스토어 배너 |
| 스크린샷 (최소 2장) | O | - | 폰/태블릿 별도 |
| 개인정보처리방침 URL | O | - | 위치/카메라 권한 사용 시 필수 |
| 앱 설명문 | O | - | 한글 작성 |

### 2.2 앱 아이콘 규격

```
필수 아이콘:
- 512 x 512 픽셀
- PNG 형식 (32비트, 알파 채널 포함 가능)
- 최대 1MB

현재 상태:
- seju/android-app/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png 존재
- 512x512 버전 별도 생성 필요
```

### 2.3 그래픽 이미지 (Feature Graphic)

```
규격:
- 1024 x 500 픽셀
- PNG 또는 JPG
- 스토어 상단에 표시되는 배너 이미지

내용 권장:
- 앱 로고 + 앱 이름
- 주요 기능 키워드
- 브랜드 색상 (파란색 #1976D2) 활용
```

### 2.4 스크린샷 규격

```
폰 스크린샷:
- 최소 2장, 최대 8장
- 권장 해상도: 1080 x 1920 (16:9) 또는 1080 x 2340 (19.5:9)
- PNG 또는 JPG
- 앱 화면 캡처 (방문등록, 조회, 설정 화면 등)

태블릿 스크린샷 (선택):
- 7인치: 1200 x 1920 권장
- 10인치: 1600 x 2560 권장

촬영 권장 화면:
1. 방문 등록 화면 (GPS 표시)
2. 방문 유형 선택 화면
3. 조회/검색 화면
4. 상세 정보 모달
5. 설정 화면
```

### 2.5 개인정보처리방침

앱이 위치, 카메라, 저장소 권한을 사용하므로 **개인정보처리방침 필수**입니다.

```
필요 내용:
1. 수집하는 개인정보 항목
   - 위치 정보 (GPS)
   - 사진/이미지
   - 기기 식별자

2. 수집 목적
   - 방문 위치 기록
   - 현장 사진 첨부
   - 기기별 데이터 구분

3. 보관 기간 및 파기 방법

4. 제3자 제공 여부

5. 이용자 권리 (열람, 정정, 삭제 요청)

6. 연락처 (문의처)
```

## 3. Google Play Console 가입

### 3.1 가입 절차

#### Step 1: Play Console 접속
```
https://play.google.com/console
```

#### Step 2: Google 계정 로그인
- 기존 Google 계정 사용 또는 새로 생성
- 회사 대표 계정 사용 권장 (개인 계정도 가능)

#### Step 3: 개발자 계정 만들기

1. **"Google Play 개발자 계정 만들기"** 클릭

2. **개발자 계정 유형 선택**
   - 개인: 본인 명의
   - 조직: 회사/단체 명의 (사업자등록증 필요할 수 있음)

3. **개발자 이름 입력**
   ```
   예: 세주FA
   예: (주)세주에프에이
   ```
   - 스토어에 "개발자" 이름으로 표시됨

4. **연락처 정보 입력**
   - 이메일 주소 (필수, 공개됨)
   - 전화번호 (필수, 비공개)
   - 웹사이트 (선택)

#### Step 4: 등록비 결제

```
금액: $25 USD (약 33,000원)
결제 수단: 신용카드, 체크카드
특징: 1회성 비용 (연간 비용 없음)
```

#### Step 5: 본인 인증
- 이메일 인증
- 전화번호 인증 (SMS)

#### Step 6: 가입 완료
- 가입 완료 후 Play Console 대시보드 접속 가능
- 바로 앱 등록 시작 가능

### 3.2 계정 정보 예시

```
개발자 이름: 세주FA
이메일: contact@sejufa.co.kr
전화번호: 031-XXX-XXXX
웹사이트: http://sejufa.co.kr
```

## 7. AAB 파일 빌드

### 7.1 AAB vs APK

| 항목 | AAB (App Bundle) | APK |
|:-----|:-----------------|:----|
| 권장 여부 | **권장 (필수화 예정)** | 가능하나 비권장 |
| 파일 크기 | 작음 (기기별 최적화) | 큼 (모든 리소스 포함) |
| Play 서명 | Google이 서명 | 개발자가 서명 |

### 7.2 AAB 빌드 방법

#### 방법 1: Android Studio 사용

```
1. Android Studio에서 프로젝트 열기
   - seju/android-app/ 폴더

2. Build > Generate Signed Bundle / APK 선택

3. Android App Bundle 선택 > Next

4. Key store 설정
   - Key store path: seju/android-app/seju-release-key.jks
   - Key store password: [설정한 비밀번호]
   - Key alias: seju-release
   - Key password: [설정한 비밀번호]

5. Build Variants: release 선택

6. Finish 클릭

7. 결과 파일:
   app/build/outputs/bundle/release/app-release.aab
```

#### 방법 2: 명령줄 사용

```bash
cd seju/android-app

# AAB 빌드
./gradlew bundleRelease

# 결과 파일 위치
ls -la app/build/outputs/bundle/release/
# app-release.aab
```

### 7.3 서명 키 정보

```
⚠️ 중요: 서명 키 분실 시 앱 업데이트 불가!

키 파일: seju/android-app/seju-release-key.jks
키 별칭: seju-release
유효기간: 10000일 (약 27년)

백업 권장:
- 안전한 곳에 키 파일 백업
- 비밀번호 별도 기록 보관
```

### 7.4 버전 관리

업데이트 시 반드시 버전 코드 증가 필요:

```gradle
// app/build.gradle
android {
    defaultConfig {
        versionCode 2        // 반드시 증가 (1 → 2 → 3...)
        versionName "1.1"    // 사용자에게 표시
    }
}
```

## 8. 앱 출시

### 8.1 출시 트랙 종류

| 트랙 | 설명 | 사용 시기 |
|:-----|:-----|:---------|
| 내부 테스트 | 최대 100명, 즉시 배포 | 개발팀 테스트 |
| 비공개 테스트 | 이메일로 초대, 검토 필요 | 베타 테스트 |
| 공개 테스트 | 누구나 참여 가능 | 공개 베타 |
| **프로덕션** | 전체 공개 | **정식 출시** |

### 8.2 내부 테스트 (권장 첫 단계)

#### Step 1: 테스터 추가
```
Play Console > 테스트 > 내부 테스트 > 테스터 탭

이메일 목록 만들기:
- 테스터 이메일 주소 추가 (최대 100명)
- 예: tester1@gmail.com, tester2@gmail.com
```

#### Step 2: 릴리스 만들기
```
Play Console > 테스트 > 내부 테스트 > 릴리스 탭

1. "새 릴리스 만들기" 클릭
2. App Bundle 업로드 (app-release.aab)

```

```
   ./gradlew bundleRelease
```

```
Play Console > 통계

확인 가능 항목:
- 설치 수 / 제거 수
- 활성 사용자 수
- 평점 및 리뷰
- 충돌 및 ANR 보고서
```

```
Play Console > 평점 및 리뷰

```

```
Play Console > 품질 > Android vitals

- 문제 원인 분석 및 수정
```

## 10. 문제 해결

### 10.1 검토 거부 사유 및 해결

#### 사유 1: 개인정보처리방침 누락
```
문제: 위치/카메라 권한 사용 앱은 개인정보처리방침 필수
해결: 개인정보처리방침 URL 등록
```

#### 사유 2: 메타데이터 정책 위반
```
문제: 앱 이름/설명에 키워드 남용, 이모지 과다 사용
해결: 간결하고 정확한 설명으로 수정
```

#### 사유 3: 기능 불완전
```
문제: 앱이 정상 작동하지 않음 (서버 연결 실패 등)
해결: 서버 상태 확인, 테스트 후 재제출
```

#### 사유 4: 권한 과다 요청
```
문제: 불필요한 권한 요청
해결: 필요한 권한만 요청, 권한 사용 이유 명시
```

#### Q1: 개발자 등록비는 환불되나요?
```
A: 아니요, $25는 환불 불가합니다.
```

#### Q2: 앱 이름을 변경할 수 있나요?
```

   단, 패키지명(com.seju.sales)은 변경 불가.

```

```
   그렇지 않으면 새 앱으로 등록해야 함.
```

```
   프로덕션 > 국가/지역 탭에서 설정.
   예: 한국만 선택
```
