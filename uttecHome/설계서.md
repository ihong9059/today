## 1. 프로젝트 개요

### 1.1 목적

UTTEC의 40년 임베디드/IoT 기술력을 기반으로 AI 시대에 맞는 새로운 사업 방향을 반영한 기업 홈페이지를 구축합니다.

### 1.2 핵심 목표

| 목표 | 설명 |
|:-----|:-----|
| **브랜드 리포지셔닝** | 기존 임베디드 전문 → AI·IoT 솔루션 기업으로 이미지 전환 |
| **사업 영역 통합 소개** | 4대 사업 영역을 체계적으로 소개 |
| **데모 사이트 연결** | 기 구축된 서비스들과 유기적 연결 |
| **2026 디자인 트렌드 반영** | 최신 웹디자인 트렌드 적용 |

### 1.3 타겟 고객

```
┌─────────────────────────────────────────────────────────────┐
│                      UTTEC 타겟 고객                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  B2B (기업)           B2C (개인)           B2G (정부)       │
│  ───────────         ───────────         ───────────       │
│  • 중소 제조업        • 취업 준비생         • 스마트공장     │
│  • 농업 법인          • 자격증 준비생       • 스마트팜       │
│  • 설비 유지보수      • 코딩/AI 교육 수강생  • 디지털 교육    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 현재 보유 자산 분석

### 2.1 기술력 (인력)

| 담당자 | 경력 | 핵심 역량 |

| **임호균 이사** | 38년 | CPU/프로세서, H/W 설계, Modbus/CAN, RTOS/Linux |

### 2.2 기 구축된 서비스 (192.168.0.32)

| 포트 | 서비스 | 상태 | 기술 스택 |

## 6. 기술 스택

### 6.1 프론트엔드

| 구분 | 기술 | 선정 이유 |
|:-----|:-----|:----------|
| **Framework** | Next.js 14 (App Router) | 기존 프로젝트와 일관성, SSG/SSR 지원 |
| **Language** | TypeScript | 타입 안정성, 유지보수성 |
| **Styling** | Tailwind CSS | 빠른 개발, 일관된 디자인 시스템 |
| **Animation** | Framer Motion | 마이크로 애니메이션, 페이지 전환 |
| **Icons** | Lucide React | 가볍고 일관된 아이콘 |

### 6.2 백엔드

| 구분 | 기술 | 선정 이유 |
|:-----|:-----|:----------|
| **Runtime** | Node.js 20.x | Next.js API Routes 활용 |
| **Database** | SQLite / PostgreSQL | 문의 폼 저장, 블로그 콘텐츠 |
| **CMS** | Markdown 파일 기반 | 블로그/뉴스 관리 용이 |

### 6.3 배포

| 구분 | 기술 | 비고 |
|:-----|:-----|:-----|
| **Server** | Raspberry Pi 5 (192.168.0.32) | 내부 테스트용 |
| **Production** | AWS EC2 / DigitalOcean | 실 서비스용 |
| **Process** | PM2 | 프로세스 관리 |
| **SSL** | Let's Encrypt | HTTPS |
| **Domain** | uttec.co.kr | 기존 도메인 활용 |
