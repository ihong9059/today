## 데이터 다운로드 방법

### KOSIS에서 시군별 데이터 다운로드
1. https://kosis.kr 접속
2. "시군별 논벼 생산량" 검색
3. 원하는 연도, 지역 선택
4. 엑셀 다운로드 버튼 클릭

### 통계청 보도자료에서 다운로드
1. 보도자료 페이지 접속
2. 첨부파일 (PDF, HWP, HWPX) 다운로드
3. 시도별, 연도별 표 데이터 확인

### 공공데이터포털에서 다운로드
1. data.go.kr 접속
2. "쌀 생산량" 검색
3. 원하는 데이터셋 선택
4. CSV 파일 다운로드
