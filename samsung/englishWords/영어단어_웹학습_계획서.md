# 영어 단어 웹 학습 시스템 계획서

## 재미있고 효과적인 영어 어휘 학습 플랫폼

---

## 1. 프로젝트 개요

### 1.1 목표
- 초등학교 ~ 고등학교 학생들이 **지루하지 않고 재미있게** 영어 단어를 학습
- 게이미피케이션(Gamification)을 활용한 몰입도 높은 학습 경험 제공
- 3,000개 필수 어휘를 단계별로 자연스럽게 습득

### 1.2 대상 사용자
| 대상 | 어휘 목표 | 특징 |
|------|----------|------|
| 초등학생 (3-6학년) | 800개 | 시각적, 게임 중심 |
| 중학생 | 2,000개 | 경쟁, 성취감 중심 |
| 고등학생 | 3,000개 | 효율성, 목표 달성 중심 |

---

## 2. 핵심 게이미피케이션 요소

### 2.1 보상 시스템 (Reward System)

```
┌─────────────────────────────────────────────────┐
│  🌟 경험치(XP)  →  📊 레벨업  →  🏆 배지 획득  │
└─────────────────────────────────────────────────┘
```

| 요소 | 설명 | 효과 |
|------|------|------|
| **포인트 (Points)** | 문제 정답 시 획득 | 즉각적 보상감 |
| **레벨 (Levels)** | XP 누적으로 레벨업 | 성장 실감 |
| **배지 (Badges)** | 특별 업적 달성 시 | 수집 욕구 자극 |
| **스트릭 (Streaks)** | 연속 학습일 | 습관 형성 |
| **코인 (Coins)** | 아바타/테마 구매용 | 커스터마이징 |

### 2.2 진행 시각화 (Progress Visualization)

```
오늘의 목표: ████████░░ 80% (16/20 단어)

이번 주 학습:
월 ✅  화 ✅  수 ✅  목 🔥  금 ⬜  토 ⬜  일 ⬜

전체 진행률: ███░░░░░░░ 32% (256/800 단어)
```

## 3. 학습 모드 설계

### 3.1 메인 학습 모드

#### 🎮 모드 1: 플래시카드 (기본 암기)
- 단어 카드 넘기기
- 발음 듣기 (TTS)
- 예문 보기
- 모르는 단어 표시

#### 🎯 모드 2: 퀴즈 챌린지
| 유형 | 설명 | 난이도 |
|------|------|--------|
| 4지선다 | 뜻 고르기 | ⭐ |
| 빈칸 채우기 | 철자 입력 | ⭐⭐ |
| 듣고 고르기 | 발음 듣고 선택 | ⭐⭐ |
| 영작하기 | 문장 완성 | ⭐⭐⭐ |

#### ⚔️ 모드 3: 배틀 모드
- 실시간 1:1 대결
- 친구와 대결
- 랜덤 매칭
- 승리 시 보너스 XP

#### 🏃 모드 4: 타임어택
- 60초 안에 최대한 많이 맞추기
- 콤보 시스템 (연속 정답 시 보너스)
- 일일/주간 랭킹

#### 🎲 모드 5: 미니게임
| 게임 | 설명 |
|------|------|
| **단어 매칭** | 영어-한글 짝 맞추기 (Memory Game) |
| **행맨** | 글자 맞추기 |
| **크로스워드** | 가로세로 퍼즐 |
| **워드 서치** | 숨은 단어 찾기 |
| **스피드 타이핑** | 빠르게 타이핑 |

## 4. 학습 효과 극대화 전략

### 4.1 간격 반복 학습 (Spaced Repetition)

```
처음 학습 → 1일 후 → 3일 후 → 7일 후 → 14일 후 → 30일 후
    ↓          ↓         ↓         ↓          ↓          ↓
  [새단어]   [복습1]   [복습2]   [복습3]    [복습4]    [장기기억]
```

### 4.2 적응형 학습 (Adaptive Learning)
- 틀린 문제 자동 재출제
- 약한 유형 집중 학습
- 개인별 난이도 조절

### 4.3 멀티미디어 활용
| 요소 | 활용 |
|------|------|
| 🔊 발음 | 원어민 TTS 또는 녹음 |
| 🖼️ 이미지 | 단어 연상 그림 |
| 🎬 GIF/애니메이션 | 동작 동사 시각화 |
| 📝 예문 | 실제 사용 문맥 |

## 5. 동기부여 시스템

### 5.1 일일 미션 (Daily Quests)
```
📋 오늘의 미션
├── ✅ 새 단어 10개 학습하기 (+50 XP)
├── ⬜ 복습 퀴즈 완료하기 (+30 XP)
├── ⬜ 타임어택 도전하기 (+20 XP)
└── ⬜ 친구와 배틀 1회 (+40 XP)
```

### 5.2 주간/월간 챌린지
- 7일 연속 학습 → 특별 배지
- 100단어 마스터 → 레어 아이템
- 월간 랭킹 TOP 10 → 명예의 전당

### 5.3 소셜 기능
| 기능 | 설명 |
|------|------|
| **친구 추가** | 함께 학습하는 친구 |
| **리더보드** | 주간/월간 순위 |
| **클래스** | 학급/학원 단위 그룹 |
| **응원하기** | 친구에게 응원 보내기 |

## 6. UI/UX 설계 원칙

### 6.1 연령별 테마
| 대상 | 테마 | 캐릭터 |
|------|------|--------|
| 초등 저학년 | 동물 농장 | 귀여운 동물 |
| 초등 고학년 | 우주 탐험 | 우주비행사 |
| 중학생 | 판타지 RPG | 영웅 캐릭터 |
| 고등학생 | 심플 모던 | 미니멀 디자인 |

### 6.2 핵심 UX 원칙
1. **3초 규칙**: 모든 액션은 3초 이내 반응
2. **원터치 학습**: 시작까지 최대 2번 터치
3. **즉각 피드백**: 정답/오답 즉시 표시
4. **부드러운 애니메이션**: 전환 효과로 몰입감

## 7. 기술 스택 (권장)

### 7.1 프론트엔드
```
HTML5 + CSS3 + JavaScript
├── React.js 또는 Vue.js (SPA)
├── Tailwind CSS (스타일링)
├── Howler.js (오디오)
└── Lottie (애니메이션)
```

### 7.2 백엔드
```
Node.js + Express.js
├── MongoDB (사용자 데이터)
├── Redis (세션, 랭킹)
└── Socket.io (실시간 대결)
```

### 7.3 추가 서비스
- Web Speech API (TTS)
- PWA (모바일 앱처럼 사용)
- Push Notifications (학습 알림)
