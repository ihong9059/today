# 대진표 생성기 (일반 버전)

## 설명
샘플 데이터로 테스트 가능한 일반용 대진표 생성 웹 애플리케이션

## 포트
7001

## 주요 기능
- 샘플 데이터 자동 생성 (인원수, 남녀 비율 입력)
- 라운드별 대진표 표시
- 실력 균형 매칭
- 경기 통계 표시

## 파일 구조
```
scheduler-general/
├── app.py          # Flask 서버 메인
├── scheduler.py    # 대진표 생성 알고리즘
└── templates/      # HTML 템플릿
```

## 실행
```bash
python app.py
```

## 샘플 데이터 사용법
1. 총 인원수 입력 (8~100명)
2. 남성 비율 입력 (30~90%)
3. "샘플 데이터 생성" 클릭
