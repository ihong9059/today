배드민턴 대진표 생성기 사용 설명서

1. 개요

이 시스템은 배드민턴 동호회의 청백전 대진표를 자동으로 생성합니다. 선수 이름, 등급, 성별을 입력하면 자동으로 경기를 배정합니다. 인원에 따라 경기 수가 자동으로 조절됩니다.

2. 선수 입력 방법

항목 설명
팀 구분 청팀과 백팀으로 나누어 입력합니다
등급 A~E등급으로 실력을 구분합니다 (A가 가장 높음)
성별 남/여로 구분하여 각각 입력합니다
이름 입력 쉼표(,)로 구분하여 여러 명을 입력합니다
예: 홍길동, 김철수, 박영희

3. 경기 종류

종류 코드 색상 설명
남자복식 MD 파란색 남자 2명 vs 남자 2명
여자복식 WD 빨간색 여자 2명 vs 여자 2명
혼합복식 XD 보라색 남녀 1명씩 vs 남녀 1명씩

4. 대진표 규칙

  • 모든 경기는 청팀 vs 백팀으로 진행됩니다
  • 같은 팀끼리 파트너가 됩니다 (청+청 vs 백+백)
  • 각 라운드에 6개 코트에서 동시에 경기가 진행됩니다
  • 같은 라운드에 같은 선수가 중복 배정되지 않습니다
  • 연속 라운드 경기를 피하도록 조정됩니다
  • 인원에 따라 경기 수가 자동 조절됩니다 (최소 3경기)
  • 가능한 한 같은 파트너/상대와 중복되지 않도록 합니다
  • 비슷한 등급끼리 경기하도록 조정됩니다
  • 최소 8명 이상이 필요합니다

5. 버튼 설명

버튼 기능
샘플 데이터 생성 총 인원과 남자 비율을 설정하고 테스트용 샘플 선수를 자동 생성합니다
대진표 생성 입력된 선수 정보로 대진표를 생성합니다
대진표 재생성 동일한 선수로 새로운 대진표를 생성합니다

6. 화면 구성

탭 설명
라운드별 대진표 라운드별로 6개 코트에서 동시 진행되는 경기를 보여줍니다
선수 목록 팀/등급별로 선수와 경기 수를 보여줍니다
통계 경기 종류별, 코트별, 라운드별 통계를 확인할 수 있습니다

선수 이름을 클릭하면 해당 선수의 전체 경기 목록을 확인할 수 있습니다.

총 인원 1인당 경기 수
