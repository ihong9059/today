1. 프로젝트 개요

1.1 배경

약 50명 규모의 배드민턴 동호회 운영을 위한 통합 웹 플랫폼 구축이 필요합니다. 현재 카카오톡, 밴드 등 분산된 채널에서 이루어지는 소통을 일원화하고, 청백전 대진표 생성 등 동호회 특화 기능을 제공하여 효율적인 동호회 운영을 지원합니다.

1.2 대상 사용자

  • 일반 회원: 동호회 활동 참여, 사진 열람, 게시판 이용
  • 운영진: 회원 관리, 일정 관리, 대진표 생성, 공지 작성
  • 관리자: 전체 시스템 관리, 권한 설정

1.3 기대 효과

  • 동호회 정보의 중앙 집중화로 소통 효율성 향상
  • 청백전 대진표 자동 생성으로 운영 부담 감소
  • 사진/영상 아카이브를 통한 추억 보존
  • 회원 관리 및 출석 현황 파악 용이

2. 목표 및 범위

2.1 핵심 목표

구분 목표 우선순위
커뮤니티 회원 간 원활한 소통 및 정보 공유 높음
대진표 청백전 대진표 자동 생성 및 관리 높음
갤러리 사진/영상 업로드 및 공유 높음
일정관리 정기 모임 및 이벤트 일정 관리 중간
회원관리 회원 정보 및 등급 관리 중간

2.2 범위

1차 범위 (MVP)

  • 회원 가입/로그인 (소셜 로그인 포함)
  • 게시판 (공지사항, 자유게시판)
  • 사진 갤러리
  • 대진표 생성 (기존 기능 통합)
  • 회원 목록 및 프로필

2차 범위 (확장)

  • 일정/출석 관리
  • 실시간 채팅
  • 경기 기록 및 통계
  • 모바일 앱 (PWA)

3. 주요 기능

회원 관리

동호회 회원 정보를 체계적으로 관리

  • 회원 가입/탈퇴
  • 프로필 관리 (사진, 소개, 연락처)
  • 실력 등급 관리 (A~E)
  • 가입일, 출석률 표시
  • 권한 관리 (회원/운영진/관리자)

게시판

다양한 주제의 게시판 운영

  • 공지사항 (운영진 전용 작성)
  • 자유게시판
  • 가입인사
  • 건의사항
  • 댓글 및 좋아요
  • 이미지/파일 첨부

사진 갤러리

동호회 활동 사진 아카이브

  • 앨범별 사진 분류
  • 다중 사진 업로드
  • 사진 뷰어 (슬라이드쇼)
  • 날짜/이벤트별 정렬
  • 사진 다운로드
  • 댓글 기능

대진표 생성

청백전 대진표 자동 생성 (기존 기능)

  • 참가자 선택/입력
  • 자동 팀 배정 (청/백)
  • 남복/여복/혼복 자동 편성
  • 라운드별 경기 배정
  • 대진표 저장/불러오기
  • PDF/이미지 내보내기

일정 관리

동호회 일정 및 출석 관리

  • 정기 운동 일정
  • 특별 이벤트 (대회, 번개)
  • 참석 여부 투표
  • 출석 체크
  • 캘린더 뷰
  • 알림 기능

알림/소통

회원 간 소통 기능

  • 새 글/댓글 알림
  • 일정 알림
  • 쪽지 기능
  • 이메일 알림 (선택)
  • 푸시 알림 (PWA)

6. 화면 구성

6.1 주요 화면 목록

화면 URL 설명 접근 권한
메인 (홈) / 동호회 소개, 최근 소식, 다가오는 일정 전체
로그인 /login 로그인 폼, 소셜 로그인 비회원
회원가입 /register 가입 폼 (승인 필요) 비회원

앨범 상세 /gallery/{id} 사진 그리드, 뷰어 회원
일정 /schedule 캘린더, 일정 목록 회원
대진표 /match 대진표 생성/관리 회원
관리자 /admin 회원 승인, 설정 관리 관리자

7. 기술 스택

7.1 프론트엔드

HTML5 CSS3 JavaScript (ES6+) Vue.js 3 (선택) Bootstrap 5 / Tailwind CSS

7.2 백엔드

Python 3.10+ Flask Flask-Login Flask-SQLAlchemy Flask-WTF Jinja2

7.3 데이터베이스

SQLite (개발) PostgreSQL (운영)

7.4 인프라

Linux (Ubuntu) Nginx Gunicorn Docker (선택) DigitalOcean / AWS

7.5 기타

Git / GitHub Pillow (이미지 처리) WeasyPrint (PDF 생성)

8. 보안 및 인증

8.1 인증 방식

  • 세션 기반 인증: Flask-Login을 활용한 세션 관리
  • 소셜 로그인: 카카오, 네이버 OAuth 연동 (선택)
  • 비밀번호: bcrypt 해싱

8.2 권한 관리

권한 설명 가능한 작업
비회원 미로그인 사용자 메인 페이지 열람, 회원가입
회원 (member) 승인된 일반 회원 게시판/갤러리 이용, 댓글 작성, 일정 확인
운영진 (staff) 동호회 운영진 공지 작성, 일정 관리, 대진표 생성, 앨범 관리
관리자 (admin) 시스템 관리자 회원 승인/관리, 권한 설정, 전체 관리

8.3 보안 조치

  • HTTPS 적용 (Let's Encrypt)
  • CSRF 토큰 적용
  • SQL Injection 방지 (ORM 사용)
  • XSS 방지 (입력값 검증, 이스케이프)
  • 파일 업로드 제한 (확장자, 크기)
  • Rate Limiting (로그인 시도 제한)
