## 3. 단계별 실행 계획

### Phase 1: 스마트폰 기반 PoC (1~2개월)

#### 1.1 NCT 펀칭설비 시범 적용

| 항목 | 내용 |
|------|------|
| **대상** | NCT 펀칭기 1대 선정 |
| **장비** | 중고 스마트폰 1대 (Galaxy A51 5G 또는 동급) |
| **설치** | 설비 본체에 스마트폰 마운트 부착 |
| **모니터링** | 가속도계로 진동 패턴 수집 |
| **목표** | 정상/이상 진동 패턴 구분 가능성 검증 |

**필요 작업**:
1. SensorMonitor 앱에 설비 ID 태깅 기능 추가
2. 웹 대시보드에 설비별 필터 기능 추가
3. 진동 데이터 FFT 분석 기능 개발
4. 진동 임계치 경고 알림 기능 개발

#### 1.2 예상 비용 (Phase 1)

| 항목 | 수량 | 단가 | 금액 |

| 중고 스마트폰 | 1대 | 10만원 | 10만원 |
