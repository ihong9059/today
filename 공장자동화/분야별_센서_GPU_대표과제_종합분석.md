## 2. 분야별 대표 과제 선정

### 2.1 분체/분쇄 설비 - "분쇄기 베어링 고장 예측"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 분쇄기 고속 회전체의 베어링 상태를 실시간 감시하여 고장 전에 미리 알려주는 시스템 |
| **대상 설비** | 에어-제트 밀, 터보 밀, 슈레더, 임펙트 크러셔 |
| **핵심 기술** | FFT 진동분석, Envelope 분석, RUL 예측 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 진동센서 (MEMS 가속도계) | 가속도 (g) | 베어링/로터 이상 감지 |
| 온도센서 (PT100) | 온도 (°C) | 과열 감지 |
| 전류센서 (CT) | 전류 (A) | 부하 변화 감지 |
| 압력센서 | 압력 (bar) | 공압 시스템 상태 |

#### GPU/처리장치

- **ARM Cortex-M4 + DSP**: DSP(디지털 신호 처리기)가 진동 신호를 빠르게 분석

#### 초보자를 위한 설명

> 분쇄기는 물건을 가루로 만드는 기계입니다. 안에 있는 베어링(회전축을 받쳐주는 부품)이 매우 빠르게 돌아가는데, 오래 쓰면 닳아서 고장납니다.
>
> **AI가 하는 일:** 진동센서로 기계의 "떨림"을 측정하면, AI가 "정상적인 떨림"과 "이상한 떨림"을 구분합니다. 마치 의사 선생님이 청진기로 심장 소리를 듣고 이상이 있는지 알아내는 것처럼요!
>
> **FFT(고속 푸리에 변환):** 복잡한 진동 신호를 "음악의 음표"처럼 분해해서, 어떤 주파수에서 이상이 있는지 찾아내는 수학적 방법입니다.

#### 기대 효과

- 베어링 수명 30% 연장
- 비계획 정지 60% 감소
- 분쇄날 수명 예측으로 교체 최적화

### 2.2 전기/배전반 - "용접 품질 실시간 모니터링"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 용접할 때 전류/전압 패턴을 분석하여 용접 불량을 즉시 발견하는 시스템 |
| **대상 설비** | 스폿용접기, CO2/MIG 용접기, 로봇 용접 시스템 |
| **핵심 기술** | 전류/전압 패턴 분석, 아크 안정성 모니터링 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 전류센서 (CT/홀센서) | 용접 전류 (A) | 용접 품질 판단 |
| 전압센서 | 용접 전압 (V) | 아크 상태 분석 |
| 온도센서 | 온도 (°C) | 용접부 온도 모니터링 |
| 유량센서 | 가스 유량 (L/min) | 보호가스 상태 확인 |

#### GPU/처리장치

- **ARM Cortex-M4**: 실시간 전류/전압 패턴 분석

#### 초보자를 위한 설명

> 용접은 금속을 녹여서 붙이는 작업입니다. 이때 전기가 흐르면서 아주 뜨거운 불꽃(아크)이 생깁니다.
>
> **AI가 하는 일:** 용접할 때 전류와 전압이 어떻게 변하는지 패턴을 기억합니다. 좋은 용접은 "매끄러운 패턴"을 보이고, 나쁜 용접은 "울퉁불퉁한 패턴"을 보입니다. AI는 수천 개의 용접 데이터를 학습해서 "이건 좋은 용접이야!" "이건 불량이야!"를 실시간으로 판단합니다.

#### 기대 효과

- 용접 불량 45~50% 감소
- 전극 수명 30% 연장
- 품질 추적성 확보

### 2.3 로봇자동화 (FPD 장비) - "Oven 히터 열화 예측"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 디스플레이 제조용 Oven의 히터가 언제 고장날지 미리 예측하는 시스템 |
| **대상 설비** | Bake Oven, Furnace Oven, 건조로 |
| **핵심 기술** | 온도 프로파일 분석, 전류-온도 상관분석, RUL 예측 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 열전대 (K-Type, PT100) | 온도 (°C) | 다점 온도 측정 |
| 전류센서 (CT/홀센서) | 히터 전류 (A) | 히터 열화 감지 |
| 진동센서 | 진동 (g) | 팬 모터 상태 |
| 온습도센서 | 온도/습도 | 환경 조건 |

#### GPU/처리장치

- **ARM Cortex-M4 + DSP**: 온도 패턴 분석 및 RUL 예측

#### 초보자를 위한 설명

> Oven(오븐)은 스마트폰 화면(디스플레이)을 만들 때 재료를 열처리하는 큰 가마 같은 장비입니다. 안에 있는 히터(전기 열선)가 오래 쓰면 점점 약해집니다.
>
> **AI가 하는 일:** 히터가 같은 온도를 내는데 점점 더 많은 전류가 필요하면, "히터가 약해지고 있구나!" 하고 알아차립니다.
>
> **RUL(잔여수명 예측):** "이 히터는 앞으로 약 30일 뒤에 고장날 거야"라고 예측해주는 기술입니다. 마치 자동차 엔진오일 교체 시기를 알려주는 것처럼요!

#### 기대 효과

- 비계획 정지 80% 감소
- 히터 부품 수명 30% 연장
- 에너지 효율 15% 향상

### 2.4 반도체 정밀가공 - "플라즈마 챔버 아킹 사전 감지"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 플라즈마 장비에서 아킹(스파크) 발생 전에 위험 징후를 감지하는 시스템 |
| **대상 설비** | 플라즈마 챔버, RF 전원 시스템, 진공 펌프 |
| **핵심 기술** | RF 신호 분석, 고주파 노이즈 감지, 아킹 패턴 인식 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| RF 파워미터 | 전진파/반사파 (W) | 매칭 효율 분석 |
| 진공 게이지 | 압력 (mTorr) | 진공도 확인 |
| OES (광학) | 발광 스펙트럼 | 플라즈마 상태 분석 |
| 임피던스 모니터 | Z, θ (Ω, °) | 부하 변화 감지 |

#### GPU/처리장치

- **ARM Cortex-M4 + FPGA**: 초고속 RF 신호 처리 (10kHz 이상 샘플링)

#### 초보자를 위한 설명

> 플라즈마는 기체에 강한 전기를 가해서 만든 "제4의 물질 상태"입니다. 번개나 네온사인 불빛이 플라즈마의 예시입니다! 반도체 공장에서는 플라즈마로 아주 정밀하게 회로를 깎습니다.
>
> **아킹(Arcing):** 갑자기 스파크가 튀는 현상입니다. 이러면 만들던 반도체 칩이 망가집니다!
>
> **AI가 하는 일:** 아킹이 일어나기 전에 RF 신호에 "이상한 노이즈"가 조금씩 생깁니다. AI는 이 미세한 변화를 감지해서 "위험해요! 전력을 줄이세요!"라고 경고해줍니다.

#### 기대 효과

- 아킹으로 인한 제품 손실 80% 감소
- RF 부품 수명 30% 연장
- 장비 가동률 15% 향상

### 2.5 도장/표면처리 - "분체도장 품질 예측"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 도장 공정의 온도, 습도, 정전기 상태를 분석하여 도장 품질을 예측하는 시스템 |
| **대상 설비** | 정전분체도장 부스, 건조로, 전처리 라인 |
| **핵심 기술** | 환경 조건-품질 상관분석, 최적 조건 도출 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 온도센서 | 온도 (°C) | 건조로 온도 프로파일 |
| 습도센서 | 습도 (%RH) | 도장 환경 조건 |
| 전압센서 | 정전압 (kV) | 정전기 상태 |
| VOC센서 | VOC 농도 (ppm) | 환경/안전 관리 |
| 차압센서 | 차압 (Pa) | 필터 상태 |

#### GPU/처리장치

- **ARM Cortex-M4**: 환경 조건 분석 및 품질 예측

#### 초보자를 위한 설명

> 분체도장은 페인트 가루를 뿌려서 물건에 색을 입히는 방법입니다. 정전기를 이용해서 가루가 물건에 달라붙게 합니다!
>
> **AI가 하는 일:** "오늘 습도가 높으니까 도장이 잘 안 붙을 수 있어요" "건조로 온도가 조금 낮아서 도장이 덜 마를 수 있어요" 같은 예측을 해줍니다. 이렇게 미리 알면 불량품이 나오기 전에 조건을 조절할 수 있습니다!

#### 기대 효과

- 도장 불량 40~50% 감소
- 에너지 비용 15% 절감
- 최적 클리닝 시기 예측

### 2.6 환경/집진 - "바이오디젤 반응기 예지정비"

| 항목 | 내용 |
|------|------|
| **과제 목표** | 바이오디젤 생산 설비의 교반기, 펌프 상태를 실시간 감시하여 고장을 예측하는 시스템 |
| **대상 설비** | CSTR 반응기, 증류탑, 이송펌프, 교반기 |
| **핵심 기술** | 진동분석, 온도 트렌드 분석, 압력 패턴 분석 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 진동센서 | 진동 (g) | 교반기/펌프 베어링 상태 |
| 온도센서 | 온도 (°C) | 반응기 온도 분포 |
| 압력센서 | 압력 (bar) | 반응 압력 측정 |
| 유량센서 | 유량 (L/min) | 원료 유량 측정 |
| 레벨센서 | 레벨 (%) | 탱크 수위 |

#### GPU/처리장치

- **ARM Cortex-M4**: 다중 센서 데이터 통합 분석

#### 초보자를 위한 설명

> 바이오디젤은 폐식용유(튀김 기름)로 만드는 친환경 연료입니다! 큰 탱크에서 기름과 화학물질을 섞어서 만드는데, 교반기(휘젓는 기계)가 계속 돌아가야 합니다.
>
> **AI가 하는 일:** 교반기가 "덜컹덜컹" 이상하게 떨리면 베어링이 닳았다는 신호입니다. AI가 이런 패턴을 감지하면 "2주 안에 교반기를 점검하세요!"라고 알려줍니다.

#### 기대 효과

- 비계획 정지 85% 감소
- 제품 품질(순도 99% 이상) 안정화
- ISCC 인증 대응 강화

#### 과제 개요

|------|------|

#### 적용 센서

#### GPU/처리장치

#### 초보자를 위한 설명

> 유압브레이커는 굴삭기 팔 끝에 달려서 콘크리트나 바위를 "쿵쿵" 깨부수는 장비입니다.
>
> **AI가 하는 일:** 전 세계에 팔린 장비들이 "오늘 몇 번 타격했고, 유압은 정상이고, 온도는 괜찮아요"라고 한국 본사에 보고합니다. AI는 이 데이터를 보고 "이 장비는 3개월 뒤에 정비가 필요해요"라고 미리 알려줘서, 갑자기 고장나는 것을 막습니다!

#### 기대 효과

- 고객 A/S 비용 40% 절감
- 글로벌 장비 통합 관리
- 원격 모니터링 서비스 상품화

### 2.8 열처리설비 - "전기로 발열체 수명 예측"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 전기로의 발열체가 언제 교체해야 하는지 예측하는 시스템 |
| **대상 설비** | Box Type 전기로, Tube Type 전기로, 연속로 |
| **핵심 기술** | 저항값 트렌드 분석, 열화 패턴 감지, RUL 예측 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 저항측정기 | 저항값 (Ω) | 발열체 열화 감지 |
| 열전대 (K-Type) | 온도 (~1200°C) | 고온 측정 |
| 전류센서 | 전류 (A) | 히터 전류 모니터링 |
| 적외선 센서 | 외피 온도 | 열손실 분석 |

#### GPU/처리장치

- **ARM Cortex-M4**: 저항 변화율 분석 및 수명 예측

#### 초보자를 위한 설명

> 전기로는 물건을 아주 뜨겁게 (1000°C 이상!) 가열하는 가마입니다. 안에 있는 발열체(전기가 흐르면 열이 나는 막대)가 점점 닳습니다.
>
> **발열체 열화:** 오래 쓰면 발열체의 저항값이 변합니다. 같은 온도를 내는데 더 많은 전기가 필요해집니다.
>
> **AI가 하는 일:** 저항값이 얼마나 빨리 변하는지 추적해서 "이 발열체는 약 6개월 뒤에 교체해야 해요"라고 알려줍니다. 갑자기 고장나면 생산이 멈추니까, 미리 알면 계획적으로 교체할 수 있습니다!

#### 기대 효과

- 발열체 돌발 고장 90% 방지
- 최적 교체로 비용 30% 절감
- 전기로 가동률 25% 향상

### 2.9 포장기계 - "서보모터 감속기 예지정비"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 자동 포장기의 서보모터와 감속기 상태를 실시간 모니터링하여 고장을 예측하는 시스템 |
| **대상 설비** | 자동테이핑기, 제함기, 밴딩기, 랩핑기 |
| **핵심 기술** | 진동 패턴 분석, 전류 패턴 분석, 토크 모니터링 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 진동센서 | 진동 (g) | 모터/감속기 상태 |
| 전류센서 | 전류 (A) | 모터 부하 측정 |
| 온도센서 | 온도 (°C) | 과열 감지 |
| 토크센서 | 토크 (Nm) | 회전력 측정 |
| 속도센서 | RPM | 회전 속도 |

#### GPU/처리장치

- **ARM Cortex-M4**: 다중 센서 통합 분석

#### 초보자를 위한 설명

> 포장기계는 물건을 박스에 넣고 테이프로 봉하는 자동 기계입니다. 안에 있는 서보모터가 아주 정확하게 움직여야 합니다!
>
> **서보모터:** 위치를 정확하게 제어할 수 있는 특별한 모터입니다.
> **감속기:** 모터의 빠른 회전을 천천히, 대신 힘있게 바꿔주는 장치입니다.
>
> **AI가 하는 일:** 모터가 평소보다 더 뜨거워지거나, 이상하게 떨리면 "감속기 기어가 닳았어요!"라고 알려줍니다. 이렇게 하면 갑자기 포장 라인이 멈추는 것을 막을 수 있습니다!

#### 기대 효과

- 설비 가동률 90% 이상 유지
- A/S 비용 40% 절감
- 글로벌 원격 모니터링 서비스화

### 2.10 기계일반제조 - "밸브 상태 진단 (Valve Signature Analysis)"

#### 과제 개요

| 항목 | 내용 |
|------|------|
| **과제 목표** | 산업용 밸브의 열림/닫힘 동작을 분석하여 밸브 상태를 진단하는 시스템 |
| **대상 설비** | 버터플라이 밸브, 게이트 밸브, 액추에이터 |
| **핵심 기술** | Valve Signature 분석, 토크 패턴 분석, 누설 감지 |

#### 적용 센서

| 센서 | 측정 항목 | 역할 |
|------|----------|------|
| 토크센서 | 토크 (Nm) | 밸브 회전력 측정 |
| 압력센서 | 압력 (bar) | 유체 압력 측정 |
| 위치센서 | 개도 (%) | 밸브 열림 정도 |
| 누설감지센서 | 누설량 | 밀봉 상태 확인 |
| 온도센서 | 온도 (°C) | 액추에이터 상태 |

#### GPU/처리장치

- **ARM Cortex-M4**: Valve Signature 패턴 분석

#### 초보자를 위한 설명

> 밸브는 파이프 안의 물이나 기름 흐름을 조절하는 장치입니다. 수도꼭지도 밸브의 일종입니다!
>
> **Valve Signature (밸브 서명):** 밸브를 열고 닫을 때 토크(회전력)가 어떻게 변하는지 그래프로 그린 것입니다. 마치 사람마다 서명이 다르듯이, 정상 밸브와 문제 있는 밸브는 다른 패턴을 보입니다!
>
> **AI가 하는 일:** 밸브의 "서명"이 이상해지면 "이 밸브의 씰(고무링)이 닳았어요" 또는 "밸브 축이 굽었어요"라고 정확히 진단해줍니다!

#### 기대 효과

- 밸브 고장 70% 감소
- 다운타임 40% 절감
- MRO 서비스 매출 30% 증가

## 3. AI 기술 핵심 개념 (초보자용)

### 3.1 FFT (고속 푸리에 변환)

**정의:** 복잡한 진동 신호를 주파수별로 분해하는 기술

**비유 설명:**
> 기타를 치면 여러 음이 섞여서 나옵니다. FFT는 그 소리를 도, 레, 미, 파... 각각의 음으로 분리해내는 것과 같습니다. 기계 진동도 이렇게 분리하면 "어떤 부품이 이상한지" 알 수 있습니다!

**적용 분야:** 분체/분쇄, 건설중장비, 포장기계 등 회전체 설비

---

### 3.2 RUL (Remaining Useful Life, 잔여수명)

**정의:** 부품이 앞으로 얼마나 더 사용 가능한지 예측하는 기술

**비유 설명:**
> 배터리 잔량 표시처럼, "이 베어링은 앞으로 약 100시간 더 쓸 수 있어요"라고 알려줍니다.

**적용 분야:** 열처리설비(발열체), 로봇자동화(히터), 반도체(RF 부품)

---

### 3.3 이상 탐지 (Anomaly Detection)

**정의:** 정상 패턴과 다른 이상 패턴을 찾아내는 기술

**비유 설명:**
> AI가 수천 개의 정상 데이터를 학습하면, 처음 보는 이상한 패턴이 나타났을 때 "이건 평소와 달라요!"라고 알려줍니다.

**적용 분야:** 반도체(아킹 감지), 환경/집진(이상 반응), 용접 품질

---

### 3.4 패턴 인식 (Pattern Recognition)

**정의:** 특정 모양이나 패턴을 구분하는 기술

**비유 설명:**
> 용접 전류 패턴을 보고 "이건 좋은 용접 패턴", "이건 불량 용접 패턴"을 구분합니다.

**적용 분야:** 전기/배전반(용접 품질), 기계일반(밸브 서명)

---

### 3.5 Edge AI (엣지 AI)

**정의:** AI를 클라우드가 아닌 현장 장비에서 직접 실행하는 기술

**비유 설명:**
> 스마트폰에서 바로 사진 인식을 하는 것처럼, 공장 현장에서 바로 분석합니다. 인터넷이 끊겨도 작동하고, 실시간으로 빠르게 처리할 수 있습니다.

**적용 분야:** 모든 분야 (ARM Cortex-M4 기반)
