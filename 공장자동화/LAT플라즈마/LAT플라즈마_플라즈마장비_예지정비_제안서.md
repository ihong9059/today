### 센서별 역할 및 설치 위치

| 센서 | 측정 대상 | 설치 위치 | 감지 목적 | 샘플링 주기 |
|------|----------|----------|----------|------------|
| **진공 게이지** | 압력 (mTorr~Torr) | 챔버, 포라인 | 진공도 확인, 누설 감지 | 100Hz |
| **RF 파워미터** | 전진파/반사파 (W) | RF 라인 | 매칭 효율, 전력 모니터링 | 100Hz |
| **임피던스 모니터** | Z, θ (Ω, °) | 매칭 네트워크 | 부하 변화 감지 | 100Hz |
| **열전대 (K-type)** | 온도 (°C) | 챔버벽, 전극 | 과열 방지, 열균일성 | 10Hz |
| **기판 온도계** | 온도 (°C) | 척/히터 | 공정 온도 제어 | 10Hz |
| **MFC 피드백** | 유량 (sccm) | 가스 라인 | 유량 정확도 확인 | 100Hz |
| **OES (광학)** | 발광 스펙트럼 | 챔버 뷰포트 | 플라즈마 상태, 종말점 | 1kHz |
| **아크 감지기** | 광펄스 | 챔버 내부 | 아킹 발생 감지 | 10kHz |

### AI 모델 구성

```python
class PlasmaEquipmentPredictor:
    """플라즈마 장비 AI 예측 모델"""

    def __init__(self):
        # RF 시스템 분석
        self.rf_analyzer = RFMatchingAnalyzer()

        # 진공 시스템 분석
        self.vacuum_analyzer = VacuumSystemAnalyzer()

        # 챔버 상태 분석
        self.chamber_analyzer = ChamberConditionAnalyzer()

        # RUL (잔여수명) 예측기
        self.rul_predictor = LSTMPredictor()

    def predict_maintenance(self, sensor_data):
        """종합 정비 예측"""

        # 각 서브시스템 분석
        rf_health = self.rf_analyzer.analyze(sensor_data['rf'])
        vacuum_health = self.vacuum_analyzer.analyze(sensor_data['vacuum'])
        chamber_health = self.chamber_analyzer.analyze(sensor_data['chamber'])

        # 종합 건강도 산출
        overall_health = self.calculate_overall_health(
            rf_health, vacuum_health, chamber_health
        )

        # 정비 권고 생성
        recommendations = self.generate_recommendations(
            overall_health,
            rf_health,
            vacuum_health,
            chamber_health
        )

        return {
            'overall_health_score': overall_health,
            'rf_health': rf_health,
            'vacuum_health': vacuum_health,
            'chamber_health': chamber_health,
            'recommendations': recommendations,
            'next_maintenance_date': self.predict_next_maintenance()
        }
```
