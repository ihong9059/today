## B. 업체별 상세 정보

### 테크윙 (Techwing)
- **웹사이트:** https://www.techwing.co.kr
- **상장:** KOSDAQ 089030
- **소재지:** 경기도 성남시
- **주요제품:** 메모리 테스트 핸들러, 번인 소터, 레이저 마킹
- **특징:** 국내 메모리 테스트 핸들러 1위, 삼성전자/SK하이닉스 주요 공급업체

### 고영테크놀러지 (Koh Young Technology)
- **웹사이트:** https://kohyoung.com
- **상장:** KOSDAQ 098460
- **소재지:** 서울특별시 금천구
- **주요제품:** 3D SPI(Solder Paste Inspection), 3D AOI(Automated Optical Inspection)
- **특징:** 3D 납도포 검사장비 글로벌 점유율 1위, SMT 검사장비 선두

### 넥스틴 (NextIn)
- **웹사이트:** https://www.nextin.com
- **소재지:** 경기도 화성시
- **주요제품:** 웨이퍼 표면 검사장비, 패턴 검사장비
- **특징:** 전공정 웨이퍼 검사 전문, 삼성전자/SK하이닉스 주요 고객사

### 유니테스트
- **웹사이트:** http://www.uni-test.com
- **상장:** KOSDAQ A086390
- **소재지:** 경기도 용인시
- **주요제품:** 메모리 테스터, 번인 테스터, SSD 테스터
- **특징:** 메모리 반도체 테스트 장비 전문

### 오로스테크놀로지
- **웹사이트:** https://www.orostech.com
- **소재지:** 경기도

- **특징:** HBM(High Bandwidth Memory) 검사장비 특화, 삼성전자 공급

### 인텍플러스
- **웹사이트:** https://www.intekplus.com
- **상장:** KOSDAQ A064290
- **소재지:** 대전광역시
- **주요제품:** 반도체 패키징 검사장비, AOI, 2D/3D 검사
- **특징:** 패키징 공정 검사장비 전문

### 펨트론
- **웹사이트:** https://pemtron.com
