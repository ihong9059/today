# 두산로보틱스 협동로봇 예지정비(PdM) 통합 솔루션 제안서

**작성일:** 2026년 1월 2일
**대상 기업:** 두산로보틱스 (www.doosanrobotics.com)
**제안 기업:** UTTEC (유텍)
**버전:** 2.0

---

## Executive Summary

두산로보틱스는 대한민국을 대표하는 협동로봇(Cobot) 전문 기업으로, P/H/M/A/E 시리즈 등 13개 제품군을 보유하고 있으며 글로벌 시장을 선도하고 있습니다.

UTTEC은 **78년 이상**의 임베디드/IoT/AI 개발 경험을 바탕으로, 두산로보틱스의 **협동로봇 예지정비 시스템**, **Edge AI 기반 실시간 모니터링**, **토크센서 데이터 분석 플랫폼** 통합 솔루션을 제안드립니다.

### 핵심 제안 가치

| 구분 | 현재 상태 | UTTEC 솔루션 적용 후 |
|------|----------|---------------------|
| **로봇 상태 모니터링** | 정기 점검/수동 관리 | AI 예지정비 실시간 모니터링 |
| **고장 예측** | 고장 후 사후 대응 | ML 기반 고장 예측 (7일 전 알림) |
| **토크센서 데이터** | 실시간 분석 한계 | Edge AI 실시간 FFT 분석 |
| **유지보수 비용** | 계획되지 않은 다운타임 | 예측 기반 사전 정비로 비용 30% 절감 |
| **글로벌 서비스** | 현지 대응 지연 | 클라우드 기반 원격 진단 |

#### 3.3.2 RUL(잔여수명) 예측
