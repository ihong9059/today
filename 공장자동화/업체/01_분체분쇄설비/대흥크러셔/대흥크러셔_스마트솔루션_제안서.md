| 타입 | 적용 재료 | 특징 |

| DHS type | 연질 PVC, PE, PP, PET, FILM, SHEET | 연질 및 중공성형품 분쇄 |
| DHG type | ABS, PC, NYLON, GLASS-FIBER 함유 | 경질 및 고부하 분쇄 |
| DHP type | DHG 동일 + Tip 조립식 Blade | 유지보수 편리 |

### 2.3 생산설비 현황 분석

#### 분쇄기 핵심 구동부
- 대형 모터 (75~125kW)
- 회전날 / 고정날 시스템
- 유압 시스템 (투입구 개폐)
- 베어링 및 축 어셈블리

#### 파쇄기 핵심 구동부
- 저속 고토크 구동 시스템
- 2축 파쇄날 어셈블리
- 유압 구동 시스템
- 감속기 및 커플링

#### 재생압출기 핵심부
- 압출 스크류 및 배럴
- 히터 존 (다구간 온도제어)
- 커팅 시스템
- 냉각 시스템

## 3. UTTEC 예지정비 역량

### 3.1 Edge AI Gateway 사양

| 구분 | 사양 |
|------|------|
| MCU | ARM Cortex-M4 + DSP |
| 진동분석 | FFT, Envelope, Cepstrum |
| 프로토콜 | RS-485, Modbus, MQTT, 4-20mA |
| AI 엔진 | 이상탐지, RUL 예측 |
| 인증 | KC, CE 대응 |

### 3.2 분쇄/파쇄 산업 특화 기능

1. **대형 분쇄기 구동부 분석**
   - 회전날/고정날 마모도 예측
   - 베어링 상태 모니터링 (진동, 온도)
   - 모터 전류 패턴 분석
   - 과부하 사전 감지

2. **파쇄기 저속 구동계 분석**
   - 2축 동기화 상태 모니터링
   - 감속기 기어 상태 분석
   - 유압 시스템 압력/온도 감시
   - 파쇄날 마모 예측

3. **재생압출기 공정 관리**
   - 스크류 마모도 예측
   - 히터 존별 온도 프로파일 분석
   - 압출 압력 모니터링
   - 에너지 효율 최적화

4. **폐기물 처리라인 통합 관리**
   - 라인 전체 OEE 분석
   - 병목 구간 식별
   - 처리량 최적화
   - 이상 상황 조기 경보

## 7. UTTEC 소개

### 7.1 회사 개요

UTTEC은 산업용 IoT 및 예지정비 솔루션 전문 기업으로, 분쇄/파쇄, 압출, 재활용 등 다양한 산업분야에서 설비 상태 모니터링 및 예측 시스템을 구축해 왔습니다.

### 7.2 핵심 역량

- **Edge AI 기술**: 현장 설비에서 실시간 분석
- **분쇄/파쇄 설비 전문성**: 대형 구동계 모니터링 다수 실적
- **통합 솔루션**: 센서부터 대시보드까지 원스톱 제공
- **SaaS 서비스**: 클라우드 기반 원격 모니터링

### 7.3 주요 실적

- 재활용 플랜트 분쇄기 예지정비 시스템
- 폐기물 처리업체 파쇄라인 모니터링
- 압출 전문업체 스크류 마모 예측 시스템
