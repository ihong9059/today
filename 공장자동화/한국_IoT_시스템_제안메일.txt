제목: [UTTEC] 산업용 IoT 환경 모니터링 시스템 도입 제안

안녕하십니까,

UTTEC 홍광삼입니다.

귀사의 무궁한 발전을 기원하며, 스마트 팩토리 구축에 도움이 될 수 있는
산업용 IoT 환경 모니터링 시스템을 제안드리고자 연락드립니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 시스템 개요

저희 UTTEC에서 개발한 소형 IoT 모니터링 시스템은 공장 내 다양한 환경 데이터를
실시간으로 수집하고 웹 대시보드를 통해 모니터링할 수 있는 솔루션입니다.

■ 주요 기능

  1. 환경 센서 모니터링
     - 온도/습도 측정 (AHT20 센서)
     - 대기압 측정 (BMP280 센서)
     - 진동/기울기 감지 (MPU6050 가속도/자이로 센서)

  2. 실시간 웹 대시보드
     - 웹 브라우저를 통한 원격 모니터링
     - WebSocket 기반 실시간 데이터 업데이트
     - PC, 태블릿, 스마트폰 접속 지원

  3. 현장 표시 장치
     - OLED 디스플레이를 통한 현장 데이터 표시
     - IP 주소, 온도, 습도, 기압 실시간 표시

  4. 경보 및 알림
     - LED 상태 표시 (정상/주의/경고)
     - 부저 알람 기능
     - 설정값 초과 시 자동 알림

■ 시스템 구성

  - Raspberry Pi Zero W 기반 (저전력, 소형)
  - WiFi 무선 통신
  - 전원 투입 시 자동 실행
  - 확장 가능한 모듈형 설계

■ 활용 분야

  - 분체 설비 주변 환경 모니터링
  - 집진기 온도/압력 감시
  - 전동기실 환경 관리
  - 품질 관리 구역 환경 감시

■ 기대 효과

  - 설비 이상 조기 감지로 예방 정비 실현
  - 환경 데이터 이력 관리를 통한 품질 향상
  - 원격 모니터링으로 인력 효율화
  - 저비용 IoT 인프라 구축
