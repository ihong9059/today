Project A: 밸브 상태 모니터링 시스템

4,000만원 3개월

KEYSTONE 밸브의 실시간 상태 모니터링 및 이상 감지 시스템 구축

구분 내용
대상 밸브 핵심 공정 버터플라이 밸브 20대
모니터링 포인트 밸브당 5개 포인트 (총 100 포인트)
센서 구성 토크 20개, 압력 40개, 위치 20개, 온도 20개

주요 기능

  • 밸브 시그니처 분석 - 토크 프로파일 기반 상태 진단
  • 누설 감지 - 압력/유량 기반 내부/외부 누설 감지
  • 액추에이터 진단 - 공압 소비량, 응답시간, 스트로크 분석
  • 자동 알람 - 임계값 + AI 기반 이상 탐지
  • 정비 권고 - 상태 기반 최적 정비 시점 제안

Project B: MRO 고객 원격 지원 플랫폼

3,000만원 2.5개월

서원텍 MRO 고객사의 밸브 원격 모니터링 및 A/S 지원 SaaS 플랫폼 구축

플랫폼 기능

  • 멸티테넌트 대시보드 - 고객사별 밸브 현황 통합 모니터링
  • 원격 진단 - 이상 발생 시 밸브 시그니처 원격 분석
  • 부품 수명 관리 - 시트, 패킹, 디스크 등 부품별 교체 이력 및 예측
  • 자동 알림 서비스 - 정비 권고, 부품 교체 알림 자동 발송

Project C: 스마트 액추에이터 진단 시스템

2,000만원 2개월

KEYSTONE F89 공압 액추에이터 전용 진단 및 예지정비 시스템

주요 기능

  • 공압 효율 분석 - 공기 소비량 모니터링, 누설 감지
  • 응답 성능 분석 - 신호 입력 → 밸브 동작 시간 측정
  • 스프링 상태 진단 - 스프링 리턴 토크 변화 모니터링
  • 포지셔너 진단 - 위치 정확도, 데드밴드 분석
