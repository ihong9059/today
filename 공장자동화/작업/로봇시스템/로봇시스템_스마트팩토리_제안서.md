#### 반도체 장비 (Semiconductor)
- **EFEM (Equipment Front End Module)**: 웨이퍼 이송 시스템
- **SORTER**: 웨이퍼 분류 장비
- **STOCKER**: 웨이퍼 저장 시스템
- **Transfer Robot**: 고정밀 웨이퍼 이송 로봇

#### 산업용 로봇 (Industrial Robot)
- 다관절 로봇 시스템
- 물류 자동화 로봇
- Pick & Place 시스템

#### 디스플레이 장비 (Display)
- LCD/OLED 패널 핸들링 장비
- Glass 이송 시스템

### 1.3 기업 강점 분석
- 15년 이상의 산업용 로봇 전문 기술력
- 반도체/디스플레이 대기업 납품 실적
- 클린룸 환경 장비 설계/제조 노하우
- 경기도 수원 소재 (지역 협력 용이)

## 4. 구체적 프로젝트 제안

### 프로젝트 A: EFEM/SORTER 스마트 모니터링 시스템

#### 개요
| 항목 | 내용 |
|------|------|
| **프로젝트명** | Smart EFEM Monitoring System (SEMS) |
| **목표** | EFEM/SORTER 장비 실시간 모니터링 및 예지정비 |

#### 주요 기능
1. **실시간 장비 모니터링**
   - 로봇 축별 토크, 위치, 속도 모니터링
   - 진동, 온도 센서 데이터 수집
   - 알람 발생 시 즉시 알림

2. **예지정비 (Predictive Maintenance)**
   - 베어링, 벨트, 모터 수명 예측
   - 이상 징후 패턴 분석
   - 정비 스케줄 자동 권고

3. **가동률(OEE) 분석**
   - 가용성, 성능, 품질 지표 실시간 계산
   - 일간/주간/월간 리포트 자동 생성

#### 개발 범위

| 구분 | 내용 |
|------|------|
| **센서 인터페이스 보드** | 진동/온도/전류 센서 연동 |
| **Edge Gateway** | 데이터 수집 및 전처리 |
| **AI 이상 탐지 모듈** | Edge AI 기반 이상 탐지 |
| **Cloud 플랫폼** | 데이터 저장 및 분석 |
| **Web Dashboard** | 실시간 모니터링 UI |
| **Mobile App** | 알람 수신 및 원격 확인 |

#### 예상 산출물
- 센서 인터페이스 보드 (PCB + Firmware)
- Edge Gateway (H/W + S/W)
- Cloud 모니터링 플랫폼
- Web Dashboard 및 Mobile App
- 사용자 매뉴얼

#### 예상 비용

| 항목 | 금액 |
|------|------|
| H/W 개발 (센서보드, Gateway) | 18,000,000원 |
| F/W 개발 (데이터 수집, 통신) | 15,000,000원 |
| AI 모델 개발 (이상탐지) | 20,000,000원 |

| 테스트 및 현장 적용 | 5,000,000원 |

### 프로젝트 B: 로봇 제어 시스템 고도화

#### 개요
| 항목 | 내용 |
|------|------|
| **프로젝트명** | Advanced Robot Control System (ARCS) |
| **목표** | 기존 로봇 제어기 성능 향상 및 신규 기능 추가 |

#### 주요 기능
1. **고정밀 모션 제어**
   - 다축 동기 제어 알고리즘 개선
   - 진동 억제 제어
   - 충돌 감지 및 안전 정지

2. **EtherCAT 기반 고속 통신**
   - 실시간 제어 루프 (1ms 이하)
   - 다중 드라이브 동기화

3. **HMI 업그레이드**
   - 터치스크린 기반 조작 UI
   - 티칭 펜던트 개선

#### 개발 범위

| 구분 | 내용 |
|------|------|
| **메인 제어보드 설계** | ARM Cortex-A 기반 MCU |
| **모션 제어 알고리즘** | 다축 동기, 진동 억제 |
| **EtherCAT Master** | 실시간 통신 구현 |
| **HMI 개발** | 터치스크린 UI |
| **상위 통신** | MES/ERP 연동 |

#### 예상 비용
