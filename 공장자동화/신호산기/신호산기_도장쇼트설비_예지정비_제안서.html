4. 설비별 모니터링 항목

4.1 쇼트블라스트 설비

모니터링 항목 센서 분석 방식 예측 가능 고장
임펠러 베어링 3축 가속도센서 FFT + 포록선 분석 마모, 편심 손상
모터 전류 CT 센서 전류파형 분석 권선이상, 과부하
임펠러 온도 PT100 트렌드 분석 윤활 부족, 임펠러 마모
진공회수 풍속 풍속계 유량 분석 배관 막힘, 쇄입자 유출
에너지 효율 전력/투사량 kWh/m² 분석 효율 저하 예측

4.2 도장부스 설비

모니터링 항목 센서 분석 방식 예측 가능 고장
송풍기 모터 진동센서 FFT + 엔벨롱포 분석 벨트 마모, 베어링 고장
도료 공급량 유량센서 외 실시간 분석 노즐 막힘, 펄프 이상
부스 내부 차압 차압센서 연속 분석 필터 막힘
분진 농도 PM센서 실시간 모니터링 필터 불량, 설비오염
VOC 농도 PID 센서 실시간 모니터링 환기 불량, 환경 이슈

4.3 집진기 설비

모니터링 항목 센서 분석 방식 예측 가능 고장
필터 차압 차압센서 연속 분석 필터 막힘, 펄스 이상
로타리밸브 상태 압력/전류 패턴 분석 이상 마모
배기 팬 베어링 진동센서 FFT 분석 벨트 마모, 베어링 고장
배출 분진 농도 PM센서 실시간 모니터링 필터 불량, 규정초과
펄스밸브 압력 압력센서 파형 분석 압축공기 솔랜 이상
