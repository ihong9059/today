### 3. Raspberry Pi Zero 프로젝트 시작 (오전)

Pi Zero 검토를 위한 프로젝트 폴더 생성 및 SSH 연결 가이드 문서 작성

| 항목 | 내용 |
|:-----|:-----|
| 생성 폴더 | `piZero/` |
| 작성 문서 | `raspberry_pi_zero_ssh_guide.md` |

**문서 내용 (SSH 연결 가이드):**

| 섹션 | 설명 |
|:-----|:-----|
| 개요 | Pi Zero 모델별 특징 비교 (Zero, Zero W, Zero 2 W) |
| 하드웨어 준비 | 필수 장비 및 포트 구성 |
| 연결 방식 비교 | WiFi, USB OTG, 이더넷 가젯, UART |
| 방법 1: USB OTG | Pi Zero → Pi 3/4 직접 연결 |
| 방법 2: WiFi | 무선 네트워크 연결 (Pi Zero W) |
| 방법 3: 이더넷 가젯 | USB를 네트워크 인터페이스로 사용 |
| 방법 4: UART | GPIO 시리얼 연결 |
| SSH 키 인증 | 비밀번호 없이 접속 설정 |
| 트러블슈팅 | 일반적인 문제 해결 방법 |
| 명령어 모음 | 네트워크/SSH/파일전송 명령어 |

**USB 케이블 요구사항 (방법 3):**
- 케이블 타입: Micro USB to USB-A (데이터 지원 필수)
- 충전 전용 케이블은 사용 불가 (D+, D- 데이터선 없음)
- Pi Zero의 USB Data 포트 (가운데) 사용

### 4. Pi Zero W USB SSH 연결 설정 (오전)

#### 4.1 SD 카드 USB 가젯 설정

2개의 SD 카드 (메인 + 예비)에 USB 이더넷 가젯 설정 완료

| 파일 | 추가 내용 |
|:-----|:----------|
| `/boot/firmware/config.txt` | `dtoverlay=dwc2` |
| `/boot/firmware/cmdline.txt` | `modules-load=dwc2,g_cdc` |
| `/boot/firmware/ssh` | 빈 파일 생성 (SSH 활성화) |

**참고:** macOS 호환을 위해 `g_ether` 대신 `g_cdc` 사용

#### 4.2 Pi Zero W 연결 확인

| 연결 방식 | IP | 상태 |
|:----------|:---|:----:|
| WiFi | 192.168.0.15 | ✅ 성공 |
| USB (CDC Ethernet) | 10.0.0.2 | ✅ 성공 |

**USB 연결 구성:**
```
┌─────────────────┐      USB Cable       ┌─────────────────┐
│      Mac        │ ◄──────────────────► │   Pi Zero W     │
│  en6: 10.0.0.1  │    CDC Ethernet      │  usb0: 10.0.0.2 │
└─────────────────┘                      └─────────────────┘
```

#### 4.3 영구 IP 설정

Pi Zero W의 `/etc/dhcpcd.conf`에 USB 고정 IP 추가:

```bash
# USB Ethernet Gadget - Static IP
interface usb0
static ip_address=10.0.0.2/24
```

### 5. Pi Zero W raspShield 설치 (오후)

Pi Zero W (192.168.1.100)에 raspShield 프로젝트 설치 완료

#### 5.1 네트워크 변경

기존 uttec0 (192.168.0.x) 네트워크에서 인터넷 연결 문제로 uttec1로 변경

| 항목 | 변경 전 | 변경 후 |
|:-----|:--------|:--------|
| WiFi SSID | uttec0 | uttec1 |
| IP | 192.168.0.100 | 192.168.1.100 |
| 비밀번호 | - | a123456789 |

#### 5.2 시스템 패키지 설치

| 패키지 | 설명 |
|:-------|:-----|
| python3-pip | Python 패키지 관리자 |
| python3-smbus | I2C 통신 |
| python3-dev | Python 개발 헤더 |
| i2c-tools | I2C 디버깅 도구 |
| python3-gpiozero | GPIO 제어 |
| python3-spidev | SPI 통신 |
| python3-pil | 이미지 처리 (Pillow) |

#### 5.3 Python 패키지 설치

| 패키지 | 용도 |
|:-------|:-----|
| flask, flask-socketio, flask-cors | 웹앱 |
| eventlet | 비동기 서버 |
| rpi_ws281x | WS2812 LED 제어 |
| luma.oled | OLED 디스플레이 |
| smbus2 | I2C 센서 통신 |

#### 5.4 하드웨어 테스트 결과

| 테스트 | 결과 |
|:-------|:----:|
| LED 테스트 (GPIO) | ✅ 성공 |
| I2C 센서 (AHT20, BMP280) | ✅ 성공 |
| WS2812 LED (4개) | ✅ 성공 |

**센서 측정값:**
- AHT20: 온도 26.4°C, 습도 19.6%
- BMP280: 온도 26.9°C, 기압 1017.8 hPa
