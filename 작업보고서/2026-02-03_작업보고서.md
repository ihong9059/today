**문서 내용 (SSH 연결 가이드):**

| 섹션 | 설명 |
|:-----|:-----|
| 개요 | Pi Zero 모델별 특징 비교 (Zero, Zero W, Zero 2 W) |

### 4. Pi Zero W USB SSH 연결 설정 (오전)

#### 4.1 SD 카드 USB 가젯 설정

2개의 SD 카드 (메인 + 예비)에 USB 이더넷 가젯 설정 완료

| 파일 | 추가 내용 |
|:-----|:----------|
| `/boot/firmware/config.txt` | `dtoverlay=dwc2` |
| `/boot/firmware/cmdline.txt` | `modules-load=dwc2,g_cdc` |
| `/boot/firmware/ssh` | 빈 파일 생성 (SSH 활성화) |

**참고:** macOS 호환을 위해 `g_ether` 대신 `g_cdc` 사용

#### 4.2 Pi Zero W 연결 확인

| 연결 방식 | IP | 상태 |
|:----------|:---|:----:|
| WiFi | 192.168.0.15 | ✅ 성공 |
| USB (CDC Ethernet) | 10.0.0.2 | ✅ 성공 |

**USB 연결 구성:**
```
┌─────────────────┐      USB Cable       ┌─────────────────┐
│      Mac        │ ◄──────────────────► │   Pi Zero W     │
│  en6: 10.0.0.1  │    CDC Ethernet      │  usb0: 10.0.0.2 │
└─────────────────┘                      └─────────────────┘
```

#### 4.3 영구 IP 설정

Pi Zero W의 `/etc/dhcpcd.conf`에 USB 고정 IP 추가:

```bash
# USB Ethernet Gadget - Static IP
interface usb0
static ip_address=10.0.0.2/24
```
