## 작업 상세 내용

### 진단 흐름
1. SSH password 인증부터 막힘 → `BatchMode` 비활성 + 비번 입력 시도 → password 자체가 거부됨 (원인 미상, sshd_config 추정)
2. 사용자가 원격 콘솔 직접 사용 가능하다 확인 → 원격 터미널에서 authorized_keys에 직접 추가하는 방향으로 전환
3. 키 등록 후에도 `Permission denied (publickey,password)` → `ssh -vv` verbose 로그로 키 offering·서버 거부 확인
4. 원격 `cat ~/.ssh/authorized_keys`로 내용 확인 → `ssh-ed25519AAAA...Y0Tklenovo@...`로 공백 누락 발견
5. `sed -i 's|ssh-ed25519AAAA|ssh-ed25519 AAAA|; s|Y0Tklenovo|Y0Tk lenovo|'` 적용 → 키 인증 성공
6. 공식 네이티브 설치 스크립트 1발에 설치 완료
