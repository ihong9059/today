## 4. 외부 접속 방법

공인 IP 또는 DDNS 주소를 `{외부주소}`로 가정:

```bash
# Raspberry Pi 4 SSH
ssh -p 4441 uttec@{외부주소}

# Raspberry Pi 5 SSH
ssh -p 5555 uttec@{외부주소}
```

| 서비스 | Pi 4 접속 | Pi 5 접속 |
|--------|-----------|-----------|
| cert-guide | http://{외부주소}:4000 | http://{외부주소}:5002 |
| edu-platform | http://{외부주소}:4002 | http://{외부주소}:5001 |
| SensorMonitor | http://{외부주소}:4050 | http://{외부주소}:5000 |
| device-info | http://{외부주소}:4808 | http://{외부주소}:5004 |
| snu-consulting | http://{외부주소}:4800 | http://{외부주소}:5005 |
