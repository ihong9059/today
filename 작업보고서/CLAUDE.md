## 자격시험 페이지 작성 규칙

### 폴더 구조
```
자격시험/ab_modify/{자격증-영문명}/
├── page.tsx          # 메인 페이지
├── exam/
│   └── page.tsx      # 시험 정보 페이지
└── study/
    ├── page.tsx      # 학습 메인 페이지
    └── {과목명}/
        └── page.tsx  # 각 과목별 문제 페이지
```

### 문제 형식
- 각 과목당 **50문항**
- 4지선다 객관식
- 정답과 해설 포함

### 링크 형식
- 내부 링크: `/category/{분야}/{자격증명}/...`
- 예: `/category/trade/logistics-manager/study/물류관리론`

### 코딩 스타일
- TypeScript 사용
- 컴포넌트명: PascalCase
- 변수명: camelCase
- 들여쓰기: 2 spaces
