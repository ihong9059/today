## 2. 완료된 작업

### Lenovo TB310FU 태블릿 웹서버 구축 (192.168.0.31)

Android/Termux 환경에서 5개의 웹서버를 성공적으로 구축했습니다.

| 서버 | 포트 | 설명 |
|------|:----:|------|
| SensorMonitor | 5000 | 센서 모니터링 서버 |
| cert-guide | 4000 | 자격시험 가이드 (정적 서버) |
| edu-platform Frontend | 3001 | 교육 플랫폼 프론트엔드 |
| edu-platform Backend | 3000 | 교육 플랫폼 백엔드 (Lite 버전) |
| Device Info | 8080 | **시스템 정보 + 서비스 모니터링** |

#### 주요 작업 내용

1. **서버 파일 전송 및 설치**
   - Windows PC에서 Lenovo 태블릿으로 SCP 전송
   - Node.js 모듈 설치 (`express`, `cors`, `pg`)

2. **Device Info 서버 개발** (`device-info/server.js`)
   - Lenovo TB310FU 하드웨어 사양 표시
   - 실시간 서비스 상태 모니터링 (Running/Stopped)
   - HTTP 포트 체크로 각 서비스 상태 확인
   - 서버 시작 방법 가이드 포함

3. **start-all.sh 스크립트 작성**
   - 5개 서버를 순차적으로 시작하는 쉘 스크립트
   - nohup으로 백그라운드 실행

4. **바탕화면 바로가기 생성**
   - `Lenovo TB310FU 시스템 정보.url` → http://192.168.0.31:8080

#### 기술적 해결책
- **Prisma 미지원**: `pg` 라이브러리 직접 사용 (server-lite.js)
- **Next.js 미지원**: PC에서 빌드 후 정적 파일 서빙 (static-server.js)
- **fs.sendFile 오류**: `fs.readFileSync` 사용으로 해결
