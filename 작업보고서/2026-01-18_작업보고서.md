## ★ 월요일 회사에서 할 일: ngrok SSH 터널 설정 ★

### 목표
집에서 회사 Raspberry Pi 5에 SSH 접속 가능하게 만들기

### 사전 조건
- Raspberry Pi 5에 모니터/키보드 연결 또는 내부 SSH 접속
- ngrok이 이미 설치되어 있음 (/usr/local/bin/ngrok)
- authtoken 설정 완료됨

### 단계별 설정 방법

#### Step 1: Raspberry Pi 5에 접속
```bash
# 회사 내부 네트워크에서 SSH 접속
ssh uttec@192.168.1.8
# 비밀번호: uttec
```

#### Step 2: 현재 ngrok 상태 확인
```bash
# 실행 중인 ngrok 프로세스 확인
pgrep -a ngrok

# 결과 예시: 2240 ngrok http 8080
# 현재는 웹서버(8080)만 터널링 중
```

#### Step 3: 기존 ngrok 중지
```bash
# 기존 ngrok 프로세스 종료
pkill ngrok
```

#### Step 4: ngrok 설정 파일 생성 (여러 터널 동시 운영)
```bash
# 설정 파일 편집
nano ~/.config/ngrok/ngrok.yml
```

**ngrok.yml 내용** (아래 내용 복사):
```yaml
version: "2"
authtoken: (기존 토큰 유지)
tunnels:
  web:
    proto: http
    addr: 8080
  ssh:
    proto: tcp
    addr: 22
```

#### Step 5: ngrok 실행 (모든 터널 시작)
```bash
# 모든 터널 시작 (백그라운드)
nohup ngrok start --all --log=stdout > ~/ngrok.log 2>&1 &

# 3초 대기 후 로그 확인
sleep 3 && cat ~/ngrok.log
```

#### Step 6: SSH 터널 URL 확인
```bash
# 로그에서 TCP URL 찾기
grep "tcp://" ~/ngrok.log

# 결과 예시:
# url=tcp://0.tcp.ap.ngrok.io:12345
```

#### Step 7: URL 기록하기
**중요!** 생성된 URL을 메모합니다:
- 웹: https://nonavoidably-unnettled-concha.ngrok-free.dev (고정)
- SSH: `tcp://0.tcp.ap.ngrok.io:XXXXX` (포트 번호 기록 필요)

#### Step 8: 집에서 SSH 접속 테스트
```bash
# 집에서 실행할 명령어 (포트 번호는 Step 6에서 확인한 값으로 변경)
ssh -p XXXXX uttec@0.tcp.ap.ngrok.io
```

### 자동 시작 설정 (선택사항)

부팅 시 자동으로 ngrok 터널을 시작하려면:

```bash
# crontab 편집
crontab -e

# 아래 줄 추가
@reboot sleep 30 && /usr/local/bin/ngrok start --all --config=/home/uttec/.config/ngrok/ngrok.yml --log=stdout > /home/uttec/ngrok.log 2>&1 &
```

### 문제 해결

#### ngrok이 실행되지 않는 경우
```bash
# ngrok 버전 확인
ngrok version

# authtoken 재설정
ngrok config add-authtoken YOUR_TOKEN
```

#### 포트 22가 사용 중이 아닌 경우
```bash
# SSH 서비스 상태 확인
sudo systemctl status ssh

# SSH 서비스 시작
sudo systemctl start ssh
```

#### 로그에서 URL이 안 보이는 경우
```bash
# ngrok 웹 인터페이스 확인 (브라우저에서)
# http://127.0.0.1:4040

# 또는 API로 확인
curl -s http://127.0.0.1:4040/api/tunnels | python3 -m json.tool
```

### 예상 결과

설정 완료 후 집에서 다음 명령어로 접속 가능:
```bash
ssh -p [ngrok에서 할당받은 포트] uttec@0.tcp.ap.ngrok.io
```

## 2. 완료된 작업

### Lenovo TB310FU 태블릿 웹서버 구축 (192.168.0.31)

Android/Termux 환경에서 5개의 웹서버를 성공적으로 구축했습니다.

| 서버 | 포트 | 설명 |
|------|:----:|------|
| SensorMonitor | 5000 | 센서 모니터링 서버 |
| cert-guide | 4000 | 자격시험 가이드 (정적 서버) |
| edu-platform Frontend | 3001 | 교육 플랫폼 프론트엔드 |
| edu-platform Backend | 3000 | 교육 플랫폼 백엔드 (Lite 버전) |
| Device Info | 8080 | **시스템 정보 + 서비스 모니터링** |

#### 주요 작업 내용

1. **서버 파일 전송 및 설치**
   - Windows PC에서 Lenovo 태블릿으로 SCP 전송
   - Node.js 모듈 설치 (`express`, `cors`, `pg`)

2. **Device Info 서버 개발** (`device-info/server.js`)
   - Lenovo TB310FU 하드웨어 사양 표시
   - 실시간 서비스 상태 모니터링 (Running/Stopped)
   - HTTP 포트 체크로 각 서비스 상태 확인
   - 서버 시작 방법 가이드 포함

3. **start-all.sh 스크립트 작성**
   - 5개 서버를 순차적으로 시작하는 쉘 스크립트
   - nohup으로 백그라운드 실행

4. **바탕화면 바로가기 생성**
   - `Lenovo TB310FU 시스템 정보.url` → http://192.168.0.31:8080

#### 기술적 해결책
- **Prisma 미지원**: `pg` 라이브러리 직접 사용 (server-lite.js)
- **Next.js 미지원**: PC에서 빌드 후 정적 파일 서빙 (static-server.js)
- **fs.sendFile 오류**: `fs.readFileSync` 사용으로 해결
