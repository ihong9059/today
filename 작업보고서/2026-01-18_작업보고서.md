## ★ Cloudflare Tunnel SSH 접속 방법 ★

### 접속 정보
| 항목 | 내용 |
|------|------|
| 도메인 | example-atmospheric-week-involved.trycloudflare.com |
| 사용자 | uttec |
| 비밀번호 | uttec |
| cloudflared 위치 | C:\todo\today\cloudflared.exe |

### PC 새로 켜고 접속하는 방법 (2단계)

#### Step 1: cloudflared 프록시 시작 (터미널 1)
```bash
"C:\todo\today\cloudflared.exe" access tcp --hostname example-atmospheric-week-involved.trycloudflare.com --url localhost:2222
```
(이 터미널은 열어둔 상태로 유지)

#### Step 2: SSH 접속 (터미널 2 - 새 터미널 열기)
```bash
ssh -p 2222 uttec@localhost
```
비밀번호 입력: `uttec`

### 한 줄 명령어 (백그라운드 실행)
```bash
# 프록시를 백그라운드로 실행하고 바로 SSH 접속
start "" "C:\todo\today\cloudflared.exe" access tcp --hostname example-atmospheric-week-involved.trycloudflare.com --url localhost:2222
timeout 3
ssh -p 2222 uttec@localhost
```

### 문제 해결

| 문제 | 해결책 |
|------|--------|
| "connection refused" 오류 | cloudflared 프록시가 실행 중인지 확인. Step 1을 먼저 실행 |
| 프록시가 이미 실행 중인데 안 됨 | `taskkill /f /im cloudflared.exe` 후 Step 1부터 다시 시작 |
| 회사 Pi 5가 꺼져 있으면 | 접속 불가. 회사에서 Pi 5를 켜야 함 |

### 상세 접속 정보 파일
`C:\todo\today\pem\rpi5-cloudflare-connection.txt` 참조

### Lenovo TB310FU 태블릿 웹서버 구축 (192.168.0.31)

Android/Termux 환경에서 5개의 웹서버를 성공적으로 구축했습니다.

| 서버 | 포트 | 설명 |
|------|:----:|------|
| SensorMonitor | 5000 | 센서 모니터링 서버 |
| cert-guide | 4000 | 자격시험 가이드 (정적 서버) |
| edu-platform Frontend | 3001 | 교육 플랫폼 프론트엔드 |
| edu-platform Backend | 3000 | 교육 플랫폼 백엔드 (Lite 버전) |
| Device Info | 8080 | **시스템 정보 + 서비스 모니터링** |

#### 주요 작업 내용

1. **서버 파일 전송 및 설치**
   - Windows PC에서 Lenovo 태블릿으로 SCP 전송
   - Node.js 모듈 설치 (`express`, `cors`, `pg`)

2. **Device Info 서버 개발** (`device-info/server.js`)
   - Lenovo TB310FU 하드웨어 사양 표시
   - 실시간 서비스 상태 모니터링 (Running/Stopped)
   - HTTP 포트 체크로 각 서비스 상태 확인
   - 서버 시작 방법 가이드 포함

3. **start-all.sh 스크립트 작성**
   - 5개 서버를 순차적으로 시작하는 쉘 스크립트
   - nohup으로 백그라운드 실행

4. **바탕화면 바로가기 생성**
   - `Lenovo TB310FU 시스템 정보.url` → http://192.168.0.31:8080

#### 기술적 해결책

- **Next.js 미지원**: PC에서 빌드 후 정적 파일 서빙 (static-server.js)
