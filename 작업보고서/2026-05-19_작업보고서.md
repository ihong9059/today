## 후반 추가 작업 (12:30~14:00) — LoRa v3 loopback + 박제 강화

### A. LoRa 펌웨어 v3 loopback (양방향 검증)
사용자 요청: TX 보드 1대로 거리 테스트 가능하도록 (LED1=송신 ON, LED2=echo 수신 toggle):
- **RX 동작**: 수신 즉시 12-byte echo back + LED1 toggle (수신 표시)
- **TX 동작**: 송신 후 echo 대기 (ECHO_TIMEOUT_MS=3000ms) + LED2 toggle (echo 수신 표시)
- 타이밍 조정: TX_PERIOD_MS 2000 → **4000 ms** (round-trip ~1.74s + 안전 마진)
- LED 매핑: led0=LED1 (P0.17), led1=LED2 (P0.18) DT alias
- 빌드·플래시 양 보드 완료 → round-trip RSSI -2~-13 dBm 검증 (벤치 1m)
