### 2. 192.168.0.9 PC에 SSH do-server 설정

Windows PC(192.168.0.9)에서 `ssh do-server`로 DigitalOcean 서버에 접속 가능하도록 설정

| 항목 | 내용 |
|:-----|:-----|
| 대상 PC | 192.168.0.9 (Windows, user/3232) |
| PEM 키 복사 | `C:\Users\user\.ssh\uttec-first-ec2.pem` |
| SSH config 생성 | `C:\Users\user\.ssh\config` |
| 접속 테스트 | `ssh do-server` → 성공 (ubuntu-s-2vcpu-4gb-sgp1-01) |

**설정 내용 (`C:\Users\user\.ssh\config`):**
```
Host do-server
    HostName 178.128.90.37
    User root
    IdentityFile ~/.ssh/uttec-first-ec2.pem
    StrictHostKeyChecking no
```
