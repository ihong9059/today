## 1. 완료된 작업

### [2026-01-13] SensorMonitor 3D 캘리브레이션 디버깅

#### JavaScript 오류 수정
- `updateRotation` 함수에서 존재하지 않는 HTML 요소 참조 오류 수정
  - `dbgAz`, `dbgPitch`, `dbgRoll`, `dbgDeltaAz` 등 제거
- Gravity 센서 데이터가 `updateTilt` 함수까지 전달되지 않던 문제 해결

#### Gravity 센서 디버그 패널 수정
- gx, gy, gz 값 실시간 표시
- 계산된 Roll/Pitch 표시
- 보정 후 Roll/Pitch 표시
- 3D 모델 rotX, rotY, rotZ 값 표시

#### Roll 방향 수정
- 3D 모델 Roll 방향이 반대로 움직이던 문제 수정
- `-finalRoll` → `finalRoll`로 변경

#### Yaw(수평 회전) 지원 추가
- Orientation 센서의 azimuth 값을 사용하여 수평 회전 구현
- calHome 기준으로 deltaYaw 계산

#### 센서 혼합 문제 해결
- **문제**: Gravity 센서 + Orientation 센서 혼합 사용 시 충돌 발생
- **해결**: Orientation 센서만 사용하도록 변경
  - 모든 회전(Yaw, Pitch, Roll)을 Orientation 센서 데이터로 처리

#### Three.js 회전 순서 설정
- `rotation.order = 'YXZ'` 설정 (Yaw → Pitch → Roll)
