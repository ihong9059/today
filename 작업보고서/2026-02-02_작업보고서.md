### 5. Claude Code Alarm Hook 설정 (오전)

사용자 입력 대기 시 알림 소리가 울리도록 Hook 설정

**설정 파일:** `~/.claude/settings.json`

**설정 내용:**
```json
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "AskUserQuestion",
      "command": "afplay /System/Library/Sounds/Funk.aiff"
    }]
  }
}
```

| 항목 | 내용 |
|:-----|:-----|
| 트리거 | AskUserQuestion 도구 사용 시 |
| 알림 소리 | Funk (macOS 기본 사운드) |
| 적용 시점 | Claude Code 재시작 후 |

**참고:** 글로벌 설정(`~/.claude/`)은 Git 동기화 안됨. PC별로 개별 설정 필요.

### 6. RaspShield 프로젝트 (오후)

Raspberry Pi 4 확장보드 하드웨어 테스트 및 웹 앱 개발

#### 6.1 하드웨어 테스트 완료

| 순번 | 하드웨어 | GPIO/I2C | 상태 |
|:----:|:---------|:---------|:----:|
| 1 | LED (RED/YELLOW/BLUE) | GPIO17/27/22 (Low Active) | ✅ |
| 2 | WS2812 RGB LED x4 | GPIO12 | ✅ |
| 3 | WS2812 64-LED Matrix | GPIO10 (MOSI) | ✅ |
| 4 | AHT20 온습도 센서 | I2C 0x38 | ✅ |
| 5 | BMP280 기압 센서 | I2C 0x77 | ✅ |
| 6 | MPU6050 가속도/자이로 | I2C 0x68 | ✅ |
| 7 | OLED 디스플레이 | I2C 0x3C (128x64) | ✅ |
| 8 | ALARM 부저 | GPIO5 (Low Active) | ✅ |
| 9 | SPEAKER | GPIO13 (PWM) | ✅ |
| 10 | SWITCH | GPIO4 | ✅ |

#### 6.2 웹 애플리케이션 개발

**기술 스택:** Flask + Flask-SocketIO + JavaScript

| 구성 요소 | 파일 | 설명 |
|:----------|:-----|:-----|
| 백엔드 | app.py | Flask 메인 앱 (REST API + WebSocket) |
| 설정 | config.py | GPIO, I2C, WS2812 설정 |
| 센서 | hardware/sensors.py | AHT20, BMP280, MPU6050 |
| LED | hardware/leds.py | RGB LED 제어 |
| WS2812 | hardware/ws2812.py | 4-LED, 64-LED 매트릭스 |
| 디스플레이 | hardware/display.py | OLED 제어 |
| 오디오 | hardware/audio.py | ALARM, SPEAKER |
| 프론트엔드 | templates/, static/ | HTML, CSS, JS |

**REST API 엔드포인트:**

| 엔드포인트 | 메소드 | 기능 |
|:-----------|:-------|:-----|
| /api/sensors | GET | 전체 센서 데이터 |
| /api/led | GET/POST | LED 상태/제어 |
| /api/ws2812/4 | POST | 4-LED 색상 제어 |
| /api/ws2812/64 | POST | 64-LED 매트릭스 (문자 표시) |
| /api/alarm | POST | ALARM 비프음 |
| /api/speaker | POST | 멜로디 재생 |
| /api/oled | POST | OLED 텍스트/센서 표시 |

#### 6.3 기울기 표시 기능 추가

MPU6050을 이용한 십자가 형태 기울기 표시 UI 개발

| 기능 | 설명 |
|:-----|:-----|
| 십자가 표시 | 앞/뒤/좌/우 방향 원형 인디케이터 |
| 실시간 기울기 | 가속도계 기반 pitch/roll 계산 |
| 원점 리셋 | 현재 위치를 0도 기준으로 설정 |
| 색상 변화 | 수평(파랑) → 중간(노랑) → 큰 기울기(빨강) |
