### 🔧 세션 2: 넷북 실제 구축 작업

#### RDP 원격 접속 설정
- 키보드 4,0 키 고장 → 화상 키보드(osk)로 IP 수동 설정
- `net user UTSOL uttec` 비밀번호 재설정
- 시스템 속성 → 원격 설정 → 원격 데스크톱 허용
- 접속 확인: 유선 10.0.0.2 / WiFi 192.168.0.199

#### 디스크 파티션 통합
- C:97GB + D:200GB → **C:298GB 단일 파티션**
- diskpart: `select volume 1 → delete volume override → select volume 0 → extend`
