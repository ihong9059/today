### 1. 콘텐츠(Contents) 정의와 미래 트렌드 분석 보고서

**목적**: 콘텐츠의 본질과 전달 방식의 역사적 진화, 미래 트렌드 분석

**주요 내용**:
- 콘텐츠의 정의: 인간이 전달하고자 하는 모든 형태의 정보, 메시지, 경험, 가치
- 전달 방식 진화: 구전 → 인쇄 → 방송 → 인터넷 → 모바일 → AI
- 미래 트렌드: 숏폼, AI 생성 콘텐츠, 개인화, 메타버스/XR

**핵심 통찰**: "콘텐츠는 항상 존재했다. 변한 것은 전달의 속도, 범위, 형태뿐이다."

**파일**: `contents/contents-definition-and-future-trends.md`

### 3. 전시회용 단독 웹서버 구축

**목적**: 전시회 현장에서 인터넷 없이 운영 가능한 데모 페이지

**구성**:
```
전시회/webserver/
├── index.html          # 메인 페이지 (스마트 파쇄기 소개)
├── about.html          # 회사 소개
├── diagram.html        # 시스템 구성도
├── monitor.html        # 모니터링 데모
├── system.html         # 시스템 설명
├── server.py           # Python 웹 서버
├── start_server.bat    # Windows 실행 스크립트
└── README.md           # 사용 가이드
```

**특징**:
- 완전 오프라인 운영 가능
- 다크 모드 UI
- 60인치 대형 화면 최적화
- 반응형 레이아웃

**실행**: `start_server.bat` 더블클릭 → http://localhost:8080
