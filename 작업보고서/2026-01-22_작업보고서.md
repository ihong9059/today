## 2. 오늘 작업 내용

### 2.1 한국 자동차 번호판 리스트 생성

AI 번호판 인식 시뮬레이션 테스트를 위한 번호판 데이터 100개 생성

#### 생성된 파일

| 파일명 | 형식 | 용도 |
|--------|------|------|
| `korean_plate_list.md` | Markdown | 번호판 체계 설명 + 전체 리스트 |
| `korean_plates.csv` | CSV | 프로그램용 데이터 |
| `korean_plates.json` | JSON | API/프로그램용 데이터 |
| `plate_numbers.txt` | TXT | 번호판 번호만 (100개) |

#### 번호판 구성

| 분류 | 개수 | 형식 예시 |
|------|:----:|----------|
| 신형 일반 | 53개 | `123가4567` |
| 신형 전기차 | 10개 | `700가1234` |
| 신형 사업용 | 7개 | `111바1234` |
| 구형 | 30개 | `12가3456` |

### 2.2 번호판 이미지 합성 가이드 작성

현실적인 AI 테스트용 이미지 생성을 위한 상세 가이드 문서 작성

#### 가이드 내용 (`번호판_이미지_합성_가이드.md`)

| 단계 | 내용 |
|:----:|------|
| 1단계 | 준비 - 자동차 이미지 수집, 폰트, Python 환경 |
| 2단계 | 번호판 이미지 생성 (Pillow) |
| 3단계 | 합성 - 좌표 지정, 원근 변환 (OpenCV) |
| 4단계 | 데이터 증강 - 노이즈, 밝기, 블러 |
| 5단계 | 라벨링 - YOLO/COCO 형식 |

#### 포함된 Python 스크립트 코드

- `generate_plate.py` - 번호판 이미지 생성
- `select_corners.py` - 마우스로 번호판 영역 좌표 선택
- `composite_plate.py` - 번호판 합성 (원근 변환)
- `augment_images.py` - 데이터 증강
- `generate_labels.py` - YOLO 형식 라벨 생성

## 4. Jetson Nano 번호판 인식 테스트

### 4.1 테스트 환경

| 항목 | 내용 |
|------|------|
| 대상 기기 | Jetson Nano (192.168.1.11) |
| OCR 엔진 | Tesseract OCR (EasyOCR 설치 실패로 대체) |
| 테스트 이미지 | 10개 (동일한 번호판 이미지) |

### 4.2 EasyOCR 설치 실패 원인

| 문제 | 원인 |
|------|------|
| numpy 호환성 | manylinux2014_aarch64 wheel이 Jetson Nano CPU와 비호환 |
| Illegal instruction | ARM 아키텍처 특정 명령어 세트 차이 |
| opencv-python-headless | 빌드 실패 (CMake 문제) |

→ **Tesseract OCR로 대체하여 테스트 진행**

### 4.3 Tesseract OCR 테스트 결과

| 플랫폼 | OCR 엔진 | 인식 성공 | 인식률 | 이미지당 시간 | 총 시간 |
|--------|----------|:---------:|:------:|:-------------:|:-------:|
| **Jetson Nano** | Tesseract | 2/10 | **20%** | 6.28초 | 62.81초 |
| MacBook Pro 2015 | Tesseract | 0/10 | 0% | 0.79초 | 7.89초 |

### 4.4 EasyOCR vs Tesseract 비교

| OCR 엔진 | 인식률 | 장점 | 단점 |
|----------|:------:|------|------|
| **EasyOCR** | 70% | 딥러닝 기반, 높은 정확도 | 무거움, Jetson 호환 어려움 |
| **Tesseract** | 0~20% | 가벼움, 설치 쉬움 | 한글 인식 부정확 |

### 4.5 EasyOCR GPU 테스트 성공! (최종)

**해결 방법:**
1. numpy 1.19.4 설치 (Jetson 호환 버전)
2. EasyOCR 1.6.2 설치 (PyTorch 1.10 호환)
3. python-bidi 패치 (import 경로 수정)
4. 이미지 크기 640px로 제한 (GPU 메모리 최적화)

#### EasyOCR GPU 테스트 결과

| 항목 | 값 |
|------|-----|
| 인식 성공 | **7/10 (70%)** |
| 총 소요시간 | 112초 (모델 로딩 포함) |
| 이미지당 평균 | ~11초 |

### 4.6 전체 플랫폼 비교

### 4.8 벤치마크 테스트 방법 (Lenovo, RPi5용)

#### 1단계: 환경 준비

```bash
# 1. aiTest 폴더 복사 (USB 또는 git clone)
git clone https://github.com/ihong9059/today.git
cd today/aiTest

# 2. Python 가상환경 생성 (권장)
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 또는 venv\Scripts\activate  # Windows

# 3. 패키지 설치
pip install easyocr opencv-python
```

#### 2단계: 벤치마크 실행

```bash

python3 benchmark_ocr.py
```
