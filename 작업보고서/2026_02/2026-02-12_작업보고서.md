## 작업 상세 내용

### 1. ESP32-C6 + ICS-43434 음성 인식 방법 조사

**목적**: ESP32-C6 마이크로컨트롤러와 ICS-43434 I2S MEMS 마이크를 사용한 음성 인식 구현 방법 조사

**하드웨어 연결 정리**:
| ICS-43434 | ESP32-C6 |
|-----------|----------|
| SCK | GPIO 6 (I2S_CLK) |
| WS | GPIO 7 (I2S_WS) |
| SD | GPIO 8 (I2S_DIN) |
| VDD | 3.3V |
| GND | GND |

**조사된 구현 방법**:

1. **ESP-SR (온디바이스)** - Espressif 공식 라이브러리
   - WakeNet: 웨이크 워드 감지
   - MultiNet: 명령어 인식
   - AFE: 노이즈 제거, 에코 캔슬링

2. **클라우드 API 연동**
   - Google Cloud Speech-to-Text
   - OpenAI Whisper API
   - Azure Speech Services

3. **Edge Impulse (커스텀 ML)**
   - 자신만의 음성 모델 학습 가능
   - ESP32용 라이브러리로 내보내기

4. **VAD (Voice Activity Detection)**
   - 단순 음성 유무 감지
   - 에너지 기반 검출

**추천 조합**:
| 목적 | 추천 방식 |
|------|----------|
| 웨이크 워드만 | ESP-SR WakeNet |
| 간단한 명령어 | ESP-SR MultiNet |
| 자유로운 대화/STT | 클라우드 API (Whisper) |
| 특정 키워드 감지 | Edge Impulse |
