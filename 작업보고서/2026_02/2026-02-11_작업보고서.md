### 1. 전시회 웹서버 영어 지원 - 두 가지 방식 구현

**목적**: 전시회 현장에서 외국인 관람객을 위한 영어 지원

**방식 1: webserver_toggle (포트 8081)**
- KO/EN 토글 버튼으로 언어 전환
- 동일 페이지에서 실시간 언어 변경
- data-ko/data-en 속성 사용

**방식 2: webserver_separate (포트 8082)**
- 별도의 영문 페이지 (*_en.html)
- 한국어/English 링크로 페이지 전환
- 10개 HTML 파일 (한글 5개 + 영문 5개)

**폴더 구조**:
```
전시회/
├── webserver/           # 기존 한글 전용 (포트 8080)
├── webserver_toggle/    # KO/EN 토글 방식 (포트 8081)

```

**문서 페이지 추가**:
