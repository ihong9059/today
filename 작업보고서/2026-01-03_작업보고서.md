### [2026-01-03 오후] HTML 파일 CSS content 속성 버그 수정

- **문제**: CSS `content` 속성에서 HTML 엔티티(`&#10003;` 등)가 렌더링되지 않고 원시 텍스트로 표시
- **원인**: CSS content 속성은 HTML 엔티티가 아닌 유니코드 이스케이프 시퀀스를 사용해야 함
- **해결**: HTML 엔티티를 CSS 유니코드 이스케이프로 변환

| 수정 전 | 수정 후 | 문자 |
|---------|---------|------|
| `&#10003;` | `\2713` | ✓ (체크마크) |
| `&#9679;` | `\25CF` | ● (검은원) |
| `&#8594;` | `\2192` | → (화살표) |

- **수정된 파일** (8개):
