## 7-1. Claude 세션 규칙 (모든 세션 필수 적용)

### 입력 요청 시 비프음 알림
사용자에게 입력을 요청하거나 확인이 필요할 때 아래 명령어로 비프음을 재생합니다:

```bash
python3 -c "
import subprocess, math, wave, struct, os
duration, frequency, sample_rate, amplitude = 1.0, 1000, 44100, 32767
samples = int(duration * sample_rate)
wav_file = '/tmp/beep.wav'
with wave.open(wav_file, 'w') as f:
    f.setnchannels(1); f.setsampwidth(2); f.setframerate(sample_rate)
    for i in range(samples):
        f.writeframes(struct.pack('<h', int(amplitude * math.sin(2 * math.pi * frequency * i / sample_rate))))
subprocess.run(['afplay', '-v', '2', wav_file]); os.remove(wav_file)
"
```

**적용 시점:**
- 사용자에게 질문할 때
- 작업 완료 후 다음 지시를 기다릴 때
- 확인이나 승인이 필요할 때
