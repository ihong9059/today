### [2026-01-19] webServer를 Raspberry Pi 5에 배포

Mac의 webServer 폴더를 회사 Raspberry Pi 5 (192.168.1.8)에 복사하고 PM2로 실행했습니다.

#### 배포된 서비스

| 서비스 | 포트 | 상태 | 설명 |
|--------|:----:|:----:|------|
| sensor-monitor | 5000 | ✅ online | 센서 모니터링 |
| cert-guide | 3000 | ✅ online | 자격시험 가이드 |
| edu-backend | 3001 | ✅ online | 교육 플랫폼 API |
| edu-frontend | 3002 | ✅ online | 교육 플랫폼 웹 |
| snu-consulting | 8000 | ✅ online | SNU Consulting |
| device-info | 8080 | ✅ online | 시스템 정보 |

#### 접속 정보
```bash
# SSH 접속
sshpass -p 'uttec' ssh uttec@192.168.1.8

# PM2 서비스 관리
pm2 status
pm2 restart all
pm2 logs
```

#### 수정 사항
- `device-info/server.js`: edu-platform Backend (포트 3001) "열기" 링크 제거 (보안)
