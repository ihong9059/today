## 작업 상세 내용

### BLE OTA 바이브 코딩 시스템 (신규 프로젝트)
- 핵심 컨셉: 사용자가 스마트폰 앱에 자연어로 원하는 동작을 입력 → 클라우드 서버가 Claude Code CLI에 펌웨어 작성 의뢰 → ESP-IDF로 빌드 → .bin을 스마트폰으로 다운로드 → BLE OTA로 ESP32-C3에 무선 플래싱
- 3-Tier 아키텍처: ESP32-C3 (Device) ↔ Smartphone App (Client) ↔ Cloud Server (Intelligence)
- 검증된 5개 기술의 결합: ESP32 BLE OTA + Android BLE GATT + Claude Code CLI + Linux ESP-IDF + HTTPS
- 핵심 강점: 어제(4/6) Claude Code CLI 통합과 Windows 호환성 이슈 3건 해결로 이미 검증된 기술 위에 구축
