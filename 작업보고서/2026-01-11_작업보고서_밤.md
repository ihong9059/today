### 현재 상태 (미해결)
- **문제**: 배터리만 표시되고 다른 센서 데이터가 표시되지 않음
- **원인 추정**: `get_sensor()` 함수의 JSON 파싱 로직 문제
- **수정 필요**: `data[0].get("values", [])` → `data[sensor_name].get("values", [])`

### 수정된 코드 (app.py의 get_sensor 함수)
```python
def get_sensor(sensor_name, count=1):
    try:
        result = subprocess.run(
            ["termux-sensor", "-s", sensor_name, "-n", str(count)],
            capture_output=True, text=True, timeout=5
        )
        data = json.loads(result.stdout)
        # Format: {"SensorName": {"values": [...]}}
        if data and sensor_name in data:
            return data[sensor_name].get("values", [])
    except:
        pass
    return None
```

### 다음 세션에서 해야 할 작업
1. **스마트폰의 app.py 파일 수정 확인**
   ```bash
   cat ~/sensor_app/app.py | grep "Format:"
   ```
   - `# Format: {"SensorName": {"values": [...]}}` 출력되면 OK

2. **파일이 업데이트 안 된 경우 수동 수정**
   ```bash
   # 스마트폰 Claude Code에서
   ~/sensor_app/app.py 파일에서 get_sensor 함수를 수정해줘.
   data[0].get("values", []) 를 data[sensor_name].get("values", []) 로 변경해야해.
   ```

3. **서버 재시작 후 테스트**
   ```bash
   cd ~/sensor_app && python app.py
   # 브라우저에서 http://192.168.0.12:5000 접속
   # Start/Stop 버튼 클릭
   ```

## 주의사항

1. **Termux 백그라운드 유지**: 스마트폰 화면이 꺼지면 SSH/서버가 종료될 수 있음
   ```bash
   termux-wake-lock  # 백그라운드 유지
   ```

2. **SSH 서버 시작**: Termux 재시작 시 SSH 서버도 재시작 필요
   ```bash
   sshd
   ```

3. **IP 주소 변경 가능**: Wi-Fi 재연결 시 IP가 바뀔 수 있음
   ```bash
   ifconfig wlan0 | grep inet
   ```
