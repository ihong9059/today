# Claude Code 세션 연결 방법

## 1. 같은 폴더에서 다시 시작

```bash
cd C:\todo\today
claude
```

같은 폴더에서 시작하면 이전 컨텍스트(git 상태, 파일 구조)를 자동으로 인식합니다.

---

## 2. 대화 이어가기 (`--continue`)

```bash
claude --continue
```

가장 최근 대화를 이어서 진행합니다.

**사용 시점:**
- 잠시 터미널을 닫았다가 다시 열었을 때
- 같은 작업을 계속 이어가고 싶을 때

---

## 3. 특정 대화 재개 (`--resume`)

```bash
claude --resume
```

이전 대화 목록에서 선택해서 재개할 수 있습니다.

**사용 시점:**
- 여러 대화 중 특정 대화를 선택해서 이어가고 싶을 때
- 며칠 전 대화를 다시 이어가고 싶을 때

---

## 4. 세션 유지하면서 이동하는 방법

| 방법 | 설명 |
|------|------|
| 절전 모드 | 노트북을 닫지 않고 절전 모드로 이동 |
| 터미널 유지 | 터미널을 열어둔 채로 이동 |

---

## 5. 새 장소에서 작업 재개

```bash
# 1. 작업 폴더로 이동
cd C:\todo\today

# 2. 최근 대화 이어가기
claude --continue

# 또는 대화 목록에서 선택
claude --resume
```

---

## 6. 기타 유용한 옵션

```bash
# 도움말 보기
claude --help

# 새 대화 시작 (이전 대화 무시)
claude

# 특정 프롬프트로 시작
claude "오늘 할 일 알려줘"
```

---

## 참고사항

- `--continue`와 `--resume`의 차이:
  - `--continue`: 가장 최근 대화를 자동으로 이어감
  - `--resume`: 대화 목록을 보여주고 선택할 수 있음

- 세션이 끊어져도 작업 내용은 git에 커밋되어 있으므로 안전합니다.
