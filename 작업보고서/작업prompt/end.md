## Claude Code 작업 규칙

### Git 커밋 시 필수 절차

**중요: 절대 확인 없이 commit하지 말 것!**

| 순서 | 명령어 | 설명 |
|:----:|:-------|:-----|
| 1 | `git status` | 변경/추가 파일 목록 확인 |
| 2 | `git diff --stat` | 변경 내용 확인 |
| 3 | `git log --oneline -3` | 최근 커밋 스타일 확인 |
| 4 | **사용자 확인 요청** | 커밋할 내용 보여주고 승인받기 |
| 5 | `git add` → `git commit` → `git push` | 승인 후 순차 실행 |
