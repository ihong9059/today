### ffmpeg 호환성 해결
```bash
# fdk-aac 설치
brew install fdk-aac

# ffmpeg with libfdk-aac 빌드 (약 30분)
brew tap homebrew-ffmpeg/ffmpeg
brew install homebrew-ffmpeg/ffmpeg/ffmpeg --with-fdk-aac

# Remotion 심볼릭 링크 설정
ln -sf /usr/local/bin/ffmpeg node_modules/@remotion/compositor-darwin-x64/ffmpeg
ln -sf /usr/local/bin/ffprobe node_modules/@remotion/compositor-darwin-x64/ffprobe
```
