## 3. 오늘 작업 내용

### [2026-01-20] Jetson Nano VNC 설정

uttec 사용자로 VNC 원격 접속이 가능하도록 설정했습니다.

#### 변경 사항

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 자동 로그인 | jetson | **uttec** |
| VNC 서버 | 수동 시작 | **자동 시작** |
| VNC 암호화 | 활성화 | 비활성화 (쉬운 연결) |

#### 설정 파일

- `/etc/gdm3/custom.conf` - 자동 로그인 사용자 변경
- `~/.config/autostart/vino-server.desktop` - VNC 자동 시작
- `~/.config/autostart/ibus-hangul-fix.desktop` - ibus 자동 재시작

#### 접속 방법

```
VNC 주소: 192.168.0.33:5900
```

### [2026-01-20] Jetson Nano 한글 입력 설정

ibus-hangul을 이용한 한글 입력 설정을 완료했습니다.

#### 설정 내용

| 항목 | 설정값 |
|------|--------|
| 입력기 | ibus-hangul |
| 입력 소스 | English (US) + Korean (Hangul) |
| 한/영 전환 | **Shift + Space** |
| 초기 모드 | Hangul |

#### 설정 파일

- `~/.config/ibus/hangul/setup.conf` - hangul 엔진 설정
- dconf `/desktop/ibus/general/preload-engines` - 엔진 프리로드
- dconf `/desktop/ibus/general/hotkey/trigger` - 전환 단축키

## 5. 향후 검토 사항

### Jetson Nano CLI 모드 전환 검토

GUI를 사용하지 않을 경우, CLI(텍스트) 모드로 부팅하면 리소스를 절약할 수 있습니다.

#### 예상 효과

| 항목 | GUI 모드 | CLI 모드 |
|------|:--------:|:--------:|
| 메모리 사용 | ~1.5GB | ~0.5GB |
| 절약량 | - | **약 1GB** |

#### 전환 명령어

```bash
# CLI 모드로 변경 (GUI 비활성화)
sudo systemctl set-default multi-user.target

# 다시 GUI 모드로 돌아가려면
sudo systemctl set-default graphical.target
```

#### 주의사항

- CLI 모드에서는 **VNC 접속 불가** (SSH로만 접속)
- 한글 입력 설정 불필요 (터미널에서는 영문 사용)
