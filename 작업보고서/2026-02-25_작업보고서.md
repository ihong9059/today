### 3. AI FanStick MVP 코드 구현
**방법1 (로컬DB + 시스템 프롬프트)** 기반 전체 시스템 구현 완료

#### 3.1 로컬 서버 (FastAPI + Gemini)
- `server/main.py`: FastAPI REST API 서버 (8080 포트)
- `server/gemini_service.py`: Gemini 2.0 Flash API 연동
- `server/prompt_generator.py`: 동적 시스템 프롬프트 생성
- `server/data/concert_data.json`: BTS 콘서트 데이터 (8곡 셋리스트)

**주요 API 엔드포인트**:
- `POST /api/ask`: AI 질문 처리 (LED 색상 포함 응답)
- `GET /api/concert`: 콘서트 정보 조회
- `POST /api/song/next`, `/api/song/prev`: 곡 이동

#### 3.2 ESP32-C3 펌웨어 (PlatformIO)
- `firmware/src/main.cpp`: 메인 펌웨어
- `firmware/src/ble_server.h`: BLE Peripheral 서버
- `firmware/src/led_controller.h`: WS2812 LED 제어 (5개 패턴)
- `firmware/src/oled_display.h`: SSD1306 OLED 표시

**BLE 명령 프로토콜**: `C:R,G,B` (색상), `P:패턴` (rainbow/pulse/blink), `T:텍스트`, `B:버저`

#### 3.3 Android 앱 (Kotlin + Compose)
- `app/src/main/.../ui/MainActivity.kt`: Jetpack Compose UI
- `app/src/main/.../ui/MainViewModel.kt`: 상태 관리
- `app/src/main/.../ble/BleManager.kt`: BLE 통신
- `app/src/main/.../api/ApiService.kt`: Retrofit API 클라이언트

**주요 기능**: 음성 입력(STT) → AI 응답 → TTS 출력 + BLE LED 제어
