## 작업 상세 내용

### A. PHY 심층 자료 (`5_OOK_2.176MHz_BiasT_상세.md`)

- 미팅에서 클라이언트가 "OOK PHY 어떻게 구현?" 류 기술 질문 시 즉시 깊이 답변 가능
- 핵심 driver IC: **ADI / Maxim MAX11947** (AISG v2/v3 통합 4채널 single-chip, 3×3 mm TQFN, +15 dB spectral mask margin)
- PHY 핵심 사양: carrier 2.176 MHz / 9.6 kbps / +3 dBm 0.89 Vpp / RX BPF 200 kHz / xtal 8.704 MHz ±100 ppm / DC 10-30V 2A
- Bias-T L/C 토폴로지 + Smart Bias-T 시스템도 + 외부 조달 5 vendor (Kaelus / HUBER+SUHNER / Amphenol / CCI / RFS)
- Q&A 6개 시뮬레이션 + 수주 후 Phase 1 검증 순서 10주 plan
- 미팅 1회용이 아닌 AISG 시장 진입 후 후속 영업·교육 자산
