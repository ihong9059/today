# 스마트폰 CCTV 설정 가이드 (Tailscale + IP Webcam)

스마트폰 카메라를 외부 PC에서 CCTV처럼 실시간으로 볼 수 있도록 설정하는 방법.

---

## 구성 요소

| 항목 | 내용 |
|------|------|
| 스마트폰 앱 | IP Webcam (Android) |
| 네트워크 | Tailscale VPN |
| 스마트폰 Tailscale IP | `100.117.189.72` |
| IP Webcam 포트 | `8080` (기본값) |

---

## 설정 절차

### 1. 스마트폰 설정

1. **Tailscale** 앱 실행 → 연결 확인 (IP: `100.117.189.72`)
2. **IP Webcam** 앱 실행 → 하단 **"Start server"** 탭
3. 서버 시작되면 화면에 로컬 IP 표시됨 (예: `http://192.168.x.x:8080`)

### 2. 외부 PC 설정

1. **Tailscale 설치** → 스마트폰과 **같은 계정**으로 로그인
2. Tailscale 연결 확인

### 3. 외부 PC에서 접속

브라우저에서 아래 URL 접속:

```
http://100.117.189.72:8080
```

---

## 주요 접속 URL

| 용도 | URL |
|------|-----|
| 웹 인터페이스 (전체) | `http://100.117.189.72:8080` |
| 실시간 영상 (브라우저) | `http://100.117.189.72:8080/videofeed` |
| MJPEG 스트림 | `http://100.117.189.72:8080/video` |
| 스냅샷 (정지 이미지) | `http://100.117.189.72:8080/shot.jpg` |
| 오디오 스트림 | `http://100.117.189.72:8080/audio.wav` |

---

## VLC 미디어 플레이어로 보기

브라우저 대신 VLC를 사용하면 더 안정적으로 시청 가능.

1. VLC 열기
2. **미디어 → 네트워크 스트림 열기** (Ctrl+N)
3. URL 입력: `http://100.117.189.72:8080/video`
4. 재생 클릭

---

## 동작 원리

```
스마트폰 (IP Webcam)          외부 PC
  카메라 캡처                  브라우저/VLC
       │                          │
       ▼                          ▼
  HTTP 서버 (:8080)    ◄── Tailscale VPN ──►  접속
  100.117.189.72:8080         (같은 계정)
```

- Tailscale은 두 기기를 같은 가상 네트워크로 연결
- 포트포워딩, 공인 IP, ngrok 등 불필요
- 암호화된 P2P 터널로 보안 우수

- [ ] 외부 PC: Tailscale 연결됨

## 참고

- IP Webcam 앱에서 해상도, 화질, 방향 등 설정 가능
- 스마트폰 화면 꺼짐 방지: IP Webcam 설정 → "Stay awake" 활성화
- 배터리 소모가 크므로 충전기 연결 상태에서 사용 권장
- Tailscale IP는 기기별 고정이므로 한 번 설정하면 계속 동일
