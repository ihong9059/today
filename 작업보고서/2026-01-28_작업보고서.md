## Claude Code 작업 규칙

### Git 커밋 시 필수 절차

**중요: 절대 확인 없이 commit하지 말 것!**

| 순서 | 명령어 | 설명 |
|:----:|:-------|:-----|
| 1 | `git status` | 변경/추가 파일 목록 확인 |
| 2 | `git diff --stat` | 변경 내용 확인 |
| 3 | `git log --oneline -3` | 최근 커밋 스타일 확인 |
| 4 | **사용자 확인 요청** | 커밋할 내용 보여주고 승인받기 |
| 5 | `git add` → `git commit` → `git push` | 승인 후 순차 실행 |

### 자주 하는 실수 방지

| 실수 | 해결책 |
|:-----|:-------|
| 확인 없이 git commit | 반드시 git status/diff 먼저 실행하고 사용자 확인 받기 |
| 한 번에 add+commit+push | 각 단계 분리하여 실행, 사용자에게 내용 보여주기 |
| 세션마다 규칙이 다름 | 매일 작업보고서 읽고 규칙 따르기 |
