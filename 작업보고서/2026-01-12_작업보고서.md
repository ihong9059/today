## 외부 SSH 접속 방법 요약

| 상황 | 접속 방법 |
|------|----------|
| 집 (같은 WiFi) | `ssh user@192.168.0.32 -p 8022` |
| 외부 → 집 스마트폰 | `ssh user@공인IP -p 8022` (포트포워딩 필요) |
| 외부 → 집 (DDNS) | `ssh user@myphone.ddns.net -p 8022` |
| 스마트폰 핫스팟 | `ssh user@192.168.43.1 -p 8022` |

### SSH config 예시 (~/.ssh/config)
```
Host phone-local
    HostName 192.168.0.32
    User u0_a314
    Port 8022

Host phone-remote
    HostName myphone.ddns.net
    User u0_a314
    Port 8022
```

## RFID RC522 카드 검토 (오전 세션)

### 1. 하드웨어 연결

| RC522 핀 | GPIO | Raspberry Pi Pin |
|----------|------|------------------|
| VCC | 3.3V | Pin 1 또는 17 |
| GND | GND | Pin 6 |
| MOSI | GPIO10 | Pin 19 |
| MISO | GPIO9 | Pin 21 |
| SCK | GPIO11 | Pin 23 |
| SDA/SS | GPIO8 | Pin 24 |
| RST | 3.3V | Pin 1 또는 17 |

### 2. RC522 모듈 확인

| 항목 | 값 |
|------|-----|
| Version Register | 0x92 |
| 버전 | RC522 v2.0 |
| 상태 | 정상 연결 |

### 3. RFID 카드 검토 결과

| # | UID | 카드 타입 | UID 변경 |
|---|-----|----------|---------|
| 1 | 04-DA-0D-2B | NTAG/Ultralight | 불가 |
| 2 | 22-BC-7D-34 | NTAG/Ultralight | 불가 |
| 3 | 2D-D6-C9-01 | NTAG/Ultralight | 불가 |
| 4 | 88-53-FC-9C | NTAG/Ultralight | 불가 |

### 4. 결론
- 검토된 4장 모두 일반 카드 (UID 변경 불가)
- UID 변경 필요 시 Magic Card 별도 구매 필요
- 현재 카드는 UID 기반 식별 또는 데이터 영역 활용 가능
