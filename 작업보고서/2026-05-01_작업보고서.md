  - 교육생 인증 신청 페이지 (/)

- Pi(192.168.0.23)에 Claude Hook 설치
  - check_auth.sh: Claude 실행 시 토큰 확인 (PreToolUse hook)
  - request_auth.sh: uttecEdu 명령 (인증 신청→승인대기→토큰저장→Claude자동실행)
  - claude_cleanup.sh: 교육 종료일 경과 시 Claude 자동 삭제 (매일 00:05 cron)
- uttecEdu 명령 기능: 서버 IP 첫 실행 시 입력(~/.uttec_server), 환영 메시지, 남은 일수, 20초 timeout
- 연동 테스트 완료: 서버OFF→timeout, 토큰없음→차단, 인증→승인→Claude자동실행
