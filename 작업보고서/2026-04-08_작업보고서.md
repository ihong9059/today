## 작업 상세 내용

### Xerix EtherCAT MFC Controller 설계 검토 (4개 문서)

#### 1. EtherCAT_Role_STM32F3_설계검토.md
- EtherCAT 기본 네트워크 구조 (1 Master + 다수 Slave, Daisy-chain)
- EtherCAT Master 역할 및 구현체 (TwinCAT, SOEM 등) — Xerix가 만드는 건 Master가 아님
- EtherCAT Slave 역할 및 하드웨어 구성 3가지 방식 비교 (전용 ESC+MCU / 내장 ESC / FPGA)
- Slave 세부 역할 분류 (토폴로지: First/Middle/Last/Junction, 프로파일: CoE/SoE/EoE/FoE, DC: Reference/Sync/Unsync)
- STM32F3 + LAN9252 조합 검토 및 개발 로드맵 Phase 0~4

#### 2. ESC_EtherCAT_Slave_Controller_설명.md
- ESC 정의: EtherCAT 프로토콜 전용 하드웨어 칩
- 하드웨어 수준 동작: On-the-fly 프레임 처리, FMMU, SyncManager, DC, PDI, ESM
- ESC 내부 블록 다이어그램 (PHY / EtherCAT Processing Unit / DPRAM / EEPROM)
- 대표 ESC 칩 7종 비교 (LAN9252/ET1100/ET1200/AX58100/XMC4800/AM243x/H7)
- STM32F3 + LAN9252 핀 연결 예시 (SPI1, IRQ, SYNC0/1, RESET#)
- DC SYNC0 기반 PID 루프 트리거 체인

#### 3. STM32F3_vs_STM32H7_EtherCAT_비교.md
- **선결 확인**: STM32 전 라인업에 ESC 내장 MCU 없음 (중요 정정)
- MCU 스펙 비교: F303(72MHz, 12bit ADC, SP FPU, CORDIC/FMAC) vs H723/H735(550MHz, 16bit ADC, DP FPU)
- EtherCAT Slave 구현 관점: SPI 속도(18MHz vs 200MHz), SSC Stack CPU 점유율, 최소 주기(1ms vs 125μs)
- 센서 신호 처리 관점: Coriolis 위상차 연산은 **F3의 CORDIC/FMAC 하드웨어 우위**, Pressure-based 고정밀은 H7의 16bit ADC + DP FPU 우위
- 비용/양산/PCB 난이도 비교
- 최종 권장: **제품 라인업 이원화** (Standard F3 + Premium H7), 단일 선택 시 **STM32H723**

#### 4. EtherCAT_Slave_플랫폼_개발리소스_비교.md
- 7개 플랫폼 종합 순위 (LAN9252+STM32 1위, ET1100 2위, XMC4800 3위, AM243x 4위, RZ/T2M 5위, AX58100 6위, LPC18xx 7위)
- 개발 리소스 유리도 상세 비교표 (데이터시트 품질, 예제 코드 양, 한국어 자료, 오픈소스 스택, 상용 스택, 커뮤니티 활성도, YouTube 튜토리얼, 책 출판, ETG 교육 언급)
- LAN9252 공식 리소스: Microchip AN1925/AN2420, STMicro AN5397, ST X-CUBE-ECAT 무료 패키지
- 커뮤니티 리소스: EasyCAT Shield (AB&T), SOES, "EtherCAT for Arduino" 도서
- Xerix 최종 권장: **LAN9252 + STM32H723** (개발 리소스 + 성능 + 비용의 최적 균형)
- 프로토타입→양산 4단계 경로 (EasyCAT PoC → EVB → 커스텀 PCB → 양산)
- 즉시 구매 가능 개발 키트 6종 가격/구득처
