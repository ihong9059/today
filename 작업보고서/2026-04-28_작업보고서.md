## 오늘 완료 사항

### 사전빌드 105개 전체 완료
- 81개 → 105개 (신규 24개: I09~I14, M01~M06, N01~N06, O01~O06)
- 16개 카테고리: A~L 기존 + M(WiFi AP) N(폰 연동) O(복합 응용)
- 난이도: ★ 27개, ★★ 35개, ★★★ 31개, ★★★★ 12개

### Base Firmware 주요 수정
- **SDLOAD 태스크 분리**: BLE 콜백에서 xTaskCreate로 8KB 스택 별도 실행 (스택 오버플로우 해결)
- **CDCOnBoot=cdc**: USB CDC 활성화하여 시리얼 모니터 동작
- **WRITE_NR 추가**: CMD characteristic에 write-without-response 지원
- **ledTaskActive 플래그**: LED 명령 수신 시 기본 파란 깜빡임 중지
- **시리얼 명령 핸들러**: loop()에서 시리얼 입력으로 LED/SDLOAD 명령 처리
- FQBN: `esp32:esp32:esp32c6:PartitionScheme=min_spiffs,CDCOnBoot=cdc`

### 105개 전체 재빌드
- 수정된 base firmware 반영하여 전체 재컴파일 (약 5시간)
- 코드 에러 수정: 마크다운 잔여물 제거(B06,D06,E07,F02), 변수 선언 수정(F01), em dash 치환(B06), onBleReceive weak 함수 처리(J01~J06,K04,N01,N02,N05,O02), 따옴표 이스케이프(M03,M05,O01,O03,O05)
- catalog.json 105개 항목 갱신

### Flutter 앱 수정
- 예시 선택 시 서버 다운로드 → **BLE SDLOAD** 방식으로 전환
- 내장 catalog.json + guide/ assets 추가 (서버 없이 동작)
- 서버 fallback: 서버 접근 가능 시 서버 우선, 실패 시 내장 데이터 사용
