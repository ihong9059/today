### A. QDY30A-B sensor 단독 통신 검증 (PC USB-RS485 경로) — 10회 측정

### B. nRF52832 Modbus master 1차 (SW-UART, FAIL)
DE/RE 자동 dongle이라 firmware 단순화. CRC16 + FC 0x03 + 4ms idle silence + TX4 USB-VCOM display. 빌드/플래시 OK. 결과: `NO/BAD RESP n=0` + TX4 디스플레이 자체에 bit 3 corruption (X→P / l→d / O→G XOR=0x08).

### C. 진단 → HW UART 우회 결정
4건 모두 data bit 3 (XOR=0x08) 일관 → SW-UART 9600 path 자체 결함. TX2가 sensor에 보내는 Modbus 요청도 같은 corruption → invalid frame → 무응답.

### D. nRF52832 Modbus master 2차 (HW UART, SUCCESS) ⭐⭐⭐
overlay `uart0_default` pinctrl P0.11/P0.13 → P0.15/P0.02. main.c HW UART0 polling TX + ISR RX + ring_buf 재작성. 결과: `Level: 676/677 mm` 23회 연속 / CRC ERR 0건 / NO RESP 0건.

### E. 디스플레이 cosmetic carry
`Level: 676 -m` (mm → -m, bit 6 flip XOR=0x40) 약 50% 혼재. RS485 path (HW UART) 무결성 확인 — Modbus CRC 자체 검증으로 23/23 통과. 디스플레이만 cosmetic. 해결 옵션: TX4 9600 → 115200 (양산 검증된 path) carry.
