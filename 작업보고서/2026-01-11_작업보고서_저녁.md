# 2026-01-11 작업 보고서 (저녁 세션)

## Web OCR App - EasyOCR 기반 번호판 인식

### 작업 배경
- 스마트폰 IP Webcam 앱을 통해 실시간 카메라 영상 수신
- 한국어 번호판(예: "201누 2734") 인식 필요
- 초기에 Tesseract OCR 시도 → 한글 인식 실패 (노이즈만 출력)
- EasyOCR로 전환하여 성공

---

### 시도한 접근 방식들

| 방식 | 결과 | 이유 |
|------|------|------|
| Tesseract OCR (Termux) | 실패 | 한글 번호판 인식 불가, 노이즈만 출력 |
| EasyOCR (Termux ARM64) | 실패 | OpenCV/PyTorch prebuilt wheel 없음, 빌드 실패 |
| EasyOCR (Windows PC) | **성공** | Flask 서버로 OCR 처리 |

### 해결한 문제들

1. **실시간 영상과 처리된 이미지 불일치 문제**
   - 원인: 브라우저와 서버가 각각 다른 시점에 IP Webcam에서 이미지를 가져옴
   - 해결: 서버가 캡처 시점에 이미지를 가져와 OCR 처리 후, 동일한 이미지를 base64로 클라이언트에 반환

2. **이미지가 잘리는 CSS 문제**
   - 원인: `max-width`와 `min-height` 설정으로 이미지 비율 깨짐
   - 해결: `width: 100%; height: auto; object-fit: contain;`으로 변경

3. **NumPy 빌드 실패 (Windows)**
   - 원인: Python 3.14에서 소스 빌드 시도
   - 해결: `pip install --only-binary :all: numpy`로 prebuilt wheel 설치
