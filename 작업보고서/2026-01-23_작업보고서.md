### 2.2 웹 서비스별 개별 DNS 할당

RPi5에서 운영 중인 6개 웹 서비스에 각각 별도의 도메인을 할당했습니다.

#### DuckDNS 도메인 생성

| 도메인 | IP | 상태 |
|--------|-----|:----:|
| uttec-cert.duckdns.org | 121.137.66.41 | ✅ |
| uttec-edu.duckdns.org | 121.137.66.41 | ✅ |
| uttec-sensor.duckdns.org | 121.137.66.41 | ✅ |
| uttec-snu.duckdns.org | 121.137.66.41 | ✅ |
| uttec-info.duckdns.org | 121.137.66.41 | ✅ |

#### Nginx 가상호스트 설정

각 도메인별로 Nginx 가상호스트를 설정하여 해당 포트로 프록시합니다.

| 도메인 | 내부 포트 | 서비스 |
|--------|:---------:|--------|
| uttec-cert | 4000 | cert-guide (자격증 가이드) |
| uttec-edu | 3001 | edu-frontend (UTTEC Edu 교육 플랫폼) |
| uttec-sensor | 5000 | sensor-monitor (센서 모니터링) |
| uttec-snu | 8088 | snu-consulting (서울대 입시 컨설팅) |
| uttec-info | 8080 | device-info (디바이스 정보) |

#### SSL 인증서 발급

모든 도메인에 Let's Encrypt SSL 인증서를 발급했습니다.

```bash
sudo certbot --nginx -d uttec-edu.duckdns.org -d uttec-sensor.duckdns.org -d uttec-snu.duckdns.org -d uttec-info.duckdns.org --non-interactive --agree-tos --email uttec@naver.com
```

| 항목 | 내용 |
|------|------|
| 인증서 경로 | `/etc/letsencrypt/live/uttec-edu.duckdns.org/` |
| 만료일 | 2026-04-22 |
| 자동 갱신 | ✅ Certbot 자동 갱신 설정됨 |
