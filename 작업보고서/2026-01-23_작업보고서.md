## 6. 포트 기반 서비스 구분 설정

### 6.1 설정 목적

같은 IP(121.137.66.41)에서 도메인 이름 외에 **포트 번호**로도 서비스를 구분하여 접속할 수 있도록 설정.

### 6.2 포트 구성

| 도메인 | 외부 포트 | 내부 포트 | 서비스 |
|--------|:---------:|:---------:|--------|
| uttec-cert.duckdns.org | **5002** | 4000 | cert-guide (자격증 가이드) |
| uttec-info.duckdns.org | **5004** | 8080 | device-info (디바이스 정보) |

### 6.3 적용 필요 사항

#### 1) Nginx 설정 (RPi5에서 실행)

```bash
# 설정 파일 생성
sudo nano /etc/nginx/sites-available/uttec-cert-port
sudo nano /etc/nginx/sites-available/uttec-info-port

# 심볼릭 링크 생성
sudo ln -sf /etc/nginx/sites-available/uttec-cert-port /etc/nginx/sites-enabled/
sudo ln -sf /etc/nginx/sites-available/uttec-info-port /etc/nginx/sites-enabled/

# Nginx 재시작
sudo nginx -t && sudo systemctl reload nginx
```

#### 2) 라우터 포트포워딩

| 외부 포트 | 내부 IP | 내부 포트 |

| 5002 | 192.168.0.32 | 5002 |
| 5004 | 192.168.0.32 | 5004 |

#### 3) 방화벽 (필요시)

```bash
sudo ufw allow 5002/tcp
```

## 7. 번호판 OCR 인식 속도 최적화 (Jetson Nano)

### 7.1 최적화 테스트 개요

기존 4.55초/장의 속도를 개선하기 위해 다양한 최적화 기법을 Jetson Nano에서 테스트했습니다.

### 7.2 최적화 결과 요약

| 방법 | 평균 시간 | 인식률 | 기존 대비 |
|:-----|:---------:|:------:|:---------:|
| 기존 (640x640) | 4.55초 | 70% | 1.00x |
| cuDNN + 480x480 | 2.04초 | 90% | 2.24x |
| **최종 최적화** | **1.94초** | **90%** | **2.35x** |

### 7.3 적용된 최적화 기법

| 기법 | 효과 | 상태 |
|------|------|:----:|
| cuDNN benchmark 모드 | 모델 로딩 41% 단축 | ✅ |
| 이미지 크기 480x480 | 1.80x 속도 향상 | ✅ |
| 영역 검출 + '오' 보정 | 인식률 70% → 90% | ✅ |

### 7.4 TensorRT 테스트

| 항목 | 결과 |
|------|------|
| TensorRT 8.2.1.9 | ✅ 설치 완료 |
| torch2trt 0.5.0 | ✅ 설치 완료 |
| EasyOCR 변환 | ❌ 모델 구조상 직접 적용 불가 |
| FP16/AMP | ❌ OpenCV 연산 호환 문제 |

### 7.5 PaddleOCR 테스트

| 항목 | 결과 |
|------|------|
| PaddlePaddle GPU 2.0.0 | ✅ 설치 완료 |

| 실행 | ❌ Python 3.6 + PaddlePaddle 2.0.0 호환성 문제 |

### 7.6 OCR 엔진 비교 결론
