## 오늘 완료 사항

### A. ⭐⭐⭐⭐ DGIST ESCO LED 도면 LED 위치 자동 표시 (E1~E6) — 완료

**목표**: E1~E7 조명제어구역 도면 PDF에 LED등 위치 파란 원 표시. 사용자가 도면별로 검증 가능한 산출물 7개 생성.

**도면 구조 → 3가지 알고리즘 도출**:

1. **A. 사용자 ink → 깨끗한 원 변환** (E1, E2)
   - E1: 사용자가 표시한 63 위치 추출 → 원 마킹
   - E2: 사용자 표시 98 위치 — **ground truth로 검증 기준**

2. **B. PE/PN 텍스트 라벨 매칭** (E3, E5, E6)
   - 정규식 `^P[EN]\d{1,3}$` — PE3/PN4 등만 LED (사용자 확정 규칙)
   - `E3`, `E4` 같은 P 없는 라벨은 그룹 라벨/구역 라벨 → LED 아님
   - 빨간 zone 안 strict containment (expand=0)
   - 결과: E3=86, E5=93, E6=91

3. **C. 도형 매칭 + PolyLine 분해** (E4 — 라벨 없음)
   - p3: 좁은 corridor 안 thin LED bar (mediabox 2×8) — 14개
   - p4: ㄷ자 strip 추출로 정확화 — 25개 (이전 172개 → strip 정확 추출로 -147 false positive 제거)
   - **PolyLine vertex 6개를 평행 line segment 쌍으로 분해** → 좁은 strip 71×15 + 15×664 추출 알고리즘 신설

**구역 종류 분류 (2가지)**:
- **조명제어구역**: E1~E6 전체, E7 p3-p4 (일반 LED ON/OFF)
- **디밍제어용 센서등 교체구역**: E7 p1-p2 (센서 디밍 제어)

**검증**:
- E2 사용자 ground truth 98 vs v7 도형 매칭 99 (≈1:1) — fixture 도형 패턴 매칭 알고리즘 검증
- E3, E4, E5, E6 p3 strip 시각 검증 — 빨간 테두리 안만 정확 마킹
