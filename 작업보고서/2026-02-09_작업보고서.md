## 작업 상세 내용

### 1. 세계 여행 가이드 웹앱 기능 개선

**URL**: http://178.128.90.37:10002/

#### 1.1 관광지 없는 공항(회색 마커) 클릭 기능 추가

**변경 전**:
- 관광지가 없는 공항(회색)은 팝업에 버튼이 없어 정보 확인 불가
- "관광지 정보 없음" 메시지만 표시

**변경 후**:
- 모든 공항에 버튼 표시
- 관광지 있는 공항: "관광지 보기" 버튼
- 관광지 없는 공항: "공항 정보 보기" 버튼
- 색상 구분은 그대로 유지 (파란색=관광지 있음, 회색=없음)

#### 1.2 공항 자체를 관광지로 표시

- Wikipedia API를 통해 공항 정보 자동 로드
- 공항 카드에 ✈️ 아이콘과 "Airport" 카테고리 표시
- Wikipedia 링크 제공

**적용 우선순위**:
1. 관광지별 개별 음악 (`attractionMusic`)
2. 공항별 기본 음악 (`defaultAirportMusic`)
3. 국가별 음악 (`countryMusic`) - 신규 추가
4. 최종 fallback: Daft Punk - Around the World

#### 1.4 공항 주변 명소 자동 검색 기능

`showAirportAsAttraction()` 함수 대폭 개선:

**표시되는 정보**:
1. **✈️ Airport** (파란색) - 공항 자체 정보
2. **🏙️ City** (보라색) - 해당 도시 정보
3. **🏛️ Landmark** (초록색) - 도시의 주요 명소 (최대 4개)

**검색 방법**:
- Wikipedia API로 `{도시명} landmark`, `{도시명} tourist attraction`, `{도시명} monument` 검색
- 검색 결과에서 최대 6개 명소 표시
- 각 명소에 이미지, 설명, Wikipedia 링크 포함
