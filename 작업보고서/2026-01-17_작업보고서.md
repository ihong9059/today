### [2026-01-17] 외부 SSH 접속 설정 (진행 중)

#### 목적
- 집에서 회사 Raspberry Pi 5에 SSH 접속

#### 설정 내용

**1. SSH 포트 추가 (22 + 2222)**
```bash
# /etc/ssh/sshd_config에 추가됨
Port 22
Port 2222
```

**2. 공유기 포트 포워딩**
| 규칙이름 | 내부 IP | 프로토콜 | 외부 포트 | 내부 포트 |
|---------|---------|---------|----------|----------|
| rasp5 | 192.168.1.8 | tcp | 22-22 | 22-22 |
| rasp5-2222 | 192.168.1.8 | tcp | 2222-2222 | 2222-2222 |

**3. 외부 접속 명령어**
```bash
ssh -p 2222 uttec@221.163.229.213
```

#### 현재 상태

- 외부 접속 (스마트폰): ❌ timeout

#### 배포 현황

| 서비스 | 포트 | 상태 | 설명 |
|--------|:----:|:----:|------|
| edu-backend | 3000 | ✅ | Node.js 백엔드 API |
| edu-frontend | 3001 | ✅ | Next.js 프론트엔드 |

#### 접속 정보
```bash
# SSH 접속
ssh uttec@192.168.0.3

# 웹 접속 (내부망)
Frontend: http://192.168.0.3:3001
Backend API: http://192.168.0.3:3000
```

#### PM2 서비스 관리
```bash
pm2 list                    # 서비스 상태 확인
pm2 logs                    # 로그 확인
pm2 restart edu-backend     # 백엔드 재시작
pm2 restart edu-frontend    # 프론트엔드 재시작
```

#### 설정 파일
- Backend: `~/hw-c-edu-platform/backend/.env`
  - DATABASE_URL: AWS RDS PostgreSQL
  - JWT_SECRET: 설정됨
  - PORT: 3000

- Frontend: `~/hw-c-edu-platform/frontend/.env`
  - NEXT_PUBLIC_API_URL: http://192.168.0.3:3000

#### 참고사항
- 이전 서비스(cert-guide-dev, sensor-monitor)는 중단됨
