## 작업 내용

### 1. 세주FA 영업관리 시스템 개발 ✅

세주FA 영업사원을 위한 현장 방문 관리 시스템 전체 구축

#### 1.1 시스템 구성

| 구성요소 | 설명 | 경로/위치 |
|:---------|:-----|:----------|
| Android 앱 | 영업사원용 방문 기록 앱 | `seju/android-app/` |
| 웹 서버 | Express + SQLite API 서버 | `seju/server/` |
| 대시보드 | 관리자용 웹 대시보드 | http://178.128.90.37:90 |
| Release APK | 배포용 APK 파일 | `seju/SejuSales-v1.0.apk` |

#### 1.2 Android 앱 기능

| 기능 | 설명 |
|:-----|:-----|
| GPS 위치 추적 | 방문 위치 자동 기록 |
| 방문 유형 선택 | 영업/납품/AS/수금/미팅/기타 |
| 거래처 정보 입력 | 거래처명, 담당자, 연락처 |
| 현장 사진 촬영 | 카메라 연동 사진 업로드 |
| 방문 이력 조회 | 검색 및 상세 보기 |

#### 1.3 서버 배포
