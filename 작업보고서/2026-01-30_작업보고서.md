### 4. 세주FA 모바일 웹 페이지 개발 및 배포 ✅

APK 설치 없이 스마트폰 브라우저에서 URL 접속만으로 앱과 동일한 기능 사용 가능하도록 모바일 웹 개발

#### 4.1 개발 배경

- APK 설치 과정이 복잡함 (알 수 없는 출처 허용 등)
- 스마트폰 브라우저에서 바로 접속하여 사용 요구

#### 4.2 구현 내용

| 항목 | 내용 |
|:-----|:-----|
| 접속 URL | http://178.128.90.37:90/mobile/ |
| 파일 위치 | `seju/server/public/mobile/index.html` |
| 서버 URL | 자동 감지 (현재 접속 서버 사용) |
| PWA 지원 | 홈 화면에 추가하면 앱처럼 사용 가능 |

#### 4.3 앱 vs 웹 비교

| 항목 | APK 앱 | 모바일 웹 |
|:-----|:-------|:---------|
| 설치 | APK 다운로드 및 설치 | URL 접속만 하면 됨 |
| 서버 주소 | 수동 설정 필요 | 자동 감지 |
| GPS | 네이티브 API | 브라우저 Geolocation |
| 카메라 | 네이티브 카메라 | 브라우저 카메라 |
| 홈 화면 | 앱 아이콘 | PWA로 앱처럼 추가 가능 |

#### 4.4 사용 방법

1. 스마트폰 브라우저에서 `http://178.128.90.37:90/mobile/` 접속
2. 설정 탭에서 영업사원명 입력
3. 위치 권한 허용
4. 방문 기록 등록/조회 사용

#### 4.5 홈 화면 추가 방법

| iPhone | Android |
|:-------|:--------|
| Safari 공유 버튼 → 홈 화면에 추가 | Chrome 메뉴(⋮) → 홈 화면에 추가 |
