### 2. Tilt 3D 모델 좌표계 수정

#### 문제점
- 폰을 기울여도 3D 모델이 반대로 움직임
- 90° 근처에서 Gimbal Lock 발생

#### 해결 방법

**Roll 계산 (좌우 기울기):**
```javascript
// 오른쪽으로 눕히면 gx가 음수 → 부호 반전
const roll = Math.atan2(-gx, Math.sqrt(gy*gy + gz*gz));
```

**Pitch 계산 (앞뒤 기울기):**
```javascript
// Roll이 45° 이상이면 Pitch를 0으로 고정 (Gimbal Lock 방지)
if (absRoll > Math.PI / 4) {
    pitch = 0;
} else {
    pitch = Math.atan2(gz, gy);
}
```

**3D 모델 적용:**
```javascript
tiltDevice.rotation.x = -finalPitch;
tiltDevice.rotation.z = -finalRoll;
```

## 기술 메모

### Android Gravity 센서 좌표계
- 폰을 세로로 들었을 때: gy ≈ 9.8
- 오른쪽으로 90° 눕히면: gx ≈ **-9.8** (음수!)
- 뒤로 90° 눕히면: gz ≈ 9.8

### Gimbal Lock 해결
- Roll이 45° 이상일 때 Pitch를 0으로 고정
- 옆으로 눕힌 상태에서 Pitch가 불안정해지는 문제 방지
