## 작업 상세 내용

### ESP32-C3 vs WROOM 주요 차이
| 항목 | final (WROOM) | aiEspMini (C3) |
|------|--------------|----------------|
| FQBN | esp32:esp32:esp32 | esp32:esp32:esp32c3:CDCOnBoot=cdc |
| LED | 개별 3개 (GPIO25/26/27) | WS2812 RGB 1개 (GPIO1) |
| 부저 | BEEP + MELODY 2개 | Speaker 1개 (GPIO2, tone) |
| I2C | SDA=21, SCL=22 | SDA=6, SCL=7 |
| 스위치 | GPIO32 | GPIO5 |
| 빌드 포트 | 8092 | 8096 |
| 웹 포트 | 8094 | 8098 |
| BLE 이름 | UTTEC-OTA | UTTEC-MINI |

### 발견된 이슈 및 해결
1. USB CDC Off → 시리얼 출력 안 보임 → CDCOnBoot=cdc 추가
2. nginx /mini 블록 한 줄 압축 → 파싱 실패 → 줄바꿈 수정
3. AI가 xTaskCreate를 loop()에 배치 → 태스크 무한 생성 크래시 → 프롬프트 강화
4. COM9 보드 부트로더 진입 불가 → 불량, 다른 보드로 교체
