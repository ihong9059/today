## 작업 내용

### 1. 저가확인 웹서버 개발 (오전)

쿠팡에서 서울우유 제품 중 저가 판매 품목을 찾는 웹서버 개발

**위치:** `저가확인/`

**기술 스택:**
- Python Flask 웹서버
- Playwright를 이용한 웹 스크래핑
- Chrome Extension (추가 기능)

**주요 파일:**
- `app.py` - 메인 웹서버 (Flask)
- `chrome_extension/` - 크롬 확장 프로그램
- `templates/` - HTML 템플릿

**기능:**
- 쿠팡에서 서울우유 검색
- 100ml당 가격 계산
- 기준 가격 이하 품목 필터링
- 결과를 마크다운 형식으로 저장

**검색 결과 예시:** 15개 저가 품목 발견 (100ml당 218~297원)
