# microGPT 완전 정리 — 초보자도 이해하는 200줄 GPT

> Andrej Karpathy(전 OpenAI 공동창업자, 전 Tesla AI 디렉터)가 2026년 2월 공개한 **순수 Python 200줄로 만든 GPT**.
> 이 문서는 LLM·GPT·트랜스포머를 한 번도 깊게 본 적 없는 사람도 이해할 수 있도록 비유와 그림으로 설명합니다.

---

## 0. 시작 전 5분 사전 지식

### 0-1. GPT가 뭔가요?
**G**enerative **P**re-trained **T**ransformer의 약자.
- **Generative** (생성형): 다음에 올 단어/글자를 만들어냅니다.
- **Pre-trained** (사전학습): 인터넷의 방대한 글을 미리 학습해두었습니다.
- **Transformer**: 2017년 구글이 발표한 신경망 아키텍처. "문맥을 이해하는 능력"이 핵심.

쉬운 비유:
> "휴대폰 자판의 자동완성 기능"을 **수십억 배 똑똑하게** 만든 것이 GPT입니다.
> 휴대폰은 "제가" 다음에 "갈게요"를 추천하지만, GPT는 "제가" 다음에 1만 단어 중 가장 적절한 것을 확률로 골라 문장을 이어갑니다.

### 0-2. ChatGPT는 GPT랑 같은 건가요?
**ChatGPT** = **GPT 모델** + **대화 인터페이스** + **안전장치(RLHF)**

GPT는 "엔진", ChatGPT는 "엔진 + 자동차 + 안전벨트" 정도의 관계입니다. microGPT는 가장 작은 엔진만 보여줍니다.

### 0-3. 파라미터(Parameter)가 뭔가요?
파라미터 = 신경망이 학습하면서 조절하는 **숫자(가중치, Weight)**의 개수.

쉬운 비유:
> 라디오의 **다이얼 개수**와 같습니다. 다이얼이 4개면 4개 채널만 맞출 수 있고, 100억 개면 100억 가지 미세 조정이 가능합니다.
> 다이얼이 많을수록 더 정교한 응답이 가능하지만, 학습에 더 많은 데이터·시간·전력이 필요합니다.

### 0-4. 모델 크기 비교 (감 잡기)
| 모델 | 파라미터 | 학습 비용 | 학습 시간 |
|------|:--------:|:---------:|:---------:|
| **microGPT** ⭐ | **4,192** (4K) | **$0** | **MacBook 1분** |
| GPT-2 (소형) | 1억 2천 4백만 (124M) | 수백~수천 달러 | 수일 |
| GPT-3 | 1,750억 (175B) | 수백만 달러 | 수개월 |
| GPT-4 (추정) | ~1조 7천억 (1.7T) | 수천만 달러 | 수개월 |
| Claude 4 Opus (추정) | 비공개, 수조 추정 | 비공개 | - |

→ **microGPT는 ChatGPT의 약 4억 분의 1 크기**입니다. 그래서 "마이크로"입니다.

## 1. microGPT란? (한 문단)

**Andrej Karpathy**가 2026년 2월 12일 공개한, **단 200줄의 순수 Python 코드**로 GPT를 처음부터 끝까지(데이터 → 학습 → 생성) 구현한 교육용 프로젝트입니다. **외부 라이브러리 0개**(NumPy도 PyTorch도 사용 안 함)로, **MacBook에서 1분이면 학습이 끝납니다**. 결과로 GPT는 32,033개 영문 이름을 학습한 뒤 새 이름을 만들어냅니다 (예: "emma", "olivia" 같은 입력에서 "amilia", "kayten" 같은 새 이름 생성).

## 3. microGPT가 왜 놀라운가? (3가지 포인트)

### 포인트 1: 의존성 ZERO
```python
# 일반 딥러닝 코드 첫 줄들
import torch
import torch.nn as nn
import numpy as np
from transformers import GPT2Model
# (그 외 수십 개...)

# microGPT 첫 줄
import math
import urllib.request
# 끝.
```

→ **표준 Python에 기본 포함된 모듈만** 사용. 컴퓨터에 Python만 설치되어 있으면 동작.
→ 비유: "라면을 끓이는 데 라면 봉지의 분말 스프 없이 소금·후추만으로 라면 맛을 낸 것"

### 포인트 2: 200줄에 LLM의 모든 것
**보통의 LLM 학습 코드** = 수만 줄 (PyTorch + transformers + accelerate + ...)
**microGPT** = **200줄** 안에:
1. 데이터 다운로드 + 전처리
2. 토크나이저(글자 → 숫자 변환)
3. **자동미분 엔진** (`Value` 클래스, 약 30줄)
4. **트랜스포머 신경망** (어텐션 + MLP + RMSNorm)
5. **Adam 옵티마이저** (학습률 조절)
6. 학습 루프 (1000번 반복)
7. 추론 루프 (새 텍스트 생성)

### 포인트 3: 1분 학습
- MacBook M1 Air 기준 **약 60초**
- 보통 GPT는 학습에 며칠~몇 달 소요
- 비유: "보통 자동차는 수백 부품 조립에 수일이 걸리는데, 종이 모형 자동차를 30초 만에 접어서 보여주는 것"

## 4. 200줄 안에 들어간 7가지 컴포넌트 — 초보자 해설

### 4-1. 데이터 (`names.txt`)
**무엇**: 영문 이름 32,033개 (한 줄에 하나, 예: emma, olivia, ava, ...)
**왜**: GPT는 "다음에 올 글자를 예측"하는 게 본질. 이름은 짧고 패턴이 있어서 작은 모델로도 학습 가능.

```
입력 데이터 예시:
emma
olivia
ava
isabella
sophia
...
(총 32,033줄)
```

### 4-2. 토크나이저 (글자 → 숫자)
**무엇**: 컴퓨터는 글자를 모르므로 숫자로 변환합니다.
**어떻게**: 영문자 26개 + 시작/끝 표시(BOS) 1개 = **27개 숫자**로 매핑

```
글자  →  숫자
a → 1
b → 2
c → 3
...
z → 26
BOS → 0  (Beginning Of Sequence, 문장 시작 표시)

"emma" → [BOS, e, m, m, a, BOS]
       = [0, 5, 13, 13, 1, 0]
```

쉬운 비유:
> 모스 부호처럼 글자를 미리 약속한 숫자로 바꾸는 작업.

### 4-3. 자동미분 (Autograd) — `Value` 클래스

**어렵나요?**: 사실 미분(고등학교 수학)을 컴퓨터가 자동으로 해주는 것뿐.

```python
        self.grad = 0      # 이 숫자를 얼마나 바꿔야 하는지 (기울기)

    def __add__(self, other):
        # 두 Value를 더하면 결과도 Value
        # "역방향 계산"도 자동으로 기록
        ...

    def backward(self):

        ...
```

쉬운 비유:
> 시험 점수가 낮을 때 "어느 단원에서 몇 점 떨어졌는지" 자동으로 채점해주는 시스템.
> 신경망은 이 정보를 보고 "다음엔 그 단원을 더 공부하자"고 가중치를 조정합니다.

### 4-4. 트랜스포머 신경망 (Transformer)
**무엇**: GPT의 심장. "문맥을 이해하는" 핵심 구조.

#### 어텐션(Attention) — 가장 중요한 개념
**핵심 아이디어**: "지금 이 글자를 예측할 때, 앞의 어떤 글자에 주목할지" 자동으로 결정.

쉬운 비유:
> "**나는** 어제 친구를 만나서 같이 영화를 봤다. **그**는 너무 재밌다고 했다."
> 여기서 "**그**"가 누구를 가리키는지 알려면 앞의 "**친구**"를 주목해야 합니다.
> 어텐션은 이런 "주목"을 자동으로 학습합니다.

microGPT의 어텐션 사양:
- **헤드(head) 4개**: 4가지 다른 관점으로 동시에 주목
- **임베딩 차원 16**: 각 글자를 16차원 벡터로 표현
- **레이어 1개**: 1번만 어텐션 적용 (보통 GPT는 12~96층)
- **컨텍스트 길이 16**: 최대 16글자까지 한 번에 봄

#### MLP (Multi-Layer Perceptron, 다층 퍼셉트론)
**무엇**: 어텐션이 모은 정보를 가공하는 단순 신경망.
**비유**: 어텐션이 "재료를 모으는 요리사"라면, MLP는 "재료를 조리하는 주방장".

#### RMSNorm
**무엇**: 숫자들이 너무 커지거나 작아지지 않게 균형을 맞추는 정규화.
**비유**: 라디오 음량을 자동 조절해서 너무 크거나 작지 않게 유지.

### 4-5. Adam 옵티마이저
**무엇**: 신경망 가중치를 "어떻게 얼마나" 바꿀지 결정하는 알고리즘.
**Adam = Adaptive Moment Estimation** (적응형 모멘텀 추정)

쉬운 비유:
> 산을 내려갈 때(=손실을 줄일 때):
> - 가파른 곳에선 작은 걸음으로
> - 평탄한 곳에선 큰 걸음으로
> - 갑자기 방향이 바뀌면 천천히
> 이런 "지능적 걷기"가 Adam.

### 4-6. 학습 루프 (1000번 반복)
**무엇**: "데이터 보고 → 예측 → 틀린 만큼 가중치 조정" 1000번 반복.

```
for step in range(1000):
    데이터 한 묶음 가져오기
    GPT에 넣고 예측 받기
    정답과 비교 → 오차(loss) 계산
    오차를 줄이는 방향으로 가중치 조정 (자동미분 + Adam)

    if step % 100 == 0:
        현재 오차 출력 (손실이 줄어드는지 확인)
```

쉬운 비유:
> 시험 → 채점 → 오답노트 → 시험 → 채점 → 오답노트 → ... 를 1000번 반복.
> 처음엔 손실(오차)이 크다가 점점 작아집니다.

### 4-7. 추론 루프 (새 이름 생성)
**무엇**: 학습 끝난 GPT에게 "새 이름 만들어줘"라고 시키는 부분.

```
시작 = [BOS]
반복:
    현재까지의 글자들을 GPT에 입력
    GPT가 "다음 글자 확률" 출력 (예: a=20%, e=15%, m=10%, ...)
    확률에 따라 다음 글자 뽑기
    BOS가 나오면 멈추기 (이름 끝)
```

쉬운 비유:
> 끝말잇기에서 "사" 다음에 무엇이 올지 직감으로 고르는 것.
> GPT는 직감 대신 학습한 패턴으로 확률을 계산합니다.

2. **생성된 글자가 점점 사람 이름 같아지는가?** — 패턴을 학습했다는 증거
3. **메모리 사용량은?** — Task Manager 켜고 보세요. 50MB 정도면 충분 (보통 LLM은 GB 단위)

## 7. UTTEC 활용 가능성 — 5가지 시나리오

### 시나리오 1: 강사양성 파일럿 Day 4 워크숍 (★★★★★)
- **언제**: 2026-06-15~19 5일 코스 중 Day 4
- **무엇**: "GPT 200줄로 직접 만들기" 1일 워크숍
- **장점**:
  - 의존성 0 → 강의실 환경 부담 0 (Python만 설치되어 있으면 됨)
  - 1분 학습 → 한 세션 안에 결과 확인 가능 (학생 만족도 ↑)
  - "오늘 GPT를 직접 만들어봤다" 후기 → 강의 화력 ↑

## 8. 자주 묻는 질문 (FAQ)

### Q1. 200줄로 만든 게 진짜 ChatGPT처럼 답변하나요?
**A**: 아닙니다. microGPT는 **이름만 생성**합니다 (예: emma → kayten). 4,192 파라미터로는 대화·번역·코딩 같은 작업 불가.
**의도**: "이해를 위한 최소 모델"이지 "실용 모델"이 아님. nanochat이 실용판.

### Q2. microGPT를 학습시키면 ChatGPT처럼 만들 수 있나요?
**A**: 데이터·시간·돈이 천문학적으로 필요합니다.
- microGPT 코드를 그대로 두고 데이터·파라미터를 키우면 → nanoGPT
- 더 키우면 → GPT-2
- GPT-3 수준은 수백만 달러 + 수개월 + 슈퍼컴퓨터급 GPU
- ChatGPT 수준은 OpenAI급 인프라 필요

### Q3. PyTorch 같은 프레임워크 없이 정말 잘 작동하나요?
**A**: 네. 단 학습 속도는 PyTorch보다 느립니다 (microGPT 1분 vs PyTorch 5초). 하지만 microGPT의 목적은 속도가 아닌 **이해**.

### Q4. ESP32 같은 작은 칩에 진짜 올릴 수 있나요?
**A**: 이론적으로 가능하나 다음 작업이 필요:
1. Python 코드 → C/C++ 포팅 (microGPT는 C로 200줄도 가능할 추정)
2. 4,192 파라미터를 SRAM에 배치
3. 부동소수점 → 양자화 (Q8/Q4)

→ **AI FanStick(#34) 후속 검토**로 적합한 주제.

### Q5. 한국어로도 학습시킬 수 있나요?
**A**: 가능합니다. 다만:
- `names.txt`를 한국 이름 데이터로 교체 (예: 김지수, 이서연, ...)
- vocab_size 27 → 수천(한글 자모) 또는 수만(완성형 음절)으로 확장
- 임베딩·파라미터 수도 증가 필요

### Q6. nanoGPT와 microGPT 중 어느 것을 봐야 하나요?
**A**: 처음이면 **microGPT 먼저** (200줄, 1분, 의존성 0).
- microGPT: 본질을 이해
- nanoGPT: 실제 GPT-2를 학습시키는 코드 (PyTorch 사용)
- nanochat: ChatGPT 클론 (SFT + RL 포함)
