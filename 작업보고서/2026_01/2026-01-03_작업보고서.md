### [2026-01-03 오후] HTML 파일 CSS content 속성 버그 수정

- **문제**: CSS `content` 속성에서 HTML 엔티티(`&#10003;` 등)가 렌더링되지 않고 원시 텍스트로 표시
- **원인**: CSS content 속성은 HTML 엔티티가 아닌 유니코드 이스케이프 시퀀스를 사용해야 함
- **해결**: HTML 엔티티를 CSS 유니코드 이스케이프로 변환

| 수정 전 | 수정 후 | 문자 |
|---------|---------|------|
| `&#10003;` | `\2713` | ✓ (체크마크) |
| `&#9679;` | `\25CF` | ● (검은원) |
| `&#8594;` | `\2192` | → (화살표) |

- **수정된 파일** (8개):

## ⚠️ 중요 패턴 유지 사항 (자격시험 가이드 웹사이트)

> **다음 세션에서 반드시 확인할 것!**
>
> 자격시험 가이드 웹사이트 (https://uttec-cert.duckdns.org/)의 모든 자격증 페이지는
> **기계기사 패턴을 표준으로 따라야 합니다.**
>
> 교육 동영상 제작을 위해 일관된 패턴이 필수입니다.
> **패턴 변경 시 반드시 사용자에게 이유를 설명하고 승인을 받을 것!**

### 표준 패턴 정의

#### 1. Breadcrumb (경로 네비게이션) - 모든 페이지 공통
```
홈 › 기계·제어 › 자격증명 › 현재페이지
```
- **모든 항목이 링크**여야 함 (현재 페이지 제외)
- **홈** → `/`
- **기계·제어** → `/category/mechanical`
- **자격증명** → `/category/mechanical/자격증명`
- gap-2, text-sm 사용

#### 2. 메인 페이지 (`/자격증명/page.tsx`)
- **정적 컴포넌트** (no 'use client')
- **구조:**
  - Header (breadcrumb 포함)
  - Hero Section (아이콘 + 제목 + 설명)
  - Quick Info Cards (4개: 합격률, 응시자격, 시험형태, 난이도)
  - Main Content (2-column: 본문 + 사이드바)
    - 본문: 자격 개요, 필기시험 과목 (학습하기 버튼 포함), 실기시험 구성, 추천 공부 순서, AI 학습 도우미
    - 사이드바: 시험일정, 과목별 목표점수, 연계 자격증, 추천 교재/인강
  - Footer

#### 3. Exam 페이지 (`/자격증명/exam/page.tsx`)
- **클라이언트 컴포넌트** (`'use client'`)
- **useState 사용:** `const [activeTab, setActiveTab] = useState<'written' | 'practical'>('written');`
- **구조:**
  - Header (breadcrumb에 activeTab 상태 표시)
  - Hero Section
  - Tab Navigation (필기시험 | 실기시험 버튼)
  - Main Content: `{activeTab === 'written' ? <WrittenExamContent /> : <PracticalExamContent />}`
  - Footer
- **Suspense 사용 금지** (이전에 문제 발생)

#### 4. Study 페이지 (`/자격증명/study/과목명/page.tsx`)
- **클라이언트 컴포넌트** (`'use client'`)
- **localStorage로 학습 진행률 저장**
- **AI 학습 버튼** (Claude, ChatGPT, Gemini)
