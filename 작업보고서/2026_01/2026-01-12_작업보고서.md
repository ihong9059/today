## 외부 SSH 접속 방법 요약

| 상황 | 접속 방법 |
|------|----------|
| 집 (같은 WiFi) | `ssh user@192.168.0.32 -p 8022` |
| 외부 → 집 스마트폰 | `ssh user@공인IP -p 8022` (포트포워딩 필요) |
| 외부 → 집 (DDNS) | `ssh user@myphone.ddns.net -p 8022` |
| 스마트폰 핫스팟 | `ssh user@192.168.43.1 -p 8022` |

### SSH config 예시 (~/.ssh/config)
```
Host phone-local
    HostName 192.168.0.32
    User u0_a314
    Port 8022

Host phone-remote
    HostName myphone.ddns.net
    User u0_a314
    Port 8022
```

## RFID RC522 카드 검토 (오전 세션)

### 1. 하드웨어 연결

| RC522 핀 | GPIO | Raspberry Pi Pin |
|----------|------|------------------|
| VCC | 3.3V | Pin 1 또는 17 |
| GND | GND | Pin 6 |
| MOSI | GPIO10 | Pin 19 |
| MISO | GPIO9 | Pin 21 |
| SCK | GPIO11 | Pin 23 |
| SDA/SS | GPIO8 | Pin 24 |
| RST | 3.3V | Pin 1 또는 17 |

### 2. RC522 모듈 확인

| 항목 | 값 |
|------|-----|
| Version Register | 0x92 |
| 버전 | RC522 v2.0 |
| 상태 | 정상 연결 |

### 3. RFID 카드 검토 결과

| # | UID | 카드 타입 | UID 변경 |
|---|-----|----------|---------|
| 1 | 04-DA-0D-2B | NTAG/Ultralight | 불가 |
| 2 | 22-BC-7D-34 | NTAG/Ultralight | 불가 |
| 3 | 2D-D6-C9-01 | NTAG/Ultralight | 불가 |
| 4 | 88-53-FC-9C | NTAG/Ultralight | 불가 |

### 4. 결론
- 검토된 4장 모두 일반 카드 (UID 변경 불가)
- UID 변경 필요 시 Magic Card 별도 구매 필요
- 현재 카드는 UID 기반 식별 또는 데이터 영역 활용 가능

### 5. 생성된 문서
- `rftech/RFID_RC522_카드검토_결과보고서.md`

## Sensor Monitor 앱 - DB 저장 기능 추가 (저녁 세션)

### 작업 목표

- 스마트폰 앱에 DB 저장 ON/OFF 스위치 추가
- 웹 대시보드에서 DB 저장 상태 실시간 확인

---

### 완료된 작업

#### 1. EC2 PostgreSQL 설치 및 설정

| 항목 | 값 |
|------|-----|
| **DB 서버** | PostgreSQL 15 |
| **데이터베이스** | sensordb |
| **사용자** | sensoruser |
| **비밀번호** | sensor2026 |

#### 2. DB 스키마 설계

```sql
CREATE TABLE sensor_data (
    id SERIAL PRIMARY KEY,
    timestamp BIGINT NOT NULL,
    device VARCHAR(100),
    gps JSONB,
    sensors JSONB,
    network JSONB,
    image_path VARCHAR(500),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

- 센서 데이터: JSONB 형식으로 유연하게 저장
- 이미지: 파일로 저장, DB에는 경로만 저장

#### 3. Android 앱 수정

- **DB Save 스위치 추가**: 앱 상단 헤더에 ON/OFF 토글 추가
- **상태 표시**: 서버 연결 상태에 DB 저장 여부 표시
- **saveToDb 플래그**: 서버로 전송 시 DB 저장 여부 전달

#### 4. EC2 서버 수정 (server.js)

- PostgreSQL 연동 (pg 모듈)
- 이미지 파일 저장 (`~/sensor-monitor/images/`)
- DB 상태 API 추가 (`/api/db/stats`, `/api/db/recent`)
- WebSocket으로 DB 상태 실시간 전송

#### 5. 웹 대시보드 수정

- DB 상태 표시 섹션 추가
  - DB: ON/OFF 상태 (색상으로 구분)
  - Records: 총 저장된 레코드 수
  - Last saved: 마지막 저장 시간
