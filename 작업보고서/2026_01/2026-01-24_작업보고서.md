## 1. 볼트 품질검사 AI 시스템

### 1.1 프로젝트 개요

볼트 생산 라인에서 이미지 기반으로 양품/불량을 자동 선별하는 AI 시스템

| 항목 | 내용 |
|------|------|
| 프로젝트 위치 | `aiTest/boltTest/` |
| 모델 | MobileNetV3-Small (경량 모델) |
| 분류 | 이진 분류 (양품/불량) |
| 결함 유형 | 스크래치, 찍힘, 녹, 균열, 나사산 결손, 이물질 (6종) |

### 1.2 프로젝트 구조

```
boltTest/
├── src/
│   ├── generate_training_data.py    # 데이터 생성 (단일 이미지용)
│   ├── generate_full_dataset.py     # 전체 데이터셋 생성 (다중 이미지용)
│   ├── train.py                     # 모델 학습
│   └── inference.py                 # 추론
├── data/
│   ├── raw/                         # 원본 이미지 (3개)
│   ├── train/good/, defect/         # 학습 데이터 (264개)
│   ├── val/good/, defect/           # 검증 데이터 (66개)
│   └── test/good/, defect/          # 테스트 데이터 (66개)
├── models/
│   ├── best_model.pth               # 최고 성능 모델
│   └── final_model.pth              # 최종 모델
├── sample/                          # 샘플 이미지
└── requirements.txt
```

## 7. 번호판 OCR 벤치마크 - Windows PC 추가

### 7.1 테스트 개요

기존 Mac / Jetson Nano 번호판 인식 벤치마크에 Windows PC를 추가하여 3자 비교 수행

| 항목 | 값 |
|:-----|:---|
| 테스트 위치 | `aiTest/test/` |
| 테스트 이미지 | 30개 (plate_01~30.png) |
| OCR 엔진 | EasyOCR 1.7.2 |
| Windows PC | Lenovo i5-1235U (12세대, Alder Lake) |

### 7.2 Windows PC 테스트 환경

| 항목 | 값 |
|:-----|:---|
| OS | Windows 11 |
| CPU | Intel i5-1235U (10C/12T, 4.4GHz 부스트) |
| RAM | 16GB |
| GPU | 없음 (CPU 모드) |
| Python | 3.14.2 |
| PyTorch | 2.9.1 |

### 7.3 3자 성능 비교 결과

| 항목 | Windows PC | Mac | Jetson Nano |
|:-----|:----------:|:---:|:-----------:|
| **인식률** | 83% | 83% | 83% |
| **평균 시간/장** | **1.00초** | 1.19초 | 2.28초 |
| **처리 속도** | **1.00 FPS** | 0.84 FPS | 0.44 FPS |
| **모델 로딩** | 2.56초 | 2.46초 | 30.14초 |

### 7.4 속도 순위

```
🥇 Windows PC (i5-1235U)  1.00초/장  ████████████████████████░░  가장 빠름
🥈 Mac (i7-4770HQ)        1.19초/장  ████████████████████░░░░░░
🥉 Jetson Nano (GPU)      2.28초/장  ███████████░░░░░░░░░░░░░░░
```

### 7.5 분석

- **Windows PC가 가장 빠른 이유**: i5-1235U는 2022년 출시된 12세대 CPU로, 2013년 i7-4770HQ보다 9세대 신형
- **인식률 동일**: 세 플랫폼 모두 83% (25/30) 동일 - OCR 엔진 일관성 확인
- **Jetson Nano**: GPU 사용에도 CPU보다 느림 (저전력 설계, 모델 로딩 지연)

| 파일 | 설명 |
