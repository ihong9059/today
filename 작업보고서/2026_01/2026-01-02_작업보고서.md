# 작업보고서 2025-01-02

## 작업 개요
UTTEC Edu 플랫폼 ESP32 Arduino IoT 과정 확장 (3개 레벨 → 8개 레벨, 100일 과정)

## 문제 상황
- 기존 ESP32 과정이 초급/중급/고급 3개 레벨로만 구성
- Day 16 이후 프롬프트가 비어있거나 제목과 내용 불일치
- 레슨 목록의 제목과 실제 프롬프트 내용이 다름

### 원인 분석
- 기존에 3개 레벨(초급/중급/고급)만 정의됨
- 프롬프트가 page.tsx 내부에 하드코딩되어 관리 어려움
- 중급/고급 프롬프트가 비어있거나 플레이스홀더 상태

## 해결 방법

### 1. 8개 레벨 구조로 확장

| 레벨 | ID | 일차 | 핵심 주제 |
|------|-----|------|----------|
| 초급 | beginner | Day 1-15 | GPIO, PWM, ADC, 센서 기초 |
| 중급1 | intermediate1 | Day 16-25 | WiFi AP, 캡티브 포털, SPIFFS |
| 중급2 | intermediate2 | Day 26-35 | WebSocket, SD카드, NTP |
| 중급3 | intermediate3 | Day 36-45 | LoRa 장거리 통신, 메시 네트워크 |
| 고급1 | advanced1 | Day 46-60 | MQTT, ThingSpeak, Firebase, AWS IoT |
| 고급2 | advanced2 | Day 61-75 | OTA 업데이트, ESP-NOW, 딥슬립, BLE |
| 고급3 | advanced3 | Day 76-90 | FreeRTOS 태스크, 세마포어, 큐, 듀얼코어 |
| 마스터 | master | Day 91-100 | Home Assistant, MQTT Discovery, 최종 프로젝트 |
