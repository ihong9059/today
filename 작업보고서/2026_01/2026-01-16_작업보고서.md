## 5. 회사 네트워크 정보

### 회사 공인 IP
- **IP 주소**: 211.46.174.177
- **용도**: 회사 네트워크 외부 접속용

### 회사 Raspberry Pi 5 localtunnel 접속 문제

**URL**: https://lucky-laws-design.loca.lt

#### 문제 상황
- localtunnel 접속 시 Tunnel Password 요구
- 회사 공인 IP (211.46.174.177) 입력 → 실패
- 집 PC 공인 IP 입력 → 실패
- 에러: "endpoint IP is not correct"

#### 원인 추정
1. 회사 Raspberry Pi 5에서 localtunnel 프로세스 중단
2. 터널 URL 만료 (연결 끊기면 URL 변경됨)
3. localtunnel 서버 측 문제

#### 해결 방법 (회사에서 확인 필요)

```bash
# 1. localtunnel 프로세스 확인
ps aux | grep lt

# 2. localtunnel 재시작 (포트 번호는 실제 서버 포트로 변경)
lt --port 3000

# 3. subdomain 고정으로 실행
lt --port 3000 --subdomain lucky-laws-design
```

#### 대안: ngrok 사용 (권장)
ngrok은 비밀번호 인증 문제가 없음:

```bash
# Raspberry Pi 5에서
ngrok http 3000
```
