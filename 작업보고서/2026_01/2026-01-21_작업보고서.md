## 5. AI 번호판 인식 테스트

### 개요

EasyOCR 기반 자동차 번호판 인식 프로그램을 개발하고, Windows PC와 Raspberry Pi 5에서 성능을 비교 테스트했습니다.

### 테스트 환경

| 항목 | Windows PC | Raspberry Pi 5 |
|------|------------|----------------|
| CPU | Intel UHD (내장) | ARM Cortex-A76 |
| GPU | 없음 (CPU only) | 없음 (CPU only) |
| Python | 3.14 | 3.13 |
| EasyOCR | 1.7.2 | 1.7.2 |

### 테스트 데이터

- 이미지 수: 10개 (plate_01.png ~ plate_10.png)
- 이미지 크기: 약 1.7~1.9MB/장

### 성능 비교 결과
