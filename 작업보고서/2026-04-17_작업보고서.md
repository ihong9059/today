## 작업 상세 내용

### Claude CLI Windows 이슈
- Windows에서 `claude -p -` stdin 파이프 안 됨
- 해결: bash cat 파이프 방식 (`cat file | claude -p -`)
- `--output-format stream-json --verbose`로 응답 추출

### BLE OTA 프로토콜
- OTA START: 리틀엔디안으로 크기 전송 (보드 펌웨어 기준)
- DATA: 240바이트 청크, writeWithoutResponse, 20청크마다 30ms delay
- OTA END: 보드 재부팅 → BLE 끊김 → 5초 후 자동 재연결

### 사전빌드 서버 구조

- API: /api/catalog, /api/prebuilt/{no}, /api/prebuilt/{no}/guide, /api/search
- firmware_db/: A01~A10 (각 ~635KB)
