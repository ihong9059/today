## 작업 상세 내용

### ESP32-C3 스마트폰 BLE OTA 프로젝트
- 스마트폰(Android)에서 ESP32-C3 펌웨어 개발 → BLE OTA 업데이트 파이프라인 설계
- 핵심 아키텍처: 코드 편집(Acode) → GitHub Actions 빌드 → .bin 다운로드 → BLE OTA 플래싱
- ESP32-C3는 RISC-V → Termux 네이티브 컴파일 불가, 클라우드 빌드 필수
- BLE OTA 참고 오픈소스: fbiego/ESP32_BLE_OTA_Arduino + Android 앱
- Phase 0~4 단계별 계획 수립 (예상 3~4일)
