# 가족 소통 플랫폼 프로젝트 계획서

## Family Connect - 우리 가족의 소통 공간

**작성일:** 2026-01-25
**버전:** v1.0

---

## 1. 프로젝트 개요

### 1.1 배경

현대 사회의 핵가족화로 인해 가족 간 물리적 거리가 멀어지고, 바쁜 일상 속에서 소통의 기회가 줄어들고 있습니다. 카카오톡, 문자 등 기존 메신저는 즉각적인 소통에는 좋지만, 소중한 추억과 일상을 기록하고 공유하기에는 부족합니다.

### 1.2 목표

가족만의 **프라이빗 공간**에서:
- 소중한 **추억**을 사진과 글로 기록하고 공유
- 일상적인 **대화**와 안부를 나눔
- 현재 하고 있는 일과 **관심사**를 글로 공유
- 가족 **일정**과 행사를 함께 관리

### 1.3 핵심 가치

```
┌─────────────────────────────────────────────────────────────┐
│                    Family Connect 핵심 가치                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   🏠 프라이버시    우리 가족만의 비공개 공간                 │
│   💝 추억 보존    사진, 글로 소중한 순간 기록                │
│   💬 소통        일상 대화와 안부 나눔                      │
│   📅 함께함      가족 일정과 행사 공유                      │
│   🔗 연결        멀리 있어도 마음은 가까이                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 주요 기능

### 2.1 기능 목록

| 기능 | 설명 | 우선순위 |
|------|------|:--------:|
| **가족 피드** | 일상, 근황, 관심사를 글과 사진으로 공유 | 높음 |
| **추억 앨범** | 사진/동영상을 날짜별, 이벤트별로 정리 | 높음 |
| **대화방** | 가족 단체 채팅 및 개인 메시지 | 높음 |
| **가족 캘린더** | 생일, 기념일, 가족 행사 공유 | 중간 |
| **안부 게시판** | 오늘 하루, 건강 상태 등 간단한 안부 | 중간 |
| **가족 프로필** | 각 가족 구성원 소개 페이지 | 낮음 |

### 2.2 기능 상세

#### 2.2.1 가족 피드 (Family Feed)
```
┌─────────────────────────────────────────┐
│  👨 아빠                    2026.01.25  │
│  ─────────────────────────────────────  │
│  오늘 등산 다녀왔어요! 정상에서 찍은    │
│  사진이에요. 날씨가 정말 좋았습니다.    │
│                                         │
│  [📷 사진 3장]                          │
│                                         │
│  ❤️ 3  💬 2                             │
│  └ 👩 엄마: 멋지네요~                   │
│  └ 👧 딸: 아빠 화이팅!                  │
└─────────────────────────────────────────┘
```

#### 2.2.2 추억 앨범 (Memory Album)
- 연도/월별 자동 분류
- 이벤트 태그 (여행, 생일, 명절 등)
- 가족 구성원별 필터
- 슬라이드쇼 기능

#### 2.2.3 가족 캘린더
- 생일, 기념일 자동 알림
- 가족 행사 일정 공유
- D-day 카운트다운

## 3. 기술 스택

### 3.1 Phase 1 (MVP - 최소 기능 제품)

| 구분 | 기술 | 이유 |
|------|------|------|
| **Frontend** | HTML, CSS, JavaScript | 심플하고 빠른 개발 |
| **Backend** | Python (Flask) | 가볍고 배우기 쉬움 |
| **Database** | SQLite → JSON 파일 | 소규모 가족용, 간단함 |
| **Server** | Raspberry Pi 5 | 저전력, 24시간 운영 |

### 3.2 Phase 2 (확장)

| 구분 | 기술 | 이유 |
|------|------|------|
| **Frontend** | React / Next.js | 더 나은 UX |
| **Backend** | Node.js | 실시간 기능 |
| **Database** | PostgreSQL | 안정성, 확장성 |
| **Storage** | MinIO | 사진/동영상 저장 |
