# [System Prompt for claude: Hyper-Personalized AI Meal Planner "Plan It"]

## 1. 프로젝트 개요 (App Purpose)
*   **앱 명칭:** Plan It (가칭)
*   **핵심 목적:** 단순한 칼로리 추적을 넘어, AI를 통해 사용자의 식이 선호도, 건강 목표, 예산 및 냉장고 잔여 식재료를 분석하여 **능동적인 주간 식단 계획 및 관리를 자동화**하는 '내 손안의 AI 영양 코치' 구현.
*   **타겟 사용자:** 시간 제약이 심한 직장인, 건강 관리가 필요한 환자(당뇨 등), 식비 절감과 식재료 낭비 방지를 원하는 가구.

## 2. 핵심 기능 및 상세 요구사항 (Core Features)

### A. AI 멀티모달 데이터 입력 시스템
*   **사진 기반 영양 분석:** 사용자가 음식 사진을 업로드하면 컴퓨터 비전 AI가 음식 종류와 양을 인식하여 칼로리 및 영양 성분(탄/단/지)을 즉시 추정해야 함 (SnapCalorie 기술 수준의 90% 정확도 지향).
*   **자연어 음성/텍스트 로깅:** "오늘 점심으로 닭가슴살 샐러드와 사과 반 쪽 먹었어"와 같은 일상 언어를 구조화된 영양 데이터로 변환.

### B. 지능형 주간 식단 생성 엔진 (Dynamic Meal Planning)
*   **개인 맞춤형 플랜:** 사용자의 식이 제한(비건, 키토, 당뇨식 등), 목표(체중 감량, 근육 증량), 예산($5/끼니 등)을 반영한 주간 식단 자동 생성.
*   **냉장고 파먹기 (Pantry Management):** 현재 보유 중인 식재료를 기반으로 식재료 낭비를 최소화하는 레시피를 우선 추천.
*   **스마트 대체 제안:** 특정 재료가 없거나 알레르기가 있는 경우, 영양학적으로 유사한 대체 재료를 AI가 즉시 제안.

### C. 협업 및 관리 도구
*   **가족/파트너 공유 플래너:** 가구 구성원이 식단을 함께 계획하고 장바구니를 실시간 공유하며, 관리자(예: 부모)가 최종 식단을 승인하는 기능.
*   **유통기한 추적:** 식재료별 유통기한을 관리하고 임박한 재료를 활용한 식단을 푸시 알림으로 추천.

### D. 데이터 기반 동기부여 (Gamification)
*   **시각적 지표:** 목표 달성률을 보여주는 **진행 표시줄(Progress bars)**과 **목표 설정(Goal-setting)** 기능을 최우선 배치.
*   **습관 형성 보상:** 연속 기록(Streaks) 달성 시 건강 관련 **쿠폰(Coupons)**이나 배지 제공.

## 3. 사용자 흐름 (User Flow: Start to Finish)

1.  **온보딩 (Onboarding):** 사용자의 기본 정보(나이, 체중), 건강 목표, 식이 선호도, 알레르기 정보를 수집하여 개인 프로필 구축.
2.  **주간 계획 수립 (Planning):** AI가 주간 식단 초안을 생성. 사용자는 드래그 앤 드롭으로 메뉴를 수정하거나 AI에게 "더 저렴한 식단으로 변경해줘"라고 요청.
3.  **장바구니 및 구매 (Shopping):** 확정된 식단에 필요한 재료가 **식료품점 동선에 맞게 정렬된 목록**으로 자동 변환. Instacart API 등을 통해 즉시 주문 가능.
4.  **식사 기록 및 모니터링 (Tracking):** 식사 전후 사진 촬영이나 음성 입력을 통해 30초 이내에 로깅 완료.
5.  **피드백 및 조정 (Review):** 일일/주간 영양 섭취 분석 리포트를 제공하고, 목표 미달 시 내일 식단을 AI가 자동으로 보정.

## 4. 디자인 스타일 및 비주얼 아이덴티티 (Design Style)

*   **메인 컬러:** 신선함과 투명성을 상징하는 **세이지 그린(Sage Green, #b9c7bd)** 및 자연 톤 사용.
*   **데이터 시각화:** 복잡한 영양 데이터를 처리하는 대시보드에는 신뢰감과 평온함을 주는 **쿨 블루/퍼플(#bde6ee, #837cb3)** 계열 활용.
*   **강조 포인트:** '식단 생성'이나 '결제' 등 핵심 행동 유도 버튼(CTA)에는 활기찬 **오렌지(#fa7f1c)** 사용.
*   **UX 원칙:** 인지적 부하를 최소화하는 간결한 인터페이스와 '디지털 웰빙'을 고려하여 과도한 알림을 자제하는 디자인.

## 5. 기술 아키텍처 및 API 통합 요구사항 (Technical Architecture)

*   **Frontend:** SEO 및 성능 최적화를 위한 **Next.js**.
*   **Backend:** 확장성 있는 AI 연동을 위한 **Python (FastAPI)**.
*   **Database:** 사용자 건강 데이터는 **PostgreSQL**, 유연한 레시피 데이터는 **MongoDB** 사용.
*   **필수 API 연동:**
    *   **영양 데이터:** 한국 시장 타겟 시 **식품안전나라 I2790 API** 필수 연동. 글로벌용으로 **USDA FDC API** 및 **spoonacular** 사용.
    *   **AI 분석:** 음식 인식용 **Clarifai** 및 자연어 처리용 **ChatGPT-4/Gemini** API.
*   **보안:** 건강 정보 취급을 위해 **HIPAA(미국) 및 GDPR(유럽) 준수** 아키텍처 설계.
