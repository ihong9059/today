# 1. 주식의 역사

## 학습 목표
- 주식의 기원과 발전 과정을 이해한다
- 세계 주요 증권거래소의 탄생 배경을 알아본다
- 주식시장의 역사적 사건들을 통해 교훈을 얻는다

---

## 1.1 주식의 기원

### 1.1.1 최초의 주식회사: 동인도회사

| 구분 | 내용 |
|------|------|
| **설립** | 1602년, 네덜란드 |
| **정식명칭** | 네덜란드 동인도회사 (VOC: Vereenigde Oost-Indische Compagnie) |
| **목적** | 아시아 향신료 무역 독점 |
| **혁신** | 최초로 일반 대중에게 주식 발행 |

```
┌─────────────────────────────────────────────────────────────┐
│                    주식회사의 탄생 배경                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   문제: 대규모 무역선 건조 비용 → 개인이 감당 불가            │
│                     ↓                                       │
│   해결: 여러 사람이 돈을 모아 투자 (자본 공동 출자)           │
│                     ↓                                       │
│   보상: 투자 비율에 따라 이익 배분 (배당금)                  │
│                     ↓                                       │
│   거래: 투자 지분(주식)을 다른 사람에게 매매 가능             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.1.2 왜 네덜란드였나?

1. **해상 무역 강국**: 17세기 네덜란드는 세계 최고의 해운국
2. **상업 문화**: 무역과 금융에 개방적인 사회 분위기
3. **법적 기반**: 유한책임 개념 도입 (투자금 이상 손실 없음)
4. **자본 집중**: 암스테르담에 풍부한 자본 축적

## 1.2 세계 주요 증권거래소의 역사

### 1.2.1 암스테르담 증권거래소 (1602년)

- **세계 최초의 공식 증권거래소**
- 네덜란드 동인도회사 주식 거래를 위해 설립
- 현재 유로넥스트(Euronext)의 일부

### 1.2.2 런던 증권거래소 (1801년 공식화)

| 시기 | 발전 과정 |
|------|----------|
| 1698년 | 조나단 커피하우스에서 비공식 거래 시작 |
| 1773년 | "증권거래소(Stock Exchange)" 명칭 사용 |
| 1801년 | 공식 증권거래소 설립 |
| 현재 | LSE Group으로 세계 3대 거래소 |

## 1.3 주식시장의 역사적 대사건

### 1.3.1 튤립 버블 (1637년, 네덜란드)

| 항목 | 내용 |
|------|------|
| **배경** | 튤립이 부의 상징으로 인기 급등 |
| **절정** | 희귀 튤립 구근 1개 = 암스테르담 운하 주택 1채 |
| **붕괴** | 1637년 2월, 갑작스러운 가격 폭락 |
| **교훈** | 실체 없는 투기의 위험성 (최초의 자산 버블) |

### 1.3.2 남해회사 버블 (1720년, 영국)

- **발단**: 남해회사가 영국 국채 인수권 획득
- **광풍**: 주가 100파운드 → 1,000파운드 (10배 상승)
- **피해자**: 과학자 뉴턴도 큰 손실
- **뉴턴의 말**: "천체의 운동은 계산할 수 있어도, 인간의 광기는 계산할 수 없다"

### 1.3.3 대공황 (1929년, 미국)

```

### 1.3.4 블랙 먼데이 (1987년, 세계)

- **일시**: 1987년 10월 19일 (월요일)
- **하락폭**: 다우지수 하루 -22.6% (역대 최대 일일 하락률)
- **원인**: 프로그램 매매, 포트폴리오 보험의 연쇄 작용
- **교훈**: 자동화된 거래 시스템의 위험성

### 1.3.5 닷컴 버블 (2000년, 세계)

| 시기 | 사건 |
|------|------|
| 1995-2000 | 인터넷 기업 주가 급등 (나스닥 5,000 돌파) |
| 2000.3 | 버블 붕괴 시작 |
| 2002.10 | 나스닥 1,114까지 하락 (-78%) |
| 교훈 | "이번엔 다르다"는 말을 경계해야 |

## 1.4 역사에서 배우는 교훈

### 1.4.1 반복되는 패턴

```
    광기와 공포의 순환

    ┌─────┐
    │ 회복 │ ←─────────────────────────┐
    └──┬──┘                            │
       │                               │
       ▼                               │
    ┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐
    │ 상승 │───→│ 과열 │───→│ 버블 │───→│ 붕괴 │
    └─────┘    └─────┘    └─────┘    └──┬──┘
                                        │
                                        ▼
                                    ┌─────┐
                                    │ 공포 │
                                    └─────┘
```

### 1.4.2 역사적 교훈 정리

| 번호 | 교훈 | 사례 |
|:----:|------|------|
| 1 | 군중심리를 경계하라 | 튤립 버블, 닷컴 버블 |
| 2 | 레버리지(빚)는 양날의 검 | 1929년 대공황 |
| 3 | 분산투자가 중요하다 | 모든 위기에서 입증 |
| 4 | 시장은 결국 회복한다 | 대공황도 25년 만에 회복 |
| 5 | "이번엔 다르다"를 의심하라 | 모든 버블의 공통 특징 |

│                                                             │
│  4. 교훈: 역사를 아는 투자자가 살아남는다                    │

```
