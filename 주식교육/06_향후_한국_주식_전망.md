## 학습 목표

```
│      → 10년 이상 보유 시 손실 확률 대폭 감소               │
│                                                             │
│   2. 분산 투자하라                                          │
│      "계란을 한 바구니에 담지 마라"                         │
│      → 산업, 지역, 자산군 분산                              │
│                                                             │
│   3. 적립식 투자를 활용하라                                 │
│      "시장 타이밍은 신도 모른다"                            │
│      → 매월 일정액 투자로 평균 단가 낮추기                  │
│                                                             │
│   4. 투자는 여유 자금으로                                   │
│      "빚내서 투자는 도박"                                   │
│      → 3~5년 쓸 일 없는 돈으로만                           │
│                                                             │
│   5. 공부를 게을리하지 마라                                 │
│      "아는 만큼 번다"                                       │
│      → 기업 분석, 경제 공부 꾸준히                          │
│                                                             │
│   6. 감정에 휘둘리지 마라                                   │
│      "공포에 사고, 탐욕에 팔아라"                           │
│      → 투자 원칙을 세우고 지키기                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
