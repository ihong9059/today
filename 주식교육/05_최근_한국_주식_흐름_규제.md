## 학습 목표

## 5.2 주요 규제 및 제도

### 5.2.1 공매도 규제

```
┌─────────────────────────────────────────────────────────────┐
│                     공매도 규제 현황                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   공매도란?                                                 │
│   ─────────                                                 │
│   주식을 빌려서 팔고, 나중에 낮은 가격에 사서 갚는 것       │
│   → 주가 하락에 베팅하는 투자 전략                         │
│                                                             │
│   규제 역사:                                                │
│   ─────────                                                 │
│   2020.03.16  전면 금지 (코로나19 충격)                     │
│   2021.05.03  부분 재개 (KOSPI200, KOSDAQ150만)             │
│   2023.11.06  불법 공매도 적발 → 재금지                     │
│   2025.03.31  재개 예정 (불법 방지 시스템 강화 후)          │
│                                                             │
│   불법 공매도:                                              │
│   ────────────                                              │
│   • 무차입 공매도 (주식 확보 없이 매도)                     │
│   • 글로벌 IB 불법 공매도 적발                              │
│   • 과징금 및 형사처벌 강화                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2.2 금융투자소득세 (금투세)

| 항목 | 내용 |
|------|------|
| **정의** | 주식·펀드 등 금융투자 수익에 대한 세금 |
| **세율** | 3억 원 이하 20%, 초과분 25% |
| **공제** | 연 5,000만 원 기본 공제 |
| **도입 경과** | 2020년 입법 → 2023년 유예 → 2025년 유예 → 폐지 추진 중 |
| **쟁점** | 투자 위축 vs 과세 형평성 |

## 5.3 투자자 보호 규정

### 5.3.1 불공정거래 유형과 처벌

| 유형 | 내용 | 처벌 |
|------|------|------|
| **내부자거래** | 미공개 정보로 매매 | 10년 이하 징역, 부당이득 3~5배 과징금 |
| **시세조종** | 인위적 가격 조작 | 10년 이하 징역, 1억 이하 벌금 |
| **부정거래** | 허위 정보 유포 | 10년 이하 징역, 5억 이하 벌금 |
| **무차입공매도** | 주식 확보 없이 매도 | 1년 이하 징역, 과징금 |

### 5.3.2 투자자 주의사항

```
┌─────────────────────────────────────────────────────────────┐
│                   개인 투자자 주의사항                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. 리딩방 사기 주의                                       │
│      • SNS/카톡 종목 추천 대부분 사기                       │
│      • 수익 보장 = 100% 사기                                │
│      • 선입금 요구 = 무조건 피할 것                         │
│                                                             │
│   2. 작전주 주의                                            │
│      • 갑자기 급등하는 소형주 주의                          │
│      • 거래량 급증 후 폭락 패턴                             │
│      • "세력"이 있다는 말 믿지 말 것                        │
│                                                             │
│   3. 미공개정보 이용 금지                                   │
│      • 회사 내부 정보로 거래 시 처벌                        │
│      • 가족, 지인에게 정보 전달도 처벌                      │
│      • 의심스러운 정보는 무시할 것                          │
│                                                             │
│   4. 투자금 관리                                            │
│      • 빚내서 투자 금지                                     │
│      • 여유자금으로만 투자                                  │
│      • 손절 기준 미리 정하기                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐

│   ─────────────────────                                     │
│   ┌─────────────────────────────────────────────┐          │
│   │ 코스피: 증권거래세 0.03% + 농특세 0.15%     │          │
│   │        = 합계 0.18%                         │          │
│   ├─────────────────────────────────────────────┤          │
│   │ 코스닥: 증권거래세 0.18%                    │          │

│   └─────────────────────────────────────────────┘          │
│                                                             │
│   ※ 2023년까지 코스피 0.08%, 코스닥 0.23%였으나            │
│      단계적 인하되어 2025년 동일하게 0.18%                  │
│                                                             │
│   배당소득세:                                               │
│   ─────────────                                             │
│   • 세율: 15.4% (소득세 14% + 지방세 1.4%)                 │
│   • 원천징수 후 지급                                        │
│   • 금융소득 2,000만 원 초과 시 종합과세                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.5.3 주식 양도세 대주주 기준

```
    대주주 기준 변화
    ─────────────────────────────────────
    ~2020년: 지분 1% 또는 15억 원
    2021년: 지분 1% 또는 10억 원
    2024년: 지분 1% 또는 50억 원 (완화)
    ─────────────────────────────────────

    → 10억 원 → 50억 원으로 완화되어
       대부분의 개인 투자자는 양도세 비과세
```
