## 학습 목표

- 주식 거래 방법과 절차를 알아본다

## 2.1 주식이란?

### 2.1.1 주식의 정의

```
┌─────────────────────────────────────────────────────────────┐
│                       주식(Stock)이란?                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   회사의 소유권을 잘게 나눈 것                               │
│                                                             │
│   예시: 삼성전자 총 발행주식 = 약 59억 주                    │
│         → 1주 = 삼성전자의 1/59억 소유권                    │
│                                                             │
│   주주(株主) = 주식을 가진 사람 = 회사의 주인 중 한 명       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.1.2 주식을 사면 얻는 것

| 권리 | 설명 |
|------|------|
| **의결권** | 주주총회에서 회사 중요 결정에 투표 |
| **배당권** | 회사 이익의 일부를 배당금으로 받음 |
| **잔여재산분배권** | 회사 청산 시 남은 재산 분배받음 |
| **신주인수권** | 새 주식 발행 시 우선 매수 권리 |

### 2.1.3 주식 vs 채권

| 구분 | 주식 | 채권 |
|------|------|------|
| **성격** | 소유권 (주인) | 채권 (빚 준 사람) |
| **수익** | 배당금 + 시세차익 | 이자 (확정) |
| **리스크** | 높음 (원금 손실 가능) | 낮음 (원금 보장 가능) |
| **기간** | 영구 | 만기 있음 |
| **청산 시** | 채권자 다음 순위 | 주주보다 먼저 |

## 2.2 주식 거래의 기초

### 2.2.1 거래 시간

```
┌─────────────────────────────────────────────────────────────┐
│              한국 증권시장 거래 시간 (월~금)                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   08:30 ~ 09:00    동시호가 (장 시작 준비)                  │
│   09:00 ~ 15:30    정규장 (실제 거래)                       │
│   15:30 ~ 15:40    장 마감 동시호가                         │
│   15:40 ~ 16:00    시간외 단일가                            │
│   16:00 ~ 18:00    시간외 종가                              │
│                                                             │
│   ※ 토, 일, 공휴일 휴장                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2.2 주문 유형

| 주문 유형 | 설명 | 장점 | 단점 |
|----------|------|------|------|
| **시장가** | 현재 가격에 즉시 체결 | 빠른 체결 | 가격 통제 불가 |
| **지정가** | 원하는 가격에 주문 | 가격 통제 가능 | 체결 안 될 수 있음 |
| **조건부지정가** | 지정가 → 장 마감 시 시장가 | 절충안 | 복잡함 |

### 2.2.3 매수와 매도

```
    매수(買收) = 사다                매도(賣渡) = 팔다
         │                               │
         ▼                               ▼
    ┌─────────┐                    ┌─────────┐
    │  주식을  │                    │  주식을  │
    │   산다   │                    │   판다   │
    └─────────┘                    └─────────┘
         │                               │
         ▼                               ▼
    돈 → 주식                        주식 → 돈
```

## 2.3 주요 투자 지표

### 2.3.1 주가 관련 기본 용어

| 용어 | 의미 | 예시 |
|------|------|------|
| **현재가** | 지금 거래되는 가격 | 70,000원 |
| **시가** | 당일 첫 거래 가격 | 69,500원 |
| **고가** | 당일 최고가 | 71,000원 |
| **저가** | 당일 최저가 | 68,000원 |
| **종가** | 당일 마지막 가격 | 70,500원 |
| **전일대비** | 어제 종가와의 차이 | +1,000원 (▲1.44%) |

### 2.3.2 거래량과 거래대금

```
┌─────────────────────────────────────────────────────────────┐
│                  거래량 vs 거래대금                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   거래량 = 거래된 주식의 수                                  │
│   예: 오늘 삼성전자 100만 주 거래됨                         │
│                                                             │
│   거래대금 = 거래량 × 가격                                  │
│   예: 100만 주 × 70,000원 = 700억 원                        │
│                                                             │
│   ※ 거래량이 많으면 = 관심 많음, 유동성 좋음                │
│   ※ 거래량이 적으면 = 관심 적음, 사고팔기 어려움            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3.3 시가총액

```
    시가총액 = 주가 × 발행주식 수

    예시: 삼성전자
    ─────────────────────────────────────
    주가: 70,000원
    발행주식: 약 59억 주
    시가총액: 70,000 × 59억 ≈ 413조 원
    ─────────────────────────────────────

    → 회사의 전체 가치를 나타내는 지표
    → 시가총액이 크면 "대형주", 작으면 "소형주"
```

## 2.4 핵심 투자 지표 (밸류에이션)

### 2.4.1 PER (주가수익비율)

```
┌─────────────────────────────────────────────────────────────┐
│                          PER                                 │
│              (Price Earning Ratio)                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   공식: PER = 주가 ÷ 주당순이익(EPS)                        │
│                                                             │
│   의미: 투자금 회수에 몇 년이 걸리나?                       │
│                                                             │
│   예시:                                                     │
│   주가 10,000원, EPS 1,000원 → PER = 10배                  │
│   → "1년에 1,000원 벌면, 10년이면 10,000원"                │
│                                                             │
│   해석:                                                     │
│   PER 낮으면 → 저평가 (싸다)                               │
│   PER 높으면 → 고평가 (비싸다) 또는 성장 기대               │
│                                                             │
│   업종별 평균 PER이 다르므로 같은 업종끼리 비교해야 함      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4.2 PBR (주가순자산비율)

```
┌─────────────────────────────────────────────────────────────┐
│                          PBR                                 │
│              (Price Book-value Ratio)                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   공식: PBR = 주가 ÷ 주당순자산(BPS)                        │
│                                                             │
│   의미: 회사 청산하면 얼마 돌려받나?                        │
│                                                             │
│   예시:                                                     │
│   주가 10,000원, BPS 5,000원 → PBR = 2배                   │
│   → 순자산의 2배 가격에 거래 중                             │
│                                                             │
│   해석:                                                     │
│   PBR < 1 → 주가가 순자산보다 낮음 (저평가 가능성)          │
│   PBR > 1 → 주가가 순자산보다 높음 (성장 프리미엄)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4.3 ROE (자기자본이익률)

```
┌─────────────────────────────────────────────────────────────┐
│                          ROE                                 │
│              (Return On Equity)                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   공식: ROE = 순이익 ÷ 자기자본 × 100%                      │
│                                                             │
│   의미: 주주 돈으로 얼마나 벌었나?                          │
│                                                             │
│   예시:                                                     │
│   자기자본 1000억, 순이익 150억 → ROE = 15%                │
│   → 주주 돈 100원당 15원을 벌었다                          │
│                                                             │
│   해석:                                                     │
│   ROE 10% 이상 → 일반적으로 우량 기업                      │
│   ROE 15% 이상 → 수익성 좋은 기업                          │
│   ROE 20% 이상 → 매우 우수한 기업                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4.4 배당수익률

```
    배당수익률 = (주당배당금 ÷ 주가) × 100%

    예시:
    ─────────────────────────────────────
    주가: 50,000원
    연간 배당금: 2,000원
    배당수익률: 2,000 ÷ 50,000 = 4%
    ─────────────────────────────────────

    → 은행 이자와 비교 가능
    → 배당주 투자자에게 중요한 지표
```

## 2.5 주식 차트 기초

### 2.5.1 캔들 차트 읽기

```
┌─────────────────────────────────────────────────────────────┐
│                     캔들(봉) 차트                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│        양봉 (상승)              음봉 (하락)                  │
│                                                             │
│           │ ← 윗꼬리              │ ← 윗꼬리               │
│        ┌──┴──┐                 ┌──┴──┐                     │
│        │     │                 │█████│                     │
│        │     │ ← 몸통          │█████│ ← 몸통              │
│        │     │ (빨강/흰색)     │█████│ (파랑/검정)         │
│        └──┬──┘                 └──┬──┘                     │
│           │ ← 아랫꼬리            │ ← 아랫꼬리              │
│                                                             │
│   양봉: 시가 < 종가 (올랐다)                                │
│   음봉: 시가 > 종가 (내렸다)                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.5.2 이동평균선

```
┌─────────────────────────────────────────────────────────────┐
│                      이동평균선                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   이동평균 = 일정 기간 종가의 평균                          │
│                                                             │
│   주요 이동평균선:                                          │
│   ─────────────────────────────────────                     │
│   5일선  → 단기 추세 (1주일)                               │
│   20일선 → 중단기 추세 (1개월)                             │
│   60일선 → 중기 추세 (3개월)                               │
│   120일선 → 장기 추세 (6개월)                              │
│   200일선 → 초장기 추세 (1년)                              │
│                                                             │
│   활용:                                                     │
│   주가 > 이동평균선 → 상승 추세                            │
│   주가 < 이동평균선 → 하락 추세                            │
│   단기선이 장기선 상향 돌파 → 골든크로스 (매수 신호)        │
│   단기선이 장기선 하향 돌파 → 데드크로스 (매도 신호)        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2.6 주식 계좌 개설하기

### 2.6.1 증권사 선택 기준

| 기준 | 설명 |
|------|------|
| **수수료** | 매매 수수료 (보통 0.015%~0.5%) |
| **MTS/HTS** | 모바일/PC 거래 앱 편의성 |
| **리서치** | 종목 분석 자료 품질 |
| **이벤트** | 신규 가입 혜택 |
| **해외주식** | 해외 주식 거래 가능 여부 |

### 2.6.2 계좌 종류

```
┌─────────────────────────────────────────────────────────────┐
│                     주요 계좌 종류                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. 위탁계좌 (일반 주식계좌)                               │
│      - 가장 기본적인 주식 거래 계좌                         │
│      - 국내/해외 주식 거래 가능                             │
│                                                             │
│   2. ISA (개인종합자산관리계좌)                             │
│      - 비과세/분리과세 혜택                                 │
│      - 연 2,000만원 납입 한도                               │
│      - 의무 가입 3년                                        │
│                                                             │
│   3. 연금저축계좌                                           │
│      - 세액공제 혜택 (연 400만원 한도)                      │
│      - 55세 이후 연금 수령                                  │
│                                                             │
│   4. IRP (개인형퇴직연금)                                   │
│      - 세액공제 혜택 (연 700만원 한도)                      │
│      - 퇴직금 이전 가능                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 핵심 정리

```
┌─────────────────────────────────────────────────────────────┐
│                    주식 기초 지식 요약                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 주식 = 회사의 소유권                                    │
│     → 주주는 배당금과 의결권을 가짐                         │
│                                                             │
│  2. 거래 시간: 09:00 ~ 15:30 (월~금)                       │
│     → 시장가 vs 지정가 주문 이해 필수                       │
│                                                             │
│  3. 핵심 지표                                               │
│     → PER: 주가/이익 (몇 배로 거래되나)                    │
│     → PBR: 주가/순자산 (자산 대비 가격)                    │
│     → ROE: 순이익/자본 (수익성)                            │
│                                                             │
│  4. 차트 기초                                               │
│     → 양봉(상승), 음봉(하락)                               │
│     → 이동평균선으로 추세 파악                              │
│                                                             │
│  5. 세금: 매도 시 약 0.33% (코스피 기준)                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
