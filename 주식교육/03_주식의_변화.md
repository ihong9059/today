# 3. 주식의 변화

## 학습 목표
- 주식 시장의 기술적 발전 과정을 이해한다
- 새로운 투자 방식과 상품의 등장을 알아본다
- 현대 주식 시장의 특징을 파악한다

---

## 3.1 거래 방식의 변화

### 3.1.1 거래 방식의 진화

```
┌─────────────────────────────────────────────────────────────┐
│                   주식 거래 방식의 진화                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   [1600년대]           [1900년대]           [2000년대]      │
│        │                    │                    │         │
│        ▼                    ▼                    ▼         │
│   ┌─────────┐          ┌─────────┐          ┌─────────┐   │
│   │ 대면거래 │    →     │ 전화거래 │    →     │전자거래 │   │
│   │(커피하우스)│         │(객장/지점)│         │(HTS/MTS)│   │
│   └─────────┘          └─────────┘          └─────────┘   │
│        │                    │                    │         │
│   거래소에 직접       전화로 주문        스마트폰으로        │
│   모여서 거래         증권사 전달          실시간 거래        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.1.2 전자거래 시스템의 도입

| 시기 | 국가 | 내용 |
|------|------|------|
| 1971년 | 미국 | NASDAQ 최초의 전자 증권거래소 |
| 1988년 | 한국 | 한국거래소 전산화 시작 |
| 1997년 | 한국 | HTS(홈트레이딩시스템) 도입 |
| 2000년대 | 세계 | 고빈도 매매(HFT) 등장 |
| 2010년대 | 세계 | MTS(모바일트레이딩) 보편화 |

```

## 3.2 투자 상품의 다양화

### 3.2.1 새로운 투자 상품들

```
┌─────────────────────────────────────────────────────────────┐
│                   현대의 투자 상품 종류                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   개별 주식                                                 │
│      └── ETF (상장지수펀드)                                │
│             └── 레버리지 ETF (2배, 3배)                    │
│             └── 인버스 ETF (하락에 베팅)                   │
│             └── 섹터 ETF (특정 산업)                       │
│             └── 테마 ETF (AI, ESG 등)                      │
│                                                             │
│   펀드                                                      │
│      └── 인덱스 펀드 (지수 추종)                           │
│      └── 액티브 펀드 (매니저 운용)                         │
│      └── TDF (타겟데이트펀드)                              │
│                                                             │
│   파생상품                                                  │
│      └── 선물 (미래 가격 계약)                             │
│      └── 옵션 (매수/매도 권리)                             │
│      └── ELW (주식워런트증권)                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2.2 ETF의 급성장

| 구분 | 설명 |
|------|------|
| **정의** | 거래소에 상장된 펀드 (주식처럼 거래) |
| **장점** | 분산투자, 낮은 수수료, 실시간 거래 |
| **예시** | KODEX 200, TIGER 미국S&P500 |
| **성장** | 2000년대 이후 폭발적 성장 |

```
    ETF 시장 규모 성장 (글로벌)
    ─────────────────────────────────────
    2000년:     약 80조 원
    2010년:    약 1,000조 원
    2020년:    약 8,000조 원
    2024년:   약 12,000조 원
    ─────────────────────────────────────
```

### 3.2.3 패시브 vs 액티브 투자

```
┌─────────────────────────────────────────────────────────────┐
│                패시브 투자 vs 액티브 투자                    │
├────────────────────────┬────────────────────────────────────┤
│      패시브 투자        │         액티브 투자               │
├────────────────────────┼────────────────────────────────────┤
│ 지수를 그대로 따라감     │ 펀드매니저가 종목 선택            │
│ 낮은 수수료 (0.1% 미만)  │ 높은 수수료 (1~2%)               │
│ 시장 평균 수익률        │ 시장 초과 수익 추구               │
│ ETF, 인덱스펀드         │ 주식형 펀드                       │
│ 장기 투자에 유리        │ 단기 성과 추구 가능               │
├────────────────────────┴────────────────────────────────────┤
│  ※ 연구 결과: 장기적으로 패시브 투자가                      │
│               액티브 투자를 이기는 경우가 많음               │
└─────────────────────────────────────────────────────────────┘
```

## 3.3 투자 주체의 변화

### 3.3.1 개인 투자자의 부상

```
┌─────────────────────────────────────────────────────────────┐
│                  투자 주체별 비중 변화                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   [과거 ~2000년대]                                          │
│   ┌────────────────────────────────────────────┐           │
│   │████████████████████░░░░░░░░░░░░░░░░░░░░░░░│           │
│   │   기관/외국인 (70%)      │  개인 (30%)    │           │
│   └────────────────────────────────────────────┘           │
│                                                             │
│   [2020년 이후 - 동학개미 운동]                             │
│   ┌────────────────────────────────────────────┐           │
│   │████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│           │
│   │  기관/외국인  │       개인 (50% 이상)      │           │
│   └────────────────────────────────────────────┘           │
│                                                             │
│   → 개인 투자자의 영향력 대폭 증가                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3.2 해외 투자의 보편화

| 시기 | 변화 |
|------|------|
| 과거 | 국내 주식만 투자 가능 |
| 2000년대 | 일부 증권사 해외주식 서비스 |
| 2010년대 | 대부분 증권사 해외주식 지원 |
| 2020년대 | 해외주식 투자 일상화, 서학개미 등장 |

```
    한국인의 해외주식 투자 현황
    ─────────────────────────────────────
    2015년:      약 3조 원
    2020년:     약 50조 원
    2023년:    약 100조 원
    ─────────────────────────────────────
    → 10년간 30배 이상 성장
```

## 3.4 기술과 투자의 융합

### 3.4.1 알고리즘 트레이딩

```
┌─────────────────────────────────────────────────────────────┐
│                   알고리즘 트레이딩이란?                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   컴퓨터 프로그램이 자동으로 주식을 사고파는 것              │
│                                                             │
│   종류:                                                     │
│   ─────────────────────────────────────                     │
│   1. 고빈도 매매 (HFT)                                      │
│      - 초당 수천 번 거래                                    │
│      - 아주 작은 가격 차이로 수익                           │
│                                                             │
│   2. 퀀트 투자                                              │
│      - 수학/통계 모델 기반                                  │
│      - 데이터 분석으로 종목 선정                            │
│                                                             │
│   3. 로보어드바이저                                         │
│      - AI가 포트폴리오 추천                                 │
│      - 개인 맞춤형 자산 배분                                │
│                                                             │
│   현재 미국 주식 거래의 70% 이상이 알고리즘 거래             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.4.2 AI와 빅데이터의 활용

| 활용 분야 | 내용 |
|----------|------|
| **뉴스 분석** | AI가 뉴스 감성 분석하여 매매 신호 |
| **패턴 인식** | 차트 패턴 자동 인식 |
| **대안 데이터** | 위성사진, 신용카드 데이터 등 분석 |
| **자연어 처리** | 실적 발표, 컨퍼런스콜 자동 분석 |

### 3.4.3 소셜 미디어와 투자

```
┌─────────────────────────────────────────────────────────────┐
│                  SNS가 바꾼 투자 문화                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   긍정적 측면:                                              │
│   ─────────────                                             │
│   • 정보 접근성 향상                                        │
│   • 투자자 커뮤니티 형성                                    │
│   • 기업 정보 실시간 공유                                   │
│                                                             │
│   부정적 측면:                                              │
│   ─────────────                                             │
│   • 허위 정보 확산                                          │
│   • 밈주식(Meme Stock) 광풍                                 │
│   • 개인 투자자 손실 위험                                   │
│                                                             │
│   대표 사례:                                                │
│   • 게임스탑(GME) 사태 (2021)                              │
│   • 레딧 월스트리트베츠 커뮤니티                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│                   주요 규제 변화 연대기                      │

│      └── 도드-프랭크법 (미국)                              │

### 3.5.2 결제 주기의 변화

| 국가 | 과거 | 현재 |
|------|------|------|
| 한국 | T+2 | T+2 (2024년 T+1 추진) |
| 미국 | T+5 → T+3 → T+2 | T+1 (2024년 5월~) |
| 중국 | T+1 | T+1 |

```
    T+1 결제란?
    ─────────────────────────────────────
    T = Trade Date (거래일)
    +1 = 1영업일 후

    예시:
    월요일 주식 매도 → 화요일 현금 수령
    ─────────────────────────────────────
```

## 3.6 새로운 투자 트렌드

### 3.6.1 ESG 투자

```
┌─────────────────────────────────────────────────────────────┐
│                     ESG 투자란?                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   E (Environment)  : 환경                                   │
│   S (Social)       : 사회                                   │
│   G (Governance)   : 지배구조                               │
│                                                             │
│   → 재무적 성과 + 비재무적 가치를 함께 평가                 │
│                                                             │
│   ESG 투자 증가 이유:                                       │
│   ─────────────────────                                     │
│   • 기후변화 리스크 인식                                    │
│   • 사회적 책임 요구 증가                                   │
│   • 장기 수익률과의 연관성 연구                             │
│   • 기관투자자 ESG 의무화                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.6.2 테마 투자의 부상

| 테마 | 관련 산업 |
|------|----------|
| AI/반도체 | 엔비디아, 삼성전자, SK하이닉스 |
| 전기차/배터리 | 테슬라, LG에너지솔루션 |
| 신재생에너지 | 태양광, 풍력, 수소 |
| 바이오/헬스케어 | 제약, 의료기기 |
| 메타버스/XR | 메타, 애플 |

### 3.6.3 소수점 주식과 접근성

```
┌─────────────────────────────────────────────────────────────┐
│                   소수점 주식 거래                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   기존: 1주 단위로만 거래                                   │
│   예: 애플 1주 = 약 25만 원                                 │
│       → 자금 적으면 투자 불가                               │
│                                                             │
│   소수점 주식: 0.001주 단위 거래                            │
│   예: 애플 0.1주 = 약 2.5만 원                             │
│       → 소액으로도 우량주 투자 가능                         │
│                                                             │
│   장점:                                                     │
│   • 투자 진입 장벽 낮춤                                     │
│   • 포트폴리오 분산 용이                                    │
│   • 적립식 투자 가능                                        │
│                                                             │
│   한국: 2022년부터 해외주식 소수점 거래 도입                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 핵심 정리

```
┌─────────────────────────────────────────────────────────────┐
│                     주식 변화의 핵심                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 거래 방식: 대면 → 전화 → 전자 → 초고속 알고리즘        │
│                                                             │
│  2. 투자 상품: 개별 주식 → ETF, 파생상품 등 다양화          │
│                                                             │
│  3. 투자 주체: 기관 중심 → 개인 투자자 영향력 확대          │
│                                                             │
│  4. 기술 융합: AI, 빅데이터, 로보어드바이저 활용            │
│                                                             │
│  5. 새로운 트렌드: ESG, 테마 투자, 소수점 주식              │
│                                                             │
│  핵심 메시지:                                               │
│  "기술이 발전해도 투자의 본질은 변하지 않는다"              │
│  → 기업 가치 분석, 분산 투자, 장기 관점이 중요              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
