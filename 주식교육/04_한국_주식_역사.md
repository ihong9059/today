# 4. 한국 주식의 역사 및 과정

## 학습 목표
- 한국 증권시장의 탄생과 발전 과정을 이해한다
- 주요 역사적 사건과 위기를 알아본다
- 한국 주식시장의 특성을 파악한다

---

## 4.1 한국 증권시장의 태동

### 4.1.1 해방 이전 (일제강점기)

```
┌─────────────────────────────────────────────────────────────┐
│                한국 증권시장의 시작 (1911년)                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1911년: 조선취인소 설립                                   │
│           └── 일본인이 설립한 거래소                        │
│           └── 주로 미곡, 광물 거래                          │
│                                                             │
│   1920년: 경성주식현물취인시장 개설                         │
│           └── 최초의 주식 전문 거래 시장                    │
│                                                             │
│   1931년: 조선취인소로 통합                                 │
│           └── 주식, 채권, 상품 통합 거래                    │
│                                                             │
│   ※ 당시 상장 기업: 대부분 일본 기업                       │
│   ※ 한국인 투자자 참여 극히 제한적                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.1.2 해방 이후 ~ 1950년대

| 연도 | 주요 사건 |
|------|----------|
| 1945년 | 광복으로 조선취인소 폐쇄 |
| 1948년 | 대한민국 정부 수립 |
| 1950년 | 6.25 전쟁 발발 |
| 1953년 | 휴전, 전후 복구 시작 |
| 1956년 | **대한증권거래소 설립 (3월 3일)** |
