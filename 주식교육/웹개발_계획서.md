# 주식 초보자를 위한 주식 추천 웹 개발 계획서

> **작성일**: 2026년 2월 27일
> **프로젝트명**: 주식 입문자 종합 가이드 & 추천 시스템
> **목표**: 주식 초보자에게 교육 + AI 기반 종목 추천을 제공하는 웹 서비스

---

## 1. 프로젝트 개요

### 1.1 목적

```
┌─────────────────────────────────────────────────────────────┐
│                      프로젝트 목적                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. 교육: 주식 기초부터 실전까지 단계별 학습              │
│   2. 분석: AI 기반 종목 분석 및 추천                       │
│   3. 실전: 모의투자로 리스크 없이 연습                     │
│   4. 관리: 포트폴리오 구성 및 모니터링                     │
│                                                             │
│   핵심 가치: "알고 투자하자, 안전하게 성장하자"            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 타겟 사용자

| 구분 | 특징 | 니즈 |
|------|------|------|
| **완전 초보** | 주식 경험 없음 | 기초 교육, 용어 설명 |
| **입문자** | 계좌 있으나 경험 적음 | 종목 선정 가이드 |
| **초급자** | 1년 미만 투자 경험 | 분석 방법, 리스크 관리 |

### 1.3 경쟁 우위

```
┌─────────────────────────────────────────────────────────────┐
│                    기존 서비스 vs 우리 서비스               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   기존 서비스 문제점:                                       │
│   ────────────────────                                      │
│   • 정보 과잉: 초보자에게 너무 많은 정보                   │
│   • 교육 부재: 추천만 하고 이유 설명 없음                  │
│   • 리딩방 사기: 수익 보장 미끼로 금전 요구                │
│   • 전문 용어: 초보자가 이해하기 어려움                    │
│                                                             │
│   우리 서비스 차별점:                                       │
│   ────────────────────                                      │
│   ✓ 단계별 교육 + 추천 통합                               │
│   ✓ AI가 "왜" 이 종목인지 상세 설명                       │
│   ✓ 모의투자로 리스크 없이 연습                           │
│   ✓ 초보자 눈높이 맞춤 설명                               │
│   ✓ 완전 무료 (광고 기반 수익)                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 기술 스택 상세

| 영역 | 기술 | 선정 이유 |
|------|------|----------|
| **Frontend** | Next.js 14 | SSR/SSG, SEO 최적화 |
| **UI** | Tailwind CSS + shadcn/ui | 빠른 개발, 일관된 디자인 |
| **차트** | TradingView Widget / Recharts | 전문적인 주식 차트 |
| **상태관리** | Zustand / React Query | 간결하고 효율적 |
| **Backend** | Node.js (Express) | 빠른 개발, 실시간 처리 |
| **AI Engine** | Python (FastAPI) | AI 모델 연동 용이 |
| **Database** | PostgreSQL + TimescaleDB | 시계열 데이터 최적화 |
| **Cache** | Redis | 실시간 시세 캐싱 |
| **AI** | Claude API (Anthropic) | 고품질 분석 및 추천 |
| **인프라** | AWS / Vercel | 확장성, 안정성 |

### 3.3 외부 API

| API | 용도 | 제공처 |
|-----|------|--------|
| **KRX API** | 실시간 시세, 거래 데이터 | 한국거래소 |
| **DART API** | 기업 공시, 재무제표 | 금융감독원 |
| **뉴스 API** | 뉴스 크롤링, 감성 분석 | 네이버/다음 |
| **Claude API** | AI 분석, 추천 설명 | Anthropic |

### 6.2 사용자 매칭 알고리즘

```python
def calculate_match_score(user_profile, stock_analysis):
    """
    사용자 프로필과 종목 분석 결과를 매칭하여 점수 산출
    """
    match_score = 0

    # 1. 위험 성향 매칭 (30점)
    if user_profile.risk_profile == 'stable':
        # 안정형: 저변동성, 고배당, 대형주 선호
        if stock_analysis.volatility < 20:
            match_score += 15
        if stock_analysis.dividend_yield > 2:
            match_score += 10
        if stock_analysis.market_cap > 10_000_000_000_000:  # 10조 이상
            match_score += 5

    elif user_profile.risk_profile == 'aggressive':
        # 공격형: 고성장, 테마주, 모멘텀 선호
        if stock_analysis.growth_rate > 20:
            match_score += 15
        if stock_analysis.momentum_score > 70:
            match_score += 10
        if stock_analysis.is_theme_stock:
            match_score += 5

    # 2. 투자 기간 매칭 (30점)
    if user_profile.investment_period == 'long':
        # 장기: 우량주, 배당주
        if stock_analysis.quality_score > 80:
            match_score += 20
        if stock_analysis.dividend_consistency:
            match_score += 10

    elif user_profile.investment_period == 'short':
        # 단기: 모멘텀, 이슈
        if stock_analysis.short_term_signal == 'buy':
            match_score += 20
        if stock_analysis.has_catalyst:
            match_score += 10

    # 3. 관심 업종 매칭 (20점)
    if stock_analysis.sector in user_profile.interested_sectors:
        match_score += 20

    # 4. 투자 금액 적합성 (20점)
    min_invest = stock_analysis.current_price * 10  # 최소 10주
    if user_profile.investment_amount >= min_invest:
        match_score += 20
    elif user_profile.investment_amount >= min_invest * 0.5:
        match_score += 10

    return min(match_score, 100)  # 최대 100점
```
