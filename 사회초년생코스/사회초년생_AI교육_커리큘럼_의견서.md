# 사회초년생 AI 교육 커리큘럼 의견서

## 1. 현황 분석

### 기존 구성 (5개 코스, 각 5강 = 총 25강)
1. **AI 시대 직장생활** - AI 시대 변화와 마인드셋
2. **AI 도구 업무 활용** - ChatGPT, Gemini 실무 활용
3. **프롬프트 마스터** - 프롬프트 엔지니어링
4. **AI 시대 커리어 개발** - 커리어 전략 수립
5. **AI 활용 포트폴리오** - 포트폴리오 제작

### 강점
- 실무 중심의 AI 활용법 제공
- 단계별 구성 (이해 → 활용 → 전략 → 실행)
- 상세한 프롬프트 템플릿 제공

### 개선 필요 사항
1. 레슨별 제목이 코스 목록에 표시되지 않음
2. 유튜브 참고 영상 연동 없음
3. 학습 완료 추적 기능 미비
4. 카드 UI 색상 단조로움

## 3. UI/UX 개선 사항

### 코스 상세 페이지 개선

## 4. 학부형 트랙과의 연계
