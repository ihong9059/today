- **URL**: https://www.wishket.com/project/155057/
- **금액**: 2,400만원
- **기간**: 90일
- **마감**: 2026-05-15
- **근무형태**: 외주 (현장 테스트는 경기도 용인시 기흥구)

**필요 기술**:
- C++ (주요 언어)
- 임베디드 MCU 펌웨어 개발
- 통신 프로토콜 (UART, RS-485)
- AISG 프로토콜

**프로젝트 내용**:
AISG 2.0 프로토콜 기반 컨트롤 보드(MCU)를 AISG 3.0으로 업그레이드. 기존 C++ 소스 분석, 패킷 프레임 생성/파싱, CRC 에러 검출, 디바이스 스캔/인식 로직 구현.

**매칭 분석**:

| 항목 | 요구 | 보유 | 매칭 |
|------|------|------|:----:|
| C++ 임베디드 | 필수 | 임호균 38년 ARM/MCU | ✅ |
| UART/RS-485 | 필수 | 홍광선 CAN/RS485 다수 | ✅ |
| 통신 프로토콜 포팅 | 필수 | EtherCAT/LoRaWAN 경험 | ✅ |
| MCU 펌웨어 | 필수 | STM32/ESP32 양산 경험 | ✅ |
| AISG 프로토콜 | 우대 | 미경험 (학습 필요) | ⚠️ |
| 현장 테스트 | 용인 기흥 | 사무실 근접 | ✅ |

**결론**: **강력 추천**. C++/MCU/RS-485 통신 프로토콜은 핵심 역량. AISG 스펙은 공개 문서 학습으로 커버 가능. 용인 기흥 현장이라 출장 부담 적음. 2,400만원/90일 적정 단가.
