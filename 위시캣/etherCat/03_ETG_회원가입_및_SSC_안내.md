# ETG 회원가입 및 SSC 확보 안내

**작성일**: 2026-02-09
**문서 버전**: 1.0

---

## 1. 개요

EtherCAT 슬레이브 장치를 개발하려면 **ETG (EtherCAT Technology Group) 회원 가입**이 필수입니다. 이 문서는 그 이유와 절차를 설명합니다.

---

## 2. EtherCAT은 "오픈" 프로토콜이지만 완전 무료는 아님

EtherCAT은 Beckhoff가 개발했고, **EtherCAT Technology Group (ETG)**에서 관리합니다.

| 항목 | 공개 여부 | 비고 |
|------|----------|------|
| 프로토콜 사양 | 공개 (무료 열람) | 웹에서 다운로드 가능 |
| **Slave Stack Code (SSC)** | **ETG 회원 전용** | 핵심 소스 코드 |
| ESI 스키마 | 공개 | XML 스키마 파일 |
| SSC Tool | ETG 회원 전용 | ESI 생성 도구 |
| CTT (Conformance Test Tool) | ETG 회원 전용 | 인증 테스트 도구 |

---

## 3. SSC (Slave Stack Code)란?

### 3.1 정의

**SSC는 EtherCAT 슬레이브 펌웨어의 핵심 소스코드**입니다.

Beckhoff에서 개발하여 ETG 회원에게 제공하며, EtherCAT 슬레이브 개발의 표준 레퍼런스입니다.

### 3.2 소프트웨어 구조에서 SSC의 위치

```
┌─────────────────────────────────────────┐
│         Your Application                │  ← 직접 개발
│   (CAN FD Gateway, DIO, DAQ 등)         │
├─────────────────────────────────────────┤
│      Beckhoff SSC (Slave Stack)         │  ← ETG에서 제공 (회원 전용)
│  ┌───────────────────────────────────┐  │
│  │ - EtherCAT State Machine          │  │
│  │   (INIT → PRE-OP → SAFE-OP → OP)  │  │
│  │ - PDO (Process Data Object) 처리   │  │
│  │ - SDO (Service Data Object) 처리   │  │
│  │ - CoE (CANopen over EtherCAT)     │  │
│  │ - FoE (File over EtherCAT)        │  │
│  │ - EoE (Ethernet over EtherCAT)    │  │
│  │ - DC 동기화 (Distributed Clocks)   │  │
│  └───────────────────────────────────┘  │
├─────────────────────────────────────────┤
│      Hardware Abstraction Layer         │  ← 직접 개발 (칩셋별)
│   (LAN9252 또는 ET1100 인터페이스)       │
├─────────────────────────────────────────┤
│      MCU HAL (SPI, Timer, GPIO 등)      │  ← MCU 벤더 제공
└─────────────────────────────────────────┘
```

### 3.3 SSC가 제공하는 기능

| 기능 | 설명 |
|------|------|
| State Machine | INIT → PRE-OP → SAFE-OP → OP 상태 전이 관리 |
| PDO 처리 | 실시간 프로세스 데이터 교환 |
| SDO 처리 | 파라미터 설정/읽기 (비실시간) |
| CoE | CANopen 오브젝트 딕셔너리 지원 |
| FoE | 파일 전송 (펌웨어 업데이트 등) |
| EoE | TCP/IP 터널링 |
| DC | 분산 클럭 동기화 |
| Mailbox | 비동기 통신 처리 |

## 4. SSC 없이 개발하면?

### 4.1 대안 비교

| 방법 | 난이도 | 개발 기간 | 문제점 |
|------|--------|----------|--------|
| **SSC 사용** | 중간 | 3~6개월 | ETG 회원 필요 |
| 직접 구현 | **매우 어려움** | 1~2년+ | 사양서 분석, 테스트 어려움 |
| 오픈소스 대안 | 어려움 | 6개월+ | 완성도 낮음, 인증 어려움 |

### 4.2 직접 구현 시 필요한 작업

SSC 없이 직접 구현하려면:

1. **사양서 분석** (수천 페이지)
   - ETG.1000: EtherCAT Specification
   - ETG.1020: Protocol Enhancements
   - ETG.2000: ESI Specification
   - 기타 다수...

2. **State Machine 직접 구현**
   - 12개 이상의 상태 전이 처리
   - 에러 핸들링
   - 타이밍 요구사항 충족

3. **PDO/SDO 매핑 직접 구현**
   - Sync Manager 설정
   - FMMU (Fieldbus Memory Management Unit) 관리
   - 오브젝트 딕셔너리 구현

4. **DC 동기화 알고리즘 직접 구현**
   - Sync0/Sync1 신호 처리
   - 지터 최소화
   - 드리프트 보상

5. **테스트 및 디버깅**
   - 레퍼런스 코드 없음
   - CTT 없이 호환성 검증 어려움

→ **현실적으로 불가능에 가까움**

### 4.3 오픈소스 대안

| 프로젝트 | 상태 | 문제점 |
|----------|------|--------|
| SOES (Simple Open EtherCAT Slave) | 제한적 | 기본 기능만, DC 미지원 |
| 기타 GitHub 프로젝트 | 불완전 | 유지보수 없음, 문서 부족 |

**결론**: 상용 제품 개발에는 **SSC 사용이 사실상 필수**

## 5. ETG 회원 가입 정보

### 5.1 회원 유형

| 회원 유형 | 연회비 (예상) | 혜택 |
|----------|--------------|------|
| **Implementer** | €500~1,000/년 | SSC, CTT, 기술 지원, 로고 사용 |
| Full Member | 더 높음 | 사양 개발 참여, 투표권 |
| Supporting Member | 무료 | 뉴스레터, 이벤트 참가 |

**일반적인 개발사는 Implementer 회원으로 가입**

### 5.2 가입 절차

1. **ETG 웹사이트 방문**
   - URL: https://www.ethercat.org

2. **회원 가입 신청**
   - 회사 정보 입력
   - 회원 유형 선택
   - 이용 약관 동의

3. **회비 납부**
   - 청구서 수령 후 납부

4. **자료 다운로드**
   - SSC 소스 코드
   - SSC Tool
   - CTT
   - 기술 문서

### 5.3 ETG 회원 혜택 상세

| 혜택 | 설명 |
|------|------|
| SSC 소스 코드 | C 소스 코드 전체 제공 |
| SSC Tool | ESI 파일 생성 도구 |
| CTT | 인증 테스트 도구 |
| 기술 문서 | 상세 구현 가이드 |
| 기술 지원 | ETG 엔지니어 지원 |
| 로고 사용권 | 제품에 EtherCAT 로고 사용 |
| 교육 | 온라인/오프라인 교육 프로그램 |

## 7. 프로젝트 152447 관련 고려사항

### 7.1 클라이언트와 협의 필요 사항

| 항목 | 내용 |
|------|------|
| ETG 회원 가입 주체 | 클라이언트 or 개발사 |
| 회비 부담 | 별도 협의 필요 |
| Vendor ID 발급 | 클라이언트 명의로 발급 권장 |
| 로고 사용권 | 클라이언트 귀속 |

### 7.2 권장 사항

1. **클라이언트가 ETG 회원 가입**
   - 제품에 클라이언트 Vendor ID 사용
   - 향후 유지보수/업그레이드 용이
   - 로고 사용권 확보

2. **개발사가 대행 가입 시**
   - 비용 정산 방법 협의
   - Vendor ID 이전 절차 확인

### 7.3 예상 비용

| 항목 | 비용 (예상) |
|------|------------|
| ETG Implementer 회원 (연간) | €500~1,000 (약 70~140만원) |
| Vendor ID 발급 | 회원비에 포함 |

## 9. 결론

| 질문 | 답변 |
|------|------|
| ETG 회원 가입이 필수인가? | **예**, SSC 없이는 개발 불가능 |
| 비용이 발생하는가? | **예**, 연간 회비 약 70~140만원 |
| SSC 없이 대안이 있는가? | 사실상 **없음** (오픈소스는 불완전) |
| 누가 가입해야 하는가? | **클라이언트 권장** (Vendor ID 귀속) |

---

**ETG 회원가입 없이는 EtherCAT 슬레이브 개발이 사실상 불가능합니다.**

프로젝트 152447 지원 시, 클라이언트에게 이 사항을 사전에 설명하고 ETG 회원 가입 비용 및 주체에 대해 협의해야 합니다.
