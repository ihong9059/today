# 회사·본인 소개 요점 — 1분 / 5분 / 15분 버전

> 미팅 초반 자기 소개 — 짧으면 강력, 길면 풍부. 시간에 맞춰 선택.

## 🕐 1분 버전 (전화·짧은 인사용)

> "안녕하세요. 유티텍(UTTEC) 대표 홍광선입니다. 임베디드 38년 경력으로 STM32·nRF52 양산 5종 + 통신 프로토콜 4종(BLE Mesh / LoRa / EtherCAT / Modbus RTU)을 실제 제품에 구현했습니다. 일본 자전거주차장 BLE Mesh 3,800대 양산 수출이 대표 실적입니다. AISG 3.0 포팅은 저희가 보유한 패턴과 1:1 매칭됩니다. 특히 **OOK PHY는 최근 CC1101로 직접 구현해서** 두 PHY 옵션 모두 즉시 대응 가능합니다."

## 🕔 5분 버전 (미팅 초반 권장)

### 회사
> "**㈜유티텍 (UTTEC)** 1인 기업 + 협업자 1인. **저(홍광선)는 펌웨어 38년**, **임호균은 회로설계 25년 + ARM CPU 설계 경험**. 1995년 설립, 용인 기흥구 사무실 운영."

### 핵심 실적 (3가지)
1. **일본 자전거주차장 BLE Mesh 양산** (2022 500대 + 2023 3,300대 수출). KC·TELEC·CE 3개국 인증.
2. **국내 최초 LoRa + 클라우드 서버 상용화** (2018). 벤처기업 인증.
3. **현재 양산 중인 통신 제품 5종** — Modbus RTU 컴프레서 밸브 컨트롤러 / EtherCAT MFC / BLE 온도 컨트롤러 등.

### 통신 프로토콜 경험
> "**4종 양산 + 2종 직접 구현 + 1종 분석 완료** — 총 7종 경험.
> - 양산: RS-485 Modbus RTU / BLE Mesh / LoRa / EtherCAT / CAN
> - 직접 구현: OOK Sub-GHz (CC1101 447.925 MHz, REVITA 2026-05)
> - 분석 완료: AISG 3.0 (위시캣 #155057 사전 학습)"

### 본 프로젝트 적합성
> "AISG 3.0 스펙을 분석한 결과, **모든 구성 요소가 저희 양산 자산과 1:1 대응**입니다. PHY (RS-485 / OOK), HDLC 프레임, CRC-CCITT 16, 그리고 3.0 변경점 4개(Device Discovery / Multi-Primary / Connection Mapping / Ping)까지 모두 BLE Mesh 3,800대 시스템에서 구현한 패턴입니다.
>
> 특히 **OOK PHY는 다른 외주가 보통 학습부터 시작해야 하는 영역인데**, 저희는 5월에 CC1101로 직접 구현 완료 상태입니다. **현장이 용인 기흥구라 저희 사무실 동일 지역**이라 추가 출장비도 없습니다."

## 🕕 15분 버전 (자세한 자기소개 요청 시)

### Part 1 — 개인 / 회사 정체성 (3분)

**저는 홍광선입니다 — 임베디드 엔지니어 38년**.
- 삼성전자: Audio/Video Controller, STB
- 파나소닉: LCD/I/O Printer Controller
- 그 외 다수 대기업·중견기업 양산 프로젝트
- 2010년부터 ㈜유티텍 대표로 1인 기업 운영

**㈜유티텍 (UTTEC)**:
- 설립: 2010년
- 사무실: 경기도 용인시 기흥구 (1995년 설립 이후 동일 지역)
- 인원: 1인 (대표) + 협업자 1인 (임호균, 회로설계)
- 주력: 임베디드 통신 제품 양산 + 1인 소규모 사업화 (강의·컨설팅·정부지원)
- 특허: 국내 1건 (디밍제어), 일본 1건 (LED 제어), AI FanStick 출원 중

**임호균 협업자**:
- ARM CPU 설계 (AuthenTec, 미국) + 대한전선 WINDER (CAN/RS485)
- 회로설계 25년
- 본 프로젝트의 **HW 디버깅 (예: OOK PHY 신호 측정)** 즉시 대응 가능

### Part 2 — 통신 프로토콜 7종 실적 (5분)

**1. RS-485 / Modbus RTU** (양산 중)
- STM32F756 컴프레서 밸브 컨트롤러
- 반이중 9600 bps, CRC-16, 다중 슬레이브 구성
- KC 인증 완료
- → AISG의 RS-485 PHY와 동일

**2. BLE Mesh** (일본 양산 수출 3,800대)
- nRF52832 + 외부 안테나 (200m+)
- 커스텀 프로토콜 (패킷 구조·헤더·페이로드 직접 설계)
- **3,800대 규모 디바이스 스캔/인식**
- 게이트웨이 ↔ 노드 양방향 통신, 암호화
- KC/TELEC/CE 인증
- → AISG의 Device Discovery / Multi-Primary 와 구조적으로 대응

**3. LoRa** (국내 최초 상용화 2018)
- LoRa + MQTT + 클라우드 서버 3-tier
- 저전력 모드 + 스케줄링
- 최근 REVITA 프로젝트에서 RAK4630 + Zephyr RTOS 재구현

**4. EtherCAT** (양산 중)
- Raspberry Pi CM4 기반 산업용 MFC 컨트롤러
- 실시간 산업 통신 / 프레임 생성 / 상태 머신

**5. CAN** (대한전선 WINDER)
- 임호균이 주도, 차량/산업 통신
- 모터 제어 + 통신 통합

**6. OOK Sub-GHz RF** (직접 구현 2026-05) ⭐ **AISG 핵심**
- CC1101 트랜시버 + nRF52840 + Zephyr RTOS
- 447.925 MHz OOK Replay 시스템
- **외부 기기 신호 캡처 → 10버튼 디코딩 → 재현**
- Zephyr 공식 드라이버 없어 SPI 드라이버부터 자체 작성
- → AISG의 OOK PHY (2.176 MHz Bias-T) **동일 변조 원리**, 캐리어 주파수만 다름

**7. AISG 3.0** (분석 완료 2026-05-07)
- 위시캣 #155057 공고 사전 학습
- 3계층 구조 (RS-485/OOK PHY + HDLC DLL + Application) 파악
- HDLC 프레임 / CRC-CCITT 16 / Bit Stuffing 검토
- AISG 2.0 → 3.0 변경점 4개 (Device Discovery / Multi-Primary / Connection Mapping / Ping) 분석
- → **착수 즉시 소스 분석 진입 가능**

### Part 3 — 최근 자산 (강조하고 싶은 것, 3분)

**REVITA 프로젝트 (2025~현재)** — 농업 IoT
- LoRa SF12 922.1 MHz + RAK4631 + nRF52840
- INA219 전류·전압 측정 + Flask Web UI + Chart.js + systemd 운용
- **현장 배포 자산 풀스택** 검증 완료
- → AISG 현장 테스트 패턴 동일

**한림용인CC 골프수조 무선제어** (시공 직전, 2026-05)
- 1,000만원 수주 직전, **용인 기흥구 골프장** (AISG 현장과 같은 지역)
- LoRa E22 + RPi 게이트웨이 + 펌프 제어
- 한림그룹과 2020년 거래 (한림광릉CC 조명) 이후 재거래

**AI FanStick** (특허 출원 중)
- 음성 + AI + BLE 통합 응원봉
- 임베디드 + AI 결합 신사업

## 💡 자기소개 시 주의사항

| Do | Don't |
|---|---|
| ✅ 숫자로 말하기 (38년 / 3,800대 / 7종 / 5종 양산) | ❌ "다양한 경험이 있습니다" 같은 모호한 표현 |
| ✅ 현장 동일 지역 강조 | ❌ AISG 직접 경험 부풀리기 |
| ✅ OOK 직접 구현 시연 가능 명시 | ❌ "어떻게든 할 수 있어요" 자신감만 |
| ✅ 1인 기업의 장점 (의사결정 / 직접 소통) | ❌ "회사가 작아서…" 사과 톤 |
| ✅ 임호균 협업자 명시 (2인 팀 강조) | ❌ "혼자입니다" — 회로 측 대응 불가로 보일 위험 |
