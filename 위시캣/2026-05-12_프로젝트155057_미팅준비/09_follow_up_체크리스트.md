# 미팅 후 Follow-up 체크리스트

> 미팅 자체보다 follow-up이 더 중요할 때가 많음. 24시간 / 1주 / 2주 단계별 액션.

## ⏰ 미팅 종료 직후 (당일 1~2시간 이내)

### A1. 미팅 메모 정리

미팅 중 받은 메모를 즉시 정리:

```markdown
# 미팅 메모 — YYYY-MM-DD

## 참석자
- 클라이언트 측: {이름·역할}
- UTTEC 측: 홍광선 (+ 임호균 동행 여부)

## 주요 논의 사항
1. 프로젝트 배경:
2. 기존 코드 규모·환경:
3. AISG 3.0 변경점 요구:
4. 현장 환경:
5. 단가·일정:

## 클라이언트의 우려사항 / 강조사항
1.
2.

## 합의 사항
1.
2.

## 보류·미정 사항
1.
2.

## 다음 단계 합의
- UTTEC: {언제까지 무엇}
- 클라이언트: {언제까지 무엇}
```

→ 파일: `2026-05-12_프로젝트155057_미팅준비/MEETING_MEMO_YYYY-MM-DD.md` (실제 미팅 후 생성)

### A3. 미팅 인상 자가 평가

```
- 매칭률 어필 잘 됐나? (1~10)
- OOK 직접 구현 시연 효과? (1~10)
- 클라이언트의 우려 사항 모두 해소됐나?
- 단가·일정 협의 분위기?
- 다음 단계 명확화됐나?

→ 약점 발견 시 follow-up 메일에서 보강
```

## 📧 미팅 후 24시간 이내 — Follow-up 메일

### 메일 작성 시점
미팅 종료 후 **24시간 이내** 발송 (당일 또는 다음 날 오전).

### 메일 표준 형식

```
제목: [위시캣 #155057] AISG 3.0 포팅 — 어제 미팅 감사드립니다 + 추가 자료

수신자: 클라이언트 미팅 참석자
참조: (있다면 양측 추가 인원)

본문:

안녕하세요. 어제 미팅에서 뵌 ㈜유티텍 홍광선입니다.

귀중한 시간 내주셔서 감사합니다. 미팅 중 논의된 내용을 정리하여 다음
사항을 회신드립니다.

[1] 미팅 합의 사항 요약
- ...
- ...

[2] 추가 답변 / 보강 자료
(미팅 중 즉답 어려웠던 사항 또는 추가 자료 필요했던 부분)
- ...

[3] 다음 단계
- {언제까지 UTTEC가 무엇} (예: 5/15까지 작업 계획 상세화 송부)
- {언제까지 클라이언트 측 결정 예상}

추가 질문 / 자료 요청 있으시면 언제든 회신 부탁드립니다.

감사합니다.

홍광선
㈜유티텍 (UTTEC)
용인 기흥구
{전화번호}
{이메일}
{GitHub URL}
```

### 첨부 자료 (선택)

- [ ] 매칭률 매트릭스 (1장 요약)
- [ ] 회사소개서 (미팅에 가져갔으면 생략)
- [ ] AISG 사전 학습 노트

## 📅 1주 이내 — 추가 자료 / 협의

### B1. 미팅에서 요청받은 자료 전달

미팅 중 클라이언트가 "보내달라"고 한 자료가 있다면 1주 이내 발송:

- [ ] 상세 작업 계획 (Phase별 일정 + 산출물)
- [ ] 견적서 (필요 시 공식 양식으로)
- [ ] 포트폴리오 + 인증서 사본
- [ ] NDA 사전 검토 (클라이언트 측 양식 요청)

### B2. 사내 결정 대기 시 — 정기 follow-up

클라이언트가 사내 결정 대기 중이면 1주 후 정중한 follow-up:

```
제목: [위시캣 #155057] 진척 문의

안녕하세요. 지난주 미팅에 이어서 진행 상황 문의드립니다.

만약 추가 자료 / 검토 필요한 부분 있으시면 언제든 회신 부탁드립니다.

본 프로젝트 우선순위 최상으로 두고 있으며, 결정해주시는 대로
5월 중순 이내 즉시 착수 가능합니다.

감사합니다.
```

### B3. 경쟁 후보와 차별화 보강 (필요 시)

만약 미팅 중 다른 후보와 경쟁 상황 확인됐다면:

- [ ] UTTEC 차별화 요소 1장 요약 (PDF)
- [ ] 추가 시연 자료 (영상 형식)
- [ ] 추천서 / 기존 클라이언트 reference (가능 시)

## 📅 2주 이내 — 결정 단계

### C1. 결정 알림 받았을 때

**Case 1: 수주 확정**
- [ ] 즉시 감사 회신
- [ ] 계약서 검토 요청
- [ ] 착수 일정 합의
- [ ] NDA 서명
- [ ] D-Day 명확화

**Case 2: 추가 검토 요청**
- [ ] 정중히 추가 자료 / 답변 제공
- [ ] 1~2회 더 follow-up

**Case 3: 탈락 통보**
- [ ] **정중한 감사 회신 + 사유 문의**
- [ ] "다음 기회 있으면 다시 연락 부탁드립니다" 톤
- [ ] **myWiki에 박제** (왜 떨어졌는지 패턴 분석)

### C2. 결정 대기 2주 초과 시

```
제목: [위시캣 #155057] 일정 조정 문의

안녕하세요. 본 프로젝트 결정이 다소 지연되는 것 같아 문의드립니다.

만약 6월 초까지 결정 가능하시면 저희도 일정 조정 어렵습니다.
혹시 추가 시간이 필요하시면 솔직히 말씀해주시면 감사하겠습니다.

저희 측 5월 중순 ~ 6월 초 일정이 다른 프로젝트로 일부 변동 가능성이
있어, 양측 모두에게 좋은 결과를 위해 진행 상황 확인 부탁드립니다.

감사합니다.
```

→ **압박이 아닌 정중한 진척 확인**. 자기 시간도 존중되는 인상.

## 📊 follow-up KPI

| 시점 | KPI | 목표 |
|---|---|---|
| 미팅 후 1~2시간 | 메모 정리 완료 | ✅ |
| 미팅 후 24시간 | follow-up 메일 발송 | ✅ |
| 미팅 후 1주 | 요청 자료 전달 + 정기 confirm | ✅ |
| 미팅 후 2주 | 결정 알림 또는 follow-up | 결정 ≥ 70% |
| 미팅 후 1개월 | 명확한 결과 (수주/탈락/명확한 일정) | 100% |

## 💡 일반 follow-up 원칙

| 원칙 | 의미 |
|---|---|
| **속도** | 24시간 이내 첫 follow-up = 진심 신호 |
| **정확성** | 합의 사항 정확히 기록 + 회신 (분쟁 방지) |
| **존중** | 압박 X, 정중한 문의 |
| **가치 제공** | follow-up 메일에 가치 ↑ (추가 자료·답변) |
| **선택지 제공** | "이런 옵션 있습니다" 능동적 |
| **기록 박제** | 결과 (수주/탈락/보류) myWiki에 영구 |

## ⚠️ 절대 하지 말 것

- ❌ 즉답 강요 (이번 주 안에 결정해주세요)
- ❌ 너무 자주 follow-up (1주에 2번+)
- ❌ 가격 자동 하향 ("다른 후보보다 싸게 해드릴게요")
- ❌ 미팅 합의와 다른 내용 메일에 적기 (분쟁 시 불리)
- ❌ 클라이언트 안 답하는데 일방 자료 폭주
