# 단가·일정·결제 협상 준비

> 제시 예산 24,000,000원 / 90일을 어떻게 받아들이고, 어떻게 협상할지.

## 💰 단가 분석 (UTTEC 내부)

### 24,000,000원 / 90일의 의미

```
24,000,000원 / 90일 = 약 266,667원 / 일

만약 1인 단독 = 1인 일당 266,667원   → 약간 낮음 (보통 30~40만원)
만약 2인 팀  = 1인 일당 133,333원   → 매우 낮음

→ UTTEC 입장: 2인 팀 투입 시 단가는 빠듯.
   다만 매칭 자산 100% → 학습 비용 0 → 실효 일당 ↑
```

### 실효 단가 계산 (UTTEC 관점)

| 항목 | 일반 외주 | UTTEC | 차이 |
|---|---|---|---|
| 학습 시간 | 10~15일 | 0~2일 | -10일 |
| 현장 출장비 | 90만원/회 × 5회 = 450만원 | 0 (동일 지역) | -450만 |
| HW 디버깅 외주 | 별도 견적 | 임호균 협업 (포함) | -200만 |
| **실효 가치** | 24M에 1인 풀투입 가능 | **24M에 2인 팀 + 학습 0 + 출장 0** | **사실상 33M 가치** |

→ **UTTEC 입장에서 24M은 합리적** (자산 활용 시).
→ **클라이언트 입장에서 24M은 매우 좋은 선택** (1인 외주 + 학습 부담 vs UTTEC 2인 즉시 대응).

## 🎯 협상 시나리오

### 시나리오 A — 클라이언트가 24M 그대로 제안

**대응**:
> "제시하신 24M / 90일 기준 협의 가능합니다. 다만 **결제 조건 + 추가 기능 발생 시 별도 견적**은 합의해두면 좋겠습니다."

**받아들임**:
- 24M 그대로 OK
- 단 결제 조건은 분할 (30% 선금 / 40% 중간 / 30% 잔금)
- Scope 변경 시 별도 견적 명시

### 시나리오 B — 클라이언트가 단가 하향 요청 (예: 20M)

**대응 1 — 정중히 거절**:
> "**24M이 본 프로젝트 가치 기준 합리적**입니다. 1인 외주 비용에 가깝지만 저희는 2인 팀이고, **AISG 학습 시간 0**으로 같은 일정 안에 더 안정적 결과를 드릴 수 있습니다. 만약 단가 조정이 필수라면, 대신 **Scope 일부를 축소**하는 방안을 검토하시면 어떨까요?"

**대응 2 — Scope 조정 제안**:
- 4개 변경점 중 일부만 (예: Device Discovery + Multi-Primary만, Ping은 옵션)
- 현장 테스트 횟수 축소
- 인계 문서 간소화

**대응 3 — 단계별 진행**:
- Phase 1~3 (Week 8까지) = 1차 계약 (예: 16M)
- 결과 확인 후 Phase 4~6 (Week 13까지) = 2차 계약 (예: 8M)

### 시나리오 C — 클라이언트가 단가 상향 가능 (예: 28M+)

**대응**:
> "감사합니다. 추가 예산이 있으시면 다음 항목을 추가해드릴 수 있습니다."

**추가 가능 항목**:
- ✅ **AISG 인증 절차 지원** (별도 인증 신청 / 문서 작성)
- ✅ 6개월 유지보수 보증 → **12개월 보증**으로 연장
- ✅ 현장 테스트 빈도 ↑ (월 2회 → 주 1회)
- ✅ 추가 기능 (예: 클라우드 대시보드 / 원격 모니터링 Web UI)
- ✅ 사용자 매뉴얼 + 교육 1회 (담당자 onboarding)

### 시나리오 D — 일정 단축 요청 (90일 → 60일)

**대응**:
> "**60일은 빠듯**합니다. 저희가 AISG 매칭 자산 보유로 학습 시간이 거의 0이지만, **현장 테스트는 압축이 어렵습니다**. 다만 다음 조건이면 가능합니다."

**조건**:
- Phase 4 통합 테스트 단축 (2주 → 1주)
- Phase 5 현장 테스트 단축 (2주 → 1주, 1차+2차 현장 동시)
- Phase 6 인계 단축 (1주 → 4일)
- 단가는 동일 (압축 = 더 집중적 작업)

→ 가능하지만 **위험 ↑** (현장 이슈 발견 시 대응 시간 부족). 합의 시 위험 분담 명시.

### 시나리오 E — 일정 연장 요청 (90일 → 120일)

**대응**:
> "여유가 있으면 더 좋은 품질 가능합니다. **단가는 동일** (총 작업량은 같음), 다만 더 충분한 현장 테스트 + 문서화 가능."

## 💳 결제 조건

### 권장 조건 (UTTEC 제안)

| 단계 | 비율 | 금액 | 시점 |
|:-:|:-:|---|---|
| 선금 | 30% | 7.2M | 계약 체결 시 |
| 1차 중간 | 20% | 4.8M | Phase 3 종료 (Week 8) — AISG 3.0 4개 기능 단위 테스트 PASS |
| 2차 중간 | 20% | 4.8M | Phase 4 종료 (Week 10) — 통합 테스트 PASS |
| 잔금 | 30% | 7.2M | Week 13 인계 + 검수 통과 |
| **총** | **100%** | **24M** | |

### 클라이언트 입장 안심 요소
- 선금 30% — 일반적 (40~50% 요구 안 함)
- 중간 결제 2회 → 진척 단계별 정산
- 잔금 30% — 인계 후 검수 통과 시

### UTTEC 입장 cash flow
- 선금으로 초기 비용 (현장 답사 / 시뮬레이션 환경) 커버
- 중간 결제로 매월 안정적 수입
- 잔금이 큰 비중 아님 → 인계 후 단가 위험 낮음

## 📝 계약서 협의 항목

### 반드시 명시

1. **Scope 명확화** — 작업 계획 (03 문서) 그대로 첨부
2. **마일스톤 6개** — 클라이언트 미팅 시점 명시
3. **결제 조건** — 위 분할
4. **Scope 변경 시 별도 견적** — 추가 기능·Scope 확장은 별도
5. **NDA + 소스 코드 보안** — 외부 유출 0%
6. **보증 기간 3~6개월** — 인계 후 동일 환경에서의 버그는 무상 수정
7. **재산권 / IP** — 본 작업 결과물은 클라이언트 소유 (UTTEC는 기술 노하우 보유)

### 선택 명시

8. **현장 테스트 횟수 제한** — 5회 이내 (초과 시 별도 출장비)
9. **인증 절차 분리** — AISG 인증 신청은 별도 견적
10. **클라이언트 측 협조 의무** — 실 ALD 장비 제공 / 사무실 접근 등

## 🚦 협상 진행 흐름

```
[1단계] 클라이언트 측 첫 제안 듣기
   → 24M 그대로? 하향? 일정 변경?

[2단계] UTTEC 측 응답
   → 시나리오 A~E 중 해당 시나리오 적용

[3단계] 조건 합의
   → 결제 조건 + Scope + 마일스톤 합의

[4단계] 계약서 초안 (클라이언트 또는 UTTEC 작성)
   → 24~48시간 내 회신

[5단계] 검토 + 서명
   → 1주 이내 계약 체결 목표
```

## 💡 협상 시 주의사항

### Do
- ✅ **자산 가치 명시** — "매칭률 13/13" / "OOK 직접 구현" / "용인 동일 지역"
- ✅ **숫자로 말하기** — "출장비 절감 450만" / "학습 시간 0~2일" 같이 구체적
- ✅ **양보 가능 영역 분명히** — Scope 축소 OK / 일정 압축 위험 / 단가 -10% 검토 가능
- ✅ **즉답 못할 사항** — "24시간 내 회신드릴게요" (단가·일정 큰 변경은 즉답 거절)

### Don't
- ❌ **단가 즉답 하향** — 클라이언트가 압박하면 "검토 후 회신"
- ❌ **무조건 응하기** — Scope·일정 모두 양보하면 적자 위험
- ❌ **자산 가치 과소평가** — "그냥 해드릴 수 있어요" 같이 말하지 X
- ❌ **타사 비교 부정** — "다른 회사 견적은…" 같은 비교 협상 X

## 🛡 협상 결렬 시 대처

만약 **단가 -20% 이상 + 일정 -30% 이상 + Scope 추가** 등 받아들이기 어려운 조건이면:

**정중 거절 메시지**:
> "본 프로젝트 가치 + 저희 자산 가치를 고려할 때 협의가 어려운 조건입니다. **현재 조건에서는 진행이 어려워 정중히 사양**하겠습니다. 만약 향후 다른 프로젝트가 있으면 다시 연락 부탁드립니다."

→ **자산 가치 인정 못 하는 클라이언트는 도와줘도 만족 못 함**. 거절도 영업 자산.
