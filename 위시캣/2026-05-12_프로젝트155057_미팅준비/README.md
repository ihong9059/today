## 🎯 핵심 메시지 (미팅 시 반복할 3가지)

### 메시지 1 — "AISG 2.0 → 3.0 포팅은 학습 비용 거의 0"

> "AISG 프로토콜의 모든 구성 요소는 저희가 이미 양산·실전 경험을 가진 패턴과 1:1로 대응됩니다. 새로 배워야 할 것은 AISG **3.0 변경점 4개** (Device Discovery / Multi-Primary / Connection Mapping / Ping Packet) 인데, **이 4개도 BLE Mesh 3,800대 시스템에서 모두 구현한 패턴**입니다."

근거:
- RS-485 PHY → Modbus RTU 양산 (KC 인증 완료)
- OOK PHY → CC1101 447.925MHz Replay 직접 구현 (2026-05, REVITA)
- HDLC 프레임 → BLE Mesh / LoRa 패킷 프레임 다수
- CRC-CCITT 16 → RS-485 Modbus CRC16 양산
- Device Discovery → BLE Mesh 디바이스 스캔
- Multi-Primary → BLE Mesh 게이트웨이 동시성
- Connection Mapping → Mesh 라우팅 테이블
- Ping Packet → BLE Heartbeat

### 메시지 2 — "OOK PHY 두 옵션 모두 직접 경험은 희소함" ⭐ 최강 차별화

> "AISG 3.0의 두 PHY 옵션은 RS-485와 **OOK 2.176MHz Bias-T** 입니다. RS-485는 흔하지만 **OOK PHY를 직접 구현한 엔지니어는 드뭅니다**. 저희는 2026년 5월에 CC1101 트랜시버로 447.925MHz OOK Replay 시스템을 완성했습니다. 캐리어 주파수만 다를 뿐 변조/디코딩 로직은 동일합니다."

→ 이 메시지가 다른 응시자와 차별화하는 가장 강력한 무기.

### 메시지 3 — "용인 기흥구 사무실 = 현장 즉시 대응"

> "현장 테스트 장소가 용인 기흥구라고 들었는데, 저희 사무실도 용인 기흥구에 있습니다. 추가 출장비 없이 수시 방문 가능하고, 긴급 디버깅도 당일 대응됩니다."

→ 매우 실용적인 장점. 다른 외주는 출장비 + 일정 협의 필요.

## ⚠️ 정직하게 인정할 사항 (먼저 말하기)

| 사항 | 정직한 답변 |
|---|---|
| AISG 3.0 직접 구현 경험 | **없음** — 그러나 스펙 분석 완료 + 모든 구성 요소 매칭 자산 보유 |
| 기지국 ALD 실장비 경험 | **없음** — 일반 산업·자동차·IoT 분야 양산이 주력. 그러나 현장 디버깅 경험은 일본 3,800대 설치로 충분 |
| ALD 인증 절차 | **별도 학습 필요** — KC/TELEC/CE 인증 경험은 있으나 AISG 특화 인증은 처음 |

→ **미리 인정하면 신뢰도 ↑**. 클라이언트가 캐묻기 전에 자발적으로 언급.
