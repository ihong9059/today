### A. ⭐ 최강 카드 — REVITA OOK Replay 실제 코드 (CC1101)

**왜 강력한가**: AISG OOK PHY와 같은 변조 방식. 캐리어 주파수만 다름. **다른 응시자는 보통 코드 시연 불가**.

**시연 절차**:
1. GitHub 페이지 열기 (또는 로컬 코드)
2. 다음 파일 보여주기:
   - `oldProject/test/bleModule/lora_e22/` (E22 LoRa)
   - `revitaProject/remocon/cc1101/cc1101.c` (CC1101 SPI 드라이버)
   - `revitaProject/remocon/cc1101/cc1101_ook.c` (OOK 변조 코드)
   - `revitaProject/remocon/tx_ook/src/main.c` (TX 앱)
3. 핵심 부분 설명:
   - SPI 통신 설정 (CC1101 레지스터 접근)
   - OOK 변조 파라미터 (캐리어 / 데이터 레이트 / 변조 깊이)
   - 패킷 생성 / CRC / 송신
4. 가능하면 **실제 동작 동영상** 1분 (LED 토글 / RF 송수신)

**준비 체크**:
- [ ] GitHub 페이지 사전 로딩 (오프라인 캐시)
- [ ] 또는 노트북에 코드 클론 + IDE 셋업 (VSCode 등)
- [ ] 화면 글자 크기 ↑ (관객이 잘 보이게)
- [ ] 동영상 백업 (USB)

## 🚫 시연 시 주의사항

| Do | Don't |
|---|---|
| ✅ 코드는 핵심 부분만 (10~20줄) — 너무 길면 지루 | ❌ 모든 함수 다 설명 |
| ✅ "이 코드가 AISG의 XX와 매칭됩니다" 명시 | ❌ 그냥 "이것도 했어요" |
| ✅ 동영상 1~2분 — 짧게 강렬하게 | ❌ 5분+ 긴 동영상 |
| ✅ 클라이언트 질문 받으면 즉시 화면 전환 | ❌ 시연 계속 강행 |
| ✅ NDA 자료는 결과·사진만, 코드 X | ❌ NDA 코드 노출 |
