# 현장 테스트 준비 — 용인 기흥구

> 현장 테스트 장소가 UTTEC 사무실과 동일 지역. 가장 큰 차별화 요소.

## 🗺 지리적 이점 — 동일 지역

```
UTTEC 사무실: 경기도 용인시 기흥구
프로젝트 현장: 경기도 용인시 기흥구

→ 차량 이동 시간: 10~30분 이내 추정
→ 추가 출장비: 0
→ 긴급 디버깅: 당일 대응 (오전 발견 → 오후 수정)
→ 임호균 협업자 동행: HW 측 즉시 대응 가능
```

## 📋 현장 테스트 단계 (Phase 5 - Week 11~12)

### Week 11 — 1차 현장: 통신 수립 확인

**목표**: 자체 시뮬레이션에서 동작한 AISG 3.0 코드가 실 ALD 장비 + 실 RF 케이블 환경에서도 통신 수립되는지 확인.

**준비 (사전 1주)**:
- 자체 시뮬레이션 환경의 동작 상태 확인 + 코드 freeze
- 현장 답사 (가능하면 Week 10에 사전 방문 1회)
- 휴대 가능 장비 정리

**현장 작업 (1일)**:
1. 오전: 셋업 + 케이블 연결 + 전원 확인
2. 오전 후반: 첫 통신 시도 (Device Discovery로 ALD 1대 인식)
3. 오후: 추가 ALD 인식 + 명령 송수신
4. 오후 후반: 발견 이슈 사무실로 가져옴 → 당일 수정

**검증 체크리스트**:
- [ ] RF 케이블 연결 OK
- [ ] AISG 모뎀 전원 + 통신 LED 동작
- [ ] Device Discovery로 ALD 1대 이상 인식
- [ ] 인식된 ALD에 기본 명령 (예: 상태 조회) 송수신 OK
- [ ] HDLC 프레임 / CRC 검증 정상

### Week 12 — 2차 / 3차 현장: 4개 기능 완전 실증

**Week 12 전반**:
- 2차 현장: Multi-Primary + Connection Mapping 실증
- 컨트롤러 2대로 동시 ALD 접근 시나리오
- 케이블 swap 시 매핑 테이블 변화 검증

**Week 12 후반**:
- 3차 현장 (필요 시): Ping Packet + 부하·내구성
- 모든 RF 채널에서 Ping 송수신
- 장애 시뮬레이션 (케이블 끊김 / 응답 없음)
- 수 시간 연속 동작

## 🔧 현장 지참 장비 (체크리스트)

### 필수 (UTTEC 보유)

| 장비 | 용도 |

| 노트북 (개발 환경 풀 셋업) | 코드 수정 / 컴파일 / 플래시 |
| J-Link / ST-Link 디버거 | MCU 펌웨어 디버그 |
| UART/RS-485 로직 분석기 | 통신 신호 분석 |

| 멀티미터 | 전압·전류 측정 |

| 자체 시뮬레이터 (모의 ALD) | 비교 / 대조군 |

## 📐 현장 환경 변수 + 대응

### RF 노이즈

**상황**: 기지국 환경은 강한 RF 잡음 있을 수 있음.
**대응**:
- 차폐 케이블 사용
- 신호 강도 측정 후 임계값 조정
- 임호균 협업자 동행해 HW 측 즉시 진단

### 케이블 손실

**상황**: 긴 RF 피더 케이블은 신호 손실 발생.
**대응**:
- OOK PHY는 2.176 MHz로 낮은 주파수 → 손실 적음
- 신호 강도 측정 + 증폭 필요 시 클라이언트 측 amplifier 확인

### 환경 온도

**상황**: 옥외 또는 옥상 = 온도 변화 큼.
**대응**:
- 본 프로젝트는 펌웨어 영역 → 환경 영향 적음
- 다만 ALD 장비 동작 온도 범위 확인

### 전원

**상황**: 기지국은 -48V DC 또는 +12V DC 등 다양한 전원.
**대응**:
- AISG 3.0은 10-30V DC 단일 → 호환 어댑터 지참
- 만약 옛 -48V 환경이면 변환기 필요

## 🚗 이동 / 일정 관리

### 1차 현장 (Week 11) — 1일 풀 방문

```
오전 09:00 - 사무실 출발 (0~30분 이동)
오전 09:30 - 현장 도착 + 셋업 (30분)
오전 10:00 - 첫 통신 시도
오후 12:00 - 점심
오후 13:00 - 추가 검증
오후 16:00 - 사무실 복귀 + 발견 이슈 수정
오후 19:00 - 1차 보고 작성
```

### 2차/3차 현장 (Week 12) — 반나절씩

```
2차 (Week 12 화): 오전 4시간 (Multi-Primary + Connection Mapping)
3차 (Week 12 목): 오전 4시간 (Ping + 부하 / 내구성)
```

→ 동일 지역 = **점심 시간 없이 반나절 효율 가능**.

## 🤝 클라이언트 측 협조 요청 사항

미팅에서 사전 확인할 항목:

1. **실 ALD 장비 제공 여부**
   - 사무실에 모의 ALD 갖다놓고 사전 테스트 가능?
   - 또는 현장에서만 가능?

2. **현장 방문 가능 시간대**
   - 평일만? 주말 가능?
   - 야간 작업 필요?

3. **현장 접근 권한**
   - 어떤 절차로 진입?
   - 사전 신청 필요?

4. **현장 인프라**
   - 전원 / 인터넷 / 작업 공간
   - AISG 모뎀 사전 셋업 상태

5. **안전 / 보안**
   - 안전 교육 필요?
   - NDA 별도?

## 🆘 현장에서 문제 발생 시 에스컬레이션

```
[Level 1] 본인이 즉시 해결 가능
   → 현장에서 수정

[Level 2] 사무실로 가져가 수정 필요 (당일 가능)
   → 클라이언트 측에 "오후 다시 방문" 통보
   → 사무실에서 코드 수정 → 재방문

[Level 3] 사무실에서도 1일 이상 소요
   → 클라이언트 측에 정직히 통보 ("내일 또는 모레 다시 방문")
   → 사무실에서 충분히 수정 후 재방문

[Level 4] Scope 밖 또는 HW 이슈 (클라이언트 측 책임)
   → 클라이언트와 즉시 협의
   → Scope 명확화
```
