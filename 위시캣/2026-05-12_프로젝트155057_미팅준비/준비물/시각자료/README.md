#### 변환 방법 (택 1)

**방법 A — Pandoc** (CLI, 빠름):
```powershell
pandoc A_미팅전용_1page_회사소개.md -o A_미팅전용_1page_회사소개.pdf --pdf-engine=xelatex -V mainfont="맑은 고딕"
```

**방법 B — PowerPoint** (시각 디자인):
1. Markdown 내용을 PowerPoint 슬라이드에 복사
2. 적절한 디자인 적용 (1장)
3. 다른 이름으로 저장 → PDF

**방법 C — Obsidian PDF Export** (가장 간단):
1. Obsidian에서 .md 파일 열기
2. Cmd/Ctrl + P → "Export to PDF"
3. 본 폴더에 저장

**방법 D — VSCode + Markdown PDF 확장**:
1. VSCode에서 .md 파일 열기
2. 우클릭 → "Markdown PDF: Export (pdf)"
