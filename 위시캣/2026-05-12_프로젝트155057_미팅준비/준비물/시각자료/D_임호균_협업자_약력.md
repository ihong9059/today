# 임호균 — UTTEC HW 측 협업자

## 한 줄 정의

**회로설계 25년 + ARM CPU 설계 경험. CAN/RS-485 양산. 본 프로젝트 HW 측·현장 RF 측 즉시 대응.**

---

## 핵심 경력

| 회사 | 역할 | 기간 (대략) |
|---|---|---|
| **AuthenTec (미국)** | ARM CPU 설계 (IC 레벨) | 다년 |
| **대한전선 WINDER** | CAN / RS-485 통신 + 모터 제어 양산 | 다년 |
| **UTTEC 협업자** | 회로설계 + HW 디버깅 + 현장 진단 | 현재 |

---

## 본 프로젝트 분담

### Phase 1~4 (Week 1~10) — 사무실 작업
- 회로 측 자문 (요청 시)
- HW 측 검증 환경 셋업 (필요 시 자체 모의 ALD 모뎀)
- 시뮬레이션 환경 구축 협력

### Phase 5 (Week 11~12) — 현장 연동 ★ 핵심 동행
- **모든 현장 방문 동행** (1차 + 2차/3차)
- 실 ALD 장비 ↔ UTTEC 시스템 HW 측 연결 검증
- 현장 RF 노이즈 / 케이블 손실 / 매칭 임피던스 즉시 진단
- 발견 이슈 → 사무실 즉시 디버깅 (동일 지역 강점)

### Phase 6 (Week 13) — 인계 (필요 시)
- HW 측 인계 자료 작성 협력

---

## 본 프로젝트 매칭 강점

| 본 프로젝트 영역 | 임호균 보유 자산 |
|---|---|
| RS-485 PHY 반이중 | 대한전선 WINDER 양산 |
| CAN 통신 | 대한전선 WINDER 양산 |
| RF 신호 측정·진단 | ARM CPU 설계 경험 (IC 레벨 신호 분석) |
| 회로 디버깅 | 25년 경력 |
| 임피던스 매칭 (RF feeder) | 회로설계 25년 |
| 양산 환경 (KC 인증 검증) | UTTEC 양산 다수 협력 |

| 항목 | UTTEC (2인) | 1인 외주 |
