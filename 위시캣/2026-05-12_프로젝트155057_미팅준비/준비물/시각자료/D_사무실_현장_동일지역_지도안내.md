# UTTEC 사무실 ↔ AISG 현장 — 동일 지역 강점

> 본 파일은 **지도 스크린샷 생성 안내**. 사용자가 직접 구글맵에서 스크린샷 후 본 폴더에 첨부.

---

## 핵심 메시지

```
UTTEC 사무실         : 경기도 용인시 기흥구 흥덕중앙로 120 흥덕유타워 2404호
AISG 현장 (공고 명시) : 경기도 용인시 기흥구

→ 같은 지역 (차로 15~30분 이내 추정)
→ 출장비 0
→ 현장 → 사무실 → 현장 디버깅 사이클 당일 가능
→ 다른 지역 외주가 따라올 수 없는 본질적 강점
```

---

## 스크린샷 생성 절차 (5분)

### Step 1 — 구글맵 열기

Chrome에서 [https://www.google.com/maps](https://www.google.com/maps) 열기.

### Step 2 — UTTEC 사무실 검색

검색창에 입력:

```
경기도 용인시 기흥구 흥덕중앙로 120 흥덕유타워
```

또는:

```
유티텍 흥덕유타워
```

→ 핀 표시됨

### Step 3 — AISG 현장 위치 확인

클라이언트가 공고에 명시한 현장 위치 (정확한 주소는 미팅 시 확인). 임시로 **용인시 기흥구**의 대략적 중심점에 표시 또는 미팅 전에 클라이언트에 정확한 주소 문의.

### Step 4 — 줌 레벨 조정

두 핀이 한 화면에 보이도록 줌 조정 (보통 동일 구 단위면 자동).

### Step 5 — 스크린샷

Windows: `Win + Shift + S` 또는 `Snipping Tool` 사용 → PNG 저장:

```
파일명: D_사무실_현장_동일지역_지도.png
저장 위치: 본 폴더 (시각자료/)
```

### Step 6 — 거리·시간 메모

지도에 표시되는 차량 이동 시간을 별도 메모:

```
거리 : 약 X km
시간 : 약 X분 (차량 기준)
```

## 미팅 시 활용 흐름

```
[화면 공유] 구글맵 스크린샷 띄우기

"사무실은 여기 흥덕유타워고, AISG 현장은 여기 [클라이언트가 알려준 위치]입니다.
같은 용인 기흥구로 차로 X분 거리입니다. 출장비도 들지 않고, 더 중요한 건
디버깅 사이클이 당일 가능하다는 점입니다. 현장에서 이슈 발견하면 바로
사무실 가서 수정하고 다시 현장 가서 검증할 수 있습니다.

다른 지역에서 출퇴근하는 외주는 따라올 수 없는 강점입니다."
```

## 대안 — 스크린샷 작성 불가 시

구글맵 URL을 노트북에서 직접 열어서 화면 공유:

```
https://www.google.com/maps/search/흥덕유타워+용인+기흥구
```

미팅 전 사무실 노트북에 사전 로드 (오프라인 캐시).
