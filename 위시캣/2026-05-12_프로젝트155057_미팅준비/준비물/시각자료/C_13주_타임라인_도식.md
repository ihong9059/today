## Phase 3 (★ 핵심) 상세 — AISG 3.0 4개 기능

```
Week 5 ─ Device Discovery
  · 버스 broadcast + 응답 타임아웃 200-500ms
  · 디바이스 목록 자료 구조 + hot-plug 감지
  · 1~10대 시뮬레이션 100% 감지

Week 6 ─ Multi-Primary
  · 컨트롤러별 세션 상태 분리
  · 동시 접근 mutex/세마포어
  · 트랜잭션 ID 기반 응답 매칭

Week 7 ─ Connection Mapping
  · Ping 패킷 RF 채널별 송신
  · 응답 수집 → 매핑 테이블
  · Flash/EEPROM 영속화 + 재스캔

Week 8 ─ Ping + 통합 단위 테스트
  · 모든 RF 채널 Ping → 장애 감지
  · 4개 기능 통합 단위 테스트 PASS
  · Phase 2 회귀 테스트 깨지지 않음 확인
```
