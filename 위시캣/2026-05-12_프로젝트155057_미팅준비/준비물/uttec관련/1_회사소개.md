## 🖥️ 화면 자료 — 어떻게 띄울 것인가

### 방법 A: 기존 회사소개 PDF 직접 사용 (간단)

위치: `C:/todo/today/homepage/회사소개/` 또는 `myWiki/raw/회사소개/`

- 장점: 이미 디자인 완성됨, 별도 작업 0
- 단점: 일반용이라 AISG 맥락에 안 맞는 페이지 다수, 분량 多
- 권고: 표지 + 핵심 페이지 2~3장만 골라서 화면 공유

### 방법 B: AISG 미팅 전용 1-page 요약 PDF 신규 작성 (권장)

위 5분 스크립트의 5개 슬라이드(정체성·실적·프로토콜 7종·인증·매칭 13/13)를 1장으로 정리한 PDF를 미팅 1일 전 작성.

- 도구: PowerPoint → PDF Export 또는 Markdown → Pandoc → PDF
- 분량: 5~7장
- 효과: 클라이언트 인상 ↑, "이 미팅을 위해 준비해왔다" 시그널

### 방법 C: 본 markdown 파일을 그대로 화면 공유 (백업)

VSCode 또는 Obsidian preview로 본 파일을 직접 띄우는 방식.

- 장점: 미팅 직전에도 수정 가능, 별도 export 불필요
- 단점: 가독성·디자인 PPT 대비 떨어짐
- 권고: 백업용 (A·B가 실패할 경우)
