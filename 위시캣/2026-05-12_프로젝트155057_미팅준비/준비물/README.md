## ⭐ 핵심 — 요구 #3 사전 인지

클라이언트 원문:
> "AISG 쪽 소스코드를 가지고 계신 경험자가 3.0으로 버전 업데이트를 진행하여 쉽고 빠르게 구현하는 방식"

**우리 상황** (정직하게 인지):
- AISG 2.x 소스 코드 ❌ **보유 없음**
- AISG 직접 양산 경험 ❌ **없음** (사전 학습으로 스펙 분석 완료)

**대응 전략** (3_개발방식_답변.md 상세):
1. 위 사실을 **숨기지 않고 먼저 명시** (신뢰 신호)
2. 클라이언트가 **기존 소스를 제공할 가능성**부터 확인 (이 경우 그들이 원하는 방식 그대로 가능)
3. 제공 불가 시 → **자체 강점 5가지로 90일 안에 처음부터 안정 구현** 가능함을 입증
