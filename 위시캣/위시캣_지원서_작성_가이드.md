# 위시캣 프로젝트 지원서 작성 가이드

## 개요

위시캣(Wishket) 프로젝트 지원서를 효율적으로 작성하기 위한 표준 프로세스입니다.

---

## 사전 준비 자료

위시캣 폴더에 다음 자료가 준비되어 있어야 합니다:

```
위시캣/
├── 이력서_홍광선.pdf        # 인력 이력서
├── 경력서 - 임호균.pdf      # 인력 경력서
├── 2026-02-05_신청항목.txt  # 보유 역량 정리 문서
└── 위시캣_지원서_작성_가이드.md  # 본 가이드
```

---

## 작성 프로세스

### Step 1. 프로젝트 정보 수집

**목표**: 프로젝트 요구사항 파악

**방법**:
```
Claude에게 요청:
"https://www.wishket.com/project/XXXXX/ 프로젝트 정보를 확인해주세요"
```

**수집 항목**:
- 프로젝트명
- 예산
- 기간
- 근무지 (상주/원격)
- 모집 마감일
- 필수 기술 스택
- 세부 업무 내용
- 필수 자격
- 우대 사항

---

### Step 2. 핵심 기술 스펙 정리

**목표**: 프로젝트에서 강조하는 기술 파악

**방법**:
```
Claude에게 요청:
"위 프로젝트에서 강조하는 기술 스펙을 정리해주세요"
```

**정리 형식**:
```
1. [필수 기술 1] - 설명
2. [필수 기술 2] - 설명
3. [필수 기술 3] - 설명
...
```

---

### Step 3. 보유 역량 매칭

**목표**: 프로젝트 요구사항과 보유 역량 매칭

**참고 자료**:
- `2026-02-05_신청항목.txt` (보유 역량 정리)
- `이력서_홍광선.pdf`
- `경력서 - 임호균.pdf`

**매칭 방법**:
```
프로젝트 요구 기술  →  보유 역량 (경험/프로젝트)
─────────────────────────────────────────────
[요구 기술 1]      →  [관련 경험]
[요구 기술 2]      →  [관련 프로젝트]
...
```

---

### Step 4. 지원서 작성

**방법**:
```
Claude에게 요청:
"위시캣 폴더의 자료를 검토하고,
https://www.wishket.com/project/XXXXX/proposal/apply/
지원내용에 작성할 내용을 만들어주세요"
```

**지원서 구조**:
```
1. 프로젝트 핵심 기술 스펙 매칭 (한눈에 보이게)
2. 지원 사유 (간략한 자기소개)
3. 핵심 기술 스펙별 보유 역량 (상세)
4. 세부 업무별 대응 역량
5. 주요 경력 (프로젝트 관련 순으로 정렬)
6. 기술 스택
7. 강점
8. 포트폴리오
9. 희망 단가
10. 기타 사항
```

---

### Step 5. 텍스트 파일 변환

**목표**: 위시캣 사이트에 복사/붙여넣기 가능한 형식으로 변환

**방법**:
```
Claude에게 요청:
"복사해서 붙여넣기해도 깨지지 않도록 txt 파일로 만들어주세요"
```

**주의사항**:
- 마크다운 표(|---|) 사용 금지
- 일반 텍스트 형식 사용
- 구분선은 `====` 또는 `----` 사용

---

### Step 6. 최종 검토 및 제출

**체크리스트**:
- [ ] 프로젝트 필수 기술 모두 언급했는가?
- [ ] 관련 경험이 구체적으로 기술되었는가?
- [ ] 희망 단가가 적절한가?
- [ ] 근무 조건(상주/원격, 기간) 확인했는가?
- [ ] 연락처/포트폴리오 링크가 정확한가?

## Claude 요청 템플릿

### 전체 프로세스 한 번에 요청

```
위시캣 폴더의 자료를 검토하고,
https://www.wishket.com/project/XXXXX/ 프로젝트에 대해:

1. 프로젝트 정보 확인
2. 핵심 기술 스펙 정리
3. 지원서 작성 (txt 파일로)

위 순서대로 진행해주세요.
```

### 단계별 요청

```
[Step 1] "https://www.wishket.com/project/XXXXX/ 프로젝트 정보를 확인해주세요"

[Step 2] "위 프로젝트에서 강조하는 기술 스펙을 정리해주세요"

[Step 3] "위시캣 폴더의 자료를 검토하고 지원내용을 작성해주세요"

[Step 4] "지원내용에 이 기술 스펙 강조해서 수정해주세요"

[Step 5] "복사해서 붙여넣기해도 깨지지 않도록 txt 파일로 만들어주세요"
```

## 지원서 작성 팁

### 1. 기술 매칭 강조
- 프로젝트 필수 기술을 상단에 배치
- 각 기술별 구체적인 경험 기술

### 2. 경력 순서
- 프로젝트와 관련된 경력을 먼저 배치
- 기술별로 그룹화 (예: CAN 관련, RTOS 관련)

### 3. 구체적인 경험 기술
```
나쁜 예: "CAN 통신 경험 있음"
좋은 예: "대한전선 WINDER CONTROLLER에서 CAN/RS485 통신 기반 산업용 제어 시스템 설계"
```

### 4. 대응 가능 여부 명시
```
세부 업무: Vehicle CAN 수집 및 SD카드 저장
→ 대응 가능 (CAN 통신 + 파일시스템 + 데이터 로깅 경험)
```

### 5. 부족한 부분 솔직히 기술
```
[참고 - 부족한 부분]
- Flutter 개발 경험 없음 → 학습 필요
- 단, 임호균의 관련 HW 경험으로 보완 가능
```
