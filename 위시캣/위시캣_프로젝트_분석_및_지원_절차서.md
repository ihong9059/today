# 위시캣 프로젝트 분석 및 지원 절차서

## 개요

위시캣(Wishket)에서 매일 업데이트되는 프로젝트를 분석하고, 지원 가능한 프로젝트를 선별하여 지원서를 작성하는 절차입니다.

---

## 폴더 구조

```
위시캣/
├── 이력서_홍광선.pdf           # 인력 이력서
├── 경력서 - 임호균.pdf          # 인력 경력서
├── 2026-02-05_신청항목.txt     # 보유 역량 정리 (기술 스택, 경력)
├── YYYY-MM-DD_가능프로젝트.md   # 일일 프로젝트 분석 결과
├── YYYY-MM-DD_프로젝트ID_지원내용.txt  # 지원서 (제출용)
├── 위시캣_지원서_작성_가이드.md  # 지원서 작성 상세 가이드
└── 위시캣_프로젝트_분석_및_지원_절차서.md  # 본 문서
```

## 1. 가능 프로젝트 Report 생성

### 목적
위시캣에서 새로 등록된 프로젝트 중 지원 가능한 프로젝트를 선별

### Claude 요청 방법

```
claude, https://www.wishket.com/project/ 에서 최근 프로젝트를 확인하고,
위시캣 폴더의 이력서(홍광선, 임호균)를 기준으로 참가 가능한 프로젝트를
YYYY-MM-DD_가능프로젝트.md 파일로 만들어주세요.

마지막 검토 ID: #XXXXXX (이전 파일에서 확인)
```

### 생성되는 파일 형식

```markdown
# 위시캣 참가 가능 프로젝트 목록

**조회일**: YYYY-MM-DD
**마지막 검토 ID**: #XXXXXX
**다음 검색 시작 ID**: #XXXXXX

## 신규 프로젝트 목록

| ID | 프로젝트명 | 금액 | 기간 | 참가 가능 여부 |
|----|-----------|------|------|---------------|
| ... | ... | ... | ... | ✅/❌/⚠️ |

## 참가 가능 프로젝트 상세

### ✅ ID: 프로젝트명
- URL: ...
- 금액/기간: ...
- 매칭 분석: ...
```

### 판단 기준

| 기호 | 의미 | 조건 |
|------|------|------|
| ✅ | 지원 추천 | 핵심 기술 70% 이상 보유 |
| ⚠️ | 검토 필요 | 핵심 기술 50% 이상, 학습 가능 |
| ❌ | 지원 불가 | 핵심 기술 부족 또는 도메인 불일치 |

### 보유 역량 기준 (신청항목.txt 참고)

**강점 분야 (지원 우선)**
- 임베디드/펌웨어 (C/C++, ARM, RTOS)
- IoT 시스템 (MQTT, 센서, Raspberry Pi)
- HW 설계 (PCB, Motor Controller)
- 공장자동화/스마트팩토리
- 통신 모듈 (BLE, Zigbee, LoRaWAN, CAN)

**가능 분야 (검토 필요)**
- 웹 백엔드 (Node.js, Python, Flask)
- 데이터 수집/대시보드
- MES/PDA 시스템

**약점 분야 (지원 제외)**
- 모바일 앱 (Flutter, React Native, iOS)
- 3D 그래픽 (Unity, Three.js, WebGL)
- 프론트엔드 전문 (React/Vue 전문)
- 특정 플랫폼 (Cafe24, Shopify)

## 3. 일일 워크플로우

### 매일 아침 (프로젝트 체크)

```
claude, 위시캣 가능프로젝트를 업데이트해주세요.
마지막 검토 ID는 위시캣 폴더의 최근 가능프로젝트.md를 참고해주세요.
```

### 지원 결정 후

```
claude, 프로젝트 XXXXX 지원서를 작성해주세요.
```

### 지원 완료 후

가능프로젝트.md 파일에 상태 업데이트:
- `✅ 지원 완료` 표시
- 지원 파일명 기록

## 5. 주의사항

1. **마지막 검토 ID 기록**: 다음 검색 시 중복 방지
2. **txt 형식 사용**: 위시캣 사이트에 복사/붙여넣기 호환
3. **마크다운 표 사용 금지**: txt 파일에서는 일반 텍스트 구분선 사용
4. **개인정보 제외**: 회사명, 전화번호 등 민감정보 제외
5. **희망 단가**: 프로젝트 제시 금액 기준 협의 가능으로 기재
