프로젝트 핵심 이해
============================================================

본 프로젝트는 교통신호제어함체에 부착된 스마트 Lock 제어
장치를 중심으로 **함체 상태 감시 + 원격 제어 + 현장 BLE
제어 + 장애·이력 관리**를 통합하는 풀스택 IoT 관리 시스템
(서버 + Web 관제 + Mobile App)을 구축하고 GS 인증까지
대응하는 사업입니다. 핵심 가치는 다음 5가지로 정리됩니다.

(1) **다중 함체 무선 통합 관리** — 분산된 다수 교통 신호함을
    중앙 서버에서 통합 감시·제어. 함체별 상태(Lock 개폐, 도어
    감지, 전원, 통신) 실시간 가시화

(2) **현장 BLE 직접 제어 + 원격 제어 이중화** — 통신망 장애
    시에도 작업자 모바일 App ↔ Lock BLE 직접 제어로 무중단
    운영. 정상 운영 시 서버 원격 명령

(3) **장애·이력 관리** — 모든 개폐 이력 / 작업자 인증 로그 /
    함체 알람을 Historian 시계열로 영속화 → 사후 추적성 확보

(4) **GS 인증 대응** — 한국 정보통신산업진흥원(NIPA) GS 인증
    절차에 맞춘 SW 품질 보증 / 보안 / 기능 시험 통과

(5) **현장 운용 안정성 (HTTPS / SSL, 인증·인가)** — 도로
    교통 핵심 시설 보안 요구 충족 (HTTPS 통신, 작업자 인증,
    권한 분리, 감사 로그)

당사는 **BLE Mesh 양산(일본 3,800대 수출 실적, KC 인증) +
풀스택(Flutter App / Next.js Web / Flask·FastAPI 서버) 양산 +
무인 원격 제어 양산(일본 자전거주차장 1차 500대 → 2차 3,300대)
+ KC / TELEC / CE 인증 양산 경험**으로 위 5가지 가치를 모두
직접 구현 가능합니다.
