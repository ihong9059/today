지원 사유
============================================================

안녕하세요. 임베디드 시스템 엔지니어 홍광선입니다.

본 프로젝트의 핵심인 C++ DSP 엔진 개발에 대해, 저는 삼성전자에서
Audio/Video Controller를 직접 설계한 경력이 있습니다. 오디오 신호
처리(EQ, 필터, 게인 제어)의 원리를 하드웨어 레벨에서 이해하고 있어
소프트웨어 DSP 구현에 강점이 있습니다.

또한 AI 파이프라인 측면에서 Claude/GPT API를 활용한 자연어 처리
시스템을 다수 구축하여 운영 중이며(교육 플랫폼, 챗봇, 코드 생성),
LLM 응답을 파싱하여 구조화된 파라미터로 변환하는 작업에 익숙합니다.

특히 본 프로젝트의 핵심인 "오디오 도메인 처리" 측면에서, 저는
Remotion + edge-tts 기반 음성 합성 파이프라인을 30편+ 영상에서
운영 중이며(한국어/영어 TTS, AI 도구 5 Track 9씬 5분 53초 등),
measure-audio.py를 직접 작성하여 mp3 신호 측정/분석을 수행하고
있습니다. 삼성 Audio Controller 양산 경력 + 현재 운영 중인 음성
합성 파이프라인의 결합으로, 본 프로젝트의 C++ DSP + 오디오 처리
요구에 직접 매칭됩니다.

또한 지식 그래프 측면에서, 저는 Anthropic 공식 Memory MCP 지식
그래프 서버를 운영 중이며(12 entities + 20 relations, JSONL 영구
저장), 일상적으로 Obsidian 그래프 뷰로 노드-엣지 관계를 모델링
합니다. Palantir Foundry Ontology Manager 시리즈 3편을 완주
(객체+액션 4단계 End-to-End)하여 도메인 온톨로지 설계 패턴을
보유하고 있습니다. Neo4j는 직접 경험이 없으나 Cypher 문법만
익히면 즉시 활용 가능합니다.

Node.js/Python 백엔드는 현재 5대 서버에서 12개+ 프로세스를 운영
중이며, React 기반 웹 UI도 교육 플랫폼으로 실서비스 중입니다.

WebAssembly는 직접 프로젝트 경험이 없으나, C++ 38년 + CMake
임베디드 빌드 양산 경험을 보유하여 Emscripten 툴체인 설정 후
기존 C++ DSP 코드를 그대로 컴파일 가능합니다. 학습 부담은 컴파일
타깃 변경 수준입니다.

본 프로젝트가 PoC 수준이라는 점에서, 핵심 모듈(C++ DSP + AI
파이프라인 + 웹 UI)을 빠르게 프로토타이핑하는 데 적합한 팀입니다.

[설계 핵심 결정 사항]

본 PoC는 "실시간 슬라이더" + "준실시간 프롬프트" 두 시간 척도를

파이프라인을, (3) 5대 서버 + 다수 React 앱 운영 경력으로 풀스택
백엔드/프론트엔드를 모두 1인 팀으로 커버 가능합니다.
