============================================================
지원 사유
============================================================

안녕하세요. 임베디드 시스템 엔지니어 홍광선입니다.

본 프로젝트의 핵심인 C++ DSP 엔진 개발에 대해, 저는 삼성전자에서
Audio/Video Controller를 직접 설계한 경력이 있습니다. 오디오 신호
처리(EQ, 필터, 게인 제어)의 원리를 하드웨어 레벨에서 이해하고 있어
소프트웨어 DSP 구현에 강점이 있습니다.

또한 AI 파이프라인 측면에서 Claude/GPT API를 활용한 자연어 처리
시스템을 다수 구축하여 운영 중이며(교육 플랫폼, 챗봇, 코드 생성),
LLM 응답을 파싱하여 구조화된 파라미터로 변환하는 작업에 익숙합니다.

Node.js/Python 백엔드는 현재 5대 서버에서 12개+ 프로세스를 운영
중이며, React 기반 웹 UI도 교육 플랫폼으로 실서비스 중입니다.

Neo4j와 WebAssembly는 직접 프로젝트 경험이 없으나, Neo4j는
그래프 쿼리(Cypher) 기반이라 SQL 경험으로 빠르게 습득 가능하고,
WASM은 C++ → Emscripten 컴파일로 기존 C++ 코드를 그대로 활용
가능하여 학습 장벽이 낮습니다.

본 프로젝트가 PoC 수준이라는 점에서, 핵심 모듈(C++ DSP + AI
파이프라인 + 웹 UI)을 빠르게 프로토타이핑하는 데 적합한 팀입니다.
