지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

"의료기기용 임베디드 제어보드 설계 및 개발" 프로젝트에 지원합니다.

**SOM 기반 베이스보드 개발은 당사의 핵심 역량**입니다.
현재 CM4(Compute Module 4) 기반 EtherCAT 컨트롤러를 국내 양산 판매 중이며,
이는 본 프로젝트의 "신규 SOM 모듈 연결 베이스보드 개발"과 동일한 구조입니다.

또한 파나소닉에서 **LCD Controller 개발 경험**이 있어
LCD 패널 제어 인터페이스 구현에 즉시 대응 가능합니다.

본 프로젝트의 핵심 업무인:
- 베이스보드 설계 및 회로도 작성 (25년 회로설계 경력)
- 핵심 부품 선정 및 BOM 작성 (다수 양산 제품 경험)
- PCB 아트워크 개발 (OrCAD/PADS/EasyEDA)
- **LVDS LCD 인터페이스** (삼성/파나소닉 Video/LCD Controller 경험)
- Embedded Linux 환경 (Raspberry Pi 기반 양산)

위 기술들은 당사가 양산 제품에서 직접 구현하여 운영 중인 기술입니다.

**LVDS 인터페이스**는 삼성전자 Video Controller, 파나소닉 LCD Controller 개발 시
직접 설계/구현한 경험이 있어 즉시 대응 가능합니다.

**SMARC 표준 SOM**은 직접 경험은 없으나, CM4 베이스보드 설계 경험이 있어
전원 시퀀싱, 고속 신호 설계, 커넥터 인터페이스 등 핵심 기술은 동일하게 적용 가능합니다.
SMARC 핀맵 및 NXP i.MX BSP는 프로젝트 착수 전 사전 학습으로 준비하겠습니다.

LVDS / SMARC 인터페이스 경험 분석
============================================================

[LVDS (Low-Voltage Differential Signaling) 경험]

LVDS는 LCD 패널 연결에 사용되는 고속 차동 신호 인터페이스입니다.

1. 삼성전자 - Video Controller (홍광선/임호균)
   - Audio/Video Controller 개발
   - Video 출력 인터페이스 설계
   - 차동 신호 회로 설계 경험
   - LVDS 송신기/수신기 회로 구현

2. 파나소닉 - LCD Controller (홍광선)
   - LCD Paper Controller 9년 개발
   - LCD 패널 인터페이스 설계
   - 디스플레이 타이밍 제어
   - 고속 신호 라우팅 경험

3. 고속 신호 PCB 설계 경험
   - 차동 페어 라우팅 (임피던스 매칭)
   - EMI/EMC 대응 설계
   - 다층 기판 신호 무결성

결론: LVDS 인터페이스 설계 경험 보유 [O]

------------------------------------------------------------

[SMARC (Smart Mobility ARChitecture) 경험]

SMARC는 임베디드 SOM의 표준 폼팩터입니다.
NXP i.MX 계열 SOM은 SMARC 표준으로 제공되는 경우가 많습니다.

1. CM4 베이스보드 설계 (양산 중) - 유사 구조
   - Raspberry Pi CM4는 독자 폼팩터이나 SOM 개념 동일
   - 고밀도 커넥터 (2x 100핀) 인터페이스 설계
   - 전원 시퀀싱 설계
   - 고속 인터페이스 (PCIe, USB, HDMI) 연결
   - GPIO/SPI/I2C/UART 핀 맵핑

2. SMARC vs CM4 비교
   | 항목 | SMARC | CM4 | 경험 전이 |
   |------|-------|-----|----------|
   | 커넥터 | 314핀 MXM3 | 2x100핀 | 유사 |
   | 전원 시퀀싱 | 필수 | 필수 | 동일 |
   | 고속 신호 | PCIe/USB/LVDS | PCIe/USB/HDMI | 유사 |
   | 핀 맵핑 | 표준화 | Pi 전용 | 학습 필요 |

3. NXP i.MX 계열 대응
   - ARM Cortex-A 프로세서 (CM4는 Cortex-A72)
   - Linux BSP 환경 유사
   - 디바이스 트리 설정 경험
   - SMARC 표준 핀맵 학습으로 대응 가능

결론: SMARC 직접 경험은 없으나 CM4 SOM 경험으로 70% 전이 가능 [△]
      - 핀 맵핑/커넥터 사양은 SMARC 스펙 학습 필요
      - 전원 시퀀싱, 고속 신호 설계는 동일하게 적용 가능

============================================================
기타 사항
============================================================

[LVDS/SMARC 관련]
- LVDS 인터페이스: 삼성/파나소닉 Video/LCD Controller 경험으로 대응 가능
- LVDS 회로 설계: 차동 페어 라우팅, 임피던스 매칭 경험 보유
- SMARC 표준: 직접 경험은 없으나 CM4 SOM 베이스보드 경험으로 70% 전이 가능
- NXP i.MX: ARM Cortex-A 기반으로 기존 Linux 경험 활용 가능
- SMARC 핀맵/커넥터 사양은 프로젝트 착수 전 사전 학습 진행 예정

[일반 사항]
- SOM 베이스보드 설계 즉시 착수 가능 (CM4 경험 보유)
- 회로도/PCB/펌웨어 원스톱 개발 가능
- LCD 제어 인터페이스는 핵심 경험 분야 (파나소닉 9년)
- Embedded Linux 환경 양산 경험 보유
- 의료기기 도메인은 직접 경험 제한적이나,
  산업용 제어 시스템 품질 기준으로 대응 가능
- 필요 시 관련 인증(IEC 62304 등) 컨설팅 협력 가능
- 시제품 제작 후 양산 전환 지원 가능
