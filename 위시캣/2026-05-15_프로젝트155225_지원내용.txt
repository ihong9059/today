============================================================
프로젝트 핵심 이해
============================================================

본 프로젝트는 수작업으로 진행되던 X-ray 선량 측정 프로세스를
**10대 장비 동시 자동 제어 + 통계 분석 + 성적서 자동 발행**의
1-Click 무인 자동화 시스템으로 전환하는 사업입니다. 핵심 가치는
다음 4가지로 정리됩니다.

(1) **PLC/DAQ 10채널 동시 제어** — 상용 PLC + 멀티채널 DAQ
    보드로 10대 X-ray 장비를 중앙 집중 동시 제어 → 한 대씩
    수작업하던 측정을 1회 명령으로 일괄 처리

(2) **데이터 파싱 + RSD 통계 계산** — 다채널 동시 수집된
    원시 데이터(전압/전류/시간 등)를 자동 파싱 → 채널별 RSD
    (Relative Standard Deviation, 상대표준편차) 계산 → 기준
    초과 시 자동 경보

(3) **시험 성적서 자동 생성·배포** — RSD 합격 데이터를 정해진
    양식의 PDF 시험 성적서로 자동 생성 + 지정 수신자 자동 발송
    → 검사실 종이 출력·서명·스캔·이메일 작업 완전 제거

(4) **1-Click 무인 자동화 (스마트폰/PC 모니터링)** — 검사 시작
    버튼 1회 → 10대 동시 측정 → 통계 계산 → 성적서 발행 → 알림
    까지 무인 수행. 검사자는 스마트폰/PC로 결과만 확인

당사는 **PLC/Modbus 양산(KC) + 멀티채널 데이터 수집·로깅
인프라 + Python 통계 파싱 양산 + PDF 자동화 양산 + 라이브
모바일 모니터링 자체 운영** 자산으로 위 4가지를 모두 직접 구현
가능합니다.
