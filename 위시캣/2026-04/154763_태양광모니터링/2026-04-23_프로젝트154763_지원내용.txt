지원 사유
============================================================

안녕하세요. 홍광선입니다.

"태양광 발전소 통합 모니터링 플랫폼 구축" 프로젝트를 검토하였습니다.

본 프로젝트의 핵심인 **분산된 여러 제조사 데이터를 하나의 플랫폼으로
통합 모니터링**하는 구조는, 저희 팀이 현재 운영 중인 **스마트팩토리
통합 모니터링 시스템**과 구조적으로 동일합니다.

저희 팀은 스마트팩토리에서 **다수 제조사의 산업 설비(PLC, MFC,
온도 컨트롤러 등)를 각기 다른 프로토콜로 연동하여 하나의
대시보드에서 통합 모니터링**하는 시스템을 직접 개발하여 현장에서
운영 중입니다. 이 경험이 본 프로젝트의 핵심 요구사항과 직접
매칭됩니다:

- **다중 제조사 데이터 통합**: 스마트팩토리에서 서로 다른
  프로토콜(Modbus/TCP/UDP/MQTT)의 설비 데이터를 통합 수집
- **실시간 모니터링 대시보드**: Three.js 3D + WebSocket 기반
  실시간 웹 대시보드 현재 운영 중 (25개 데모)
- **외부 API 데이터 연동/파싱**: 산업장비 커스텀 바이너리
  프로토콜 파싱 + REST API 연동 양산 경험 다수
- **서버 + DB + 클라우드**: Node.js + PostgreSQL + AWS EC2 +
  Docker 현재 운영 중

특히 본 프로젝트가 **1단계 사업**이며 향후 EMS, 전력 중개,
VPP로 고도화 예정이라는 점에서, 저희 팀의 **IoT 디바이스 양산
+ 서버 + 웹 풀스택 역량**은 장기 파트너로서 H/W 확장까지
대응 가능한 차별점입니다.

[1. 스마트팩토리 통합 모니터링 시스템 - 현장 운영 중] ★★★

제품: 공장 설비 실시간 통합 모니터링 시스템
- 데이터 소스: **다수 제조사 산업 설비** (PLC, MFC, 온도 컨트롤러 등)
- 통신: TCP/IP, UDP, Modbus RTU/TCP, **MQTT**
- 서버: **Node.js + Express + Flask**
- DB: **MariaDB/PostgreSQL**
- 프론트: **웹 대시보드 (Three.js 3D 모니터링)**

- **다중 제조사 데이터 통합 수집** (각기 다른 프로토콜 → 통합 DB)
- **커스텀 바이너리 프로토콜 파싱** (프레임/체크섬/분기/응답)

- **WebSocket** 기반 실시간 대시보드 업데이트

- REST API 서버 (설비 상태 조회, 이력, 통계)

- 이상 감지 시 알림 (SMS/이메일/LED)

→ **본 프로젝트와의 핵심 매칭:**
