지원 사유
============================================================

안녕하세요. 홍광선입니다.

"PVDF 압전센서 기반 층간소음 예방 디바이스 MVP 개발" 프로젝트를
검토하였습니다.

본 프로젝트의 핵심인 **아날로그 센서 신호 수집 → 증폭 회로 설계 →
MCU 펌웨어 처리 → 알림 출력**의 전체 파이프라인이 저희 팀의
핵심 역량과 직접적으로 연결됩니다.

특히 본 프로젝트와 직접 매칭되는 영역:

- **아날로그 센서 신호 처리 양산 다수**: nRF52832 BLE 온도 컨트롤러
  (정밀 ADC, 1Hz 샘플링, 임계치 알람) 국내 양산 판매 중
- **회로 설계 25년+**: OrCAD 상급, 센서 신호 증폭/필터 회로 설계,
  파워/신호 분리 레이아웃 양산 수준
- **ESP32 + FreeRTOS 펌웨어**: ESP-IDF 네이티브 개발 + FreeRTOS
  양산 5종 보유
- **노이즈 대응**: 산업 현장 센서 노이즈 필터링 (이동평균, IIR/FIR)
  양산 적용 경험 다수
- **임계치 기반 단계별 판별**: 컴프레샤 컨트롤러에서 압력/온도
  임계치 기반 단계별 경보(약/중/강) 양산 적용

저희 팀은 **회로 설계(H/W) + 펌웨어(F/W) 수직 통합** 역량을
보유하고 있어, 센서 증폭 회로부터 MCU 펌웨어까지 일관된 설계가
가능합니다. 38년 + 25년 시니어 2명이 함께합니다.

[1. nRF52832 BLE 온도 컨트롤러 - 국내 양산] ★★★

제품: BLE 정밀 온도 계측 디바이스
- MCU: nRF52832 (ARM Cortex-M4F)
- 센서: 아날로그 온도 센서 (정밀 ADC)
- 상태: **국내 양산 판매 중**

개발 내용:
- **정밀 ADC 처리** (저주파 샘플링, 오버샘플링)
- 아날로그 신호 노이즈 필터링 (이동평균 + 디지털 필터)
- **임계치 기반 알람** (단계별 경보)
- 실시간 데이터 로깅 + 이벤트 카운트
- RTC + 시간 스탬프
- BLE 통신 (모바일 앱 연동)

→ PVDF 센서의 아날로그 신호 처리, 임계치 판별, 이벤트 저장과
  동일한 패턴


[2. 컴프레샤 컨트롤러 (STM32F756 + FreeRTOS) - 국내 양산] ★★

제품: 산업용 공기압축기 정밀 제어 보드
- MCU: STM32F756
- OS: FreeRTOS
- 상태: **국내 양산 판매 중**

개발 내용:
- 다중 센서(압력/온도/진동) 동시 수집
- **임계치 기반 단계별 경보** (약/중/강 → 본 프로젝트와 동일 패턴)
- FreeRTOS Task 분리 (센서/제어/UI/로깅)
- LED + 부저 알람 출력 (GPIO 제어)
- 데이터 로깅 (일/월/년 통계)
- **OrCAD 회로 설계** (파워/신호 분리, 노이즈 대응 레이아웃)

→ 충격 강도 구분(약/중/강), LED/부저 알림, 이벤트 카운트와
  직접 매칭


[3. 스마트팩토리 센서 모니터링 시스템]

제품: 공장 설비 실시간 센서 모니터링
- 센서: 진동/온도/압력 등 다중 센서
- 플랫폼: Raspberry Pi + ESP32
- 상태: 현장 운영 중

개발 내용:
- 다중 아날로그 센서 동시 수집
- **진동 센서 신호 처리** (FFT, 이동평균, 임계치 판별)
- 실시간 모니터링 대시보드 (Three.js 3D)
- 이상 감지 시 알람 (SMS/LED/부저)

→ PVDF 압전센서도 진동/충격 감지 센서로, 신호 처리 패턴이 동일


[4. ESP32 기반 IoT 센서 노드 - 양산]

제품: 저전력 IoT 센서 노드
- MCU: ESP32 (ESP-IDF)
- 상태: 양산

개발 내용:
- ESP-IDF 네이티브 API
- FreeRTOS Task + Queue 패턴
- ADC 센서 입력 처리

- Deep Sleep 저전력 관리

→ 본 프로젝트 MCU(ESP32) 환경과 직접 매칭

기타 사항
============================================================

- 계약 체결 즉시 투입 가능
- PVDF 센서 특성상 고임피던스 출력 → 차지 앰프 필수이며,
  저희 팀은 OP-AMP 기반 증폭 회로 설계를 직접 수행 가능
- MVP 단계이므로 만능기판 또는 간이 PCB로 빠르게 프로토타입
  제작 후, 양산 전환 시 정식 PCB 설계 가능
- 실제 바닥 충격 환경에서의 튜닝 경험 제공 (현장 대응)
- 필요 시 회로 설계 + 펌웨어 2인 공동 투입 가능
- MVP 이후 양산 설계/BLE 앱 연동 등 후속 개발 연계 가능
