## 1. PVDF 압전센서 핵심 이해

### 1.1 PVDF란?
- **Polyvinylidene Fluoride** (폴리비닐리덴 플루오라이드)
- 고분자(플라스틱) 압전 소재. 필름 형태로 기계적 압력/진동 → 전기 신호 변환
- 1969년 Kawai가 압전 특성 발견. 센서용으로 가장 널리 쓰이는 고분자 압전체

### 1.2 PZT(세라믹) vs PVDF(고분자) 비교

| 항목 | PVDF 필름 | PZT 세라믹 |
|------|-----------|------------|
| **전압 감도 (g₃₃)** | **-339 mV·m/N** | -25 mV·m/N |
| 변형 계수 (d₃₃) | -33 pC/N | 300~600 pC/N |
| 주파수 응답 | **0.001Hz ~ GHz** | ~수백kHz |
| 유전율 | 12~13 | 1200~3400 |
| 밀도 | 1.78 g/cm³ | 7.5 g/cm³ |
| 형태 | **유연한 필름** (25~110μm) | 딱딱한 세라믹 |
| 기계적 수명 | **>10⁹ 사이클** | ~10⁷ 사이클 |
| 비용 | **$5~30** | $50~500 |

**핵심**: PVDF는 전압 감도가 PZT의 **13.6배** → 센서 용도로는 PVDF가 유리

### 1.3 왜 층간소음에 PVDF가 적합한가?

1. **광대역 저주파 응답**: 층간소음 핵심 대역 30~500Hz를 왜곡 없이 감지
2. **높은 전압 감도**: 작은 바닥 진동에도 측정 가능한 전압 생성
3. **유연한 필름**: 바닥/천장에 접착제로 비파괴 설치, 건축 구조물 변형 없음
4. **대면적 센서 가능**: 넓은 면적 = 더 많은 전하 = 높은 SNR
5. **저가**: BOM 기준 $30 이하 IoT 센서 모듈 구현 가능

## 2. 층간소음의 물리적 특성

### 2.1 층간소음 분류

| 구분 | 경량 충격음 | 중량 충격음 |
|------|------------|------------|
| 발생원 | 숟가락 낙하, 의자 끌기 | **아이 뛰기, 점프, 쿵쿵** |
| 주파수 | 500Hz ~ 5kHz | **30Hz ~ 500Hz** |
| 민원 비율 | ~20% | **~80%** |
| 파형 | 짧은 펄스, 고주파 | 긴 펄스, 저주파 에너지 집중 |

**타겟**: 민원 80%가 중량 충격음 → **30~500Hz 대역이 핵심 감지 대상**

### 2.2 환경부 층간소음 기준 (직접충격음)

| 시간대 | 1분 등가소음도 | 최고소음도 |
|--------|---------------|-----------|
| 주간 (06~22시) | 43dB 이하 | 57dB 이하 |
| 야간 (22~06시) | 38dB 이하 | 52dB 이하 |

> **주의**: PVDF는 "진동"을 측정하지 "소음(음압)"을 측정하지 않음
> → 진동-소음 상관관계 모델 또는 자체 진동 임계값 기준 수립 필요

## 3. 기술 설계 핵심 사항

### 3.1 신호 처리 체인

```
[PVDF 센서] → [Charge Amplifier] → [HPF (5Hz)] → [LPF (1kHz)] → [가변 증폭] → [외장 ADC] → [ESP32]
```

### 3.2 Charge Amplifier (전하 증폭기) - 가장 중요한 회로

PVDF 출력은 **전하(charge)** 형태 → 전압 모드 증폭이 아닌 **전하 증폭기 필수**

| 설계 파라미터 | 값 | 설명 |
|-------------|-----|------|
| 피드백 커패시터 (Cf) | 100pF ~ 10nF | Vout = Q/Cf, 작을수록 감도 높음 |
| 피드백 저항 (Rf) | 1GΩ ~ 10GΩ | 저주파 차단 결정 |
| Op-Amp | OPA140, LTC6240 | 초저 입력 바이어스(<1pA), 저노이즈 |
| 총 이득 | 100~1000배 (40~60dB) | PVDF 출력 ~0.1mV → ADC 입력 ~1V |

**출력 예시 계산**:
```
10N 충격, d₃₃=33pC/N, Cf=1nF → Vout = 0.33mV
→ 후단 100배 증폭 → 33mV → ESP32 ADC로 측정 가능
```

### 3.3 ADC 선택 - ESP32 내장 ADC는 부족

| 항목 | ESP32 내장 ADC | 외장 ADS1256 (권장) |
|------|---------------|-------------------|
| 해상도 | 12-bit (실효 9~10bit) | **24-bit** |
| 비선형성 | 큼 (±7 LSB) | 극히 낮음 |
| 샘플링 | 충분 | 30kSPS (충분) |
| 비용 | 0 | ~$5 |

**권장**: 외장 24-bit ADC (ADS1256 또는 MCP3561) 사용

### 3.4 필터 설계

| 필터 | 차단 주파수 | 목적 |
|------|-----------|------|
| HPF | 5Hz | DC 차단 + 파이로전기 노이즈 제거 |
| LPF | 1kHz | 안티앨리어싱, 고주파 노이즈 제거 |
| 통과 대역 | **5Hz ~ 1kHz** | 층간소음 전 대역 포함 |

## 4. 기술적 도전과 해결방안 (미팅에서 전문성 어필 포인트)

### 4.1 파이로전기 효과 (온도에 의한 오신호)

**문제**: PVDF는 온도 변화에도 전하를 발생 → 충격 신호 대비 수십~수천 배 큰 노이즈 가능

**해결**:
- HPF(5Hz)로 느린 온도 변화 제거 (가장 효과적)
- 차동 센서 구성 (역병렬 연결 → 파이로 상쇄, 기계적 신호 합산)
- 디지털 온도 보상 (NTC 센서 병용)

### 4.2 EMI 차폐 (전자파 간섭)

**문제**: Charge Amp 입력 임피던스 >10¹²Ω → 전자파에 극도로 민감. 50/60Hz 전원 노이즈가 관심 대역과 겹침

**해결**:
- 센서 바로 옆에 Charge Amp 배치 (케이블 최소화)
- 가드 링(Guard Ring) PCB 설계
- 금속 인클로저 차폐
- 소프트웨어 50/60Hz 노치 필터

### 4.3 생활소음과 층간소음 구분

**문제**: 세탁기, 냉장고 등도 저주파 진동 발생

**해결**:
- 시간-주파수 분석 (STFT): 충격음 = 짧은 시간 + 넓은 주파수, 기계음 = 연속 + 특정 주파수
- 임계치 기반 단계별 판별 (약/중/강)
- 향후 ML 분류기 (TFLite Micro on ESP32-S3)

### 4.4 오감지 최소화

- 디바운싱 (연속 충격 1건 처리)
- 윈도우 판별 (일정 시간 내 에너지 합산)
- 적응형 임계값 (환경 노이즈 레벨에 따라 자동 조정)

## 7. 예상 질문 & 답변 준비

### Q1. "PVDF 센서로 개발해본 경험이 있나요?"

> PVDF 센서 자체는 처음이지만, PVDF의 핵심인 **아날로그 센서 신호 처리**는 저희 팀의 핵심 역량입니다.
> - nRF52832 정밀 ADC 온도 컨트롤러를 **양산 판매 중**이며
> - 스마트팩토리에서 **진동 센서 신호 처리**(FFT, 이동평균, 임계치 판별)를 운영 중입니다.
> - PVDF는 출력이 전하(charge) 형태라 **Charge Amplifier**가 필요한데, 임호균 이사가 OP-AMP 기반 증폭 회로를 **25년간 60개+ 프로젝트**에서 설계해왔습니다.
> - 센서가 다를 뿐, **신호 처리 파이프라인은 동일**합니다.

### Q2. "45일 안에 가능한가요?"

> 가능합니다. 이유:
> 1. H/W(회로) + F/W(펌웨어) **2인 동시 투입** → 병렬 작업
> 2. 센서 신호 처리 → 임계치 판별 → LED/부저 알림 → 데이터 저장 패턴이 **컴프레샤 컨트롤러 양산**과 동일 → 검증된 코드 재활용
> 3. MVP이므로 만능기판/간이PCB로 빠르게 프로토타입 → 1주차 회로 검증, 2주차 펌웨어, 3~4주차 통합, 5~6주차 튜닝

### Q3. "외장 ADC가 왜 필요한가요? ESP32에 ADC 있지 않나요?"

> ESP32 내장 ADC는 12-bit이지만 실효 해상도가 **9~10bit 수준**이고 비선형성이 큽니다.
> PVDF 미세 진동을 정확히 감지하려면 **24-bit 외장 ADC** (ADS1256, ~$5)를 사용해야 합니다.
> BOM 원가 $5 추가로 제품 품질이 획기적으로 향상됩니다.

### Q4. "온도 변화에 영향 받지 않나요?"

> PVDF의 파이로전기 효과로 온도 변화 시 오신호가 발생합니다.
> 그러나 온도 변화는 매우 느린 신호(<1Hz)이고, 층간소음은 30Hz 이상이므로
> **HPF(5Hz 차단)** 하나로 효과적으로 제거됩니다.
> 추가로 차동 센서 구성이나 디지털 온도 보상도 적용 가능합니다.

### Q5. "세탁기 소리도 감지되지 않나요?"

> 좋은 질문입니다. 해결 방법:
> 1. **시간-주파수 분석**: 충격음은 짧고 넓은 에너지, 기계음은 연속적이고 특정 주파수에 집중
> 2. **윈도우 판별**: 일정 시간 내 에너지 급변 패턴으로 충격 판별
> 3. **적응형 임계값**: 배경 노이즈 레벨에 따라 자동 조정
> 4. MVP 이후 **ML 분류기** 추가도 가능 (ESP32-S3에서 TFLite Micro 구동)

### Q6. "단가가 왜 1,000만원인가요?"

> MVP 개발은 양산과 달리 **설계 비용**이 핵심입니다.
> - Charge Amplifier 회로 설계 + 검증
> - ESP32 펌웨어 (신호 처리 + 판별 알고리즘 + UI + 저장)
> - 실제 환경 튜닝 (현장 캘리브레이션)
> - 2명(H/W + F/W) × 45일 = 인건비 기준 적정
>
> 양산 시 BOM 원가는 **$30 이하**로, 제조 원가는 매우 경쟁력 있습니다.
