1. **바닥 충격 감지**: 아이들이 뛰거나 점프할 때 발생하는 바닥 진동을 PVDF 압전센서로 감지

4. **설치 편의성**: 가정 바닥에 비파괴 방식으로 간단히 설치 가능

## 2. 시스템 구성도

### 2.1 전체 아키텍처

```
[바닥 설치]                    [디바이스 본체]                      [출력]

PVDF 압전센서 ──→ Charge Amplifier ──→ 아날로그 필터 ──→ 외장 ADC ──→ ESP32-S3 ──→ 경고 스피커/부저
(바닥 부착)       (전하→전압 변환)     (HPF+LPF)        (24-bit)     (판별 엔진)    (단계별 경고음)
                                                                          │
                                                                          ├──→ LED 표시등
                                                                          │    (상태/강도 표시)
                                                                          │
                                                                          ├──→ OLED 디스플레이
                                                                          │    (충격 횟수/강도)
                                                                          │
                                                                          └──→ 물리 버튼
                                                                               (감도조절/음소거)
```

### 2.2 신호 처리 흐름

```
[PVDF 센서]
    │
    │  바닥 충격 → 전하(charge) 출력
    ▼
[Charge Amplifier] ─── OPA140 Op-Amp
    │                   Cf = 1nF, Rf = 1GΩ
    │  전하 → 전압 변환 (Q/Cf)
    ▼
[High-Pass Filter] ─── fc = 5Hz
    │                   DC 차단 + 파이로전기 노이즈 제거
    ▼
[Low-Pass Filter] ──── fc = 1kHz
    │                   안티앨리어싱 + 고주파 노이즈 제거
    ▼
[가변 증폭] ────────── 100~1000배 (40~60dB)
    │                   PVDF 미세 출력을 ADC 입력 범위로 증폭
    ▼
[외장 ADC] ─────────── ADS1256 (24-bit, SPI)
    │                   30kSPS, 고정밀 변환
    ▼
[ESP32-S3 MCU]
    │
    ├── 디지털 필터링 (이동평균 + IIR 밴드패스 30~500Hz)
    ├── 충격 감지 알고리즘 (에너지 산출 → 임계값 비교)
    ├── 강도 분류 (약/중/강 3단계)
    ├── 경고음 출력 결정 (강도별 차등 경고)
    └── 이벤트 기록 (NVS Flash)
```

### 3.2 PVDF 센서 설치 방식

```
[거실 바닥 단면도]

    ═══════════════════════════════════  ← 바닥 마감재 (장판/마루)
    ───────────────────────────────────  ← 양면테이프 접착층
    ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■  ← PVDF 센서 필름 (25~110μm)
    ───────────────────────────────────  ← 양면테이프 접착층
    ═══════════════════════════════════  ← 바닥 하부 (콘크리트/합판)
```

- **비파괴 설치**: 양면테이프로 바닥면에 접착 (원상복구 가능)
- **설치 위치**: 아이들이 주로 뛰어노는 거실/방 바닥
- **센서 보호**: 얇은 보호 시트로 센서 필름 커버
- **케이블**: 센서 → 본체 연결 (플랫 케이블, 최소 길이 → EMI 최소화)

### 3.3 Charge Amplifier 회로 설계 (핵심 회로)

```
                        Cf (1nF)
                    ┌───||───┐
                    │        │
                    │  Rf    │
                    │ (1GΩ)  │
                    │  ┌─┤   │
    PVDF ───┬───────┤  │ │   │
            │       │  └─┤   │
           Cs       │        │        Vout
          (센서     ├───┤-   │──┬────→ (HPF → LPF → 증폭 → ADC)
          정전용량)  │   │  Op-Amp│
                    │   │ OPA140 │
            GND ────┤   │+      │
                    │   ├───────┘
                    │   │
                    │  Vref
                    │ (Vcc/2)
                   GND

    * 출력: Vout = Q / Cf
    * 10N 충격 시: Q = d33 × F = 33pC/N × 10N = 330pC
    * Vout = 330pC / 1nF = 0.33mV → 후단 100배 증폭 → 33mV
```

**설계 파라미터**:

| 파라미터 | 값 | 설명 |
|---------|-----|------|
| 피드백 커패시터 (Cf) | 1nF | 감도 조절 (작을수록 감도 높음) |
| 피드백 저항 (Rf) | 1GΩ | 저주파 차단 주파수 결정 (fc = 1/(2π·Rf·Cf) ≈ 0.16Hz) |
| Op-Amp | OPA140 | 입력 바이어스 <1pA, 저노이즈, FET 입력 |
| 전원 | 3.3V 단전원 (Vref = 1.65V) | ESP32 전원 공유 |
| 후단 증폭 | 100~1000배 (가변) | 디지털 포텐셔미터로 소프트웨어 감도 조절 |

### 4.3 충격 감지 알고리즘

#### 4.3.1 신호 처리 파이프라인

```
[ADC 원시 데이터] (1kHz 샘플링)
       │
       ▼
[DC 오프셋 제거] ─── 이동평균 기준선 차감
       │
       ▼
[디지털 밴드패스 필터] ─── IIR 2차, 30~500Hz
       │                    (층간소음 핵심 대역)
       ▼
[절대값 변환] ─── 양/음 피크 모두 포착
       │
       ▼
[에너지 산출] ─── 슬라이딩 윈도우 (50ms)
       │            E = Σ|x[n]|² (윈도우 내 에너지 합산)
       ▼
[임계값 비교] ─── 3단계 판별
       │
       ├── E < T1 (약) ────→ 무시 (일상 생활 진동)
       ├── T1 ≤ E < T2 ────→ [주의] 노란 LED 점등
       ├── T2 ≤ E < T3 ────→ [경고] 경고음 1회 (짧은 비프)
       └── E ≥ T3 (강) ────→ [강력 경고] 연속 경고음 + 빨간 LED
```

#### 4.3.2 임계값 설정

| 단계 | 에너지 레벨 | 해당 행동 예시 | 반응 |
|------|------------|---------------|------|
| **무시** | E < T1 | 걷기, 의자 끌기, TV 소리 | 없음 (녹색 LED 유지) |
| **주의** | T1 ≤ E < T2 | 가벼운 뜀박질, 빠른 걸음 | 노란 LED 점등, 로그 기록 |
| **경고** | T2 ≤ E < T3 | 뛰어다니기, 점프 | **경고음 1회** (삐- 짧은 비프) + 빨간 LED |
| **강력 경고** | E ≥ T3 | 반복 점프, 쿵쿵 | **연속 경고음** (삐삐삐-) + 빨간 LED 점멸 |

- T1, T2, T3는 **현장 캘리브레이션**으로 결정 (설치 환경별 상이)
- 물리 버튼으로 감도 3단계 조절 가능 (민감/보통/둔감)

#### 4.3.3 오감지 방지 로직

```
[충격 감지됨]
     │
     ▼
[디바운싱] ─── 최소 간격 300ms
     │          (연속 충격을 1건으로 처리)
     ▼
[지속시간 확인] ─── 최소 20ms 이상 유지?
     │               (순간 전기 노이즈 제거)
     ▼
[패턴 판별] ─── 충격형(짧고 강함) vs 기계형(길고 일정)
     │           세탁기/냉장고 등 연속 진동 필터링
     ▼
[적응형 임계값] ─── 배경 노이즈 레벨에 따라 T1~T3 자동 보정
     │                (조용한 밤 vs 시끄러운 낮 자동 대응)
     ▼
[최종 판정] ─── 경고 출력 결정
```

### 4.4 경고음 설계

| 단계 | 경고음 패턴 | 음량 | 지속시간 |
|------|------------|------|---------|
| 주의 | - (소리 없음, LED만) | 0% | - |
| 경고 | 삐- (단일 비프) | 60% | 0.3초 |
| 강력 경고 | 삐삐삐- (3연속 비프) | 100% | 1초 |
| 반복 강력 경고 | 삐~삐~삐~ (연속) | 100% | 충격 멈출 때까지 |

- **경고음 주파수**: 2~3kHz (아이들이 잘 인지하는 주파수대)
- **음소거 기능**: 버튼으로 일시 음소거 (30분 타이머 후 자동 해제)
- **야간 모드**: 22시~06시 음량 자동 50% 감소, LED 밝기 감소

## 5. 기술적 도전과 해결 방안

### 5.1 파이로전기 효과 (온도 오신호)

| 문제 | 해결 방안 |
|------|----------|
| PVDF는 온도 변화에도 전하 발생 | **HPF (5Hz)**: 온도 변화(<1Hz)는 느린 신호이므로 필터로 완전 제거 |
| 에어컨/난방 ON/OFF 시 급격 온도 변화 | **차동 센서 구성**: 2장의 PVDF를 역병렬 연결 → 파이로 상쇄, 기계적 신호 합산 |
| 계절별 기온차 | **디지털 온도 보상**: NTC 센서 병용하여 소프트웨어 보정 |

### 5.2 EMI (전자파 간섭)

| 문제 | 해결 방안 |
|------|----------|
| Charge Amp 고임피던스 입력 → 전자파 민감 | **최단 케이블**: 센서 바로 옆에 Charge Amp 배치 |
| 60Hz 전원 노이즈 | **디지털 노치 필터**: 60Hz 제거 |
| 가전제품 EMI | **금속 차폐 인클로저** + **가드 링 PCB 설계** |

### 5.3 생활 진동 vs 층간소음 구분

| 문제 | 해결 방안 |
|------|----------|
| 세탁기, 냉장고 진동 오감지 | **패턴 판별**: 충격음=짧고 넓은 에너지, 기계음=연속적이고 특정 주파수 |
| 문 닫기, 물건 떨어뜨림 | **에너지 윈도우**: 50ms 윈도우 내 에너지로 판별 (단발 vs 반복) |
| TV/음악 저주파 | **진동 vs 음압 구분**: PVDF는 구조물 진동만 감지 (공기 전달 소음 무시) |

### 5.4 아이들 적응 (경고음 무시) 대응

| 문제 | 해결 방안 |
|------|----------|
| 경고음에 익숙해져 무시 | **점진적 강화**: 반복 감지 시 경고음 패턴/음량 점진 상승 |
| 경고음 자체가 소음 | **쾌적한 알림음**: 불쾌하지 않되 인지 가능한 톤 설계 |
| 부모 부재 시 효과 감소 | **이벤트 로그**: 부모가 나중에 통계 확인 가능 |
