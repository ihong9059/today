### ⚠️ #154889: 소각장 크레인 오알람 방지용 멀티모달 화재 탐지 AI SW 개발
- **URL**: https://www.wishket.com/project/154889/
- **금액**: 2,000만원
- **기간**: 60일
- **마감**: 확인 필요
- **근무**: 외주 (원격 협의 + 현장 테스트)
- **위치**: 경기도 성남시 분당구

**필요 기술:**
- NVIDIA Jetson Orin Nano/NX 엣지 AI + TensorRT
- Python, Linux (Ubuntu)
- 멀티모달 AI (RGB + 열화상 센서 융합)
- 객체 검출, 화재/연기 분류 모델
- Camera SDK, GPIO/Modbus 인터페이스

**매칭 분석:**

| 요구사항 | 보유 역량 | 매칭 |
|---------|----------|------|
| Jetson Orin 엣지 AI | Raspberry Pi/ESP32 임베디드 경험 | △ (유사하나 직접 경험 부족) |
| Python + Linux | Python + Linux 사용 가능 | ○ |
| 멀티모달 AI 모델 개발 | AI 모델 직접 개발 경험 부족 | × |
| Camera SDK 연동 | 센서 연동 경험 풍부 | ○ |
| GPIO/Modbus 인터페이스 | RS485/CAN 등 산업용 통신 전문 | ○ |
| TensorRT 최적화 | 직접 경험 없음 | × |

**결론**: GPIO/Modbus, 센서 연동 등 하드웨어 인터페이스 부분은 강점이나, **AI 모델 개발(객체 검출, TensorRT 최적화)이 핵심 업무**여서 매칭도가 낮음. AI 모델 개발 전문가와 협업 가능하다면 하드웨어 연동 파트 담당 가능하나, 단독 수행은 어려움.
