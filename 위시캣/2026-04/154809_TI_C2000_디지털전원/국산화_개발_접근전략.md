# iHP 국산화 개발 접근 전략

## 1. 프로젝트 구조 (3단계)

### Phase 1: 분석 및 설계 (1~3개월)
- Advanced Energy iHP 시리즈 역설계 분석
  - 전원 토폴로지 파악 (PFC + DC-DC 구조)
  - 모듈 인터페이스 분석 (백플레인 통신, 전력 버스)
  - 보호 회로 동작 분석
- 목표 사양서 작성
- 전체 시스템 블록도 설계
- 핵심 부품 선정 (C2000 MCU, 파워 MOSFET/GaN, 트랜스포머, 게이트 드라이버)
- OrCAD 회로 설계 시작

### Phase 2: 하드웨어 개발 (4~10개월)
- 3kW 단일 모듈 프로토타입
  - AC-DC PFC 단: Totem-Pole Bridgeless PFC
  - DC-DC 단: LLC Resonant 또는 PSFB
  - 제어보드: TMS320F28379D 기반
- PCB 아트웍 (4레이어 이상, 고전압/대전류 설계)
- 시제품 제작 및 단위 테스트
- 백플레인/섀시 설계
- 다중 모듈 통합 테스트

### Phase 3: 펌웨어 개발 및 검증 (4~18개월, Phase 2와 병행)
- 전원 제어 펌웨어 (C2000 CCS)
  - PFC 제어 루프 (역률 0.99 이상)
  - DC-DC 전압/전류 제어 루프
  - 소프트 스타트/정지 시퀀스
  - 과전압/과전류/과온 보호 루틴
- 통신 펌웨어
  - RS485/Modbus 프로토콜
  - CAN Bus 프로토콜
  - Ethernet UDP/TCP
- 통합 테스트 및 성능 검증
- EMI/EMC 대응

## 2. 핵심 기술 요소

### 전원 토폴로지 (iHP 추정 구조)

```
AC Input (3상) ──→ [EMI Filter] ──→ [PFC Stage] ──→ DC Bus (400V)
                                                        │
                    ┌───────────────────────────────────┘
                    │
              [DC-DC Stage] ──→ Output (0.6~300V, 3kW per module)
                    │
              [C2000 MCU] ←→ [Backplane Communication]
                    │
              [Protection] (OVP/OCP/OTP)
```

### PFC 단 설계
- **토폴로지**: Totem-Pole Bridgeless PFC (GaN FET 적용 시 효율 99%+)
- **제어**: 평균 전류 모드 제어 (Average Current Mode Control)
- **C2000 활용**: HRPWM으로 스위칭, ADC로 전류/전압 센싱
- **레퍼런스**: TI TIDM-02013 (Totem-Pole PFC 부분)

### DC-DC 단 설계
- **토폴로지**: LLC Half-Bridge Resonant Converter (고효율, 저노이즈)
- **제어**: 주파수 제어 + 위상 제어 (부하에 따른 주파수 변조)
- **C2000 활용**: HRPWM 데드타임 제어, CMPSS 과전류 보호
- **레퍼런스**: TI TIDM-02000 (PSFB), TIDM-02013 (CLLLC)

### 보호 회로
- **하드웨어 보호**: C2000 CMPSS (나노초 응답)
- **소프트웨어 보호**: 펌웨어 기반 감시 (밀리초 응답)
- **보호 항목**: OVP, OCP, OTP, SCP, UVLO

## 3. 우리 팀 역량 활용

| 프로젝트 영역 | 담당 | 근거 |
|--------------|------|------|
| 전체 시스템 설계 | 홍광선 | ARM/DSP 40년, Factory Automation |
| 회로 설계 / PCB | 임호균 | ASIC/FPGA/회로설계 38년, OrCAD |
| C2000 펌웨어 | 홍광선 + 임호균 | MCU 펌웨어 다수, CAN/RS485 경험 |
| 통신 프로토콜 | 임호균 | EtherCAT 양산, CAN/RS485 |
| 시제품 제작 | 공동 | PCB 발주 + 부품 실장 + 테스트 |

## 4. 리스크 및 대응

| 리스크 | 영향 | 대응 방안 |
|--------|------|----------|
| C2000 직접 경험 부족 | 초기 개발 지연 | TI Digital Power SDK 레퍼런스 활용, LAUNCHXL-F28379D로 선행 학습 |
| 전원 토폴로지 미경험 | 설계 품질 | TI 레퍼런스 디자인 기반 설계, 전력전자 전문가 자문 |
| 고전압 안전 | 시제품 테스트 위험 | 안전 장비/절차 수립, 단계별 전압 인가 |
| EMI/EMC | 인증 실패 | 초기부터 EMI 고려 설계, 전문 시험소 활용 |
| 상주 근무 | 자체 사업 병행 어려움 | 부분 원격 협의, 주 3일 상주 등 조건 조율 |
