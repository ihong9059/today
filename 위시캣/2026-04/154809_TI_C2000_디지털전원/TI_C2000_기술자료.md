# TI C2000 기술 자료 — 디지털 전원 개발용

## 1. C2000 MCU 개요

TI C2000은 실시간 제어에 최적화된 32비트 DSP 기반 마이크로컨트롤러 패밀리.
디지털 전원, 모터 제어, 신재생에너지 분야에서 업계 표준으로 사용됨.

## 2. 추천 MCU: TMS320F28379D

디지털 전원공급장치 개발에 가장 적합한 고성능 C2000 MCU.

### 주요 사양

| 항목 | 사양 |
|------|------|
| **아키텍처** | Dual-core C28x 32-bit CPU |
| **클럭** | 200 MHz (코어당) |
| **총 성능** | 800 MIPS |
| **Flash** | 1024KB (512KW), ECC 보호 |
| **RAM** | 204KB (102KW), ECC/패리티 |
| **PWM** | 24채널 (고해상도 16채널) |
| **ADC** | 4개, 16비트 (최대 4.4 MSPS) / 12비트 (최대 14 MSPS) |
| **DAC** | 3개, 12비트 |
| **CAN** | 2개 |
| **SPI** | 3개 |
| **UART** | 4개 |
| **I2C** | 2개 |
| **USB** | 2.0 (MAC + PHY) |
| **SDFM** | 8채널 (시그마-델타 필터) |
| **패키지** | 337-ball nFBGA / 176-pin HLQFP / 100-pin HTQFP |

### 디지털 전원 핵심 기능

- **고해상도 PWM (HRPWM)** — 150ps 분해능, 정밀한 듀티 제어
- **ADC 트리거 연동** — PWM과 동기화된 고속 샘플링
- **CLA (Control Law Accelerator)** — 독립 실시간 제어 루프 처리
- **CMPSS (Comparator Subsystem)** — 하드웨어 과전류/과전압 보호
- **SDFM** — 격리형 전류/전압 센싱
- **듀얼 코어** — 전원 제어 + 통신/모니터링 분리 운용

### 제품 페이지

https://www.ti.com/product/TMS320F28379D

## 3. C2000 Digital Power SDK

TI에서 제공하는 디지털 전원 전용 소프트웨어 개발 키트.

### 지원 전원 토폴로지

| 토폴로지 | 유형 | 설명 |
|----------|------|------|
| Totem-Pole PFC | AC-DC | 역률 보정 |
| LLC Resonant | DC-DC | 고효율 절연형 변환 |
| Phase-Shifted Full Bridge (PSFB) | DC-DC | 대전력 절연형 변환 |
| Half Bridge | DC-DC | 중전력 변환 |
| Synchronous Buck | DC-DC | 비절연형 강압 |
| Single/3-Phase Inverter | DC-AC | 인버터 |

### 핵심 도구

| 도구 | 기능 |
|------|------|
| **powerSUITE** | 디지털 전원 GUI 설계 도구 |
| **Solution Adapter** | 커스텀 HW 맞춤 코드 생성 |
| **Compensation Designer** | 폐루프 보상기 설계 |
| **SFRA** | 주파수 응답 분석 (안정성 검증) |

### SDK 페이지

https://www.ti.com/tool/C2000WARE-DIGITALPOWER-SDK

## 4. TI 레퍼런스 디자인 (이 프로젝트에 활용 가능)

### TIDM-02000: Phase-Shifted Full Bridge (PSFB)
- **입력**: 400V DC → **출력**: 12V DC
- **토폴로지**: 위상 편이 풀브릿지
- **용도**: 서버/통신 전원
- **활용**: iHP 모듈 내부 DC-DC 단 설계 참조
- https://www.ti.com/tool/TIDM-02000

### TIDM-02013: Bidirectional OBC (양방향 온보드 차저)
- **토폴로지**: Totem-Pole PFC + CLLLC DC-DC
- **제어**: 단일 C2000 MCU로 AC-DC + DC-DC 제어
- **활용**: iHP 전체 시스템 아키텍처 참조
- https://www.ti.com/tool/TIDM-02013

### TIDM-DC-DC-BUCK: Synchronous Buck Converter
- **토폴로지**: 동기 벅 컨버터
- **활용**: 저전압 출력 모듈 설계 참조
- https://www.ti.com/tool/TIDM-DC-DC-BUCK

### TIDA-010210: 기타 전원 레퍼런스
- https://www.ti.com/tool/TIDA-010210

## 6. iHP 국산화에 필요한 C2000 기능 매핑

| iHP 기능 | C2000 구현 방법 |
|----------|----------------|
| AC-DC PFC | Totem-Pole PFC (HRPWM + ADC 동기) |
| DC-DC 절연형 변환 | LLC 또는 PSFB (HRPWM + CMPSS) |
| 다중 출력 제어 | 듀얼코어: Core1=전원제어, Core2=통신 |
| 과전압/과전류 보호 | CMPSS 하드웨어 비교기 (나노초 응답) |
| RS485/CAN 통신 | 내장 SCI/CAN 모듈 |
| EtherCAT | 외부 ET1100 + SPI 또는 전용 칩 |
| GUI/원격 제어 | USB/Ethernet + PC 소프트웨어 |
| 고정밀 전압 제어 | 16비트 ADC + HRPWM (150ps) |
