[1. 스마트팩토리 MQTT 센서 모니터링 시스템 - 현장 운영 중] ★★★

제품: 공장 설비 실시간 모니터링 시스템
- IoT: ESP32 센서 노드 다수
- 통신: **MQTT** (센서 → Broker → 서버)
- 서버: **Node.js + Express**
- DB: **MariaDB/PostgreSQL**
- 프론트: 웹 대시보드 (Three.js 3D 모니터링)
- 상태: **현장 운영 중**

개발 내용:
- **MQTT Publish/Subscribe** 기반 실시간 센서 데이터 수집
- **WebSocket** 기반 실시간 웹 대시보드 업데이트
- Node.js + Express REST API 서버
- DB 설계 + 데이터 저장/조회/통계
- 기기 상태 모니터링 + 이벤트 알림
- 관리자 페이지 (설비 관리, 통계, 이벤트 로그)

→ 운동기구 제어의 IoT 통신(MQTT) + 서버 + 대시보드와 직접 매칭
