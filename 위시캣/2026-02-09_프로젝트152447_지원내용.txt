============================================================
지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

산업용 통신 및 제어 시스템 개발 38년 경력의 하드웨어/펌웨어 전문 팀입니다.
삼성전자, 파나소닉에서 다양한 Controller Board를 설계하였고,
대한전선에서 CAN/RS485 기반 산업용 WINDER CONTROLLER를 개발하였습니다.

본 프로젝트의 핵심인 '회로 설계부터 펌웨어 구현, 검증까지 턴키 수행'에
풍부한 경험을 보유하고 있으며, CAN FD 및 고속 신호 처리 회로 설계에
정확히 매칭되는 역량을 갖추고 있습니다.

============================================================
핵심 기술 스펙별 보유 역량
============================================================

[1. 산업용 통신 프로토콜]

- CAN 통신: 대한전선 WINDER CONTROLLER에서 CAN/RS485 기반 산업용 통신 설계
- RS485: 산업용 Motor Controller 시리얼 통신 다수 구현
- 고속 통신: SPI, UART, I2C 등 다양한 프로토콜 38년 경험
- EtherCAT: 산업용 Fieldbus 프로토콜 아키텍처 이해 (구현 학습 가능)

[2. 회로/PCB 설계 (턴키)]

- 임호균: PCB 회로도, Gerber 파일, BOM 리스트 작성 다수 경험
- 홍광선: PCB 설계 → 시제품 → 양산 전 과정 대응 가능
- 설계 경험:
  > Motor Controller Board (대한전선)
  > Video Controller Board (삼성전자)
  > Printer Controller Board (파나소닉)
  > LED Controller Board (유티즘)
  > IoT 센서 보드 다수

[3. CAN FD 및 고속 신호 처리]

- CAN 통신 설계 경험 (대한전선 WINDER CONTROLLER)
- 고속 신호 처리 회로 설계 (Motor Controller, Video Controller)
- EMI/EMC 대응 설계 경험
- 다채널 통신 동시 처리 (4포트 변환 대응 가능)

[4. 펌웨어 개발 (C/C++)]

- ARM Cortex-M 기반 MCU 펌웨어 다수 개발
- RTOS 기반 실시간 제어 시스템 구현 경험
- 상태 머신 설계 및 구현 전문
- 삼성전자, 파나소닉 양산급 펌웨어 개발 경력

[5. DC 동기화 / 실시간 제어]

- 산업용 Motor Controller 동기 제어 경험
- PWM 기반 정밀 타이밍 제어 (ms/us 단위)
- 다중 타이머 동기화 설계 경험
- PLC 연동 실시간 제어 시스템 구축

[6. MCU/칩셋 설계]

- 임호균: ARM CPU 설계 전문가 (삼성전자, AuthenTec, QuickLogic)
- FPGA 설계 경험 (QuickLogic Corp.)
- ASIC 설계 경험 (AuthenTec - 지문인식 디바이스)
- 다양한 MCU 플랫폼 경험 (ARM, DSP, CISC, RISC)

============================================================
세부 업무별 대응 역량
============================================================

[Board 1: EtherCAT to CAN FD 통신 컨버터 (신규)]

- 4포트 CAN FD 변환  --> CAN 통신 설계 경험, 다채널 처리 가능
- DC 동기화 (Sync0)  --> 산업용 동기 제어 시스템 설계 경험
- 양방향 중계 (PDO↔CAN FD) --> 프로토콜 변환 로직 설계 가능
- 회로/PCB 설계     --> PCB Gerber/BOM 턴키 대응

[Board 2: DIO 보드 (EtherCAT 전환)]

- 기존 통신부 전환   --> 레거시 시스템 마이그레이션 경험
- Digital I/O 제어  --> GPIO 제어 38년 경험
- 펌웨어 수정       --> 기존 코드 분석 및 수정 가능

[Board 3: DAQ 보드 (EtherCAT 전환)]

- 데이터 수집 시스템 --> 센서 데이터 수집 시스템 25개 현장 운영
- ADC/DAC 제어     --> 아날로그 신호 처리 경험
- 고속 샘플링       --> 실시간 데이터 처리 시스템 구축 경험
