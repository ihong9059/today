# 위시캣 프로젝트 지원 이력 관리

위시캣 플랫폼에서의 프로젝트 탐색, 지원서 작성, 미팅 준비 등 지원 활동 전반을 관리하는 폴더.

## 폴더 구조

```
위시캣/
├── 2026-02/                    # 2월 활동
│   ├── YYYY-MM-DD_가능프로젝트.md      # 일별 지원 가능 프로젝트 목록
│   └── YYYY-MM-DD_프로젝트XXXXX_지원내용.txt  # 개별 프로젝트 지원서
├── 2026-03/                    # 3월 활동
│   ├── 가능프로젝트.md (일별)
│   ├── 지원내용.txt (프로젝트별)
│   └── Actuator_정보_제공_시스템_개발안.pdf  # 기술 제안서
├── 2026-04/                    # 4월 활동
│   ├── 가능프로젝트/                   # 일별 프로젝트 목록 (하위 폴더로 정리)
│   ├── 154362_레거시코드/              # 지원 프로젝트별 폴더
│   ├── 154780_PVDF_층간소음/           #   - 지원서, 미팅준비, 개발계획서 포함
│   ├── 154806_BLE출입통제/
│   ├── 154809_TI_C2000_디지털전원/
│   └── ...
└── ref/                        # 참고 자료
    ├── 이력서_홍광선.pdf
    ├── 경력서 - 임호균.pdf
    ├── 보유기술.pdf / 보유기술_jpg.png
    ├── prompt.txt                      # 지원서 작성 프롬프트 템플릿
    └── 기술 참고 문서 (md)
```

## 주요 내용

### 일별 가능 프로젝트 탐색 (`가능프로젝트.md`)
- 위시캣에 새로 올라온 프로젝트를 날짜별로 스캔
- 파트너 보유 역량(임베디드, IoT, 회로설계 등)과 매칭하여 지원 가능 여부 판별
- 마지막 검토 프로젝트 ID를 기록하여 다음 검색 시 이어서 조회

### 프로젝트 지원서 (`지원내용.txt`)
- 프로젝트별 기술 스펙 매칭표, 지원 사유, 관련 경력 요약
- 핵심 역량: ARM/MCU 펌웨어, CAN/RS485/BLE 통신, PCB 회로설계, RTOS, 센서 신호처리

### 프로젝트별 폴더 (4월~)
- 지원이 진행된 프로젝트는 개별 폴더로 관리
- 지원서, 추가 답변, 미팅 준비 자료, 개발계획서 등 포함

### 참고 자료 (`ref/`)
- 프리랜서/파트너 이력서 및 보유기술 목록
- 지원서 작성용 프롬프트 템플릿
- 프로젝트 관련 기술 참고 문서

## 운영 방식

1. 매일 위시캣 신규 프로젝트 확인 -> `가능프로젝트.md` 작성
2. 매칭되는 프로젝트 발견 시 -> `지원내용.txt` 작성하여 지원
3. 미팅/계약 진행 시 -> 프로젝트별 폴더에 관련 문서 축적
