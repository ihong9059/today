- **금액**: 6,000,000원
- **기간**: 30일
- **마감**: 2026-04-07
- **위치**: 서울 금천구

**필요 기술**: SMPS 전원공급장치 회로/PCB 설계, Altium/PADS/OrCAD, SMT 샘플 제작 및 디버깅

**과업 범위**:
1. 75W급 소방전원공급장치 신규 모델 개발

**산출물**: 회로도, PCB 아트웍(Gerber), BOM, 시제품 6대, 테스트 리포트

- **금액**: 협의 후 결정
- **기간**: 90일
- **마감**: 2026-04-08
- **지원자**: 4명

**필요 기술**: STM32F, C/C++, OrCAD/Altium, RS485, PID 제어, SPI OLED

**과업 범위**:
1. STM32 MCU 기반 제어 회로 및 Actuator Driver 설계
2. +24VDC/±15VDC 입력 처리 (D-SUB 09P Male)
3. Pressure Sensor, 4-20mA/0-5Vdc 입출력 회로
4. PCB 규격: 110mm × 70mm
5. RS485 Serial 프로토콜 적용
6. SPI OLED Driver 포팅 및 UI 구현
7. PID Control Valve 알고리즘 + Auto PID 구현
8. Analog In/Out 신호 변환 처리

**산출물**: 회로도/PCB 아트웍(Gerber), BOM, 펌웨어 소스코드, 시제품 보드
