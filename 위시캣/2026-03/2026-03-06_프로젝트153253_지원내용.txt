지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

에너토크 "Actuator 정보 제공 시스템" 개발안을 상세히 검토하였습니다.

**nRF52832 BLE 기반 IoT 컨트롤러를 국내 양산 판매 중**이며,
BLE GATT 프로토콜, Hex Data(바이트 배열) 처리,
산업용 장비 제어 시스템을 40년간 전문으로 개발해왔습니다.

본 프로젝트의 핵심 기능인:
- BLE GATT 기반 Actuator 연결 및 제어
- 동작 명령 (Open/Close/Stop) 송신
- 상태 정보 (토크, 각도) 수신
- MES 서버 연동 (완제품 성적서, 대리점 정보)
- API Gateway 및 REST API 구현

위 기술들은 당사가 양산 제품에서 직접 구현하여 운영 중인 기술입니다.

특히 "Hex Data(Byte array) 처리에 능숙한 개발자" 요구사항은
임베디드 펌웨어 38년 경력으로 가장 강점인 분야입니다.

모바일 앱은 Flutter/React Native 협력 개발자와 함께 진행하며,
BLE 통신 프로토콜 설계 및 미들웨어 서버 개발을 담당하겠습니다.

- MCU: STM32F756 + FreeRTOS
- 통신: RS485, Modbus
- 역할: 펌웨어 전체 개발

기술 스택
============================================================

[BLE/무선통신 - 핵심 역량]
- BLE: nRF52832 GATT 프로토콜, 양산 경험
- LoRaWAN: 게이트웨이/노드 개발 (SX1276/78)
- Zigbee: IEEE 802.15.4, 메쉬 네트워크
- WiFi: ESP32 기반 IoT

[MCU/임베디드]
- Nordic: nRF52 시리즈 (BLE)
- STM32: F4/F7 시리즈 양산 경험
- ARM Cortex-M: M0/M3/M4/M7
- FreeRTOS: 양산 경험 다수

[산업용 통신]
- EtherCAT: 컨트롤러 양산
- CAN/CANopen: 산업용 장비
