SOM 기반 베이스보드 설계부터 시제품 제작까지 전 과정을 수행할 수 있습니다.

본 프로젝트의 핵심인:
- **Compute Module 기반 베이스보드 설계** → 이더캣 컨트롤러(CM4) 양산 경험
- **NXP i.MX 계열 AP** → ARM Cortex-A 프로세서 인터페이스 설계 경험
- **LVDS LCD 인터페이스** → 고속 차동 신호 설계 경험
- **회로도/PCB/BOM/시제품** → 5종 이상 양산 제품 직접 개발

위 기술들은 당사가 직접 양산 제품에서 구현하여 운영 중입니다.

특히 **Compute Module 4 기반 이더캣 컨트롤러**를 자체 설계/양산 판매 중이며,

LVDS/SMARC 인터페이스 기술 역량
============================================================

[LVDS (Low-Voltage Differential Signaling)]

특징:
- 저전압 차동 신호 방식
- 고속 데이터 전송 (수백 MHz)
- 낮은 EMI, 긴 전송 거리

설계 경험:
- 고속 신호 PCB 레이아웃
- 차동 임피던스 제어 (100Ω)
- LCD 패널 연결 설계

적용 방안:
┌─────────────────────────────────────────────────────────────┐
│  [NXP i.MX AP] ─LVDS─► [LVDS 커넥터] ─FFC─► [LCD 패널]     │
│                                                             │
│  설계 포인트:                                               │
│  1. AP의 LVDS 출력 핀 확인                                  │
│  2. LVDS 송신기 IC 필요 여부 검토                           │
│  3. FFC/FPC 커넥터 선정                                     │
│  4. 임피던스 매칭 PCB 설계                                  │
│  5. EMI 대책 (차폐, GND 설계)                               │
└─────────────────────────────────────────────────────────────┘

[SMARC (Smart Mobility ARChitecture)]

특징:
- 산업용 표준 SOM 폼팩터
- 314-pin MXM3 커넥터
- 다양한 AP 지원 (NXP, TI, Qualcomm 등)

설계 경험:
- Compute Module 4: 200-pin 고밀도 커넥터
- Board-to-Board 커넥터 설계
- 전원 시퀀싱, 고속 신호 라우팅

SMARC 베이스보드 설계 접근:
┌─────────────────────────────────────────────────────────────┐
