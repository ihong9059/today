지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

"환자 ECG 데이터 수집 및 서버 전송 시스템" 프로젝트를 검토하였습니다.

본 프로젝트의 핵심인 **라즈베리파이 기반 다중 BLE 디바이스 데이터 수집 게이트웨이**는
당사가 보유한 기술과 정확히 일치합니다.

1) **Raspberry Pi 양산 경험**: CM4 기반 EtherCAT 컨트롤러를 개발하여
   국내 양산 판매 중이며, Pi3 기반 V-Cut 컨트롤러는 중국 수출 중입니다.

2) **BLE 양산 경험**: nRF52832 기반 BLE 온도 컨트롤러를 개발하여
   국내 양산 판매 중이며, BLE 프로토콜 스택에 대한 깊은 이해를 보유하고 있습니다.

3) **다중 디바이스 실시간 데이터 수집**: EtherCAT 컨트롤러에서
   다축 모터/센서를 실시간 동기 수집하는 시스템을 양산 운영 중이며,
   스마트팩토리에서 다중 센서 모니터링 시스템을 납품 운영 중입니다.

특히 **BLE + Raspberry Pi + 서버 전송**이라는 3가지 핵심 기술을
모두 양산 제품에서 직접 구현한 경험이 있어,
안정적이고 검증된 시스템 개발이 가능합니다.

관련 실무 경험
============================================================

[1. nRF52832 BLE 컨트롤러 - 국내 양산 판매 중] ★최핵심

제품: BLE 기반 무선 온도 센서/컨트롤러
- MCU: Nordic nRF52832
- 통신: BLE (Bluetooth Low Energy)
- 역할: 회로설계 → 펌웨어 → 양산 턴키
- 상태: 국내 양산 판매 중

개발 내용:
- BLE GATT 프로파일 설계 및 구현
- BLE Advertising/Connection 관리
- 센서 데이터 수집 및 BLE 전송
- 저전력 설계 (배터리 구동)
- BLE Central/Peripheral 모드 구현

프로젝트 연관성:
- ECG 디바이스의 BLE 통신 프로토콜과 동일한 기술
- 다중 BLE 디바이스 연결 시 Connection 관리 노하우 보유
- BLE 데이터 패킷 설계 및 처리 경험

[2. EtherCAT 컨트롤러 (CM4 기반) - 국내 양산 판매 중] ★핵심

제품: 산업용 다축 모션 컨트롤러
- SBC: Raspberry Pi CM4
- OS: Raspberry Pi OS (Linux)
- 통신: EtherCAT (산업용 이더넷)
- 역할: 전체 시스템 개발 (HW+SW)
- 상태: 국내 양산 판매 중

개발 내용:
- Raspberry Pi OS 기반 임베디드 소프트웨어 개발
- 다축 모터/센서 실시간 동기 데이터 수집
- Linux 디바이스 드라이버 연동
- 네트워크 통신 (TCP/IP) 기반 서버 연동
- 시스템 안정성 확보 (워치독, 에러 복구)

프로젝트 연관성:
- Raspberry Pi OS 기반 개발 환경 동일
- 다중 디바이스 실시간 데이터 수집과 동일한 아키텍처
- 서버 전송 시스템 직접 구현 경험

[3. V-Cut 컨트롤러 (Pi3 기반) - 중국 수출]

제품: PCB V-Cut 2축 제어기
- SBC: Raspberry Pi 3
- 통신: Wi-Fi, 시리얼
- 역할: 전체 시스템 개발
- 상태: 중국 수출 중

개발 내용:
- Raspberry Pi 기반 2축 모터 제어
- Wi-Fi 기반 원격 모니터링
- 웹 인터페이스 개발

프로젝트 연관성:
- Raspberry Pi + Wi-Fi 조합 양산 경험
- 원격 데이터 전송 시스템

[4. 스마트팩토리 센서 모니터링 - 한국타이어 등 납품 운영 중]

제품: B2B 스마트팩토리 IoT 솔루션
- URL: https://uttec-sensor.duckdns.org/demo/hankook/
- 역할: 전체 시스템 설계/개발
- 상태: 납품 운영 중

개발 내용:
