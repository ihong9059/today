============================================================
지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

"PIO Type MFC 제어 보드 및 펌웨어 개발" 프로젝트를 검토하였습니다.

본 프로젝트의 핵심 기술인 **STM32 + PID 제어 + RS485 + 회로/PCB 설계 +
4-20mA 산업용 신호 처리**는 당사가 양산 제품에서 직접 구현하여
현재 운영 중인 기술과 정확히 일치합니다.

특히 **컴프레샤 컨트롤러**(STM32F756 + FreeRTOS)에서:
- PID 밸브 제어 (비례/Open/Close)
- RS485/Modbus 통신
- 압력/온도 센서 4-20mA 아날로그 입력
- 실시간 모니터링 및 알람

위 기능들을 양산 제품으로 개발하여 국내 판매 중이며,
MFC 프로젝트에서 요구하는 기술과 거의 동일한 구조입니다.

또한 **회로설계 25년 + 펌웨어 40년** 경력으로
회로도 → PCB → 펌웨어 → 시제품까지 턴키 개발이 가능하며,
5개 이상의 양산 제품을 통해 검증된 품질을 보장합니다.

관련 실무 경험

[1. 컴프레샤 컨트롤러 - 국내 양산 판매 중] ★최핵심 (MFC와 구조 동일)

제품: 산업용 컴프레샤 제어 시스템
- MCU: STM32F756 + FreeRTOS
- 통신: RS485 (Modbus RTU)
- I/O: 4-20mA 압력센서, 아날로그 출력
- 역할: 회로설계 → PCB → 펌웨어 → 양산 턴키
- 상태: 국내 양산 판매 중

개발 내용:
- PID 밸브 제어 (비례제어/Open/Close)
- 압력/온도 센서 4-20mA 아날로그 입력 처리
- RS485 Modbus RTU 프로토콜 구현
- 디스플레이 구동 (상태 표시, 설정값)
- 알람/에러 핸들링 및 데이터 로깅

MFC 프로젝트 연관성:
- PID Control Valve → 컴프레샤 PID 밸브 제어와 동일
- 4-20mA/0-5Vdc I/O → 압력센서 아날로그 처리와 동일
- RS485 Protocol → Modbus RTU 구현 경험 직접 활용
- Actuator Driver → 밸브/모터 드라이버 회로 설계 경험

[2. 세탁기 컨트롤러 - 빨래방 납품 양산 중]

- 역할: 회로설계 → PCB → 펌웨어 → 양산 턴키
- 상태: 국내 빨래방 납품 양산 중

개발 내용:
- 모터/밸브 시퀀스 제어
- 디스플레이 구동 (7세그먼트, LCD)
- 센서 기반 자동 제어
- 전원부 설계 (24V 입력)

MFC 프로젝트 연관성:
- STM32F4 시리즈 양산 검증 경험
- 밸브/모터 구동 회로 설계
- 전원부 설계 (+24VDC 입력 처리)

[3. EtherCAT 컨트롤러 - 국내 양산 판매 중]

MFC 프로젝트 연관성:

강점
============================================================

1. MFC와 동일 구조의 양산 제품 보유
   - 컴프레샤 컨트롤러: STM32 + PID + RS485 + 4-20mA
   - MFC 프로젝트 요구사항과 거의 1:1 매칭
   - 양산 검증된 코드/회로 기반으로 빠른 개발 가능

2. 회로 → PCB → 펌웨어 → 시제품 턴키 개발
   - 회로설계 25년 + 펌웨어 40년
   - 분업 없이 HW/SW 일관된 설계
   - HW 문제를 FW로, FW 문제를 HW로 유연하게 해결

3. RS485 + 4-20mA 산업용 통신/신호 양산 전문
   - 컴프레샤/세탁기/EtherCAT 등 양산 제품에서 검증
   - 노이즈 대책, 신호 무결성 확보 노하우

4. PID 제어 양산 경험
   - 컴프레샤 압력 PID 제어 양산 중
   - 대한전선 WINDER 장력 PID 제어 경험
   - Auto PID Tuning 구현 가능

5. 5개 이상 양산 제품 운영 실적
   - EtherCAT, V-Cut, 컴프레샤, 세탁기, BLE 컨트롤러
   - 시제품 → 양산 전환 프로세스 숙련
