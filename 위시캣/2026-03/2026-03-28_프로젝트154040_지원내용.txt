안녕하세요. 홍광선입니다.

"모드버스 TCP/IP 데이터 수집 및 통신" 프로젝트를 검토하였습니다.

당사는 **Modbus RTU/TCP 프로토콜을 양산 제품에 직접 구현**하여
현재 국내에서 판매 중입니다. 모드버스는 산업 현장에서 가장 많이
사용하는 통신 프로토콜이며, 당사의 핵심 기술 영역입니다.

특히:
- 컴프레샤 컨트롤러에서 Modbus RTU/TCP를 직접 구현하여 양산 중
- Python 기반 TCP/IP 데이터 수집 시스템을 스마트팩토리에서 운영 중
- FreeRTOS 기반 멀티스레드/프로세스 환경에서 38년간 개발

기존 운영 중인 프로그램의 유지보수/기능 추가 업무이므로,
기존 코드 분석 → 문제 파악 → 개선의 접근이 가능합니다.
