지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

임베디드 시스템 개발 38년 경력의 펌웨어 전문가입니다.
삼성전자에서 STB/디지털TV 개발을 시작으로, 파나소닉 LCD Controller,
유티즘 스마트팩토리 IoT 시스템까지 다양한 MCU 펌웨어를 개발해왔습니다.

본 프로젝트의 핵심인 'STM32F4 기반 센서 제어 및 통신 펌웨어'에
정확히 매칭되는 기술 역량을 보유하고 있으며, 2주 내 개발 완료라는
일정 요구사항을 충족할 수 있습니다.

============================================================
핵심 기술 스펙별 보유 역량
============================================================

[1. STM32/ARM MCU 개발]

- ARM7/ARM9/Cortex-M 기반 펌웨어 다수 개발
- STM32CubeMX, STM32CubeIDE, HAL 라이브러리 활용 경험
- 삼성전자 Digital STB: ARM 기반 Set-Top Box 펌웨어
- 유티즘: ARM 기반 IoT 센서 컨트롤러 개발

[2. 타이머 및 PWM 제어]

- TIM2/TIM3/TIM4/TIM5 다중 타이머 활용 경험
- PWM 기반 Motor Controller 개발 (대한전선 WINDER)
- PWM 기반 LED Controller 개발 (유티즘)
- 온도 제어 시스템 PID 구현 경험

[3. 통신 인터페이스 (UART/SPI/GPIO)]

- UART: RS232/RS485 산업용 통신 다수 구현
- SPI: 센서 데이터 고속 전송, FPGA 인터페이스 경험
- I2C: 센서 10종 연동 (AHT20, BMP280, MPU6050 등)
- GPIO: 디지털 I/O 제어, 인터럽트 처리

[4. 상태 머신 설계]

- 산업용 장비 상태머신 다수 설계 경험
- IDLE/INIT/RUNNING/ERROR/CALIBRATION 등 복잡한 상태 전이 구현
- 에러 핸들링 및 복구 로직 설계

주요 경력 (프로젝트 관련 우선)
============================================================

[MCU/펌웨어 관련]

1. 삼성전자 - Digital Set-Top Box (1993~1999)
   - ARM 기반 STB 펌웨어 개발
   - Audio/Video Controller, CD/DVD Player Controller
   - UCC Printer Controller, ReelCool Digital STB

2. 파나소닉 교환파견 (1999~2005)
   - LCD/I/O Printer Controller 개발
   - ARM7 기반 시스템 설계

3. 유티즘 - 스마트팩토리 IoT (2014~현재)
   - ARM 기반 센서 컨트롤러 개발
   - Zigbee/LoRaWAN/BLE 통신 모듈 개발 및 양산
   - Motor Controller, LED Controller 설계
   - PWM 기반 전력 제어 시스템

4. 대한전선 - WINDER CONTROLLER (임호균)
   - Motor Controller 펌웨어 (RS485 통신)
   - 산업용 장비 제어 시스템

[센서/IoT 관련]

5. raspShield - IoT 센서 통합 모니터링
   - Raspberry Pi 기반 10종 센서 실시간 제어
   - I2C/SPI 센서 드라이버 직접 구현
   - GitHub: https://github.com/ihong9059/raspShield

6. 스마트팩토리 센서모니터링 시스템
   - 25개 현장 실시간 센서 데이터 수집
   - 데모: https://uttec-sensor.duckdns.org/demo/hankook/
