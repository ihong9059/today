프로젝트 핵심 이해
============================================================

본 프로젝트는 **이미 운영 중인 IoT 플랫폼**의 기능을 확장
하는 사업입니다. 신규 개발과 본질적으로 다른 다음 4가지
요구를 충족해야 합니다.

(1) **기존 시스템 무중단 확장** — 운영 중인 사용자 / 데이터
    를 유지하면서 기능 추가. 회귀 위험 최소화 + 마이그
    레이션 안전성

(2) **크로스 플랫폼 모바일 (Flutter)** — Android / iOS
    동시 지원으로 운영 부담 최소화. 기존 사용자 UX 일관성
    유지

(3) **실시간 데이터 연동 (IoT 디바이스 ↔ 서버 ↔ App)** —
    IoT 도메인 고유의 통신 지연 / 끊김 / 재연결 / 시계열
    동기화 처리

(4) **관리자 기능 (Web 관제 + 권한·인증·감사 로그)** —
    서비스형 플랫폼의 운영 안정성을 위한 핵심 인프라

당사는 **IoT 무선 제어 사업 10년 양산 운영 + Flutter
4개 앱 양산 + Node.js·Python 풀스택 양산 + 양산 제품 5개
유지보수 운영 중**이므로 본 프로젝트의 "기존 시스템 확장"
영역에 직접 적용 가능한 자산을 모두 보유하고 있습니다.

지원 사유
============================================================

안녕하세요. 본 프로젝트는 **단순 SW 외주가 아닌 "기존 IoT
플랫폼의 무중단 기능 확장"**이라는 IoT 도메인 특수 영역
입니다. 당사는 본 영역에 다음 3가지 차별점을 제공합니다.

(1) **10년 IoT 운영 자산 — 양산 제품 5개 동시 유지보수
    중** — 신규 개발 외주가 아닌 "운영 중 시스템 확장"
    경험이 양산 검증되어 있습니다. 운영 중 마이그레이션 /
    회귀 위험 / 사용자 단절 위험을 실제 양산 환경에서
    다루어 왔습니다.

(2) **Flutter + Node.js + Python 필수 스택 모두 양산** —
    Flutter 4개 앱 양산 (BLE + 카메라 + 센서 + AI API
    통합), Node.js 양산 (영업관리 + 학습 앱 + 데모 25개),
    Python 양산 (Flask + FastAPI + AI 모델 + 자동화 cron).
    스택 학습 비용 없이 즉시 투입.

(3) **IoT 도메인 + 풀스택 동일 팀 한 사이클** — 일반 SW
    외주는 IoT 디바이스 측 변경이 필요할 때 외부 협력사
    의존이 발생합니다. 당사는 HW(BLE Mesh 3,800대 양산) +
    FW(KC 인증 양산) + App(Flutter 4개) + Server(Node /
    Python) + 인증(KC + TELEC + CE) 전체 사이클을 한 팀
    (2인)이 자체 수행하여 의사소통·일정·책임 분담 위험
    최소화.

추가 보너스: **AI 통합 자산** — Claude / GPT / Gemini /
Groq LLM API + AI 모델 양산. 본 프로젝트의 향후 AI 기능
확장 시 즉시 적용 가능합니다.

본 프로젝트는 **IoT 운영 자산 + 필수 스택 양산 + 풀스택
한 팀 + AI 보너스**의 4중 차별점으로 90일 안에 안전한
기능 확장을 보장할 수 있는 영역입니다.
