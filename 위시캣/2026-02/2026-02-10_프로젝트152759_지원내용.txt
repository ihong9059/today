지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

**CAN 통신 기반 산업용 제어 시스템을 38년간 개발**해왔습니다.
대한전선에서 CAN/RS485 기반 WINDER CONTROLLER를 설계하였고,
현재 5개 양산 제품에서 RS485/인버터 통신을 사용 중입니다.

회로설계 25년, 임베디드 하드웨어/펌웨어 전문으로
CAN 프로토콜 구조와 MCU-PC 통신 아키텍처를 깊이 이해하고 있습니다.

C++ 기반 PC 프로그램 개발로 본 프로젝트 수행이 가능합니다.

============================================================
CAN 통신 관련 경험
============================================================

[1. 대한전선 - WINDER CONTROLLER]

제품: FLOTTER/FLYER WINDER 제어 시스템
- 통신: CAN, RS485 기반 산업용 Motor Controller
- MCU: ARM 기반 임베디드 시스템
- 역할: 회로설계 → 펌웨어 → 양산 턴키

개발 내용:
- CAN 프로토콜 설계 및 구현
- 다중 노드 CAN 네트워크 구성
- 실시간 데이터 송수신 처리
- 오류 검출 및 재전송 로직 구현

[2. 컴프레샤/세탁기 컨트롤러 - 양산 판매 중]

제품: 산업용 컨트롤러 (STM32F756, STM32F407)
- 통신: RS485, 인버터 통신
- OS: FreeRTOS (멀티태스크)
- 상태: 국내 양산 판매 중

개발 범위:
- 회로설계 (100%): OrCAD, EasyEDA
- PCB Artwork (100%)
- 펌웨어 (100%): C++, FreeRTOS
- 시리얼 통신 프로토콜 설계 및 구현

[3. EtherCAT 컨트롤러 - 양산 판매 중]

제품: 축 컨트롤 보드 (Raspberry Pi CM4 기반)
- 통신: Gbit LAN (EtherCAT), RS485
- 용도: 다축 모션 제어
- 상태: 국내 양산 판매 중

개발 범위:
- 회로설계 (100%): EasyEDA
- PCB Artwork (100%)
- 펌웨어 (50%): C++ (Linux OS)
- 통신 프로토콜 구현
