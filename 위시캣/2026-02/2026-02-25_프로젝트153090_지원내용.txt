지원 사유
============================================================

안녕하세요. UTTEC의 홍광선입니다.

**nRF52832 기반 BLE 온도 컨트롤러를 국내 양산 판매 중**입니다.
LoRaWAN 게이트웨이/센서 노드 개발, Zigbee 통신 시스템까지
IoT/무선통신 펌웨어를 40년간 전문으로 개발해왔습니다.

스마트팩토리 센서 모니터링 시스템을 직접 운영 중이며,
저전력 배터리 기반 IoT 장비 양산 경험이 다수 있습니다.

본 프로젝트의 핵심인 nRF52 + LoRa/LTE 무선통신 폴백,
저전력 모드 구현, MQTT 서버 연동 모두 직접 경험한 분야입니다.

============================================================
nRF/BLE 관련 실무 경험
============================================================

[1. nRF52832 BLE 온도 컨트롤러 - 국내 양산 판매 중]

제품: BLE 기반 무선 온도 센서/컨트롤러
- MCU: Nordic nRF52832
- 통신: BLE (Bluetooth Low Energy)
- 역할: 회로설계 → 펌웨어 → 양산 턴키
- 상태: 국내 양산 판매 중

개발 내용:
- nRF52 SDK 기반 펌웨어 개발
- BLE GATT 프로토콜 구현
- 저전력 슬립 모드 최적화
- 센서 데이터 수집 및 BLE 전송
- 배터리 수명 최적화 설계

[2. LoRaWAN 게이트웨이/센서 노드 - 유티즘]

제품: 스마트팜/공장자동화용 LoRa 통신 시스템
- 통신: LoRaWAN (장거리 저전력 무선)
- 역할: 게이트웨이/노드 펌웨어 전체 개발
- 분야: 노지 스마트팜, 공장자동화

개발 내용:
- LoRa 모듈 드라이버 개발 (SX1276/SX1278)
- LoRaWAN 프로토콜 스택 구현
- 장거리 통신 (수 km) 안정성 확보
- 저전력 wake-up 및 sleep 모드 설계
- 게이트웨이-서버 MQTT 연동

[3. Zigbee 센서 네트워크 - 유티즘]

제품: 빌딩/공장 환경 모니터링 시스템
- 통신: Zigbee (IEEE 802.15.4)
- 구성: 다중 노드 메쉬 네트워크
- 역할: 펌웨어 개발 (Coordinator/Router/End Device)

개발 내용:
- Zigbee 스택 포팅 및 커스터마이징
- 메쉬 네트워크 라우팅 구현
- 센서 데이터 수집/전송
- 저전력 End Device 설계
