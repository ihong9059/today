## 핵심 기술 스펙별 보유 역량

### 1. CAN 통신 / CCP / XCP / DDLI

| 항목 | 상세 경험 |
|------|-----------|
| **CAN 통신 설계** | 대한전선 FLOTTER/FLYER WINDER CONTROLLER - CAN 기반 산업용 제어 시스템 설계 |
| **차량 통신 프로토콜** | Motor Controller 시리얼 통신 (CAN/RS485) 구현 경험 |
| **관련 경험** | 공장자동화 시스템에서 다중 장비 간 CAN 버스 통신 구축 |

### 2. FreeRTOS / RTOS

| 항목 | 상세 경험 |

| **멀티태스킹** | 실시간 데이터 수집 + 통신 + 제어 동시 처리 시스템 구현 |
| **Wakeup/Sleep** | 저전력 모드 및 시나리오 기반 Wakeup 로직 설계 경험 |

| **SPI/XSPI 통신** | SPI/I2C 기반 외부 메모리 제어 펌웨어 개발 |
| **SD카드 저장** | 데이터 로깅 시스템 구현 (파일시스템 + 저장 로직) |

| **부트로더** | Flash 메모리 기반 펌웨어 업데이트 로직 구현 |

## 주요 경력

### 1. 대한전선(대한로체) - CAN 통신 관련
- **FLOTTER/FLYER WINDER CONTROLLER 설계**
- CAN/RS485 시리얼 통신 구현
- 산업용 장비 제어 시스템 개발

### 2. 삼성전자 / 파나소닉 - RTOS 관련
- Video Desk Controller, Motor Controller Board 설계
- **RTOS 기반 Audio/Video 시스템 펌웨어 개발**
- LCD/I/O Printer Controller 개발

### 3. 유티즘 - Bluetooth 관련
- **BLE/Zigbee/LoRaWAN 통신 모듈 개발 및 양산**
- 스마트 IoT 시스템, 공장자동화 스마트 시스템

### 4. 세주테크놀로지 - 펌웨어 업데이트 관련
- Digital Set-Top Box, Digital Cable STB(IRDM) 개발
- **펌웨어 업데이트 시스템 개발**

### 5. AuthenTec Corp. (미국)
- ARM CPU 설계, 지문인식 디바이스 ASIC 개발
- 임베디드 펌웨어 (C/Assembler)

### 6. QuickLogic Corp. (미국)
- FPGA 설계, 하드웨어 인터페이스 개발

## 강점

1. **CAN 통신 전문가**
   - 대한전선 WINDER CONTROLLER에서 **CAN/RS485 통신 기반 산업용 제어 시스템** 설계
   - CCP/XCP 등 차량 진단 프로토콜 대응 가능

2. **RTOS 개발 38년 경력**
   - 삼성전자, 파나소닉 등에서 **RTOS 기반 임베디드 시스템** 다수 개발
   - FreeRTOS cmsis2 환경 즉시 적응 가능

3. **Bluetooth 모듈 양산 경험**
   - 유티즘에서 **BLE 통신 모듈 설계부터 양산까지 턴키** 수행

4. **Flash/메모리 인터페이스 설계**
   - SPI/XSPI 기반 외부 Flash 제어 경험 다수
   - FMC 인터페이스 PCB 설계 경험

5. **펌웨어 업데이트 시스템 개발**
   - 셋톱박스 OTA 업데이트 시스템 구축 경험

6. **장기 프로젝트 대응 가능**
   - 10개월 상주 근무 가능
   - 60+ 프로젝트 양산/품질 대응 경험
