============================================================
프로젝트 핵심 이해
============================================================

본 프로젝트는 화장품 제조공장의 핵심 설비에서 발생하는 센서
데이터를 수집하고, AI 모델을 통해 이상 징후를 사전에 탐지하는
"예지보전(Predictive Maintenance)" 기능을 기 운영중인 Spring
Boot MES에 추가하는 작업입니다.

핵심 도전 영역 (사전 분석 결과):

(1) **이종 PLC 통합** — LS산전, Cimon, 중국산 PLC가 혼재하는
    공장 환경에서 통일된 데이터 수집 채널 구축
    → 각 PLC의 통신 프로토콜(LS XGT/Modbus, Cimon Tag, 중국산
      Modbus TCP/RTU) 매핑 + 마스터 게이트웨이 설계 필요

(2) **MES ↔ AI 서버 파이프라인** — Spring Boot 기존 MES와
    Python AI 서버 사이의 양방향 데이터 흐름 설계
    → 실시간 센서 데이터 수집 (Python) → 분석 → 이상 알람
       (MES 콘솔로 송신) 양방향 흐름

(3) **데이터 부족 환경의 AI 모델 학습** — 이상 감지 데이터
    미존재 → 2~3개월 정상 운영 데이터 수집 후 학습 필요
    → 1차 단계는 데이터 수집 + 통계 기반 임계값 + 룰 기반
      이상 탐지, 2차 단계에서 ML 모델 학습 전환이 합리적

(4) **공장 안정성 유지** — 운영중 MES이므로 무중단 통합 필수
    → 별도 데이터 수집 경로 + Read-only 인터페이스 + 단계별
      Roll-out 전략 필요

당사는 위 네 영역 모두 공장자동화 양산 + 데이터 파이프라인
운영 + AI 모델 실전 구현 경험으로 직접 대응 가능합니다.

직접 연결됩니다.

(1) **공장자동화 38년 + 이종 PLC 양산 경험** — 협업자 임호균은
    삼성전자 Video/Motor Controller, AuthenTec(미국) ARM ASIC,
    QuickLogic FPGA, 대한전선 WINDER CONTROLLER(CAN/RS485)를
    거쳐 공장자동화 분야 38년 경력입니다. EtherCAT 컨트롤러,
    RS-485 Modbus RTU 컴프레서 밸브 컨트롤러, V-Cut 컨트롤러를
    국내 양산 + 중국 수출 중이며, 이종 PLC 환경에서의 통신
    프로토콜 매핑 / 마스터-슬레이브 통합 / 데이터 무결성
    검증을 다수 양산에서 검증했습니다.

(2) **데이터 파이프라인 + 클라우드 운영 자산** — 농업 IoT
    프로젝트 REVITA(RAK4630 + LTE + MQTT + Zephyr RTOS)에서
    센서 → LTE 클라우드 → 명령 수신 → 액추에이터 제어의
    24/7 파이프라인을 운영 중입니다. 본 프로젝트의 PLC →
    Python AI 서버 → MES 콘솔 흐름이 구조적으로 동일합니다.

    검증한 자산을 보유하고 있습니다.

(3) **AI 모델 실전 구현 + AI 사업 라인 정조준** — Python
    기반 AI 모델을 다수 실전 구현 했습니다.

협업 방식 제안
============================================================

본 프로젝트는 외주(계약 단위)이므로 다음 협업 방식을 제안합니다.

[원격 + 핵심 마일스톤 현장]
- 1주차 (현장 1~2회): 공장 환경 파악 + 기존 MES 코드 분석 +
  PLC 통신 점검 (대면 협의)
- 2~8주차 (원격): 펌웨어/AI 서버 개발, 주 1회 화상 진행 공유
- 9주차~ (현장 1~2회): 통합 테스트 + 안정화 + 인수인계 협의

당사 위치: 경기도 용인시 기흥구 흥덕유타워. 수도권 공장은
현장 방문 즉시 가능, 그 외 지역도 마일스톤 단위 출장 협의
가능합니다. 화장품 공장 위치 안내 받는 즉시 상세 일정 협의
드리겠습니다.

본 프로젝트는 2명(펌웨어 + AI 분석)이 함께 투입 가능하여
60일 일정 안에 1단계(데이터 수집 + 통계 임계값) 완료 + 2단계
(ML 모델 학습 기반) 사전 설계까지 수행 가능합니다.
