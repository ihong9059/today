## 1. LVDS (Low-Voltage Differential Signaling)

### 1.1 개요

LVDS는 고속 데이터 전송을 위한 **차동 신호 인터페이스** 표준입니다. 주로 LCD 패널, 카메라, 고속 데이터 링크에 사용됩니다.

| 항목 | 사양 |
|------|------|
| 표준 | ANSI/TIA/EIA-644 |
| 전압 스윙 | 약 350mV (차동) |
| 공통 모드 전압 | 1.2V |
| 데이터 레이트 | 최대 3.125 Gbps (채널당) |
| 임피던스 | 100Ω (차동) |

### 1.2 동작 원리

```
        ┌─────────────┐                    ┌─────────────┐
        │   LVDS TX   │                    │   LVDS RX   │
        │  (송신기)   │                    │  (수신기)   │
        │             │      D+            │             │
        │    ┌───┐    ├────────────────────┤    ┌───┐    │
Data ───┤    │   │    │                    │    │   │    ├─── Data
        │    │ 드│    │      D-            │    │비 │    │
        │    │라 │    ├────────────────────┤    │교 │    │
        │    │이│    │                    │    │기 │    │
        │    │버 │    │     100Ω 종단     │    │   │    │
        │    └───┘    │        ┴          │    └───┘    │
        └─────────────┘                    └─────────────┘
```

**차동 신호 방식**:
- D+와 D- 두 신호선 사용
- 두 신호의 전압 차이로 데이터 표현
- D+ > D- : 논리 '1'
- D+ < D- : 논리 '0'

### 1.3 LVDS의 장점

| 장점 | 설명 |
|------|------|
| **저전력** | 낮은 전압 스윙 (350mV)으로 전력 소모 감소 |
| **고속 전송** | 수 Gbps 데이터 전송 가능 |
| **EMI 감소** | 차동 신호로 전자기 간섭 최소화 |
| **노이즈 내성** | 공통 모드 노이즈 제거 |
| **장거리 전송** | 수 미터 케이블 전송 가능 |

### 1.4 LCD 패널 연결 구조

```
┌────────────────┐         LVDS Cable         ┌────────────────┐
│                │                            │                │
│   AP/SoC       │    ┌──────────────────┐    │   LCD Panel    │
│   (i.MX8)      │    │                  │    │                │
│                │    │  CLK+, CLK-      │    │   T-CON        │
│   LVDS TX      ├────┤  DATA0+, DATA0-  ├────┤   (Timing      │
│                │    │  DATA1+, DATA1-  │    │   Controller)  │
│                │    │  DATA2+, DATA2-  │    │                │
│                │    │  DATA3+, DATA3-  │    │                │
│                │    │                  │    │                │
└────────────────┘    └──────────────────┘    └────────────────┘
```

### 1.5 LVDS 종류

| 종류 | 채널 수 | 해상도 지원 | 용도 |
|------|---------|------------|------|
| Single LVDS | 1채널 (4 data + 1 clk) | ~WXGA (1280x800) | 소형 패널 |
| Dual LVDS | 2채널 (8 data + 2 clk) | ~FHD (1920x1080) | 중형 패널 |
| Quad LVDS | 4채널 | 4K 이상 | 대형 패널 |

### 1.6 PCB 설계 시 주의사항

#### 1.6.1 임피던스 매칭
```
차동 임피던스: 100Ω ±10%
단일 임피던스: 50Ω ±10%
```

#### 1.6.2 라우팅 규칙

| 항목 | 권장값 |
|------|--------|
| 차동 페어 간격 | 트레이스 폭의 2배 이내 |
| 길이 매칭 | 차동 페어 내 ±5mil 이내 |
| 채널 간 길이 매칭 | ±50mil 이내 |
| 비아 최소화 | 가능한 적게 사용 |
| GND 참조 | 연속적인 GND 플레인 유지 |

#### 1.6.3 커넥터

일반적으로 사용되는 LVDS 커넥터:
- **FFC/FPC**: 30핀, 40핀, 51핀 등
- **JAE FI-X 시리즈**: 고밀도 커넥터
- **Hirose DF19 시리즈**: 산업용

## 2. SMARC (Smart Mobility ARChitecture)

### 2.1 개요

SMARC는 **임베디드 컴퓨터 모듈(SOM)의 표준 폼팩터**입니다. SGET(Standardization Group for Embedded Technologies)에서 관리합니다.

| 항목 | 사양 |
|------|------|
| 표준 | SMARC 2.0 / 2.1 |
| 커넥터 | MXM3 타입 (314핀) |
| 크기 | 82mm x 50mm (Short) / 82mm x 80mm (Full) |
| 용도 | 산업용, 의료기기, IoT, 엣지 컴퓨팅 |

### 2.2 SMARC vs 다른 SOM 표준

| 표준 | 핀 수 | 크기 | 특징 |
|------|-------|------|------|
| **SMARC** | 314 | 82x50/80mm | ARM/x86 범용, 산업용 |
| COM Express | 220/440 | 95x95mm~ | x86 중심, 고성능 |
| Qseven | 230 | 70x70mm | 저전력 ARM/x86 |
| **CM4** | 200 | 55x40mm | Raspberry Pi 전용 |

### 2.3 SMARC 커넥터 구조

```
┌────────────────────────────────────────────────────────────────┐
│                        SMARC Module                            │
│                     (NXP i.MX8, etc.)                          │

│   │              MXM3 Connector (314 pins)               │     │
│   │  ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐  │     │
│   │  │Power│ GND │GPIO │ I2C │ SPI │UART │USB  │PCIe │  │     │
│   │  │     │     │     │     │     │     │     │     │  │     │
│   │  │LVDS │HDMI │CSI  │Audio│SDIO │GbE  │SATA │ ... │  │     │
│   │  └─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘  │     │
│   └──────────────────────────────────────────────────────┘     │
└────────────────────────────────────────────────────────────────┘
                              │
```

### 2.5 SMARC 전원 시퀀싱

SMARC 모듈은 엄격한 전원 시퀀싱을 요구합니다:

```
Power-On Sequence:
                    ┌─────────────────────────────────
VIN (5V~24V)   ─────┘
                         ┌────────────────────────────
CARRIER_PWR_ON ──────────┘
                              ┌───────────────────────
3.3V_STBY      ───────────────┘
                                   ┌──────────────────
MODULE_PWR_BTN ────────────────────┘
                                        ┌─────────────
1.8V, 3.3V     ─────────────────────────┘
                                             ┌────────
RESET_OUT#     ──────────────────────────────┘

             T1    T2    T3    T4    T5
```

| 시퀀스 | 신호 | 설명 |
|--------|------|------|
| T1 | VIN | 메인 전원 입력 (5V~24V) |
| T2 | CARRIER_PWR_ON | 캐리어 보드 전원 준비 신호 |
| T3 | 3.3V_STBY | 스탠바이 전원 |
| T4 | MODULE_PWR_BTN | 모듈 전원 버튼 |
| T5 | RESET_OUT# | 모듈 리셋 완료 |

## 3. 프로젝트 적용 시 고려사항

### 3.1 베이스보드 설계 체크리스트

#### LVDS 관련
- [ ] LVDS TX/RX 칩셋 선정 (또는 SoC 내장 사용)
- [ ] 차동 임피던스 100Ω 설계
- [ ] 차동 페어 길이 매칭 (±5mil)
- [ ] LVDS 커넥터 선정 (FFC/FPC)
- [ ] ESD 보호 회로 설계
- [ ] 백라이트 전원/PWM 제어

#### SMARC 관련
- [ ] MXM3 커넥터 풋프린트 확인
- [ ] 전원 시퀀싱 회로 설계
- [ ] 전원 레귤레이터 선정 (5V→3.3V, 1.8V)
- [ ] 리셋 회로 설계
- [ ] 고속 신호 라우팅 (PCIe, USB 3.0)
- [ ] 디버그 인터페이스 (UART, JTAG)

### 3.2 CM4 vs SMARC 비교 (경험 전이)

| 항목 | CM4 | SMARC | 전이 가능성 |
|------|-----|-------|-------------|
| 커넥터 | 2x100핀 Hirose | 314핀 MXM3 | 다름 (학습 필요) |
| 전원 입력 | 5V 단일 | 5V~24V | 유사 |
| 전원 시퀀싱 | 간단 | 복잡 | 유사 원리 |
| LVDS | 미지원 (HDMI) | 지원 | 별도 경험 활용 |
| PCIe | Gen 2.0 x1 | Gen 3.0 x4 | 유사 |
| USB | USB 2.0 x4 | USB 3.0 x2 + 2.0 x4 | 유사 |
| GbE | 1포트 | 2포트 | 유사 |
| Linux BSP | Raspberry Pi OS | Yocto/Buildroot | 유사 원리 |

## 4. 요약

### LVDS
- LCD 패널 연결을 위한 **고속 차동 신호 인터페이스**
- 낮은 전압 스윙, 낮은 EMI, 고속 전송
- PCB 설계 시 **임피던스 매칭(100Ω)**과 **길이 매칭** 중요

### SMARC
- 임베디드 SOM의 **표준 폼팩터** (314핀 MXM3 커넥터)
- NXP i.MX, Qualcomm, TI 등 다양한 프로세서 지원
- **전원 시퀀싱**과 **고속 신호 설계**가 핵심

### 프로젝트 적용
- 기존 CM4 베이스보드 경험 70% 전이 가능
- SMARC 핀맵과 전원 시퀀싱 사전 학습 필요
- LVDS는 삼성/파나소닉 경험으로 즉시 대응 가능
