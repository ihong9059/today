지원 사유
============================================================

안녕하세요. 해양 안전 신호시스템 시제품 프로젝트에 지원합니다.

당사는 ESP32 + FreeRTOS + LTE + WiFi + IoT 클라우드 연동을
하나의 시제품에서 통합한 양산 경험을 다수 보유하고 있어,
본 프로젝트가 요구하는 "시제품 펌웨어 + 하드웨어 조립"을
40일 안에 1차 동작 검증 + 2차 안정화까지 수행 가능합니다.

특히 다음 세 가지가 본 프로젝트와 직접 연결됩니다:

(1) ESP32 + FreeRTOS + LTE 통합 운영 — 농업 IoT 시제품에서
    동일 스택을 운영 중이며, RAK4630(nRF52840 + LTE 모듈)
    기반 시스템에서 센서 수집 → 클라우드 송신을 24/7 동작
    상태로 검증했습니다. 해양 환경의 LTE 음영지역 대응 패턴
    (재시도, 메시지 큐, 오프라인 캐시)을 그대로 이전 가능합니다.

(2) 시제품 회로 + 펌웨어 + 조립 일체 — 당사 협업팀은 회로
    설계 25년(임호균) + 펌웨어 38년(홍광선)으로, 시제품 단계의
    PCB·부품 선정·조립·1차 동작 검증을 한 사람의 외주에 분산
    의뢰할 필요 없이 수직 통합 수행합니다.

(3) 공공안전 IoT 도메인 — 당사 자체 제품 라인이 음성 + AI +
    BLE 통합 안전 신호 디바이스(특허 출원)이며, 위치/움직임
    감지 + 음향 + 광 신호 출력의 통합 설계 패턴을 직접 보유
    하고 있어 본 프로젝트의 신호 출력 부분을 빠르게 구현
    가능합니다.

40일 / 6백만원 일정 안에 1차 시제품 동작 + 현장 1회 검증까지
완료를 목표로 협의 가능합니다.

관련 실무 경험
============================================================

[1. ESP32 + FreeRTOS + IoT 통합 시제품 (당사 자체 제품군)]

ESP32-C3 기반 무선 신호 디바이스를 양산 라인에 적용 중이며,
FreeRTOS 다중 태스크 구조로 다음을 동시 운영 중입니다.
- 센서 입력 태스크 (마이크/가속도/터치)
- BLE 통신 태스크 (스마트폰 페어링, 명령 송수신)
- 신호 출력 태스크 (RGB LED 256단계, 진동 모터, 음향)
- 저전력 태스크 (Deep Sleep, 외부 인터럽트 wake-up)

해양 안전 신호 시제품의 신호 출력 + 통신 + 저전력 운영 패턴이
이 구조에 그대로 매핑됩니다.

[2. RAK4630(nRF52840 + LTE) 농업 IoT 양산 시스템]

기술: Zephyr RTOS, LTE-CAT M1, MQTT, 16바이트 고정 프레임,
ACK 상태머신, 저전력 슬립
운영: Tower 게이트웨이 + Link 노드 다중 계층 구조,
센서 데이터 수집 → LTE 클라우드 송신 → 명령 수신 → 액추에이터
제어, 24/7 운영
인증: KC RS485 Modbus RTU 인증 Testbed 완료 (2026-04-30)

해양 안전 시스템의 24/7 무인 운영 + 음영지역 대응 + 클라우드
연동을 동일 패턴으로 구현 가능합니다.

[3. STM32 + FreeRTOS 양산 펌웨어 2종]

a) STM32F756 컴프레서 밸브 컨트롤러 (FreeRTOS, RS485)
   - PID 제어 + 상태머신
   - 양산 판매 중

b) STM32F407 세탁기 컨트롤러 (FreeRTOS)
   - 다중 프로그램 + 시간 기반 태스크
   - 양산 판매 중

FreeRTOS의 mutex/semaphore/queue를 활용한 안정 동작
패턴을 다수 사례에서 검증했습니다.

[4. nRF52832 BLE 온도 컨트롤러 양산]

저전력 BLE 무선 모니터링 디바이스, 양산 판매 중. 본 프로젝트의
BLE 백업 채널 또는 근거리 페어링 기능 추가 시 즉시 적용 가능.

[5. AI 신호 디바이스 시제품 + 특허]

음성 + AI + BLE 통합 안전 신호 디바이스에 대한 특허 출원 자산
보유. 마이크 입력 → 키워드 감지 → LED/음향/진동 출력의
저전력 실시간 신호 처리 경험이 본 프로젝트에 직접 활용
가능합니다 (예: 비명/구조요청 음향 감지 → 신호 발신).

[6. ESP32 기반 On-Device AI PoC (2026-05-08 완료)]

ESP32-S3에서 Karpathy microGPT(4,192 파라미터)를 INT8 양자화로
탑재 가능함을 PC 기반 PoC로 검증 완료. 추론 시간 token당 0.1~5ms,
메모리 4.1KB. 향후 본 프로젝트에 음향/움직임 anomaly detection을
온디바이스에서 처리하는 옵션을 제공할 수 있습니다.
