============================================================
방사선/HPIC 도메인에 대한 솔직한 입장
============================================================

방사선(HPIC: High Pressure Ion Chamber) 도메인 자체는 신규 영역이나,
**핵심 전기적 특성은 정밀 미세전류/전압 계측 + 노이즈 차단**으로
당사가 현재 수행 중인 반도체 공정용 MFC(0.01% F.S. 정밀도)와
동일한 설계 원칙이 적용됩니다.

대응 방안:
- HPIC 센서의 전기적 인터페이스(전류 범위, 임피던스, 응답 시간)
  사양을 NDA 체결 후 즉시 검토
- 필요 시 HPIC 제조사(Centronic, Thermo Fisher 등) 데이터시트 분석
- 방사선 계측 표준(IEC 60050, IEC 61526) 참조
- 1차 시제품에서 충분한 노이즈 마진 확보 후 캘리브레이션

당사가 진행 중인 정밀 MFC 프로젝트의 24bit/32bit ADC 다채널 처리
경험이 그대로 본 프로젝트에 이식 가능합니다.

60일 일정 제안
============================================================

[Week 1] NDA 체결 + 사양 확정

- MCU 선정 (STM32F0/L0 저전력 또는 F4 범용)

- BOM 초안 + 부품 리드타임 조사

[Week 2~3] 회로 설계 (Schematic)
- ADS1120 + 5채널 아날로그 프론트엔드
- MCU + 클럭/전원/디버그
- RS-232 / UART / USB 트랜시버
- 릴레이 3단 구동 회로
- ESD/EMI 보호
- DRC/ERC + 1차 Review

[Week 4~5] PCB 아트웍
- 다층 (4층 권장) 스택업 결정
- Analog/Digital 영역 분리
- 임피던스 제어 라인
- Gerber/Drill/Pick&Place 출력
- PCB 발주

[Week 6~7] 펌웨어 1차 개발 (PCB 제작 대기 병렬)
- ADS1120 SPI 드라이버
- 5채널 시퀀셜 변환
- 디지털 필터
- RS-232/UART/USB 통신 모듈
- 릴레이 제어 로직
- Nucleo 보드에서 Mock 검증

[Week 8] PCB 수령 + SMT 조립 (10대)

- 통신 시험 (RS-232/UART/USB)
- 릴레이 시험

[Week 10] 성능 시험 + 산출물 정리
- 노이즈/정확도/안정성 시험
