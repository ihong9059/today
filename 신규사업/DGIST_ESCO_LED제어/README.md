## 자료 목적

DGIST ESCO사업 중 **LED 조명제어 시스템 공사 (총 1,271등)** 부분에 대한 UTTEC 측 기술 제안. 시방서 §2.1 IR 통신 방식 LED 센서등 (354등) 및 §2.2 IoT 기반 무선 조명제어 시스템 (917등) 두 시스템의 **계통도 + 구현 방법**을 상세히 정리한다.

## 시스템 구성 요약

| 구분 | 적용 범위 | 통신 방식 | UTTEC 제안 코어 |
|---|---|---|---|
| **§2.1 IR 통신 LED 센서등** | **354등** (컨실리언스센터 지하주차장) | 적외선(IR) chain + 리모컨 그룹화 | **STM32G0/G4 기반 IR-NEC v2 확장 프로토콜 + PIR + 디밍** |
| **§2.2 IoT 기반 무선 조명제어** | **917등** (본관·E2~E7동 복도 등) | **BLE Mesh** (나고야 사카에 자전거 주차장 BLE Mesh Locking 사례 참조) | **nRF52840 BLE Mesh node + Gateway (Provisioner)** + 관제 서버 |
| **통합 관제** | 양 시스템 단일 대시보드 | Gateway → MQTT/HTTP | 웹 관제 + 스케줄 + 사용자 권한 + 보안 암호화 |

## 시방서 핵심 요구사항 충족 매트릭스

| 시방서 요구 | 충족 위치 | 충족 방식 |
|---|---|---|
| **§2.1 IR 통신 chain 점등** | 03 IR 시스템 § 4 | NEC v2 확장 32bit 패킷 + chain hop 1~3단 |
| **§2.1 단독·그룹·연동 제어** | 03 IR 시스템 § 5 | DIP 5bit (32 그룹) + 리모컨 그룹 ID 설정 |
| **§2.1 리모컨 그룹화** | 03 IR 시스템 § 6 | 17키 리모컨 + 학습 모드 |
| **§2.1 PIR + 디밍** | 03 IR 시스템 § 3 | PIR 무동작 → 10% dim → 소등 3단계 |
| **§2.2 BLE Mesh 무선** | 02 IoT 시스템 § 3 | Bluetooth SIG Mesh 1.1 표준 + Friend/Low Power node |
| **§2.2 IoT 게이트웨이 양방향** | 02 IoT 시스템 § 5 | nRF52840 + LTE Cat-M1 또는 WiFi |
| **§2.2 MAIN/SUB Controller 16채널** | 02 IoT 시스템 § 6 | SUB Controller per Zone (16 luminaire 그룹) |
| **§2.2 관제 서버 + 웹페이지** | 02 IoT 시스템 § 7 | Node-RED/n8n 기반 관제 + Grafana dashboard |
| **§2.2 보안 암호화** | 02 IoT 시스템 § 8 | BLE Mesh AES-CCM + TLS 1.3 (Gateway↔Cloud) |
| **§2.2 스케줄·점유 제어** | 02 IoT 시스템 § 9 | 시간·요일·점유 3축 룰 엔진 |

## UTTEC 차별화

| 강점 | 근거 |
|---|---|
| **Cortex-M tier AI 노드 carry** | STM32H745 dual-core M7+M4 박제 (CMSIS-NN CNN 17.6× 가속) — 향후 점유 패턴 학습 기반 절감 가능 |
| **BLE 양산 경험** | nRF52 시리즈 14 보드 매트릭스 박제, BLE Mesh provisioning 검증 |
| **펌웨어 50건 함정 인벤토리** | Espressif 16 + Nordic 18 + STM32 15 등 cross-vendor carry-over |
| **IQC 자동화 4축 패턴** | DUT 다중 + 브리지 단일 + 두 하향 경로 동일 규약 + BLE pairing L2 (revita 카드 검증 4축, 본 사업 양산 단계 carry) |
| **multi-agent 자동화 운영** | n8n 자동화 broker + Notion + Grafana 통합 — 관제 SW 신속 구축 |
