## 3. LED 검출 알고리즘 (3가지)

### A. 사용자 ink 마킹 → 원 변환
- 대상: **E1, E2**
- 방법: 사용자가 PDF에 파란 ink로 표시한 위치 추출 → 깨끗한 파란 원으로 변환
- 스크립트: `generate_e2_clean.py` (E2용, E1도 동일)

### B. PE/PN 텍스트 라벨 매칭
- 대상: **E3, E5, E6**
- 규칙: `^P[EN]\d{1,3}$` 정규식 매칭 (PE3, PN4 등)
  - `E3`, `E4` 같은 P 없는 라벨은 **LED 아님** (사용자 확정)
- 조건: 라벨 center가 빨간 zone 안에 strict containment
- 스크립트: `mark_e3to6_text.py`

### C. 도형 매칭 (작은 사각형)
- 대상: **E4** (라벨 없음)
- E4 fixture 형태 (mediabox 기준, rotation 270° 적용):
  - **thin bar (2×8)**: E4 p3 corridor의 가로 LED bar
  - **bar (13×6, 6×11)**: E4 p4 격자형 LED
  - **square (8×8 등)**: E4 p4 추가
- PolyLine vertex 분해로 ㄷ자 strip 정확 추출
- 스크립트: `mark_e4_v2.py`

## 4. 핵심 함정 박제

### 4-A. 빨간 zone 검출 시 좌표계 주의
- 페이지 rotation 270° → mediabox 좌표와 display 좌표 다름
- 모든 좌표 비교는 **mediabox 통일** (annot.rect, drawing.rect, span.bbox 모두 mediabox)
- v3에서 dual-coord 시도 시 87개 false positive 발생 → 단일 mediabox로 해결

### 4-B. zone expand는 strip 형태별 차등
- E2 (도형 매칭): expand=12 필요 (fixture가 좁은 strip 약간 벗어남)
- E3-E6 (텍스트 매칭): expand=0 strict (라벨은 strip 안에 정확히 위치)
- E4 (도형 매칭): expand=0 (PolyLine 분해 후 정확한 좁은 strip 사용)

### 4-C. PolyLine vertex 6개 = ㄷ자 strip 2개
- E4 p4 PolyLine bounding box = 100×694 (강의실 전체 포함)
- 실제 strip은 vertex segment를 평행 line 쌍으로 그룹화하여 추출
- 결과: 71×15 (위 가로) + 15×664 (왼 세로) — 사용자 의도 정확 매칭
- 알고리즘: `extract_strips_from_polyline()` in `mark_e4_v2.py`

### 4-D. E3-E6에서 P-only 필터 (사용자 확정 규칙)
- LED 라벨 = PE/PN으로 시작하는 것만
- E3, E4 같은 P 없는 라벨은 그룹 라벨/구역 라벨 → LED 아님
