4. 기존 방식 vs USLC (LoRa 무선)

❌ 기존 방식

📋 매일 야간 순찰로 등기구 고장 확인
⏰ 계절마다 타이머 수동 조정
🔌 통신 배선 신규 포설 (수일~수주 공사)
📝 에너지 보고서 수작업 집계
🚫 분산 시설 통합 관제 어려움
⚠️ 환경 위험 (가스 등) 사후 인지

✅ USLC (UTTEC LoRa)

📡 고장 자동 감지 → 즉시 알림
🌅 일출/일몰 GPS 자동, 계절 조정 불요
📶 LoRa 무선 — 배선 공사 0원
📊 월간 리포트 자동 생성 (PDF 발송)
🌐 1개 Gateway로 1km 반경 통합 관제
🔔 환경 24시간 자동 감시 + 임계치 알림
