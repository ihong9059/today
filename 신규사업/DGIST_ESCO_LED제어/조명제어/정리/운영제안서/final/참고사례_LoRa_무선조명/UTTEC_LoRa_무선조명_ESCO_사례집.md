## 🗺️ 2. LoRa 무선 조명제어 시스템 (USLC) 개요

### 2.1 시스템 컨셉 — "배선 공사 없이, 무선으로 통합 관제"

USLC는 **3개 계층의 무선 통합 관제 시스템**입니다. 기존 인프라(AC 220V)만 사용하고 추가 통신 배선이 필요 없습니다.

| 계층 | 구성요소 | 역할 |
|:-:|---|---|
| ☁️ **Cloud 관제 서버** | 조명 관제 대시보드 · 환경 감시 대시보드 · 모바일 알림 (운영자) | 통합 시각화 · 알림 발송 · 데이터 누적 |
| ⬇ *통신* | **LTE (4G)** | Gateway ↔ Cloud 양방향 통신 |
| 🌐 **Gateway** (관리실/사무실) | AC 콘센트 연결만으로 완료 | **별도 통신 인프라 불요** — LoRa ↔ LTE 브리지 |
| ⬇ *통신* | **LoRa 무선 (922.1MHz)** | **배선 없음 / 최대 1km / Gateway 1대당 최대 254 노드** |
| 📡 **노드 (Node) 3종** | 조명 Node · 환경 감시 Node · 전력 관리 Node | 현장 센싱 · 디밍 제어 · 환경 감시 |

**노드 3종 세부**:

| 노드 종류 | 적용처 | 내장 센서·제어 |
|---|---|---|
| **조명 Node** | 옥외등 · 보안등 · 보행등 | PWM 디밍 0~100% (0-10V/DALI/PWM) + PIR 동체감지 + 조도 + 온도 |
| **환경 감시 Node** | 지하주차장 · 실내 환경 | CO / CO₂ / 온습도 / VOC / 연기 |
| **전력 관리 Node** | 분전반 | CT 클램프 비접촉 계측 + 피크 관리 |

> 📐 **상세 시각화 다이어그램**: 본 폴더 내 `USLC_시스템_구성도.html` (브라우저 인터랙티브 보기) 또는 `USLC_시스템_구성도.pdf` (인쇄용 4페이지) 참조. 4개 섹션 — 3계층 구성도 / 통합 대시보드 mockup / 시간대별 운영 시나리오 / 기존 방식 vs USLC 비교.

### 2.2 핵심 기술 사양

| 항목 | 사양 |
|---|---|
| **통신** | LoRa 922.1MHz (국내 ISM 대역, 무선, 최대 1km) |
| **보안** | AES-128 암호화 |
| **조명 제어** | PWM 디밍 0~100% (0-10V / DALI / PWM 호환) |
| **조명 센서** | 조도(럭스), PIR 동체감지, 온도 |
| **환경 센서** | CO/CO₂ 가스, VOC, 온습도, 연기 |
| **전력 계측** | CT 클램프 방식 (비접촉, 분전반 무수정 설치) |
| **전원** | 기존 AC 220V 활용 (별도 전원 공사 불요) |
| **방수 등급** | IP65 (옥외) / IP44 (실내·지하) |
| **동작 온도** | -20℃ ~ +60℃ |
| **노드 수용** | Gateway 1대당 최대 **254 노드** |
| **관제** | 웹 대시보드 + 모바일 앱 |
| **인증** | KC (국내), TELEC (일본), CE (유럽) 기 취득 경험 |

### 2.3 ESCO 시공 관점의 차별화

| 항목 | 기존 유선 시스템 | USLC (LoRa 무선) |
|---|---|---|
| 시공 기간 | 2~4주 (배선 공사 포함) | **3~5일 (노드 설치만)** |
| 통신 배선 | 케이블 신규 포설 필요 | **없음 (LoRa 무선)** |
| 야간 시공 | 빌딩 비중지 어려움 | **노드 설치만 → 야간 가능** |
| 기존 등기구 활용 | 등기구 교체 필요 | **0-10V/DALI 호환 등기구는 즉시 활용** |
| 확장성 | 추가 배선 공사 | **노드 추가만 (Gateway당 254개)** |

## 📡 3. ESCO 사업 적용 시나리오

### 3.1 적용 가능 영역 (체크리스트)

ESCO 사업자(귀사)의 사업장 또는 향후 확장 사업에서 다음 영역에 USLC 적용 검토 가능:

| # | 영역 | 적용 가치 |
|:-:|---|---|
| 1 | **캠퍼스·사업장 옥외등** (보안등·가로등·보행등) | 야간 자동 디밍 + 고장 자동 감지 |
| 2 | **건물 외주 조명** (외벽 무대조명·간판등) | 시간대별 시나리오 + 절전 |
| 3 | **공원·산책로 조명** | PIR 점유 감지 + 보행자 동선 점등 |
| 4 | **주차장 일반 조명** (지상) | 차량·보행 동선 기반 디밍 |
| 5 | **지하주차장 환경 감시** | CO/CO₂ + 온습도 + 환기 시스템 연동 |
| 6 | **공장·창고 작업등** | 작업 시간 + 보행 동선 자동 점등 |
| 7 | **사옥 옥상·외부 통로** | 야간 자동 점소등 + 모바일 원격 제어 |
| 8 | **분산 시설 통합 관제** | 1개 Gateway로 1km 반경 통합 관제 |

## 🤝 5. UTTEC × ESCO 사업자 협력 모델

본 사례집의 USLC를 ESCO 사업에 적용 시 다음 4가지 협력 모델 가능 (DGIST 본 제안서 § H.2와 동일 구조):

| 모델 | 역할 분담 |
|:-:|---|
| **A) 기술자문** | UTTEC = 컨설팅·기술 검토 / ESCO = 자체 양산·시공·운영 |
| **B) OEM** | UTTEC = H/W·펌웨어 공급 / ESCO = 시공·운영 SaaS |
| **C) 통합 플랫폼** | UTTEC = H/W + 펌웨어 + 관제 SaaS 통합 / ESCO = 영업·운영 |
| **D) PoC + 단계 결정** | 1 Zone 시범 PoC 후 단계별 협력 모델 확정 |
