## 1. 인프라 위치·치수 (현장 답사 필수)

### 1-A. 노드별 위치 (GPS)
- ★★★ **펌프1A** GPS 좌표 + 사진 (사방 4장) + 펌프 인근 전원·통신 환경
- ★★★ **중계기1** 후보 위치 (사파이어 4번~5번 사이 지도 표기) — 안테나 가시성·전원
- ★★★ **고가수조1** (사파이어 3번홀, B) — 위치, 높이, 진입성
- ★★★ **펌프2** (루비 6번 인근)
- ★★★ **중계기2** 후보 위치
- ★★★ **고가수조2** (다이아몬드 9번홀)
- ★★★ **저장탱크 3개소** 위치 (견적서 명시, 지도 미표기)
- ★★★ **관리실 / 게이트웨이** 설치 후보 위치

### 1-B. 노드 간 거리·LoS
- ★★★ **노드 간 직선거리** (실측 또는 정밀 GPS 계산)
- ★★★ **장애물** (잡목·언덕·건물·기타 통신탑) 존재 여부 + 사진
- ★★ 안테나 설치 가능 높이 (고가수조 상단·기둥 등)

### 1-C. 고가수조·저장탱크 치수
- ★★★ **탱크 높이** (수위 측정 범위)
- ★★★ **탱크 직경/단면적** (체적 계산)
- ★★★ **재질** (콘크리트·스틸·PE) — 무선 신호 차폐 영향
- ★★ 입수구/출수구 위치, 배관 직경

## 2. 기존 설비 (반드시 발주자 시설팀 자료)

### 2-A. 펌프 사양
- ★★★ **펌프 모델명·제조사·시리얼**
- ★★★ **정격 전압** (220V 단상 / 380V 3상)
- ★★★ **정격 전류** (A) — 펌프 제어반 MC 용량 결정
- ★★★ **정격 전력** (kW) — 차단기·SPD 용량
- ★★★ **유량** (L/min, m³/h) — 만수 충전 시간 계산
- ★★ 양정 (m), 토출압 (bar)
- ★★ 운전 방식 (단순 ON/OFF / 인버터 / 가변속)

### 2-B. 기존 제어반
- ★★★ **현재 제어 방식** (수동 / 자동 / 외부 제어)
- ★★★ **기존 플로트 스위치** 존재 여부 (있으면 그대로 활용 가능)
- ★★★ 제어반 사진 (전체 + 내부)
- ★★ 차단기 용량, 결선 도면

### 2-C. 기존 수위·유량 센서
- ★★ 현재 설치된 센서 (있으면 모델·신호 형식)
- ★★ 만수위·저수위 물리적 표시 (옵투랜·플로트)

### 2-D. 배관
- ★★ 배관 직경, 재질, 길이
- ★ 밸브 위치 (수동 / 전동)

## 3. 전력 환경

- ★★★ **각 펌프·노드 위치별 AC 220V 가용성** (콘센트 또는 인입 가능 거리)
- ★★★ **관리실 인터넷** 회선 종류 (광랜·KT·LG·SK), 고정 IP 가능 여부
- ★★ 정전 빈도 (월 N회 이상이면 UPS 필수)
- ★★ 접지 시스템 존재 여부 (낙뢰 보호용)
- ★ 야간 작업 가능 여부 (전력 작업 시간대)

## 4. 통신·네트워크

- ★★★ **관리실 인터넷 회선** — 게이트웨이 인터넷 업로드용

## 5. 운용 요구사항 (발주자 인터뷰 필수)

### 5-A. 동작 시나리오
- ★★★ **저수위 임계값** (몇 m → 펌프 ON?)
- ★★★ **만수위 임계값** (몇 m → 펌프 OFF?)
- ★★★ **수위 측정 주기** (1초 / 1분 / 1시간 — air rate에 영향)
- ★★ 펌프 최대 연속 운전 시간 (모터 보호)
- ★★ 펌프 OFF 후 최소 휴지 시간 (재기동 빈도 제한)

### 5-B. 모니터링·알람
- ★★★ **알람 채널** (관리실 PC / 시설팀 모바일 / SMS / 이메일)
- ★★★ **알람 등급** (경보·경고·정보)
- ★★★ **수신 담당자** (이름·연락처·교대 일정)
- ★★ 데이터 보관 기간 (1개월 / 1년 / 영구)
- ★★ 보고서 생성 (일·주·월간)

### 5-C. 수동 개입
- ★★★ **로컬 비상 정지 버튼** 위치·필요 여부
- ★★★ **원격 수동 제어** 권한 (시설팀 / 관리자만)
- ★★ 안전 인터록 (저수위·과전류·과열 차단)

### 5-D. 운영 시간
- ★★ 골프장 운영 시간 (라운딩 시간대 시공 회피)

## 자료 수집 방법

| 자료 카테고리 | 수집 방법 | 주관 |
|---------------|----------|------|
| 1. 인프라 위치·치수 | **현장 답사** + 사진·실측·GPS | UTTEC + 시설팀 동행 |
| 2. 기존 설비 | 시설팀 자료 수령 + 현장 확인 | 시설팀 → UTTEC |
| 3. 전력 환경 | 시설팀 자료 + 현장 확인 | 시설팀 → UTTEC |
| 4. 통신 | IT팀 인터뷰 | IT팀 → UTTEC |
| 5. 운용 요구사항 | **결재권자/운영 담당자 인터뷰** | UTTEC 인터뷰 |
| 6. 환경 조건 | 한국 기상자료 + 시설팀 경험 | UTTEC 조사 |
| 7. 인허가 | UTTEC 측 + 한전·전기안전공사 | UTTEC |
| 8. 이해관계자 | 발주자 측 명단 수령 | 발주자 |
| 9. 기존 문서 | 시설팀 자료 수령 | 시설팀 → UTTEC |

## 권장 — 발주자에게 전달할 자료 요청 양식

다음 사항을 한 장 양식으로 정리해 발주자에게 전달:

1. 펌프 2대 사양표 (모델·전압·전류·kW·유량)
2. 기존 제어반 사진 + 결선 정보
3. 운용 요구사항 (저수위·만수위 임계값·알람 수신자)
4. 인터넷 회선·고정 IP 가능 여부
5. 결재·시설·운영 담당자 명단

→ 이 자료가 1주일 내 도착하면 시공 일정 1주일 단축 효과.

## 본 프로젝트 산출물 (설계 단계 완료 시)

이 자료들이 모이면 다음 산출물 작성 가능:

- [ ] **시스템 블록도** (8개 노드 + 게이트웨이 + 클라우드)
- [ ] **무선 통신 토폴로지** (LoRa 거리·중계 경로)
- [ ] **노드별 BOM** (펌프 노드·중계기·게이트웨이 별 자재)
- [ ] **결선도** (전원·신호·통신)
- [ ] **펌웨어 동작 시퀀스** (수위 측정 → 임계값 비교 → 펌프 제어 → 알람)
- [ ] **모니터링 대시보드 와이어프레임**
- [ ] **시공 절차서** (단계·작업 시간·인력 배치)
- [ ] **시운전 절차서** (검증 항목·합격 기준)
- [ ] **운영 매뉴얼** (시설팀용)
- [ ] **하자보증·계약서** (한계 명시)
