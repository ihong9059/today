# 수위 측정 방법 검토 — 한림용인CC 수조

> 작성일: 2026-05-10
> 적용 환경: 옥외 골프장 5개 탱크 (고가수조 2 + 저장탱크 3)
> 예산: 5개 노드 × 8~15만원 = **40~75만원** (1,000만원 시스템 중)
> 인터페이스: nRF52832 + LoRa 노드 (UTTEC 자체 보드)

## 1. 측정 방법 비교

| 방식 | 정확도 | 단가/대 | 옥외 적합 | 권장도 |
|------|-------|---------|----------|--------|
| **수중 압력식** | ±5~10mm | 8~15만 (저가형) / 30~50만 (산업급) | ★★★ | ★★★★ |
| **초음파 비접촉** | ±10~30mm | 5~30만 | ★★ | ★★★ |
| **레이더 비접촉** | ±2mm | 100~500만 | ★★★★ | ✗ (예산 초과) |
| **정전용량 막대** | ±5mm | 50~200만 | ★★ | ✗ (단가) |
| **자기변형식** | <1mm | 100~500만 | ★★★ | ✗ (단가) |
| **플로트 스위치** | 임계값 ON/OFF | 1.5만 | ★★★ | ★★★ (백업용) |
| **전극식 (다단)** | 임계값 다단 | 5만 | ★★ | △ (보조) |

### 각 방식 상세

#### 🏆 수중 압력식 (Submersible pressure) ← **최우선 권장**
- **원리**: 다이어프램 압력 센서를 수조 바닥에 침수, 정수압 (ρgh) 측정
- **장점**:
  - 외부 환경(바람·온도) 영향 적음 — 물이 thermal mass로 안정화
  - 옥외 자연 노출 OK (센서 자체가 IP68)
  - 한국 겨울 안정 (수중이라 -20°C 외기 무관, 다만 결빙 시 위험)
  - 4-20mA 표준 출력 → nRF52832 SAADC 직결 용이
- **단점**:
  - 케이블이 항상 수중 (UV·물때 영향)
  - 조류·이끼 부착 시 점진 오차 (연 1회 청소 권장)
  - 결빙 위험 시 손상 가능 → 동결심도 아래 또는 단열 필요
- **출력**: 4-20mA (가장 흔함), RS485, 0-10V
- **단가**: 8~15만 (중국 일반) / 30~50만 (산업급)

#### 초음파 비접촉 (Ultrasonic)
- **원리**: 수조 상단 트랜스듀서, 음파 ToF로 거리 측정
- **장점**:
  - 비접촉 → 센서 침수 안 함, 오염 영향 적음
  - 설치 쉬움 (탱크 상단 마운트)
  - 가격 다양 (저가 JSN-SR04T 1만 ~ 산업급 30만)
- **단점**:
  - **외기 온도 보정 필수** (음속 c=331+0.6T m/s)
  - 결로/김 발생 시 오차
  - 강풍·소용돌이로 거품 → 오차
  - 한국 겨울 결빙 시 표면 반사 변화
  - 트랜스듀서가 옥외 노출 (IP65 필요)
- **출력**: 직렬 거리값 (mm), GPIO TTL, RS485
- **단가**: 5~30만

#### 레이더 비접촉 (Radar)
- **원리**: 마이크로파 (24/80 GHz) FMCW 거리 측정
- **장점**: 날씨 무관, 정확도 ±2mm, 결로·먼지·온도 무관
- **단점**: **단가 100만원~** → 본 예산 초과
- 본 프로젝트에서는 미고려, 향후 산업급 업그레이드 시 검토

#### 플로트 스위치 (Float switch)
- **원리**: 부유 자석 + 리드 스위치, 임계 수위에서 ON/OFF
- **사용처**: **연속 측정의 안전 백업**
  - 압력 센서 고장 시 펌프 강제 OFF (만수)
  - 펌프 강제 ON (저수)
- **단가**: 1.5만/대 (저수+만수 2개 = 3만)

## 2. 한림용인CC 환경 특수 고려사항

### 2-A. 물 출처 → 수질
- **연못 → 펌프 → 고가수조** (호수 물 직접 사용)
- 골프장 호수: 조류·플랑크톤·낙엽·미세 침전물 함유
- **압력센서 다이어프램 fouling 가능** → 연 1~2회 청소 필요
- 초음파는 비접촉이라 fouling 영향 적음 (단, 트랜스듀서 결로 별도 이슈)

### 2-B. 한국 겨울 (-20°C 가능)
- **결빙 위험**: 고가수조는 옥외 노출 → 상부 결빙 가능
- **압력센서**: 수중에 있으면 결빙 영향 적음, 다만 **수면 결빙 시 압력 왜곡** (얼음 무게가 추가)
  - 대안: 센서를 동결심도 아래 (예: 탱크 바닥 50cm 위)에 설치
- **초음파**: 수면 얼음이 있으면 얼음 표면 반사 → 실제 수위 측정 불가
- **저장탱크 (지하·반지하)**: 결빙 가능성 낮음, 압력센서 적합

### 2-C. 옥외 노출
- **압력센서**: 케이블만 노출 → UV-resistant 마린 케이블 사용
- **초음파**: 트랜스듀서 자체 옥외 노출 → IP65/IP67 등급 필수
- 함체 (BOM 7개) 모두 IP65 견적 반영됨 ✅

### 2-D. 낙뢰
- 각 노드 SPD (낙뢰 보호) BOM 포함됨 (-25만 견적)
- 케이블 길이 긴 압력센서가 낙뢰 리스크 약간 ↑ → SPD 필수

### 2-E. 동물·해충
- 케이블 외피: 쥐·다람쥐 갉아먹는 경우 있음 → **금속 conduit 또는 metal-armored 케이블** 권장 (저장탱크 외부 노출 구간)

## 3. 권장안 (1순위 → 3순위)

### 🥇 1순위: **수중 압력식 (4-20mA) + 플로트 백업**
**구성**:
- 메인: 수중 압력 센서 5대 (탱크당 1) — 연속 수위 측정
- 백업: 플로트 스위치 5쌍 (저수+만수) — 펌프 강제 제어 + 압력센서 고장 알림

**이유**:
- 견적서가 이미 이 구성 채택 (BOM: 압력센서 5 × 8만 + 플로트 5 × 1.5만)
- 옥외 환경에 가장 안정
- 정확도 ±5~10mm 충분 (수만 리터 탱크에 1cm 이내 충분)
- 4-20mA → nRF52832 SAADC 직결 단순

**단점 + 대응**:
- 조류 fouling → 연 1~2회 청소 (시설팀 매뉴얼화)
- 결빙 → 센서 위치 바닥 +50cm
- 케이블 UV → 마린급 케이블 사용

### 🥈 2순위: **초음파 비접촉 + 플로트 백업**
**구성**:
- 메인: 초음파 트랜스듀서 5대 (탱크 상단)
- 백업: 플로트 스위치 5쌍

**이유**:
- 센서 비접촉 → 청소 부담 적음
- 케이블이 짧음 (탱크 상단 → 함체)
- **다만 한국 겨울 결빙 + 수면 거품 시 오차**

**단점**:
- 트랜스듀서 결로 → 가열 또는 단열
- 결빙 시 측정 불가
- 외기 온도 보정 알고리즘 필요
- 1순위보다 trade-off 많음

### 🥉 3순위: **압력 + 초음파 이중 측정 (산업급 옵션)**
- 두 방식 동시 사용, 교차 검증
- 단가 ↑↑ → 산업급 1차 구축 (1,000만원, PDF 8번 단계별 권장) 시 적용
- 1차 (1개소만) 적용해 운용 검증 후 2차 확장

## 4-A. 5m 깊이 선정 시 핵심 체크포인트

### A. 측정 범위 = 0-5m가 아니라 **0-7m 권장**
- 5m 만수 시 다이어프램 100% 압력 → 장기 신뢰성 ↓
- 0-7m 모델 사용 시 5m = 71% → 다이어프램 여유
- 정확도 ±0.5% FS × 7m = ±35mm (충분)

### B. 케이블 길이 산정
```
탱크 바닥 (센서) → 탱크 상단 (1m 외부) → 함체 (2m) + 서비스 루프 (2m)
= 5m + 1m + 2m + 2m = 10m
```
**주문 시 케이블 길이 10m 명시** (1m 단위 추가 비용 보통 5,000~10,000원/m).

### C. 벤트 튜브 (Vent tube) 필수
- 4-20mA 수중 압력 센서 케이블 내부에 **작은 통기 튜브** 포함
- 대기압 변동 → 절대압이 아닌 **게이지압**으로 자동 보정
- 함체 끝에 **벤트 필터 (방수+통기)** 부착 필수
- 함체 안에 튜브 입구가 갇히면 ±50mm 오차 발생

### D. 다이어프램 보호망 (Cap)
- 호수 물 → 모래·낙엽·이물질 → 다이어프램 직접 접촉 시 손상
- **stainless steel 보호망** 옵션 추가 (+10,000~20,000원/대)
- Holykell·KELLER 모두 옵션 제공

## 4-C. 즉시 액션 (자재 발주 트랙)

### Step 1 — 샘플 1대 발주
- **모델**: Holykell HPT604, 측정 범위 **0-7m**, 출력 **4-20mA**, 케이블 **10m**

### Step 2 — 사내 테스트 (1주)
- nRF52832 + 250Ω 정밀저항 + SAADC 측정 회로 구성
- 수직 호스로 0~5m 수두 시뮬레이션 (양동이 + PVC 파이프)
- 검증 항목:
  - [ ] 0m·1m·3m·5m 정적 정확도
  - [ ] 측정 반복성 (24시간 동일 수위 모니터링)
  - [ ] 온도 변화 (실내 vs 야외) 영향
  - [ ] LoRa 노드 통합 (1분 주기 측정·전송)
  - [ ] 전력 소모 (측정 시·idle)

### Step 3 — 5대 일괄 발주 (테스트 OK 후)
- 동일 사양 5대 + 벤트필터 5개 + 보호망 5개
- 5대 일괄 시 5~10% 단가 인하 협상 가능
- 납기: 알리 1.5주 / 국내 재고 시 즉시

## 5. nRF52832 LoRa 노드 통합

### 4-20mA 인터페이스 (가장 단순)
```
[압력센서 4-20mA] --- [250Ω 정밀저항] --- [GND]
                         |
                  [전압 1-5V] --> nRF52832 SAADC pin
                         |
                  [TVS diode 보호]
```
- nRF52832 SAADC 12-bit, 1-5V 범위 → 분해능 ~1mV → 0.025% 측정 가능
- 측정 코드 ~10 줄 (Zephyr ADC API)
- 전력: 측정 시만 센서 ON (relay 또는 BJT 스위치) → 평균 <1mA

### 측정 빈도
- 1분에 1회 측정 → LoRa 전송 (8 byte payload)
- 0.3 kbps air rate에서 ~250ms 송신 시간
- 24시간 = 1440 측정, 평균 전류 매우 낮음 (배터리 노드 가능)

### 전원 옵션
- AC 220V 인근: SMPS 24V → 5V LDO (견적 BOM)
- 솔라+배터리 옵션: LiFePO4 12V 6Ah + 솔라 패널 20W (옥외 원격 노드용, +75만/대)

## 6. 결정 사항·확인 필요

### 즉시 결정
- [ ] **메인 수위 센서: 수중 압력식 4-20mA** (1순위 권장 채택)
- [ ] **백업: 플로트 스위치 (저수+만수)** ★ 필수
- [ ] **측정 빈도: 1분/회** (조정 가능)

### 발주자 협의
- [ ] 탱크 깊이 → 센서 측정 범위 결정 (0-5m vs 0-10m vs 0-15m)
- [ ] 정확도 요구 (±5mm vs ±50mm — 운용 임계값 설정에 영향)
- [ ] 청소 주기 합의 (연 1~2회 시설팀 작업)

### 제품 발주
- [ ] 5대 일괄 발주 전 1대 샘플 입수 → 사내 테스트 (1주)
- [ ] 케이블 길이 확정 (탱크 깊이 + 함체까지 거리 + 여유 1m)
