## Level 3 — Tech Verification (실제 검증 결과)

**목표**: "기술적으로 가능한가"의 실증 데이터를 본다. **이미 5/8에 Phase 1A·1B 완료된 핵심 자료**.

### ⑩ `microGPT/01_검증절차.md` (340줄, 15분) ⭐ 실증 1
- **답**: Karpathy 200줄 GPT를 PC에서 실제 실행한 결과
  - Loss 3.37 → 2.65 (1000 step)
  - 파라미터 실측: **4,192**
  - 추론: token당 0.510 ms (PC)
  - 메모리: FP32 16.4KB / INT8 4.1KB
- **읽는 이유**: 가설 1 (탑재 가능성)의 **돌이 깨졌는지 확인**

### ⑪ `통합검증/01_SRAM_파라미터_매트릭스.md` (178줄, 10분) ⭐ 확장 분석
- **답**: SRAM × 파라미터 × 양자화 매트릭스 → **Korean-Small (154K params, INT8 155KB) 권장 결정 근거**
- **읽는 이유**: microGPT 4K는 PoC이고, **실제 AI FanStick은 Korean-Small 154K로 간다**는 다리

### ⑫ `aiFanStick_차세대/01_검증절차.md` (271줄, 10분)
- **답**: Phase 2 (보드 도착 후) 절차 — hello_world → C++ 포팅 → SRAM·추론 시간 측정
- **상태**: ⬜ 보드 입수 대기 중 (사용자 직접 구매 액션 필요)
- **읽는 이유**: 다음 액션이 뭔지 (ESP32-S3-DevKit-C-1 구매 1~2만원)

### ⑬ `통합검증/02_Stage4_영업매핑.md` (163줄, 10분) ⭐ 비즈니스 다리
- **답**: 기술 검증 → Stage 4 (1,500만) 영업 패키지로 어떻게 흐르는가

## 검토 시 권장 작업 방식

1. **메모지 1장 준비**: 각 파일 읽을 때 "놀란 점·의문점·수정 후보" 한 줄씩 기록
2. **순서대로**: L0→L1→L2→L3→L4. 역행 최소화 (의존성 깨짐)
3. **L2 시장조사는 폭독 OK**: 11섹션 README만 정독, 나머지 3 파일은 표·그림만 봐도 됨
4. **L4 학습설계는 정독**: 실제 의사결정의 근거가 여기 모여있음
5. **메모 통합**: 검토 종료 시 `00_검토메모_2026-05-11.md` 형식으로 본인 메모를 vault에 추가 (선택)
