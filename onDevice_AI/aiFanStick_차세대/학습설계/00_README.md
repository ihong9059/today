# 학습설계 폴더

## 한 줄 정의

**"AI FanStick의 실제 용도(K-POP 콘서트 음성 비서 + LED 동기화)에 맞춰 어떤 모델을 어떻게 학습·배포할 것인가"** 의 설계 문서.

## 배경

본 vault `microGPT/01_검증절차.md` Phase 1A·1B 완료 (5/8) → "ESP32-S3에 microGPT 4K 파라미터 탑재 가능" 검증.

그러나 **검증 = 가능성**이지 **AI FanStick 실제 응용**이 아님. 실제 콘서트 시나리오에 쓸 모델은 다음 갭이 있음:

| 항목 | microGPT (검증) | AI FanStick (필요) | 갭 |
|---|---|---|---|
| 학습 데이터 | 영문 이름 32K개 | 한국어 콘서트 QA 500~2000쌍 | **도메인 전체 다름** |
| vocab | 27 (영문 char) | 1000~5000 (한국어 BPE) | **40~200배** |
| 표현력 | 4K params (이름 생성) | QA + LED 색상 추출 | **불충분** |
| 응답 구조 | 단순 텍스트 | `{response, led_color}` JSON | **구조화 필요** |
| 실행 위치 | ESP32-S3 (검증 대상) | 응원봉 검토서는 폰의 Gemma 2B 가정 | **위치 불일치** |

→ 이 폴더는 **갭 4개를 어떻게 메울지** 4가지 가능 경로로 검토.
