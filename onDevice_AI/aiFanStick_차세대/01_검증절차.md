- 시간 4~8시간

## Step 1 — ESP32-S3 보드 입수 (사용자 직접, 1~2주)

### 구매 옵션

| 모델 | 가격 | 특징 | 권장 |
|---|:-:|---|:-:|
| ESP32-S3-DevKit-C-1 | 1~2만 | 기본형, SRAM 520KB | ★★ |
| ESP32-S3-N16R8 | 2~3만 | PSRAM 8MB 추가, 더 큰 모델 가능 | ★★★ |
| ESP32-S3 N32R8 | 3~4만 | Flash 32MB | ★★★ |

→ **권장**: ESP32-S3-N16R8 (PSRAM 8MB로 1MB SLM도 가능, 향후 확장성)

### 구매 채널
- 알리익스프레스 (저렴, 1~2주 배송)
- 디바이스마트 / 엘레파츠 / 메카솔루션 (국내, 2~3일)
- 디지키 / 마우저 (글로벌, 1주)

## Step 2 — hello_world 검증 (1시간)

### 절차 (Arduino IDE 기준, 사용자 친숙한 환경)

```cpp
// arduino-cli 또는 Arduino IDE
void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  Serial.println("Hello ESP32-S3");
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
```

### 또는 ESP-IDF

```bash
cd ~/esp32-s3/hello_world
idf.py set-target esp32s3
idf.py build
idf.py -p COM3 flash monitor
```

## Step 3 — microGPT 포팅 시도 (4~8시간)

### 사전 조건
- microGPT/01_검증절차.md Phase 1A·1B 완료
- 학습 가중치 .bin 또는 .h 파일 추출 완료

### 절차

#### 3-1. 가중치 변환 (Python → C 헤더)
```python
# 학습된 가중치를 ESP32에 flash 가능한 형식으로 변환
import numpy as np
weights = model.state_dict()
with open('weights.h', 'w') as f:
    f.write('// microGPT weights for ESP32-S3\n')
    for name, tensor in weights.items():
        arr = tensor.numpy().flatten()
        f.write(f'const float {name}[{len(arr)}] = {{\n')
        f.write(', '.join(map(str, arr)))
        f.write('\n};\n')
```

#### 3-2. C++ 추론 코드 작성
- numpy.matmul → C++ matmul 함수
- softmax → 지수 lookup table
- 토큰화 → 간단한 vocab 테이블

#### 3-3. 빌드 + 플래시 + 측정
- 메모리 사용량 (Build 결과)
- 추론 시간 (millis() 측정)
- 정확도 (생성된 텍스트가 PC와 비슷한가)

## Step 4 — AI FanStick 적용 시나리오 (2시간)

### AI FanStick 차세대 기능 가설

```
[현재 AI FanStick (특허 출원)]
- ESP32-C3 기반
- BLE Mesh 통신
- LED 효과 출력
- 음성 인식 → 클라우드 API → BLE 명령

[차세대 AI FanStick (검증 후)]
- ESP32-S3-N16R8 기반 (칩 변경)
- BLE Mesh 통신 (유지)
- LED 효과 출력 (유지)
- microGPT 변종 탑재 → 클라우드 API 0회
- "외부 인터넷 0%" 카피 검증
```

### 적용 시나리오 (콘서트장)

```
1. 사용자: "박상민님 응원해!" 음성 입력
2. ESP32-S3: 음성 → 텍스트 (Whisper Tiny 또는 자체 모델)
3. ESP32-S3 microGPT: 응원 컨텍스트 분석 → 명령 생성
4. BLE Mesh: 다른 응원봉에 명령 전파
5. LED: 동기 효과 (반짝임·색 변화)

→ 인터넷 끊겨도 동작 (콘서트장 특화)
```
