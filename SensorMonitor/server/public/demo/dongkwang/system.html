🔧 예지정비 대상 제품

⚡ MCCB (배선용차단기)

모니터링 항목 트립 횟수, 온도, 접점 저항
예측 지표 잔여 수명 (회)
센서 타입 CT + 온도

🛡️ ELCB (누전차단기)

모니터링 항목 누전 감지 횟수, 테스트 결과
예측 지표 교체 권고 시점
센서 타입 디지털 입력

🔄 릴레이

모니터링 항목 동작 횟수, 접점 상태, 코일 온도
예측 지표 고장 확률 (%)
센서 타입 카운터 + 온도

⏱️ 타이머

모니터링 항목 동작 정확도, 설정 오차
예측 지표 열화 상태
센서 타입 정밀 타이밍

🔌 전자개폐기

모니터링 항목 개폐 횟수, 아크 발생, 온도
예측 지표 잔여 수명 (회)
센서 타입 CT + 카운터 + 온도
