설비 정보

설비명임팩트크러셔 (Impact Crusher)
용도암석/골재 2차 파쇄
처리량150~300 ton/h
모터 출력200~315 kW
회전수600~900 RPM
입도 범위입력 300mm / 출력 0~40mm

센서 배치

진동 센서2EA (메인 베어링 양측)
온도 센서2EA (베어링 온도)
전류 센서1EA (모터 전류)
모니터링 항목진동, 온도, 전류, 회전수
예측 기능베어링 RUL, 해머/라이너 마모

설비 정보

설비명진동스크린 (Vibrating Screen)
용도입도별 선별 분류
처리량200~400 ton/h
모터 출력15~30 kW x 2
진동수850~1000 RPM
스크린 면적6~12 m²

센서 배치

진동 센서2EA (진동 모터)
온도 센서1EA (모터)
전류 센서1EA (모터 전류)
모니터링 항목진동 진폭, 주파수, 온도
예측 기능베어링 상태, 스크린 망 상태

설비 정보

설비명필터프레스 (Filter Press)

처리량5~20 m³/cycle
최대 압력15~25 bar
여과 면적100~500 m²
사이클 시간30~60 분

센서 배치

예측 기능여과포 상태, 유압 이상
최적화압착 시간 자동 조절

Edge AI Gateway 사양

현장에서 실시간 분석을 수행하는 핵심 장비

🖥️ 하드웨어 사양

  • 프로세서ARM Cortex-A72 + DSP
  • AI 가속NPU 2 TOPS
  • 메모리4GB DDR4
  • 아날로그 입력16ch (4-20mA, 0-10V)
  • 디지털 I/O16ch 입력, 8ch 출력
  • 전원24VDC, 20W

📊 AI 분석 기능

  • FFT 분석실시간 주파수 분석
  • Envelope 분석베어링 결함 검출
  • Autoencoder이상 패턴 탐지
  • RUL 예측잔여수명 예측
  • 마모율 추정부품 마모 진행률
  • 샘플링최대 51.2 kHz

  • Modbus RTU/TCP지원
  • MQTTAWS IoT, Azure
  • HTTP RESTAPI 제공
  • OPC-UA옵션
  • 로컬 저장7일 (32GB)
  • 보안TLS 1.3
