4-Layer 스마트 플라즈마 시스템

L1

설비 계층 (Equipment Layer)

플라즈마 장비 핵심 구성요소 및 센서 시스템

RF 전원 (13.56MHz) 매칭 네트워크 플라즈마 챔버 진공 펌프 MFC 가스 제어 PLC 시퀀스
⬇️
L2

센서 계층 (Sensor Layer)

고정밀 센서를 통한 실시간 데이터 수집

진공 게이지 (100Hz) RF 파워미터 임피던스 모니터 온도 센서 (다채널) OES 광학센서 (1kHz) 아크 감지기 (10kHz)
⬇️
L3

Edge AI 계층 (Processing Layer)

ARM Cortex-M4 기반 실시간 분석 및 제어

실시간 FFT 분석 이상 감지 알고리즘 아킹 보호 제어 자동 매칭 최적화 Modbus RTU/TCP OPC-UA 통신
⬇️
L4

플랫폼 계층 (Cloud Platform)

중앙 관제, AI 분석, 원격 서비스 제공

실시간 모니터링 AI 예지정비 웹 대시보드 원격 진단 SMS/카카오 알림 모바일 앱
