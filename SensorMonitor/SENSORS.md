# 스마트폰 센서 가이드

## 개요

스마트폰에는 다양한 센서가 내장되어 있어 디바이스의 움직임, 환경, 위치 등을 감지합니다.
이 문서는 Galaxy M53 5G (SM-M536S)에 탑재된 센서들의 상세 설명과 활용 방법을 다룹니다.

---

## 1. 모션 센서 (Motion Sensors)

### 1.1 가속도계 (Accelerometer)

| 항목 | 내용 |
|------|------|
| **센서명** | LSM6DSL Accelerometer |
| **제조사** | STMicroelectronics |
| **타입** | android.sensor.accelerometer |
| **출력값** | X, Y, Z축 가속도 (m/s²) |
| **범위** | -19.6 ~ +19.6 m/s² (약 ±2g) |

#### 작동 원리
- MEMS(미세전자기계시스템) 기술 사용
- 미세한 질량체의 움직임을 전기 신호로 변환
- 중력 가속도(9.8 m/s²)를 포함한 총 가속도 측정

#### 출력값 해석
```
X축: 화면을 향해 왼쪽(-)에서 오른쪽(+)
Y축: 화면을 향해 아래(-)에서 위(+)
Z축: 화면 뒤(-)에서 앞(+)

예시 (평평하게 놓은 상태):
X: 0.0, Y: 0.0, Z: 9.8 (중력이 Z축으로 작용)
```

#### 용도
| 용도 | 설명 |
|------|------|
| **화면 회전** | 디바이스 방향 감지로 자동 회전 |
| **만보기** | 걸음 감지 (상하 가속도 패턴 분석) |
| **흔들기 제스처** | 흔들어서 실행취소, 셔플 등 |
| **게임 컨트롤** | 레이싱 게임 핸들 조작 |
| **낙하 감지** | 자유낙하 시 모든 축이 0에 가까워짐 |
| **충격 감지** | 급격한 가속도 변화로 충돌 감지 |

#### 센서 결합 활용
| 결합 센서 | 결합 기능 |
|----------|----------|
| + 자이로스코프 | **정밀 모션 추적**: 드리프트 보정된 자세 추정 |
| + 자력계 | **절대 방향**: 나침반 + 기울기 보정 |
| + GPS | **차량 네비게이션**: 터널 내 위치 추정 |
| + 기압계 | **층간 이동 감지**: 엘리베이터/계단 구분 |

### 1.2 자이로스코프 (Gyroscope)

| 항목 | 내용 |
|------|------|
| **센서명** | LSM6DSL Gyroscope |
| **제조사** | STMicroelectronics |
| **타입** | android.sensor.gyroscope |
| **출력값** | X, Y, Z축 각속도 (rad/s) |
| **범위** | ±2000 °/s |

#### 작동 원리
- 코리올리 효과 이용
- 회전 시 진동하는 질량체에 작용하는 힘 측정
- 가속도계보다 빠른 회전 감지 가능

#### 출력값 해석
```
X축 (Roll): 화면 좌우 기울기 회전
Y축 (Pitch): 화면 앞뒤 기울기 회전
Z축 (Yaw): 수평면에서의 회전

단위: rad/s (라디안/초)
1 rad/s ≈ 57.3 °/s
```

#### 용도
| 용도 | 설명 |
|------|------|
| **VR/AR** | 머리 움직임 추적, 360도 뷰 |
| **게임** | FPS 게임 조준, 드론 시뮬레이터 |
| **사진 촬영** | 손떨림 보정 (OIS 보조) |
| **제스처 인식** | 손목 회전으로 기능 실행 |
| **네비게이션** | 회전 방향 감지 |

#### 센서 결합 활용
| 결합 센서 | 결합 기능 |
|----------|----------|
| + 가속도계 | **센서 퓨전**: 6축 자세 추정 (Roll, Pitch, Yaw) |
| + 가속도계 + 자력계 | **9축 자세 추정**: 절대 방향 + 안정적인 추적 |
| + 카메라 | **영상 안정화**: EIS(전자식 손떨림 보정) |

### 1.3 자력계 / 지자기 센서 (Magnetometer)

| 항목 | 내용 |
|------|------|
| **센서명** | MMC5633 Magnetometer |
| **제조사** | Memsic |
| **타입** | android.sensor.magnetic_field |
| **출력값** | X, Y, Z축 자기장 강도 (μT) |
| **범위** | ±4900 μT |

#### 작동 원리
- 홀 효과 또는 자기저항 원리 사용
- 지구 자기장 감지 (약 25-65 μT)
- 주변 금속이나 전자기기의 영향을 받음

#### 출력값 해석
```
지구 자기장 강도: 약 25-65 μT (위도에 따라 다름)
한국(서울): 약 50 μT

출력값 예시:
X: 15.5, Y: -25.3, Z: 42.1 (μT)
```

#### 용도
| 용도 | 설명 |
|------|------|
| **나침반** | 지자기 방향으로 북쪽 감지 |
| **지도 회전** | 사용자가 바라보는 방향으로 지도 회전 |
| **AR 네비게이션** | 화살표 방향 표시 |
| **금속 탐지기** | 주변 금속에 의한 자기장 변화 감지 |

#### 보정 필요성
```
하드 아이언 보정: 디바이스 내부 자성 물질 보정
소프트 아이언 보정: 외부 자성 물질 영향 보정

보정 방법: 8자 모양으로 디바이스 회전
```

#### 센서 결합 활용
| 결합 센서 | 결합 기능 |
|----------|----------|
| + 가속도계 | **틸트 보정 나침반**: 기울어져도 정확한 방향 |
| + GPS | **진행 방향**: 이동 중 방향 + 정지 시 나침반 |
| + 자이로스코프 | **안정적인 방향**: 드리프트 보정된 방향 추적 |

### 1.4 회전 벡터 센서 (Rotation Vector)

| 항목 | 내용 |
|------|------|
| **센서명** | Samsung Rotation Vector Sensor |
| **타입** | android.sensor.rotation_vector |
| **출력값** | 쿼터니언 (x, y, z, w) + 정확도 |

#### 작동 원리
- **센서 퓨전**: 가속도계 + 자이로스코프 + 자력계 결합
- 쿼터니언으로 3D 방향 표현
- 칼만 필터로 노이즈 제거

#### 출력값 해석
```
쿼터니언: (x, y, z, w)
- 4개의 값으로 3D 회전 표현
- ||(x, y, z, w)|| = 1 (단위 쿼터니언)

오일러 각도로 변환 가능:
- Azimuth (방위각): 0-360° (북쪽 기준)
- Pitch (피치): -180° ~ 180°
- Roll (롤): -90° ~ 90°
```

#### 용도
| 용도 | 설명 |
|------|------|
| **VR/AR** | 헤드셋 방향 추적 |
| **3D 게임** | 디바이스를 컨트롤러로 사용 |
| **파노라마 촬영** | 카메라 방향 추적 |
| **스카이맵** | 하늘을 비추면 해당 위치의 별자리 표시 |

---

### 1.5 중력 센서 (Gravity Sensor)

| 항목 | 내용 |
|------|------|
| **센서명** | Samsung Gravity Sensor |
| **타입** | android.sensor.gravity |
| **출력값** | X, Y, Z축 중력 가속도 (m/s²) |

#### 작동 원리
- 가속도계에서 선형 가속도 제거
- 항상 약 9.8 m/s² 크기 유지
- 중력 방향만 표시

#### 출력값 예시
```
평평하게 놓음: X: 0, Y: 0, Z: 9.8
세로로 세움: X: 0, Y: 9.8, Z: 0
왼쪽으로 기울임: X: -9.8, Y: 0, Z: 0
```

#### 용도
| 용도 | 설명 |
|------|------|
| **화면 방향** | 4방향 화면 회전 결정 |
| **수평계** | 건설/인테리어용 수평 측정 |
| **기울기 측정** | 각도기 앱 |

---

### 1.6 선형 가속도 센서 (Linear Acceleration)

| 항목 | 내용 |
|------|------|
| **센서명** | Samsung Linear Acceleration Sensor |
| **타입** | android.sensor.linear_acceleration |
| **출력값** | X, Y, Z축 선형 가속도 (m/s²) |

#### 작동 원리
```
선형 가속도 = 총 가속도 - 중력
Linear Acceleration = Accelerometer - Gravity
```

#### 용도
| 용도 | 설명 |
|------|------|
| **순수 움직임 감지** | 중력 영향 없이 이동 감지 |
| **차량 가속 측정** | 0-100km/h 가속 시간 측정 |
| **충격 감지** | 낙하/충돌 시 급격한 값 변화 |
| **제스처 인식** | 손 움직임 패턴 분석 |

### 2.2 근접 센서 (Proximity Sensor)

| **전력 절약** | 주머니/가방 속 감지하여 화면 끄기 |
| **제스처** | 손 흔들어서 알림 확인 (에어 제스처) |

#### 작동 원리

- 어둡고 + 가까우면 = 주머니

#### 용도
| 용도 | 설명 |
|------|------|
| **오작동 방지** | 주머니에서 터치 비활성화 |
| **전력 절약** | 주머니에서 화면 끄기 유지 |

## 6. 센서 결합 응용 (Sensor Fusion Applications)

### 6.1 실내 네비게이션 (PDR: Pedestrian Dead Reckoning)

```
사용 센서: 가속도계 + 자이로스코프 + 자력계 + (기압계)

작동 원리:
1. 걸음 감지 (가속도계)
2. 보폭 추정 (가속도 크기)
3. 방향 추적 (자이로 + 자력계)
4. 층 변화 감지 (기압계)

결과: GPS 없이 실내 위치 추적
```

### 6.2 운동 분류 (Activity Classification)

```
사용 센서: 가속도계 + 자이로스코프

분류 가능한 활동:
- 정지 (Standing)
- 걷기 (Walking)
- 달리기 (Running)
- 계단 오르기 (Climbing)
- 자전거 (Cycling)
- 차량 이동 (Driving)

방법: 머신러닝 모델로 센서 패턴 분류
```

### 6.3 낙상 감지 (Fall Detection)

```
사용 센서: 가속도계 + 자이로스코프

낙상 패턴:
1. 자유낙하 (가속도 ≈ 0)
2. 충격 (가속도 급증, >3g)
3. 정지 (움직임 없음)

활용: 노인 안전, 응급 서비스 호출
```

### 6.4 차량 충돌 감지 (Crash Detection)

```
사용 센서: 가속도계 + 자이로스코프 + GPS + 마이크

감지 기준:
- 급격한 감속 (>4g)
- 급격한 회전
- 속도 급감 (GPS)
- 충돌음 (마이크)

활용: 자동 긴급 전화 (iPhone 14+, Pixel)
```

### 6.5 수면 추적 (Sleep Tracking)

```
사용 센서: 가속도계 + (심박 센서)

측정 항목:
- 뒤척임 횟수 (가속도 패턴)
- 수면 단계 (움직임 + 심박)
- 코골이 (마이크)

활용: 수면 품질 분석, 최적 기상 시간 알람
```

## 7. 센서 데이터 활용 팁

### 7.1 샘플링 레이트 선택

| 용도 | 권장 레이트 | 설명 |
|------|------------|------|
| UI 반응 | NORMAL (5Hz) | 화면 회전 등 |
| 게임 | GAME (50Hz) | 부드러운 조작 |
| VR/AR | FASTEST (100Hz+) | 지연 최소화 |

### 7.2 배터리 최적화

```java
// 필요할 때만 센서 등록
onResume() → registerListener()
onPause() → unregisterListener()

// 적절한 샘플링 레이트 사용
SensorManager.SENSOR_DELAY_NORMAL  // 저전력
SensorManager.SENSOR_DELAY_UI      // 일반
SensorManager.SENSOR_DELAY_GAME    // 게임
SensorManager.SENSOR_DELAY_FASTEST // 고정밀
```

### 7.3 노이즈 필터링

```
저역 통과 필터 (Low-pass filter):
- 고주파 노이즈 제거
- 부드러운 값 출력
- 예: 중력 추출

고역 통과 필터 (High-pass filter):
- 저주파(중력) 제거
- 급격한 변화만 감지
- 예: 충격 감지

칼만 필터 (Kalman filter):
- 센서 퓨전에 사용
- 예측 + 측정 결합
- 최적 상태 추정
```
