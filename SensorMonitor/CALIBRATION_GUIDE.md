# Sensor Monitor 캘리브레이션 가이드

## 개요

스마트폰의 Tilt(기울기) 3D 모델이 실제 폰의 자세와 일치하도록 캘리브레이션하는 방법입니다.

**대시보드 URL**: http://52.78.119.132:5000

---

## 빠른 시작 (1분)

1. 대시보드 접속
2. 폰을 **세로로 똑바로 세움**
3. `[① 원위치 설정]` 버튼 클릭
4. **끝!**

---

## 3D 모델 설명

### Tilt / Orientation (왼쪽)
- **센서**: Gravity 센서
- **측정**: Roll (좌우 기울기), Pitch (앞뒤 기울기)
- **용도**: 폰이 얼마나 기울었는지 확인

### Rotation (오른쪽)
- **센서**: Orientation 센서
- **측정**: Yaw (방위각), Pitch, Roll
- **용도**: 폰이 어느 방향(동서남북)을 향하는지 확인

### Vibration
- **센서**: Linear Acceleration (중력 제외)
- **측정**: 순수 진동/움직임
- **용도**: 폰이 움직이거나 진동하는지 확인

---

## 상세 캘리브레이션 절차

### 준비물
- 스마트폰 (SensorMonitor 앱 실행 중)
- 평평한 수평면 (책상 등)
- 웹 브라우저 (대시보드 접속용)

---

### Step 1: 원위치 설정 (필수)

**목적**: 폰의 기준 자세 설정

**절차:**
1. 스마트폰을 **세로로 똑바로 세움** (화면이 정면을 향함)
2. 수평면에 기대거나 손으로 고정
3. 대시보드에서 `[① 원위치 설정]` 버튼 클릭
4. 버튼이 **녹색**으로 변하면 성공

**폰 자세:**
```
     ┌─────────┐
     │    ▲    │  ← 상단 (노란색 표시)
     │         │
     │  화면   │  ← 정면을 향함 (파란색)
     │         │
     │         │
     └─────────┘
        ━━━━
       테이블
```

**예상 디버그 값:**
| 항목 | 예상 값 |
|------|---------|
| gx | ≈ 0 |
| gy | ≈ 9.8 |
| gz | ≈ 0 |
| 보정 후 Roll | ≈ 0° |
| 보정 후 Pitch | ≈ 0° |

---

### Step 2: 오른쪽 90° 테스트

**목적**: Roll 동작 확인

**절차:**
1. 원위치에서 폰을 **오른쪽으로 90° 눕힘** (오른쪽 면이 바닥)
2. 버튼 클릭 없이 **디버그 값 확인**

**폰 자세 (정면에서 봤을 때):**
```
  ┌──────────────────┐
  │                  │
  │   화면 (정면)    │  ← 오른쪽 면이 바닥
  │                  │
  └──────────────────┘
         ━━━━
        테이블
```

**예상 디버그 값:**
| 항목 | 예상 값 |
|------|---------|
| gx | ≈ -9.8 |
| gy | ≈ 0 |
| gz | ≈ 0 |
| 보정 후 Roll | ≈ 86~90° |
| 보정 후 Pitch | ≈ 0° |

**3D 모델 확인:**
- Tilt 모델이 **오른쪽으로 기울어져야 함**
- 왼쪽 면(초록색)이 보여야 함

---

### Step 3: 뒤로 90° 테스트

**목적**: Pitch 동작 확인

**절차:**
1. 다시 **원위치 자세**로 세움 (세로로 똑바로)
2. 폰을 **뒤로 90° 눕힘** (화면이 하늘을 향함)
3. 버튼 클릭 없이 **디버그 값 확인**

**폰 자세:**
```
  원위치 (세로)              뒤로 90° 눕힘

  ┌─────────┐
  │    ▲    │               ┌─────────┐
  │         │      →        │         │  ← 화면이 하늘 ↑
  │  화면   │   뒤로        │    ▲    │
  │         │   눕힘        └─────────┘
  │         │                    │
  └─────────┘               ━━━━━┷━━━━━
     ━━━━                      테이블
    테이블
```

**예상 디버그 값:**
| 항목 | 예상 값 |
|------|---------|
| gx | ≈ 0 |
| gy | ≈ 0 |
| gz | ≈ 9.8 |
| 보정 후 Roll | ≈ 0° |
| 보정 후 Pitch | ≈ 90° |

**3D 모델 확인:**
- Tilt 모델이 **뒤로 눕혀져야 함**
- 밑면(마젠타색)이 보여야 함

## 트러블슈팅

### 문제: 3D 모델이 반대로 움직임

**원인:** 폰을 거꾸로 들고 캘리브레이션함
**해결:** 폰을 올바른 자세로 들고 `[① 원위치 설정]` 다시 클릭

### 문제: 3D 모델이 너무 많이 회전함

**원인:** 센서 노이즈 또는 잘못된 캘리브레이션
**해결:** 폰을 안정적인 곳에 놓고 다시 캘리브레이션

### 문제: 디바이스 전환 시 3D 모델이 이상함

**원인:** 각 디바이스의 센서 특성이 다름
**해결:** 디바이스 전환 시 자동으로 캘리브레이션 리셋됨, 새로 `[① 원위치 설정]` 클릭

### 문제: 90° 근처에서 3D 모델이 불안정함

**원인:** Gimbal Lock 현상 (수학적 한계)
**해결:** 정상 동작임, 45° 이상 기울이면 일부 축이 고정됨

### 문제: Vibration이 9 m/s²로 나옴

**원인:** Accelerometer 사용 중 (중력 포함)
**해결:** Linear Acceleration 센서가 있는 폰 사용 (자동 선택됨)

### 2. 앱 실행

- http://52.78.119.132:5000 접속

## 기술 정보

### Android 센서 좌표계
```
        Y (위)
        │
        │    폰을 세로로 들었을 때
        │    Y축이 위를 향함
        └──────── X (오른쪽)
       /
      /
     Z (화면 밖으로)
```

### 사용 센서

| 센서 | 용도 | 데이터 |
|------|------|--------|
| Gravity | Tilt (기울기) | gx, gy, gz (m/s²) |
| Orientation | Rotation (방위각) | azimuth, pitch, roll (°) |
| Linear Acceleration | Vibration (진동) | ax, ay, az (m/s²) |

### Roll/Pitch 계산 공식

```javascript
// Roll: 좌우 기울기 (오른쪽으로 눕히면 +)
roll = atan2(-gx, sqrt(gy² + gz²))

// Pitch: 앞뒤 기울기 (뒤로 눕히면 +)
// Roll이 45° 이상이면 0으로 고정 (Gimbal Lock 방지)
pitch = atan2(gz, gy)
```

### 실측 데이터 (Galaxy A23 기준)

| 자세 | gx | gy | gz |
|------|-----|-----|-----|
| 원위치 (세로) | -0.2 | 9.8 | -0.9 |
| 오른쪽 90° | -9.8 | 0.0 | 0.3 |
| 뒤로 90° | 0.0 | 0.0 | 9.8 |
