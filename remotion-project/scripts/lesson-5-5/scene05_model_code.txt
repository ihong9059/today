실제 코드로 모델을 정의해볼게요.

nn.Module을 상속받아 CNN 클래스를 만들어요.
__init__에서 레이어들을 정의해요.

Conv2d는 합성곱 레이어예요.
첫 번째 인자는 입력 채널, 두 번째는 출력 채널이에요.
kernel_size=3은 필터 크기, padding=1은 패딩이에요.
padding=1을 넣으면 크기가 유지돼요.

BatchNorm2d는 배치 정규화예요.
학습을 안정화시키고 더 빠르게 수렴하게 해요.

MaxPool2d는 풀링 레이어예요.
2 곱하기 2 영역에서 최댓값을 뽑아요.

Dropout은 과적합을 방지해요.
0.25면 25% 뉴런을 랜덤하게 끄는 거예요.

forward 함수에서 순서대로 연결해요.
Conv, BatchNorm, ReLU, Pool 순서가 표준이에요.
