역전파 핵심 정리!

순전파: 입력 → 출력, 예측을 만드는 과정
역전파: 출력 → 입력, 그래디언트를 전파하는 과정

연쇄 법칙으로 각 층의 그래디언트를 곱해가며 전파하고,
이 값으로 경사하강법이 가중치를 업데이트해요.

PyTorch 실전 코드는 이렇게 간단해요!
output = model(x)       # 순전파
loss = criterion(output, y)
loss.backward()         # 역전파
optimizer.step()        # 가중치 업데이트

다음 시간에는 활성화 함수를 더 깊이 파헤쳐볼 거예요!
