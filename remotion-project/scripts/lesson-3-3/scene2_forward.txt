역전파를 이해하려면 먼저 순전파를 알아야 해요.

순전파, Forward Propagation은 입력에서 출력 방향으로 계산해요.
입력 x가 들어오면, 가중치 w를 곱하고 편향 b를 더하고,
활성화 함수를 통과해서 다음 층으로 전달되죠.

예를 들어 3층 네트워크라면,
z1 = W1·x + b1, a1 = ReLU(z1)
z2 = W2·a1 + b2, a2 = ReLU(z2)
z3 = W3·a2 + b3, output = Softmax(z3)

이렇게 층층이 통과해서 최종 예측이 나오고,
손실 함수로 정답과의 오차를 계산합니다.

순전파가 예측을 만든다면, 역전파는 그 예측을 개선해요!
