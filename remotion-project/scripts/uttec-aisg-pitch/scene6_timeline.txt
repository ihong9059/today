전체 90일 일정을 의뢰자님께서 한눈에 보실 수 있도록 정리했습니다.

1주에서 2주, Phase 1. 기존 코드 분석 또는 표준 기반 환경 셋업. 1차 미팅으로 분석 결과를 공유드립니다.

3주에서 4주, Phase 2. AISG 2.0 회귀 테스트 베이스 구축. 2차 미팅으로 기존 동작 보존을 확인드립니다.

5주에서 8주, Phase 3. AISG 3.0 신기능 4종을 한 주에 하나씩, 단위 테스트와 함께 구현합니다. 3차 미팅에서 신기능 동작을 직접 시연드립니다. 본 프로젝트의 핵심 구간입니다.

9주에서 10주, Phase 4. 24시간 연속 통합 안정성 테스트. 4차 미팅으로 안정성 데이터를 보고드립니다.

11주에서 12주, Phase 5. 용인 기흥구 현장에서 1차, 2차 실제 ALD 연동 시험. 사무실과 같은 지역이므로 일과 중 왕복이 가능합니다. 5차 미팅 현장 진행.

13주, Phase 6. 디버깅, 안정화, 문서 인계, 최종 검수. 6차 미팅으로 마무리합니다.

2주에 한 번씩 마일스톤 미팅이 있다는 것, 이것이 의뢰자님께 약속드리는 가시성입니다.
