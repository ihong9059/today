특성 맵에 대해 알아볼게요.

합성곱의 출력을 특성 맵, Feature Map이라고 해요.
원본 이미지에서 특정 특징이 어디에 있는지를 나타내는 지도와 같아요.

예를 들어 수직 엣지 커널을 적용하면, 특성 맵에서 밝은 부분이 세로선이 있는 위치예요.

그런데 CNN에서는 커널을 하나만 쓰지 않아요.
여러 개의 커널을 동시에 사용해요.
각 커널이 서로 다른 특징을 감지하거든요.

32개의 커널을 사용하면 32개의 특성 맵이 나와요.
이걸 채널이라고도 불러요.

입력이 28 곱하기 28 흑백 이미지라면 채널이 1개예요.
여기에 32개의 3 곱하기 3 커널을 적용하면
출력은 26 곱하기 26 곱하기 32가 돼요.

처음에는 간단한 선이나 엣지를 감지하지만,
층이 깊어질수록 특성 맵은 더 복잡한 패턴을 담게 돼요.
나중에는 얼굴이나 물체 같은 고수준 특징을 감지하게 되죠.
