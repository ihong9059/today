합성곱 연산이 어떻게 이루어지는지 알아볼게요.

커널이라고 하는 작은 필터가 있어요. 보통 3 곱하기 3 크기예요.
이 커널이 이미지 위를 한 칸씩 이동하면서 계산을 해요.

계산 방법은 간단해요.
커널과 이미지의 해당 영역을 겹쳐 놓고, 같은 위치의 숫자끼리 곱해요.
그리고 모든 곱셈 결과를 더하면 하나의 숫자가 나와요.

예를 들어 볼게요.
3 곱하기 3 이미지 영역에 1, 2, 3, 0, 1, 2, 1, 2, 1 이 있고,
커널에 1, 0, 1, 0, 1, 0, 1, 0, 1 이 있다고 해볼게요.

같은 위치끼리 곱하면, 1 곱하기 1은 1, 2 곱하기 0은 0, 3 곱하기 1은 3, 이런 식이에요.
모두 더하면 8이 나와요.

이 과정을 이미지 전체에서 반복하면 새로운 이미지가 만들어져요.
이걸 특성 맵, Feature Map이라고 불러요.
