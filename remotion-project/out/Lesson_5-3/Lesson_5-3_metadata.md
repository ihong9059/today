## 설명
CNN의 중요한 구성 요소인 풀링과 배치 정규화를 배웁니다.
MaxPooling, AveragePooling, BatchNorm의 원리와 효과를 이해합니다.

📚 이 레슨에서 배우는 내용:
• 풀링(Pooling)의 목적과 종류
• Max Pooling vs Average Pooling
• 풀링의 장점: 계산량 감소, 과적합 방지
• 배치 정규화(Batch Normalization)의 원리
• BatchNorm의 효과: 학습 안정화, 속도 향상

🎯 학습 목표:
1. 풀링이 특성 맵 크기를 줄이는 방법 이해
2. 배치 정규화의 학습 안정화 효과 파악
3. CNN 아키텍처에서 각 레이어의 역할 이해
