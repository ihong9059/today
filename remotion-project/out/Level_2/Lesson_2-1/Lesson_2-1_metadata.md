## 씬 구성

### Scene 1: 인트로 (0:00 ~ 0:38)
- 레슨 소개
- Level 2 시작: AI의 수학적 기초
- 함수 종류 미리보기

### Scene 2: 함수 개념 (0:38 ~ 1:28)
- 자판기 비유: 입력 → 규칙 → 출력
- y = f(x) 수식 소개
- 결정론적 특성 설명

### Scene 3: 일차함수 & 이차함수 (1:28 ~ 2:16)
- 일차함수: y = ax + b (직선, 신경망 기본)
- 이차함수: y = ax² + bx + c (포물선, 손실 함수)
- 기울기의 의미

### Scene 4: 지수함수 & 로그함수 (2:16 ~ 3:04)
- 지수함수: y = eˣ (폭발적 증가, Softmax)
- 로그함수: y = log(x) (천천히 증가, Cross-Entropy)
- 역함수 관계

### Scene 5: 시그모이드 함수 (3:04 ~ 3:49)
- σ(x) = 1/(1 + e⁻ˣ)
- 출력 범위: 0~1 (확률 해석)
- S자 커브, 이진 분류 활용

### Scene 6: ReLU 함수 (3:49 ~ 4:42)
- ReLU(x) = max(0, x)
- 음수 → 0, 양수 → 그대로
- 빠른 계산, 기울기 소실 방지
- 현대 딥러닝 표준

### Scene 7: 아웃트로 (4:42 ~ 5:32)
- 오늘 배운 내용 정리
- 다음 레슨 예고: 미분

## AI 교육 연결점
- 일차함수 → 신경망의 기본 연산 (가중합)
- 이차함수 → 손실 함수 (MSE)
- 지수함수 → Softmax 함수
- 로그함수 → Cross-Entropy 손실
- 시그모이드 → 이진 분류 출력층
- ReLU → 은닉층 활성화 함수
