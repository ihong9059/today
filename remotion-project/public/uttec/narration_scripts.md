## TTS 생성 권장 설정

### 한국어 음성 설정
- 속도: 1.0 (표준)
- 음조: 낮음~중간 (신뢰감 있는 톤)
- 스타일: 비즈니스/프로페셔널
- 권장 서비스: 네이버 클로바 음성, Google Cloud TTS (ko-KR)

### 영어 음성 설정
- Speed: 1.0 (standard)
- Pitch: Medium-low (trustworthy tone)
- Style: Business/Professional
- Recommended: ElevenLabs (Daniel, Adam), Google Cloud TTS (en-US)
