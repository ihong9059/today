# AI SmartFactory 계획서 개선사항 TTS 스크립트

## Scene 01: 인트로 (약 30초)
본 영상은 기존 한국기계 AI SmartFactory 시스템의 개선 방안을 설명합니다.
고장예지 시스템과 품질관리 시스템의 세부 개선사항을 도출하고,
두 시스템의 통합 아키텍처를 제안합니다.
센서 표준화, 안전 이중화, MLOps 체계, 품질 교정 프로세스 등
실무 적용을 위한 구체적인 개선 권고안을 전문가 관점에서 상세히 다룹니다.

## Scene 02: 센서 ID 체계 표준화 (약 40초)
첫 번째 개선사항은 센서 ID 체계의 통일입니다.
현재 VIB-1A, TMP-1B 등 개별 센서 ID는 존재하나, 통합 태그 명명 규칙이 부재합니다.
5단계 계층 구조를 제안합니다.
Level 1은 공장 코드로 BRF, Battery Recycling Factory를 나타냅니다.
Level 2는 SHR, CRS, PIN, CLF 등 공정 코드입니다.
Level 3은 장비 번호, Level 4는 센서 유형, Level 5는 설치 위치입니다.
예시로 BRF-SHR-01-VIB-A는 1차 파쇄기 1호 진동센서 A를 의미합니다.
이 체계로 전사적 센서 관리와 데이터 추적이 용이해집니다.

## Scene 03: 통신 프로토콜 명시 (약 40초)
두 번째 개선사항은 센서별 통신 프로토콜 명시입니다.
진동 가속도계는 IEPE 100밀리볼트퍼지 출력, 24비트 ADC로 100킬로헤르츠 샘플링합니다.
PT100 온도센서는 RTD 3선식, 적외선 온도센서는 4대시20밀리암페어 출력입니다.
CT 전류센서는 0대시5볼트, 엔코더는 NPN 펄스 출력입니다.
분진센서와 가스센서는 RS485 Modbus 디지털 통신입니다.
MEMS 마이크는 PDM 또는 I2S 방식으로 48킬로헤르츠 샘플링합니다.
아날로그 센서는 Junction Box에서 신호 컨디셔닝 후 전송하고,
RS485 버스는 최대 32개 디바이스를 수용합니다.

## Scene 04: 안전 센서 이중화 (약 45초)
세 번째 핵심 개선사항은 안전 관련 센서의 이중화 구성입니다.
발화 감지는 적외선 온도센서와 열화상 카메라를 OR 로직으로 운영합니다.
하나라도 감지 시 즉시 경보가 발생합니다.
폭발 위험 감지는 분진센서 2개를 투표 로직으로 구성하여 오경보를 방지합니다.
전해액 누출은 가스센서 2개를 OR 로직으로 운영하여 신속 대응합니다.
과열 감지는 PT100 2개로 교차 검증합니다.
중요한 점은 Safety PLC가 Edge Gateway와 독립적으로 운영되어,
네트워크 장애 시에도 비상정지, 소화, 환기 기능이 정상 작동합니다.
안전 센서는 SIL 2 이상 인증 제품을 사용해야 합니다.

## Scene 05: MLOps 체계 (약 45초)
네 번째 개선사항은 AI 모델 운영을 위한 MLOps 체계 구축입니다.
데이터 파이프라인은 센서 데이터를 Data Lake에 수집하고,
Feature Engineering을 거쳐 모델 학습에 활용합니다.
데이터 버전 관리는 DVC, 모델 레지스트리는 MLflow를 사용합니다.
신규 모델 배포 시 Shadow Mode A/B 테스트로 안정성을 검증합니다.
모델 재학습은 성능 저하 감지 시 자동으로 트리거됩니다.
성능 저하 시 버전 기반 자동 롤백으로 서비스 연속성을 보장합니다.
Edge Deployment를 통해 현장에서 실시간 추론이 가능하며,
지속적인 성능 모니터링으로 모델 드리프트를 조기에 감지합니다.

## Scene 06: 인라인-오프라인 측정값 교정 (약 40초)
다섯 번째 개선사항은 품질 측정값 교정 체계입니다.
인라인 센서는 연속 측정, FRITSCH 분석기는 시간당 1회 기준 측정을 수행합니다.
교정 알고리즘은 인라인 보정값 = 인라인 측정값 곱하기 교정계수 더하기 오프셋입니다.
교정계수는 FRITSCH 기준값으로부터 산출됩니다.
정기 교정은 주 1회, 매 오프라인 측정 시 자동 교정이 실행됩니다.
인라인과 FRITSCH 측정값 편차가 5퍼센트 초과 시 교정계수를 재계산하고,
10퍼센트 초과 시 인라인 센서 점검 알림을 발송합니다.
이를 통해 인라인 측정의 신뢰도를 지속적으로 유지합니다.

## Scene 07: 품질 등급 기준표 (약 35초)
여섯 번째 개선사항은 품질 등급 기준의 구체화입니다.
A등급 우수는 D50 45~55마이크로미터, D90 150 이하, Span 1.8 이하입니다.
원형도 0.88 이상, 회수율 96퍼센트 이상, 수분 0.8퍼센트 이하, 순도 99퍼센트 이상입니다.
B등급 양호는 D50 40~60마이크로미터, 회수율 94퍼센트 이상입니다.
C등급 보통은 회수율 90퍼센트 이상, D등급 불량은 그 외입니다.
등급 결정 로직은 모든 항목 중 가장 낮은 등급이 최종 등급으로 적용됩니다.
이 기준으로 품질 판정의 일관성과 객관성을 확보합니다.

## Scene 08: 품질 이상 대응 SOP (약 40초)
일곱 번째 개선사항은 품질 이상 시 표준 운영 절차입니다.
입도 과대 이상 대응 SOP를 예로 설명합니다.
D90이 165마이크로미터를 3회 연속 초과 시 시스템이 즉시 알림을 발송합니다.
운전자는 1분 내 대시보드에서 트렌드를 확인하고,
2분 내 분쇄기 RPM을 5퍼센트 증가 조치합니다.
10분 후 시스템이 재측정하여 효과를 확인합니다.
미개선 시 엔지니어가 30분 내 현장 점검으로 해머 또는 칼날 마모를 확인합니다.
부품 교체 또는 조정은 1~4시간 소요됩니다.
회수율 저하 시에는 공정 중단 여부 결정, 근본 원인 분석 보고서 작성까지 포함됩니다.

## Scene 09: 통합 시스템 아키텍처 (약 45초)
여덟 번째 핵심 개선사항은 고장예지와 품질관리의 통합 아키텍처입니다.
센서 레이어에서 고장예지 센서 31개와 품질관리 센서 12개가 데이터를 수집합니다.
통합 Edge Gateway는 NVIDIA Jetson Orin NX 16기가바이트를 사용하며,
고장예지 추론 엔진과 품질 추론 엔진이 동시에 구동됩니다.
통합 데이터 플랫폼은 TimescaleDB, PostgreSQL, MinIO로 구성됩니다.
핵심은 통합 AI 분석 엔진의 상관관계 분석 모듈입니다.
설비 상태가 품질에 미치는 영향도를 분석합니다.
예를 들어 해머 마모는 전류-D90 상관분석으로 교체 시점을 최적화하고,
베어링 상태는 진동-Span 상관분석으로 사전 정비 시점을 결정합니다.
통합 대시보드에서 설비 현황, 품질 현황, 상관 분석을 한눈에 파악합니다.

## Scene 10: 보안 및 유지보수 체계 (약 35초)
마지막 개선사항은 사이버 보안과 유지보수 체계입니다.
OT 네트워크와 IT 네트워크를 물리적, 논리적으로 분리합니다.
역할 기반 접근 제어 RBAC과 TLS 암호화를 적용합니다.
산업용 침입 탐지 시스템 IDS/IPS를 설치하고, 일간 자동 백업을 수행합니다.
유지보수 체계는 센서 교정 월 1회, Edge Gateway 점검 분기 1회입니다.
AI 모델 재학습은 분기 1회 또는 자동 트리거, FRITSCH 분석기 교정은 연 1회입니다.
이상의 9가지 개선사항을 Phase 1부터 3까지 단계적으로 적용하면,
한국기계 AI SmartFactory 시스템의 안정성, 신뢰성, 효율성이 대폭 향상됩니다.
