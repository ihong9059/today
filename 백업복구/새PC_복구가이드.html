3. 백업 가져오기 (mac → 새 PC)

Git Bash를 열고 (PowerShell 아님 — 바이너리 파이프 깨짐 방지) 아래를 실행:

# 첫 접속은 SSH 키가 아직 없으므로 비밀번호 인증 (mac 계정: uttec)
MAC=uttec@100.90.158.36
BK=/mnt/backup-ssd/pc-backup/myhome-lenovo-20261114

# ① C:\todo 복원 — 폴더별 아카이브 순차 해제 (회선에 따라 수 시간)
mkdir -p /c/todo
for f in $(ssh $MAC "ls $BK/todo-parts"); do
  echo "$f"
  ssh $MAC "cat '$BK/todo-parts/$f'" | tar -xzf - -C /c/todo
done

# ② 사용자 홈 복원 (.claude / .claude.json / .ssh)
ssh $MAC "cat $BK/home-claude.tar.gz" | tar -xzf - -C ~

중간에 끊기면 실패한 폴더부터 다시 실행하면 됩니다 (tar 해제는 덮어쓰기라 재실행 안전).

⚠️ 새 PC의 사용자명이 lenovo가 아닌 경우: ②는 현재 사용자 홈(~)에 풀리므로 그대로 두면 되지만, ~\.claude\settings.json의 hook 명령에 C:/Users/lenovo/... 절대경로가 박혀 있습니다. 복원 후 settings.json에서 lenovo를 새 사용자명으로 일괄 치환하세요. (~\.claude\hooks\의 스크립트 자체는 함께 복원됨)

SSH 키 복원 후에는 ssh mac·ssh ubuntu·ssh ponet 등 기존 별칭이 전부 되살아납니다 (~\.ssh\config 포함).

4. Junction 재생성

tar 백업은 junction 57개(myWiki raw 미러 등)를 제외했으므로 재생성 필요. PowerShell에서:

powershell -ExecutionPolicy Bypass -File C:\todo\today\백업복구\restore-junctions.ps1

전체 목록·대상은 junctions.json이 단일출처. 이미 존재하는 것은 SKIP 처리되므로 재실행 안전.

사용자 환경변수

9. 참고 — 이 백업이 커버하지 않는 것

  • 개발 도구체인: nRF Connect SDK(NCS)·Zephyr·nrfjprog·west, ffmpeg, ODA File Converter 등은 C:\todo\tools 외 시스템 설치분이 있으면 재설치 필요. 펌웨어 작업 재개 시 해당 프로젝트 README의 셋업 절차를 따를 것.
  • 터미널 기본 디렉토리(C:\todo): cmd AutoRun·PowerShell $PROFILE 재적용 (단, NCS 빌드 시 AutoRun 충돌 주의 — 메모리 feedback_ncs_build_cmd_autorun_conflict)
  • 원격 호스트들(ubuntu/mac·factory-rpi4·EC2·DigitalOcean)은 이 PC와 무관하게 생존 — SSH 키만 복원되면 즉시 접근 가능
