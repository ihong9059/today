## 핵심 개념 요약

### 경사 하강법 (Gradient Descent)

딥러닝의 핵심 학습 알고리즘:

1. **손실 함수(Loss Function)** 정의 - MSE 등
2. **기울기(Gradient)** 계산 - 손실 함수의 미분
3. **가중치 업데이트** - 기울기 반대 방향으로 이동
4. **반복** - 손실이 충분히 작아질 때까지

```python
# 경사 하강법 핵심 코드
for epoch in range(num_epochs):
    y_pred = w * x_input + b
    error = y_pred - y_target
    loss = np.mean(error ** 2)  # MSE

    # Gradient 계산
    dw = np.mean(error * x_input) * 2.0
    db = np.mean(error) * 2.0

    # 가중치 업데이트
    w -= learning_rate * dw
    b -= learning_rate * db
```
