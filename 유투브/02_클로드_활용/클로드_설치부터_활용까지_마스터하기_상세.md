### 2. 모델 및 요금제 완벽 이해 (00:45-02:42)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=45s)

#### 핵심 메시지
세 가지 모델(Opus/Sonnet/Haiku)의 특성을 이해하고 상황에 맞게 선택. 일상 업무는 Sonnet이 최적. 적응형 사고는 켜두는 것을 추천.

#### 상세 내용
- **Opus 4.7**: 고차원적이고 복잡한 사고에 가장 강력. 단, 토큰을 빠르게 소모 → 질문 몇 개에 토큰이 뚝 떨어짐. 복잡한 사고가 필요할 때만 선택
- **Sonnet 4.6**: 일상 업무에 가장 효율적. 적당히 빠르고, 적당히 토큰 사용, 적당히 사고도 하는 무난한 모델. 연사가 보통 선택하는 모델
- **Haiku 4.5**: 빠른 답변을 주지만 사고는 적게 함. 아주 단순한 작업에 적합
- **적응형 사고**: 클로드가 스스로 생각하는 시간을 조절하는 기능. 쉬운 건 바로 대답, 어려운 건 심사숙고. 굳이 껐다 켰다 할 필요 없이 켜두면 됨. 다만 토큰이 조금 더 소모될 수 있음
- **요금제**: 무료/프로/맥스. 프로 요금제를 사용하면 복잡한 작업 시 토큰 소진 메시지가 자주 뜸

#### 언급된 사례/에피소드
- **연사 경험**: 프로 요금제 사용 중 복잡한 작업 시 토큰 소진 메시지가 자주 뜸
  - 시사점: 클로드는 토큰이 빠르게 소모되는 단점이 있으므로 모델 선택이 중요

#### 주요 발언
> "오퍼스는 고난도 작업에 가장 강력하다. 다만 토큰을 너무 빠르게 잡아먹어 질문 몇 개에 토큰이 뚝 떨어지는데요."

> "소넷 4.6은 일상 업무를 처리할 때 가장 효율적이라고 하죠. 적당히 빠르면서도 적당히 토큰을 사용하고 적당히 사고도 하는 무난한 모델입니다."

### 3. 채팅창 플러스(+) 버튼의 비밀 (02:42-04:33)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=162s)

#### 핵심 메시지
플러스 버튼에는 웹 검색, 연구(심층 조사), 스타일 사용 등 핵심 기능이 모여 있다. 이것만 제대로 다루면 클로드 마스터.

#### 상세 내용
- **웹 검색**: 실시간 데이터가 필요할 때 검색을 통해 지식 자료를 가져오는 기능. 클로드는 26년 4월 기준 25년 8월까지의 지식 보유. 웹 검색을 켜두면 지식 컷오프 보완 가능
- **연구 기능**: 단순 답변이 아닌 여러 번 웹 검색을 반복하고 정보를 종합하는 심층 조사 모드. 특정 주제의 다양한 관점 종합, 정보 교차 검증에 유용 → 신뢰도 높은 정보 획득
- **스타일 사용**: 미리 저장한 말투/문체를 자동 적용하는 기능
  - 기본 스타일: 일반, 학습, 간결한, 설명적인, 격식 있는
  - 맞춤 스타일 만들기: 나의 글쓰기 스타일이 반영된 자료를 추가하면 말투/어조 분석 후 해당 스타일 생성
  - 자료 없이도 "대신 스타일 설명하기"로 커스텀 스타일 생성 가능

#### 주요 발언
> "사실 클로드는 이 플러스 버튼의 기능들만 제대로 다룰 줄 알면 마스터했다고도 볼 수 있는데"

> "연구 기능은 클로드가 스스로 더 오래 생각하고 추론하는 게 아닌 웹 검색을 여러 번 반복하는 거예요."

### 4. 스마트한 설정과 메모리 관리 (04:33-07:02)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=273s)

#### 핵심 메시지
프로필에 업무/선호를 설정하면 모든 답변에 반영된다. 메모리 3가지(채팅 검색, 기억 생성, AI 가져오기)로 맥락을 유지.

#### 상세 내용
- **프로필 설정**: 좌측 하단 → 설정 → 프로필. 내 업무, 성향, 선호하는 설명 방식 기재. 한번 설정하면 모든 답변에 반영. 특정 업무 전용이면 설정 추천, 다양하게 사용하면 설정 안 해도 됨
- **메모리 기능 3가지**:
  1. **채팅 검색 및 참조** (프로 이상): 과거 대화를 검색해 정보를 찾아주는 기능. 채팅의 대화에서만 검색 가능(프로젝트 채팅은 불가)
  2. **채팅 기록에서의 기억 생성** (무료 가능): 대화 내용을 자동 요약/저장하여 이후 대화에서 맥락 유지. 예: "다이어트 중, 저녁 8시 이후 안 먹음" → 며칠 뒤 저녁 메뉴 질문 시 자동 반영
  3. **다른 AI에서 가져오기**: ChatGPT나 Gemini에서 쌓인 데이터를 클로드로 이전하는 기능. 프롬프트 복사 → 기존 AI에 입력 → 결과값을 클로드에 붙여넣기

#### 언급된 사례/에피소드
- **다이어트 기억 예시**: "나 요즘 다이어트 중이야. 저녁 8시 이후로 안 먹어" → 며칠 뒤 "저녁 메뉴 뭐 먹을까?" 질문 시 자동으로 다이어트 맥락 반영
  - 시사점: 매번 반복 설명 없이 개인화된 응답 가능

#### 주요 발언
> "여기에 한번 설정해 두면 클로드는 이 세팅에 맞추어 모든 답변을 하게 됩니다."

> "과거 대화를 일일이 다 뒤지기보단 다시 한번 물어보는 게 더 편하더라고요."

#### 주요 발언
> "커넥터를 활용해 구글 드라이브와 연동하기 전에는 이 자료들을 일일이 다운받아 채팅창에 직접 놓고 질문했어야 했지만 이제는 그냥 물으면 구글 드라이브에 가서 찾아옵니다."

### 6. 스킬(Skill) (08:51-11:42)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=531s)

#### 핵심 메시지
반복하는 프롬프트를 스킬로 저장하면 매번 같은 내용을 입력할 필요 없이 재사용 가능. 스킬 크리에이터를 활용하면 대화로 쉽게 스킬 생성.

#### 상세 내용
- 스킬이란: 클로드가 특정 작업을 더 잘, 더 일관되게 수행하도록 만든 커스텀 지침 파일
- 기존: 나는 누구고, 상대방은 어떠하며, 어떤 상황인지, 어떤 결과물을 원하는지 매번 반복 입력 → 스킬로 저장하면 한 번에 불러오기
- 스킬 만들기 3가지 방법:
  1. **클로드와 함께 창작하기**: 스킬 크리에이터 스킬 활용, 대화로 스킬 생성
  2. **스킬 지침 작성**: 이름/설명/지침을 직접 입력
  3. **스킬 업로드**: 외부에서 만든 스킬 파일 업로드
- 스킬 둘러보기: 클로드에서 만들어 놓은 기본 스킬 목록 확인
- 스킬 사용 판단 기준: 매번 비슷한 규칙으로 반복하는 작업 → 스킬, 한번 쓰고 마는 질문 → 그냥 프롬프트
- 외부 스킬 자료: Anthropic 공식 저장소, 커뮤니티 스킬 모음

#### 언급된 사례/에피소드
- **강의자료 분석 스킬 데모**: "강의 자료를 주면 목차를 정리하고 내용을 핵심 요약한 뒤 퀴즈를 자동으로 생성해 주는 스킬" 생성 → 이후 "강의자료 요약해 줘"만 입력하면 스킬이 자동 적용되어 목차/핵심요약/퀴즈 생성
  - 시사점: 복잡한 프롬프트를 한번만 만들면 이후 간단한 명령으로 동일 품질 산출

#### 주요 발언
> "반복해서 사용하던 프롬프트를 스킬로 만들어 저장해 두면 매번 같은 내용을 입력할 필요 없이 스킬로 불러와서 재사용이 가능합니다."

> "간단하게 명령만 내려도 스스로 스킬을 불러와서 목차, 핵심, 요약, 퀴즈까지 생성해 냈어요."

### 7. 프로젝트(Project) (11:42-13:22)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=702s)

#### 핵심 메시지
스킬이 프롬프트 저장이라면, 프로젝트는 프롬프트 + 파일 저장. 지침과 참고 파일을 함께 저장해두면 고차원적 업무 자동화가 가능.

#### 상세 내용
- 프로젝트 = 스킬(지침) + 파일 저장. 스킬보다 훨씬 더 활용도 높음
- 비유: 스킬이 요리 레시피라면, 프로젝트는 요리 레시피에 재료까지 담아두는 공간
- 프로젝트 구성: 이름, 목표(선택), 지침(프롬프트), 파일(참고 자료)
- 프로젝트에 와서 간단히 입력하면 내가 제공한 파일 양식에 맞춰 결과물을 바로 생성

#### 언급된 사례/에피소드
- **견적서 작성 프로젝트**: 청과 영업 담당자가 거래처에 보낼 견적서 자동 작성
  - 지침: 품목과 수량을 받으면 첨부 단가표 참고 → 할인/배송 정책 파일에 따라 자동 계산 → 견적서 양식에 맞춰 작성
  - 첨부 파일: 단가표, 할인 및 배송 정책, 견적서 양식
  - 결과: 품목/수량만 입력하면 전체 견적서가 자동 생성
  - 시사점: 반복 업무의 극적인 효율화

#### 주요 발언
> "스킬이 요리 레시피라면 프로젝트는 요리 레시피에 재료까지 담아두는 공간인 거죠."

> "이게 스킬과 프로젝트의 차이로 업무의 효율성을 높이는 데 아주 큰 도움이 되는 기능입니다."

### 8. 코워크(Cowork) (13:22-15:43)
[바로가기](https://www.youtube.com/watch?v=OQfpuuftKew&t=802s)

#### 핵심 메시지
커넥터가 외부 앱 연동이라면, 코워크는 내 컴퓨터 파일을 클로드가 직접 제어하는 기능. 프로 이상 + 데스크톱 앱 필수.

#### 상세 내용
- 커넥터 vs 코워크: 커넥터 = 다른 앱 돌아다니기, 코워크 = 내 컴퓨터 파일 직접 조작
- 요구 사항: 프로 버전 이상 + 클로드 데스크톱 앱 필수
- 설치: 좌측 사이드바 상단 코워크 버튼 → 윈도우/맥 선택 → 설치
- 사용법: 코워크 채팅창에서 폴더 연동 버튼 → 작업할 폴더 선택 → 허용
- 코워크에서 사용 가능한 기능: 채팅, 프로젝트, 스킬, 커넥터 + 예약/디스패치 기능

#### 언급된 사례/에피소드
- **거래처 발주 분석 데모**: 3개 거래처의 발주 현황 엑셀 파일이 든 폴더를 연동 → "3월에 발주가 가장 많은 업체를 찾아줘" 입력 → 클로드가 스스로 거래처별 3월 발주 내역을 분석해 결과 도출
