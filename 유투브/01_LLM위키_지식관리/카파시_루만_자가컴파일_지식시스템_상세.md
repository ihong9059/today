### 1. 도입부 - 메모의 근본적 문제 (0:00-1:12)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=0s)

#### 핵심 메시지
메모를 열심히 쌓지만 다시 꺼내보지 않고, 지식으로 전환되지 않는 것이 대부분 사람의 현실이다.

#### 상세 내용
- 발표자는 노션을 주로 사용하고, 구글 킵에 읽은 책의 문장을 기록
- 옵시디언을 새롭게 배우려고 노력 중
- 메모는 열심히 쌓지만 지식으로 전환되는 일은 거의 없었음
- 이 고민 속에서 안드레 카파시의 트윗을 발견

#### 주요 발언
> "기록하면 여러분 다시 꺼내 보시나요? 저도 잘 꺼내 보지 않게 되더라고요."

### 2. 두 천재의 소개 - 루만과 카파시 (1:12-3:10)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=72s)

#### 핵심 메시지
50년 전 아날로그 메모법의 거장 루만과 최첨단 AI 기반 지식 관리의 카파시가 본질적으로 같은 원리를 추구한다.

#### 상세 내용
- **니클라스 루만**: 독일의 사회학자, 평생 종이 카드 9만 장 이상 작성
  - 9만 장의 메모로 논문 70편, 책 50권을 혼자 집필
  - 비결: 제텔카스텐(Zettelkasten) 메모 시스템
  - 수집 → 분류 → 연결 → 축적의 4단계
- **안드레 카파시**: OpenAI 공동 창립자, 테슬라 AI 디렉터 출신
  - "나는 요즘 코딩보다 지식 정리에 토큰을 더 쓴다"
  - raw 폴더에 자료를 던지면 LLM이 알아서 위키를 생성
- 종이 카드냐 디지털 마크다운이냐? 매체만 다르지 본질(수집-분류-연결-축적)은 동일

#### 언급된 사례/에피소드
- **루만의 9만 장 카드**: 평생에 걸쳐 종이 카드에 기록, 각 카드에 고유 주소 부여, 카드 간 상호 참조로 지식 네트워크 구축
- **카파시의 트윗**: "나는 요즘 코딩보다 지식 정리에 토큰을 더 쓴다"는 발언으로 화제

#### 주요 발언
> "9만 장의 가치가 얼마나 될지. 그 사람은 그 9만 장의 메모로 논문을 70편을 썼고요. 그리고 책을 50권을 혼자 썼습니다."

### 3. 카파시의 워크플로우 상세 (2:25-3:19)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=145s)

#### 핵심 메시지
카파시의 시스템은 "인간은 던지기만, AI가 정리"하는 구조이며, 이를 '컴파일'이라고 부른다.

#### 상세 내용
- 사람이 하는 건 딱 하나: raw 폴더에 자신의 지식을 던지기
- LLM이 알아서 하는 것:
  1. raw 폴더 읽기
  2. 개념별 분류
  3. 각 개념에 대해 글로 정리
  4. 문서끼리 서로 연결
- 이 과정을 카파시는 "컴파일"이라고 부름
- 개발자가 소스 코드를 바이너리로 변환하듯, 날것의 자료를 구조화된 위키로 변환
- 완성된 위키를 옵시디언에서 확인 (슬라이드, 차트 등)

#### 주요 발언
> "정리 정도는 AI가 하는 거예요. 인간은 자신이 수집한 정보를 AI에게 전달만 하는 거죠."

### 4. 현실 체크 - 토큰 폭탄 문제 (3:19-4:12)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=199s)

#### 핵심 메시지
카파시의 방식을 그대로 따라하면 토큰 소비가 폭발적이어서 일반인에게는 비현실적이다.

#### 상세 내용
- 카파시 위키: 문서 100개, 40만 단어
- LLM이 컴파일하려면 전체를 읽어야 함 (매번)
- 연결할 문서를 찾으려면? 전체를 읽어야
- 린팅으로 오류를 잡으려면? 또 전체를 읽어야
- Q&A를 하려면? 또 읽어야
- **검색이 아니라 전수 조사** → 토큰이 폭탄처럼 나감
- 카파시는 OpenAI 공동 창립자 = 사실상 토큰 무제한
- 일반인: Claude Pro 월 $20 결제해도 하루에 몇 번씩 한도에 걸림
- "그대로 따라하면 솔직히 코딩할 토큰이 없겠죠"

#### 주요 발언
> "이게 뭐냐하면 독해의 문제예요. 검색이 아니라 전수 조사가 필요한 거죠."

### 5. Claude Code 스킬 소개 (4:12-5:01)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=252s)

#### 상세 내용
- 스킬 = `.claude/skills/` 폴더 내 `skills.md` 파일
- 내용: "너는 이런 상황에서 이렇게 반드시 행동해"
- 코딩이 아님, 일상 언어로 문서에 정리만 하면 됨
- "문서 한 장이 나의 AI 비서의 업무 매뉴얼이 되는 거죠"

### 6. 루만 + 카파시 융합 레시피 (5:01-6:07)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=301s)

#### 핵심 메시지
루만의 효율적 연결 로직 + 카파시의 자동화 철학 + Claude Code 스킬 = 자가 컴파일 지식 시스템

#### 상세 내용
- **루만에서 빌려오는 3가지**:
  1. 원자성: 메모 하나에 하나의 생각, 여러 주제 절대 섞지 않음
  2. 인덱스 코드: 각 메모에 고유의 주소 (예: 004111A)
  3. 백링크: 메모끼리 서로 참조
- **카파시에서 빌려오는 것**: 자동화 개념
  - LLM이 컴파일
  - 린팅으로 자기 치유
  - 하나의 프론트엔드에서 통합 열람
- **마법 가루**: Claude Code 커스텀 스킬 (재사용 가능한 사고 프로토콜)
- 세 가지를 합치면: "인간은 메모를 던지고, 시스템이 지식을 기르는 구조"

### 7. 토큰 1/10 줄이는 3가지 비법 (6:07-7:22)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=367s)

#### 핵심 메시지
인박스 제로 전략, 프런트 메터만 읽기, 과거 생각 보존 링크로 토큰을 1/10로 줄인다.

#### 상세 내용
1. **인박스 제로 전략**
   - 처리 끝난 raw 파일에 아카이브 플래그를 붙여서 숨김 (삭제가 아님!)
   - raw 폴더(받은 편지함)는 항상 비어 있는 상태 유지
   - "이거 새거야? 이미 처리한 거야?"를 물어볼 필요 없음
   - raw 폴더에 있으면 무조건 100% 새 것

2. **프런트 메터(머리말)만 읽기**
   - 카파시 방식: LLM이 40만 단어 전체를 읽음
   - 우리 방식: 각 메모마다 프런트 메터(제목, 태그, 한줄 요약) 추가
   - 메모 200개든 수십만 개든, 프런트 메터만 분석하면 수백 줄로 끝
   - "40만 단어와 수백 줄 차이 느껴지시죠?"

3. **과거 생각 보존**
   - 연구 메모에서 원본 임시 메모로의 링크가 살아 있음
   - 필요하면 언제든 돌아가서 원래 맥락을 확인 가능

### 8. 실습 데모 - 세 가지 스킬 (10:46-22:25)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=646s)

#### 핵심 메시지
옵시디언 터미널에서 Claude Code를 실행하고, 슬래시 명령어 3개로 지식 시스템을 운영한다.

#### 상세 내용

**환경 설정**:
- 옵시디언에서 터미널 오픈 → 볼트 위치에서 Claude Code 실행
- `--dangerously-skip-permissions` 옵션으로 권한 부여

**스킬 1: `/fleeting` (플리팅 - 임시 메모)**
- 슬래시 F로 실행
- 갑자기 떠오른 아이디어, 조각 생각, 짧은 메모를 기록
- 인박스(inbox) 폴더에 자동 저장
- 입력 예: "안드레 카파시와 제텔카스텐으로 유명한 루만 교수의 메모법"
- AI가 자동으로: 기존 노트와의 연결점 제안, 한 줄 메모 작성

**스킬 2: `/literature` (리터러처 - 문헌 노트)**
- 슬래시 L로 실행
- 출처가 있는 메모를 작성 (뉴스 기사, 책 문장, 논문 인용)
- 사용자가 직접 옵시디언에서 노트를 만드는 게 아니라 Claude Code가 생성
- 입력 예: 책에서 읽은 밑줄 문장 + 출처(예: "치매에 걸린 뇌과학자")
- AI가 자동으로: 문헌 노트 생성, 기존 연구 노트와 연결

**스킬 3: `/permanent` (퍼머넌트 - 연구 메모)**
- 슬래시 P로 실행
- 임시 메모나 문헌 노트를 연구 메모로 확장
- 과정:
  1. 임시 메모를 지정
  2. AI가 기존 연구 메모의 프런트 메터를 분석
  3. 핵심 주장 3가지를 제안 + 어디에 배치할지 후보 제시
  4. 사용자가 배치 위치 결정
  5. AI가 인덱스 코드 자동 부여 (예: 1A2) + 메모 끼워넣기
- 프런트 메터에: 생성 날짜, 타입, 아이디, 태그, 연결 계통 정보

#### 언급된 사례/에피소드
- **실습 예시 1**: "안드레 카파시와 루만 교수의 메모법" 임시 메모 → AI가 "사고는 글쓰기의 전제가 아니라 부산물이다"라는 기존 노트와 연결 제안
- **실습 예시 2**: "치매에 걸린 뇌과학자" 책의 밑줄 → 문헌 노트로 생성 → 연구 노트 4번(새 계열) + 4A(하위 메모)로 자동 배치

### 9. 카파시 + 루만 통합 확장 (22:25-36:40)
[바로가기](https://www.youtube.com/watch?v=5JpnmbE039E&t=1345s)

#### 핵심 메시지
카파시의 LLM 워크플로우를 제텔카스텐에 통합하되, 루만의 "자기 말로 쓰기" 철학은 지키면서 자동화할 수 있는 영역만 확장한다.

#### 상세 내용
- 카파시의 노션 페이지 내용을 Claude Code에 프롬프트로 입력
- Claude Code가 두 시스템의 통합 방안 제안:
  - 수집 자동화 그룹 / 인간의 사고 그룹 / LLM 자동화 그룹으로 3분류
- **추가 스킬 4개**:
  1. **ingest**: raw 폴더에 수집 → 리터러처 자동 생성
  2. **curl**: 볼트 전체 대상 Q&A → 결과를 MD로 파일링
  3. **lint**: 끊긴 노트(고아 노트) 탐색 + 자가 치유
  4. **index**: 클러스터별 인덱스 자동 생성
- **기존 스킬 보강**: 퍼머넌트 스킬 강화, 리터러처를 ingest와 연계
- **루만 철학 유지**: "자기 말로 쓰지 않으면 이해된 게 아니다" → 사람이 쓰는 영역(퍼머넌트)은 지키고, LLM이 자동화할 수 있는 영역만 추가
- **배치/루프 스킬**: 잠자는 동안에도 자동으로 웹/논문/뉴스를 검색 → 제텔카스텐에 저장 → 기존 노트와 연결

#### 주요 발언
> "여러분이 잠든 사이에도 시스템은 돌아가고 있어요. 새 메모가 들어오면 자동으로 분류되고 기존의 지식과도 연결이 잘 되고 인덱스가 자동으로 매겨집니다."

> "루만은 자기 말로 쓰지 않으면 이해된 게 아니라고 했으니까 이 철학을 유지하는 게 좋습니다."
