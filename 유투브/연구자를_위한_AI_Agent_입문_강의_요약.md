## 전체 요약

### 핵심 주제
AI 에이전트는 챗봇을 넘어 계획 수립, 도구 활용, 파일 조작을 자율적으로 수행하는 LLM 기반 시스템이며, 연구자가 이를 효과적으로 설계하고 관리하는 방법을 실전 중심으로 소개한다.

### 핵심 내용
1. **챗봇 vs 에이전트**: 챗봇은 대화창 안에서 복붙 왕복, 에이전트는 목표만 주면 계획→실행→피드백 루프를 자율적으로 수행
2. **에이전트 3요소**: 계획(Planning), 메모리(Memory), 도구(Tool) — 코드 실행, 파일 조작, API 호출 가능
3. **실제 도구**: Claude Code, OpenAI Codex, Google AntiGravity 등 3대 에이전트 도구
4. **Agent.md / Rules**: 워크스페이스 루트에 배치하는 프로젝트 지침서, 에이전트가 매 세션 시작 시 읽고 상황 파악
5. **Skills**: 반복 작업을 표준화한 재사용 가능한 지시서 (SOP 역할)
6. **MCP (Model Context Protocol)**: 에이전트가 외부 서비스(캘린더, DB, API 등)에 접근하는 표준 프로토콜
7. **Vibe Research**: 에이전트에게 연구 방향만 주고 탐색적으로 작업시키는 새로운 연구 패러다임
8. **Context Engineering**: 에이전트에게 적절한 맥락(발산/수렴)을 설계하는 것이 핵심 역량
9. **실패 패턴**: 에이전트를 과신하면 안 됨 — 환각, 맥락 잊음, 과도한 자신감 등 한계 존재
10. **인간의 역할**: 판단, 검토, 방향 설정은 여전히 인간 연구자의 몫
