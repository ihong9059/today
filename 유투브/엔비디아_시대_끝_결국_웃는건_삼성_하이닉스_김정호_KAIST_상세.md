## 핵심 요약 (TL;DR)

> "AI 시대의 게임은 **지능이 아니라 토큰**으로 넘어갔다. 토큰 생산량 = 메모리 양 = 돈. 금광을 팔 때 금이 아니라 청바지가 돈을 벌었듯, AI 시대의 돈은 **메모리**가 벌 것이다."

- **패러다임 전환**: 사전학습(Pre-training, GPU 중심) → 추론(Inference, 메모리 중심)
- **GPU 한계**: 미분 연산 + 발열로 더 이상 성능 향상 불가, 4~16개가 한계
- **메모리 게임**: KV 캐시 + 컨텍스트 길이 + 백그라운드 세션 + 멀티 에이전트 = 메모리 폭증
- **새 아키텍처**: HBM5에서 GPU를 HBM 위로(옥상으로) 올리는 구조, HBM 뒤에 HBF(Flash) 부착
- **한국 기회**: 삼성·SK하이닉스가 메모리 센트릭 컴퓨팅의 중심으로 부상

### 4. 학습의 수학적 본질과 GPU의 한계 (03:18-05:13)
[바로가기](https://www.youtube.com/watch?v=NWKCWzFgt14&t=198s)

#### 핵심 메시지
학습 = 미분(△) 연산이고 이를 잘 하는 것이 GPU지만, GPU 성능을 더 높일 방법이 없어졌다. 추론은 메모리에 데이터를 "때려 넣는" 작업이다.

#### 상세 내용
- 학습의 수학적 표현: `min ||Y - F_θ(X)||` (정답 Y와 모델 예측의 차이 최소화)
- 미분(∇, 역삼각형)을 계속 수행하며 학습
- **미분을 잘하는 반도체 계층**:
  - GPU (범용)
  - NPU (특수 목적)
  - TPU (더 특수 - Google)
- **GPU 한계**: 성능을 높일 방법이 더 없음
- 젠슨 황 변화: "잠바 입고 잘난척하는 게 줄어들고", "치킨 들고 다닌다" (자신감 하락 비유)
- **추론의 본질**: X(현존 데이터)를 최대한 메모리에 때려 넣어 결과 도출
  - 본인 기록 + 인터넷 검색 결과 모두 활용
  - = **RAG (Retrieval-Augmented Generation)**

#### 주요 발언
> "GPU의 성장은 성능을 높여야 되는데 성능을 높일 방법이 없다라는 거예요. 그래서 젠슨이 요즘 눈빛이 흔들리고 잠바 입고 잘난척하는게 조금 많이 줄어들어가는 겁니다." (04:26)

> "미분이 아니라 메모리 시대가 왔다." (05:05)

### 6. 에이전틱 AI의 도구(Tool)와 KV 캐시 (07:00-09:32)
[바로가기](https://www.youtube.com/watch?v=NWKCWzFgt14&t=420s)

#### 핵심 메시지
에이전틱 AI는 Excel/PPT/예약사이트 등 모든 소프트웨어 도구를 다뤄야 하며, 이를 위한 KV 캐시는 컨텍스트 길이의 **제곱**에 비례해 증가한다.

#### 상세 내용
- **툴(Tool)의 영역 확장**:
  - Excel, PPT, 예약 사이트 등 일반 소프트웨어
  - **생산 현장 제어 소프트웨어**까지
  - 반도체 제조 공정: **약 1,000개 소프트웨어** 사용
- 도구 문제는 "돈 주면 해결" - 결국 메모리가 결정
- **KV 캐시(KV Cache)** 작동 방식:
  1. 인간 언어 → AI 언어 번역 (GPU 담당) = Y0
  2. 이게 KV 캐시
  3. **컨텍스트 길이의 제곱에 비례해 KV 캐시 사이즈 증가**
  4. 컨택스트가 KB → 100M 가면 10^18 = 1,000PB(페타바이트)
  5. **개인당 1,000PB 메모리 필요**
- 디코딩(단어 한 개씩 출력) 속도 = HBM이 결정
- **메모리 증가 공식**:
  - 시퀀스 랭스 (Sequence Length) ∝
  - 배치 사이즈 (동시 사용자) ∝
  - 프리시전 (비트수) ∝
- 터보 어텐션 논문: 16비트→3비트로 줄여보자 → "그냥 논문에 불과"

#### 언급된 사례/에피소드
- **클로드 코드 유출**: "8배 더 메모리가 필요하다" (의도적 유출 가능성)
- **멀티 에이전트 병렬 처리**:
  - 1개 에이전트 X
  - 여러 개 에이전트 병렬로 보고서 작성 + 평가 에이전트가 베스트 선택
  - = KV 캐시 8배 폭증

#### 주요 발언
> "결국 시퀀스 랭스와 배치사이즈 B 곱하기. 저게 10배 10배 되면 100배가 되는 겁니다." (09:12)

### 7. 백그라운드 세션과 토큰 경제학 (09:32-12:54)
[바로가기](https://www.youtube.com/watch?v=NWKCWzFgt14&t=572s)

#### 핵심 메시지
AI는 사용자 세션을 끄지 않고 백그라운드로 유지하며, 이것이 다시 메모리를 8배 폭증시킨다. 기업은 "토큰 맥싱"으로 직원을 평가하기 시작했다.

#### 상세 내용
- **백그라운드 세션의 비밀**:
  - 10분 전 ChatGPT 사용 → 10분 후 다시 사용
  - 그 10분 동안 끄지 않고 살려둠
  - 짧은 시간 내 끊임없는 대화 유지를 위해
- 동시 멀티 서비스 사용:
  - 클로드 + 퍼플렉시티 + 노트북 등
  - 각각 안 꺼지고 KV 캐시 누적
- **결과**: 2배 × 2배 = 8배 메모리 폭증
- **오토드림(Auto-dream?)**: 12시간 미사용시 압축 후 낸드 플래시로 저장
  - **NAND Flash 가격 상승 원인**
- **클라이언트-서브 에이전트 컨트랙트**: 수십 개 에이전트 동시 운용

#### 언급된 사례/에피소드
- **애플의 평가 시스템**: 직원 평가 기준 = 토큰 사용량
- **뉴욕타임즈 표현**: **"맥스 토큰 맥싱(Max Token Maxing)"**
- **3년 후 인사평가 예측**:
  - 출퇴근 시간 무의미
  - 윈도우 켜놓은 시간 무의미
  - 실제 토큰 입력/생산량 + 성과 ROI(Return on Token, RoT)
- **터보 어텐션 결론**: 3비트 압축 → **"부질없다"**, 정확도 떨어지면 환각 발생
- 첫 단어 출력 속도 (1~2분 걸림) = 레이턴시 = **GPU가 결정** (Compute Bound)
- 단어 한 개씩 출력 속도 = 스루풋 = **HBM이 결정**
- 새벽배송 경쟁 비유: AI 경쟁의 본질

#### 주요 발언
> "토큰 생산량은 결국 메모리고, 메모리는 돈이고 전기고 결국 돈이다. 그래서 토큰 경제학이라 그러는데요." (12:48)

> "토큰 맥시멈 생산한다는 그 단어를 뉴욕 타임스에서 맥 토큰 맥싱이라는 표현을 쓰더라고요." (11:50)

### 9. HBM4 - GPU와 메모리의 융합 (14:20-15:10)

### 11. HBF - 메모리의 반란, 메모리 센트릭 컴퓨팅 (15:55-18:18)
[바로가기](https://www.youtube.com/watch?v=NWKCWzFgt14&t=955s)

#### 핵심 메시지
HBM 뒤에 HBF(High-Bandwidth Flash)를 붙여 1인당 1,000PB 메모리를 국가가 제공해야 한다. CPU/GPU 거치지 않고 메모리가 직접 네트워크를 갖는 **메모리 센트릭 컴퓨팅**이 답이다.

#### 상세 내용
- **현재 컴퓨터 계층**:
  - CPU = 왕
  - GPU = 왕자
  - 메모리 = 하인
- **반란**: GPU가 힘이 커지자 시스템 균형 붕괴
- 김 교수 제안: **메모리가 반란을 일으킬 수 있다**
  - CPU/GPU 거치지 않고 메모리 자체 네트워크
  - GPU 일부 기능을 메모리가 보유
  - = **메모리 센트릭 컴퓨팅(Memory-Centric Computing)**
- **메모리 계층 제안**:
  - HBM (~100GB, 1TB)
  - HBF (NAND Flash 적층, 100TB)
  - 네트워크 연결 (1,000TB) = **HBM7**

#### 언급된 사례/에피소드
- **개인당 1,000TB 메모리 필요론**: "자동차/아파트처럼 국가가 1인당 1,000PB를 줘야 빈부격차 안 난다"
- **NVIDIA의 대응 - IGMS**:
  - DPU(Data Processing Unit) 신설
  - 스토리지 ↔ ICMS NAND로 자체 메모리 네트워크
  - 삼성·하이닉스 의존도 낮추려는 시도
- **샌디스크 주가 급등**: NVIDIA IGMS 영향
- 김 교수 반박: PCIe로 와도 너무 느림 → 우리만의 메모리 네트워크(PCI Gen 6/7) 필요

#### 주요 발언
> "1인당 1,000PB를 국가에서 줘야 된다는게 제 주장입니다. 안 그러면 빈부 격차가 난다는 거예요." (16:57)

### 12. KAIST 연구 성과 및 결론 (18:18-19:45)
[바로가기](https://www.youtube.com/watch?v=NWKCWzFgt14&t=1098s)

#### 핵심 메시지
KAIST 연구실 결과: 메모리 센트릭 구조로 405B 모델 추론 시 스루풋 100배 향상. 메모리가 중심이 되고 CPU/GPU가 보조하는 시대가 온다.

#### 상세 내용
- **연구 성과**:
  - 405B 빌리언 큰 모델 인퍼런스
  - 로그 스케일, 스루풋 **약 100배 증가**
  - 단어 1초에 1개 → **1,000개**
- 전 세계 회사들 대상 마케팅 진행 중
- **다음 과제**: 냉각 - 반도체 안으로 물 통과시켜야 함
  - "10년 후 전 세계 반도체 회사의 운명을 가를 것"
- **결론**:
  - 과거: CPU에 메모리·스토리지 종속
  - 미래: 메모리만의 계층 (SRAM ~ Memory Factory)
  - 메모리가 중심, CPU/GPU가 보조
  - **2038년 HBF의 인퍼런스 전용 메모리 수요 폭증 예상**

#### 주요 발언
> "금광을 팔 때 금으로 돈 벌은게 아니라 청바지로 돈 벌었듯이 AI 시대의 돈은 메모리가 벌 것이다." (19:06)

> "2038년에는 HBF의 그 인퍼런스 전용 메모리가, 더 수요가 커질 것이다." (19:16)
