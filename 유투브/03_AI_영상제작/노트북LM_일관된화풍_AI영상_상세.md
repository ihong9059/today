### 1. 문제 제기 - 일관성의 중요성 (00:00-01:26)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=0s)

#### 핵심 메시지
AI 영상에서 조회수를 결정하는 핵심 요소는 "일관된 화풍". 보통 AI로 이미지를 생성하면 얼굴과 색감이 계속 변해서 포기하게 되지만, NotebookLM을 활용하면 무료로 해결 가능.

#### 상세 내용
- 영상 도입부에 명화급 AI 이미지로 만든 시대물 영상 시연 (전부 0원으로 제작)
- 대사 한 마디 없어도 조회수 20만 달성한 비결 = 한 사람이 그린 듯한 일관성
- AI로 이미지 생성 시 문제: 장면마다 얼굴이 바뀌고 색감이 달라짐 → 포기
- 해결책: NotebookLM 하나로 무제한 명화급 이미지를 일관되게 생성
- "돈 안 드는 역대급 치트키, 딱 10분만 투자해서 배워 가세요"

#### 주요 발언
> "대사 한 마디 없어도 조회수 20만이 나오는 비결. 바로 한 사람이 그린 듯한 일관성이죠."

> "보통 AI로 하면 얼굴이랑 색감이 계속 변해서 포기하시잖아요."

### 2. [1단계] 시대 설정 시트 만들기 (01:26-02:46)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=86s)

#### 핵심 메시지
레퍼런스 이미지 한 장 + 주제 한 문장으로 AI에게 명확한 기준을 제공. 글로만 설명하는 것보다 이미지 한 장이 훨씬 정확한 기준이 됨.

#### 상세 내용
- **핀터레스트에서 레퍼런스 이미지 찾기**: 원하는 영상 분위기와 가장 비슷한 그림 하나 선택. 화풍은 유화로 설정되어 있으므로 전체적인 색감과 느낌 위주로 선택
- **Gemini Gem(전용 도구)에 이미지 + 주제 입력**: 연사가 만든 "역사시대물 이미지 생성기" Gem 활용. 예시: "1920년대 저택에 사는 여성의 아침 일상"
- AI가 이미지의 색감과 분위기를 통째로 분석 → 시대적 배경, 주인공 외모, 공간 묘사까지 한 번에 정리한 "시대 설정 시트" 생성
- "백마디 말보다 이 이미지와 핵심 한 문장이 훨씬 정확한 기준"

#### 언급된 사례/에피소드
- **핀터레스트 + Gem 조합**: 글로만 설명하면 결과물이 미묘하게 달라지는 한계를 이미지 레퍼런스로 해결
  - 시사점: AI에게 시각적 기준을 함께 제공하면 품질이 극적으로 향상

#### 주요 발언
> "글로만 설명하는 데는 분명 한계가 있기 때문이에요. 이럴 때 이미지 한 장을 던져 주면 완전 다른 퀄리티의 결과물을 받아보실 수 있습니다."

> "백마디 말보다 이 이미지와 핵심 한 문장이 훨씬 정확한 기준이 되는 거죠."

### 3. [2단계] NotebookLM에 소스로 고정 (02:46-03:10)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=166s)

#### 핵심 메시지
NotebookLM의 핵심 차별점: 소스로 등록하면 AI가 절대 잊지 않고 해당 기준으로만 동작. 이것이 일관된 이미지 생성의 비밀.

#### 상세 내용
- NotebookLM에 접속 → 새 노트북 생성
- 1단계에서 복사한 시대 설정 시트를 소스로 등록
- "소스로 박아두는 순간 AI는 이 시트 기준으로만 움직입니다"
- NotebookLM은 소스로 등록된 내용을 절대 잊지 않음 → 이것이 다른 AI 툴과의 결정적 차이

#### 주요 발언
> "노트북은 이렇게 소스로 등록된 내용을 절대 잊지 않아요. 소스로 박아두는 순간 AI는 이 시트 기준으로만 움직입니다."

### 4. [3단계] 60장 장면 프롬프트 생성 (03:10-03:46)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=190s)

#### 핵심 메시지
소스를 기반으로 60개의 키프레임 이미지 프롬프트를 생성하고, 결과물도 다시 소스로 변환하여 정보를 축적.

#### 상세 내용
- 채팅창에 입력: "이 소스를 바탕으로 1920년 여인의 아침을 담은 60개의 키프레임 이미지 프롬프트 작성해 줘"
- 1번부터 60번까지 장면이 나열됨
- 결과물 하단의 "메모에 저장" 클릭 → 메모의 "더보기" → "소스로 변환" 클릭
- 소스로 변환하는 이유: NotebookLM은 항상 소스 기준으로 움직이므로, 더 많은 정보가 소스에 있을수록 디테일한 출력물 가능

#### 주요 발언
> "다시 소스로 변환해 주는 이유는 노트북 LM은 항상 이 소스 기준으로 움직입니다. 그래서 더 많은 정보가 들어 있을수록 디테일하게 출력물을 받아보실 수 있어요."

### 5. [4단계] 20장씩 끊어서 이미지 시각화 + 스타일 유지 꿀팁 (03:46-05:20)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=226s)

#### 핵심 메시지
60장 한꺼번에 시키면 AI 과부하로 스타일 무너짐. 반드시 20장씩 분할 요청. 이전 결과물 PDF를 소스에 재업로드하면 스타일 일관성 유지 가능.

#### 상세 내용
- **프롬프트**: "1번부터 20번 프롬프트를 슬라이드로 시각화해 줘. 텍스트, 숫자, 레이블 일체 넣지 마. 오직 이미지만"
- **핵심 주의**: 60장 한꺼번에 시키면 AI 과부하 → 중간부터 스타일 무너짐. 무조건 20장씩 끊어서 요청
- **오류 대응**: "이 질문에 답할 수 없습니다" 오류 시 → 새로고침 후 프롬프트 재입력
- **스타일 유지 꿀팁** (핵심):
  1. 1-20번 슬라이드 PDF 파일을 다운로드
  2. 해당 PDF를 다시 소스에 업로드
  3. 21-40번 요청 시 프롬프트에 추가: "소스에 등록된 화풍, 색감, 주인공 외모 반드시 그대로 유지해 줘"
  4. 이렇게 하면 NoebookLM이 이전 이미지 스타일을 소스로 인식하여 일관성 유지
- 마음에 안 드는 이미지는 우측 상단 수정 버튼으로 즉석 수정 가능 (다른 AI 툴과의 결정적 차이)

#### 언급된 사례/에피소드
- **PDF 소스 재업로드 기법**: NotebookLM이 앞에서 만든 이미지 스타일을 완전히 기억하지 못하는 문제를 PDF 소스 등록으로 해결
  - 시사점: NotebookLM의 소스 시스템을 창의적으로 활용하면 스타일 일관성 문제 극복 가능

#### 주요 발언
> "예순장을 한꺼번에 시키면 안 됩니다. AI가 과부하가 걸려서 중간부터 스타일이 무너지기 시작해요. 무조건 스물장씩 끊어서 요청하세요."

> "이게 다른 AI 툴이랑 노트북 LM의 결정적인 차이예요."

### 6. [5단계] 영상 편집 + 마무리 (05:20-07:49)
[바로가기](https://www.youtube.com/watch?v=ub1jawjT6ec&t=320s)

#### 핵심 메시지
완성된 이미지를 그록으로 영상화하고, 편집기에서 BGM만 입히면 완성. 역사 시대물뿐 아니라 모든 장르에 적용 가능. 핵심은 소스만 바꾸면 콘텐츠가 무한 확장.

#### 상세 내용
- 이미지를 움직이는 영상으로 만드는 방법: 그록(Grok) 활용
- 완성된 60장을 필모라나 브루 같은 영상 편집기에 넣고 잔잔한 배경 음악만 입히면 완성
- 적용 가능 장르: 역사 시대물, 야담, 심리학, 경제학 등 장르 무관
- 핵심 포인트: NotebookLM은 모든 출력이 소스 기반 → 소스만 바꾸면 콘텐츠 무한 확장
- 캐릭터 이미지를 소스로 넣으면 캐릭터 기반 출력도 가능
- 이미지뿐 아니라 청각 PPT 같은 콘텐츠도 제작 가능

#### 주요 발언
> "노트북 LM은 모든 출력이 소스 기반으로 만들어진다는 겁니다. 소스만 바꾸면 콘텐츠가 무한으로 확장되는 거예요."

> "조회수 20만, 30만 찍는 채널들 그냥 운이 좋아서 터진 게 아닙니다. 거기에는 AI를 똑똑하게 활용하는 명확한 공식이 숨어 있어요."

## 5단계 워크플로우 요약

1. Gem에서 레퍼런스 이미지 + 주제 한 줄 → **시대 설정 시트 생성**
2. NotebookLM에 시대 설정 시트를 **소스로 등록**
3. "60개 키프레임 프롬프트 작성해 줘" → 결과를 **메모 → 소스로 변환**
4. **20장씩 끊어서** "슬라이드로 시각화해 줘" (PDF 소스 재업로드로 스타일 유지)
5. 그록으로 영상화 → 편집기에서 **BGM 입혀서 완성**
