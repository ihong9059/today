## 한 줄 요약
**옵시디언 vault 폴더 안에서 Claude Code(터미널)를 실행 → `claude.md`(시스템 프롬프트) 자동 생성 → 제텔카스텐 + PARA 폴더 구조를 AI가 자동 구축 → `todos.md`로 다음 단계 자동 추적**까지, **'바이브 코딩' 방식**으로 비코더도 옵시디언 PKM 시스템을 만들 수 있는 15분 튜토리얼.

### 4. `/init` 명령 → CLAUDE.md 자동 생성 (03:00 – 04:00)
[바로가기](https://www.youtube.com/watch?v=veA3bpAWJQA&t=180s)

#### 상세 내용
- **명령**: `/init` (또는 "이니치"라고 발음)
- **동작**: 현재 폴더 구조를 분석 → `CLAUDE.md` 파일 자동 생성
- **CLAUDE.md의 역할**:
  - "루트 폴더에 생성되면서 **전역적으로 적용되는 시스템 프롬프트**"
  - 클로드 코드가 이 폴더에서 작동할 때 항상 따르는 지침
  - 사용자가 직접 수정해서 원하는 방향으로 커스터마이징 가능
- **현재 상태**: 빈 vault라 마크다운 문법 안내 정도만 포함

#### 주요 발언
> "클로드 MD라는 파일이 생겼죠. 이게 지금 루트 폴더에 생성이 되면서 **전력적으로 적용되는 시스템 프롬폴트**라고 생각하시면 됩니다."

### 5. 제텔카스텐 폴더 구조 자동 생성 (04:00 – 07:00)
[바로가기](https://www.youtube.com/watch?v=veA3bpAWJQA&t=240s)

#### 핵심 메시지
"제텔카스텐 + PARA 메모법에 맞는 옵시디언 폴더 구조 만들어줘" 한 줄 → 클로드가 전체 구조 자동 생성.

#### 상세 내용
- **자동 생성된 폴더 구조** (제텔카스텐 + PARA 통합):
  - **인박스 (Inbox)** — 새로 들어온 미분류 메모
  - **임시 메모 (Fleeting Notes)** — 1차 메모 (제텔카스텐)
  - **문업 메모 (Literature Notes)** — 외부 자료 정리
  - **연구 메모 (Permanent Notes)** — 자기 사고로 재구성한 지식
  - **프로젝트 (Projects)** — PARA의 P
  - **에어리아 (Areas)** — PARA의 A *(생성 누락 → 재명령 필요)*
  - **리소스 (Resources)** — PARA의 R
  - **아카이브 (Archive)** — PARA의 A
  - **템플릿 (Templates)** — 재사용 템플릿
  - **첨부 파일 (Attachments)** — 이미지/PDF 등
- **각 폴더마다**: README + 사용 원칙 자동 작성
- **수정**: 마음에 안 들면 ESC로 중단 → 다시 명령

#### 토큰 절약 팁
- 큰 작업은 **카피·페이스트로 외부 텍스트 입력** (API 호출 횟수 감소)
- ESC로 즉시 중단 → 토큰 낭비 방지

#### 주요 발언
> "여러분들이 어떤 원리나 이런 것들을 이해하지 않아도 **바이브하게 진행할 수 있게** 된게, 이런 LLM과 대화하면서 옵시디언에 클로드 코드를 붙여서 사용할 수 있기 때문입니다."

### 8. 기존 노트로 연구 메모 만들기 (08:30 – 10:30)
[바로가기](https://www.youtube.com/watch?v=veA3bpAWJQA&t=510s)

#### 핵심 메시지
**기존 텍스트를 인박스에 복사 → 템플릿 적용 → AI가 연구 메모로 자동 변환**.

#### 상세 내용
- **워크플로우**:
  1. 외부 텍스트 복사 → 인박스에 붙여넣기 (= 임시 메모)
  2. AI에게 "이걸 제텔카스텐 템플릿에 맞춰 연구 메모로 변환해줘"
  3. AI가 핵심 아이디어 + 상세 설명 + 키워드 자동 추출
  4. 적절한 폴더(연구 메모)에 자동 저장 + 넘버링
- **검수 필요**: AI 출력은 **반드시 사람이 검수**
- **방향성과 실제 내용 모두**: 사용자 검수 책임

#### 주요 발언
> "**LLM이 개인 지식 관리를 하는데 도움을 줄 수 있는 부분은**, 기존에 대량 학습된 지식들로 내가 원하는 부분에 있는 어떤 노트를 작성하는 부분이 조금 도와줄 수 있다는 거죠."

> "근데 이런 방향성이나 아니면 실제 들어가는 내용에 대해서는 **여러분들이 검수를 하셔야 됩니다**."

> "**여러분들이 어떤 원리나 이런 것들을 이해하지 않아도 바이브하게 진행할 수 있게 된게**, 이런 LLM과 대화하면서 옵시디언에 클로드 코드를 붙여서 사용할 수 있기 때문입니다."

### AI의 역할 (검수 강조)
> "LLM이 개인 지식 관리를 하는데 도움을 줄 수 있는 부분은, 기존에 대량 학습된 지식들로 내가 원하는 부분에 있는 어떤 노트를 작성하는 부분이 조금 도와줄 수 있다는 거죠."

> "**방향성이나 아니면 실제 들어가는 내용에 대해서는 여러분들이 검수를 하셔야 됩니다.**"

### todos.md 활용
> "이건 개발자분들이 실제 진행한 개발 내역을 남기고, 그리고 앞으로 할 일에 대해서 클로드 코드가 계획을 짠 걸 반영해 놓고, 실제로 그걸 하나씩 처리하는 방식으로 개발이 진행되거든요. **그것도 개인 지식 관리에도 얼마든지 적용할 수가 있습니다.**"

### 결론
> "터미널 방식으로 더하시면 훨씬 더 수월하게 작업하실 수가 있습니다."
