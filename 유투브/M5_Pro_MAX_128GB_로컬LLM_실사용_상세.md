## 한 줄 요약

**M5 Pro Max 128GB MacBook** + **OMLX (Apple MLX 추론 서버)** 조합으로 로컬 LLM이 **클라우드 모델(Claude Sonnet 3.6)에 견줄 만한 속도(117 toks/s)와 품질** 달성. Claude Code / Codex / LMS Agent 등 기존 CLI 도구를 **명령어 하나로 로컬 LLM에 연결**하여 사용 가능. 작년까지 컨텍스트·캐싱 한계로 사용 곤란했던 로컬 LLM이 OMLX의 80~90% 캐싱으로 실용 단계 진입.

### 4. OMLX 서버 핵심 강점 — 117 tok/s, 80~90% 캐싱 (03:30 - 05:00)

[바로가기](https://www.youtube.com/watch?v=1y9LCBuSTS8&t=210s)

#### 핵심 메시지 ⭐⭐⭐
**최근 OMLX 도입 후 속도 엄청나게 개선** — 초당 **117 토큰**, 평균 **80.2% 캐싱**, 최근 최대 **90%+ 캐싱**. Apple 전용 (Windows 불가).

#### OMLX 본질

| 항목 | 값 |
|---|---|
| **명칭** | OMLX (OpenMLX 추론 서버) |
| **기반** | Apple MLX |
| **속도** | **117 tok/s** (초당) |
| **캐싱 평균** | **80.2%** |
| **캐싱 최대** | **90%+** |
| **호환 OS** | Apple Silicon 전용 (Windows ❌) |

#### 빠른 이유 — 캐싱
- 대화 진행할수록 / 작업 누적될수록 **속도가 빨라지는 효과**
- 컨텍스트 캐시 재사용으로 첫 응답보다 후속 응답이 더 빠름

#### 통합 도구 — 명령어 하나로 로컬 LLM 연결

OMLX 설치 후 다음 도구 모두 로컬 LLM 사용 가능:
- **Claude Code**
- **Codex**
- **Open Code**
- **Open Claw**
- **LMS Agent** ⭐
- **Pi**
- **Copilot CLI**

→ "기존 클라우드 LLM 워크플로우를 그대로 로컬로 전환"

#### 주요 발언
> "OMLX를 사용을 하면서 이 속도가 엄청나게 [개선]되더라고요. 117 토큰/sec인데요. 1초에 117 토큰이 나오는 정도의 속도 개선이 있어서..."

> "이 OMLX가 속도가 빨라지는 이유는 결국에 이 캐싱을 하기 때문인데요. 평균적으로 80.2%고요. 최근에 높을 때는 90% 이상의 캐싱이 가능하거든요. 캐싱이 잘 되기 때문에 대화가 이어지고 작업이 진행될수록 그 작업의 속도가 좀 더 빨라지는 그런 효과가 있는 것 같습니다."

> "참고로 OMLX는 애플 전용 서버이기 때문에 윈도우로는 어 쉽지 않을 것 같습니다."

#### 설치 방법
GitHub 주소 → AI에 붙여 넣고 "서버 설치해 달라" 요청 → 자동 설치 + 대시보드 자동 생성
