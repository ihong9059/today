### 4. 마크다운 사용법 (02:34-04:32) — 진입장벽 1순위
[바로가기](https://www.youtube.com/watch?v=ZuEu8SDqHOE&t=154s)

#### 핵심 메시지
옵시디언 노트는 **모두 .md 마크다운 파일**로 저장 → 다른 마크다운 편집기와 호환. 자주 쓰는 3가지 문법만 알면 됨.

#### 상세 내용
1. **헤딩**: `#` + 띄어쓰기 + 제목 (#이 많을수록 작은 제목)
   - ⚠️ **#만 쓰고 띄어쓰지 않으면 태그가 됨** (초보자 함정)
2. **불릿 포인트**: `-` + 띄어쓰기 (엔터로 유지, 백스페이스로 빠져나오기)
3. **볼드**: `**텍스트**` (별표 두 개로 감싸기)
- 다른 문법은 인터넷에서 마크다운 자료 참고

#### 시사점 (UTTEC)
- 사용자의 myWiki는 이미 마크다운 깊이 활용 중 → 본 구간은 강사양성 파일럿 입문자 슬롯용 콘텐츠
- "마크다운 = 다른 편집기 호환 = 데이터 영구 소유권"이라는 메시지를 어제 #28 구요한 티타임즈TV·오늘 OpenClaude USB 영상과 결합 가능

### 12. 커뮤니티 플러그인 + 다이어리 만들기 (12:15-14:37) ★ 실습 핵심
[바로가기](https://www.youtube.com/watch?v=ZuEu8SDqHOE&t=735s)

#### 핵심 메시지
2개 플러그인만으로 일/주/월/연간 다이어리 완성: **Calendar** + **Periodic Notes**.

#### 상세 절차
1. **커뮤니티 플러그인 사용** 활성화 (보안 경고 후 동의)
2. **탐색** → 정렬: Most Downloaded
3. **Calendar** 설치 + 활성화
4. **Periodic Notes** 설치 + 활성화
5. Periodic Notes 옵션:
   - Daily / Weekly / Monthly / Yearly 모두 ON
   - 각각 **앞서 만든 폴더 (Daily/Weekly/Monthly/Yearly) 매핑**
6. Ctrl+P → "Periodic Notes: Open Daily Note" → 오늘 일자로 자동 노트 생성
7. 위클리·먼슬리·이얼리도 동일 방식
8. 우측 펴기 → 달력 아이콘 클릭 → **Calendar 플러그인 UI** → 날짜 클릭으로 노트 자동 생성

#### 시사점 (UTTEC)
- ⭐ **사용자 myWiki + 작업보고서 시스템과 직접 매칭**:
  - 작업보고서 (`작업보고서/2026-05-06_작업보고서.md`) = Daily Note
  - 향후 위클리·먼슬리 보고서 자동화 후보 → Periodic Notes 플러그인이 정확히 그 역할
  - 어제 #27 (생산적생산자) 영상의 todos.md 패턴과 결합 가능
- **강사양성 Day 4 실습 콘텐츠**로 직접 활용 가능 (옵시디언 콰르텟 입문 슬롯)
- 자동화 가능: n8n + Periodic Notes API로 작업보고서 자동 생성·아카이브

### 13. 단축키 (14:37-15:34) ★ 워크플로우 마무리

#### 상세 단축키 매핑
| 단축키 | 명령 | 결과 |
|--------|------|------|
| `Shift + 1` | Open Daily Note | 오늘 일자 노트 |
| `Shift + 2` | Open Weekly Note | 이번 주 노트 |
| `Shift + 3` | Open Monthly Note | 이번 달 노트 |
| `Shift + 4` | Open Yearly Note | 올해 노트 |

#### 주요 발언
> "연 단위의 장기계획부터 월간 주간 1단위의 단기계획까지 상세하게 계획하실 수 있겠죠." (15:25)

#### 시사점 (UTTEC)
- 사용자의 작업보고서 시스템에 적용 시:
  - Shift+1 → 오늘 작업보고서
  - Shift+2 → 이번 주 회고 (현재 미운영, 도입 후보)
  - Shift+3 → 월간 회고
  - Shift+4 → 연간 OKR/계획
