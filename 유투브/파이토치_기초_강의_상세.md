## 2. Python 프로그래밍 복습 (00:04:15 ~ 00:31:12)

### 2.1 클래스와 객체지향 프로그래밍

#### 클래스의 기본 구조

```python
class Animal:
    def __init__(self, name):
        """생성자: 객체가 만들어질 때 자동으로 호출됨"""
        self.name = name  # 인스턴스 변수

    def speak(self):
        """메서드: 클래스에 속한 함수"""
        pass
```

**핵심 개념:**
- `__init__`: 생성자 메서드, 객체 초기화
- `self`: 객체 자신을 가리키는 참조
- 인스턴스 변수: `self.name`처럼 객체마다 다른 값을 가짐

#### 클래스 상속 (Inheritance)

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return f"{self.name} says Woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says Meow!"

# 사용 예시
dog = Dog("Buddy")
print(dog.speak())  # "Buddy says Woof!"
```

**상속의 핵심:**
- 부모 클래스(Animal)의 속성과 메서드를 자식 클래스(Dog, Cat)가 물려받음
- 메서드 오버라이딩: 부모의 메서드를 자식이 재정의
- **PyTorch에서의 활용**: `nn.Module`을 상속받아 신경망 클래스 정의

```python
# PyTorch에서의 상속 활용
import torch.nn as nn

class MyModel(nn.Module):  # nn.Module을 상속
    def __init__(self):
        super().__init__()  # 부모 클래스 초기화
        self.layer = nn.Linear(10, 1)

    def forward(self, x):  # forward 메서드 오버라이딩
        return self.layer(x)
```

### 2.2 연산자 오버로딩 (Operator Overloading)

#### 매직 메서드 (Magic Methods)

Python에서 `__`로 시작하고 끝나는 특수 메서드들:

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        """+ 연산자 오버로딩"""
        return Vector(self.x + other.x, self.y + other.y)

    def __sub__(self, other):
        """- 연산자 오버로딩"""
        return Vector(self.x - other.x, self.y - other.y)

    def __mul__(self, scalar):
        """* 연산자 오버로딩 (스칼라 곱)"""
        return Vector(self.x * scalar, self.y * scalar)

    def __repr__(self):
        """객체의 문자열 표현"""
        return f"Vector({self.x}, {self.y})"

    def __len__(self):
        """len() 함수 지원"""
        return 2

# 사용 예시
v1 = Vector(1, 2)
v2 = Vector(3, 4)
v3 = v1 + v2  # __add__ 호출
print(v3)     # Vector(4, 6)
```

**주요 매직 메서드:**
| 메서드 | 연산자/함수 | 설명 |
|--------|------------|------|
| `__add__` | `+` | 덧셈 |
| `__sub__` | `-` | 뺄셈 |
| `__mul__` | `*` | 곱셈 |
| `__truediv__` | `/` | 나눗셈 |
| `__eq__` | `==` | 동등 비교 |
| `__lt__` | `<` | 작음 비교 |
| `__len__` | `len()` | 길이 |
| `__getitem__` | `[]` | 인덱싱 |
| `__iter__` | `for ... in` | 반복 |

**PyTorch Tensor에서의 활용:**
```python
import torch

a = torch.tensor([1, 2, 3])
b = torch.tensor([4, 5, 6])

# 연산자 오버로딩 덕분에 직관적인 연산 가능
c = a + b  # tensor([5, 7, 9])
d = a * 2  # tensor([2, 4, 6])
e = a @ b  # 내적: tensor(32)
```

## 5. 미분 (00:50:21 ~ 01:15:32)

### 5.1 미분의 직관적 이해

**핵심 개념 (강사 인용):**
> "미분은 순간변화율이고, 이것이 딥러닝에서 경사하강법의 핵심입니다."

#### 미분이란?

**일상적 비유:**
- 자동차의 속도계: 현재 순간의 속도 = 위치의 미분
- 주식 차트: 현재 순간의 상승/하락 추세 = 가격의 미분

**수학적 정의:**
```
f'(x) = lim(h→0) [f(x+h) - f(x)] / h
```

이것은 "h가 0에 가까워질 때, x에서 x+h까지의 평균 변화율"입니다.

#### 기울기의 의미

```
        ↗ 기울기 > 0: 함수가 증가하는 방향
   ____/
  /
 /     ← 기울기 = 0: 극값 (최소점 또는 최대점)
 \
  \____
       ↘ 기울기 < 0: 함수가 감소하는 방향
```

### 5.2 수치 미분 구현

#### 전방차분법 (Forward Difference)

```python
def forward_diff(f, x, h=1e-5):
    """전방차분: f'(x) ≈ [f(x+h) - f(x)] / h"""
    return (f(x + h) - f(x)) / h
```

#### 중앙차분법 (Central Difference) - 더 정확

```python
def central_diff(f, x, h=1e-5):
    """중앙차분: f'(x) ≈ [f(x+h) - f(x-h)] / (2h)"""
    return (f(x + h) - f(x - h)) / (2 * h)
```

#### 예제: f(x) = x² 의 미분

```python
f = lambda x: x ** 2

# x = 3에서의 미분값 계산
x = 3

# 수치 미분
numerical = central_diff(f, x)
print(f"수치 미분: {numerical}")  # 약 6.0

# 해석적 미분 (정확한 값)
# f'(x) = 2x, f'(3) = 6
analytical = 2 * x
print(f"해석적 미분: {analytical}")  # 정확히 6

# 오차
print(f"오차: {abs(numerical - analytical)}")  # 매우 작은 값
```

### 5.3 딥러닝에서 미분의 역할

#### 1. 손실 함수의 기울기 계산

손실 함수 L(w)에서 현재 가중치 w에서의 기울기 ∂L/∂w를 계산합니다.

```python
# 예: 이차 손실 함수
def loss(w):
    return (w - 3) ** 2  # 최소점이 w=3인 손실 함수

# w=5에서의 기울기
w = 5
gradient = central_diff(loss, w)
print(f"기울기: {gradient}")  # 양수 → w를 줄여야 손실 감소
```

#### 2. 경사하강법 (Gradient Descent)

```
새로운 가중치 = 현재 가중치 - 학습률 × 기울기
w_new = w_old - α × ∂L/∂w
```

**핵심 아이디어:**
- 기울기가 양수면: 오른쪽으로 갈수록 손실 증가 → 왼쪽으로 이동
- 기울기가 음수면: 오른쪽으로 갈수록 손실 감소 → 오른쪽으로 이동

```python
# 경사하강법 구현
w = 10  # 초기값
learning_rate = 0.1

for step in range(20):
    gradient = central_diff(loss, w)
    w = w - learning_rate * gradient
    print(f"Step {step+1}: w = {w:.4f}, loss = {loss(w):.4f}")

# w가 점점 3에 가까워짐
```

#### 3. 역전파 (Backpropagation)

**연쇄 법칙 (Chain Rule):**
```
∂L/∂w₁ = ∂L/∂y × ∂y/∂z × ∂z/∂w₁
```

- 출력층에서 입력층 방향으로 기울기를 전파
- 각 층의 기울기를 효율적으로 계산

### 5.4 PyTorch 자동 미분 (Autograd)

```python
import torch

# requires_grad=True: 이 텐서에 대한 미분 계산 필요
x = torch.tensor(3.0, requires_grad=True)

# 계산 수행
y = x ** 2

# 역전파: dy/dx 계산
y.backward()

# 기울기 확인
print(f"x = {x.item()}")
print(f"y = x² = {y.item()}")
print(f"dy/dx = 2x = {x.grad.item()}")  # 6.0
```

**복잡한 예제:**
```python
x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)

# z = x² + xy + y²
z = x**2 + x*y + y**2

z.backward()

print(f"∂z/∂x = 2x + y = {x.grad.item()}")  # 2*2 + 3 = 7
print(f"∂z/∂y = x + 2y = {y.grad.item()}")  # 2 + 2*3 = 8
```

#### 핵심 개념

| 용어 | 설명 | 예시 |
|------|------|------|
| 데이터 (X) | 입력 특성 (features) | 이미지 픽셀, 텍스트 |
| 레이블 (Y) | 정답 (targets) | "고양이", 3.5점 |
| 모델 | X → Y 매핑을 학습 | 신경망, 결정 트리 |

#### 학습 과정

```python
# 의사 코드로 표현한 학습 과정
def train(model, data, labels, epochs, learning_rate):
    for epoch in range(epochs):
        # 1. 예측
        predictions = model(data)

        # 2. 손실 계산
        loss = compute_loss(labels, predictions)

        # 3. 기울기 계산 (역전파)
        gradients = compute_gradients(loss, model.parameters)

        # 4. 파라미터 업데이트
        for param, grad in zip(model.parameters, gradients):
            param = param - learning_rate * grad

        print(f"Epoch {epoch}: Loss = {loss}")
```

### 7.1 LLM과 확률

**핵심 원리 (강사 인용):**

#### 다음 토큰 예측 예시

```
입력: "The cat sat on the"

출력 확률 분포:
  - "mat"    : 0.35  ████████████████████
  - "floor"  : 0.25  ██████████████
  - "chair"  : 0.15  ████████
  - "bed"    : 0.10  █████
  - "roof"   : 0.05  ██

```

#### 샘플링 전략

**1. Greedy Decoding**
```python
# 항상 최고 확률 선택
def greedy_sample(probs):
    return probs.argmax()
```
- 장점: 결정적, 재현 가능
- 단점: 다양성 부족, 반복적 출력

**2. Top-k Sampling**
```python
def top_k_sample(probs, k=10):
    # 상위 k개만 남기고 나머지는 0
    top_k_probs, top_k_indices = torch.topk(probs, k)
    # 정규화 후 샘플링
    selected = torch.multinomial(top_k_probs, 1)
    return top_k_indices[selected]
```

**3. Temperature Scaling**
```python
def temperature_sample(probs, temperature=1.0):
    # temperature > 1: 더 다양한 출력
    # temperature < 1: 더 보수적인 출력
    scaled_probs = torch.softmax(torch.log(probs) / temperature, dim=0)
    return torch.multinomial(scaled_probs, 1)
```

### 7.2 확률의 기초

#### 확률의 공리

1. **비음수성**: P(A) ≥ 0
2. **정규화**: P(전체) = 1
3. **가법성**: P(A ∪ B) = P(A) + P(B) (A, B가 배반사건일 때)

#### 조건부 확률

```
P(A|B) = P(A ∩ B) / P(B)
```

"B가 주어졌을 때 A의 확률"

**예시:**
- 비가 올 확률: P(비) = 0.3
- 비가 올 때 우산을 가져갈 확률: P(우산|비) = 0.9
- 비가 오고 우산을 가져갈 확률: P(비 ∩ 우산) = P(비) × P(우산|비) = 0.27

#### 베이즈 정리

```
P(A|B) = P(B|A) × P(A) / P(B)
```

**머신러닝에서의 해석:**
- P(A): 사전 확률 (prior)
- P(B|A): 가능도 (likelihood)
- P(A|B): 사후 확률 (posterior)
- P(B): 증거 (evidence)

## 9. 선형 회귀 (01:55:56 ~ 02:16:34)

### 9.1 선형 회귀란?

**가장 간단한 머신러닝 모델**

수식:
```
y = ax + b
```
- a: 기울기 (weight, 가중치)
- b: y절편 (bias, 편향)

**목표:**
- 데이터에 가장 잘 맞는 직선을 찾는 것
- 즉, 최적의 a와 b를 찾는 것

### 9.2 손실 함수 (Loss Function)

**강사의 설명 (원문에서 추출):**
> "손실 함수 값을 최소로 만드는 a와 b를 찾는 것이 목표입니다."

#### MSE (Mean Squared Error) - 평균 제곱 오차

```
L(a, b) = (1/n) × Σ(yᵢ - (axᵢ + b))²
```

**분해:**
1. `yᵢ`: 실제 값 (정답)
2. `axᵢ + b`: 예측 값
3. `yᵢ - (axᵢ + b)`: 오차 (실제 - 예측)
4. `(...)²`: 오차의 제곱 (부호 제거, 큰 오차에 더 큰 페널티)
5. `Σ(...)`: 모든 데이터의 오차 합
6. `(1/n) × ...`: 평균

```python
def mse_loss(y_true, y_pred):
    """평균 제곱 오차 계산"""
    return np.mean((y_true - y_pred) ** 2)

# 예시
y_true = np.array([3, 5, 7, 9])
y_pred = np.array([2.5, 5.5, 6.5, 9.5])
loss = mse_loss(y_true, y_pred)
print(f"MSE: {loss}")  # 0.25
```

### 9.3 최소 제곱법 (Least Squares Method)

**강사의 설명:**
> "제곱 오차의 합을 최소화하는 a와 b를 찾는 방법입니다."

#### 해석적 해 (Closed-form Solution)

간단한 선형 회귀의 경우, 미분을 통해 직접 해를 구할 수 있습니다:

```python
def least_squares(x, y):
    """최소 제곱법으로 a, b 계산"""
    n = len(x)

    # a = (n*Σxy - Σx*Σy) / (n*Σx² - (Σx)²)
    numerator = n * np.sum(x * y) - np.sum(x) * np.sum(y)
    denominator = n * np.sum(x ** 2) - np.sum(x) ** 2
    a = numerator / denominator

    # b = (Σy - a*Σx) / n
    b = (np.sum(y) - a * np.sum(x)) / n

    return a, b

# 예시 데이터
x = np.array([1, 2, 3, 4, 5])
y = np.array([2.1, 4.0, 5.9, 8.1, 10.0])

a, b = least_squares(x, y)
print(f"y = {a:.2f}x + {b:.2f}")  # 약 y = 2.00x + 0.02
```

### 9.4 경사하강법으로 선형 회귀 구현

```python
import numpy as np
import matplotlib.pyplot as plt

# 데이터 생성
np.random.seed(42)
x = np.linspace(0, 10, 50)
y_true = 2 * x + 1  # 실제 관계: y = 2x + 1
y = y_true + np.random.randn(50) * 2  # 노이즈 추가

# 초기화
a = np.random.randn()  # 가중치 (기울기)
b = np.random.randn()  # 편향 (y절편)
learning_rate = 0.01
epochs = 100

# 학습 기록
losses = []

# 경사하강법
for epoch in range(epochs):
    # 예측
    y_pred = a * x + b

    # 손실 계산
    loss = np.mean((y - y_pred) ** 2)
    losses.append(loss)

    # 기울기 계산 (손실 함수를 a, b로 미분)
    # ∂L/∂a = -2/n × Σ(yᵢ - (axᵢ + b)) × xᵢ
    # ∂L/∂b = -2/n × Σ(yᵢ - (axᵢ + b))
    da = -2 * np.mean((y - y_pred) * x)
    db = -2 * np.mean(y - y_pred)

    # 파라미터 업데이트
    a = a - learning_rate * da
    b = b - learning_rate * db

    if epoch % 20 == 0:
        print(f"Epoch {epoch:3d}: a = {a:.4f}, b = {b:.4f}, loss = {loss:.4f}")

print(f"\n최종 결과: y = {a:.4f}x + {b:.4f}")
print(f"실제 관계: y = 2.0000x + 1.0000")
```

### 10.1 왜 비선형이 필요한가?

#### XOR 문제

```
(0, 0) →   0

(1, 0) →   1
```

**시각화:**

### 10.3 활성화 함수 (Activation Functions)

#### Sigmoid 함수

```python
def sigmoid(x):
    """시그모이드 함수: 출력을 0~1 사이로 압축"""
    return 1 / (1 + np.exp(-x))
```

**특징:**
- 출력 범위: (0, 1)
- 확률로 해석 가능
- 이진 분류의 출력층에서 사용

**단점:**
- **Vanishing Gradient**: 입력이 크거나 작으면 기울기가 거의 0
- 학습이 느려지는 원인

```python
# Sigmoid의 기울기 (도함수)
def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

# x = 10일 때
x = 10
print(f"sigmoid(10) = {sigmoid(x):.6f}")           # 0.999955
print(f"sigmoid'(10) = {sigmoid_derivative(x):.8f}")  # 0.00004539 (매우 작음!)
```

#### ReLU (Rectified Linear Unit)

```python
def relu(x):
    """ReLU: max(0, x)"""
    return np.maximum(0, x)
```

**특징:**
- 출력 범위: [0, ∞)
- 계산이 매우 단순
- **현재 가장 많이 사용되는 활성화 함수**

**장점:**
- Vanishing Gradient 문제 완화
- 계산 효율적
- Sparse activation (일부 뉴런만 활성화)

**단점:**
- **Dying ReLU**: 음수 입력에 대해 항상 0 출력 → 학습 중단

```python
# ReLU 변형들
def leaky_relu(x, alpha=0.01):
    """Leaky ReLU: 음수에서도 작은 기울기"""
    return np.where(x > 0, x, alpha * x)

def elu(x, alpha=1.0):
    """ELU: 음수에서 지수함수"""
    return np.where(x > 0, x, alpha * (np.exp(x) - 1))
```

### 10.4 다층 퍼셉트론 (MLP, Multi-Layer Perceptron)

#### 구조

```
입력층 (Input)    은닉층 (Hidden)    출력층 (Output)
     x₁ ○ ─────────┬──→ ○ h₁ ──────┬──→ ○ y₁
                   │              │
     x₂ ○ ─────────┼──→ ○ h₂ ──────┼──→ ○ y₂
                   │              │
     x₃ ○ ─────────┴──→ ○ h₃ ──────┴──→
                   │
                   └──→ ○ h₄
```

**구성 요소:**
- **입력층**: 데이터를 받음
- **은닉층**: 특성 추출 및 변환 (여러 개 가능)
- **출력층**: 최종 예측
- **각 연결**: 가중치 (학습됨)
- **각 뉴런**: 활성화 함수 적용

#### PyTorch로 MLP 구현

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()

        # 층 정의
        self.layer1 = nn.Linear(input_size, hidden_size)
        self.layer2 = nn.Linear(hidden_size, hidden_size)
        self.layer3 = nn.Linear(hidden_size, output_size)

        # 활성화 함수
        self.relu = nn.ReLU()

    def forward(self, x):
        # 순전파 정의
        x = self.relu(self.layer1(x))  # 입력 → 은닉1 → ReLU
        x = self.relu(self.layer2(x))  # 은닉1 → 은닉2 → ReLU
        x = self.layer3(x)              # 은닉2 → 출력 (활성화 없음)
        return x

# 모델 생성
model = MLP(input_size=10, hidden_size=64, output_size=2)
print(model)
```

## 11. 경사하강법 심화 (02:32:29 ~ 02:52:26)

### 11.1 MSE 손실 함수의 기울기 계산

**강사의 설명:**
> "MSE 손실을 파라미터로 미분하면, 그 방향으로 파라미터를 업데이트합니다."

**수식 유도:**

손실 함수:
```
L = (1/n) × Σ(yᵢ - ŷᵢ)²
```

예측:
```
ŷᵢ = w × xᵢ + b
```

기울기:
```
∂L/∂w = -(2/n) × Σ(yᵢ - ŷᵢ) × xᵢ
∂L/∂b = -(2/n) × Σ(yᵢ - ŷᵢ)
```

### 11.2 학습률 (Learning Rate)의 영향

**강사의 설명:**
> "학습률이 너무 크면 발산하고, 너무 작으면 수렴이 느립니다. 적절한 값을 찾는 것이 중요합니다."

#### 시각적 비교

```python
import numpy as np
import matplotlib.pyplot as plt

def loss_function(w):
    """간단한 이차 손실 함수: L = (w-3)²"""
    return (w - 3) ** 2

def gradient(w):
    """손실 함수의 기울기: dL/dw = 2(w-3)"""
    return 2 * (w - 3)

def train_with_lr(learning_rate, epochs=50):
    """특정 학습률로 학습"""
    w = 10  # 초기값
    history = [w]

    for _ in range(epochs):
        w = w - learning_rate * gradient(w)
        history.append(w)

    return history

# 다양한 학습률 비교
lrs = [0.01, 0.1, 0.5, 1.1]
fig, axes = plt.subplots(1, 4, figsize=(16, 4))

for ax, lr in zip(axes, lrs):
    history = train_with_lr(lr)
    ax.plot(history, 'b.-')
    ax.axhline(y=3, color='r', linestyle='--', label='Optimal')
    ax.set_title(f'Learning Rate = {lr}')
    ax.set_xlabel('Epoch')
    ax.set_ylabel('w')
    ax.legend()
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

| 학습률 | 결과 |
|--------|------|
| 0.01 (너무 작음) | 느린 수렴, 많은 epoch 필요 |
| 0.1 (적절) | 안정적 수렴 |
| 0.5 (약간 큼) | 진동하면서 수렴 |
| 1.1 (너무 큼) | 발산 (loss가 증가) |

### 11.3 역전파 (Backpropagation)

**강사 인용:**
> "역전파는 연쇄 법칙을 이용해서 각 층의 기울기를 효율적으로 계산합니다."

#### 연쇄 법칙 (Chain Rule)

```
L = f(g(h(w)))

∂L/∂w = ∂L/∂f × ∂f/∂g × ∂g/∂h × ∂h/∂w
```

**직관적 이해:**
- 출력층에서 입력층 방향으로 기울기를 "전파"
- 각 층에서 local gradient를 곱해나감

#### 간단한 예제

```
입력 x → [×w] → z → [ReLU] → a → [×v] → y → [Loss] → L

순전파:
z = w × x
a = ReLU(z)
y = v × a
L = (y - target)²

역전파:
∂L/∂y = 2(y - target)
∂L/∂v = ∂L/∂y × ∂y/∂v = ∂L/∂y × a
∂L/∂a = ∂L/∂y × ∂y/∂a = ∂L/∂y × v
∂L/∂z = ∂L/∂a × ∂a/∂z = ∂L/∂a × (1 if z > 0 else 0)
∂L/∂w = ∂L/∂z × ∂z/∂w = ∂L/∂z × x
```

### 12.6 완전한 학습 루프

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

# 1. 데이터 준비
dataset = CustomDataset(X_train, y_train)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)

# 2. 모델 정의
class NeuralNet(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.fc2(x)
        return x

model = NeuralNet(10, 64, 1)

# 3. 손실 함수와 최적화기
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 4. GPU 설정
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = model.to(device)

# 5. 학습 루프
epochs = 100
for epoch in range(epochs):
    epoch_loss = 0.0

    for batch_x, batch_y in dataloader:
        # 데이터를 GPU로
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)

        # 순전파
        outputs = model(batch_x)
        loss = criterion(outputs, batch_y)

        # 역전파
        optimizer.zero_grad()  # 기울기 초기화
        loss.backward()        # 기울기 계산
        optimizer.step()       # 파라미터 업데이트

        epoch_loss += loss.item()

    # 로깅
    if (epoch + 1) % 10 == 0:
        avg_loss = epoch_loss / len(dataloader)
        print(f"Epoch [{epoch+1}/{epochs}], Loss: {avg_loss:.4f}")

print("학습 완료!")
```

## 15. Stochastic Gradient Descent (03:24:28 ~ 끝)

### 15.1 Full Batch vs Mini-Batch vs Stochastic

**강사의 설명:**
> "전체 데이터로 기울기를 계산하는 것이 Full Batch이고, 일부만 사용하는 것이 Mini-Batch입니다."

| 방법 | 데이터 사용량 | 특징 |
|------|-------------|------|
| Full Batch GD | 전체 데이터 | 정확하지만 느림, 메모리 많이 필요 |
| Stochastic GD | 1개 데이터 | 빠르지만 노이즈 많음 |
| Mini-Batch GD | n개 데이터 (보통 32~256) | 둘의 절충, 가장 많이 사용 |

### 15.2 Mini-Batch의 장점

1. **메모리 효율**: 전체 데이터를 한번에 올리지 않아도 됨
2. **GPU 병렬화**: 배치 내 데이터를 병렬 처리
3. **정규화 효과**: 노이즈가 일반화에 도움
4. **빠른 업데이트**: 한 epoch에 여러 번 파라미터 업데이트

### 15.3 배치 크기의 영향

```python
# 작은 배치 (예: 8, 16)
# - 장점: 정규화 효과, 메모리 절약
# - 단점: 학습 불안정, 느린 수렴

# 큰 배치 (예: 256, 512)
# - 장점: 안정적 학습, GPU 효율
# - 단점: 일반화 성능 저하 가능, 메모리 많이 필요

# 일반적인 선택: 32, 64, 128
dataloader = DataLoader(dataset, batch_size=64, shuffle=True)
```

### 15.4 전체 학습 과정 정리

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

# 1. 데이터 준비
X_train = torch.randn(1000, 10)
y_train = torch.randn(1000, 1)
dataset = TensorDataset(X_train, y_train)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)

# 2. 모델, 손실 함수, 최적화기
model = nn.Sequential(
    nn.Linear(10, 64),
    nn.ReLU(),
    nn.Linear(64, 1)
)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 3. 학습 루프
epochs = 50
for epoch in range(epochs):
    model.train()  # 학습 모드
    epoch_loss = 0.0

    for batch_x, batch_y in dataloader:
        # 순전파
        outputs = model(batch_x)
        loss = criterion(outputs, batch_y)

        # 역전파
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        epoch_loss += loss.item()

    # 에폭 종료 후 로깅
    avg_loss = epoch_loss / len(dataloader)
    print(f"Epoch {epoch+1}/{epochs}, Loss: {avg_loss:.4f}")

# 4. 평가
model.eval()
with torch.no_grad():
    test_outputs = model(X_test)
    test_loss = criterion(test_outputs, y_test)
    print(f"Test Loss: {test_loss.item():.4f}")

# 5. 모델 저장
torch.save(model.state_dict(), 'final_model.pth')
```
