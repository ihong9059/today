# 클로드 코드(Claude Code) + 피그마(Figma)로 일관된 디자인 하는 방법

## 영상 정보
- **채널:** 피튜브
- **연사:** 피그마 튜터 (피튜브 운영자)
- **재생시간:** 21:39
- **링크:** [YouTube 영상 보기](https://www.youtube.com/watch?v=cSx1GCgoCrU)

## 전체 요약

### 핵심 주제
피그마 디자인 시스템(베리어블, 스타일, 컴포넌트)을 피그마 데브모드 MCP로 클로드 코드에 연결하여, 일관된 디자인 토큰과 컴포넌트 기반의 바이브 코딩으로 랜딩 페이지를 제작하는 전체 워크플로우를 실습한다.

### 핵심 내용
- **디자인 시스템이 필요한 3가지 이유**: 일관된 디자인, 유지보수 효율, 비용(토큰) 절감 — 디자인 시스템 없이 바이브 코딩하면 매번 디자인 설명을 반복해야 하고, 수정 시 전체를 다시 만들어야 한다
- **피그마 디자인 시스템 핵심 3요소**: 베리어블(디자인 토큰 구현), 스타일(반복 속성 등록), 컴포넌트(템플릿 원본+인스턴스) — 원본 수정 시 모든 사본이 한번에 수정됨
- **피그마 MCP 2종류**: 데브모드 MCP(피그마 공식, 유료, 디자인→코드 최적화)와 톡투 피그마 MCP(서드파티, 무료 가능, 디자인 수정/자동화 용도) — 용도에 따라 선택 사용
- **클로드 코드 연결 실습**: 커서 확장 프로그램 또는 터미널로 클로드 코드 설치 → MCP 명령어 입력 → 피그마 인증 → 13가지 도구 활용 가능
- **디자인 토큰/컴포넌트 추출**: 피그마에서 프레임 선택 후 데브모드 MCP로 베리어블/스타일 읽어서 JS/CSS 토큰 파일 자동 생성
- **CLAUDE.md 활용**: 디자인 시스템 규칙을 CLAUDE.md에 등록하면, 매번 설명 없이 토큰 재사용/하드코딩 방지/누락 요소 확인 자동화
- **최종 랜딩 페이지 완성**: 추출한 토큰과 컴포넌트 기반으로 원본과 거의 유사한 랜딩 페이지 생성 — 디테일은 MCP 대화로 다듬기
- **피그마 커뮤니티 활용 팁**: 처음부터 디자인 시스템 작업이 부담되면 피그마 커뮤니티의 무료 디자인 시스템 소스로 시작 추천

## 구간별 요약

### 1. 인트로 — 바이브 코딩에 디자인 시스템이 필요한 이유 [0:00-2:45](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=0s)
피그마 디자인 시스템 기반 클로드 코드 바이브 코딩 소개. 디자인 시스템이 필요한 3가지 이유: 일관된 디자인, 유지보수 효율, 토큰 비용 절감. 실제 프로젝트(피그마 피디아, 스크린플로우)를 예시로 컴포넌트 기반 페이지 구성 방식 설명.

### 2. 피그마 디자인 시스템 핵심 요소 3가지 [2:45-10:51](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=165s)
베리어블(디자인 토큰 구현, 4종류), 스타일(반복 속성 등록), 컴포넌트(원본+인스턴스 구조, 4종 프로퍼티). 핵심 공통점은 원본 수정 시 모든 사본 일괄 수정. 작업 흐름: 토큰 제작 → 컴포넌트 적용 → 조합 → 페이지.

### 3. 피그마 MCP 개념 및 종류 [10:51-13:07](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=651s)
MCP는 클로드 코드와 외부 도구(피그마, 슬랙 등)를 연결하는 USB 허브 같은 커넥터. 데브모드 MCP(공식, 유료, 디자인→코드 최적화, 플러그인 불필요)와 톡투 피그마 MCP(서드파티, 무료 가능, 40가지 도구, 디자인 수정/주석 자동화)의 차이 설명.

### 4. 클로드 코드에 피그마 MCP 연결하기 [13:07-16:08](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=787s)
커서 확장 프로그램 또는 터미널에서 클로드 코드 설치. MCP 연결 명령어 입력 → 피그마 인증 → /mcp로 연결 확인. 데브모드 MCP 13가지 도구 확인. 피그마에서 데브모드 열고 프레임 선택 후 프롬프트 입력하는 실습 과정.

### 5. 디자인 토큰 및 컴포넌트를 코드로 추출하기 [16:08-20:47](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=968s)
피그마의 컬러/타이포그라피 베리어블을 읽어 JS/CSS 토큰 파일 자동 생성. 컴포넌트 섹션 선택 후 코드화(버튼, 드롭다운, 헤더 등). 디자인 시스템 페이지 자동 생성으로 시각적 확인. 컨텍스트 70% 초과 시 /compact 처리 필요. CLAUDE.md에 작업 원칙 등록하여 토큰 재사용, 하드코딩 방지, 누락 시 확인 요청 자동화.

### 6. 추출한 시스템으로 최종 랜딩 페이지 완성하기 [20:47-21:06](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=1247s)
제작한 토큰과 컴포넌트 기반으로 랜딩 페이지 바이브 코딩. 원본과 거의 유사한 아웃풋 생성 확인. 디테일(정렬, 아이콘, 로고 등)은 MCP 대화로 추가 다듬기 필요.

### 7. 마무리 및 유용한 팁 [21:06-21:39](https://www.youtube.com/watch?v=cSx1GCgoCrU&t=1266s)
처음부터 디자인 시스템 작업이 부담되면 피그마 커뮤니티의 무료 디자인 시스템 소스로 시작 추천. 어떤 프로덕트든 디자인 시스템을 먼저 잡고 토큰을 적용하면 토큰 절약 + 원하는 아웃풋에 가까운 결과물 생성 가능.

## 실전 적용 포인트

### 즉시 적용 가능
- 피그마 데브모드 MCP를 클로드 코드에 연결하여 디자인→코드 자동 변환
- 피그마 커뮤니티에서 무료 디자인 시스템 복제 후 MCP로 토큰/컴포넌트 추출
- CLAUDE.md에 디자인 시스템 규칙(토큰 재사용, 하드코딩 금지) 등록

### 필수 준비 사항
- 피그마 유료 계정 (데브모드 MCP 사용 시 필수)
- 클로드 코드 설치 (커서 확장 프로그램 또는 터미널)
- 디자인 시스템 기본 이해 (베리어블, 스타일, 컴포넌트)

### 워크플로우
1. 피그마에서 디자인 시스템 구성 (토큰 → 컴포넌트 → 페이지)
2. 클로드 코드에 데브모드 MCP 연결
3. 토큰/스타일 추출하여 코드 파일 생성
4. 컴포넌트 섹션 선택 후 코드화
5. CLAUDE.md에 작업 원칙 등록
6. 최종 페이지 바이브 코딩 + MCP 대화로 디테일 다듬기
