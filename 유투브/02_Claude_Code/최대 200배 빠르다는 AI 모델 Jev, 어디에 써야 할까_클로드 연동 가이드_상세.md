## 한 줄 요약

**Jev = TypeSafe AI가 2026-09-15 출시한 "System One" 판단 전용 모델.** 문장을 생성하지 않고(대화·설명 불가), 텍스트/JSON을 입력받아 **미리 정의한 타입의 판단 결과(참/거짓 확률·선택지·점수)만 구조화해서 반환**한다. 환각이 없고, 지연시간 70~500ms, 가격은 입력 100만 토큰당 $0.042(출력 무료) 수준으로 범용 LLM 대비 압도적으로 빠르고 저렴하다. **범용 LLM을 대체하는 게 아니라, 업무 안에서 "반복되는 분류·평가"를 Jev가 맡고 "답변 작성·복잡한 해결"은 Claude가 맡는 역할 분담**이 핵심. Claude Code 공식 skill로 둘을 연결한다.

## 구간별 상세 내용

### 1. 도입 — Jev로 뭘 하고 있나 (00:00-00:55)
#### 핵심 메시지
SNS에서 Jev 활용 사례가 쏟아지는데, 정작 이 모델은 문장 하나 못 쓰고 대화도 못 하며 판단 근거도 설명 안 한다. 그런데 어떻게 작업을 처리할까?

#### 언급된 사례/에피소드
- **잠재 고객 700명 × 고객별 영업 메시지 적합도 평가**
- **한 사람의 경력을 400개 기업 채용 조건과 비교 → 잘 맞는 일자리 매칭**
- **뉴스 수백 건 분석 → 브랜드별로 활용할 기사 선별**
- 공통점: 다양한 작업을 **빠른 시간 + 적은 비용**으로 처리

### 2. 왜 필요한가 — 조건문의 한계 (00:55-02:55)
#### 핵심 메시지
프로그램은 "주문 5만원 이상 → 무료배송" 같은 **조건문(숫자 비교)**은 잘 하지만, "고객 불만이 얼마나 강한가" 같은 **맥락 판단**은 못 한다. Jev가 바로 이 지점을 메운다.

#### 상세 내용
- 예: "3일째 결제 연동 실패, 매출 손해, 최대한 빨리 도와주세요" → 금액은 숫자 비교 가능하지만 불만 강도는 맥락을 읽어야 함
- 불만 정도를 (차분함 / 불만 있지만 정중 / 매우 화남) 단계로 정의 → Jev가 척도에 따라 **점수 반환** → 프로그램이 불만 큰 순으로 정렬
- 사람의 말 → 프로그램이 쓸 수 있는 **숫자로 변환**하는 역할
- **"기존 LLM(클로드·GPT)도 되는 거 아닌가?" → 맞다. 중요한 건 '할 수 있느냐'가 아니라 '얼마나 빠르고 싸게 반복'하느냐.** 1~2건은 차이 없지만 하루 수천 건이면 건당 시간·비용이 결정적.

### 3. 작동 방식 — 생성 vs 병렬 판단 (02:55-04:00)
#### 핵심 메시지
일반 LLM은 토큰을 **하나씩 순차 생성**. Jev는 자유 문장 생성 대신 **여러 판단을 한 요청에 병렬 출력**하도록 설계 → 속도·비용 강점의 근원.
- 예: 한 문의에 대해 "문의 유형? / 환불 요구하나? / 불만 정도?"를 **한 번의 요청에 함께** 넣어 동시 평가

### 4. 세 가지 질문 타입 (04:00-05:30) ⭐
| 타입 | 용도 | 반환 | 제약 |
|---|---|---|---|
| **Noul** (너/불) | 예/아니오 조건 판단 | 0~1 확률 (1에 가까울수록 참) | boolean형 |
| **Choice** (초이스) | 여러 선택지 중 하나로 분류 | 각 선택지별 확률 (결제 85% / 기술 10% / 기능 5%) | 최대 255개 선택지 |
| **Score** (스코어) | 순서 있는 척도로 정도 평가 | 척도에 따른 점수 | 2~10 레벨 |

- 정리: 조건 확인=Noul, 분류=Choice, 정도 평가=Score. 같은 내용 판단이면 셋을 한 요청에 함께 넣을 수 있음.

### 5. 신뢰도(불확실성)까지 반환 (05:30-06:40) ⭐
#### 핵심 메시지
결과만이 아니라 **그 판단이 얼마나 불확실한지(confidence)도 함께** 준다.
- 예: 결제 90%/기술 10% vs 결제 51%/기술 49% → 둘 다 "결제"가 최상위지만 취급이 달라야 함
- **분명한 건 → 담당자에게 자동 전달 / 애매한 건 → 추가 확인 목록**으로 라우팅
- 단, 확률 높다고 항상 맞는 건 아님 → 실제 업무 데이터로 검증 필수
- **활용 원칙: 업무 전체를 통째로 맡기지 말고, 그 안의 "반복되는 분류·평가"만 찾아 맡겨라. 그다음 설명 작성·복잡한 문제는 Claude가 이어서 처리.**

### 6. 실습 — 가입·API 키·skill 설치 (06:40-08:45)
#### 상세 내용
1. **TypeSafe 웹사이트 가입** → 콘솔
2. **크레딧 충전** (최소 $5) — $5로도 수만~수십만 건 분류·평가 가능
3. 좌측 메뉴 **API Keys → Create Key**로 키 생성
4. **클로드 코드**로 이동 → TypeSafe **공식 skill 설치**(공식 문서의 두 명령어를 터미널에서 실행). skill에는 "Jev 질문을 어떤 형식으로 보내고, 돌아온 결과를 어떻게 읽는지"가 들어 있음
5. 프로젝트 폴더에 **`.env` 파일** 생성 → `TYPESAFE_API_KEY=발급받은키` 저장

### 7. 연결 테스트 (08:45-10:05)
- 입력창에 `/` → TypeSafe skill 선택 → "고객 메시지가 환불 요청인지 Jev Noul 질문으로 평가하고, 응답·소요시간 보여줘"
- 결과: 환불 요청 확률 **0.99**, 전체 소요 **약 0.26초**(네트워크+서버 포함), 입력 토큰 342 / 출력 토큰 23

### 8. 100건 일괄 분류 → Claude 답변 연결 (10:05-14:20)
#### 핵심 메시지
시연용 고객 문의 100건(비밀번호 변경 같은 사용법 / 이중결제 같은 결제 / 업로드 오류 같은 기술)을 **Jev로 먼저 분류** → 처리 경로별로 분기.
- 환불 요청 → 결제 내역·환불 가능 여부 확인 필요 → **사람 검토 목록**
- 로그인/저장 오류 → **기술팀 확인**
- "다크모드 추가해줘" 기능 요청 → **별도 수집**(제품 개선 참고)
- "비밀번호 어디서 바꾸나요" 사용법 → 안내 내용 정해져 있음 → **Claude가 답변 초안 작성**

### 9. 결론 — 어디에 써야 하나 (14:20-16:29) ⭐
#### 핵심 메시지
- **역할 분담(공식 권장)**: Jev가 분류 → 프로그램이 결과에 따라 (일반 코드 처리 / 다른 AI / 사람 확인)으로 분기 → 답변 필요한 것만 Claude에 전달. 모든 건에 Claude를 돌릴 필요가 없어져 전체 시간·비용 절감.
- **핵심**: 업무 전체를 맡기는 게 아니라 **"반복적으로 판단해야 하는 부분"에 Jev를 쓰고 그 결과를 다음 작업으로 연결**.
- **확장 적용 예**: 뉴스에서 자사 관련 기사 선별 / 잠재고객 구매신호 평가 / 상품 리뷰를 배송·품질·가격 불만으로 분류.
- **주의**: 빠르고 싸다고 모든 판단이 정확한 건 아니다 → 우리 업무 데이터로 결과 검증 + 사람 검토 기준 설정 필수. Jev는 범용 LLM 대체가 아니라 **각자 장점을 살려 함께 쓰는** 모델.
- **권고**: 비슷한 작업을 수백~수천 번 반복하는 과정이 있다면 **작은 작업부터 테스트**해보라.

## 용어 및 개념 설명
| 용어 | 설명 |
|------|------|
| **System One / System Two** | 카너먼의 빠른 직관(System 1) vs 느린 추론(System 2) 비유. Jev=System One(빠른 구조적 판단), 범용 LLM=System Two(추론·생성) |
| **Noul** | 참/거짓 질문에 0~1 확률 반환 (boolean) |
| **Choice** | 선택지(최대 255개) 중 분류, 선택지별 확률 반환 |
| **Score** | 순서 있는 척도(2~10레벨) 점수 반환 |
| **Confidence(신뢰도)** | 판단의 불확실성. >0.9 자동처리 / 0.5~0.9 사용자 확인 / <0.5 사람 검토 라우팅(캘리브레이션됨) |
| **구조화 출력(never hallucinates)** | 자유 텍스트 대신 타입이 보장된 값만 반환 → 파싱·환각 문제 없음 |

## 검증된 핵심 사실 (웹 교차확인)
- **출시**: 2026-09-15, TypeSafe AI. Jev = 첫 System One 모델.
- **API**: `POST https://api.typesafe.ai/v1/systemone`, 모델 라우트 `jev-latest`. (초기 waitlist 가능성)
- **성능/가격**: 지연 70~500ms / 입력 $0.042 per 1M tokens, 출력 무료. 콘솔 최소 충전 $5.
- **대체 접근경로**: OpenRouter(`typesafe/jev-1.14`, OpenAI 호환), Vercel AI Gateway, LiteLLM, Pydantic AI, Cloudflare AI.
- **Claude Code 연동**: 공식 skill `claude plugin marketplace add typesafe-ai/skills` + 커뮤니티 skill 다수(GitHub: jev-skill, jev-claude-skill, jev-code). Python/JS SDK 제공.
