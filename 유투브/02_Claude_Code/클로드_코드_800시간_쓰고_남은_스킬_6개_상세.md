### 1. Andrej Karpathy Skill (00:34 ~ 01:57)
[바로가기](https://www.youtube.com/watch?v=UClLUoGaCxU&t=34s)

#### 핵심 메시지
"스킬이라 부르기도 애매한" **MD 파일 한 장 + 4가지 규칙**. 그런데 GitHub stars 15만 개를 넘김. 설치 10초.

#### 상세 내용
- 만든 사람: **Andrej Karpathy** — 테슬라 AI 총괄, 최근 **Anthropic 합류**
- AI 코드에이트(코딩 어시스턴트)를 계속 쓰면서 **반복적으로 나타나는 문제 3가지** 발견:
  1. **모르는 걸 모르는 상태에서 그냥 코드를 짜기 시작** — 질문도 안 하고 바로 구현부터 들어감
  2. **100줄이면 충분한 코드를 천 줄 자리로** 만듦
  3. **버그 하나만 고쳐 달라 했는데 주변 코드까지 같이 건드림**
- 이 문제들을 `CLAUDE.md` 형식의 **4가지 규칙**으로 깔끔하게 정리
- 설치는 터미널에서 명령 두 줄을 복사·붙여넣기 (UserScope 설치 가능)
- `/reload-plugin`으로 설정 새로고침 → "Karpathy 가이드라인"이 새 스킬로 등록

#### 언급된 사례/에피소드
- **Andrej Karpathy 합류 + 글 게시**: 테슬라 AI 총괄 출신 → Anthropic 합류 → AI 코딩 가이드라인 공개. **MD 파일 1장이 GitHub stars 15만+** 도달

#### 주요 발언
> "안드레 카파시라 하면 테슬라 AI 총괄이었기도 하고 최근에 Anthropic에 합류한 인물이죠." (00:49~00:53)

> "설치는 10초도 안 걸리지만, 써보시면 확실히 달라진 게 체감이 될 겁니다." (01:54~01:59)

[바로가기](https://www.youtube.com/watch?v=UClLUoGaCxU&t=202s)

### 4. Understand (04:51 ~ 06:16)
[바로가기](https://www.youtube.com/watch?v=UClLUoGaCxU&t=291s)

#### 핵심 메시지
처음 보는 코드베이스의 막막함을 해결. `/understand` 한 줄이면 멀티에이전트가 전체를 스캔 → **지식 그래프 + 인터랙티브 대시보드 + 가이드 투어**.

- 해외 커뮤니티에서 주목받는 초기 스킬, GitHub stars 이미 **4만+**
- 해결하는 문제: **20만 줄짜리 코드베이스를 받았는데 어디서부터 봐야 할지 모르겠을 때**
- 사용 흐름:
  1. 스킬 설치 + `/reload-plugin`
  2. 프로젝트 폴더에서 `/understand` 입력 → 분석 시작

- 변경 추적:
  - 한 번 만든 그래프는 폴더에 저장됨
  - 코드가 바뀌면 **diff로 영향도** 확인 가능

### 5. Agent Memory (06:16 ~ 07:27)
[바로가기](https://www.youtube.com/watch?v=UClLUoGaCxU&t=376s)

#### 핵심 메시지
클로드 코드 기본 메모리(MD 파일 수동 관리)의 한계를 해결. **12개 자동 후크로 모든 세션 작업을 조용히 기록** + **벡터·그래프 검색**으로 다음 세션에 필요한 컨텍스트만 주입.

#### 상세 내용
- 기본 클로드 코드 메모리: 마크다운 파일에 세션별 기록을 적어두는 방식
  - **한계 1**: 분량이 커지면 관리가 어려워짐
  - **한계 2**: 매번 기록할 때 **모든 내용을 기록할 수 없음**
- Agent Memory 작동 방식:
  - **12개의 자동 후크**가 세션에서 일어나는 모든 작업을 조용히 기록
  - 사용자가 따로 뭘 할 필요 없이 평소처럼 코딩하면 됨
  - 알아서 **내용을 압축해서 로컬 데이터베이스에 저장**
  - 다음 세션 시작 시 **필요한 컨텍스트만 골라서 다시 주입**
- 기존 빌트인 메모리와 가장 다른 점 — **검색 방식**:
  - 기존: 파일 전체를 컨텍스트에 넣다 보니 **관련 없는 내용까지 같이 들어감**
  - Agent Memory: **벡터 검색 + 그래프 검색을 조합**해 현재 작업에 필요한 정보만 골라서 가져옴
- **웹 뷰어** 제공 → 클로드가 지금 프로젝트에 대해 무엇을 기억하고 있는지 직접 확인 가능

#### 주요 발언
> "12개의 자동 후크가 세션에서 일어나는 모든 작업을 조용히 기록합니다. 사용자가 따로 뭘 할 필요는 없습니다." (06:46~06:53)

> "벡터 검색·그래프 검색을 조합해서 현재 작업에 필요한 정보만 골라서 가져올 수 있습니다." (07:14~07:20)

[바로가기](https://www.youtube.com/watch?v=UClLUoGaCxU&t=447s)

#### 핵심 메시지
**Anthropic 공식 스킬**. 가장 강력한 스킬은 결국 본인한테 딱 맞는 걸 직접 만드는 것. 단, **"한 번 만들고 끝"이 아니라 결과물을 보고 계속 다듬는 게 핵심**.

#### 상세 내용
- 동작:
  1. Skill Creator에게 "이런 걸 만들고 싶다" 자연어로 설명
  2. 클로드가 스킬을 **생성·테스트·패키징**까지 수행
  3. 사용자는 코드 직접 수정하거나 포맷을 외울 필요 없음
- 화자 사례:
  - YouTube 채널 운영 → **"영상 대본을 넣으면 SRT 자막 파일을 교정해 주는 스킬 만들어 줘"** → Skill Creator가 만들어 줌 → 그 후 재사용
