## 한 줄 요약

**OhMyClaude Code (오마이클로드 코드)** — Claude Code 플러그인 소개 영상. 핵심 두 기능:

1. **랄프 모드 (Ralph Mode)** = "끝까지 멈추지 않고 완성될 때까지" 자율 실행 + 에이전트들끼리 핑퐁 (리뷰 에이전트 자동 추가) — Human-in-the-Loop 최소화
2. **딥 인터뷰 (Deep Interview)** = AI가 사용자를 인터뷰하여 **모호성 100% → 20%까지 떨어트림** (개발자가 클라이언트에게 질문하듯)

초보자가 "쇼핑몰 만들어줘" 같은 모호한 요청을 던져도 AI가 알아서 클라이언트 입장에서 질문 → 명세 도출 → 자율 개발까지 완결.

### 1. 도입 — Human-in-the-Loop 지옥 (00:00 - 01:00)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=0s)

#### 핵심 메시지
"바이브 코딩" 한다면서 **ChatGPT 들어가서 검색 → 복붙 → 수정 요청 → 에러 → 또 수정** 무한 반복. 인간 개입(HITL)이 끝없는 — 이건 진짜 "에이전트 코딩"이 아니다.

#### 상세 내용
- 영상 화자 본인의 자조 — "다른 개발자들처럼 창 여러 개 띄우고 병렬 실행 미친 듯이 하고 싶은데"
- 정작 본인은 ChatGPT 들어가서 검색 → 복사 → 붙여 넣기 → 수정 요청 → 에러 → 또 수정의 반복
- 이건 **에이전트 코딩이 아니다** — HITL이 너무 많음
- 진정한 에이전트 코딩 = 에이전트들끼리 자기네들끼리 일하는 것

#### 주요 발언
> "거진 휴먼 인 더 룸이 거진 매번 들어가는 인간의 개입이 끝이 없는 내가 그런 에이전트 코딩을 하고 있다. 이런 거 살짝 에이전트 코딩이라 부르기엔 조금 그렇죠."

### 5. 딥 인터뷰 기능 소개 — 모호성 100% → 20% (04:00 - 05:00)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=240s)

#### 핵심 메시지 ⭐⭐⭐
**"개발자와 일하는 경험을 가져가실 수 있습니다"** — AI가 클라이언트에게 질문하듯 사용자에게 인터뷰. **모호성을 100%에서 20%로 떨어트릴 때까지 질문 반복**.

#### 상세 내용
- **타겟**: 초보자 / 상세화 잘 못 하는 사람
- 모호한 요청 ("쇼핑몰 만들어줘") → AI가 알아서 질문
  - "어떤 쇼핑몰?"
  - "기술 스택은?"
  - "어떤 디자인?"
  - "어떤 기능까지?"
- **모호성 % 표시** — 사용자가 답할 때마다 떨어짐
- **임계값 도달 시 자동으로 개발 시작**

#### 주요 발언
> "내가 단순히 나 개발 잘 못 해 가지고 나 디테일화 뭐 상세화 시키는 거 정말 못 하는 사람이야. 그런 사람들이 이거 쓰시면 너무 좋습니다."

> "이 딥 인터뷰가 말 그대로 딥 인터뷰 당신을 인터뷰를 해 드립니다. 알아서 언제까지 이 모호성이... 모호성이 100%면은 정말 아무것도 모르겠는 거고요. 이 모호성이 20%로 떨어질 때까지 지금 물어보잖아요."

### 6. 딥 인터뷰 실시연 — "쇼핑몰 만들어줘" (05:00 - 08:30)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=300s)

#### 핵심 메시지 ⭐⭐⭐
사용자 입력 "쇼핑몰 만들어줘" 한 줄 → AI가 클라이언트 인터뷰하듯 7~8개 질문 → 모호성 100%→7%까지 → 명세 자동 도출.

#### 시연 진행표

| 단계 | AI 질문 | 사용자 응답 | 모호성 |
|:-:|---|---|:-:|
| 0 | (사용자 입력: "쇼핑몰 만들어줘") | — | **100%** |
| 1 | "어떤 쇼핑몰? 상품 탐색·결제·회원 이런 거 만들려는 거 맞니?" | "**MVP만** 만들게 (탐색·결제·회원)" | **62%** |
| 2 | "본질적 목적이 뭐냐? 사업용? 프로토타입? 데모 포트폴리오?" | "**포트폴리오 데모용**" | (떨어짐) |
| 3 | "뭘 파는 가게? 단일 브랜드? 전자제품? 일반 잡화?" | "**패션 의류**" | (떨어짐) |
| 4 | "기술 스택은? (모르면 추천도 가능)" | "**Next.js 풀스택**" | **48%** |
| 5 | "회원가입 진짜 필요해? 포트폴리오용이라며? 게스트 결제만으로도 가능하잖아" | "**게스트 결제만**" | **41%** |
| 6 | "데모 완성 기준? 엔드투엔드? 반응형 디자인? 배포까지?" | "**핵심 = 엔드투엔드**" | **27%** |
| 7 | "결제 흐름 디테일? 바로 주문 완료? 배송지 폼? 가짜 카드 UI?" | "**바로 주문 완료**" | **임계값 도달 → 개발 시작** |

#### 핵심 통찰 ⭐⭐
**"내가 사실 말해 줘야 되는 거를 이 친구가 찾아서 알아서 질문해 주는 거"** — 사용자가 갑(클라이언트), AI가 을(개발자) 입장.

**"굉장히 개발자스럽죠"** — AI가 개발자처럼 "정말 필요해?" "포트폴리오용이라며?" 식으로 합리적 의문 제기.

#### 주요 발언
> "지금 이 친구가 어, 너 야, 너 뭐 뭐 만들 거야? 뭐 이렇게 물어보죠."

> "내가 사실 말해 줘야 되는 거를 이 친구가 찾아서 알아서 질문해 주는게 굉장히 좋지 않나요?"

> "저는 지금 제가 굉장히 클라이언트 입장에서 어, 그래서 제가 상당히 갑의 입장에 있는 느낌입니다."

> "회원갈 로그인 진짜 필요해? 너 이거 게스트 비회원 결제만으로도 가능하잖아라고 알려 주는 거죠." (= 개발자스러운 합리적 의문)

### 7. 플랜 선택 — Plan / Autopilot / Ralph (08:30 - 09:30)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=510s)

#### 핵심 메시지

#### 상세 내용

**명세 저장**:
- 딥 인터뷰 질문/답변 모두 `specs/` 폴더에 정리 → 시스템 요구사항 도출
- 그 후 AI가 "이제 뭐 할래?" 물어봄

**선택지 (실행 모드)**:
- **Plan 모드**: 계획만 세우고 코드는 안 짜고 넘어가기
- **Autopilot**: 바로 개발 쭉 진행
- **Ralph 모드** ⭐: 모든게 완료될 때까지 무한 진행, 사용자는 그냥 지켜만 보기
- **(추가 질문)**: 명세 더 다듬기

#### 시연 선택
영상 화자: **랄프 모드** 선택 → 바로 실행

### 8. 랄프 모드 실행 — 리뷰 에이전트 자동 추가 (09:30 - 11:00)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=570s)

#### 핵심 메시지 ⭐
랄프 모드 실행 시 **새로운 "리뷰어 에이전트"가 자동으로 추가**되어 메인 에이전트가 만든 코드를 검증. "코드 만든 애가 또 검증하는 건 말이 안 되니까."

#### 상세 내용

**랄프 모드의 약속**:
> "수용 기준이 모두 통과할 때까지 어, 놓치는 거 하나 없이 모두 통과해야 됩니다. 아키텍처 검증과 함께 반복해서 이제 작업에 들어갑니다"

**진행 과정**:
1. 모든 스토리 (요구사항) 패스 확인
2. **리뷰어 에이전트 자동 추가** — 검증 전담 (메인 코드 작성 에이전트와 분리)
3. Verification 단계 진입

**핵심 아키텍처 통찰**:
> "메인은 코드를 만든 앤데 코드를 만든 애가 또 검증한다는게 좀 약간 말이 안 되잖아요. 그래서 새로운 이제 검사하는 리뷰 에이전트를 하나 만들어 가지고 얘가 이제 이 이 코드를 검사할 수 있게끔"

→ **역할 분리 원칙** (Maker ↔ Reviewer 분리)

### 11. 마무리 (12:00 - 12:26)

[바로가기](https://www.youtube.com/watch?v=gj_5zjpkguM&t=720s)

#### 핵심 메시지
순수 Claude Code가 아니라 **기존 플러그인 (OhMyClaude) 설치 → 거기 있는 에이전트 활용 → 효율적 개발**. 추가로 본인 바이브 코딩 강의 (스터디 모집) 홍보.

#### 주요 발언
> "여러분들이 순수 클로드 코드가 아니라 기존에 있는 플러그인들을 설치를 해서 거기에 있는 에이전트를 가져다가 내가 많은 개발을 효율적으로 여러분들이 해 볼 수 있다라는 점입니다."
