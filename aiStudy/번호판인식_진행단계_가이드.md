# 번호판 인식 시스템 - 진행 중요 단계 가이드

## 전체 프로세스 흐름도

```
[1. 이미지 입력] → [2. 전처리] → [3. 번호판 검출] → [4. 번호판 정렬]
                                                           ↓
[8. 결과 출력] ← [7. 후처리] ← [6. 문자 인식] ← [5. 문자 분할]
```

## 1단계: 이미지 입력 (Image Acquisition)

### 1.1 입력 소스
| 항목 | 설명 |
|------|------|
| 카메라 종류 | IP 카메라, CCTV, 웹캠, 스마트폰 |

- [ ] 카메라 설치 각도 (15~30도 권장)
- [ ] 조명 조건 (주간/야간/역광)
- [ ] 차량 속도에 따른 셔터 스피드
- [ ] 이미지 왜곡 보정 필요 여부

## 2단계: 이미지 전처리 (Preprocessing)

### 2.1 전처리 단계
| 순서 | 처리 | 목적 |
|------|------|------|
| 2.1.1 | 리사이징 | 일정한 입력 크기 유지 |
| 2.1.2 | 그레이스케일 변환 | 연산량 감소 |
| 2.1.3 | 노이즈 제거 | 잡음 제거 (Gaussian Blur) |
| 2.1.4 | 대비 향상 | CLAHE, 히스토그램 평활화 |
| 2.1.5 | 이진화 | Adaptive Threshold |

### 2.2 상세 처리
```
원본 이미지
    │
    ▼
┌─────────────────┐
│ 2.1.1 리사이징   │  640x480 또는 모델 입력 크기
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 2.1.2 그레이스케일│  BGR → Gray (채널 3→1)
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 2.1.3 노이즈 제거 │  GaussianBlur(5,5)
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 2.1.4 대비 향상  │  CLAHE (clipLimit=2.0)
└─────────────────┘
    │
    ▼
전처리 완료 이미지
```

### 2.3 핵심 코드
```python
# 리사이징
img = cv2.resize(img, (640, 480))

# 그레이스케일
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 노이즈 제거
blur = cv2.GaussianBlur(gray, (5, 5), 0)

# 대비 향상 (CLAHE)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
enhanced = clahe.apply(blur)
```

## 3단계: 번호판 검출 (Plate Detection)

### 3.1 검출 방법 비교
| 방법 | 장점 | 단점 | 정확도 |
|------|------|------|--------|
| Cascade Classifier | 빠름, 가벼움 | 정확도 낮음 | 70~80% |
| YOLO | 실시간, 높은 정확도 | GPU 필요 | 95%+ |
| SSD | 균형잡힌 성능 | 중간 복잡도 | 90%+ |
| Faster R-CNN | 최고 정확도 | 느림 | 97%+ |

### 3.2 YOLO 기반 검출 프로세스
```
입력 이미지 (416x416)
        │
        ▼
┌─────────────────────┐
│   Backbone (CSP)    │  특징 추출
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│   Neck (PANet)      │  다중 스케일 특징 융합
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│   Head (Detection)  │  바운딩 박스 예측
└─────────────────────┘
        │
        ▼
출력: [x, y, w, h, confidence, class]
```

### 3.3 출력 정보
| 항목 | 설명 |
|------|------|
| x, y | 바운딩 박스 중심 좌표 |
| w, h | 바운딩 박스 너비, 높이 |
| confidence | 신뢰도 (0~1) |
| class | 클래스 (번호판) |

### 3.4 핵심 코드
```python
from ultralytics import YOLO

# 모델 로드
model = YOLO('license_plate_detector.pt')

# 검출 수행
results = model(img)

# 바운딩 박스 추출
for box in results[0].boxes:
    x1, y1, x2, y2 = box.xyxy[0]
    confidence = box.conf[0]
```

## 4단계: 번호판 정렬 (Plate Alignment)

### 4.1 정렬이 필요한 이유
```
기울어진 번호판          정렬된 번호판
  ╱─────────╲              ┌─────────┐
 ╱ 12가3456  ╲      →      │ 12가3456 │
╱─────────────╲            └─────────┘
```

### 4.2 정렬 단계
| 순서 | 처리 | 설명 |
|------|------|------|
| 4.2.1 | 코너 검출 | 번호판 4개 꼭지점 찾기 |
| 4.2.2 | 원근 변환 | Perspective Transform |
| 4.2.3 | 크기 정규화 | 고정 크기로 변환 (520x110) |

### 4.3 원근 변환 (Perspective Transform)
```
원본 좌표 (src)              목표 좌표 (dst)
    A──────B                  A'─────B'
   ╱        ╲                 │       │
  ╱          ╲       →        │       │
 D────────────C               D'─────C'

변환 행렬 M = cv2.getPerspectiveTransform(src, dst)
결과 = cv2.warpPerspective(img, M, (width, height))
```

### 4.4 핵심 코드
```python
# 코너 포인트 정의
src_pts = np.float32([[x1,y1], [x2,y2], [x3,y3], [x4,y4]])
dst_pts = np.float32([[0,0], [520,0], [520,110], [0,110]])

# 변환 행렬 계산
M = cv2.getPerspectiveTransform(src_pts, dst_pts)

# 원근 변환 적용
aligned = cv2.warpPerspective(img, M, (520, 110))
```

## 5단계: 문자 분할 (Character Segmentation)

### 5.1 분할 방법
| 방법 | 설명 | 적용 상황 |
|------|------|----------|
| 수직 투영 | 세로 방향 픽셀 합 분석 | 깨끗한 이미지 |
| 윤곽선 검출 | findContours 활용 | 일반적 상황 |
| 딥러닝 | Semantic Segmentation | 복잡한 상황 |
| End-to-End | 분할 없이 직접 인식 | 최신 방법 |

### 5.2 수직 투영 방법
```
번호판 이미지: │1│2│가│3│4│5│6│

수직 투영 히스토그램:
▓▓    ▓▓    ▓▓▓   ▓▓    ▓▓    ▓▓    ▓▓
▓▓    ▓▓    ▓▓▓   ▓▓    ▓▓    ▓▓    ▓▓
▓▓    ▓▓    ▓▓▓   ▓▓    ▓▓    ▓▓    ▓▓
──────────────────────────────────────
  1     2    가     3     4     5     6

→ 히스토그램 최소점에서 문자 분리
```

### 5.3 윤곽선 기반 분할
```
이진화 이미지
      │
      ▼
┌─────────────────┐
│ findContours()  │  윤곽선 검출
└─────────────────┘
      │
      ▼
┌─────────────────┐
│ boundingRect()  │  각 문자 영역 추출
└─────────────────┘
      │
      ▼
┌─────────────────┐
│ 필터링          │  크기/비율로 노이즈 제거
└─────────────────┘
      │
      ▼
개별 문자 이미지 7개
```

### 5.4 핵심 코드
```python
# 이진화
_, binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 윤곽선 검출
contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

# 각 문자 추출
chars = []
for cnt in contours:
    x, y, w, h = cv2.boundingRect(cnt)
    if 20 < h < 100 and 10 < w < 80:  # 크기 필터
        char_img = binary[y:y+h, x:x+w]
        chars.append((x, char_img))

# x좌표로 정렬 (왼쪽→오른쪽)
chars.sort(key=lambda c: c[0])
```

## 6단계: 문자 인식 (Character Recognition / OCR)

### 6.1 인식 방법 비교
| 방법 | 구조 | 특징 |
|------|------|------|
| CNN 분류기 | CNN + Softmax | 단일 문자 분류 |
| CRNN | CNN + RNN + CTC | 시퀀스 인식 |
| Transformer OCR | CNN + Transformer | 최신, 높은 정확도 |
| TrOCR | ViT + Transformer | End-to-End |

### 6.2 CRNN 구조 (가장 널리 사용)
```
입력: 번호판 이미지 (W x H)
              │
              ▼
┌─────────────────────────┐
│   CNN Feature Extractor │  특징 추출
│   (VGG / ResNet)        │
└─────────────────────────┘
              │
              ▼
       (W/4 x 512) 특징맵
              │
              ▼
┌─────────────────────────┐
│   Bidirectional LSTM    │  시퀀스 학습
│   (256 hidden units)    │
└─────────────────────────┘
              │
              ▼
┌─────────────────────────┐
│   CTC Decoder           │  문자열 디코딩
│   (Connectionist        │
│    Temporal             │
│    Classification)      │
└─────────────────────────┘
              │
              ▼
출력: "12가3456"
```

### 6.3 CTC Loss 이해
```
CRNN 출력 (각 시점별 확률):
시점:  t1    t2    t3    t4    t5    t6    t7    t8    t9
      ─────────────────────────────────────────────────────
확률:  1     1     -     2     가    -     3     4     5
       ↓     ↓           ↓     ↓           ↓     ↓     ↓

CTC 디코딩: 1 1 - 2 가 - 3 4 5 → "12가345"
            (중복 제거, blank(-) 제거)
```

### 6.4 인식 대상 문자셋
| 카테고리 | 문자 | 개수 |
|----------|------|------|
| 숫자 | 0-9 | 10 |
| 한글 (지역) | 서울, 부산, 대구... | 17 |
| 한글 (용도) | 가-힣 (일부) | 37 |
| **총합** | | **64** |

## 7단계: 후처리 (Post-processing)

### 7.1 후처리 단계
| 순서 | 처리 | 설명 |
|------|------|------|
| 7.1.1 | 형식 검증 | 한국 번호판 규칙 확인 |
| 7.1.2 | 오류 교정 | 유사 문자 교정 (0↔O, 1↔I) |
| 7.1.3 | 신뢰도 필터링 | 낮은 신뢰도 결과 제거 |
| 7.1.4 | 중복 제거 | 동일 차량 중복 인식 제거 |

### 7.2 한국 번호판 형식 검증
```
신형 번호판 (2019~):
┌─────────────────────────────┐
│  123 가 4567                │  숫자3 + 한글1 + 숫자4
└─────────────────────────────┘

구형 번호판 (~2019):
┌─────────────────────────────┐
│  12 가 3456                 │  숫자2 + 한글1 + 숫자4
│  서울 12 가 3456            │  지역 + 숫자2 + 한글1 + 숫자4
└─────────────────────────────┘

정규식 검증:
- 신형: ^[0-9]{3}[가-힣][0-9]{4}$
- 구형: ^[0-9]{2}[가-힣][0-9]{4}$
- 구형(지역): ^[가-힣]{2}[0-9]{2}[가-힣][0-9]{4}$
```

### 7.3 유사 문자 교정
| 혼동 쌍 | 교정 규칙 |
|---------|----------|
| 0 ↔ O | 숫자 위치면 0, 한글 위치면 불가 |
| 1 ↔ I | 숫자 위치면 1 |
| 8 ↔ B | 숫자 위치면 8 |
| 2 ↔ Z | 숫자 위치면 2 |
| 5 ↔ S | 숫자 위치면 5 |

### 7.4 핵심 코드
```python
import re

def validate_plate(text):
    """한국 번호판 형식 검증"""
    patterns = [
        r'^[0-9]{3}[가-힣][0-9]{4}$',      # 신형
        r'^[0-9]{2}[가-힣][0-9]{4}$',      # 구형
        r'^[가-힣]{2}[0-9]{2}[가-힣][0-9]{4}$'  # 구형(지역)
    ]
    return any(re.match(p, text) for p in patterns)

def correct_similar_chars(text):
    """유사 문자 교정"""
    corrections = {'O': '0', 'I': '1', 'B': '8', 'Z': '2', 'S': '5'}
    result = list(text)
    for i, char in enumerate(result):
        # 숫자 위치인 경우 교정
        if should_be_digit(i, len(text)):
            if char in corrections:
                result[i] = corrections[char]
    return ''.join(result)
```

## 8단계: 결과 출력 (Output)

### 8.1 출력 형식
| 출력 유형 | 내용 | 용도 |
|----------|------|------|
| 텍스트 | "123가4567" | 데이터베이스 저장 |
| JSON | {"plate": "123가4567", "confidence": 0.98} | API 응답 |
| 이미지 | 바운딩 박스가 그려진 이미지 | 시각화 |
| 로그 | 타임스탬프, 위치 정보 포함 | 기록 관리 |

### 8.2 출력 데이터 구조
```json
{
    "timestamp": "2026-02-28T15:30:45",
    "plate_number": "123가4567",
    "confidence": 0.98,
    "bounding_box": {
        "x1": 100, "y1": 200,
        "x2": 300, "y2": 280
    },
    "processing_time_ms": 45,
    "camera_id": "CAM_01",
    "image_path": "/data/captures/2026-02-28/frame_001.jpg"
}
```

### 8.3 시각화 출력
```
┌─────────────────────────────────────────┐
│                                         │
│         ┌─────────────────┐             │
│         │   123가4567     │ ← 인식 결과 │
│    🚗   │   conf: 98%     │             │
│         └─────────────────┘             │
│              ↑                          │
│         바운딩 박스                      │
│                                         │
└─────────────────────────────────────────┘
```

### 8.4 핵심 코드
```python
import json
from datetime import datetime

def output_result(plate_number, confidence, bbox, image):
    """결과 출력"""

    # JSON 결과 생성
    result = {
        "timestamp": datetime.now().isoformat(),
        "plate_number": plate_number,
        "confidence": float(confidence),
        "bounding_box": {
            "x1": int(bbox[0]), "y1": int(bbox[1]),
            "x2": int(bbox[2]), "y2": int(bbox[3])
        }
    }

    # 이미지에 결과 표시
    cv2.rectangle(image, (bbox[0], bbox[1]), (bbox[2], bbox[3]), (0, 255, 0), 2)
    cv2.putText(image, f"{plate_number} ({confidence:.2f})",
                (bbox[0], bbox[1]-10), cv2.FONT_HERSHEY_SIMPLEX, 0.9, (0, 255, 0), 2)

    return result, image
```
