## 1. 활성화 함수란?

### 정의
활성화 함수(Activation Function)는 신경망의 각 뉴런에서 입력 신호를 출력 신호로 변환하는 **비선형 함수**입니다.

### 비유로 이해하기

| 비유 | 설명 |
|------|------|
| **조명 디머 스위치** | 단순 on/off가 아닌, 0~100% 밝기 조절 |
| **물 수도꼭지** | 물의 흐름을 얼마나 통과시킬지 결정 |
| **뇌의 뉴런** | 특정 임계값 이상이면 발화(fire), 이하면 억제 |

### 수학적 표현
```
뉴런 출력 = 활성화함수(가중치 × 입력 + 편향)
         = f(Wx + b)
```

---

## 2. 왜 활성화 함수가 필요한가?

### 핵심 이유: 비선형성 도입

활성화 함수가 없으면 **아무리 깊은 신경망도 하나의 선형 변환과 동일**합니다.

```
층1: z₁ = W₁x + b₁
층2: z₂ = W₂z₁ + b₂
     = W₂(W₁x + b₁) + b₂
     = (W₂W₁)x + (W₂b₁ + b₂)
     = W_combined × x + b_combined  ← 결국 1층과 같음!
```

### 수학적 증명 코드
```python
import numpy as np

# 3개의 선형 층
W1 = np.random.randn(4, 3)
W2 = np.random.randn(5, 4)
W3 = np.random.randn(2, 5)

x = np.array([[1.0], [2.0], [3.0]])

# 3층 순전파 (활성화 없음)
z1 = W1 @ x
z2 = W2 @ z1
z3 = W3 @ z2

# 하나로 합친 것
W_combined = W3 @ W2 @ W1
z_single = W_combined @ x

print("차이:", np.max(np.abs(z3 - z_single)))  # 0.0 (거의 동일!)
```

### 비선형성이 있으면?
- 각 층이 **다른 특징(feature)**을 학습 가능
- 복잡한 패턴(곡선, 원, 나선 등) 표현 가능
- **XOR 문제** 같은 비선형 문제 해결 가능

## 3. 주요 활성화 함수 상세

### 3.1 Sigmoid

```
σ(x) = 1 / (1 + e^(-x))
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | (0, 1) |
| **미분 최대값** | 0.25 |
| **장점** | 확률로 해석 가능, 부드러운 곡선 |
| **단점** | 기울기 소실(Vanishing Gradient) |
| **용도** | 이진 분류 출력층, LSTM 게이트 |

**기울기 소실 문제**:
```
미분값 최대 = 0.25
10층 통과 시: 0.25^10 = 0.00000095 ≈ 0
→ 앞쪽 층의 가중치가 거의 업데이트 안됨!
```

---

### 3.2 Tanh (Hyperbolic Tangent)

```
tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | (-1, 1) |
| **미분 최대값** | 1.0 |
| **장점** | 영점 중심(zero-centered), Sigmoid보다 기울기 큼 |
| **단점** | 여전히 기울기 소실 존재 |
| **용도** | RNN/LSTM 내부, 출력이 -1~1 필요할 때 |

**Sigmoid vs Tanh**:
| 비교 | Sigmoid | Tanh |
|------|---------|------|
| 출력 중심 | 0.5 | 0 |
| 기울기 최대 | 0.25 | 1.0 |
| 영점 중심 | X | O |

---

### 3.3 ReLU (Rectified Linear Unit) ⭐

```
ReLU(x) = max(0, x)
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | [0, +∞) |
| **미분값** | 0 (x<0), 1 (x>0) |
| **장점** | 기울기 소실 해결, 계산 빠름, 희소 활성화 |
| **단점** | Dying ReLU (죽은 뉴런) |
| **용도** | **은닉층의 기본 선택!** |

**왜 ReLU가 혁명적인가?**
1. **기울기 소실 해결**: 양수 구간에서 미분=1 → 기울기 그대로 전달
2. **계산 효율**: exp() 대신 max() 한 번
3. **희소 활성화**: 음수 입력은 0 → 효율적 표현

**Dying ReLU 문제**:
- 뉴런이 한번 음수 영역에 빠지면 기울기=0
- 영원히 업데이트 안됨 (죽은 뉴런)
- 해결책: Leaky ReLU, 작은 학습률

---

### 3.4 Leaky ReLU

```
f(x) = x       (x > 0)
     = αx     (x ≤ 0)   // 보통 α = 0.01
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | (-∞, +∞) |
| **장점** | Dying ReLU 해결 |
| **단점** | α 하이퍼파라미터 추가 |
| **용도** | GAN, 깊은 네트워크 |

---

### 3.5 ELU (Exponential Linear Unit)

```
f(x) = x              (x > 0)
     = α(e^x - 1)    (x ≤ 0)
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | (-α, +∞) |
| **장점** | 부드러운 곡선, 노이즈에 강함, 평균 출력 ≈ 0 |
| **단점** | exp() 계산 비용 |
| **용도** | 깊은 CNN |

---

### 3.6 GELU (Gaussian Error Linear Unit) ⭐⭐

```
GELU(x) = x × Φ(x)   // Φ = 정규분포 누적분포함수

근사: GELU(x) ≈ 0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | 약 (-0.17, +∞) |
| **장점** | 확률적 통과, 매우 부드러움 |
| **단점** | 계산 비용 (근사 사용) |
| **용도** | **Transformer, BERT, GPT, ViT** |

**GELU의 직관**:
- 입력값이 클수록 → 높은 확률로 통과
- 입력값이 작을수록 → 낮은 확률로 통과/차단
- "확률적 ReLU"라고 생각하면 됨

---

### 3.7 Swish (SiLU)

```
Swish(x) = x × σ(x) = x × sigmoid(x)
```

| 특성 | 값 |
|------|-----|
| **출력 범위** | 약 (-0.28, +∞) |
| **장점** | 자기 게이팅, 부드러움, 비단조 |
| **단점** | sigmoid 계산 필요 |
| **용도** | **EfficientNet, MobileNet v3** |

---

### 3.8 활성화 함수 비교 총정리

| 함수 | 수식 | 출력 범위 | 기울기 소실 | 계산 비용 | 주 용도 |
|------|------|-----------|-------------|-----------|---------|
| Sigmoid | 1/(1+e^-x) | (0,1) | 심각 | 중간 | 출력층(이진) |
| Tanh | (e^x-e^-x)/(e^x+e^-x) | (-1,1) | 있음 | 중간 | RNN |
| ReLU | max(0,x) | [0,∞) | 없음 | **낮음** | **기본 선택** |
| Leaky ReLU | max(αx,x) | (-∞,∞) | 없음 | 낮음 | GAN |
| ELU | 조건부 | (-α,∞) | 없음 | 높음 | 깊은 CNN |
| GELU | x×Φ(x) | (-0.17,∞) | 없음 | 중간 | **Transformer** |
| Swish | x×σ(x) | (-0.28,∞) | 없음 | 중간 | EfficientNet |

## 4. 활성화 함수 선택 가이드

### 4.1 층별 선택 원칙

| 층 | 추천 활성화 함수 | 이유 |
|----|------------------|------|
| **은닉층 (기본)** | ReLU | 빠르고 효과적 |
| **은닉층 (깊은 네트워크)** | Leaky ReLU, ELU | Dying ReLU 방지 |
| **은닉층 (Transformer)** | GELU | 부드러움, 확률적 |
| **출력층 (이진 분류)** | Sigmoid | 확률 [0,1] |
| **출력층 (다중 분류)** | Softmax | 확률 분포 |
| **출력층 (회귀)** | None (Linear) | 실수 전체 |

### 4.2 상황별 선택

```
Q: 어떤 활성화 함수를 선택할까?

[시작]
  │
  ├── 출력층인가? ────────────────────────────────┐
  │       │                                       │
  │       ├── 이진 분류 → Sigmoid                 │
  │       ├── 다중 분류 → Softmax                 │
  │       └── 회귀 → Linear (없음)                │
  │                                               │
  └── 은닉층인가? ────────────────────────────────┘
          │
          ├── 간단한 네트워크 → ReLU
          │
          ├── 깊은 네트워크 (>20층) → Leaky ReLU or ELU
          │
          ├── Transformer 기반 → GELU
          │
          ├── GAN → Leaky ReLU
          │
          ├── RNN/LSTM 내부 → Tanh, Sigmoid
          │
          └── 최신 CNN (EfficientNet) → Swish
```

### 4.3 선택 시 고려사항

| 고려사항 | 설명 |
|----------|------|
| **계산 비용** | ReLU > Leaky ReLU > GELU > ELU |
| **학습 안정성** | ELU, GELU > ReLU (Dying ReLU 위험) |
| **출력 범위** | 필요에 따라 선택 |
| **논문/프레임워크 기본값** | 따라가는 것이 안전 |

## 5. 실전: 모델별 활성화 함수 선택

### 5.1 CNN (이미지 분류)

```python
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(inplace=True),          # ← 은닉층: ReLU
            nn.MaxPool2d(2),

            nn.Conv2d(64, 128, 3, padding=1),
            nn.BatchNorm2d(128),
            nn.ReLU(inplace=True),          # ← 은닉층: ReLU
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Linear(128 * 8 * 8, 256),
            nn.ReLU(inplace=True),          # ← 은닉층: ReLU
            nn.Dropout(0.5),
            nn.Linear(256, num_classes),    # ← 출력층: Linear (Softmax는 loss에서)
        )
```

### 5.2 Transformer (NLP/Vision)

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff):
        super().__init__()
        self.attention = nn.MultiheadAttention(d_model, n_heads)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),                      # ← Transformer는 GELU!
            nn.Linear(d_ff, d_model),
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
```

### 5.3 GAN (생성 모델)

```python
class Generator(nn.Module):
    def __init__(self):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(100, 256),
            nn.LeakyReLU(0.2),              # ← GAN은 Leaky ReLU
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 784),
            nn.Tanh(),                      # ← 출력: Tanh (-1~1)
        )

class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(784, 512),
            nn.LeakyReLU(0.2),              # ← Leaky ReLU
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
            nn.Sigmoid(),                   # ← 출력: Sigmoid (진짜/가짜 확률)
        )
```

### 5.4 LSTM (시계열/텍스트)

```python
# LSTM 내부는 자동으로 Sigmoid(게이트) + Tanh(상태) 사용
lstm = nn.LSTM(input_size=128, hidden_size=256, num_layers=2)

# LSTM 위에 추가 층
class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)
        # 출력층: CrossEntropyLoss 사용 시 Linear로 끝냄
```

### 5.5 MLP (다층 퍼셉트론 - 범용)

```python
class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dims, output_dim, task='classification'):
        super().__init__()
        layers = []
        prev_dim = input_dim

        # 은닉층
        for h_dim in hidden_dims:
            layers.append(nn.Linear(prev_dim, h_dim))
            layers.append(nn.ReLU())        # ← 기본: ReLU
            layers.append(nn.Dropout(0.2))
            prev_dim = h_dim

        # 출력층
        layers.append(nn.Linear(prev_dim, output_dim))

        if task == 'binary':
            layers.append(nn.Sigmoid())     # 이진 분류
        elif task == 'regression':
            pass                            # 회귀: Linear
        # 다중 분류: CrossEntropyLoss가 Softmax 포함

        self.model = nn.Sequential(*layers)
```

## 6. 코드 예제

### 6.1 활성화 함수 시각화

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-4, 4, 1000)

# 활성화 함수 정의
def sigmoid(x): return 1 / (1 + np.exp(-x))
def tanh(x): return np.tanh(x)
def relu(x): return np.maximum(0, x)
def leaky_relu(x, alpha=0.01): return np.where(x > 0, x, alpha * x)
def elu(x, alpha=1.0): return np.where(x > 0, x, alpha * (np.exp(x) - 1))
def gelu(x): return 0.5 * x * (1 + np.tanh(np.sqrt(2/np.pi) * (x + 0.044715 * x**3)))
def swish(x): return x * sigmoid(x)

# 시각화
fig, axes = plt.subplots(2, 4, figsize=(16, 8))
functions = [
    (sigmoid, 'Sigmoid'), (tanh, 'Tanh'), (relu, 'ReLU'), (leaky_relu, 'Leaky ReLU'),
    (elu, 'ELU'), (gelu, 'GELU'), (swish, 'Swish')
]

for ax, (func, name) in zip(axes.flatten(), functions):
    ax.plot(x, func(x), linewidth=2)
    ax.axhline(0, color='gray', linestyle='--', alpha=0.5)
    ax.axvline(0, color='gray', linestyle='--', alpha=0.5)
    ax.set_title(name, fontsize=14)
    ax.set_xlim(-4, 4)
    ax.grid(True, alpha=0.3)

axes[1, 3].axis('off')
plt.tight_layout()
plt.savefig('activation_functions.png', dpi=150)
plt.show()
```

### 6.2 PyTorch에서 활성화 함수 사용

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 방법 1: nn.Module로 사용 (권장)
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 128),
    nn.GELU(),
    nn.Linear(128, 10),
)

# 방법 2: F.함수로 사용
class CustomModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.gelu(self.fc2(x))
        x = self.fc3(x)
        return x

# 방법 3: inplace=True로 메모리 절약
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(inplace=True),  # 입력 텐서 재사용
    nn.Linear(256, 10),
)
```

### 6.3 TensorFlow/Keras에서 활성화 함수 사용

```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# 방법 1: 문자열로 지정
model = keras.Sequential([
    layers.Dense(256, activation='relu'),
    layers.Dense(128, activation='gelu'),
    layers.Dense(10, activation='softmax'),
])

# 방법 2: 별도 층으로 분리
model = keras.Sequential([
    layers.Dense(256),
    layers.Activation('relu'),
    layers.Dense(128),
    layers.Activation('gelu'),
    layers.Dense(10),
    layers.Activation('softmax'),
])

# 방법 3: 커스텀 활성화 함수
def custom_swish(x):
    return x * tf.nn.sigmoid(x)

model = keras.Sequential([
    layers.Dense(256, activation=custom_swish),
    layers.Dense(10, activation='softmax'),
])
```
