# Track 1: AI 업무 활용
> 기간: 2주 (10일) | 대상: AI 초보자 | 도구: Claude

## 목표
- AI에게 질문하는 방법(프롬프트 엔지니어링) 습득
- 일상 업무에 Claude를 즉시 적용
- AI의 한계와 올바른 활용법 이해

---

## Week 1: AI와 대화하기

### Day 1: AI란 무엇인가
- **이론**: AI/LLM 기본 개념 (ChatGPT, Claude, Gemini 비교)
- **실습**: Claude 첫 대화 — 자기소개 시키기, 간단한 질문
- **핵심**: AI는 "매우 똑똑한 인턴"이다. 명확하게 지시해야 좋은 결과
- **과제**: Claude에게 자신의 업무를 설명하고 도움 받을 수 있는 영역 3가지 찾기

### Day 2: 프롬프트 엔지니어링 기초
- **이론**: 좋은 프롬프트 vs 나쁜 프롬프트
- **실습**:
  - 역할 부여: "당신은 마케팅 전문가입니다..."
  - 맥락 제공: 배경 정보 + 원하는 결과 형태
  - 단계적 지시: "먼저 ... 그 다음 ... 마지막으로 ..."
- **핵심**: 구체적일수록 결과가 좋다
- **과제**: 같은 질문을 3가지 방식으로 바꿔서 결과 비교

### Day 3: 문서 작성 자동화
- **실습**:
  - 보고서 초안 작성 (주간보고, 회의록, 제안서)
  - 이메일 작성 (공식/비공식, 한글/영문)
  - 문서 요약 (긴 문서 → 핵심 3줄)
  - 번역 (한↔영, 뉘앙스 조절)
- **과제**: 실제 업무 문서 1개를 Claude로 작성

### Day 4: 데이터 분석 기초
- **실습**:
  - 표 데이터 분석 (매출, 재고, 일정)
  - CSV 붙여넣기 → 분석 요청
  - 차트/그래프 설명 요청
  - 수식/계산 검증
- **과제**: 실제 업무 데이터로 분석 리포트 생성

### Day 5: 아이디어 브레인스토밍
- **실습**:
  - 기획서 아이디어 발산 → 수렴
  - SWOT 분석 자동 생성
  - 비교 분석표 작성
  - 마인드맵 구조화
- **과제**: 팀 프로젝트 기획안 초안 완성

## Week 2: 업무 고급 활용

### Day 6: 프레젠테이션 제작
- **실습**:
  - 발표 자료 구조 설계 (슬라이드별 내용)
  - 발표 스크립트 생성
  - Q&A 예상 질문/답변 준비
  - Mermaid 다이어그램으로 프로세스 시각화
- **과제**: 실제 발표 자료 1세트 완성

### Day 7: 업무 프로세스 자동화
- **실습**:
  - 반복 업무 템플릿화 (Claude에게 포맷 학습시키기)
  - 체크리스트 자동 생성
  - 일정 관리/우선순위 정리
  - 회의 안건 → 회의록 → 할일 추출
- **과제**: 자신의 주간 업무 프로세스 1개를 템플릿화

### Day 8: AI + 외부 도구 연동
- **실습**:
  - Claude + Google Sheets (데이터 가공 수식 생성)
  - Claude + Notion (업무 정리 구조 설계)
  - Claude + Excel (VBA 매크로 생성)
  - Claude로 간단한 자동화 스크립트 생성 (복사-붙여넣기 수준)
- **과제**: 외부 도구 1개와 Claude 연동 실습

### Day 9: AI 윤리와 한계
- **이론**:
  - 할루시네이션 (AI가 거짓말하는 경우)
  - 기밀 정보 입력 금지 원칙
  - 저작권과 AI 생성물
  - AI 결과 검증 습관
- **실습**: 일부러 AI를 틀리게 만들어보기 (한계 체험)
- **과제**: "AI 활용 가이드라인" 자기 버전 작성

### Day 10: 종합 프로젝트
- **실습**: 실제 업무 시나리오 종합 실습
  - 기획 → 문서화 → 데이터 분석 → 보고서 → 발표
  - 전 과정을 Claude 활용하여 2시간 내 완료
- **발표**: 각자 결과물 공유 + 피드백
- **수료**: Track 1 수료증 발급
