## 실습 3: 서버 설정 + 도메인 + HTTPS (40분)

1. 서버 초기 설정을 한다 (Day 2 복습)

```bash
ssh root@NEW_SERVER_IP
adduser deploy
usermod -aG sudo deploy
# SSH 키 복사
mkdir -p /home/deploy/.ssh
cp ~/.ssh/authorized_keys /home/deploy/.ssh/
chown -R deploy:deploy /home/deploy/.ssh
```

2. Docker를 설치한다

```bash
ssh deploy@NEW_SERVER_IP
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker deploy
exit && ssh deploy@NEW_SERVER_IP
```

3. DuckDNS 도메인을 설정한다

```bash
# DuckDNS에서 도메인 등록: finalproject-student01.duckdns.org
ping finalproject-student01.duckdns.org
```

4. 방화벽을 설정한다

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

5. HTTPS를 설정한다 (Nginx + certbot)

```
Claude에게: "서버에 Nginx를 설치하고 certbot으로 SSL 인증서를 발급해줘. 도메인은 finalproject-student01.duckdns.org. Docker Compose의 Nginx 대신 호스트의 Nginx를 사용하는 방법으로 설정해줘."
```
