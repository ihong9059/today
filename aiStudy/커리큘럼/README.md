# AI 실무 교육 커리큘럼
> Claude 중심 AI 활용 교육 — 초보자부터 전문가까지

## 교육 철학
- **"문법 암기가 아닌 AI 협업 능력"** — AI가 코드를 생성하는 시대, 핵심은 AI와 대화하는 능력
- **즉시 체험**: 설명 → 실습 → 결과 확인 사이클을 최소화
- **실무 중심**: 교육 후 바로 업무에 적용 가능한 커리큘럼

## 대상
- AI를 처음 접하는 직장인/학생
- 프로그래밍 경험 없어도 참여 가능 (Track 1부터 시작)
- 프로그래밍 경험자는 Track 2~4로 바로 진입

## 전체 구조 (4 Track)

```
Track 1: 업무 활용        (2주)  — AI로 업무 효율 10배
Track 2: 프로그래밍       (4주)  — AI와 함께 코딩하기
Track 3: 시스템 구축      (4주)  — 서버/인프라/자동화
Track 4: AI 전문가        (4주)  — 컴퓨터 비전/딥러닝 실전
```

```
[Track 1] ─────→ [Track 2] ─────→ [Track 3]
  업무 활용         프로그래밍        시스템 구축
  (2주)             (4주)             (4주)
                      │
                      └──────────→ [Track 4]
                                    AI 전문가
                                    (4주)
```

- Track 1은 모든 수강생 필수
- Track 2 이후는 관심 분야에 따라 선택
- Track 3, 4는 Track 2 수료 후 진행 (병행 가능)

## 공통 도구: Obsidian

모든 Track에서 **Obsidian**을 지식 관리 도구로 사용합니다.
- AI와 대화한 내용을 축적하고 연결하는 "제2의 뇌"
- 상세 가이드: [자료/Obsidian_활용_가이드.md](자료/Obsidian_활용_가이드.md)
- Track 1 Day 1에서 설치, 이후 매일 학습 노트 작성

## 전체 일정 요약

| Track | 기간 | 주요 도구 | 결과물 |
|-------|------|----------|--------|
| 1. 업무 활용 | 2주 (10일) | Claude, Google Docs, Notion | 업무 자동화 템플릿 |
| 2. 프로그래밍 | 4주 (20일) | Claude Code, Python, VS Code | 웹앱 1개 + API 서버 |
| 3. 시스템 구축 | 4주 (20일) | Linux, Docker, Nginx, GitHub | 운영 가능한 서버 |
| 4. AI 전문가 | 4주 (20일) | PyTorch, OpenCV, YOLO, Jetson | 번호판 인식 시스템 |

**총 교육 기간**: 최대 14주 (Track 1 필수 + Track 2~4 선택)
