## 실습 1: pytest 기초 — 첫 테스트 작성 (20분)

1. pytest 설치:
```bash
pip install pytest
```

2. Claude Code에게 요청:
```
pytest를 배우기 위한 테스트 예제를 만들어줘.

먼저 테스트할 함수가 있는 calculator.py:
- add(a, b), subtract(a, b), multiply(a, b), divide(a, b)
- average(numbers), is_even(n), fizzbuzz(n)

그리고 test_calculator.py:
1. 기본 테스트: assert로 결과 확인
2. 여러 입력값 테스트 (경계값, 음수, 0 등)
3. 예외 테스트: divide(1, 0)이 ZeroDivisionError 발생하는지 (pytest.raises)
4. 파라미터화 테스트: @pytest.mark.parametrize로 여러 케이스
5. 테스트 이름을 한글로 알아보기 쉽게

테스트 함수 이름은 test_로 시작하는 규칙을 설명해줘.
```

3. 테스트 실행:
```bash
pytest test_calculator.py -v
```

### 관찰 포인트
- pytest가 test_로 시작하는 함수를 자동으로 찾아서 실행하는 방식
- 녹색(통과) / 빨간색(실패) 결과의 의미
- 경계값 테스트의 중요성 (0으로 나누기, 빈 리스트 등)

## 실습 2: 메모 앱 테스트 작성 (20분)

1. Claude Code에게 요청:
```
Day 13의 메모 앱에 대한 테스트를 작성해줘.

test_memo_app.py:
1. database.py 테스트:
   - DB 생성 테스트
   - 메모 삽입 후 조회 테스트
   - 메모 수정 테스트
   - 메모 삭제 테스트
   - 존재하지 않는 메모 조회 시 에러 테스트

2. API 테스트 (FastAPI TestClient):
   - POST /api/memos — 메모 작성 성공
   - POST /api/memos — 제목 없이 요청 시 422 에러
   - GET /api/memos — 목록 조회
   - DELETE /api/memos/{id} — 삭제 후 조회 시 404

3. 테스트용 임시 DB 사용 (테스트마다 새 DB)
4. fixture로 테스트 데이터 준비

pip install httpx도 설치해줘 (FastAPI 테스트에 필요).
```

2. 테스트 실행:
```bash
pip install httpx
pytest test_memo_app.py -v
```

### 관찰 포인트
- 테스트가 있으면 코드를 수정해도 기존 기능이 깨지지 않았는지 확인 가능
- fixture로 테스트 환경을 세팅하고 정리하는 패턴
- API 테스트에서 다양한 시나리오(정상, 에러, 경계값)를 확인하는 방법

## 실습 3: Claude Code로 코드 리뷰 (15분)

1. Claude Code에게 리뷰 요청:
```
내 메모 앱 코드 전체를 리뷰해줘.
다음 관점에서 분석해줘:
1. 보안 문제 (SQL 인젝션, 입력 검증 등)
2. 에러 처리 누락 (try-except가 필요한 곳)
3. 코드 중복 (함수로 분리해야 할 부분)
4. 변수명/함수명 개선 (PEP 8 스타일)
5. 성능 개선 (불필요한 DB 호출 등)
6. 주석/문서화 부족한 부분

각 문제에 대해 구체적인 개선 코드도 보여줘.
```

2. 리뷰 결과 반영:
```
리뷰에서 지적된 문제들을 모두 수정해줘.
수정 전/후를 비교할 수 있게 해줘.
```

### 관찰 포인트
- Claude Code가 코드 리뷰어 역할을 할 수 있다는 점
- 보안, 에러 처리, 가독성 관점의 코드 품질 기준
- PEP 8 (Python 코딩 스타일 가이드)의 주요 규칙

## 실습 4: 에러 처리 심화 (15분)

1. Claude Code에게 요청:
```
에러 처리 패턴을 배우는 error_handling.py를 만들어줘.

1. 기본 try-except-else-finally 구조
2. 여러 예외를 각각 처리하는 패턴
3. 커스텀 예외 클래스 정의 (MemoNotFoundError 등)
4. 로깅(logging 모듈)으로 에러 기록
5. 데코레이터로 에러 처리를 자동화하는 패턴

메모 앱에서 발생할 수 있는 에러 시나리오별 처리 예제:
- DB 연결 실패
- 잘못된 입력 데이터
- 존재하지 않는 메모 접근
- 파일 읽기 실패
```

2. 메모 앱에 로깅 추가:
```
메모 앱에 logging 모듈을 추가해줘.
API 호출마다 로그를 남기고, 에러 발생 시 상세 정보를 로그 파일에 저장해줘.
```

### 관찰 포인트
- 에러를 무시하지 않고 적절히 처리하는 것이 안정적인 프로그램의 핵심
- logging 모듈로 디버깅 정보를 파일에 남기는 실무 패턴
- 커스텀 예외로 에러 종류를 명확히 구분하는 방법
