# Day 20: 발표 + 수료 — "내 프로젝트를 세상에 보여주자"

## 학습 목표
- 프로젝트 발표를 통한 커뮤니케이션 능력 향상
- 동료 프로젝트 피드백을 통한 시야 확장
- 20일간 학습 내용 정리 및 향후 성장 로드맵 수립
- 수료 후 독학으로 이어갈 수 있는 자신감 확보

## 준비물
- 완성된 종합 프로젝트 (Day 18-19)
- 발표 자료 (프로젝트 실행 가능한 상태)
- ngrok 데모 URL (발표 직전 생성)

---

## 실습 1: 발표 최종 준비 (20분)

1. 프로젝트 최종 점검:
```bash
# 서버 정상 실행 확인
uvicorn main:app --host 0.0.0.0 --port 8000

# 새 터미널에서 ngrok 실행
ngrok http 8000
```

2. Claude Code에게 요청:
```
발표 전 최종 체크리스트를 확인해줘.
1. 서버가 정상 실행되는지
2. 모든 주요 기능이 동작하는지
3. 데모용 샘플 데이터가 있는지
4. 에러 발생 시 치명적이지 않은지
5. 발표 순서 정리 (2분 발표 + 1분 데모 + 1분 Q&A)

혹시 문제가 있으면 빠르게 수정해줘.
```

3. 발표 리허설 (짝과 함께 또는 혼자):
   - 프로젝트 소개 (30초)
   - 핵심 기능 데모 (1분)
   - 기술적 하이라이트 (30초)
   - 소감 (30초)

### 관찰 포인트
- 발표 직전 데모가 안 되는 상황을 대비하여 스크린샷 백업 준비
- 2-3분 내에 핵심만 전달하는 연습

---

## 실습 2: 프로젝트 발표 (60분)

### 발표 형식 (1인 4분)
1. **프로젝트 소개** (30초): 이름, 프로젝트명, 한 줄 설명
2. **라이브 데모** (1분 30초): 핵심 기능 3가지 시연
3. **기술 설명** (1분): 사용 기술, 어려웠던 점, Claude Code 활용 사례
4. **Q&A** (1분): 동료 질문 답변

### 발표 시 피드백 기록

각 발표마다 다른 학생들은 피드백 작성:
```markdown
## 발표 피드백
- 발표자:
- 프로젝트명:
- 좋았던 점:
- 인상적인 기능:
- 개선 제안:
- 점수 (5점 만점): /5
```

### 관찰 포인트
- 같은 주제라도 사람마다 다른 접근 방식
- 다른 프로젝트에서 배울 수 있는 아이디어
- 발표와 데모 능력도 개발자의 중요한 역량

## 실습 4: 향후 성장 로드맵 (20분)

1. Claude Code에게 요청:
```
Track 2 수료 후 계속 성장하기 위한 로드맵을 만들어줘.

Level 1 (수료 직후, 1개월):
- 복습해야 할 핵심 개념
- 추가로 만들어볼 프로젝트 3개
- 추천 학습 자료

Level 2 (3개월 후):
- 배워야 할 새로운 기술 (Django, React, Docker 등)
- 참여할 수 있는 오픈소스 프로젝트
- 기술 블로그 시작

Level 3 (6개월 후):
- 포트폴리오 완성
- 사이드 프로젝트로 실제 서비스 운영
- 개발자 커뮤니티 참여

각 레벨에서 Claude Code를 활용하는 구체적 방법도 포함해줘.
```

2. 개인 성장 계획 작성:
```
내 상황(직업, 목표, 가용 시간)에 맞는 맞춤 성장 계획을 세워줘.
일주일에 프로그래밍에 투자할 수 있는 시간: [    ]시간
목표: [                               ]
```

### 관찰 포인트
- 수료가 끝이 아니라 시작이라는 마인드셋
- Claude Code가 있으면 혼자서도 계속 학습할 수 있다는 자신감
- 구체적인 목표가 있어야 지속 가능
