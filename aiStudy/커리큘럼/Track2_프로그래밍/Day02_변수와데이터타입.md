## 실습 1: 숫자와 문자열 — 변수의 기본 (15분)

1. Claude Code에게 요청:
```
Python 변수와 데이터 타입을 배우고 싶어.
다음 내용을 포함하는 variables.py를 만들어줘:
1. 정수형 변수 (나이, 점수)
2. 실수형 변수 (키, 몸무게)
3. 문자열 변수 (이름, 직업)
4. 불리언 변수 (학생여부)
5. 각 변수의 type()을 출력
6. f-string으로 자기소개 문장 출력
모든 줄에 한글 주석을 달아줘.
```

2. 실행 후 출력 확인:
```bash
python variables.py
```

3. 직접 수정 연습 — 자신의 정보로 변수값 변경 후 재실행

### 관찰 포인트
- int, float, str, bool 타입의 차이
- f-string에서 변수가 치환되는 방식

## 실습 2: 리스트 — 여러 데이터 묶기 (15분)

1. Claude Code에게 요청:
```
리스트를 활용하는 list_practice.py를 만들어줘.
다음 기능을 포함해줘:
1. 과일 리스트 5개 만들기
2. 리스트에 항목 추가(append), 삭제(remove)
3. 인덱싱과 슬라이싱 예제
4. for 문으로 리스트 순회하며 출력
5. 리스트 정렬(sort)과 길이(len)
각 단계마다 print로 결과를 확인할 수 있게 해줘.
```

2. Claude Code에게 개념 질문:
```
리스트의 인덱스가 0부터 시작하는 이유가 뭐야?
슬라이싱에서 [1:3]이 왜 인덱스 1, 2만 포함하는지 쉽게 설명해줘.
```

### 관찰 포인트
- 리스트는 순서가 있고 수정 가능한(mutable) 자료구조
- 인덱스 0부터 시작하는 규칙

## 실습 3: 딕셔너리 — 키-값 쌍 데이터 (15분)

1. Claude Code에게 요청:
```
딕셔너리를 활용하는 dict_practice.py를 만들어줘.
학생 성적 관리 예제로:
1. 학생 3명의 정보를 딕셔너리로 (이름, 국어, 영어, 수학)
2. 딕셔너리 리스트로 여러 학생 관리
3. 특정 학생의 평균 점수 계산
4. 전체 학생 중 최고 평균 학생 찾기
5. 결과를 보기 좋게 표 형태로 출력
```

2. 데이터 수정 연습:
```
학생 한 명을 추가하고, 기존 학생의 수학 점수를 변경하는 코드를 추가해줘.
```

### 관찰 포인트
- 딕셔너리의 key-value 구조가 실제 데이터 관리에 어떻게 쓰이는지
- 리스트 안에 딕셔너리를 넣는 패턴 (실무에서 매우 자주 사용)

## 실습 4: 타입 변환 + 사용자 입력 (15분)

1. Claude Code에게 요청:
```
사용자로부터 입력을 받아 처리하는 input_practice.py를 만들어줘.
1. 이름(문자열)과 나이(숫자)를 input()으로 입력받기
2. 태어난 연도 계산하기 (타입 변환 필요)
3. 좋아하는 음식 3개를 콤마로 입력받아 리스트로 변환
4. 입력받은 정보를 딕셔너리로 정리해서 출력
input()은 항상 문자열로 받으므로 int() 변환이 필요하다는 점을 주석으로 설명해줘.
```

2. 잘못된 입력 테스트:
```bash
python input_practice.py
# 나이에 "스물다섯" 입력해보기 → 에러 발생
```

3. Claude Code에게 에러 해결 요청:
```
나이에 숫자가 아닌 값을 입력하면 에러가 나. try-except로 에러를 처리해줘.
```

### 관찰 포인트
- input()의 반환값이 항상 str인 이유
- try-except로 예외 처리하는 기본 패턴
