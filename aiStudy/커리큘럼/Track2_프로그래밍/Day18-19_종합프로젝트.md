# Day 18 (오전): 기획 + 설계 + 기본 구현

## 실습 1: 프로젝트 선택 + 기획 (30분)

### 프로젝트 옵션 4가지

**옵션 A: AI 챗봇 서비스**
- Claude API + FastAPI + HTML 프론트엔드
- 특정 분야 전문 챗봇 (요리/운동/공부 도우미 등)
- 대화 기록 저장 (SQLite)
- system 프롬프트로 캐릭터/전문성 설정

**옵션 B: 데이터 대시보드**
- 공공 API/CSV 데이터 + pandas + matplotlib
- FastAPI 백엔드 + Chart.js 프론트엔드
- 실시간 데이터 갱신
- 필터/검색/통계 기능

**옵션 C: IoT 센서 모니터링 앱**
- Day 11 시뮬레이터 확장
- 센서 데이터 수집/저장/시각화
- 경고 알림 (임계치 초과 시)
- 제어 기능 (LED, 모터 등)

**옵션 D: 업무 관리 도구**
- 할 일 관리 (투두리스트) + 일정 관리
- CRUD + 우선순위 + 마감일 + 카테고리
- 완료율 통계 + 생산성 그래프
- AI로 할 일 분석/제안 (선택)

1. Claude Code에게 기획 요청:
```
[선택한 옵션]을 구현하기 위한 프로젝트 기획서를 작성해줘.
1. 프로젝트 이름
2. 핵심 기능 목록 (MVP — 최소 기능 제품)
3. 기술 스택 (Day 1-17에서 배운 것 중심)
4. 데이터베이스 설계 (테이블, 컬럼)
5. API 설계 (엔드포인트 목록)
6. 화면 구성 (페이지별 기능)
7. 2일간 개발 일정 (시간 단위)

현실적으로 2일 안에 완성할 수 있는 범위로 조정해줘.
```

### 관찰 포인트
- MVP(최소 기능 제품)를 먼저 정의하는 것이 중요
- 기능이 너무 많으면 완성 못함 — 핵심 기능 3-5개에 집중
- 기획서를 먼저 작성하면 개발이 훨씬 수월해짐

## 실습 2: 프로젝트 초기 설정 + 기본 구조 (30분)

1. Claude Code에게 요청:
```
[프로젝트명] 프로젝트를 시작해줘.
1. 프로젝트 폴더 구조 생성

5. .env.example 생성
```

```bash

```

### 관찰 포인트
- 프로젝트 구조를 처음부터 잘 잡으면 나중에 편함
- CLAUDE.md를 먼저 작성하면 이후 Claude Code 요청이 정확해짐

## 실습 3: 핵심 기능 구현 — 백엔드 (60분)

1. Claude Code에게 순차적으로 요청:

**데이터베이스 구현:**
```
기획서에 따라 데이터베이스 테이블을 모두 생성하고,
각 테이블에 대한 CRUD 함수를 database.py에 구현해줘.
테스트 데이터 10건도 자동으로 넣어줘.
```

**API 구현:**
```
기획서의 API 엔드포인트를 모두 구현해줘.
각 API에 Pydantic 모델로 요청/응답 검증을 적용하고,
에러 처리(try-except)와 적절한 HTTP 상태 코드를 사용해줘.
```

**비즈니스 로직:**
```
[프로젝트별 핵심 로직] 구현해줘.
예: AI 챗봇이면 Claude API 연동, 대시보드면 데이터 분석 로직
```

2. Swagger UI에서 모든 API 테스트:
   - http://localhost:8000/docs

### 관찰 포인트
- 기획서대로 하나씩 구현하면 길을 잃지 않음
- 백엔드를 먼저 완성하고 프론트엔드를 붙이는 순서가 효율적
- API를 Swagger UI에서 테스트하면 프론트엔드 없이도 기능 확인 가능

# Day 19 (오후): 프론트엔드 + 마무리 + 발표 준비

## 실습 4: 프론트엔드 구현 (60분)

1. Claude Code에게 요청:
```
프로젝트의 프론트엔드를 구현해줘.
1. 메인 페이지: [프로젝트별 메인 화면 설명]
2. 데이터 표시: API에서 데이터를 가져와서 카드/테이블/차트로 표시
3. 입력 폼: 데이터 생성/수정 폼
4. 반응형 디자인: 모바일에서도 사용 가능
5. 에러 표시: API 에러 시 사용자에게 메시지

디자인은 모던하고 깔끔하게, 다크 모드도 지원해줘.
```

2. 추가 기능 구현:
```
다음 기능을 추가해줘:
1. 로딩 스피너 (데이터 가져오는 동안)
2. 검색/필터 기능
3. 통계/차트 (Chart.js)
4. 키보드 단축키 (선택)
```

### 관찰 포인트
- 프론트엔드는 "사용자가 직접 보는 부분"이므로 디자인이 중요
- fetch() API 호출 패턴이 반복됨 — 함수로 분리하면 효율적
