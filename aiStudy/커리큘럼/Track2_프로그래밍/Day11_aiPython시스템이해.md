- aiPython(UTTEC 보드 연동 시스템)의 전체 아키텍처 이해
- server.py 코드를 분석하며 Flask/FastAPI 실전 활용 학습
- 클라이언트-서버 통신 구조 파악
- Claude Code로 기존 코드를 분석하는 방법 습득

## 준비물

- aiPython 프로젝트 소스 코드 (강사 제공)

## 실습 1: aiPython 아키텍처 파악 (15분)

1. Claude Code에게 코드 분석 요청:
```
aiHardStudy/smartphone/python_vibe/ 폴더의 프로젝트 구조를 분석해줘.
1. 전체 파일 목록과 각 파일의 역할
2. 서버(server.py)와 클라이언트(앱)의 관계
3. 데이터 흐름: 스마트폰 → 서버 → UTTEC 보드
4. 사용된 라이브러리와 기술 스택
5. 아키텍처 다이어그램을 텍스트로 그려줘

초보자가 이해할 수 있도록 쉬운 비유로 설명해줘.
```

2. Claude Code에게 질문:
```
이 시스템에서 Flask(또는 FastAPI)가 하는 역할이 뭐야?
Day 9-10에서 배운 것과 어떻게 연결되는지 설명해줘.
```

### 관찰 포인트
- 실제 서비스의 코드 구조가 학습했던 Flask/FastAPI 패턴과 동일함
- 클라이언트(앱) → HTTP 요청 → 서버(Python) → 하드웨어(UTTEC 보드) 흐름
- 파일 하나하나의 역할을 이해하는 것이 코드 분석의 첫 단계

## 실습 2: server.py 코드 분석 (20분)

1. Claude Code에게 요청:
```
server.py 파일을 한 줄씩 분석해줘.
특히 다음 부분을 자세히 설명해줘:
1. 라우트(route) 정의 — 어떤 URL이 어떤 기능을 하는지
2. UTTEC 보드와 시리얼 통신하는 부분
3. 센서 데이터를 받아서 처리하는 부분
4. 에러 처리 방식
5. HTTPS/SSL 설정 부분

각 함수의 역할과 호출 순서를 정리해줘.
```

2. 직접 코드 읽기 연습:
```
server.py에서 가장 핵심적인 함수 3개를 골라서,
입력값(파라미터), 처리 과정, 출력값(반환값)을 표로 정리해줘.
```

### 관찰 포인트
- 실제 프로덕션 코드에서 에러 처리가 얼마나 중요한지
- 시리얼 통신(Serial)으로 하드웨어를 제어하는 방식
- HTTPS 설정으로 보안을 확보하는 방법

## 실습 3: 시뮬레이터 만들기 (20분)

1. Claude Code에게 요청:
```
UTTEC 보드 없이도 테스트할 수 있는 시뮬레이터를 만들어줘.
simulator.py:
1. 가짜 센서 데이터 생성 (온도, 습도, 조도 — 랜덤값)
2. server.py와 같은 API 엔드포인트 제공
3. LED 제어 요청을 받으면 터미널에 상태 출력
4. 센서 데이터를 1초마다 갱신
5. /api/sensor — 현재 센서값 반환 (JSON)
6. /api/led — LED 제어 (POST, on/off)
7. /api/history — 최근 10건의 센서 기록

FastAPI로 구현하고, Day 10에서 배운 패턴을 적용해줘.
```

2. 시뮬레이터 실행 및 테스트:
```bash
python simulator.py
# 브라우저에서 http://localhost:8000/docs 접속
```

### 관찰 포인트
- 시뮬레이터를 만들면 하드웨어 없이도 소프트웨어 개발/테스트 가능
- 실제 코드(server.py)와 시뮬레이터 코드의 구조가 유사함

## 실습 4: 프론트엔드 연동 — 센서 대시보드 (15분)

1. Claude Code에게 요청:
```
시뮬레이터와 연동하는 간단한 센서 대시보드 웹 페이지를 만들어줘.
static/dashboard.html:
1. 현재 센서값(온도, 습도, 조도) 실시간 표시
2. LED ON/OFF 버튼
3. 센서 기록 차트 (최근 10건, Chart.js 사용)
4. 3초마다 자동 갱신 (setInterval + fetch)
5. 깔끔한 대시보드 UI

JavaScript에서 fetch()로 시뮬레이터 API를 호출해줘.
```

2. 대시보드 테스트:
   - 시뮬레이터 실행 상태에서 브라우저로 대시보드 접속
   - LED 버튼 클릭, 센서값 변화 관찰

### 관찰 포인트
- 실시간 데이터 갱신의 원리 (폴링 방식)
- Chart.js로 데이터를 시각화하는 방법
- Day 10의 메모 앱과 구조가 같다는 것을 확인
