## 실습 1: 조건문 기초 — 성적 등급 판정기 (15분)

1. Claude Code에게 요청:
```
if/elif/else를 배우기 위한 grade.py를 만들어줘.
1. 점수를 입력받아 등급을 판정 (A: 90+, B: 80+, C: 70+, D: 60+, F: 60 미만)
2. 등급별로 다른 응원 메시지 출력
3. 비교 연산자(>, >=, ==, !=)와 논리 연산자(and, or, not) 예제 포함
4. 점수가 0~100 범위가 아니면 "잘못된 입력" 처리
모든 조건 분기마다 한글 주석으로 설명 달아줘.
```

2. 다양한 점수로 테스트:
```bash
python grade.py
# 95, 85, 72, 55, -10, 150 입력해보기
```

### 관찰 포인트
- elif가 여러 개일 때 위에서 아래로 순서대로 검사하는 원리
- 조건문 순서를 바꾸면 결과가 달라질 수 있는 경우

---

## 실습 2: 반복문 기초 — 구구단 + 별 찍기 (15분)

1. Claude Code에게 요청:
```
for문과 while문을 배우기 위한 loops.py를 만들어줘.
다음 기능을 순서대로 구현해줘:
1. for문으로 1~10까지 합 구하기
2. 사용자가 입력한 단의 구구단 출력 (for + range)
3. while문으로 1부터 숫자를 더해가며 합이 100 넘으면 멈추기
4. 별 찍기 피라미드 (5줄)
5. break와 continue 사용 예제
각 예제 사이에 구분선과 제목을 출력해줘.
```

2. 코드 수정 연습:
```
구구단을 2단부터 9단까지 전체 출력하도록 이중 for문으로 변경해줘.
```

### 관찰 포인트
- for문의 range(시작, 끝, 간격) 사용법
- while문은 조건이 False가 될 때까지 반복 — 무한 루프 위험성

## 실습 3: 가위바위보 게임 (20분)

1. Claude Code에게 요청:
```
가위바위보 게임 rps_game.py를 만들어줘.
요구사항:
1. 사용자가 가위/바위/보 중 하나를 입력
2. 컴퓨터는 random.choice()로 랜덤 선택
3. 승패 판정 후 결과 출력 (이겼다/졌다/비겼다)
4. 3판 2선승제로 진행
5. 현재 전적(승/패/무)을 매 라운드 표시
6. 게임 종료 시 최종 결과 출력
7. 잘못된 입력 시 다시 입력받기
```

2. 게임 플레이 후 기능 추가 요청:
```
가위바위보 게임에 다음 기능을 추가해줘:
1. 게임 시작 시 아스키 아트로 타이틀 출력
2. 승률 퍼센트 계산
3. "다시 하시겠습니까?" 기능
```

### 관찰 포인트
- random 모듈의 import와 사용법
- 조건문과 반복문이 결합되는 패턴
- 게임 루프(while True + break) 구조

## 실습 4: 숫자 맞히기 게임 (15분)

1. Claude Code에게 요청:
```
숫자 맞히기 게임 number_game.py를 만들어줘.
1. 컴퓨터가 1~100 사이 랜덤 숫자를 정함
2. 사용자가 숫자를 입력하면 "더 높게" / "더 낮게" 힌트 제공
3. 맞히면 "정답! {시도횟수}번 만에 맞혔습니다!" 출력
4. 7번 이내에 맞히면 "천재!", 15번 이상이면 "힌트를 잘 활용하세요" 메시지
5. 난이도 선택 기능 (쉬움: 1~50, 보통: 1~100, 어려움: 1~500)
```

2. Claude Code에게 알고리즘 질문:
```
이 숫자 맞히기 게임에서 가장 효율적인 전략은 뭐야?
이진 탐색(Binary Search) 개념을 쉽게 설명해줘.
```

### 관찰 포인트
- while 루프 안에서 조건에 따라 break하는 패턴
- 시도 횟수를 카운터 변수로 관리하는 방법
