- 실무에서 즉시 쓸 수 있는 자동화 스크립트 작성

## 준비물
- Day 1-6에서 설정한 개발 환경

## 실습 1: 파일 정리 자동화 (20분)

1. Claude Code에게 요청:
```
다운로드 폴더를 자동 정리하는 file_organizer.py를 만들어줘.
1. 먼저 테스트용 폴더와 파일 20개를 자동 생성 (txt, pdf, jpg, png, xlsx, docx, mp3, mp4 등)
2. 파일 확장자별로 분류 폴더 생성:
   - 문서/ (txt, pdf, docx, xlsx)
   - 이미지/ (jpg, png, gif)
   - 미디어/ (mp3, mp4)
   - 기타/
3. 파일을 해당 폴더로 이동
4. 이동 결과 리포트 출력 (몇 개 파일이 어디로 이동했는지)
5. 중복 파일명 처리 (같은 이름 있으면 _1, _2 붙이기)

os, shutil, pathlib 모듈을 사용하고 각 함수를 설명해줘.
```

2. 실행 및 결과 확인:
```bash
python file_organizer.py
```

3. 기능 확장 요청:
```
파일 생성일 기준으로 연-월 폴더(2025-01, 2025-02...)를 만들어서 정리하는 기능도 추가해줘.
```

### 관찰 포인트
- os.path vs pathlib의 차이 (pathlib이 더 현대적)
- shutil.move()와 shutil.copy()의 차이
- 자동화 스크립트의 "안전장치" (dry-run 모드) 필요성

## 실습 2: 엑셀 자동화 — openpyxl (25분)

1. 패키지 설치:
```bash
pip install openpyxl
```

2. Claude Code에게 요청:
```
openpyxl로 엑셀 보고서를 자동 생성하는 excel_automation.py를 만들어줘.
1. 새 엑셀 파일 생성
2. 직원 근태 데이터 시트 작성:
   - 헤더: 이름, 부서, 출근시간, 퇴근시간, 근무시간, 비고
   - 샘플 데이터 20행
3. 셀 서식 적용:
   - 헤더: 파란색 배경, 흰색 글자, 볼드
   - 근무시간 8시간 미만: 빨간색 글자
   - 테두리 적용
4. 수식 추가:
   - 평균 근무시간, 최대/최소 근무시간
5. 차트 생성:
   - 부서별 평균 근무시간 막대 차트
6. 여러 시트 생성 (부서별 분리)
7. 파일 저장 (monthly_report.xlsx)
```

3. 생성된 엑셀 파일을 Excel이나 VS Code에서 열어서 확인

### 관찰 포인트
- openpyxl로 셀 하나하나를 제어할 수 있는 세밀함
- 수식(formula)을 문자열로 넣는 방식
- 차트 생성 코드가 복잡하지만 Claude Code가 대신 작성해줌

## 실습 3: 대량 파일 이름 변경기 (10분)

1. Claude Code에게 요청:
```
파일 이름을 일괄 변경하는 batch_rename.py를 만들어줘.
1. 테스트 파일 30개 생성 (IMG_001.jpg ~ IMG_030.jpg)
2. 다음 이름 변경 규칙 적용:
   - 접두사 변경: IMG → PHOTO
   - 날짜 추가: PHOTO_2025-01-01_001.jpg
   - 순번 재정렬: 001부터 다시
3. 변경 전/후 미리보기 출력 (dry-run)
4. 사용자 확인 후 실제 변경 실행
5. 변경 로그를 텍스트 파일로 저장
```

### 관찰 포인트
- dry-run 패턴으로 실수를 방지하는 방법
- 정규표현식(re 모듈)으로 파일명 패턴 매칭

## 실습 4: 종합 — 업무 보고서 자동 생성기 (15분)

1. Claude Code에게 요청:
```
주간 업무 보고서를 자동 생성하는 weekly_report.py를 만들어줘.
1. 이번 주 작업 내용을 딕셔너리로 입력받기
2. 엑셀 보고서 생성 (서식 포함)
3. 텍스트 보고서도 동시 생성 (보고서_2025-01-06.txt)
4. 보고서 내용:
   - 주간 요약 (총 작업 수, 완료율)
   - 일별 상세 내용
   - 다음 주 계획
5. 이전 주 보고서가 있으면 비교 통계 추가
```

2. 실행 후 생성된 파일 확인:
```bash
python weekly_report.py
```

### 관찰 포인트
- 한 스크립트가 여러 형식(엑셀 + 텍스트)의 파일을 동시에 생성하는 패턴
- 날짜 기반 파일명으로 자동 관리하는 방법
