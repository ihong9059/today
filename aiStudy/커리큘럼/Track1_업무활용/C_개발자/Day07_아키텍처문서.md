# Day 7: 아키텍처 문서 + PDF — "시스템 설계를 시각화하자"

## 학습 목표
- Claude Code로 아키텍처 문서 HTML 제작
- Mermaid로 다이어그램 자동 생성 (시퀀스, 클래스, ER, 배포)
- 기술 발표자료 제작 + PDF 변환

---

## 실습 1: 시스템 아키텍처 문서 (20분)

### 프롬프트
```
우리 서비스의 시스템 아키텍처 문서를 HTML로 만들어줘.

시스템: TaskFlow (업무 관리 SaaS)

구성:
1. 표지: 시스템명 + 버전 + 작성일
2. 시스템 개요: 1문단 설명 + 기술 스택 표
3. 아키텍처 다이어그램: Mermaid (클라이언트 → Nginx → API → DB)
4. API 서버 구조: 계층별 설명 (Router → Service → Repository)
5. 데이터베이스: ER 다이어그램 (Mermaid)
6. 인증 플로우: 시퀀스 다이어그램 (Mermaid)
7. 배포 구조: Docker Compose + CI/CD 파이프라인
8. 모니터링: 헬스체크, 로그, 알림

디자인: 깔끔한 기술 문서 스타일 (흰 배경, 코드 블록)
A4 인쇄 최적화
```

---

## 실습 2: Mermaid 다이어그램 4종 (15분)

### 시퀀스 다이어그램 (인증 플로우)
```
로그인 → JWT 발급 → API 호출 → 토큰 검증 → 응답
시퀀스 다이어그램으로 만들어줘
```

### 클래스 다이어그램 (도메인 모델)
```
User, Task, Project, Comment 모델의 관계를
클래스 다이어그램으로 만들어줘
```

### ER 다이어그램 (데이터베이스)
```
위 모델의 DB 테이블 ER 다이어그램을 만들어줘
PK, FK 표시 포함
```

### 배포 다이어그램 (인프라)
```
Docker Compose 기반 배포 구조:
Nginx → FastAPI (2 replicas) → PostgreSQL → Redis
Mermaid로 그려줘
```

---

## 실습 3: 기술 발표자료 (10분)

```
"TaskFlow 아키텍처 리뷰" 발표자료를 HTML로 만들어줘.
팀 내 기술 공유 세션용. 15분 발표.

슬라이드:
1. 표지
2. 현재 아키텍처 (다이어그램)
3. 성능 현황 (가상 수치)
4. 병목 지점 3가지
5. 개선안 (Before → After)
6. 마이그레이션 계획
7. Q&A

다크 테마, 코드 하이라이트 포함.
```

## 강사 참고 사항
- Mermaid는 텍스트로 다이어그램을 그리므로 버전 관리 가능 (Git-friendly)
- 자기 프로젝트 아키텍처를 문서화하면 실무에 바로 활용
- 아키텍처 문서가 없는 프로젝트가 대부분 → "이참에 만들자" 동기 부여
