# Day 6: Claude Code 코딩 — "기능 구현, 리팩토링, 테스트 생성"

## 학습 목표
- Claude Code에게 기능 구현을 요청하고 결과를 검토
- 기존 코드 리팩토링을 Claude Code로
- 테스트 코드 자동 생성

---

## 실습 1: 기능 구현 요청 (15분)

### 프롬프트
```
사용자 프로필 API를 구현해줘.

요구사항:
- GET /api/profile — 내 프로필 조회
- PATCH /api/profile — 프로필 수정 (이름, 이메일, 프로필 이미지 URL)
- 인증: JWT Bearer Token 필수
- 입력 검증: Pydantic 모델
- 에러 처리: 400, 401, 404
- DB: SQLAlchemy + PostgreSQL

파일:
- src/schemas/profile.py (Pydantic 모델)
- src/routes/profile.py (라우터)
- src/services/profile.py (비즈니스 로직)

CLAUDE.md 규칙을 따라줘.
```

### 결과 검토
```
생성된 코드를 리뷰해줘. 내가 놓칠 수 있는 문제점은?
```

## 실습 2: 리팩토링 (10분)

```
src/routes/auth.py를 읽고 리팩토링해줘.

목표:
1. 하나의 함수가 30줄 이상이면 분리
2. 반복 코드 → 헬퍼 함수로 추출
3. 매직 넘버 → 상수로 분리
4. 에러 처리 통일

변경 전/후 diff를 보여주고, 각 변경의 이유를 설명해줘.
```

---

## 실습 3: 테스트 자동 생성 (15분)

```
src/services/profile.py를 읽고 pytest 테스트를 작성해줘.

포함:
1. 정상 케이스 (프로필 조회/수정 성공)
2. 인증 실패 케이스 (토큰 없음, 만료)
3. 입력 검증 실패 (잘못된 이메일 형식)
4. 존재하지 않는 사용자
5. 엣지 케이스 (빈 문자열, 매우 긴 이름)

파일: tests/test_profile.py
fixture: 테스트 유저, 테스트 DB 세팅 포함
```

### 테스트 실행
```
테스트를 실행해줘 (pytest)
```
```
실패한 테스트가 있으면 원인을 분석하고 수정해줘
```

## 강사 참고 사항
- "Claude Code가 코드를 쓰고, 나는 리뷰한다"는 워크플로우 강조
- 생성된 코드를 무조건 수용하지 않고 비판적으로 검토하도록
- 테스트 자동 생성이 "가장 시간을 아껴주는 기능"
- 자기 프로젝트 코드로 실습하면 바로 PR 올릴 수 있음
