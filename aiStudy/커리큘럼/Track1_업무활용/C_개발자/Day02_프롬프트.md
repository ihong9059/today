## 실습 1: 코드 리뷰 프롬프트 비교 (15분)

### 나쁜 프롬프트
```
이 코드 봐줘

def calc(a,b,c):
    if a>0:
        x=a*b+c
        if x>100:
            return x-10
        else:
            return x
    else:
        return 0
```

### 좋은 프롬프트
```
당신은 Python 시니어 개발자입니다.
아래 코드를 다음 관점에서 리뷰해주세요:

1. 가독성 (변수명, 함수명, 구조)
2. 버그 가능성 (엣지 케이스)
3. 성능 (불필요한 연산)
4. 테스트 용이성
5. PEP 8 준수

각 항목마다 구체적 개선안과 수정 코드를 제시해주세요.

```python
def calc(a,b,c):
    if a>0:
        x=a*b+c
        if x>100:
            return x-10
        else:
            return x
    else:
        return 0
```

이 함수의 비즈니스 로직이 무엇인지 추론하고,
적절한 함수명과 docstring도 제안해주세요.
```

## 실습 2: 상황별 프롬프트 패턴 (15분)

### 패턴 1: 코드 설명 요청
```
아래 코드가 무엇을 하는지 설명해주세요.
- 전체 흐름 (3줄 요약)
- 함수별 역할
- 핵심 알고리즘
- 시간/공간 복잡도
초보 개발자도 이해할 수 있게.
```

### 패턴 2: 리팩토링 요청
```
아래 코드를 리팩토링해주세요.
목표:
- SOLID 원칙 적용
- 함수 분리 (한 함수 10줄 이내)
- 타입 힌트 추가
- 에러 처리 추가
변경 전/후 비교와 변경 이유를 함께 설명해주세요.
```

### 패턴 3: 버그 수정 요청
```
아래 코드에서 버그가 있습니다.
증상: [에러 메시지 또는 예상과 다른 동작]
환경: [Python 3.12, FastAPI 0.110]
입력: [재현 가능한 입력 예시]

원인을 분석하고, 수정 코드와 테스트 케이스를 함께 제시해주세요.
```

### 패턴 4: 기술 비교 요청
```
[A 라이브러리] vs [B 라이브러리]를 비교해주세요.
우리 상황: [프로젝트 규모, 팀 경험, 요구사항]
비교 기준: 성능, 학습 곡선, 커뮤니티, 유지보수, 라이선스
표로 정리하고 최종 추천을 해주세요.
```
