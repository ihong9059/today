# Day 10: 종합 프로젝트 — "기술 포트폴리오 완성"

## 학습 목표
- 10일간 배운 모든 도구를 종합 활용
- 기술 포트폴리오 또는 팀 기술 가이드 완성
- 개발자로서의 AI 활용 전략 수립

---

## 프로젝트 선택 (택 1)

### 옵션 A: 기술 포트폴리오 (이직/성장)

```
개발자 기술 포트폴리오를 HTML로 만들어줘.

구성 (6페이지):
1. 표지: 이름 + 직함 + 기술 스택 뱃지
2. 소개: 경력 요약 + 핵심 역량 (3가지)
3. 프로젝트 1: [주요 프로젝트] 아키텍처 + 기여도 + 기술 스택
4. 프로젝트 2: [사이드 프로젝트 또는 오픈소스]
5. 기술 블로그: 주요 글 3개 요약 + 링크
6. 연락처 + GitHub + 블로그

디자인: 다크 테마, 개발자스러운 모노스페이스 + 코드 블록 느낌
```

### 옵션 B: 팀 기술 가이드북 (팀 리딩)

```
우리 팀 기술 가이드북을 HTML로 만들어줘.

구성:
1. 팀 소개 + 기술 스택
2. 개발 환경 세팅 가이드 (신규 입사자용)
3. Git 브랜치 전략 + PR 규칙
4. 코딩 컨벤션 (네이밍, 스타일, 구조)
5. CI/CD 파이프라인 설명
6. AI 코딩 정책 (Day 9 결과)
7. 온콜/장애 대응 프로세스
8. 유용한 도구/링크 모음
```

### 옵션 C: 오픈소스 프로젝트 문서화 (오픈소스)

```
내 오픈소스 프로젝트를 문서화해줘.

포함:
1. README.md (뱃지, 설치, 사용법, 기여 방법)
2. CONTRIBUTING.md (기여 가이드)
3. CODE_OF_CONDUCT.md
4. 아키텍처 문서 (Mermaid 다이어그램)
5. API 레퍼런스
6. CHANGELOG.md
```

PDF 생성 → 1인 3분 발표
