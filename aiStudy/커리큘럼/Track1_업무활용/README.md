| 카테고리 | 대상 | 핵심 키워드 |

| **A** | 초등학생 | 체험, 창작, 호기심 |
| **B** | 직장인 | 업무 효율, 문서, 보고 |
| **C** | 개발자 | 기술 문서, 코드, 아키텍처 |

## Week 1: Claude 기초

### Day 1: AI란 무엇인가 + Claude 첫 경험

**공통 이론**: AI/LLM 기본 개념, Claude 가입 및 첫 대화

| 카테고리 | 실습 내용 | 결과물 |
|:--------:|----------|--------|
| A 초등학생 | "너는 누구야?" 대화 → "나를 소개하는 글 써줘" → "더 재미있게 바꿔줘" | 자기소개 글 1편 |
| B 직장인 | "나는 OO팀 대리입니다" → 업무 소개 → "도움 받을 수 있는 영역 3가지 찾아줘" | 업무 활용 영역 목록 |
| C 개발자 | "나는 Python 개발자입니다" → 기술 스택 설명 → "내 스택에서 Claude 활용법 제안해줘" | 개발자용 Claude 활용 가이드 |
| D 교사 | "나는 초등학교 5학년 담임입니다" → 수업 고민 공유 → "AI로 해결할 수 있는 것 제안해줘" | 교사용 AI 활용 아이디어 목록 |

**과제**: Claude에게 자기 상황을 설명하고 도움 받을 영역 3가지 찾기

---

### Day 2: 프롬프트 엔지니어링

**공통 이론**: 좋은 프롬프트 vs 나쁜 프롬프트, 역할 부여 + 맥락 + 단계적 지시

| 카테고리 | 실습 내용 | 결과물 |
|:--------:|----------|--------|
| A 초등학생 | 같은 질문 "강아지에 대해 알려줘"를 3가지로 바꿔보기 → 결과 비교 ("초등학생에게 설명해줘" vs "과학자처럼 설명해줘" vs "동화로 알려줘") | 비교 노트 |
| B 직장인 | 이메일 작성: 나쁜 프롬프트("이메일 써줘") vs 좋은 프롬프트("마케팅팀 대리로서 거래처에 납기 변경 요청 이메일, 정중하게, 3문단") | 이메일 3종 비교 |
| C 개발자 | 코드 리뷰: "이 코드 봐줘" vs "Python FastAPI 서버의 보안 취약점을 OWASP 기준으로 검토해줘" | 코드 리뷰 비교 |
| D 교사 | 교안 작성: "수학 수업 만들어줘" vs "초등 5학년 분수 단원, 40분, 게임형 활동 포함, 학생 수준 차이 고려" | 교안 2종 비교 |

**과제**: 같은 요청을 3가지 프롬프트로 바꿔서 결과 비교 리포트

---

### Day 3: 문서 작성

**공통 이론**: Claude로 문서 초안 → 수정 → 완성 워크플로우

| 카테고리 | 실습 내용 | 결과물 |
|:--------:|----------|--------|
| A 초등학생 | ① 독후감 쓰기 (책 줄거리 말하면 구조 잡아줌) ② 일기 쓰기 도움 ③ 편지 쓰기 (감사 편지) | 독후감 1편 + 편지 1편 |
| B 직장인 | ① 주간보고서 작성 ② 거래처 이메일 (한글/영문) ③ 회의록 정리 (메모 → 정식 회의록) | 보고서 + 이메일 + 회의록 |
| C 개발자 | ① README.md 작성 ② API 문서 (엔드포인트 명세) ③ 기술 블로그 초안 | README + API 문서 + 블로그 |
| D 교사 | ① 가정통신문 작성 ② 학생 생활기록부 문구 ③ 학부모 상담 안내문 | 가정통신문 + 생기부 문구 3종 |

**과제**: 실제 필요한 문서 1개를 Claude로 완성

### Day 4: 데이터 분석 + 시각화

**공통 이론**: 표 데이터 → Claude에 붙여넣기 → 분석 요청 → 시각화

| 카테고리 | 실습 내용 | 결과물 |
|:--------:|----------|--------|
| A 초등학생 | 우리 반 좋아하는 과목 설문 결과 표 → "막대그래프로 그려줘" → "1등 과목은?" 질문 | 설문 분석 + 그래프 설명 |
| B 직장인 | 월별 매출 CSV → 분석 요청 → 추세/이상치 파악 → 차트 생성 요청 | 매출 분석 리포트 + 차트 |
| C 개발자 | 서버 로그 데이터 → 에러율 분석 → 시간대별 트래픽 패턴 → Mermaid 다이어그램 | 로그 분석 + 아키텍처 다이어그램 |
| D 교사 | 학생 성적표 → 과목별 평균/분포 → 부진 학생 파악 → 성적 분석 보고서 | 성적 분석 리포트 |

**과제**: 실제 데이터(또는 샘플)로 분석 리포트 생성

### Day 5: Claude Code CLI 설치 + 첫 체험

**공통 실습**: Claude Code 설치 (npm install -g @anthropic-ai/claude-code) + 터미널 기본

| 카테고리 | 실습 내용 | 결과물 |
|:--------:|----------|--------|
| A 초등학생 | "내 소개 파일 만들어줘" → 마크다운 파일 생성 → "이모지 추가해줘" | 자기소개.md |
| B 직장인 | "이 폴더 파일 정리해줘" → 업무 폴더 구조 정리 → "보고서 양식 만들어줘" | 폴더 정리 + 보고서 양식.md |
| C 개발자 | `/init` → CLAUDE.md 생성 → "이 프로젝트 구조 분석해줘" → README 자동 생성 | CLAUDE.md + README.md |
| D 교사 | "8주 교안 폴더 구조 만들어줘" → 주차별 폴더 생성 → "1주차 교안 초안 만들어줘" | 교안 폴더 + 1주차 교안.md |

**핵심**: claude.ai = 브라우저 대화 / Claude Code = 내 컴퓨터에서 직접 파일 작업
**과제**: Claude Code로 자신에게 필요한 파일 1개 생성
