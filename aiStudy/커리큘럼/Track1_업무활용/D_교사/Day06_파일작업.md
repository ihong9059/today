# Day 6: Claude Code 파일 작업 — "교과서 → 주차별 교안 자동 생성"

## 학습 목표
- Claude Code로 여러 파일을 한 번에 생성/수정
- 기존 문서를 읽어서 새로운 문서로 변환
- 교과서 단원 → 주차별 교안 자동 분리

---

## 실습 1: 교과서 단원 → 교안 자동 생성 (20분)

### Step 1: 단원 정보 입력
Claude Code에서:
```
다음은 5학년 1학기 과학 단원 목록이야:

1단원: 온도와 열 (4차시)
2단원: 태양계와 별 (5차시)
3단원: 용해와 용액 (5차시)
4단원: 다양한 생물과 우리 생활 (4차시)

각 단원별로 교안 파일을 만들어줘.
폴더: 5학년_과학_1학기/

각 교안에 포함할 내용:
- 단원 개요
- 차시별 학습 목표 (표)
- 1차시 상세 수업 흐름 (도입/전개/정리)
- 실험/활동 목록
- 준비물
- 평가 계획
```

### Step 2: 결과 확인
```
5학년_과학_1학기 폴더의 파일 목록을 보여줘
```

### Step 3: 특정 교안 보강
```
2단원_태양계와별 교안을 읽고, 다음을 추가해줘:
- 천체 관측 활동 (야간 또는 앱 활용)
- 학생 흥미 유발 질문 5개
- 관련 유튜브 영상 검색 키워드 3개
```

---

## 실습 2: 학습지 자동 생성 (15분)

### 프롬프트
```
5학년 수학 "약수와 배수" 단원의 학습지를 만들어줘.

구성:
1. 개념 정리 (빈칸 채우기 5문제)
2. 기본 문제 (10문제)
3. 심화 문제 (3문제)
4. 서술형 문제 (2문제)

파일명: 약수와배수_학습지.md
별도로 정답지도 만들어줘: 약수와배수_정답지.md
```

---

## 실습 3: 기존 교안 분석 + 개선 (10분)

Day 5에서 만든 교안 폴더를 활용:
```
1단원_자연수의혼합계산 교안.md를 읽고:
1. 부족한 부분이 있으면 알려줘
2. 학생 활동을 2개 더 추가해줘
3. 수준별 활동을 상/중/하로 분리해줘
```

---

## 과제

### 제출물: 주차별 교안 4개 + 학습지 1세트

1. 자기 과목의 4개 단원 교안 (Claude Code로 생성)
2. 1개 단원의 학습지 + 정답지
3. 기존 교안 1개를 분석 → 개선한 결과
