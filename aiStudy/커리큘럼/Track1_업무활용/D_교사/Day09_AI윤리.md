# Day 9: AI 윤리와 한계 — "교실 AI 정책을 만들자"

## 학습 목표
- AI가 틀리는 경우(할루시네이션) 직접 체험
- 학생의 AI 사용에 대한 교사의 판단 기준 수립
- 교실 AI 정책 문서 작성

---

## 실습 1: AI가 틀리는 경우 체험 (10분)

### 할루시네이션 체험
Claude에게 다음을 질문하세요:

```
세종대왕이 만든 컴퓨터 프로그래밍 언어는 무엇인가요?
```

```
2026년 초등학교 5학년 수학 교과서 138페이지의 내용을 알려주세요.
```

```
한국의 초등학교 교사 평균 연봉을 구체적 수치로 알려주세요.
```

### 분석
- Claude가 "모른다"고 답하는가, 그럴듯하게 지어내는가?
- Perplexity에서 같은 질문을 검색하여 팩트체크

### 교훈
- AI는 **자신있게 틀릴 수 있다**
- 특히 숫자, 날짜, 구체적 사실은 반드시 검증
- "Claude가 말했으니까 맞겠지"는 위험

## 실습 2: 개인정보와 AI (10분)

### 해서는 안 되는 것 (시연)
```
❌ "우리 반 김민수(실명)의 성적은 국어 65, 수학 40인데, 어떻게 지도할까요?"
❌ "학부모 전화번호 010-xxxx-xxxx로 문자 보낼 내용 만들어줘"
❌ "이 학생의 가정환경은... (구체적 개인정보)"
```

### 올바른 방법
```
✅ "학생 A는 국어 성적이 중하위권이고, 수학은 하위권입니다. 지도 방법을 알려주세요."
✅ 이름/연락처 등 개인정보는 제거하고 입력
✅ 가명 사용 또는 일반화
```

## 실습 3: 학생의 AI 사용 — 어디까지 허용할 것인가? (15분)

### 토론 주제
1. 학생이 독후감을 Claude로 썼다면?
2. 수학 풀이를 AI에게 물어보는 것은?
3. 발표 자료를 Claude로 만든 것은?
4. 시험에서 AI 사용은?

### 판단 프레임워크
Claude에게 요청:
```
초등학교 5학년 학생의 AI 사용에 대한 교사 정책을 만들어줘.

다음 상황별로 "허용/조건부 허용/금지"를 구분하고 이유를 설명해줘:
1. 숙제에서 AI로 초안 작성 후 수정
2. 숙제에서 AI 결과를 그대로 제출
3. 수업 중 AI에게 개념 질문
4. 수업 중 AI에게 답 직접 확인
5. 발표 자료 제작에 AI 활용
6. 시험/평가에서 AI 사용
7. 자유 탐구/프로젝트에서 AI 활용
```

## 실습 4: 교실 AI 정책 문서 작성 (15분)

### Claude Code로 정책 문서 생성
```
우리 학교 교실 AI 사용 정책 문서를 만들어줘.

포함 내용:
1. AI 사용 목적 (학습 보조 도구)
2. 허용 범위 (어떤 상황에서 사용 가능)
3. 금지 사항 (개인정보 입력, 시험 중 사용 등)
4. AI 결과 검증 규칙 (반드시 확인하는 습관)
5. 출처 표시 규칙 ("AI 도움을 받았습니다" 명시)
6. 위반 시 대응

대상: 학생, 학부모 모두 읽을 수 있는 쉬운 언어
분량: A4 1페이지
파일명: 교실_AI_정책.md
```

## 과제

### 제출물: 교실 AI 정책 문서

3. 학생 AI 사용 판단 표 (실습 3 결과)

## 강사 참고 사항
- 이 수업은 **정답이 없는 토론**이 핵심 — 시간 배분에 유의
- 학교마다, 교사마다 AI 정책이 다를 수 있음을 인정
