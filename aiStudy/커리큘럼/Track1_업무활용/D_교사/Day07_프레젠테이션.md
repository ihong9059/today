# Day 7: 프레젠테이션 + PDF — "학부모 설명회 자료를 Claude Code로"

## 학습 목표
- Claude Code로 프레젠테이션용 HTML 제작
- AI 이미지 생성(Claude Design)으로 시각자료 보강
- edge-tts로 음성 나레이션 생성
- HTML → PDF 변환

---

## 실습 1: 학부모 설명회 HTML 제작 (20분)

### 프롬프트
```
초등학교 5학년 1학기 학부모 설명회 발표자료를 HTML로 만들어줘.

구성 (슬라이드형, 페이지별):
1. 표지: "5학년 1반 학부모 설명회" + 담임 이름 + 날짜
2. 학급 운영 방침 (3가지 핵심 가치)
3. 교과별 학습 계획 (국어/수학/사회/과학/영어 표)
4. 평가 방법 (수행평가 비율, 일정)
5. 학교생활 안내 (등하교, 급식, 방과후)
6. 현장체험학습 계획
7. 학부모 협조 사항
8. Q&A + 연락처

디자인:
- 깔끔한 파스텔 톤 배경
- 둥근 카드 스타일
- A4 인쇄에 적합한 레이아웃
- 각 페이지 구분선
```

### 브라우저에서 확인
```
이 HTML 파일을 브라우저에서 열어줘
```

---

## 실습 2: AI 이미지 + 시각자료 (10분)

### Claude Design 활용
claude.ai에서:
```
학부모 설명회에 사용할 아이콘/일러스트를 만들어줘:
1. "함께 성장하는 교실" 컨셉의 헤더 이미지
2. 교과 아이콘 (책, 계산기, 지구본, 현미경)
```

### Mermaid 다이어그램
Claude Code에서 HTML에 추가:
```
평가 방법 페이지에 Mermaid 파이 차트를 추가해줘:
- 수행평가 40%
- 지필평가 40%
- 참여도 20%
```

---

## 실습 3: edge-tts 음성 나레이션 (10분)

### 설치 + 실행
Claude Code에서:
```
edge-tts를 설치하고, 다음 텍스트를 한국어 음성 파일로 만들어줘:

"안녕하세요, 5학년 1반 담임 홍길동입니다.
오늘 설명회에서는 1학기 학급 운영 방침과 교과 학습 계획을 안내드리겠습니다.
궁금하신 점은 언제든 말씀해주세요."

파일명: 설명회_인사.mp3
목소리: 여성, 자연스러운 톤
```

### 활용 아이디어
- 학습 자료에 음성 설명 추가
- 다문화 가정용 다국어 안내 음성
- 학생 자습용 오디오 가이드

---

## 실습 4: HTML → PDF 변환 (5분)

### Claude Code에서:
```
학부모 설명회 HTML을 PDF로 변환해줘.
A4 사이즈, 배경색 포함.
```

또는 브라우저에서 `Ctrl+P` → "PDF로 저장"

---

## 과제

### 제출물: 설명회 발표자료 (HTML + PDF)

1. 자기 학급에 맞는 학부모 설명회 HTML
2. PDF 변환본
3. (선택) 음성 나레이션 1개

---

## 강사 참고 사항
- HTML 경험이 없어도 됨 — Claude Code가 전부 생성
- "이 색상을 바꿔줘", "폰트를 더 크게 해줘" 등 수정 요청으로 디자인 조절
- edge-tts는 인터넷 연결 필요, 속도 빠름 (1분 내 생성)
- PDF 변환이 안 되면 브라우저 인쇄 기능으로 대체
