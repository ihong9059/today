# Day 2: 프롬프트 엔지니어링 — "같은 요청, 다른 결과"

## 학습 목표
- 프롬프트 품질이 결과를 결정한다는 것을 체험
- 역할 부여, 맥락 제공, 형식 지정 3가지 기법 습득
- 교안 작성에 최적화된 프롬프트 패턴 학습

---

## 실습 1: 나쁜 프롬프트 vs 좋은 프롬프트 (15분)

### 나쁜 프롬프트
```
수학 수업 만들어줘
```

### 보통 프롬프트
```
초등학교 5학년 수학 분수 수업을 만들어줘
```

### 좋은 프롬프트
```
당신은 초등교육 전문가입니다.

초등학교 5학년 수학 "분수의 덧셈과 뺄셈" 단원의 40분 수업 교안을 작성해주세요.

조건:
- 대상: 5학년 28명 (수준 차이 있음)
- 시간: 40분 (도입 5분, 전개 25분, 정리 10분)
- 활동: 게임형 모둠 활동 1개 포함
- 평가: 형성평가 문항 3개 포함
- 수준별: 상/중/하 학생별 활동 차이 명시

출력 형식: 마크다운 표로 시간별 활동 정리
```

## 실습 2: 프롬프트 패턴 연습 (15분)

### 패턴 1: 역할 부여
```
당신은 [역할]입니다.
```
예시: "당신은 15년 경력의 초등 국어 교육 전문가입니다."

### 패턴 2: 맥락 + 조건
```
[배경 상황]
[구체적 조건 나열]
```
예시: "우리 반은 28명이고, 다문화 학생이 3명 있습니다."

### 패턴 3: 출력 형식 지정
```
다음 형식으로 작성해주세요:
- 표 형식 / 번호 목록 / 마크다운
- 분량: A4 1페이지 / 3문단 / 5줄
```

### 패턴 4: 단계적 지시
```
다음 순서로 진행해주세요:
1. 먼저 학습 목표를 정하고
2. 그 다음 활동을 설계하고
3. 마지막으로 평가 문항을 만들어주세요
```

### 연습 문제
아래 요청을 좋은 프롬프트로 바꿔보세요:

1. "과학 실험 수업 만들어줘" → ?
2. "학생한테 쓸 상장 문구 만들어줘" → ?
3. "학부모 상담 준비 도와줘" → ?

## 실습 3: 교안 2종 비교 제작 (15분)

같은 단원에 대해 **두 가지 수업 방식**의 교안을 Claude에게 요청하세요.

### 교안 A: 강의형
```
초등 5학년 사회 "우리나라의 경제 성장" 단원을
강의 중심으로 40분 교안을 작성해주세요.
교사 설명 → 학습지 풀기 → 정리 구조.
```

### 교안 B: 활동형
```
같은 단원을 모둠 활동 중심으로 40분 교안을 작성해주세요.
역할극, 토론, 발표 등 학생 참여 활동 포함.
```

## 과제

### 제출물: "프롬프트 비교 분석 + 나만의 교안 프롬프트"

1. 실습 1의 비교 분석 표 완성
2. 실습 3의 교안 A/B 비교 분석 완성
3. **나만의 최적 교안 프롬프트** 1개 작성 (자기 담당 과목/학년에 맞춰서)

```markdown
# 나만의 교안 프롬프트

## 담당: [학년] [과목] [단원명]

## 프롬프트:
(여기에 작성)

## 이 프롬프트를 만든 이유:
- 역할 부여: ...
- 맥락/조건: ...
- 출력 형식: ...
```

## 강사 참고 사항
- "정답 프롬프트"는 없음 — 자기 상황에 맞게 계속 다듬는 것이 핵심
- 선생님들이 서로의 프롬프트를 공유하고 피드백하는 시간 확보
- 실습 3에서 자기 과목이 아닌 단원도 가능 — 프롬프트 기법이 핵심이므로
