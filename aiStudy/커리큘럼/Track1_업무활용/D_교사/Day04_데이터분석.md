## 실습 1: 성적 데이터 분석 (15분)

### 샘플 데이터 (아래를 Claude에 붙여넣기)
```
이름,국어,수학,사회,과학,영어
김민준,85,72,90,88,78
이서연,92,95,88,91,96
박지호,68,55,72,65,60
최수아,88,90,85,92,87
정우진,75,60,78,70,72
한예은,95,98,92,95,97
송태현,70,65,75,68,62
윤하늘,82,78,80,85,80
임도윤,90,88,86,89,92
장서윤,65,50,70,62,58
```

### 프롬프트
```
위 성적 데이터를 분석해주세요.

다음을 포함해주세요:
1. 과목별 평균, 최고점, 최저점
2. 전체 평균 기준 상위/중위/하위 학생 분류
3. 과목 간 상관관계 (수학이 낮으면 과학도 낮은가?)
4. 부진 학생(전 과목 70 미만) 식별 + 보충 지도 제안
5. 결과를 표로 정리

마지막에 담임교사가 학부모 면담 시 활용할 수 있는 코멘트도 학생별로 작성해주세요.
```

## 실습 2: Claude 멀티모달 — 이미지 분석 (10분)

### 실습 2-1: 학생 작품 분석
학생이 그린 그림이나 작품 사진을 Claude에 업로드하고:
```
이 그림은 초등학교 5학년 학생의 미술 작품입니다.
다음을 분석해주세요:
1. 작품의 주제와 표현 기법
2. 잘한 점 (구체적으로)
3. 발전 가능한 부분 (긍정적 표현으로)
4. 생기부에 쓸 수 있는 1~2문장 코멘트
```

### 실습 2-2: 판서/프린트 분석
수업 자료 사진(판서, 학습지 등)을 촬영하여 업로드:
```
이 사진은 수학 수업 판서입니다.
내용을 텍스트로 정리하고, 학습지로 재구성해주세요.
```

## 실습 3: NotebookLM 체험 (10분)

### 사용 방법
1. notebooklm.google.com 접속
2. "새 노트북" 생성
3. 교과서 PDF 또는 교육 관련 문서 업로드
4. 질문하기: "이 단원의 핵심 개념 3가지는?"
5. "오디오 요약" 생성 → 팟캐스트 형태로 듣기

### 교사 활용 아이디어
- 교과서 단원 업로드 → 핵심 정리 자동화
- 교육부 고시문 업로드 → "이번 개정에서 바뀐 점은?"
- 연수 자료 업로드 → 요약 + 퀴즈 자동 생성

> **참고**: NotebookLM 활용 범위는 추후 확정. 오늘은 체험 수준.

## 실습 4: Perplexity로 교육 리서치 (10분)

### 사용 방법

2. 교육 관련 질문 검색

### 예시 질문

```
프로젝트 기반 학습(PBL) 초등 수학 적용 사례
```
```
학생 참여형 수업 평가 방법 최신 연구
```

### Claude vs Perplexity 비교
| 항목 | Claude | Perplexity |
|------|--------|-----------|
| 강점 | 문서 생성, 분석, 창작 | 실시간 검색, 출처 제공 |
| 약점 | 최신 정보 부족 가능 | 긴 문서 생성에 약함 |
| 교사 활용 | 교안/문서 작성 | 자료 조사, 팩트체크 |

## 강사 참고 사항
- 실제 학생 성적 데이터 사용 시 개인정보 주의 — 이름을 가명으로 변경
- 멀티모달은 스마트폰 카메라로 바로 찍어서 업로드하면 편리
- NotebookLM은 체험 수준으로, 깊이 들어가지 않아도 됨
- Perplexity는 "AI가 만든 답을 검증하는 도구"로 소개
