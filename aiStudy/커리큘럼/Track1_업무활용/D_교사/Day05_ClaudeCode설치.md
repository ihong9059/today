# Day 5: Claude Code 설치 — "교안 폴더를 자동으로 만들자"

## 학습 목표
- Claude Code CLI 설치 및 첫 실행
- claude.ai(브라우저) vs Claude Code(터미널) 차이 이해
- Claude Code로 교안 폴더 구조 + 1주차 교안 자동 생성

## 준비물
- 노트북 (Windows/Mac)
- Claude Pro 계정
- Node.js 설치 (18+)

---

## 실습 1: 설치 (15분)

### Step 1: Node.js 설치 확인
```bash
node --version
```
없으면 nodejs.org에서 다운로드 → 설치

### Step 2: Claude Code 설치
```bash
npm install -g @anthropic-ai/claude-code
```

### Step 3: 첫 실행
```bash
claude
```
로그인 안내에 따라 Claude Pro 계정 연결

### Step 4: 첫 대화
```
안녕! 나는 초등학교 5학년 담임이야. 잘 부탁해.
```

---

## 실습 2: 브라우저 vs 터미널 차이 체험 (10분)

### claude.ai (브라우저)
- 대화창에서 텍스트 주고받기
- 결과를 복사해서 워드/메모장에 붙여넣기
- 파일을 직접 만들 수 없음

### Claude Code (터미널)
- 내 컴퓨터의 파일을 직접 읽고/만들고/수정
- 폴더 구조 자동 생성
- 명령어 실행 가능

### 체험
Claude Code에서 입력:
```
내 바탕화면에 "테스트" 폴더를 만들고, 그 안에 "안녕하세요.md" 파일을 만들어줘.
파일 내용은 "Claude Code 첫 파일입니다!" 로 해줘.
```

→ 실제로 바탕화면에 폴더와 파일이 생기는 것 확인!

## 실습 3: 교안 폴더 자동 생성 (15분)

### 프롬프트
```
나는 초등학교 5학년 담임이고, 1학기 수학 교안을 정리하려고 해.
다음 구조로 폴더와 파일을 만들어줘:

5학년_수학_1학기/
├── 1단원_자연수의혼합계산/
│   └── 교안.md
├── 2단원_약수와배수/
│   └── 교안.md
├── 3단원_규칙과대응/
│   └── 교안.md
├── 4단원_약분과통분/
│   └── 교안.md
├── 5단원_분수의덧셈과뺄셈/
│   └── 교안.md
└── 6단원_다각형의둘레와넓이/
    └── 교안.md

각 교안.md에는 아래 양식으로 초안을 넣어줘:
- 단원명
- 학습 목표 (3개)
- 차시 구성 (표)
- 핵심 개념 키워드
```

### 결과 확인
```
이 폴더 구조를 보여줘
```

## 강사 참고 사항
- Node.js 설치에서 막히는 분이 많음 — 사전에 설치 안내서 배포 권장
- Windows는 PowerShell 또는 Git Bash 사용
- Claude Code가 파일을 만들 때 "허용하시겠습니까?" 팝업이 뜸 → "허용" 설명
- 폴더 생성이 눈에 보이는 성공 경험이므로, 탐색기/Finder로 직접 확인시켜주기
