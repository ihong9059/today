# Day 3: 문서 작성 — "가정통신문, 생기부, 상담안내문을 Claude로"

## 학습 목표
- 교사가 반복적으로 작성하는 문서 3종을 Claude로 작성
- 초안 생성 → 수정 요청 → 완성 워크플로우 체험
- 톤/형식/분량 조절 기법

---

## 실습 1: 가정통신문 작성 (15분)

### 프롬프트 예시
```
초등학교 5학년 담임교사입니다.
다음 주 현장체험학습(5월 15일, 국립과천과학관) 안내 가정통신문을 작성해주세요.

포함 내용:
- 일시: 2026년 5월 15일(금) 09:00~15:00
- 장소: 국립과천과학관
- 준비물: 도시락, 물, 필기도구, 돗자리
- 비용: 버스비 15,000원 (5월 10일까지 납부)
- 복장: 교복 대신 편한 옷 + 운동화
- 우천 시: 정상 진행 (실내 관람)
- 하단에 회신란 (동의/미동의 체크, 학부모 서명)

톤: 정중하지만 따뜻하게
분량: A4 1페이지
```

### 수정 요청 연습
- "비용 납부 방법을 계좌이체로 구체화해줘"
- "알레르기 관련 주의사항도 추가해줘"
- "조금 더 간결하게 줄여줘"

---

## 실습 2: 생활기록부 문구 작성 (15분)

### 프롬프트 예시
```
초등학교 5학년 학생의 생활기록부 교과세부능력 및 특기사항을 작성해주세요.

학생 정보:
- 과목: 수학
- 특징: 문제 풀이 속도는 느리지만 정확도가 높음, 친구들에게 풀이 방법을 잘 설명함
- 활동: 모둠 활동에서 리더 역할, 수학 퍼즐 대회 참가
- 성장: 1학기 초 분수 개념 부족 → 학기 말 분수 응용문제 해결 가능

조건:
- 교육부 생기부 작성 가이드라인 준수
- 긍정적 표현 위주
- 3~4문장
- "~함", "~임" 종결어미 사용
```

### 다양한 학생 유형별 연습
아래 학생 특성을 입력하고 각각 생기부 문구를 생성해보세요:

1. **적극적 참여형**: 발표를 좋아하고, 창의적 아이디어가 많음
2. **조용한 노력형**: 말은 적지만 과제를 꼼꼼하게 수행
3. **성장 두드러진 학생**: 초반 부진 → 후반 급성장

## 실습 3: 학부모 상담 안내문 (10분)

### 프롬프트 예시
```
초등학교 5학년 1학기 학부모 상담 주간 안내문을 작성해주세요.

정보:
- 상담 기간: 6월 2일(월) ~ 6월 6일(금)
- 시간: 14:00 ~ 16:30 (1인 15분)
- 방법: 대면(교실) 또는 전화 선택
- 신청: 첨부 시간표에서 희망 시간 3순위 기재

포함:
- 상담 시 준비하면 좋은 질문 예시 3가지
- 하단에 희망 시간 기재란

톤: 따뜻하고 환영하는 느낌
```

## 실습 4: 번역 + 다문화 가정용 (5분)

### 프롬프트 예시
```
위에서 작성한 가정통신문을 영어로 번역해주세요.
다문화 가정 학부모가 읽을 수 있도록 쉬운 영어로 작성해주세요.
```

추가 연습:
- "베트남어로도 번역해줘" (Claude가 지원하는 범위 내)
- "한국어와 영어를 나란히 배치한 이중언어 버전으로 만들어줘"

## 과제

### 제출물: 문서 3종 완성본

자기 학교/학년/상황에 맞게 아래 3종을 Claude로 작성하세요:

1. **가정통신문** 1건 (실제 행사 또는 가상)
2. **생기부 문구** 3명분 (학생 유형별)
3. **안내문** 1건 (상담, 방과후, 행사 등)

각 문서마다:
- 사용한 프롬프트
- Claude 초안
- 수정 요청 내용
- 최종 완성본

을 함께 제출하세요.

## 강사 참고 사항
- 생기부 문구는 교육부 가이드라인과 맞는지 반드시 교사가 검수해야 함을 강조
- "Claude가 만든 것을 그대로 쓰지 말고, 초안으로 활용" 메시지 반복
- 번역 실습은 다문화 학생이 있는 학교에서 특히 반응이 좋음
