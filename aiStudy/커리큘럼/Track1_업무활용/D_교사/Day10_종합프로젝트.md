# Day 10: 종합 프로젝트 — "1학기 교육과정 안내서 완성"

## 학습 목표
- 10일간 배운 모든 도구를 종합 활용
- 기획 → 작성 → 디자인 → PDF 출력까지 전 과정 수행
- 실제 학교에서 사용 가능한 결과물 완성

---

## 프로젝트 개요

### 최종 결과물: "1학기 교육과정 안내서" PDF

학부모에게 배포하거나 학급 게시용으로 사용할 수 있는 **교육과정 안내서**를 Claude + Claude Code로 처음부터 끝까지 제작합니다.

### 포함 내용 (6~8페이지)
1. 표지 (학교명, 학년, 담임, 날짜)
2. 담임 인사말
3. 학급 운영 방침
4. 교과별 학습 계획 (국어/수학/사회/과학/영어)
5. 평가 방법 및 일정
6. 연간 행사 일정
7. 학부모 협조 사항
8. 연락처 및 상담 안내

---

## 진행 순서 (50분)

### Step 1: 기획 — Claude로 구조 설계 (5분)

claude.ai에서:
```
초등학교 5학년 1반 1학기 교육과정 안내서를 만들려고 합니다.
8페이지 구성으로 목차와 각 페이지별 포함 내용을 제안해주세요.
학부모 대상, 따뜻하지만 전문적인 톤입니다.
```

### Step 2: 내용 작성 — Claude Code로 파일 생성 (15분)

Claude Code에서:
```
1학기_교육과정_안내서 폴더를 만들고,
아래 구성으로 안내서.html 파일을 만들어줘.

1페이지 - 표지
  - 학교명: 김포나진초등학교
  - 학년/반: 5학년 1반
  - 담임: (본인 이름)
  - 날짜: 2026년 3월

2페이지 - 담임 인사말
  - 따뜻한 인사 + 올해 교육 방향 소개
  - 3~4문단

3페이지 - 학급 운영 방침
  - 3가지 핵심 가치 (예: 존중, 도전, 협력)
  - 각 가치별 구체적 실천 내용

4페이지 - 교과별 학습 계획
  - 국어/수학/사회/과학/영어 표
  - 각 교과: 단원명, 핵심 내용, 평가 방법

5페이지 - 평가 방법
  - 수행평가 / 지필평가 비율
  - 월별 평가 일정 표

6페이지 - 연간 행사
  - 월별 주요 행사 (현장체험, 운동회, 학예발표 등)

7페이지 - 학부모 협조 사항
  - 출결, 준비물, 가정학습, 스마트폰 관리

8페이지 - 연락처 + 상담 안내
  - 교무실 번호, 이메일
  - 상담 가능 시간
  - 긴급 연락처

디자인:
- 연한 녹색 계열 배경
- 둥근 카드 스타일
- 각 페이지에 아이콘/이모지 활용
- A4 인쇄 최적화
- 인쇄 시 페이지 구분
```

### Step 3: 수정 + 보강 (10분)

```
인사말을 좀 더 따뜻하게 수정해줘
```
```
교과별 학습 계획 표에 "가정에서 도울 수 있는 방법" 열을 추가해줘
```
```
연간 행사 페이지에 월별 타임라인 형식으로 시각화해줘
```

### Step 4: PDF 변환 (5분)

```
이 HTML을 PDF로 변환해줘. A4, 배경색 포함.
```

### Step 5: 발표 (15분)

- 각자 완성한 안내서를 화면에 띄우고 소개 (1인 2~3분)
- "어떤 부분을 Claude가 도왔는가?"
- "어떤 부분은 내가 직접 수정했는가?"
- 동료 교사 피드백
