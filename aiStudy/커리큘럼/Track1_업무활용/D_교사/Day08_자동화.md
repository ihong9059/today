# Day 8: 반복 업무 자동화 — "시험 출제, 채점 기준을 자동으로"

## 학습 목표
- 반복되는 양식을 템플릿화
- Claude Code로 시험지 + 채점 기준 자동 생성
- Notion 연동 — 스마트폰에서 교안/할일 확인

---

## 실습 1: 시험 출제 자동화 (15분)

### 프롬프트
```
5학년 수학 "약수와 배수" 단원 시험지를 만들어줘.

구성:
- 객관식 10문제 (4지선다)
- 주관식 5문제 (단답형)
- 서술형 3문제
- 총 100점 배점
- 난이도: 쉬움 40%, 보통 40%, 어려움 20%

파일 2개 생성:
1. 약수와배수_시험지.md (문제만, 정답 없음)
2. 약수와배수_채점기준.md (정답 + 배점 + 부분점수 기준)
```

### 변형 요청
```
이 시험지를 기반으로 B형 시험지도 만들어줘.
문제 순서를 섞고, 객관식 보기 순서도 바꿔줘.
정답이 같은 번호에 몰리지 않게 해줘.
```

---

## 실습 2: 평가 루브릭 생성 (10분)

### 프롬프트
```
5학년 과학 "태양계와 별" 단원 수행평가 루브릭을 만들어줘.

수행평가 내용: 태양계 행성 소개 포스터 만들기

평가 기준:
- 내용 정확성 (30점)
- 창의적 표현 (30점)
- 발표 능력 (20점)
- 완성도 (20점)

각 기준마다 상/중/하 수준별 구체적 기술을 작성해줘.
표 형식으로.
```

---

## 실습 3: Notion 연동 — 스마트폰 접근 (15분)

### Notion 기본 설정
1. notion.so 가입 (무료)
2. 스마트폰에 Notion 앱 설치

### 교사용 Notion 구성
Claude에게 Notion 페이지 구조를 설계 요청:
```
교사용 Notion 워크스페이스 구조를 설계해줘.

포함 페이지:
1. 주간 계획 (월~금 수업 시간표 + 할일)
2. 학생 관리 (이름, 특이사항, 상담 기록)
3. 교안 저장소 (과목별 링크)
4. 가정통신문 아카이브
5. 회의/연수 메모

각 페이지의 구조와 속성을 구체적으로 알려줘.
```

### 핵심 가치
- **PC에서 작성** (Claude Code로 교안 생성) → **Notion에 복사** → **스마트폰에서 확인**
- 출근길에 오늘 수업 교안 확인
- 학부모 전화 시 학생 정보 즉시 조회
- 회의 중 메모 → PC에서 이어서 정리

## 실습 4: 주간 업무 템플릿 (5분)

### 프롬프트
```
교사용 주간 업무 보고 템플릿을 만들어줘.

포함 항목:
- 이번 주 수업 진도
- 학생 특이사항
- 행사/회의 참석
- 다음 주 준비사항
- 건의사항

매주 복사해서 쓸 수 있는 양식으로.
파일명: 주간업무_템플릿.md
```

---

## 과제

### 제출물: 시험지 + Notion 설정

1. 자기 과목 시험지 + 채점 기준 (Claude Code로 생성)
2. 수행평가 루브릭 1개
3. Notion 가입 + 기본 페이지 1개 생성 (스마트폰에서 확인 스크린샷)

## 강사 참고 사항
- 시험지 생성 시 "교과서에 없는 문제가 나올 수 있음" 반드시 검수 강조
- Notion은 무료 플랜으로 충분 — 개인 사용에 제한 없음
- Obsidian(개인 PC 지식관리) + Notion(외부 접근/공유) 조합 설명
- 스마트폰 연동이 "교실 밖에서도 준비할 수 있다"는 실용적 가치 강조
