# Day 1: AI 첫 경험 — "Claude에게 업무 고민을 물어보자"

## 학습 목표
- Claude 가입 및 첫 대화
- AI에게 역할을 부여하고 업무 질문하기
- 내 업무에서 AI 활용 가능 영역 파악

## 준비물
- 노트북 또는 PC
- Claude 계정 (claude.ai)

---

## 실습 1: Claude 가입 + 첫 대화 (10분)

1. claude.ai 접속 → 회원가입
2. 첫 대화:
```
안녕하세요. 저는 ○○기업 마케팅팀 대리입니다.
주로 하는 업무는 시장 조사, 보고서 작성, SNS 콘텐츠 기획입니다.
제 업무에서 AI가 도움을 줄 수 있는 부분을 알려주세요.
```

### 관찰 포인트
- Claude가 내 직무를 이해하고 답변하는가?
- 일반적 답변인가, 구체적 제안인가?

---

## 실습 2: 역할 부여하기 (10분)

```
당신은 20년 경력의 경영 컨설턴트입니다.
저는 중소기업 마케팅팀 대리(3년차)이고,
팀장님이 "신규 고객 확보 전략"을 다음 주까지 보고하라고 했습니다.

다음을 도와주세요:
1. 보고서 목차 구성 (5개 챕터)
2. 각 챕터별 핵심 포인트 3줄
3. 팀장님이 좋아할 만한 데이터/수치 예시
4. 예상 질문 3가지와 답변

마크다운 형식으로 정리해주세요.
```

### 관찰 포인트
- "경영 컨설턴트" 역할이 답변 품질에 미치는 영향
- 목차, 데이터, 예상 질문까지 구조화된 답변

---

## 실습 3: 업무별 AI 활용 영역 분석 (15분)

```
저의 주간 업무를 나열하면:
- 주간 업무 보고서 작성 (월요일)
- 시장/경쟁사 동향 조사 (수시)
- 이메일 작성 및 회신 (매일 20건+)
- 회의 참석 및 회의록 작성 (주 3회)
- SNS 콘텐츠 기획 및 카피 작성 (주 2건)
- 마케팅 캠페인 성과 데이터 분석 (월 1회)
- 기획안/제안서 작성 (월 1~2건)
- 상사 보고용 PPT 제작 (월 2~3건)
- 거래처 미팅 준비 (주 1회)

각 업무별로 분석해주세요:
1. AI 활용도 (상/중/하)
2. AI가 할 수 있는 부분
3. 사람만 할 수 있는 부분
4. 예상 시간 절약 (%)
표로 정리해주세요.
```

---

## 실습 4: 다양한 업무 질문 체험 (10분)

직무에 맞게 골라서 질문:

### 마케팅/기획
```
경쟁사 A가 신제품을 출시했습니다. 우리 대응 전략 3가지를 제안해주세요.
SWOT 분석 형태로 정리해주세요.
```

### 영업
```
거래처 미팅 전 준비 체크리스트를 만들어주세요.
미팅 시 사용할 아이스브레이킹 멘트 3가지도 포함해주세요.
```

### 인사/총무
```
신입사원 온보딩 체크리스트(첫 1주일)를 만들어주세요.
부서별로 안내해야 할 사항을 표로 정리해주세요.
```

### 재무/회계
```
월말 결산 프로세스를 체크리스트로 만들어주세요.
흔히 놓치기 쉬운 항목도 표시해주세요.
```

## 과제

### 제출물: "나의 AI 활용 계획"

```markdown
# 나의 AI 활용 계획

## 기본 정보
- 이름:
- 회사/부서/직급:
- 주요 업무:

## AI 활용 우선순위 (Top 3)

### 1. [업무명]
- 현재 소요 시간:
- AI 활용 시 예상 절약 시간:
- AI가 할 부분:
- 내가 할 부분:

### 2. [업무명]
- ...

### 3. [업무명]
- ...

## 오늘 느낀 점
- 기대되는 것:
- 우려되는 것:
- 내일부터 바로 써보고 싶은 것:
```

## 강사 참고 사항
- 직무/직급이 다양한 수강생이 섞여 있으므로 "자기 업무에 맞게" 유도
- "AI가 내 일자리를 뺏는다"는 우려 → "반복 업무를 줄이고 핵심 업무에 집중" 메시지
- 기밀 정보 입력에 대한 주의는 Day 9에서 본격적으로, 여기서는 간단히 언급
