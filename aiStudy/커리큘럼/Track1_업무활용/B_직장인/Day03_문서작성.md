# Day 3: 문서 작성 — "보고서, 이메일, 회의록, 제안서를 10분 만에"

## 학습 목표
- 업무 핵심 문서 4종을 Claude로 작성
- 초안 → 수정 → 톤 변경 워크플로우
- 한영 번역 + 톤 조절

---

## 실습 1: 주간 업무 보고서 (10분)

### 프롬프트
```
마케팅팀 주간 업무 보고서를 작성해주세요.

보고 대상: 마케팅팀장
보고 기간: 5월 19일(월) ~ 5월 23일(금)

이번 주 완료:
- SNS 캠페인 A 론칭 (인스타+페이스북)
- 거래처 3곳 미팅 (△△전자, □□산업, ◇◇테크)
- 2분기 마케팅 예산 재배분안 작성

진행 중:
- 신제품 런칭 이벤트 기획 (6월 예정)
- 고객 만족도 설문 설계

다음 주 계획:
- 캠페인 A 1주차 성과 분석
- 런칭 이벤트 협력사 미팅
- 뉴스레터 5월호 발송

형식: 표 기반, A4 1페이지, 간결하게
```

### 수정 연습
- "완료 항목에 성과 수치를 추가해줘 (예: SNS 노출 5만회)"
- "팀장님이 좋아하는 스타일로 더 간결하게 줄여줘"
- "이슈/리스크 섹션을 추가해줘"

## 실습 2: 비즈니스 이메일 — 상황별 4종 (10분)

### 이메일 A: 납기 변경 요청 (정중)
```
거래처 구매팀장에게 납기 1주 연장을 요청하는 이메일.
원자재 수급 지연이 원인. 부분 선적 대안 제시.
3년 거래 관계, 정중하되 신뢰감 있게. 10줄 이내.
```

### 이메일 B: 미팅 요청 (첫 접촉)
```
처음 연락하는 잠재 고객에게 미팅을 요청하는 이메일.
우리 서비스 간단 소개 + 30분 미팅 제안.
상대방의 시간을 존중하는 톤. 8줄 이내.
```

### 이메일 C: 사내 공지 (공식)
```
전 직원 대상 "사무실 이전 안내" 이메일.
이전 날짜, 새 주소, 준비 사항, 문의처 포함.
공식적이지만 친근한 톤.
```

### 이메일 D: 영문 비즈니스 이메일
```
위 납기 변경 요청 이메일을 영어로 번역해주세요.
비즈니스 영어, 프로페셔널한 톤 유지.
```

## 실습 3: 회의록 정리 (10분)

### 프롬프트
```
아래 회의 메모를 정식 회의록으로 정리해주세요.

메모:
- 5/22 오전 10시 마케팅팀 주간 회의
- 참석: 김팀장, 박대리, 이주임, 최사원
- SNS 캠페인 1주차 결과 공유 (노출 5만, 클릭 2천, CTR 4%)
- 팀장 의견: 타겟 연령 30대 → 20대로 확대 검토
- 런칭 이벤트: 6/15로 확정, 장소 3곳 후보
- 박대리가 장소 비교표 금요일까지 작성
- 다음 회의: 5/29(목) 10시

정리 형식:
1. 회의 기본 정보 (표)
2. 논의 사항 (번호 목록)
3. 결정 사항
4. 액션 아이템 (담당자/기한 표)
5. 다음 회의 일정
```

### 추가 요청
```
이 회의록에서 액션 아이템만 뽑아서 할일 체크리스트로 만들어줘.
각 항목에 담당자, 기한, 우선순위(상/중/하) 포함.
```

## 실습 4: 제안서 초안 (15분)

### 프롬프트
```
당신은 기획 전문가입니다.

"사내 커뮤니케이션 개선" 제안서 초안을 작성해주세요.

배경: 부서 간 소통 부족으로 프로젝트 지연 발생
대상: 경영진 보고용

구성:
1. 현황 분석 (문제점 3가지)
2. 원인 분석
3. 개선안 3가지 (비용/효과/기간 표)
4. 기대 효과
5. 실행 일정 (간트 차트 형태)
6. 예산

분량: A4 3페이지 분량
톤: 전문적, 데이터 기반, 설득력 있게
```

## 과제

### 제출물: 업무 문서 4종

자기 업무에 맞게 아래 4종을 Claude로 작성:

1. **주간 보고서** 1건
2. **비즈니스 이메일** 2건 (국문 + 영문)
3. **회의록** 1건 (실제 또는 가상)
4. **제안서 초안** 1건

각 문서에 사용한 프롬프트와 수정 과정 포함.

---

## 강사 참고 사항
- 실제 업무 문서를 가져와서 실습하면 효과 극대화
- 기밀 정보는 가명/가상 데이터로 대체
- 이메일 실습이 "바로 쓸 수 있다"는 반응이 가장 높음
- 회의록은 메모 → 정식 회의록 변환이 핵심 포인트
