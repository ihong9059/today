# Day 7: 프레젠테이션 + PDF — "분기 실적 발표자료를 30분 만에"

## 학습 목표
- Claude Code로 업무 프레젠테이션 HTML 제작
- Mermaid 다이어그램으로 프로세스 시각화
- edge-tts로 발표 연습용 나레이션
- HTML → PDF 변환

---

## 실습 1: 분기 실적 발표자료 제작 (20분)

### 프롬프트
```
2분기 마케팅 실적 발표자료를 HTML로 만들어줘.
경영진 대상, 프로페셔널한 디자인.

구성 (슬라이드형, 페이지별):
1. 표지: "2026년 2분기 마케팅 실적 보고" + 부서명 + 발표일
2. 요약: 핵심 KPI 4개 (매출, 신규고객, CAC, ROI) 카드 형태
3. 매출 실적: 제품별 월간 매출 표 + 전년 대비
4. 캠페인 성과: SNS/이메일/이벤트별 성과 표
5. 경쟁사 대비: 시장점유율 비교 (우리 vs 경쟁 3사)
6. 이슈 & 리스크: 문제점 3가지 + 대응 방안
7. 하반기 전략: 핵심 전략 3가지 + 예상 효과
8. Q&A: 예상 질문 3개와 답변 준비

디자인:
- 네이비+화이트 비즈니스 톤
- 숫자는 크게, 설명은 간결하게
- 표와 카드 UI 활용
- A4 인쇄 최적화
```

---

## 실습 2: Mermaid 다이어그램 (10분)

### 프로세스 흐름도
```
발표자료에 마케팅 캠페인 프로세스 Mermaid 다이어그램을 추가해줘:

기획 → 콘텐츠 제작 → 검수 → 배포 → 성과 측정 → 개선
```

### 조직도
```
마케팅팀 조직도도 Mermaid로 만들어서 추가해줘:
팀장 아래에 기획파트(2명), 콘텐츠파트(2명), 분석파트(1명)
```

---

## 실습 3: 발표 나레이션 생성 (10분)

```
발표자료의 각 페이지별 발표 스크립트를 작성해줘.
1페이지당 30초~1분 분량.
자연스러운 구어체, "안녕하십니까" 시작.

그리고 2페이지(요약) 스크립트를 edge-tts로 음성 파일로 만들어줘.
파일명: 발표_요약.mp3
목소리: 남성, 차분한 톤
```

### 활용
- 발표 전 연습용으로 들어보기
- 온라인 미팅 시 자료와 함께 재생 가능

```
이 발표자료 HTML을 PDF로 변환해줘.
```

발표 연습:

- "이 자료의 핵심 메시지가 뭔가?"에 답할 수 있는지

## 과제

### 제출물: 발표자료 (HTML + PDF)

1. 자기 업무에 맞는 발표자료 (실적/제안/보고 중 택 1)
2. PDF 변환본
3. (선택) 발표 스크립트 또는 나레이션 음성

## 강사 참고 사항
- "30분 만에 경영진 보고 자료 완성"이 핵심 메시지
- Mermaid 다이어그램은 텍스트만으로 생성되어 수정이 쉬움을 강조
- 실제 업무 데이터가 있으면 효과 극대화 (수치만 변경)
- edge-tts는 온라인 미팅 시 대본 연습용으로 실용적
