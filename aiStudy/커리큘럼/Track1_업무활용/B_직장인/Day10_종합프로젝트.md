## 프로젝트: "업무 개선 제안서" PDF

실제 회사에 제출하거나 팀 내 공유할 수 있는 **업무 개선 제안서**를 처음부터 끝까지 제작합니다.

### 주제 선택 (택 1 또는 자유)
| 주제 | 설명 |
|------|------|
| AI 도입 제안 | "우리 팀에 AI 도구 도입 제안서" |
| 프로세스 개선 | "○○ 업무 프로세스 개선안" |
| 비용 절감 | "분기별 비용 절감 방안" |
| 고객 만족도 향상 | "CS 개선 제안서" |
| 사내 교육 제안 | "AI 활용 사내 교육 프로그램 제안" |

---

## 진행 순서 (50분)

### Step 1: 기획 — Claude로 구조 설계 (5분)

```
"[선택한 주제]" 제안서를 만들려고 합니다.
경영진에게 보고할 6페이지 구성으로 목차를 제안해주세요.
각 페이지의 핵심 메시지도 한 줄씩.
```

### Step 2: 데이터 수집 — Perplexity로 리서치 (5분)

perplexity.ai에서:
```
[관련 키워드] 시장 데이터/통계/사례
```
→ 수집한 데이터를 Claude에게 전달

### Step 3: 내용 작성 — Claude Code로 HTML 생성 (20분)

```
업무 개선 제안서를 HTML로 만들어줘.

구성:
1. 표지: "[제안서 제목]" + 부서명 + 이름 + 날짜
2. 현황 분석: 문제점 데이터 (표/그래프)
3. 원인 분석: 근본 원인 3가지 (Mermaid 다이어그램)
4. 개선안: 3가지 방안 (비용/효과/기간 비교 표)
5. 기대 효과: ROI 산출, 정량적 목표
6. 실행 계획: 월별 타임라인 + 담당자

디자인:
- 네이비+화이트 비즈니스 톤
- 데이터는 표와 카드로 시각화
- A4 인쇄 최적화
```

### Step 4: 수정 + 보강 (10분)

```
원인 분석에 Mermaid 피쉬본 다이어그램을 추가해줘
```
```
기대 효과에 구체적 수치를 넣어줘 (연간 절감 예상액)
```
```
경영진이 물어볼 예상 질문 3개와 답변도 마지막에 추가해줘
```

### Step 5: PDF 변환 + 발표 (10분)

```
PDF로 변환해줘
```

발표: 1인 3분
- 제안서 핵심 메시지
- "AI 도구를 어떻게 활용했나"
- 동료 피드백
