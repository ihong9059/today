## 실습 1: 매출 데이터 분석 (15분)

### 샘플 데이터 (Claude에 붙여넣기)
```
월,제품A,제품B,제품C,광고비,인건비
1월,4200,3100,1800,500,2200
2월,3800,3500,2000,600,2200
3월,5100,2900,1500,800,2300
4월,4500,3200,2200,550,2300
5월,6200,2800,1900,1200,2400
6월,5800,3400,2500,900,2400
```
(단위: 만원)

### 프롬프트
```
위 데이터는 우리 회사 상반기 제품별 매출과 비용입니다.

다음을 분석해주세요:
1. 월별 총매출, 총비용, 영업이익 계산
2. 제품별 매출 트렌드 (성장/하락/안정)
3. 광고비 대비 매출 효율 (ROAS) 분석
4. 가장 수익성 높은 제품과 이유
5. 하반기 매출 예측 (상반기 트렌드 기반)
6. 경영진에게 보고할 핵심 인사이트 3줄

표와 함께 정리해주세요.
```

### 추가 분석
```
이 데이터를 기반으로 하반기 마케팅 예산 배분을 제안해주세요.
제품별 예산 비율과 그 이유를 포함해주세요.
```

## 실습 2: Claude 멀티모달 — 업무 이미지 분석 (10분)

### 실습 2-1: 명함 → 연락처 정리
명함 사진을 Claude에 업로드:
```
이 명함의 정보를 아래 형식으로 정리해주세요:
- 이름:
- 직함:
- 회사:
- 이메일:
- 전화:
- 주소:
```

### 실습 2-2: 화이트보드/판서 → 회의록
회의 중 화이트보드 사진 업로드:
```
이 화이트보드 내용을 텍스트로 정리하고,
액션 아이템을 추출해주세요.
```

### 실습 2-3: 경쟁사 제품 사진 → 분석
경쟁사 제품/광고 사진 업로드:
```
이 제품(광고)의 특징을 분석해주세요.
우리 제품과 비교하여 장단점을 정리해주세요.
```

## 실습 3: NotebookLM 체험 (10분)

### 사용 방법
1. notebooklm.google.com 접속
2. 업무 관련 문서 업로드 (보고서 PDF, 제안서 등)
3. 질문: "이 보고서의 핵심 요약 3줄", "문제점과 해결방안"
4. "오디오 요약" → 출퇴근길에 듣기!

### 활용 시나리오
- 100페이지 사업계획서 → 핵심 요약 추출
- 경쟁사 리포트 여러 개 → 교차 분석
- 법률/규정 문서 → "우리에게 해당되는 부분은?"

### Claude vs Perplexity 업무 활용
| 상황 | Claude | Perplexity |
|------|--------|-----------|
| 보고서 작성 | ★★★ | ★ |
| 최신 시장 데이터 | ★ | ★★★ |
| 경쟁사 분석 | ★★ | ★★★ |
| 문서 초안 | ★★★ | ★ |
| 팩트체크 | ★ | ★★★ |

> **워크플로우**: Perplexity로 데이터 수집 → Claude로 보고서 작성
