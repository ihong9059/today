# Day 8: 반복 업무 자동화 — "주간보고 자동 초안, Notion 모바일 연동"

## 학습 목표
- 반복 업무를 템플릿 + AI로 자동화
- Notion으로 스마트폰에서 업무 확인/관리
- 주간 루틴 최적화

---

## 실습 1: 주간 보고서 자동 초안 (10분)

### 매주 반복하는 패턴
```
지난주 주간보고서(0519_주간보고.md)를 읽고,
이번 주 주간보고서 초안을 만들어줘.

규칙:
- 지난주 "진행 중" → 이번 주 "완료" 또는 계속 "진행 중"
- 지난주 "다음 주 계획" → 이번 주 "이번 주 완료" 후보
- 새로운 이슈는 비워두기 (내가 채울 것)
- 날짜 자동 업데이트
```

→ **매주 5분이면 보고서 초안 완성!**

---

## 실습 2: Notion 업무 관리 시스템 (20분)

### Step 1: Notion 가입 + 앱 설치
1. notion.so 가입 (무료)
2. 스마트폰에 Notion 앱 설치

### Step 2: 업무 관리 구조 설계
Claude에게:
```
직장인용 Notion 업무 관리 워크스페이스를 설계해줘.

필요 페이지:
1. 오늘 할일 (체크리스트, 우선순위, 기한)
2. 주간 계획 (월~금 업무 + 회의 일정)
3. 프로젝트 트래커 (프로젝트명/진행률/기한/담당자)
4. 회의 노트 (날짜별 기록)
5. 거래처 연락처 (회사/담당자/전화/이메일)
6. 아이디어/메모 (빠르게 캡처)

각 페이지의 데이터베이스 속성(property)과 뷰를 구체적으로 알려줘.
```

### Step 3: PC → 스마트폰 연동 확인
1. PC에서 오늘 할일 입력
2. 스마트폰에서 확인 + 체크
3. 회의 중 스마트폰으로 메모 → PC에서 정리

### 핵심 가치
- **회의 중**: 스마트폰으로 메모 → PC에서 회의록 정리
- **출장 중**: 거래처 연락처 즉시 조회
- **퇴근 후**: 내일 할일 확인 → 다음날 바로 시작
- **Claude Code 연동**: PC에서 보고서 생성 → Notion에 복사 → 어디서든 확인

## 실습 3: 이메일 답장 자동 초안 (10분)

```
자주 받는 이메일 유형별 답장 템플릿을 만들어줘:

1. 견적 문의 답장 — 감사 + 견적서 첨부 안내 + 미팅 제안
2. 일정 조율 답장 — 가능한 시간 3개 제시 + 장소 제안
3. 컴플레인 답장 — 사과 + 원인 설명 + 해결 방안 + 보상 제안
4. 협업 제안 답장 — 긍정적 수용 + 다음 단계 제안
5. 정중한 거절 — 감사 + 사유 + 대안 제시

각 템플릿에 [빈칸]을 넣어서 바로 수정 발송 가능하게.
```

## 실습 4: 업무 루틴 체크리스트 (5분)

```
직장인 일일 업무 루틴 체크리스트를 만들어줘:

오전:
□ 이메일 확인 + 긴급건 회신
□ 오늘 할일 우선순위 정리 (Notion)
□ 주요 미팅 준비

오후:
□ 핵심 업무 집중 시간 (2시간)
□ 미팅/협업
□ 이메일 2차 확인

퇴근 전:
□ 오늘 완료 사항 정리
□ 내일 할일 Notion에 입력
□ 주간보고 업데이트 (금요일)
```

## 강사 참고 사항
- "주간보고 5분 완성"이 직장인에게 가장 큰 어필 포인트
- Notion 스마트폰 연동은 "출장/미팅 중에도 업무 확인" 가치
- 이메일 템플릿은 팀 내 공유하면 팀 전체 효율 향상
- Obsidian(개인 지식) vs Notion(팀 공유/모바일) 용도 차이 설명
