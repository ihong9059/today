# Day 9: AI 윤리와 한계 — "사내 AI 가이드라인을 만들자"

## 학습 목표
- AI 할루시네이션을 업무 맥락에서 체험
- 기밀 정보/개인정보 입력의 위험성
- 사내 AI 활용 가이드라인 작성

---

## 실습 1: 업무에서 AI가 틀리는 경우 (10분)

### 위험한 질문 체험
```
우리 회사(○○기업)의 2025년 매출이 얼마인가요?
```
```
노동법상 연차 미사용 수당 계산 방법을 정확히 알려주세요.
```
```
이 계약서 조항에 법적 문제가 있는지 검토해주세요.
```

### 분석
| 질문 유형 | AI 신뢰도 | 위험도 | 대응 |
|----------|:---------:|:------:|------|
| 회사 내부 정보 | 매우 낮음 | 높음 | AI 사용 불가 |
| 법률/세무 | 낮음 | 높음 | 전문가 확인 필수 |
| 시장 데이터 | 보통 | 중간 | 팩트체크 필요 |
| 문서 초안 | 높음 | 낮음 | 검토 후 사용 |
| 아이디어 | 높음 | 낮음 | 자유롭게 활용 |

### 핵심
> **AI는 "매우 자신감 있는 인턴"이다.**
> 초안은 잘 쓰지만, 숫자와 법률은 반드시 확인해야 한다.

## 실습 2: 기밀 정보와 AI (15분)

### 절대 입력하면 안 되는 것 ❌
```
❌ 고객 개인정보 (이름, 연락처, 계좌)
❌ 매출/재무 실제 데이터
❌ 계약서/NDA 내용
❌ 사내 기밀 전략/로드맵
❌ 직원 인사 정보 (연봉, 평가)
❌ 소스코드/영업비밀
```

### 안전하게 사용하는 방법 ✅
```
✅ 수치를 변경: "매출 150억" → "매출 약 100~200억 규모의 중견기업"
✅ 가명 사용: "김철수 과장" → "A 담당자"
✅ 일반화: "우리 제품 X의 특허 기술" → "특정 IoT 제품의 기능"
✅ 구조만 요청: "이 계약서 검토해줘" → "일반적인 용역 계약서 체크리스트 알려줘"
```

### 연습: 이 요청은 안전한가?
| 요청 | 안전 | 위험 | 이유 |
|------|:----:|:----:|------|
| "주간보고서 양식 만들어줘" | | | |
| "우리 회사 매출 2000억 기준으로 분석해줘" | | | |
| "마케팅 전략 아이디어 10개 만들어줘" | | | |
| "이 계약서 내용을 요약해줘" (실제 계약서 첨부) | | | |
| "거래처 김과장에게 보낼 이메일 써줘" | | | |

## 실습 3: AI 결과 검증 워크플로우 (10분)

### 3단계 검증 프로세스
```
Claude에게:
업무에서 AI 결과물을 검증하는 3단계 프로세스를 만들어줘.

1단계: 사실 확인 (숫자, 날짜, 고유명사)
2단계: 논리 확인 (주장의 근거가 타당한가)
3단계: 톤/맥락 확인 (우리 회사 상황에 맞는가)

각 단계별 구체적 체크리스트 포함.
```

## 실습 4: 사내 AI 활용 가이드라인 작성 (15분)

### Claude Code로 생성
```
우리 회사 "AI 활용 가이드라인"을 작성해줘.

대상: 전 직원
분량: A4 2페이지

포함:
1. AI 활용 목적 (업무 효율화 도구)
2. 사용 가능 도구 (Claude, Perplexity 등)
3. 허용 업무 (초안 작성, 아이디어, 번역, 데이터 분석)
4. 금지 사항 (기밀 입력, 법률 판단, 고객 개인정보)
5. 필수 검증 규칙 (3단계 프로세스)
6. 결과물 표시 ("AI 보조 활용" 명시 기준)
7. 위반 시 대응
8. FAQ (5개)

톤: 공식적이지만 이해하기 쉽게
파일명: 사내_AI_가이드라인.md
```

## 강사 참고 사항
- "기밀 유출"은 직장인에게 가장 민감한 주제 — 구체적 사례로 경각심
- 가이드라인을 실제 회사에 제출할 수 있도록 품질 확보
- "AI를 쓰면 안 된다"가 아니라 "안전하게 쓰는 법"에 초점
- 법무/보안팀이 있는 회사는 기존 정책과 연계 안내
