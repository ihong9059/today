# Day 5: Claude Code 설치 — "업무 폴더를 자동으로 정리하자"

## 학습 목표
- Claude Code CLI 설치
- claude.ai vs Claude Code 차이 (브라우저 대화 vs 파일 작업)
- 업무 폴더 정리 + 보고서 양식 자동 생성

## 준비물
- 노트북 (Windows/Mac)
- Claude Pro 계정
- Node.js (18+)

---

## 실습 1: 설치 (10분)

```bash
node --version          # Node.js 확인
npm install -g @anthropic-ai/claude-code  # 설치
claude                  # 실행
```

첫 대화:
```
안녕. 나는 마케팅팀 대리야. 업무 효율화를 도와줘.
```

## 실습 2: 업무 폴더 자동 정리 (15분)

### 프롬프트
```
내 바탕화면에 "2026_업무" 폴더를 만들고 다음 구조로 정리해줘:

2026_업무/
├── 주간보고/
│   ├── 양식_주간보고서.md
│   └── 05월/
├── 회의록/
│   ├── 양식_회의록.md
│   └── 05월/
├── 제안서/
├── 이메일_템플릿/
│   ├── 납기변경_요청.md
│   ├── 미팅요청_첫접촉.md
│   └── 감사인사.md
├── 데이터분석/
└── 참고자료/

각 양식 파일에는 Day 2~3에서 배운 프롬프트 기반의 기본 양식을 넣어줘.
```

### 확인
```
2026_업무 폴더 구조를 보여줘
```

---

## 실습 3: 이메일 템플릿 자동 생성 (10분)

```
이메일_템플릿 폴더에 자주 쓰는 비즈니스 이메일 템플릿 5개를 만들어줘:

1. 납기변경_요청.md — 거래처에 납기 연장 요청
2. 미팅요청_첫접촉.md — 잠재 고객 미팅 제안
3. 감사인사.md — 미팅 후 감사 이메일
4. 견적요청.md — 업체에 견적 요청
5. 프로젝트완료_안내.md — 프로젝트 완료 보고

각 템플릿에 [회사명], [담당자명], [날짜] 등 빈칸을 넣어서
복사-수정만 하면 바로 발송할 수 있게 해줘.
```

---

## 실습 4: 주간 보고서 양식 상세 작성 (10분)

```
양식_주간보고서.md를 상세하게 작성해줘.

포함 섹션:
1. 보고 기본 정보 (보고자, 기간, 부서)
2. 이번 주 완료 (표: 업무/성과/비고)
3. 진행 중 (표: 업무/진행률/예상완료)
4. 이슈/리스크 (표: 이슈/영향/대응방안)
5. 다음 주 계획 (표: 업무/기한/우선순위)
6. 건의사항

매주 복사해서 쓸 수 있는 양식으로.
```
