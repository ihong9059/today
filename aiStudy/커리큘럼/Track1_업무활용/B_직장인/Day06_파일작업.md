# Day 6: Claude Code 파일 작업 — "회의록 요약, 다중 파일 한 번에 처리"

## 학습 목표
- Claude Code로 기존 파일을 읽고 분석/요약
- 여러 파일을 한 번에 처리하는 경험
- 회의록 → 할일 자동 추출

---

## 실습 1: 회의록에서 할일 자동 추출 (15분)

### Step 1: 회의록 파일 생성
```
회의록/05월/ 폴더에 "0522_마케팅회의.md" 파일을 만들어줘.

내용:
# 마케팅팀 주간 회의 - 5/22(목)

## 참석자
김팀장, 박대리, 이주임, 최사원

## 논의 사항
1. SNS 캠페인 1주차 성과: 노출 5만, 클릭 2천, CTR 4%
   - 팀장: 타겟 20대로 확대 검토 필요
   - 박대리가 20대 타겟 리서치 5/26까지

2. 신제품 런칭 이벤트
   - 일시: 6/15 확정
   - 장소: 3곳 후보 (삼성동/강남/역삼)
   - 이주임이 장소별 비교표 5/26까지
   - 최사원이 초청 리스트 100명 5/28까지

3. 뉴스레터 5월호
   - 콘텐츠 확정, 디자인 진행 중
   - 발송일: 5/30(금)
   - 최사원이 최종 검수 5/29까지

## 다음 회의: 5/29(목) 10:00
```

### Step 2: 할일 자동 추출
```
이 회의록을 읽고 액션 아이템만 추출해줘.
표 형식으로: 담당자 | 업무 | 기한 | 상태
```

### Step 3: 개인별 할일 분리
```
이 액션 아이템을 담당자별로 분리해서 각각 파일로 만들어줘.
박대리_할일.md, 이주임_할일.md, 최사원_할일.md
```

---

## 실습 2: 여러 보고서 통합 요약 (10분)

```
주간보고/05월/ 폴더에 3주치 보고서가 있다고 가정하고,
3개 파일을 만든 후, 월간 요약 보고서를 생성해줘.

1. 0505_주간보고.md (1주차 내용)
2. 0512_주간보고.md (2주차 내용)
3. 0519_주간보고.md (3주차 내용)

그 다음:
"3주치 주간 보고서를 읽고, 5월 월간 요약 보고서를 만들어줘.
주요 성과, 미해결 이슈, 다음 달 핵심 과제를 포함."
```

---

## 실습 3: 경쟁사 분석 자료 정리 (10분)

```
참고자료/ 폴더에 경쟁사 3사 분석 파일을 만들어줘:
경쟁사A_분석.md, 경쟁사B_분석.md, 경쟁사C_분석.md

각 파일에 포함: 회사 개요, 주력 제품, 강점, 약점, 최근 동향

그 다음:
"3개 파일을 읽고 경쟁사_비교표.md를 만들어줘.
항목별 비교 표 + 우리의 차별화 전략 제안."
```

---

## 실습 4: 데이터 파일 변환 (10분)

```
데이터분석/ 폴더의 매출_샘플.csv를 읽고:
1. 마크다운 표로 변환한 매출_분석.md 생성
2. 핵심 인사이트 3줄 추가
3. 경영진 보고용 1페이지 요약본도 별도 생성
```

---

## 과제

### 제출물
1. 회의록 → 담당자별 할일 파일
2. 3주치 주간보고 → 월간 요약
3. 경쟁사 비교표 또는 데이터 분석 결과

---

## 강사 참고 사항
- "여러 파일을 한 번에 읽고 종합"하는 것이 Claude Code만의 강점
- 회의록 → 할일 추출은 실무에서 즉시 활용 가능
- 실제 회의록이 있으면 가져와서 실습하도록 유도 (기밀 주의)
