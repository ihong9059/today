## 도입: 두 가지 Claude (5분)

### 선생님 설명
> 여러분이 Day 1~4에서 만난 Claude는 **인터넷 창(브라우저)** 에서 대화하는 거였어요.
> 오늘 만날 **Claude Code**는 **내 컴퓨터에서 직접 파일을 만들어주는** Claude예요!

| claude.ai (브라우저) | Claude Code (터미널) |
|---------------------|---------------------|
| 인터넷 창에서 채팅 | 까만 화면(터미널)에서 대화 |
| 답변을 읽기만 함 | 파일을 진짜 만들어줌! |
| 복사-붙여넣기 필요 | 자동으로 저장됨 |

---

## 실습 1: Claude Code 만나기 (10분)

### 터미널 열기
- Windows: 시작 메뉴 → "터미널" 또는 "명령 프롬프트"
- Mac: Spotlight → "터미널"

### 첫 대화
```bash
claude
```

입력 후:
```
안녕! 나는 ○○초등학교 5학년 ○○○이야!
```

### 간단한 명령
```
바탕화면에 "안녕하세요.txt" 파일을 만들어줘.
내용은 "Claude Code 첫 체험 성공!" 으로!
```

→ **탐색기/Finder에서 바탕화면에 진짜 파일이 생겼는지 확인!**

## 실습 2: 자기소개 파일 만들기 (15분)

### 프롬프트
```
바탕화면에 "나의소개" 폴더를 만들고,
그 안에 "자기소개.md" 파일을 만들어줘.

내용:
# 나를 소개합니다!

- 이름: ○○○
- 학교: ○○초등학교 5학년 ○반
- 좋아하는 과목: 과학, 체육
- 좋아하는 음식: 치킨, 떡볶이
- 꿈: 게임 개발자
- 취미: 축구, 레고
- 좋아하는 동물: 강아지

## 나의 특기
(여기에 특기 3가지를 재미있게 써줘)

## 올해 목표
(여기에 목표 3가지를 써줘)
```

### 확인하기
```
"나의소개" 폴더에 뭐가 있는지 보여줘
```

### 수정하기
```
자기소개에 이모지를 추가해줘! 각 항목마다.
그리고 "내가 좋아하는 유튜버" 항목도 추가해줘.
```

## 실습 3: 친구 퀴즈 파일 만들기 (10분)

```
"나의소개" 폴더에 "친구퀴즈.md" 파일을 만들어줘.

내 자기소개를 바탕으로 나에 대한 퀴즈 5문제를 만들어줘.
4지선다로, 정답도 하단에 적어줘.

예:
Q1. ○○○이 좋아하는 과목은?
① 국어 ② 수학 ③ 과학 ④ 영어
정답: ③
```

---

## 실습 4: 시간표 파일 만들기 (5분)

```
"나의소개" 폴더에 "시간표.md" 파일도 만들어줘.

월~금 시간표를 표로 만들어줘.
1교시부터 6교시까지.
내가 알려줄게:

월: 국어, 수학, 과학, 체육, 음악, 미술
화: 수학, 국어, 사회, 영어, 도덕, 창체
수: 국어, 수학, 과학, 체육, 영어, 동아리
목: 수학, 국어, 사회, 음악, 실과, 창체
금: 국어, 수학, 영어, 과학, 체육, 자율
```

## 강사 참고 사항
- Claude Code 설치는 선생님이 사전에 완료 (학생이 직접 설치는 어려움)
- 계정도 교육용 공유 계정 사용 권장
- **"파일이 진짜 생겼다!"** 는 경험이 핵심 — 탐색기에서 확인하는 순간 환호
- 타이핑 어려운 학생은 선생님이 대신 입력하거나, 간단한 요청만
- md(마크다운) 파일은 메모장이나 VS Code로 열어서 보여주기
