# Day 7: 발표 자료 만들기 — "예쁜 포스터를 컴퓨터로!"

## 학습 목표
- Claude Code로 예쁜 HTML 포스터 만들기
- AI 이미지 생성 체험
- HTML → PDF 변환 (인쇄용)

---

## 실습 1: 탐구 보고서 포스터 제작 (20분)

Day 4에서 만든 탐구 주제를 포스터로!

### 프롬프트
```
Day 4에서 내가 탐구한 "공룡"을 주제로 발표 포스터를 HTML로 만들어줘.

구성:
1. 큰 제목: "공룡의 세계로 떠나자! 🦕"
2. 탐구 동기: 왜 궁금했는지 (2줄)
3. 알게 된 사실 5가지 (이모지 + 큰 글씨)
4. 가장 놀라운 사실 1가지 (특별 강조 박스)
5. 친구들에게 퀴즈 3문제
6. 이름 + 날짜

디자인:
- 배경: 연한 초록색
- 글씨: 크고 읽기 쉽게
- 이모지 많이!
- 둥근 모서리 카드 스타일
- A4 1장에 들어가게

파일명: 공룡포스터.html
```

### 브라우저에서 확인
```
이 파일을 브라우저에서 열어줘
```

### 수정 요청
```
배경색을 파란색으로 바꿔줘
```
```
글씨를 더 크게 해줘
```
```
반짝이는 효과를 제목에 넣어줘
```

## 실습 3: 다른 주제 포스터 (10분)

탐구 보고서 외에 다른 포스터도 만들어보기:

### 우리 반 소개 포스터
```
"5학년 1반을 소개합니다!" 포스터를 HTML로 만들어줘.

포함:
- 우리 반 인원 (28명)
- 담임 선생님 이름
- 우리 반 약속 3가지
- 이번 달 목표
- 반 구호
- 예쁜 디자인으로!
```

### 환경 캠페인 포스터
```
"지구를 지키자!" 환경 캠페인 포스터를 만들어줘.
- 실천 방법 5가지
- 큰 글씨 + 이모지
- 밝고 초록색 테마
```

## 실습 4: PDF로 변환 + 인쇄 (5분)

```
공룡포스터.html을 PDF로 만들어줘
```

또는 브라우저에서:
1. 포스터 HTML 열기
2. Ctrl+P (인쇄)
3. "PDF로 저장" 선택

→ **실제로 인쇄해서 교실에 붙이기!**

## 과제

### 제출물: 나만의 포스터 (HTML + PDF)

1. 탐구 보고서 포스터 또는 다른 주제 포스터
2. PDF 파일
3. (보너스) 교실에 붙일 포스터 인쇄물

---

## 강사 참고 사항
- "내가 만든 포스터가 진짜 인쇄된다!"는 성취감이 큼
- HTML 코드를 보여줄 필요는 없음 — 결과물에 집중
- 색상/폰트 수정 요청을 자유롭게 하도록 유도
- 우수 포스터는 교실 게시판에 부착 → 동기 부여
- 프린터가 없으면 PDF 파일 제출로 대체
