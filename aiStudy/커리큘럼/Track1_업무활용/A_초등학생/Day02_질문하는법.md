## 실습 1: 나쁜 질문 vs 좋은 질문 비교 (15분)

### 직접 해보기 — 주제: 우주

**나쁜 질문** (직접 입력해보세요):
```
우주 알려줘
```

**좋은 질문** (직접 입력해보세요):
```
너는 우주비행사야.
초등학교 5학년인 나에게 우주에서 가장 신기한 사실 5가지를 알려줘.
각 사실마다 "와!" 하고 놀랄 수 있는 비유를 포함해줘.
예를 들어 "목성은 지구가 1,300개 들어갈 만큼 커요!"처럼.
```

### 비교 정리
| | 나쁜 질문 | 좋은 질문 |
|------|---------|---------|
| 누구한테 물어봤나 | 그냥 | 우주비행사 |
| 얼마나 자세한가 | 막연함 | 5가지, 비유 포함 |
| 나한테 맞는가 | 모름 | 초등학생 수준 |
| 답변이 재미있는가 | | |

## 실습 2: "역할 부여" 마법 (10분)

같은 질문에 역할만 바꿔보기:

### 주제: "비가 왜 와?"

**과학자에게**:
```
너는 기상학 과학자야.
비가 왜 오는지 과학적으로 설명해줘.
초등학생이 이해할 수 있게, 그림 없이 글로만.
```

**동화 작가에게**:
```
너는 동화 작가야.
비가 왜 오는지 재미있는 동화로 만들어줘.
구름 나라 친구들이 등장하는 이야기로!
```

**요리사에게**:
```
너는 요리사야.
비 오는 날 먹으면 좋은 간식 3가지를 추천해줘.
초등학생이 부모님과 함께 만들 수 있는 것으로!
```

### 관찰
- 같은 "비" 주제인데 답변이 어떻게 달라지나요?
- 어떤 역할의 답변이 가장 재미있었나요?

## 강사 참고 사항
- "질문을 잘 하는 것 = 프롬프트 엔지니어링"이라는 어려운 말은 쓰지 않아도 됨
- 학생들이 서로 질문을 공유하고 "누구 질문이 가장 좋았나?" 투표하면 재미있음
- 역할 부여가 마법처럼 느껴지는 순간이 핵심 — "와, 같은 질문인데 답이 달라!"
- 타이핑 느린 학생은 짧은 질문부터 시작
