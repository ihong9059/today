## 프로젝트: 나만의 미니북 (4페이지 PDF)

### 주제 선택 (택 1)

| 주제 | 설명 |
|------|------|
| **나만의 탐구북** | 궁금한 주제 조사 → 보고서 형태 |
| **나만의 동화책** | Day 3 동화를 확장 → 그림책 형태 |
| **나만의 퀴즈북** | Day 6 퀴즈를 확장 → 퀴즈 책 형태 |
| **우리 반 소개북** | 반 소개, 친구들, 선생님, 약속 |
| **나의 꿈 소개북** | 장래희망, 준비 과정, 롤모델 |

---

## 진행 순서 (50분)

### Step 1: 주제 선택 + 구성 기획 (5분)

Claude에게:
```
나는 "○○" 주제로 미니북을 만들 거야.
4페이지 구성으로 각 페이지에 뭘 넣으면 좋을지 제안해줘.
초등학생이 만든 미니북이야.
```

### Step 2: 내용 작성 (10분)

Claude에게 각 페이지 내용 요청:
```
1페이지: 표지 (제목 + 지은이 + 예쁜 디자인)
2페이지: (내용)
3페이지: (내용)
4페이지: 마무리 (느낀 점 + 퀴즈 또는 한마디)
```

### Step 3: HTML 제작 (15분)

Claude Code에서:
```
나의 미니북을 예쁜 HTML로 만들어줘.

4페이지 구성:
[Step 2에서 만든 내용 입력]

디자인:
- 각 페이지 구분 (인쇄 시 페이지 나뉘게)
- 밝고 귀여운 색상
- 큰 글씨
- 이모지 많이
- A4 인쇄용

파일명: 나의미니북.html
```

### Step 4: 수정 + 꾸미기 (10분)

```
2페이지 배경색을 하늘색으로 바꿔줘
```
```
제목에 반짝이는 효과 넣어줘
```
```
마지막 페이지에 "THE END ⭐" 넣어줘
```

### Step 5: PDF 변환 + 발표 (10분)

```
이 HTML을 PDF로 만들어줘
```

**발표**: 각자 미니북을 화면에 보여주면서 소개 (1인 1~2분)
- "내 미니북의 제목은 ○○이고..."
- "AI가 도와준 부분은 ○○이고, 내가 직접 한 부분은 ○○입니다"

## 강사 참고 사항
- 50분 안에 완성이 어려우면 Step 2까지 사전 준비
- 미니북을 **실제로 인쇄**해서 가져가게 하면 성취감 극대화
- 우수작은 교실 게시판 또는 학교 도서관에 전시
- 발표 시간은 짧게 (1인 1분) — 모든 학생이 발표할 수 있도록
- 수료증도 Claude Code로 HTML → PDF 만들면 특별한 경험
- **"10일 전에는 AI가 뭔지도 몰랐는데, 이제 미니북을 만들 수 있다!"** 라는 성장 강조
