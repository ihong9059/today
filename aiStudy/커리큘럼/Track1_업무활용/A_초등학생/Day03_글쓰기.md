# Day 3: 글쓰기 — "AI와 함께 동화를 쓰자!"

## 학습 목표
- Claude와 함께 동화/이야기를 만드는 체험
- 독후감, 편지 쓰기에 AI 활용
- "AI가 쓴 글 vs 내가 쓴 글"의 차이 이해

---

## 실습 1: 나만의 동화 만들기 (15분)

### Step 1: 주인공 정하기
```
나는 동화를 쓰고 싶어!
주인공은 마법을 쓸 수 있는 고양이 "달빛이"야.
달빛이는 밤에만 마법을 쓸 수 있어.
이 주인공으로 재미있는 동화를 써줘.

조건:
- 초등학생이 읽을 수 있는 쉬운 말로
- 3장으로 나눠줘 (시작, 중간, 끝)
- 각 장마다 제목 붙여줘
- 교훈이 담긴 이야기로
- 길이: 한 장에 5~7문장
```

### Step 2: 내가 수정하기
```
2장에서 달빛이가 친구를 만나는 장면을 추가해줘.
친구 이름은 "별이"로 해줘.
```
```
결말을 해피엔딩으로 바꿔줘.
```
```
"달빛이가 무서워하는 장면"을 넣어서 긴장감을 줘!
```

### Step 3: 제목 정하기
```
이 동화에 어울리는 제목을 5개 추천해줘.
재미있고 궁금해지는 제목으로!
```

## 실습 2: 독후감 쓰기 도우미 (10분)

### 프롬프트 (읽은 책에 맞게 수정)
```
나는 "어린 왕자"를 읽었어.
독후감을 쓰는 것을 도와줘.

나한테 질문을 해줘:
1. 가장 기억에 남는 장면은?
2. 왜 그 장면이 기억에 남았어?
3. 주인공에게 하고 싶은 말은?
4. 이 책에서 배운 것은?

내가 답하면, 그걸로 독후감 초안을 만들어줘.
```

### 학생이 답변하면:
```
내 답변:
1. 여우와 친구가 되는 장면
2. 진짜 친구가 되려면 시간이 걸린다는 게 신기했어
3. 외롭지 않았으면 좋겠어
4. 눈에 보이지 않는 것이 중요하다

이걸로 독후감을 써줘. 300자 정도. 내가 쓴 것처럼 자연스럽게.
```

### 핵심 포인트
> AI가 독후감을 대신 써주는 게 아니라, **내 생각을 정리하는 것을 도와주는 거예요!**
> 답변은 반드시 내가 하고, AI는 그걸 글로 다듬어주는 역할.

## 실습 3: 편지 쓰기 (10분)

### 감사 편지
```
우리 할머니에게 감사 편지를 쓰고 싶어.
할머니는 매주 맛있는 떡볶이를 만들어주셔.
지난 주말에 놀이공원에도 데려가주셨어.

따뜻하고 사랑이 느껴지는 편지를 써줘.
초등학생이 쓴 것처럼 자연스럽게.
200자 정도.
```

### 수정 요청
```
"할머니 건강하세요"도 넣어줘.
마지막에 "사랑해요 할머니♡"로 끝내줘.
```

### 다른 편지 아이디어
- 친구에게 사과 편지
- 선생님께 감사 편지
- 미래의 나에게 보내는 편지

## 실습 4: AI 글 vs 내 글 비교 (10분)

### 같은 주제로 둘 다 쓰기
주제: "내가 좋아하는 계절"

1. **내가 직접 쓰기** (3분, 5문장)
2. **Claude에게 부탁하기**: "초등학생이 '좋아하는 계절'에 대해 쓴 것처럼 5문장 써줘"
3. **비교하기**

| | 내 글 | AI 글 |
|--|------|------|
| 진짜 내 경험이 있나? | | |
| 감정이 느껴지나? | | |
| 자연스러운가? | | |
| 더 좋은 글은? | | |

### 핵심 메시지
> AI는 글을 잘 쓰지만, **나만의 경험과 감정**은 넣을 수 없어요.
> 최고의 글 = **내 이야기** + **AI의 표현력**

## 강사 참고 사항
- 동화 쓰기가 가장 흥미도 높은 실습 — 충분한 시간 확보
- "AI가 써준 동화를 그대로 내는 것"이 아니라, "내가 아이디어를 주고 AI가 도와주는 것"을 강조
- 독후감은 반드시 학생이 먼저 생각을 답한 후 AI가 정리하도록 순서 지키기
- 학생들의 동화를 서로 읽어주는 시간이 있으면 매우 좋음
- 그림을 그릴 수 있는 학생은 각 장에 삽화 그리기 활동 추가 가능
