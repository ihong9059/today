# Day 4: 탐구하기 — "궁금한 건 AI에게 물어보자!"

## 학습 목표
- AI로 궁금한 주제를 깊이 탐구하는 방법
- 사진을 AI에게 보여주고 분석받기 (멀티모달)
- NotebookLM으로 오디오 요약 체험
- 탐구 보고서 작성

---

## 실습 1: 나만의 탐구 주제 조사 (15분)

### Step 1: 주제 정하기
궁금한 것 중 하나를 골라요:
- 공룡 / 우주 / 바다 생물 / 로봇 / 날씨 / 화산 / 동물 / 곤충 / 인체 / 발명

### Step 2: AI 탐구 인터뷰
```
너는 [주제] 전문 박사야.
초등학생 기자가 인터뷰하는 거야.
내가 질문하면 쉽고 재미있게 답해줘.
비유와 예시를 많이 써줘!
```

### 질문 예시 (공룡을 골랐다면):
```
1. 가장 큰 공룡은 뭐야? 학교 운동장이랑 비교하면 얼마나 커?
2. 공룡은 뭘 먹었어? 편의점에 있는 것으로 비유하면?
3. 공룡이 지금 살아있다면 어떻게 될까?
4. 공룡 중에 가장 똑똑한 공룡은?
5. 공룡이 멸종한 진짜 이유는?
```

### Step 3: 탐구 결과 정리 요청
```
위에서 알려준 내용을 "탐구 보고서" 형식으로 정리해줘.

형식:
- 제목: "○○에 대해 알아보자!"
- 탐구 동기: 왜 이게 궁금했는지
- 알게 된 사실 5가지 (번호 매기기)
- 가장 놀라운 사실 1가지
- 더 알고 싶은 것

초등학생이 읽기 쉬운 말로 써줘.
```

## 실습 2: 사진으로 AI에게 물어보기 — 멀티모달 (10분)

### 실습 2-1: 곤충/식물 사진
학교 운동장이나 화단에서 곤충/식물 사진을 찍어서 Claude에 업로드:
```
이 사진에 있는 곤충(또는 식물)이 뭐야?
이름, 특징, 재미있는 사실 3가지를 알려줘.
위험한 건지 아닌지도 알려줘!
```

### 실습 2-2: 그림/작품 분석
친구의 그림이나 미술 작품을 촬영해서 업로드:
```
이 그림을 보고 느낀 점을 말해줘.
잘한 점 3가지도 알려줘.
미술 선생님처럼 칭찬해줘!
```

### 실습 2-3: 교과서 사진
교과서의 어려운 부분을 촬영:
```
이 페이지 내용을 초등학생이 이해할 수 있게 쉽게 설명해줘.
```

## 실습 3: NotebookLM 체험 (10분)

### 사용 방법
1. notebooklm.google.com 접속 (선생님 도움)
2. 탐구 주제 관련 글 복사 → 붙여넣기
3. "이 내용을 초등학생에게 설명해줘" 질문
4. **"오디오 요약"** 버튼 → 팟캐스트 형태로 듣기!

### 체험 포인트
- "내가 조사한 내용이 라디오 방송처럼 나온다!"
- 집에서 공부할 때 오디오로 들을 수 있음

## 강사 참고 사항
- 탐구 주제를 학생이 직접 고르게 하면 몰입도가 높음
- 사진 분석(멀티모달)은 "와!" 하는 반응이 큼 — 운동장에서 사진 찍기 활동 추천
- NotebookLM은 선생님이 화면 공유로 시연하고, 학생은 오디오를 함께 들으면 됨
- 탐구 보고서를 교실에 게시하거나 발표하면 효과적
