# Day 1: AI 첫 만남 — "Claude야, 너는 누구야?"

## 학습 목표
- AI가 무엇인지 쉽게 이해하기
- Claude와 첫 대화 체험
- AI가 잘하는 것과 못하는 것 구분

## 준비물
- 노트북 또는 태블릿 (claude.ai 접속)
- (선생님/부모님이 Claude 계정 미리 준비)

---

## 도입: AI란 뭘까? (10분)

### 선생님 설명
> AI는 사람이 만든 "매우 똑똑한 대화 친구"예요.
> 책을 아주아주 많이 읽어서 여러 가지를 알고 있어요.
> 하지만 진짜로 생각하거나 느끼는 건 아니에요.
> 우리가 질문하면 답을 찾아주는 "도우미"예요!

### 퀴즈: AI일까, 아닐까?
| 이것은 AI일까요? | 정답 |
|-----------------|:----:|
| 시리(Siri)에게 날씨를 물어보기 | ○ |
| 계산기로 덧셈하기 | ✕ |
| 유튜브가 영상을 추천해주는 것 | ○ |
| 전자레인지가 음식을 데우는 것 | ✕ |
| Claude에게 동화를 써달라고 하기 | ○ |
| 구글에서 검색하기 | △ (AI가 포함되어 있어요) |

## 실습 1: Claude와 첫 대화 (10분)

### 자기소개하기
```
안녕! 나는 ○○초등학교 5학년 ○○○이야.
나는 축구를 좋아하고, 좋아하는 과목은 과학이야.
너는 누구야? 자기소개 해줘!
```

### 이어서 질문하기
```
내가 좋아하는 것들을 기억하고 있어?
```
```
우리 반에서 인기 있는 놀이가 뭔지 알아?
```

### 관찰 포인트
- Claude가 자기소개를 어떻게 하는지 보기
- "기억하고 있어?"라고 물었을 때 어떻게 답하는지
- "모른다"고 솔직하게 말하는지

## 실습 2: AI에게 재미있는 질문 (10분)

하나씩 질문해보고, 답변을 관찰하세요:

### 쉬운 질문
```
공룡이 왜 멸종했어?
```
```
달은 왜 모양이 바뀌어?
```

### 재미있는 질문
```
만약에 개미가 사람만큼 크다면 어떻게 될까?
```
```
100년 후에 학교는 어떤 모습일까?
```

### 엉뚱한 질문
```
피자와 치킨이 싸우면 누가 이겨?
```
```
세종대왕이 스마트폰을 가지고 있었다면?
```

### 관찰 포인트
- 진짜 질문에는 잘 답하는가?
- 상상 질문에도 재미있게 답하는가?
- 엉뚱한 질문에는 어떻게 반응하는가?

---

## 실습 3: AI가 잘하는 것 vs 못하는 것 (10분)

### AI에게 물어보기
```
너는 뭘 잘해? 그리고 뭘 못해?
초등학생도 이해할 수 있게 설명해줘.
```

### 함께 정리하기

| AI가 잘하는 것 | AI가 못하는 것 |
|:-------------:|:-------------:|
| 글 쓰기 | 진짜 감정 느끼기 |
| 질문에 답하기 | 냄새 맡기, 맛 보기 |
| 이야기 만들기 | 축구 하기 |
| 번역하기 | 진짜 친구가 되어주기 |
| 계산하기 | 새로운 것 발명하기 |

### 핵심 메시지
> AI는 **도구**예요. 연필이 글을 대신 써주지 않듯이,
> AI도 생각을 대신 해주지 않아요.
> **내가 질문을 잘 해야** AI가 좋은 답을 줘요!

## 강사 참고 사항
- 계정은 선생님이 미리 준비 (학생 개별 가입은 어려움)
- 타이핑이 느린 학생은 선생님이 대신 입력하거나, 음성입력 활용
- "AI가 뭐든 다 해준다"는 인식을 막기 위해 "못하는 것"을 반드시 강조
- 엉뚱한 질문을 많이 하도록 유도 — 호기심이 학습의 시작
- 학생들이 서로의 질문과 답변을 공유하면 흥미가 배가됨
