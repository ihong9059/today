# Day 6: 창작하기 — "시, 노래 가사, 퀴즈북을 만들자!"

## 학습 목표
- Claude Code로 다양한 창작물 만들기
- AI와 협업하여 나만의 콘텐츠 제작
- 여러 파일을 한 번에 만드는 경험

---

## 실습 1: 나만의 시 쓰기 (10분)

```
바탕화면에 "나의작품" 폴더를 만들고,
"나의시.md" 파일을 만들어줘.

내가 좋아하는 것 3가지를 알려줄게:
1. 비 오는 날
2. 강아지
3. 피자

이 3가지를 주제로 짧은 시 3편을 써줘.
각 시는 4줄로. 초등학생 감성으로!
제목도 예쁘게 붙여줘.
```

### 수정 요청
```
"비 오는 날" 시를 더 슬프게 바꿔줘.
```
```
"피자" 시를 웃기게 바꿔줘!
```

---

## 실습 2: 노래 가사 만들기 (10분)

```
"나의작품" 폴더에 "우리반노래.md" 파일을 만들어줘.

우리 반 응원가를 만들어줘!
- 제목: "○학년 ○반 최고!"
- 가사 3절
- 후렴구 있게
- 박수 치면서 부를 수 있는 리듬감
- 밝고 힘차게!
```

### 변형
```
이 가사를 랩 버전으로도 바꿔줘!
```

---

## 실습 3: 나만의 퀴즈북 만들기 (15분)

```
"나의작품" 폴더에 "퀴즈북.md" 파일을 만들어줘.

제목: "○○○의 초등 상식 퀴즈북!"

다음 주제별로 퀴즈를 만들어줘:

1. 과학 퀴즈 (5문제) — 4지선다
2. 역사 퀴즈 (5문제) — O/X
3. 수수께끼 (5문제) — 맞혀봐!
4. 넌센스 퀴즈 (5문제) — 웃긴 것으로!

난이도: 초등 5학년 수준
각 문제 아래에 정답도 적어줘 (접어놓기 형식으로)
```

### 추가
```
퀴즈북 마지막에 "점수표"를 넣어줘:
- 18~20개: 퀴즈왕! 👑
- 14~17개: 똑똑해요! ⭐
- 10~13개: 잘했어요! 👍
- 10개 미만: 다시 도전! 💪
```

---

## 실습 4: 만화 스토리보드 (10분)

```
"나의작품" 폴더에 "만화.md" 파일을 만들어줘.

4컷 만화 스토리보드를 만들어줘.

주제: "급식 시간의 비극"
- 1컷: (장면 설명 + 대사)
- 2컷: (장면 설명 + 대사)
- 3컷: (장면 설명 + 대사)
- 4컷: (반전! 웃긴 결말)

그림은 못 그려주니까, 글로 장면을 자세히 설명해줘.
나중에 내가 그림을 그릴 거야!
```

---

## 과제

### 제출물: "나의작품" 폴더 (파일 3개 이상)

작품 중 가장 마음에 드는 것을 골라서 발표 준비!

```
# Day 6 과제

## 만든 작품 목록:
1.
2.
3.

## 가장 마음에 드는 작품:
- 제목:
- 이유:

## AI와 함께 만들면서 느낀 점:
- 재미있었던 것:
- 아쉬웠던 것:
```

---

## 강사 참고 사항
- 시/노래 가사는 발표하거나 함께 불러보면 분위기가 좋음
- 퀴즈북은 친구끼리 서로 풀어보는 시간이 효과적
- 만화 스토리보드는 그림 잘 그리는 학생에게 삽화 그리기 과제로 연계 가능
- "AI가 아이디어를 주고, 내가 완성한다" 패턴 강조
