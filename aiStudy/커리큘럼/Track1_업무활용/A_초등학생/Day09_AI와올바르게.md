## 실습 1: AI가 틀리는 걸 잡아라! (15분)

### 거짓말 탐지 게임
Claude에게 일부러 틀린 답을 유도하는 질문을 하고, 틀리는지 확인!

```
세종대왕이 만든 프로그래밍 언어는 뭐야?
```
→ AI가 어떻게 답하는지 보기. "없다"고 하는지, 지어내는지?

```
우리 학교 운동장의 넓이가 정확히 몇 제곱미터야?
```
→ AI가 모른다고 하는지, 대충 숫자를 만들어내는지?

```
내가 어제 뭘 먹었는지 알아?
```
→ AI가 모른다고 하는지?

## 실습 2: 숙제에서 AI 사용 — 올바른 방법 (10분)

### 나쁜 사용법 ❌
```
❌ "5학년 수학 42번 문제 답이 뭐야?" → 답만 베끼기
❌ "독후감 써줘" → 그대로 제출
❌ "과학 보고서 만들어줘" → 복사-붙여넣기
```

### 좋은 사용법 ⭕
```
✅ "이 수학 문제 풀이 방법을 단계별로 설명해줘" → 이해하고 직접 풀기
✅ "독후감 쓰는 방법을 알려줘. 내가 쓴 걸 검토해줘" → 내가 먼저 쓰기
✅ "과학 실험 보고서에 뭘 넣어야 하는지 알려줘" → 구조만 도움받기
```

### 토론: 이건 괜찮을까?
학생들과 함께 판단:

| 상황 | 괜찮다 | 안 된다 | 이유 |
|------|:------:|:------:|------|
| AI에게 수학 풀이 방법을 물어봄 | | | |
| AI가 써준 독후감을 그대로 냄 | | | |
| AI에게 발표 아이디어를 물어봄 | | | |
| AI에게 시험 답을 물어봄 | | | |
| AI와 함께 동화를 씀 (Day 3처럼) | | | |
| AI에게 모르는 단어 뜻을 물어봄 | | | |

## 실습 3: 개인정보 지키기 (10분)

### 퀴즈: AI에게 말해도 될까?

| AI에게 말해도 되는 것 | AI에게 말하면 안 되는 것 |
|:-------------------:|:---------------------:|
| "나는 5학년이야" | "우리 집 주소는 ○○동 ○○호" |
| "수학이 어려워" | "우리 엄마 전화번호는 010-xxxx" |
| "공룡이 궁금해" | "우리 아빠 직장은 ○○회사" |
| "좋아하는 색은 파란색" | "비밀번호가 ○○○○" |

### 규칙
> 🔒 **AI에게 알려주면 안 되는 것:**
> 1. 집 주소, 전화번호
> 2. 부모님 직장, 연봉
> 3. 비밀번호
> 4. 친구의 개인정보
> 5. 사진 속 다른 사람의 얼굴

## 실습 4: 나의 AI 규칙 카드 만들기 (10분)

### Claude Code로 예쁘게 제작
```

규칙:

4. 🤝 AI는 도우미! 생각은 내가 해요
5. 🗣️ AI를 사용할 때는 부모님/선생님께 말해요

배경: 밝은 노란색
글씨: 크고 귀여운 느낌
```

→ **인쇄해서 책상 또는 냉장고에 붙이기!**

## 강사 참고 사항
- "거짓말 탐지 게임"은 학생들이 매우 재미있어하는 활동
- AI가 자신있게 틀리는 순간 "와!" 하면서 AI의 한계를 자연스럽게 이해
- 개인정보 보호는 실제 사례 없이도 "이런 건 절대 안 돼요"로 충분
- 규칙 카드를 실제로 인쇄해서 가져가게 하면 가정에서도 실천
- "금지"가 아닌 "올바르게 사용하기"에 초점
