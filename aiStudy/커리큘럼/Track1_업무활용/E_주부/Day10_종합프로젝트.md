# Day 10: 종합 프로젝트 — "나를 소개하는 포트폴리오 완성"

## 학습 목표
- 10일간 배운 모든 도구를 종합 활용
- 기획 → 작성 → 디자인 → PDF까지 전 과정 수행
- 자기계발 또는 재취업에 활용할 수 있는 결과물 완성

---

## 프로젝트 선택 (택 1)

### 옵션 A: 재취업 포트폴리오 (재취업 준비 중인 분)

```
재취업용 자기소개 포트폴리오를 HTML로 만들어줘.

구성 (4페이지):
1. 표지 + 인적사항
2. 경력 요약 + 보유 능력
   - 이전 직장 경력 (9년 사무직)
   - 육아 중 습득 능력 (일정관리, 예산관리, 멀티태스킹)
   - AI 도구 활용 능력 (Claude, Claude Code, Notion)
3. 자기소개서 (500자)
4. 희망 직종 + 강점 어필

디자인: 깔끔하고 전문적인 느낌
```

### 옵션 B: 우리 가족 생활 매뉴얼 (가정 관리 중심)

```
우리 가족 생활 매뉴얼을 HTML로 만들어줘.

구성 (6페이지):
1. 표지 (가족 소개)
2. 주간 식단 + 장보기 시스템
3. 월간 가계 관리
4. 아이들 교육/일정 관리
5. 집안일 루틴
6. 긴급 연락처 + 병원/약국 목록

디자인: 따뜻한 파스텔 톤, 이모지 활용
```

### 옵션 C: 취미/부업 소개 페이지 (자기계발 중심)

```
나의 취미/부업 소개 페이지를 HTML로 만들어줘.

구성:
1. 자기소개 (관심사, 특기)
2. 활동 기록 (블로그, 핸드메이드, 베이킹 등)
3. 포트폴리오 (작품/활동 사진 설명)
4. 연락처/SNS

디자인: 감성적이고 예쁜 스타일
```

---

## 진행 순서 (50분)

### Step 1: 기획 — Claude로 구조 설계 (5분)
선택한 옵션에 맞춰 Claude에게 구조 상담

### Step 2: 내용 작성 — Claude Code로 HTML 생성 (20분)
Claude Code에서 HTML 파일 생성 + 내용 채우기

### Step 3: 수정 + 보강 (10분)
- "색상을 바꿔줘"
- "이 부분을 더 자세하게"
- "사진 설명을 추가해줘"

### Step 4: PDF 변환 (5분)
```
이 HTML을 PDF로 변환해줘
```

### Step 5: 발표 (10분)
- 각자 결과물 공유 (1인 2분)
- "10일 전의 나 vs 지금의 나" 비교
- 동료 피드백

## 최종 과제

### 제출물
1. **선택한 프로젝트 PDF** (4~6페이지)
2. **10일간 과제 포트폴리오** (Day 1~9 결과물 모음)
3. **소감문** (200자 이상)
   - AI가 일상생활에 어떤 변화를 줄 수 있는가?
   - 앞으로 어떤 영역에 Claude를 쓸 것인가?
   - 가족에게 AI를 어떻게 소개할 것인가?
   - Track 2(프로그래밍)에 관심이 있는가?

## 강사 참고 사항
- 옵션 A(재취업)를 선택한 분에게는 실제 취업 사이트 등록까지 안내 가능
- 옵션 B(가족 매뉴얼)는 "가족에게 자랑할 수 있는 결과물"로 동기 부여
- 옵션 C(취미/부업)는 부업 관심 있는 분에게 SNS/블로그 연결 안내
- **"10일 만에 이런 걸 만들 수 있다"**는 성취감이 핵심
- Track 2 안내: "Claude Code를 더 깊이 배우면 블로그, 쇼핑몰도 직접 만들 수 있습니다"
