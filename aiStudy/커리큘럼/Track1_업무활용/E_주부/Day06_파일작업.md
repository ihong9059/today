# Day 6: Claude Code 파일 작업 — "레시피북, 장보기 목록 자동 생성"

## 학습 목표
- Claude Code로 여러 파일을 한 번에 생성/수정
- 식단 → 장보기 목록 자동 연동
- 가족 레시피북 제작

---

## 실습 1: 식단에서 장보기 목록 자동 생성 (10분)

```
이번주_식단표.md를 읽고,
필요한 재료를 장보기_목록.md로 정리해줘.

형식:
- 카테고리별 분류 (채소, 고기, 유제품, 양념, 기타)
- 수량/중량 표시
- 냉장고에 이미 있을 법한 기본 양념(소금, 설탕, 간장 등)은 제외
- 예상 가격도 표시
- 하단에 총 예상 금액
```

---

## 실습 2: 우리 가족 레시피북 만들기 (20분)

```
우리가족_레시피_모음.md에 다음 레시피를 추가해줘:

1. 아이들이 좋아하는 메뉴 5가지
2. 30분 이내 원팟 요리 3가지
3. 밀프렙 가능한 반찬 5가지

각 레시피 포함:
- 재료 (4인분)
- 조리 시간
- 난이도 (★~★★★)
- 조리 순서 (번호 매기기)
- 꿀팁 1개
- 아이 참여 가능 단계 표시 (해당 시)
```

### 특정 레시피 추가
```
레시피 모음에 추가해줘:
"엄마표 치킨너겟" — 냉동 닭가슴살로 만드는 건강한 버전.
에어프라이어 사용, 20분 이내.
```

---

## 실습 3: 집안일 체크리스트 (10분)

```
집안일_체크리스트.md를 요일별로 작성해줘.

월: 빨래 + 화장실 청소
화: 거실 청소기 + 먼지 닦기
수: 냉장고 정리 + 식료품 체크
목: 아이들 방 정리 + 침구 세탁
금: 주방 대청소 + 장보기
토: 가족 함께 대청소
일: 휴식 (최소한만)

각 항목에 예상 소요 시간과 체크박스를 넣어줘.
```

---

## 실습 4: 아이 학습 관리 (10분)

```
큰아이_학교일정.md를 이번 달 일정으로 업데이트해줘.

포함:
- 시험 일정 (중간고사 5/12~14)
- 현장학습 (5/15)
- 방과후 수업 시간표 (월: 축구, 수: 미술, 금: 영어)
- 숙제 체크리스트 (주간)
- 준비물 목록
```

---

## 과제

### 제출물
1. 장보기 목록 (식단표에서 자동 생성)
2. 레시피 3개 이상 추가된 레시피북
3. 집안일 체크리스트 또는 아이 학습 관리 파일

---

## 강사 참고 사항
- "식단 → 장보기 자동 연동"이 가장 실용적이라 반응 좋음
- 레시피북은 계속 추가해나갈 수 있는 "살아있는 문서"로 소개
- 아이가 없는 분은 집안일/자기계발 쪽으로 대체
