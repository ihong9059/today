# Day 3: 문서 작성 — "가계부 양식, 감사 편지, 이력서를 Claude로"

## 학습 목표
- 생활에서 필요한 문서를 Claude로 빠르게 작성
- 초안 → 수정 → 완성 워크플로우 체험
- 톤/형식/분량 조절하는 방법

---

## 실습 1: 가계부 양식 만들기 (10분)

### 프롬프트
```
4인 가족(부부 + 아이 2명) 월간 가계부 양식을 만들어주세요.

항목:
- 고정비: 주거비, 보험, 통신비, 구독료
- 변동비: 식비, 외식, 교통, 생활용품, 의류
- 교육비: 학원, 교재, 체험학습
- 특별비: 경조사, 의료비, 기타
- 저축: 적금, 투자

포함:
- 월 예산 / 실 지출 / 차이 열
- 하단에 월간 요약 (총수입, 총지출, 잔액, 저축률)

표 형식, 마크다운으로 작성해주세요.
```

---

## 실습 2: 편지/감사 메시지 작성 (10분)

### 감사 편지
```
아이의 담임 선생님께 드리는 감사 편지를 작성해주세요.

상황:
- 5학년 아들이 학교 적응을 어려워했는데
- 선생님이 개별 상담과 격려를 해주셔서 자신감을 되찾음
- 학기 말에 감사 카드와 함께 드릴 편지

톤: 진심이 느껴지는, 정중하지만 따뜻한
분량: 200~300자
```

### 축하 메시지
```
친구에게 보낼 출산 축하 메시지를 3가지 버전으로 만들어주세요:
1. 카카오톡 메시지 (짧고 유쾌하게)
2. 축하 카드 문구 (정성스럽게)
3. 선물과 함께 보낼 편지 (따뜻하게)
```

---

## 실습 3: 재취업 이력서 초안 (15분)

### 프롬프트
```
전업주부 5년차의 재취업용 이력서 초안을 작성해주세요.

기본 정보:
- 이름: (본인)
- 나이: 38세
- 학력: OO대학교 경영학과 졸업 (2010)
- 경력: ABC 회사 총무팀 (2010~2019, 9년)
  - 문서 관리, 경비 처리, 일정 관리, 행사 기획
- 경력 공백: 2019~2024 (육아)

강조할 점:
- 9년 사무 경력의 문서/행정 능력
- 육아 중 습득한 능력 (일정 관리, 예산 관리, 멀티태스킹)
- AI 도구 활용 능력 (이 교육과정 수료!)

원하는 직종: 사무직, 재택근무 가능한 곳
톤: 전문적이면서 성실한 인상
```

### 수정 요청 연습
- "경력 공백 기간을 긍정적으로 표현해줘"
- "자기소개서도 500자로 작성해줘"
- "이력서를 영문으로도 만들어줘"

## 실습 4: 중고 거래 글 작성 (5분)

```
당근마켓에 올릴 중고 유모차 판매 글을 작성해주세요.

제품: 스토케 익스플로리 V6
구매 시기: 2023년 3월
상태: 양호 (사용감 있으나 기능 이상 없음)
구성: 본체 + 시트 + 바구니 + 레인커버
구매가: 150만원
판매가: 45만원

매력적이고 신뢰감 주는 글로 작성해주세요.
주의사항이나 사용 후기도 포함해주세요.
```

---

## 과제

### 제출물: 문서 3종 완성본

1. **가계부 양식** (자기 가정에 맞게 수정)
2. **편지 또는 메시지** 1건 (감사/축하/안부 등)
3. **이력서 초안** 또는 **중고 거래 글** 1건

각 문서에 사용한 프롬프트와 수정 과정을 함께 제출

---

## 강사 참고 사항
- 이력서 실습은 재취업에 관심 있는 분에게 매우 실용적
- 재취업 의향이 없는 분은 중고 거래 글, 편지 등으로 대체
- "AI가 초안을 만들어주면 내가 다듬는다"는 워크플로우 강조
