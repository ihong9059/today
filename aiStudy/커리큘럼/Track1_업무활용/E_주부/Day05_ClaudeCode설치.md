# Day 5: Claude Code 설치 — "생활 관리 폴더를 자동으로 만들자"

## 학습 목표
- Claude Code CLI 설치 및 첫 실행
- claude.ai(브라우저) vs Claude Code(터미널) 차이 이해
- Claude Code로 가족 생활 관리 폴더 자동 생성

## 준비물
- 노트북 (Windows/Mac)
- Claude Pro 계정
- Node.js 설치 (18+)

---

## 실습 1: 설치 (15분)

### Step 1: Node.js 설치 확인
```bash
node --version
```
없으면 nodejs.org에서 다운로드 → 설치

### Step 2: Claude Code 설치
```bash
npm install -g @anthropic-ai/claude-code
```

### Step 3: 첫 실행
```bash
claude
```
로그인 안내에 따라 Claude Pro 계정 연결

### Step 4: 첫 대화
```
안녕! 나는 두 아이를 키우는 주부야. 생활 관리를 도와줘!
```

---

## 실습 2: 브라우저 vs 터미널 차이 (5분)

| claude.ai (브라우저) | Claude Code (터미널) |
|---------------------|---------------------|
| 대화창에서 텍스트 주고받기 | 내 컴퓨터 파일을 직접 생성/수정 |
| 결과를 복사-붙여넣기 | 파일로 바로 저장 |
| 스마트폰에서도 사용 | PC에서 사용 (파일 작업) |

---

## 실습 3: 생활 관리 폴더 생성 (15분)

### 프롬프트
```
우리 가족 생활 관리 폴더를 만들어줘.

가족생활관리/
├── 가계부/
│   ├── 2026년_월별_가계부.md
│   └── 절약_목표.md
├── 식단/
│   ├── 이번주_식단표.md
│   └── 우리가족_레시피_모음.md
├── 아이들/
│   ├── 큰아이_학교일정.md
│   ├── 작은아이_유치원일정.md
│   └── 학원_스케줄.md
├── 살림/
│   ├── 장보기_목록.md
│   └── 집안일_체크리스트.md
└── 나의시간/
    ├── 읽고싶은책.md
    ├── 배우고싶은것.md
    └── 자기계발_계획.md

각 파일에 기본 양식을 넣어줘.
```

### 결과 확인
```
가족생활관리 폴더의 모든 파일을 보여줘
```

## 실습 4: 이번 주 식단표 작성 (10분)

```
식단 폴더의 이번주_식단표.md를 작성해줘.

조건:
- 월~금 5일
- 아침: 간단하게 (10분 이내)
- 점심: 혼자 먹는 간편식
- 저녁: 4인 가족 (아이 2명 포함, 30분 이내)
- 예산: 주간 식비 15만원 이내
- 아이들이 좋아하는 메뉴 위주
- 장보기 목록도 함께 생성

표 형식으로 만들어줘.
```

## 과제

### 제출물: 생활 관리 폴더 + 식단표

1. Claude Code로 가족 생활 관리 폴더 생성 (스크린샷)
2. 이번 주 식단표 완성
3. 폴더 중 하나를 자기 상황에 맞게 수정

---

## 강사 참고 사항
- Node.js 설치에서 막히는 분이 많음 — 사전 안내서 또는 1:1 도움
- "내 컴퓨터에 폴더가 진짜 생긴다!"는 경험이 핵심
- 탐색기/Finder에서 직접 확인시켜주기
- 식단표가 생활 밀착형이라 반응이 좋음
