## 실습 1: 나쁜 프롬프트 vs 좋은 프롬프트 (15분)

### 나쁜 프롬프트
```
저녁 뭐 해먹지?
```

### 보통 프롬프트
```
4인 가족 저녁 메뉴 추천해줘
```

### 좋은 프롬프트
```
당신은 가정 요리 전문가입니다.

4인 가족(부부 + 초등생 + 유치원생) 저녁 메뉴를 추천해주세요.

조건:
- 조리 시간: 30분 이내
- 재료비: 15,000원 이내
- 아이가 편식이 심해서 채소를 잘 안 먹음 → 채소를 숨길 수 있는 메뉴
- 남편은 매운 음식 선호
- 밥 + 국 + 반찬 2개 구성

각 메뉴의 재료, 조리 순서, 꿀팁을 포함해주세요.
```

## 실습 2: 생활 영역별 프롬프트 연습 (20분)

### 육아 프롬프트
```
당신은 아동 발달 전문가입니다.

7살(유치원) 아이가 동생이 태어난 후 갑자기 퇴행 행동을 보입니다.
(젖병 달라기, 아기 말투 사용, 떼쓰기 증가)

이 행동의 원인과 대처법을 알려주세요.
- 부모가 해야 하는 것 3가지
- 절대 하면 안 되는 것 3가지
- 전문가 상담이 필요한 신호
```

### 가계 관리 프롬프트
```
4인 가족 월 예산 350만원을 항목별로 배분해주세요.

고정비: 주거비 80만원, 보험 15만원, 통신비 10만원
나머지를 식비, 교육비, 교통비, 생활용품, 저축, 여유자금으로 분배해주세요.
각 항목에 절약 팁도 포함해주세요.
표 형식으로 정리해주세요.
```

### 자기계발 프롬프트
```
전업주부 5년차, 이전 직업: 일반사무직(엑셀, 문서작성)
나이: 38세, 학력: 대졸

재취업을 위해 지금 배울 수 있는 기술을 추천해주세요.
조건:
- 하루 1~2시간 투자 가능 (아이들 유치원/학교 가는 시간)
- 무료 또는 저렴한 교육
- 3~6개월 안에 성과가 보이는 것
- 재택근무 가능한 직종 우선

각 기술마다 학습 방법, 추천 사이트, 예상 수입을 알려주세요.
```

## 실습 3: 레시피 비교 (10분)

같은 요리를 **두 가지 버전**으로 요청:

### 버전 A: 간단 버전
```
초등학생 아이와 함께 만들 수 있는 쉬운 쿠키 레시피를 알려주세요.
30분 이내, 오븐 없이 가능한 것으로요.
```

### 버전 B: 상세 버전
```
같은 쿠키 레시피를 단계별 사진 설명 형식으로 다시 작성해주세요.
각 단계에서 아이에게 시킬 수 있는 역할도 표시해주세요.
실패하기 쉬운 포인트와 해결법도 포함해주세요.
```

## 과제

### 제출물: "나만의 생활 프롬프트 3개"

자기 생활에서 가장 필요한 영역 3가지를 골라 최적 프롬프트를 작성하세요:

```markdown
# 나만의 생활 프롬프트

## 프롬프트 1: [영역] (예: 주간 식단)
- 프롬프트: (전문)
- 이 프롬프트를 만든 이유:
- 결과 만족도 (1~5):

## 프롬프트 2: [영역]
- ...

## 프롬프트 3: [영역]
- ...
```

## 강사 참고 사항
- 요리/육아 예시가 공감대를 형성하기 좋음
- "프롬프트 = 잘 부탁하는 법"이라고 설명하면 이해가 빠름
- 서로의 프롬프트를 공유하는 시간이 매우 효과적
