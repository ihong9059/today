# Day 8: 반복 업무 자동화 — "주간 일정, Notion으로 스마트폰 연동"

## 학습 목표
- 반복되는 생활 양식을 템플릿화
- Notion 연동 — 스마트폰에서 가족 일정/장보기 확인
- 가족 공유 시스템 구축

---

## 실습 1: 주간 일정 템플릿 (10분)

```
매주 복사해서 쓸 수 있는 주간 가족 일정 템플릿을 만들어줘.

포함:
- 날짜 (월~일)
- 엄마 일정
- 큰아이 일정 (학교 + 학원 + 숙제)
- 작은아이 일정 (유치원 + 활동)
- 아빠 일정 (출퇴근, 특이사항)
- 식단 (아침/점심/저녁)
- 장보기 메모
- 기타 메모 (택배, 공과금, 병원 등)

파일명: 주간일정_템플릿.md
```

---

## 실습 2: Notion 가입 + 생활 관리 보드 (20분)

### Step 1: Notion 가입
1. notion.so 가입 (무료)
2. **스마트폰에 Notion 앱 설치** (핵심!)

### Step 2: 생활 관리 구조 만들기
Claude에게 구조 설계 요청:
```
주부용 Notion 생활관리 워크스페이스 구조를 설계해줘.

필요한 페이지:
1. 주간 식단표 (월~금, 아침/점심/저녁)
2. 장보기 목록 (체크박스, 카테고리별)
3. 가계부 (월별 표)
4. 아이들 일정 (학교/학원/숙제)
5. 할일 목록 (오늘/이번주/이번달)
6. 메모/아이디어

각 페이지의 속성과 뷰를 구체적으로 알려줘.
```

### Step 3: PC에서 작성 → 스마트폰에서 확인
1. PC에서 Notion에 이번 주 식단 입력
2. 스마트폰 앱에서 확인
3. 마트에서 장보기 목록 체크

### 핵심 가치
- **집에서 Claude Code로 작성** → **Notion에 복사** → **마트에서 스마트폰으로 확인**
- 냉장고 앞에서 식단 확인
- 마트에서 장보기 목록 체크
- 외출 중 가족 일정 확인

---

## 실습 3: 가족 공유 (10분)

### Notion 페이지 공유
- 남편에게 장보기 목록 공유 → "퇴근길에 사다줘" 링크 전송
- 아이들 일정 페이지를 가족 공유

### 카카오톡 활용
Claude에서 생성한 내용을 카카오톡으로 공유:
```
이번 주 식단표를 카카오톡에 보내기 좋은 형식으로 요약해줘.
이모지 포함, 5줄 이내로.
```

---

## 실습 4: 자동 생성 패턴 (5분)

매주 반복:
```
Claude Code에서:
"지난주 식단표를 참고해서 이번주 식단표를 새로 만들어줘.
지난주와 겹치지 않게, 예산은 15만원 이내로."
```

→ 매주 5분이면 식단 + 장보기 목록 완성!

## 과제

### 제출물
1. 주간 일정 템플릿 (Claude Code로 생성)
2. Notion 가입 + 페이지 1개 생성 (스마트폰 스크린샷)
3. 스마트폰에서 Notion 확인 스크린샷

---

## 강사 참고 사항
- Notion 스마트폰 연동이 "오늘의 하이라이트" — 실생활 변화를 느끼는 순간
- "마트에서 스마트폰으로 장보기 목록 체크"가 가장 공감 포인트
- 남편/가족과 공유하는 실습은 가정에서 바로 활용 가능
- Obsidian은 PC 전용, Notion은 스마트폰 연동이 핵심 차이
