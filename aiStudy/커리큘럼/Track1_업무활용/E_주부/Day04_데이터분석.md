## 실습 2: Claude 멀티모달 — 사진으로 질문하기 (10분)

### 실습 2-1: 냉장고 사진 → 레시피
냉장고 안을 촬영하여 Claude에 업로드:
```
냉장고 사진입니다.
보이는 재료로 만들 수 있는 저녁 메뉴 3가지를 추천해주세요.
조리 시간 30분 이내로요.
```

### 실습 2-2: 영수증 분석
마트 영수증을 촬영하여 업로드:
```
이 영수증 내용을 정리해주세요.
항목별로 분류하고, 총액을 확인해주세요.
불필요한 지출이 있으면 알려주세요.
```

### 실습 2-3: 제품 비교
관심 있는 제품 사진(가전, 가구 등) 업로드:
```
이 제품의 장단점을 분석해주세요.
비슷한 가격대의 대안도 추천해주세요.
```

## 실습 3: NotebookLM 체험 (10분)

### 사용 방법
1. notebooklm.google.com 접속
2. "새 노트북" 생성
3. 관심 있는 문서 업로드 (육아 가이드, 요리책 PDF 등)
4. 질문: "이 책의 핵심 내용 3가지는?"
5. "오디오 요약" 생성 → 집안일하면서 듣기!

### 활용 아이디어
- 육아서 업로드 → 핵심 정리 (책 전체를 읽을 시간이 없을 때)
- 보험 약관 업로드 → "우리 가족에게 필요한 보장은?"
- 학교 교육과정 안내 업로드 → "우리 아이에게 중요한 부분은?"

### Claude vs Perplexity 비교
| 항목 | Claude | Perplexity |
|------|--------|-----------|
| 강점 | 문서 작성, 분석, 조언 | 최신 정보 검색, 출처 제공 |
| 활용 | 가계부, 편지, 레시피 | 제품 비교, 학원 비교, 여행지 |

## 강사 참고 사항
- 실제 가계부 데이터는 민감할 수 있음 — 샘플 데이터로 대체 가능
- 냉장고 사진은 미리 준비하거나, 수업 중 스마트폰으로 촬영
- NotebookLM "오디오 요약"이 집안일하면서 들을 수 있다는 점에서 반응 좋음
- Perplexity는 "쇼핑/비교 검색에 특화"로 소개
