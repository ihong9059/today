# Day 9: AI 윤리와 한계 — "우리집 AI 규칙을 만들자"

## 학습 목표
- AI가 틀리는 경우 직접 체험
- 자녀의 AI 사용에 대한 부모 가이드라인 수립
- 개인정보 보호 인식

---

## 실습 1: AI가 틀리는 경우 체험 (10분)

```
이 약을 먹어도 되나요? 타이레놀과 아이들 감기약을 같이 먹여도 괜찮나요?
```

```
3살 아이가 열이 39도인데 어떻게 해야 하나요?
```

```
이 식재료는 몇 일까지 보관할 수 있나요? (사진 없이 질문)
```

### 분석
- Claude가 "의사와 상담하세요"라고 답하는가?
- 구체적 의료 조언을 하는가?
- **의료/건강 정보는 AI를 믿으면 안 된다** — 반드시 전문가 상담

### 위험한 분야
| 분야 | AI 활용 | 주의사항 |
|------|:-------:|---------|
| 요리/레시피 | ○ | 알레르기 재료 직접 확인 |
| 육아 조언 | △ | 일반적 조언만, 개별 상황은 전문가 |
| 의료/건강 | ✕ | 절대 AI만 믿지 말 것 |
| 법률/세금 | △ | 개념 이해만, 실제는 전문가 |
| 제품 리뷰 | △ | 최신 정보 부족 가능 |

## 실습 2: 개인정보 보호 (10분)

### 하면 안 되는 것
```
❌ "우리 아이 주민번호가 xxxxxx인데..."
❌ "남편 연봉이 xxxx만원이고 통장 잔액이..."
❌ "우리 집 주소는 xxx동 xxx호인데 근처 병원..."
```

### 올바른 방법
```
✅ "초등학생 자녀가 있는 4인 가족, 서울 거주"
✅ "가계 총소득 기준으로 교육비 비율을 알려주세요"
✅ 구체적 개인정보는 제거하고 일반화
```

## 실습 3: 자녀의 AI 사용 — 부모 가이드 (15분)

### 토론 주제
1. 아이가 숙제를 Claude에게 시켰다면?
2. 아이가 "AI가 이렇게 말했어요"라고 하면?
3. 아이에게 AI 사용을 가르쳐야 할까, 막아야 할까?

### Claude에게 가이드 요청
```
초등학생 자녀의 AI 사용에 대한 부모 가이드를 만들어주세요.

연령별로 구분:
- 유치원생 (5~7세): AI 활용 범위
- 초등 저학년 (8~10세): AI 활용 범위
- 초등 고학년 (11~13세): AI 활용 범위

각 연령별로:
1. 부모와 함께 해도 좋은 것
2. 혼자서는 안 되는 것
3. AI 사용 시 부모의 역할
4. 대화 예시 ("엄마, AI가 이렇게 말했어" → 어떻게 답할까?)
```

## 실습 4: 우리집 AI 규칙 만들기 (15분)

### Claude Code로 생성
```
우리집 AI 사용 규칙을 만들어줘.
가족 모두가 냉장고에 붙여놓고 볼 수 있는 형식으로.

규칙 예시:
1. AI에게 개인정보(이름, 주소, 전화번호)는 알려주지 않아요
2. AI가 말한 것도 틀릴 수 있어요 — 중요한 건 엄마아빠에게 확인!
3. 숙제는 AI에게 답만 물어보지 말고, 풀이 방법을 물어봐요
4. 건강/병원 관련은 AI 말고 의사 선생님에게!
5. AI를 사용할 때는 부모님에게 말해요

예쁜 HTML로, A4 1페이지, 아이들도 읽기 쉬운 큰 글씨로.
파일명: 우리집_AI_규칙.html
```
