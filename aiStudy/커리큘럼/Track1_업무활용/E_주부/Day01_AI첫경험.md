# Day 1: AI 첫 경험 — "Claude에게 생활 고민을 물어보자"

## 학습 목표
- Claude 가입 및 첫 대화
- AI에게 역할을 부여하고 질문하는 방법 체험
- 일상생활에서 AI 활용 가능 영역 파악

## 준비물
- 노트북 또는 스마트폰 (claude.ai 접속)
- Claude 계정

---

## 실습 1: Claude 가입 + 첫 대화 (10분)

1. claude.ai 접속 → 회원가입
2. 첫 대화: "안녕하세요. 저는 두 아이(초등 2학년, 유치원)를 키우는 전업주부입니다."
3. 이어서: "요즘 아이들 간식 고민이 많아요. 건강하면서 아이들이 좋아하는 간식 5가지 추천해주세요."

### 관찰 포인트
- Claude의 답변이 구체적인가?
- 내 상황을 반영한 답변인가?

---

## 실습 2: 역할 부여하기 (10분)

```
당신은 15년 경력의 영양사이자 두 아이의 엄마입니다.
저는 초등 2학년, 유치원 아이를 키우고 있고,
아이들이 편식이 심해서 걱정입니다.

다음 조건에 맞는 주간 간식 계획을 만들어주세요:
- 월~금 5일
- 준비 시간: 15분 이내
- 재료비: 1일 5,000원 이내
- 편식하는 아이도 먹을 수 있는 방법 포함

표 형식으로 정리해주세요.
```

### 관찰 포인트
- "영양사이자 엄마"라는 역할이 답변에 어떤 영향을 주는가?
- 조건(시간, 비용)을 넣으면 얼마나 구체적으로 나오는가?

---

## 실습 3: 다양한 생활 질문 체험 (15분)

아래 질문들을 하나씩 해보세요:

### 육아
```
초등 2학년 아이가 수학을 어려워해요.
집에서 놀이처럼 수학을 가르칠 수 있는 방법 3가지를 구체적으로 알려주세요.
준비물과 진행 방법을 포함해주세요.
```

### 요리
```
냉장고에 닭가슴살, 양파, 감자, 당근, 계란이 있어요.
이 재료로 만들 수 있는 저녁 메뉴 3가지를 추천해주세요.
각 메뉴의 조리 시간과 난이도도 알려주세요.
```

### 가계 관리
```
4인 가족(부부 + 초등생 + 유치원생) 월 생활비를 절약하는 방법을 알려주세요.
현재 월 지출이 약 350만원인데, 품질을 유지하면서 줄일 수 있는 항목을
구체적 금액과 함께 제안해주세요.
```

### 자기계발
```
전업주부 5년차인데, 나중에 재취업을 준비하고 싶어요.
이전 직업은 사무직(일반사무)이었습니다.
지금부터 준비할 수 있는 것들을 6개월 로드맵으로 만들어주세요.
```

---

## 실습 4: AI 활용 영역 찾기 (10분)

```
저는 전업주부입니다. 하루 일과를 나열하면:
- 아침 준비 (아이들 등교)
- 집안일 (청소, 빨래, 정리)
- 장보기 + 요리 (점심/저녁)
- 아이들 하교 후 간식 + 숙제 봐주기
- 아이들 학원 스케줄 관리
- 가계부 정리
- 택배/공과금/은행 업무
- 저녁 후 자기계발 시간 (독서, 온라인 강의)

이 중에서 AI(Claude)가 도움을 줄 수 있는 영역을 분석해주세요.
각 영역마다:
1. AI가 할 수 있는 것
2. AI가 할 수 없는 것
3. 절약되는 시간 (예상)
을 표로 정리해주세요.
```
