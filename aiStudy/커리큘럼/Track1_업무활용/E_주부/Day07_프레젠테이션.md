# Day 7: 프레젠테이션 + PDF — "여행 계획서, 가족 앨범을 만들자"

## 학습 목표
- Claude Code로 예쁜 HTML 문서 제작
- AI 이미지 생성(Claude Design) 체험
- edge-tts로 음성 생성
- HTML → PDF 변환

---

## 실습 1: 가족 여행 계획서 HTML 제작 (20분)

### 프롬프트
```
가족 여행 계획서를 예쁜 HTML로 만들어줘.

여행 정보:
- 일시: 2026년 7월 25일(토) ~ 27일(월), 2박 3일
- 장소: 강릉/양양
- 인원: 4명 (부부 + 초등생 + 유치원생)
- 예산: 50만원

구성:
1. 표지 (여행 제목 + 날짜 + 가족 수)
2. 일정표 (일자별 시간 + 장소 + 활동)
   - 1일차: 출발 → 점심 → 경포해변 → 숙소
   - 2일차: 서핑체험 → 점심 → 양양 쏠비치 → 저녁 해산물
   - 3일차: 체크아웃 → 정동진 → 점심 → 귀가
3. 준비물 체크리스트
4. 예산 상세 (교통/숙박/식비/활동비/기타)
5. 비상 연락처 (숙소, 병원, 렌터카)

디자인:
- 바다/여름 느낌 파란색 계열
- 이모지 활용
- A4 인쇄 가능한 레이아웃
```

---

## 실습 2: AI 이미지 + 시각화 (10분)

### Claude Design 활용
claude.ai에서:
```
가족 여행 계획서 표지에 사용할 일러스트를 만들어줘:
- 바다, 모래성, 가족 4명 실루엣
- 밝고 따뜻한 여름 느낌
```

### 활용 아이디어
- 아이 생일 파티 초대장
- 가족 연말 카드
- 중고 거래 상품 설명 이미지

---

## 실습 3: edge-tts 음성 생성 (10분)

```
다음 텍스트를 음성 파일로 만들어줘:

"우리 가족 여름 여행 계획!
7월 25일부터 27일까지, 강릉과 양양으로 떠나요.
바다에서 놀고, 맛있는 것도 먹고, 추억을 만들어요!"

파일명: 여행안내.mp3
목소리: 여성, 밝은 톤
```

### 활용
- 여행 계획을 가족에게 음성으로 공유
- 아이에게 들려줄 동화 음성 제작
- 학습 자료 음성화

---

## 실습 4: PDF 변환 + 다른 문서 아이디어 (5분)

```
여행 계획서 HTML을 PDF로 변환해줘
```

### 더 만들어볼 수 있는 것들
- 아이 생일 파티 초대장
- 월간 가족 일정표 (냉장고 부착용)
- 연말 가족 사진 앨범 레이아웃
