## 실습 1: 프로젝트 발표 (90분)

1. 발표 순서와 형식:

```
발표 형식 (1인당 15분):
- 발표: 10분
- Q&A: 3분
- 피드백: 2분

발표 포함 항목:
1. 프로젝트 개요 (1분)
   - 해결하고자 한 문제
   - 최종 결과물 한 줄 요약

2. 기술 스택 및 아키텍처 (2분)
   - YOLO + OpenCV + EasyOCR 파이프라인
   - 시스템 구성도

3. 핵심 구현 (3분)
   - 번호판 검출 모델 학습 과정
   - OCR 전처리 최적화
   - 후처리 정규식 패턴

4. 데모 (2분)
   - 라이브 데모 또는 녹화 영상
   - API 호출 시연

5. 성능 분석 (1분)
   - 정량적 수치 (mAP, 정확도, FPS)
   - 성공/실패 사례

6. 한계점 및 향후 계획 (1분)
   - 현재 시스템의 약점
   - 개선 아이디어
```

1. GitHub 저장소를 교차 리뷰한다:

```

[문서화]

- [ ] README에 사용법 예제가 있는가?
- [ ] requirements.txt가 정확한가?

[성능]
- [ ] 벤치마크 결과가 문서화되어 있는가?
- [ ] 모델 파일은 별도 관리(Git LFS 등)되는가?
```
