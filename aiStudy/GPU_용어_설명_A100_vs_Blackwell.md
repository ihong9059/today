# GPU 성능 비교 용어 설명

## NVIDIA A100 vs Blackwell (B100/B200)

**작성일:** 2026년 01월 30일

---

## 1. 기본 용어

### GPU (Graphics Processing Unit)
- **한글:** 그래픽 처리 장치
- **설명:** 원래 그래픽 렌더링을 위해 설계되었으나, 현재는 AI/딥러닝 연산에 핵심적으로 사용됨
- **특징:** 수천 개의 작은 코어로 병렬 연산에 최적화

### NVIDIA
- **설명:** 미국의 GPU 제조 회사
- **주요 제품:** GeForce(게임용), Quadro(전문가용), Tesla/A100/H100/B200(데이터센터/AI용)

### Ampere / Blackwell
- **Ampere:** NVIDIA GPU 아키텍처 이름 (2020년, A100에 사용)
- **Blackwell:** NVIDIA 최신 GPU 아키텍처 이름 (2024년, B100/B200에 사용)
- **참고:** NVIDIA는 과학자 이름을 아키텍처명으로 사용 (Tesla, Pascal, Volta, Turing, Ampere, Hopper, Blackwell)

---

## 2. 제조 공정 관련

### nm (Nanometer, 나노미터)
- **한글:** 나노미터
- **설명:** 10억분의 1미터 (10⁻⁹ m)
- **GPU에서의 의미:** 트랜지스터 크기를 나타냄
- **예시:**
  - A100: 7nm 공정 → 트랜지스터 크기가 7나노미터
  - B200: 4nm 공정 → 더 작은 트랜지스터로 더 많이 집적 가능
- **작을수록:** 전력 효율 ↑, 성능 ↑, 발열 ↓

### 트랜지스터 (Transistor)
- **설명:** 전자 신호를 증폭하거나 스위칭하는 반도체 소자
- **GPU에서의 역할:** 연산의 기본 단위, 많을수록 복잡한 연산 가능
- **비교:**
  - A100: 542억 개
  - B200: 2,080억 개 (약 4배)

---

## 3. 메모리 관련

### HBM (High Bandwidth Memory)
- **한글:** 고대역폭 메모리
- **설명:** GPU 전용으로 설계된 초고속 메모리
- **특징:**
  - 일반 GDDR 메모리보다 대역폭이 훨씬 높음
  - 3D 적층 구조로 공간 효율적
  - AI/딥러닝에서 대량의 데이터 처리에 필수

### HBM2e / HBM3e
- **HBM2e:** HBM 2세대의 향상된 버전
  - A100에서 사용
  - 대역폭: 약 2TB/s
- **HBM3e:** HBM 3세대의 향상된 버전
  - B200에서 사용
  - 대역폭: 약 8TB/s (4배 향상)

### GB (Gigabyte, 기가바이트)
- **설명:** 데이터 저장 용량 단위
- **크기:** 1GB = 1,024MB = 약 10억 바이트
- **예시:**
  - A100: 40GB 또는 80GB
  - B200: 192GB (더 큰 AI 모델 로드 가능)

### TB/s (Terabytes per second)
- **한글:** 초당 테라바이트
- **설명:** 메모리 대역폭 단위 (1초에 전송 가능한 데이터량)
- **크기:** 1TB = 1,024GB
- **예시:**
  - A100: 2TB/s → 1초에 2TB 데이터 전송 가능
  - B200: 8TB/s → 1초에 8TB 데이터 전송 가능

## 4. 연산 성능 단위

### FLOPS (Floating Point Operations Per Second)
- **한글:** 초당 부동소수점 연산 횟수
- **설명:** 컴퓨터의 연산 성능을 측정하는 단위
- **부동소수점:** 소수점이 있는 숫자 (예: 3.14159)

### TFLOPS (TeraFLOPS)
- **크기:** 1 TFLOPS = 10¹² FLOPS = 1조 FLOPS
- **의미:** 1초에 1조 번의 부동소수점 연산
- **예시:** A100 FP64 = 9.7 TFLOPS → 1초에 9.7조 번 연산

### PFLOPS (PetaFLOPS)
- **크기:** 1 PFLOPS = 1,000 TFLOPS = 10¹⁵ FLOPS
- **의미:** 1초에 1,000조 번의 부동소수점 연산
- **예시:** B200 FP16 = 2.25 PFLOPS → 1초에 2,250조 번 연산

### TOPS (Tera Operations Per Second)
- **한글:** 초당 테라 연산
- **설명:** 정수 연산 성능 단위 (주로 INT8 추론에 사용)
- **크기:** 1 TOPS = 10¹² OPS = 1조 연산/초

---

## 5. 데이터 정밀도 (Precision)

### FP (Floating Point, 부동소수점)
- **설명:** 소수점이 있는 숫자를 표현하는 방식
- **비트 수가 클수록:** 정밀도 ↑, 메모리 사용량 ↑, 연산 속도 ↓

### FP64 (64-bit Floating Point)
- **다른 이름:** Double Precision (배정밀도)
- **용도:** 과학 계산, 시뮬레이션 (높은 정밀도 필요)
- **메모리:** 숫자 1개당 8바이트

### FP32 (32-bit Floating Point)
- **다른 이름:** Single Precision (단정밀도)
- **용도:** 일반적인 딥러닝 학습
- **메모리:** 숫자 1개당 4바이트

### FP16 (16-bit Floating Point)
- **다른 이름:** Half Precision (반정밀도)
- **용도:** 딥러닝 학습 및 추론 (속도 중시)
- **메모리:** 숫자 1개당 2바이트
- **특징:** FP32 대비 2배 빠름, 약간의 정밀도 손실

### FP8 (8-bit Floating Point)
- **용도:** AI 추론 (속도 극대화)
- **메모리:** 숫자 1개당 1바이트
- **특징:** FP16 대비 2배 빠름, Hopper/Blackwell에서 지원

### FP4 (4-bit Floating Point)
- **용도:** LLM 추론 최적화
- **메모리:** 숫자 1개당 0.5바이트
- **특징:** Blackwell에서 새로 지원, 추론 속도 극대화

### INT8 (8-bit Integer)
- **한글:** 8비트 정수
- **용도:** AI 추론 (정수 연산)
- **특징:** 부동소수점보다 빠르고 전력 효율적

### 정밀도별 비교 표

| 정밀도 | 비트 | 메모리 | 속도 | 용도 |
|:-------|:-----|:-------|:-----|:-----|
| FP64 | 64비트 | 8바이트 | 느림 | 과학계산 |
| FP32 | 32비트 | 4바이트 | 보통 | 일반 학습 |
| FP16 | 16비트 | 2바이트 | 빠름 | AI 학습/추론 |
| FP8 | 8비트 | 1바이트 | 매우 빠름 | AI 추론 |
| FP4 | 4비트 | 0.5바이트 | 가장 빠름 | LLM 추론 |
| INT8 | 8비트 | 1바이트 | 매우 빠름 | AI 추론 |

## 6. 전력 관련

### TDP (Thermal Design Power)
- **한글:** 열 설계 전력
- **설명:** GPU가 최대 성능으로 작동할 때 발생하는 열을 처리하기 위해 필요한 냉각 시스템의 용량
- **단위:** W (와트)
- **의미:** 실질적으로 GPU의 최대 전력 소비량
- **예시:**
  - A100: 400W
  - B200: 1000W (전력 소비 2.5배, 성능은 4~30배)

### W (Watt, 와트)
- **설명:** 전력의 단위
- **의미:** 1초당 소비되는 에너지량

## 7. 연결/통신 관련

### NVLink
- **설명:** NVIDIA가 개발한 GPU 간 초고속 연결 기술
- **용도:** 여러 GPU를 연결하여 하나처럼 사용
- **버전별 대역폭:**
  - NVLink 3.0 (A100): 600GB/s
  - NVLink 5.0 (B200): 1.8TB/s

### GB/s (Gigabytes per second)
- **한글:** 초당 기가바이트
- **설명:** 데이터 전송 속도 단위

---

## 8. AI/딥러닝 관련

### Tensor
- **한글:** 텐서
- **설명:** 다차원 배열 (행렬의 일반화)
- **예시:**
  - 0차원 텐서: 스칼라 (숫자 하나)
  - 1차원 텐서: 벡터 [1, 2, 3]
  - 2차원 텐서: 행렬
  - 3차원 이상: 고차원 텐서

### Tensor Core
- **설명:** NVIDIA GPU에 내장된 AI 연산 전용 하드웨어
- **특징:** 행렬 연산을 매우 빠르게 처리
- **용도:** 딥러닝 학습 및 추론 가속

### Transformer
- **설명:** 2017년 Google이 발표한 AI 모델 구조
- **특징:** 병렬 처리에 최적화, 긴 문맥 이해 가능
- **활용:** GPT, BERT, ChatGPT 등 모든 현대 LLM의 기반

### Transformer Engine
- **설명:** NVIDIA가 Transformer 모델 연산을 최적화한 기술
- **기능:** FP8/FP16 정밀도를 자동으로 전환하여 성능 극대화

### LLM (Large Language Model)
- **한글:** 대규모 언어 모델
- **설명:** 수천억 개의 파라미터를 가진 AI 언어 모델
- **예시:** GPT-4, Claude, Llama, Gemini

### GPT (Generative Pre-trained Transformer)
- **한글:** 생성형 사전학습 트랜스포머
- **설명:** OpenAI가 개발한 언어 모델 시리즈
- **예시:** GPT-3 (175B 파라미터), GPT-4

### 175B
- **의미:** 1,750억 (175 Billion)
- **예시:** GPT-3 175B = 1,750억 개의 파라미터를 가진 모델

### 학습 (Training)
- **설명:** AI 모델이 데이터를 보고 패턴을 배우는 과정
- **특징:** 대량의 연산과 메모리 필요, 시간이 오래 걸림

### 추론 (Inference)
- **설명:** 학습된 AI 모델이 새로운 입력에 대해 결과를 출력하는 과정
- **특징:** 학습보다 가벼움, 실시간 응답 필요

## 9. 성능 비교 요약

### A100 vs B200 상세 비교

| 항목 | A100 | B200 | 설명 |
|:-----|:-----|:-----|:-----|

| 공정 | 7nm | 4nm | 트랜지스터 크기 |
| 트랜지스터 | 542억 개 | 2,080억 개 | 연산 능력의 기반 |

| 메모리 대역폭 | 2TB/s | 8TB/s | 데이터 전송 속도 |
| FP16 성능 | 312 TFLOPS | 2,250 TFLOPS | AI 학습 속도 |
| INT8 성능 | 624 TOPS | 4,500 TOPS | AI 추론 속도 |
| TDP | 400W | 1,000W | 전력 소비 |
| NVLink | 600GB/s | 1,800GB/s | GPU 간 연결 속도 |
