## 1. ESP32-CAM 문제

### 1.1 업로드 실패

#### 증상
```
A fatal error occurred: Failed to connect to ESP32: Timed out waiting for packet header
```

#### 해결방법
1. **GPIO0을 GND에 연결** (업로드 모드)
2. **리셋 버튼** 누른 후 업로드 시도
3. **USB 케이블 교체** (데이터 케이블인지 확인)
4. **포트 확인**: 올바른 COM 포트 선택
5. **업로드 속도 낮추기**: 115200 → 57600

```bash
# macOS/Linux에서 포트 확인
ls /dev/tty.*
ls /dev/cu.*
```

### 1.2 WiFi 연결 안됨

#### 증상
```
WiFi connection failed
```

#### 해결방법
1. **SSID/Password 확인**: 대소문자 구분
2. **2.4GHz 확인**: ESP32는 5GHz 지원 안함
3. **공유기 설정 확인**: MAC 필터링 해제
4. **신호 강도 확인**: ESP32-CAM을 공유기 가까이

```cpp
// 디버그 코드 추가
Serial.println("Connecting to WiFi...");
WiFi.begin(ssid, password);
int attempts = 0;
while (WiFi.status() != WL_CONNECTED && attempts < 30) {
  delay(500);
  Serial.print(".");
  attempts++;
}
if (WiFi.status() == WL_CONNECTED) {
  Serial.println("\nConnected!");
  Serial.println(WiFi.localIP());
} else {
  Serial.println("\nConnection failed!");
  Serial.println(WiFi.status()); // 상태 코드 확인
}
```

WiFi 상태 코드:
- 0: WL_IDLE_STATUS
- 1: WL_NO_SSID_AVAIL
- 4: WL_CONNECT_FAILED
- 6: WL_DISCONNECTED

### 1.3 카메라 초기화 실패

#### 증상
```
Camera init failed with error 0x20001
```

#### 해결방법
1. **카메라 모델 확인**: `#define CAMERA_MODEL_AI_THINKER`
2. **카메라 커넥터 확인**: 평면 케이블 재연결
3. **PSRAM 확인**: 4MB PSRAM 필요
4. **전원 확인**: 안정적인 5V 공급

```cpp
// 카메라 설정 디버그
camera_config_t config;
config.ledc_channel = LEDC_CHANNEL_0;
config.ledc_timer = LEDC_TIMER_0;
// ... 기타 설정

esp_err_t err = esp_camera_init(&config);
if (err != ESP_OK) {
  Serial.printf("Camera init failed with error 0x%x\n", err);
  // 에러 코드별 원인
  // 0x101: 카메라 연결 안됨
  // 0x103: 프레임 버퍼 할당 실패
  // 0x20001: 카메라 초기화 실패
}
```

#### 증상

### 1.5 ESP32-CAM 재부팅 반복

#### 증상

2. **커패시터 추가**: 5V-GND 사이에 470µF
3. **WiFi 전송 파워 낮추기**:

## 3. 번호판 인식 문제

### 3.1 번호판 검출 실패

#### 증상
- 번호판 영역을 찾지 못함
- Contour가 검출되지 않음

#### 해결방법

1. **전처리 파라미터 조정**:
```python
# Canny 엣지 검출 임계값 조정
edges = cv2.Canny(blur, 30, 100)  # 값 낮추기

# 모폴로지 연산 추가
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
edges = cv2.dilate(edges, kernel, iterations=2)
edges = cv2.erode(edges, kernel, iterations=1)
```

2. **면적 필터 조정**:
```python
# 번호판 면적 범위 조정
MIN_AREA = 500   # 더 작은 번호판도 검출
MAX_AREA = 100000  # 더 큰 번호판도 검출
```

3. **가로세로 비율 조정**:
```python
# 한국 번호판 비율: 약 2:1 ~ 5:1
ASPECT_RATIO_MIN = 1.5
ASPECT_RATIO_MAX = 6.0
```

### 3.2 OCR 인식률 저하

#### 증상
- 글자가 제대로 인식되지 않음
- 이상한 문자가 출력됨

#### 해결방법

1. **이미지 전처리 개선**:
```python
# 이진화 전 처리
gray = cv2.cvtColor(plate_img, cv2.COLOR_BGR2GRAY)

# 적응형 이진화 사용
binary = cv2.adaptiveThreshold(
    gray, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY_INV, 11, 2
)

# 노이즈 제거
binary = cv2.medianBlur(binary, 3)
```

2. **Tesseract 설정 최적화**:
```python
custom_config = r'--oem 3 --psm 7 -c tessedit_char_whitelist=0123456789가나다라마바사아자차카타파하'
text = pytesseract.image_to_string(binary, lang='kor', config=custom_config)
```

PSM (Page Segmentation Mode) 옵션:
- 6: 단일 텍스트 블록
- 7: 단일 텍스트 라인 (번호판에 적합)
- 8: 단일 단어
- 13: Raw line

3. **이미지 크기 조정**:
```python
# 번호판 이미지 확대 (Tesseract는 큰 이미지에서 더 잘 동작)
scale = 2
plate_img = cv2.resize(plate_img, None, fx=scale, fy=scale, interpolation=cv2.INTER_CUBIC)
```

## 4. 네트워크 문제

### 4.1 간헐적 연결 끊김

#### 해결방법
```python
# 재연결 로직 추가
import time

def capture_with_retry(url, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = requests.get(url, timeout=5)
            if response.status_code == 200:
                return response.content
        except Exception as e:
            print(f"Attempt {attempt + 1} failed: {e}")
            time.sleep(1)
    return None
```

### 4.2 스트림 끊김

#### 해결방법
```python
# 스트림 버퍼링 처리
cap = cv2.VideoCapture(stream_url)
```

## 6. 자주 묻는 질문 (FAQ)

### Q1: 어떤 해상도가 가장 좋나요?
**A**: VGA (640x480)가 처리 속도와 인식률의 균형이 좋습니다. 더 높은 정확도가 필요하면 SVGA (800x600)를 사용하세요.

### Q2: 야간에도 동작하나요?
**A**: 추가 조명(IR LED) 없이는 어렵습니다. ESP32-CAM 내장 Flash LED (GPIO4)를 활용하거나 외부 IR 조명을 추가하세요.

### Q3: 움직이는 차량도 인식 가능한가요?
**A**: 저속(~20km/h 이하)이면 가능합니다. 고속 차량은 모션 블러로 인식률이 떨어집니다.

### Q4: 여러 대의 카메라를 사용할 수 있나요?
**A**: 가능합니다. 멀티스레딩으로 여러 ESP32-CAM을 동시에 처리할 수 있습니다.

### Q5: 인식률을 높이려면?
**A**:
1. 조명 개선
2. 카메라 각도 최적화 (정면에 가깝게)
3. 해상도 증가
4. 이미지 전처리 튜닝
