### 2.2 통신 프로토콜

#### ESP32-CAM 엔드포인트

| 엔드포인트 | 메서드 | 설명 | 응답 |
|-----------|--------|------|------|
| `/` | GET | 스트리밍 페이지 | HTML |
| `/capture` | GET | 단일 이미지 캡처 | JPEG |
| `/stream` | GET | MJPEG 스트림 | multipart/x-mixed-replace |
| `/status` | GET | 카메라 상태 | JSON |
| `/control` | GET | 카메라 설정 변경 | - |

#### 요청/응답 예시

```python
# 단일 이미지 캡처
import requests
import cv2
import numpy as np

ESP32_CAM_URL = "http://192.168.1.100"

response = requests.get(f"{ESP32_CAM_URL}/capture", timeout=5)
if response.status_code == 200:
    img_array = np.frombuffer(response.content, dtype=np.uint8)
    frame = cv2.imdecode(img_array, cv2.IMREAD_COLOR)
```

```
┌─────────────────────────────────────────┐

      335mm x 170mm (구형 번호판)
```

### 3.2 번호판 패턴 정규표현식

```python
# 신형 번호판 (2019년 이후)
# 형식: 숫자2-3자리 + 한글1자리 + 숫자4자리
NEW_PLATE_PATTERN = r'^[0-9]{2,3}[가-힣][0-9]{4}$'

# 구형 번호판
# 형식: 지역명 + 숫자2자리 + 한글1자리 + 숫자4자리
OLD_PLATE_PATTERN = r'^[가-힣]{2}[0-9]{2}[가-힣][0-9]{4}$'

# 영업용 번호판
# 형식: 지역명 + 숫자2자리 + 한글(아,바,사,자) + 숫자4자리
COMMERCIAL_PATTERN = r'^[가-힣]{2}[0-9]{2}[아바사자][0-9]{4}$'
```

## 6. 보안 고려사항

1. **네트워크 보안**
   - ESP32-CAM과 RPi는 같은 로컬 네트워크에 배치
   - 외부 접근 시 VPN 또는 SSH 터널 사용

2. **데이터 보안**
   - 번호판 이미지는 처리 후 삭제 권장
   - 개인정보보호법 준수 필요

3. **인증**
   - ESP32-CAM 웹서버에 기본 인증 추가 고려
   - API 키 기반 접근 제어
