# 소프트웨어 설치 가이드

## 1. ESP32-CAM 펌웨어 설치

### 1.1 Arduino IDE 설치 및 설정

#### Step 1: Arduino IDE 다운로드
- https://www.arduino.cc/en/software 에서 다운로드
- 버전 2.x 권장

#### Step 2: ESP32 보드 매니저 추가
1. `파일` → `기본 설정` (또는 `Arduino IDE` → `Settings`)
2. "추가 보드 매니저 URLs"에 아래 URL 추가:
```
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
```

#### Step 3: ESP32 보드 패키지 설치
1. `도구` → `보드` → `보드 매니저`
2. "esp32" 검색
3. **esp32 by Espressif Systems** 설치 (버전 2.x 권장)

#### Step 4: 보드 설정
1. `도구` → `보드` → `ESP32 Arduino` → **AI Thinker ESP32-CAM**
2. 설정 확인:
   - Board: AI Thinker ESP32-CAM
   - Upload Speed: 115200
   - Flash Frequency: 80MHz
   - Flash Mode: QIO
   - Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS)
   - Core Debug Level: None

### 1.2 CameraWebServer 예제 수정 및 업로드

#### Step 1: 예제 열기
`파일` → `예제` → `ESP32` → `Camera` → **CameraWebServer**

#### Step 2: WiFi 설정 수정
```cpp
// CameraWebServer.ino 파일에서

// 카메라 모델 선택 (아래 라인 주석 해제)
#define CAMERA_MODEL_AI_THINKER  // Has PSRAM

// WiFi 설정
const char* ssid = "YOUR_WIFI_SSID";        // WiFi 이름
const char* password = "YOUR_WIFI_PASSWORD"; // WiFi 비밀번호
```

#### Step 3: 고정 IP 설정 (선택)
```cpp
// setup() 함수 내에 WiFi.begin() 전에 추가

#include <WiFi.h>

// 고정 IP 설정
IPAddress local_IP(192, 168, 1, 100);
IPAddress gateway(192, 168, 1, 1);
IPAddress subnet(255, 255, 255, 0);
IPAddress dns(8, 8, 8, 8);

// WiFi.begin() 전에 호출
if (!WiFi.config(local_IP, gateway, subnet, dns)) {
  Serial.println("STA Failed to configure");
}
```

#### Step 4: 업로드
1. ESP32-CAM-MB에 ESP32-CAM 모듈 삽입
2. USB 케이블로 PC 연결
3. 포트 선택: `도구` → `포트` → (COM포트 선택)
4. 업로드 버튼 클릭
5. 업로드 완료 후 RST 버튼 눌러 재시작

#### Step 5: 동작 확인
1. 시리얼 모니터 열기 (115200 baud)
2. IP 주소 확인 (예: 192.168.1.100)
3. 웹 브라우저에서 해당 IP 접속
4. "Start Stream" 클릭하여 영상 확인

## 2. Raspberry Pi OS 설치

### 2.1 Raspberry Pi Imager 사용

#### Step 1: Imager 다운로드
https://www.raspberrypi.com/software/

#### Step 2: OS 이미지 굽기
1. Raspberry Pi Imager 실행
2. OS 선택: **Raspberry Pi OS (64-bit)** 권장
3. 저장소: SD 카드 선택
4. 설정 (톱니바퀴 아이콘):
   - 호스트이름: `lpr-server`
   - SSH 활성화: 체크
   - 사용자 이름/비밀번호 설정
   - WiFi 설정
   - 로케일 설정: Asia/Seoul
5. "쓰기" 클릭

#### Step 3: 첫 부팅
1. SD 카드를 Raspberry Pi에 삽입
2. 전원 연결
3. 첫 부팅 시 약 2-3분 소요

### 2.2 초기 시스템 설정

```bash
# SSH 접속
ssh pi@192.168.1.200

# 시스템 업데이트
sudo apt update && sudo apt upgrade -y

# 시스템 설정
sudo raspi-config
```

raspi-config에서 설정:
- `Interface Options` → `Camera` → Enable (CSI 카메라 사용 시)
- `Interface Options` → `SSH` → Enable
- `Localisation Options` → `Timezone` → Asia/Seoul

```yaml
# ~/lpr-system/config/config.yaml

# ESP32-CAM 설정
camera:
  url: "http://192.168.1.100"
  capture_endpoint: "/capture"
  stream_endpoint: "/stream"
  resolution: "VGA"  # QVGA, CIF, VGA, SVGA, XGA, SXGA, UXGA
  timeout: 5

# 이미지 처리 설정
image_processing:
  width: 640
  height: 480
  blur_kernel: 5
  canny_low: 50
  canny_high: 150
  min_plate_area: 1000
  max_plate_area: 50000
  plate_aspect_ratio_min: 2.0
  plate_aspect_ratio_max: 6.0

ocr:
  language: "kor+eng"
  psm: 7  # Page Segmentation Mode (7 = single line)

# 로깅 설정

  image_dir: "captured_images"
  save_format: "jpg"
```

## 8. 시스템 서비스 등록 (자동 시작)

### 8.1 서비스 파일 생성

```bash
sudo nano /etc/systemd/system/lpr-system.service
```

```ini
[Unit]
Description=License Plate Recognition System
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/lpr-system
Environment="PATH=/home/pi/lpr-system/venv/bin"
ExecStart=/home/pi/lpr-system/venv/bin/python3 src/lpr_main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 8.2 서비스 활성화

```bash
# 서비스 등록
sudo systemctl daemon-reload

# 서비스 활성화 (부팅 시 자동 시작)
sudo systemctl enable lpr-system

# 서비스 시작
sudo systemctl start lpr-system

# 서비스 상태 확인
sudo systemctl status lpr-system

# 로그 확인
sudo journalctl -u lpr-system -f
```
