# 사용 가이드

## 1. 시스템 시작

### 1.1 ESP32-CAM 시작

1. ESP32-CAM에 전원 연결 (5V)
2. 약 5-10초 대기 (WiFi 연결)
3. 웹 브라우저에서 확인: `http://192.168.1.100`

### 1.2 Raspberry Pi 시작

```bash
# SSH 접속
ssh pi@192.168.1.200

# 가상환경 활성화
cd ~/lpr-system
source venv/bin/activate

# 프로그램 실행
python3 src/lpr_main.py
```

## 2. 기본 사용법

### 2.1 단일 이미지 캡처 및 인식

```bash
# 단일 이미지 모드로 실행
python3 src/lpr_main.py --mode single

# 결과 예시:
# [2024-01-01 12:00:00] 이미지 캡처 완료
# [2024-01-01 12:00:01] 번호판 검출: 1개
# [2024-01-01 12:00:02] 인식 결과: 12가3456 (신뢰도: 92.5%)
```

### 2.2 연속 모니터링 모드

```bash
# 연속 모니터링 (기본값)
python3 src/lpr_main.py --mode continuous --interval 2

# --interval: 캡처 간격 (초)
```

### 2.3 스트림 모드

```bash
# 실시간 스트림 처리 (CPU 부하 높음)
python3 src/lpr_main.py --mode stream
```

## 3. 명령줄 옵션

```bash
python3 src/lpr_main.py [OPTIONS]

옵션:
  --mode        : 동작 모드 (single, continuous, stream)
  --config      : 설정 파일 경로 (기본: config/config.yaml)
  --interval    : 캡처 간격 초 (기본: 3)
  --save        : 이미지 저장 여부 (기본: True)
  --display     : 화면 표시 여부 (기본: False)
  --verbose     : 상세 로그 출력
  --help        : 도움말 표시

예시:
  python3 src/lpr_main.py --mode continuous --interval 5 --save --verbose
```

## 5. 카메라 설정 조정

### 5.1 ESP32-CAM 웹 인터페이스

브라우저에서 `http://192.168.1.100` 접속 후 설정 가능:

| 설정 | 권장값 | 설명 |
|------|--------|------|
| Resolution | VGA (640x480) | 처리 속도와 품질 균형 |
| Quality | 10 | JPEG 압축 품질 (4-63, 낮을수록 좋음) |
| Brightness | 0 | 밝기 (-2 ~ 2) |
| Contrast | 0 | 대비 (-2 ~ 2) |
| Saturation | 0 | 채도 (-2 ~ 2) |
| Special Effect | None | 특수 효과 |
| AWB | On | 자동 화이트밸런스 |
| AEC | On | 자동 노출 |
| AGC | On | 자동 게인 |
| Gain Ceiling | 2x | 최대 게인 |

### 5.2 최적 설정 예시

#### 주간 실외
```
Resolution: SVGA (800x600)
Quality: 10
Brightness: 0
Contrast: 1
AWB: On
AEC: On
```

#### 야간/실내
```
Resolution: VGA (640x480)
Quality: 12
Brightness: 1
Contrast: 0
AGC: On
Gain Ceiling: 8x
```

## 6. 번호판 인식 결과

### 6.1 결과 출력 형식

```json
{
  "timestamp": "2024-01-01T12:00:00",
  "plate_number": "12가3456",
  "confidence": 92.5,
  "processing_time_ms": 850,
  "image_path": "captured_images/20240101_120000.jpg",
  "plate_region": {
    "x": 150,
    "y": 200,
    "width": 180,
    "height": 45
  }
}
```

### 6.2 로그 파일 확인

```bash
# 실시간 로그 확인
tail -f logs/lpr.log

# 최근 인식 결과
grep "인식 결과" logs/lpr.log | tail -20

# 특정 날짜 검색
grep "2024-01-01" logs/lpr.log
```

## 7. 화이트리스트 관리

### 7.1 화이트리스트 파일

```bash
# data/whitelist.txt
# 등록된 차량 번호판 목록
12가3456
34나7890
56다1234
서울78마9012
```

### 7.2 화이트리스트 체크 활성화

```yaml
# config/config.yaml
whitelist:
  enabled: true
  file: "data/whitelist.txt"
  action_on_match: "allow"      # allow, log, notify
  action_on_mismatch: "deny"    # deny, log, notify
```

## 8. 알림 설정

### 8.1 GPIO 알림 (LED/부저)

```yaml
# config/config.yaml
notifications:
  gpio:
    enabled: true
    success_pin: 17    # 인식 성공 시 LED
    failure_pin: 27    # 인식 실패 시 LED
    buzzer_pin: 22     # 부저
    pulse_duration: 0.5  # 초
```

### 8.2 텔레그램 알림 (선택)

# config/config.yaml
notifications:
  telegram:
    enabled: true

    chat_id: "YOUR_CHAT_ID"
    send_image: true

## 9. 데이터 관리

### 9.1 캡처 이미지 정리

```bash
# 30일 이상 된 이미지 삭제
find ~/lpr-system/captured_images -type f -mtime +30 -delete

# 이미지 개수 확인
ls -1 ~/lpr-system/captured_images | wc -l

# 디스크 사용량 확인
du -sh ~/lpr-system/captured_images
```

### 9.2 자동 정리 설정 (cron)

```bash
# crontab 편집
crontab -e

# 매일 새벽 3시에 30일 이상 된 이미지 삭제
0 3 * * * find /home/pi/lpr-system/captured_images -type f -mtime +30 -delete
```

### 9.3 로그 로테이션

```bash
# /etc/logrotate.d/lpr-system
/home/pi/lpr-system/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 644 pi pi
}
```

## 11. 백업

```bash
# 설정 파일 백업
tar -czvf lpr-config-backup.tar.gz config/ data/

# 원격 서버로 백업
scp lpr-config-backup.tar.gz user@backup-server:/backups/
```

### 11.2 전체 백업

```bash
# 전체 프로젝트 백업 (이미지 제외)
tar --exclude='captured_images' --exclude='venv' -czvf lpr-backup.tar.gz ~/lpr-system/
```

## 12. 종료

### 12.1 프로그램 종료

```bash
# 실행 중인 터미널에서
Ctrl+C

# 백그라운드 프로세스 종료
pkill -f lpr_main.py
```

### 12.2 서비스 종료

```bash
# 서비스 중지
sudo systemctl stop lpr-system

# 서비스 비활성화 (부팅 시 시작 안함)
sudo systemctl disable lpr-system
```
