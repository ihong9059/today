## 1. 시작하기 전에: 왜 역전파가 어렵게 느껴지나?

### 흔한 오해들

| 오해 | 진실 |
|------|------|
| "수학이 너무 어려워서" | 사실 곱셈과 덧셈만 알면 됩니다 |
| "복잡한 공식을 외워야 해서" | 딱 하나의 규칙만 이해하면 됩니다 |
| "뭘 하는 건지 모르겠어서" | 비유로 이해하면 아주 직관적입니다 |

### 이 문서의 목표

**"역전파 = 책임 추적"**이라는 하나의 개념만 이해하면 됩니다.

```
최종 결과가 틀렸을 때,
"누가 얼마나 잘못했는지" 끝에서부터 추적하는 것 = 역전파
```

## 2. 신경망 학습의 큰 그림

역전파를 이해하려면 먼저 "신경망이 어떻게 학습하는가"의 전체 그림을 봐야 합니다.

### 2.1 신경망 학습 = 시험 보고 오답노트 쓰기

학생이 시험을 보는 과정과 완전히 같습니다:

```
┌─────────────────────────────────────────────────────────────┐
│                      학생의 시험 과정                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 문제를 푼다        →  시험지 제출                        │
│  2. 채점 받는다        →  점수 확인 (몇 점 틀렸는지)          │
│  3. 오답노트 쓴다      →  어떤 개념이 부족했는지 분석         │
│  4. 공부한다          →  부족한 부분 집중 학습               │
│  5. 다시 시험         →  1번으로 돌아감                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 신경망에서는?

```
┌─────────────────────────────────────────────────────────────┐
│                      신경망의 학습 과정                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 순전파 (Forward)   →  입력으로 예측값 계산               │
│  2. 손실 계산 (Loss)   →  예측값과 정답 비교 (얼마나 틀렸나)  │
│  3. 역전파 (Backward)  →  각 가중치의 책임 계산 ⬅ 여기!     │
│  4. 가중치 업데이트    →  책임만큼 가중치 수정               │
│  5. 반복              →  1번으로 돌아감                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 핵심 질문

**"가중치를 어떻게 바꿔야 틀리는 양을 줄일 수 있을까?"**

이 질문에 답하는 것이 바로 **역전파**입니다.

## 3. 역전파를 이해하기 위한 준비물

### 3.1 미분이란? (1분 설명)

**미분 = 변화율 = "이것을 살짝 바꾸면 저것이 얼마나 변하나?"**

```
예시: y = 2x

x가 1 증가하면 → y는 2 증가
따라서 dy/dx = 2 (미분값)

해석: "x를 1만큼 바꾸면 y는 2만큼 변한다"
```

### 3.2 연쇄 법칙이란? (Chain Rule)

**여러 단계를 거쳐 영향을 미칠 때, 각 단계의 변화율을 곱한다**

```
일상 예시: 환율 계산

1달러 = 1,300원
1유로 = 1.1달러

Q: 1유로는 몇 원?
A: 1.1 × 1,300 = 1,430원

이게 바로 연쇄 법칙!
유로→원 = (유로→달러) × (달러→원)
```

수학으로 쓰면:
```
dz/dx = dz/dy × dy/dx

"x가 z에 미치는 영향 = x가 y에 미치는 영향 × y가 z에 미치는 영향"
```

### 3.3 이것만 기억하세요!

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   역전파의 유일한 규칙:                                       │
│                                                             │
│   "내가 받은 책임" × "내가 다음에 미친 영향" = "내 책임"        │
│                                                             │
│   수학으로: (받은 기울기) × (지역 미분) = (전달할 기울기)       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. 역전파의 핵심 아이디어

### 4.1 비유 1: 공장 불량품 추적

자동차 공장에서 불량 자동차가 나왔습니다.

```
[철판] → [프레임] → [도색] → [조립] → [완성차] ← 불량 발견!
```

품질 관리자는 **끝에서부터 역추적**합니다:

```
완성차 불량! (100% 책임)
     ↓
조립 공정: "내가 20% 잘못, 나머지 80%는 앞 공정 문제"
     ↓
도색 공정: "80% 중 내가 10% 잘못 = 8%, 나머지 72%는 앞으로"
     ↓
프레임 공정: "72% 중 내가 50% 잘못 = 36%, 나머지 36%는 앞으로"
     ↓
철판 공정: "남은 36% 책임"
```

**이것이 역전파입니다!**
- 최종 오차(100%)를 각 공정에 분배
- 끝에서 앞으로 책임을 추적
- 각 공정(가중치)이 얼마나 잘못했는지 알 수 있음

### 4.2 비유 2: 팀 프로젝트 성적

팀 프로젝트에서 60점(목표: 100점)을 받았습니다.

```
[자료조사 팀] → [분석 팀] → [발표 팀] → 최종 발표 ← 60점!
```

교수님이 감점 원인을 역추적:

```
"40점 감점 중..."

발표 팀: "전달력이 아쉬웠네 → 10점 감점은 발표 팀 책임"
         "나머지 30점은 내용 문제니까 분석 팀한테 물어봐"

분석 팀: "30점 중 분석 오류로 15점 감점은 우리 책임"
         "나머지 15점은 자료가 부족해서야"

자료조사 팀: "남은 15점은 우리 책임이네"
```

**결과:**
| 팀 | 책임 비율 | 개선 필요도 |
|----|-----------|------------|
| 발표 팀 | 10점 (25%) | 중간 |
| 분석 팀 | 15점 (37.5%) | 높음 |
| 자료조사 팀 | 15점 (37.5%) | 높음 |

→ 분석 팀과 자료조사 팀을 더 많이 교육(업데이트)해야 함!

### 4.3 신경망에서의 적용

```
입력(x) → [가중치 W1] → [가중치 W2] → 예측값 → 손실(오차)
                                              ↑
                                         "10만큼 틀렸다!"

역전파:
손실 10 → W2가 6만큼 책임 → W1이 4만큼 책임

결과:
- W2를 6만큼 수정
- W1을 4만큼 수정
→ 다음엔 덜 틀릴 것!
```

## 5. 단계별 역전파 완전 해부

### 5.1 가장 간단한 신경망

```
입력(x) ──→ [×w] ──→ [+b] ──→ 예측(y_pred) ──→ 손실(L)
                                    ↑              ↑
                                  "3.0"         "(3-5)² = 4"
                                              (정답은 5)
```

### 5.2 순전파 (Forward Pass) - 앞으로 계산

**목표: 입력에서 예측값, 그리고 손실까지 계산**

```python
# 초기값
x = 2.0       # 입력
w = 1.0       # 가중치
b = 1.0       # 편향
y_true = 5.0  # 정답

# 순전파
z = w * x + b           # z = 1×2 + 1 = 3
y_pred = z              # 예측값 = 3 (활성화 함수 생략)
loss = (y_pred - y_true) ** 2  # 손실 = (3-5)² = 4
```

### 5.3 역전파 (Backward Pass) - 뒤로 추적

**목표: 손실을 줄이려면 w와 b를 얼마나 바꿔야 하는가?**

#### Step 1: 손실에서 시작

```
손실 L = (y_pred - y_true)²

Q: y_pred가 변하면 L은 얼마나 변하나?
A: dL/dy_pred = 2 × (y_pred - y_true) = 2 × (3 - 5) = -4
```

**해석:** y_pred를 1 증가시키면 L은 -4만큼 변한다 (= 줄어든다!)

#### Step 2: y_pred → z

우리 예시에서 y_pred = z (활성화 함수 없음)

```
dy_pred/dz = 1
```

#### Step 3: z → w와 b

```
z = w × x + b

dz/dw = x = 2        (w가 변하면 z는 x배만큼 변함)
dz/db = 1            (b가 변하면 z는 1만큼 변함)
```

#### Step 4: 연쇄 법칙으로 연결!

```
dL/dw = dL/dy_pred × dy_pred/dz × dz/dw
      = (-4) × 1 × 2
      = -8

dL/db = dL/dy_pred × dy_pred/dz × dz/db
      = (-4) × 1 × 1
      = -4
```

### 5.4 가중치 업데이트

```python
learning_rate = 0.1  # 학습률

w_new = w - learning_rate × dL/dw
      = 1.0 - 0.1 × (-8)
      = 1.0 + 0.8
      = 1.8

b_new = b - learning_rate × dL/db
      = 1.0 - 0.1 × (-4)
      = 1.0 + 0.4
      = 1.4
```

### 5.5 검증: 정말 나아졌나?

```python
# 새 가중치로 다시 계산
z_new = 1.8 × 2 + 1.4 = 5.0
y_pred_new = 5.0
loss_new = (5.0 - 5.0)² = 0  # 손실 = 0! 완벽!
```

**손실이 4에서 0으로 줄었습니다!**

## 6. 숫자로 직접 따라가 보기

### 6.1 2층 신경망 예제

```
      입력층        은닉층         출력층
        x    ──W1──→  h    ──W2──→  y_pred  ──→  손실(L)
       (2)   ×0.5   (1)   ×1.0    (1)         MSE
                    ReLU
```

**초기값:**
- 입력: x = 2
- 가중치: W1 = 0.5, W2 = 1.0
- 정답: y_true = 3

### 6.2 순전파 단계별

```
Step 1: 은닉층 선형 변환
z1 = W1 × x = 0.5 × 2 = 1.0

Step 2: ReLU 활성화
h = ReLU(z1) = max(0, 1.0) = 1.0

Step 3: 출력층
z2 = W2 × h = 1.0 × 1.0 = 1.0
y_pred = z2 = 1.0  (활성화 생략)

Step 4: 손실 계산
L = (y_pred - y_true)² = (1 - 3)² = 4
```

### 6.3 역전파 단계별

**끝에서부터 시작!**

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 손실 → 예측값                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ L = (y_pred - y_true)²                                      │
│                                                             │
│ dL/dy_pred = 2(y_pred - y_true)                             │
│            = 2(1 - 3)                                       │
│            = -4                                             │
│                                                             │
│ 의미: "y_pred가 1 증가하면 손실이 -4만큼 변한다"              │
│       즉, y_pred를 늘리면 손실이 줄어든다!                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Step 2: 예측값 → W2                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ y_pred = z2 = W2 × h                                        │
│                                                             │
│ dz2/dW2 = h = 1.0                                           │
│                                                             │
│ 연쇄 법칙:                                                   │
│ dL/dW2 = dL/dy_pred × dy_pred/dz2 × dz2/dW2                 │
│        = (-4) × 1 × 1                                       │
│        = -4                                                 │
│                                                             │
│ 의미: "W2가 1 증가하면 손실이 -4만큼 변한다"                  │
│       즉, W2를 늘리면 손실이 줄어든다!                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Step 3: 예측값 → 은닉층                                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ z2 = W2 × h                                                 │
│                                                             │
│ dz2/dh = W2 = 1.0                                           │
│                                                             │
│ 연쇄 법칙:                                                   │
│ dL/dh = dL/dy_pred × dy_pred/dh                             │
│       = (-4) × 1                                            │
│       = -4                                                  │
│                                                             │
│ 의미: 은닉층 출력 h가 손실에 -4만큼 영향                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Step 4: 은닉층 → W1 (ReLU 통과!)                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ h = ReLU(z1)                                                │
│                                                             │
│ ReLU의 미분:                                                 │
│   z1 > 0 이면 → dh/dz1 = 1                                  │
│   z1 ≤ 0 이면 → dh/dz1 = 0                                  │
│                                                             │
│ 우리 경우 z1 = 1 > 0 이므로: dh/dz1 = 1                      │
│                                                             │
│ z1 = W1 × x                                                 │
│ dz1/dW1 = x = 2                                             │
│                                                             │
│ 연쇄 법칙:                                                   │
│ dL/dW1 = dL/dh × dh/dz1 × dz1/dW1                           │
│        = (-4) × 1 × 2                                       │
│        = -8                                                 │
│                                                             │
│ 의미: "W1이 1 증가하면 손실이 -8만큼 변한다"                  │
│       W1을 늘리면 손실이 크게 줄어든다!                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.4 가중치 업데이트 (학습률 = 0.1)

```python
W2_new = W2 - 0.1 × dL/dW2
       = 1.0 - 0.1 × (-4)
       = 1.0 + 0.4
       = 1.4

W1_new = W1 - 0.1 × dL/dW1
       = 0.5 - 0.1 × (-8)
       = 0.5 + 0.8
       = 1.3
```

### 6.5 검증

```python
# 새 가중치로 순전파
z1 = 1.3 × 2 = 2.6
h = ReLU(2.6) = 2.6
y_pred = 1.4 × 2.6 = 3.64

# 새 손실
loss_new = (3.64 - 3)² = 0.41

# 비교
print(f"기존 손실: 4.0")
print(f"새 손실: 0.41")
print(f"개선율: {(4-0.41)/4*100:.1f}%")  # 89.8% 개선!
```

## 7. 코드로 구현해 보기

### 7.1 가장 간단한 역전파 (1층)

```python
import numpy as np

# ===== 데이터 =====
x = 2.0
y_true = 5.0

# ===== 초기 가중치 =====
w = 1.0
b = 1.0

# ===== 학습률 =====
lr = 0.1

print("=" * 50)
print("1층 신경망 역전파 학습")
print("=" * 50)

for epoch in range(5):
    # ----- 순전파 -----
    y_pred = w * x + b
    loss = (y_pred - y_true) ** 2

    # ----- 역전파 -----
    # 손실 → 예측값
    dL_dy = 2 * (y_pred - y_true)

    # 예측값 → 가중치
    dy_dw = x       # y = w*x + b 에서 w에 대한 미분
    dy_db = 1       # y = w*x + b 에서 b에 대한 미분

    # 연쇄 법칙
    dL_dw = dL_dy * dy_dw
    dL_db = dL_dy * dy_db

    # ----- 업데이트 -----
    w = w - lr * dL_dw
    b = b - lr * dL_db

    print(f"Epoch {epoch+1}: loss={loss:.4f}, w={w:.4f}, b={b:.4f}")
```

**출력:**
```
Epoch 1: loss=4.0000, w=1.8000, b=1.4000
Epoch 2: loss=0.0400, w=1.7600, b=1.4800
Epoch 3: loss=0.0004, w=1.7560, b=1.4880
Epoch 4: loss=0.0000, w=1.7556, b=1.4888
Epoch 5: loss=0.0000, w=1.7556, b=1.4889
```

### 7.2 2층 신경망 역전파 (XOR 문제)

```python
import numpy as np

# ===== XOR 데이터 =====
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]]).T  # shape: (2, 4)
Y = np.array([[0, 1, 1, 0]])                       # shape: (1, 4)

# ===== 초기 가중치 (랜덤) =====
np.random.seed(42)
W1 = np.random.randn(4, 2) * 0.5   # 입력(2) → 은닉(4)
b1 = np.zeros((4, 1))
W2 = np.random.randn(1, 4) * 0.5   # 은닉(4) → 출력(1)
b2 = np.zeros((1, 1))

# ===== 활성화 함수 =====
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    return a * (1 - a)

# ===== 학습 =====
lr = 1.0
epochs = 10000

print("=" * 50)
print("2층 신경망으로 XOR 학습")
print("=" * 50)

for epoch in range(epochs):
    # ===== 순전파 =====
    # 은닉층
    Z1 = W1 @ X + b1          # 선형 변환
    A1 = sigmoid(Z1)          # 활성화

    # 출력층
    Z2 = W2 @ A1 + b2         # 선형 변환
    A2 = sigmoid(Z2)          # 활성화 (예측값)

    # 손실 (Binary Cross Entropy)
    m = X.shape[1]
    loss = -np.mean(Y * np.log(A2 + 1e-8) + (1-Y) * np.log(1-A2 + 1e-8))

    # ===== 역전파 =====
    # Step 1: 출력층
    dZ2 = A2 - Y                              # 손실의 미분 (시작점!)
    dW2 = (1/m) * dZ2 @ A1.T                  # W2의 기울기
    db2 = (1/m) * np.sum(dZ2, axis=1, keepdims=True)

    # Step 2: 은닉층으로 전파
    dA1 = W2.T @ dZ2                          # 은닉층에 전달할 "책임"
    dZ1 = dA1 * sigmoid_derivative(A1)        # 활성화 함수 통과
    dW1 = (1/m) * dZ1 @ X.T                   # W1의 기울기
    db1 = (1/m) * np.sum(dZ1, axis=1, keepdims=True)

    # ===== 가중치 업데이트 =====
    W2 -= lr * dW2
    b2 -= lr * db2
    W1 -= lr * dW1
    b1 -= lr * db1

    # 진행 상황 출력
    if epoch % 2000 == 0:
        predictions = (A2 > 0.5).astype(int)
        accuracy = np.mean(predictions == Y) * 100
        print(f"Epoch {epoch:5d}: loss={loss:.4f}, accuracy={accuracy:.0f}%")

# ===== 최종 결과 =====
print("\n" + "=" * 50)
print("학습 완료! XOR 테스트:")
print("=" * 50)

# 최종 순전파
A1 = sigmoid(W1 @ X + b1)
A2 = sigmoid(W2 @ A1 + b2)

for i in range(4):
    x1, x2 = X[0, i], X[1, i]
    pred = round(A2[0, i], 3)
    result = 1 if pred > 0.5 else 0
    print(f"입력: ({x1}, {x2}) → 예측: {pred:.3f} → 결과: {result}, 정답: {int(Y[0, i])}")
```

```

Epoch  2000: loss=0.0284, accuracy=100%
Epoch  4000: loss=0.0106, accuracy=100%

Epoch  8000: loss=0.0041, accuracy=100%

입력: (1, 1) → 예측: 0.019 → 결과: 0, 정답: 0
```

### 7.3 PyTorch에서는 자동으로!

```python
import torch
import torch.nn as nn

# 모델 정의
model = nn.Sequential(
    nn.Linear(2, 4),
    nn.Sigmoid(),
    nn.Linear(4, 1),
    nn.Sigmoid()
)

# 데이터
X = torch.tensor([[0,0], [0,1], [1,0], [1,1]], dtype=torch.float32)
Y = torch.tensor([[0], [1], [1], [0]], dtype=torch.float32)

# 손실 함수 & 옵티마이저
criterion = nn.BCELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=1.0)

# 학습
for epoch in range(10000):
    # 순전파
    outputs = model(X)
    loss = criterion(outputs, Y)

    # 역전파 (한 줄로 끝!)
    optimizer.zero_grad()  # 기울기 초기화
    loss.backward()        # ← 이 한 줄이 위의 모든 역전파 계산!
    optimizer.step()       # 가중치 업데이트

    if epoch % 2000 == 0:
        print(f"Epoch {epoch}: loss={loss.item():.4f}")
```

## 8. 자주 묻는 질문 (FAQ)

### Q1: 왜 "역"전파인가요?

**A:** 계산이 뒤에서 앞으로 진행되기 때문입니다.

```
순전파: 입력 → 은닉층 → 출력 → 손실
역전파: 입력 ← 은닉층 ← 출력 ← 손실 (반대 방향!)
```

### Q2: 왜 끝에서부터 계산하나요?

**A:** 효율성 때문입니다!

```
방법 1 (비효율적): 각 가중치마다 처음부터 새로 계산
- W1의 영향 계산 → 처음부터 끝까지 계산
- W2의 영향 계산 → 또 처음부터 끝까지 계산
- 시간 복잡도: O(N²)

방법 2 (역전파): 끝에서 시작해서 재사용
- 손실 → 마지막 층 기울기 계산 후 저장
- 저장된 값 재사용 → 이전 층 기울기 계산
- 시간 복잡도: O(N)
```

### Q3: 왜 미분을 사용하나요?

**A:** "이 방향으로 가면 손실이 줄어든다"를 알려주기 때문입니다.

```
미분값 > 0: 가중치 증가 → 손실 증가 → 가중치를 줄여야 함
미분값 < 0: 가중치 증가 → 손실 감소 → 가중치를 늘려야 함
미분값 = 0: 이미 최적! (기울기가 0인 지점)
```

### Q4: 기울기 소실(Vanishing Gradient)이 뭔가요?

**A:** 역전파할 때 기울기가 너무 작아지는 문제입니다.

```
연쇄 법칙: dL/dW1 = a × b × c × d × ...

Sigmoid 미분의 최대값 = 0.25
10층 네트워크: 0.25^10 = 0.00000095 ≈ 0

→ 앞쪽 층의 가중치가 거의 업데이트 안됨!
→ 해결책: ReLU 사용 (양수 구간에서 미분 = 1)
```

### Q5: 학습률은 어떻게 정하나요?

**A:** 실험으로 찾습니다!

```
학습률 너무 크면: 최적점을 지나침 (발산)
학습률 너무 작으면: 학습이 너무 느림

일반적인 시작점: 0.001 ~ 0.01
```

## 9. 정리 및 핵심 요약

### 9.1 한 줄 요약

```
역전파 = "최종 오차를 끝에서 앞으로 전파하며 각 가중치의 책임을 계산"
```

### 9.2 핵심 개념 정리

| 개념 | 설명 | 비유 |
|------|------|------|
| **순전파** | 입력 → 출력 계산 | 공장 조립 라인 |
| **손실** | 예측과 정답의 차이 | 품질 검사 점수 |
| **역전파** | 손실을 뒤에서 앞으로 전파 | 불량 원인 역추적 |
| **연쇄 법칙** | 각 단계의 변화율을 곱함 | 환율 변환 |
| **기울기** | 가중치가 손실에 미치는 영향 | 각 공정의 책임 비율 |
| **가중치 업데이트** | w = w - lr × 기울기 | 책임진 만큼 개선 |

### 9.3 역전파 공식 요약

```
1. 손실의 미분 (시작점)
   dL/dy_pred = 2(y_pred - y_true)   [MSE의 경우]

2. 활성화 함수 미분
   Sigmoid: da/dz = a(1-a)
   ReLU:    da/dz = 1 (z>0), 0 (z≤0)
   Tanh:    da/dz = 1 - a²

3. 선형 변환 미분
   z = Wx + b
   dz/dW = x
   dz/db = 1
   dz/dx = W

4. 연쇄 법칙
   dL/dW = dL/da × da/dz × dz/dW
```

### 9.4 체크리스트

- [ ] 역전파가 "책임 추적"이라는 것을 이해했다
- [ ] 연쇄 법칙이 왜 필요한지 안다
- [ ] 간단한 예제를 손으로 따라갈 수 있다
- [ ] numpy로 역전파를 구현할 수 있다
- [ ] PyTorch의 `loss.backward()`가 하는 일을 안다
