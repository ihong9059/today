# Level 9: 종합 프로젝트 - 번호판 인식 시스템

## 개요

Level 9는 지금까지 배운 모든 내용을 종합하여 **실제 동작하는 번호판 인식 시스템(LPR: License Plate Recognition)**을 구축하는 종합 프로젝트입니다.

### 프로젝트 목표
- 이미지에서 번호판을 자동으로 검출하고 문자를 인식
- 95% 이상 정확도, 200ms 이내 추론 속도
- REST API로 서비스 배포

## 핵심 아키텍처: 2단계 파이프라인

```
[입력 이미지] → [1단계: 번호판 검출] → [2단계: 문자 인식] → [결과 출력]
                  (Detection)            (Recognition)
                  YOLO 모델               CNN 모델
                  "어디에 있나?"           "뭐라고 쓰여 있나?"
```

### 왜 2단계로 나누는가?

| 항목 | End-to-End (1단계) | 2-Stage (2단계) |
|------|-------------------|----------------|
| 구조 | 이미지 → 바로 텍스트 | 이미지 → 검출 → 인식 |
| 학습 난이도 | 매우 높음 | 각 단계별로 쉬움 |
| 디버깅 | 어디서 틀렸는지 파악 어려움 | 검출/인식 문제 분리 가능 |
| 모듈 교체 | 전체 재학습 필요 | 해당 모듈만 교체 가능 |

## 레슨별 핵심 개념 요약

### 9-1: 프로젝트 개요
- **LPR 시스템**: 번호판 검출 + 문자 인식
- **요구사항 분석**: 기능(F1~F6) + 비기능(N1~N6) 요구사항 정의
- **모듈화 설계**: 독립 개발 → 통합 테스트

### 9-2: 데이터 파이프라인
- **데이터 수집**: 공개 데이터 + 직접 촬영 + 합성 데이터
- **라벨링**: YOLO 형식(검출) + CSV(인식)
- **데이터 증강**: Albumentations 활용

### 9-3: 번호판 검출 (YOLO)
- **Object Detection**: 위치 + 클래스 동시 예측
- **One-stage vs Two-stage**: YOLO는 실시간 처리에 최적
- **NMS**: 중복 박스 제거

### 9-4: 문자 인식 (CNN)
- **OCR**: 광학 문자 인식
- **문자 단위 분류**: 각 문자를 개별 클래스로 분류
- **후처리**: 문자열 조합, 형식 검증

### 9-5: 모델 통합 및 평가
- **IoU**: 바운딩 박스 겹침 정도
- **mAP**: 검출 종합 성능 지표
- **Confusion Matrix**: 문자 혼동 패턴 분석

### 9-6: 모델 배포
- **모델 저장**: state_dict, TorchScript, ONNX
- **FastAPI**: REST API 구축
- **Docker**: 컨테이너화 배포

### 9-7: MLOps 기초
- **버전 관리**: Git(코드), MLflow/DVC(모델/데이터)
- **CI/CD**: 자동 테스트 + 배포
- **모니터링**: 드리프트 감지, A/B 테스트

### 9-8: 최종 회고
- **전체 여정 리뷰**: Level 0~9
- **커리어 가이드**: ML 엔지니어, CV 엔지니어
- **다음 학습 방향**: Kaggle, 논문, 새 프로젝트
