## 🔄 1. for 반복문 - AI 학습의 심장

### 기본 구조
```python
for epoch in range(100):
    train_one_epoch()
```

### AI에서의 의미
```
┌─────────────────────────────────────────┐
│  Epoch = 전체 데이터를 한 번 학습        │
│                                         │
│  range(100) = 100번 반복               │
│  → 전체 데이터를 100번 보겠다!          │
└─────────────────────────────────────────┘
```

### 실제 학습 코드
```python
for epoch in range(100):
    print(f"Epoch {epoch+1}/100")

    total_loss = 0
    for batch in dataloader:
        loss = train_step(batch)
        total_loss += loss

    print(f"Loss: {total_loss/len(dataloader):.4f}")
```

## 📦 2. 중첩 for 루프 - Batch 처리

### 왜 Batch가 필요한가?
```
전체 데이터: 100만 장의 이미지
메모리 한계: 한 번에 100만 장 못 올림
→ 32장씩 나눠서 처리 = Batch!
```

### 이중 반복문 구조
```python
for epoch in range(100):              # 바깥 루프: Epoch
    for batch in dataloader:          # 안쪽 루프: Batch
        output = model(batch)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
```

### 용어 정리
| 용어 | 의미 | 예시 |
|------|------|------|
| **Epoch** | 전체 데이터 1회 학습 | 100 epochs |
| **Batch** | 한 번에 처리하는 데이터 묶음 | 32개 |
| **Iteration** | 1개 배치 처리 단위 | 3125회 (10만/32) |

### 시각화
```
전체 데이터 10만 개, Batch Size 32일 때:

Epoch 1: [Batch 1][Batch 2][Batch 3]...[Batch 3125]
         ↓        ↓        ↓           ↓
         32개     32개     32개        32개

Epoch 2: [Batch 1][Batch 2][Batch 3]...[Batch 3125]
...
Epoch 100: [Batch 1][Batch 2]...[Batch 3125]
```

## ✋ 3. if 조건문 - Early Stopping

### 과적합 방지의 핵심!
```python
best_loss = float('inf')
patience = 0
max_patience = 10

for epoch in range(100):
    train_loss = train()
    val_loss = validate()

    if val_loss < best_loss:
        best_loss = val_loss
        save_model('best_model.pth')
        patience = 0
        print("✓ 최고 모델 저장!")
    else:
        patience += 1
        print(f"⚠ 개선 없음 ({patience}/{max_patience})")

        if patience >= max_patience:
            print("🛑 Early Stopping!")
            break  # 학습 중단
```

### 동작 원리
```
Epoch 1:  val_loss = 0.5  → 저장 ✓, patience = 0
Epoch 2:  val_loss = 0.4  → 저장 ✓, patience = 0
Epoch 3:  val_loss = 0.35 → 저장 ✓, patience = 0
Epoch 4:  val_loss = 0.36 → patience = 1 ⚠
Epoch 5:  val_loss = 0.37 → patience = 2 ⚠
...
Epoch 13: val_loss = 0.40 → patience = 10 → STOP! 🛑
```

## 📉 4. 학습률 스케줄링

### 왜 필요한가?
```
초반: 큰 보폭으로 빠르게 최적점 근처로
후반: 작은 보폭으로 정밀하게 최적점 도달
```

### if 조건문 활용
```python
initial_lr = 0.001

for epoch in range(100):
    # 학습률 조정
    if epoch < 50:
        lr = initial_lr
    elif epoch < 80:
        lr = initial_lr * 0.1    # 10배 감소
    else:
        lr = initial_lr * 0.01   # 100배 감소

    # optimizer에 적용
    for param_group in optimizer.param_groups:
        param_group['lr'] = lr
```

### PyTorch 내장 스케줄러
```python
from torch.optim.lr_scheduler import StepLR

scheduler = StepLR(optimizer, step_size=30, gamma=0.1)

for epoch in range(100):
    train()
    scheduler.step()  # 자동으로 학습률 조정
```

## 🔁 5. while 반복문

### 목표 달성까지 반복
```python
accuracy = 0
epoch = 0

while accuracy < 0.95:  # 95% 정확도까지 학습
    epoch += 1
    accuracy = train_and_evaluate()
    print(f"Epoch {epoch}: Accuracy = {accuracy:.2%}")

print(f"목표 달성! {epoch}번 만에 95% 정확도 도달!")
```

### 강화학습에서 자주 사용
```python
while not done:
    action = agent.select_action(state)
    next_state, reward, done = env.step(action)
    agent.learn(state, action, reward, next_state)
    state = next_state
```

## 🧩 실전 학습 루프 전체 구조

```python
import torch

# 설정
epochs = 100
best_loss = float('inf')
patience = 0
max_patience = 10

# 학습 루프
for epoch in range(epochs):
    # 1. 학습 모드
    model.train()
    train_loss = 0

    for batch in train_loader:
        optimizer.zero_grad()
        output = model(batch)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
        train_loss += loss.item()

    # 2. 평가 모드
    model.eval()
    val_loss = evaluate()

    # 3. Early Stopping 체크
    if val_loss < best_loss:
        best_loss = val_loss
        torch.save(model.state_dict(), 'best.pth')
        patience = 0
    else:
        patience += 1
        if patience >= max_patience:
            break

    # 4. 학습률 스케줄링
    scheduler.step()
```
