## 프로젝트 개요

### 목적
> **AI가 실제로 어떻게 동작하는지** 체험하고 이해하는 교육 시스템 구축

### 대상
- 중학생 (1~3학년)
- AI에 관심 있는 초보자

### 교육 철학
```
"듣는 것은 잊어버리고,
 보는 것은 기억하고,
 직접 해보는 것은 이해한다."

 → Physical AI로 직접 만들고 체험하는 교육!
```

## 시스템별 상세

### 시스템 1: 번호판/문자 인식 (PC & Raspberry Pi 5)

| 항목 | 내용 |
|------|------|
| **플랫폼** | PC (Windows/Linux), Raspberry Pi 5 |
| **입력** | 스마트폰 IP Webcam 영상 |
| **AI 기술** | OCR (광학 문자 인식), 딥러닝 |
| **출력** | 인식된 글자 + 확률(%) |
| **교육 목표** | 이미지 처리, 신경망 기초 이해 |

**시스템 흐름:**
```
스마트폰 카메라 → WiFi 전송 → 영상 표시 → Capture → AI 분석 → 결과
```

**상세 보고서:** `01_번호판_문자인식_시스템.md`

---

### 시스템 2: 고장 예측 (ESP32)

| 항목 | 내용 |
|------|------|
| **플랫폼** | ESP32 마이크로컨트롤러 |
| **입력** | MPU6050 (진동), 마이크 (소음) |
| **AI 기술** | 패턴 분석, 이상 감지, 예측 |
| **출력** | 정상/이상 상태, 고장 예측 |
| **교육 목표** | 센서 원리, 데이터 분석, IoT |

**시스템 흐름:**
```
기계 진동/소음 → 센서 측정 → 특징 추출 → AI 분석 → 상태 판단 → 알림
```

**상세 보고서:** `02_ESP32_고장예측_시스템.md`

---

### 시스템 3: 스마트폰 올인원 (NEW!)

| 항목 | 내용 |
|------|------|
| **플랫폼** | Android / iOS 스마트폰 |
| **입력** | 스마트폰 내장 카메라 |
| **AI 기술** | ML Kit, TensorFlow Lite (온디바이스) |
| **출력** | 실시간 인식 결과 + 확률(%) |
| **교육 목표** | 온디바이스 AI, 앱 개발 기초 |

**시스템 흐름:**
```
카메라 촬영 → 전처리 → AI 분석(NPU) → 결과 표시 (모두 스마트폰 내에서!)
```

**장점:**
- 추가 장비 불필요 (스마트폰만 있으면 됨)
- 설정 간단, 즉시 체험 가능
- 휴대성 최고, 실용성 높음

**구현 방법 3가지:**
1. 기존 앱 활용 (Google Lens 등)
2. MIT App Inventor (블록 코딩)
3. 직접 개발 (Android Studio + ML Kit)

**상세 보고서:** `03_스마트폰_올인원_시스템.md`
