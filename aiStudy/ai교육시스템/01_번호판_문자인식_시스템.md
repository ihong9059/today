## 1. 시스템의 필요성 (교육 목적 포함)

### 1.1 왜 이 시스템을 배워야 할까요?

**일상생활 속 AI 기술**
- 주차장 자동 요금 정산 시스템
- 과속 단속 카메라
- 무인 주차 시스템
- 도서관 책 제목 자동 인식

**교육적 목적**

| 학습 목표 | 설명 |
|-----------|------|
| AI의 기본 원리 이해 | 컴퓨터가 어떻게 "보고" "읽는지" 체험 |

```
✅ 카메라로 영상을 받아오는 방법
✅ 영상에서 원하는 부분(번호판)을 찾는 방법
✅ 찾은 부분에서 글자를 읽는 방법
✅ AI가 얼마나 확신하는지 (확률) 이해하기
```

## 3. 시스템의 작동 원리 (중학생용 상세 설명)

### 3.1 전체 흐름 (5단계)

```
1단계          2단계          3단계          4단계          5단계
영상 촬영  →  영상 전송  →  화면 표시  →  AI 분석  →  결과 표시
(스마트폰)    (WiFi)       (PC화면)     (두뇌역할)   (글자+확률)
```

---

### 3.2 각 단계 상세 설명

#### 📱 1단계: 영상 촬영 (스마트폰)

**IP Webcam이란?**
> 스마트폰을 무선 카메라로 만들어주는 앱입니다.

**작동 방식:**
1. 스마트폰에서 IP Webcam 앱을 실행
2. 앱이 카메라 영상을 **인터넷 주소(IP)**로 내보냄
3. 예: `http://192.168.0.10:8080/video`

**쉬운 비유:**
```
스마트폰 = TV 방송국 📺
IP 주소 = 채널 번호
PC/라즈베리파이 = TV (시청자)
```

---

#### 📡 2단계: 영상 전송 (WiFi)

**어떻게 전달될까?**

```
스마트폰 ──WiFi──▶ 공유기 ──WiFi──▶ PC/Raspberry Pi
   │                                      │
   │      같은 집(네트워크) 안에서         │
   └──────────────────────────────────────┘
```

**데이터 흐름:**
- 1초에 약 30장의 사진(프레임)을 전송
- 사진들이 빠르게 바뀌면서 동영상처럼 보임

**쉬운 비유:**
```
플립북(만화책 넘기기)처럼!
한 장 한 장은 사진이지만, 빨리 넘기면 움직이는 것처럼 보여요.
```

---

#### 🖥️ 3단계: 화면 표시 및 캡처

**프로그램 화면 구성:**

```
┌─────────────────────────────────────┐
│         번호판 인식 프로그램          │
├─────────────────────────────────────┤
│                                     │
│     ┌─────────────────────┐         │
│     │                     │         │
│     │    실시간 영상      │         │
│     │    (카메라 화면)    │         │
│     │                     │         │
│     └─────────────────────┘         │
│                                     │
│     [ 📷 Capture 버튼 ]             │
│                                     │
│     ┌─────────────────────┐         │
│     │ 인식 결과:          │         │
│     │ 12가 3456           │         │
│     │ 확률: 94.5%         │         │
│     └─────────────────────┘         │
└─────────────────────────────────────┘
```

**Capture 버튼을 누르면?**
1. 현재 영상에서 한 장의 사진을 "찰칵" 저장
2. 저장된 사진을 AI에게 전달
3. AI가 분석 시작!

#### 🧠 4단계: AI 분석 (핵심!)

**AI가 글자를 읽는 과정:**

```
원본 이미지
    │
    ▼
┌─────────────┐
│ 1. 전처리   │ → 사진을 AI가 읽기 쉽게 가공
└─────────────┘
    │
    ▼
┌─────────────┐
│ 2. 영역찾기 │ → 번호판 위치를 찾아냄
└─────────────┘
    │
    ▼
┌─────────────┐
│ 3. 글자분리 │ → 한 글자씩 잘라냄
└─────────────┘
    │
    ▼
┌─────────────┐
│ 4. 글자인식 │ → 각 글자가 무엇인지 판단
└─────────────┘
    │
    ▼
결과 출력
```

---

##### 🔍 4-1단계: 전처리 (사진 정리하기)

**왜 필요할까?**
> AI도 깔끔한 사진을 더 잘 읽어요!

**전처리 과정:**

| 과정 | 설명 | 예시 |
|------|------|------|
| 그레이스케일 | 컬러 → 흑백 변환 | 🌈 → ⬛⬜ |
| 노이즈 제거 | 지저분한 점 제거 | 깨끗하게 정리 |
| 이진화 | 글자=검정, 배경=흰색 | 대비를 극대화 |
| 크기 조절 | 적당한 크기로 조정 | 너무 작으면 확대 |

**쉬운 비유:**
```
숙제를 선생님께 제출할 때:
  ❌ 구겨진 종이, 낙서 있는 것
  ✅ 깨끗하고 정돈된 것

AI도 마찬가지예요!
```

---

##### 🎯 4-2단계: 번호판 영역 찾기

**어떻게 찾을까?**

```
전체 사진에서 번호판만 찾아내기:

┌─────────────────────────┐
│  🚗                     │
│    ┌─────────┐          │
│    │ 12가3456│ ← 여기!  │
│    └─────────┘          │
│                         │
└─────────────────────────┘
```

**번호판의 특징:**
- 직사각형 모양
- 특정 비율 (가로가 세로보다 긺)
- 흰색 또는 노란색 배경
- 진한 글씨

**AI의 생각 과정:**
```
"음... 이 사진에서 직사각형을 찾아보자"
"비율이 맞는 것을 골라보자"
"글자가 있는 것 같은 부분을 선택!"
→ 번호판 발견! ✅
```

##### ✂️ 4-3단계: 글자 분리

**한 글자씩 잘라내기:**

```
┌─────────────────────┐
│  1 2 가 3 4 5 6    │
└─────────────────────┘
         ↓ 분리
┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
│1│ │2│ │가│ │3│ │4│ │5│ │6│
└─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘
```

**분리 방법:**
1. 글자 사이의 빈 공간(흰색 영역) 찾기
2. 빈 공간을 기준으로 자르기
3. 각 글자를 개별 이미지로 저장

##### 🔤 4-4단계: 글자 인식 (OCR)

**OCR이란?**
> **O**ptical **C**haracter **R**ecognition
> 광학 문자 인식 = 사진 속 글자를 텍스트로 변환

**AI의 글자 인식 방법 (신경망):**

```
입력: 글자 이미지 "가"

    ┌─────────────────────────────────────┐
    │           인공 신경망               │
    │                                     │
    │  입력층    은닉층      출력층       │
    │    ○ ─────○─────○                  │
    │    ○ ─────○─────○ ────▶ "가" 98%   │
    │    ○ ─────○─────○       "나" 1%    │
    │    ○ ─────○─────○       "다" 0.5%  │
    │   ...    ...   ...       ...       │
    └─────────────────────────────────────┘

결과: "가"일 확률 98%!
```

**쉬운 비유 - 선생님의 채점:**
```
학생이 쓴 글씨를 보고...

선생님: "이건 '가'인 것 같은데...
         98% 확신해!
         근데 혹시 '나'일 수도... 1%?"

→ 가장 확률 높은 것으로 결정!
```

**AI가 학습한 방법:**
1. 수만 개의 글자 예시를 봤어요
2. "이건 '가'야, 이건 '나'야" 라고 배웠어요
3. 패턴을 기억해서 새로운 글자도 맞출 수 있어요

│                                     │
│  인식 확률:                         │
│  ├─ "1" → 99.2% ✅                  │

│  ├─ "가" → 94.5% ✅                 │
│  ├─ "3" → 98.1% ✅                  │

**확률의 의미:**
- **90% 이상**: AI가 "거의 확실해!" 라고 말하는 것
- **70~90%**: "아마 맞을 거야"
- **70% 미만**: "잘 모르겠어..."

### 3.3 PC vs Raspberry Pi 5 비교

| 항목 | PC | Raspberry Pi 5 |
|------|-----|----------------|
| 처리 속도 | 빠름 ⚡ | 보통 |
| 크기 | 큼 | 신용카드 크기 📇 |
| 가격 | 비쌈 | 저렴 (약 10만원) |
| 전력 소비 | 높음 | 낮음 (5V) |
| 교육적 가치 | 기본 학습 | 임베디드 시스템 이해 |

**둘 다 배우면 좋은 이유:**
- PC: 빠른 테스트와 개발
- Raspberry Pi: 실제 IoT 환경 체험
