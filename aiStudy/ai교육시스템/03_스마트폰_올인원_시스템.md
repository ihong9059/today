```
│   └─────────┘            └──────────────────┘                  │

│   │       ↓                                 │                  │
│   │  📊 결과 표시                           │                  │
│   └─────────────────────────────────────────┘                  │
│                                                                 │
│   장점: 장비 1개, 설정 간단, 실시간 처리, 휴대 용이             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 왜 가능할까?

**현대 스마트폰의 성능:**

| 항목 | 2015년 스마트폰 | 2024년+ 스마트폰 |
|------|-----------------|------------------|
| CPU | 쿼드코어 1.5GHz | 옥타코어 3.0GHz+ |
| RAM | 2GB | 8~16GB |
| NPU | 없음 | AI 전용 프로세서 탑재 |
| 카메라 | 12MP | 50~200MP, AI 보정 |
| 저장공간 | 16GB | 128~512GB |

**NPU (Neural Processing Unit)란?**
> AI 연산에 특화된 칩. 이미지 인식, 음성 인식 등을 빠르게 처리

```
삼성 갤럭시: Exynos NPU
아이폰: Neural Engine
구글 픽셀: Tensor TPU
```

**TextAnalyzer.kt (OCR 처리):**

```kotlin
class TextAnalyzer : ImageAnalysis.Analyzer {

    private val recognizer = TextRecognition.getClient(
        KoreanTextRecognizerOptions.Builder().build()
    )

    override fun analyze(imageProxy: ImageProxy) {
        val mediaImage = imageProxy.image ?: return

        val image = InputImage.fromMediaImage(
            mediaImage,
            imageProxy.imageInfo.rotationDegrees
        )

        recognizer.process(image)
            .addOnSuccessListener { result ->
                // 인식된 텍스트 처리
                val recognizedText = result.text
                Log.d("OCR", "인식 결과: $recognizedText")

                // 번호판 패턴 추출
                val platePattern = Regex("\\d{2,3}[가-힣]\\d{4}")
                val plate = platePattern.find(recognizedText)
                plate?.let {
                    Log.d("OCR", "번호판: ${it.value}")
                }
            }
            .addOnCompleteListener {
                imageProxy.close()
            }
    }
}
```

**장점:**
- 완전한 커스터마이징

```
🧠 CPU (중앙처리장치):
   "나는 뭐든지 할 수 있어! 하지만 AI 계산은 좀 느려..."

🎮 GPU (그래픽처리장치):
   "나는 그림 그리는 게 특기야. AI도 꽤 잘해!"

🤖 NPU (신경망처리장치):
   "나는 AI 계산만 전문이야! 초고속으로 해줄게!"

비유:
┌─────────────────────────────────────────┐
│  CPU = 만능 요리사 (뭐든 함, 느림)      │
│  GPU = 그림 전문가 (그래픽+AI 겸함)     │
│  NPU = AI 전문가 (AI만 초고속!)        │
└─────────────────────────────────────────┘
```
