## 1. 역전파란 무엇인가?

### 1.1 한 줄 정의

> **역전파(Backpropagation)**는 신경망이 "얼마나 틀렸는지"를 계산하고, 그 오차를 거꾸로 전파하여 각 가중치를 조금씩 수정하는 학습 방법입니다.

### 1.2 쉬운 비유: 활쏘기 연습

```
🎯 목표: 과녁 중앙 맞추기

1회차: 화살이 오른쪽으로 20cm 빗나감
       → "오른쪽으로 너무 쐈구나" → 왼쪽으로 조준 수정

2회차: 화살이 왼쪽으로 5cm 빗나감
       → "조금 왼쪽으로 갔네" → 오른쪽으로 살짝 수정

3회차: 중앙 명중!
```

신경망도 똑같습니다:
- **순전파(Forward)**: 화살을 쏘는 것 (예측 만들기)
- **오차 계산**: 과녁에서 얼마나 빗나갔는지 측정
- **역전파(Backward)**: 조준을 수정하는 것 (가중치 조정)

### 1.3 신경망에서의 역전파

```
입력층      은닉층       출력층
  ○ ──┐
       ├──→ ○ ──┐
  ○ ──┤          ├──→ ○ ──→ 예측값
       ├──→ ○ ──┘              ↓
  ○ ──┘                     오차 계산
                               ↓
  ←←←←←←←←←←←←←←←←←←←←←←← 역전파 (오차를 거꾸로 전달)
```

## 2. 왜 역전파가 필요한가?

### 2.1 신경망 학습의 핵심 문제

신경망에는 수백만~수십억 개의 **가중치(weight)**가 있습니다.

```
문제: 이 수많은 가중치를 어떻게 조정해야 할까?

가중치 1개 = 1개의 "조절 나사"
가중치 1억 개 = 1억 개의 나사를 동시에 조절해야 함!
```

### 2.2 역전파 없이 학습한다면?

**방법 1: 랜덤 시도 (무작위 탐색)**
```
- 가중치를 랜덤하게 바꿔보고
- 결과가 좋아지면 유지, 나빠지면 취소
- 문제: 1억 개 가중치 × 무한한 조합 = 영원히 못 끝남
```

**방법 2: 하나씩 조정**
```
- 가중치 1개를 조금 바꿔보고 결과 확인
- 다음 가중치로 이동...
- 문제: 1억 번 반복해야 1회 학습 완료 (너무 느림)
```

### 2.3 역전파의 해결책

```
역전파의 핵심: "모든 가중치를 한 번에 계산"

1. 순전파로 예측 생성 (1회)
2. 오차 계산 (1회)
3. 미분을 이용해 모든 가중치의 조정량을 한꺼번에 계산 (1회)

→ 3단계만에 1억 개 가중치 업데이트 방향 결정!
```

## 3. 역전파의 작동 원리

### 3.1 핵심 수학: 연쇄 법칙 (Chain Rule)

역전파는 **미분의 연쇄 법칙**을 사용합니다.

```
연쇄 법칙이란?

y = f(g(x)) 일 때

dy/dx = (dy/dg) × (dg/dx)

"최종 결과의 변화 = 중간 결과들의 변화의 곱"
```

### 3.2 간단한 예제: 2층 신경망

```
입력: x = 2
가중치: w1 = 3, w2 = 4
목표값: target = 50

계산 과정:
  h = x × w1 = 2 × 3 = 6       (은닉층)
  y = h × w2 = 6 × 4 = 24      (출력)

오차: Loss = (target - y)² = (50 - 24)² = 676
```

**역전파 계산:**

```
목표: Loss를 줄이려면 w1, w2를 얼마나 바꿔야 할까?

Step 1: Loss가 y에 얼마나 민감한가?
  dLoss/dy = 2(y - target) = 2(24 - 50) = -52

Step 2: y가 w2에 얼마나 민감한가?
  dy/dw2 = h = 6

Step 3: w2의 조정량 (연쇄 법칙)
  dLoss/dw2 = (dLoss/dy) × (dy/dw2) = -52 × 6 = -312

  → w2를 증가시키면 Loss가 감소! (음수이므로)

Step 4: y가 h에 얼마나 민감한가?
  dy/dh = w2 = 4

Step 5: h가 w1에 얼마나 민감한가?
  dh/dw1 = x = 2

Step 6: w1의 조정량 (연쇄 법칙)
  dLoss/dw1 = (dLoss/dy) × (dy/dh) × (dh/dw1)
            = -52 × 4 × 2 = -416

  → w1을 증가시키면 Loss가 감소!
```

**가중치 업데이트:**

```
학습률(learning rate) = 0.001

w1_new = w1 - 학습률 × dLoss/dw1
       = 3 - 0.001 × (-416)
       = 3 + 0.416 = 3.416

w2_new = w2 - 0.001 × (-312)
       = 4 + 0.312 = 4.312
```

### 3.3 그림으로 보는 역전파

```
순전파 (Forward Pass) →→→→→→→→→→→→→→→→→→→
                                          ↓
[입력 x] → [×w1] → [은닉 h] → [×w2] → [출력 y] → [Loss]
                                          ↓
역전파 (Backward Pass) ←←←←←←←←←←←←←←←←←←←
    ↓          ↓           ↓
  dL/dw1    (전달)      dL/dw2

각 가중치마다 "Loss를 얼마나 바꾸는가"를 계산
```

### 3.4 활성화 함수와 역전파

실제 신경망에는 **활성화 함수**(ReLU, Sigmoid 등)가 있습니다.

```
ReLU 함수: f(x) = max(0, x)

ReLU의 미분:
  x > 0 이면: f'(x) = 1  (기울기 그대로 전달)
  x ≤ 0 이면: f'(x) = 0  (기울기 차단)

역전파 시:
  - 양수였던 뉴런: 오차를 그대로 뒤로 전달
  - 음수였던 뉴런: 오차 전달 중단 (학습 안 됨)
```

## 4. LLM에서의 역전파

### 4.1 LLM의 구조

LLM(Large Language Model)은 **트랜스포머(Transformer)** 아키텍처를 사용합니다.

```
GPT, Claude, LLaMA 등의 구조:

[입력 토큰] → [임베딩] → [트랜스포머 블록 ×N] → [출력 확률]
                              ↓
                        각 블록 구성:
                        - Self-Attention (자기 주의)
                        - Feed-Forward Network
                        - Layer Normalization
```

### 4.2 LLM 학습 과정

**Step 1: 데이터 준비**
```
학습 데이터: "오늘 날씨가 [좋다]"

입력: "오늘 날씨가"
정답: "좋다"
```

**Step 2: 순전파 (예측)**
```
모델 입력: "오늘 날씨가"
모델 예측 확률:
  - "좋다": 0.15 (15%)
  - "춥다": 0.12 (12%)
  - "덥다": 0.08 (8%)
  - ...기타 단어들
```

**Step 3: 손실 계산**
```
Cross-Entropy Loss 사용

정답 = "좋다"
예측 확률 = 0.15

Loss = -log(0.15) = 1.89

(확률이 1에 가까울수록 Loss → 0)
(확률이 0에 가까울수록 Loss → ∞)
```

**Step 4: 역전파**
```
Loss = 1.89를 줄이기 위해:

1. 출력층에서 시작
   → "좋다"의 확률을 높이는 방향으로 가중치 조정

2. 트랜스포머 블록들을 거슬러 올라감
   → 각 Attention, FFN의 가중치에 대한 기울기 계산

3. 임베딩 층까지 전파
   → 단어 벡터 조정

총 가중치 수: 수십억 ~ 수천억 개
모두 한 번의 역전파로 업데이트 방향 계산!
```

### 4.3 Attention에서의 역전파

Attention 메커니즘도 미분 가능합니다:

```
Attention(Q, K, V) = softmax(QK^T / √d) × V

역전파 시:
1. V에 대한 기울기: softmax 결과를 그대로 전달
2. Q, K에 대한 기울기: softmax 미분 + 행렬곱 미분

→ "어떤 단어에 주목해야 하는지"를 학습
```

### 4.4 LLM 학습의 특징

```
일반 신경망 vs LLM:

| 항목 | 일반 신경망 | LLM |
|------|------------|-----|
| 파라미터 수 | 수백만 | 수십억~수천억 |
| 학습 데이터 | GB 단위 | TB 단위 |
| 학습 시간 | 시간~일 | 주~월 |
| GPU 수 | 1~8개 | 수백~수천 개 |

역전파 원리는 동일하지만 규모가 압도적으로 큼!
```

## 5. GPU가 사용되는 이유

### 5.1 CPU vs GPU 구조

```
CPU (Central Processing Unit):
┌─────────────────────────────────┐
│ [강력한 코어] [강력한 코어]      │
│ [강력한 코어] [강력한 코어]      │  ← 4~16개의 강력한 코어
│                                 │
│ 큰 캐시 메모리                   │
│ 복잡한 제어 장치                 │
└─────────────────────────────────┘
특징: 복잡한 작업을 빠르게 (직렬 처리)


GPU (Graphics Processing Unit):
┌─────────────────────────────────────────────┐
│ [코어][코어][코어][코어][코어][코어][코어]    │
│ [코어][코어][코어][코어][코어][코어][코어]    │
│ [코어][코어][코어][코어][코어][코어][코어]    │  ← 수천 개의 작은 코어
│ [코어][코어][코어][코어][코어][코어][코어]    │
│ ...                                         │
└─────────────────────────────────────────────┘
특징: 단순한 작업을 동시에 (병렬 처리)
```

### 5.2 신경망 연산의 특징

신경망은 **행렬 연산**이 대부분입니다:

```
행렬 곱셈 예시:

[a b]   [e f]   [ae+bg  af+bh]
[c d] × [g h] = [ce+dg  cf+dh]

각 요소의 계산이 독립적!
→ 4개의 계산을 동시에 할 수 있음
```

**실제 LLM에서의 행렬 크기:**
```
GPT-3 기준:
- 입력 행렬: [2048 × 12288]
- 가중치 행렬: [12288 × 12288]
- 결과 행렬: [2048 × 12288]

총 연산 수: 2048 × 12288 × 12288 = 약 3,000억 번의 곱셈+덧셈
```

### 5.3 CPU vs GPU 성능 비교

```
예시: 1억 개의 숫자 더하기

CPU (8코어):
  - 8개를 동시에 처리
  - 1억 ÷ 8 = 1,250만 번의 사이클

GPU (10,000코어):
  - 10,000개를 동시에 처리
  - 1억 ÷ 10,000 = 1만 번의 사이클

→ GPU가 1,250배 빠름!
```

### 5.4 역전파에서 GPU의 역할

```
역전파 = 수많은 기울기(gradient) 계산

가중치 1억 개 → 기울기 1억 개 계산 필요

CPU: 순차적으로 계산 → 매우 느림
GPU: 병렬로 동시 계산 → 매우 빠름

실제 속도 차이:
- CPU로 LLM 학습: 수백 년
- GPU로 LLM 학습: 수개월
```

## 6. GPU 활용 방법

### 6.1 딥러닝 프레임워크

```python
# PyTorch 예시

import torch

# GPU 사용 설정
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 모델을 GPU로 이동
model = MyNeuralNetwork().to(device)

# 데이터를 GPU로 이동
data = data.to(device)

# 학습 (자동으로 GPU에서 실행)
output = model(data)
loss = criterion(output, target)
loss.backward()  # 역전파 - GPU에서 병렬 계산!
optimizer.step()
```

### 6.2 GPU 메모리 구조

```
GPU 메모리 (VRAM):

┌─────────────────────────────────────┐
│ 모델 가중치 (Parameters)             │  ← 모델 크기
├─────────────────────────────────────┤
│ 기울기 (Gradients)                   │  ← 역전파용
├─────────────────────────────────────┤
│ 옵티마이저 상태 (Adam moments 등)    │  ← 학습 정보
├─────────────────────────────────────┤
│ 활성화 값 (Activations)              │  ← 순전파 중간 결과
├─────────────────────────────────────┤
│ 입력 데이터 (Batch)                  │  ← 현재 처리 중인 데이터
└─────────────────────────────────────┘

예: 7B 모델 (70억 파라미터)
- 가중치: 14GB (FP16 기준)
- 기울기: 14GB
- 옵티마이저: 28GB (Adam)
- 활성화: 가변적

→ 최소 56GB+ VRAM 필요!
```

### 6.3 대규모 모델의 GPU 활용

**문제: 하나의 GPU에 모델이 안 들어감**

**해결책 1: 데이터 병렬화 (Data Parallelism)**
```
┌────────────┐  ┌────────────┐  ┌────────────┐
│   GPU 0    │  │   GPU 1    │  │   GPU 2    │
│ 전체 모델   │  │ 전체 모델   │  │ 전체 모델   │
│ 배치 1/3   │  │ 배치 2/3   │  │ 배치 3/3   │
└────────────┘  └────────────┘  └────────────┘
       ↓              ↓              ↓
       └──────── 기울기 평균 ────────┘
                     ↓
              가중치 업데이트
```

**해결책 2: 모델 병렬화 (Model Parallelism)**
```
┌────────────┐  ┌────────────┐  ┌────────────┐
│   GPU 0    │  │   GPU 1    │  │   GPU 2    │
│ 레이어 1-10│→ │레이어 11-20│→ │레이어 21-30│
└────────────┘  └────────────┘  └────────────┘

모델을 여러 GPU에 나눠서 배치
```

**해결책 3: 텐서 병렬화 (Tensor Parallelism)**
```
하나의 거대한 행렬 연산을 여러 GPU로 분할:

┌─────────────────────────────┐
│      거대한 가중치 행렬      │
│  [GPU 0 부분] [GPU 1 부분]  │
└─────────────────────────────┘

각 GPU가 행렬의 일부분만 담당
```

### 6.5 효율적인 GPU 활용 기법

**1. Mixed Precision Training (혼합 정밀도)**
```
FP32 (32비트) → FP16 (16비트)

장점:
- 메모리 사용량 50% 감소
- 연산 속도 2배 향상
- 정확도는 거의 동일

코드:
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
with autocast():
    output = model(input)
    loss = criterion(output, target)
scaler.scale(loss).backward()
```

**2. Gradient Checkpointing (기울기 체크포인팅)**
```
문제: 역전파를 위해 순전파의 중간 결과를 모두 저장해야 함
     → 메모리 폭발

해결: 일부만 저장하고, 필요할 때 다시 계산

메모리: √N 으로 감소 (N = 레이어 수)
속도: 약 30% 느려짐
```

**3. Gradient Accumulation (기울기 누적)**
```
문제: 배치 크기를 키우고 싶지만 메모리 부족

해결: 작은 배치로 여러 번 계산 후 한 번에 업데이트

# 예: 배치 32를 원하지만 메모리는 배치 8만 가능
accumulation_steps = 4
for i, (data, target) in enumerate(dataloader):
    loss = model(data)
    loss = loss / accumulation_steps
    loss.backward()

    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

### 7.1 역전파 핵심 정리

| 개념 | 설명 |
|------|------|
| **역전파** | 오차를 출력층에서 입력층으로 거꾸로 전파하며 가중치 조정량 계산 |
| **필요성** | 수억 개의 가중치를 효율적으로 한 번에 업데이트 |
| **핵심 수학** | 연쇄 법칙 (Chain Rule)을 이용한 미분 |
| **순서** | 순전파 → 손실 계산 → 역전파 → 가중치 업데이트 |

### 7.2 LLM에서의 역전파

| 항목 | 내용 |
|------|------|
| **구조** | 트랜스포머 (Attention + FFN) |
| **손실 함수** | Cross-Entropy (다음 토큰 예측) |
| **특징** | 수십억~수천억 파라미터를 동시에 학습 |
| **학습 방식** | 자기회귀적 언어 모델링 |

### 7.3 GPU 활용

| 항목 | CPU | GPU |
|------|-----|-----|
| 코어 수 | 4~16개 | 수천~만 개 |
| 특화 작업 | 복잡한 순차 작업 | 단순한 병렬 작업 |
| 딥러닝 적합성 | 낮음 | 높음 |
| 행렬 연산 | 느림 | 매우 빠름 |

### 7.4 한 눈에 보는 전체 흐름

```
[학습 데이터]
      ↓
[순전파] ─────→ [예측] ─────→ [손실 계산]
      ↑                           ↓
      │                           │
[가중치 업데이트] ←── [역전파] ←──┘
      ↑                    │
      │                    ↓
      └──── [GPU 병렬 계산] ───┘

이 과정을 수백만~수십억 번 반복 = 학습 완료
```
