## 0. 교육 개요

### 0-1. 한 줄 소개
> **"AI 도구 13개를 학습 곡선 우선 5단계로 묶어, 초심자가 한 달 안에 일상 업무를 자동화할 수 있게 만드는 통합 교육"**

### 0-2. 교육 대상
| 대상 | 추천 정도 | 학습 후 효과 |
|------|----------|-------------|
| **중소기업 사무직 신입~5년차** | ⭐⭐⭐⭐⭐ | 매일 반복 업무를 Claude로 자동화, 보고서·문서 제작 시간 50%↓ |
| **1인 사업자/프리랜서** | ⭐⭐⭐⭐⭐ | 외주 없이 동영상·이미지·웹 콘텐츠 자체 제작 |
| **중소기업 대표/팀장** | ⭐⭐⭐⭐ | 직원 교육·디지털 전환 의사결정에 활용 |
| **개발자(주니어)** | ⭐⭐⭐⭐ | Claude Code + GitHub + AWS 통합 워크플로우 |
| **학생/취준생** | ⭐⭐⭐ | 포트폴리오·이력서·자기 PR 영상 자체 제작 |
| **대학교 비전공 교수/직원** | ⭐⭐⭐ | 강의 자료·연구 노트·발표 영상 제작 |

### 0-3. 교육 목표 (Learning Outcomes)
교육 종료 시점에 학습자는 다음을 **혼자서** 수행할 수 있어야 한다:

1. ✅ Claude Code를 터미널에서 실행하고, 기본 명령어로 파일 편집·검색을 시킬 수 있다
2. ✅ Obsidian Vault를 만들고, 양방향 링크로 자기만의 지식 네트워크를 구축한다
3. ✅ 자기만의 Skill(/work-start, /work-end 등)을 작성하고 실행한다
4. ✅ MCP를 설정해 Notion·Google Calendar에 Claude로 직접 접근한다
5. ✅ GitHub에 코드/문서를 commit·push하고, 다른 PC에서 이어 작업한다
6. ✅ SSH로 원격 서버에 접속하고, 포트포워딩으로 Jupyter를 사용한다
7. ✅ Tailscale로 내 모든 장비를 원클릭으로 연결한다
8. ✅ Slack 워크스페이스를 만들고 GitHub·MCP 봇 자동 알림을 설정한다
9. ✅ Google Colab에서 무료 GPU로 간단한 AI 모델을 실행한다
10. ✅ NotebookLM으로 PDF를 오디오 팟캐스트와 슬라이드로 변환한다
11. ✅ Remotion으로 30초 분량 자기 소개 영상을 코드로 만든다
12. ✅ AWS 프리티어로 EC2 서버를 생성하고 SSH로 접속한다
13. ✅ 13개 도구를 **연결**해 한 가지 실제 업무 시나리오를 자동화한다

### 0-4. 교육 산출물 (학습자가 가지고 가는 것)
| 산출물 | 형태 | 활용 |
|-------|------|------|

## 3. 5 Track 학습 의도

### Track A — 즉시 효용 핵심 3종 (1-2일)
**철학**: "내일 출근하자마자 쓸 수 있는 것부터"
- **Claude Code**: AI 비서를 터미널에 상주시킴 → 일상 명령의 50% 자동화

→ **이 3개만 익혀도 일주일 안에 업무 효율 체감 가능**

**철학**: "Claude를 나만의 도구로 변형"
- **Skill**: 매일 반복하는 절차를 슬래시 명령으로 압축

### Track C — 인프라 + 원격 환경 (2-3일)
**철학**: "혼자 PC 안에서 끝나지 않고, 외부 세계와 연결"

→ **재택·출장·다중 장비 사용 시나리오의 기반**

**철학**: "혼자 잘 쓰는 도구를, 팀 전체가 같이"

→ **개인 도구를 조직의 도구로 확장하는 단계**

### 📘 Module 01: Claude Code (Track A, 3시간)

**학습 목표**:
1. Claude Code의 본질을 이해 — "터미널의 AI 비서"
2. Node.js + Claude CLI를 본인 PC에 설치
3. 대화형 모드와 한 줄 명령(`-p`) 차이를 안다
4. 모델(Sonnet/Opus/Haiku) 선택 기준을 안다
5. 권한 모델(`y/n/always`)과 위험성을 이해한다

**핵심 메시지**:
> "Claude Code 없이 ChatGPT만 쓴다면, 매번 복사·붙여넣기를 반복하게 됩니다. Claude Code는 **터미널 안에서 직접 파일을 편집하고 명령을 실행**합니다."

**선수 학습**: 없음 (시작점)

**이론 강의 (1시간)**:
- 챗봇 vs CLI AI의 차이
- Claude Pro/Max 등급과 사용량 한도
- Node.js의 역할 (Claude CLI는 Node 패키지)

**실습 (2시간)**:
1. Node.js LTS 설치 + `node --version` 확인 (15분)
2. `npm install -g @anthropic-ai/claude-code` (10분)
3. `claude` 첫 실행 + OAuth 로그인 (15분)
4. 대화형 모드 5분 체험 ("안녕하세요" → "이 폴더 정리해줘")
5. `-p` 한 줄 명령 5개 직접 작성 (30분)
6. 모델 변경 (`/model`) 체험 — 동일 질문에 Sonnet vs Opus 응답 비교 (15분)
7. 권한 요청 시나리오 — `ls`, `git status`, `rm` (위험 명령 거부 연습) (20분)
8. 첫 작업: 현재 폴더에 `hello.py` 생성 후 실행 명령 시키기 (10분)

**검증 체크리스트**:
- [ ] `claude --version` 출력 확인
- [ ] 한 줄 명령으로 한국어 답변 받기
- [ ] 모델 3개 모두 한 번씩 사용해 보기
- [ ] 권한 요청을 한 번씩 `y`, `n`, `always` 모두 선택해 보기

**자주 막히는 지점**:
| 증상 | 원인 | 해결 |
|------|------|------|
| `claude` 명령을 찾을 수 없음 | npm 전역 경로 미등록 | `$env:PATH += ";C:\Users\사용자\AppData\Roaming\npm"` |
| 로그인 후에도 인증 실패 | 브라우저 캐시 | `claude logout` → `claude login` 재시도 |
| 응답이 너무 느림 | Opus 모델 사용 | `/model` → Sonnet 변경 |
| Pro 구독 안 됨 메시지 | 결제 미반영 | claude.ai에서 Settings > Billing 확인 |

**다음 모듈 연결**:
> "이제 Claude를 설치했으니, Claude가 정리할 **메모 저장소**가 필요합니다 — Module 02 Obsidian으로."

### 📘 Module 02: Obsidian (Track A, 3시간)

**학습 목표**:
1. 마크다운 + 양방향 링크의 가치를 이해
2. Vault 생성 + 첫 노트 작성
3. `[[링크]]` 문법으로 노트 간 연결
4. 그래프 뷰로 자기 지식 네트워크 시각화
5. 핵심 플러그인 설치 (Dataview, Calendar, Excalidraw)

**핵심 메시지**:
> "AI가 매일 쏟아내는 정보를 **그냥 메모장에 쌓으면** 일주일 후 사라집니다. Obsidian은 **양방향 링크 [[]]**로 정보를 그물망처럼 연결합니다. Notion은 협업 도구, Obsidian은 두뇌 확장 도구."

**선수 학습**: Module 01 (Claude Code)

## 8. FAQ (학습자 자주 묻는 질문)

### Q1. Claude Pro 구독이 꼭 필요한가요?
A. Module 01에서 Claude Code를 사용하려면 필수입니다. 다만 **Anthropic API 키 직접 발급**으로 토큰 단위 과금도 가능 (가벼운 학습은 월 $5 미만).

### Q2. Mac/Linux도 가능한가요?
A. 모든 도구가 macOS/Linux 지원. 다만 본 가이드는 Windows 기준이라 일부 명령어 차이 있음 (PowerShell vs bash). 강사가 Mac 사용자에게는 별도 안내.

### Q3. 학습 후 잊어버리지 않으려면?
A. **매일 /work-start로 시작 + /work-end로 종료** 습관이 핵심. Module 02 Obsidian Vault에 자기 학습 노트를 계속 누적하면 자연스럽게 복습됨.

### Q4. 회사에서 도구 사용을 막으면?
A. 일부 도구는 회사 보안 정책상 제약 가능 (특히 AWS, GitHub 공개 repo). 이 경우:
- **개인 PC + 개인 Google 계정**으로 우선 학습
- 회사 정책 변경 제안 시 본 교육의 ROI 자료 활용 (시간 절감 50%↑)

### Q5. 13개 다 외울 자신이 없어요
A. **Track A+B 5개만** 익혀도 충분합니다. 나머지는 필요할 때 다시 가이드 보면서 진행하면 됨. 본 교육은 **레퍼런스 매뉴얼**이지 암기용이 아님.

### Q6. 비용이 너무 많이 들어요 (Claude $20 + AWS + ...)
A. 실제 발생 비용:
- **반드시**: Claude Pro $20/월
- **선택**: AWS $0 (프리티어), Tailscale $0 (개인 사용), Slack $0 (무료 플랜), Notion $0
- **콘텐츠 도구**: ElevenLabs $5/월 (선택), Suno $0 (무료 플랜)
- **합계**: 최소 **$20/월** (약 28,000원)

→ 이 비용으로 시간 효율 50% 향상 시, 시급 2만원 기준 **월 1.5시간만 절약해도 본전**
