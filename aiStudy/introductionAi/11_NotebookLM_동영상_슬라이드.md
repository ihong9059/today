# NotebookLM으로 동영상 & 슬라이드 만들기

## 1. NotebookLM이란?
- Google이 만든 AI 기반 리서치/학습 도구
- 문서를 업로드하면 AI가 내용을 분석, 요약, 설명
- **Audio Overview (오디오 개요)**: 업로드한 자료를 팟캐스트 형태의 대화로 변환
- 문서 기반으로 정확한 답변 제공 (할루시네이션 최소화)
- 무료 사용 가능

## 2. NotebookLM 시작하기

### 2.1 접속
1. https://notebooklm.google.com 접속
2. Google 계정으로 로그인
3. "새 노트북" 클릭

### 2.2 소스 자료 업로드
지원 형식:
- Google Docs
- PDF 파일
- 텍스트 파일
- 웹사이트 URL
- YouTube 동영상 URL
- 복사-붙여넣기 텍스트

업로드 방법:
1. "소스 추가" 클릭
2. 파일 선택 또는 URL 입력
3. 최대 50개 소스 추가 가능

## 3. 동영상 제작 (Audio Overview 활용)

### 3.1 Audio Overview 생성
1. 소스 자료 업로드 완료
2. 우측 패널에서 "Audio Overview" 클릭
3. "생성" 버튼 클릭
4. 5~10분 대기 (AI가 대화 스크립트 생성 + 음성 합성)
5. 완성된 오디오 재생/다운로드

### 3.2 Audio Overview 커스터마이징
- "맞춤 설정" 옵션으로 대화 방향 지정
- 예: "초보자를 위해 쉽게 설명해줘"
- 예: "핵심 개념 3가지에 집중해줘"
- 언어: 한국어 지원 (소스가 한국어면 한국어로 생성)

### 3.3 오디오를 동영상으로 변환
방법 1: 간단한 슬라이드 영상
1. Audio Overview 다운로드 (mp3)
2. 핵심 내용을 슬라이드 이미지로 제작
3. 영상 편집 도구(CapCut, 등)로 오디오 + 슬라이드 결합

방법 2: AI 동영상 도구 활용
1. Audio Overview의 내용을 대본으로 활용
2. Remotion 등 도구로 본격 동영상 제작 (08번 가이드 참고)

## 4. 슬라이드 제작

### 4.1 NotebookLM에서 슬라이드 요약 생성
1. 소스 업로드 후 채팅창에 요청:
   - "이 내용을 10장 슬라이드로 요약해줘"
   - "프레젠테이션 구조로 정리해줘"
   - "각 슬라이드마다 제목, 핵심 포인트 3개, 설명으로 구성해줘"
2. 생성된 내용을 복사

### 4.2 슬라이드로 변환
방법 1: Google Slides
1. slides.google.com 접속
2. 새 프레젠테이션 생성
3. NotebookLM에서 생성한 내용을 각 슬라이드에 붙여넣기
4. 테마/디자인 적용

방법 2: Claude Code로 HTML 슬라이드 생성
- Claude Code에서: "이 내용으로 HTML 프레젠테이션 만들어줘"
- reveal.js 기반 슬라이드 자동 생성

방법 3: Gamma.app (AI 슬라이드)
1. https://gamma.app 접속
2. NotebookLM 요약 내용 붙여넣기
3. AI가 자동으로 디자인된 슬라이드 생성

## 5. NotebookLM 활용 팁

### 5.1 질문하기
- "이 문서의 핵심 내용을 3줄로 요약해줘"
- "이 개념을 초등학생도 이해할 수 있게 설명해줘"
- "A와 B의 차이점을 표로 정리해줘"

### 5.2 노트 저장
- AI 응답 중 유용한 내용은 "노트에 저장" 클릭
- 저장된 노트는 좌측 패널에서 관리

### 5.3 소스 관리
- 관련 있는 소스만 모아서 하나의 노트북에 관리
- 주제별로 노트북을 분리하면 정확도 향상

## 6. 실전 워크플로우 예시

### 교육 동영상 제작 플로우
1. 교육 자료(PDF/문서) 준비
2. NotebookLM에 업로드
3. "이 내용으로 5분 강의 대본을 만들어줘" 요청
4. Audio Overview 생성 (팟캐스트 형태)
5. 대본 + 오디오를 기반으로 동영상 제작
6. 또는 슬라이드 요약 생성 → Google Slides/PPT 제작

## 7. 제한사항
- 소스 최대 50개, 각 소스 최대 500,000단어
- Audio Overview 생성 시간: 5~15분
- 오프라인 사용 불가 (웹 기반)
- 소스에 없는 내용은 답변하지 않음 (장점이자 제한)

## 8. 자주 묻는 질문
- Q: 무료인가요? → 기본 기능은 무료. NotebookLM Plus는 유료
- Q: 한국어 지원되나요? → 네, 한국어 소스와 질문 모두 지원
- Q: 생성된 오디오를 상업용으로 사용 가능한가요? → Google 서비스 약관 확인 필요
- Q: 여러 명이 같이 사용할 수 있나요? → 노트북 공유 기능으로 협업 가능
