Deep Dive

각 도구의 필요성과 연결 관계

13가지 도구가 왜 필수인지, 서로 어떻게 연결되는지 알아봅니다

01
🤖

Claude Code 핵심 — 모든 것의 시작점

AI가 직접 코드를 쓰고, 파일을 편집하고, 명령을 실행합니다

💡 왜 반드시 필요한가?

Claude Code는 단순한 챗봇이 아닙니다. 터미널에서 실행되는 AI 비서입니다.
파일을 읽고, 수정하고, 프로그램을 실행하고, 서버를 관리합니다.
이 도구 하나가 나머지 8개 도구를 모두 연결하고 제어하는 중앙 허브 역할을 합니다.
Claude Code 없이는 나머지 도구들을 각각 수동으로 사용해야 합니다.

→ Skill을 실행 → MCP로 외부 서비스 접근 → Git 커밋/푸시 → AWS/SSH 명령 실행 → Remotion 코드 생성
02
🔧

Skill 자동화

반복 작업을 한 단어로 실행하는 자동화 명령어

💡 왜 반드시 필요한가?

매일 작업을 시작할 때마다 git pull, 보고서 확인, 할일 정리를 수동으로 하시나요?
/work-start 한 번이면 전부 자동 실행됩니다.
퇴근 시 /work-end로 보고서 작성, 커밋, 푸시까지 자동 완료.
Skill은 Claude Code의 매크로입니다. 복잡한 절차를 명령 하나로 압축합니다.

← Claude Code가 실행 → Git 자동 커밋 → 보고서 자동 생성 → Notion 동기화 트리거
03
🔗

MCP 연결

Claude에게 "손"을 달아줍니다 — Notion, 캘린더를 직접 조작

💡 왜 반드시 필요한가?

Claude가 아무리 똑똑해도 Notion을 읽지 못하면 일정을 모릅니다.
MCP를 연결하면 Claude가 Notion 페이지를 직접 읽고 쓰고,
캘린더 일정을 확인하고 등록할 수 있습니다.
"오늘 일정 알려줘" → 캘린더에서 바로 조회.
"이 내용 Notion에 추가해줘" → 자동 저장.
MCP 없이는 매번 브라우저를 열고 수동으로 복사-붙여넣기 해야 합니다.

← Claude Code가 호출 → Notion 읽기/쓰기 → Google Calendar 조회/등록
04
🐙

GitHub 필수 인프라

코드와 파일의 "타임머신" — 모든 변경 이력을 보존

💡 왜 반드시 필요한가?

파일을 실수로 삭제했다면? 어제 버전으로 돌아가고 싶다면?
GitHub은 모든 변경 이력을 기록하는 타임머신입니다.
Claude Code가 작성한 코드도 GitHub에 자동 저장됩니다.
집 PC에서 작업하다 회사 PC에서 이어하기도 가능합니다.
GitHub 없이 AI 도구를 쓰면, 만들어진 결과물을 안전하게 보관할 방법이 없습니다.

← Claude Code가 커밋/푸시 ← Skill이 자동 저장 → AWS 서버에 배포 → Colab에서 코드 불러오기
05
☁️

AWS Cloud 서버 인프라

내 PC가 꺼져도 24시간 돌아가는 클라우드 서버

💡 왜 반드시 필요한가?

만든 웹서비스나 AI 모델을 세상에 공개하려면 24시간 서버가 필요합니다.
AWS는 서버를 빌려주는 서비스입니다. 필요할 때 켜고, 안 쓸 때 끕니다.
프리 티어로 1년간 무료 사용 가능합니다.
AI 모델 서빙, 웹 애플리케이션 배포, 파일 저장소 모두 AWS 위에서 동작합니다.
Claude Code에서 "서버에 배포해줘" 한 마디로 자동 배포됩니다.

← GitHub에서 코드 가져옴 ← Claude Code가 관리 → SSH로 접속/관리 → 웹서비스 배포
06
🔬

Google Colab AI 실습

브라우저에서 바로 AI를 실행하는 무료 실험실

💡 왜 반드시 필요한가?

AI 모델을 학습하려면 고가의 GPU가 필요합니다 (GPU 컴퓨터 가격: 200만원 이상).
Colab은 무료로 GPU를 제공합니다. 브라우저만 있으면 됩니다.
설치 없이 Python 코드를 바로 실행할 수 있어 초보자에게 최적입니다.
이미지 분류, 텍스트 생성, 데이터 분석 등 모든 AI 실습을 여기서 합니다.
GitHub의 코드를 Colab에서 바로 불러와 실행할 수 있습니다.

← GitHub에서 코드 클론 → Google Drive에 결과 저장 → 학습된 모델을 AWS에 배포
07
📖

NotebookLM 콘텐츠 생성

문서를 넣으면 동영상, 슬라이드, 팟캐스트가 나옵니다

💡 왜 반드시 필요한가?

교육 자료를 만들려면? 보고서를 발표용 슬라이드로 바꾸려면?
NotebookLM에 문서를 업로드하면 AI가 핵심을 분석하고,
팟캐스트 형태의 오디오를 자동 생성합니다.
"이 내용을 10장 슬라이드로 요약해줘" → 프레젠테이션 완성.
100페이지 PDF도 5분 안에 핵심만 뽑아냅니다.

← 문서/PDF/URL 입력 → 오디오를 Remotion과 결합 → 슬라이드 자동 생성
08
🎬

Remotion 영상 제작

코드로 동영상을 만듭니다 — Claude가 코드를 작성해줍니다

💡 왜 반드시 필요한가?

교육 영상, 제품 소개 영상, 홍보 영상을 외주 없이 직접 만들 수 있습니다.
Remotion은 코드로 동영상을 제작하는 도구입니다.
코드를 모르셔도 괜찮습니다 — Claude Code가 코드를 대신 작성합니다.
"AI 소개 동영상 만들어줘" → 씬 구성, 애니메이션, 자막까지 자동 생성.
NotebookLM의 오디오 + Remotion의 영상 = 완성된 교육 동영상.

← Claude Code가 코드 작성 ← NotebookLM 오디오 사용 → MP4 렌더링 출력 → GitHub에 프로젝트 저장
09
🔐

SSH & 포트포워딩 원격 접속

어디서든 서버에 접속하고, 서비스를 안전하게 연결합니다

💡 왜 반드시 필요한가?

AWS 서버, 라즈베리파이, 회사 PC에 원격으로 접속하려면 SSH가 필수입니다.
포트포워딩을 사용하면 원격 서버에서 실행 중인 Jupyter Notebook이나
웹 서비스를 내 PC 브라우저에서 바로 접근할 수 있습니다.
SSH 없이는 서버 앞에 직접 앉아야만 작업할 수 있습니다.
재택근무, 출장 중에도 모든 서버를 제어할 수 있는 열쇠입니다.

← AWS EC2에 접속 ← Claude Code에서 실행 → Jupyter 포트포워딩 → 라즈베리파이 원격 제어
13
💬

Slack 팀 협업

카카오톡은 개인용, Slack은 업무용 — 모든 도구의 알림이 한 곳에

💡 왜 반드시 필요한가?

카카오톡으로 업무 협의하면 파일이 2주 후 만료되고, 대화가 섞이고, 검색이 안 됩니다.
Slack은 채널(#)로 주제를 분리하고, 파일을 영구 보관하며, 코드를 예쁘게 공유합니다.
GitHub PR 알림, AWS 서버 장애 알림, Notion 업데이트가 자동으로 Slack에 도착합니다.
Claude Code MCP로 연결하면 AI가 작업 결과를 직접 채널에 공유합니다.
Slack은 단순한 메신저가 아닌, 모든 도구를 잇는 업무 알림 허브입니다.

← GitHub PR/이슈 알림 ← AWS 서버 장애 알림 ← Notion 업데이트 알림 ← Claude Code MCP 연동 → 팀원에게 작업 공유
10
💎

Obsidian 지식 관리

AI가 쏟아내는 정보를 체계적으로 연결하는 "세컨드 브레인"

💡 왜 반드시 필요한가?

AI 시대에 정보는 넘칩니다. 문제는 정리하고 연결하는 것입니다.
Obsidian은 마크다운 파일을 양방향 링크 [[]]로 연결하여 지식 네트워크를 만듭니다.
오늘 배운 AI 개념이 지난주 프로젝트와 어떻게 연결되는지 그래프로 보여줍니다.
Claude Code가 생성한 지식을 Obsidian에 자동 축적하면 복리로 성장하는 위키가 됩니다.
Notion이 "협업 도구"라면, Obsidian은 "두뇌 확장 도구"입니다. 둘 다 필요합니다.

← Claude Code가 위키 자동 업데이트 ← GitHub으로 버전 관리 → Notion과 역할 분담 → NotebookLM 소스로 활용
11
🛡

Tailscale 네트워크

설치만 하면 끝 — 모든 장비를 하나의 네트워크로 연결

💡 왜 반드시 필요한가?

SSH는 강력하지만 설정이 복잡합니다 (포트 열기, 방화벽, 공인 IP, DuckDNS...).
Tailscale은 설치만 하면 모든 장비가 같은 네트워크에 들어옵니다.
집 PC, 회사 서버, 라즈베리파이, AWS, 스마트폰까지 100.x.x.x IP로 바로 접속.
카페에서도, 출장 중에도 포트포워딩 없이 서버 접속 가능.
무료 플랜으로 100대 장비까지 지원합니다.

← SSH를 더 쉽게 만듦 → AWS EC2에 간편 접속 → 라즈베리파이 원격 관리 → VS Code Remote SSH 연결
12
💻

VS Code 코드 에디터

전 세계 개발자 70%가 사용하는 표준 코드 에디터

💡 왜 반드시 필요한가?

Claude Code가 터미널에서 코드를 작성하지만, 결과물을 보고 편집하려면 에디터가 필요합니다.
VS Code는 문법 하이라이팅, 자동 완성, Git 통합, 디버깅을 모두 제공합니다.
Claude Code 확장을 설치하면 에디터 안에서 바로 AI와 협업합니다.
Remote SSH 확장으로 Tailscale을 통해 원격 서버 파일을 로컬처럼 편집합니다.
무료이며, Python, JavaScript, Markdown 등 모든 언어를 지원합니다.

← Claude Code 확장 내장 ← Tailscale로 원격 편집 → Git 통합 커밋/푸시 → Remotion 프로젝트 편집 → Obsidian 마크다운 편집
