# Slack 업무 협의 가이드

## 1. Slack이란?
- 팀 커뮤니케이션 플랫폼 (업무용 메신저)
- 채널(#)로 주제별 대화 분리 — 카카오톡 단톡방과 근본적 차이
- 파일 영구 보관, 강력한 검색, 코드 공유 지원
- GitHub, Notion, AWS 등 외부 서비스와 봇/자동화 연동
- Claude Code MCP로 AI가 직접 Slack 메시지 전송 가능
- 무료 플랜으로 소규모 팀 충분히 사용 가능

## 2. 왜 카카오톡이 아닌 Slack인가?

### 2.1 카카오톡 vs Slack 비교
| 구분 | 카카오톡 | Slack |
|------|---------|-------|
| 채널 분리 | 불가 (단톡방 나열) | 주제별 채널 (#개발, #교육, #일반) |
| 파일 관리 | 2주 후 만료 | 영구 보관 + 검색 |
| 스레드 | 없음 | 대화 맥락 유지 (답글 스레드) |
| 코드 공유 | 깨짐, 가독성 나쁨 | 문법 하이라이팅, 코드 블록 지원 |
| 봇/자동화 | 없음 | GitHub, Notion, AWS, Claude 연동 |
| 검색 | 제한적 | 전체 히스토리 + 필터 검색 |
| 업무/개인 분리 | 혼재 | 완전 분리 (워크스페이스) |
| 화상 회의 | 제한적 | Huddle (음성/영상 내장) |
| 알림 설정 | 단순 | 채널별, 키워드별 세밀한 알림 |

### 2.2 실제 업무에서의 차이
- 카카오톡: "어제 보낸 파일 어디 갔지?" → 만료됨
- Slack: 파일 이름 검색 → 즉시 발견
- 카카오톡: 3개 프로젝트 논의가 한 단톡방에 섞임
- Slack: #프로젝트A, #프로젝트B, #프로젝트C 채널 분리

## 3. 시작하기

### 3.1 워크스페이스 만들기 (관리자)
1. https://slack.com 접속
2. "무료로 시작하기" 클릭
3. 이메일 입력 → 인증 코드 확인
4. 워크스페이스 이름 입력 (예: "우리회사")
5. 첫 채널 만들기 (예: #일반)
6. 팀원 이메일로 초대

### 3.2 워크스페이스 참가 (팀원)
1. 초대 이메일에서 "참가하기" 클릭
2. 이름, 비밀번호 설정
3. 프로필 사진 등록 (선택)
4. 바로 사용 시작

### 3.3 앱 설치
- 데스크톱: https://slack.com/downloads 에서 다운로드
- 모바일: App Store / Play Store에서 "Slack" 검색
- 웹: 브라우저에서 바로 사용 가능

## 4. 기본 사용법

### 4.1 채널 (#)
- #일반: 전체 공지, 일반 대화
- #개발: 개발 관련 논의
- #교육: 교육 일정, 자료 공유
- #random: 잡담, 가벼운 대화
- 새 채널 만들기: 좌측 "채널" > "채널 추가"

### 4.2 다이렉트 메시지 (DM)
- 1:1 또는 소그룹 비공개 대화
- 좌측 "다이렉트 메시지" > 상대방 선택

### 4.3 스레드 (답글)
- 메시지에 마우스 올리기 > "스레드로 답장"
- 주제별 대화가 분기되어 메인 채널이 깔끔하게 유지
- 중요: 채널이 시끄러워지지 않도록 스레드 적극 활용!

### 4.4 메시지 서식
```
*굵게*     _기울임_     ~취소선~

`인라인 코드`

```python
print("코드 블록")
```

> 인용문

- 목록
1. 번호 목록
```

### 4.5 파일 공유
- 메시지 입력창 하단 "+" 또는 파일 드래그 앤 드롭
- PDF, 이미지, 코드 파일 모두 미리보기 지원
- 업로드된 파일은 검색으로 언제든 찾기 가능

### 4.6 검색
- Ctrl+K 또는 상단 검색창
- 필터: from:사용자, in:#채널, before:날짜, has:파일
- 예: "from:홍길동 in:#개발 has:pdf"

### 4.7 알림 설정
- 채널별 알림 켜기/끄기 가능
- 키워드 알림: 특정 단어가 언급되면 알림 (예: "장애", "긴급")
- 방해금지 시간 설정: 퇴근 후~출근 전 알림 차단

## 5. 추천 채널 구성 (회사용)

### 5.1 기본 채널

## 6. 외부 서비스 연동 (봇/앱)

### 6.1 GitHub 연동
- Slack 앱 디렉토리에서 "GitHub" 설치
- /github subscribe owner/repo 명령으로 알림 활성화
- PR 생성, 머지, 이슈 등 자동 알림

### 6.2 Notion 연동
- Notion 앱 설치
- Notion 페이지 업데이트 시 Slack 알림
- Slack에서 바로 Notion 페이지 미리보기

### 6.3 Google Calendar 연동
- Google Calendar 앱 설치
- 일정 시작 전 Slack 알림
- 일일 일정 요약 자동 전송

### 6.4 Claude Code MCP 연동
settings.json에 추가:
```json
{
  "mcpServers": {
    "slack": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-slack"],
      "env": {
        "SLACK_BOT_TOKEN": "xoxb-여기에-토큰-입력"
      }
    }
  }
}
```
Claude Code에서:
- "이 작업 완료 내용을 #개발 채널에 공유해줘"
- "오늘 작업 요약을 Slack에 보내줘"

### 6.5 Slack Bot 토큰 발급
1. https://api.slack.com/apps 접속
2. "Create New App" > "From scratch"
3. 앱 이름, 워크스페이스 선택
4. "OAuth & Permissions" > Bot Token Scopes 추가:
   - chat:write, channels:read, channels:history
5. "Install to Workspace" > 허용
6. Bot User OAuth Token (xoxb-...) 복사

## 7. Huddle (음성/영상 통화)
- 채널 또는 DM에서 헤드폰 아이콘 클릭
- 즉석 음성 통화 시작 (카메라 켜기 가능)
- 화면 공유 지원
- 별도 화상회의 앱 없이 바로 미팅

## 8. 요금제

- 소규모 팀(~10명)은 무료 플랜으로 충분

## 9. 자주 묻는 질문
- Q: 무료 플랜 제한은? → 메시지 이력 90일, 앱 연동 10개 제한. 소규모 팀은 충분
- Q: 카카오톡과 병행해야 하나요? → Slack은 업무용, 카카오톡은 개인용으로 분리 추천
- Q: 영어만 지원하나요? → 한국어 UI 완벽 지원
- Q: 보안은 안전한가요? → 엔터프라이즈급 보안, SOC2 인증, 데이터 암호화

## 10. 정리
Slack은 단순한 메신저가 아니라 **업무 허브**입니다:
- GitHub 알림 받고
- Notion 업데이트 확인하고
- AWS 서버 상태 모니터링하고
- Claude Code가 작업 결과를 공유하는
모든 도구의 **알림과 소통이 한 곳에서** 이루어집니다.
