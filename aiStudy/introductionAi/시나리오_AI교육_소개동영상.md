# AI 업무효율화 Base Tool 교육 — 소개 동영상 시나리오

> **목적**: 중소기업 담당자·1인 사업자·신입 사원 대상 AI 도구 13종 통합 교육 과정의 가치를 전달하는 7분 분량 소개 영상
> **타겟**: AI 도구를 한 번도 써본 적 없는 초심자 + 의사결정권자(대표/팀장)
> **결과 기대**: 시청 후 "이 교육 받아야겠다 / 직원에게 보내야겠다"는 결심을 만들어내는 것

## 0. 영상 메타 정보

| 항목 | 값 |
|------|-----|
| **총 길이** | 7분 00초 (420초) |
| **해상도** | 1920×1080 (Full HD) / 30fps |
| **종횡비** | 16:9 (가로) — YouTube·Vimeo·홈페이지·교육 발주처 제출 모두 호환 |
| **언어** | 한국어 내레이션 + 한국어 자막 (자막 별도 SRT 분리) |
| **음성** | ElevenLabs (한국어 모델) 또는 CLOVA Voice (남성 30대 차분한 톤) |
| **BGM** | 잔잔한 인스트루멘탈 (Pixabay/YouTube 오디오 라이브러리, 저작권 무료) |
| **제작 도구** | Remotion (React 기반) — 본 교육 #12번 모듈에서 다루는 도구로 자체 제작 가능 |
| **제작 시간** | Claude Code + Remotion 조합으로 약 8~12시간 (시나리오 → 코드 → TTS → 렌더링) |

## 3. 음성·자막·BGM 가이드

### 3-1. 내레이션 (TTS 또는 직접 녹음)

**옵션 A: ElevenLabs (한국어, 유료)**
```python
from elevenlabs import generate, save

scenes = [
    "AI 시대, 진짜 변한 게 뭘까요?",  # Scene 1
    "ChatGPT, 미드저니, Suno, Runway...",  # Scene 1 cont.
    # ... 모든 씬 내레이션 분할
]

for i, text in enumerate(scenes):
    audio = generate(
        text=text,
        voice="Bohun",  # 한국어 남성 차분한 톤
        model="eleven_multilingual_v2",
        voice_settings={"stability": 0.7, "similarity_boost": 0.85}
    )
    save(audio, f"narration/scene_{i+1:02d}.mp3")
```

**옵션 B: CLOVA Voice (한국어 특화, 무료 티어)**
- https://clova.ai/voice
- 가장 자연스러운 한국어 음성
- 월 1,000자 무료 → 약 7분 영상에 충분

**옵션 C: 직접 녹음**
- 강사(UTTEC 대표) 음성으로 진정성 확보
- Audacity로 후처리 (노이즈 제거 + 노멀라이즈)

### 3-2. 자막 (SRT 파일 분리 제작)

```srt
1
00:00:00,000 --> 00:00:05,000
AI 시대, 진짜 변한 게 뭘까요?

2
00:00:05,000 --> 00:00:12,000
한 달에 새로운 AI 도구 수십 개

3
00:00:12,000 --> 00:00:20,000
어떤 도구를 어떤 순서로?
...
```

**자막 디자인**:
- 위치: 화면 하단 1/4 지점
- 폰트: Noto Sans KR Medium 36pt
- 색: 흰색 + 검은 외곽선 (가독성)
- 배경: 반투명 검은 박스 (`rgba(0,0,0,0.5)`)

### 4-2. 제작 단계
