## 권장 학습 순서 — 5 Track (초심자 학습 곡선 우선)

```
Track A: 1. Claude Code → 2. Obsidian → 3. VS Code
         (당장 매일 쓰는 핵심 3종 — 즉시 효용 최대)

Track B: 4. Skill → 5. MCP
         (Claude Code 확장 — 자동화 도약)

Track C: 6. GitHub → 7. SSH → 8. Tailscale
         (개발 인프라 + 원격 환경 구축)

Track D: 9. Slack
         (팀 소통 + 봇 자동화)

Track E: 10. Colab → 11. NotebookLM → 12. Remotion → 13. AWS
         (AI 활용·콘텐츠 제작·클라우드 — 가장 무거운 영역, 마지막)
```

### Track 별 학습 의도

| Track | 학습 목표 | 예상 시간 |
|-------|----------|----------|
| **A** | "AI와 같이 일하는 환경" 즉시 구축 | 1-2일 |
| **B** | Claude를 '나만의 도구'로 확장 | 1일 |
| **C** | 코드 + 원격 환경의 기초 인프라 | 2-3일 |
| **D** | 팀 협업의 디지털 허브 | 0.5일 |
| **E** | AI 모델 학습·콘텐츠·클라우드 (선택적 심화) | 2-4일 |

→ **A+B (3일)**만 끝내도 일상 업무에 즉시 적용 가능. C 이후는 필요에 따라 단계적 진입.

## 사전 요구사항

- Windows 10/11 PC
- 인터넷 연결
- Google 계정 (Gmail)
- 신용카드/체크카드 (AWS 가입용, 프리 티어 사용 시 과금 없음)
- Claude Pro 구독 ($20/월) — Claude Code 사용 시 필요
