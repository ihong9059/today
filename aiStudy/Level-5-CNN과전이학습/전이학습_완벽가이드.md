# 전이 학습 (Transfer Learning) 완벽 가이드

## 개요

**전이 학습**은 이미 학습된 모델의 지식을 새로운 문제에 재사용하는 기법입니다.

> **"거인의 어깨 위에 서라."**
> ImageNet에서 훈련된 모델은 이미 일반적인 이미지 특징(엣지, 텍스처, 패턴)을 학습했습니다.

---

## 1. 왜 전이 학습인가?

### 직접 학습 vs 전이 학습

| 항목 | 직접 학습 | 전이 학습 |
|------|----------|----------|
| 필요 데이터 | 수백만 장 | 수백~수천 장 |
| 학습 시간 | 수일~수주 | 수분~수시간 |
| GPU 요구 | 고성능 필수 | 일반 GPU 가능 |
| 시작점 | 랜덤 가중치 | 학습된 지식 |

### 전이 학습의 이점

1. **적은 데이터로 가능** - 소량 데이터셋에서도 효과적
2. **빠른 학습** - 이미 학습된 특성 재활용
3. **높은 성능** - 일반화된 특성 활용
4. **컴퓨팅 절약** - GPU 시간 대폭 감소

---

## 2. CNN의 계층별 특성

사전학습 모델은 계층별로 다른 수준의 특성을 학습합니다:

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 1-2 (초기 층)                                        │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 저수준 특성: 엣지, 색상, 텍스처                        │  │
│  │ → 거의 모든 이미지에서 공통                            │  │
│  │ → 보통 동결 (freeze)                                  │  │
│  └──────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  Layer 3-4 (중간 층)                                        │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 중간수준 특성: 패턴, 형태, 부분                        │  │
│  │ → 도메인에 따라 유사하거나 다름                        │  │
│  │ → 선택적 미세조정                                     │  │
│  └──────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  FC Layer (분류 층)                                         │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 고수준 특성: 클래스 특화                               │  │
│  │ → 원본 데이터셋(ImageNet)에 특화                       │  │
│  │ → 항상 새로 학습                                       │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 3. 두 가지 접근 방식

### 방법 1: 특성 추출 (Feature Extraction)

사전 훈련된 층은 **동결(freeze)**하고, 새로운 분류기만 학습합니다.

```
Conv1 → Conv2 → Conv3 → Conv4 → [새 FC Layer]
 🔒      🔒      🔒      🔒        ✏️ 학습
```

| 특징 | 설명 |
|------|------|
| 동결 층 | Conv 레이어 전체 |
| 학습 층 | FC 레이어만 |
| 학습 파라미터 | 전체의 ~1% |
| 사용 시점 | 데이터 적거나, 원본과 유사한 도메인 |

```python
# 특성 추출 구현
model = models.resnet18(weights='IMAGENET1K_V1')

# 모든 파라미터 동결
for param in model.parameters():
    param.requires_grad = False

# 새 분류기 추가 (이 레이어만 학습됨)
model.fc = nn.Sequential(
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10)  # 10개 클래스
)
```

### 방법 2: 미세 조정 (Fine-tuning)

전체 또는 일부 층을 **작은 학습률**로 추가 학습합니다.

```
Conv1 → Conv2 → Conv3 → Conv4 → [새 FC Layer]
 🔒      🔒      ✏️      ✏️        ✏️ 학습
                (lr=1e-5) (lr=1e-4)  (lr=1e-3)
```

| 특징 | 설명 |
|------|------|
| 동결 층 | 초기 Conv 레이어 |
| 학습 층 | 후기 Conv + FC |
| 학습률 | 층별로 다르게 설정 |
| 사용 시점 | 데이터 충분하거나, 다른 도메인 |

```python
# 미세 조정 구현
model = models.resnet18(weights='IMAGENET1K_V1')

# 먼저 모두 동결
for param in model.parameters():
    param.requires_grad = False

# layer4만 해동 (미세 조정)
for param in model.layer4.parameters():
    param.requires_grad = True

# 새 분류기
model.fc = nn.Linear(512, 10)

# 레이어별 학습률 설정
optimizer = torch.optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-4},  # 작은 학습률
    {'params': model.fc.parameters(), 'lr': 1e-3}       # 일반 학습률
])
```

## 4. 전이 학습 전략 선택

### 데이터 양과 유사성에 따른 전략

```
                    데이터 유사성
                 높음 ◄─────────► 낮음
              ┌────────────────────────┐
데이터   많음 │  미세 조정 전체       │  미세 조정 + 강한 정규화
양            │  (모든 층 학습)        │  (과적합 주의)
              ├────────────────────────┤
         적음 │  특성 추출             │  특성 추출 + 데이터 증강
              │  (FC만 학습)           │  (또는 다른 모델 시도)
              └────────────────────────┘
```

### 도메인별 권장 전략

| 원본 (ImageNet) | 목표 도메인 | 권장 전략 |
|-----------------|-------------|----------|
| 일반 이미지 | 개/고양이 분류 | 특성 추출 |
| 일반 이미지 | 자동차 모델 분류 | 특성 추출 |
| 일반 이미지 | 의료 영상 | 미세 조정 |
| 일반 이미지 | 위성 이미지 | 미세 조정 (많은 층) |

## 5. 대표적인 사전학습 모델

### PyTorch에서 사용 가능한 모델

| 모델 | 파라미터 | Top-1 정확도 | 특징 |
|------|----------|-------------|------|
| ResNet-18 | 11M | 69.8% | 가볍고 빠름 |
| ResNet-50 | 25M | 76.1% | 균형 잡힌 성능 |
| VGG-16 | 138M | 71.6% | 단순한 구조 |
| EfficientNet-B0 | 5M | 77.1% | 효율적 |
| EfficientNet-B7 | 66M | 84.3% | 최고 성능 |

### 모델 로드 방법

```python
from torchvision import models

# 다양한 사전 훈련 모델 로드
resnet18 = models.resnet18(weights='IMAGENET1K_V1')
resnet50 = models.resnet50(weights='IMAGENET1K_V2')
vgg16 = models.vgg16(weights='IMAGENET1K_V1')
efficientnet = models.efficientnet_b0(weights='IMAGENET1K_V1')

# 모델별 마지막 층 이름
# ResNet: model.fc
# VGG: model.classifier[6]
# EfficientNet: model.classifier[1]
```

## 6. 전체 코드 예제

### CIFAR-10에 전이 학습 적용

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import models, datasets, transforms
from torch.utils.data import DataLoader

# 디바이스 설정
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# ═══════════════════════════════════════════════════════════════
# 1. 데이터 준비 (ImageNet 정규화 사용)
# ═══════════════════════════════════════════════════════════════
transform = transforms.Compose([
    transforms.Resize(224),  # ResNet 입력 크기
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406],  # ImageNet 평균
                        [0.229, 0.224, 0.225])   # ImageNet 표준편차
])

train_data = datasets.CIFAR10('./data', train=True, download=True, transform=transform)
test_data = datasets.CIFAR10('./data', train=False, transform=transform)

# 작은 서브셋 사용 (전이 학습의 장점 테스트)
train_subset = torch.utils.data.Subset(train_data, range(5000))  # 5000개만
train_loader = DataLoader(train_subset, batch_size=32, shuffle=True)
test_loader = DataLoader(test_data, batch_size=100)

# ═══════════════════════════════════════════════════════════════
# 2. 모델 준비 (특성 추출 방식)
# ═══════════════════════════════════════════════════════════════
model = models.resnet18(weights='IMAGENET1K_V1')

# 모든 파라미터 동결
for param in model.parameters():
    param.requires_grad = False

# 새 분류기로 교체 (이 부분만 학습)
model.fc = nn.Linear(512, 10)
model = model.to(device)

# ═══════════════════════════════════════════════════════════════
# 3. 학습 설정
# ═══════════════════════════════════════════════════════════════
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.fc.parameters(), lr=0.001)

# ═══════════════════════════════════════════════════════════════
# 4. 학습 루프
# ═══════════════════════════════════════════════════════════════
epochs = 5
for epoch in range(1, epochs + 1):
    model.train()
    for data, target in train_loader:
        data, target = data.to(device), target.to(device)
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()

    # 평가
    model.eval()
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(device), target.to(device)
            correct += model(data).argmax(1).eq(target).sum().item()

    acc = 100. * correct / len(test_data)
    print(f"Epoch {epoch}/{epochs} | Test Acc: {acc:.2f}%")
```

### 미세 조정 버전

```python
# ═══════════════════════════════════════════════════════════════
# 미세 조정: layer4와 fc 학습
# ═══════════════════════════════════════════════════════════════
model = models.resnet18(weights='IMAGENET1K_V1')

# 모두 동결
for param in model.parameters():
    param.requires_grad = False

# layer4 해동
for param in model.layer4.parameters():
    param.requires_grad = True

# 새 분류기
model.fc = nn.Linear(512, 10)
model = model.to(device)

# 레이어별 다른 학습률
optimizer = optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 1e-3}
])
```

## 7. 주의사항 및 팁

### 주의사항

1. **입력 크기 맞추기**
   - ResNet: 224×224
   - EfficientNet: 모델마다 다름 (224~600)
   - `transforms.Resize()`로 조정

2. **정규화 값 사용**
   - ImageNet 평균: [0.485, 0.456, 0.406]
   - ImageNet 표준편차: [0.229, 0.224, 0.225]

3. **배치 정규화 모드**
   - 학습 시: `model.train()` (BN 업데이트)
   - 평가 시: `model.eval()` (BN 고정)

### 성능 향상 팁

1. **데이터 증강 추가**
   ```python
   train_transform = transforms.Compose([
       transforms.Resize(256),
       transforms.RandomCrop(224),
       transforms.RandomHorizontalFlip(),
       transforms.ToTensor(),
       transforms.Normalize(...)
   ])
   ```

2. **Learning Rate Scheduler 사용**
   ```python
   scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=3, gamma=0.1)
   ```

3. **점진적 해동 (Progressive Unfreezing)**
   - 1단계: FC만 학습
   - 2단계: layer4 + FC
   - 3단계: layer3 + layer4 + FC

## 8. 핵심 요약

| 항목 | 특성 추출 | 미세 조정 |
|------|----------|----------|
| 동결 층 | Conv 전체 | 초기 Conv만 |
| 학습 층 | FC만 | 후기 Conv + FC |
| 학습률 | 일반 (1e-3) | 층별 다르게 (1e-5~1e-3) |
| 데이터 양 | 적어도 OK | 많을수록 좋음 |
| 학습 시간 | 빠름 | 상대적으로 느림 |
| 과적합 위험 | 낮음 | 중간 |
