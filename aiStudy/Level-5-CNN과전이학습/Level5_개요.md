## 핵심 개념 요약

### 1. CNN 기본 구성요소

| 구성요소 | 역할 | 파라미터 |
|---------|------|---------|
| Conv2d | 특징 추출 | 커널 크기, 채널 수 |
| MaxPool2d | 크기 축소 | 풀링 크기, 스트라이드 |
| BatchNorm2d | 학습 안정화 | 채널 수 |
| ReLU | 비선형성 | 없음 |
| Dropout | 과적합 방지 | 드롭 확률 |
| Linear | 분류 | 입출력 크기 |

### 2. 텐서 Shape 변화

```
입력: (N, 3, 224, 224)   # 배치, 채널, 높이, 너비
      ↓ Conv2d(3, 64, 3, padding=1)
      (N, 64, 224, 224)
      ↓ MaxPool2d(2)
      (N, 64, 112, 112)
      ↓ Conv2d(64, 128, 3, padding=1)
      (N, 128, 112, 112)
      ↓ ... (반복)
      ↓ Flatten
      (N, 특성수)
      ↓ Linear
출력: (N, 클래스수)
```

### 3. 전이 학습 핵심

| 방법 | 동결 | 학습 | 데이터 양 |
|------|------|------|----------|
| 특성 추출 | Conv 전체 | FC만 | 적음 |
| 미세 조정 | 초기 Conv | 후기 Conv + FC | 많음 |

### 4. 데이터 증강 기법

| 기법 | 설명 | 코드 |
|------|------|------|
| 수평 뒤집기 | 좌우 반전 | `RandomHorizontalFlip()` |
| 회전 | ±N도 회전 | `RandomRotation(N)` |
| 자르기 | 랜덤 영역 | `RandomCrop(size)` |
| 색상 변환 | 밝기/대비 | `ColorJitter(...)` |
