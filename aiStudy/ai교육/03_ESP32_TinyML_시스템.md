# ESP32 TinyML 시스템 (MPU6050 + AHT20)

## 개요

TinyML은 **초소형 마이크로컨트롤러**에서 실행되는 머신러닝 기술입니다.
ESP32와 센서를 이용해 실시간으로 AI 추론을 수행하는 시스템을 구축합니다.

---

## 1. TinyML이란?

### 1.1 정의

```
┌─────────────────────────────────────────────────────────────┐
│                     TinyML 정의                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Tiny + ML = 초소형 머신러닝                                 │
│                                                             │
│  특징:                                                       │
│  - 모델 크기: 수십 KB ~ 수백 KB                              │
│  - 메모리: 수십 KB RAM으로 동작                              │
│  - 전력: mW 단위 (배터리로 수개월 동작)                       │
│  - 처리: 엣지에서 실시간 추론                                 │
│                                                             │
│  vs 일반 AI:                                                 │
│  - 클라우드 AI: 수 GB 모델, 고전력                           │
│  - TinyML: 수 KB 모델, 초저전력                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 왜 TinyML인가?

| 장점 | 설명 |
|:---|:---|
| **프라이버시** | 데이터가 디바이스를 떠나지 않음 |
| **실시간성** | 네트워크 지연 없음 (ms 단위 응답) |
| **저전력** | 배터리로 장기간 동작 가능 |
| **저비용** | $10 이하의 하드웨어 |
| **오프라인** | 인터넷 연결 불필요 |
| **확장성** | 수백만 개 디바이스 배포 가능 |

### 2.2 각 부품 설명

#### ESP32 (메인 컨트롤러)
```
┌──────────────────────────────────────┐
│            ESP32 DevKit              │
├──────────────────────────────────────┤
│  CPU: Xtensa LX6 240MHz (듀얼코어)   │
│  RAM: 520KB SRAM                     │
│  Flash: 4MB                          │
│  WiFi: 802.11 b/g/n                  │
│  Bluetooth: 4.2 BR/EDR + BLE         │
│  GPIO: 34개                          │
│  전력: 약 80mA (동작), 10μA (딥슬립)  │
│  가격: 약 $5~10                      │
└──────────────────────────────────────┘
```

#### MPU6050 (6축 IMU 센서)
```
┌──────────────────────────────────────┐
│            MPU6050 센서              │
├──────────────────────────────────────┤
│  가속도계: ±2g, ±4g, ±8g, ±16g       │
│  자이로스코프: ±250~2000°/s          │
│  출력 데이터: 6축 (ax, ay, az,       │
│               gx, gy, gz)            │
│  샘플링: 최대 1kHz                   │
│  통신: I2C (주소: 0x68)              │
│  전력: 3.9mA (동작)                  │
│  가격: 약 $2~3                       │
├──────────────────────────────────────┤
│  용도: 동작 인식, 기울기, 진동 감지   │
└──────────────────────────────────────┘
```

#### AHT20 (온습도 센서)
```
┌──────────────────────────────────────┐
│            AHT20 센서                │
├──────────────────────────────────────┤
│  온도 범위: -40°C ~ 85°C             │
│  온도 정확도: ±0.3°C                 │
│  습도 범위: 0~100% RH                │
│  습도 정확도: ±2% RH                 │
│  통신: I2C (주소: 0x38)              │
│  전력: 0.25mA                        │
│  가격: 약 $1~2                       │
├──────────────────────────────────────┤
│  용도: 환경 모니터링, 이상 감지       │
└──────────────────────────────────────┘
```

## 3. 센서 데이터 이해

### 3.1 MPU6050 데이터 구조

```python
# 6축 센서 데이터
sensor_data = {
    'ax': 0.02,    # X축 가속도 (g)
    'ay': -0.01,   # Y축 가속도 (g)
    'az': 1.00,    # Z축 가속도 (g) - 중력
    'gx': 0.5,     # X축 각속도 (°/s)
    'gy': -0.3,    # Y축 각속도 (°/s)
    'gz': 0.1      # Z축 각속도 (°/s)
}

# 정상 상태 (정지)
# az ≈ 1.0g (중력), 나머지 ≈ 0

# 움직임 감지
# ax, ay, az 변화 → 이동
# gx, gy, gz 변화 → 회전
```

### 3.2 AHT20 데이터 구조

```python
# 온습도 데이터
environment_data = {
    'temperature': 25.3,  # 섭씨 온도
    'humidity': 45.2      # 상대 습도 (%)
}

# 정상 범위 (실내)
# 온도: 18~28°C
# 습도: 40~60%
```

### 3.3 시계열 데이터 수집

```python
# 50개 샘플 수집 (1초 분량)
time_series_data = []
for i in range(50):  # 50Hz 샘플링
    sample = [ax, ay, az, gx, gy, gz]
    time_series_data.append(sample)
    time.sleep(0.02)  # 20ms 간격

# 결과: (50, 6) 형태의 데이터
# 50개 시간 포인트, 6개 특성
```

## 4. TinyML 동작 원리

### 4.1 전체 파이프라인

```
┌─────────────────────────────────────────────────────────────┐
│                   TinyML 파이프라인                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [PC에서 수행]                                               │
│  ┌────────────────────────────────────────────────────┐    │
│  │ 1. 데이터 수집 → 2. 모델 학습 → 3. 모델 변환       │    │
│  │    (Python)       (TensorFlow)   (TFLite/Quantize) │    │
│  └────────────────────────────────────────────────────┘    │
│                            │                                │
│                            ▼                                │
│  [ESP32에서 수행]          모델 배포 (.h 파일)              │
│  ┌────────────────────────────────────────────────────┐    │
│  │ 4. 센서 읽기 → 5. 전처리 → 6. 추론 → 7. 액션      │    │
│  │   (실시간)      (정규화)    (예측)    (출력)       │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 모델 구조 (간단한 분류기)

```
입력: (50, 6) - 1초간 센서 데이터
      │
      ▼
┌─────────────────────────────────┐
│  Reshape: (50, 6) → (300,)      │  평탄화
└─────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────┐
│  Dense(64, ReLU)                │  은닉층 1
│  파라미터: 300×64 + 64 = 19,264 │
└─────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────┐
│  Dense(32, ReLU)                │  은닉층 2
│  파라미터: 64×32 + 32 = 2,080   │
└─────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────┐
│  Dense(3, Softmax)              │  출력층
│  파라미터: 32×3 + 3 = 99        │
└─────────────────────────────────┘
      │
      ▼
출력: [0.95, 0.03, 0.02]
      정상   넘어짐  충격

총 파라미터: 약 21,443개 ≈ 84KB (float32)
양자화 후: 약 21KB (int8)
```

### 4.3 양자화(Quantization)

```
┌─────────────────────────────────────────────────────────────┐
│                      양자화 과정                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  원본 모델 (float32)          양자화 모델 (int8)            │
│  ─────────────────            ────────────────              │
│  가중치: 32비트               가중치: 8비트                  │
│  크기: 84KB                   크기: 21KB                     │
│  정확도: 98%                  정확도: 97%                    │
│  연산: 느림                   연산: 4배 빠름                 │
│                                                             │
│  변환 코드:                                                  │
│  converter = tf.lite.TFLiteConverter.from_keras_model(model)│
│  converter.optimizations = [tf.lite.Optimize.DEFAULT]       │
│  tflite_model = converter.convert()                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
