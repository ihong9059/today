## 1. 프로젝트 개요

### 1.1 배경

현재 보유한 교육 자료를 기반으로 AI 입문자를 위한 체계적인 학습 플랫폼을 구축합니다.

**활용 자료:**
| 출처 | 내용 | 특징 |
|------|------|------|
| `유투브/` | 홍정모 강의 요약 (공부 순서, PyTorch 기초) | 학습 로드맵, 방법론 |
| `aiStudy/introduction/` | 퍼셉트론, XOR, 역전파, 번호판 인식 설명서 | 이론 + 실습 코드 |
| `hongLab/` | Jupyter Notebook (미분, 확률, 경사하강법, PyTorch) | 인터랙티브 실습 |
| `cuda/` | Jetson CUDA 학습 계획서 | GPU 프로그래밍 심화 |

### 1.2 목표 사용자

```
┌─────────────────────────────────────────────────────────────────┐
│                        대상 사용자                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 프로그래밍 입문자 (Python 기초 수준)                        │
│     - AI에 관심 있지만 어디서 시작할지 모르는 분                │
│     - 수학에 대한 두려움이 있는 분                              │
│                                                                 │
│  2. 개발자 전환 희망자                                          │
│     - 웹/앱 개발자 중 AI 분야로 전환 희망                       │
│     - 실무에 AI를 적용하고 싶은 분                              │
│                                                                 │
│  3. 학생                                                        │
│     - 컴퓨터공학/데이터사이언스 전공자                          │
│     - 비전공자 중 AI 기초를 배우고 싶은 분                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 핵심 철학

홍정모님의 교육 철학을 기반으로:

> **"핵심 개념 우선"** - 핵심을 알면 나머지는 유도 가능
> **"J커브 성장"** - 초반 정체기 이후 폭발적 성장
> **"수학은 프로그래밍과 함께"** - 코드로 수학을 이해
