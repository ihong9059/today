## 0. 한국기계 맞춤 핵심 ⭐⭐⭐

### 0-1. 가장 큰 우려 = 회사 고유 기술 외부 노출

> "한국기계만이 보유하고 있는 전문지식과 관련 기술이 외부로 노출되는 점을 가장 우려"

본 교육은 이 우려를 **첫 강의 시간부터 마지막 시간까지 일관되게 차단하는 4중 방어 구조**로 설계.

### 0-2. 보안 4중 방어 ⭐⭐⭐

| # | 방어층 | 방법 | Phase |
|:-:|---|---|:-:|
| 1 | **마스킹 SOP** (입력 단계) | 회사명·고유 기술명·고객명·도면번호 등은 입력 전 `[COMPANY]`, `[TECH-A]`, `[PART-001]` 등 placeholder 치환 | 1~3 |
| 2 | **On-Device AI** (Track F) | Ollama / LM Studio 로컬 SLM — 외부 LLM 호출 0%. 회사 노트북 안에서 모든 처리 완결 | 3 |
| 3 | **사내 저장소 격리** | Git 사내 GitLab / 사내 NAS 저장. GitHub·Notion 외부 동기화 금지 정책 | 1~3 |
| 4 | **API zero-retention** | 부득이 Claude API 사용 시 enterprise zero-retention 옵션 + 사내 IT 승인 워크플로우 | 2~3 |

### 0-3. 단계별 AI 도구 사용 vs 보안 위험 매트릭스

| Phase | 도구 | 외부 전송 | 차단 수단 |
|:-:|---|---|---|
| **1** | Claude Code (Pro) | 있음 (Anthropic) | 마스킹 SOP + 사내 정책 + 일반 사무 데이터만 |
| **2** | Claude Code + MCP (Notion 사내) | 제한적 | 마스킹 강화 + 사내 Notion 인스턴스 + 검토 게이트 |
| **3** | Ollama (Mistral·Llama 로컬) | **0%** | 완전 격리 — 외부 망 차단 환경에서도 작동 |

## 1. 교육 목적 (사용자 명시 3대 지향) ⭐

1. **업무 효율성** — 반복 업무 자동화 + 문서·보고서 작성 시간 절감
2. **관련 기술 확보 및 정리** — 사내 분산 노하우의 단일 지식 베이스화
3. **향후 회사 비전 구축** — AI 기반 신제품·서비스 로드맵 도출

각 Phase는 위 3대 목적과 직접 매핑.

## 3. Phase 1 — AI 기초 + 업무 효율화 (2주)

> **목표**: AI를 "도구"로 인식하게 만들고, 회사 데이터를 외부에 노출시키지 않는 마스킹 SOP를 첫날에 정착시킨다.

## 4. Phase 2 — 국책과제 보고서 실무 적용 (2주)

> **목표**: 국책과제 RFP 분석부터 중간/결과 보고서 작성까지 AI로 자동화. 마스킹 + 검토 게이트로 회사 고유 기술 보호.

### 3주차 — 국책과제 RFP·계획서 AI 분석 SOP

|:-:|---|

| 1h | AI에게 RFP 읽히기 — 핵심 요구사항·평가 항목·예산·기간 자동 추출 |
| 1h | **마스킹 강화** — 자사 보유 기술을 입력할 때 placeholder 변환 후 매칭 분석 |
| 1h | 매칭 매트릭스 자동 생성 (자사 자산 ↔ RFP 요구사항) |

**Day 2 (4h) — 사업계획서 초안 자동화**

### 4주차 — 국책과제 중간보고서·결과보고서 자동화

| 시간 | 내용 |
|:-:|---|
