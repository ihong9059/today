# ESP32-DEVKIT_V4 + RC522 배선도

## 연결 다이어그램

```
    ESP32-DEVKIT_V4                    RC522 RFID
    ┌─────────────┐                  ┌─────────────┐
    │             │                  │             │
    │       3.3V ─┼──────────────────┼─ 3.3V       │
    │             │                  │             │
    │        GND ─┼──────────────────┼─ GND        │
    │             │                  │             │
    │  GPIO5 (D5)─┼──────────────────┼─ SDA (SS)   │
    │             │                  │             │
    │ GPIO18(D18)─┼──────────────────┼─ SCK        │
    │             │                  │             │
    │ GPIO23(D23)─┼──────────────────┼─ MOSI       │
    │             │                  │             │
    │ GPIO19(D19)─┼──────────────────┼─ MISO       │
    │             │                  │             │
    │  GPIO4 (D4)─┼──────────────────┼─ RST        │
    │             │                  │             │
    │             │      (미사용) ───┼─ IRQ        │
    │             │                  │             │
    └─────────────┘                  └─────────────┘
```

## 핀 연결표

| RC522 핀 | ESP32 핀 | GPIO | 색상 권장 | 설명 |
|----------|----------|------|----------|------|
| **3.3V** | 3V3 | - | 빨강 | 전원 (5V 절대 금지!) |
| **GND** | GND | - | 검정 | 접지 |
| **SDA** | D5 | GPIO5 | 주황 | SPI Slave Select |
| **SCK** | D18 | GPIO18 | 노랑 | SPI Clock |
| **MOSI** | D23 | GPIO23 | 초록 | SPI Master Out |
| **MISO** | D19 | GPIO19 | 파랑 | SPI Master In |
| **RST** | D4 | GPIO4 | 보라 | Reset |
| **IRQ** | - | - | - | 미사용 (연결 안함) |

## ESP32 보드 실제 핀 위치 (사진 기준)

사진에서 확인된 핀 레이블:
```
상단 (안테나 쪽):
3V3 - EN - UP - UN - 34 - 35 - 32 - 33 - 25 - 26 - 27 - 14 - 12 - GND - 13 - D9 - D10 - D11 - 5V

하단 (USB 쪽):
GND - 23 - 22 - TX - RX - 21 - GND - 19 - 18 - 5 - 17 - 16 - 4 - 0 - 2 - 15 - D8 - D7 - D6

RC522 연결에 사용할 핀:
- GPIO23 (MOSI): 하단 왼쪽에서 2번째
- GPIO19 (MISO): 하단 GND 다음
- GPIO18 (SCK): GPIO19 다음
- GPIO5 (SS): GPIO18 다음
- GPIO4 (RST): 하단 오른쪽 중앙
```

## 주의사항

1. **전압 확인**: RC522는 반드시 **3.3V** 연결 (5V 연결 시 모듈 손상)

2. **점퍼선 품질**: 접촉 불량 시 통신 오류 발생 - 고품질 점퍼선 사용

3. **배선 길이**: 가능한 짧게 (10cm 이내 권장)

4. **안테나 간섭**: RC522 안테나 근처에 금속 물체 배치 금지

5. **공유 SPI**: 다른 SPI 장치와 함께 사용 시 SS 핀 분리 필요

## 테스트 순서

1. 배선 완료 후 전원 연결 전 멀티미터로 단락 확인
2. ESP32 USB 연결
3. RC522의 LED가 켜지는지 확인 (일부 모듈에 LED 있음)
4. Arduino IDE에서 예제 코드 업로드
5. 시리얼 모니터에서 초기화 메시지 확인
6. RFID 카드를 가까이 대고 읽기 테스트
