# 아파트 단지 스마트 조명 + 전기차 충전 안전관리 시스템 제안서

## UTTEC Smart Lighting & EV Safety System (USLC)

**제안사**: ㈜유티텍 (UTTEC Inc.)
**제안일**: 2026-04-25
**대상**: 삼환 아파트 단지
**핵심 컨셉**: 무선(LoRa) 통합 관제 — 옥외 조명 + 전기차 충전소 안전감시

---

## 1. 제안 배경

아파트 관리사무소는 **두 가지 긴급 과제**에 직면해 있습니다.

### 과제 1: 옥외 조명 관리의 비효율

| 현재 문제 | 영향 |
|----------|------|
| 고장 등기구를 순찰로만 발견 | 수일간 사각지대, 주민 불안 |
| 전체 동시 점등/소등 | 전력 낭비, 전기요금 상승 |
| 수동 타이머 운영 | 계절 변화 대응 불가 |
| 전력 사용량 파악 불가 | 에너지 절감 근거 부족 |

### 과제 2: 전기차 충전소 화재 위험 — 더 이상 남의 일이 아닙니다

> **2024년 인천 청라 아파트 지하주차장 전기차 화재** — 아파트 전체가 마비되었습니다.
> 차량 23대 소실, 주민 100여 명 대피, 복구에 수개월.

| 현재 문제 | 위험도 |
|----------|:------:|
| 충전 중 배터리 과열 → 열폭주 → 화재 | 🔴 |
| 지하주차장 스프링클러 작동률 **18%** (소방청 통계) | 🔴 |
| 충전기 과부하/누전 감지 수단 없음 | 🔴 |
| 화재 발생 후에야 인지 (CCTV만으로는 한계) | 🟡 |
| 전기차 충전 전력 관리 체계 없음 (피크 부하 위험) | 🟡 |
| 충전 이력/비용 정산이 불투명 | 🟡 |
| 관리사무소에 전기차 안전 관련 민원 급증 | 🟡 |

**정부도 움직이고 있습니다:**
- 2024.09 — 「전기차 화재 안전관리 대책」 발표 (소방청)
- 2025.02 — 「지하주차장 전기차 안전대책」 추진 (행안부/국토부)
- 2025.08 — 충전사업자 **무과실 책임보험** 가입 의무화
- **스마트 제어 충전기 보급 확대** 정책 추진 중

→ **USLC는 조명제어와 전기차 충전 안전관리를 하나의 무선 플랫폼으로 통합합니다.**

## 4. 전기차 충전소 안전관리 — 핵심 기능

### 4.1 실시간 화재 예방 감시

전기차 화재의 가장 큰 문제는 **"발생 후에야 인지"**한다는 것입니다.
USLC는 화재 **발생 전 징후**를 감지합니다.

```
[충전 중 차량]
     │
     ├── 열화상 온도 센서 ──→ 차량 하부 표면 온도 실시간 감시
     │                         45℃ 경고 → 60℃ 위험 → 80℃ 비상 차단
     │
     ├── 충전기 전류 감시 ──→ 과전류/누전/아크 실시간 감지
     │                         정격 대비 120% → 경고
     │                         정격 대비 150% → 자동 차단
     │
     ├── 연기 감지 센서   ──→ 광학식 연기 감지
     │                         초기 연기 발생 시 즉시 알림
     │
     ├── 가스 센서 (CO)   ──→ 일산화탄소 농도 감시
     │                         50ppm 경고 → 200ppm 환기 강제 가동
     │
     └── VOC 센서         ──→ 전해질 가스 누출 감지
                                배터리 손상 시 전해질 기화 → 조기 경보
```

### 4.2 3단계 자동 대응 체계

관리자가 부재해도 시스템이 **자동으로 대응**합니다.

| 단계 | 감지 조건 | 자동 조치 | 알림 |
|:----:|----------|----------|------|
| **1단계 경고** | 표면 온도 45℃ 이상 또는 전류 120% | 관리사무소 알림, 충전 출력 자동 감소 | 📱 관리소장 앱 푸시 |
| **2단계 위험** | 온도 60℃ 이상 또는 연기 감지 | **해당 충전기 자동 차단**, 인접 충전기 정지, 경고등/경고음 작동 | 📱 + 경비실 + 관리사무소 동시 알림 |
| **3단계 비상** | 온도 80℃ 이상 또는 화재 확정 | **전체 충전기 차단**, 주차장 조명 100% 점등, 비상구 안내등 점멸, 환기 시스템 가동 | 📱 + 🚨 119 자동 신고 + 주민 대피 안내 |

### 4.3 충전기 이상 징후 조기 감지

화재까지 가지 않더라도, 일상적인 **충전기 고장/열화**를 미리 감지합니다.

| 감지 항목 | 방식 | 관리 효과 |
|----------|------|----------|
| 충전 커넥터 과열 | 커넥터부 온도 센서 | 접촉 불량 사전 발견 → 화재 예방 |
| 충전 케이블 열화 | 전류-온도 상관관계 분석 | 케이블 교체 시기 사전 알림 |
| 충전기 내부 과열 | 충전기 하우징 온도 | 냉각 팬 고장, 먼지 축적 감지 |
| 누전/지락 | 누설 전류 감시 | 감전 사고 예방 |
| 충전기 통신 두절 | 텔레메트리 미수신 | 충전기 고장 즉시 파악 |
| 전력 품질 이상 | 전압/전류 파형 분석 | 전기 설비 이상 조기 발견 |

### 4.4 지하주차장 환경 감시

전기차 화재는 **밀폐된 지하공간**에서 특히 위험합니다.

| 감시 항목 | 센서 | 기준값 | 자동 조치 |
|----------|------|--------|----------|
| **일산화탄소 (CO)** | 전기화학식 CO 센서 | 50ppm 경고, 200ppm 위험 | 환기 팬 자동 가동, 알림 |
| **이산화탄소 (CO₂)** | NDIR CO₂ 센서 | 1000ppm 경고 | 환기량 자동 조절 |
| **온도** | 디지털 온도 센서 | 40℃ 이상 경고 | 환기 강화, 충전 제한 |
| **습도** | 온습도 센서 | 80% 이상 경고 | 결로 방지 알림 |
| **VOC (휘발성유기화합물)** | VOC 센서 | 기준 초과 | 전해질 누출 경보 |
| **침수** | 수위 센서 | 수위 감지 | 충전기 전원 차단, 알림 |

### 4.5 스마트 전력 관리

전기차 30대가 동시에 충전하면 아파트 전체 전력의 **30~50%**를 소비합니다.

```

│    ├ 피크 시간대 충전 출력 자동 조절 (7kW → 3.5kW)   │

```

```
Step 2. 열화상 센서 → 충전 차량 하부 방향 조준
Step 3. 가스 센서 → 천장 부근 설치 (가스 상승 특성)
Step 4. 전력 계측 모듈 → 충전기 전원 라인에 클램프
Step 5. 비상 차단 릴레이 → 충전기 전원 라인에 연결
Step 6. 앱으로 등록 및 기준값 설정
```
