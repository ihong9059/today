# 아파트 단지 스마트 조명제어 시스템 제안서

## UTTEC Smart Lighting Control System (USLC)

**제안사**: ㈜유티텍 (UTTEC Inc.)
**제안일**: 2026-04-23
**대상**: 삼환 아파트 단지 보안등 및 옥외등
**기술 기반**: RAK4630 (nRF52840 + SX1262 LoRa) + Zephyr RTOS

---

## 1. Executive Summary

㈜유티텍은 2018년 **국내 최초 LoRa 조명 콘트롤러 상용화**, 2019년 **BLE Mesh 조명제어 기술 개발**, 골프장·금융캠퍼스 납품, 일본 자전거주차장 3,800대 수출 등 **무선 조명제어 전문 기업**입니다.

본 제안은 REVITA 프로젝트에서 검증된 **RAK4630 기반 LoRa 통신 기술**과 UTTEC의 조명제어 양산 경험을 결합하여, 아파트 단지의 보안등·옥외등을 **무선으로 통합 관제**하는 스마트 조명제어 시스템을 제안합니다.

### 핵심 가치
| 항목 | 기존 방식 | USLC 시스템 |
|------|----------|-------------|
| 제어 | 타이머/수동 | AI 자동 + 원격 제어 |
| 에너지 | 고정 출력 | 적응형 디밍 (최대 60% 절감) |
| 유지보수 | 현장 순찰 | 실시간 고장 감지/알림 |
| 배선 | 유선 공사 필요 | **무선 (LoRa), 배선 공사 불필요** |
| 보안 | 단순 점등 | 침입 감지 연동 조명 |

## 3. 하드웨어 구성

### 3.1 Gateway (Tower Unit)

| 항목 | 사양 |
|------|------|
| **MCU** | RAK4630 (nRF52840 + SX1262) |
| **통신 (WAN)** | LTE Cat-M1/NB-IoT (RC76xx) 또는 이더넷 |
| **통신 (LAN)** | LoRa 922.1MHz (SF7~SF12, 14dBm) |
| **유선 확장** | RS485 Modbus RTU (기존 유선 조명 연동) |
| **BLE** | Bluetooth 5.0 (현장 설정/진단) |
| **전원** | AC 220V → DC 12V/5V/3.3V |
| **설치 위치** | 관리사무소 또는 통신실 |
| **커버리지** | 반경 2km (도심 기준 500m~1km) |
| **노드 수용** | 최대 254개 노드 |
| **RTOS** | Zephyr (NCS v2.x) |
| **보안** | AES-128 암호화, TLS 1.2 (LTE) |
| **인증** | KC, CE 대응 (기 취득 경험) |

### 3.2 Node (조명 제어 노드)

| 항목 | 사양 |
|------|------|
| **MCU** | RAK4630 (nRF52840 + SX1262) |
| **통신** | LoRa 922.1MHz + BLE 5.0 |
| **센서** | 조도 센서, PIR 동체감지, 온도 센서 |
| **계측** | 전력 계측 (전류/전압/소비전력) |
| **출력** | PWM 디밍 제어 (0~100%, 0.1% 해상도) |
| **LED 드라이버** | 0-10V / DALI / PWM 인터페이스 |
| **전원** | 등기구 내 AC-DC (기존 전원선 활용) |
| **방수** | IP65 (옥외 설치) |
| **크기** | 80 × 50 × 25mm (등기구 내장형) |
| **동작 온도** | -20℃ ~ +60℃ |

### 3.3 센서 모듈 (옵션)

| 센서 | 용도 | 인터페이스 |
|------|------|-----------|
| 조도 센서 (BH1750) | 주변 밝기 측정 → 자동 디밍 | I2C |
| PIR 센서 (AM312) | 보행자/차량 감지 → 밝기 상승 | GPIO |
| 온도 센서 (TMP117) | LED 과열 보호, 환경 모니터링 | I2C |
| 전력 계측 (HLW8032) | 소비전력/누적전력량 측정 | UART |
| 진동 센서 (SW-420) | 기물 파손/충격 감지 | GPIO (ISR) |
| 카메라 (옵션) | 주차장/출입구 영상 | UART/SPI |

## 5. 핵심 기능

### 5.1 적응형 자동 디밍

```
┌─────────────────────────────────────────────────┐
│              적응형 디밍 알고리즘                  │
│                                                   │
│  입력                                             │
│  ├── 조도 센서 (주변 밝기)                        │
│  ├── PIR 센서 (보행자/차량 감지)                  │
│  ├── 시간 스케줄 (일출/일몰, 계절)                │
│  └── AI 패턴 학습 (과거 데이터)                   │
│                                                   │
│  로직                                             │
│  ├── 일몰 감지 → 자동 점등 (디밍 30%)             │
│  ├── 보행자 감지 → 밝기 상승 (디밍 100%, 30초)    │
│  ├── 심야 시간 → 최저 밝기 (디밍 20%)             │
│  ├── 새벽 감지 → 점진적 소등                      │
│  └── 비상 시 → 전등 100% 점등                     │
│                                                   │
│  출력                                             │
│  └── PWM 0~100% (0-10V / DALI / PWM)             │
└─────────────────────────────────────────────────┘
```

**시간대별 기본 디밍 스케줄**

| 시간대 | 디밍 레벨 | 조건 | 에너지 절감 |
|--------|----------|------|------------|
| 일몰~22시 | 80% | 주민 활동 시간 | 20% |
| 22시~00시 | 50% | 활동 감소 | 50% |
| 00시~04시 | 20% | 심야 (PIR 감지 시 100%) | 80% |
| 04시~일출 | 40% | 새벽 활동 시작 | 60% |
| **PIR 감지** | **100%** | **30초 유지 후 복귀** | - |
| **비상 모드** | **100%** | **화재/침입 시 전체 점등** | - |

### 5.2 실시간 모니터링 및 고장 감지

| 감지 항목 | 방식 | 알림 |
|----------|------|------|
| LED 단선/단락 | 전류 이상 감지 | 즉시 푸시 알림 |
| LED 열화 | 광출력 대비 전력 비율 추적 | 예지정비 알림 |
| 통신 두절 | 텔레메트리 미수신 (3회) | 노드 오프라인 알림 |
| 과열 | 온도 센서 70℃ 초과 | 자동 디밍 감소 + 알림 |
| 전력 이상 | 소비전력 ±30% 편차 | 이상 전력 알림 |
| 기물 파손 | 진동 센서 (슬라이딩 윈도우) | 즉시 알림 + CCTV 연동 |

### 5.3 에너지 관리

- **실시간 전력 계측**: 각 노드별 소비전력(W), 누적전력량(kWh) 측정
- **에너지 리포트**: 일별/월별/연별 전력 소비 분석
- **비용 절감 시뮬레이션**: 기존 대비 절감 금액 자동 산출
- **탄소 배출량**: CO₂ 감축량 자동 계산
- **피크 관리**: 시간대별 전력 피크 분산

### 5.4 보안 연동

```
보안 이벤트 발생
  ├── PIR 센서 → 비정상 시간대 인체 감지
  │   └── 해당 구역 + 인접 구역 100% 점등
  │   └── CCTV PTZ 연동 (해당 방향 전환)
  │   └── 관리사무소 알림
  │
  ├── 진동 센서 → 등기구 충격/파손 감지
  │   └── 즉시 부저 알람
  │   └── CCTV 녹화 트리거
  │   └── 관리사무소 + 경비실 알림
  │
  ├── 화재 경보 연동 → 소방 신호 수신
  │   └── 피난 경로 등 100% 점등
  │   └── 비상구 방향 점멸
  │   └── 전체 옥외등 100% 점등
  │
  └── 출입 통제 연동
      └── 게이트 개폐 시 주차장등 점등
      └── 경비초소 주변 조명 강화
```

### 5.5 스마트 스케줄링

- **천문 시계**: GPS 기반 일출/일몰 자동 계산 (계절별 자동 보정)
- **요일별 스케줄**: 평일/주말/공휴일 차별 운영
- **이벤트 연동**: 단지 행사 시 특별 조명 모드
- **구역별 그룹**: 보안등/산책로/주차장/놀이터 등 구역별 독립 제어
- **우천 모드**: 기상 API 연동 → 흐린 날 조기 점등

### 5.6 OTA 원격 펌웨어 업데이트

- **Gateway → Node**: LoRa 분할 전송 (MCUboot Dual-bank)
- **안전성**: CRC32 검증, 실패 시 자동 롤백
- **순차 배포**: 구역별 순차 업데이트 (서비스 중단 최소화)
- **버전 관리**: 관제 대시보드에서 전체 노드 펌웨어 버전 확인

### 5.7 BLE 현장 설정

- **스마트폰 앱**: 현장에서 BLE로 노드 개별 설정
- **설정 항목**: 디밍 커브, 센서 감도, 스케줄, 노드 ID
- **진단**: 센서값 실시간 확인, LoRa 통신 품질(RSSI) 측정
- **커미셔닝**: 설치 시 노드 등록 및 위치 매핑

## 6. 통신 프로토콜

### 6.1 LoRa 통신 (REVITA 검증 프로토콜 확장)

| 항목 | 사양 |
|------|------|
| **주파수** | 922.1MHz (한국 ISM 대역) |
| **변조** | LoRa SF7~SF12, BW125kHz |
| **출력** | 14dBm (KC 인증 기준) |
| **프레임** | 16B 고정 (RVT-LoRa v1.1) |
| **암호화** | AES-128-CTR + AES-CMAC |
| **ACK** | 1.5초 타임아웃, 최대 3회 재전송 |
| **도달 거리** | 도심 500m~1km, 개활지 2km |
| **노드 수** | 최대 254개 (TDMA 스케줄링) |

### 6.2 조명 제어 Opcode (확장)

| Op | 이름 | 방향 | 용도 |
|----|------|:----:|------|
| 0x60 | OP_DIMMING_SET | G→N | 디밍 레벨 설정 (0~1000, 0.1% 단위) |
| 0x61 | OP_DIMMING_FADE | G→N | 페이드 전환 (target, duration_ms) |
| 0x62 | OP_SCHEDULE_SET | G→N | 스케줄 설정 (slot_id, hour, min, level) |
| 0x63 | OP_GROUP_CMD | G→N | 그룹 명령 (group_id, action) |
| 0x64 | OP_EMERGENCY | G→N | 비상 모드 (ON/OFF) |
| 0x70 | OP_LIGHT_TELEMETRY | N→G | 조명 상태 (level, power_w, temp, lux) |
| 0x71 | OP_LIGHT_EVENT | N→G | 이벤트 (PIR, 고장, 과열, 진동) |
| 0x72 | OP_ENERGY_REPORT | N→G | 에너지 리포트 (kWh, 운영시간) |

### 6.3 텔레메트리 데이터 구조

```c
struct light_telemetry {      // 10B (LoRa DATA 필드)
    uint16_t dimming_level;    // 현재 디밍 (0~1000)
    uint16_t power_mw;         // 소비전력 (mW)
    int8_t   temperature;      // LED 모듈 온도 (℃)
    uint16_t lux;              // 주변 조도 (lux)
    uint8_t  pir_count;        // PIR 감지 횟수 (마지막 보고 이후)
    uint16_t energy_wh;        // 누적 전력량 (Wh, 리셋 가능)
};
```
