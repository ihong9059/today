## 1. 시스템 개요

### 1.1 도입 배경

영업사원의 현장 방문 업무를 체계적으로 관리하는 것은 기업 경쟁력 강화의 핵심입니다. 그러나 기존 방식의 영업 관리에서는:

- 방문 기록이 개인별로 관리되어 공유가 어려움
- 거래처 방문 이력 추적이 체계적이지 않음
- GPS 기반 위치 정보가 없어 방문 현황 파악 어려움
- 현장 사진 등 시각적 자료가 기록되지 않음
- 영업사원 활동 현황 실시간 모니터링 불가

### 1.2 시스템 목적

**UTTEC 영업관리 시스템**은 영업사원이 현장에서 수집한 방문 데이터를 체계적으로 데이터베이스화하여:

| 목적 | 기대 효과 |
|------|-----------|
| **방문 기록 체계화** | 모든 현장 활동이 GPS 위치, 사진, 텍스트로 기록됨 |
| **거래처 관리 강화** | 거래처별 방문 이력 및 담당자 정보 통합 관리 |
| **영업 활동 모니터링** | 영업사원별 방문 현황 실시간 파악 |
| **데이터 기반 의사결정** | 축적된 데이터를 기반으로 영업 전략 수립 |

## 3. 주요 기능

### 3.1 모바일 웹 기능

#### 3.1.1 방문 기록 입력 화면

| 기능 | 설명 |
|------|------|
| **GPS 자동 수집** | 앱 실행 시 자동으로 현재 위치를 수집하여 표시 |
| **영업사원 이름** | 담당 영업사원 입력 |
| **방문 유형 선택** | 영업/납품/AS/수금/미팅/기타 중 선택 |
| **거래처 정보** | 거래처명, 담당자, 연락처 입력 |
| **방문 내용** | 상세 내용 기술 |
| **다음 방문일** | 후속 방문 예정일 설정 |
| **사진 촬영/선택** | 카메라로 촬영하거나 갤러리에서 선택 |

#### 3.1.2 방문 유형 분류

| 코드 | 유형 | 설명 | 활용 |
|------|------|------|------|
| sales | 영업 | 일반 영업 방문 | 신규 고객 발굴, 계약 상담 |
| delivery | 납품 | 제품 납품 | 제품 인도, 검수 |
| service | AS | 사후 서비스 | 장비 수리, 점검 |
| collect | 수금 | 대금 수금 | 미수금 회수 |
| meeting | 미팅 | 회의/상담 | 기술 미팅, 협의 |
| other | 기타 | 기타 방문 | 기타 목적 |

#### 3.1.3 검색 화면

| 기능 | 설명 |
|------|------|
| **키워드 검색** | 거래처명, 메모에서 키워드 검색 |
| **방문 유형 필터** | 특정 유형만 조회 |
| **기간 필터** | 시작일~종료일 지정 |
| **상세 보기** | 사진, 지도, 전체 내용 확인 |

### 3.2 웹 대시보드 기능

#### 3.2.1 통계 현황

| 항목 | 설명 |
|------|------|
| 전체 방문 수 | 누적된 총 방문 기록 건수 |
| 오늘 방문 | 당일 등록된 방문 건수 |
| 주간 방문 | 최근 7일 방문 건수 |
| 월간 방문 | 최근 30일 방문 건수 |
| 거래처 수 | 등록된 총 거래처 수 |
| 유형별 현황 | 방문 유형별 건수 분포 |

#### 3.2.2 지도 기능

- 모든 방문 기록을 지도 위에 마커로 표시
- 마커 클릭 시 상세 정보 팝업
- 자동 줌/패닝으로 전체 데이터 영역 표시
- 방문 유형별 마커 색상 구분

#### 3.2.3 검색 및 조회

- 실시간 검색 기능
- 자동 새로고침
- 상세 정보 모달 (사진, 위치, 내용)
- 영업사원별 필터링

   └─▶ 영업: 일반 영업 방문

5. 거래처 정보 입력
   └─▶ 거래처명: (주)○○기업

9. 데이터 전송
   └─▶ "방문 기록 저장" 버튼 클릭

## 5. 방문 유형별 활용 가이드

### 5.1 유형별 권장 사용 시나리오

| 유형 | 사용 시나리오 | 예시 |
|------|--------------|------|
| **영업** | 신규 고객 발굴, 견적 상담 | "A공장 설비 견적 상담", "신규 고객 현장 조사" |
| **납품** | 제품 인도, 설치 | "IoT 센서 납품 완료", "설치 및 시운전" |
| **AS** | 장비 수리, 정기 점검 | "센서 모듈 교체", "정기 점검 완료" |
| **수금** | 대금 수금, 미수금 회수 | "3월분 대금 수금 완료", "미수금 협의" |
| **미팅** | 기술 회의, 프로젝트 협의 | "신규 프로젝트 킥오프", "설계 협의" |
| **기타** | 위 유형에 해당하지 않는 경우 | "전시회 참관", "교육 참석" |

### 5.2 효과적인 데이터 입력 팁

1. **거래처명은 일관되게**
   - 좋은 예: "(주)○○기업"
   - 나쁜 예: "○○기업", "○○", "주식회사○○"

2. **방문 내용은 구체적으로**
   - 상담 내용
   - 고객 요청 사항
   - 후속 조치 필요 사항
   - 다음 방문 예정 내용

3. **사진은 적극 활용**
   - 현장 상황 기록
   - 장비 상태 기록
   - 명함 촬영
   - 견적서/주문서 촬영

## 7. API 명세

### 7.1 방문 기록 저장 API

```
POST /api/visit
Content-Type: multipart/form-data

Parameters:
- device_id: 기기 식별자 (string, 필수)
- sales_name: 영업사원명 (string, 필수)
- customer_name: 거래처명 (string, 필수)
- contact_person: 담당자 (string, 선택)
- contact_phone: 연락처 (string, 선택)
- visit_type: 방문 유형 (string, 필수)
  - sales | delivery | service | collect | meeting | other
- notes: 방문 내용 (string, 선택)
- next_visit_date: 다음 방문일 (string, 선택)
- latitude: 위도 (number, 선택)
- longitude: 경도 (number, 선택)
- photo: 사진 파일 (file, 선택)

Response:
{
  "id": 123,
  "message": "방문 기록이 저장되었습니다"
}
```
