## 4. 검토서가 놓친 핵심 발견 (포트폴리오 분석)

기존 협업 검토서(2026-05-02)는 응원봉을 1순위로 추천했지만, **이진서 포트폴리오에서 검토서가 놓친 강한 매칭 신호 2개**를 발견:

### 발견 1: 응원단장 직접 운영 경력 (A안 슈퍼매칭)
- 검토서: "음악 관심 + K-POP 시장 감각" (간접 추정)
- 실제 포트폴리오:
  - 서울대 응원단 7기 입단 (2019.12)
  - **제7대 응원단장** (2022.09 ~)
  - **제6대 기획단장** (2020.12 ~ 2021.02)
  - **공과대학 홍보전략국장** (2021.12 ~)
- → "응원단장이 진짜 만드는 응원봉" 메시지 = 심사위원 한 줄 임팩트 최강

### 발견 2: 수학 교육 + EdTech 마케팅 인턴 (B안 신규 강력 후보)
- 검토서: 누락 (교육은 "강사" 역량으로만 일반화)
- 실제 포트폴리오:
  - 수학 과외 25회 (총 40회) — **서울대 수학교육과 24학번 합격생 배출**
  - 수학 조교 7곳 (예섬·한석원·진인사·에듀플렉스·허윤정수학연구소·연세이룸·CSM17)
  - **수학대왕 그로스 마케팅팀 인턴** (2024.03)
  - 수학 문제 제작자 (허윤정수학연구소·CSM17)
- → UTTEC Remotion 30+ 영상 파이프라인과 결합 시 **시제품 1주 + 첫 매출 2개월** 가능

### 발견 3: 영상·콘텐츠 풀세트 (전 아이템 공통 강점)
- Adobe CC 전체 (Ps/Pr/Ae/Ai)
- AI 영상툴 풀세트 (ChatGPT·Gemini·Claude·SunoAI·LumaAI·Higgsfield)
- 총학생회 영상팀장 2회 (제62대·제64대)
- 인스타그램 스낵툰 채널 운영
- → **외주비 0원으로 모든 콘텐츠 자체 생산 가능** (1R 도전신청서 이미지·숏폼 즉시 제작)

### 발견 4: 본인 최종 비전 = "락 기반 미디어 커뮤니티 회사"
- 포트폴리오 PERSONAL GOALS 명시
- → A안 + C안과 직접 정렬, 장기 몰입 보장

## 5. 추천 전략

### 🥇 메인 신청: **A안 (AI 응원봉 + 팬덤 미디어 플랫폼)**

**이유:**
1. 이진서 매칭 + UTTEC 자산 + 시장 차별성 + 임팩트 모두 만점 (30/30)
2. **특허 + MVP 보유** → 1R 시점 즉시 시연 가능 (시제품 단계 패스)
3. **블루오션** → 검토서 검증 완료 (경쟁 제품 없음)
4. 4R 대국민 IR에서 **응원봉 라이브 시연 = 화제성 폭발**
5. 이진서 본인 최종 비전과 정렬

### 🥈 보조: **B안 (AI 개념해설 영상)** — 별도 트랙 진행

**이유:**
1. 본 사업은 1인 1아이디어 신청만 가능
2. B안은 UTTEC 인프라 100% 활용 → 시제품 1주 가능
3. 수익화 빠름 → **TIPS 또는 청년창업사관학교 별도 신청** 권장
4. A안 사업화 단계의 캐시플로우로 활용

### 미선택 사유

- **C안**: 강력한 카테고리지만 B2B 사이클 길어 4R 시점(7개월) 시제품 검증 어려움 → A안 사업화 단계의 후속 사업으로 보존
- **D안**: 시장 검증 완료지만 이진서 매칭이 응원봉만큼 강하지 않음 → UTTEC 단독 onDevice AI 검증 트랙으로 별도 진행 (이미 2026-05-08 결정됨)
