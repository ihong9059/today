# AI FanStick — 이미지 5장 디자인 가이드

> **용도**: 「모두의 창업 프로젝트」 도전신청서 첨부 이미지 5장
> **사양**: 1920 × 1080 px (16:9), JPG/PNG/GIF, 각 5MB 이하 권장
> **시안 미리보기**: `index.html` (Chrome에서 열기)
> **최종 제작 도구**: Adobe Illustrator / Photoshop / Figma (이진서 직접 제작)

---

## 1. 디자인 시스템

### 1.1 컬러 팔레트

| 역할 | 컬러 | HEX | 용도 |
|------|------|-----|------|
| Primary | 일렉트릭 퍼플 | `#6B2DCB` | 주 강조 (헤드라인·CTA) |
| Accent 1 | 핫핑크 | `#FF2D87` | K-POP 에너지 (그라디언트) |
| Accent 2 | 시안 네온 | `#00E5CY` | 데이터·기술 강조 |
| Accent 3 | 그린 네온 | `#00FF95` | 검증·신뢰 (체크리스트) |
| Accent 4 | 오렌지 | `#FF8C42` | 우상향·성장 |
| Background | 딥 네이비 | `#0A0E27` | 메인 배경 |
| BG 보조 | 다크 퍼플 | `#1A0E3A` | 그라디언트 보조 |
| Text 주 | 화이트 | `#FFFFFF` | 본문 |
| Text 보조 | 그레이 블루 | `#9BA3C7` | 캡션·라벨 |

### 1.2 그라디언트 공식

```css
/* 메인 K-POP 그라디언트 */
background: linear-gradient(135deg, #6B2DCB 0%, #FF2D87 100%);

/* 텍스트 글로우 그라디언트 */
background: linear-gradient(90deg, #FF2D87, #FF8C42, #00E5FF);

/* 시간 흐름 (4단계 동작) */
색1 시안 #00E5FF → 색2 보라 #6B2DCB → 색3 핑크 #FF2D87 → 색4 오렌지 #FF8C42
```

### 1.3 타이포그래피

| 용도 | 폰트 | 크기 | 굵기 |
|------|------|------|------|
| Hero (제품명) | Pretendard / Wanted Sans | 200pt | ExtraBold (800) |
| H2 (시장 헤드) | Pretendard | 84~100pt | Black (900) |
| H3 (부제) | Pretendard | 44~56pt | Bold (700) |
| 강조 숫자 | Pretendard | 200~240pt | Black (900) |
| 본문 | Pretendard | 24~32pt | Regular (400) |
| 캡션 | Pretendard | 16~22pt | Medium (500) |
| Eyebrow (영문) | Pretendard | 24pt | Bold (700), letter-spacing 0.15em |

> **다운로드**: https://github.com/orioncactus/pretendard (무료 한글 폰트)
> **대체 무료 폰트**: Wanted Sans (원티드랩), 노토 산스 KR

### 슬라이드 3 — 제품

**목적**: AI 동작 원리 한눈에

## 3. 제작 워크플로우 (이진서)

### Step 1 — 시안 검토 (5/10 토)

1. Chrome에서 `index.html` 열어 5장 시안 확인
2. 슬라이드별 디자인 의도(노트) 숙지
3. UTTEC과 미팅 시 자산 요청 목록 확정

### Step 2 — 자산 수집 (5/10 토)

이진서 본인:
- [ ] 응원단장 시절 사진 1~2장 (무대 위, 화려한 조명)
- [ ] 비즈니스 캐주얼 프로필 사진 1장 (정면 또는 사선)

UTTEC 요청:
- [ ] AI FanStick MVP 실물 사진 (발광 상태)
- [ ] AI FanStick 3D 렌더 또는 PCB 사진
- [ ] 특허 출원증 PDF
- [ ] BLE Mesh 양산 사진 (일본 자전거주차장 또는 기타)
- [ ] UTTEC 로고

### Step 3 — Adobe 제작 (5/12 월, 약 4~6시간)

**옵션 A: Photoshop**
1. 1920×1080 px 파일 5개 생성
2. 각 슬라이드 시안 참고하여 레이아웃 재현
3. 자산 합성 + 글로우 효과 (Outer Glow)
4. PNG 24bit 저장

**옵션 B: Figma (권장)**
1. Figma에서 1920×1080 5개 프레임 생성
2. 디자인 시스템 변수 등록 (컬러·폰트)
3. 자산 임포트 + 효과 추가
4. PNG 2x로 Export

**옵션 C: AI 활용 (가장 빠름)**
1. 본 시안의 HTML을 디자인 베이스로 사용
2. Higgsfield/Luma로 응원봉 발광 영상 생성 → 정지 컷 추출
3. Adobe로 텍스트만 한국어 다듬어 합성
4. PNG Export

### Step 4 — 검토 (5/13 화)

- 5장 모두 1920×1080 px 확인
- 텍스트 가독성 (모니터 50% 축소해도 헤드라인 읽힘)
- 컬러 일관성 (5장이 한 시리즈로 보이는지)
- 파일 크기 5MB 이하

### Step 5 — 제출 (5/15 목)

- modoo.or.kr 「도전하기」 → 이미지 첨부 (5장 이내)
- 파일명 권장: `01_표지.png`, `02_시장.png`, ... `05_팀로드맵.png`

## 4. 빠른 제작 단축키

### "Adobe 익숙하지 않은 경우" — Canva 활용

1. Canva에서 1920×1080 프레젠테이션 생성
2. 본 시안 스크린샷을 참조 이미지로 업로드
3. Pretendard 폰트 + 본 가이드 컬러 코드 적용
4. 자산만 교체하면 1~2시간 내 완성 가능

### "시간이 정말 없을 때" — 본 HTML 시안 직접 사용

1. Chrome에서 `index.html` 열기
2. 각 슬라이드 영역만 보이도록 스크롤
3. F12 (개발자도구) → 디바이스 모드 1920×1080
4. Ctrl+Shift+P → "Capture full size screenshot"
5. PNG 저장 후 자산만 Photoshop으로 합성

→ **이 방법으로도 시안 그대로 제출 가능**. 다만 본인 사진·MVP 사진은 반드시 합성 권장.
