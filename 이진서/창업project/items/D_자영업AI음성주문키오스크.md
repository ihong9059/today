# D. 자영업 AI 음성주문 키오스크

> **한 줄 요약**: 시니어·외국인도 말로 주문하는, 인터넷 없이 동작하는 온디바이스 AI 음성주문 키오스크. 고령 자영업자를 위한 키오스크 보급 솔루션.

> **트랙**: 일반/기술트랙 (창업진흥원) — 또는 로컬트랙도 가능
> **신청 마감**: 2026-05-15 16:00
> **종합 점수**: 22/30 (TOP 4순위)

## 1. 사업 개요

### 1.1 제품 정의

| 구성 | 내용 |
|------|------|
| **하드웨어** | 자영업용 키오스크 (안드로이드 태블릿 + 마이크 + 스피커 + 카드리더) |
| **온디바이스 AI** | KWS(메뉴명 인식) + STT(음성→텍스트) + 의도 분류 (microGPT 4K~150K) |
| **소프트웨어** | 메뉴 등록 + 주문 처리 + POS 연동 + 다국어(한·영·중·일) |
| **운영자 앱** | 사장님용 메뉴 관리 + 매출 분석 (인터넷 없어도 운영 가능) |
| **차별 핵심** | **인터넷 단절·노이즈 환경에서도 동작** (Whisper/Cloud 미사용, 100% 온디바이스) |

### 1.2 한 문장 정의

> 「'키오스크 어떻게 써요?' 시니어 손님이 못 쓰는 키오스크는 의미가 없다. **메뉴를 그냥 말하면 주문이 들어가는, 인터넷 없이도 동작하는 AI 음성 키오스크.**」

### 1.3 핵심 차별점

1. **온디바이스** — Whisper 등 클라우드 AI 미사용, 매장 인터넷 끊겨도 동작
2. **시니어·외국인 친화** — 터치 UI 한계 돌파, 음성으로 자연스러운 주문
3. **저비용** — 클라우드 AI API 월 비용 0원 (자영업자 부담 최소)

## 8. 모집공고 정합성 — 도전신청서 핵심 메시지 초안

### 8.1 아이디어 명

### 8.2 한 단락 요약 (도전신청서 메인)

> 한국 키오스크 보급률은 18%까지 올랐지만, 시니어 손님은 여전히 '키오스크 어떻게 써요?'를 묻는다. 외국인 관광객은 메뉴 사진만으로 주문하기 어렵다. 본 아이템은 **메뉴를 그냥 말하면 주문이 들어가는 온디바이스 AI 음성 키오스크**다. Whisper 등 클라우드 AI를 사용하지 않아 매장 인터넷이 끊겨도 동작하며, 자영업자는 클라우드 API 비용 부담이 없다. 서울대 마케팅 인턴 출신 대표가 자영업 영업과 정부 사업 매칭을 책임지고, **38년 임베디드 + onDevice AI 검증을 마친 UTTEC**이 기술 파트너다. 키오스크 1대 150만(BOM 80만) + 월 1만 구독 모델로 1년차 매출 6.5억, 3년차 94억을 목표로 한다. **소상공인 디지털전환 정부지원 사업과 직접 매칭** 가능하다.

### 8.3 차별성 (1R 평가 핵심)

1. **온디바이스 AI** — 매장 인터넷 끊겨도 동작 (Whisper·Cloud 의존 ❌)

3. **시니어·외국인 친화** — 터치 UI 한계 돌파
4. **정부지원 직접 매칭** — 소상공인 디지털전환 사업 적합
