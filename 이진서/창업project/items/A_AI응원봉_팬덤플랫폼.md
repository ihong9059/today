# A. AI 응원봉 + 팬덤 미디어 플랫폼

> **한 줄 요약**: 서울대 응원단장 출신이 만드는, AI가 노래를 듣고 스스로 색·패턴을 만드는 K-POP 응원봉 + 팬덤 영상 자동생성 플랫폼

> **트랙**: 일반/기술트랙 (창업진흥원)
> **신청 마감**: 2026-05-15 16:00
> **종합 점수**: 30/30 (TOP 1순위)

---

## 1. 사업 개요

### 1.1 제품 정의

| 구성 | 내용 |
|------|------|
| **하드웨어** | AI 응원봉 (ESP32-C3 + BLE + 고휘도 LED + 마이크 + IMU) |
| **온디바이스 AI** | KWS(Keyword Spotting) + 비트 검출 + 색·패턴 자동 생성 (Voice AI/Beat-tracking 4K~150K params) |
| **앱** | Android/iOS 앱 (BLE 연결, 곡 인식, 팬덤 커뮤니티) |
| **클라우드** | 곡별 응원 시나리오 저장·공유 (FastAPI + WebSocket) |
| **팬덤 플랫폼** | 응원봉 사용 영상 자동 편집 → 숏폼 자동 생성 → 인스타·틱톡 업로드 |

### 1.2 한 문장 정의

> 「수동 응원봉의 시대는 끝났다. **곡을 듣고 스스로 빛나는 응원봉** + **팬이 찍은 영상을 AI가 편집해주는 자동 숏폼 플랫폼** = K-POP 팬덤 경제의 다음 인프라」

### 1.3 핵심 차별점

1. **세계 최초** — 온디바이스 AI(microGPT/KWS) 통합 응원봉 (블루오션, UTTEC 특허 출원 완료)
2. **응원단장 출신 대표** — 진짜 사용자가 만든 제품
3. **응원봉 + 콘텐츠 = 양면 시장** — HW 1회 판매 + 팬덤 콘텐츠 지속 수익

## 8. 모집공고 정합성 — 도전신청서 핵심 메시지 초안

### 8.1 아이디어 명

> **「AI FanStick — 노래를 듣고 스스로 빛나는, 세계 최초 K-POP AI 응원봉」**

### 8.2 한 단락 요약 (도전신청서 메인)

> 글로벌 K-POP 시장은 13조 원 규모로 성장했지만, 응원봉은 30년째 똑같다. 팬은 콘서트마다 곡별 색·패턴을 미리 외워야 하고, 기획사는 곡마다 수동으로 프로그래밍한다. 본 아이템은 **온디바이스 AI(KWS+Beat Detection)를 탑재해 곡을 듣고 스스로 색·패턴을 생성하는 세계 최초 AI 응원봉**이다. 서울대 응원단장 출신 대표가 사용자 관점에서 설계하고, 38년 임베디드·양산 5종 실적의 UTTEC이 기술 파트너로 참여한다. 핵심 기술은 **특허 출원 완료**, MVP는 ESP32-C3+BLE+Android+FastAPI로 구현 완료된 상태다. 응원봉 1회 판매 + 팬덤 영상 자동편집 플랫폼 구독의 **양면 수익 모델**로 1년차 매출 9.7억, 3년차 100억을 목표로 한다.

### 8.3 차별성 (1R 평가 핵심)

1. **세계 최초 카테고리** — onDevice AI 응원봉, 경쟁 제품 없음 (블루오션)
2. **특허 + MVP 보유** — 1R 시점 이미 검증 완료, 시제품 제작 단계 패스
3. **응원단장 출신 대표** — 진짜 사용자가 만든 제품, 사용자 인사이트 깊이
4. **양산 실적 보유 기술 파트너** — 1만 대 양산 즉시 가능, 신뢰성 확보

### 8.4 효과성 (1R 평가 핵심)
