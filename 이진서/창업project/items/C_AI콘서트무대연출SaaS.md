# C. AI 콘서트 무대연출 SaaS (응원봉 + 조명 + 영상 동기화)

> **한 줄 요약**: 응원봉 1만 개, 무대 조명 200채널, 미디어월 영상을 AI가 곡 한 번 듣고 자동으로 동기화 연출하는, 콘서트·페스티벌 무대연출 자동화 SaaS

> **트랙**: 일반/기술트랙 (창업진흥원)
> **신청 마감**: 2026-05-15 16:00
> **종합 점수**: 25/30 (TOP 3순위, B2B 큰그림)

---

## 1. 사업 개요

### 1.1 제품 정의

| 구성 | 내용 |
|------|------|
| **AI 엔진** | 곡 분석(BPM·키·감정·구간) + 무대연출 시퀀스 자동 생성 |
| **응원봉 제어** | BLE Mesh 기반 1만 개 동시 색·패턴 제어 (UTTEC 기존 기술) |
| **조명 제어** | DMX512 / Art-Net 통합 (업계 표준) |
| **영상 제어** | 미디어월 영상 자동 생성 (Suno + Luma + Higgsfield + Remotion) |
| **타임라인 에디터** | 연출가 수정 가능한 웹 GUI (드래그·드롭) |
| **운영 모드** | 사전 프로그램 + 실시간 보정 (현장 반응형) |

### 1.2 한 문장 정의

> 「콘서트 1회 연출 비용 1억, 준비 기간 2개월. **AI에게 곡만 주면 1시간 안에 응원봉·조명·영상이 한 호흡으로 연출되는 시퀀스를 만든다.** 비용 1/10, 시간 1/100.」

### 1.3 핵심 차별점

1. **응원봉까지 통합** — 기존 무대연출 SW (Resolume·Madrix)는 조명·영상까지만, 응원봉은 별도 시스템
2. **AI 자동 생성** — 곡 한 번 듣고 시퀀스 초안 완성
3. **실시간 보정** — 현장 관객 반응에 따라 색·강도 자동 조정

## 8. 모집공고 정합성 — 도전신청서 핵심 메시지 초안

### 8.1 아이디어 명

> **「StagePilot — 응원봉·조명·영상을 AI가 자동 연출하는 콘서트 무대 SaaS」**

### 8.2 한 단락 요약 (도전신청서 메인)

> K-POP 글로벌 투어는 연 1,200회를 넘어섰고, 콘서트 1회 무대연출에 평균 1억, 준비 기간 2개월이 든다. 그러나 응원봉(팬용), 조명(무대), 영상(미디어월)은 여전히 따로 운영된다. 본 아이템은 **곡 1개를 입력하면 AI가 응원봉 1만 개·조명 200채널·미디어월 영상까지 한 호흡으로 자동 연출하는 세계 최초 무대연출 SaaS**다. 서울대 응원단장 출신 대표가 무대 운영을 책임지고, **15년간 BLE Mesh 양산을 해온 UTTEC의 응원봉 제어 기술 + AI FanStick 특허 + 38년 임베디드 노하우**가 기술 파트너다. 월 3,000만 라이선스 모델로 1년차 매출 약 17억(보수적 5억), 3년차 110억을 목표로 한다.

### 8.3 차별성 (1R 평가 핵심)

1. **세계 최초 응원봉 통합** — Resolume·Madrix 등 기존 솔루션 대비 유일한 차별점
2. **AI 자동 생성** — 연출가 5~10년 노하우를 1주로 단축
3. **검증된 기술 파트너** — UTTEC BLE Mesh 양산 15년, AI FanStick 특허
4. **응원단장 출신 대표** — 무대 운영 실전 경험

### 8.4 효과성 (1R 평가 핵심)

1. **B2B 큰 매출 단가** — 월 3,000만 × 10개사 = 36억 (3년차)
2. **K-POP 글로벌 시장** — 연 1,200회 투어 × 회당 1억 무대연출 시장
3. **인디 시장 확장 가능** — 월 50만 구독으로 4차 시장
4. **데이터 자산** — 곡-연출 패턴 누적 → 향후 음악·영상 AI 인프라
