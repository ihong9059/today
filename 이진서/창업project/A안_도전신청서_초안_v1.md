## 3. 아이디어 상세

### 3.1 문제 인식 (Why now?)

- **K-POP 글로벌 시장**은 2025년 약 13.4조 원 규모로, 매년 두 자릿수 성장 중이다 (CAGR 7.3%).
- 그러나 **응원봉**은 30년 전과 본질적으로 동일하다 — 기획사가 곡마다 색을 미리 프로그래밍하거나, 팬이 수동 버튼으로 색을 바꿔야 한다.
- **3가지 미해결 문제**:
  1. **팬 입장**: 콘서트마다 곡별 색·패턴을 미리 외워야 하고, 새 곡이면 색 통일이 안 된다.
  2. **기획사 입장**: 곡당 평균 200만 원의 응원봉 시퀀스 프로그래밍 비용 + 매 투어마다 반복 작업.
  3. **시장 전체**: 응원봉 1회 판매 후 추가 매출 없음. 팬덤 데이터 자산화 부재.

### 3.2 해결 방안 (What we make)

**AI FanStick**은 **온디바이스 AI(KWS + Beat Detection)**를 탑재해 곡을 듣고 스스로 색·패턴을 생성하는 응원봉 + 팬덤 영상 자동편집 플랫폼이다.

| 구성 | 내용 |
|------|------|
| **하드웨어** | ESP32-C3 + BLE 5.0 + 고휘도 LED + MEMS 마이크 + IMU (관성센서) + 리튬 배터리 |
| **온디바이스 AI** | KWS(Keyword Spotting) + Beat Tracking + 색·패턴 생성 모델 (4K~150K params, microGPT 기반) |
| **모바일 앱** | Android/iOS — BLE 연결, 곡 인식, 팬덤 커뮤니티 |
| **클라우드** | FastAPI + WebSocket — 곡별 응원 시나리오 저장·공유 |
| **팬덤 플랫폼** | 응원봉 사용 영상 → AI 자동 편집 → 숏폼 자동 생성 → SNS 업로드 |

**핵심 동작**:
- 콘서트장 또는 집에서 음악이 재생되면, 응원봉이 마이크로 곡을 인식 → BPM과 감정을 분석 → 곡에 맞는 색·패턴을 자동 생성
- 사용자는 별도 조작 없음. 노래만 들리면 응원봉이 알아서 빛난다.

### 3.3 지금 (Now) 가능한 이유

| 요인 | 근거 |
|------|------|
| **온디바이스 AI 가능** | microGPT 등 4K~150K 파라미터 모델로 ESP32-C3에서 실시간 추론 가능 (UTTEC 자체 검증 완료, 2026-05) |
| **BLE 5.0 보급** | 모든 스마트폰이 BLE 5.0 지원, 응원봉-앱 즉시 연결 |
| **K-POP 글로벌 정점** | 2024년 K-POP 글로벌 투어 1,200회+ 사상 최대 |
| **특허·MVP 확보** | UTTEC이 AI FanStick 특허 출원 완료, MVP(ESP32-C3+BLE+Android+FastAPI) 구현 완료 |
