## 2. 협업이 필요한 이유

### 2.1 UTTEC 측 필요

| 과제 | 설명 |
|------|------|
| **국가지원 접근** | 사업년수 10년으로 창업지원금, 청년창업사관학교 등 수혜 불가. 신규 법인이 필요 |
| **세대교체** | AI 시대는 젊은 감각과 빠른 실행력이 경쟁력 |
| **영업/마케팅** | 기술은 있으나 B2C 마케팅, 콘텐츠 유통, SNS 운영 역량 부족 |
| **자원 분산 해소** | 교육·제품·팩토리 3개 사업을 1인이 운영하는 한계 |

### 2.2 이진서 측 강점

| 강점 | UTTEC과의 시너지 |
|------|-----------------|
| **서울대 기계공학** | 하드웨어/제조 이해 → 응원봉 양산, 스마트팩토리 기술 소통 가능 |
| **벤처경영 부전공** | 사업계획서, 투자유치, 법인설립 등 경영 기초 보유 |
| **활달한 성격 + 친교감** | 교육 현장 강사, 영업 미팅, 네트워킹에 적합 |
| **동영상 제작 관심** | 교육 콘텐츠(레슨비디오), 마케팅 영상 제작 가능 |
| **음악 관심** | AI 응원봉 사업의 타겟 시장(콘서트/K-POP)에 대한 감각 |
| **자유로운 개성** | 창업가 마인드셋, 형식보다 실행 중시 |
| **졸업학기** | 청년창업 지원사업 자격 충족 (만 39세 이하) |

## 3. 협업 형태 비교

### 형태 A: 신규 법인 공동설립

```
이진서 (대표이사) ─── 신규 AI 스타트업 ─── UTTEC (기술제휴/지분참여)
                         │
                    청년창업 지원 수혜 가능
```

| 항목 | 내용 |
|------|------|
| 구조 | 이진서 대표의 신규 법인 + UTTEC 기술이전/지분참여 |
| 장점 | 청년창업사관학교, 예비창업패키지(최대 1억), 초기창업패키지(최대 1억) 등 지원 가능 |
| 장점 | 신규법인이므로 각종 세제혜택, 고용지원금 수혜 가능 |
| 장점 | 이진서 명의 대표로 청년 네트워크, 데모데이, 투자유치 접근 용이 |
| 단점 | 의사결정 구조 명확히 해야 함 (지분/역할 갈등 가능) |
| 단점 | 이진서의 경영 경험 부족 → 초기 학습비용 |
| 적합도 | ★★★★★ (가장 추천) |

### 형태 B: UTTEC 내부 사업부 운영

```
UTTEC ─── AI 신사업부 (이진서 사업부장)
```

| 항목 | 내용 |
|------|------|
| 구조 | UTTEC 소속으로 특정 사업라인 담당 |
| 장점 | 빠른 시작, 별도 법인설립 비용 없음 |
| 단점 | 국가지원 수혜 불가 (기존 법인) |
| 단점 | 이진서의 동기부여 약화 (오너십 부족) |
| 적합도 | ★★☆☆☆ |

### 형태 C: 프리랜서/파트너 계약

```
UTTEC ←── 업무위탁 계약 ──→ 이진서 (개인사업자)
```

| 항목 | 내용 |
|------|------|
| 구조 | 특정 프로젝트 단위 협업 |
| 장점 | 리스크 최소, 서로 부담 적음 |
| 단점 | 장기적 몰입 어려움, 국가지원 활용 제한 |
| 적합도 | ★★★☆☆ (초기 테스트용으로는 적합) |

### 추천: 형태 C → 형태 A 단계적 전환

> **1단계 (1~3개월)**: 프리랜서 계약으로 함께 일하며 서로의 업무방식 확인
> **2단계 (3~6개월)**: 시너지 확인 후 신규 법인 공동설립
> **3단계 (6개월~)**: 청년창업 지원사업 신청 및 본격 사업화

## 4. 우선 사업 추천

### 4.1 사업별 적합도 평가

| 초기 자금 부담 | ★★★☆☆ | ★★★★★ | ★★☆☆☆ |
| 시장 차별성 | ★★★★★ | ★★★☆☆ | ★★★☆☆ |

| **종합** | **24** | **23** | **14** |

### 4.2 1순위 추천: AI 응원봉 (AI FanStick)

**이진서와 가장 잘 맞는 이유:**

1. **음악 관심 + K-POP 시장 감각**
   - 콘서트 현장의 니즈를 체감할 수 있는 세대
   - 팬덤 문화에 대한 자연스러운 이해

2. **동영상 제작 역량**
   - 제품 홍보영상, SNS 콘텐츠, 크라우드펀딩 영상 직접 제작 가능
   - 이것만으로도 외주비 수백만원 절감

3. **기계공학 전공**
   - 양산 설계, 금형, 조립공정 이해
   - 하드웨어 제품의 제조 과정 기술적 소통 가능

4. **벤처경영 부전공**
   - 크라우드펀딩(와디즈/텀블벅) 기획
   - 투자유치 IR 준비

5. **활달한 성격**
   - 엔터테인먼트 업계 미팅, 기획사 영업에 적합
   - 데모데이 발표, 투자자 피칭에 강점

6. **청년창업 지원사업 스토리**
   - "서울대 기계공학도가 만드는 AI 스마트 응원봉"
   - 심사위원에게 강한 인상 (기술+시장+청년)
   - 블루오션 확인 완료 (경쟁 제품 없음)
   - 특허 출원 완료 → 기술력 증명

**실행 로드맵:**

| 시기 | 활동 | 담당 |
|------|------|------|
| 1개월차 | MVP 체험 + 시장 리서치 + 사업계획서 초안 | 이진서(주도) + UTTEC(기술지원) |
| 2개월차 | 와디즈 크라우드펀딩 기획 + 홍보영상 제작 | 이진서(영상/기획) + UTTEC(제품) |
| 3개월차 | 예비창업패키지 or 초기창업패키지 신청 | 이진서(대표) + UTTEC(기술멘토) |
| 4~6개월차 | 시제품 10~50개 소량생산 + 펀딩 런칭 | 공동 |
| 6~12개월차 | 엔터사 B2B 영업 + 양산 준비 | 이진서(영업) + UTTEC(양산) |

### 4.3 2순위 추천: AI 교육 (병행 가능)

**교육 사업을 병행 추천하는 이유:**

- 응원봉은 수익화까지 시간 필요 → 교육으로 **캐시플로우 확보**
- 이진서의 친교감 + 활달함 → **현장 강사로 적합**
- 서울대 졸업 → 교육 콘텐츠 **신뢰도 상승**
- 동영상 제작 → 교육 영상 콘텐츠 직접 제작

**역할 분담:**

| 역할 | UTTEC | 이진서 |
|------|-------|--------|
| 커리큘럼 설계 | ● (기존 자산) | ○ (피드백) |
| 현장 강의 | ○ (기술 심화) | ● (메인 강사) |
| 교육 영상 제작 | ○ (기술 내용) | ● (촬영/편집) |
| 수강생 관리 | ○ | ● (소통/관리) |
| 마케팅/SNS | ○ | ● |

## 9. 결론

이진서 학생은 UTTEC이 필요로 하는 **젊은 에너지, 마케팅 감각, 콘텐츠 역량, 국가지원 자격**을 모두 갖추고 있습니다.

**가장 추천하는 조합:**

> **AI 응원봉(메인) + AI 교육(캐시플로우)** 을 신규 법인으로 시작하되,
> 1~3개월 프리랜서 협업으로 상호 검증 후 법인설립

이진서의 **서울대 기계공학 + 벤처경영 + 콘텐츠 제작 + 활달한 성격**과
UTTEC의 **38년 임베디드 경력 + AI 교육 플랫폼 + 특허 + 양산 실적**이 만나면,

AI 시대에 **하드웨어 + 소프트웨어 + 콘텐츠**를 모두 아우르는
희소한 팀이 될 수 있습니다.
