왜 코드가 하나가 아닐까?

🍎 "과일" 비유로 이해하기

"과일"이라고만 하면 — 사과? 배? 포도? 알 수 없습니다.

마찬가지로 "폐렴"이라고만 하면 — 세균성? 바이러스성? 곰팡이성? 알 수 없습니다.
폐렴은 하나의 병이 아니라, 폐에 염증을 일으키는 여러 병의 총칭입니다.

일반인 vs 의사의 시각

👤 일반인의 시각

"폐렴이에요" → 끝. 하나의 병.

🩺 의사의 시각

"폐렴이에요" →
  ├─ 원인이 뭔가요? (세균? 바이러스? 곰팡이?)
  ├─ 어느 쪽 폐? (왼쪽? 오른쪽? 양쪽?)
  ├─ 폐의 어느 부분? (상엽? 중엽? 하엽?)
  ├─ 심각도는? (경증? 중등증? 중증?)
  ├─ 감염 경로? (지역사회? 병원 내?)
  └─ 환자 상태? (면역저하? 기저질환?)

코드가 여러 개인 이유 정리

이유설명예시
원인이 다르다원인균에 따라 치료법이 완전히 다름세균성 → 항생제 / 바이러스성 → 항바이러스제
위치가 다르다감염된 폐 부위에 따라 심각도 달라짐좌하엽 폐렴, 우상엽 폐렴
감염 경로가 다르다지역사회 vs 병원 내 감염은 원인균이 다름지역사회 획득, 병원 획득 폐렴
심각도가 다르다경증과 중증은 치료 방침이 다름경증 폐렴, 중증 폐렴
통계/연구 필요"올해 COVID-19 폐렴이 몇 건?" 통계COVID-19 폐렴만 따로 집계

IS-A 관계란?

📚 IS-A = "~의 한 종류이다"
  • "세균성 폐렴" IS-A "폐렴" → 세균성 폐렴은 폐렴의 한 종류이다 ✅
  • "폐렴" IS-A "폐 감염" → 폐렴은 폐 감염의 한 종류이다 ✅
  • 일상 비유: "골든 리트리버" IS-A "개" → 골든 리트리버는 개의 한 종류이다

정식 명칭(FSN) vs 선호 용어(PT)

구분설명예시
FSN
Fully Specified Name		괄호 안에 의미 분류가 포함된 공식 이름Pneumonia (disorder)
PT
Preferred Term		해당 언어에서 일상적으로 쓰는 이름한국: "폐렴" / 영어: "Pneumonia"
SYN
Synonym		추가 동의어"허파염", "Lung inflammation"
⚠️ FSN의 괄호가 중요한 이유

"Pneumonia"라는 단어가 여러 맥락에서 쓰일 수 있습니다:

  • Pneumonia (disorder) → 질환으로서의 폐렴
  • Pneumonia (finding) → 소견(발견)으로서의 폐렴
  • Pneumonia (organism) → 폐렴을 일으키는 균 이름

괄호 안의 구분이 있어야 정확히 어떤 의미인지 알 수 있습니다!

ICD-10 코드와의 관계

SNOMED CT와 ICD-10의 차이

📚 "병원에서 ICD-10을 쓰는데, SNOMED CT는 왜 또 필요하죠?"

ICD-10 = 보험 청구, 사망 통계 등을 위한 "분류" 체계 (큰 카테고리)

SNOMED CT = 진료 기록을 위한 "서술" 체계 (세밀한 구분)

비유: ICD-10 = 도서관의 "분류 번호" (문학, 과학, 역사...) / SNOMED CT = 책의 "ISBN 번호" (한 권 한 권 고유)

예시:

  • ICD-10: J13 "폐렴구균에 의한 폐렴" (위치, 심각도 정보 사라짐)

이것이 진료 기록에는 SNOMED CT를 쓰고, 보험 청구에만 ICD-10을 쓰는 이유입니다.

자주 묻는 질문 (FAQ)

Q1 폐렴 코드를 외워야 하나요? ▼
아닙니다. 실제 시스템에서는 "폐렴"이라고 검색하면 관련 코드 목록이 자동으로 나타납니다. 코드 번호를 암기할 필요는 전혀 없습니다. 중요한 것은 어떤 상황에서 어떤 수준의 코드를 선택해야 하는지 이해하는 것입니다.
Q2 233604007과 233607000 중 어떤 것을 써야 하나요? ▼
원인을 아느냐에 따라 다릅니다. 원인이 확인되지 않은 폐렴이면 233604007, 세균이 원인인 것이 확인되면 233607000을 씁니다. "확실하지 않으면 일반(상위) 코드"가 원칙입니다.
Q3 ICD-10 코드만 쓰면 안 되나요? ▼
ICD-10은 보험 청구에는 충분하지만, 진료 기록에는 부족합니다. "폐렴"의 위치, 심각도, 원인까지 기록하려면 SNOMED CT가 필요합니다. 또한 AI 시스템 간 데이터 교환에는 SNOMED CT가 국제 표준입니다.
Q4 한국에서도 SNOMED CT를 쓰나요? ▼
한국은 2020년에 SNOMED International에 가입했습니다. 아직 전면 도입 단계는 아니지만, 의료 AI 시스템과 국제 데이터 교환을 위해 점차 확대되고 있습니다. 현재는 주로 AI 의료기기와 연구 분야에서 사용 중입니다.
Q5 코드가 바뀌기도 하나요? ▼
SNOMED CT는 연 2회 업데이트됩니다. 새로운 질환이 추가되거나(예: COVID-19), 기존 코드가 비활성화될 수 있습니다. 다만, 한 번 부여된 코드 번호가 다른 의미로 재사용되지는 않습니다. 버전 관리를 통해 추적 가능합니다.

📌 폐렴의 SNOMED CT 코드 핵심 요약

    233604007 = "폐렴" = "Pneumonia" = "허파염" = "肺炎"
  5. 5 속성으로 정보 추가
    위치, 심각도, 원인 등을 코드로 함께 기록
  6. 6 가장 구체적인 코드를 사용하는 것이 원칙
    확실하지 않으면 상위(일반) 코드 사용
