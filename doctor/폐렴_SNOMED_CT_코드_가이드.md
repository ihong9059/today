## 1. 먼저 알아야 할 것: SNOMED CT란?

### 1.1 한 줄 요약

> **SNOMED CT = 전 세계 병원이 공통으로 사용하는 "의료 용어 사전 + 번호 체계"**

### 1.2 왜 필요한가?

병원마다, 나라마다 같은 병을 다르게 부릅니다. 이것이 문제가 됩니다.

```
[SNOMED CT가 없을 때 — 혼란]

  🇰🇷 한국 병원:  "폐렴"
  🇺🇸 미국 병원:  "Pneumonia"
  🇯🇵 일본 병원:  "肺炎"
  🤖 AI 시스템A: "lung_infection_type3"
  🤖 AI 시스템B: "pneumonia_detected"

  → 전부 같은 병인데, 컴퓨터는 이것이 같은 병인지 알 수 없음!
  → 병원 간 데이터 공유 불가능
```

```
[SNOMED CT가 있을 때 — 통일]

  🇰🇷 한국 병원:  233604007
  🇺🇸 미국 병원:  233604007
  🇯🇵 일본 병원:  233604007
  🤖 AI 시스템A: 233604007
  🤖 AI 시스템B: 233604007

  → 전부 같은 번호! 컴퓨터가 즉시 "같은 병"이라고 인식
  → 전 세계 어디서든 데이터 공유 가능
```

### 1.3 일상생활 비유

| 일상 | 의료 |
|------|------|
| 모든 상품에 **바코드**가 있다 | 모든 질환에 **SNOMED CT 코드**가 있다 |
| 바코드를 찍으면 상품 정보가 나온다 | 코드를 입력하면 질환 정보가 나온다 |
| 전 세계 어디서든 같은 바코드 = 같은 상품 | 전 세계 어디서든 같은 코드 = 같은 질환 |

## 3. 왜 코드가 하나가 아닐까?

### 3.1 폐렴이 하나가 아니기 때문

"폐렴"은 하나의 병이 아니라, **폐에 염증을 일으키는 여러 병의 총칭**입니다.

```
"폐렴"은 마치 "과일"과 같습니다:

  "과일"이라고만 하면 → 사과? 배? 포도? 알 수 없음

  마찬가지로:

  "폐렴"이라고만 하면 → 세균성? 바이러스성? 곰팡이성? 알 수 없음
```

### 3.2 의료 현장에서의 차이

```
[일반인의 시각]

  "폐렴이에요" → 끝. 하나의 병.


[의사의 시각]

  "폐렴이에요" →
    ├── 원인이 뭔가요? (세균? 바이러스? 곰팡이?)
    ├── 어느 쪽 폐인가요? (왼쪽? 오른쪽? 양쪽?)
    ├── 폐의 어느 부분인가요? (상엽? 중엽? 하엽?)
    ├── 심각도는? (경증? 중등증? 중증?)
    ├── 어떻게 감염되었나요? (지역사회? 병원 내?)
    └── 환자 상태는? (면역저하? 기저질환?)

  → 이 모든 경우를 구별해야 올바른 치료가 가능합니다.
  → 그래서 SNOMED CT도 이 모든 경우에 대해 별도 코드를 부여합니다.
```

### 3.3 코드가 여러 개인 이유 정리

| 이유 | 설명 | 예시 |
|------|------|------|
| **원인이 다르다** | 원인균에 따라 치료법이 완전히 다름 | 세균성 → 항생제, 바이러스성 → 항바이러스제 |
| **위치가 다르다** | 감염된 폐 부위에 따라 심각도 달라짐 | 좌하엽 폐렴, 우상엽 폐렴 |
| **감염 경로가 다르다** | 지역사회 감염 vs 병원 내 감염은 원인균이 다름 | 지역사회 획득 폐렴, 병원 획득 폐렴 |
| **심각도가 다르다** | 경증과 중증은 치료 방침이 다름 | 경증 폐렴, 중증 폐렴 |
| **통계/연구에 필요** | "올해 COVID-19 폐렴이 몇 건?" 같은 통계 | COVID-19 폐렴만 따로 집계 가능 |

## 4. 폐렴의 계층 구조

### 4.1 가족 관계처럼 이해하기

SNOMED CT에서 폐렴은 **가족 트리(족보)**처럼 구성되어 있습니다.

```
[폐렴의 가족 트리 — IS-A 관계]

"질환(Disease)"이라는 가장 큰 할아버지가 있고,
 그 아래로 점점 구체적인 자녀/손자가 있습니다.

                    질환 (Disease)
                        │
                    호흡기 질환
                   (Respiratory disorder)
                        │
                    하기도 질환
                   (Lower respiratory tract disorder)
                        │
                    폐 감염
                   (Pulmonary infection)
                        │
              ┌─────────┼─────────┐
              │         │         │
         ★ 폐렴 ★     폐결핵    폐농양
        (Pneumonia)  (Pulmonary TB)
        233604007    154283005
              │
     ┌────────┼────────┬──────────┐
     │        │        │          │
  세균성    바이러스성  곰팡이성   흡인성
  폐렴      폐렴       폐렴       폐렴
233607000  75570004   233611009  422588002
     │
     ├── 폐렴구균 폐렴 (폐렴구균이 원인)
     ├── 포도상구균 폐렴 (포도상구균이 원인)
     └── 클렙시엘라 폐렴 (클렙시엘라균이 원인)
```

### 4.2 IS-A 관계란?

```
"IS-A"는 "~의 한 종류이다"라는 뜻입니다.

예시:
  "세균성 폐렴" IS-A "폐렴"
   → 세균성 폐렴은 폐렴의 한 종류이다 ✅

  "폐렴" IS-A "폐 감염"
   → 폐렴은 폐 감염의 한 종류이다 ✅

  "폐 감염" IS-A "호흡기 질환"
   → 폐 감염은 호흡기 질환의 한 종류이다 ✅


일상 비유:
  "골든 리트리버" IS-A "개"    → 골든 리트리버는 개의 한 종류이다
  "개" IS-A "동물"            → 개는 동물의 한 종류이다
```

### 4.3 이 구조가 왜 중요한가?

```
[검색할 때 편리합니다]

  의사가 "폐렴 환자를 모두 찾아주세요"라고 하면:

  233604007 (폐렴) 아래의 모든 하위 코드를 자동으로 포함

  → 세균성 폐렴 환자 ✅ 포함
  → 바이러스성 폐렴 환자 ✅ 포함
  → COVID-19 폐렴 환자 ✅ 포함
  → 흡인성 폐렴 환자 ✅ 포함

  하나하나 찾을 필요 없이, 상위 코드 하나로 전부 검색 가능!
```

```
  의사 A: "폐렴" 이라고 입력  → 시스템이 233604007로 변환
  의사 B: "허파염" 이라고 입력 → 시스템이 233604007로 변환
  의사 C: "Pneumonia" 입력     → 시스템이 233604007로 변환

  → 어떤 단어로 입력하든 같은 코드가 됩니다!
  → 검색할 때도 어떤 단어로 찾든 같은 결과
```

### 6.3 정식 명칭(FSN) vs 선호 용어(PT)

| 구분 | 설명 | 예시 |
|------|------|------|
| **FSN** (Fully Specified Name) | 괄호 안에 의미 분류가 포함된 공식 이름. 코드를 정확히 식별하기 위한 용도 | Pneumonia **(disorder)** |
| **PT** (Preferred Term) | 해당 언어에서 일상적으로 쓰는 이름 | 한국: "폐렴", 영어: "Pneumonia" |
| **SYN** (Synonym) | 추가 동의어 | "허파염", "Lung inflammation" |

```
FSN의 괄호가 중요한 이유:

  "Pneumonia" 라는 단어가 여러 맥락에서 쓰일 수 있음

  • Pneumonia (disorder)   → 질환으로서의 폐렴
  • Pneumonia (finding)    → 소견(발견)으로서의 폐렴
  • Pneumonia (organism)   → 폐렴을 일으키는 균 이름

  괄호 안의 구분이 있어야 정확히 어떤 의미인지 알 수 있음!
```

## 7. 폐렴 코드에 붙는 추가 정보

### 7.1 속성(Attribute)이란?

코드 하나만으로는 정보가 부족할 때, **추가 정보를 속성으로 붙입니다.**

```
비유: 택배 송장

  택배 상자 = 233604007 (폐렴)

  여기에 붙이는 추가 스티커들:
  ┌──────────────────────────────────┐
  │ 📍 위치:     왼쪽 아래 폐        │ ← FINDING-SITE
  │ 🔬 형태:     염증                │ ← ASSOCIATED-MORPHOLOGY
  │ 🦠 원인:     폐렴구균            │ ← CAUSATIVE-AGENT
  │ ⚠️ 심각도:  중증                 │ ← SEVERITY
  │ ↔️ 좌우:    왼쪽                 │ ← LATERALITY
  └──────────────────────────────────┘
```

### 7.2 폐렴에 사용되는 주요 속성

| 속성 이름 | 의미 | 예시 코드 | 예시 값 |
|----------|------|----------|--------|
| **FINDING-SITE** | 어디에 발생했는가 | 41224006 | 왼쪽 폐 하엽 (Lower lobe of left lung) |
| **ASSOCIATED-MORPHOLOGY** | 어떤 형태 변화인가 | 23583003 | 염증 (Inflammation) |
| **CAUSATIVE-AGENT** | 원인이 무엇인가 | 9861002 | 폐렴구균 (Streptococcus pneumoniae) |
| **SEVERITY** | 얼마나 심한가 | 24484000 | 중증 (Severe) |
| **LATERALITY** | 좌우 어느 쪽인가 | 7771000 | 왼쪽 (Left) |

### 7.3 속성 조합 예시

```
예시: "왼쪽 아래 폐의 중증 세균성 폐렴"

이것을 SNOMED CT로 표현하면:

  233604007 | Pneumonia (폐렴)
    ├── FINDING-SITE = 41224006 | Lower lobe of left lung
    │                             (왼쪽 폐 하엽)
    ├── SEVERITY = 24484000 | Severe
    │                         (중증)
    ├── CAUSATIVE-AGENT = (세균 코드)
    │                       (원인: 세균)
    └── ASSOCIATED-MORPHOLOGY = 23583003 | Inflammation
                                          (염증)
```

```
예시: "오른쪽 위 폐의 경증 바이러스성 폐렴"

  75570004 | Viral pneumonia (바이러스성 폐렴)
    ├── FINDING-SITE = 45653009 | Upper lobe of right lung
    │                             (오른쪽 폐 상엽)
    └── SEVERITY = 255604002 | Mild
                               (경증)
```

### 7.4 속성이 중요한 이유

```
[속성이 없을 때]

  "폐렴입니다"
  → 어디? 얼마나 심해? 원인은? → 알 수 없음


[속성이 있을 때]

  "233604007 + FINDING-SITE:41224006 + SEVERITY:24484000"
  → 왼쪽 아래 폐 + 중증 → 즉시 이해 가능
  → 다른 병원에서도, 다른 나라에서도 정확히 같은 의미
```

## 9. ICD-10 코드와의 관계

### 9.1 SNOMED CT와 ICD-10의 차이

```
흔한 질문: "병원에서 ICD-10 코드를 쓰는데, SNOMED CT는 왜 또 필요하죠?"

  ICD-10  = 보험 청구, 사망 통계 등을 위한 "분류" 체계 (큰 카테고리)
  SNOMED CT = 진료 기록을 위한 "서술" 체계 (세밀한 구분)

  비유:
  ICD-10  = 도서관의 "분류 번호" (문학, 과학, 역사...)
  SNOMED CT = 책의 "ISBN 번호" (한 권 한 권 고유)
```

| 비교 항목 | SNOMED CT | ICD-10 |
|----------|-----------|--------|
| **목적** | 진료 기록의 정밀한 코딩 | 보험 청구, 질병 통계 |
| **규모** | 35만+ 개념 | ~7만 코드 |
| **폐렴 코드 수** | 수십~수백 개 | 약 20개 |
| **정밀도** | 매우 높음 (원인, 위치, 심각도 포함) | 중간 (큰 카테고리) |
| **사용 장면** | AI 진단, 전자건강기록, 연구 | 보험 청구서, 사망진단서 |

### 9.2 폐렴의 SNOMED CT → ICD-10 매핑

| SNOMED CT Code | SNOMED CT 명칭 | → | ICD-10 Code | ICD-10 명칭 |
|:-:|---|:-:|:-:|---|
| 233604007 | Pneumonia | → | **J18.9** | 폐렴, 상세불명 |
| 233607000 | Bacterial pneumonia | → | **J15.9** | 세균성 폐렴, 상세불명 |
| 75570004 | Viral pneumonia | → | **J12.9** | 바이러스성 폐렴, 상세불명 |
| 840539006 | COVID-19 | → | **U07.1** | COVID-19, 바이러스 확인 |
| 385093006 | Community-acquired pneumonia | → | **J18.9** | 폐렴, 상세불명 |
| 422588002 | Aspiration pneumonia | → | **J69.0** | 흡인성 폐렴 |
| 278516003 | Lobar pneumonia | → | **J18.1** | 대엽성 폐렴, 상세불명 |

### 9.3 매핑 시 주의점

```
⚠️ SNOMED CT → ICD-10 변환 시 정보가 손실될 수 있습니다!

예시:
  SNOMED CT: "왼쪽 하엽의 중증 폐렴구균 폐렴" (매우 자세함)
       ↓ 변환
  ICD-10:    J13 "폐렴구균에 의한 폐렴" (위치, 심각도 정보 사라짐)

  → SNOMED CT가 훨씬 상세하기 때문에,
    ICD-10으로 변환하면 일부 정보가 빠질 수 있습니다.
  → 이것이 진료 기록에는 SNOMED CT를 쓰고,
    보험 청구에만 ICD-10을 쓰는 이유입니다.
```

## 11. 자주 묻는 질문

### Q1. 폐렴 코드를 외워야 하나요?

> **아닙니다.** 실제 시스템에서는 "폐렴"이라고 검색하면 관련 코드 목록이 자동으로 나타납니다. 코드 번호를 암기할 필요는 전혀 없습니다. 중요한 것은 **어떤 상황에서 어떤 수준의 코드를 선택해야 하는지** 이해하는 것입니다.

### Q2. 233604007과 233607000 중 어떤 것을 써야 하나요?

> **원인을 아느냐에 따라 다릅니다.** 원인이 확인되지 않은 폐렴이면 233604007, 세균이 원인인 것이 확인되면 233607000을 씁니다. **"확실하지 않으면 일반(상위) 코드"**가 원칙입니다.

### Q3. ICD-10 코드만 쓰면 안 되나요?

> ICD-10은 보험 청구에는 충분하지만, **진료 기록에는 부족**합니다. "폐렴"의 위치, 심각도, 원인까지 기록하려면 SNOMED CT가 필요합니다. 또한 AI 시스템 간 데이터 교환에는 SNOMED CT가 국제 표준입니다.

### Q4. 한국에서도 SNOMED CT를 쓰나요?

> 한국은 **2020년에 SNOMED International에 가입**했습니다. 아직 전면 도입 단계는 아니지만, 의료 AI 시스템과 국제 데이터 교환을 위해 점차 확대되고 있습니다. 현재는 주로 AI 의료기기와 연구 분야에서 사용 중입니다.

### Q5. 코드가 바뀌기도 하나요?

> SNOMED CT는 **연 2회 업데이트**됩니다. 새로운 질환이 추가되거나(예: COVID-19), 기존 코드가 비활성화될 수 있습니다. 다만, 한 번 부여된 코드 번호가 다른 의미로 **재사용되지는 않습니다.** 버전 관리를 통해 추적 가능합니다.
