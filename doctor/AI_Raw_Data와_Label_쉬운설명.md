# AI의 기초: Raw Data와 Label 쉽게 이해하기

---

## 한 줄 요약

> AI를 가르치려면 **문제(Raw Data)**와 **정답(Label)**이 필요합니다.

---

## 1. Raw Data란?

**Raw Data(원시 데이터)**는 AI에게 보여주는 **가공되지 않은 원본 자료**입니다.

우리 주변의 거의 모든 것이 Raw Data가 될 수 있습니다:

| 종류 | 예시 |
|------|------|
| 사진 | 길거리에서 찍은 자동차 사진 |
| 소리 | 사람이 말하는 음성 녹음 |
| 글 | 인터넷에 올라온 상품 후기 |
| 숫자 | 온도센서가 측정한 온도 값 |
| 영상 | CCTV에 녹화된 동영상 |

### 비유: 시험 문제지

Raw Data는 **시험의 문제지**와 같습니다.

```
문제: 다음 사진 속 동물은 무엇일까요?

    ┌─────────────┐
    │             │
    │   🐱 사진   │  ← 이것이 Raw Data
    │             │
    └─────────────┘
```

문제지만 있으면 학생(AI)은 공부할 수 없습니다. **정답지**가 필요하죠.

---

## 2. Label이란?

**Label(라벨)**은 Raw Data에 사람이 붙여주는 **정답 태그**입니다.

"이 사진은 고양이야", "이 음성은 '안녕하세요'라고 말하는 거야" 처럼 **사람이 직접 알려주는 답**입니다.

### 비유: 시험 정답지

```
문제(Raw Data)          정답(Label)
─────────────          ──────────
🐱 사진        →       "고양이"
🐶 사진        →       "개"
🚗 사진        →       "자동차"
```

---

## 3. AI는 이걸로 어떻게 배우나요?

사람이 공부하는 방식과 똑같습니다:

### 사람의 공부
```
1. 문제를 본다        →  "이 사진 속 동물은?"
2. 정답을 확인한다    →  "고양이였구나"
3. 수백 번 반복한다   →  "이런 특징이면 고양이!"
4. 새 문제를 맞힌다   →  처음 보는 고양이 사진도 맞춤
```

### AI의 학습
```
1. Raw Data를 입력    →  고양이 사진을 넣음
2. Label과 비교       →  "고양이"라는 정답과 비교
3. 수만 번 반복       →  패턴을 스스로 발견
4. 새 데이터에 적용   →  처음 보는 사진도 "고양이"라고 맞춤
```

### 그림으로 보기

```
   학습 단계 (Training)
   ════════════════════

   ┌──────────┐        ┌────────┐
   │ 🐱 사진  │───────→│        │
   │(Raw Data)│        │        │
   └──────────┘        │  AI    │
                       │  모델  │──→ "고양이" (예측)
   ┌──────────┐        │        │        │
   │ "고양이"  │───────→│        │        │
   │ (Label)  │        └────────┘        │
   └──────────┘                          │
                                         ▼
                               정답과 비교해서
                               틀리면 수정하고
                               다시 반복!


   사용 단계 (Inference)
   ════════════════════

   ┌──────────┐        ┌────────┐
   │ 🐱 새사진│───────→│ 학습된 │──→ "고양이!" ✅
   │(처음 봄) │        │ AI모델 │
   └──────────┘        └────────┘
                       (Label 없이도 맞춤)
```

## 4. 라벨링의 종류

데이터에 정답을 붙이는 방식은 여러 가지가 있습니다:

### 4-1. 분류 (Classification)
> "이것은 무엇인가요?"

```
사진 → "고양이"
사진 → "개"
리뷰 → "긍정" 또는 "부정"
```

가장 기본적인 형태. 전체 데이터에 카테고리 하나를 붙입니다.

### 4-2. 위치 표시 (Object Detection)
> "어디에 무엇이 있나요?"

```
┌────────────────────────┐
│         사진            │
│   ┌─────────┐          │
│   │  고양이  │ ← 사각형 │
│   │         │   으로    │
│   └─────────┘   표시    │
│          ┌──────┐      │
│          │  컵  │      │
│          └──────┘      │
└────────────────────────┘
```

사진 속에서 물체의 **위치(바운딩 박스)**와 **이름**을 함께 라벨링합니다.

### 4-3. 영역 칠하기 (Segmentation)
> "정확히 어느 부분이 무엇인가요?"

```
┌────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░ │  ░ = 배경
│ ░░░░████████░░░░░░░░░░ │  █ = 고양이
│ ░░░████████████░░░░░░░ │
│ ░░░░████████████░░░░░░ │  (픽셀 단위로
│ ░░░░░░████████░░░░░░░░ │   정밀하게 표시)
│ ░░░░░░░░░░░░░░░░░░░░░░ │
└────────────────────────┘
```

의료 영상(CT, X-ray)에서 종양 영역을 표시할 때 많이 사용합니다.

### 4-4. 수치 예측 (Regression)
> "얼마인가요?"

```
집 사진 → "3억 5천만 원"
환자 데이터 → "혈당 수치 120"
```

카테고리가 아니라 **연속적인 숫자 값**을 라벨로 붙입니다.

## 5. 라벨이 없으면 어떻게 하나요?

라벨이 항상 필요한 것은 아닙니다. AI 학습 방식에 따라 다릅니다:

| 학습 방식 | 라벨 필요? | 쉬운 설명 |
|----------|----------|----------|
| **지도학습** | ⭕ 필요 | 선생님이 정답을 알려주며 가르침 |
| **비지도학습** | ❌ 불필요 | 학생이 스스로 비슷한 것끼리 분류 |
| **자기지도학습** | ❌ 불필요 | 문장의 빈칸을 스스로 채우며 학습 (ChatGPT 방식) |
| **반지도학습** | 🔺 조금만 | 소수의 정답 + 대량의 무정답 데이터 활용 |

### 비유로 이해하기

```
지도학습:     선생님이 "이건 고양이야" 하나하나 알려줌
비지도학습:   아이가 동물원에서 "이것들은 비슷하게 생겼네!" 스스로 발견
자기지도학습: "고양이는 ___를 좋아한다" 빈칸 채우기를 수만 번 반복
```

## 6. 실생활 예시

### 예시 1: 스팸 메일 필터

```
Raw Data (이메일 내용)              Label
───────────────────              ──────
"축하합니다! 1억 당첨!"          → 스팸
"내일 회의 10시에 합시다"         → 정상
"지금 바로 클릭하세요!!!"        → 스팸
"프로젝트 진행상황 공유합니다"     → 정상
```

이렇게 수만 건의 이메일에 "스팸/정상" 라벨을 붙여 학습시키면, 새 이메일이 와도 자동으로 스팸을 걸러냅니다.

### 예시 2: 번호판 인식 (LPR)

```
Raw Data (차량 사진)               Label
────────────────               ───────
📷 차량 사진 1                  → "12가 3456"
📷 차량 사진 2                  → "서울 78나 9012"
📷 차량 사진 3                  → "34다 5678"
```

### 예시 3: 음성 인식

```
Raw Data (음성 파일)               Label
────────────────               ──────
🔊 음성 1                      → "오늘 날씨 어때?"
🔊 음성 2                      → "알람 7시에 맞춰줘"
🔊 음성 3                      → "노래 틀어줘"
```

## 7. 왜 라벨링이 그렇게 중요한가?

### "쓰레기를 넣으면 쓰레기가 나온다" (Garbage In, Garbage Out)

```
❌ 잘못된 라벨:
   🐱 사진 → "개" (오답)
   → AI가 고양이를 보고 "개"라고 학습
   → 틀린 AI 완성!

✅ 올바른 라벨:
   🐱 사진 → "고양이" (정답)
   → AI가 올바르게 학습
   → 정확한 AI 완성!
```

### 라벨링의 현실

- AI 성능의 **70~80%는 데이터와 라벨의 품질**이 결정합니다
- 좋은 AI 모델을 만드는 것보다 **좋은 데이터를 모으는 것이 더 어렵습니다**
- 라벨링은 **사람이 직접** 해야 하므로 비용과 시간이 많이 듭니다
- 이 라벨링 작업을 전문적으로 해주는 회사가 있을 정도입니다 (예: Scale AI — 기업 가치 약 19조 원)

## 8. 한 눈에 정리

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   Raw Data (문제)  +  Label (정답)  =  학습 데이터    │
│                                                     │
│          │                │                         │
│          ▼                ▼                         │
│   ┌─────────────────────────────┐                   │
│   │       AI 모델 학습           │                   │
│   │   (수만~수억 번 반복)        │                   │
│   └──────────────┬──────────────┘                   │
│                  ▼                                  │
│   ┌─────────────────────────────┐                   │
│   │     학습 완료된 AI 모델      │                   │
│   │  새로운 데이터 → 자동 예측   │                   │
│   └─────────────────────────────┘                   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

| 용어 | 한 줄 설명 |
|------|----------|
| **Raw Data** | AI에게 보여주는 원본 자료 (사진, 음성, 텍스트 등) |
| **Label** | 사람이 Raw Data에 붙인 정답 태그 |
| **라벨링** | Raw Data에 Label을 붙이는 작업 |
| **학습(Training)** | Raw Data + Label로 AI를 가르치는 과정 |
| **추론(Inference)** | 학습된 AI가 새 데이터를 보고 답을 예측하는 것 |
