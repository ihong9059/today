# 당신이 몰랐던 팔란티어! 이 영상 하나로 끝!

## 영상 정보
- **채널:** 와이스트릿 - 지식과 자산의 복리효과
- **연사:** 변우철 본부장 (KT 팔란티어 사업 담당, 前 두산 인프라코어/DL ENC 팔란티어 도입 담당)
- **재생시간:** 1:03:04
- **링크:** [YouTube 영상 보기](https://www.youtube.com/watch?v=P0Mpab4ly_U)
- **저서:** 『팔란티어 시대가 온다』

## 전체 요약

### 핵심 주제
팔란티어(Palantir)의 본질, 온톨로지 개념, 도입 사례, 국방/상업 분야 활용, 경쟁력, 그리고 한국 기업 도입 시 성공 조건을 실무자 관점에서 심층 분석한다.

### 핵심 내용
- **팔란티어의 본질은 "문제 해결"**: 기존 IT 솔루션 벤더가 예산/RFP를 묻는 것과 달리, 팔란티어 엔지니어는 "당신 회사의 가장 큰 문제가 뭐냐?"부터 묻는다
- **온톨로지(Ontology)**: 실제 비즈니스 프로세스를 가상 공간에 데이터, 로직, 액션 3가지 요소로 재현한 것. 팔란티어만의 고유한 컨셉으로 경쟁사에는 없다
- **데이터 민주화**: 사장부터 사원까지 같은 데이터를 보고 의사결정하는 것이 핵심 가치
- **컨설팅과의 차이**: 컨설팅은 PPT를 남기지만, 팔란티어는 실제 돌아가는 시스템을 남긴다
- **국방에서 상업으로**: 911 테러 이후 피터 틸이 창업, 고담(국방용) → 파운드리(상업용) → 아폴로(운영체제)로 제품 확장
- **한국 도입 기업**: 삼성전자, 삼성 ENA, KT, HD 현대 인프라코어, DL ENC 등
- **도입 성공 조건 3가지**: (1) CEO/의사결정권자의 직접 참여, (2) IT 프로젝트가 아닌 전사 디지털 혁신 프로젝트로 접근, (3) 내재화 전략 수립

## 구간별 요약

### 1. 도입 - 왜 팔란티어인가? [0:00-5:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=0s)
변우철 본부장 소개. 팔란티어의 본질은 "고객의 문제 해결"이며, 일반 IT 벤더와 달리 예산이 아닌 문제부터 묻는다. 2019년부터 팔란티어 엔지니어를 만나며 이 차이를 체감했다.

### 2. 컨설팅 vs 팔란티어 [5:00-8:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=300s)
전략 컨설팅(맥킨지, BCG)은 PPT를 남기고 떠나지만, 팔란티어는 실제 데이터를 연결한 시스템을 남긴다. 고객 문제에 맞춰 솔루션이 변형되므로, 각 고객이 팔란티어를 다르게 인식한다.

### 3. 두산 인프라코어 도입 사례 [5:48-9:30](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=348s)
각 부서별 독립된 시스템들을 팔란티어로 통합. CEO가 "팔란티어로 사장단 회의를 하겠다"고 선언. 데이터 민주화를 통해 사장부터 사원까지 같은 데이터를 보는 환경 구축.

### 4. 온톨로지 개념 설명 [9:53-18:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=593s)
팔란티어 이해의 핵심 개념. 실제 비즈니스를 데이터/로직/액션 3요소로 가상 공간에 재현한 것. 산재된 데이터를 의미론적으로 연결하여 의사결정 가능하게 만드는 것이 팔란티어 온톨로지의 본질.

### 5. 팔란티어 창업 스토리와 제품 구조 [10:20-15:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=620s)
911 테러 → 피터 틸의 결심 → 2003년 알렉스 카프와 공동 창업. 고담(국방), 파운드리(상업), 아폴로(운영) 3개 제품. 팔란티어는 설치가 아닌 문제 해결이 목적이며, FD(Forward Deployed) 엔지니어를 고객사에 파견.

### 6. 골든 돔과 국방 활용 [20:33-24:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=1233s)
트럼프의 골든 돔 프로젝트(우주 공간 미사일 요격). 40년 전 불가능했던 것이 팔란티어 때문에 가능해졌다는 평가. 알렉스 카프 曰 "하드웨어는 소프트웨어의 액세서리가 될 것."

### 7. 팔란티어 엔지니어의 3가지 질문 [26:43-31:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=1603s)
What decision(어떤 의사결정을 하려는가), What data(어떤 데이터가 필요한가), What action(어떤 실행을 할 것인가). 문제 정의에 따라 본질이 바뀌며, 데이터 기반 문제 정의가 가장 중요.

### 8. 재무 성과와 ROI [33:17-37:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=1997s)
Rule of 40이 94를 기록. BP 사례: 생산성 40조 향상, 1억 투자로 2조 영업이익 창출 가능. 관계 기반/네트워크 기반 영업이 팔란티어 도입의 핵심.

### 9. 보안과 데이터 주권 [39:00-42:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=2340s)
팔란티어는 보안으로 시작한 회사. AWS, Azure, 팔란티어 자체도 고객 데이터에 접근 불가. 종속 우려에 대해: 젤렌스키의 스타링크 사례를 통한 논의.

### 10. 투자 관점과 밸류에이션 [49:00-50:30](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=2940s)
변우철 본부장은 팔란티어 주식을 한 주도 보유하지 않아 객관적 관점 유지. PER가 높다는 우려 인정하면서도, 폐쇄적 문화와 신비주의로 뭉친 팔란티어가 앞으로도 잘할 것이라 전망.

### 11. 도입 성공/실패 조건 [50:30-57:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=3030s)
IT 프로젝트로 접근하면 실패 확률 높음. 전사 디지털 혁신 프로젝트로 이해해야 함. CEO급 의사결정권자의 직접 참여가 필수. 기존 IT 조직과의 마찰 관리, 내재화 전략이 3대 성공 조건.

### 12. 현장 에피소드와 마무리 [57:00-1:03:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=3420s)
