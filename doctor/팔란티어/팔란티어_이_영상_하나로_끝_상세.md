### 1구간: 오프닝 & 왜 팔란티어인가 [0:00-5:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=0s)

**핵심 메시지:** 팔란티어를 아는 사람은 회사 직원보다 더 잘 알고, 모르는 사람은 전혀 모른다. 이 간극을 메우는 것이 이 영상의 목적.

**상세 내용:**
- 와이스트릿에서 처음으로 팔란티어 콘텐츠를 다루게 됨
- 변우철 본부장은 팔란티어를 좋아하는 분들 사이에서 "구루" 존재로 평가받는 인물
- 최근 『팔란티어 시대가 온다』라는 책을 출간
- 팔란티어를 아는 사람들은 "거의 우리 사주 있는 사람들 같다"는 표현 — 그만큼 열정적 팬층 보유
- 반면 모르는 사람들은 "도대체 팔란티어가 뭐야? 온톨로지 뭐야?" 수준

**주요 발언:**
- "팔란티어는 본질은 문제 해결에 있다고 볼 수 있습니다."
- "2019년부터 팔란티어 엔지니어를 처음 만났거든요. 근데 첫 마디가 보통 IT 솔루션 벤더의 사람들과 달랐어요."
- "예산이 어떻게 되시나요? 언제 RFP를 내실 건가요? 이런 질문은 하나도 없고, '당신의 회사에 가장 큰 문제가 뭐냐?'라고 묻더라고요."

### 2구간: 컨설팅 vs 팔란티어 — 문제 해결 방식의 차이 [5:00-8:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=300s)

**핵심 메시지:** 전략 컨설팅은 해결책을 PPT로 제시하고 떠나지만, 팔란티어는 실제 데이터 기반 시스템을 구축하여 문제를 해결한다.

**상세 내용:**
- 문제 해결하면 떠오르는 조직 = 전략 컨설팅(맥킨지, BCG 등)
- 컨설팅의 한계: 수백 페이지 PPT를 전달하며 "아름다운 해결책을 만들었으니 실행하세요"라고 하지만, 실행률은 10개 중 1~2개
- 팔란티어의 차이점: Day Zero부터 실제 고객 데이터를 연결하여 시스템을 구축
- 약 3개월짜리 PoC(Proof of Concept) 후 실제 데이터 기반 시스템이 남음
- 문제 해결의 실현 가능성(feasibility)이 확실히 높음
- 고객 문제가 무엇이냐에 따라 팔란티어를 다르게 인식:
  - A회사: "대시보드 만드는 회사"
  - B회사: "AI 플랫폼"
  - C회사: "고객 관리 시스템"
  - D회사: "글로벌 통합 운영 시스템"

**주요 발언:**
- "팔란티어라는 솔루션이 고객의 문제에 맞춰서 변경이 되기 때문에 그렇습니다."
- "실제 데이터를 가지고 시스템이 남는 거니까 PPT가 아니잖아요."

### 3구간: 두산 인프라코어 도입 사례 [5:48-9:30](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=348s)

**핵심 메시지:** 각 부서별 독립 시스템을 팔란티어로 통합하고, CEO 주도로 데이터 기반 의사결정 체계를 구축한 실사례.

**상세 내용:**
- 두산 인프라코어(현 HD 현대 인프라코어)는 이미 많은 IT 솔루션이 있었으나, 각각 독립적으로 운영(사일로)
- 영업 시스템, SCM 시스템, R&D 시스템 등이 유기적이지 않게 운영
- 팔란티어를 통해 각각 독립된 시스템들을 통합하고 데이터 기반 의사결정 환경 구축
- CEO가 "팔란티어로 앞으로 사장단 회의를 하겠다"고 선언
- 첫 번째로 만든 것: 제품 개발 의사결정을 위한 솔루션
- 프로젝트명: 처음에 D스퀘어 → 나중에 DI360 (두산 인프라코어의 360도를 같이 보고 소통하자)
- 제품 개발 시 타겟 코스트 100불인데 110불이 나온 경우 → 10불 갭을 누가 책임지나?
- 과거: 각 부서가 데이터를 따로 만들어 보고하니 진실된 숫자를 알 수 없었음
- 모든 부서가 "문제 없다"고 주장 → 시스템 데이터로 회의하니 객관적 판단 가능
- 사장님부터 사원까지 같은 데이터를 봄 = "데이터 민주화"
- 대시보드에 "팔란티어"라고 쓰여있지 않음 — 고객사 브랜딩으로 운영

**사례:**
- 두산 인프라코어: 제품 개발 원가 관리 통합 대시보드
- KT: 외부 사업 확장 (현재 진행 중)
- 삼성전자, 삼성 ENA: 팔란티어 파운드리 사용 중

- 3가지 구성 요소:
  1. **데이터 (시멘틱 레이어)**: 원천 데이터 연결 및 의미론적 관계 정의
  2. **로직 (다이나믹 레이어)**: 비즈니스 규칙과 연산

- 팔란티어 온톨로지에서 이 데이터들을 의사결정 가능한 형태로 연결/조합
- 온톨로지 구축 후: 사장님이 말단까지의 모든 데이터를 통해서 관장 가능
- 다만 권한 관리는 별도로 제어됨

**사례:**
- 빌딩 속 양복 비유: 데이터가 있어도 연결(온톨로지)이 없으면 찾을 수 없다
- 와이스트릿 비유: 좋은 콘텐츠는 많지만 통합이 안 되어 의사결정이 힘든 상황

### 7구간: 팔란티어 엔지니어의 3가지 질문 & 모듈러 주택 비유 [26:43-31:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=1603s)

**핵심 메시지:** 팔란티어는 맞춤 설계가 아닌 모듈 조합 방식이며, 3가지 핵심 질문으로 문제를 정의한다.

**상세 내용:**
- **팔란티어 엔지니어의 3가지 질문:**
  1. What decision — 어떤 의사결정을 하려 하는가?
  2. What data — 그 결정에 어떤 데이터가 필요한가?
  3. What action — 결정 후 어떤 실행을 할 것인가?
- **모듈러 주택 비유:**
  - 전통 건축: 통창으로 호수가 보이는 맞춤 집 → 6개월 소요
  - 모듈러 주택(팔란티어): 주방 한 칸, 방 한 칸 등 기성 모듈 조합 → 빠르게 지을 수 있음
  - 단점: 통창이 아닌 분리된 창문 → "조망이 가려서 별로야" 가능
  - 장점: 빠른 구축, 이미 검증된 앱들의 조합
- 실제 프로젝트 하나 도입하면 최소 6개월 소요
- 181일째에 와봤는데 아직 변화가 느껴지지 않는 케이스 존재
- 문제 정의에 따라 본질이 바뀌므로, 데이터 기반 문제 정의 능력이 핵심

**주요 발언:**
- "문제 정의를 데이터 기반으로 해 본 적이 없어요. 그러다 보니까 잘 못 합니다."

### 8구간: 재무 성과, Rule of 40, BP 사례 [33:17-37:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=1997s)

**핵심 메시지:** 팔란티어는 Rule of 40에서 94를 기록하며 폭발적 성장 중이며, BP 사례는 ROI의 극단적 효율성을 보여준다.

**상세 내용:**
- **Rule of 40**: 성장률 + 영업이익률의 합이 40 이상이면 우수 소프트웨어 기업
  - 팔란티어: 2023년 3Q부터 40 돌파, 2024년 2Q 기준 94 기록
  - 성장률 ~20% + 영업이익률 ~20% → 현재는 더 높은 수준
  - 영업이익이 매우 높다 = 돈을 매우 잘 벌고 있다
- **BP(영국 석유) 사례:**
  - BP 글로벌 매출: 약 4천억 원 규모
  - 팔란티어 도입 후 생산성 10% 향상 → 40조 원의 생산성 증가
  - 도입 비용 약 1천억 원 투자 → 영업이익률 5% 적용 시 2조 원 추가 이익
  - ROI가 극도로 높은 구조
- 팔란티어 도입 시 가장 힘든 점: 관계 기반/네트워크 기반의 영업이 필요
- 단순 투자 금액만 보면 큰 돈이지만, 회사 규모 대비 ROI로 보면 압도적

### 9구간: 도입 현황, 실패 사례, 구독 모델 [38:46-42:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=2326s)

**핵심 메시지:** 한국에서 팔란티어를 도입 후 버린 케이스는 아직 없으며, 서브스크립션 모델로 고객 이탈률이 매우 낮다.

**상세 내용:**
- 변우철 본부장: 두산 인프라코어, DL ENC에서 2번의 대기업 팔란티어 도입 경험, 현재 KT에서 3번째 도전
- 한국에서 팔란티어를 도입 후 버린 케이스는 없음
- 모든 도입 기업이 더 디벨롭하기 위해 노력 중
- **비용 구조**: 서브스크립션(구독) 모델 — 유튜브 구독처럼 매년 구독료 지불
- 끊으면 못 쓰는 구조 → 자연스러운 고객 락인(Lock-in)
- 이를 긍정적으로 보면 "지속적 가치 제공", 부정적으로 보면 "종속"

**보안 관련:**
- 팔란티어는 보안으로 시작한 회사

### 12구간: 도입 성공 조건 3가지 & 현장 에피소드 [53:00-1:03:00](https://www.youtube.com/watch?v=P0Mpab4ly_U&t=3180s)

**핵심 메시지:** IT 프로젝트가 아닌 전사 디지털 혁신으로 접근해야 하며, CEO급 참여와 내재화 전략이 필수.

**상세 내용:**

**성공 조건 3가지:**
1. **CEO/의사결정권자의 직접 참여 (인게이지먼트)**
   - IT 부서에 맡기고 "예산만 결정해 줄게" 식이면 실패 확률 급증
   - CEO가 됐든, 그에 준하는 역할을 할 수 있는 사람이 직접 참여해야 조직 간 조정 가능
2. **전사 디지털 혁신 프로젝트로 접근**
   - IT 투자 프로세스를 태우면 팔란티어 프로젝트가 죽음
   - SCM 솔루션, 고객 관리 솔루션 같은 포인트 솔루션 관점으로 보면 실패 확률 높음
   - 전사적 데이터를 다 열어 놓고 해야 하므로 특정 부서가 불편할 수 있음
3. **내재화 전략 수립**
   - 외부 엔지니어 의존을 줄이고 자체 역량을 키우는 전략 필요
   - 구독 모델이므로 지속적 비용 발생 → 내부 역량이 없으면 영원히 종속

**현장 에피소드:**
- 실제 프로젝트 미팅에서 30분 넘어갈 때 "지금 하는 질문이 해결해야 할 문제와 어떤 연관이 있지?" 하는 생각이 듦
- 회의를 멈추고 "이 질문과 본질적 문제가 연관이 있느냐?" 물었더니 흐지부지됨
- 두 가지를 항상 되물어야 함:
  - 이 질문이 해결해야 할 문제와 본질적 연관이 있는가?
  - 이 질문을 해결하면 그 본질적 문제가 해결되는가?
- 기존 IT 개발자들의 저항: "우리도 잘하는데 영어 쓰는 사람들 와서 뭐 한다고" — 현실적으로 비슷한 상황 많음
- 팔란티어라는 "무엇이든 할 수 있는 솔루션"이라는 프레임을 넘어서, 구체적 문제에 집중해야 함

**마무리 발언:**
- "팔란티어 시대가 이미 왔고, 앞으로 더 올 겁니다."
- "엔비디아, 테슬라를 뛰어넘는 AI 패권 전쟁의 승자"라는 표현

## 용어 및 개념 설명

| 용어 | 설명 |
|------|------|
| **온톨로지 (Ontology)** | 팔란티어의 핵심 개념. 실제 비즈니스 프로세스를 데이터/로직/액션 3요소로 가상 공간에 재현한 것. 산재된 데이터에 의미론적 관계를 부여하여 의사결정을 가능하게 함 |
| **고담 (Gotham)** | 팔란티어의 국방용 소프트웨어 제품. 미군, FBI 등이 사용. 이름은 배트맨의 고담시에서 유래 |
| **파운드리 (Foundry)** | 팔란티어의 상업용 소프트웨어 제품. 민간 기업(삼성, KT, 두산 등)이 사용 |
| **아폴로 (Apollo)** | 팔란티어의 운영체제 제품. 더 많은 고객에게 서비스를 확장하기 위한 인프라 |
| **FD (Forward Deployed) 엔지니어** | 팔란티어가 고객사에 직접 파견하는 엔지니어. 단순 설치가 아닌 문제 해결을 목적으로 현장에 투입 |
| **데이터 민주화** | 사장부터 사원까지 조직 전체가 동일한 데이터에 접근하여 의사결정하는 것 |
| **Rule of 40** | 소프트웨어 기업의 건전성 지표. 매출 성장률 + 영업이익률의 합이 40 이상이면 우수 기업으로 평가 |
| **PoC (Proof of Concept)** | 개념 검증. 팔란티어는 약 3개월간 실제 데이터로 PoC를 수행 |
| **시멘틱 레이어 (Semantic Layer)** | 온톨로지의 데이터 영역. 원천 데이터에 의미론적 관계를 부여하는 계층 |
| **다이나믹 레이어 (Dynamic Layer)** | 온톨로지의 로직 영역. 비즈니스 규칙과 연산을 처리하는 계층 |
| **키네틱 레이어 (Kinetic Layer)** | 온톨로지의 액션 영역. 실행과 자동화를 담당하는 계층 |
| **골든 돔 (Golden Dome)** | 트럼프 정부의 우주 공간 미사일 요격 시스템 프로젝트. 이스라엘 아이언 돔의 확장 개념 |
| **DOGE (정부효율부)** | 미국 정부 효율화 기관. 가짜 프로젝트를 걸러내는 역할, 팔란티어에게 유리한 환경 조성 |
| **인큐텔 (In-Q-Tel)** | CIA 산하 벤처 캐피탈 기관. 팔란티어에 초기 200만 달러 투자 |
| **톨키니스트** | 톨킨(반지의 제왕 저자) 소설의 열렬한 팬. 피터 틸이 톨키니스트로 유명 |
| **락인 (Lock-in)** | 고객이 특정 서비스에 종속되어 이탈하기 어려운 상태. 팔란티어 구독 모델의 특성 |
