## 1. 개요

### 1.1 X-ray AI 진단이란?

**X-ray AI 진단**은 딥러닝 기반 인공지능이 X-ray(방사선) 영상을 자동으로 분석하여 **질환의 유무, 위치, 심각도를 판별**하는 기술입니다.

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ X-ray    │     │  AI 모델     │     │  분석 결과   │     │ 영상의학과  │
│ 촬영     │────▶│  (딥러닝)    │────▶│  히트맵 +    │────▶│ 전문의 확인 │
│          │     │              │     │  확률 + 위치 │     │ (최종 진단) │
└──────────┘     └──────────────┘     └──────────────┘     └──────────────┘
  (DICOM)         <1초 추론             "폐렴 확률 92%       AI는 "보조"
                                         좌하엽 의심"        최종은 의사
```

### 1.2 현재 수준 (2025~2026)

| 지표 | 수치 |
|------|------|
| FDA 승인 AI 의료기기 | **1,451개** (2025.12 기준) |
| 그 중 영상의학(Radiology) | **1,104개** (76%) |
| 2025년 신규 승인 | **295개** (역대 최다) |
| 흉부 X-ray AI 정확도 | **95~99%** (질환별 상이) |
| AI + 전문의 결합 정확도 | **전문의 단독 대비 2~5%p 향상** |

### 1.3 핵심 포인트

> **AI는 영상의학 전문의를 "대체"하는 것이 아니라 "보조"합니다.**
> AI + 전문의 > 전문의 단독 > AI 단독 — 이것이 현재의 의학적 합의입니다.

### 2.2 DICOM이란?

| 항목 | 내용 |
|------|------|
| **정식명** | Digital Imaging and Communications in Medicine |
| **역할** | 의료 영상의 **국제 표준 파일 포맷** |
| **특징** | 영상 데이터 + 환자 정보 + 촬영 조건을 하나의 파일에 포함 |
| **비유** | JPEG가 일반 사진 표준이듯, DICOM은 의료 사진 표준 |

### 2.3 PACS란?

| 항목 | 내용 |
|------|------|
| **정식명** | Picture Archiving and Communication System |
| **역할** | 병원 내 모든 의료 영상을 **저장·전송·열람**하는 시스템 |
| **비유** | 의료 영상 전용 "클라우드 드라이브" |
| **AI 연동** | AI 진단 결과를 PACS에 다시 전송하여 전문의가 함께 열람 |

## 3. 핵심 AI 기술 상세

### 3.1 CNN (합성곱 신경망) — 가장 널리 사용되는 기술

#### CNN이란?

**CNN (Convolutional Neural Network)** = 이미지에서 패턴을 자동으로 찾아내는 딥러닝 모델

```
  X-ray 이미지 입력
       │
       ▼
  ┌──────────────┐
  │ 합성곱 레이어 │  ← "가장자리, 밝기 변화" 같은 저수준 특징 추출
  │ (Conv Layer)  │     (필터가 이미지를 스캔하며 패턴을 찾음)
  └──────┬───────┘
         │
  ┌──────┴───────┐
  │ 합성곱 레이어 │  ← "폐의 윤곽, 심장 모양" 같은 중수준 특징
  └──────┬───────┘
         │
  ┌──────┴───────┐
  │ 합성곱 레이어 │  ← "폐렴 침윤, 결절 패턴" 같은 고수준 특징
  └──────┬───────┘
         │
  ┌──────┴───────┐
  │ 완전연결     │  ← 추출된 특징을 종합하여 최종 판단
  │ (FC Layer)   │
  └──────┬───────┘
         │
         ▼
  "폐렴 확률: 92%"
```

#### 주요 CNN 아키텍처 비교

| 아키텍처 | 핵심 특징 | X-ray 진단 성능 | 권장 용도 |
|----------|----------|:---------------:|----------|
| **ResNet-50/101** | 잔차 연결(Skip Connection)로 깊은 네트워크 가능 | **98.37%** (흉부 X-ray) | 범용 분류, 가장 검증됨 |
| **DenseNet-121/201** | 모든 레이어가 연결, 특징 재사용 | 높음 (Transfer Learning 최적) | **X-ray 분류에 가장 추천** |
| **EfficientNet-B0~B7** | 효율적 스케일링, 경량 | **98%** (COVID-19 감지) | 경량 모델, 에지 배포 |
| **InceptionV3** | 다중 스케일 특징 추출 | **95.56%** (14개 폐질환) | 다중 질환 동시 분류 |

> **핵심 발견**: ImageNet에서 성능이 좋은 최신 모델이 의료 영상에서도 반드시 좋은 것은 아닙니다. DenseNet-121, ResNet-50 같은 "검증된" 모델이 X-ray에서는 더 안정적인 성능을 보입니다.

### 3.2 Vision Transformer (ViT)

| 항목 | 내용 |
|------|------|
| **원리** | 이미지를 작은 패치(조각)로 나누어 텍스트처럼 처리 |
| **장점** | 이미지 전체의 장거리 관계를 파악 (예: 좌폐와 우폐 비교) |
| **단점** | 대규모 데이터 필요, 현재 흉부 X-ray에서는 CNN이 약간 우세 |
| **현황** | CNN+ViT 하이브리드 모델이 연구 중, 점차 성능 향상 |

### 3.3 Transfer Learning (전이 학습)

> **"자연 이미지(ImageNet)에서 배운 지식을 의료 영상에 전이하는 기법"**

```
  1단계: ImageNet (1400만 장의 자연 이미지)에서 사전 학습
         → "가장자리, 텍스처, 형태" 등 기본 시각 특징 학습

  2단계: 의료 X-ray 데이터로 미세 조정 (Fine-tuning)
         → 기본 시각 특징을 활용하여 "폐렴 패턴, 결절 패턴" 학습

  효과: 처음부터 학습하는 것 대비
        • 학습 시간 대폭 단축
        • 적은 데이터로도 높은 정확도
        • 수렴 속도 향상
```

**RadImageNet**: 의료 영상 전용 사전학습 데이터셋. ImageNet 대비 소규모 의료 데이터에서 **AUC 9.4% 향상**

### 3.4 Grad-CAM (설명 가능한 AI)

| 항목 | 내용 |
|------|------|
| **정식명** | Gradient-weighted Class Activation Mapping |
| **역할** | AI가 "왜 그렇게 판단했는지"를 **히트맵**으로 시각화 |
| **원리** | 마지막 합성곱 레이어의 기울기(Gradient)를 사용하여 중요한 영역 강조 |
| **중요성** | 의사가 AI의 판단 근거를 확인 → 신뢰 구축, 임상 수용성 향상 |

```
  원본 X-ray              Grad-CAM 히트맵           결합

  ┌──────────┐          ┌──────────┐          ┌──────────┐
  │          │          │     ██   │          │     ██   │
  │    폐    │    +     │    ████  │    =     │    ████  │
  │          │          │   ██████ │          │   ██████ │
  │          │          │    ████  │          │    ████  │
  └──────────┘          └──────────┘          └──────────┘
                        빨간색 = AI가 주목한 영역
                        → "좌하엽에 폐렴 소견"
```

### 3.5 데이터 증강 (Data Augmentation)

학습 데이터가 부족한 의료 분야에서 필수적인 기법입니다.

| 기법 | 방법 | 주의사항 |
|------|------|---------|
| 회전 | 90°, 180° 회전 | 과도한 회전은 비현실적 |
| 크기 조절 | 확대/축소 | |
| 밝기/대비 조절 | 감마 보정, CLAHE | 원본 대비 유지 |
| 노이즈 추가 | 가우시안 노이즈 | |
| **좌우 반전 금지!** | - | **흉부 X-ray는 좌우 반전하면 심장이 반대편으로 가서 비정상 이미지가 됨** |
| GAN 합성 | 생성적 적대 신경망 | 합성 데이터의 품질 검증 필요 |

## 4. 적용 분야별 상세

### 4.1 흉부 X-ray (가장 활발한 분야)

| 질환 | AI 최고 정확도 | 모델/방법 | 설명 |
|------|:-------------:|----------|------|
| **폐렴 (Pneumonia)** | **99.20%** | Dense CNN | 세균성/바이러스성 구분 가능 |
| **COVID-19** | **99.37%** | Parallel CNN-ELM | 일반 폐렴과 COVID 구분 |
| **폐결핵 (TB)** | **98.72%** | Multiclass CNN | 활동성 결핵 감지 |
| **폐암/결절 (Lung Cancer)** | **97.20%** | Deep CNN | 결절 위치 + 크기 감지 |
| **심비대 (Cardiomegaly)** | 95%+ | ResNet/DenseNet | 심장 크기 비율 측정 |
| **흉막삼출 (Pleural Effusion)** | 95%+ | CNN | 흉수 존재 여부 |
| **기흉 (Pneumothorax)** | 95%+ | CNN | 긴급 상황 자동 알림 |
| **다중 질환 동시 분류 (5종)** | **99.39%** | CDC_Net | COVID, 기흉, 폐렴, 폐암, 결핵 동시 |
| **14개 질환 분류** | **95.56%** | InceptionV3 | NIH ChestX-ray14 기반 |

> **Lunit INSIGHT CXR**: 폐결절 감지 AUC **0.93**으로 글로벌 경쟁 제품 대비 최고 성능 기록 (Radiology 저널 게재)

### 4.2 근골격계 X-ray (골절 등)

| 질환 | AI 정확도 | 비고 |
|------|:---------:|------|
| 골절 감지 (전반) | **85~95%** 민감도/특이도 | 메타분석 기반 |
| 대퇴경부 골절 | **91%** 정확도 | 87% 민감도, 91% 특이도 |
| 요골/척골 골절 | **98%** 정확도 | 증강 데이터셋 활용 |
| 앙상블 딥러닝 | **92.96%** 정확도 | 7개 상지 부위 대상 |

**핵심 가치**: 응급실에서 미세 골절을 놓치는 비율을 크게 줄일 수 있음

### 4.3 치과 X-ray

| 질환 | AI 성능 | 비고 |
|------|:-------:|------|
| 충치 (Dental Caries) | AUC **98.31%** | YOLOv7 기반 검출 |
| 치주질환 (Periodontitis) | AUC **98.67%**, 병기 분류 90.73% | EfficientNet-B0 |
| 동시 감지 | 충치 + 치주질환 동시 | 기존 단일 질환 방식 대비 혁신 |

### 4.4 유방 촬영 (Mammography)

| 지표 | AI 단독 | 전문의 단독 | AI + 전문의 |
|------|:-------:|:----------:|:-----------:|
| 민감도 | 87% | 98% | **향상** |
| 특이도 | 44.4% | 17% | **향상** |
| 종합 정확도 | - | 전문의 89%, 일반의 84% | **양쪽 모두 ~93%** |

- **FDA 승인 20개+** 유방 영상 AI 제품
- **Clairity Breast**: 표준 유방촬영으로 **5년 유방암 위험도 예측** (FDA De Novo 최초 승인)

### 7.3 간단한 코드 예시 (PyTorch + DenseNet-121)

```python
import torch
import torchvision.models as models
from torchvision import transforms
from PIL import Image

# 1. DenseNet-121 사전학습 모델 로드
model = models.densenet121(pretrained=True)

# 2. 마지막 분류층을 질환 수에 맞게 변경 (예: 14개 질환)
model.classifier = torch.nn.Linear(1024, 14)

# 3. X-ray 이미지 전처리
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485], std=[0.229])  # X-ray는 단일 채널
])

# 4. 추론
image = Image.open("chest_xray.png").convert("RGB")
input_tensor = transform(image).unsqueeze(0)

with torch.no_grad():
    output = model(input_tensor)
    probabilities = torch.sigmoid(output)  # 다중 라벨이므로 sigmoid

# 5. 결과 해석
diseases = ["무기폐", "심비대", "삼출", "침윤", "종괴",
            "결절", "폐렴", "기흉", "경화", "부종",
            "폐기종", "섬유화", "흉막비후", "탈장"]

for disease, prob in zip(diseases, probabilities[0]):
    if prob > 0.5:
        print(f"  {disease}: {prob:.1%}")
```

## 9. 한계점 및 과제

### 9.1 기술적 한계

| 한계 | 설명 | 대응 방안 |
|------|------|----------|
| **데이터 불균형** | 희귀 질환 데이터 부족 → 감지 성능 저하 | 오버샘플링, GAN 합성, 가중 손실 함수 |
| **편향 (Bias)** | 성별/인종 편향된 학습 데이터 → 특정 그룹 오진 | 다양한 인구통계 데이터 확보, 편향 감사 |
| **일반화 한계** | 한 병원 데이터로 학습 → 다른 병원 X-ray에서 성능 저하 | 다기관 학습, 도메인 적응 |
| **설명 불가능** | "왜 폐렴이라 판단했는지" 완전한 설명 어려움 | Grad-CAM, Attention Map, SHAP |
| **후향적 vs 전향적** | 연구 환경 성능 > 실제 임상 성능 (루닛: AUC 0.94 → 0.84) | 전향적 임상시험 필수 |

### 9.2 임상적 과제

| 과제 | 설명 |
|------|------|
| **거짓 양성 (False Positive)** | 정상을 질환으로 오판 → 불필요한 검사/불안 유발 |
| **거짓 음성 (False Negative)** | 질환을 놓침 → 치료 지연 (가장 위험) |
| **경보 피로 (Alert Fatigue)** | 너무 많은 AI 알림 → 의사가 무시하는 습관 |
| **법적 책임** | AI 오진 시 책임 소재 불명확 (AI? 의사? 제조사?) |
| **전문의 수용성** | "AI가 내 업무를 대체할까" 우려 → 저항 |

## 11. 요약 및 시사점

### 11.1 핵심 요약

| 항목 | 핵심 내용 |
|------|----------|
| **기술 성숙도** | 흉부 X-ray AI는 95~99% 정확도로 임상 적용 단계 |
| **역할** | 전문의 "대체"가 아닌 "보조" (AI+전문의 > 전문의 단독) |
| **핵심 기술** | CNN(DenseNet-121 추천) + Transfer Learning + Grad-CAM |
| **한국 강점** | 루닛·코어라인소프트 등 글로벌 경쟁력 보유, 식약처 선진적 가이드라인 |
| **주요 과제** | 데이터 편향, 설명 가능성, 전향적 임상 검증, 건보 수가 |
| **구축 기간** | 데이터 준비~배포까지 약 12~24개월 |
| **트렌드** | 멀티모달, 생성형 AI 리포트, Edge AI 배포 |

### 11.2 시사점

1. **비용 대비 효과가 높은 분야부터 시작**: 흉부 X-ray 폐렴/결핵 감지가 가장 기술 성숙도가 높고, 공개 데이터셋이 풍부
2. **Transfer Learning 활용**: 처음부터 모델을 만들지 말고, DenseNet-121/ResNet-50 사전학습 모델에서 Fine-tuning
3. **설명 가능성 필수**: Grad-CAM 없이는 임상 수용 불가. 처음부터 설계에 포함
4. **규제 선행 확인**: 식약처 인허가 요건을 개발 초기부터 반영 (사후 대응은 비용 폭증)
5. **한국 기업 솔루션 활용 검토**: 루닛 INSIGHT CXR 등 이미 검증된 국내 제품 도입이 가장 빠른 경로
