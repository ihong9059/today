왜 SNOMED CT를 도입해야 하는가

💡 투자자를 위한 쉬운 설명

SNOMED CT는 전 세계 40개국 병원이 공통으로 사용하는 "의료 용어 바코드 시스템"입니다.

마트에서 상품마다 바코드를 찍어 관리하듯, 병원에서 모든 질환/소견에 고유 번호(코드)를 부여하여 컴퓨터가 이해하고 자동 처리할 수 있게 합니다.

현재 vs SNOMED CT 도입 후

❌ 현재 (대부분의 영상의학 병원)

  • 판독문을 자유 텍스트로만 기록
  • 의사마다 다른 표현/약어 사용
  • 컴퓨터가 내용을 이해할 수 없음
  • 보험 청구 코드(ICD-10) 수동 입력
  • 다른 병원과 데이터 호환 불가
  • 통계 산출 불가 ("이달 폐렴 환자 몇 명?")

= 데이터가 사장되는 병원

✅ SNOMED CT 도입 후

  • 판독 시 국제 표준 코드 자동 부여
  • AI가 판독문을 읽고 코드 추천
  • 보험 청구(ICD-10) 자동 변환
  • 전 세계 어떤 병원과도 데이터 호환
  • 통계/연구 데이터 즉시 추출
  • 원격판독 서비스 사업 가능

= 데이터가 돈이 되는 병원
