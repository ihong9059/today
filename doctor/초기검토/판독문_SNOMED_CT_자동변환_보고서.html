Executive Summary

💡 초보자를 위한 배경 설명

판독문이란? 영상의학과 전문의가 X-ray, CT 등 영상을 보고 쓰는 진단 소견서입니다. "좌측 하엽에 2.3cm 크기의 폐렴 의심 소견" 같은 자연어 문장입니다.

SNOMED CT란? 전 세계 병원이 공통으로 쓰는 의료 용어 번호 체계입니다. "폐렴" = 233604007처럼 모든 질환에 고유 번호를 부여합니다.

왜 변환이 필요한가? 의사가 쓴 텍스트를 컴퓨터가 이해할 수 있는 코드로 바꿔야 — 병원 간 데이터 공유, 보험 청구, AI 연구가 가능합니다.

❌ 현재 (수동 코딩)

의사가 판독문을 쓴 뒤, 별도의 코더가 수동으로 SNOMED CT / ICD-10 코드를 찾아 입력합니다.

시간 소모 / 인력 비용 / 코더 간 편차 / 오류 가능성

✅ 목표 (AI 자동 변환)

AI가 판독문을 읽고 자동으로 SNOMED CT 코드를 추천, 의사가 승인만 하면 끝.

기술적 타당성 분석 — AI 자동 변환이 가능한가?

✅ 결론: 가능하다. 단, 조건부

AI가 판독문에서 질환/부위/수치를 추출하고 SNOMED CT 코드로 매핑하는 것은 기술적으로 가능합니다. 다만 정확 매칭률이 57.6%이므로, 의사가 최종 확인하는 Human-in-the-Loop 구조가 필수입니다.

Tool 개발 흐름 — 어떻게 만드는가?

전체 시스템 아키텍처

SYSTEM ARCHITECTURE ┌───────────────────────────────────────────────────┐ │ 👤 사용자 인터페이스 (Web/API) │ │ 판독문 입력 → 코드 추천 결과 → 승인/수정 → 최종 확정 │ └───────────────────────┬───────────────────────────┘ │ NER Engine → Entity Linker → Ontology Validator → Human Review (개체명 인식) (SNOMED CT 매핑) (계층 구조 검증) (의사 최종 확인) │ ┌───────────────────────┴───────────────────────────┐ │ 🗃 데이터 레이어 │ │ SNOMED CT DB │ 한국어 의학 사전 │ 학습 데이터 │ 피드백 데이터 │ └───────────────────────────────────────────────────┘

개발 4단계 (총 13~17개월)

1

Phase 1: 데이터 및 기반 구축

3~4개월
  • SNOMED CT Affiliate License 취득 (K-HIS)
  • SNOMED CT 한국어 에디션 DB 구축
  • 협력 병원과 한국어 판독문 코퍼스 수집 (익명화)
  • 영상의학 전문의 참여한 NER 어노테이션(라벨링)
  • 간(Liver) 질환군 우선 범위 정의 (HCC, LC, Fatty Liver 등)
2

Phase 2: NLP 엔진 개발

4~5개월
  • 한국어 의학 NER 모델 학습 (BioBERT/KoBERT Fine-tuning)
  • SNOMED CT Entity Linker 개발 (SapBERT + FAISS)
  • LLM 기반 RAG 파이프라인 구축 (GPT-4o / Claude API)
  • 온톨로지 검증 로직 (IS-A 관계 그래프)
  • 신뢰도 스코어링: 고신뢰 → 자동 / 저신뢰 → 사람 검토
3

Phase 3: 서비스 플랫폼 개발

3~4개월
  • REST API 개발 (판독문 입력 → SNOMED CT 코드 반환)
  • 리뷰 UI 개발 (코드 추천/승인/수정 웹)
  • PACS/EMR 연동 모듈 (HL7 FHIR R4)
  • 피드백 루프: 전문의 수정 → 모델 재학습
4

Phase 4: 검증 및 출시

3~4개월
  • 파일럿 테스트 (협력 병원 2~3곳)
  • MFDS 사전 상담 (의료기기 해당 여부)
  • 보안 인증 (ISMS-P, 개인정보보호)
  • 상용 출시 v1.0

판독 코딩 자동화 플랫폼
병원/의원이 API를 호출하여 판독문을 보내면 SNOMED CT 코드를 자동 추천받는 서비스.
타겟: 원격판독센터, 중소 병원, 건강검진센터
건당 ₩500~2,000 / 월정액 ₩50만~500만

의료 데이터 거래소

모델 C: EMR/PACS 플러그인

기존 시스템에 설치
기존 EMR/PACS에 플러그인으로 설치하여 워크플로우 변경 없이 바로 적용. 대형 병원, 종합병원 타겟.

AI 코딩 + 전문의 판독 패키지
AI 코딩 + 한국 영상의학 전문의 원격판독을 원스톱 서비스. 동남아, 중동 등 전문의 부족 국가 타겟.

로드맵 제안

1

단기 (0~6개월) — MVP 개발

간(Liver) 질환 특화 프로토타입
  • SNOMED CT Affiliate License 취득
  • 간 질환 SNOMED CT 서브셋 구축 (HCC, LC, Fatty Liver 등)
  • 협력 병원 1곳 → 판독문 500건+ 수집/어노테이션
  • GPT-4o + RAG 기반 매핑 엔진 MVP
  • 간단한 리뷰 UI (Web) 구축
  • 목표: 유효 매칭 90%+
2

중기 (6~12개월) — 파일럿 및 검증

실제 병원 환경에서 파일럿 운영
  • 파일럿 병원 2~3곳 확보 (원격판독센터 포함)
  • NER 모델 자체 학습 (BioBERT/KoBERT Fine-tuning)
  • 피드백 루프 → 모델 지속 개선
  • MFDS 사전 상담, ISMS-P 인증 준비
  • 목표: 유효 매칭 95%+, 사용자 만족도 80%+
3

장기 (12~24개월) — 상용화 및 확장

상용 출시, 다장기 확장, 해외 진출
  • 정식 상용 출시 (SaaS)
  • 간 → 폐 → 뇌 → 복부 순차 확장
  • EMR/PACS 플러그인 개발
  • 대형병원 Enterprise 계약
  • 데이터 표준화 플랫폼으로 확장
  • 해외 시장 진출 준비 (동남아 우선)
