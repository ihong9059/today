## 네트워크 설정

| 인터페이스 | IP | 용도 |
|---|---|---|
| **유선 (로컬 영역 연결)** | 10.0.0.2 / 255.255.255.0 | 메인 PC(10.0.0.1)와 직결 |
| **WiFi (무선 네트워크 연결)** | 192.168.0.199 (DHCP) | 인터넷 접속 |

- 메인 PC 유선 어댑터: 이더넷 9 (Realtek USB GbE) → 10.0.0.1/24
- 넷북 유선 IP 설정 명령: `netsh interface ip set address "로컬 영역 연결" static 10.0.0.2 255.255.255.0`
- RDP 접속: `mstsc` → `192.168.0.199` 또는 `10.0.0.2` (UTSOL / uttec)

## 완료된 작업

### 1. RDP 원격 접속 설정
- 넷북에서 화상 키보드(osk)로 IP 수동 설정
- 비밀번호 재설정: `net user UTSOL uttec`
- 원격 데스크톱 활성화 (시스템 속성 → 원격 설정 → 허용 체크)
- 메인 PC에서 RDP 접속 확인 (10.0.0.2 및 192.168.0.199)

### 2. 디스크 파티션 통합 (C + D → C 단일)
- **변경 전**: C: 97GB + D: 200GB (2파티션)
- **변경 후**: C: 298GB (단일 파티션)
- 작업 도구: diskpart
  ```
  select volume 1 → delete volume override → select volume 0 → extend
  ```
- D 드라이브 기존 내용 (CH341SER, CP210x, MPLABX, nRFgo Studio, SEGGER J-Link 등) 전체 삭제

### 3. 불필요 프로그램 제거
- **삭제됨**:
  - Microsoft SQL Server Compact 4.0 KOR
  - Java 8 Update 131
  - Java Auto Updater
  - nRFgo Studio
  - nRF5x-Command-Line-Tools
  - JLink OB CDC Driver Package
  - SEGGER 폴더 (`rmdir /s /q "C:\Program Files\SEGGER"`)
- **유지**:
  - Microsoft .NET Framework 4.7.2
  - Microsoft Visual C++ 2012 x86 (Minimum + Additional Runtime)
  - Xshell 5 (SSH 터미널)
  - 인텔 PROSet/무선 WiFi 소프트웨어

### 4. 모니터링 유틸리티 다운로드 및 전송
- 메인 PC에서 다운로드 → 네트워크 공유(`\\10.0.0.2\shared` = `C:\shared`)로 전송
- Win7 .NET이 TLS 1.2 미지원 → 넷북에서 직접 HTTPS 다운로드 불가 → 메인 PC 경유

| 파일 | 크기 | 용도 | 설치 상태 |
|---|---|---|:---:|
| putty.exe | 1.4MB | SSH/Serial 터미널 (단독 실행) | 미설치 |
| teraterm-5.6.0-x86.exe | 12MB | UART 메인 터미널, 로그 자동저장 | 미설치 |
| npp.8.4.9.Installer.exe | 4.4MB | 로그 파일 뷰어 | 미설치 |
| Wireshark-3.6.24.exe | 59MB | 패킷 캡처 (Ethernet/WiFi/EtherCAT/Modbus) | 미설치 |

- 넷북 내 위치: `C:\shared\`

## 참고 사항

- **Win7 보안**: 외부망 직접 노출 금지, 사내망/테스트망 전용
- **화상 키보드**: `Win+R` → `osk` (4, 0 키 고장 대안)
- **RDP 접속**: `mstsc` → `192.168.0.199`(WiFi) 또는 `10.0.0.2`(유선)
- **파일 전송**: 메인 PC → `\\10.0.0.2\shared` (= 넷북 `C:\shared`)
- **Wireshark**: Win7 지원 마지막 = 3.6.x LTS, 32bit(x86) 필수
- **Tera Term**: 5.x는 Win7 호환 (PE32 for MS Windows 6.01 확인됨)
- **넷북은 원래 임베디드 개발용**: SEGGER J-Link, MPLABX, nRFgo Studio, CH341/CP210x 설치 이력 있음
