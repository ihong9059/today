# Raspberry Pi + ESP32-C3 교육과정 소개 영상 대본

스마트폰 하나로 집안의 온도를 확인하고, 멀리 있는 LED를 제어한다면 어떨까요?

공유기도 필요 없습니다.
스마트폰으로 직접 연결해서 제어할 수 있습니다.

이제 여러분도 할 수 있습니다.
Raspberry Pi와 ESP32-C3 교육보드 하나면 충분합니다.

이 강좌는 UTTEC Lab에서 제작했습니다.
uttec-edu.duckdns.org에서 수강할 수 있습니다.


이 교육보드는 Raspberry Pi의 40핀 헤더에 바로 연결됩니다.

손바닥보다 작은 이 보드 하나에,
LED 3개, NeoPixel RGB LED 4개, 부저, 스피커,
온습도 센서, OLED 디스플레이가 모두 연결되어 있습니다.

그리고 가장 중요한 것,
ESP32-C3가 WiFi AP 역할을 합니다.

공유기가 없어도,
스마트폰이 직접 ESP32에 연결되고,
ESP32가 Raspberry Pi와 통신해서 하드웨어를 제어합니다.

인터넷이 없는 곳에서도
나만의 IoT 시스템을 구축할 수 있습니다.


초급 과정은 15일 동안 GPIO 기초와 웹 서버를 배웁니다.

LED를 켜고 끄는 것부터 시작해서,
버튼 입력을 받고,
부저로 알람을 울립니다.

I2C 통신으로 OLED 디스플레이에 글자를 출력하고,
온습도 센서에서 데이터를 읽어옵니다.

NeoPixel RGB LED로 화려한 효과도 만들어봅니다.

그리고 Python Flask로 웹 서버를 만들어서
브라우저에서 LED를 제어하는 것까지가 초급 과정입니다.


중급 과정에서는 ESP32 WiFi AP 연동을 본격적으로 배웁니다.

PWM으로 LED 밝기를 조절하고,
스피커로 멜로디를 연주하고,
NeoPixel 애니메이션을 만듭니다.

ESP32-C3에 펌웨어를 올리고,
WiFi AP 모드로 설정하면,
스마트폰이 직접 연결됩니다.

스마트폰 브라우저에서 192.168.4.1에 접속하면
바로 제어 화면이 나타납니다.

버튼을 누르면 실제 LED가 바로 반응합니다.
PC에서도 똑같이 접속할 수 있습니다.

SQLite 데이터베이스로 센서 데이터를 저장하고,
그래프로 변화 추이를 확인하는 것도 배웁니다.


고급 과정에서는 실시간 통신과 외부 서비스 연동을 배웁니다.

WebSocket으로 실시간 통신을 구현합니다.
센서 데이터가 즉시 화면에 반영되고,
여러 사용자가 동시에 제어해도 동기화됩니다.

로그인, 권한 관리, HTTPS까지
보안 기능을 추가합니다.

MQTT로 클라우드와 연동하고,
Home Assistant로 스마트홈 시스템에 통합합니다.

텔레그램 알림, 음성 제어 같은
실무 기능도 배웁니다.

마지막 8일은 종합 프로젝트입니다.
지금까지 배운 모든 것을 통합해서
나만의 스마트홈 시스템을 완성합니다.


이 강좌에서 사용하는 교육보드는
학습에 필요한 모든 부품이 이미 연결되어 있습니다.

복잡한 배선 없이 코드만 작성하면 바로 동작을 확인할 수 있어서,
프로그래밍 학습에 집중할 수 있습니다.

LED 세 개, NeoPixel 네 개, 부저, 스피커, 스위치,
OLED 디스플레이, 온습도 센서,
그리고 WiFi AP 역할을 하는 ESP32-C3까지.

하나의 보드로 초급부터 고급까지 모든 실습이 가능합니다.
