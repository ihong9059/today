# 초급 과정 (15일)

> **목표:** GPIO 기본 제어, 센서 읽기, 웹 기초

## Part 1: GPIO 기본 (Day 1-5)

### Day 1: 환경설정 및 LED 켜기
- **이론:** Raspberry Pi GPIO 구조, BCM vs BOARD 모드
- **실습:**
  - Python 개발환경 설정
  - RPi.GPIO 라이브러리 설치
  - RED LED 켜기/끄기 (GPIO17, LOW=켜짐)
- **목표:** `GPIO.output(17, GPIO.LOW)` → LED ON 이해

### Day 2: 신호등 만들기
- **이론:** 순차 제어, time.sleep()
- **실습:**
  - 3색 LED 순차 점등 (RED→YELLOW→BLUE)
  - 신호등 타이밍 구현 (빨강 3초, 노랑 1초, 파랑 3초)
- **목표:** 다중 GPIO 출력 제어

### Day 3: 버튼 입력 처리
- **이론:** 풀업/풀다운 저항, Active LOW
- **실습:**
  - SWITCH(GPIO4) 상태 읽기
  - 버튼 누르면 LED 토글
  - 디바운싱 처리 (소프트웨어)
- **목표:** 입력 GPIO와 내부 풀업 이해

### Day 4: 버튼 인터럽트
- **이론:** 폴링 vs 인터럽트, Edge Detection
- **실습:**
  - `GPIO.add_event_detect()` 사용
  - 버튼 누를 때마다 LED 색상 변경
  - 콜백 함수 작성
- **목표:** 이벤트 기반 프로그래밍

### Day 5: 부저 제어
- **이론:** 능동 부저 vs 수동 부저
- **실습:**
  - ALARM(GPIO5) 제어 (LOW=울림)
  - 버튼 누르면 부저 울림
  - 비프음 패턴 만들기 (SOS 모스부호)
- **목표:** 출력 장치 확장

## Part 2: 센서와 디스플레이 (Day 6-10)

- **목표:** I2C 센서 데이터 수집

### Day 8: OLED 디스플레이 기초

- **실습:**

- **목표:** I2C 디스플레이 제어

### Day 9: OLED에 센서 데이터 표시

  - 온도/습도 아이콘 추가
- **목표:** 센서 + 디스플레이 연동

### Day 10: NeoPixel LED 기초
- **이론:** WS2812 프로토콜, RGB 색상
- **실습:**
  - rpi_ws281x 라이브러리 설정 (GPIO12)
  - 4개 LED 개별 색상 제어
  - 무지개 색상 순환
- **목표:** 어드레서블 LED 이해
