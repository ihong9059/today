이제 여러분도 할 수 있습니다.
Raspberry Pi와 ESP32-C3 교육보드 하나면 충분합니다.

### Scene 2: 교육보드 소개 (0:30 - 1:15)

**[화면]** 교육보드 클로즈업, 각 부품 하이라이트

| 시간 | 화면 | 하이라이트 |
|------|------|------------|
| 0:30 | 보드 전체 | "40핀 헤더 연결" |
| 0:38 | LED 3개 | "LED 제어" |
| 0:42 | NeoPixel | "RGB LED 효과" |
| 0:46 | OLED | "디스플레이" |
| 0:50 | AHT20 | "온습도 센서" |
| 0:54 | ESP32-C3 칩 | "WiFi AP!" (강조) |
| 1:00 | 연결 다이어그램 | 스마트폰 → ESP32 → RPi |
| 1:10 | 야외/실내 이미지 | "인터넷 없이 어디서든" |

**[대본]**
```
이 교육보드는 Raspberry Pi의 40핀 헤더에 바로 연결됩니다.

손바닥보다 작은 이 보드 하나에,
LED 3개, NeoPixel RGB LED 4개, 부저, 스피커,
온습도 센서, OLED 디스플레이가 모두 연결되어 있습니다.

그리고 가장 중요한 것,
ESP32-C3가 WiFi AP 역할을 합니다.

공유기가 없어도,
스마트폰이 직접 ESP32에 연결되고,
ESP32가 Raspberry Pi와 통신해서 하드웨어를 제어합니다.

인터넷이 없는 곳에서도
나만의 IoT 시스템을 구축할 수 있습니다.
```

### Scene 3: 초급 과정 (1:15 - 1:55)

**[화면]** 실습 화면 (코드 + 하드웨어 동작)

| 시간 | 화면 | 내용 |
|------|------|------|
| 1:15 | "초급 15일" 타이틀 | 페이드인 |
| 1:20 | LED 점등 | GPIO 제어 |
| 1:26 | 버튼 누르기 | 입력 처리 |
| 1:30 | 부저 소리 | 알람 |
| 1:34 | OLED 화면 | I2C 통신 |
| 1:40 | NeoPixel 효과 | RGB LED |
| 1:46 | 웹 브라우저 LED 제어 | Flask 웹서버 |

**[대본]**
```
초급 과정은 15일 동안 GPIO 기초와 웹 서버를 배웁니다.

LED를 켜고 끄는 것부터 시작해서,
버튼 입력을 받고,
부저로 알람을 울립니다.

I2C 통신으로 OLED 디스플레이에 글자를 출력하고,
온습도 센서에서 데이터를 읽어옵니다.

NeoPixel RGB LED로 화려한 효과도 만들어봅니다.

그리고 Python Flask로 웹 서버를 만들어서
브라우저에서 LED를 제어하는 것까지가 초급 과정입니다.
```

### Scene 4: 중급 과정 (1:55 - 2:45)

**[화면]** ESP32 연동, 스마트폰 UI

| 시간 | 화면 | 내용 |
|------|------|------|
| 1:55 | "중급 30일" 타이틀 | 페이드인 |
| 2:00 | NeoPixel 애니메이션 | PWM 효과 |
| 2:06 | 스피커 멜로디 | 소리 파형 |
| 2:12 | ESP32 코드 업로드 | Arduino IDE |
| 2:18 | 스마트폰 WiFi 연결 | "RPI_EDU_AP" |
| 2:24 | 192.168.4.1 접속 | 웹 UI |
| 2:30 | LED 제어 시연 | 화면 분할 |
| 2:36 | 그래프 화면 | 데이터베이스 |

**[대본]**
```
중급 과정에서는 ESP32 WiFi AP 연동을 본격적으로 배웁니다.

PWM으로 LED 밝기를 조절하고,
스피커로 멜로디를 연주하고,
NeoPixel 애니메이션을 만듭니다.

ESP32-C3에 펌웨어를 올리고,
WiFi AP 모드로 설정하면,
스마트폰이 직접 연결됩니다.

스마트폰 브라우저에서 192.168.4.1에 접속하면
바로 제어 화면이 나타납니다.

버튼을 누르면 실제 LED가 바로 반응합니다.
PC에서도 똑같이 접속할 수 있습니다.

SQLite 데이터베이스로 센서 데이터를 저장하고,
그래프로 변화 추이를 확인하는 것도 배웁니다.
```

### Scene 5: 고급 과정 (2:45 - 3:30)

**[화면]** 실시간 대시보드, 외부 서비스 연동

|------|------|------|

| 3:18 | 최종 프로젝트 | 종합 시스템 |

**[대본]**
```
고급 과정에서는 실시간 통신과 외부 서비스 연동을 배웁니다.

WebSocket으로 실시간 통신을 구현합니다.
센서 데이터가 즉시 화면에 반영되고,
여러 사용자가 동시에 제어해도 동기화됩니다.

MQTT로 클라우드와 연동하고,
Home Assistant로 스마트홈 시스템에 통합합니다.

텔레그램 알림, 음성 제어 같은
실무 기능도 배웁니다.

마지막 8일은 종합 프로젝트입니다.
지금까지 배운 모든 것을 통합해서
나만의 스마트홈 시스템을 완성합니다.
```
