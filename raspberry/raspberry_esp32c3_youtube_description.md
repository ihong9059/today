## 설명 (Description)

```
공유기 없이 스마트폰으로 직접 연결해서 LED를 제어하고, 온도를 확인한다면 어떨까요?

이제 여러분도 할 수 있습니다!
Raspberry Pi와 ESP32-C3 교육보드 하나면 충분합니다.

ESP32-C3가 WiFi AP 역할을 하기 때문에,
인터넷이 없는 곳에서도 스마트폰으로 바로 연결해서 제어할 수 있습니다.

이 강좌는 UTTEC Lab에서 제작했습니다.
Python과 웹 기술로 배우는 실용적인 IoT 프로그래밍 강좌입니다.

━━━━━━━━━━━━━━━━━━━━━━

📌 이 강좌에서 배우는 내용

🔹 초급 (15일) - GPIO와 웹 기초
• LED 제어 (3색 신호등, Active LOW)
• 버튼 입력, 부저 알람
• I2C 통신 (OLED 디스플레이, AHT20 온습도 센서)
• NeoPixel RGB LED 효과
• Flask 웹서버, HTML/CSS/JavaScript 기초

🔹 중급 (30일) - ESP32 WiFi AP 연동
• PWM으로 스피커 멜로디 연주
• ESP32-C3 WiFi AP 모드 설정
• 스마트폰/PC에서 직접 연결 (공유기 불필요!)
• UART 통신으로 RPi-ESP32 연동
• SQLite 데이터베이스, 센서 로깅

🔹 고급 (45일) - 완전한 IoT 시스템
• WebSocket 실시간 통신
• 사용자 인증, HTTPS 보안
• MQTT, 클라우드 연동
• Home Assistant 스마트홈 통합
• 텔레그램 알림, 음성 제어
```
