## 0. 사용 가이드 (강사용)

### 0.1 이 지침서의 목적
- 강사 1명이 **사장님 1명을 1:1 또는 소그룹으로 교육**할 때 그대로 따라 쓰는 매뉴얼
- 모든 단계는 **체크박스**로 제공 — 빠뜨림 방지
- 업종이 다르더라도 **공통 절차 + 업종별 시뮬레이션**으로 적용
- 강사 1주 학습 후 즉시 활용 가능한 수준

### 0.2 지침서 구성
- **Part 1**: 교육 프레임워크 (4-Agent 모델)
- **Part 2**: 사전 준비 체크리스트
- **Part 3**: 표준 교육 절차 (Step 0~7)
- **Part 4**: 업종별 시뮬레이션 10개
- **Part 5**: 트러블슈팅
- **Part 6**: 평가·후속
- **Part 7**: 부록 (대본·FAQ·시뮬 데이터)

### 0.3 사용 패턴
1. 사장님 1명 만나기 전: Part 2 체크리스트 완료
2. 첫 미팅: Part 3 Step 0~2 (3시간)
3. 두 번째 미팅: Part 3 Step 3~5 + Part 4의 해당 업종 (4시간)
4. 1주 후: Part 3 Step 6 + Part 5 트러블슈팅
5. 한 달 후: Part 6 follow-up

## Part 1. 교육 프레임워크

### 1.1 교육 목적 (3가지)
1. **자율 운영**: 강사 떠나도 사장님이 자체 운영 가능
2. **즉시 가치**: 1주 안에 "**아 이거 진짜 도움 되네**" 경험
3. **점진 성장**: 매월 더 정교해지는 시스템

### 1.2 핵심 모델 — 4-Agent 시스템 (단순화 버전)

| Layer | 일반인용 비유 | 사장님이 할 일 |
|:---:|--------------|--------------|
| Substrate (Obsidian) | "**노트장**" | 신경 안 써도 됨 (강사가 세팅) |
| Schema (CLAUDE.md) | "**규칙표**" | 강사가 업종 맞게 줌 |
| Agent (Claude) | "**비서**" | 카톡으로 말 시킴 |
| Director (사장님) | "**나 자신**" | 매일 1~3분 음성·메모 |

→ **사장님 부담 = 매일 1~3분만**

### 1.3 표준 교육 형식 4가지

| 형식 | 시간 | 대상 | 가격 (제안) |
|------|------|------|:---:|
| **A. 1:1 컨설팅** | 8시간 (4회) | 사장님 1명 | 50~100만 |
| **B. 소그룹 워크숍** | 1일 8시간 | 5~8명 | 인당 15~25만 |
| **C. 5일 집중 코스** | 5일 40시간 | 10~15명 | 인당 80~150만 |
| **D. 12주 코칭** | 주 1회 1시간 × 12주 | 1~3명 | 200~300만 |

→ **첫 시작은 A (1:1)** — 사장님 1명에게 깊게, 사례 축적

### 1.4 교육 후 사장님이 할 수 있어야 하는 것 (Bloom Taxonomy)

| 수준 | 졸업 시점 | 1개월 후 | 3개월 후 |
|------|---------|---------|---------|
| 기억 | Claude·Obsidian이 뭔지 | 매일 입력 습관 | — |
| 이해 | 4-Agent 흐름 | 자기 schema 일부 수정 | — |
| 적용 | 1일 분량 raw 입력 | 주간 리포트 활용 | 월간 리포트 행동 변화 |
| 분석 | — | 자기 사업 약점 발견 | 경쟁자 비교 |
| 평가 | — | AI 제안 채택/거부 판단 | 자기 schema 진화 |
| 창조 | — | — | 다른 사장님에게 추천·교육 |

## Part 3. 표준 교육 절차 (Step 0 ~ 7)

### Step 0. 진단 (1시간, 첫 미팅)

#### 목적
사장님의 사업·고민·기대를 정확히 파악

#### 절차
- [ ] 인사 + 본 교육 목적 설명 (10분)
- [ ] 사장님 사업 현황 청취 (20분)
  - 사장님이 자유롭게 1번 풀어내게 두기
  - 메모하지 말고 듣기 (강사 노트북 닫고)
- [ ] 5대 표준 질문 (15분)
  1. "**어제 하루 어떻게 지냈어요?**" — 일과 패턴
  2. "**최근 한 달 가장 힘들었던 게 뭐예요?**" — 페인 포인트
  3. "**가장 알고 싶은 게 뭐예요?**" — 정보 수요
  4. "**지금 어떻게 정리하고 계세요?**" — 현 상태
  5. "**한 달 1~3만원이면 도움 받고 싶어요?**" — 결제 의향
- [ ] 강사 정리 + 다음 단계 안내 (15분)

#### 산출물
- 사장님 진단 노트 1장 (Obsidian Vault entities/사장님_{이름}.md)
- 적용할 업종 schema 결정
- 사장님 페인 포인트 우선순위 3가지

### Step 1. 4-Agent 모델 소개 (30분)

#### 목적
사장님이 "**왜 매일 1~3분만 입력해도 되는지**" 직관적 이해

#### 강사 대본
> "사장님, 사장님이 옆에 비서를 두는 셈인데요. 
> 사장님은 **매일 카톡에 떠오르는 거 음성으로 1~3분만** 보내시면 됩니다.
> 그 비서가 자동으로 정리해서, 일주일에 한 번 '**이번 주 어떻게 갔는지, 무엇을 해보면 좋을지**' 알려드립니다.
> 형식 신경 쓰지 마시고, 그냥 떠오르는 거 다 던지세요."

#### 시각 자료
- A4 1장에 4-Agent 다이어그램 (사장님이 보고 이해할 수 있는 단순화)
- "사장님(나) → 카톡 비서(AI) → 노트장(자동) → 주간 리포트" 한 줄 흐름

#### 체크
- [ ] 사장님이 "**그래서 내가 매일 뭐 하면 되는 거예요?**"에 답할 수 있나?
- 답: "**카톡에 음성 1~3분, 그게 다입니다.**"

### Step 2. 도구 설치·세팅 (1시간)

#### 사장님 측 (15분)
- [ ] 카톡 채널 친구 추가
- [ ] 첫 메시지: "**안녕하세요. 오늘부터 1주일 시범 시작합니다.**"
- [ ] 사장님이 음성 메시지 1번 시범 (강사 보는 앞에서)

#### 강사 측 (45분)
- [ ] 사장님 전용 Obsidian Vault 신설 (`/{사장님_이름}_vault/`)
- [ ] CLAUDE.md 작성 (해당 업종 schema 복사)
- [ ] 카톡 → Vault 자동 저장 워크플로우 활성화 (n8n)
- [ ] Claude API 키 사장님 전용 할당
- [ ] 첫 음성 메시지가 정상 처리되는지 검증

#### 검증 체크
- [ ] 사장님 음성 → 강사 Vault에 자동 저장됨
- [ ] Claude가 1차 분류 정상 출력
- [ ] 분류 결과가 카톡으로 사장님에게 도착

### Step 3. 업종 Schema 적용 + 맞춤 (1시간)

#### 절차
- [ ] Part 4의 해당 업종 schema 사장님과 함께 검토
- [ ] **빠진 항목 추가** (사장님이 알려주는 사업 고유 항목)
- [ ] **불필요한 항목 제거**
- [ ] **카테고리 우선순위** 사장님이 직접 매김

#### 예시 — 학원 schema 맞춤화
```
[사장님 "음악 학원이라 학생 이름·학년·교재 진도가 핵심"]
    ↓
강사가 학원 schema에서:
- 매출 ✅
- 학생 ✅
- 학부모 ✅
- 강사 ✅ (학원이라 강사 항목)
- 진도 ★ (음악이라 곡명·페이지 추가)
- 교재 ✅
- 시간표 ✅
- 발표회 ✅ (음악 학원 특이 항목 추가)
```

### Step 4. 1주일 시뮬레이션 데이터 입력 (2시간)

#### 목적
"실제 1주일 운영 데이터"를 사장님이 강사 앞에서 입력 → 작동 확인

#### 절차
- [ ] 강사가 Part 4 해당 업종 시뮬레이션 raw data 1주일치 보여줌
- [ ] 사장님이 자기 사업 1주일 회고하며 raw 입력
  - 사장님이 음성 → 강사가 도움 → 7일치 누적
- [ ] 매일 분량 1~3분으로 압축 (너무 많이 쓰면 지속 X)
- [ ] 7일치 누적되면 강사 모니터에서 같이 봄

#### 입력 가이드 (사장님에게)
- "**그날 떠오르는 거 아무거나 OK**"
- "**문법·맞춤법 신경 쓰지 마세요**"
- "**숫자만 정확하면 OK**"
- "**모르는 건 빼도 OK** — AI가 알아서 채움"

### Step 5. AI 정리·인사이트 시연 (1시간)

#### 목적
사장님이 "**아 이거 진짜 도움 되겠다**" 느끼는 순간 만들기

#### 절차 (강사가 라이브)
- [ ] 7일치 누적 데이터로 Claude에게 주간 리포트 요청
- [ ] **사장님 보는 앞에서** 리포트 생성
- [ ] 함께 읽고 토론
- [ ] 사장님이 가장 인상 깊었던 것 3개 표시
- [ ] 노이즈였던 것 1~2개 표시 → schema 조정

#### 강사 시연 시 주의
- 라이브 데모이므로 **Claude API 응답 시간 대비 대화 채움**
- "**이렇게 정리되는 거 보면서 사장님 생각이 어떠세요?**" 질문
- 사장님 표정·반응 관찰 — 가치 매칭 점검

#### 가치 매칭 체크
- [ ] 사장님이 "**이거 어떻게 알았어요?**" 라고 한 번이라도 말했나? (1회 이상이면 합격)
- [ ] 사장님이 "**다음 주에 이거 해봐야겠다**" 했나? (행동 변화 의지)

### Step 6. 1주 자체 운영 + 피드백 (1주)

#### 절차
- [ ] 사장님 혼자 7일간 매일 카톡 음성 입력
- [ ] 강사가 매일 백엔드 모니터링 (사장님 입력 누락 시 가벼운 격려)
- [ ] 매일 자동 정리 + 토요일 자동 주간 리포트
- [ ] 1주 후 미팅 (1시간):
  - 사장님 만족도 5점 척도
  - 어떤 게 도움 됐고 안 됐는지
  - schema 조정 필요한지
  - 결제 의향 확정

#### 매일 강사 모니터링 체크
- [ ] 사장님 입력 들어왔는가? (3일 연속 누락 시 친근한 격려 카톡)
- [ ] AI 분류 정상인가? (이상 시 즉시 schema 보정)
- [ ] 카톡 알림 정상 도달했는가?

### Step 7. 졸업 + 운영 가이드 인계 (1시간)

#### 사장님에게 인계
- [ ] **본인 Vault 백업** (Google Drive 또는 USB)
- [ ] **자체 운영 매뉴얼 1장** (사장님 맞춤 1페이지)
- [ ] **트러블 시 연락처** (강사 카톡)
- [ ] **결제 시작** (Lite 또는 Standard)
- [ ] **1개월·3개월 후 follow-up 약속**

#### 사장님 자체 운영 매뉴얼 (1페이지 양식)

### 4.11 업종별 공통 패턴 (강사 메타 가이드)

모든 업종에서 5가지 공통 가치:

1. **매출 트렌드** (vs 지난주, vs 작년)
2. **단골·고객 미방문 알림** (이탈 방지)
3. **재고·재료 자동 발주 알림**
4. **직원·강사 근태·효율**
5. **방향 제시·아이디어** (시장 비교, 시즌 효과 등)

→ 새 업종 만나도 위 5가지 + 업종 고유 1~2가지로 schema 빠르게 정의 가능.

## Part 5. 트러블슈팅

### 5.1 사장님이 입력 안 할 때

| 증상 | 원인 | 대응 |
|------|------|------|
| 첫 3일 입력 0 | 부담감 | "**아무거나 한 줄 OK**" 격려, 강사가 첫 음성 시범 |
| 1주 누락 | 바쁨·잊음 | "**매일 같은 시간 알람 설정**" 제안 (저녁 마감 후) |
| 이번 주만 짧음 | 일시적 | 격려, 다음 주 정상화 기대 |
| 한 달 이탈 | 진짜 가치 못 느낌 | **재진단 미팅** + schema 재조정 또는 졸업 결정 |

### 5.2 AI가 부정확할 때

| 증상 | 원인 | 대응 |
|------|------|------|
| 단가 잘못 추출 | 음성 인식 오류 | 사장님이 정정 → AI 학습 |
| 단골 이름 헷갈림 | 동명이인 | 단골 ID 부여 (이름 + 인덱스) |
| 매출 totals 안 맞음 | 입력 누락 | "**일주일 끝에 한 번 합계 알려주세요**" |
| 황당한 제안 | hallucination | 강사가 schema 가이드 강화 |

### 5.3 데이터가 너무 적을 때 (첫 1~2주)

- AI는 4~6주 데이터부터 패턴 발견 가능
- 첫 2주는 "**기록 안정화**" 메시지 강조
- 3주차부터 "**비교 가능한 인사이트**" 등장
- 이걸 사장님에게 미리 안내해서 실망 방지

### 5.4 사장님이 AI 제안 거부할 때

- **그게 정답**. AI는 제안, 결정은 사장님
- 거부 이유 캡처 (예: "**김치찌개 단가 그대로 갈래**" → "왜?" 청취)
- 거부 패턴이 학습 자료 → schema 진화

### 5.5 데이터 백업·이전

| 상황 | 대응 |
|------|------|
| 강사 변경 | Vault 통째로 인계 (Git or Drive) |
| 사장님 폐업 | Vault 인계 + 파기 옵션 |
| 사장님 다른 도구로 이전 | 마크다운 파일 그대로 export 가능 (영구 소유) |
| 사고로 데이터 분실 | 매주 자동 백업으로 복원 |

## Part 7. 부록

### 7.1 강사 표준 대본

#### A. 첫 만남 인사 (5분)
```
"안녕하세요, [강사 이름]입니다.
오늘부터 [N]시간 동안 사장님 사업을 도와드릴
'AI 비서 시스템' 만드는 걸 도와드릴 거예요.

목적은 단 하나입니다:
사장님이 매일 [영업/생산]에 바쁘셔서
'**왜 이번 달이 잘 됐는지, 왜 안 됐는지**' 추적할 시간이 없잖아요?
그걸 카톡 음성 1~3분만으로 자동 추적·정리·제안하도록
만들어 드리는 거예요.

오늘은 그냥 [N]시간만 같이 보내시면 됩니다.
끝나면 사장님은 매일 1~3분 음성, 매주 한 번 리포트 받기,
그게 전부예요. 시작해볼까요?"
```

#### B. 진단 질문 5개 (Step 0)
```
1. "어제 하루 어떻게 지내셨어요? 일과 시작부터 끝까지 천천히 말씀해주세요."

2. "최근 한 달 가장 힘들었던 게 뭐예요? 무엇 때문에 잠 못 주무셨어요?"

3. "사장님 사업에서 '이거 알고 싶다'는 게 있으세요? 예를 들면 매출 추이, 어느 메뉴가 잘 팔리는지 같은 거요."

4. "지금 사업 정보를 어떻게 정리하고 계세요? 종이 노트, 엑셀, 머리, 영수증 박스, 뭐든 OK입니다."

5. "한 달에 1~3만원 정도면 도움 받고 싶으세요? 가격은 부담 안 되시는지요?"
```

#### C. 4-Agent 모델 설명 (Step 1)
```
"사장님, 이걸 그냥 '비서 한 명 들이는 셈'으로 보시면 됩니다.

이 비서는 4가지 역할이 있어요:
1. 노트장 (자동 정리됨, 신경 안 써도 OK)
2. 규칙표 (사장님 업종에 맞춰 제가 만들어드립니다)
3. AI 비서 (24시간 자동 작동, 카톡으로 도착)
4. 사장님 본인 (매일 1~3분 음성만 던지시면 끝)

다른 거창한 ERP나 POS 시스템처럼 형식 맞춰 입력 X.
그냥 '오늘 매출 65만 김치찌개 23그릇 박부장 가족 옴' 이렇게 떠오르는 거 다 던지면 끝.
나머지는 AI가 알아서 분류·정리·제안합니다."
```

#### D. 시연 후 마무리 (Step 5 끝)
```
"보셨죠? 사장님이 던진 7일치 음성이
이렇게 한 페이지 리포트로 나왔어요.

여기에 사장님 다음 주 시도해볼 만한 거 3가지도 자동 제안됐고요.
이걸 매주 토요일에 자동으로 받으실 수 있게 다음 1주 운영해볼까요?

이번 주는 사장님 혼자 입력만 해주세요.
저는 백엔드에서 모니터링만 하고, 토요일 리포트가 자동으로 도착할 겁니다.
중간에 뭐든 막히면 카톡 주세요."
```

#### E. 졸업 폐회 (Step 7)
```
"사장님, [N]주간 정말 수고하셨습니다.

사장님 데이터는 100% 사장님 거예요. 
저장 위치 [경로], 백업 매주 자동 [Drive].
회사가 망해도, 제가 사라져도, 사장님 마크다운 파일은 평생 사장님 겁니다.

자체 운영 매뉴얼 1장 드렸어요. 냉장고에 붙여두세요.
1개월 후, 3개월 후 제가 다시 카톡 드릴 거예요.
그 사이 막히는 거 있으면 언제든 카톡 주세요.

수고하셨고, 사업 번창하시길 바랍니다."
```

### 7.2 자주 묻는 질문 (FAQ 30)

9. **Q: 직원에게 알리나요?** A: 사장님 결정. 강제 X.
10. **Q: 가족에게 보여줄 수 있나요?** A: 사장님 결정.

26. **Q: 다른 직원도 입력 가능?** A: 가능. 단, 사장님 동의 + 권한 분리.

28. **Q: 바코드 스캔?** A: Phase 3+ 검토.

1. **표준 절차 = Step 0~7 (8시간 + 1주 자체 + follow-up)**

   - 새 업종은 30분 청취로 schema 작성 가능

3. **강사가 갖춰야 할 것**
   - 본 지침서 5개 문서 통독 + myWiki 1개 운영 + 가족·지인 1명 베타 = 8주 학습으로 충분
