# Vault 템플릿 — 5분 만에 시작 가이드

## 이 폴더가 무엇인가

강의 실습용 **샘플 Obsidian Vault**입니다. 이 폴더 전체를 본인 PC로 복사하면 즉시 시작할 수 있습니다.

## 5분 시작 가이드

### 1단계 (1분) — 폴더 복사
```
1. vault_template/ 폴더 전체를 본인 PC에 복사
2. 폴더 이름을 본인 것으로 변경
   예: "내_두번째뇌" 또는 "MyVault"
```

### 2단계 (1분) — 옵시디언 설치 및 열기
```
1. https://obsidian.md 접속 → 다운로드 + 설치
2. 옵시디언 실행 → "Open existing vault"
3. 1단계에서 복사한 폴더 선택
```

### 3단계 (1분) — Vault 둘러보기
```
1. CLAUDE.md 열어보기 (Claude를 위한 규칙)
2. README.md (이 파일) 다시 읽기
3. daily/, entities/, thoughts/ 폴더 확인
```

### 4단계 (1분) — Claude Code 진입
```
1. PowerShell 또는 터미널 열기
2. cd "복사한_폴더_경로"
3. claude  (Claude Code 실행)
4. CLAUDE.md를 Claude가 자동으로 읽음
```

### 5단계 (1분) — 첫 메모 작성
```
방법 A — 직접 작성:
  - daily/ 폴더에 오늘 날짜로 노트 작성
  - 예: 2026-05-07.md
  - 본문에 오늘 일과 적기

방법 B — Claude에게 입력:
  사용자: "오늘 한국기계 미팅 갔어. 박부장 만났고 견적 1억 5천 협의."
  Claude: 자동으로 daily/2026-05-07.md + entities/한국기계.md 작성
```

**완료!** 첫 메모를 던져보세요.

```
사용자: "이 폴더 정리해줘"
```

```
- Ctrl+G → 그래프 뷰

- 별처럼 빛나는 지식 그래프 시작
```

## 자주 막히는 지점

### Q. CLAUDE.md를 수정해도 됩니까?
**A**: 네. 본인 업종에 맞춰 자유롭게 수정하세요. 이 파일이 곧 schema입니다.

### Q. 본 폴더의 entities/, daily/, thoughts/는 비어있는데?
**A**: 의도적입니다. 본인 데이터로 채워가는 게 목적.

### Q. log.md는 무엇입니까?
**A**: 시간순 활동 기록. Claude가 정리할 때마다 한 줄씩 추가합니다.

### Q. 폴더 구조를 다르게 가고 싶은데?
**A**:
1. 본인 폴더 구조 만들기 (예: 음식점이면 `메뉴/`, `매출/`, `직원/`)
2. CLAUDE.md 갱신 (Claude에게 새 구조 알려주기)
3. Claude에게 "기존 노트를 새 구조로 정리해줘" 요청
