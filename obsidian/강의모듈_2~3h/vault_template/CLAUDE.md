# Vault 샘플 schema

이 Vault는 **강의 실습용 샘플**. 수강생이 즉시 복제해서 시작할 수 있는 출발점.

## 구조

```
vault_template/
├── CLAUDE.md          # 이 파일 (Claude를 위한 schema)
├── README.md          # 수강생 시작 가이드 (사람을 위한)
├── daily/             # 일별 노트 (선택)
├── entities/          # 사람·조직·도구 등
├── thoughts/          # 생각·인사이트
└── log.md             # 시간순 활동 기록
```

## 폴더 규칙

- **daily/**: 매일 하나씩 (예: `2026-05-07.md`)
- **entities/**: 사람·조직·도구별 1파일 (예: `홍길동.md`, `회사ABC.md`)
- **thoughts/**: 자유 형식, 인사이트가 떠오를 때

## 명명 규칙

- 한글 또는 영어, 띄어쓰기 사용 가능
- 날짜는 `YYYY-MM-DD` 형식
- 엔티티는 고유명사 그대로 (예: `한국기계.md`, `Claude.md`)

## 링크 규칙

- 다른 노트 참조: `[[노트명]]`
- 표시 텍스트 변경: `[[노트명|보일 텍스트]]`
- 외부 링크: `[텍스트](URL)`

## Claude 작업 가이드

사용자가 "정리해줘"라고 하면:
1. 모든 .md 파일 읽기
2. 주제 분류 (사람/조직/도구/인사이트/기록)
3. 적절한 폴더로 이동
4. 양방향 링크 보강 (`[[관련노트]]` 자동 추가)
5. log.md에 작업 기록

사용자가 "X에 대해 알려줘"라고 하면:
1. 관련 entity 파일 확인
2. 백링크 패널 확인 (다른 노트에서 X를 어떻게 참조하는지)
3. 종합 답변 + 가치 있으면 thoughts/에 새 노트 작성

## 워크플로우

### 일일 (매일)
- daily/ 폴더에 오늘 노트 추가 (간단해도 OK)
- 떠오르는 생각은 thoughts/에 자유 형식

### 주간 (매주 일요일)
- Claude에게 "이번 주 정리해줘" 요청
- 새로운 entity 발견 시 entities/에 추가
- log.md 갱신

### 월간 (매월 첫째 주)
- Claude에게 "이번 달 인사이트는?" 요청
- 패턴 발견 → thoughts/에 종합 노트 작성

## 본 Vault의 한계

이 Vault는 **샘플**. 실제 사용 시:
- 본인 업종에 맞춰 폴더 추가 (예: 음식점 → `메뉴/`, 제조 → `제품/`)
- 본인 schema로 본 CLAUDE.md 갱신
- 30개 페이지 이상 쌓이면 정원사 사이클 시작
