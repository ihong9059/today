# 실습 가이드

## 데모 시나리오

**1인 사업자가 1주일 동안 쌓인 자료를 옵시디언 + Claude로 정리하는 흐름**

## 라이브 데모 6 Step (60분)

### Step 1 — Vault 생성 + 첫 노트 (5분)

**강사 시범**:
```
1. https://obsidian.md 접속 → 다운로드 + 설치
2. "Create new vault" 클릭
3. Vault 이름: "내_두번째뇌" (예시)
4. 폴더 위치: C:\내문서\Vault (또는 Desktop)
5. 첫 노트 작성: "오늘_미팅_노트.md"
6. 마크다운 기초 시연:
   # 제목
   ## 부제목
   - 항목
   **굵게**
   *기울임*
   [링크](https://example.com)
   [[다른노트]]
```

**수강생 따라하기**: 본인 노트북에 동일하게 진행.

**예상 트러블**:
- 옵시디언 다운로드 못 함 → 사전 USB 배포본 활용
- 폴더 위치 모름 → "C:\내문서\Vault" 추천

---

### Step 2 — 양방향 링크 + 그래프 뷰 (10분)

**강사 시범**:
```
1. 노트 A 작성: "한국기계_미팅.md"
   본문에 [[REVITA_제품]] 입력
2. 노트 B 작성: "REVITA_제품.md"
   - 자동으로 백링크 패널에 "한국기계_미팅" 표시됨!
3. Ctrl+G → 그래프 뷰
   - 두 노트가 선으로 연결됨
4. 노트 5~10개 추가 후 그래프 뷰 다시 보기
   - 별처럼 빛나는 지식 그래프
```

**수강생 따라하기**: 본인 메모 3~5개 작성 + 양방향 링크 연결.

**예상 트러블**:
- `[[]]` 자동완성 안 됨 → 옵시디언 설정 → "Files & Links" → "Use [[Wikilinks]]" 활성화

---

### Step 3 — Claude Code 설치 + Vault 진입 (10분)

**강사 시범**:
```
1. https://claude.ai/install.sh 접속 → 설치 스크립트 다운로드
   또는 https://claude.ai/code 데스크톱 앱 다운로드
2. PowerShell 또는 터미널 열기
3. cd "C:\내문서\Vault"
4. claude  (Claude Code 실행)
5. /init 명령
   → CLAUDE.md 자동 생성
   → 이 파일 = "보이지 않는 schema"
6. CLAUDE.md 열어서 함께 보기:
   - 폴더 구조
   - 명명 규칙
   - 자동화 패턴
```

**수강생 따라하기**: 본인 Vault에 Claude 진입 + /init 실행.

**예상 트러블**:
- Claude 가입 안 함 → 5분 안에 가입 가능, 무료도 가능
- PowerShell 모름 → "시작 메뉴 → cmd" 또는 옵시디언 내장 터미널 플러그인 안내
- /init 실패 → 권한 문제일 수 있음, "관리자 권한으로" 재실행

---

### Step 4 — Claude에게 "정리해줘" 라이브 데모 (15분)

**강사 시범** (이게 핵심):
```
사용자: "이 폴더의 노트들을 카테고리별로 정리해줘"

Claude가 진행하는 것:
  1. 모든 .md 파일 읽음
  2. 주제 분류 — 제품/고객/내부/외부
  3. 새 폴더 구조 제안 (yes/no 확인)
     예:
       - vault/
         ├── 고객/
         │   ├── 한국기계_미팅.md
         │   └── 태명과학_제안.md
         ├── 제품/
         │   ├── REVITA_제품.md
         │   └── AI_FanStick.md
         └── 내부/
             └── 이번주_할일.md
  4. 자동 이동 + 양방향 링크 보강
  5. log.md에 정리 기록
```

**핵심 메시지**:
> "여러분이 한 일은? '카테고리별로 정리해줘' 한 마디.
> Claude가 한 일은? 모든 노트 읽기 + 분류 + 이동 + 링크 보강 + 기록.
> 5분 만에 100개 노트가 정리됩니다."

**수강생 따라하기**: 본인 Vault에서 Claude에게 정리 요청.

**예상 트러블**:
- 노트가 너무 적어 정리할 게 없음 → 강사가 미리 준비한 "샘플 노트 20개" 제공
- Claude가 yes/no 묻는데 어떻게 답? → 그냥 "yes" 또는 "y"

---

### Step 5 — 메모 → 구조화 라이브 데모 (10분)

**강사 시범**:
```
사용자: "오늘 한국기계 미팅에서 나온 얘기들이야:
  - 분쇄 라인 8월 도입
  - 견적 1억 5천 협의
  - 박부장 의사결정자
  - 다음 미팅 5/14 14시"

Claude:
  → 자동으로 다음을 생성:
    1. 미팅 노트 한국기계_2026-05-07.md (구조화된 형식)
    2. 한국기계.md entity 업데이트 (의사결정자: 박부장)
    3. 영업 추적 DB에 "1억 5천 협의 중" 추가
    4. 일정 5/14 14시 다음 미팅 등록
    5. 양방향 링크 [[박부장]], [[분쇄라인]], [[견적]] 추가
```

**핵심 메시지**:
> "여러분이 한 일은? 떠오르는 대로 줄줄이 입력.
> Claude가 한 일은? 5개 파일에 흩뿌려 구조화.
> **메모하는 시간 == 구조화하는 시간**입니다."

**수강생 따라하기**: 본인 오늘 일과 1줄로 Claude에게 입력.

---

### Step 6 — 수강생 실습 + 1:1 트러블슈팅 (10분)

**진행**:
- 수강생 각자 본인 Vault에 메모 5~10개 추가
- Claude에게 정리 요청
- 강사가 순회하며 1:1 트러블슈팅

**자주 나오는 1:1 질문**:
- "내 업종에는 어떤 schema가 좋을까?" → Part 3에서 다룸
- "Claude가 너무 느려요" → 모델 변경 (Sonnet/Haiku)
- "백업은 어떻게?" → Git 또는 클라우드 동기화 안내

## 수강생 실습 자료

### Vault 템플릿 사용법
폴더 `vault_template/`에 미리 준비한 샘플 Vault 있음.

```
1. vault_template/ 전체 폴더 복사 → 본인 PC
2. 옵시디언에서 "Open existing vault" → 복사한 폴더 선택
3. CLAUDE.md 열어서 schema 확인
4. README.md 따라 5분 만에 시작
```

### 사전 준비물 (수강생용)
- 노트북 (Windows 10/11 권장, 8GB RAM 이상)
- Claude 계정 (Pro 또는 무료, https://claude.ai 가입)
- 본인 메모 5~10개 (실습 데이터용, 미리 준비하면 좋음)

### 5분 만에 시작 (강의 후 본인 실행)

```
1. obsidian.md 다운로드 + 설치 (1분)
2. Vault 생성 (1분)
3. 첫 노트 작성: "나의 두 번째 뇌" (1분)
4. Claude 가입 + claude.ai/code 설치 (1분)
5. cd Vault → claude → /init (1분)
완료 — 첫 메모를 던져보세요!
```
