## 학습 목표 (3가지)

1. **이해** — 옵시디언이 왜 LLM 시대의 PKM 표준이 됐는지 (4-Agent 시스템)
2. **실습** — Claude Code + 옵시디언 연동 워크플로우 1개 구축
3. **응용** — 본인 업종에 맞춘 schema 1개 설계
