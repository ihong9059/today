## 1. 호오컨설팅 단발 강연 (1순위)

### 컨셉
**"바이브 코딩으로 1인 사업자 두 번째 뇌"**

### 시간 / 구성
- **2시간 압축 버전**
- Part 1 (이론) 25분 + Part 2 (실습) 60분 + Q&A 35분
- Part 3은 1~2 사례만 짧게

### 대상
- 1인 사업자
- 컨설턴트
- 자영업 사장님 (장년층 가능)

### 단가
- 호오컨설팅 표준: **50~150만원** (단발 강연 1회)
- 강의실 제공 + 모집 호오컨설팅이 진행

### 차별화 포인트
1. **임베디드 38년 + 1인 사업자 본인 사례** — 다른 강사에게 없는 깊이
2. **본인 myWiki 라이브 데모** — 18일 운영 실측 데이터
3. **REVITA 제조업 사례** — 산업 도메인 특화

### 영업 액션
- [ ] 호오컨설팅 강연 모집 게시판 확인 (url 미상 — 사용자 직접 컨택)
- [ ] 강연 제안서 1페이지 작성 (본 모듈 0_README 기반)
- [ ] 본인 포트폴리오 첨부 (uttec-sensor.duckdns.org)

### 강의 후 자산
- 강의 영상 → uttec-edu 무한 재사용
- 후기 1~2건 → 다음 채널 영업 자료
- 강의안 v2 → Stage 1 (300만) 패키지 데모 자료

## 2. 인프런 단기 코스 (2순위)

### 컨셉
**"스마트팩토리 엔지니어를 위한 Claude Code + 옵시디언 PKM"**

### 시간 / 구성
- **3시간 풀버전** (또는 1시간 × 3편으로 분할 가능)
- Part 1+2+3 풀 + Q&A
- 영상 강의이므로 실습은 "함께 따라하기" 형식

### 대상
- 제조업 엔지니어
- 임베디드 개발자
- 산업 자동화 종사자

### 단가
- 인프런 표준: **5~10만원 / 학생** (강의 가격, 인프런 7:3 분배)
- 100명 수강 시: 350~700만원 (강사 측)
- 1,000명 수강 시: 3,500~7,000만원 (강사 측)

### 차별화 포인트
1. **REVITA 제조업 4축 분류 사례** — 강의 핵심
2. **KC 인증 도메인 노하우** — 산업 특화
3. **옵시디언 + Claude + 임베디드 통합** — 인프런에 비슷한 강의 거의 없음

### 영업 액션
- [ ] 인프런 강의 등록 페이지 확인 (https://www.inflearn.com/instructor)
- [ ] 강의 페이지 작성 (본 모듈 + 영상 5분 트레일러)
- [ ] 영상 촬영 (본 모듈 강의안 그대로 활용)
- [ ] 인프런 강의 심사 (1~2주 소요)

### 강의 후 자산
- 인프런 강의 페이지 = 영구 영업 자료
- 수강생 후기 → 다음 채널 영업
- 인프런 강사 인지도 → uttec-edu 자체 패키지로 유입 유도

## 3. 디지털배움터 (3순위)

### 컨셉
**정부지원 AI 도구 입문 강사 차별화**

### 시간 / 구성
- **3시간** (단시간) 또는 **8시간** (확장, 1일 풀)
- 8시간 시: Part 1+2+3 + 추가 응용 워크숍 + 평가

### 대상
- 시니어 (디지털배움터 주 타겟)
- 자영업 사장님 (50~70대)
- 사업자 (50~60대)

### 단가
- 디지털배움터 강사료: **시간당 4~10만**
- 8시간 강의 시: 32~80만 / 1회

### 차별화 포인트 (시니어 친화)
1. **로컬 우선 = 시니어 친화** — 클라우드 거부감 없음
2. **마크다운 5분 학습** — Word보다 단순
3. **음성 입력 데모** — 타이핑 부담 ↓ (스마트폰 음성 → Claude → 정리)
4. **자영업 사례 위주** — 음식점·미용실·카페 (시니어 공감 ↑)

### 영업 액션
- [ ] 디지털배움터 강사 지원 (1~2개 기관 선택)
- [ ] 본 모듈 + 디지털배움터 차별화 자료 첨부
- [ ] 시니어 시범 강의 1회 (가족·지인 무료) → 후기 확보

### 강의 후 자산
- 정부지원 신청 시 실적 (강사양성 파일럿과 시너지)
- 시니어 후기 → 다른 정부지원 채널 진입 자료
- 디지털배움터 자체 매출 (2026 NIA 12,000명 강사 예산)

## 채널 간 시너지

```
호오컨설팅 강연 → 후기 + 인지도
                       ↓
인프런 강의 → 학생 후기 + 영구 매출
                       ↓
디지털배움터 → 정부지원 실적 + 시니어 후기
                       ↓
강사양성 2차 차수 통합 → 강사 양성 + 콘텐츠 확산
                       ↓
다른 채널 (정부지원 9채널, uttec-edu, Stage 1~3) 영업 자산
```

**핵심**: 본 2~3h 모듈 1개가 4개 채널을 동시 진입.
