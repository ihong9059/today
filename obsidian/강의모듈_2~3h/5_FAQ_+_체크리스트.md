# FAQ + 강사 사전 준비 체크리스트

## Q&A 10 — 자주 나오는 질문

### Q1. 옵시디언 무료인가요?
**답**:
> 개인용 무료, 상업용도 1인 사업자라면 무료. Sync(클라우드 동기화) 기능만 유료 ($5/월), 대신 iCloud/구글드라이브로 대체 가능.

**부연**: 옵시디언 라이센스는 https://obsidian.md/license 참고.

---

### Q2. Claude Pro $20/월 비싸요. 무료로도 됩니까?
**답**:
> 가능. 무료 Claude도 하루 30~50건 정도 처리 가능. 본격 사용 시 Pro 권장.

**부연**: 본 강의 데모는 모두 Claude Pro 기준이지만, 무료로도 Step 1~3 + Step 6은 충분히 가능.

---

### Q3. Notion vs 옵시디언 차이?
**답**:
> Notion = 클라우드, 데이터는 Notion 회사 소유. 옵시디언 = 로컬, 내 데이터는 내 컴퓨터. **회사 망해도 OK**가 옵시디언의 핵심.

**부연**:
| 항목 | Notion | 옵시디언 |
|---|---|---|
| 저장 | 클라우드 | 로컬 |
| 데이터 소유 | Notion | 본인 |
| 협업 | 강함 | 약함 (1인용) |
| LLM 친화 | 중간 | **강함** |
| 회사 망함 시 | 데이터 위험 | **안전** |

---

### Q4. 내 데이터로 AI 학습되나요?
**답**:
> Claude API 정책 — 학습 안 함 (Anthropic 공식). 다만 매번 처리 시 prompt에 데이터가 포함되어 Anthropic 서버를 거침. 민감 정보는 별도 폴더로 분리하고 Claude에 안 줄 수 있음.

**부연**: 100% 로컬을 원하면 Ollama + 로컬 LLM (성능은 Claude의 50~70% 수준).

---

### Q5. 마크다운 모르는데?
**답**:
> 강의 중 5분이면 익힘. 또한 Claude가 마크다운으로 다 변환해줌. 여러분은 일상 문장으로 입력만 하시면 됩니다.

**부연**: 마크다운 5분 입문 — `# 제목`, `**굵게**`, `- 항목`, `[[링크]]`. 끝.

---

### Q6. 기존 Word/Notion 메모 마이그레이션?
**답**:
> Notion → 옵시디언: Notion의 export 기능 무료 (Markdown 형식 지원). Word → 옵시디언: pandoc으로 변환 또는 Claude에게 던지면 자동 변환.

**부연**:
- Notion: Settings → Export → Markdown & CSV
- Word: `pandoc input.docx -o output.md`
- 카톡: 채팅 export → Claude에게 정리 요청

---

### Q7. 모바일에서도 됩니까?
**답**:
> 옵시디언 모바일 앱 무료 (iOS/Android). Vault는 iCloud/구글드라이브로 동기화. Claude 모바일 앱도 있음.

**부연**: 모바일에서는 음성 입력 활용이 강력. 카톡 음성 → 옵시디언 노트 → Claude 정리 흐름이 시니어 친화.

---

### Q8. 팀 협업?
**답**:
> 1인 권장. 팀은 Notion이 더 적합. 옵시디언은 1인 second-brain 운영에 강점.

**부연**: 팀 옵시디언은 Git + GitHub로 가능하지만 충돌 관리 부담 ↑. 5인 이상이면 Notion 추천.

---

### Q9. 백업?
**답**:
> Git 권장 (GitHub 무료 1인). 또는 클라우드 동기화 (iCloud/구글드라이브). 옵시디언은 단순 폴더라 어떤 백업 도구든 가능.

**부연**:
- Git 워크플로우: `git init` + 매일 `git commit + push` (Claude가 자동화 가능)
- 클라우드 동기화: 폴더를 iCloud/Google Drive 폴더 안에 두면 자동
- 외장 SSD: 매주 1회 수동 백업

---

### Q10. 어디서 시작?
**답**:
> 본 강의 자료의 "5분 만에 시작" 가이드 (3_실습_가이드.md 끝부분). 또는 본 6편 시리즈 1편(`Obsidian_상세설명서.md`)부터 차근차근.

**부연**: 가장 효과적인 시작 — **오늘 미팅 노트 1개부터**. 거대한 시스템 만들기보다 작게 시작.
