## 1. 검토 배경 — 사용자가 본 것

### 1.1 사용자의 통찰
- 사용자(홍광선)는 myWiki + Claude로 **"자연스러운 정리"**를 매일 경험 중
- 그러나 일반인(자영업자·소상공인)은:
  - DB·폴더·형식을 어려워함
  - IT 진입장벽 높음
  - 매일 영업·생산에 바빠 정리 시간 X
  - 그러나 **방향 제시·인사이트·아이디어가 가장 필요한 계층**

### 1.2 시장 공백
- 한국에서 ERP·POS는 많지만 **"사장님의 일기장 + AI 비서"** 시장은 거의 비어있음
- 글로벌에는 mem.ai, Reflect, Notion AI, Mem0 등 등장하나 한국어·자영업 맞춤 없음
- 정부지원(디지털배움터·혁신바우처·K-DT) 흐름 ↑

### 1.3 사용자 자산과의 매칭
- 3.5-Stage 패키지 = 중소기업 IT 인프라 (Stage 0~3)
- 본 검토 플랫폼 = **Stage 0 이전의 "Stage -1"** (자영업자가 IT를 모르는 단계)
- → **사업 라인 확장 + 시장 진입 채널 다변화**

## 3. 솔루션 컨셉 — "사장님의 두 번째 두뇌"

### 3.1 한 문장 정의
> "**음성·사진·짧은 글로 던지면, AI가 자동으로 정리하고 매주 방향을 제시하는 사장님 전용 두뇌**"

### 3.2 사용자 경험 (User Experience)

#### 시나리오 1. 음식점 사장님 (점심 마감 후)
```
[사장님] (스마트폰 음성 한 마디)
"오늘 점심 매출 65만, 김치찌개 23그릇으로 1등, 
 단골 박부장 가족 8명 와서 인당 만 5천 매출, 
 김장 김치 떨어졌고, 김 알바생 2시간 늦게 옴"

         ↓ (AI 자동 처리, 사장님은 끝)

[플랫폼이 자동 분류]
- 매출/일자별: 2026-05-06 점심 65만
- 메뉴/판매: 김치찌개 23, ...
- 단골/방문: 박부장 가족 8명 (단골 #023)
- 재고/필요: 김장 김치 발주
- 직원/이슈: 김 알바생 지각 (3회째)

[일주일 뒤 자동 리포트 (카톡으로 도착)]
"이번 주 매출 320만 (지난주 대비 +12%)
 👍 김치찌개가 지속 1위 — 단가 인상 검토 가치 (다른 식당 8,500원, 사장님 7,000원)
 ⚠️ 김 알바생 지각 4회 — 면담 권장
 💡 박부장 가족 단골 → 단체 예약 할인 제안 SMS 보낼까요?
 📦 김장 김치는 매주 화·금 발주 패턴 — 자동 알림 설정해드릴까요?"
```

#### 시나리오 2. 농업 (3대째 사과 농가)
```
[사장님] (사진 1장 + 음성)
사진: 사과나무 잎 누런 부분
음성: "30번 줄 사과나무 잎이 누렇게 됨, 
       오늘 농약 친 거 5L 썼고, 
       어제 김씨가 일당 12만 받아감"

         ↓

[플랫폼 자동 처리]
- 작업일지: 2026-05-06 농약 살포 5L
- 인건비: 김씨 일당 12만
- 작물 이상: 30번 줄 잎 변색 (사진 첨부)
- AI 분석 (사진): "잎 변색 패턴은 질소 부족 또는 응애 의심"

[자동 제안 (저녁에 카톡)]
"💡 잎 변색 사진 분석 결과 질소 부족 또는 응애 의심
   → 전문가 상담 가능 시간: 농기원 김OO 연구사 02-XXX
   → 작년 같은 시기 사진 비교: 첨부
 📊 이번 달 농약 누적 28L (작년 동기 22L) — 지출 증가 중
 💰 김씨 누적 일당 156만 (이번 달) — 인건비 추적 중"
```

#### 시나리오 3. 미용실 (1인 운영)
```
[사장님] (틈틈이 음성 메모)
"박○○님 단골 컷+염색 5만 받음, 
 며칠 후 다시 오시겠다고, 
 최○○님 커트만 1만 5천, 
 샴푸 거의 떨어짐"

         ↓

[자동 분류 + 다음 주]
"이번 주 매출 47만 (지난주 +8%)
 단골 박OO 재방문 가능성 ↑ (다음 예약 알림 보낼까요?)
 샴푸 발주 자동 등록함 — 이번 주 화요일 도착 예정
 💡 단골 12명 중 6명이 5월 미방문 — 안부 문자 자동 발송 옵션?"
```

### 3.3 핵심 원칙 4가지

1. **0 형식 입력** — 사장님이 적응 불필요. 그냥 말하면 끝
2. **자동 분류** — AI가 매출/재고/직원/단골/일정으로 자동 정리
3. **주간 인사이트** — 사장님은 정리 안 해도 매주 자동 리포트
4. **방향·아이디어 제시** — 단순 기록이 아니라 **"이렇게 해보면 어떠세요?"**

### 3.4 4-Agent 시스템의 자영업 버전

| Layer | myWiki (홍광선) | 자영업 플랫폼 |
|:---:|---------------|--------------|
| Substrate | Obsidian + 마크다운 | 카톡/앱 + 백엔드 마크다운 (사장님 안 봄) |
| Schema | CLAUDE.md (사용자 작성) | **AI가 업종별 자동 schema** (음식점/농업/미용실 등) |
| Agent | Claude (사용자 호출) | **24/7 AI 비서** (자동 분류·리포트·제안) |
| Director | 사용자 (의도 제공) | **사장님 (음성·사진만 던지면 됨)** |

→ 핵심 혁신: **Schema를 AI가 자동 생성**하여 사용자 부담 0.

## 4. 타겟 페르소나 5개

### 4.1 페르소나 A — 음식점 사장님 김미경 (52세)
- **사업**: 한식당 (15년차, 종업원 3명)
- **고민**: 매출이 지난해보다 줄었는데 어디서 새는지 모름
- **현 상태**: 영수증 박스에 모음, 통장 잔고만 봄
- **AI 가치**: "**김치찌개 단가 8,500원이 평균. 사장님 7,000원**" 같은 즉답
- **결제 의향**: 월 1.5~2만원

### 4.2 페르소나 B — 사과 농가 박철수 (58세)
- **사업**: 사과 과수원 3대째 (3,000평)
- **고민**: 작년 대비 수확량·지출이 어떻게 변했는지 종이 노트로 추적
- **현 상태**: 농업기술센터 보고서 받지만 자기 농장 데이터 매칭 어려움
- **AI 가치**: "**작년 같은 시기 대비 농약 +28% — 응애 발생 추세 가능성**"
- **결제 의향**: 월 1만원 (정부지원 활용 시 확장)

### 4.3 페르소나 C — 미용실 원장 이지혜 (38세)
- **사업**: 1인 미용실 (5년차, 단골 80명)
- **고민**: 단골 관리 + 예약 관리 + 재료 발주 동시에 못 함
- **현 상태**: 카카오톡 채널 + 종이 예약장
- **AI 가치**: "**단골 12명이 1개월 미방문 — 안부 메시지 자동 발송**"
- **결제 의향**: 월 2만원

### 4.4 페르소나 D — 편의점주 정태식 (45세)
- **사업**: 편의점 가맹점 (2년차, 종업원 4명)
- **고민**: 본사 시스템(POS)는 매출만, 직원 관리·재고 패턴 모름
- **현 상태**: 본사 앱 + 메모지 + 머리
- **AI 가치**: "**오후 9~11시 매출 30%, 야간 직원 효율 분석**"
- **결제 의향**: 월 2만원

### 4.5 페르소나 E — 카페 오너 박지영 (32세)
- **사업**: 1인 카페 (3년차)
- **고민**: SNS 마케팅·메뉴 개발·재고·고객 동시에
- **현 상태**: 인스타그램 + 머릿속
- **AI 가치**: "**금요일 저녁 매출 +35% — 금요일 한정 메뉴 어떨까요?**"
- **결제 의향**: 월 1.5만원

### 4.6 공통 페인 포인트
- 매일 영업·생산에 바빠서 **정리할 시간 0**
- 데이터는 머리·종이·여러 앱에 흩어짐
- **"왜 이번 달이 안 좋은지" 추적 불가**
- 외부 컨설턴트는 비싸고 자기 데이터 모름
- 큰 ERP는 과도하고 어렵고 비쌈

## 6. 차별화 — "한국 자영업자만의 AI 비서"

### 6.1 5대 차별화 포인트

| 포인트 | 의미 | 경쟁사 대비 |
|-------|------|------------|
| **1. 한국어 voice-first** | 사장님이 한국어로 말하면 끝 | 글로벌 도구 = 영어 우선 |
| **2. 업종별 schema 자동** | 음식점·농업·미용실 등 자동 분류 | mem.ai = 일반 노트 |
| **3. 데이터 영구 소유** | 사장님 PC/폰에 저장, 회사 망해도 OK | Notion = 회사 호스팅 |
| **4. 클라우드 옵션** | 인터넷 없는 농촌도 사용 가능 | 대부분 = 클라우드 필수 |

## 9. 차별화 핵심 — Schema 자동화

### 9.1 일반 PKM과의 차이
- 일반: 사용자가 schema(폴더·태그) 만들어야 함 → 진입장벽 높음
- 본 플랫폼: **AI가 업종 첫 인식 후 자동 schema 적용**

### 9.2 업종별 표준 Schema (사전 정의)

#### 음식점 schema (예시)
```yaml
fields:
  - 매출/일자/시간대 (자동 추출)
  - 메뉴/판매수량/단가
  - 단골/예약/방문
  - 재고/발주
  - 직원/근태/급여
  - 식자재/단가/협력업체
ai_questions_weekly:
  - "이번 주 가장 잘 팔린 메뉴?"
  - "재고 떨어진 항목 알림"
  - "단골 미방문 N일 이상 → 안부?"
ai_directions_monthly:
  - 매출 트렌드 + 원인 분석
  - 메뉴 단가 시장 비교
  - 직원 효율
```

#### 농업 schema (예시)
```yaml
fields:
  - 작업일지/날짜/내용
  - 농약·비료/종류/양/지출
  - 인건비/일꾼/일당
  - 수확량/판매처/단가
  - 작물 이상/사진/대응
ai_questions_weekly:
  - 작년 동기 비교
  - 비용 트렌드
  - 작물 이상 경고
ai_directions_monthly:
  - 시장 가격 + 출하 타이밍
  - 다음 작기 계획
```

→ **20~30개 업종 schema 사전 정의** + 사용 중 자동 학습.

### 9.3 4-Agent 시스템의 단순화

| myWiki | 본 플랫폼 |
|--------|----------|
| 사용자가 CLAUDE.md 작성 | **AI가 업종 인식 후 자동 schema 적용** |
| 사용자가 폴더·링크 관리 | **백엔드에서 자동, 사장님 안 봄** |
| 사용자가 Claude 호출 | **24/7 자동 + 카톡으로 결과 도착** |
| 사용자가 방향 제시 | **AI가 방향 제안 → 사장님이 채택/거부** |

→ Director 역할까지 AI가 일부 보조. **진입 장벽 0**.

## 10. 단계별 진행 계획

### 10.1 Phase 0 — 컨셉 검증 (즉시 ~ 2주, 비용 0)

**목표**: 한 사장님이 실제로 가치를 느끼는지

- [ ] 베타 사용자 1명 확보 (사용자 지인 음식점 사장님)
- [ ] 카톡 채널 1:1 운영 (수동 시뮬레이션)
- [ ] 사용자가 매일 음성 보냄 → Claude로 수동 정리 → 주간 리포트
- [ ] 2주 후 평가:
  - 사장님이 "이거 돈 내고도 쓰고 싶다" 했나?
  - 어떤 정보가 가장 가치 있었나?
  - 어떤 정보가 노이즈였나?

**산출**: Phase 1 가/부 결정

### 10.2 Phase 1 — MVP (1~3개월)

**목표**: 자동화된 시스템으로 5명 운영

- [ ] 카톡 챗봇 자동화 (n8n + Claude API)
- [ ] 음식점 schema 1차 정의
- [ ] 주간 리포트 자동 발송
- [ ] 5명 베타 (음식점 3 + 미용실 1 + 카페 1)
- [ ] 월 1회 사용자 인터뷰
- [ ] 비용 분석 (사용자당 API 비용 측정)

**산출**: 정식 출시 가능 여부 + 가격 결정

### 10.3 Phase 2 — 다업종 확장 (3~6개월)

**목표**: 20~50명, 5개 업종 schema

- [ ] 업종 schema: 음식점·농업·미용실·카페·소매·편의점·세탁소·의류
- [ ] 모바일 PWA (앱 다운로드 없이 카톡에서 시작)
- [ ] Free → Lite 전환 funnel 설계
- [ ] 사용자 추천 프로그램 (소상공인 입소문)
- [ ] 정부지원 채널 1차 진입 (디지털배움터 시범 강사)

**산출**: 월 매출 50~200만원

### 10.4 Phase 3 — 정식 출시 (6~12개월)

**목표**: 200~500명 + 협회 1~2건

- [ ] 정식 브랜드 런칭
- [ ] 소상공인진흥공단 바우처 등록
- [ ] 협회·조합 1~2건 (음식점 협회, 농협 등)
- [ ] 강사양성 파일럭 + 본 플랫폼 통합 (강사들이 영업 채널)
- [ ] 미디어·SNS 마케팅 (사장님 사례 인터뷰)

**산출**: 월 매출 500만~2,000만

### 10.5 Phase 4 — 확장 (1~2년)

**목표**: 5,000~20,000명 + B2B 5~10건

- [ ] 외주 인력 채용 (CS·마케팅 1~2명)
- [ ] B2B 진출: 협회·조합·지자체·금융권
- [ ] 정부지원 정식 채널 (혁신바우처·K-DT)
- [ ] 일본·동남아 진출 검토 (한국형 자영업 플랫폼 수출)

**산출**: 연 매출 5억~15억

### 10.6 진행 조건 (Go/No-Go 판단)

| 단계 | Go 조건 | No-Go 조건 |
|------|--------|-----------|
| Phase 0 → 1 | 베타 사용자 "돈 내고 쓰고 싶음" | 가치 못 느낌 |
| Phase 1 → 2 | 5명 중 3명 이상 유지 + 추천 의향 ≥ 50% | 이탈률 50%↑ |
| Phase 2 → 3 | 월 매출 100만 + Churn < 10% | API 비용 > 매출 |
| Phase 3 → 4 | 협회 도입 1건 이상 + 손익분기 | 1년 손실 누적 |

## 14. 강사양성 파일럭과의 통합 전략

### 14.1 시너지 구조
- **강사양성 파일럭** = 5일간 강사 양성 (현재 06-15~19 가설정)
- 강사들에게 **본 플랫폼 무료 권한 + 영업 권한** 부여
- 강사들이 자기 지역 자영업자에게 영업 → **분산 채널**

### 14.2 강사 인센티브 모델 (제안)
- 강사가 사장님 1명 신규 가입 시 → 첫 3개월 50% 강사 수익
- 강사가 협회 1건 도입 시 → 30% 매출 분배
- → 강사들이 자발적 영업

### 14.3 파일럭 콘텐츠 추가
- Day 4 옵시디언 워크숍 + **본 플랫폼 시연**
- "여러분이 옵시디언으로 운영하는 방식을, 자영업자에게는 카톡으로 제공" 메시지
- → 강사양성 차별화 + 본 플랫폼 영업 채널 확보

## 16. 결론

### 16.1 가능성 — **YES, 매우 높음**
- 시장 공백 명확 (한국어 + 자영업자 + 자연어 입력)
- 기술 가능 (LLM production grade)
- 사용자 자산 압도적 (4-Agent 노하우 + 영업 매트릭스 + 자동화)
- 정부지원 채널 풍부

### 16.2 사용자 적합도 — **최상위**
- 사용자 사업 후보 중 가능성 23/25 — 1위
- 다른 누가 하더라도 사용자만큼 빠르게 시작 X
- 기존 사업과 시너지 (3.5-Stage 패키지 funnel)

### 16.3 진행 권고 — **단계적, 즉시 시작**
- Phase 0 (2주) 비용 거의 0, 학습 가치 ↑
- Phase 1까지 Stage 0~3 영업과 병행 가능
- Phase 2부터 본격 투자 결정

### 16.4 다음 질문 (사용자 결정용)

1. **베타 사용자 1명 후보가 있는가?** (가족·지인·고객 중 음식점·미용실·카페 등)
2. **Phase 0(2주) 시작에 동의하는가?** (비용 거의 0, 시간 주 5시간 내외)
3. **본 플랫폼이 3.5-Stage 패키지에 Stage -1로 추가되는 것에 동의?**
4. **강사양성 파일럭 Day 4에 본 플랫폼 시연 추가?**
5. **디지털배움터 진입 시 본 플랫폼을 차별화 요소로?**

## 17. 부록 A — Phase 0 베타 운영 가이드 (즉시 사용 가능)

### 17.1 사장님에게 보낼 첫 메시지 (예시)
```
안녕하세요 사장님,
홍광선입니다.

저는 평소 작업 내용을 카톡 음성으로 1~3분씩 던져두면, 
일주일 뒤에 "이번 주 어떻게 갔는지, 무엇을 해보면 좋을지" 
요약을 받는 시스템을 운영 중입니다.

이걸 사장님 가게에 적용해보면 어떨지 무료로 2주 시범 운영 제안드립니다.
- 매일 1~3분: 사장님이 카톡 음성 보내주시기 (오늘 매출, 잘 팔린 메뉴, 단골, 직원 등 떠오르는 거 아무거나)
- 매주 금요일: 제가 정리해서 사장님께 보내드림
- 2주 후: "이거 도움 됐나" 30분 미팅

비용 0, 사장님 데이터는 100% 사장님 소유.
시작해보시겠어요?
```

### 17.2 사장님 음성 예시 (사장님이 보내는 형태)
```
"오늘 점심 매출 65만,
김치찌개 23그릇으로 1등,
박부장 가족 8명 와서 단가 1만 5천,
김장 김치 다 떨어졌고,
김씨 알바 2시간 늦었음."
```

### 17.3 Claude로 처리하는 방법 (사용자 측, 매일)
```
1. 사장님 음성 → Whisper로 텍스트 변환
2. Claude에게 다음 프롬프트:

"다음은 음식점 사장님의 일일 운영 메모이다.
[원문 붙여넣기]

이를 다음 카테고리로 자동 분류해주세요:
- 매출 (일자/시간대/총액)
- 메뉴 (이름/판매수/단가)
- 단골/고객 (이름/방문/특징)
- 직원 (이름/이슈)
- 재고/발주
- 기타

마크다운 형식으로 출력하고, 
이전 데이터([이전 누적 파일])와 비교해서 
주목할 패턴이 있으면 별도 섹션에 표시."

3. 결과를 사장님 별 마크다운 파일에 누적 저장
```

### 17.4 주간 리포트 생성 (매주 금요일)
```
"다음은 음식점 사장님의 1주일 운영 데이터이다.
[1주일 누적 마크다운 붙여넣기]

다음을 포함한 카톡 발송용 주간 리포트를 작성해주세요:
1. 매출 요약 (지난주 대비 비교)
2. 메뉴 베스트/워스트
3. 단골 동향
4. 직원 이슈
5. 💡 사장님이 다음 주 시도해볼만한 것 1~3가지 (시장가격 비교, 단골 관리, 메뉴 개선 등)

톤: 친근하고 짧게. 카톡 1~2 메시지 분량."
```

### 17.5 2주 후 사장님 인터뷰 질문
1. 카톡으로 보내는 게 부담스럽지 않았나?
2. 받은 리포트 중 가장 도움 된 것은?
3. 노이즈였던 것은?
4. 한 달에 얼마면 돈 내고 쓰겠나?
5. 주변에 추천하겠나?
6. 어떤 기능이 더 있으면 좋겠나?
