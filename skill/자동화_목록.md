### 사용자 레벨 Hook

위치: `C:\Users\lenovo\.claude\settings.local.json`

| 이벤트 | 대상 | 스크립트 | 설명 |
|--------|------|----------|------|
| PreToolUse | 모든 도구 | (내장 beep) | 도구 실행 전 알림 비프음 (1000→1200→1500 Hz) |
| PreToolUse | Write, Edit | `gsd-prompt-guard.js` | 프롬프트 인젝션 패턴 감지 (경고만, 차단 안 함) |
| PostToolUse | Bash, Edit, Write 등 | `gsd-context-monitor.js` | 컨텍스트 윈도우 사용량 모니터링 (35% 이하 WARNING, 25% 이하 CRITICAL) |
| SessionStart | 모든 | `gsd-check-update.js` | GSD 프레임워크 업데이트 확인 |
| Stop | 모든 | (내장 beep) | 작업 완료 시 알림 비프음 |
| StatusLine | - | `gsd-statusline.js` | 상태바에 모델/태스크/디렉토리/컨텍스트 실시간 표시 |

## 5. 자동화 흐름도

```
[세션 시작]
  ├── SessionStart Hook → 작업보고서 자동 생성
  ├── GSD Update Check → 프레임워크 업데이트 확인
  └── /work-start → git pull + 세션 복원 + 할일 표시

[작업 중]
  ├── PreToolUse Hook → 비프음 + 프롬프트 인젝션 감지
  ├── PostToolUse Hook → 컨텍스트 사용량 모니터링
  ├── StatusLine Hook → 상태바 실시간 업데이트
  ├── /wiki-log → wiki 작업 수시 기록
  └── 기타 Skills → 필요 시 호출

[작업 종료]
  ├── /work-end → 세션 저장 + 작업보고서 + wiki 마무리 + git commit
  └── Stop Hook → 완료 비프음

[Git 커밋]
  ├── pre-commit → 50MB 초과 파일 차단
  └── Git LFS → 대용량 파일 처리
```
