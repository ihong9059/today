# 로봇 제어 통신 프로토콜 비교 평가서

> EtherCAT과 경쟁하는 주요 실시간 산업용 이더넷 프로토콜 심층 분석

---

## 1. Executive Summary

2024년 기준 산업용 이더넷이 전체 신규 설치 노드의 **71%**를 차지하며, 기존 필드버스(22%)를 완전히 압도하고 있다. 로봇 제어 분야에서 EtherCAT이 성능 면에서 우위를 점하고 있으나, PROFINET, EtherNet/IP, SERCOS III, CC-Link IE TSN 등이 각자의 생태계와 강점을 바탕으로 경쟁 중이다.

### 시장 점유율 (2024, HMS Networks)

| 프로토콜 | 점유율 | 설치 노드 |
|----------|--------|----------|
| **PROFINET** | 23% | 60M+ |
| **EtherNet/IP** | 21% | - |
| **EtherCAT** | 16% | 35M+ |
| CC-Link | - | 아시아 강세 |
| Modbus TCP | - | 레거시 |

## 2. 주요 프로토콜 상세 분석

### 2.1 EtherCAT (Ethernet for Control Automation Technology)

**개발**: Beckhoff Automation (2003)
**표준**: IEC 61158, IEC 61784

#### 기술 사양

| 항목 | 사양 |
|------|------|
| 사이클 타임 | **< 100 µs** (50µs 가능) |
| 동기화 정밀도 | **< 100 ns** (DC 모드) |
| 지터 | **< 1 µs** (일반적으로 ns 수준) |
| 대역폭 | 100 Mbps |
| 토폴로지 | 라인, 트리, 스타 (스위치 불필요) |
| 최대 노드 | 65,535 |

#### 동작 원리: Processing on-the-fly

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    EtherCAT Frame Processing                             │
└─────────────────────────────────────────────────────────────────────────┘

  ┌──────────┐                                              ┌──────────┐
  │  Master  │──── Ethernet Frame ────►                     │  Master  │
  │          │                         │                    │          │
  └──────────┘                         │                    └──────────┘
                                       ▼                          ▲
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐   │
  │ Slave 1  │───►│ Slave 2  │───►│ Slave 3  │───►│ Slave N  │───┘
  │          │    │          │    │          │    │          │
  │ Read/    │    │ Read/    │    │ Read/    │    │ Read/    │
  │ Write    │    │ Write    │    │ Write    │    │ Write    │
  │ on-fly   │    │ on-fly   │    │ on-fly   │    │ on-fly   │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘

  * 프레임이 각 슬레이브를 통과하면서 데이터 읽기/쓰기 수행
  * 별도의 스위치 없이 하드웨어 레벨에서 처리
  * Distributed Clock으로 나노초 수준 동기화
```

#### 장점
- **최고 성능**: 모션 제어에 최적화된 가장 빠른 프로토콜
- **낮은 비용**: 스위치 불필요, 저렴한 슬레이브 ASIC
- **개방성**: 10배 이상 많은 서보 드라이브/IO 공급업체 지원
- **유연성**: 다양한 토폴로지 지원

#### 단점
- **마스터 복잡성**: 소프트웨어 마스터 구현 난이도
- **케이블링**: 라인 토폴로지 시 케이블 길이 증가
- **기존 인프라**: Siemens 생태계와 통합 시 추가 작업 필요

#### 로봇 적용 사례
- Boston Dynamics Atlas (Petman의 CAN에서 전환)
- LOLA 휴머노이드 (4 kHz 업데이트)
- TOCABI 휴머노이드 (듀얼 채널, 4 kHz)

### 2.2 PROFINET IRT (Isochronous Real-Time)

**개발**: Siemens, PROFIBUS & PROFINET International (PI)
**표준**: IEC 61158, IEC 61784

#### 기술 사양

| 항목 | 사양 |
|------|------|
| 사이클 타임 | **250 µs ~ 1 ms** (IRT: < 250 µs) |
| 동기화 정밀도 | **< 1 µs** |
| 지터 | **< 1 µs** |
| 대역폭 | 100 Mbps / 1 Gbps |
| 토폴로지 | 스타, 트리, 라인 (스위치 필요) |
| 최대 노드 | 이론상 무제한 |

#### PROFINET 등급 체계

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    PROFINET Performance Classes                          │
└─────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
  │   PROFINET RT   │   │  PROFINET IRT   │   │ PROFINET w/TSN  │
  │   (Real-Time)   │   │  (Isochronous)  │   │   (Future)      │
  ├─────────────────┤   ├─────────────────┤   ├─────────────────┤
  │ Cycle: 1-10ms   │   │ Cycle: <250µs   │   │ Cycle: <100µs   │
  │ Standard SW     │   │ Special HW      │   │ TSN Integration │
  │ I/O Control     │   │ Motion Control  │   │ IT/OT 융합       │
  │                 │   │ Robotics        │   │                 │
  └─────────────────┘   └─────────────────┘   └─────────────────┘
         ▲                     ▲                     ▲
         │                     │                     │
    일반 자동화            모션 제어            차세대 통합
```

#### 장점
- **Siemens 생태계**: TIA Portal, S7 PLC와 완벽 통합
- **글로벌 1위**: 최대 시장 점유율, 광범위한 지원
- **확장성**: 1 Gbps, 10 Gbps 업그레이드 용이
- **IT 친화적**: 표준 이더넷 인프라 활용

#### 단점
- **비용**: IRT용 특수 스위치/ASIC 필요 → 가장 비싼 옵션
- **성능 한계**: EtherCAT 대비 사이클 타임, 지터 열위
- **복잡성**: IRT 설정 및 도메인 구성 복잡

#### 로봇 적용 사례
- Siemens/KUKA 통합 시스템
- 자동차 생산라인 용접 로봇
- 유럽/중동 지역 주도적 사용

### 2.3 EtherNet/IP + CIP Motion

**개발**: ODVA (Open DeviceNet Vendors Association)
**표준**: IEC 61158, IEC 61784

#### 기술 사양

| 항목 | 사양 |
|------|------|
| 사이클 타임 | **1 ms** (CIP Motion) |
| 동기화 정밀도 | **±100 ns** (CIP Sync) |
| 지터 | 중간 |
| 대역폭 | 100 Mbps / 1 Gbps / 10 Gbps |
| 토폴로지 | 표준 이더넷 (스위치 사용) |
| 최대 축 | 100축 @ 1ms 업데이트 |

#### 시간 기반 동기화 방식

```
┌─────────────────────────────────────────────────────────────────────────┐
│                 CIP Motion Time-Based Control                            │
└─────────────────────────────────────────────────────────────────────────┘

  전통적 방식 (EtherCAT, PROFINET IRT):
  ┌─────────┐    명령    ┌─────────┐
  │ Master  │──────────►│ Drive   │  → 즉시 실행
  └─────────┘           └─────────┘

  CIP Motion 방식:
  ┌─────────┐  명령+시간  ┌─────────┐
  │ Master  │──────────►│ Drive   │  → 지정 시간에 실행
  └─────────┘  (T=100ms) └─────────┘
                              │
                              ▼
                    ┌──────────────────┐
                    │ IEEE 1588 기반    │
                    │ CIP Sync 동기화   │
                    │ 네트워크 결정론    │
                    │ 요구 제거          │
                    └──────────────────┘
```

#### 장점
- **북미 시장 지배**: Rockwell Automation 생태계
- **표준 이더넷**: 100% 표준 호환, 특수 하드웨어 불필요
- **확장성**: 기가비트/10기가비트 쉬운 업그레이드
- **통합 플랫폼**: 모션 + 안전 + I/O + 로봇 단일 네트워크

#### 단점
- **성능 제한**: 모션 제어 성능 최하위
- **CIP Motion 필요**: 기본 EtherNet/IP는 동기화 약함
- **비용**: CIP Motion 구현 시 추가 비용

#### 로봇 적용 사례
- Rockwell/Fanuc 통합 시스템
- 북미 자동차 공장
- 물류 자동화 (AMR 통합)

### 2.4 SERCOS III

**개발**: Sercos International (Bosch Rexroth 주도)
**표준**: IEC 61158, IEC 61784

#### 기술 사양

| 항목 | 사양 |
|------|------|
| 사이클 타임 | **31.25 µs ~ 65 ms** |
| 동기화 정밀도 | **< 20 ns** (하드웨어 기반) |
| 지터 | **< 100 ns** |
| 대역폭 | 100 Mbps (풀 듀플렉스) |
| 토폴로지 | 라인, 링 (스위치 불필요) |
| 안전 | SIL 3 (IEC 61508) |

#### SERCOS 진화

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      SERCOS Evolution                                    │
└─────────────────────────────────────────────────────────────────────────┘

  1991           1999           2003           현재/미래
    │              │              │              │
    ▼              ▼              ▼              ▼
┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────────┐
│SERCOS I │─►│SERCOS II│─►│SERCOS III─►│SERCOS + TSN │
│         │  │         │  │         │  │             │
│ 광섬유  │  │ 2Mbps   │  │ 100Mbps │  │ 기존 장치   │
│ 전용    │  │ 광섬유  │  │ 이더넷  │  │ TSN 통합    │
└─────────┘  └─────────┘  └─────────┘  └─────────────┘
                              │
                              ▼
                    서보 드라이브 전문
                    CNC 기계 최적화
```

#### 장점
- **서보 전문**: 모션 제어 분야 최초의 실시간 버스
- **최고 동기화**: 하드웨어 기반 20ns 이하 동기화
- **안전 통합**: SIL 3 기본 지원
- **Hot Plugging**: 운전 중 노드 추가/제거

#### 단점
- **시장 점유율**: EtherCAT 대비 10분의 1 채택률
- **비용**: 중간 수준 하드웨어 비용
- **생태계 제한**: Bosch Rexroth 중심

#### 로봇 적용 사례
- CNC 공작기계
- 고정밀 서보 시스템
- 독일 제조업 설비

### 2.5 POWERLINK (EPL)

**개발**: B&R Automation (2001), 현재 B&R 단독 관리 (2023~)
**표준**: IEC 61158, IEC 61784, IEEE 61158

#### 기술 사양

| 항목 | 사양 |
|------|------|
| 사이클 타임 | **200 µs** (소프트웨어 기반) |
| 동기화 정밀도 | **±100 ns** |
| 지터 | **< 1 µs** |
| 대역폭 | 100 Mbps |
| 토폴로지 | 스타, 트리, 데이지 체인 |
| 안전 | openSAFETY (IEC 61508) |

#### POWERLINK 통신 모델

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    POWERLINK Communication Cycle                         │
└─────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────┐
    │                      Isochronous Phase                            │
    │ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                     │
    │ │ SoC  │ │PReq/1│ │PReq/2│ │ ...  │ │PReq/N│                     │
    │ │      │ │PRes/1│ │PRes/2│ │      │ │PRes/N│                     │
    │ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘                     │
    └──────────────────────────────────────────────────────────────────┘
    ┌──────────────────────────────────────────────────────────────────┐
    │                      Asynchronous Phase                           │
    │ ┌──────────────────────────────────────────────────────────────┐ │
    │ │        Standard TCP/IP, UDP Traffic                          │ │
    │ └──────────────────────────────────────────────────────────────┘ │
    └──────────────────────────────────────────────────────────────────┘

    * SoC: Start of Cycle (동기화 시작)
    * PReq: Poll Request (마스터 → 슬레이브)
    * PRes: Poll Response (슬레이브 → 마스터)
    * Poll Response Chaining: 로봇 응용에 최적화
```

#### 장점
- **순수 소프트웨어**: 특수 하드웨어 불필요
- **Hot Plugging**: 네트워크 재부팅 없이 노드 관리
- **로봇 최적화**: Poll Response Chaining 모드
- **개방형 안전**: openSAFETY 표준

#### 단점
- **B&R 종속**: 2023년 이후 B&R 단독 관리
- **성능**: EtherCAT, SERCOS III 대비 열위
- **시장 제한**: 주로 B&R 장비에서 사용

#### 로봇 적용 사례
- B&R 통합 로봇 시스템
- 포장 기계
- 플라스틱 사출 성형기

#### 장점
- **기가비트 기본**: 유일하게 1Gbps 기본 지원
- **TSN 네이티브**: 최신 IEEE TSN 표준 통합
- **아시아 강세**: 일본, 한국, 중국 제조업
- **완전 통합**: Mitsubishi PLC, 서보, 로봇

#### 단점
- **지역 제한**: 아시아 외 점유율 낮음
- **Mitsubishi 중심**: 타사 통합 제한적
- **상대적 신기술**: TSN 버전은 아직 성숙 단계

#### 로봇 적용 사례
- Mitsubishi MELFA 로봇
- 일본/한국 반도체 공장
- 아시아 자동차 생산라인

## 3. 종합 성능 비교

### 3.1 정량적 비교표

| 프로토콜 | 사이클 타임 | 동기화 정밀도 | 지터 | 비용 | 시장 점유율 |

| **EtherCAT** | **< 100 µs** | **< 100 ns** | **< 100 ns** | **낮음** | 16% |
| **SERCOS III** | 31.25 µs~ | **< 20 ns** | **< 100 ns** | 중간 | 낮음 |
| PROFINET IRT | 250 µs~ | < 1 µs | < 1 µs | **높음** | **23%** |
| EtherNet/IP | 1 ms~ | ±100 ns | 중간 | 중간 | 21% |
| POWERLINK | 200 µs~ | ±100 ns | < 1 µs | 낮음 | 낮음 |
| CC-Link IE TSN | 설정가능 | IEEE 1588 | TSN 기반 | 중간 | 아시아 강세 |

### 3.2 성능 티어 분류

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    Performance Tier Classification                       │

  Tier 1: Ultra High Performance (< 100 µs, < 100 ns sync)
  ┌─────────────────────────────────────────────────────────────────────┐
  │  EtherCAT          │  SERCOS III                                    │
  │  - 50-100 µs       │  - 31.25 µs 최소                               │

  └─────────────────────────────────────────────────────────────────────┘

  Tier 2: High Performance (250 µs ~ 1 ms)
  ┌─────────────────────────────────────────────────────────────────────┐
  │  PROFINET IRT      │  POWERLINK         │  CC-Link IE TSN          │
  │  - 250 µs~         │  - 200 µs~         │  - 1 Gbps 대역폭         │
  │  - Siemens 생태계  │  - B&R 생태계      │  - TSN 통합              │
  └─────────────────────────────────────────────────────────────────────┘

  Tier 3: Standard Performance (1 ms+)
  ┌─────────────────────────────────────────────────────────────────────┐
  │  EtherNet/IP + CIP Motion                                           │
  │  - 1 ms 사이클                                                      │
  │  - 표준 이더넷 인프라                                               │
  │  - Rockwell 생태계                                                  │
  └─────────────────────────────────────────────────────────────────────┘
```

3. **EtherNet/IP**: 중간 (표준 인프라, 라이선스 비용)
4. **SERCOS III**: 중간-높음
5. **CC-Link IE TSN**: 중간-높음
6. **PROFINET IRT**: 최고 (IRT 스위치, ASIC)

## 8. 결론

### 핵심 요약

1. **성능 측면**: EtherCAT과 SERCOS III가 **Tier 1 성능**을 제공하며, 로봇 제어에 최적화
2. **시장 측면**: PROFINET이 점유율 1위지만, **모션 제어에서는 EtherCAT이 우위**
3. **비용 측면**: EtherCAT이 **가격 대비 성능 최고**
4. **미래 방향**: 모든 프로토콜이 **TSN 융합**으로 수렴 중

### 최종 평가

로봇 제어 분야에서 **EtherCAT이 사실상의 표준**으로 자리잡았으며, 이는:
- 10배 이상의 공급업체 지원
- 최저 비용으로 최고 성능
- 유연한 토폴로지와 쉬운 확장성

기존 Siemens/Rockwell 생태계 사용자는 각각 PROFINET IRT/EtherNet/IP를 유지하되, 신규 프로젝트에서는 **EtherCAT 또는 TSN 기반 솔루션**을 고려하는 것이 바람직하다.
