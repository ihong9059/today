이 프로젝트(`C:/todo/today`)에는 작업 시작과 종료를 자동화하는 2개의 skill이 설정되어 있습니다.

## 사용 절차

### 1. 작업 시작 시 (`/work-start`)

```
사용자: /work-start
```

또는 Claude에게 직접 요청:
```
사용자: 작업 시작해줘
```

**Claude가 수행하는 작업:**

1. `git pull` 실행하여 최신 상태로 동기화
2. 최근 작업보고서 검토 (어제 완료/미완료 사항 파악)
3. 오늘 날짜 작업보고서 확인
   - 있으면: 내용 표시
   - 없으면: 새로 생성 (어제 미완료 + 오늘 할일 포함)
4. 오늘 할일 목록 표시
5. 어떤 작업부터 시작할지 질문

---

### 2. 작업 종료 시 (`/work-end`)

```
사용자: /work-end
```

또는 Claude에게 직접 요청:
```
사용자: 작업 마무리해줘
사용자: 커밋하고 푸시해줘
```

**Claude가 수행하는 작업:**

1. 이번 세션 작업 내용 정리
2. 작업보고서 업데이트
   - 할일 상태 변경 (⬜ → ✅)
   - 작업 내용 상세 기록
   - 세션 요약 작성
3. Git 커밋 절차 (사용자 확인 필수)
   - `git status` → 변경 파일 확인
   - `git diff --stat` → 변경 내용 확인
   - 사용자 승인 요청
   - `git add` → `git commit` → `git push`
4. 완료율 및 내일 작업 안내

## 기존 방식과의 비교

### 기존 방식 (수동)
```
사용자: start.md 파일 내용 복사해서 입력
사용자: (작업 진행)
사용자: end.md 파일 내용 복사해서 입력
```

### Skill 사용 방식 (자동화)
```
사용자: /work-start
사용자: (작업 진행)
사용자: /work-end
```

---

## 주의사항

1. **Git 커밋 시 반드시 사용자 확인 필요**
   - Claude가 자동으로 커밋하지 않음
   - 변경 내용을 보여주고 승인받은 후 진행

2. **작업보고서 형식 유지**
   - 파일명: `YYYY-MM-DD_작업보고서.md`
   - 위치: `작업보고서/` 폴더

3. **Skill은 이 프로젝트에서만 동작**
   - `.claude/skills/` 폴더가 프로젝트 내부에 있음
   - 다른 폴더에서 작업 시 적용되지 않음
